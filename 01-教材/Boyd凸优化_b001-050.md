一个 mathematical optimization problem（数学优化问题，或简称 optimization problem，优化问题）具有如下形式：

```math
\text{minimize}\quad f_0(x) \qquad \text{subject to}\quad f_i(x) \le b_i,\; i = 1,\dots,m. \tag{1.1}
```

这里向量 $x = (x_1,\dots,x_n)$ 是问题的 optimization variable（优化变量），函数 $f_0:\mathbb{R}^n \to \mathbb{R}$ 是 objective function（目标函数），函数 $f_i:\mathbb{R}^n\to\mathbb{R},\; i=1,\dots,m$ 是（不等式）constraint functions（约束函数），常数 $b_1,\dots,b_m$ 是约束的 limits（限制）或 bounds（界）。如果一个向量 $x^\star$ 在所有满足约束的向量中具有最小的目标值，就称它为 optimal（最优的），或问题 (1.1) 的 solution（解）：即对任意满足 $f_1(z)\le b_1,\dots,f_m(z)\le b_m$ 的 $z$，都有 $f_0(z)\ge f_0(x^\star)$。

我们通常研究的是以目标函数和约束函数的特定形式为特征的一族或一类优化问题。一个重要的例子：若 (1.1) 中目标函数与约束函数 $f_0,\dots,f_m$ 都是 linear（线性的），即满足

```math
f_i(\alpha x + \beta y) = \alpha f_i(x) + \beta f_i(y) \tag{1.2}
```

对所有 $x, y\in\mathbb{R}^n$ 与所有 $\alpha,\beta\in\mathbb{R}$ 成立，则该优化问题称为 linear program（线性规划）。若优化问题不是线性的，则称为 nonlinear program（非线性规划）。



本书讨论的是一类称为 convex optimization problems（凸优化问题）的优化问题。凸优化问题是指目标函数与约束函数都是 convex（凸）的问题，也就是说它们满足不等式

```math
f_i(\alpha x + \beta y) \le \alpha f_i(x) + \beta f_i(y)
```

对所有 $x, y\in\mathbb{R}^n$ 以及满足 $\alpha+\beta=1,\;\alpha\ge 0,\;\beta\ge 0$ 的 $\alpha,\beta\in\mathbb{R}$ 成立。比较 (1.3) 与 (1.2) 可以看到：convexity（凸性）比 linearity（线性）更一般——不等式取代了限制更强的等式，而且不等式只须对特定的 $\alpha,\beta$ 取值成立。既然任何 linear program 都是凸优化问题，我们可以把 convex optimization（凸优化）看作 linear programming（线性规划）的推广。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">1.1.1 Applications（应用）</span>

优化问题 (1.1) 是「从 $\mathbb{R}^n$ 中一组候选选择里做出最优决策」这一问题的抽象。变量 $x$ 代表所做的选择；约束 $f_i(x)\le b_i$ 代表限制可能选择的硬性要求或规格；目标值 $f_0(x)$ 代表选择 $x$ 的 cost（代价）。（我们也可以把 $-f_0(x)$ 看作选择 $x$ 的 value（价值）或 utility（效用）。）优化问题 (1.1) 的解，对应的就是在所有满足硬性要求的选择中代价最小（或效用最大）的那个选择。

例如在 portfolio optimization（投资组合优化）中，我们要把一笔资金以最佳方式投资到 $n$ 种资产上。变量 $x_i$ 表示对第 $i$ 种资产的投资额，于是向量 $x\in\mathbb{R}^n$ 描述了整个投资组合在资产集合上的 allocation（配置）。约束可以表示：预算上限（即总投资额的限制）、投资额非负的要求（假设不允许 short positions（空头头寸））、以及整个组合 expected return（期望收益）的最低可接受值。目标函数（成本函数）可以是组合收益的整体 risk（风险）或 variance（方差）的度量。此时优化问题 (1.1) 对应的就是：在所有满足硬性要求的配置中，选择风险最小的投资组合配置。

另一个例子是电子设计中的 device sizing（器件尺寸设计），即为电路中每个器件选择宽度与长度的任务。这里变量表示各器件的宽度和长度；约束表示各种工程要求，例如制造工艺对器件尺寸的限制、保证电路能在指定速度下可靠运行的 timing requirements（时序要求），以及电路总面积的上限。器件尺寸设计中一个常见目标函数是电路消耗的 total power（总功耗）。于是优化问题 (1.1) 就是：找到既满足设计要求（可制造性、时序、面积），又最省电的器件尺寸。

在 data fitting（数据拟合）中，任务是从一族候选模型中找到最能拟合观测数据与先验信息的模型。这里变量是模型中的 parameters（参数），约束可以表示先验信息或对参数的必要限制（如非负性）。目标函数可以是观测数据与模型预测值之间的 misfit（失配）或 prediction error（预测误差）的度量，也可以是对参数值不可能性/不合理性的统计度量。优化问题 (1.1) 就是：找到与先验信息一致、且对观测数据失配或预测误差最小（或在统计框架下最有可能）的模型参数值。



大量涉及决策（或系统设计、分析与运行）的实际问题，都可以归结为数学优化问题或其某种变体（例如多准则优化问题）。事实上，数学优化已成为许多领域的重要工具：它广泛用于工程领域——电子设计自动化、自动控制系统，以及土木、化工、机械与航空航天工程中的最优设计问题；也用于网络设计与运行、金融、供应链管理、调度等许多其他领域的问题。应用清单仍在稳步增长。

对上述大多数应用而言，数学优化是作为人类决策者、系统设计者或系统操作者的辅助工具：由人来监督过程、检查结果，并在必要时修改问题（或求解方法）。这位人类决策者还执行优化问题所建议的行动，例如买卖资产以实现最优投资组合。

一个较新的现象为数学优化开辟了许多其他应用可能：随着嵌入产品的计算机的激增，embedded optimization（嵌入式优化）快速增长。在这类嵌入式应用中，优化被用来自动做出实时选择，甚至执行相应行动，几乎没有（或完全没有）人工干预或监督。在某些应用领域，传统自动控制系统与嵌入式优化的融合已在顺利进行；在另一些领域才刚刚起步。嵌入式实时优化带来一些新挑战：特别是它要求求解方法极其可靠，并且能在可预测的时间（和内存）内解决问题。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">1.1.2 Solving optimization problems（求解优化问题）</span>



某一类优化问题的 solution method（求解方法）是一个 algorithm（算法）：给定该类中的一个具体问题（即问题的一个 instance（实例）），它计算出该问题的（在给定精度下的）解。自 1940 年代末以来，人们投入大量精力去开发求解各类优化问题的算法、分析其性质、并给出良好的软件实现。这些算法的有效性——即我们求解优化问题 (1.1) 的能力——差异很大，取决于诸如目标函数与约束函数的具体形式、变量与约束的数量，以及特殊结构（例如 sparsity（稀疏性）：若每个约束函数只依赖于少量变量，则称问题是稀疏的）。

即使目标函数和约束函数都是 smooth（光滑）的（例如多项式），一般优化问题 (1.1) 的求解也出奇地困难。因此求解一般问题的方法都要做某种妥协：要么计算时间极长，要么可能找不到解。其中一些方法将在 §1.4 讨论。

然而，「大多数优化问题都难解」这条一般规律存在一些重要的例外。对少数问题类，我们拥有

<!-- p.18/19 -->

即使面对有数百甚至数千个变量和约束的大型问题也能可靠求解的有效算法。§1.2 描述的两个著名例子——least-squares problems（最小二乘问题）与 linear programs（线性规划）——就是如此。而一个鲜为人知的事实是：凸优化是这条规律的另一个例外。与最小二乘或线性规划一样，存在非常有效的算法，能够可靠而高效地求解即使是大型凸问题。

## <span style="color:#c0392b;">1.2 Least-squares and linear programming（最小二乘与线性规划）</span>

本节介绍两个广为人知、广泛使用的凸优化子类：least-squares（最小二乘）与 linear programming（线性规划）。（对这些问题的完整技术处理将在第 4 章给出。）

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">1.2.1 Least-squares problems（最小二乘问题）</span>



least-squares problem（最小二乘问题）是一个无约束（即 $m=0$）的优化问题，其目标是形如 $a_i^Tx-b_i$ 的各term（项）的平方和：

```math
\text{minimize}\quad f_0(x) = \|Ax-b\|_2^2 = \sum_{i=1}^k (a_i^T x - b_i)^2. \tag{1.4}
```

这里 $A\in\mathbb{R}^{k\times n}$（$k\ge n$），$a_i^T$ 是 $A$ 的各行，向量 $x\in\mathbb{R}^n$ 是优化变量。

**求解最小二乘问题。** 最小二乘问题 (1.4) 的求解可以归结为解一组线性方程

```math
(A^TA)x = A^Tb,
```

于是有解析解 $x = (A^TA)^{-1}A^Tb$。对最小二乘问题，我们有能把问题解到高精度、可靠性非常高的好算法（和软件实现）。求解时间近似正比于 $n^2k$，且比例常数已知。当前的台式计算机可以在几秒内求解数百个变量、数千个项的最小二乘问题；更强大的计算机当然能更快地求解更大的问题或同样规模的问题。（而且按 Moore's law（摩尔定律），这些求解时间在未来会呈指数下降。）最小二乘的算法与软件已经可靠到可以用于嵌入式优化。

<!-- p.19/20 -->

许多情况下，通过利用系数矩阵 $A$ 的某种特殊结构，我们能求解甚至更大的最小二乘问题。例如设矩阵 $A$ 是 sparse（稀疏）的，即它的非零元远少于 $kn$ 个。利用稀疏性，通常能以远低于 $n^2k$ 阶的时间求解。当前台式计算机可以在一分钟左右求解数万个变量、数十万个项的稀疏最小二乘问题（尽管这取决于具体的稀疏模式）。

对于极大规模的问题（比如数百万个变量）或有苛刻实时计算要求的问题，求解最小二乘仍具挑战。但在绝大多数情况下，可以说现有方法非常有效且极其可靠。事实上，我们可以说求解最小二乘问题（未触及当前能力边界时）是一项 (mature) technology（「成熟」的技术），可以被许多不了解、也不需要了解细节的人可靠地使用。

**使用最小二乘。** 最小二乘问题是 regression analysis（回归分析）、optimal control（最优控制）以及许多 parameter estimation（参数估计）与数据拟合方法的基础。它有多种统计解释，例如：在受 Gaussian measurement errors（高斯测量误差）污染的线性测量下，对向量 $x$ 做 maximum likelihood estimation（最大似然估计）。

识别一个优化问题是不是最小二乘问题很直接：只须验证目标是 quadratic function（二次函数），再检验相应的 quadratic form（二次型）是否 positive semidefinite（半正定）。

虽然基本最小二乘问题有简单固定的形式，但应用中有若干标准技术可以增加其灵活性。在 weighted least-squares（加权最小二乘）中，最小化的是加权代价

```math
\sum_{i=1}^k w_i (a_i^T x - b_i)^2,
```

其中 $w_1,\dots,w_k$ 为正数。（这个问题很容易转化并作为标准最小二乘问题求解。）权重 $w_i$ 的选取用来反映对各项 $a_i^Tx-b_i$ 大小的不同关注程度，或者仅仅是为了影响解。在统计背景下，当线性测量的误差具有不相等的 variances（方差）时，加权最小二乘自然出现。



最小二乘的另一项技术是 regularization（正则化），即在代价函数中加入额外的项。最简单的情形是把变量的平方和乘以一个正常数后加入代价函数：

```math
\sum_{i=1}^k (a_i^T x - b_i)^2 + \rho \sum_{i=1}^n x_i^2,
```

其中 $\rho > 0$。（这个问题同样可以表述为标准最小二乘问题。）额外的项惩罚 $x$ 的过大取值，使得在只最小化第一个和会得到不合理结果的情形下，仍能得到 sensible solution（合乎情理的解）。参数 $\rho$ 由使用者选择，以便在「让原目标函数 $\sum_{i=1}^k(a_i^Tx-b_i)^2$ 小」与「让 $\sum_{i=1}^n x_i^2$ 不至于太大」之间取得正确的 trade-off（权衡）。当被估计的向量 $x$ 具有先验分布时，正则化就会在统计估计中出现。

加权最小二乘与正则化将在第 6 章讲述；它们的统计解释在第 7 章给出。

> <span style="color:#2471a3;">**[译者注｜跨课程连接]** 正则化项 $\rho\sum x_i^2$ 与你在大二概率论（6.431）里会遇到的 MAP 估计直接对应：加上 Gaussian 先验的最小二乘就是 ridge regression（岭回归）。「先验分布 → 代价函数中的额外项」这一对应是贝叶斯视角与优化视角的第一座桥。</span>

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">1.2.2 Linear programming（线性规划）</span>

<!-- p.20/21 -->

另一类重要的优化问题是 linear programming（线性规划），其目标函数与所有约束函数都是线性的：

```math
\text{minimize}\quad c^T x \qquad \text{subject to}\quad a_i^T x \le b_i,\; i=1,\dots,m. \tag{1.5}
```

这里向量 $c, a_1,\dots,a_m\in\mathbb{R}^n$ 与标量 $b_1,\dots,b_m\in\mathbb{R}$ 是规定目标函数与约束函数的 problem parameters（问题参数）。

**求解线性规划。** 线性规划的解没有简单的解析公式（不像最小二乘），但有很多非常有效的求解方法，包括 Dantzig 的 simplex method（单纯形法），以及本书后面讲述的较新的 interior-point methods（内点法）。虽然我们无法像最小二乘那样给出求解所需的精确算术运算数，但可以建立严格的 bounds（界）：用内点法把线性规划解到给定精度所需的运算次数界。实际复杂度约为 $n^2m$ 阶（设 $m\ge n$），但其常数不如最小二乘刻画得那么清楚。这些算法相当可靠，尽管可能不如最小二乘的方法。我们可以在小型台式计算机上、几秒内轻松求解数百个变量、数千个约束的问题。如果问题稀疏或有其他可利用的结构，常常能求解数万乃至数十万个变量与约束的问题。

与最小二乘一样，求解极大规模的线性规划、或满足苛刻实时计算要求的线性规划仍具挑战。但和最小二乘一样，我们可以说求解（大多数）线性规划是一项成熟技术。Linear programming solvers（线性规划求解器）可以（并且已经）被嵌入许多工具与应用中。

**使用线性规划。** 有些应用直接导出形如 (1.5) 的线性规划或其几个标准变体。在许多其他情形，原始优化问题并不具有标准线性规划形式，但可以用第 4 章详述的技术把它变换成一个等价的线性规划（然后当然可以求解）。



举一个简单例子：Chebyshev approximation problem（切比雪夫逼近问题）：

```math
\text{minimize}\quad \max_{i=1,\dots,k} |a_i^T x - b_i|. \tag{1.6}
```

这里 $x\in\mathbb{R}^n$ 是变量，$a_1,\dots,a_k\in\mathbb{R}^n$、$b_1,\dots,b_k\in\mathbb{R}$ 是规定问题实例的参数。注意它与最小二乘问题 (1.4) 的相似之处：两个问题的目标都是度量 $a_i^Tx-b_i$ 这些项的大小。最小二乘用各项的平方和作目标，而切比雪夫逼近用绝对值的 maximum（最大值）。

另一个重要区别是：切比雪夫逼近问题 (1.6) 的目标函数不是 differentiable（可微）的；而最小二乘问题 (1.4) 的目标是二次的，因而可微。

切比雪夫逼近问题 (1.6) 可以通过求解线性规划

```math
\begin{aligned}
\text{minimize}\quad & t\\
\text{subject to}\quad & a_i^T x - t \le b_i, && i = 1,\dots,k\\
& -a_i^T x - t \le -b_i, && i = 1,\dots,k,
\end{aligned}
\tag{1.7}
```

来求解，其中变量为 $x\in\mathbb{R}^n$ 与 $t\in\mathbb{R}$。（细节将在第 6 章给出。）由于线性规划很容易求解，切比雪夫逼近问题也就容易求解了。

任何具备线性规划实用知识的人都会看出切比雪夫逼近问题 (1.6) 可以归结为线性规划。但对没有这种背景的人来说，带不可微目标的 (1.6) 能被表述并求解为线性规划，可能并不显然。



识别可归结为线性规划的问题，比识别最小二乘问题要复杂，但这是一项很容易习得的技能，因为用到的只是少数几个标准技巧。这项任务甚至可以部分自动化：一些用于描述和求解优化问题的软件系统能自动识别（某些）可以重新表述为线性规划的问题。

## <span style="color:#c0392b;">1.3 Convex optimization（凸优化）</span>

convex optimization problem（凸优化问题）是如下形式的问题：

```math
\text{minimize}\quad f_0(x) \qquad \text{subject to}\quad f_i(x)\le b_i,\; i=1,\dots,m, \tag{1.8}
```

其中函数 $f_0,\dots,f_m:\mathbb{R}^n\to\mathbb{R}$ 都是 convex（凸）的，即满足

```math
f_i(\alpha x + \beta y) \le \alpha f_i(x) + \beta f_i(y)
```

对所有 $x,y\in\mathbb{R}^n$ 与满足 $\alpha+\beta=1,\;\alpha\ge0,\;\beta\ge0$ 的 $\alpha,\beta\in\mathbb{R}$ 成立。最小二乘问题 (1.4) 与线性规划问题 (1.5) 都是一般凸优化问题 (1.8) 的特例。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">1.3.1 Solving convex optimization problems（求解凸优化问题）</span>

<!-- p.22/23 -->

凸优化问题的解一般没有解析公式，但（与线性规划一样）有非常有效的求解方法。Interior-point methods（内点法）在实践中表现非常好，某些情形下还能证明：可以用不超过问题维度多项式数量级的运算次数把问题解到指定精度。（这将在第 11 章讲述。）

我们将会看到，内点法求解问题 (1.8) 所需的步数或 iteration（迭代）次数几乎总在 10 到 100 之间。若忽略问题中的任何结构（如稀疏性），每一步需要

```math
\max\{n^3,\; n^2 m,\; F\}
```

阶的运算，其中 $F$ 是计算目标与约束函数 $f_0,\dots,f_m$ 的一阶与二阶导数的代价。



与求解线性规划的方法一样，这些内点法相当可靠。当前台式计算机上，我们可以在至多几十秒内轻松求解数百个变量、数千个约束的问题。利用问题结构（如稀疏性），可以求解远更大的、有成千上万个变量与约束的问题。

我们还不能宣称求解一般凸优化问题已是像求解最小二乘或线性规划那样的成熟技术。针对一般非线性凸优化的内点法研究仍是非常活跃的领域，关于什么是最佳方法尚无共识。但可以合理预期，求解一般凸优化问题将在几年内成为一种技术。而对某些凸优化子类——例如 second-order cone programming（二阶锥规划）或 geometric programming（几何规划）（第 4 章详述）——可以说内点法已接近成为技术。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">1.3.2 Using convex optimization（使用凸优化）</span>

<!-- p.23/24 -->

使用凸优化（至少在概念上）非常像使用最小二乘或线性规划。如果我们能把一个问题表述为凸优化问题，就能高效地求解它，正如我们能高效求解最小二乘问题一样。稍微夸张一点说：如果你把一个实际问题表述成了凸优化问题，那么你已经解决了原来的问题。

当然也存在一些重要差异。识别最小二乘问题很容易，但识别 convex function（凸函数）可能很难。此外，变换凸问题的技巧比变换线性规划的技巧多得多。因此，识别凸优化问题（或可变换为凸优化问题的问题）可能很有挑战性。本书的主要目标，正是让读者具备完成这件事所需的背景知识。



一旦发展出识别或表述凸优化问题的技能，你会发现多得惊人的问题都可以通过凸优化求解。

使用凸优化的挑战与艺术，正在于识别与表述问题。表述一旦完成，求解问题就像最小二乘或线性规划一样，（几乎）成了技术。

> <span style="color:#2471a3;">**[译者注｜第一性原理]** 本章最重要的主线是「技术 vs 艺术」的分界线：最小二乘/线性规划 = 技术（机械流程可复用）；局部优化 = 艺术（依赖初始点、调参、运气）；凸优化 = 正从艺术走向技术，其难点唯一地集中在 formulation（建模）环节。这也是本书后面 400 多页内容的定位——把「识别凸性」从艺术变成可教学的技能。</span>

## <span style="color:#c0392b;">1.4 Nonlinear optimization（非线性优化）</span>



Nonlinear optimization（非线性优化，或 nonlinear programming，非线性规划）一词描述的是目标函数或约束函数不是线性、但也不已知为凸的优化问题。遗憾的是，求解一般非线性规划问题 (1.1) 并没有有效方法。哪怕只有十个变量的、看起来简单的问题也可能极具挑战，而有几百个变量的问题可能完全 intractable（难以处理）。因此，一般非线性规划的方法采取了几种不同的路线，每种都包含某种妥协。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">1.4.1 Local optimization（局部优化）</span>

<!-- p.24/25 -->

在 local optimization（局部优化）中，妥协是放弃寻找在所有可行点上最小化目标的 optimal $x$（最优解），转而寻找一个 merely locally optimal（仅局部最优）的点：它在「邻近的可行点」中使目标函数最小，但不保证比所有其他可行点的目标值更低。一般非线性规划研究中有很大比例集中在局部优化方法上，因此这些方法发展得很成熟。

局部优化方法可以很快、能处理大规模问题、并且适用面广，因为它们只要求目标与约束函数可微。因此，在「找到一个好点（即使不是最好的点）也有价值」的应用中，局部优化方法被广泛使用。例如在工程设计应用中，局部优化可用来改进最初由手工（或其他）设计方法得到的设计。



局部优化方法除（可能）找不到真正的 globally optimal solution（全局最优解）之外，还有若干缺点：方法需要对优化变量有 initial guess（初始猜测）；这个初始点或 starting point（起始点）至关重要，会极大影响所得局部解的目标值；对于局部解距离（全局）最优有多远，它几乎不提供信息；局部优化方法常常对算法参数值敏感，参数可能需要针对具体问题或问题族来调整。

使用局部优化方法比求解最小二乘问题、线性规划或凸优化问题更棘手：它包括尝试选择算法、调整算法参数、以及（在求解单个实例时）找到一个足够好的初始点，或（在求解一族问题时）设计产生足够好初始点的方法。粗略地说，局部优化方法与其说是技术，不如说是艺术（more art than technology）。局部优化是一门发展成熟的「艺术」，常常非常有效，但它终究是艺术。相比之下，求解最小二乘问题或线性规划几乎不涉及「艺术」（当然，触及当前能力边界的问题除外）。

<!-- p.25/26 -->

可以在非线性规划的局部优化方法与凸优化之间做一个有趣的比较。既然目标与约束函数的可微性是大多数局部优化方法的唯一要求，把实际问题表述为非线性优化问题相对直接：局部优化中的「艺术」在于表述完成之后去求解问题（以「找到局部最优点」这一弱化的意义）。而在凸优化中这两者是颠倒的：艺术与挑战在于问题表述；一旦把问题表述为凸优化问题，求解它就相对直接了。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">1.4.2 Global optimization（全局优化）</span>

在 global optimization（全局优化）中，找到的是优化问题 (1.1) 的真正的全局解；妥协是效率。全局优化方法的 worst-case complexity（最坏情况复杂度）随问题规模 $n$ 与 $m$ 呈指数增长；人们希望在实际中，对遇到的特定问题实例，方法会快得多。这种有利情形确实会出现，但并非典型。即使有几十个变量的小问题，也可能需要很长时间（例如几小时或几天）来求解。



全局优化用于变量少、计算时间不关键、而找到真正全局解的价值很高的那些问题。工程设计中的一个例子是对高价值或安全攸关系统做 worst-case analysis（最坏情况分析）或验证。这里变量表示不确定的 parameters（参数），它们会随制造、环境或运行条件而变化；目标函数是一个 utility function（效用函数），即值越小越糟的函数；约束表示关于参数可能取值的先验知识。优化问题 (1.1) 就是寻找参数的最坏取值。如果最坏值尚可接受，就能认证该系统（关于这些参数变化）是安全或可靠的。

局部优化方法能快速找到一组「很糟、但不保证是绝对最坏」的参数值。如果局部优化方法找到了导致不可接受性能的参数值，它成功地判定了系统不可靠。但局部优化方法无法认证系统可靠——它只能「没有找到坏参数」。全局优化方法则相反，会找到参数的绝对最坏值，若相应性能可以接受，就能认证系统安全。代价是计算时间，即使参数相对较少，也可能非常大。但在「认证性能的价值很高」或「对可靠性/安全性判断错误的代价很高」的情形下，这可能是值得的。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">1.4.3 Role of convex optimization in nonconvex problems（凸优化在非凸问题中的作用）</span>

本书主要讨论凸优化问题以及可归结为凸优化问题的应用。但凸优化在非凸问题中也扮演着重要角色。



**为局部优化提供初始化（Initialization for local optimization）。** 一个明显的用法是把凸优化与局部优化方法结合。从非凸问题出发，先找到问题的一个近似但 convex（凸）的表述。求解这个近似问题（这很容易做，且不需要初始点），得到近似凸问题的精确解，然后把这一点用作局部优化方法的 starting point（起始点），作用于原始非凸问题。

**非凸优化的凸启发式（Convex heuristics for nonconvex optimization）。** 凸优化是若干求解非凸问题的 heuristics（启发式方法）的基础。我们后面会看到一个有趣的例子：寻找满足某些约束的 sparse vector（稀疏向量，即非零元很少的向量）。这是一个困难的组合问题，但存在一些基于凸优化的简单启发式，常常能找到相当稀疏的解。（这些将在第 6 章描述。）

另一个宽泛的例子是 randomized algorithms（随机化算法）：从某个 probability distribution（概率分布）抽取若干候选解，把其中最好的作为非凸问题的近似解。现在假设抽样的分布族被参数化（例如由均值与 covariance（协方差）参数化），于是可以提出这样的问题：这些分布中哪个给出目标函数最小的 expected value（期望值）？事实证明这个问题有时本身就是凸问题，因而可以高效求解。（见习题 11.23。）

<!-- p.27/28 -->

**为全局优化提供界（Bounds for global optimization）。** 许多全局优化方法需要一个关于非凸问题最优值的、计算代价低的 lower bound（下界）。两个标准方法都基于凸优化。在 relaxation（松弛）中，每个非凸约束被替换为更宽松但 convex（凸）的约束。在 Lagrangian relaxation（拉格朗日松弛）中，求解 Lagrangian dual problem（拉格朗日对偶问题）（第 5 章描述）。这个问题是凸的，并给出非凸问题最优值的下界。

> <span style="color:#2471a3;">**[译者注｜跨课程连接]** 「用松弛取下界」与你已经熟悉的算法思路同构：CLRS 中用决策树模型给比较排序取 $\Omega(n\log n)$ 下界，这里用 Lagrangian 对偶给非凸优化取下界——都是「构造一个更容易分析、且不劣于（不优于）原问题的替身」。</span>

第二部分 Applications 描述凸优化在概率与统计、computational geometry（计算几何）、数据拟合等领域的各种应用。我们以希望对广泛读者都易于理解的方式来描述这些应用。为了让每个应用保持简短，我们只考虑简单情形，有时加上关于可能推广的评论。我们确信对其中某些应用的处理会让专家们皱眉，在此预先致歉。但我们的目标是快速地向广泛读者传达应用的「风味」，而不是给出优雅、理论完备或完整的处理。我们的背景是 electrical engineering（电气工程）中的控制系统、signal processing（信号处理）、电路分析与设计等领域。虽然我们在教学中（以本书为主要教材）包括这些主题，但其中只有少数应用足够普适而收入本书。

第二部分的目标是通过例子向读者展示凸优化在实践中如何被应用。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">1.5.3 Part III: Algorithms（第三部分：算法）</span>

<!-- p.29/30 -->

第三部分 Algorithms 描述求解凸优化问题的数值方法，重点是 Newton's algorithm（牛顿算法）与 interior-point methods（内点法）。第三部分按三章组织，分别讲述 unconstrained optimization（无约束优化）、equality constrained optimization（等式约束优化）与 inequality constrained optimization（不等式约束优化）。这三章遵循一个自然的 hierarchy（层级结构）：把求解一个问题约化为求解一列更简单的问题。Quadratic optimization problems（二次优化问题，包括例如最小二乘）位于该层级的基础，它们可以通过解一组线性方程精确求解。在第 9、10 章发展的 Newton's method（牛顿法）是层级的下一层：用牛顿法求解无约束或等式约束问题被约化为求解一列二次问题。第 11 章描述的 interior-point methods（内点法）构成层级的顶层：这些方法通过求解一列无约束或等式约束问题来求解不等式约束问题。



总体上我们只讲少数几个算法，并省略了整类好方法，例如 quasi-Newton（拟牛顿）、conjugate-gradient（共轭梯度）、bundle（束方法）与 cutting-plane（割平面）算法。对我们讲述的方法，给的是简化变体，而非最新、最精巧的版本。选择算法的标准有几点：我们选择 simple（简单，易于描述与实现）、而且 reliable（可靠）、robust（稳健）、对大多数问题足够有效且快的方法。

许多凸优化使用者最终只是使用（而非开发）标准软件，例如线性规划或半定规划求解器。对这些使用者，第三部分意在传达这些方法的基本风味，并给出其基本属性的一些概念。对少数将要开发新算法的人，我们认为第三部分是一个很好的入门。

## <span style="color:#c0392b;">1.6 Notation（记号）</span>



我们的记号大体标准，只有少量例外。本节描述基本记号；更完整的列表见第 697 页。

我们用 $\mathbb{R}$ 表示 real numbers（实数）集合，$\mathbb{R}_+$ 表示 nonnegative real numbers（非负实数）集合，$\mathbb{R}_{++}$ 表示 positive real numbers（正实数）集合。$n$ 维实向量的集合记作 $\mathbb{R}^n$，$m\times n$ 实矩阵的集合记作 $\mathbb{R}^{m\times n}$。我们用方括号定界向量与矩阵，分量之间用空格分隔；用圆括号从逗号分隔的列表构造 column vectors（列向量）。例如，若 $a,b,c\in\mathbb{R}$，则

```math
(a,b,c) = \begin{bmatrix} a\\ b\\ c\end{bmatrix} = \left[\,a\;\;b\;\;c\,\right]^T,
```

它是 $\mathbb{R}^3$ 的元素。符号 $\mathbf{1}$ 表示所有分量均为 1 的向量（维度由上下文确定）。记号 $x_i$ 可以指向量 $x$ 的第 $i$ 个 component（分量），也可以指向量序列 $x_1,x_2,\dots$ 中第 $i$ 个元素。上下文或正文会明确所指。

我们用 $\mathbf{S}^k$ 表示 $k\times k$ 对称矩阵的集合，$\mathbf{S}^k_+$ 表示对称 positive semidefinite（半正定）的 $k\times k$ 矩阵集合，$\mathbf{S}^k_{++}$ 表示对称 positive definite（正定）的 $k\times k$ 矩阵集合。

卷曲不等号 $\succeq$（及其严格形式 $\succ$）用于表示 generalized inequality（广义不等式）：在向量之间表示 componentwise inequality（逐分量不等式）；在对称矩阵之间表示 matrix inequality（矩阵不等式）。带下标时，符号 $\preceq_K$（或 $\prec_K$）表示关于 cone（锥）$K$ 的广义不等式（在 §2.4.1 解释）。

我们对函数的记号与标准记号略有偏离，但希望不会引起混淆。记号 $f:\mathbb{R}^p\to\mathbb{R}^q$ 表示 $f$ 是 $\mathbb{R}^p$ 某个子集（即其 domain（定义域），记作 $\mathbf{dom}\, f$）上的 $\mathbb{R}^q$ 值函数。可以把 $f:\mathbb{R}^p\to\mathbb{R}^q$ 的用法理解为如计算机语言般的函数类型声明：$f:\mathbb{R}^p\to\mathbb{R}^q$ 表示函数 $f$ 以实 $p$-向量为参数，返回实 $q$-向量。集合 $\mathbf{dom}\, f$（函数 $f$ 的定义域）指明 $\mathbb{R}^p$ 中使 $f(x)$ 有定义的点的子集。例如，我们把对数函数描述为 $\log:\mathbb{R}\to\mathbb{R}$，且 $\mathbf{dom}\,\log = \mathbb{R}_{++}$。记号 $\log:\mathbb{R}\to\mathbb{R}$ 表示对数函数接受并返回一个实数；$\mathbf{dom}\,\log = \mathbb{R}_{++}$ 表示对数仅对正数有定义。



我们把 $\mathbb{R}^n$ 用作 generic finite-dimensional vector space（一般有限维向量空间）。我们还会遇到其他有限维向量空间，例如具有给定最大次数的 variable（变量）的多项式空间，或对称 $k\times k$ 矩阵空间 $\mathbf{S}^k$。通过为向量空间选定一组 basis（基），总能把它与 $\mathbb{R}^n$（$n$ 为其维度）等同起来，因此针对向量空间 $\mathbb{R}^n$ 陈述的一般结果都可以应用。我们通常把「把一般结果翻译到其他向量空间」留给读者。例如，任何 linear function（线性函数）$f:\mathbb{R}^n\to\mathbb{R}$ 都可以表示为 $f(x)=c^Tx$（$c\in\mathbb{R}^n$）。对于空间 $\mathbf{S}^k$，选一组基并翻译，即得相应陈述：任何线性函数 $f:\mathbf{S}^k\to\mathbb{R}$ 都可以表示为 $f(X) = \mathbf{tr}(CX)$，其中 $C\in\mathbf{S}^k$。

「凸优化问题 tractable（易于处理）」的思想并不新鲜。人们早就认识到，凸优化理论远比一般非线性优化理论来得直截了当（而且完备）。在此背景下，Rockafellar 在其 1993 年 SIAM Review 综述 [Roc93] 中陈述道：

> In fact the great watershed in optimization isn't between linearity and nonlinearity, but convexity and nonconvexity.
> （事实上，优化中真正的分水岭不在于线性与非线性，而在于凸与非凸。）



第一个正式论证「凸优化问题比一般非线性优化问题易解」的是 Nemirovski 与 Yudin 在其 1983 年的书《Problem Complexity and Method Efficiency in Optimization》[NY83] 中：他们证明凸优化问题的 information-based complexity（基于信息的复杂度）远低于一般非线性优化问题。关于该主题较新的书是 Vavasis [Vav91]。

内点法低（理论）复杂度是该领域现代研究的核心。许多研究致力于证明：某个内点法（或其他方法）求解某类凸优化问题所需的运算次数增长不超过问题维数的多项式与 $\log(1/\epsilon)$（其中 $\epsilon>0$ 是所需精度）。（第 11 章会看到一些这类简单结果。）该主题第一部全面的著作是 Nesterov 与 Nemirovski [NN94]。其他书包括 Ben-Tal 与 Nemirovski [BTN01, lecture 5] 与 Renegar [Ren01]。内点法对各种凸优化问题的多项式时间复杂度，与许多非凸优化问题（其所有已知算法在最坏情况下都需要问题维数的指数级运算次数）形成鲜明对照。



凸优化已被用于太多应用领域，无法在此一一引用。凸分析在经济学与金融学中处于核心地位，是许多结果的基础。例如：separating hyperplane theorem（分离超平面定理）加上 no-arbitrage assumption（无套利假设）可用来推出 prices（价格）与 risk-neutral probabilities（风险中性概率）的存在性（见 Luenberger [Lue95, Lue98] 与 Ross [Ros99]）。凸优化（尤其是求解 semidefinite programs，半定规划的能力）近来在自动控制理论中受到特别关注。凸优化在控制理论中的应用可见 Boyd 与 Barratt [BB91]、Boyd, El Ghaoui, Feron 与 Balakrishnan [BEFB94]、Dahleh 与 Diaz-Bobillo [DDB95]、El Ghaoui 与 Niculescu [EN00]、Dullerud 与 Paganini [DP00] 的书。embedded (convex) optimization（嵌入式凸优化）的一个好例子是 model predictive control（模型预测控制）：这种自动控制技术要求每一步求解一个（凸）二次规划。模型预测控制现在广泛用于化工过程控制工业；见 Morari 与 Zafiriou [MZ89]。另一个凸优化（尤其是 geometric programming，几何规划）有悠久历史的应用领域是 electronic circuit design（电子电路设计）。该方向的研究论文包括 Fishburn 与 Dunlop [FD85]、Sapatnekar, Rao, Vaidya 与 Kang [SRVK93]、Hershenson, Boyd 与 Lee [HBL01]。Luo [Luo03] 给出了在 signal processing（信号处理）与 communications（通信）中应用的综述。更多凸优化应用的参考见第 4 章与第 6–8 章。

```math
y = \theta x_1 + (1-\theta)x_2,\qquad \theta\in\mathbb{R}
```

的点构成穿过 $x_1$ 与 $x_2$ 的 line（直线）。参数值 $\theta=0$ 对应 $y=x_2$，$\theta=1$ 对应 $y=x_1$；介于 0 与 1 之间的 $\theta$ 对应 $x_1$ 与 $x_2$ 之间的（闭）line segment（线段）。

若集合 $C\subseteq\mathbb{R}^n$ 中任意两个不同点之间的直线仍在 $C$ 内，即对任意 $x_1,x_2\in C$ 与任意 $\theta\in\mathbb{R}$ 都有 $\theta x_1+(1-\theta)x_2\in C$，则称 $C$ 是 affine（仿射）的。换句话说：只要线性组合的系数之和为 1，$C$ 就包含其中任意两点的线性组合。

这个想法可以推广到多于两个点。我们把形如 $\theta_1x_1+\cdots+\theta_kx_k$（其中 $\theta_1+\cdots+\theta_k=1$）的点称为点 $x_1,\dots,x_k$ 的 affine combination（仿射组合）。从仿射集的定义（它包含其中任意两点的仿射组合）出发，用归纳法可以证明：仿射集包含其点的所有仿射组合——若 $C$ 是仿射集，$x_1,\dots,x_k\in C$，且 $\theta_1+\cdots+\theta_k=1$，则 $\theta_1x_1+\cdots+\theta_kx_k\in C$。

若 $C$ 是仿射集且 $x_0\in C$，则集合

```math
V = C - x_0 = \{x - x_0 \mid x\in C\}
```

是一个 subspace（子空间），即对加法与标量乘法封闭。为看出这一点，设 $v_1,v_2\in V$，$\alpha,\beta\in\mathbb{R}$，则 $v_1+x_0\in C$，$v_2+x_0\in C$，于是

```math
\alpha v_1 + \beta v_2 + x_0 = \alpha(v_1+x_0) + \beta(v_2+x_0) + (1-\alpha-\beta)x_0 \in C,
```

因为 $C$ 仿射且 $\alpha+\beta+(1-\alpha-\beta)=1$。由 $\alpha v_1+\beta v_2+x_0\in C$ 得 $\alpha v_1+\beta v_2\in V$。

因此仿射集 $C$ 可以表示为

```math
C = V + x_0 = \{v + x_0 \mid v\in V\},
```

即一个子空间加一个 offset（偏移）。与仿射集 $C$ 相联系的子空间 $V$ 不依赖于 $x_0$ 的选取，所以 $x_0$ 可取 $C$ 中任意点。我们定义仿射集 $C$ 的 dimension（维数）为子空间 $V=C-x_0$（$x_0$ 为 $C$ 中任意元素）的维数。

<span style="color:#00838f;">**[例 2.1]** **线性方程组的解集。** 线性方程组的解集 $C=\{x \mid Ax=b\}$（$A\in\mathbb{R}^{m\times n}$，$b\in\mathbb{R}^m$）是仿射集。证明：设 $x_1,x_2\in C$，即 $Ax_1=b$，$Ax_2=b$，则对任意 $\theta$，

```math
A(\theta x_1+(1-\theta)x_2) = \theta Ax_1 + (1-\theta)Ax_2 = \theta b + (1-\theta)b = b,
```

即仿射组合 $\theta x_1+(1-\theta)x_2$ 也在 $C$ 中。与 $C$ 相联系的子空间是 $A$ 的 nullspace（零空间）。

反之亦然：每个仿射集都可以表示为某个线性方程组的解集。



集合 $C\subseteq\mathbb{R}^n$ 中点的所有仿射组合组成的集合称为 $C$ 的 affine hull（仿射包），记作 $\mathbf{aff}\, C$：

```math
\mathbf{aff}\, C = \{\theta_1x_1+\cdots+\theta_kx_k \mid x_1,\dots,x_k\in C,\; \theta_1+\cdots+\theta_k=1\}.
```

仿射包是包含 $C$ 的最小仿射集，含义是：若 $S$ 是任何满足 $C\subseteq S$ 的仿射集，则 $\mathbf{aff}\, C\subseteq S$。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">2.1.3 Affine dimension and relative interior（仿射维数与相对内部）</span>

我们定义集合 $C$ 的 affine dimension（仿射维数）为其仿射包的维数。仿射维数在凸分析与优化中很有用，但并不总是与其他维数定义一致。例如考虑 $\mathbb{R}^2$ 中的 unit circle（单位圆）$\{x\in\mathbb{R}^2 \mid x_1^2+x_2^2=1\}$：它的仿射包是整个 $\mathbb{R}^2$，因此仿射维数是 2；但按大多数维数定义，$\mathbb{R}^2$ 中单位圆的维数是 1。

若集合 $C\subseteq\mathbb{R}^n$ 的仿射维数小于 $n$，则该集合位于仿射集 $\mathbf{aff}\, C\neq\mathbb{R}^n$ 中。我们把 $C$ 的 relative interior（相对内部）定义为它在 $\mathbf{aff}\, C$ 意义下的内部，记作 $\mathbf{relint}\, C$：

```math
\mathbf{relint}\, C = \{x\in C \mid B(x,r)\cap\mathbf{aff}\, C \subseteq C \text{ 对某个 } r>0\},
```

其中 $B(x,r)=\{y \mid \|y-x\|\le r\}$ 是范数 $\|\cdot\|$ 下以 $x$ 为心、半径 $r$ 的球。（这里 $\|\cdot\|$ 是任意范数；所有范数定义出同一个相对内部。）进而可定义集合 $C$ 的 relative boundary（相对边界）为 $\mathbf{cl}\, C \setminus \mathbf{relint}\, C$，其中 $\mathbf{cl}\, C$ 是 $C$ 的 closure（闭包）。

<span style="color:#00838f;">**[例 2.2]** 考虑 $\mathbb{R}^3$ 中 $(x_1,x_2)$ 平面上的正方形

```math
C = \{x\in\mathbb{R}^3 \mid -1\le x_1\le 1,\; -1\le x_2\le 1,\; x_3=0\}.
```

它的仿射包是 $(x_1,x_2)$ 平面，即 $\mathbf{aff}\, C=\{x\in\mathbb{R}^3 \mid x_3=0\}$。$C$ 的内部为空，但相对内部为

```math
\mathbf{relint}\, C = \{x\in\mathbb{R}^3 \mid -1<x_1<1,\; -1<x_2<1,\; x_3=0\}.
```

它在 $\mathbb{R}^3$ 中的边界就是它自己；它的相对边界是线框轮廓 $\{x\in\mathbb{R}^3 \mid \max\{|x_1|,|x_2|\}=1,\; x_3=0\}$。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">2.1.4 Convex sets（凸集）</span>



若集合 $C$ 中任意两点之间的线段仍在 $C$ 内，即对任意 $x_1,x_2\in C$ 与任意满足 $0\le\theta\le1$ 的 $\theta$ 都有

```math
\theta x_1 + (1-\theta)x_2 \in C,
```

则称 $C$ 是 convex（凸）的。粗略地说：凸集就是集合中每一点都能被其他每一点「看见」——沿着两点之间一条 unobstructed（无遮挡）的直线路径，而无遮挡的意思是路径全程位于集合内。每个仿射集都是凸集，因为它包含任意两点间的整条直线，当然也包含线段。图 2.2 展示了 $\mathbb{R}^2$ 中一些简单的凸集与非凸集。

我们称形如 $\theta_1x_1+\cdots+\theta_kx_k$（其中 $\theta_1+\cdots+\theta_k=1$ 且 $\theta_i\ge0,\; i=1,\dots,k$）的点为点 $x_1,\dots,x_k$ 的 convex combination（凸组合）。与仿射集一样，可以证明：集合是凸的当且仅当它包含其点的所有凸组合。点的凸组合可以看作这些点的 mixture（混合）或 weighted average（加权平均），$\theta_i$ 就是 $x_i$ 在混合中所占的比例。

<!-- p.38/39 -->

集合 $C$ 的 convex hull（凸包）记作 $\mathbf{conv}\, C$，是 $C$ 中点的所有凸组合的集合：

```math
\mathbf{conv}\, C = \{\theta_1x_1+\cdots+\theta_kx_k \mid x_i\in C,\; \theta_i\ge0,\; \theta_1+\cdots+\theta_k=1\}.
```

顾名思义，$\mathbf{conv}\, C$ 总是凸的。它是包含 $C$ 的最小凸集：若 $B$ 是任何包含 $C$ 的凸集，则 $\mathbf{conv}\, C\subseteq B$。图 2.3 展示了凸包的定义。

凸组合的概念可以推广到无穷级数、积分，以及最一般形式的 probability distributions（概率分布）。设 $\theta_1,\theta_2,\dots$ 满足

```math
\theta_i\ge0,\; i=1,2,\dots,\qquad \sum_{i=1}^{\infty}\theta_i = 1,
```

且 $x_1,x_2,\dots\in C$（$C\subseteq\mathbb{R}^n$ 凸），则（若级数收敛）

```math
\sum_{i=1}^{\infty}\theta_i x_i \in C.
```

更一般地，设 $p:\mathbb{R}^n\to\mathbb{R}$ 对所有 $x\in C$ 满足 $p(x)\ge0$ 且 $\int_C p(x)\,dx=1$（$C\subseteq\mathbb{R}^n$ 凸），则（若积分存在）$\int_C p(x)x\,dx\in C$。

在最一般的形式中：设 $C\subseteq\mathbb{R}^n$ 凸，$x$ 是随机向量且 $x\in C$ 以概率 1 成立，则 $\mathbb{E}\, x\in C$。事实上这一形式包含前面所有形式作为特例：例如设随机变量 $x$ 只取两个值 $x_1,x_2$，$\mathrm{prob}(x=x_1)=\theta$，$\mathrm{prob}(x=x_2)=1-\theta$（$0\le\theta\le1$），则 $\mathbb{E}\,x=\theta x_1+(1-\theta)x_2$，回到了两点的简单凸组合。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">2.1.5 Cones（锥）</span>



若对每个 $x\in C$ 与每个 $\theta\ge0$ 都有 $\theta x\in C$，则称集合 $C$ 为 cone（锥），或 nonnegative homogeneous（非负齐次）的。若 $C$ 既是凸集又是锥，则称它为 convex cone（凸锥），即对任意 $x_1,x_2\in C$ 与 $\theta_1,\theta_2\ge0$，有

```math
\theta_1x_1+\theta_2x_2\in C.
```

这种形式的点在几何上构成以 0 为 apex（顶点）、边缘穿过 $x_1$ 与 $x_2$ 的二维 pie slice（扇形楔）。（见图 2.4。）

形如 $\theta_1x_1+\cdots+\theta_kx_k$（$\theta_1,\dots,\theta_k\ge0$）的点称为 $x_1,\dots,x_k$ 的 conic combination（锥组合）或 nonnegative linear combination（非负线性组合）。若 $x_i$ 属于凸锥 $C$，则它们的每个锥组合都属于 $C$；反之，$C$ 是凸锥当且仅当它包含其元素的所有锥组合。与凸（或仿射）组合一样，锥组合的概念也可推广到无穷和与积分。

集合 $C$ 的 conic hull（锥包）是 $C$ 中点的所有锥组合的集合，即

```math
\{\theta_1x_1+\cdots+\theta_kx_k \mid x_i\in C,\; \theta_i\ge0,\; i=1,\dots,k\},
```

它也是包含 $C$ 的最小凸锥（见图 2.5）。

```math
\mu = \frac{\lambda x_{n+1}}{\lambda x_{n+1} + (1 - \lambda) y_{n+1}} \in [0, 1].
```

$\lambda$ 与 $\mu$ 之间的这一对应是单调的：当 $\lambda$ 在 $0$ 到 $1$ 之间变化时（这一变化扫出线段 $[x, y]$），$\mu$ 也在 $0$ 到 $1$ 之间变化（这一变化扫出线段 $[P(x), P(y)]$）。这就证明了 $P([x, y]) = [P(x), P(y)]$。

现在设 $C$ 是 convex 的且 $C \subseteq \operatorname{dom} P$（即对所有 $x \in C$ 都有 $x_{n+1} > 0$），并取 $x, y \in C$。要确立 $P(C)$ 的 convexity，我们需要证明线段 $[P(x), P(y)]$ 含于 $P(C)$ 之中。但这条线段正是线段 $[x, y]$ 在 $P$ 下的 image，因此它落在 $P(C)$ 里。

convex set 在 perspective function 下的 inverse image 也是 convex 的：若 $C \subseteq \mathbb{R}^n$ 是 convex 的，则

```math
P^{-1}(C) = \{(x, t) \in \mathbb{R}^{n+1} \mid x/t \in C,\ t > 0\}
```

是 convex 的。为证明这一点，设 $(x, t) \in P^{-1}(C)$、$(y, s) \in P^{-1}(C)$，且 $0 \le \lambda \le 1$。我们需要证明

```math
\lambda (x, t) + (1 - \lambda)(y, s) \in P^{-1}(C),
```

也就是要证明

```math
\frac{\lambda x + (1 - \lambda) y}{\lambda t + (1 - \lambda) s} \in C
```



本节描述全书会反复遇到的一些重要凸集例子。先看几个简单例子：

- empty set（空集）$\varnothing$、任何单点（singleton，单元素集）$\{x_0\}$、以及全空间 $\mathbb{R}^n$，都是 $\mathbb{R}^n$ 的仿射（从而凸）子集。
- 任何 line（直线）都是仿射的；若它穿过零点，则它是子空间，从而也是凸锥。
- line segment（线段）是凸的，但不仿射（除非退化成一个点）。
- ray（射线）$\{x_0+\theta v \mid \theta\ge0\}$（$v\neq0$）是凸的，但不仿射；若其 base（基点）$x_0=0$，则它是凸锥。
- 任何 subspace（子空间）都是仿射的，也是凸锥（从而是凸的）。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">2.2.1 Hyperplanes and halfspaces（超平面与半空间）</span>

hyperplane（超平面）是形如

```math
\{x \mid a^Tx = b\}
```

的集合，其中 $a\in\mathbb{R}^n$，$a\neq0$，$b\in\mathbb{R}$。从分析角度看，它是 $x$ 的分量之间一个非平凡线性方程的解集（因而是仿射集）。从几何角度看，超平面 $\{x\mid a^Tx=b\}$ 可以解释为「与给定向量 $a$ 的 inner product（内积）为常数」的点集，即一个以 $a$ 为 normal vector（法向量）的超平面；常数 $b\in\mathbb{R}$ 决定超平面相对原点的 offset（偏移）。把超平面写成

```math
\{x \mid a^T(x-x_0)=0\}
```

即可理解这一几何解释，其中 $x_0$ 是超平面上的任意点（即满足 $a^Tx_0=b$ 的任意点）。这个表示又可写成

```math
\{x \mid a^T(x-x_0)=0\} = x_0 + a^\perp,
```

其中 $a^\perp$ 表示 $a$ 的 orthogonal complement（正交补），即所有与 $a$ 正交的向量组成的集合：

```math
a^\perp = \{v \mid a^Tv=0\}.
```

这说明超平面由偏移 $x_0$ 加上所有与（法）向量 $a$ 正交的向量构成（见图 2.6）。

<!-- p.41/42 -->

超平面把 $\mathbb{R}^n$ 分成两个 halfspaces（半空间）。一个（闭）halfspace（半空间）是形如

```math
\{x \mid a^Tx \le b\} \tag{2.1}
```

的集合，其中 $a\neq0$，即一个（非平凡）线性不等式的解集。半空间是凸的，但不仿射（见图 2.7）。



> <span style="color:#7f8c8d;">原书 p.42｜图 2.16、保凸性、Example 2.13</span>

[Figure 2.16：左图是一个集合 $C \subseteq \mathbb{R}^2$。虚线给出了 linear-fractional 函数 $f(x) = x/(x_1 + x_2 + 1)$ 的定义域边界，其中 $\operatorname{dom} f = \{(x_1, x_2) \mid x_1 + x_2 + 1 > 0\}$。右图是 $C$ 在 $f$ 下的像。虚线给出了 $f^{-1}$ 的定义域边界。]

与 perspective function 一样，linear-fractional 函数保持 convexity。若 $C$ 是 convex 的且落在 $f$ 的定义域内（即对 $x \in C$ 有 $c^T x + d > 0$），则它的 image $f(C)$ 是 convex 的。这一点可以由上面已得的结果立即推出：$C$ 在 affine 映射 (2.12) 下的 image 是 convex 的，而这个得到的集合在 perspective function $P$ 下（其 image 就是 $f(C)$）也是 convex 的。类似地，若 $C \subseteq \mathbb{R}^m$ 是 convex 的，则 inverse image $f^{-1}(C)$ 是 convex 的。

#### <span style="color:#6c3483;">**[example]**</span> <span style="color:#c0392b">Example 2.13（例 2.13）：条件概率</span>

设 $u$ 与 $v$ 是随机变量，分别取值于 $\{1, \ldots, n\}$ 与 $\{1, \ldots, m\}$，并令 $p_{ij}$ 表示 $\operatorname{prob}(u = i, v = j)$。那么 conditional probability（条件概率）$f_{ij} = \operatorname{prob}(u = i \mid v = j)$ 由下式给出：

```math
f_{ij} = \frac{p_{ij}}{\sum_{k=1}^{n} p_{kj}}.
```

于是 $f$ 是由 $p$ 经一个 linear-fractional 映射得到的。

由此可知：若 $C$ 是 $(u, v)$ 的 joint probability（联合概率）构成的一个 convex 集合，则与之关联的「给定 $v$ 时 $u$ 的条件概率」集合也是 convex 的。

图 2.16 画出了集合 $C \subseteq \mathbb{R}^2$，以及它在 linear-fractional 函数

```math
f(x) = \frac{1}{x_1 + x_2 + 1} x,\qquad \operatorname{dom} f = \{(x_1, x_2) \mid x_1 + x_2 + 1 > 0\}
```

下的 image。



半空间 (2.1) 也可以表示为

```math
\{x \mid a^T(x-x_0)\le0\}, \tag{2.2}
```

其中 $x_0$ 是相关超平面上的任意点（即满足 $a^Tx_0=b$）。表示 (2.2) 给出一个简单的几何解释：半空间由 $x_0$ 加上所有与（外法向）向量 $a$ 成 obtuse（钝）角或直角的向量构成（见图 2.8）。

半空间 (2.1) 的 boundary（边界）是超平面 $\{x\mid a^Tx=b\}$。集合 $\{x \mid a^Tx\lt b\}$ 是半空间 $\{x\mid a^Tx\le b\}$ 的内部，称为 open halfspace（开半空间）。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">2.2.2 Euclidean balls and ellipsoids（欧氏球与椭球）</span>



$\mathbb{R}^n$ 中的（Euclidean）ball（欧氏球，或简称 ball，球）形如

```math
B(x_c, r) = \{x \mid \|x-x_c\|_2 \le r\} = \{x \mid (x-x_c)^T(x-x_c)\le r^2\},
```

其中 $r>0$，$\|\cdot\|_2$ 表示 Euclidean norm（欧氏范数），即 $\|u\|_2=(u^Tu)^{1/2}$。向量 $x_c$ 是球的 center（球心），标量 $r$ 是 radius（半径）；$B(x_c,r)$ 由与球心距离不超过 $r$ 的所有点组成。欧氏球另一种常见表示是

```math
B(x_c,r) = \{x_c + ru \mid \|u\|_2\le1\}.
```



欧氏球是凸集：若 $\|x_1-x_c\|_2\le r$，$\|x_2-x_c\|_2\le r$，且 $0\le\theta\le1$，则

```math
\begin{aligned}
\|\theta x_1+(1-\theta)x_2-x_c\|_2
&= \|\theta(x_1-x_c)+(1-\theta)(x_2-x_c)\|_2\\
&\le \theta\|x_1-x_c\|_2 + (1-\theta)\|x_2-x_c\|_2 \le r.
\end{aligned}
```

（这里用到 $\|\cdot\|_2$ 的齐次性与三角不等式；见 §A.1.2。）

与之相关的一族凸集是 ellipsoids（椭球），形如

```math
\mathcal{E} = \{x \mid (x-x_c)^TP^{-1}(x-x_c)\le1\}, \tag{2.3}
```

其中 $P=P^T\succ0$，即 $P$ 是对称 positive definite（正定）矩阵。向量 $x_c\in\mathbb{R}^n$ 是椭球的中心。矩阵 $P$ 决定椭球从 $x_c$ 向每个方向延伸多远：$\mathcal{E}$ 的 semi-axes（半轴）长度为 $\sqrt{\lambda_i}$，其中 $\lambda_i$ 是 $P$ 的 eigenvalues（特征值）。球是 $P=r^2I$ 时的椭球。图 2.9 展示了 $\mathbb{R}^2$ 中的一个椭球。

<!-- p.44/45 -->

椭球另一种常见表示是

```math
\mathcal{E} = \{x_c + Au \mid \|u\|_2\le1\}, \tag{2.4}
```

其中 $A$ 是方阵且 nonsingular（非奇异）。在这个表示中，不失一般性可假设 $A$ 对称正定：取 $A=P^{1/2}$ 即得 (2.3) 定义的椭球。当 (2.4) 中的矩阵 $A$ 对称半正定但 singular（奇异）时，集合 (2.4) 称为 degenerate ellipsoid（退化椭球）；其仿射维数等于 $A$ 的 rank（秩）。退化椭球同样是凸的。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">2.2.3 Norm balls and norm cones（范数球与范数锥）</span>

设 $\|\cdot\|$ 是 $\mathbb{R}^n$ 上的任意范数（见 §A.1.2）。由范数的一般性质可以证明：半径 $r$、中心 $x_c$ 的 norm ball（范数球）$\{x \mid \|x-x_c\|\le r\}$ 是凸的。与范数 $\|\cdot\|$ 相关联的 norm cone（范数锥）是集合

```math
C = \{(x,t) \mid \|x\|\le t\} \subseteq \mathbb{R}^{n+1}.
```



它（顾名思义）是一个凸锥。

<span style="color:#00838f;">**[例 2.3]** **二阶锥（second-order cone）。** 二阶锥是欧氏范数对应的范数锥，即

```math
\begin{aligned}
C &= \{(x,t)\in\mathbb{R}^{n+1} \mid \|x\|_2\le t\}\\
&= \left\{\begin{bmatrix}x\\t\end{bmatrix} \;\middle|\; \begin{bmatrix}x\\t\end{bmatrix}^T\begin{bmatrix}I&0\\0&-1\end{bmatrix}\begin{bmatrix}x\\t\end{bmatrix}\le0,\; t\ge0\right\}.
\end{aligned}
```

二阶锥还有几个别名：因为它由二次不等式定义，所以叫 quadratic cone（二次锥）；也叫 Lorentz cone（洛伦兹锥）或 ice-cream cone（冰激凌锥）。图 2.10 展示了 $\mathbb{R}^3$ 中的二阶锥。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">2.2.4 Polyhedra（多面体）</span>



polyhedron（多面体）定义为有限个线性等式与不等式的解集：

```math
P = \{x \mid a_j^Tx\le b_j,\; j=1,\dots,m,\;\; c_j^Tx=d_j,\; j=1,\dots,p\}. \tag{2.5}
```

因此多面体是有限个半空间与超平面的 intersection（交）。仿射集（如子空间、超平面、直线）、射线、线段与半空间都是多面体。容易证明多面体是凸集。bounded polyhedron（有界多面体）有时称为 polytope（多胞形），但有些作者使用相反的约定（即 polytope 指任何形如 (2.5) 的集合，polyhedron 指其中有界的）。图 2.11 展示了一个由五个半空间相交定义的多面体。



使用紧凑记号很方便：

```math
P = \{x \mid Ax\preceq b,\; Cx=d\} \tag{2.6}
```

表示 (2.5)，其中

```math
A=\begin{bmatrix}a_1^T\\ \vdots\\ a_m^T\end{bmatrix},\qquad
C=\begin{bmatrix}c_1^T\\ \vdots\\ c_p^T\end{bmatrix},
```

符号 $\preceq$ 表示 $\mathbb{R}^m$ 中的向量不等式或 componentwise inequality（逐分量不等式）：$u\preceq v$ 意味着 $u_i\le v_i$（$i=1,\dots,m$）。

<span style="color:#00838f;">**[例 2.4]** **非负卦限（nonnegative orthant）。** 非负卦限是分量均非负的点集，即

```math
\mathbb{R}^n_+ = \{x\in\mathbb{R}^n \mid x_i\ge0,\; i=1,\dots,n\} = \{x\in\mathbb{R}^n \mid x\succeq0\}.
```

（这里 $\mathbb{R}_+$ 表示非负数集：$\mathbb{R}_+=\{x\in\mathbb{R}\mid x\ge0\}$。）非负卦限既是多面体又是锥（因此称为 polyhedral cone，多面锥）。

**Simplexes（单纯形）。** 单纯形是另一类重要的多面体。设 $k+1$ 个点 $v_0,\dots,v_k\in\mathbb{R}^n$ 是 affinely independent（仿射无关）的，即 $v_1-v_0,\dots,v_k-v_0$ 线性无关。由它们确定的 simplex（单纯形）为

```math
C = \mathbf{conv}\{v_0,\dots,v_k\} = \{\theta_0v_0+\cdots+\theta_kv_k \mid \theta\succeq0,\; \mathbf{1}^T\theta=1\}, \tag{2.7}
```



其中 $\mathbf{1}$ 表示全 1 向量。该单纯形的仿射维数为 $k$，因此有时称为 $\mathbb{R}^n$ 中的 $k$-维单纯形。

<span style="color:#00838f;">**[例 2.5]** **几个常见的单纯形。** 1-维单纯形是线段；2-维单纯形是三角形（含内部）；3-维单纯形是四面体。unit simplex（单位单纯形）是由零向量与单位向量确定的 $n$-维单纯形，即由 $0,e_1,\dots,e_n\in\mathbb{R}^n$ 确定，可表示为满足

```math
x\succeq0,\qquad \mathbf{1}^Tx\le1
```

的向量集合。probability simplex（概率单纯形）是由单位向量 $e_1,\dots,e_n\in\mathbb{R}^n$ 确定的 $(n-1)$-维单纯形，是满足

```math
x\succeq0,\qquad \mathbf{1}^Tx=1
```

的向量集合。概率单纯形中的向量对应 $n$ 个元素集合上的概率分布，$x_i$ 解释为第 $i$ 个元素的概率。

要把单纯形 (2.7) 描述成多面体（即 (2.6) 的形式），按如下步骤进行。由定义，$x\in C$ 当且仅当 $x=\theta_0v_0+\theta_1v_1+\cdots+\theta_kv_k$，其中某个 $\theta\succeq0$ 且 $\mathbf{1}^T\theta=1$。等价地，定义 $y=(\theta_1,\dots,\theta_k)$ 与

```math
B = [\,v_1-v_0\;\; \cdots\;\; v_k-v_0\,]\in\mathbb{R}^{n\times k},
```

则可以说：$x\in C$ 当且仅当

```math
x = v_0 + By \tag{2.8}
```

对某个 $y\succeq0$、$\mathbf{1}^Ty\le1$ 成立。注意点 $v_0,\dots,v_k$ 的仿射无关性意味着矩阵 $B$ 的 rank（秩）为 $k$。因此存在非奇异矩阵 $A=(A_1,A_2)\in\mathbb{R}^{n\times n}$ 使

```math
AB=\begin{bmatrix}A_1\\A_2\end{bmatrix}B=\begin{bmatrix}I\\0\end{bmatrix}.
```

<!-- p.47/48 -->

用 $A$ 左乘 (2.8) 得

```math
A_1x = A_1v_0 + y,\qquad A_2x = A_2v_0.
```

由此看出：$x\in C$ 当且仅当 $A_2x=A_2v_0$，且向量 $y=A_1x-A_1v_0$ 满足 $y\succeq0$、$\mathbf{1}^Ty\le1$。换言之：

```math
x\in C \iff A_2x=A_2v_0,\quad A_1x\succeq A_1v_0,\quad \mathbf{1}^TA_1x\le 1+\mathbf{1}^TA_1v_0,
```

这是关于 $x$ 的一组线性等式与不等式，因此描述一个多面体。

**多面体的凸包描述（Convex hull description of polyhedra）。** 有限集 $\{v_1,\dots,v_k\}$ 的凸包是

```math
\mathbf{conv}\{v_1,\dots,v_k\} = \{\theta_1v_1+\cdots+\theta_kv_k \mid \theta\succeq0,\; \mathbf{1}^T\theta=1\}.
```

这个集合是多面体且有界，但（除 simplex 等特殊情形外）不容易把它写成 (2.5) 的形式，即用一组线性等式与不等式表达。这种凸包描述的一个推广是

```math
\{\theta_1v_1+\cdots+\theta_kv_k \mid \theta_1+\cdots+\theta_m=1,\; \theta_i\ge0,\; i=1,\dots,k\}, \tag{2.9}
```

其中 $m\le k$：这里考虑 $v_i$ 的非负线性组合，但只要求前 $m$ 个系数之和为 1。也可以把 (2.9) 解释为点 $v_1,\dots,v_m$ 的凸包加上点 $v_{m+1},\dots,v_k$ 的锥包。集合 (2.9) 定义一个多面体；反之，每个多面体都可以表示成这种形式（虽然我们不证明这一点）。



多面体如何表示是一个微妙的问题，而且有非常重要的实际影响。举个简单例子：考虑 $\mathbb{R}^n$ 中 $\ell_\infty$-范数的 unit ball（单位球）

```math
C = \{x \mid |x_i|\le1,\; i=1,\dots,n\}.
```

集合 $C$ 可以用 (2.5) 的形式以 $2n$ 个线性不等式 $\pm e_i^Tx\le1$ 描述（$e_i$ 是第 $i$ 个单位向量）。而要用凸包形式 (2.9) 描述它至少需要 $2^n$ 个点：$C=\mathbf{conv}\{v_1,\dots,v_{2^n}\}$，其中 $v_1,\dots,v_{2^n}$ 是分量全为 $1$ 或 $-1$ 的所有 $2^n$ 个向量。因此当 $n$ 很大时，两种表示的规模差别巨大。

> <span style="color:#2471a3;">**[译者注｜跨课程连接]** 「同一集合的两种表示规模可以指数级不同」正是 CLRS 里 NP 难问题的影子：多面体的 H-表示（不等式）与 V-表示（顶点凸包）之间的转换，本质上和 0/1 背包里「n 个物品 → 2^n 个子集」是同一类复杂度墙。</span>

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">2.2.5 The positive semidefinite cone（半正定锥）</span>



我们用记号 $\mathbf{S}^n$ 表示对称 $n\times n$ 矩阵的集合

```math
\mathbf{S}^n = \{X\in\mathbb{R}^{n\times n} \mid X=X^T\},
```

它是一个维数为 $n(n+1)/2$ 的向量空间。用 $\mathbf{S}^n_+$ 表示对称 positive semidefinite（半正定）矩阵的集合：

```math
\mathbf{S}^n_+ = \{X\in\mathbf{S}^n \mid X\succeq0\},
```

用 $\mathbf{S}^n_{++}$ 表示对称 positive definite（正定）矩阵的集合：

```math
\mathbf{S}^n_{++} = \{X\in\mathbf{S}^n \mid X\succ0\}.
```

（这个记号意在类比 $\mathbb{R}_+$ 表示非负实数、$\mathbb{R}_{++}$ 表示正实数。）



集合 $\mathbf{S}^n_+$ 是凸锥：若 $\theta_1,\theta_2\ge0$ 且 $A,B\in\mathbf{S}^n_+$，则 $\theta_1A+\theta_2B\in\mathbf{S}^n_+$。这可以直接从半正定的定义看出：对任意 $x\in\mathbb{R}^n$，

```math
x^T(\theta_1A+\theta_2B)x = \theta_1x^TAx + \theta_2x^TBx \ge 0
```

（当 $A\succeq0$，$B\succeq0$，$\theta_1,\theta_2\ge0$ 时）。

<span style="color:#00838f;">**[例 2.6]** **$\mathbf{S}^2$ 中的半正定锥。** 我们有

```math
X=\begin{bmatrix}x&y\\y&z\end{bmatrix}\in\mathbf{S}^2_+
\quad\Longleftrightarrow\quad
x\ge0,\; z\ge0,\; xz\ge y^2.
```

这个锥的边界如图 2.12 所示（在 $\mathbb{R}^3$ 中以 $(x,y,z)$ 绘制）。



凸性在 intersection（交）下保持：若 $S_1$ 与 $S_2$ 凸，则 $S_1\cap S_2$ 凸。这个性质可推广到无穷多个集合的交：若 $S_\alpha$ 对每个 $\alpha\in\mathcal{A}$ 都是凸的，则 $\bigcap_{\alpha\in\mathcal{A}} S_\alpha$ 凸。（子空间、仿射集与凸锥对任意交也封闭。）简单例子：多面体是半空间与超平面（都是凸的）的交，因此是凸的。

<span style="color:#00838f;">**[例 2.7]** 半正定锥 $\mathbf{S}^n_+$ 可以表示为

```math
\bigcap_{z\neq0} \{X\in\mathbf{S}^n \mid z^TXz\ge0\}.
```

对每个 $z\neq0$，$z^TXz$ 是 $X$ 的一个（非恒零的）linear function（线性函数），所以集合 $\{X\in\mathbf{S}^n \mid z^TXz\ge0\}$ 实际上是 $\mathbf{S}^n$ 中的 halfspaces（半空间）。因此半正定锥是无穷多个半空间的交，从而是凸的。

<span style="color:#00838f;">**[例 2.8]** 考虑集合

```math
S = \{x\in\mathbb{R}^m \mid |p(t)|\le1 \text{ 对 } |t|\le\pi/3\}, \tag{2.10}
```

其中 $p(t)=\sum_{k=1}^m x_k\cos kt$。集合 $S$ 可以表示为无穷多个 slabs（板状体/带状区域）的交：$S=\bigcap_{|t|\le\pi/3} S_t$，其中

```math
S_t = \{x \mid -1\le(\cos t,\dots,\cos mt)^Tx\le1\},
```

因此是凸的。$m=2$ 时该定义与该集合见图 2.13 与 2.14。

<!-- p.50/51 -->

在上面的例子里，我们通过把集合表示成（可能无穷多个）半空间的交来确立凸性。§2.5.1 将给出一个逆命题：每个 closed convex set（闭凸集）都是（通常无穷多个）半空间的交。事实上，闭凸集 $S$ 是所有包含它的半空间的交：

```math
S = \bigcap\{H \mid H \text{ 为半空间},\; S\subseteq H\}.
```

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">2.3.2 Affine functions（仿射函数）</span>



回顾：函数 $f:\mathbb{R}^n\to\mathbb{R}^m$ 是 affine（仿射）的，若它是线性函数加常数，即形如 $f(x)=Ax+b$，$A\in\mathbb{R}^{m\times n}$，$b\in\mathbb{R}^m$。设 $S\subseteq\mathbb{R}^n$ 凸，$f:\mathbb{R}^n\to\mathbb{R}^m$ 是仿射函数，则 $S$ 在 $f$ 下的 image（像）

```math
f(S) = \{f(x) \mid x\in S\}
```

是凸的。同样，若 $f:\mathbb{R}^k\to\mathbb{R}^n$ 是仿射函数，则 $S$ 在 $f$ 下的 inverse image（原像/逆像）

```math
f^{-1}(S) = \{x \mid f(x)\in S\}
```

也是凸的。

两个简单例子是 scaling（缩放）与 translation（平移）。若 $S\subseteq\mathbb{R}^n$ 凸，$\alpha\in\mathbb{R}$，$a\in\mathbb{R}^n$，则集合 $\alpha S$ 与 $S+a$ 凸，其中

```math
\alpha S = \{\alpha x \mid x\in S\},\qquad S+a = \{x+a \mid x\in S\}.
```

凸集向部分坐标的 projection（投影）是凸的：若 $S\subseteq\mathbb{R}^m\times\mathbb{R}^n$ 凸，则

```math
T = \{x_1\in\mathbb{R}^m \mid (x_1,x_2)\in S \text{ 对某个 } x_2\in\mathbb{R}^n\}
```

凸。两个集合的 sum（和）定义为

```math
S_1+S_2 = \{x+y \mid x\in S_1,\; y\in S_2\}.
```

若 $S_1$ 与 $S_2$ 凸，则 $S_1+S_2$ 凸。为看出这一点：若 $S_1,S_2$ 凸，则 direct product 或 Cartesian product（笛卡尔积）

```math
S_1\times S_2 = \{(x_1,x_2) \mid x_1\in S_1,\; x_2\in S_2\}
```

也凸，而这个集合在线性函数 $f(x_1,x_2)=x_1+x_2$ 下的像正是 $S_1+S_2$。



我们还可以考虑 $S_1,S_2\subseteq\mathbb{R}^n\times\mathbb{R}^m$ 的 partial sum（部分和）：

```math
S = \{(x, y_1+y_2) \mid (x,y_1)\in S_1,\; (x,y_2)\in S_2\},
```

其中 $x\in\mathbb{R}^n$，$y_i\in\mathbb{R}^m$。当 $m=0$ 时部分和给出 $S_1\cap S_2$；当 $n=0$ 时它就是集合加法。凸集的部分和是凸的（见习题 2.16）。

<span style="color:#00838f;">**[例 2.9]** **多面体。** 多面体 $\{x \mid Ax\preceq b,\; Cx=d\}$ 可以表示为非负卦限与原点的笛卡尔积在仿射函数 $f(x)=(b-Ax,\; d-Cx)$ 下的原像：

```math
\{x \mid Ax\preceq b,\; Cx=d\} = \{x \mid f(x)\in\mathbb{R}^m_+\times\{0\}\}.
```

<span style="color:#00838f;">**[例 2.10]** **线性矩阵不等式的解集。** 条件

```math
A(x) = x_1A_1+\cdots+x_nA_n \preceq B \tag{2.11}
```

（其中 $B,A_i\in\mathbf{S}^m$）称为关于 $x$ 的 linear matrix inequality（线性矩阵不等式，LMI）。（注意它与普通线性不等式 $a^Tx=x_1a_1+\cdots+x_na_n\le b$（$b,a_i\in\mathbb{R}$）的相似性。）线性矩阵不等式的解集 $\{x \mid A(x)\preceq B\}$ 是凸的：它正是半正定锥在仿射函数 $f:\mathbb{R}^n\to\mathbf{S}^m$，$f(x)=B-A(x)$ 下的原像。

<span style="color:#00838f;">**[例 2.11]** **双曲锥（hyperbolic cone）。** 集合

```math
\{x \mid x^TPx\le(c^Tx)^2,\; c^Tx\ge0\}
```

（其中 $P\in\mathbf{S}^n_+$，$c\in\mathbb{R}^n$）是凸的，因为它是 second-order cone（二阶锥）

```math
\{(z,t) \mid z^Tz\le t^2,\; t\ge0\}
```

在仿射函数 $f(x)=(P^{1/2}x,\; c^Tx)$ 下的原像。

<span style="color:#00838f;">**[例 2.12]** **椭球。** 椭球

```math
\mathcal{E} = \{x \mid (x-x_c)^TP^{-1}(x-x_c)\le1\}
```

（$P\in\mathbf{S}^n_{++}$）是单位欧氏球 $\{u \mid \|u\|_2\le1\}$ 在仿射映射 $f(u)=P^{1/2}u+x_c$ 下的像。（它也是单位球在仿射映射 $g(x)=P^{-1/2}(x-x_c)$ 下的原像。）

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">2.3.3 Linear-fractional and perspective functions（线性分式函数与透视函数）</span>



本节研究一类称为 linear-fractional（线性分式）的函数，它比仿射函数更一般，但仍然保持凸性。

**透视函数（The perspective function）。** 我们定义 perspective function（透视函数）$P:\mathbb{R}^{n+1}\to\mathbb{R}^n$，定义域 $\mathbf{dom}\,P=\mathbb{R}^n\times\mathbb{R}_{++}$，为 $P(z,t)=z/t$。（$\mathbb{R}_{++}$ 表示正数集：$\mathbb{R}_{++}=\{x\in\mathbb{R}\mid x>0\}$。）透视函数把向量 scale（缩放）或 normalize（归一化）使最后一个分量为 1，然后丢掉最后一个分量。

<span style="color:#00838f;">**[注 2.1]** 我们可以把透视函数解释为 pin-hole camera（针孔相机）的作用。$\mathbb{R}^3$ 中的针孔相机由一个不透明的水平平面 $x_3=0$（在原点处有一个允许光线通过的单个针孔）和一个水平 image plane（成像平面）$x_3=-1$ 组成。位于相机上方（即 $x_3>0$）的物体 $x$ 在成像平面上成像于点 $-(x_1/x_3, x_2/x_3, 1)$。丢掉像点的最后一个分量（它总为 $-1$），$x$ 处的点成像于 $y=-(x_1/x_3, x_2/x_3)=-P(x)$。见图 2.15。

<!-- p.53/54 -->

若 $C\subseteq\mathbf{dom}\,P$ 凸，则它的像

```math
P(C) = \{P(x) \mid x\in C\}
```

是凸的。这个结果非常直观：透过针孔相机看一个凸的物体，得到凸的像。为确立这一事实，我们证明线段在透视函数下映为线段（这同样直观：透过针孔相机看线段得到线段的像）。设 $x=(\tilde{x},x_{n+1})$，$y=(\tilde{y},y_{n+1})\in\mathbb{R}^{n+1}$，$x_{n+1}>0$，$y_{n+1}>0$，则对 $0\le\theta\le1$，

```math
P(\theta x+(1-\theta)y) = \frac{\theta\tilde{x}+(1-\theta)\tilde{y}}{\theta x_{n+1}+(1-\theta)y_{n+1}} = \mu P(x) + (1-\mu)P(y),
```

其中

```math
\mu = \frac{\theta x_{n+1}}{\theta x_{n+1}+(1-\theta)y_{n+1}}\in[0,1].
```



$\theta$ 与 $\mu$ 之间的对应是单调的：当 $\theta$ 在 0 与 1 之间变化（扫出线段 $[x,y]$）时，$\mu$ 也在 0 与 1 之间变化（扫出线段 $[P(x),P(y)]$）。这表明 $P([x,y])=[P(x),P(y)]$。

现在设 $C$ 凸且 $C\subseteq\mathbf{dom}\,P$（即对一切 $x\in C$ 有 $x_{n+1}>0$），$x,y\in C$。为确立 $P(C)$ 的凸性，须证线段 $[P(x),P(y)]$ 在 $P(C)$ 内；但该线段正是线段 $[x,y]$ 在 $P$ 下的像，故属于 $P(C)$。

凸集在透视函数下的原像也是凸的：若 $C\subseteq\mathbb{R}^n$ 凸，则

```math
P^{-1}(C) = \{(x,t)\in\mathbb{R}^{n+1} \mid x/t\in C,\; t>0\}
```

凸。为证明，设 $(x,t)\in P^{-1}(C)$，$(y,s)\in P^{-1}(C)$，$0\le\theta\le1$，须证

```math
\theta(x,t)+(1-\theta)(y,s)\in P^{-1}(C),
```

即

```math
\frac{\theta x+(1-\theta)y}{\theta t+(1-\theta)s}\in C
```



（$\theta t+(1-\theta)s>0$ 显然）。这由

```math
\frac{\theta x+(1-\theta)y}{\theta t+(1-\theta)s} = \mu(x/t) + (1-\mu)(y/s)
```

得到，其中

```math
\mu = \frac{\theta t}{\theta t+(1-\theta)s}\in[0,1].
```

**线性分式函数（Linear-fractional functions）。** 线性分式函数由透视函数与仿射函数复合而成。设 $g:\mathbb{R}^n\to\mathbb{R}^{m+1}$ 是仿射的，即

```math
g(x) = \begin{bmatrix}A\\ c^T\end{bmatrix}x + \begin{bmatrix}b\\ d\end{bmatrix}, \tag{2.12}
```

其中 $A\in\mathbb{R}^{m\times n}$，$b\in\mathbb{R}^m$，$c\in\mathbb{R}^n$，$d\in\mathbb{R}$。函数 $f:\mathbb{R}^n\to\mathbb{R}^m$ 由 $f=P\circ g$ 给出，即

```math
f(x) = (Ax+b)/(c^Tx+d),\qquad \mathbf{dom}\,f = \{x \mid c^Tx+d>0\}, \tag{2.13}
```

称为 linear-fractional（线性分式）函数或 projective（射影）函数。当 $c=0$ 且 $d>0$ 时，$f$ 的定义域是 $\mathbb{R}^n$，$f$ 是仿射函数。因此可以把仿射函数与线性函数看作线性分式函数的特例。

<span style="color:#00838f;">**[注 2.2]** **射影解释。** 用矩阵

```math
Q = \begin{bmatrix}A&b\\ c^T&d\end{bmatrix}\in\mathbb{R}^{(m+1)\times(n+1)} \tag{2.14}
```

来表示线性分式函数常常很方便：它作用于（乘）形如 $(x,1)$ 的点，得到 $(Ax+b,\; c^Tx+d)$，

<!-- p.55/56 -->

其结果再被缩放/归一化使最后一个分量为 1，即得 $(f(x),1)$。

这个表示可以几何化地解释：把 $\mathbb{R}^n$ 与 $\mathbb{R}^{n+1}$ 中的一族 rays（射线）联系起来。对每个点 $z\in\mathbb{R}^n$，关联 $\mathbb{R}^{n+1}$ 中的（开）射线 $\mathcal{P}(z)=\{t(z,1)\mid t>0\}$，其最后一个分量取正值。反之，$\mathbb{R}^{n+1}$ 中任何基在原点、最后分量取正值的射线都可写成 $\mathcal{P}(v)=\{t(v,1)\mid t\ge0\}$（某个 $v\in\mathbb{R}^n$）。这个 $\mathbb{R}^n$ 与「最后分量为正的射线构成的半空间」之间的（射影）对应 $\mathcal{P}$ 是一一且到上的。

线性分式函数 (2.13) 可以表示为

```math
f(x) = \mathcal{P}^{-1}(Q\mathcal{P}(x)).
```

即：从 $x\in\mathbf{dom}\,f$（即 $c^Tx+d>0$）出发，构造 $\mathbb{R}^{n+1}$ 中的射线 $\mathcal{P}(x)$；矩阵为 $Q$ 的线性变换作用在这条射线上产生另一条射线 $Q\mathcal{P}(x)$（由于 $x\in\mathbf{dom}\,f$，该射线的最后分量取正值）；最后用逆射影变换恢复出 $f(x)$。



与透视函数一样，线性分式函数保持凸性。若 $C$ 凸且位于 $f$ 的定义域内（即对 $x\in C$ 有 $c^Tx+d>0$），则其像 $f(C)$ 凸。这可由上面的结果立即得出：$C$ 在仿射映射 (2.12) 下的像凸，而所得集合在透视函数 $P$ 下的像（即 $f(C)$）也凸。同样，若 $C\subseteq\mathbb{R}^m$ 凸，则原像 $f^{-1}(C)$ 凸。

<span style="color:#00838f;">**[例 2.13]** **条件概率（conditional probabilities）。** 设 $u$ 与 $v$ 是分别取值于 $\{1,\dots,n\}$ 与 $\{1,\dots,m\}$ 的随机变量，$p_{ij}$ 表示 $\mathrm{prob}(u=i, v=j)$。则 conditional probability（条件概率）$f_{ij}=\mathrm{prob}(u=i\mid v=j)$ 由

```math
f_{ij} = \frac{p_{ij}}{\sum_{k=1}^n p_{kj}}
```

给出，即 $f$ 是由 $p$ 经一个线性分式映射得到的。由此：若 $C$ 是 $(u,v)$ 的 joint probabilities（联合概率）的一个凸集，则相应的「给定 $v$ 下 $u$ 的条件概率」的集合也凸。

图 2.16 展示了一个集合 $C\subseteq\mathbb{R}^2$ 及其在线性分式函数

```math
f(x) = \frac{1}{x_1+x_2+1}\,x,\qquad \mathbf{dom}\,f=\{(x_1,x_2)\mid x_1+x_2+1>0\}
```

下的像。

> <span style="color:#2471a3;">**[译者注｜跨课程连接]** 例 2.13 与你大二概率论（6.431/Bertsekas）直接衔接：贝叶斯后验 $P(u\mid v)$ 对似然 $p$ 是线性分式映射——「联合分布的凸集 → 后验分布的凸集」。这正是贝叶斯滤波、EM 等算法中「凸性得以保持」的底层机制。</span>

## <span style="color:#c0392b;">2.4 Generalized inequalities（广义不等式）</span>

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">2.4.1 Proper cones and generalized inequalities（真锥与广义不等式）</span>



若锥 $K\subseteq\mathbb{R}^n$ 满足以下条件，则称为 proper cone（真锥）：

- $K$ 是 convex（凸）的。
- $K$ 是 closed（闭）的。
- $K$ 是 solid（实心的），即它有非空的 interior（内部）。
- $K$ 是 pointed（尖）的，即它不包含任何直线（等价地，$x\in K,\;-x\in K \implies x=0$）。

真锥 $K$ 可以用来定义一个 generalized inequality（广义不等式）——$\mathbb{R}^n$ 上一个具有 $\mathbb{R}$ 上标准序的许多性质的 partial ordering（偏序）。我们把真锥 $K$ 与 $\mathbb{R}^n$ 上的偏序

```math
x\preceq_K y \iff y-x\in K
```

联系起来。同样写 $x\succeq_K y$ 表示 $y\preceq_K x$。类似地定义相应的 strict partial ordering（严格偏序）：

```math
x\prec_K y \iff y-x\in\mathbf{int}\,K,
```

并写 $x\succ_K y$ 表示 $y\prec_K x$。（为了区分广义不等式 $\preceq_K$ 与严格广义不等式，有时把 $\preceq_K$ 称为 nonstrict generalized inequality，非严格广义不等式。）

当 $K=\mathbb{R}_+$ 时，偏序 $\preceq_K$ 就是 $\mathbb{R}$ 上通常的序 $\le$，严格偏序 $\prec_K$ 就是通常的严格序 $<$。所以广义不等式把 $\mathbb{R}$ 中普通（非严格与严格）不等式作为特例包含进来。

<span style="color:#00838f;">**[例 2.14]** **非负卦限与逐分量不等式。** 非负卦限 $K=\mathbb{R}^n_+$ 是真锥。相应的广义不等式 $\preceq_K$ 对应向量间的逐分量不等式：$x\preceq_K y$ 意味着 $x_i\le y_i$（$i=1,\dots,n$）。相应的严格不等式对应逐分量严格不等式：$x\prec_K y$ 意味着 $x_i\lt y_i$（$i=1,\dots,n$）。与 $\mathbb{R}^n_+$ 相联系的非严格与严格偏序出现得如此频繁，以至于我们把下标 $\mathbb{R}^n_+$ 省略：当符号 $\preceq$ 或 $\prec$ 出现在向量之间时，默认就是这种含义。

<span style="color:#00838f;">**[例 2.15]** **半正定锥与矩阵不等式。** 半正定锥 $\mathbf{S}^n_+$ 是 $\mathbf{S}^n$ 中的真锥。相应的广义不等式 $\preceq_K$ 就是通常的 matrix inequality（矩阵不等式）：$X\preceq_K Y$ 意味着 $Y-X$ 半正定。$\mathbf{S}^n_+$ 的内部（在 $\mathbf{S}^n$ 中）由正定矩阵组成，所以严格广义不等式也与对称矩阵间通常的严格不等式一致：$X\prec_K Y$ 意味着 $Y-X$ 正定。这里偏序同样出现得太频繁以致省略下标：对对称矩阵我们直接写 $X\preceq Y$ 或 $X\prec Y$，默认广义不等式是关于半正定锥的。

<span style="color:#00838f;">**[例 2.16]** **在 $[0,1]$ 上非负的多项式之锥。** 令 $K$ 定义为

```math
K = \{c\in\mathbb{R}^n \mid c_1+c_2t+\cdots+c_nt^{n-1}\ge0 \text{ 对 } t\in[0,1]\}, \tag{2.15}
```

即 $K$ 是在区间 $[0,1]$ 上非负的 $n-1$ 次多项式（的系数）构成的锥。可以证明 $K$ 是真锥；其内部是「在 $[0,1]$ 上取正的多项式」的系数集合。两个向量 $c,d\in\mathbb{R}^n$ 满足 $c\preceq_K d$ 当且仅当

```math
c_1+c_2t+\cdots+c_nt^{n-1}\le d_1+d_2t+\cdots+d_nt^{n-1}
```

对一切 $t\in[0,1]$ 成立。

**广义不等式的性质（Properties of generalized inequalities）。** 广义不等式 $\preceq_K$ 满足许多性质，例如：

- $\preceq_K$ 对加法保持：若 $x\preceq_K y$ 且 $u\preceq_K v$，则 $x+u\preceq_K y+v$。
- $\preceq_K$ 是 transitive（传递）的：若 $x\preceq_K y$ 且 $y\preceq_K z$，则 $x\preceq_K z$。
- $\preceq_K$ 对非负缩放保持：若 $x\preceq_K y$ 且 $\alpha\ge0$，则 $\alpha x\preceq_K \alpha y$。
- $\preceq_K$ 是 reflexive（自反）的：$x\preceq_K x$。
- $\preceq_K$ 是 antisymmetric（反对称）的：若 $x\preceq_K y$ 且 $y\preceq_K x$，则 $x=y$。
- $\preceq_K$ 对极限保持：若 $x_i\preceq_K y_i$（$i=1,2,\dots$），且 $x_i\to x$、$y_i\to y$（$i\to\infty$），则 $x\preceq_K y$。



相应的严格广义不等式 $\prec_K$ 满足（例如）：

- 若 $x\prec_K y$，则 $x\preceq_K y$。
- 若 $x\prec_K y$ 且 $u\preceq_K v$，则 $x+u\prec_K y+v$。
- 若 $x\prec_K y$ 且 $\alpha>0$，则 $\alpha x\prec_K \alpha y$。
- $x\nprec_K x$。
- 若 $x\prec_K y$，则对足够小的 $u$ 与 $v$，有 $x+u\prec_K y+v$。

这些性质由 $\preceq_K$、$\prec_K$ 的定义与真锥的性质继承而来；见习题 2.30。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">2.4.2 Minimum and minimal elements（最小元与极小元）</span>



广义不等式的记号（$\preceq_K$、$\prec_K$）意在暗示与 $\mathbb{R}$ 上普通不等式（$\le$、$<$）的类比。虽然普通不等式的许多性质对广义不等式成立，但有些重要的并不成立。最明显的差异是：$\mathbb{R}$ 上的 $\le$ 是 linear ordering（线性序/全序）——任何两点都可比较，即要么 $x\le y$ 要么 $y\le x$。这个性质对其他广义不等式不成立。其后果之一是：在广义不等式的语境下，minimum（最小）与 maximum（最大）之类的概念变得更复杂。本节简要讨论这一点。

我们说 $x\in S$ 是 $S$ 的 minimum element（最小元）（关于广义不等式 $\preceq_K$），如果对每个 $y\in S$ 都有 $x\preceq_K y$。类似地定义 maximum element（最大元）。若一个集合有最小（最大）元，则它是唯一的。一个相关概念是 minimal element（极小元）。我们说 $x\in S$ 是 $S$ 的极小元（关于 $\preceq_K$），如果 $y\in S$、$y\preceq_K x$ 仅当 $y=x$。类似地定义 maximal element（极大元）。一个集合可以有许多不同的极小（极大）元。

我们可以用简单的集合记号描述最小元与极小元。点 $x\in S$ 是 $S$ 的最小元当且仅当

```math
S\subseteq x+K.
```

这里 $x+K$ 表示所有与 $x$ 可比较且（按 $\preceq_K$）大于等于 $x$ 的点。点 $x\in S$ 是极小元当且仅当

```math
(x-K)\cap S = \{x\}.
```

这里 $x-K$ 表示所有与 $x$ 可比较且（按 $\preceq_K$）小于等于 $x$ 的点；它与 $S$ 的公共点只有 $x$。

对 $K=\mathbb{R}_+$（它诱导 $\mathbb{R}$ 上通常的序）来说，minimal 与 minimum 的概念相同，与集合最小元的通常定义一致。

<span style="color:#00838f;">**[例 2.17]** 考虑锥 $\mathbb{R}^2_+$，它在 $\mathbb{R}^2$ 中诱导逐分量不等式。这里可以给出极小元与最小元的简单几何描述：不等式 $x\preceq y$ 意味着 $y$ 在 $x$ 的「右上方」。说 $x\in S$ 是集合 $S$ 的最小元，意味着 $S$ 的其他所有点都在 $x$ 的右上方；说 $x$ 是 $S$ 的极小元，意味着没有其他点位于 $x$ 的「左下方」。见图 2.17。

<span style="color:#00838f;">**[例 2.18]** **对称矩阵集合的最小元与极小元。** 给每个 $A\in\mathbf{S}^n_{++}$ 关联一个以原点为中心的椭球

```math
\mathcal{E}_A = \{x \mid x^TA^{-1}x\le1\}.
```

我们有 $A\preceq B$ 当且仅当 $\mathcal{E}_A\subseteq\mathcal{E}_B$。设 $v_1,\dots,v_k\in\mathbb{R}^n$ 给定，定义

```math
S = \{P\in\mathbf{S}^n_{++} \mid v_i^TP^{-1}v_i\le1,\; i=1,\dots,k\},
```



它对应「包含点 $v_1,\dots,v_k$ 的椭球」的集合。集合 $S$ 没有最小元：对任何包含这些点的椭球，都能找到另一个包含这些点、且与它不可比较的椭球。一个椭球是极小的，如果它包含这些点，但没有更小的椭球也包含它们。图 2.18 展示了 $\mathbb{R}^2$ 中 $k=2$ 的例子。



本节描述一个后面很重要的想法：用超平面或仿射函数去 separate（分离）不相交的凸集。基本结果是 separating hyperplane theorem（分离超平面定理）：设 $C$ 与 $D$ 是非空、不相交的凸集，即 $C\cap D=\varnothing$。则存在 $a\neq0$ 与 $b$，使得对所有 $x\in C$ 有 $a^Tx\le b$，对所有 $x\in D$ 有 $a^Tx\ge b$。换言之，仿射函数 $a^Tx-b$ 在 $C$ 上非正、在 $D$ 上非负。超平面 $\{x\mid a^Tx=b\}$ 称为集合 $C$ 与 $D$ 的 separating hyperplane（分离超平面），或说它分离 $C$ 与 $D$。（见图 2.19。）

**分离超平面定理的证明。** 这里考虑一个特殊情形，把证明推广到一般情形留作习题（习题 2.22）。我们假设 $C$ 与 $D$ 之间的（欧氏）distance（距离）

```math
\mathbf{dist}(C,D) = \inf\{\|u-v\|_2 \mid u\in C,\; v\in D\}
```



为正，且存在点 $c\in C$ 与 $d\in D$ 达到最小距离，即 $\|c-d\|_2=\mathbf{dist}(C,D)$。（例如当 $C$ 与 $D$ 是闭的、且其中一个是有界的时候，这些条件满足。）定义

```math
a = d-c,\qquad b = \frac{\|d\|_2^2-\|c\|_2^2}{2}.
```

我们将证明仿射函数

```math
f(x) = a^Tx-b = (d-c)^T\bigl(x-(1/2)(d+c)\bigr)
```

在 $C$ 上非正、在 $D$ 上非负，即超平面 $\{x\mid a^Tx=b\}$ 分离 $C$ 与 $D$。这个超平面垂直于 $c$ 与 $d$ 之间的线段并穿过其中点（见图 2.20）。

先证 $f$ 在 $D$ 上非负（$f$ 在 $C$ 上非正的证明类似，或通过交换 $C$ 与 $D$ 并考虑 $-f$ 得到）。反设存在点 $u\in D$ 使

```math
f(u) = (d-c)^T\bigl(u-(1/2)(d+c)\bigr) < 0. \tag{2.16}
```



把 $f(u)$ 写成

```math
f(u) = (d-c)^T\bigl(u-d+(1/2)(d-c)\bigr) = (d-c)^T(u-d) + (1/2)\|d-c\|_2^2,
```

可见 (2.16) 蕴含 $(d-c)^T(u-d)<0$。现在注意

```math
\left.\frac{d}{dt}\|d+t(u-d)-c\|_2^2\right|_{t=0} = 2(d-c)^T(u-d) < 0,
```

所以对某个小的 $t>0$（$t\le1$），有

```math
\|d+t(u-d)-c\|_2 < \|d-c\|_2,
```

即点 $d+t(u-d)$ 比 $d$ 更靠近 $c$。但 $D$ 是凸的且包含 $d$ 与 $u$，故 $d+t(u-d)\in D$。这与「$d$ 是 $D$ 中离 $C$ 最近的点」的假设矛盾。

<span style="color:#00838f;">**[例 2.19]** **仿射集与凸集的分离。** 设 $C$ 凸，$D$ 仿射，即 $D=\{Fu+g \mid u\in\mathbb{R}^m\}$（$F\in\mathbb{R}^{n\times m}$）。设 $C$ 与 $D$ 不相交，则由分离超平面定理，存在 $a\neq0$ 与 $b$ 使 $a^Tx\le b$（$x\in C$）、$a^Tx\ge b$（$x\in D$）。而 $a^Tx\ge b$ 对一切 $x\in D$ 成立，意味着 $a^TFu\ge b-a^Tg$ 对一切 $u\in\mathbb{R}^m$ 成立。线性函数在 $\mathbb{R}^m$ 上有下界仅当它恒为零，故 $a^TF=0$（从而 $b\le a^Tg$）。于是我们得出：存在 $a\neq0$ 使 $F^Ta=0$ 且 $a^Tx\le a^Tg$ 对一切 $x\in C$ 成立。



**严格分离（Strict separation）。** 我们构造的分离超平面满足更强的条件：$a^Tx\lt b$ 对所有 $x\in C$，且 $a^Tx>b$ 对所有 $x\in D$。这称为 $C$ 与 $D$ 的 strict separation（严格分离）。简单的例子表明：一般而言，不相交的凸集未必能被超平面严格分离（即使两个集合都是闭的；见习题 2.23）。但在许多特殊情形下可以建立严格分离。

<span style="color:#00838f;">**[例 2.20]** **一个点与一个闭凸集的严格分离。** 设 $C$ 是闭凸集，$x_0\notin C$。则存在严格分离 $x_0$ 与 $C$ 的超平面。为看出这一点，注意对某个 $\epsilon>0$，集合 $C$ 与 $B(x_0,\epsilon)$ 不相交。由分离超平面定理，存在 $a\neq0$ 与 $b$ 使 $a^Tx\le b$（$x\in C$）、$a^Tx\ge b$（$x\in B(x_0,\epsilon)$）。利用 $B(x_0,\epsilon)=\{x_0+u \mid \|u\|_2\le\epsilon\}$，第二个条件可写成 $a^T(x_0+u)\ge b$ 对所有 $\|u\|_2\le\epsilon$ 成立。使左边最小的 $u$ 是 $u=-\epsilon a/\|a\|_2$；代入得 $a^Tx_0-\epsilon\|a\|_2\ge b$。因此仿射函数

```math
f(x) = a^Tx-b-\epsilon\|a\|_2/2
```

在 $C$ 上为负，在 $x_0$ 处为正。

由此立即得到前面提到过的一个事实：闭凸集是所有包含它的半空间的交。设 $C$ 闭且凸，$S$ 为所有包含 $C$ 的半空间之交集。显然 $x\in C \implies x\in S$。反之，设存在 $x\in S$、$x\notin C$。由严格分离结果，存在严格分离 $x$ 与 $C$ 的超平面，即存在一个包含 $C$ 但不含 $x$ 的半空间；换言之 $x\notin S$，矛盾。

**逆分离超平面定理（Converse separating hyperplane theorems）。** 分离超平面定理的逆命题（「存在分离超平面」蕴含「$C$ 与 $D$ 不相交」）一般不真，除非对 $C$ 或 $D$ 附加超出凸性的额外条件。一个简单的反例：$C=D=\{0\}\subseteq\mathbb{R}$，此时超平面 $x=0$ 分离 $C$ 与 $D$。



通过给 $C$、$D$ 加条件，可以导出各种逆分离定理。一个非常简单的例子：设 $C$ 与 $D$ 是凸集，$C$ 是 open（开）的，且存在仿射函数 $f$ 在 $C$ 上非正、在 $D$ 上非负，则 $C$ 与 $D$ 不相交。（为看出这一点：先注意 $f$ 在 $C$ 上必为负——若 $f$ 在 $C$ 的某点为零，则 $f$ 会在该点附近取正值，矛盾；而 $f$ 在 $C$ 上为负、在 $D$ 上非负，所以 $C$ 与 $D$ 必不相交。）把这个逆命题与分离超平面定理合起来，得到如下结果：任何两个凸集 $C$ 与 $D$（至少一个是开的）不相交，当且仅当存在分离超平面。

<span style="color:#00838f;">**[例 2.21]** **严格线性不等式的择一定理（theorem of alternatives）。** 我们推导严格线性不等式组

```math
Ax \prec b \tag{2.17}
```

可解的充要条件。这组不等式 infeasible（不可行）当且仅当（凸）集合

```math
C = \{b-Ax \mid x\in\mathbb{R}^n\},\qquad D = \mathbb{R}^m_{++} = \{y\in\mathbb{R}^m \mid y\succ0\}
```

不相交。集合 $D$ 是开的；$C$ 是仿射集。于是由上面的结果，$C$ 与 $D$ 不相交当且仅当存在分离超平面，即非零 $\lambda\in\mathbb{R}^m$ 与 $\mu\in\mathbb{R}$ 使 $\lambda^Ty\le\mu$ 在 $C$ 上、$\lambda^Ty\ge\mu$ 在 $D$ 上成立。

<!-- p.64/65 -->

每个条件都可化简。第一个意味着 $\lambda^T(b-Ax)\le\mu$ 对所有 $x$ 成立，正如例 2.19 那样可推出 $A^T\lambda=0$ 与 $\lambda^Tb\le\mu$。第二个不等式意味着 $\lambda^Ty\ge\mu$ 对所有 $y\succ0$ 成立，这蕴含 $\mu\le0$ 且 $\lambda\succeq0$、$\lambda\neq0$。
