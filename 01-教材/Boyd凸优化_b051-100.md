### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">2.5.2 Supporting hyperplanes（支撑超平面）</span>



设 $C\subseteq\mathbb{R}^n$，$x_0$ 是其边界 $\mathbf{bd}\,C$ 上的点，即

```math
x_0\in\mathbf{bd}\,C = \mathbf{cl}\,C \setminus \mathbf{int}\,C.
```

若 $a\neq0$ 满足 $a^Tx\le a^Tx_0$ 对所有 $x\in C$，则超平面 $\{x \mid a^Tx=a^Tx_0\}$ 称为 $C$ 在点 $x_0$ 处的 supporting hyperplane（支撑超平面）。这等价于说：点 $x_0$ 与集合 $C$ 被超平面 $\{x\mid a^Tx=a^Tx_0\}$ 分离。几何解释是：超平面 $\{x\mid a^Tx=a^Tx_0\}$ 在 $x_0$ 处与 $C$ 相切（tangent），且半空间 $\{x\mid a^Tx\le a^Tx_0\}$ 包含 $C$。（见图 2.21。）

一个基本结果称为 supporting hyperplane theorem（支撑超平面定理）：对任何非空凸集 $C$ 与任何 $x_0\in\mathbf{bd}\,C$，存在 $C$ 在 $x_0$ 处的支撑超平面。支撑超平面定理很容易从分离超平面定理推出。分两种情形：若 $C$ 的内部非空，对集合 $\{x_0\}$ 与 $\mathbf{int}\,C$ 应用分离超平面定理即可；若 $C$ 的内部为空，则 $C$ 必位于维数小于 $n$ 的仿射集中，任何包含该仿射集的超平面都包含 $C$ 与 $x_0$，因而是（平凡的）支撑超平面。

支撑超平面定理也有一个部分逆命题：若一个集合是闭的、内部非空、且在其边界的每一点都有支撑超平面，则它是凸的。（见习题 2.27。）

<span style="color:#00838f;">**[例 2.23]** **非负卦限。** 锥 $\mathbb{R}^n_+$ 是它自己的对偶：

<span style="color:#00838f;">**[例 2.24]** **半正定锥。** 在对称 $n\times n$ 矩阵集合 $\mathbf{S}^n$ 上使用标准内积 $\mathbf{tr}(XY)=\sum_{i,j=1}^n X_{ij}Y_{ij}$（见 §A.1.1），半正定锥 $\mathbf{S}^n_+$ 是自对偶的，即对 $X,Y\in\mathbf{S}^n$：

```math
\mathbf{tr}(XY)\ge0 \text{ 对所有 } X\succeq0 \iff Y\succeq0.
```

我们来确立这个事实。设 $Y\notin\mathbf{S}^n_+$，则存在 $q\in\mathbb{R}^n$ 使

```math
q^TYq = \mathbf{tr}(qq^TY) < 0.
```

于是半正定矩阵 $X=qq^T$ 满足 $\mathbf{tr}(XY)<0$；故 $Y\notin(\mathbf{S}^n_+)^*$。反之设 $X,Y\in\mathbf{S}^n_+$。把 $X$ 按特征值分解写成 $X=\sum_{i=1}^n\lambda_iq_iq_i^T$（特征值 $\lambda_i\ge0$，$i=1,\dots,n$），则

```math
\mathbf{tr}(YX) = \mathbf{tr}\Bigl(Y\sum_{i=1}^n\lambda_iq_iq_i^T\Bigr) = \sum_{i=1}^n\lambda_iq_i^TYq_i\ge0.
```

这表明 $Y\in(\mathbf{S}^n_+)^*$。

对偶锥满足若干性质，例如：

- $K^*$ 是闭的且凸的。
- $K_1\subseteq K_2$ 蕴含 $K_2^*\subseteq K_1^*$。
- 若 $K$ 有非空内部，则 $K^*$ 是尖的（pointed）。
- 若 $K$ 的闭包是尖的，则 $K^*$ 有非空内部。

（见习题 2.31。）这些性质表明：若 $K$ 是真锥，则其对偶 $K^*$ 也是真锥，而且 $K^{**}=K$。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">2.6.2 Dual generalized inequalities（对偶广义不等式）</span>



现在设凸锥 $K$ 是 proper（真）的，因此它诱导广义不等式 $\preceq_K$。其对偶锥 $K^*$ 也是真的，因此也诱导一个广义不等式。我们把广义不等式 $\preceq_{K^*}$ 称为广义不等式 $\preceq_K$ 的 dual（对偶）。

联系广义不等式与其对偶的一些重要性质：

- $x\preceq_K y$ 当且仅当 $\lambda^Tx\le\lambda^Ty$ 对所有 $\lambda\succeq_{K^*}0$ 成立。
- $x\prec_K y$ 当且仅当 $\lambda^Tx<\lambda^Ty$ 对所有 $\lambda\succeq_{K^*}0$、$\lambda\neq0$ 成立。

由于 $K=K^{**}$，与 $\preceq_{K^*}$ 相关联的对偶广义不等式是 $\preceq_K$，所以把广义不等式与其对偶互换后这些性质同样成立。具体例子：$\lambda\preceq_{K^*}\mu$ 当且仅当 $\lambda^Tx\le\mu^Tx$ 对所有 $x\succeq_K0$ 成立。

<span style="color:#00838f;">**[例 2.26]** **线性严格广义不等式的择一定理。** 设 $K\subseteq\mathbb{R}^m$ 是真锥。考虑严格广义不等式

```math
Ax\prec_K b, \tag{2.21}
```

其中 $x\in\mathbb{R}^n$。我们来推导这个不等式的择一定理。设它不可行，即仿射集 $\{b-Ax \mid x\in\mathbb{R}^n\}$ 与开凸集 $\mathbf{int}\,K$ 不相交。则存在分离超平面：非零 $\lambda\in\mathbb{R}^m$ 与 $\mu\in\mathbb{R}$ 使 $\lambda^T(b-Ax)\le\mu$（对所有 $x$）、$\lambda^Ty\ge\mu$（对所有 $y\in\mathbf{int}\,K$）。第一个条件蕴含 $A^T\lambda=0$ 与 $\lambda^Tb\le\mu$；第二个条件蕴含 $\lambda^Ty\ge\mu$ 对所有 $y\in K$ 成立，这只在 $\lambda\in K^*$ 且 $\mu\le0$ 时可能。

合起来：若 (2.21) 不可行，则存在 $\lambda$ 使

```math
\lambda\neq0,\qquad \lambda\succeq_{K^*}0,\qquad A^T\lambda=0,\qquad \lambda^Tb\le0. \tag{2.22}
```

<!-- p.68/69 -->

现在证逆命题：若 (2.22) 成立，则不等式组 (2.21) 不可行。反设两个不等式组同时成立。则 $\lambda^T(b-Ax)>0$，因为 $\lambda\neq0$、$\lambda\succeq_{K^*}0$、$b-Ax\succ_K0$。但用 $A^T\lambda=0$ 得 $\lambda^T(b-Ax)=\lambda^Tb\le0$，矛盾。

因此不等式组 (2.21) 与 (2.22) 是 alternatives（择一的）：对任意数据 $A,b$，恰好一个可行。（这推广了 $K=\mathbb{R}^m_+$ 的特例 (2.17)、(2.18)。）

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">2.6.3 Minimum and minimal elements via dual inequalities（借助对偶不等式刻画最小元与极小元）</span>



我们可以用对偶广义不等式来刻画（可能非凸的）集合 $S\subseteq\mathbb{R}^m$ 关于真锥 $K$ 诱导的广义不等式的最小元与极小元。

**最小元的对偶刻画（Dual characterization of minimum element）。** 先考虑最小元的刻画：$x$ 是 $S$ 的最小元（关于 $\preceq_K$），当且仅当对所有 $\lambda\succ_{K^*}0$，$x$ 是 $\lambda^Tz$ 在 $z\in S$ 上的 unique minimizer（唯一最小化点）。几何上这意味着：对任何 $\lambda\succ_{K^*}0$，超平面

```math
\{z \mid \lambda^T(z-x)=0\}
```

是 $S$ 在 $x$ 处的 strict supporting hyperplane（严格支撑超平面）。（严格支撑超平面指该超平面与 $S$ 只交于点 $x$。）注意不需要集合 $S$ 的凸性。（见图 2.23。）

<!-- p.69/70 -->

为证明此结果，设 $x$ 是 $S$ 的最小元（即 $x\preceq_K z$ 对所有 $z\in S$），且 $\lambda\succ_{K^*}0$。设 $z\in S$、$z\neq x$。由于 $x$ 是最小元，有 $z-x\succeq_K0$。由 $\lambda\succ_{K^*}0$、$z-x\succeq_K0$、$z-x\neq0$ 得 $\lambda^T(z-x)>0$。由于 $z$ 是 $S$ 中任意不等于 $x$ 的元素，这表明 $x$ 是 $\lambda^Tz$ 在 $S$ 上的唯一最小化点。反之，设对所有 $\lambda\succ_{K^*}0$，$x$ 是 $\lambda^Tz$ 在 $S$ 上的唯一最小化点，但 $x$ 不是 $S$ 的最小元。则存在 $z\in S$ 使 $z\not\succeq_K x$。由于 $z-x\not\succeq_K0$，存在 $\tilde{\lambda}\succeq_{K^*}0$ 使 $\tilde{\lambda}^T(z-x)<0$。于是在 $\tilde{\lambda}$ 的邻域内有 $\lambda^T(z-x)<0$（$\lambda\succ_{K^*}0$），与「$x$ 是 $\lambda^Tz$ 在 $S$ 上的唯一最小化点」矛盾。

**极小元的对偶刻画（Dual characterization of minimal elements）。** 再看极小元的类似刻画。这里必要条件与充分条件之间有一个 gap（间隙）。若 $\lambda\succ_{K^*}0$ 且 $x$ 最小化 $\lambda^Tz$（$z\in S$），则 $x$ 是极小的。（见图 2.24。）

<!-- p.70/71 -->

为证明：设 $\lambda\succ_{K^*}0$，$x$ 最小化 $\lambda^Tz$（$z\in S$），但 $x$ 不是极小的，即存在 $z\in S$、$z\neq x$、$z\preceq_Kx$。则 $\lambda^T(x-z)>0$，与「$x$ 是最小化点」的假设矛盾。

逆命题一般不成立：点 $x$ 可以是 $S$ 的极小元，却对任何 $\lambda$ 都不是 $\lambda^Tz$（$z\in S$）的最小化点，如图 2.25 所示。此图提示凸性在逆命题中起重要作用，事实确实如此：只要集合 $S$ 凸，就可以说——对任何极小元 $x$，存在非零的 $\lambda\succeq_{K^*}0$ 使 $x$ 最小化 $\lambda^Tz$（$z\in S$）。

为证明：设 $x$ 极小，即 $((x-K)\setminus\{x\})\cap S=\varnothing$。对凸集 $(x-K)\setminus\{x\}$ 与 $S$ 应用分离超平面定理，得存在 $\lambda\neq0$ 与 $\mu$ 使 $\lambda^T(x-y)\le\mu$（对所有 $y\in K$）、$\lambda^Tz\ge\mu$（对所有 $z\in S$）。由第一个不等式得 $\lambda\succeq_{K^*}0$。由 $x\in S$ 且 $x\in x-K$ 得 $\lambda^Tx=\mu$，所以第二个不等式表明 $\mu$ 是 $\lambda^Tz$ 在 $S$ 上的最小值。因此 $x$ 是 $\lambda^Tz$ 在 $S$ 上的最小化点，其中 $\lambda\neq0$、$\lambda\succeq_{K^*}0$。



Strict convexity 也可以用一阶条件刻画：$f$ 是 strictly convex 当且仅当 $\operatorname{dom} f$ 是 convex set，且对 $x, y \in \operatorname{dom} f$、$x \ne y$，有

```math
f(y) > f(x) + \nabla f(x)^{T}(y - x)
```

即式 (3.3)。

对 concave function 有相应的刻画：$f$ 是 concave 当且仅当 $\operatorname{dom} f$ 是 convex set，且对一切 $x, y \in \operatorname{dom} f$ 有 $f(y) \le f(x) + \nabla f(x)^{T}(y-x)$。

<span style="color:#2471a3;">**[proof]**</span> <span style="color:#c0392b">*Proof of first-order convexity condition（一阶 convexity 条件的证明）.*</span>

要证 (3.2)，先看 $n = 1$ 的情形：我们证明可微函数 $f : \mathbf{R} \to \mathbf{R}$ 是 convex 当且仅当对 $\operatorname{dom} f$ 中一切 $x$ 与 $y$ 有

```math
f(y) \ge f(x) + f'(x)(y - x)
```

即式 (3.4)。

先设 $f$ 是 convex，且 $x, y \in \operatorname{dom} f$。由于 $\operatorname{dom} f$ 是 convex set（即一个 interval），可知对一切 $0 < t \le 1$ 有 $x + t(y-x) \in \operatorname{dom} f$；再由 $f$ 的 convexity，

```math
f(x + t(y-x)) \le (1-t) f(x) + t f(y)
```

两边同除以 $t$，得到

```math
f(y) \ge f(x) + \frac{f(x + t(y-x)) - f(x)}{t}
```

令 $t \to 0$ 取极限即得 (3.4)。

为证充分性，设该函数在 $\operatorname{dom} f$（是一个 interval）中对一切 $x$ 与 $y$ 都满足 (3.4)。任取 $x \ne y$ 与 $0 \le \lambda \le 1$，令 $z = \lambda x + (1-\lambda)y$。把 (3.4) 用两次，得到

```math
f(x) \ge f(z) + f'(z)(x - z), \qquad f(y) \ge f(z) + f'(z)(y - z)
```

第一条乘 $\lambda$、第二条乘 $1 - \lambda$，再相加，得

```math
\lambda f(x) + (1-\lambda) f(y) \ge f(z)
```

这就证明了 $f$ 是 convex。

现在证明一般情形 $f : \mathbf{R}^n \to \mathbf{R}$。设 $x, y \in \mathbf{R}^n$，考虑把 $f$ 限制到过这两点的 line 上，即由 $g(t) = f(ty + (1-t)x)$ 定义的函数，于是 $\nabla g(t) = \nabla f(ty + (1-t)x)^{T}(y-x)$。

先设 $f$ 是 convex，这蕴含 $g$ 是 convex，故由上面的论证有 $g(1) \ge g(0) + g'(0)$，即

```math
f(y) \ge f(x) + \nabla f(x)^{T}(y - x)
```

反之，设这条不等式对任意 $x$ 与 $y$ 都成立。那么只要 $ty + (1-t)x \in \operatorname{dom} f$ 且 $\tilde{t}y + (1-\tilde{t})x \in \operatorname{dom} f$，就有

```math
f(ty + (1-t)x) \ge f(\tilde{t}y + (1-\tilde{t})x) + \nabla f(\tilde{t}y + (1-\tilde{t})x)^{T}(y-x)(t - \tilde{t})
```

即 $g(t) \ge g(\tilde{t}) + g'(\tilde{t})(t - \tilde{t})$。我们已经看到，这蕴含 $g$ 是 convex。



这个逆定理不能加强为 $\lambda\succ_{K^*}0$：例子表明点 $x$ 可以是凸集 $S$ 的极小点，却对任何 $\lambda\succ_{K^*}0$ 都不是最小化点（见图 2.26 左）。同样，「$\lambda\succeq_{K^*}0$ 时 $\lambda^Tz$ 在 $S$ 上的最小化点必是极小的」也不成立（见图 2.26 右）。

<span style="color:#00838f;">**[例 2.27]** **Pareto 最优生产前沿。** 考虑一个需要 $n$ 种 resources（资源）（如劳动力、电力、天然气、水）来制造的产品。该产品可以按许多方式生产。对每种 production method（生产方式），关联一个 resource vector（资源向量）$x\in\mathbb{R}^n$，其中 $x_i$ 表示该方法制造产品所消耗的第 $i$ 种资源的量。我们假设 $x_i\ge0$（即资源被生产方式消耗）且资源是有价值的（所以任何资源用得越少越好）。production set（生产集）$P\subseteq\mathbb{R}^n$ 定义为对应某种生产方式的所有资源向量的集合。

资源向量为 $P$ 的极小元（关于逐分量不等式）的生产方式称为 Pareto optimal（Pareto 最优）或 efficient（有效率的）。$P$ 的极小元集合称为 efficient production frontier（有效生产前沿）。

Pareto 最优有一个简单解释。我们说一种生产方式（资源向量 $x$）比另一种（资源向量 $y$）better（更好），如果 $x_i\le y_i$ 对所有 $i$，且对某个 $i$ 有 $x_i\lt y_i$。换言之，一种生产方式比另一种好，是指它每种资源用量都不多于对方，且至少一种资源确实用得更少。这正对应 $x\preceq y$、$x\neq y$。于是可以说：一种生产方式是 Pareto 最优的（有效率的），当且仅当没有比它更好的生产方式。

我们可以通过在 $P$ 上最小化

```math
\lambda^Tx = \lambda_1x_1+\cdots+\lambda_nx_n
```

来寻找 Pareto 最优的生产方式（即极小资源向量），其中 $\lambda\succ0$ 任意。这里向量 $\lambda$ 有一个简单解释：$\lambda_i$ 是第 $i$ 种资源的 price（价格）。在 $P$ 上最小化 $\lambda^Tx$，就是在找（按价格 $\lambda_i$ 计的）总成本最低的生产方式。只要价格全为正，得到的生产方式就保证是有效率的。这些想法见图 2.27。

### 3.1.5 Examples（例子）

我们前面已经提到：所有 linear 与 affine function 都既是 convex 又是 concave；也描述了 convex 与 concave 的 quadratic function。本节再给几个 convex 与 concave function 的例子。先从 $\mathbf{R}$ 上以 $x$ 为变量的一些函数说起。

- **Exponential（指数）.** 对任意 $a \in \mathbf{R}$，$e^{ax}$ 在 $\mathbf{R}$ 上是 convex。


**Log-sum-exp.** log-sum-exp 函数的 Hessian 是

```math
\nabla^2 f(x) = \frac{1}{(\mathbf{1}^{T} z)^2} \left( (\mathbf{1}^{T} z) \operatorname{diag}(z) - z z^{T} \right)
```

其中 $z = (e^{x_1}, \ldots, e^{x_n})$。要验证 $\nabla^2 f(x) \succeq 0$，必须证明对一切 $v$ 有 $v^{T} \nabla^2 f(x) v \ge 0$，即

```math
v^{T} \nabla^2 f(x) v = \frac{1}{(\mathbf{1}^{T} z)^2} \left( \left(\sum_{i=1}^{n} z_i\right) \left(\sum_{i=1}^{n} v_i^2 z_i\right) - \left(\sum_{i=1}^{n} v_i z_i\right)^2 \right) \ge 0
```

而这可由 Cauchy-Schwarz inequality（Cauchy-Schwarz 不等式）$(\mathbf{a}^{T}\mathbf{a})(\mathbf{b}^{T}\mathbf{b}) \ge (\mathbf{a}^{T}\mathbf{b})^2$ 取分量 $a_i = v_i \sqrt{z_i}$、$b_i = \sqrt{z_i}$ 而得。

**Geometric mean.** 用类似方法可以证明 geometric mean $f(x) = \left(\prod_{i=1}^{n} x_i\right)^{1/n}$ 在 $\operatorname{dom} f = \mathbf{R}_{++}^{n}$ 上是 concave。它的 Hessian $\nabla^2 f(x)$ 由

```math
\frac{\partial^2 f}{\partial x_k^2} = -(n-1) \frac{\left(\prod_{i=1}^{n} x_i\right)^{1/n}}{n^2 x_k^2}, \qquad \frac{\partial^2 f}{\partial x_k \partial x_l} = \frac{\left(\prod_{i=1}^{n} x_i\right)^{1/n}}{n^2 x_k x_l} \quad \text{for } k \ne l
```

给出，并可写成

```math
\nabla^2 f(x) = -\frac{\left(\prod_{i=1}^{n} x_i\right)^{1/n}}{n^2} \left( n \operatorname{diag}(1/x_1^2, \ldots, 1/x_n^2) - q q^{T} \right)
```

其中 $q_i = 1/x_i$。我们必须证明 $\nabla^2 f(x) \preceq 0$，即对一切 $v$ 有

```math
v^{T} \nabla^2 f(x) v = -\frac{\left(\prod_{i=1}^{n} x_i\right)^{1/n}}{n^2} \left( n \sum_{i=1}^{n} v_i^2/x_i^2 - \left(\sum_{i=1}^{n} v_i/x_i\right)^2 \right) \le 0
```

这同样由 Cauchy-Schwarz inequality $(\mathbf{a}^{T}\mathbf{a})(\mathbf{b}^{T}\mathbf{b}) \ge (\mathbf{a}^{T}\mathbf{b})^2$ 取 $\mathbf{a} = \mathbf{1}$、$b_i = v_i/x_i$ 而得。

**Log-determinant.** 对函数 $f(X) = \log \det X$，我们可以通过考察任意一条 line、即 $X = Z + tV$（其中 $Z, V \in \mathbf{S}^n$）来验证 concavity。定义 $g(t) = f(Z + tV)$，并把 $g$ 限制在使 $Z + tV \succ 0$ 的那些 $t$ 的区间上。不失一般性可以假定 $t = 0$ 在该区间内部，即 $Z \succ 0$。我们有

```math
\begin{aligned}
g(t) &= \log \det(Z + tV) \\
&= \log \det\left(Z^{1/2}(I + t Z^{-1/2} V Z^{-1/2}) Z^{1/2}\right) \\
&= \sum_{i=1}^{n} \log(1 + t \lambda_i) + \log \det Z
\end{aligned}
```

其中 $\lambda_1, \ldots, \lambda_n$ 是 $Z^{-1/2} V Z^{-1/2}$ 的 eigenvalues。因此

```math
g'(t) = \sum_{i=1}^{n} \frac{\lambda_i}{1 + t \lambda_i}, \qquad g''(t) = -\sum_{i=1}^{n} \frac{\lambda_i^2}{(1 + t \lambda_i)^2}
```

由 $g''(t) \le 0$ 可知 $f$ 是 concave。



### 3.1.6 Sublevel sets（下水平集）

函数 $f : \mathbf{R}^n \to \mathbf{R}$ 的 $\alpha$-sublevel set（$\alpha$-下水平集）定义为

```math
C_\alpha = \{x \in \operatorname{dom} f \mid f(x) \le \alpha\}
```

<span style="color:#00838f">convex function 的 sublevel set 对任何 $\alpha$ 值都是 convex 的。</span>由 convexity 的定义可以直接得到这个证明：若 $x, y \in C_\alpha$，则 $f(x) \le \alpha$ 且 $f(y) \le \alpha$，故对 $0 \le \lambda \le 1$ 有 $f(\lambda x + (1-\lambda)y) \le \alpha$，于是 $\lambda x + (1-\lambda)y \in C_\alpha$。

反过来不成立：一个函数的全部 sublevel set 都 convex，它本身却可能不是 convex function。例如 $f(x) = -e^{x}$ 在 $\mathbf{R}$ 上不是 convex（实际上它是 strictly concave），但它的全部 sublevel set 都是 convex 的。

若 $f$ 是 concave，则它的 $\beta$-superlevel set（$\beta$-上水平集）$\{x \in \operatorname{dom} f \mid f(x) \ge \beta\}$ 是 convex set。sublevel set 性质往往是证明某个集合 convex 的好办法：把该集合写成某个 convex function 的 sublevel set，或某个 concave function 的 superlevel set。

<span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">**Example 3.3**</span> <span style="color:#c0392b">（几何平均与算术平均）</span>

$x \in \mathbf{R}_{+}^{n}$ 的几何平均与算术平均分别是

```math
G(x) = \left(\prod_{i=1}^{n} x_i\right)^{1/n}, \qquad A(x) = \frac{1}{n} \sum_{i=1}^{n} x_i
```

（在 $G$ 的定义中取 $0^{1/n} = 0$）。arithmetic-geometric mean inequality（算术-几何平均不等式）说的是 $G(x) \le A(x)$。

设 $0 \le \lambda \le 1$，考虑集合

```math
\{x \in \mathbf{R}_{+}^{n} \mid G(x) \ge \lambda A(x)\}
```

即满足「几何平均至少是算术平均的 $\lambda$ 倍」的那些向量构成的集合。这个集合是 convex 的，因为它是函数 $G(x) - \lambda A(x)$ 的 $0$-superlevel set，而该函数是 concave 的。事实上这个集合是 positively homogeneous（正齐次）的，所以它是一个 convex cone（凸锥）。

### 3.1.7 Epigraph（上图）

函数 $f : \mathbf{R}^n \to \mathbf{R}$ 的 graph（图像）定义为

```math
\{(x, f(x)) \mid x \in \operatorname{dom} f\}
```

它是 $\mathbf{R}^{n+1}$ 的一个子集。函数 $f : \mathbf{R}^n \to \mathbf{R}$ 的 epigraph（上图）定义为

```math
\operatorname{epi} f = \{(x, t) \mid x \in \operatorname{dom} f,\ f(x) \le t\}
```

它也是 $\mathbf{R}^{n+1}$ 的子集。（`epi' 意为「在上方」，故 epigraph 意为「graph 之上的部分」。）定义见图 3.5。

<span style="color:#00838f">convex set 与 convex function 之间的联系正是通过 epigraph 建立的：一个函数是 convex，当且仅当它的 epigraph 是 convex set。</span>一个函数是 concave，当且仅当它的 hypograph（下图），即

```math
\operatorname{hypo} f = \{(x, t) \mid t \le f(x)\}
```

是 convex set。

<span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">**Example 3.4**</span> <span style="color:#c0392b">Matrix fractional function（矩阵分式函数）.</span>

函数 $f : \mathbf{R}^n \times \mathbf{S}^n \to \mathbf{R}$，定义为

```math
f(x, Y) = x^{T} Y^{-1} x
```

在 $\operatorname{dom} f = \mathbf{R}^n \times \mathbf{S}_{++}^{n}$ 上是 convex。（它推广了 quadratic-over-linear function $f(x, y) = x^2/y$，后者的 $\operatorname{dom} f = \mathbf{R} \times \mathbf{R}_{++}$。）

要建立 $f$ 的 convexity，一个容易的办法是通过它的 epigraph：

```math
\begin{aligned}
\operatorname{epi} f &= \{(x, Y, t) \mid Y \succ 0,\ x^{T} Y^{-1} x \le t\} \\
&= \left\{(x, Y, t) \ \middle|\ \begin{bmatrix} Y & x \\ x^{T} & t \end{bmatrix} \succeq 0,\ Y \succ 0 \right\}
\end{aligned}
```

这里用了块矩阵 positive semidefinite 的 Schur complement condition（Schur 补条件，见 §A.5.5）。最后一个条件是 $(x, Y, t)$ 上的 linear matrix inequality（线性矩阵不等式），因此 $\operatorname{epi} f$ 是 convex 的。

对 $n = 1$ 的特殊情形，matrix fractional function 退化为 quadratic-over-linear function $x^2/y$，相应的 LMI 表示为

```math
\begin{bmatrix} y & x \\ x & t \end{bmatrix} \succeq 0, \qquad y > 0
```

（它的 graph 见图 3.3）。

关于 convex function 的许多结果，都可以借助 epigraph 做几何式的证明（或解释），即套用关于 convex set 的结果。举例来说，考虑 convexity 的一阶条件

```math
f(y) \ge f(x) + \nabla f(x)^{T}(y - x)
```

其中 $f$ 是 convex 且 $x, y \in \operatorname{dom} f$。我们可以用 $\operatorname{epi} f$ 几何地解释这条基本不等式。若 $(y, t) \in \operatorname{epi} f$，则

```math
t \ge f(y) \ge f(x) + \nabla f(x)^{T}(y - x)
```

可以把它写成：

```math
(y, t) \in \operatorname{epi} f \Longrightarrow \begin{bmatrix} \nabla f(x) \\ -1 \end{bmatrix}^{T} \begin{bmatrix} y - x \\ t - f(x) \end{bmatrix} \le 0
```

### 3.1.8 Jensen's inequality and extensions（Jensen 不等式及其推广）

基本不等式 (3.1)，即

```math
f(\lambda x + (1-\lambda) y) \le \lambda f(x) + (1-\lambda) f(y)
```

有时被称作 Jensen's inequality（Jensen 不等式）。它很容易推广到多于两个点的 convex combination（凸组合）：若 $f$ 是 convex，$x_1, \ldots, x_k \in \operatorname{dom} f$，且 $\theta_1, \ldots, \theta_k \ge 0$、$\theta_1 + \cdots + \theta_k = 1$，则

```math
f(\theta_1 x_1 + \cdots + \theta_k x_k) \le \theta_1 f(x_1) + \cdots + \theta_k f(x_k)
```

与 convex set 的情形一样，这条不等式还可推广到 infinite sum（无限和）、integral（积分）与 expected value（期望值）。例如，若 $p(x) \ge 0$ 在 $S \subseteq \operatorname{dom} f$ 上，且 $\int_S p(x) \, dx = 1$，则

```math
f\left(\int_S p(x) x \, dx\right) \le \int_S f(x) p(x) \, dx
```

前提是这些积分存在。最一般的情形下，我们可以取任何支撑集位于 $\operatorname{dom} f$ 内的 probability measure（概率测度）。若 $x$ 是一个以概率一落在 $\operatorname{dom} f$ 中的随机变量，且 $f$ 是 convex，则

```math
f(\mathbf{E} x) \le \mathbf{E} f(x)
```

即式 (3.5)，前提是相关期望存在。从这条一般形式可以还原出基本不等式 (3.1)：取随机变量 $x$ 的支撑集为 $\{x_1, x_2\}$，其概率为 $\operatorname{\mathbf{prob}}(x = x_1) = \theta$、$\operatorname{\mathbf{prob}}(x = x_2) = 1 - \theta$。



于是不等式 (3.5) 反过来刻画了 convexity：若 $f$ 不是 convex，则存在一个以概率一落在 $\operatorname{dom} f$ 中的随机变量 $x$，使得 $f(\mathbf{E} x) > \mathbf{E} f(x)$。

现在这些不等式统统被称作 Jensen's inequality，尽管 Jensen 本人研究的那条不等式是非常简单的

```math
f\left(\frac{x + y}{2}\right) \le \frac{f(x) + f(y)}{2}
```

<span style="color:#c0392b">**Remark 3.2（注 3.2）**</span> 我们可以这样解释 (3.5)。设 $x \in \operatorname{dom} f \subseteq \mathbf{R}^n$，$z$ 是 $\mathbf{R}^n$ 中任一零均值随机向量。则

```math
\mathbf{E} f(x + z) \ge f(x)
```

也就是说，randomization 或 dithering（随机化或抖动，即给自变量加上一个零均值随机向量）平均而言不能减小 convex function 的取值。

### 3.1.9 Inequalities（不等式）

许多著名不等式都可以通过对某个恰当的 convex function 使用 Jensen's inequality 推出。（确实，convexity 与 Jensen's inequality 可以作为一整套不等式理论的基础。）举个简单的例子，考虑 arithmetic-geometric mean inequality：

```math
\sqrt{ab} \le (a + b)/2
```

即式 (3.6)，对 $a, b \ge 0$ 成立。函数 $-\log x$ 是 convex；取 $\theta = 1/2$ 的 Jensen's inequality 给出

```math
-\log \frac{a + b}{2} \le -\frac{\log a}{2} - \frac{\log b}{2}
```

两边取指数即得 (3.6)。

再举一个不那么平凡的例子，我们来证明 Hölder's inequality（Hölder 不等式）：对 $p > 1$、$1/p + 1/q = 1$，以及 $x, y \in \mathbf{R}^n$，有

```math
\sum_{i=1}^{n} x_i y_i \le \left(\sum_{i=1}^{n} |x_i|^p\right)^{1/p} \left(\sum_{i=1}^{n} |y_i|^q\right)^{1/q}
```

由 $-\log x$ 的 convexity 与一般 $\theta$ 的 Jensen's inequality，可得更一般的 arithmetic-geometric mean inequality

```math
a^{\theta} b^{1-\theta} \le \theta a + (1-\theta) b
```

它对 $a, b \ge 0$、$0 \le \theta \le 1$ 成立。取

```math
a = \frac{|x_i|^p}{\sum_{j=1}^{n} |x_j|^p}, \qquad b = \frac{|y_i|^q}{\sum_{j=1}^{n} |y_j|^q}, \qquad \theta = 1/p
```

即得

```math
\left(\frac{|x_i|^p}{\sum_{j=1}^{n} |x_j|^p}\right)^{1/p} \left(\frac{|y_i|^q}{\sum_{j=1}^{n} |y_j|^q}\right)^{1/q} \le \frac{|x_i|^p}{p \sum_{j=1}^{n} |x_j|^p} + \frac{|y_i|^q}{q \sum_{j=1}^{n} |y_j|^q}
```

对 $i$ 求和即得 Hölder's inequality。



## 3.2 Operations that preserve convexity（保凸运算）

本节描述一些保持函数 convexity 或 concavity 的运算，以及一些允许我们构造新的 convex 与 concave function 的运算。我们先从加法、缩放、逐点上确界这类简单运算讲起，然后描述一些更精巧的运算（其中一部分把简单运算作为特例包含在内）。

### 3.2.1 Nonnegative weighted sums（非负加权和）

显然，若 $f$ 是 convex function 且 $\alpha \ge 0$，则函数 $\alpha f$ 是 convex。若 $f_1$ 与 $f_2$ 都是 convex function，则它们的和 $f_1 + f_2$ 也是 convex。把非负缩放与加法合起来看：全部 convex function 构成的集合本身就是一个 convex cone（凸锥）——convex function 的非负加权和

```math
f = w_1 f_1 + \cdots + w_m f_m
```

是 convex 的。同样地，concave function 的非负加权和是 concave 的。strictly convex（concave）function 的非负、非零加权和是 strictly convex（concave）的。

这些性质可以推广到 infinite sum 与 integral。例如，若对每个 $y \in \mathcal{A}$，$f(x, y)$ 关于 $x$ 是 convex，且对每个 $y \in \mathcal{A}$ 有 $w(y) \ge 0$，则由

```math
g(x) = \int_{\mathcal{A}} w(y) f(x, y) \, dy
```

定义的函数 $g$ 关于 $x$ 是 convex（前提是该积分存在）。

convexity 在非负缩放与加法下保持不变这一事实很容易直接验证，也可以从相应的 epigraph 看出来。例如，若 $w \ge 0$ 且 $f$ 是 convex，则

```math
\operatorname{epi}(wf) = \begin{bmatrix} I & 0 \\ 0 & w \end{bmatrix} \operatorname{epi} f
```

它是 convex 的，因为 convex set 在线性映射下的像仍是 convex。

### 3.2.2 Composition with an affine mapping（与 affine 映射复合）

设 $f : \mathbf{R}^n \to \mathbf{R}$、$A \in \mathbf{R}^{n \times m}$、$b \in \mathbf{R}^n$。定义 $g : \mathbf{R}^m \to \mathbf{R}$ 为

```math
g(x) = f(Ax + b)
```

其 $\operatorname{dom} g = \{x \mid Ax + b \in \operatorname{dom} f\}$。则若 $f$ 是 convex，$g$ 也是 convex；若 $f$ 是 concave，$g$ 也是 concave。

### 3.2.3 Pointwise maximum and supremum（逐点最大与逐点上确界）

若 $f_1$ 与 $f_2$ 是 convex function，则它们的 pointwise maximum（逐点最大）$f$，定义为

```math
f(x) = \max\{f_1(x), f_2(x)\}
```

其 $\operatorname{dom} f = \operatorname{dom} f_1 \cap \operatorname{dom} f_2$，也是 convex。这条性质容易验证：若 $0 \le \lambda \le 1$ 且 $x, y \in \operatorname{dom} f$，则

```math
\begin{aligned}
f(\lambda x + (1-\lambda)y) &= \max\{f_1(\lambda x + (1-\lambda)y),\ f_2(\lambda x + (1-\lambda)y)\} \\
&\le \max\{\lambda f_1(x) + (1-\lambda) f_1(y),\ \lambda f_2(x) + (1-\lambda) f_2(y)\} \\
&\le \lambda \max\{f_1(x), f_2(x)\} + (1-\lambda) \max\{f_1(y), f_2(y)\} \\
&= \lambda f(x) + (1-\lambda) f(y)
\end{aligned}
```

这就建立了 $f$ 的 convexity。也很容易证明：若 $f_1, \ldots, f_m$ 都是 convex，则它们的 pointwise maximum

```math
f(x) = \max\{f_1(x), \ldots, f_m(x)\}
```

也是 convex。



<span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">**Example 3.5**</span> <span style="color:#c0392b">Piecewise-linear functions（分段线性函数）.</span>

函数

```math
f(x) = \max\{a_1^{T} x + b_1, \ldots, a_L^{T} x + b_L\}
```

定义了一个 piecewise-linear（分段线性，严格说是分段仿射）函数（至多 $L$ 个区域）。它是 convex 的，因为它是若干 affine function 的 pointwise maximum。

反过来也成立：任何至多 $L$ 个区域的 piecewise-linear convex function 都可以写成这种形式（见 exercise 3.29）。

<span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">**Example 3.6**</span> <span style="color:#c0392b">Sum of r largest components（最大 r 个分量之和）.</span>

对 $x \in \mathbf{R}^n$，用 $x_{[i]}$ 记 $x$ 的第 $i$ 大的分量，即

```math
x_{[1]} \ge x_{[2]} \ge \cdots \ge x_{[n]}
```

是按非增序排好的 $x$ 的各分量。则函数

```math
f(x) = \sum_{i=1}^{r} x_{[i]}
```

即 $x$ 的最大 $r$ 个元素之和，是 convex function。这可以通过把它写成

```math
f(x) = \sum_{i=1}^{r} x_{[i]} = \max\{x_{i_1} + \cdots + x_{i_r} \mid 1 \le i_1 < i_2 < \cdots < i_r \le n\}
```

看出来，即写成 $x$ 的 $r$ 个不同分量所有可能和中的最大者。由于它是 $n!/(r!(n-r)!)$ 个 linear function 的 pointwise maximum，故是 convex。

作为推广可以证明：只要 $w_1 \ge w_2 \ge \cdots \ge w_r \ge 0$，函数 $\sum_{i=1}^{r} w_i x_{[i]}$ 就是 convex（见 exercise 3.19）。



函数 $f:\mathbb{R}^n\to\mathbb{R}$ 是 convex（凸）的，如果 $\mathbf{dom}\,f$ 是凸集，且对所有 $x,y\in\mathbf{dom}\,f$ 与满足 $0\le\theta\le1$ 的 $\theta$，有

```math
f(\theta x+(1-\theta)y) \le \theta f(x)+(1-\theta)f(y). \tag{3.1}
```

几何上，这个不等式意味着 $(x,f(x))$ 与 $(y,f(y))$ 之间的线段——即从 $x$ 到 $y$ 的 chord（弦）——位于 $f$ 的图像之上（图 3.1）。

若当 $x\neq y$ 且 $0<\theta<1$ 时 (3.1) 中严格不等号成立，则称 $f$ 是 strictly convex（严格凸）的。若 $-f$ 是凸的，则称 $f$ 是 concave（凹）的；若 $-f$ 严格凸，则称 $f$ 是 strictly concave（严格凹）的。

对 affine function（仿射函数），(3.1) 中总取等号，所以所有仿射（从而也包括线性）函数既凸又凹。反之，任何既凸又凹的函数都是仿射的。

函数是凸的，当且仅当它限制到任何与其定义域相交的直线上都是凸的。换言之，$f$ 凸当且仅当对所有 $x\in\mathbf{dom}\,f$ 与所有 $v$，函数 $g(t)=f(x+tv)$ 是凸的（在其定义域 $\{t \mid x+tv\in\mathbf{dom}\,f\}$ 上）。这个性质非常有用：它允许我们通过把函数限制到直线上来检验凸性。

凸函数分析是一个发展成熟的领域，我们不做深入展开。一个简单结果是：凸函数在其定义域的 relative interior（相对内部）上是 continuous（连续）的；它只可能在相对边界上不连续。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">3.1.2 Extended-value extensions（扩值延拓）</span>



把凸函数延拓到整个 $\mathbb{R}^n$（在定义域之外取值 $\infty$）常常很方便。若 $f$ 凸，我们定义其 extended-value extension（扩值延拓）$\tilde{f}:\mathbb{R}^n\to\mathbb{R}\cup\{\infty\}$：

```math
\tilde{f}(x) = \begin{cases} f(x) & x\in\mathbf{dom}\,f\\ \infty & x\notin\mathbf{dom}\,f. \end{cases}
```

延拓 $\tilde{f}$ 定义在整个 $\mathbb{R}^n$ 上，取值于 $\mathbb{R}\cup\{\infty\}$。由延拓 $\tilde{f}$ 可恢复原函数 $f$ 的定义域：$\mathbf{dom}\,f=\{x \mid \tilde{f}(x)<\infty\}$。

延拓可以简化记号：不再需要显式描述定义域，也不必在每次提到 $f(x)$ 时加上限定语「对所有 $x\in\mathbf{dom}\,f$」。例如基本定义不等式 (3.1)，用延拓 $\tilde{f}$ 可以表述为：对 $0<\theta<1$，

```math
\tilde{f}(\theta x+(1-\theta)y)\le\theta\tilde{f}(x)+(1-\theta)\tilde{f}(y)
```

对任意 $x,y$ 成立（$\theta=0$ 或 $\theta=1$ 时不等式恒成立）。当然这里必须用 extended arithmetic（扩展算术）与扩展序来解释该不等式。当 $x,y$ 都属于 $\mathbf{dom}\,f$ 时，它与 (3.1) 一致；若任一在定义域外，则右边为 $\infty$，不等式自然成立。作为这种记号技巧的另一个例子：设 $f_1,f_2$ 是 $\mathbb{R}^n$ 上两个凸函数，逐点求和 $f=f_1+f_2$ 的定义域是 $\mathbf{dom}\,f=\mathbf{dom}\,f_1\cap\mathbf{dom}\,f_2$，且对 $x\in\mathbf{dom}\,f$ 有 $f(x)=f_1(x)+f_2(x)$。用扩值延拓可以直接说：对任意 $x$，$\tilde{f}(x)=\tilde{f}_1(x)+\tilde{f}_2(x)$——方程中 $f$ 的定义域被自动定义为 $\mathbf{dom}\,f_1\cap\mathbf{dom}\,f_2$，因为只要 $x\notin\mathbf{dom}\,f_1$ 或 $x\notin\mathbf{dom}\,f_2$ 就有 $\tilde{f}(x)=\infty$。这个例子依赖扩展算术来自动定义定义域。

本书中，在歧义无害时，我们用同一个符号表示凸函数及其延拓。这等价于假设所有凸函数都被隐式延拓，即在定义域外定义为 $\infty$。

<span style="color:#00838f;">**[例 3.1]** **凸集的示性函数（indicator function）。** 设 $C\subseteq\mathbb{R}^n$ 是凸集，考虑定义域为 $C$、对所有 $x\in C$ 取值 $I_C(x)=0$ 的（凸）函数。也就是说，该函数在集合 $C$ 上恒为零。其扩值延拓为

```math
\tilde{I}_C(x) = \begin{cases} 0 & x\in C\\ \infty & x\notin C. \end{cases}
```

凸函数 $\tilde{I}_C$ 称为集合 $C$ 的 indicator function（示性函数）。



我们可以用示性函数 $\tilde{I}_C$ 玩好几种记号把戏。例如「在集合 $C$ 上最小化函数 $f$（设 $f$ 定义在整个 $\mathbb{R}^n$ 上）」与「在整个 $\mathbb{R}^n$ 上最小化函数 $f+\tilde{I}_C$」是同一回事：按我们的约定，$f+\tilde{I}_C$ 就是 $f$ 限制到集合 $C$。

类似地，可以把凹函数延拓为在定义域外取值 $-\infty$。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">3.1.3 First-order conditions（一阶条件）</span>

设 $f$ 是 differentiable（可微）的（即梯度 $\nabla f$ 在定义域每一点存在，且定义域是开的）。则 $f$ 凸当且仅当 $\mathbf{dom}\,f$ 凸，且

```math
f(y) \ge f(x)+\nabla f(x)^T(y-x) \tag{3.2}
```

对所有 $x,y\in\mathbf{dom}\,f$ 成立（见图 3.2）。

由 $y$ 表达的仿射函数 $f(x)+\nabla f(x)^T(y-x)$ 当然是 $f$ 在 $x$ 附近的 first-order Taylor approximation（一阶泰勒近似）。不等式 (3.2) 陈述：对凸函数，一阶泰勒近似其实是函数的 global underestimator（全局低估器）。反之，若一个函数的一阶泰勒近似总是它的全局低估器，则该函数是凸的。

不等式 (3.2) 表明：从凸函数的局部信息（它在一点的值与导数）可以导出全局信息（它的一个全局低估器）。这也许是凸函数最重要的性质，它解释了凸函数与凸优化问题的一些非凡性质。作为一个简单例子，(3.2) 表明：若 $\nabla f(x)=0$，则对所有 $y\in\mathbf{dom}\,f$ 有 $f(y)\ge f(x)$，即 $x$ 是函数 $f$ 的 global minimizer（全局最小化点）。



严格凸也可以用一阶条件刻画：$f$ 严格凸当且仅当 $\mathbf{dom}\,f$ 凸，且对 $x,y\in\mathbf{dom}\,f$、$x\neq y$ 有

```math
f(y) > f(x)+\nabla f(x)^T(y-x). \tag{3.3}
```

对凹函数有相应的刻画：$f$ 凹当且仅当 $\mathbf{dom}\,f$ 凸且 $f(y)\le f(x)+\nabla f(x)^T(y-x)$ 对所有 $x,y\in\mathbf{dom}\,f$ 成立。

**一阶凸性条件的证明。** 先证 $n=1$ 的情形：可微函数 $f:\mathbb{R}\to\mathbb{R}$ 凸当且仅当

```math
f(y)\ge f(x)+f'(x)(y-x) \tag{3.4}
```

对 $\mathbf{dom}\,f$ 中所有 $x,y$ 成立。

先设 $f$ 凸且 $x,y\in\mathbf{dom}\,f$。由于 $\mathbf{dom}\,f$ 凸（即是一个 interval（区间）），对一切 $0\lt t\le1$ 有 $x+t(y-x)\in\mathbf{dom}\,f$，且由 $f$ 的凸性

```math
f(x+t(y-x))\le(1-t)f(x)+tf(y).
```

两边除以 $t$ 得

```math
f(y)\ge f(x)+\frac{f(x+t(y-x))-f(x)}{t},
```

令 $t\to0$ 取极限即得 (3.4)。

再证充分性：设函数对 $\mathbf{dom}\,f$（一个区间）中所有 $x,y$ 满足 (3.4)。任取 $x\neq y$ 与 $0\le\theta\le1$，令 $z=\theta x+(1-\theta)y$。应用 (3.4) 两次：

```math
f(x)\ge f(z)+f'(z)(x-z),\qquad f(y)\ge f(z)+f'(z)(y-z).
```

第一式乘 $\theta$、第二式乘 $1-\theta$ 后相加：

```math
\theta f(x)+(1-\theta)f(y)\ge f(z),
```

即证 $f$ 凸。

现在证一般情形 $f:\mathbb{R}^n\to\mathbb{R}$。设 $x,y\in\mathbb{R}^n$，考虑 $f$ 限制到穿过它们的直线上，即 $g(t)=f(ty+(1-t)x)$，则 $g'(t)=\nabla f(ty+(1-t)x)^T(y-x)$。

先设 $f$ 凸，这意味着 $g$ 凸，于是由上面的论证 $g(1)\ge g(0)+g'(0)$，即

```math
f(y)\ge f(x)+\nabla f(x)^T(y-x).
```

再设这个不等式对任意 $x,y$ 成立。若 $ty+(1-t)x\in\mathbf{dom}\,f$ 且 $\tilde{t}y+(1-\tilde{t})x\in\mathbf{dom}\,f$，则有

```math
f(ty+(1-t)x)\ge f(\tilde{t}y+(1-\tilde{t})x)+\nabla f(\tilde{t}y+(1-\tilde{t})x)^T(y-x)(t-\tilde{t}),
```

即 $g(t)\ge g(\tilde{t})+g'(\tilde{t})(t-\tilde{t})$。前面已见过这意味着 $g$ 凸。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">3.1.4 Second-order conditions（二阶条件）</span>



现在设 $f$ 是 twice differentiable（二阶可微）的，即 Hessian（海森矩阵）或二阶导数 $\nabla^2f$ 在定义域每一点存在且定义域是开的。则 $f$ 凸当且仅当 $\mathbf{dom}\,f$ 凸且其 Hessian 半正定：

```math
\nabla^2f(x)\succeq0 \quad \text{对所有 } x\in\mathbf{dom}\,f.
```

对 $\mathbb{R}$ 上的函数，这退化为简单条件 $f''(x)\ge0$（且 $\mathbf{dom}\,f$ 凸，即一个区间），意味着导数 nondecreasing（非减）。条件 $\nabla^2f(x)\succeq0$ 在几何上可解释为函数图像在 $x$ 处具有正（向上）的 curvature（曲率）。我们把二阶条件的证明留作习题（习题 3.8）。

类似地，$f$ 凹当且仅当 $\mathbf{dom}\,f$ 凸且 $\nabla^2f(x)\preceq0$ 对所有 $x\in\mathbf{dom}\,f$。严格凸可以由二阶条件部分刻画：若 $\nabla^2f(x)\succ0$ 对所有 $x\in\mathbf{dom}\,f$，则 $f$ 严格凸。但逆命题不成立：例如 $f(x)=x^4$ 严格凸，但在 $x=0$ 处二阶导数为零。

<span style="color:#00838f;">**[例 3.2]** **二次函数。** 考虑二次函数 $f:\mathbb{R}^n\to\mathbb{R}$，$\mathbf{dom}\,f=\mathbb{R}^n$：

```math
f(x)=(1/2)x^TPx+q^Tx+r,
```

其中 $P\in\mathbf{S}^n$，$q\in\mathbb{R}^n$，$r\in\mathbb{R}$。由于 $\nabla^2f(x)=P$（对所有 $x$），$f$ 凸当且仅当 $P\succeq0$（凹当且仅当 $P\preceq0$）。对二次函数，严格凸容易刻画：$f$ 严格凸当且仅当 $P\succ0$（严格凹当且仅当 $P\prec0$）。

<span style="color:#00838f;">**[注 3.1]** 在凸性与凹性的一阶、二阶刻画中，「$\mathbf{dom}\,f$ 凸」这一单独要求不能去掉。例如函数 $f(x)=1/x^2$（$\mathbf{dom}\,f=\{x\in\mathbb{R} \mid x\neq0\}$）对所有 $x\in\mathbf{dom}\,f$ 满足 $f''(x)>0$，但它不是凸函数。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">3.1.5 Examples（例子）</span>

<!-- p.85/86 -->

我们已经提过：所有线性与仿射函数都凸（且凹），也描述过凸与凹的二次函数。本节再给一些凸函数与凹函数的例子。先看几个 $\mathbb{R}$ 上（变量为 $x$）的函数：

- Exponential（指数函数）：$e^{ax}$ 在 $\mathbb{R}$ 上凸，对任意 $a\in\mathbb{R}$。
- Powers（幂函数）：$x^a$ 在 $\mathbb{R}_{++}$ 上当 $a\ge1$ 或 $a\le0$ 时凸，当 $0\le a\le1$ 时凹。
- Powers of absolute value（绝对值的幂）：$|x|^p$（$p\ge1$）在 $\mathbb{R}$ 上凸。
- Logarithm（对数）：$\log x$ 在 $\mathbb{R}_{++}$ 上凹。
- Negative entropy（负熵）：$x\log x$（在 $\mathbb{R}_{++}$ 上，或在 $\mathbb{R}_+$ 上且定义 $x=0$ 时取 0）是凸的。

<!-- p.86/87 -->

这些例子的凸性或凹性可以通过验证基本不等式 (3.1) 来证明，或通过检查二阶导数非负/非正。例如 $f(x)=x\log x$：$f'(x)=\log x+1$，$f''(x)=1/x$，故 $x>0$ 时 $f''(x)>0$，即负熵函数（严格）凸。

现在给几个 $\mathbb{R}^n$ 上有趣的例子：

- Norms（范数）：$\mathbb{R}^n$ 上的每个范数都是凸的。
- Max function（最大值函数）：$f(x)=\max\{x_1,\dots,x_n\}$ 在 $\mathbb{R}^n$ 上凸。
- Quadratic-over-linear function（二次-线性分式函数）：$f(x,y)=x^2/y$，$\mathbf{dom}\,f=\mathbb{R}\times\mathbb{R}_{++}=\{(x,y)\in\mathbb{R}^2 \mid y>0\}$，是凸的（图 3.3）。
- Log-sum-exp（对数-和-指数）：$f(x)=\log(e^{x_1}+\cdots+e^{x_n})$ 在 $\mathbb{R}^n$ 上凸。这个函数可以解释为 max 函数的一个 differentiable（可微，其实是 analytic（解析））的近似，因为对所有 $x$ 有

```math
\max\{x_1,\dots,x_n\}\le f(x)\le\max\{x_1,\dots,x_n\}+\log n.
```

（当 $x$ 的分量全相等时第二个不等式取等。）图 3.4 展示了 $n=2$ 时的 $f$。

- Geometric mean（几何平均）：$f(x)=(\prod_{i=1}^n x_i)^{1/n}$ 在 $\mathbf{dom}\,f=\mathbb{R}^n_{++}$ 上凹。
- Log-determinant（对数行列式）：$f(X)=\log\det X$ 在 $\mathbf{dom}\,f=\mathbf{S}^n_{++}$ 上凹。

这些例子的凸性（或凹性）可以用几种方式验证：直接验证不等式 (3.1)、验证 Hessian 半正定、或把函数限制到任意直线上并验证所得一元函数的凸性。

**范数。** 若 $f:\mathbb{R}^n\to\mathbb{R}$ 是范数，$0\le\theta\le1$，则

```math
f(\theta x+(1-\theta)y)\le f(\theta x)+f((1-\theta)y)=\theta f(x)+(1-\theta)f(y).
```

不等号由 triangle inequality（三角不等式）得出，等号由范数的 homogeneity（齐次性）得出。

**最大值函数。** $f(x)=\max_i x_i$ 满足（$0\le\theta\le1$）：

```math
f(\theta x+(1-\theta)y)=\max_i(\theta x_i+(1-\theta)y_i)\le\theta\max_i x_i+(1-\theta)\max_i y_i=\theta f(x)+(1-\theta)f(y).
```

**二次-线性分式函数。** 为证 $f(x,y)=x^2/y$ 凸，注意（$y>0$ 时）：

```math
\nabla^2f(x,y)=\frac{2}{y^3}\begin{bmatrix}y^2&-xy\\-xy&x^2\end{bmatrix}=\frac{2}{y^3}\begin{bmatrix}y\\-x\end{bmatrix}\begin{bmatrix}y\\-x\end{bmatrix}^T\succeq0.
```



把 (3.13) 与 (3.14) 合起来，得

```math
h(g(\lambda x + (1-\lambda)y)) \le \lambda h(g(x)) + (1-\lambda) h(g(y))
```

这就证明了复合定理。证毕。

<span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">**Example 3.13**</span> <span style="color:#c0392b">Simple composition results（简单的复合结果）.</span>

- 若 $g$ 是 convex，则 $\exp g(x)$ 是 convex。
- 若 $g$ 是 concave 且取正值，则 $\log g(x)$ 是 concave。
- 若 $g$ 是 concave 且取正值，则 $1/g(x)$ 是 convex。
- 若 $g$ 是 convex 且非负，且 $p \ge 1$，则 $g(x)^p$ 是 convex。
- 若 $g$ 是 convex，则 $-\log(-g(x))$ 在 $\{x \mid g(x) < 0\}$ 上是 convex。

<span style="color:#c0392b">**Remark 3.3（注 3.3）**</span> 「monotonicity 必须对 extended-value extension $\tilde{h}$ 成立、而不只是对函数 $h$ 成立」这条要求不能去掉。例如考虑函数 $g(x) = x^2$，$\operatorname{dom} g = \mathbf{R}$，以及 $h(x) = 0$，$\operatorname{dom} h = [1, 2]$。这里 $g$ 是 convex，$h$ 是 convex 且非减。但函数 $f = h \circ g$，即

```math
f(x) = 0, \qquad \operatorname{dom} f = [-\sqrt{2}, -1] \cup [1, \sqrt{2}]
```

不是 convex 的，因为它的 domain 不是 convex set。这里当然是因为 $\tilde{h}$ 不是非减的。

**Vector composition（向量复合）**

现在转向更复杂的 $k \ge 1$ 的情形。设

```math
f(x) = h(g(x)) = h(g_1(x), \ldots, g_k(x))
```

其中 $h : \mathbf{R}^k \to \mathbf{R}$、$g_i : \mathbf{R}^n \to \mathbf{R}$。同样不失一般性可以假定 $n = 1$。与 $k = 1$ 的情形一样，我们先假定函数二次可微、$\operatorname{dom} g = \mathbf{R}$、$\operatorname{dom} h = \mathbf{R}^k$，以便发现复合规则。我们有

```math
f''(x) = g'(x)^{T} \nabla^2 h(g(x)) g'(x) + \nabla h(g(x))^{T} g''(x)
```

即式 (3.15)，它是 (3.9) 的向量版本。同样，问题归结为确定 $f''(x) \ge 0$（对一切 $x$，或对 concavity 而言 $f''(x) \le 0$）成立的条件。由 (3.15) 可以导出许多规则，例如：

```math
\begin{aligned}
&f \text{ is convex if } h \text{ is convex}, h \text{ is nondecreasing in each argument,} \\
&\qquad \text{and } g_i \text{ are convex}, \\
&f \text{ is convex if } h \text{ is convex}, h \text{ is nonincreasing in each argument,} \\
&\qquad \text{and } g_i \text{ are concave}, \\
&f \text{ is concave if } h \text{ is concave}, h \text{ is nondecreasing in each argument,} \\
&\qquad \text{and } g_i \text{ are concave}.
\end{aligned}
```



（本页起承接上一份文件 `Boyd凸优化_p081-100.bilingual.md` 末尾的 **3.2.4 Composition**，随后进入 3.2.5 Minimization。）

与标量情形一样，当 $n > 1$、不假定 $h$ 或 $g$ 可微、且 domain 一般时，类似的复合结果同样成立。对一般结果，关于 $h$ 的 monotonicity 条件必须对 extended-value extension $\tilde{h}$ 成立。

要理解「extended-value extension $\tilde{h}$ 单调」这条条件的意思，我们考虑 $h : \mathbf{R}^k \to \mathbf{R}$ 是 convex、且 $\tilde{h}$ nondecreasing 的情形，即只要 $u \preceq v$，就有 $\tilde{h}(u) \le \tilde{h}(v)$。这蕴含：若 $v \in \operatorname{dom} h$，则 $u \in \operatorname{dom} h$，即 $h$ 的 domain 必须沿 $-\mathbf{R}_{+}^{k}$ 方向无限延伸。这一点可以紧凑地写成 $\operatorname{dom} h - \mathbf{R}_{+}^{k} = \operatorname{dom} h$。

<span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">**Example 3.14**</span> <span style="color:#c0392b">Vector composition examples（向量复合的例子）.</span>

- 令 $h(z) = z_{[1]} + \cdots + z_{[r]}$，即 $z \in \mathbf{R}^k$ 的最大 $r$ 个分量之和。则 $h$ 是 convex 的，且在每个自变量上 nondecreasing。设 $g_1, \ldots, g_k$ 是 $\mathbf{R}^n$ 上的 convex function。则复合函数 $f = h \circ g$，即最大的 $r$ 个 $g_i$ 的逐点之和，是 convex 的。
- 函数 $h(z) = \log\left(\sum_{i=1}^{k} e^{z_i}\right)$ 是 convex 的，且在每个自变量上 nondecreasing，因此只要 $g_i$ 是 convex，$\log\left(\sum_{i=1}^{k} e^{g_i}\right)$ 就是 convex。
- 当 $0 < p \le 1$ 时，函数 $h(z) = \left(\sum_{i=1}^{k} z_i^{p}\right)^{1/p}$ 在 $\mathbf{R}_{+}^{k}$ 上是 concave 的，且其扩张（对 $z \not\succeq 0$ 取值为 $-\infty$）在每个分量上 nondecreasing。于是若 $g_i$ 是 concave 且非负，可推出 $f(x) = \left(\sum_{i=1}^{k} g_i(x)^{p}\right)^{1/p}$ 是 concave 的。
- 设 $p \ge 1$，$g_1, \ldots, g_k$ 是 convex 且非负。则函数 $\left(\sum_{i=1}^{k} g_i(x)^{p}\right)^{1/p}$ 是 convex 的。要证明这一点，考虑由

```math
h(z) = \left(\sum_{i=1}^{k} \max\{z_i, 0\}^{p}\right)^{1/p}
```

定义的函数 $h : \mathbf{R}^k \to \mathbf{R}$，其 $\operatorname{dom} h = \mathbf{R}^k$，故 $h = \tilde{h}$。这个函数是 convex 且 nondecreasing 的，于是可推出 $h(g(x))$ 是 $x$ 的 convex function。当 $z \succeq 0$ 时 $h(z) = \left(\sum_{i=1}^{k} z_i^{p}\right)^{1/p}$，所以结论就是 $\left(\sum_{i=1}^{k} g_i(x)^{p}\right)^{1/p}$ 是 convex 的。
- 几何平均 $h(z) = \left(\prod_{i=1}^{k} z_i\right)^{1/k}$ 在 $\mathbf{R}_{++}^{k}$ 上是 concave 的，且其扩张在每个自变量上 nondecreasing。由此可知：若 $g_1, \ldots, g_k$ 是非负的 concave function，则它们的几何平均 $\left(\prod_{i=1}^{k} g_i\right)^{1/k}$ 也是非负 concave 的。

### 3.2.5 Minimization（最小化）

我们已经看到：任意一族 convex function 的 maximum 或 supremum 都是 convex 的。结果表明，某些特殊形式的最小化也能产生 convex function。若 $f$ 关于 $(x, y)$ 是 convex，且 $C$ 是 convex 非空集合，则由

```math
g(x) = \inf_{y \in C} f(x, y)
```

定义的函数（即式 (3.16)）关于 $x$ 是 convex，前提是对一切 $x$ 有 $g(x) > -\infty$。$g$ 的 domain 是 $\operatorname{dom} f$ 在其 $x$-坐标上的投影，即

```math
\operatorname{dom} g = \{x \mid (x, y) \in \operatorname{dom} f \text{ for some } y \in C\}
```



**对数-和-指数。** log-sum-exp 函数的 Hessian 为

```math
\nabla^2f(x)=\frac{1}{(\mathbf{1}^Tz)^2}\bigl((\mathbf{1}^Tz)\,\mathbf{diag}(z)-zz^T\bigr),
```

其中 $z=(e^{x_1},\dots,e^{x_n})$。为验证 $\nabla^2f(x)\succeq0$，须证对所有 $v$，

```math
v^T\nabla^2f(x)v=\frac{1}{(\mathbf{1}^Tz)^2}\left[\Bigl(\sum_{i=1}^n z_i\Bigr)\Bigl(\sum_{i=1}^n v_i^2z_i\Bigr)-\Bigl(\sum_{i=1}^n v_iz_i\Bigr)^2\right]\ge0.
```

这正是 Cauchy-Schwarz inequality（柯西-施瓦茨不等式）$(a^Ta)(b^Tb)\ge(a^Tb)^2$ 应用于分量 $a_i=v_i\sqrt{z_i}$、$b_i=\sqrt{z_i}$ 的结果。

**几何平均。** 类似地可以证明几何平均 $f(x)=(\prod_{i=1}^nx_i)^{1/n}$ 在 $\mathbf{dom}\,f=\mathbb{R}^n_{++}$ 上凹。其 Hessian $\nabla^2f(x)$ 为

```math
\frac{\partial^2f}{\partial x_k^2}=-\frac{(n-1)(\prod_{i=1}^nx_i)^{1/n}}{n^2x_k^2},\qquad
\frac{\partial^2f}{\partial x_k\partial x_l}=\frac{(\prod_{i=1}^nx_i)^{1/n}}{n^2x_kx_l}\ (k\neq l),
```

可表达为

```math
\nabla^2f(x)=-\frac{\prod_{i=1}^nx_i^{1/n}}{n^2}\bigl(n\,\mathbf{diag}(1/x_1^2,\dots,1/x_n^2)-qq^T\bigr),
```

其中 $q_i=1/x_i$。须证 $\nabla^2f(x)\preceq0$，即对所有 $v$，

```math
v^T\nabla^2f(x)v=-\frac{\prod_{i=1}^nx_i^{1/n}}{n^2}\left[n\sum_{i=1}^n v_i^2/x_i^2-\Bigl(\sum_{i=1}^n v_i/x_i\Bigr)^2\right]\le0.
```

这同样由 Cauchy-Schwarz 不等式（取 $a=\mathbf{1}$、$b_i=v_i/x_i$）得出。

**对数行列式。** 对函数 $f(X)=\log\det X$，可以通过考虑任意直线 $X=Z+tV$（$Z,V\in\mathbf{S}^n$）来验证凹性。定义 $g(t)=f(Z+tV)$，把 $g$ 限制在使 $Z+tV\succ0$ 的 $t$ 区间上。不失一般性可设 $t=0$ 在此区间内，即 $Z\succ0$。我们有

```math
g(t)=\log\det(Z+tV)=\log\det\bigl(Z^{1/2}(I+tZ^{-1/2}VZ^{-1/2})Z^{1/2}\bigr)=\sum_{i=1}^n\log(1+t\lambda_i)+\log\det Z,
```

其中 $\lambda_1,\dots,\lambda_n$ 是 $Z^{-1/2}VZ^{-1/2}$ 的特征值。因此

```math
g'(t)=\sum_{i=1}^n\frac{\lambda_i}{1+t\lambda_i},\qquad g''(t)=-\sum_{i=1}^n\frac{\lambda_i^2}{(1+t\lambda_i)^2}.
```

由于 $g''(t)\le0$，得出 $f$ 凹。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">3.1.6 Sublevel sets（下水平集）</span>



函数 $f:\mathbb{R}^n\to\mathbb{R}$ 的 α-sublevel set（α-下水平集）定义为

```math
C_\alpha=\{x\in\mathbf{dom}\,f \mid f(x)\le\alpha\}.
```

凸函数的下水平集对任何 $\alpha$ 值都是凸的。证明直接由凸性定义得出：若 $x,y\in C_\alpha$，则 $f(x)\le\alpha$、$f(y)\le\alpha$，于是对 $0\le\theta\le1$ 有 $f(\theta x+(1-\theta)y)\le\alpha$，故 $\theta x+(1-\theta)y\in C_\alpha$。

逆命题不成立：一个函数的所有下水平集都凸，但它本身可以不是凸函数。例如 $f(x)=-e^x$ 在 $\mathbb{R}$ 上不凸（其实它严格凹），但它的所有下水平集都凸。

若 $f$ 凹，则它的 α-superlevel set（α-上水平集）$\{x\in\mathbf{dom}\,f \mid f(x)\ge\alpha\}$ 是凸集。sublevel set property（下水平集性质）常常是确立集合凸性的好办法：把集合表示成某个凸函数的下水平集，或某个凹函数的上水平集。

<span style="color:#00838f;">**[例 3.3]** $x\in\mathbb{R}^n_+$ 的 geometric mean（几何平均）与 arithmetic mean（算术平均）分别为

```math
G(x)=\Bigl(\prod_{i=1}^nx_i\Bigr)^{1/n},\qquad A(x)=\frac{1}{n}\sum_{i=1}^nx_i
```

（在我们的 $G$ 的定义中取 $0^{1/n}=0$）。arithmetic-geometric mean inequality（算术-几何平均不等式）陈述 $G(x)\le A(x)$。设 $0\le\alpha\le1$，考虑集合

```math
\{x\in\mathbb{R}^n_+ \mid G(x)\ge\alpha A(x)\},
```

即「几何平均至少为算术平均的 $\alpha$ 倍」的向量集合。这个集合是凸的，因为它是函数 $G(x)-\alpha A(x)$（凹）的 0-上水平集。事实上该集合还是 positively homogeneous（正齐次）的，所以它是一个凸锥。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">3.1.7 Epigraph（上图）</span>

函数 $f:\mathbb{R}^n\to\mathbb{R}$ 的 graph（图像）定义为

```math
\{(x,f(x)) \mid x\in\mathbf{dom}\,f\},
```

它是 $\mathbb{R}^{n+1}$ 的子集。函数 $f$ 的 epigraph（上图）定义为

```math
\mathbf{epi}\,f=\{(x,t) \mid x\in\mathbf{dom}\,f,\; f(x)\le t\},
```

它也是 $\mathbb{R}^{n+1}$ 的子集。（「Epi」意为「在……之上」，epigraph 即「图像之上」。）定义见图 3.5。

凸集与凸函数之间的联系通过上图建立：**函数凸当且仅当它的上图是凸集**。函数凹当且仅当它的 hypograph（下图）

```math
\mathbf{hypo}\,f=\{(x,t) \mid t\le f(x)\}
```

是凸集。

<span style="color:#00838f;">**[例 3.4]** **矩阵分式函数（matrix fractional function）。** 函数 $f:\mathbb{R}^n\times\mathbf{S}^n\to\mathbb{R}$ 定义为

```math
f(x,Y)=x^TY^{-1}x
```

在 $\mathbf{dom}\,f=\mathbb{R}^n\times\mathbf{S}^n_{++}$ 上凸。（它推广了二次-线性分式函数 $f(x,y)=x^2/y$，$\mathbf{dom}\,f=\mathbb{R}\times\mathbb{R}_{++}$。）



确立 $f$ 凸性的一个简单办法是通过它的上图：

```math
\begin{aligned}
\mathbf{epi}\,f &= \{(x,Y,t) \mid Y\succ0,\; x^TY^{-1}x\le t\}\\
&= \left\{(x,Y,t)\;\middle|\;\begin{bmatrix}Y&x\\x^T&t\end{bmatrix}\succeq0,\; Y\succ0\right\},
\end{aligned}
```

这里用了分块矩阵半正定性的 Schur complement condition（舒尔补条件）（见 §A.5.5）。最后一个条件是关于 $(x,Y,t)$ 的 linear matrix inequality（线性矩阵不等式），因此 $\mathbf{epi}\,f$ 凸。

当 $n=1$ 时，矩阵分式函数退化为二次-线性分式函数 $x^2/y$，相应的 LMI 表示为

```math
\begin{bmatrix}y&x\\x&t\end{bmatrix}\succeq0,\qquad y>0
```

（其图像见图 3.3）。

许多凸函数的结果可以借助上图用几何方式证明（或解释），再应用凸集的结果。例如考虑凸性的一阶条件

```math
f(y)\ge f(x)+\nabla f(x)^T(y-x) \qquad (f \text{ 凸}，\ x,y\in\mathbf{dom}\,f).
```



我们可以在 $\mathbf{epi}\,f$ 的语境下几何化地解释这个基本不等式。若 $(y,t)\in\mathbf{epi}\,f$，则

```math
t\ge f(y)\ge f(x)+\nabla f(x)^T(y-x).
```

这可以写成：

```math
(y,t)\in\mathbf{epi}\,f \implies \begin{bmatrix}\nabla f(x)\\-1\end{bmatrix}^T\left(\begin{bmatrix}y\\t\end{bmatrix}-\begin{bmatrix}x\\f(x)\end{bmatrix}\right)\le0.
```

这意味着由 $(\nabla f(x),-1)$ 定义的超平面在边界点 $(x,f(x))$ 处支撑 $\mathbf{epi}\,f$；见图 3.6。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">3.1.8 Jensen's inequality and extensions（Jensen 不等式及其推广）</span>

<!-- p.91/92 -->

基本不等式 (3.1)，即

```math
f(\theta x+(1-\theta)y)\le\theta f(x)+(1-\theta)f(y),
```

有时称为 Jensen's inequality（Jensen 不等式）。它很容易推广到多于两点的凸组合：若 $f$ 凸，$x_1,\dots,x_k\in\mathbf{dom}\,f$，$\theta_1,\dots,\theta_k\ge0$ 且 $\theta_1+\cdots+\theta_k=1$，则

```math
f(\theta_1x_1+\cdots+\theta_kx_k)\le\theta_1f(x_1)+\cdots+\theta_kf(x_k).
```

与凸集情形一样，该不等式可推广到无穷和、积分与期望。例如，若 $p(x)\ge0$（$S\subseteq\mathbf{dom}\,f$），$\int_Sp(x)\,dx=1$，则（积分存在时）

```math
f\Bigl(\int_Sp(x)x\,dx\Bigr)\le\int_Sf(x)p(x)\,dx.
```

最一般的情形可取任何 support（支撑）在 $\mathbf{dom}\,f$ 中的 probability measure（概率测度）。若 $x$ 是随机变量、$x\in\mathbf{dom}\,f$ 以概率 1 成立、$f$ 凸，则（期望存在时）

```math
f(\mathbb{E}\,x)\le\mathbb{E}\,f(x). \tag{3.5}
```

从这一般形式可以恢复基本不等式 (3.1)：取随机变量 $x$ 的支撑为 $\{x_1,x_2\}$，$\mathrm{prob}(x=x_1)=\theta$、$\mathrm{prob}(x=x_2)=1-\theta$ 即可。因此不等式 (3.5) 刻画了凸性：若 $f$ 不凸，则存在随机变量 $x$（$x\in\mathbf{dom}\,f$ 以概率 1 成立）使 $f(\mathbb{E}\,x)>\mathbb{E}\,f(x)$。

<!-- p.92/93 -->

这些不等式现在都叫 Jensen 不等式，尽管 Jensen 当年研究的是非常简单的那一个：

```math
f\Bigl(\frac{x+y}{2}\Bigr)\le\frac{f(x)+f(y)}{2}.
```

<span style="color:#00838f;">**[注 3.2]** 可以这样解释 (3.5)：设 $x\in\mathbf{dom}\,f\subseteq\mathbb{R}^n$，$z$ 是 $\mathbb{R}^n$ 中任意 zero mean random vector（零均值随机向量），则

```math
\mathbb{E}\,f(x+z)\ge f(x).
```

也就是说，randomization 或 dithering（随机化/抖动，即给自变量加一个零均值随机向量）不可能平均地降低凸函数的值。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">3.1.9 Inequalities（不等式）</span>

许多著名的不等式都可以通过把 Jensen 不等式应用于某个适当的凸函数来导出。（事实上，可以把凸性与 Jensen 不等式做成一套不等式理论的基础。）举一个简单例子，考虑 arithmetic-geometric mean inequality（算术-几何平均不等式）：

```math
\sqrt{ab}\le(a+b)/2 \tag{3.6}
```

（$a,b\ge0$）。函数 $-\log x$ 是凸的；取 $\theta=1/2$ 的 Jensen 不等式给出

```math
-\log\Bigl(\frac{a+b}{2}\Bigr)\le\frac{-\log a-\log b}{2}.
```

两边取指数即得 (3.6)。



$f^{*}(y) = \sup_x (-e^{x}) = 0$。总之，$\operatorname{dom} f^{*} = \mathbf{R}_{+}$，且 $f^{*}(y) = y \log y - y$（按约定 $0 \log 0 = 0$）。

- **Negative entropy.** $f(x) = x \log x$，$\operatorname{dom} f = \mathbf{R}_{+}$（且 $f(0) = 0$）。函数 $xy - x \log x$ 对一切 $y$ 都在 $\mathbf{R}_{+}$ 上有上界，故 $\operatorname{dom} f^{*} = \mathbf{R}$。它在 $x = e^{y-1}$ 处取最大值，代入得 $f^{*}(y) = e^{y-1}$。
- **Inverse.** $f(x) = 1/x$，定义在 $\mathbf{R}_{++}$ 上。当 $y > 0$ 时，$yx - 1/x$ 无上界。当 $y = 0$ 时该函数的上确界为 $0$；当 $y < 0$ 时上确界在 $x = (-y)^{-1/2}$ 处取到。因此 $f^{*}(y) = -2(-y)^{1/2}$，$\operatorname{dom} f^{*} = -\mathbf{R}_{+}$。

<span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">**Example 3.22**</span> <span style="color:#c0392b">Strictly convex quadratic function（严格凸二次函数）.</span>

考虑 $f(x) = \frac{1}{2} x^{T} Q x$，$Q \in \mathbf{S}_{++}^{n}$。作为 $x$ 的函数，$y^{T} x - \frac{1}{2} x^{T} Q x$ 对一切 $y$ 都有上界。它在 $x = Q^{-1} y$ 处取最大值，故

```math
f^{*}(y) = \frac{1}{2} y^{T} Q^{-1} y
```

<span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">**Example 3.23**</span> <span style="color:#c0392b">Log-determinant（对数行列式）.</span>

考虑 $\mathbf{S}_{++}^{n}$ 上的 $f(X) = \log \det X^{-1}$。conjugate function 定义为

```math
f^{*}(Y) = \sup_{X \succ 0} \left(\operatorname{tr}(Y X) + \log \det X\right)
```

因为 $\operatorname{tr}(Y X)$ 是 $\mathbf{S}^n$ 上的标准内积。我们先证明：除非 $Y \prec 0$，否则 $\operatorname{tr}(Y X) + \log \det X$ 无上界。若 $Y \not\prec 0$，则 $Y$ 有一个 eigenvector $v$（$\|v\|_2 = 1$）对应 eigenvalue $\lambda \ge 0$。取 $X = I + t v v^{T}$，得

```math
\operatorname{tr}(Y X) + \log \det X = \operatorname{tr} Y + t \lambda + \log \det(I + t v v^{T}) = \operatorname{tr} Y + t \lambda + \log(1 + t \lambda)
```

当 $t \to \infty$ 时它无上界。

现在考虑 $Y \prec 0$ 的情形。令关于 $X$ 的 gradient 为零即可找到最大值点：

```math
\nabla_X \left(\operatorname{tr}(Y X) + \log \det X\right) = Y + X^{-1} = 0
```

（见 §A.4.1），从而 $X = -Y^{-1}$（它确实是 positive definite）。因此

```math
f^{*}(Y) = \log \det(-Y)^{-1} - n
```

且 $\operatorname{dom} f^{*} = -\mathbf{S}_{++}^{n}$。

<span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b">**Example 3.24**</span> <span style="color:#c0392b">Indicator function（指示函数）.</span>

设 $I_S$ 是（不必 convex 的）集合 $S \subseteq \mathbf{R}^n$ 的 indicator function，即 $I_S(x) = 0$，$\operatorname{dom} I_S = S$。它的 conjugate 是

```math
I_S^{*}(y) = \sup_{x \in S} y^{T} x
```

这正是集合 $S$ 的 support function。



一个不那么平凡的例子是 Hölder's inequality（赫尔德不等式）的证明：对 $p>1$、$1/p+1/q=1$、$x,y\in\mathbb{R}^n$，

```math
\sum_{i=1}^nx_iy_i\le\Bigl(\sum_{i=1}^n|x_i|^p\Bigr)^{1/p}\Bigl(\sum_{i=1}^n|y_i|^q\Bigr)^{1/q}.
```

由 $-\log x$ 的凸性与一般 $\theta$ 的 Jensen 不等式，得到更一般的算术-几何平均不等式

```math
a^\theta b^{1-\theta}\le\theta a+(1-\theta)b,
```

对 $a,b\ge0$、$0\le\theta\le1$ 成立。代入

```math
a=\frac{|x_i|^p}{\sum_{j=1}^n|x_j|^p},\qquad b=\frac{|y_i|^q}{\sum_{j=1}^n|y_j|^q},\qquad \theta=1/p,
```

得

```math
\Bigl(\frac{|x_i|^p}{\sum_{j=1}^n|x_j|^p}\Bigr)^{1/p}\Bigl(\frac{|y_i|^q}{\sum_{j=1}^n|y_j|^q}\Bigr)^{1/q}\le\frac{|x_i|^p}{p\sum_{j=1}^n|x_j|^p}+\frac{|y_i|^q}{q\sum_{j=1}^n|y_j|^q}.
```

对 $i$ 求和即得 Hölder 不等式。

## <span style="color:#c0392b;">3.2 Operations that preserve convexity（保持凸性的运算）</span>



本节描述一些保持函数凸性或凹性的运算，或能构造新凸函数与凹函数的运算。先讲简单运算（加法、缩放、逐点上确界），再讲一些更精细的运算（其中有些把简单运算作为特例包含进来）。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">3.2.1 Nonnegative weighted sums（非负加权和）</span>

显然，若 $f$ 凸且 $\alpha\ge0$，则函数 $\alpha f$ 凸。若 $f_1$ 与 $f_2$ 都是凸函数，则它们的和 $f_1+f_2$ 也凸。把非负缩放与加法结合起来：凸函数的集合本身就是一个 convex cone（凸锥）——凸函数的非负加权和

```math
f = w_1f_1+\cdots+w_mf_m
```

是凸的。类似地，凹函数的非负加权和是凹的。严格凸（凹）函数的非负且不全为零的加权和是严格凸（凹）的。

这些性质可推广到无穷和与积分。例如，若 $f(x,y)$ 对每个 $y\in\mathcal{A}$ 关于 $x$ 凸，且 $w(y)\ge0$（对每个 $y\in\mathcal{A}$），则函数

```math
g(x)=\int_{\mathcal{A}}w(y)f(x,y)\,dy
```

关于 $x$ 凸（积分存在时）。

凸性在非负缩放与加法下保持这件事可以直接验证，也可以借助相应的上图来看。例如若 $w\ge0$ 且 $f$ 凸，则

```math
\mathbf{epi}(wf)=\begin{bmatrix}I&0\\0&w\end{bmatrix}\mathbf{epi}\,f,
```

它凸，因为凸集在线性映射下的像是凸的。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">3.2.2 Composition with an affine mapping（与仿射映射复合）</span>

<!-- p.93/94 -->

设 $f:\mathbb{R}^n\to\mathbb{R}$，$A\in\mathbb{R}^{n\times m}$，$b\in\mathbb{R}^n$。定义 $g:\mathbb{R}^m\to\mathbb{R}$：

```math
g(x)=f(Ax+b),\qquad \mathbf{dom}\,g=\{x \mid Ax+b\in\mathbf{dom}\,f\}.
```

则若 $f$ 凸，$g$ 也凸；若 $f$ 凹，$g$ 也凹。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">3.2.3 Pointwise maximum and supremum（逐点最大值与上确界）</span>



若 $f_1$ 与 $f_2$ 是凸函数，则它们的 pointwise maximum（逐点最大值）$f$，定义为

```math
f(x)=\max\{f_1(x),f_2(x)\},\qquad \mathbf{dom}\,f=\mathbf{dom}\,f_1\cap\mathbf{dom}\,f_2,
```

也是凸的。这个性质容易验证：若 $0\le\theta\le1$，$x,y\in\mathbf{dom}\,f$，则

```math
\begin{aligned}
f(\theta x+(1-\theta)y)
&= \max\{f_1(\theta x+(1-\theta)y),\; f_2(\theta x+(1-\theta)y)\}\\
&\le \max\{\theta f_1(x)+(1-\theta)f_1(y),\; \theta f_2(x)+(1-\theta)f_2(y)\}\\
&\le \theta\max\{f_1(x),f_2(x)\}+(1-\theta)\max\{f_1(y),f_2(y)\}\\
&= \theta f(x)+(1-\theta)f(y),
\end{aligned}
```

即确立 $f$ 的凸性。容易证明：若 $f_1,\dots,f_m$ 凸，则它们的逐点最大值

```math
f(x)=\max\{f_1(x),\dots,f_m(x)\}
```

也凸。

<span style="color:#00838f;">**[例 3.5]** **分段线性函数。** 函数

```math
f(x)=\max\{a_1^Tx+b_1,\dots,a_L^Tx+b_L\}
```

定义一个 piecewise-linear（分段线性，实际是分段仿射）函数（有 $L$ 个或更少的区域）。它凸，因为它是仿射函数的逐点最大值。逆命题也成立：任何有 $L$ 个或更少区域的分段线性凸函数都可以表示成这种形式。（见习题 3.29。）

<span style="color:#00838f;">**[例 3.6]** **最大 $r$ 个分量之和。** 对 $x\in\mathbb{R}^n$，用 $x_{[i]}$ 表示 $x$ 的第 $i$ 大的分量，即

```math
x_{[1]}\ge x_{[2]}\ge\cdots\ge x_{[n]}
```

是按非增序排列的分量。则函数

```math
f(x)=\sum_{i=1}^rx_{[i]},
```

即 $x$ 的最大 $r$ 个元素之和，是凸函数。可以这样看：

```math
f(x)=\sum_{i=1}^rx_{[i]}=\max\{x_{i_1}+\cdots+x_{i_r} \mid 1\le i_1<i_2<\cdots<i_r\le n\},
```

即 $x$ 的 $r$ 个不同分量的所有可能和的最大值。由于它是 $n!/(r!(n-r)!)$ 个线性函数的逐点最大值，它是凸的。作为推广可以证明：只要 $w_1\ge w_2\ge\cdots\ge w_r\ge0$，函数 $\sum_{i=1}^rw_ix_{[i]}$ 也是凸的。（见习题 3.19。）



逐点最大值性质可推广到无穷多个凸函数的 pointwise supremum（逐点上确界）。若对每个 $y\in\mathcal{A}$，$f(x,y)$ 关于 $x$ 凸，则函数

```math
g(x)=\sup_{y\in\mathcal{A}}f(x,y) \tag{3.7}
```

关于 $x$ 凸。$g$ 的定义域为

```math
\mathbf{dom}\,g=\{x \mid (x,y)\in\mathbf{dom}\,f \text{ 对所有 } y\in\mathcal{A},\; \sup_{y\in\mathcal{A}}f(x,y)<\infty\}.
```

类似地，一族凹函数的 pointwise infimum（逐点下确界）是凹函数。

用上图的语言：函数的逐点上确界对应上图之交。按 (3.7) 定义的 $f,g$ 与 $\mathcal{A}$，有

```math
\mathbf{epi}\,g=\bigcap_{y\in\mathcal{A}}\mathbf{epi}\,f(\cdot,y).
```

于是结果由「一族凸集之交是凸的」得出。

<span style="color:#00838f;">**[例 3.7]** **集合的支撑函数（support function）。** 设 $C\subseteq\mathbb{R}^n$，$C\neq\varnothing$。与集合 $C$ 相关联的 support function（支撑函数）$S_C$ 定义为

```math
S_C(x)=\sup\{x^Ty \mid y\in C\}
```

（自然地，$\mathbf{dom}\,S_C=\{x \mid \sup_{y\in C}x^Ty<\infty\}$）。对每个 $y\in C$，$x^Ty$ 是 $x$ 的线性函数，所以 $S_C$ 是一族线性函数的逐点上确界，因而凸。

<span style="color:#00838f;">**[例 3.8]** **到集合最远点的距离。** 设 $C\subseteq\mathbb{R}^n$。到 $C$ 最远点的距离（按任何范数）

```math
f(x)=\sup_{y\in C}\|x-y\|
```

是凸的。为看出这一点，注意对任意 $y$，函数 $\|x-y\|$ 关于 $x$ 凸。由于 $f$ 是一族凸函数（由 $y\in C$ 索引）的逐点上确界，它是 $x$ 的凸函数。

<span style="color:#00838f;">**[例 3.9]** **作为权重函数的最小二乘代价。** 设 $a_1,\dots,a_n\in\mathbb{R}^m$。在加权最小二乘问题中，我们在 $x\in\mathbb{R}^m$ 上最小化目标函数 $\sum_{i=1}^nw_i(a_i^Tx-b_i)^2$。我们把 $w_i$ 称为 weights（权重），并允许 $w_i$ 为负（这使目标函数可能无下界）。我们定义（最优）加权最小二乘代价为

```math
g(w)=\inf_x\sum_{i=1}^nw_i(a_i^Tx-b_i)^2,
```

定义域为

```math
\mathbf{dom}\,g=\left\{w\;\middle|\;\inf_x\sum_{i=1}^nw_i(a_i^Tx-b_i)^2>-\infty\right\}.
```



由于 $g$ 是一族（以 $x\in\mathbb{R}^m$ 索引的）$w$ 的线性函数的下确界，它是 $w$ 的凹函数。

我们至少可以在 $g$ 定义域的一部分上导出它的显式表达式。设 $W=\mathbf{diag}(w)$（以 $w_1,\dots,w_n$ 为对角元的对角矩阵），$A\in\mathbb{R}^{n\times m}$ 以 $a_i^T$ 为行，则

```math
g(w)=\inf_x(Ax-b)^TW(Ax-b)=\inf_x(x^TA^TWAx-2b^TWAx+b^TWb).
```

由此看出：若 $A^TWA\not\succeq0$，该二次函数关于 $x$ 无下界，故 $g(w)=-\infty$，即 $w\notin\mathbf{dom}\,g$。当 $A^TWA\succ0$（一个严格线性矩阵不等式）时，可以通过解析地最小化二次函数给出 $g$ 的简单表达式：

```math
\begin{aligned}
g(w) &= b^TWb-b^TWA(A^TWA)^{-1}A^TWb\\
&= \sum_{i=1}^nw_ib_i^2-\sum_{i=1}^nw_i^2b_i^2a_i^T\Bigl(\sum_{j=1}^nw_ja_ja_j^T\Bigr)^{-1}a_i.
\end{aligned}
```

从这个表达式看 $g$ 的凹性并不直观（但它确实成立，例如可由矩阵分式函数的凸性得出；见例 3.4）。

<span style="color:#00838f;">**[例 3.10]** **对称矩阵的最大特征值。** 函数 $f(X)=\lambda_{\max}(X)$（$\mathbf{dom}\,f=\mathbf{S}^m$）是凸的。为看出这一点，把 $f$ 表为

```math
f(X)=\sup\{y^TXy \mid \|y\|_2=1\},
```

即一族（由 $y\in\mathbb{R}^m$ 索引的）$X$ 的线性函数 $y^TXy$ 的逐点上确界。

<span style="color:#00838f;">**[例 3.11]** **矩阵的范数。** 考虑 $f(X)=\|X\|_2$，$\mathbf{dom}\,f=\mathbb{R}^{p\times q}$，其中 $\|\cdot\|_2$ 表示 spectral norm（谱范数）或 maximum singular value（最大奇异值）。$f$ 的凸性由

```math
f(X)=\sup\{u^TXv \mid \|u\|_2=1,\; \|v\|_2=1\}
```

得出：它是 $X$ 的线性函数族的逐点上确界。

作为推广，设 $\|\cdot\|_a$ 与 $\|\cdot\|_b$ 分别是 $\mathbb{R}^p$ 与 $\mathbb{R}^q$ 上的范数。矩阵 $X\in\mathbb{R}^{p\times q}$ 的 induced norm（诱导范数）定义为

```math
\|X\|_{a,b}=\sup_{v\neq0}\frac{\|Xv\|_a}{\|v\|_b}.
```

（当两个范数都是欧氏范数时，它退化为谱范数。）诱导范数可表达为

```math
\|X\|_{a,b}=\sup\{\|Xv\|_a \mid \|v\|_b=1\}=\sup\{u^TXv \mid \|u\|_{a*}=1,\; \|v\|_b=1\},
```

<!-- p.96/97 -->

其中 $\|\cdot\|_{a*}$ 是 $\|\cdot\|_a$ 的对偶范数，且用了事实 $\|z\|_a=\sup\{u^Tz \mid \|u\|_{a*}=1\}$。既然把 $\|X\|_{a,b}$ 表成了 $X$ 的线性函数的上确界，它就是凸函数。

**表示为仿射函数族的逐点上确界（Representation as pointwise supremum of affine functions）。** 上面的例子展示了一个确立函数凸性的好方法：把它表示成一族仿射函数的逐点上确界。除一个技术性条件外，逆命题也成立：几乎每个凸函数都可以表示成一族仿射函数的逐点上确界。例如，若 $f:\mathbb{R}^n\to\mathbb{R}$ 凸且 $\mathbf{dom}\,f=\mathbb{R}^n$，则

```math
f(x)=\sup\{g(x) \mid g \text{ 仿射}，\; g(z)\le f(z) \text{ 对所有 } z\}.
```

换言之，$f$ 是它的所有 affine global underestimators（仿射全局低估器）的逐点上确界。下面给出证明；$\mathbf{dom}\,f\neq\mathbb{R}^n$ 的情形留作习题（习题 3.28）。



设 $f$ 凸且 $\mathbf{dom}\,f=\mathbb{R}^n$。不等式

```math
f(x)\ge\sup\{g(x) \mid g \text{ 仿射}，\; g(z)\le f(z) \text{ 对所有 } z\}
```

是清楚的：若 $g$ 是 $f$ 的任何仿射低估器，则 $g(x)\le f(x)$。为确立等号，我们将证明：对每个 $x\in\mathbb{R}^n$，存在一个仿射函数 $g$，它是 $f$ 的全局低估器，且满足 $g(x)=f(x)$。

$f$ 的上图当然是凸集。因此可以在点 $(x,f(x))$ 处找到它的一个支撑超平面：即 $a\in\mathbb{R}^n$、$b\in\mathbb{R}$，$(a,b)\neq0$，且

```math
\begin{bmatrix}a\\b\end{bmatrix}^T\begin{bmatrix}x-z\\f(x)-t\end{bmatrix}\le0
```

对所有 $(z,t)\in\mathbf{epi}\,f$ 成立。这意味着

```math
a^T(x-z)+b(f(x)-f(z)-s)\le0 \tag{3.8}
```

对所有 $z\in\mathbf{dom}\,f=\mathbb{R}^n$ 与所有 $s\ge0$ 成立（因为 $(z,t)\in\mathbf{epi}\,f$ 意味着 $t=f(z)+s$，某个 $s\ge0$）。要 (3.8) 对所有 $s\ge0$ 成立，必须有 $b\ge0$。若 $b=0$，则 (3.8) 退化为 $a^T(x-z)\le0$（对所有 $z\in\mathbb{R}^n$），从而 $a=0$，与 $(a,b)\neq0$ 矛盾。于是 $b>0$，即支撑超平面不是竖直的。

利用 $b>0$，把 (3.8) 在 $s=0$ 时改写为

```math
g(z)=f(x)+(a/b)^T(x-z)\le f(z)
```

对所有 $z$。函数 $g$ 是 $f$ 的仿射低估器，且满足 $g(x)=f(x)$。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">3.2.4 Composition（复合）</span>

<!-- p.97/98 -->

本节考察 $h:\mathbb{R}^k\to\mathbb{R}$ 与 $g:\mathbb{R}^n\to\mathbb{R}^k$ 的条件，保证它们的复合 $f=h\circ g:\mathbb{R}^n\to\mathbb{R}$ 凸或凹，其中

```math
f(x)=h(g(x)),\qquad \mathbf{dom}\,f=\{x\in\mathbf{dom}\,g \mid g(x)\in\mathbf{dom}\,h\}.
```

**标量复合（Scalar composition）。** 先考虑 $k=1$ 的情形：$h:\mathbb{R}\to\mathbb{R}$，$g:\mathbb{R}^n\to\mathbb{R}$。可以只考虑 $n=1$（因为凸性由函数在与其定义域相交的任意直线上的行为决定）。

为发现复合规则，先假设 $h$ 与 $g$ 二阶可微，$\mathbf{dom}\,g=\mathbf{dom}\,h=\mathbb{R}$。此时 $f$ 的凸性退化为 $f''\ge0$（即 $f''(x)\ge0$ 对所有 $x\in\mathbb{R}$）。复合函数 $f=h\circ g$ 的二阶导数为

```math
f''(x)=h''(g(x))g'(x)^2+h'(g(x))g''(x). \tag{3.9}
```



例如设 $g$ 凸（$g''\ge0$），$h$ 凸且 nondecreasing（非减）（$h''\ge0$，$h'\ge0$），则由 (3.9) 得 $f''\ge0$，即 $f$ 凸。类似地，(3.9) 给出结果：

```math
\begin{aligned}
& f \text{ 凸}， && \text{若 } h \text{ 凸且非减，} g \text{ 凸}；\\
& f \text{ 凸}， && \text{若 } h \text{ 凸且非增，} g \text{ 凹}；\\
& f \text{ 凹}， && \text{若 } h \text{ 凹且非减，} g \text{ 凹}；\\
& f \text{ 凹}， && \text{若 } h \text{ 凹且非增，} g \text{ 凸}.
\end{aligned} \tag{3.10}
```

这些陈述在 $g,h$ 二阶可微且定义域为全 $\mathbb{R}$ 时有效。事实上，非常相似的复合规则在一般情形 $n>1$ 下也成立，不需要假设 $h,g$ 可微或 $\mathbf{dom}\,g=\mathbb{R}^n$、$\mathbf{dom}\,h=\mathbb{R}$：

```math
\begin{aligned}
& f \text{ 凸}， && \text{若 } h \text{ 凸}，\ \tilde{h} \text{ 非减}，\ g \text{ 凸}；\\
& f \text{ 凸}， && \text{若 } h \text{ 凸}，\ \tilde{h} \text{ 非增}，\ g \text{ 凹}；\\
& f \text{ 凹}， && \text{若 } h \text{ 凹}，\ \tilde{h} \text{ 非减}，\ g \text{ 凹}；\\
& f \text{ 凹}， && \text{若 } h \text{ 凹}，\ \tilde{h} \text{ 非增}，\ g \text{ 凸}.
\end{aligned} \tag{3.11}
```

这里 $\tilde{h}$ 表示函数 $h$ 的扩值延拓（对凸的 $h$，把 $\mathbf{dom}\,h$ 之外的点赋值 $\infty$；对凹的 $h$ 赋值 $-\infty$）。这些结果与 (3.10) 的唯一差别是：要求扩值延拓函数 $\tilde{h}$ 在整个 $\mathbb{R}$ 上非增或非减。

<!-- p.98/99 -->

为理解这意味着什么：设 $h$ 凸，所以 $\tilde{h}$ 在 $\mathbf{dom}\,h$ 外取值 $\infty$。说 $\tilde{h}$ 非减，意味着对任意 $x,y\in\mathbb{R}$（$x\lt y$）有 $\tilde{h}(x)\le\tilde{h}(y)$。特别地，若 $y\in\mathbf{dom}\,h$ 则 $x\in\mathbf{dom}\,h$。换言之，$h$ 的定义域向负方向无限延伸：它是 $\mathbb{R}$，或形如 $(-\infty,a)$ 或 $(-\infty,a]$ 的区间。类似地，「$h$ 凸且 $\tilde{h}$ 非增」意味着 $h$ 非增且 $\mathbf{dom}\,h$ 向正方向无限延伸。见图 3.7。

<span style="color:#00838f;">**[例 3.12]** 一些简单例子可说明复合定理中对 $h$ 的条件：

- 函数 $h(x)=\log x$（$\mathbf{dom}\,h=\mathbb{R}_{++}$）凹，且 $\tilde{h}$ 非减。
- 函数 $h(x)=x^{1/2}$（$\mathbf{dom}\,h=\mathbb{R}_+$）凹，且满足 $\tilde{h}$ 非减。
- 函数 $h(x)=x^{3/2}$（$\mathbf{dom}\,h=\mathbb{R}_+$）凸，但不满足 $\tilde{h}$ 非减：例如 $\tilde{h}(-1)=\infty$ 但 $\tilde{h}(1)=1$。
- 函数 $h(x)=x^{3/2}$（$x\ge0$）、$h(x)=0$（$x<0$），$\mathbf{dom}\,h=\mathbb{R}$，凸且满足 $\tilde{h}$ 非减。



复合结果 (3.11) 可以直接证明（不假设可微、不用公式 (3.9)）。作为例子，我们证明如下复合定理：若 $g$ 凸，$h$ 凸，$\tilde{h}$ 非减，则 $f=h\circ g$ 凸。设 $x,y\in\mathbf{dom}\,f$，$0\le\theta\le1$。由于 $x,y\in\mathbf{dom}\,f$，有 $x,y\in\mathbf{dom}\,g$ 且 $g(x),g(y)\in\mathbf{dom}\,h$。由 $\mathbf{dom}\,g$ 凸得 $\theta x+(1-\theta)y\in\mathbf{dom}\,g$，又由 $g$ 的凸性

```math
g(\theta x+(1-\theta)y)\le\theta g(x)+(1-\theta)g(y). \tag{3.12}
```

由 $g(x),g(y)\in\mathbf{dom}\,h$ 得 $\theta g(x)+(1-\theta)g(y)\in\mathbf{dom}\,h$，即 (3.12) 的右边属于 $\mathbf{dom}\,h$。现在用 $\tilde{h}$ 非减的假设（其定义域向负方向无限延伸）：由于 (3.12) 的右边属于 $\mathbf{dom}\,h$，可推出左边 $g(\theta x+(1-\theta)y)\in\mathbf{dom}\,h$。这意味着 $\theta x+(1-\theta)y\in\mathbf{dom}\,f$。至此我们已证明 $\mathbf{dom}\,f$ 凸。

再用 $\tilde{h}$ 非减与不等式 (3.12)：

```math
h(g(\theta x+(1-\theta)y))\le h(\theta g(x)+(1-\theta)g(y)). \tag{3.13}
```



由 $h$ 的凸性：

```math
h(\theta g(x)+(1-\theta)g(y))\le\theta h(g(x))+(1-\theta)h(g(y)). \tag{3.14}
```

把 (3.13) 与 (3.14) 合起来：

```math
h(g(\theta x+(1-\theta)y))\le\theta h(g(x))+(1-\theta)h(g(y)),
```

复合定理得证。

<span style="color:#00838f;">**[例 3.13]** **简单复合结果。**

- 若 $g$ 凸，则 $\exp g(x)$ 凸。
- 若 $g$ 凹且为正，则 $\log g(x)$ 凹。
- 若 $g$ 凹且为正，则 $1/g(x)$ 凸。
- 若 $g$ 凸且非负，$p\ge1$，则 $g(x)^p$ 凸。
- 若 $g$ 凸，则 $-\log(-g(x))$ 在 $\{x \mid g(x)<0\}$ 上凸。

<span style="color:#00838f;">**[注 3.3]** 「单调性须对扩值延拓 $\tilde{h}$ 成立而不只是对 $h$」这一要求不能去掉。例如取 $g(x)=x^2$（$\mathbf{dom}\,g=\mathbb{R}$），$h(x)=0$（$\mathbf{dom}\,h=[1,2]$）。$g$ 凸，$h$ 凸且非减。但复合函数 $f=h\circ g$：

```math
f(x)=0,\qquad \mathbf{dom}\,f=[-\sqrt{2},-1]\cup[1,\sqrt{2}]
```

不凸，因为其定义域不凸。这里当然 $\tilde{h}$ 不是非减的。

**向量复合（Vector composition）。** 现在看更复杂的 $k\ge1$ 的情形。设

```math
f(x)=h(g(x))=h(g_1(x),\dots,g_k(x)),
```

其中 $h:\mathbb{R}^k\to\mathbb{R}$，$g_i:\mathbb{R}^n\to\mathbb{R}$。同样不失一般性可设 $n=1$。与 $k=1$ 的情形一样，先假设函数二阶可微、$\mathbf{dom}\,g=\mathbb{R}$、$\mathbf{dom}\,h=\mathbb{R}^k$，以发现复合规则。我们有

```math
f''(x)=g'(x)^T\nabla^2h(g(x))g'(x)+\nabla h(g(x))^Tg''(x), \tag{3.15}
```

它是 (3.9) 的向量类比。问题仍是确定使 $f''(x)\ge0$ 对所有 $x$ 成立的条件（凹性则是 $\le0$）。由 (3.15) 可导出许多规则，例如：

```math
\begin{aligned}
& f \text{ 凸}， && \text{若 } h \text{ 凸}，\ h \text{ 对每个自变量非减}，\ g_i \text{ 凸}；\\
& f \text{ 凸}， && \text{若 } h \text{ 凸}，\ h \text{ 对每个自变量非增}，\ g_i \text{ 凹}；\\
& f \text{ 凹}， && \text{若 } h \text{ 凹}，\ h \text{ 对每个自变量非减}，\ g_i \text{ 凹}.
\end{aligned}
```



与标量情形一样，类似的一般复合结果在 $n>1$、不假设 $h,g$ 可微、一般定义域下也成立；一般结果中 $h$ 的单调性条件必须对扩值延拓 $\tilde{h}$ 成立。

为理解「扩值延拓 $\tilde{h}$ 单调」条件的含义，考虑 $h:\mathbb{R}^k\to\mathbb{R}$ 凸且 $\tilde{h}$ 非减的情形：即只要 $u\preceq v$ 就有 $\tilde{h}(u)\le\tilde{h}(v)$。这意味着若 $v\in\mathbf{dom}\,h$ 则 $u$ 也是：$h$ 的定义域必须沿 $-\mathbb{R}^k_+$ 方向无限延伸。可以紧凑地表为 $\mathbf{dom}\,h-\mathbb{R}^k_+=\mathbf{dom}\,h$。

<span style="color:#00838f;">**[例 3.14]** **向量复合的例子。**

- 令 $h(z)=z_{[1]}+\cdots+z_{[r]}$（$z\in\mathbb{R}^k$ 的最大 $r$ 个分量之和）。则 $h$ 凸且对每个自变量非减。设 $g_1,\dots,g_k$ 是 $\mathbb{R}^n$ 上的凸函数，则复合函数 $f=h\circ g$（即 $g_i$ 中最大 $r$ 个的逐点和）凸。
- 函数 $h(z)=\log(\sum_{i=1}^ke^{z_i})$ 凸且对每个自变量非减，所以只要 $g_i$ 凸，$\log(\sum_{i=1}^ke^{g_i})$ 就凸。
- 对 $0\lt p\le1$，函数 $h(z)=(\sum_{i=1}^kz_i^p)^{1/p}$ 在 $\mathbb{R}^k_+$ 上凹，其延拓（对 $z\not\succeq0$ 取 $-\infty$）对每个分量非减。所以若 $g_i$ 凹且非负，则 $f(x)=(\sum_{i=1}^kg_i(x)^p)^{1/p}$ 凹。
- 设 $p\ge1$，$g_1,\dots,g_k$ 凸且非负，则函数 $(\sum_{i=1}^kg_i(x)^p)^{1/p}$ 凸。为证明，考虑函数 $h:\mathbb{R}^k\to\mathbb{R}$：

```math
h(z)=\Bigl(\sum_{i=1}^k\max\{z_i,0\}^p\Bigr)^{1/p},
```

$\mathbf{dom}\,h=\mathbb{R}^k$，故 $h=\tilde{h}$。这个函数凸且非减，所以 $h(g(x))$ 是 $x$ 的凸函数。当 $z\succeq0$ 时 $h(z)=(\sum_{i=1}^kz_i^p)^{1/p}$，于是结论是 $(\sum_{i=1}^kg_i(x)^p)^{1/p}$ 凸。
- 几何平均 $h(z)=(\prod_{i=1}^kz_i)^{1/k}$ 在 $\mathbb{R}^k_+$ 上凹，其延拓对每个自变量非减。因此若 $g_1,\dots,g_k$ 是非负凹函数，则它们的几何平均 $(\prod_{i=1}^kg_i)^{1/k}$ 也是。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">3.2.5 Minimization（最小化）</span>

<!-- p.101/102 -->

我们已经看到：任意一族凸函数的最大值或上确界是凸的。而某些特殊形式的最小化也产生凸函数。若 $f$ 关于 $(x,y)$ 凸，$C$ 是凸的非空集合，则函数

```math
g(x)=\inf_{y\in C}f(x,y) \tag{3.16}
```

关于 $x$ 凸（只要 $g(x)>-\infty$ 对所有 $x$ 成立）。$g$ 的定义域是 $\mathbf{dom}\,f$ 在其 $x$ 坐标上的投影：

```math
\mathbf{dom}\,g=\{x \mid (x,y)\in\mathbf{dom}\,f \text{ 对某个 } y\in C\}.
```



我们对 $x_1,x_2\in\mathbf{dom}\,g$ 验证 Jensen 不等式来证明。设 $\epsilon>0$，则存在 $y_1,y_2\in C$ 使 $f(x_i,y_i)\le g(x_i)+\epsilon$（$i=1,2$）。令 $\theta\in[0,1]$，有

```math
\begin{aligned}
g(\theta x_1+(1-\theta)x_2)
&= \inf_{y\in C}f(\theta x_1+(1-\theta)x_2,\; y)\\
&\le f(\theta x_1+(1-\theta)x_2,\; \theta y_1+(1-\theta)y_2)\\
&\le \theta f(x_1,y_1)+(1-\theta)f(x_2,y_2)\\
&\le \theta g(x_1)+(1-\theta)g(x_2)+\epsilon.
\end{aligned}
```

由 $\epsilon>0$ 任意，得

```math
g(\theta x_1+(1-\theta)x_2)\le\theta g(x_1)+(1-\theta)g(x_2).
```

这个结果也可以用上图来看。按 (3.16) 定义的 $f,g$ 与 $C$，并假设对每个 $x$ 下确界在 $y\in C$ 上达到，则

```math
\mathbf{epi}\,g=\{(x,t) \mid (x,y,t)\in\mathbf{epi}\,f \text{ 对某个 } y\in C\}.
```

于是 $\mathbf{epi}\,g$ 凸，因为它是凸集向部分分量的投影。

<span style="color:#00838f;">**[例 3.15]** **舒尔补（Schur complement）。** 设二次函数

```math
f(x,y)=x^TAx+2x^TBy+y^TCy
```

（$A$ 与 $C$ 对称）关于 $(x,y)$ 凸，这意味着

```math
\begin{bmatrix}A&B\\B^T&C\end{bmatrix}\succeq0.
```

我们可以把 $g(x)=\inf_yf(x,y)$ 表示为

```math
g(x)=x^T(A-BC^\dagger B^T)x,
```

其中 $C^\dagger$ 是 $C$ 的 pseudo-inverse（伪逆）（见 §A.5.4）。由最小化规则，$g$ 凸，所以 $A-BC^\dagger B^T\succeq0$。若 $C$ 可逆（即 $C\succ0$），则矩阵 $A-BC^{-1}B^T$ 称为 $C$ 在矩阵 $\begin{bmatrix}A&B\\B^T&C\end{bmatrix}$ 中的 Schur complement（舒尔补）（见 §A.5.5）。

<span style="color:#00838f;">**[例 3.16]** **到集合的距离。** 点 $x$ 到集合 $S\subseteq\mathbb{R}^n$ 的距离（按范数 $\|\cdot\|$）定义为

```math
\mathbf{dist}(x,S)=\inf_{y\in S}\|x-y\|.
```

函数 $\|x-y\|$ 关于 $(x,y)$ 凸，所以若集合 $S$ 凸，距离函数 $\mathbf{dist}(x,S)$ 是 $x$ 的凸函数。

<span style="color:#00838f;">**[例 3.17]** 设 $h$ 凸。则函数

```math
g(x)=\inf\{h(y) \mid Ay=x\}
```

凸。为看出这一点，定义

```math
f(x,y)=\begin{cases}h(y) & \text{若 } Ay=x\\ \infty & \text{否则}，\end{cases}
```

它关于 $(x,y)$ 凸。则 $g$ 是 $f$ 关于 $y$ 的最小值，因此凸。（直接证明 $g$ 凸也不难。）

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">3.2.6 Perspective of a function（函数的透视）</span>



若 $f:\mathbb{R}^n\to\mathbb{R}$，则 $f$ 的 perspective（透视）是函数 $g:\mathbb{R}^{n+1}\to\mathbb{R}$：

```math
g(x,t)=tf(x/t),
```

定义域为

```math
\mathbf{dom}\,g=\{(x,t) \mid x/t\in\mathbf{dom}\,f,\; t>0\}.
```

透视运算保持凸性：若 $f$ 凸，则其透视函数 $g$ 凸。同样，若 $f$ 凹，则 $g$ 凹。

这可以用几种方式证明，例如直接验证定义不等式（见习题 3.33）。这里我们用上图与 §2.3.3 中 $\mathbb{R}^{n+1}$ 上的透视映射给一个简短证明（这也解释了「透视」这个名字）。对 $t>0$：

```math
(x,t,s)\in\mathbf{epi}\,g
\iff tf(x/t)\le s
\iff f(x/t)\le s/t
\iff (x/t,\; s/t)\in\mathbf{epi}\,f.
```

因此 $\mathbf{epi}\,g$ 是 $\mathbf{epi}\,f$ 在「把 $(u,v,w)$ 映到 $(u,w)/v$」的透视映射下的原像。由 §2.3.3 得 $\mathbf{epi}\,g$ 凸，故函数 $g$ 凸。

<span style="color:#00838f;">**[例 3.18]** **欧氏范数平方。** 凸函数 $f(x)=x^Tx$（在 $\mathbb{R}^n$ 上）的透视是

```math
g(x,t)=t(x/t)^T(x/t)=\frac{x^Tx}{t},
```

它在 $(x,t)$ 上凸（$t>0$）。我们可以用另外几种方法推出 $g$ 的凸性：第一，可以把 $g$ 表示为二次-线性分式函数 $x_i^2/t$ 之和（§3.1.5 已证其凸）；也可以把 $g$ 表示为矩阵分式函数 $x^T(tI)^{-1}x$ 的特例（见例 3.4）。

<span style="color:#00838f;">**[例 3.19]** **负对数。** 考虑凸函数 $f(x)=-\log x$（$\mathbb{R}_{++}$ 上）。其透视是

```math
g(x,t)=-t\log(x/t)=t\log(t/x)=t\log t-t\log x,
```

在 $\mathbb{R}^2_{++}$ 上凸。函数 $g$ 称为 $t$ 与 $x$ 的 relative entropy（相对熵）。当 $x=1$ 时 $g$ 退化为负熵函数。



由 $g$ 的凸性可以确立若干有趣的有关函数的凸性或凹性。首先，两个向量 $u,v\in\mathbb{R}^n_{++}$ 的相对熵，定义为

```math
\sum_{i=1}^nu_i\log(u_i/v_i),
```

关于 $(u,v)$ 凸，因为它是 $u_i,v_i$ 的相对熵之和。

一个密切相关的函数是 $u,v\in\mathbb{R}^n_{++}$ 之间的 Kullback-Leibler divergence（Kullback-Leibler 散度）：

```math
D_{kl}(u,v)=\sum_{i=1}^n\bigl(u_i\log(u_i/v_i)-u_i+v_i\bigr), \tag{3.17}
```

它是凸的，因为它是相对熵加上一个 $(u,v)$ 的线性函数。KL 散度满足 $D_{kl}(u,v)\ge0$，且 $D_{kl}(u,v)=0$ 当且仅当 $u=v$，因此可用作两个正向量之间 deviation（偏离）的度量；见习题 3.13。（注意当 $u,v$ 是 probability vectors（概率向量），即 $\mathbf{1}^Tu=\mathbf{1}^Tv=1$ 时，相对熵与 KL 散度相同。）

若在相对熵函数中取 $v_i=\mathbf{1}^Tu$，则得到 $u\in\mathbb{R}^n_{++}$ 的一个凹（且齐次）函数：

```math
\sum_{i=1}^nu_i\log(\mathbf{1}^Tu/u_i)=(\mathbf{1}^Tu)\sum_{i=1}^nz_i\log(1/z_i),
```

其中 $z=u/(\mathbf{1}^Tu)$，称为 normalized entropy function（归一化熵函数）。向量 $z=u/\mathbf{1}^Tu$ 是 normalized vector（归一化向量）或 probability distribution（概率分布）（分量和为 1）；$u$ 的归一化熵是这个归一化分布的熵乘以 $\mathbf{1}^Tu$。

<span style="color:#00838f;">**[例 3.20]** 设 $f:\mathbb{R}^m\to\mathbb{R}$ 凸，$A\in\mathbb{R}^{m\times n}$，$b\in\mathbb{R}^m$，$c\in\mathbb{R}^n$，$d\in\mathbb{R}$。定义

```math
g(x)=(c^Tx+d)\,f\bigl((Ax+b)/(c^Tx+d)\bigr),
```

其中

```math
\mathbf{dom}\,g=\{x \mid c^Tx+d>0,\; (Ax+b)/(c^Tx+d)\in\mathbf{dom}\,f\}.
```

则 $g$ 凸。

> <span style="color:#7f8c8d;">§3.1–3.2 翻译完毕。§3.3 共轭函数起见 boyd_ch03b.bilingual.md。</span>



设 $f:\mathbb{R}^n\to\mathbb{R}$。函数 $f^*:\mathbb{R}^n\to\mathbb{R}$ 定义为

```math
f^*(y)=\sup_{x\in\mathbf{dom}\,f}\bigl(y^Tx-f(x)\bigr), \tag{3.18}
```

称为 $f$ 的 conjugate（共轭）。共轭函数的定义域由使上确界有限的 $y\in\mathbb{R}^n$ 组成，即 $y^Tx-f(x)$ 在 $\mathbf{dom}\,f$ 上有上界的那些 $y$。（见图 3.8。）

我们立即看到 $f^*$ 是凸函数：它是 $y$ 的一族凸（其实是仿射）函数的逐点上确界。这与 $f$ 是否凸无关。（注意当 $f$ 凸时，下标 $x\in\mathbf{dom}\,f$ 并不需要，因为按约定，对 $x\notin\mathbf{dom}\,f$ 有 $y^Tx-f(x)=-\infty$。）

我们先看几个简单例子，然后给出共轭的运算规则，从而能导出许多常见凸函数共轭的解析表达式。

<span style="color:#00838f;">**[例 3.21]** 我们推导 $\mathbb{R}$ 上一些凸函数的共轭：

- **仿射函数**。$f(x)=ax+b$。作为 $x$ 的函数，$yx-ax-b$ 有界当且仅当 $y=a$，此时它是常数。因此共轭函数 $f^*$ 的定义域是单点集 $\{a\}$，且 $f^*(a)=-b$。
- **负对数**。$f(x)=-\log x$，$\mathbf{dom}\,f=\mathbb{R}_{++}$。函数 $xy+\log x$ 当 $y\ge0$ 时无上界；否则在 $x=-1/y$ 处达到最大。因此 $\mathbf{dom}\,f^*=\{y \mid y<0\}=-\mathbb{R}_{++}$，且对 $y<0$，$f^*(y)=-\log(-y)-1$。
- **指数函数**。$f(x)=e^x$。$xy-e^x$ 当 $y<0$ 时无界；对 $y>0$，在 $x=\log y$ 处达到最大，故 $f^*(y)=y\log y-y$。对 $y=0$，



$f^*(y)=\sup_x-e^x=0$。总之 $\mathbf{dom}\,f^*=\mathbb{R}_+$，$f^*(y)=y\log y-y$（约定 $0\log0=0$）。
- **负熵**。$f(x)=x\log x$（$\mathbf{dom}\,f=\mathbb{R}_+$，$f(0)=0$）。函数 $xy-x\log x$ 对所有 $y$ 在 $\mathbb{R}_+$ 上有上界，故 $\mathbf{dom}\,f^*=\mathbb{R}$。它在 $x=e^{y-1}$ 处达到最大，代入得 $f^*(y)=e^{y-1}$。
- **倒数**。$f(x)=1/x$（$\mathbb{R}_{++}$ 上）。$y>0$ 时 $yx-1/x$ 无上界；$y=0$ 时上确界为 0；$y<0$ 时上确界在 $x=(-y)^{-1/2}$ 达到。因此 $f^*(y)=-2(-y)^{1/2}$，$\mathbf{dom}\,f^*=-\mathbb{R}_+$。

<span style="color:#00838f;">**[例 3.22]** **严格凸二次函数。** 考虑 $f(x)=\frac{1}{2}x^TQx$（$Q\in\mathbf{S}^n_{++}$）。函数 $y^Tx-\frac{1}{2}x^TQx$ 作为 $x$ 的函数对所有 $y$ 有上界，在 $x=Q^{-1}y$ 达到最大，故

```math
f^*(y)=\frac{1}{2}y^TQ^{-1}y.
```

<span style="color:#00838f;">**[例 3.23]** **对数行列式。** 考虑 $f(X)=\log\det X^{-1}$（$\mathbf{S}^n_{++}$ 上）。共轭函数定义为

```math
f^*(Y)=\sup_{X\succ0}\bigl(\mathbf{tr}(YX)+\log\det X\bigr),
```

因为 $\mathbf{tr}(YX)$ 是 $\mathbf{S}^n$ 上的标准内积。先证除非 $Y\prec0$，$\mathbf{tr}(YX)+\log\det X$ 无上界：若 $Y\not\prec0$，则 $Y$ 有特征向量 $v$（$\|v\|_2=1$）与特征值 $\lambda\ge0$。取 $X=I+tvv^T$，得

```math
\mathbf{tr}(YX)+\log\det X=\mathbf{tr}Y+t\lambda+\log(1+t),
```

当 $t\to\infty$ 时无上界。再考虑 $Y\prec0$ 的情形：令对 $X$ 的梯度为零可找到最大化点：

```math
\nabla_X\bigl(\mathbf{tr}(YX)+\log\det X\bigr)=Y+X^{-1}=0
```

（见 §A.4.1），解得 $X=-Y^{-1}$（确为正定）。因此

```math
f^*(Y)=\log\det(-Y)^{-1}-n,\qquad \mathbf{dom}\,f^*=-\mathbf{S}^n_{++}.
```

<span style="color:#00838f;">**[例 3.24]** **示性函数。** 设 $I_S$ 是（不必凸的）集合 $S\subseteq\mathbb{R}^n$ 的示性函数，即 $I_S(x)=0$（$\mathbf{dom}\,I_S=S$）。其共轭为

```math
I_S^*(y)=\sup_{x\in S}y^Tx,
```

即集合 $S$ 的支撑函数。



<span style="color:#00838f;">**[例 3.25]** **Log-sum-exp 函数。** 为推导 log-sum-exp 函数 $f(x)=\log(\sum_{i=1}^ne^{x_i})$ 的共轭，先确定使 $y^Tx-f(x)$ 关于 $x$ 的最大值能取到的那些 $y$。令对 $x$ 的梯度为零，得条件

```math
y_i=\frac{e^{x_i}}{\sum_{j=1}^ne^{x_j}},\qquad i=1,\dots,n.
```

这组方程关于 $x$ 可解当且仅当 $y\succ0$ 且 $\mathbf{1}^Ty=1$。把 $y_i$ 的表达式代入 $y^Tx-f(x)$ 得 $f^*(y)=\sum_{i=1}^ny_i\log y_i$。只要 $y\succeq0$ 且 $\mathbf{1}^Ty=1$（约定 $0\log0=0$），即使 $y$ 的某些分量为零，这个 $f^*$ 的表达式仍然正确。

事实上 $f^*$ 的定义域恰为 $\mathbf{1}^Ty=1$、$y\succeq0$。为证之：设 $y$ 有负分量，比如 $y_k<0$，则取 $x_k=-t$、$x_i=0$（$i\neq k$）并令 $t\to\infty$，可证 $y^Tx-f(x)$ 无上界。若 $y\succeq0$ 但 $\mathbf{1}^Ty\neq1$，取 $x=t\mathbf{1}$，则

```math
y^Tx-f(x)=t\,\mathbf{1}^Ty-t-\log n.
```

若 $\mathbf{1}^Ty>1$，它当 $t\to\infty$ 时无界增长；若 $\mathbf{1}^Ty<1$，当 $t\to-\infty$ 时无界增长。总之：

```math
f^*(y)=\begin{cases}\sum_{i=1}^ny_i\log y_i & \text{若 } y\succeq0 \text{ 且 } \mathbf{1}^Ty=1\\ \infty & \text{否则}. \end{cases}
```

换言之，log-sum-exp 函数的共轭是限制在概率单纯形上的负熵函数。

<span style="color:#00838f;">**[例 3.26]** **范数。** 设 $\|\cdot\|$ 是 $\mathbb{R}^n$ 上的范数，对偶范数 $\|\cdot\|_*$。我们将证明 $f(x)=\|x\|$ 的共轭是

```math
f^*(y)=\begin{cases}0 & \|y\|_*\le1\\ \infty & \text{否则}，\end{cases}
```

即范数的共轭是对偶范数单位球的示性函数。若 $\|y\|_*>1$，则由对偶范数定义存在 $z\in\mathbb{R}^n$ 使 $\|z\|\le1$ 且 $y^Tz>1$。取 $x=tz$ 并令 $t\to\infty$：

```math
y^Tx-\|x\|=t(y^Tz-\|z\|)\to\infty,
```

故 $f^*(y)=\infty$。反之若 $\|y\|_*\le1$，则对所有 $x$ 有 $y^Tx\le\|x\|\|y\|_*$，从而对所有 $x$ 有 $y^Tx-\|x\|\le0$。因此最大化 $y^Tx-\|x\|$ 的是 $x=0$，最大值 0。

<span style="color:#00838f;">**[例 3.27]** **范数平方。** 考虑 $f(x)=(1/2)\|x\|^2$（$\|\cdot\|$ 为范数，对偶范数 $\|\cdot\|_*$）。我们将证明其共轭为 $f^*(y)=(1/2)\|y\|_*^2$。由 $y^Tx\le\|y\|_*\|x\|$ 得

```math
y^Tx-(1/2)\|x\|^2\le\|y\|_*\|x\|-(1/2)\|x\|^2
```



（对所有 $x$）。右边是关于 $\|x\|$ 的二次函数，最大值为 $(1/2)\|y\|_*^2$。因此对所有 $x$：

```math
y^Tx-(1/2)\|x\|^2\le(1/2)\|y\|_*^2,
```

即 $f^*(y)\le(1/2)\|y\|_*^2$。为证另一侧不等式，取满足 $y^Tx=\|y\|_*\|x\|$ 的向量 $x$，并缩放使 $\|x\|=\|y\|_*$。对这个 $x$：

```math
y^Tx-(1/2)\|x\|^2=(1/2)\|y\|_*^2,
```

故 $f^*(y)\ge(1/2)\|y\|_*^2$。

<span style="color:#00838f;">**[例 3.28]** **收益与利润函数。** 考虑一个消耗 $n$ 种资源并生产可售产品的企业。令 $r=(r_1,\dots,r_n)$ 表示消耗的资源量向量，$S(r)$ 表示由所生产产品获得的销售收入（作为消耗资源的函数）。设 $p_i$ 是资源 $i$ 的单价，则企业为资源支付的总金额是 $p^Tr$。企业的 profit（利润）为 $S(r)-p^Tr$。固定资源价格，问：通过明智地选择资源消耗量，能获得的最大利润是多少？这个最大利润由

```math
M(p)=\sup_r\bigl(S(r)-p^Tr\bigr)
```

给出。函数 $M(p)$ 给出作为资源价格函数的可获得最大利润。用共轭函数的语言：$M(p)=(-S)^*(-p)$。因此最大利润（作为资源价格的函数）与总销售额（作为资源消耗的函数）的共轭密切相关。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">3.3.2 Basic properties（基本性质）</span>

**Fenchel 不等式（Fenchel's inequality）。** 由共轭函数的定义立即得到不等式

```math
f(x)+f^*(y)\ge x^Ty
```

对所有 $x,y$ 成立。这称为 Fenchel's inequality（Fenchel 不等式）（当 $f$ 可微时也称 Young's inequality，杨氏不等式）。例如取 $f(x)=(1/2)x^TQx$（$Q\in\mathbf{S}^n_{++}$），得不等式

```math
x^Ty\le(1/2)x^TQx+(1/2)y^TQ^{-1}y.
```

<!-- p.108/109 -->

**共轭的共轭（Conjugate of the conjugate）。** 上面的例子与「conjugate」这个名字暗示：凸函数的共轭的共轭是原函数。这只在一个技术性条件下成立：若 $f$ 凸且 closed（闭，即 $\mathbf{epi}\,f$ 是闭集；见 §A.3.3），则 $f^{**}=f$。例如若 $\mathbf{dom}\,f=\mathbb{R}^n$，则 $f^{**}=f$（见习题 3.39）。

**可微函数（Differentiable functions）。** 可微函数 $f$ 的共轭也称为 $f$ 的 Legendre transform（勒让德变换）。（为了区分一般定义与可微情形，有时用术语 Fenchel conjugate 代替 conjugate。）

设 $f$ 凸且可微，$\mathbf{dom}\,f=\mathbb{R}^n$。$y^Tx-f(x)$ 的任何 maximizer（最大化点）$x^*$ 满足 $y=\nabla f(x^*)$；反之，若 $x^*$ 满足 $y=\nabla f(x^*)$，则 $x^*$ 最大化 $y^Tx-f(x)$。因此若 $y=\nabla f(x^*)$，有

```math
f^*(y)=x^{*T}\nabla f(x^*)-f(x^*).
```

这使我们能对任何「能把梯度方程 $y=\nabla f(z)$ 解出 $z$」的 $y$ 确定 $f^*(y)$。

也可以这样表达：设 $z\in\mathbb{R}^n$ 任意，定义 $y=\nabla f(z)$，则

```math
f^*(y)=z^T\nabla f(z)-f(z).
```

**缩放与仿射变换复合（Scaling and composition with affine transformation）。** 对 $a>0$、$b\in\mathbb{R}$，$g(x)=af(x)+b$ 的共轭是 $g^*(y)=af^*(y/a)-b$。设 $A\in\mathbb{R}^{n\times n}$ 非奇异，$b\in\mathbb{R}^n$，则 $g(x)=f(Ax+b)$ 的共轭是

```math
g^*(y)=f^*(A^{-T}y)-b^TA^{-T}y,\qquad \mathbf{dom}\,g^*=A^T\mathbf{dom}\,f^*.
```

**独立函数之和（Sums of independent functions）。** 若 $f(u,v)=f_1(u)+f_2(v)$（$f_1,f_2$ 凸，共轭分别为 $f_1^*,f_2^*$），则

```math
f^*(w,z)=f_1^*(w)+f_2^*(z).
```

换言之，独立凸函数之和的共轭是共轭之和。（「独立」指它们是不同变量的函数。）

## <span style="color:#c0392b;">3.4 Quasiconvex functions（拟凸函数）</span>

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">3.4.1 Definition and examples（定义与例子）</span>



函数 $f:\mathbb{R}^n\to\mathbb{R}$ 称为 quasiconvex（拟凸）的（或 unimodal，单峰的），如果其定义域与它的所有下水平集

```math
S_\alpha=\{x\in\mathbf{dom}\,f \mid f(x)\le\alpha\}\qquad(\alpha\in\mathbb{R})
```

都是凸的。函数是 quasiconcave（拟凹）的，若 $-f$ 拟凸，即每个上水平集 $\{x \mid f(x)\ge\alpha\}$ 凸。既拟凸又拟凹的函数称为 quasilinear（拟线性）的。若 $f$ 拟线性，则其定义域与每个 level set（水平集）$\{x \mid f(x)=\alpha\}$ 都是凸的。



对 $\mathbb{R}$ 上的函数，拟凸性要求每个下水平集是一个区间（可能是无限区间）。图 3.9 展示了 $\mathbb{R}$ 上拟凸函数的例子。

凸函数具有凸的下水平集，因此是拟凸的。但简单的例子（如图 3.9）表明逆命题不成立。

<span style="color:#00838f;">**[例 3.29]** $\mathbb{R}$ 上的一些例子：

- **对数**。$\log x$（$\mathbb{R}_{++}$ 上）拟凸（且拟凹，从而拟线性）。
- **上取整函数**。$\mathbf{ceil}(x)=\inf\{z\in\mathbb{Z} \mid z\ge x\}$ 拟凸（且拟凹）。

这些例子表明拟凸函数可以是凹的，或是不连续的。现在给 $\mathbb{R}^n$ 上的一些例子。

<span style="color:#00838f;">**[例 3.30]** **向量的长度。** 我们定义 $x\in\mathbb{R}^n$ 的 length（长度）为非零分量的最大下标：

```math
f(x)=\max\{i \mid x_i\neq0\}
```

（零向量的长度定义为零）。这个函数在 $\mathbb{R}^n$ 上拟凸，因为其下水平集是子空间：

```math
f(x)\le\alpha \iff x_i=0,\ i=\lfloor\alpha\rfloor+1,\dots,n.
```

<span style="color:#00838f;">**[例 3.31]** 考虑 $f:\mathbb{R}^2\to\mathbb{R}$，$\mathbf{dom}\,f=\mathbb{R}^2_+$，$f(x_1,x_2)=x_1x_2$。这个函数既不凸也不凹，因为其 Hessian

```math
\nabla^2f(x)=\begin{bmatrix}0&1\\1&0\end{bmatrix}
```



indefinite（不定）：有一个正特征值与一个负特征值。但 $f$ 是拟凹的，因为上水平集

```math
\{x\in\mathbb{R}^2_+ \mid x_1x_2\ge\alpha\}
```

对所有 $\alpha$ 都是凸集。（不过注意 $f$ 在 $\mathbb{R}^2$ 上不是拟凹的。）

<span style="color:#00838f;">**[例 3.32]** **线性分式函数。** 函数

```math
f(x)=\frac{a^Tx+b}{c^Tx+d},\qquad \mathbf{dom}\,f=\{x \mid c^Tx+d>0\}
```

既拟凸又拟凹，即拟线性。其 $\alpha$-下水平集为

```math
\begin{aligned}
S_\alpha &= \{x \mid c^Tx+d>0,\; (a^Tx+b)/(c^Tx+d)\le\alpha\}\\
&= \{x \mid c^Tx+d>0,\; a^Tx+b\le\alpha(c^Tx+d)\},
\end{aligned}
```

它是凸的，因为它是开半空间与闭半空间的交。（同样的方法可证其上水平集凸。）

<span style="color:#00838f;">**[例 3.33]** **距离比函数。** 设 $a,b\in\mathbb{R}^n$，定义

```math
f(x)=\frac{\|x-a\|_2}{\|x-b\|_2},
```

即到 $a$ 的欧氏距离与到 $b$ 的距离之比。则 $f$ 在半空间 $\{x \mid \|x-a\|_2\le\|x-b\|_2\}$ 上拟凸。为看出这一点，考虑 $f$ 的 $\alpha$-下水平集（$\alpha\le1$，因为在该半空间上 $f(x)\le1$）。此下水平集是满足

```math
\|x-a\|_2\le\alpha\|x-b\|_2
```

的点集。两边平方并整理，等价于

```math
(1-\alpha^2)x^Tx-2(a-\alpha^2b)^Tx+a^Ta-\alpha^2b^Tb\le0.
```

当 $\alpha\le1$ 时这描述一个凸集（其实是一个欧氏球）。

<span style="color:#00838f;">**[例 3.34]** **内部收益率（internal rate of return）。** 设 $x=(x_0,x_1,\dots,x_n)$ 表示 $n$ 个周期上的 cash flow（现金流）序列，$x_i>0$ 表示第 $i$ 期付给我们，$x_i<0$ 表示我们付出。定义现金流在利率 $r\ge0$ 下的 present value（现值）：

```math
\mathrm{PV}(x,r)=\sum_{i=0}^n(1+r)^{-i}x_i
```

（因子 $(1+r)^{-i}$ 是第 $i$ 期收支的 discount factor（贴现因子））。现在考虑满足 $x_0<0$ 且 $x_0+x_1+\cdots+x_n>0$ 的现金流：这表示第 0 期我们投资 $|x_0|$，且其余现金流总和 $x_1+\cdots+x_n$（不计贴现）超过初始投资。



对这样的现金流，$\mathrm{PV}(x,0)>0$ 且当 $r\to\infty$ 时 $\mathrm{PV}(x,r)\to x_0<0$，因此至少存在一个 $r\ge0$ 使 $\mathrm{PV}(x,r)=0$。我们把现金流的 internal rate of return（内部收益率）定义为使现值为零的最小利率：

```math
\mathrm{IRR}(x)=\inf\{r\ge0 \mid \mathrm{PV}(x,r)=0\}.
```

内部收益率是 $x$ 的拟凹函数（限制在 $x_0<0$、$x_1+\cdots+x_n>0$ 上）。为看出这一点，注意

```math
\mathrm{IRR}(x)\ge R \iff \mathrm{PV}(x,r)>0 \text{ 对 } 0\le r<R.
```

左边定义了 IRR 的 $R$-上水平集；右边是以 $r$ 索引的集合 $\{x \mid \mathrm{PV}(x,r)>0\}$ 在 $0\le r\lt R$ 范围上的交。对每个 $r$，$\mathrm{PV}(x,r)>0$ 定义一个开半空间，所以右边定义一个凸集。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">3.4.2 Basic properties（基本性质）</span>

<!-- p.112/113 -->

上面的例子表明拟凸性是凸性的一个相当大的推广。尽管如此，凸函数的许多性质对拟凸函数也成立或有对应物。例如，Jensen 不等式有一个刻画拟凸性的变体：**函数 $f$ 拟凸当且仅当 $\mathbf{dom}\,f$ 凸，且对任意 $x,y\in\mathbf{dom}\,f$ 与 $0\le\theta\le1$，**

```math
f(\theta x+(1-\theta)y)\le\max\{f(x),f(y)\}, \tag{3.19}
```

即函数在线段上的值不超过它在端点值的最大值。不等式 (3.19) 有时称为 quasiconvex functions 的 Jensen 不等式（拟凸函数的 Jensen 不等式），见图 3.10。

<span style="color:#00838f;">**[例 3.35]** **非负向量的基数。** 向量 $x\in\mathbb{R}^n$ 的 cardinality（基数/大小）是它非零分量的个数，记作 $\mathbf{card}(x)$。函数 $\mathbf{card}$ 在 $\mathbb{R}^n_+$ 上拟凹（但在 $\mathbb{R}^n$ 上不是）。这直接由修正的 Jensen 不等式

```math
\mathbf{card}(x+y)\ge\min\{\mathbf{card}(x),\mathbf{card}(y)\}
```

得出（对 $x,y\succeq0$ 成立）。

<span style="color:#00838f;">**[例 3.36]** **半正定矩阵的秩。** 函数 $\mathbf{rank}\,X$ 在 $\mathbf{S}^n_+$ 上拟凹。这由修正的 Jensen 不等式 (3.19) 得出：

```math
\mathbf{rank}(X+Y)\ge\min\{\mathbf{rank}\,X,\mathbf{rank}\,Y\}
```

对 $X,Y\in\mathbf{S}^n_+$ 成立。（这可看作前一例的推广，因为对 $x\succeq0$ 有 $\mathbf{rank}(\mathbf{diag}(x))=\mathbf{card}(x)$。）

<!-- p.113/114 -->

与凸性一样，拟凸性由函数 $f$ 在直线上的行为刻画：$f$ 拟凸当且仅当它限制到任何与其定义域相交的直线上是拟凸的。特别地，拟凸性可以通过把函数限制到任意直线、再检查所得 $\mathbb{R}$ 上函数的拟凸性来验证。

**$\mathbb{R}$ 上的拟凸函数。** 我们可以对 $\mathbb{R}$ 上的拟凸函数给出简单刻画。考虑 continuous（连续）函数，因为在一般情形陈述条件会很繁琐。连续函数 $f:\mathbb{R}\to\mathbb{R}$ 拟凸当且仅当以下条件至少一个成立：

- $f$ 是非减的；
- $f$ 是非增的；
- 存在点 $c\in\mathbf{dom}\,f$，使得对 $t\le c$（且 $t\in\mathbf{dom}\,f$），$f$ 非增；对 $t\ge c$（且 $t\in\mathbf{dom}\,f$），$f$ 非减。

点 $c$ 可取为 $f$ 的任何 global minimizer（全局最小化点）。图 3.11 展示了这一点。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">3.4.3 Differentiable quasiconvex functions（可微拟凸函数）</span>

```math
f(y)\le f(x) \implies \nabla f(x)^T(y-x)\le0. \tag{3.20}
```

条件 (3.20) 在 $\nabla f(x)\neq0$ 时有简单的几何解释：它说 $\nabla f(x)$ 定义了下水平集 $\{y \mid f(y)\le f(x)\}$ 在点 $x$ 处的支撑超平面（见图 3.12）。

虽然凸性的一阶条件 (3.2) 与拟凸性的一阶条件 (3.20) 相似，但存在重要差异。例如：若 $f$ 凸且 $\nabla f(x)=0$，则 $x$ 是 $f$ 的全局最小化点。但这对拟凸函数不成立：可能有 $\nabla f(x)=0$ 而 $x$ 并非 $f$ 的全局最小化点。

**二阶条件（Second-order conditions）。** 现在设 $f$ 二阶可微。若 $f$ 拟凸，则对所有 $x\in\mathbf{dom}\,f$ 与所有 $y\in\mathbb{R}^n$：

```math
y^T\nabla f(x)=0 \implies y^T\nabla^2f(x)y\ge0. \tag{3.21}
```

对 $\mathbb{R}$ 上的拟凸函数，这退化为简单条件

```math
f'(x)=0 \implies f''(x)\ge0,
```
