作为（部分）逆命题：若 $f$ 满足

```math
y^T\nabla f(x)=0 \implies y^T\nabla^2f(x)y>0 \tag{3.22}
```

（对所有 $x\in\mathbf{dom}\,f$ 与所有 $y\in\mathbb{R}^n$、$y\neq0$），则 $f$ 拟凸。这个条件等价于：在 $\nabla f(x)=0$ 的点要求 $\nabla^2f(x)$ 正定，在其他所有点要求 $\nabla^2f(x)$ 在 $(n-1)$ 维子空间 $\nabla f(x)^\perp$ 上正定。

**拟凸性二阶条件的证明。** 通过把函数限制到任意直线，只需考虑 $f:\mathbb{R}\to\mathbb{R}$ 的情形。

先证：若 $f:\mathbb{R}\to\mathbb{R}$ 在区间 $(a,b)$ 上拟凸，则必满足 (3.21)，即若 $f'(c)=0$（$c\in(a,b)$），则必有 $f''(c)\ge0$。反设 $f'(c)=0$、$c\in(a,b)$ 而 $f''(c)<0$，则对小的正 $\epsilon$ 有 $f(c-\epsilon)\lt f(c)$ 且 $f(c+\epsilon)\lt f(c)$。于是下水平集 $\{x \mid f(x)\le f(c)-\epsilon\}$ 对小的正 $\epsilon$ 是 disconnected（不连通）的，因此不凸，与 $f$ 拟凸的假设矛盾。

再证：若条件 (3.22) 成立，则 $f$ 拟凸。设 (3.22) 成立，即对每个使 $f'(c)=0$ 的 $c\in(a,b)$ 有 $f''(c)>0$。这意味着 $f'$ 每当穿过值 0 时都是严格递增的，因此至多穿过 0 一次。若 $f'$ 完全不穿过 0，则 $f$ 在 $(a,b)$ 上非增或非减，从而拟凸。否则它恰好穿过 0 一次，设在 $c\in(a,b)$。由 $f''(c)>0$ 得：对 $a\lt t\le c$，$f'(t)\le0$；对 $c\le t\lt b$，$f'(t)\ge0$。这表明 $f$ 拟凸。

**非负加权最大值（Nonnegative weighted maximum）。** 拟凸函数的非负加权最大值

```math
f=\max\{w_1f_1,\dots,w_mf_m\}
```



（$w_i\ge0$，$f_i$ 拟凸）是拟凸的。这个性质可推广到一般的逐点上确界：

```math
f(x)=\sup_{y\in C}\bigl(w(y)g(x,y)\bigr),
```

其中 $w(y)\ge0$ 且 $g(x,y)$ 对每个 $y$ 关于 $x$ 拟凸。这个事实容易验证：$f(x)\le\alpha$ 当且仅当

```math
w(y)g(x,y)\le\alpha \text{ 对所有 } y\in C,
```

即 $f$ 的 $\alpha$-下水平集是函数 $w(y)g(x,y)$（视为 $x$ 的函数）的 $\alpha$-下水平集之交。

<span style="color:#00838f;">**[例 3.37]** **广义特征值。** 对称矩阵对 $(X,Y)$（$Y\succ0$）的 maximum generalized eigenvalue（最大广义特征值）定义为

```math
\lambda_{\max}(X,Y)=\sup_{u\neq0}\frac{u^TXu}{u^TYu}=\sup\{\lambda \mid \det(\lambda Y-X)=0\}
```

（见 §A.5.3）。这个函数在 $\mathbf{dom}\,f=\mathbf{S}^n\times\mathbf{S}^n_{++}$ 上拟凸。为看出这一点，考虑表达式

```math
\lambda_{\max}(X,Y)=\sup_{u\neq0}\frac{u^TXu}{u^TYu}.
```

对每个 $u\neq0$，函数 $u^TXu/u^TYu$ 关于 $(X,Y)$ 是线性分式的，因此是 $(X,Y)$ 的拟凸函数。我们得出 $\lambda_{\max}$ 拟凸，因为它是拟凸函数族的上确界。

**复合（Composition）。** 若 $g:\mathbb{R}^n\to\mathbb{R}$ 拟凸且 $h:\mathbb{R}\to\mathbb{R}$ 非减，则 $f=h\circ g$ 拟凸。

拟凸函数与仿射或线性分式变换的复合产生拟凸函数。若 $f$ 拟凸，则 $g(x)=f(Ax+b)$ 拟凸，且 $\tilde{g}(x)=f((Ax+b)/(c^Tx+d))$ 在集合

```math
\{x \mid c^Tx+d>0,\; (Ax+b)/(c^Tx+d)\in\mathbf{dom}\,f\}
```

上拟凸。

**最小化（Minimization）。** 若 $f(x,y)$ 关于 $x,y$ 联合拟凸且 $C$ 是凸集，则函数

```math
g(x)=\inf_{y\in C}f(x,y)
```

拟凸。为证明，须证 $\{x \mid g(x)\le\alpha\}$ 凸（$\alpha\in\mathbb{R}$ 任意）。由 $g$ 的定义，$g(x)\le\alpha$ 当且仅当对任意 $\epsilon>0$ 存在



$y\in C$ 使 $f(x,y)\le\alpha+\epsilon$。设 $x_1,x_2$ 是 $g$ 的 $\alpha$-下水平集中两点，则对任意 $\epsilon>0$ 存在 $y_1,y_2\in C$ 使

```math
f(x_1,y_1)\le\alpha+\epsilon,\qquad f(x_2,y_2)\le\alpha+\epsilon,
```

且由于 $f$ 关于 $x,y$ 拟凸，对 $0\le\theta\le1$ 也有

```math
f(\theta x_1+(1-\theta)x_2,\; \theta y_1+(1-\theta)y_2)\le\alpha+\epsilon.
```

因此 $g(\theta x_1+(1-\theta)x_2)\le\alpha$，即证 $\{x \mid g(x)\le\alpha\}$ 凸。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">3.4.5 Representation via family of convex functions（通过凸函数族的表示）</span>

<!-- p.117/118 -->

在后文中，用凸函数的不等式来表示拟凸函数 $f$ 的（凸的）下水平集会很方便。我们寻找一族由 $t\in\mathbb{R}$ 索引的凸函数 $\phi_t:\mathbb{R}^n\to\mathbb{R}$，满足

```math
f(x)\le t \iff \phi_t(x)\le0, \tag{3.23}
```

即拟凸函数 $f$ 的 $t$-下水平集是凸函数 $\phi_t$ 的 0-下水平集。显然 $\phi_t$ 须满足：对所有 $x\in\mathbb{R}^n$，

```math
\phi_t(x)\le0 \implies \phi_s(x)\le0 \text{ 对 } s\ge t.
```

若对每个 $x$，$\phi_t(x)$ 是 $t$ 的非增函数（即 $s\ge t$ 时 $\phi_s(x)\le\phi_t(x)$），则上式满足。

为看到这种表示总存在，可取

```math
\phi_t(x)=\begin{cases}0 & f(x)\le t\\ \infty & \text{否则}，\end{cases}
```

即 $\phi_t$ 是 $f$ 的 $t$-下水平集的示性函数。显然这种表示不唯一：例如若 $f$ 的下水平集是闭的，可取

```math
\phi_t(x)=\mathbf{dist}\bigl(x,\{z \mid f(z)\le t\}\bigr).
```

我们通常关心有良好性质（如可微性）的函数族 $\phi_t$。

<span style="color:#00838f;">**[例 3.38]** **凸比凹函数。** 设 $p$ 是凸函数，$q$ 是凹函数，在凸集 $C$ 上 $p(x)\ge0$、$q(x)>0$。则定义在 $C$ 上的函数 $f(x)=p(x)/q(x)$ 拟凸。这里

```math
f(x)\le t \iff p(x)-tq(x)\le0,
```

所以可取 $\phi_t(x)=p(x)-tq(x)$（$t\ge0$）。对每个 $t$，$\phi_t$ 凸；对每个 $x$，$\phi_t(x)$ 关于 $t$ 递减。

## <span style="color:#c0392b;">3.5 Log-concave and log-convex functions（对数凹与对数凸函数）</span>

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">3.5.1 Definition（定义）</span>



函数 $f:\mathbb{R}^n\to\mathbb{R}$ 称为 logarithmically concave（对数凹，log-concave）的，如果 $f(x)>0$ 对所有 $x\in\mathbf{dom}\,f$ 且 $\log f$ 凹。称为 logarithmically convex（对数凸，log-convex）的，如果 $\log f$ 凸。因此 $f$ 对数凸当且仅当 $1/f$ 对数凹。允许 $f$ 取零值会带来方便，此时取 $\log f(x)=-\infty$；在这种情况下，若扩值函数 $\log f$ 凹，则称 $f$ 对数凹。

我们可以不用对数直接表达对数凹性：定义域凸且 $f(x)>0$（对所有 $x\in\mathbf{dom}\,f$）的函数 $f:\mathbb{R}^n\to\mathbb{R}$ 对数凹，当且仅当对所有 $x,y\in\mathbf{dom}\,f$ 与 $0\le\theta\le1$：

```math
f(\theta x+(1-\theta)y)\ge f(x)^\theta f(y)^{1-\theta}.
```

特别地，对数凹函数在两点平均值处的值至少是它在两点取值的 geometric mean（几何平均）。

由复合规则知道 $e^h$ 在 $h$ 凸时凸，所以对数凸函数是凸的。类似地，非负的凹函数是对数凹的。同样显然：由于对数单调递增，对数凸函数拟凸，对数凹函数拟凹。

<span style="color:#00838f;">**[例 3.39]** 一些简单的对数凹与对数凸函数例子：

- **仿射函数**。$f(x)=a^Tx+b$ 在 $\{x \mid a^Tx+b>0\}$ 上对数凹。
- **幂函数**。$f(x)=x^a$（$\mathbb{R}_{++}$ 上）当 $a\le0$ 时对数凸，当 $a\ge0$ 时对数凹。
- **指数函数**。$f(x)=e^{ax}$ 既对数凸又对数凹。
- **高斯密度的累积分布函数**，

```math
\Phi(x)=\frac{1}{\sqrt{2\pi}}\int_{-\infty}^xe^{-u^2/2}\,du,
```

对数凹（见习题 3.54）。
- **Gamma 函数**，

```math
\Gamma(x)=\int_0^\infty u^{x-1}e^{-u}\,du,
```

对 $x\ge1$ 对数凸（见习题 3.52）。
- **行列式**。$\det X$ 在 $\mathbf{S}^n_{++}$ 上对数凹。
- **行列式比迹**。$\det X/\,\mathbf{tr}\,X$ 在 $\mathbf{S}^n_{++}$ 上对数凹（见习题 3.49）。

<!-- p.118/119 -->

<span style="color:#00838f;">**[例 3.40]** **对数凹的密度函数。** 许多常见的概率密度函数都是对数凹的。两个例子：multivariate normal distribution（多元正态分布）

```math
f(x)=\frac{1}{\sqrt{(2\pi)^n\det\Sigma}}e^{-\frac{1}{2}(x-\bar{x})^T\Sigma^{-1}(x-\bar{x})}
```



（其中 $\bar{x}\in\mathbb{R}^n$，$\Sigma\in\mathbf{S}^n_{++}$），以及 $\mathbb{R}^n_+$ 上的 exponential distribution（指数分布）

```math
f(x)=\Bigl(\prod_{i=1}^n\lambda_i\Bigr)e^{-\lambda^Tx}
```

（其中 $\lambda\succ0$）。另一个例子是凸集 $C$ 上的 uniform distribution（均匀分布）：

```math
f(x)=\begin{cases}1/\alpha & x\in C\\ 0 & x\notin C,\end{cases}
```

其中 $\alpha=\mathbf{vol}(C)$ 是 $C$ 的 volume（体积，Lebesgue 测度）。此时 $\log f$ 在 $C$ 外取值 $-\infty$、在 $C$ 上取 $-\log\alpha$，因此凹。

一个更奇特（exotic）的例子是 Wishart distribution（Wishart 分布），定义如下：设 $x_1,\dots,x_p\in\mathbb{R}^n$ 是独立的零均值、协方差 $\Sigma\in\mathbf{S}^n$ 的 Gaussian random vectors（高斯随机向量），$p>n$。随机矩阵 $X=\sum_{i=1}^px_ix_i^T$ 具有 Wishart 密度

```math
f(X)=a\,(\det X)^{(p-n-1)/2}e^{-\frac{1}{2}\mathbf{tr}(\Sigma^{-1}X)},
```

$\mathbf{dom}\,f=\mathbf{S}^n_{++}$，$a$ 为正常数。Wishart 密度对数凹，因为

```math
\log f(X)=\log a+\frac{p-n-1}{2}\log\det X-\frac{1}{2}\mathbf{tr}(\Sigma^{-1}X)
```

是 $X$ 的凹函数。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">3.5.2 Properties（性质）</span>

**二阶可微的对数凸/凹函数。** 设 $f$ 二阶可微，$\mathbf{dom}\,f$ 凸，则

```math
\nabla^2\log f(x)=\frac{1}{f(x)}\nabla^2f(x)-\frac{1}{f(x)^2}\nabla f(x)\nabla f(x)^T.
```

我们得出：$f$ 对数凸当且仅当对所有 $x\in\mathbf{dom}\,f$，

```math
f(x)\nabla^2f(x)\succeq\nabla f(x)\nabla f(x)^T,
```

对数凹当且仅当对所有 $x\in\mathbf{dom}\,f$，

```math
f(x)\nabla^2f(x)\preceq\nabla f(x)\nabla f(x)^T.
```

**乘法、加法与积分。** 对数凸性与对数凹性在乘法与正缩放下封闭。例如若 $f,g$ 对数凹，则逐点乘积 $h(x)=f(x)g(x)$ 也对数凹，因为 $\log h(x)=\log f(x)+\log g(x)$，而 $\log f(x)$ 与 $\log g(x)$ 是 $x$ 的凹函数。

<!-- p.119/120 -->

简单的例子表明对数凹函数之和一般不对数凹。但 log-convexity（对数凸性）在求和下保持。设 $f,g$ 对数凸，即 $F=\log f$ 与 $G=\log g$ 凸。由凸函数的复合规则，

```math
\log(\exp F+\exp G)=\log(f+g)
```



凸。因此两个对数凸函数之和对数凸。

更一般地，若 $f(x,y)$ 对每个 $y\in C$ 关于 $x$ 对数凸，则

```math
g(x)=\int_Cf(x,y)\,dy
```

对数凸。

<span style="color:#00838f;">**[例 3.41]** **非负函数的拉普拉斯变换以及矩母函数与累积量母函数。** 设 $p:\mathbb{R}^n\to\mathbb{R}$ 满足 $p(x)\ge0$（对所有 $x$）。$p$ 的 Laplace transform（拉普拉斯变换）

```math
P(z)=\int p(x)e^{-z^Tx}\,dx
```

在 $\mathbb{R}^n$ 上对数凸（$\mathbf{dom}\,P$ 自然是 $\{z \mid P(z)<\infty\}$）。现在设 $p$ 是一个 density（密度），即满足 $\int p(x)\,dx=1$。函数 $M(z)=P(-z)$ 称为该密度的 moment generating function（矩母函数）。其名称来自：密度的各阶 moment（矩）可由矩母函数在 $z=0$ 处的导数求出，例如

```math
\nabla M(0)=\mathbb{E}\,v,\qquad \nabla^2M(0)=\mathbb{E}\,vv^T,
```

其中 $v$ 是密度为 $p$ 的随机变量。函数 $\log M(z)$（凸）称为 $p$ 的 cumulant generating function（累积量母函数），因为它的导数给出密度的 cumulants（累积量）。例如累积量母函数在零处的一阶与二阶导数分别是相应随机变量的均值与协方差：

```math
\nabla\log M(0)=\mathbb{E}\,v,\qquad \nabla^2\log M(0)=\mathbb{E}(v-\mathbb{E}\,v)(v-\mathbb{E}\,v)^T.
```

**对数凹函数的积分。** 在某些特殊情形，对数凹性在积分下保持。若 $f:\mathbb{R}^n\times\mathbb{R}^m\to\mathbb{R}$ 对数凹，则

```math

```

是 $x$ 的对数凹函数（$\mathbb{R}^n$ 上）。（这里积分在 $\mathbb{R}^m$ 上进行。）这个结果的证明不简单；见参考文献。


也对数凹。（为看出这一点，注意 $g(y)$ 与 $f(x-y)$ 关于 $(x,y)$ 对数凹，因此乘积 $f(x-y)g(y)$ 也是；再应用积分结果。）

## <span style="color:#c0392b;">3.6 Convexity with respect to generalized inequalities（关于广义不等式的凸性）</span>



现在考虑 monotonicity（单调性）与 convexity（凸性）概念的推广：用广义不等式代替 $\mathbb{R}$ 上通常的序。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">3.6.1 Monotonicity with respect to a generalized inequality（关于广义不等式的单调性）</span>

设 $K\subseteq\mathbb{R}^n$ 是真锥，具有相应的广义不等式 $\preceq_K$。函数 $f:\mathbb{R}^n\to\mathbb{R}$ 称为 $K$-nondecreasing（$K$-非减）的，如果

```math
x\preceq_K y \implies f(x)\le f(y),
```

称为 $K$-increasing（$K$-递增）的，如果

```math
x\preceq_K y,\; x\neq y \implies f(x)<f(y).
```

类似地定义 $K$-nonincreasing（$K$-非增）与 $K$-decreasing（$K$-递减）函数。

<span style="color:#00838f;">**[例 3.45]** **单调向量函数。** 函数 $f:\mathbb{R}^n\to\mathbb{R}$ 关于 $\mathbb{R}^n_+$ 非减，当且仅当

```math
x_1\le y_1,\dots,x_n\le y_n \implies f(x)\le f(y)
```

对所有 $x,y$ 成立。这等价于说：$f$ 限制到任何分量 $x_i$ 上（即把 $x_i$ 看作变量、$x_j$（$j\neq i$）固定）是非减的。

<span style="color:#00838f;">**[例 3.46]** **矩阵单调函数。** 函数 $f:\mathbf{S}^n\to\mathbb{R}$ 称为 matrix monotone（矩阵单调，递增、递减）的，如果它关于半正定锥单调。关于变量 $X\in\mathbf{S}^n$ 的矩阵单调函数的一些例子：



- $\mathbf{tr}(WX)$（$W\in\mathbf{S}^n$）：当 $W\succeq0$ 时矩阵非减，当 $W\succ0$ 时矩阵递增（$W\preceq0$ 时矩阵非增，$W\prec0$ 时矩阵递减）。
- $\mathbf{tr}(X^{-1})$ 在 $\mathbf{S}^n_{++}$ 上矩阵递减。
- $\det X$ 在 $\mathbf{S}^n_{++}$ 上矩阵递增，在 $\mathbf{S}^n_+$ 上矩阵非减。

**单调性的梯度条件（Gradient conditions for monotonicity）。** 回顾：定义域凸（即区间）的可微函数 $f:\mathbb{R}\to\mathbb{R}$ 非减当且仅当 $f'(x)\ge0$ 对所有 $x\in\mathbf{dom}\,f$；递增若 $f'(x)>0$ 对所有 $x\in\mathbf{dom}\,f$（但逆命题不成立）。这些条件容易推广到关于广义不等式的单调性。定义域凸的可微函数 $f$ 是 $K$-非减的，当且仅当

```math
\nabla f(x)\succeq_{K^*}0 \tag{3.24}
```

对所有 $x\in\mathbf{dom}\,f$。注意与简单标量情形的差别：梯度必须在对偶不等式意义下非负。对严格情形有：若

```math
\nabla f(x)\succ_{K^*}0 \tag{3.25}
```

对所有 $x\in\mathbf{dom}\,f$，则 $f$ 是 $K$-递增的。与标量情形一样，逆命题不成立。

我们来证明这些单调性的一阶条件。先设 $f$ 对所有 $x$ 满足 (3.24)，但不是 $K$-非减的，即存在 $x,y$ 使 $x\preceq_K y$ 且 $f(y)\lt f(x)$。由 $f$ 的可微性，存在 $t\in[0,1]$ 使

```math
\frac{d}{dt}f(x+t(y-x))=\nabla f(x+t(y-x))^T(y-x)<0.
```

由于 $y-x\in K$，这意味着

```math
\nabla f(x+t(y-x))\notin K^*,
```

与「(3.24) 处处满足」的假设矛盾。类似地可证 (3.25) 蕴含 $f$ 是 $K$-递增的。

也容易看出 (3.24) 处处成立是必要的。设 (3.24) 对 $x=z$ 不成立。由对偶锥的定义，存在 $v\in K$ 使

```math
\nabla f(z)^Tv<0.
```

考虑 $h(t)=f(z+tv)$ 作为 $t$ 的函数。我们有 $h'(0)=\nabla f(z)^Tv<0$，因此存在 $t>0$ 使 $h(t)=f(z+tv)\lt h(0)=f(z)$，即 $f$ 不是 $K$-非减的。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">3.6.2 Convexity with respect to a generalized inequality（关于广义不等式的凸性）</span>

<!-- p.123/124 -->

设 $K\subseteq\mathbb{R}^m$ 是真锥，具有相应的广义不等式 $\preceq_K$。我们说 $f:\mathbb{R}^n\to\mathbb{R}^m$ 是 $K$-convex（$K$-凸）的，如果对所有 $x,y$ 与 $0\le\theta\le1$：

```math
f(\theta x+(1-\theta)y)\preceq_K\theta f(x)+(1-\theta)f(y).
```



若

```math
f(\theta x+(1-\theta)y)\prec_K\theta f(x)+(1-\theta)f(y)
```

对所有 $x\neq y$ 与 $0<\theta<1$ 成立，则称函数 strictly $K$-convex（严格 $K$-凸）。当 $m=1$（且 $K=\mathbb{R}_+$）时这些定义退化为普通凸性与严格凸性。

<span style="color:#00838f;">**[例 3.47]** **关于逐分量不等式的凸性。** 函数 $f:\mathbb{R}^n\to\mathbb{R}^m$ 关于逐分量不等式（即 $\mathbb{R}^m_+$ 诱导的广义不等式）凸，当且仅当对所有 $x,y$ 与 $0\le\theta\le1$，

```math
f(\theta x+(1-\theta)y)\preceq\theta f(x)+(1-\theta)f(y),
```

即每个分量 $f_i$ 是凸函数。$f$ 关于逐分量不等式严格凸当且仅当每个分量 $f_i$ 严格凸。

<span style="color:#00838f;">**[例 3.48]** **矩阵凸性（matrix convexity）。** 设 $f$ 是对称矩阵值函数，即 $f:\mathbb{R}^n\to\mathbf{S}^m$。函数 $f$ 关于矩阵不等式凸，如果

```math
f(\theta x+(1-\theta)y)\preceq\theta f(x)+(1-\theta)f(y)
```

对任意 $x,y$ 与 $\theta\in[0,1]$ 成立。这有时称为 matrix convexity（矩阵凸性）。等价定义是：标量函数 $z^Tf(x)z$ 对所有向量 $z$ 凸。



（这通常是证明矩阵凸性的好办法。）矩阵函数严格矩阵凸，如果当 $x\neq y$、$0<\theta<1$ 时

```math
f(\theta x+(1-\theta)y)\prec\theta f(x)+(1-\theta)f(y),
```

或等价地，$z^Tfz$ 对每个 $z\neq0$ 严格凸。一些例子：

- 函数 $f(X)=XX^T$（$X\in\mathbb{R}^{n\times m}$）矩阵凸，因为对固定的 $z$，函数 $z^TXX^Tz=\|X^Tz\|_2^2$ 是 $X$（的分量）的凸二次函数。同理 $f(X)=X^2$ 在 $\mathbf{S}^n$ 上矩阵凸。
- 函数 $X^p$ 在 $\mathbf{S}^n_{++}$ 上当 $1\le p\le2$ 或 $-1\le p\le0$ 时矩阵凸，当 $0\le p\le1$ 时矩阵凹。
- 函数 $f(X)=e^X$ 在 $\mathbf{S}^n$ 上不矩阵凸（$n\ge2$）。

凸函数的许多结果可以推广到 $K$-凸函数。举一个简单例子：函数 $K$-凸当且仅当它限制到其定义域内任何直线上是 $K$-凸的。本节其余部分列出几个后面会用到的 $K$-凸性结果；更多结果见习题。

**$K$-凸性的对偶刻画。** 函数 $f$ 是 $K$-凸的，当且仅当对每个 $w\succeq_{K^*}0$，（实值的）函数 $w^Tf$ 凸（普通意义下）；$f$ 严格 $K$-凸当且仅当对每个非零 $w\succeq_{K^*}0$，函数 $w^Tf$ 严格凸。（这些直接由对偶不等式的定义与性质得出。）



**可微的 $K$-凸函数。** 可微函数 $f$ 是 $K$-凸的，当且仅当其定义域凸，且对所有 $x,y\in\mathbf{dom}\,f$：

```math
f(y)\succeq_K f(x)+Df(x)(y-x).
```

（这里 $Df(x)\in\mathbb{R}^{m\times n}$ 是 $f$ 在 $x$ 处的 derivative（导数）或 Jacobian matrix（雅可比矩阵）；见 §A.4.1。）$f$ 严格 $K$-凸当且仅当对所有 $x,y\in\mathbf{dom}\,f$、$x\neq y$：

```math
f(y)\succ_K f(x)+Df(x)(y-x).
```

**复合定理（Composition theorem）。** 复合的许多结果可以推广到 $K$-凸性。例如：若 $g:\mathbb{R}^n\to\mathbb{R}^p$ 是 $K$-凸的，$h:\mathbb{R}^p\to\mathbb{R}$ 凸，且 $\tilde{h}$（$h$ 的扩值延拓）是 $K$-非减的，则 $h\circ g$ 凸。这推广了「凸函数的非减凸函数是凸函数」这一事实。条件「$\tilde{h}$ 是 $K$-非减的」蕴含 $\mathbf{dom}\,h-K=\mathbf{dom}\,h$。

<span style="color:#00838f;">**[例 3.49]** 由 $g(X)=X^TAX+B^TX+X^TB+C$ 定义的二次矩阵函数 $g:\mathbb{R}^{m\times n}\to\mathbf{S}^n$（$A\in\mathbf{S}^m$，$B\in\mathbb{R}^{m\times n}$，$C\in\mathbf{S}^n$）当 $A\succeq0$ 时凸。函数 $h(Y)=-\log\det(-Y)$（$h:\mathbf{S}^n\to\mathbb{R}$）在 $\mathbf{dom}\,h=-\mathbf{S}^n_{++}$ 上凸且递增。由复合定理得：

```math
f(X)=-\log\det\bigl(-(X^TAX+B^TX+X^TB+C)\bigr)
```

在

```math
\mathbf{dom}\,f=\{X\in\mathbb{R}^{m\times n} \mid X^TAX+B^TX+X^TB+C\prec0\}
```

上凸。这推广了：当 $a\ge0$ 时，

```math
-\log(-(ax^2+bx+c))
```

在 $\{x\in\mathbb{R} \mid ax^2+bx+c<0\}$ 上凸。

## 4.1 Optimization problems（优化问题）

### 4.1.1 Basic terminology（基本术语）

我们使用记号

```math
\begin{aligned}
\text{minimize} \quad & f_0(x) \\
\text{subject to} \quad & f_i(x) \le 0, \quad i = 1, \ldots, m \\
& h_i(x) = 0, \quad i = 1, \ldots, p \qquad \text{(4.1)}
\end{aligned}
```

来描述这样一个问题：在所有满足条件 $f_i(x) \le 0$（$i = 1, \ldots, m$）与 $h_i(x) = 0$（$i = 1, \ldots, p$）的 $x$ 之中，找出使 $f_0(x)$ 最小的那个 $x$。我们称 $x \in \mathbb{R}^n$ 为 optimization variable（优化变量），称函数 $f_0 : \mathbb{R}^n \to \mathbb{R}$ 为 objective function（目标函数）或 cost function（代价函数）。不等式 $f_i(x) \le 0$ 称为 inequality constraints（不等式约束），相应的函数 $f_i : \mathbb{R}^n \to \mathbb{R}$ 称为 inequality constraint functions（不等式约束函数）。方程 $h_i(x) = 0$ 称为 equality constraints（等式约束），函数 $h_i : \mathbb{R}^n \to \mathbb{R}$ 则是 equality constraint functions（等式约束函数）。若没有约束（即 $m = p = 0$），我们说问题 (4.1) 是 unconstrained（无约束）的。

使目标函数与全部约束函数都有定义的那些点构成的集合

```math
\mathcal{D} = \bigcap_{i=0}^{m} \mathop{\bf dom} f_i \cap \bigcap_{i=1}^{p} \mathop{\bf dom} h_i
```

称为优化问题 (4.1) 的 domain（定义域）。点 $x \in \mathcal{D}$ 是 feasible（可行的），如果它满足约束 $f_i(x) \le 0$（$i = 1, \ldots, m$）与 $h_i(x) = 0$（$i = 1, \ldots, p$）。若至少存在一个 feasible point，则问题 (4.1) 称为 feasible 的；否则称为 infeasible（不可行）。全部 feasible point 构成的集合称为 feasible set（可行集）或 constraint set（约束集）。

问题 (4.1) 的 optimal value（最优值）$p^{\star}$ 定义为

```math
p^{\star} = \inf\left\{f_0(x) \mid f_i(x) \le 0,\ i = 1, \ldots, m,\ h_i(x) = 0,\ i = 1, \ldots, p\right\}.
```

我们允许 $p^{\star}$ 取 extended values（扩展实数值）$\pm\infty$。若问题 infeasible，则 $p^{\star} = +\infty$（按标准约定，空集的下确界为 $+\infty$）。

若存在 feasible point $x_k$ 使 $f_0(x_k) \to -\infty$（当 $k \to \infty$），则 $p^{\star} = -\infty$，此时我们说问题 (4.1) 是 unbounded below（下方无界）的。

#### <span style="color:#117864;">**[definition]**</span> <span style="color:#c0392b">Optimal and locally optimal points（最优点与局部最优点）</span>

我们说 $x$ 是 optimal point（最优点），或称 $x$ 解出了问题 (4.1)，若 $x$ 是 feasible 的且 $f_0(x) = p^{\star}$。全部 optimal point 构成的集合称为 optimal set（最优集），记作

```math
X_{\text{opt}} = \{x \mid f_i(x) \le 0,\ i = 1, \ldots, m,\ h_i(x) = 0,\ i = 1, \ldots, p,\ f_0(x) = p^{\star}\}.
```

若问题 (4.1) 存在 optimal point，我们说 optimal value 是 attained（可达到）或 achieved 的，并称该问题是 solvable（可解的）。若 $X_{\text{opt}}$ 为空，我们说 optimal value 是 not attained 或 not achieved 的。（当问题 unbounded below 时这总是发生。）一个 feasible point $x$ 若满足 $f_0(x) \le p^{\star} + \epsilon$（其中 $\epsilon \gt 0$），称为 $\epsilon$-suboptimal（$\epsilon$-次优）的；全部 $\epsilon$-suboptimal point 构成的集合称为问题 (4.1) 的 $\epsilon$-suboptimal set。

我们说一个 feasible point $x$ 是 locally optimal（局部最优）的，若存在 $R \gt 0$ 使得

```math
f_0(x) = \inf\{f_0(z) \mid f_i(z) \le 0,\ i = 1, \ldots, m,\ h_i(z) = 0,\ i = 1, \ldots, p,\ \|z - x\|_2 \le R\},
```

换句话说，$x$ 解出了下面这个以 $z$ 为变量的优化问题：

```math
\begin{aligned}
\text{minimize} \quad & f_0(z) \\
\text{subject to} \quad & f_i(z) \le 0, \quad i = 1, \ldots, m \\
& h_i(z) = 0, \quad i = 1, \ldots, p \\
& \|z - x\|_2 \le R
\end{aligned}
```

粗略地说，这意味着 $x$ 在可行集中它附近的点上使 $f_0$ 最小。为了区分「locally optimal」与「optimal」，人们有时用 term `globally optimal'（全局最优）来代替 `optimal'。不过，在本书全文中，optimal 一律指 globally optimal。

若 $x$ 是 feasible 的且 $f_i(x) = 0$，我们说第 $i$ 个 inequality constraint $f_i(x) \le 0$ 在 $x$ 处是 active（起作用的）。若 $f_i(x) \lt 0$，我们说该约束是 inactive（不起作用的）。（equation constraint 在所有 feasible point 处都是 active 的。）我们说一个约束是 redundant（冗余）的，若删去它不改变 feasible set。

#### <span style="color:#6c3483;">**[example]**</span> <span style="color:#c0392b">例 4.1（三个无约束问题的 optimal value 形态）</span>

我们用几个变量为 $x \in \mathbb{R}$、$\mathop{\bf dom} f_0 = \mathbb{R}_{++}$ 的简单无约束优化问题来说明这些定义。

- $f_0(x) = 1/x$：$p^{\star} = 0$，但 optimal value 取不到（not achieved）。

- $f_0(x) = -\log x$：$p^{\star} = -\infty$，所以这个问题是 unbounded below 的。

- $f_0(x) = x \log x$：$p^{\star} = -1/e$，在（唯一的）optimal point $x = 1/e$ 处达到。

<span style="color:#1e8449;">**[译注]**</span> 这三个例子恰好把「infimum 存在但不可达」「下确界是 $-\infty$」「可达且唯一」三种情形摆在一起。$f_0(x)=1/x$ 那一条尤其值得记住：**infimum 只是一个下界，不是解**；算法能给的是后者或它的近似，不是一个下确界。

#### Feasibility problems（可行性问题）

若 objective function 恒等于零，则 optimal value 要么是零（feasible set 非空），要么是 $+\infty$（feasible set 为空）。我们称这类问题为 feasibility problem（可行性问题），有时把它写成

```math
\begin{aligned}
\text{find} \quad & x \\
\text{subject to} \quad & f_i(x) \le 0, \quad i = 1, \ldots, m \\
& h_i(x) = 0, \quad i = 1, \ldots, p
\end{aligned}
```

feasibility problem 因此就是判定约束是否 consistent（相容），若相容则找出一个满足它们的点。

### 4.1.2 Expressing problems in standard form（把问题写成标准形式）

我们称 (4.1) 为 standard form（标准形式）下的优化问题。在标准形式问题中我们采用这样的约定：不等式约束与等式约束的右端都是零。这一点总能通过减去任意非零右端做到：例如把等式约束 $g_i(x) = \tilde g_i(x)$ 表示成 $h_i(x) = 0$，其中 $h_i(x) = g_i(x) - \tilde g_i(x)$。类似地，形如 $f_i(x) \ge 0$ 的不等式我们写成 $-f_i(x) \le 0$。

#### <span style="color:#6c3483;">**[example]**</span> <span style="color:#c0392b">例 4.2（Box constraints，箱约束）</span>

考虑优化问题

```math
\begin{aligned}
\text{minimize} \quad & f_0(x) \\
\text{subject to} \quad & l_i \le x_i \le u_i, \quad i = 1, \ldots, n,
\end{aligned}
```

其中 $x \in \mathbb{R}^n$ 是变量。这些约束称为 variable bounds（变量界，因为它们给每个 $x_i$ 上下界），或称 box constraints（箱约束，因为 feasible set 是一个 box（盒子））。

我们可以把它写成标准形式

```math
\begin{aligned}
\text{minimize} \quad & f_0(x) \\
\text{subject to} \quad & l_i - x_i \le 0, \quad i = 1, \ldots, n \\
& x_i - u_i \le 0, \quad i = 1, \ldots, n.
\end{aligned}
```

这里有 $2n$ 个 inequality constraint functions：

```math
f_i(x) = l_i - x_i, \quad i = 1, \ldots, n,
```

以及

```math
f_i(x) = x_{i-n} - u_{i-n}, \quad i = n + 1, \ldots, 2n.
```

#### Maximization problems（最大化问题）

按约定我们集中处理 minimization 问题。maximization 问题

```math
\begin{aligned}
\text{maximize} \quad & f_0(x) \\
\text{subject to} \quad & f_i(x) \le 0, \quad i = 1, \ldots, m \\
& h_i(x) = 0, \quad i = 1, \ldots, p \qquad \text{(4.2)}
\end{aligned}
```

可以通过在同样约束下最小化函数 $-f_0$ 来求解。

通过这种对应关系，我们可以对 maximization 问题 (4.2) 定义上面所有术语。例如 (4.2) 的 optimal value 定义为

```math
p^{\star} = \sup\{f_0(x) \mid f_i(x) \le 0,\ i = 1, \ldots, m,\ h_i(x) = 0,\ i = 1, \ldots, p\},
```

而一个 feasible point $x$ 若满足 $f_0(x) \ge p^{\star} - \epsilon$ 则称为 $\epsilon$-suboptimal 的。考虑 maximization 问题时，objective 有时被称为 utility（效用）或 satisfaction level（满意度），而不是 cost。

### 4.1.3 Equivalent problems（等价问题）

在本书中我们会以一种非形式的方式使用 optimization problem 的 equivalence（等价性）这一概念。我们称两个问题是 equivalent 的，若从其中一个的解可以立刻得到另一个的解，反之亦然。（给出等价性的形式定义是可能的，但相当繁琐。）

一个简单的例子是问题

```math
\begin{aligned}
\text{minimize} \quad & \tilde f_0(x) = \sigma_0 f_0(x) \\
\text{subject to} \quad & \tilde f_i(x) = \sigma_i f_i(x) \le 0, \quad i = 1, \ldots, m \\
& \tilde h_i(x) = \gamma_i h_i(x) = 0, \quad i = 1, \ldots, p \qquad \text{(4.3)}
\end{aligned}
```

其中 $\sigma_i \gt 0$（$i = 0, \ldots, m$），$\gamma_i \ne 0$（$i = 1, \ldots, p$）。这个问题由标准形式问题 (4.1) 通过「把 objective 与 inequality constraint functions 乘以正的常数、把 equality constraint functions 乘以非零常数」得到。结果是：问题 (4.3) 与原问题 (4.1) 的 feasible set 完全相同。点 $x$ 对原问题 (4.1) 是 optimal 的，当且仅当它对缩放后的问题 (4.3) 是 optimal 的，因此我们说这两个问题是 equivalent 的。然而问题 (4.1) 与 (4.3) 并不相同（除非全部 $\sigma_i$ 与 $\gamma_i$ 都等于 $1$），因为它们的 objective 与 constraint functions 不同。

下面我们描述一些能产生 equivalent problem 的通用变换。

#### Change of variables（变量替换）

设 $\phi : \mathbb{R}^n \to \mathbb{R}^n$ 是一一的（one-to-one），其像覆盖问题定义域 $\mathcal{D}$，即 $\phi(\mathop{\bf dom} \phi) \supseteq \mathcal{D}$。我们定义函数 $\tilde f_i$ 与 $\tilde h_i$ 为

```math
\tilde f_i(z) = f_i(\phi(z)), \quad i = 0, \ldots, m, \qquad \tilde h_i(z) = h_i(\phi(z)), \quad i = 1, \ldots, p.
```

现在考虑问题

```math
\begin{aligned}
\text{minimize} \quad & \tilde f_0(z) \\
\text{subject to} \quad & \tilde f_i(z) \le 0, \quad i = 1, \ldots, m \\
& \tilde h_i(z) = 0, \quad i = 1, \ldots, p \qquad \text{(4.4)}
\end{aligned}
```

变量为 $z$。我们说标准形式问题 (4.1) 与问题 (4.4) 由 change of variable（变量替换）或 substitution of variable $x = \phi(z)$ 相联系。

这两个问题显然是 equivalent 的：若 $x$ 解出问题 (4.1)，则 $z = \phi^{-1}(x)$ 解出问题 (4.4)；若 $z$ 解出问题 (4.4)，则 $x = \phi(z)$ 解出问题 (4.1)。



> <span style="color:#7f8c8d;">原书 p.131｜objective 与 constraint 的变换、例 4.3、slack variables</span>

#### Transformation of objective and constraint functions（目标函数与约束函数的变换）

设 $\psi_0 : \mathbb{R} \to \mathbb{R}$ 单调递增，$\psi_1, \ldots, \psi_m : \mathbb{R} \to \mathbb{R}$ 满足「$\psi_i(u) \le 0$ 当且仅当 $u \le 0$」，且 $\psi_{m+1}, \ldots, \psi_{m+p} : \mathbb{R} \to \mathbb{R}$ 满足「$\psi_i(u) = 0$ 当且仅当 $u = 0$」。把 $\tilde f_i$ 与 $\tilde h_i$ 定义为复合：

```math
\tilde f_i(x) = \psi_i(f_i(x)), \quad i = 0, \ldots, m, \qquad \tilde h_i(x) = \psi_{m+i}(h_i(x)), \quad i = 1, \ldots, p.
```

显然相应的优化问题

```math
\begin{aligned}
\text{minimize} \quad & \tilde f_0(x) \\
\text{subject to} \quad & \tilde f_i(x) \le 0, \quad i = 1, \ldots, m \\
& \tilde h_i(x) = 0, \quad i = 1, \ldots, p
\end{aligned}
```

与标准形式问题 (4.1) 是 equivalent 的；事实上两者的 feasible set 完全相同，optimal point 也完全相同。（上面 (4.3) 那个例子，即把 objective 与 constraint functions 乘以适当常数，正是全部 $\psi_i$ 都为线性的特例。）

#### <span style="color:#6c3483;">**[example]**</span> <span style="color:#c0392b">例 4.3（least-norm 与 least-norm-squared）</span>

作为一个简单例子，考虑无约束的 Euclidean norm 极小化问题

```math
\text{minimize} \quad \|A x - b\|_2, \tag{4.5}
```

变量为 $x \in \mathbb{R}^n$。由于 norm 总是非负的，我们完全可以改为求解问题

```math
\text{minimize} \quad \|A x - b\|_2^2 = (A x - b)^T (A x - b), \tag{4.6}
```

即最小化 Euclidean norm 的平方。问题 (4.5) 与 (4.6) 显然是 equivalent 的：optimal point 相同。然而这两个问题并不相同。例如 (4.5) 的 objective 在任何满足 $A x - b = 0$ 的 $x$ 处不可微，而 (4.6) 的 objective 对一切 $x$ 都可微（事实上是二次的）。

<span style="color:#1e8449;">**[译注]**</span> 这个例子点出了「等价」的实用含义：**解集相同，但求解难度和可用的算法工具可以完全不同**。$t^2$ 在 $t \ge 0$ 上单调递增，所以 (4.5) 与 (4.6) 的 optimal set 一致；可是 (4.6) 是光滑的二次问题，可以直接写成线性方程 $(A^T A) x = A^T b$，而 (4.5) 在残差为零处不可微，需要专门处理。后面 §5 的最优性条件与 §6 的逼近方法都默认 objective 可微，这就是为什么实际建模时几乎总用 (4.6) 而不是 (4.5)。

#### Slack variables（松弛变量）

一个简单的变换基于这样一个观察：$f_i(x) \le 0$ 当且仅当存在 $s_i \ge 0$ 满足 $f_i(x) + s_i = 0$。用这个变换我们得到问题

```math
\begin{aligned}
\text{minimize} \quad & f_0(x) \\
\text{subject to} \quad & s_i \ge 0, \quad i = 1, \ldots, m \\
& f_i(x) + s_i = 0, \quad i = 1, \ldots, m \\
& h_i(x) = 0, \quad i = 1, \ldots, p \qquad \text{(4.7)}
\end{aligned}
```

变量是 $x \in \mathbb{R}^n$ 与 $s \in \mathbb{R}^m$。这个问题有 $n + m$ 个变量、$m$ 个 inequality constraint（即 $s_i$ 的非负性约束）以及 $m + p$ 个 equality constraint。新变量 $s_i$ 称为与原 inequality constraint $f_i(x) \le 0$ 关联的 slack variable（松弛变量）。引入 slack variable 把每个 inequality constraint 换成「一个 equality constraint + 一个非负性约束」。



> <span style="color:#7f8c8d;">原书 p.132｜slack variable 的等价性论证、Eliminating linear equality constraints</span>

问题 (4.7) 与原标准形式问题 (4.1) 是 equivalent 的。事实上若 $(x, s)$ 对 (4.7) 是 feasible 的，则 $x$ 对原问题是 feasible 的，因为 $s_i = -f_i(x) \ge 0$。反过来若 $x$ 对原问题 feasible，则取 $s_i = -f_i(x)$ 便使 $(x, s)$ 对 (4.7) feasible。同理，$x$ 对原问题 (4.1) 是 optimal 的，当且仅当 $(x, s)$ 对 (4.7) 是 optimal 的，其中 $s_i = -f_i(x)$。

#### Eliminating equality constraints（消去等式约束）

若我们能用某个参数 $z \in \mathbb{R}^k$ 显式地参数化 equality constraints

```math
h_i(x) = 0, \quad i = 1, \ldots, p, \tag{4.8}
```

的全部解，就可以把这些 equality constraint 从问题中消去，做法如下。设函数 $\phi : \mathbb{R}^k \to \mathbb{R}^n$ 使得「$x$ 满足 (4.8)」当且仅当「存在 $z \in \mathbb{R}^k$ 使 $x = \phi(z)$」。那么优化问题

```math
\begin{aligned}
\text{minimize} \quad & \tilde f_0(z) = f_0(\phi(z)) \\
\text{subject to} \quad & \tilde f_i(z) = f_i(\phi(z)) \le 0, \quad i = 1, \ldots, m
\end{aligned}
```

与原问题 (4.1) 等价。这个变换后的问题以 $z \in \mathbb{R}^k$ 为变量，有 $m$ 个 inequality constraint，没有 equality constraint。若 $z$ 对变换后的问题是 optimal 的，则 $x = \phi(z)$ 对原问题是 optimal 的。反过来若 $x$ 对原问题 optimal，则（因 $x$ feasible）至少存在一个 $z$ 使 $x = \phi(z)$，任何这样的 $z$ 对变换后的问题都是 optimal 的。

#### Eliminating linear equality constraints（消去线性等式约束）

当全部 equality constraint 都是线性的，即形如 $A x = b$ 时，消去变量的过程可以写得更具体，也便于数值实施。若 $A x = b$ 是 inconsistent（不相容）的，即 $b \notin \mathcal{R}(A)$，则原问题是 infeasible 的。假设情形并非如此，取 $x_0$ 为 equality constraint 的任意一个解。设 $F \in \mathbb{R}^{n \times k}$ 是任一满足 $\mathcal{R}(F) = \mathcal{N}(A)$ 的矩阵，于是线性方程组 $A x = b$ 的通解为 $F z + x_0$，其中 $z \in \mathbb{R}^k$。（我们可以取 $F$ 为满秩，此时 $k = n - \mathop{\bf rank} A$。）

把 $x = F z + x_0$ 代入原问题，得到问题

```math
\begin{aligned}
\text{minimize} \quad & f_0(F z + x_0) \\
\text{subject to} \quad & f_i(F z + x_0) \le 0, \quad i = 1, \ldots, m,
\end{aligned}
```

变量为 $z$。它与原问题等价，没有 equality constraint，变量个数少 $\mathop{\bf rank} A$ 个。

#### Introducing equality constraints（引入等式约束）

我们也可以向问题中引入 equality constraint 与新变量。一般情形既繁琐又不具启发性，我们只给出一个后面会用到的典型例子。考虑问题

```math
\begin{aligned}
\text{minimize} \quad & f_0(A_0 x + b_0) \\
\text{subject to} \quad & f_i(A_i x + b_i) \le 0, \quad i = 1, \ldots, m \\
& h_i(x) = 0, \quad i = 1, \ldots, p,
\end{aligned}
```



> <span style="color:#7f8c8d;">原书 p.133｜Introducing equality constraints、Optimizing over some variables、例 4.4、epigraph form 开头</span>

其中 $x \in \mathbb{R}^n$，$A_i \in \mathbb{R}^{k_i \times n}$，$f_i : \mathbb{R}^{k_i} \to \mathbb{R}$。这个问题的 objective 与 constraint functions 是函数 $f_i$ 与由 $A_i x + b_i$ 给出的 affine 变换的复合。

我们引入新变量 $y_i \in \mathbb{R}^{k_i}$，以及新的 equality constraint $y_i = A_i x + b_i$（$i = 0, \ldots, m$），构成等价问题

```math
\begin{aligned}
\text{minimize} \quad & f_0(y_0) \\
\text{subject to} \quad & f_i(y_i) \le 0, \quad i = 1, \ldots, m \\
& y_i = A_i x + b_i, \quad i = 0, \ldots, m \\
& h_i(x) = 0, \quad i = 1, \ldots, p.
\end{aligned}
```

这个问题有 $k_0 + \cdots + k_m$ 个新变量

```math
y_0 \in \mathbb{R}^{k_0}, \ldots, y_m \in \mathbb{R}^{k_m},
```

以及 $k_0 + \cdots + k_m$ 个新 equality constraint

```math
y_0 = A_0 x + b_0, \ldots, y_m = A_m x + b_m.
```

在这个问题里，objective 与 inequality constraint 是互相独立的，即它们涉及不同的优化变量。

#### Optimizing over some variables（对部分变量优化）

我们总有

```math
\inf_{x, y} f(x, y) = \inf_{x} \tilde f(x),
```

其中 $\tilde f(x) = \inf_y f(x, y)$。换句话说，我们总可以先把一个函数对某些变量取极小，再对剩下的变量取极小。这一简单而普遍的原理可用来把问题变换成更有用的形式，下面给出一个例子。

设变量 $x \in \mathbb{R}^n$ 被分块为 $x = (x_1, x_2)$，其中 $x_1 \in \mathbb{R}^{n_1}$、$x_2 \in \mathbb{R}^{n_2}$，且 $n_1 + n_2 = n$。考虑问题

```math
\begin{aligned}
\text{minimize} \quad & f_0(x_1, x_2) \\
\text{subject to} \quad & f_i(x_1) \le 0, \quad i = 1, \ldots, m_1 \\
& \tilde f_i(x_2) \le 0, \quad i = 1, \ldots, m_2, \qquad \text{(4.9)}
\end{aligned}
```

其中约束是互相独立的，意思是每个 constraint function 只依赖 $x_1$ 或只依赖 $x_2$。我们先对 $x_2$ 取极小。定义 $x_1$ 的函数 $\tilde f_0$ 为

```math
\tilde f_0(x_1) = \inf\{f_0(x_1, z) \mid \tilde f_i(z) \le 0,\ i = 1, \ldots, m_2\}.
```

于是问题 (4.9) 等价于

```math
\begin{aligned}
\text{minimize} \quad & \tilde f_0(x_1) \\
\text{subject to} \quad & f_i(x_1) \le 0, \quad i = 1, \ldots, m_1. \qquad \text{(4.10)}
\end{aligned}
```

#### <span style="color:#6c3483;">**[example]**</span> <span style="color:#c0392b">例 4.4（部分变量受约束的二次函数极小化）</span>

考虑一个 objective 为 strict convex quadratic（严格凸二次）、其中某些变量无约束的问题：

```math
\begin{aligned}
\text{minimize} \quad & x_1^T P_{11} x_1 + 2 x_1^T P_{12} x_2 + x_2^T P_{22} x_2 \\
\text{subject to} \quad & f_i(x_1) \le 0, \quad i = 1, \ldots, m,
\end{aligned}
```

其中 $P_{11}$ 与 $P_{22}$ 是对称的。这里我们可以解析地对 $x_2$ 取极小：

```math
\inf_{x_2} \left(x_1^T P_{11} x_1 + 2 x_1^T P_{12} x_2 + x_2^T P_{22} x_2\right) = x_1^T \left(P_{11} - P_{12} P_{22}^{-1} P_{12}^T\right) x_1.
```

见 §A.5.5。因此原问题等价于

```math
\begin{aligned}
\text{minimize} \quad & x_1^T \left(P_{11} - P_{12} P_{22}^{-1} P_{12}^T\right) x_1 \\
\text{subject to} \quad & f_i(x_1) \le 0, \quad i = 1, \ldots, m.
\end{aligned}
```

<span style="color:#1e8449;">**[译注]**</span> 推导步骤：对 $x_2$ 求梯度并令其为零，得 $P_{22} x_2 = -P_{12}^T x_1$，即 $x_2 = -P_{22}^{-1} P_{12}^T x_1$；代回原式，中间交叉项 $2 x_1^T P_{12} x_2 = -2 x_1^T P_{12} P_{22}^{-1} P_{12}^T x_1$，二次项 $x_2^T P_{22} x_2 = x_1^T P_{12} P_{22}^{-1} P_{12}^T x_1$，于是剩下 $P_{11} - P_{12} P_{22}^{-1} P_{12}^T$。这个矩阵就是 $P$ 关于 $P_{22}$ 的 Schur complement；它保持 positive definite 当且仅当 $P_{22} \succ 0$。

#### Epigraph problem form（上图问题形式）

标准问题 (4.1) 的 epigraph form 是问题

```math
\begin{aligned}
\text{minimize} \quad & t \\
\text{subject to} \quad & f_0(x) - t \le 0 \\
& f_i(x) \le 0, \quad i = 1, \ldots, m \\
& h_i(x) = 0, \quad i = 1, \ldots, p, \qquad \text{(4.11)}
\end{aligned}
```

变量为 $x \in \mathbb{R}^n$ 与 $t \in \mathbb{R}$。容易看出它与原问题等价：$(x, t)$ 对 (4.11) 是 optimal 的，当且仅当 $x$ 对 (4.1) 是 optimal 的且 $t = f_0(x)$。注意 epigraph form 问题的 objective function 是变量 $x, t$ 的线性函数。



> <span style="color:#7f8c8d;">原书 p.134｜epigraph form 的几何解释、Implicit and explicit constraints</span>

epigraph form 问题 (4.11) 可以几何地解释为「graph space」$(x, t)$ 中的优化问题：我们在 $f_0$ 的 epigraph 上、在 $x$ 的约束之下，最小化 $t$。图 4.1 画出了这一点。

#### Implicit and explicit constraints（隐式约束与显式约束）

用 §3.1.2 已提到的一个简单技巧，我们可以把任何一个约束隐式地包含进 objective function，办法是重新定义它的定义域。作为极端例子，标准形式问题可以表示成无约束问题

```math
\text{minimize} \quad F(x), \tag{4.12}
```

其中我们把函数 $F$ 定义为 $f_0$，但定义域限制到 feasible set 上：

```math
\mathop{\bf dom} F = \{x \in \mathop{\bf dom} f_0 \mid f_i(x) \le 0,\ i = 1, \ldots, m,\ h_i(x) = 0,\ i = 1, \ldots, p\},
```

且对 $x \in \mathop{\bf dom} F$ 有 $F(x) = f_0(x)$。（等价地，可以让 $F(x)$ 对不可行的 $x$ 取值 $+\infty$。）问题 (4.1) 与 (4.12) 显然是 equivalent 的：它们有相同的 feasible set、optimal point 与 optimal value。

当然，这一变换不过是一个记号上的技巧。把约束变成隐式并没有让问题更容易分析或求解，尽管问题 (4.12) 至少在名义上是无约束的。在某些方面这个变换反而使问题更难。例如，假设原问题中的 objective $f_0$ 是可微的，因此它的定义域是开集。那么限制后的 objective function $F$ 很可能不可微，因为它的定义域很可能不是开集。

反过来，我们也会遇到带隐式约束的问题，这时可以把它变成显式的。一个简单例子是无约束问题

```math
\text{minimize} \quad f(x), \tag{4.13}
```

其中函数 $f$ 由

```math
f(x) = \begin{cases} x^T x, & A x = b \\ +\infty, & \text{otherwise} \end{cases}
```

给出。于是 objective function 在由 $A x = b$ 定义的 affine set 上等于二次型 $x^T x$，在该 affine set 之外取值 $+\infty$。由于我们显然可以把注意力限制在满足 $A x = b$ 的点上，我们说问题 (4.13) 隐含着一个藏在 objective 里的 implicit equality constraint $A x = b$。我们可以把这个隐式 equality constraint 变成显式的，办法是构造等价问题

```math
\begin{aligned}
\text{minimize} \quad & x^T x \\
\text{subject to} \quad & A x = b. \qquad \text{(4.14)}
\end{aligned}
```

问题 (4.13) 与 (4.14) 显然 equivalent，但它们并不相同。(4.13) 是无约束的，但其 objective function 不可微；(4.14) 有一个 equality constraint，但其 objective 与 constraint functions 都可微。

### 4.1.4 Parameter and oracle problem descriptions（参数描述与 oracle 描述）

对标准形式 (4.1) 的问题，仍有一个问题没解决：objective 与 constraint functions 究竟是怎么给出的。许多情况下这些函数有某种解析形式或闭式（closed form），即由某个包含变量 $x$ 以及一些参数的公式或表达式给出。例如设 objective 是二次的，形如 $f_0(x) = (1/2) x^T P x + q^T x + r$。为指定这个 objective function，我们给出系数（也称 problem parameters 问题参数，或 problem data 问题数据）$P \in \mathbb{S}^n$、$q \in \mathbb{R}^n$ 与 $r \in \mathbb{R}$。我们称这种描述为 parameter problem description（参数问题描述），因为待求解的具体问题（即 problem instance（问题实例））是由 objective 与 constraint functions 表达式中出现的那些参数的取值来指定的。

另一些情况下，objective 与 constraint functions 由 oracle model（oracle 模型，也称 black box model 黑箱模型或 subroutine model 子程序模型）描述。在 oracle 模型中我们并不显式地知道 $f$，但可以在任意 $x \in \mathop{\bf dom} f$ 处求值 $f(x)$（通常还能求某些导数）。这称为 querying the oracle（查询 oracle），通常伴随某种成本，例如时间。我们还会拿到关于该函数的一些 prior information（先验信息），例如它是 convex 的，以及它的取值范围的一个界。作为一个具体的 oracle 模型例子，考虑一个待最小化函数 $f$ 的无约束问题：函数值 $f(x)$ 与其梯度 $\nabla f(x)$ 由一个子程序计算。我们可以在任意 $x \in \mathop{\bf dom} f$ 处调用该子程序，但无法看到它的源代码。以 $x$ 为参数调用该子程序会（在子程序返回时）给出 $f(x)$ 与 $\nabla f(x)$。注意在 oracle 模型中我们从不真正知道这个函数；我们只知道在查询过 oracle 的那些点上函数值（以及某些导数）。（我们还知道关于该函数的一些给定先验信息，例如可微性与凸性。）

在实践中，parameter 描述与 oracle 描述之间的界线并不那么分明。若给定的是 parameter problem description，我们可以为它构造一个 oracle，查询时直接计算所需的函数与导数即可。我们在第 III 部分研究的大多数算法都按 oracle 模型工作，但当它们被限制去求解某个特定的参数化问题族时，可以做得更高效。

## 4.2 Convex optimization（凸优化）

### 4.2.1 Convex optimization problems in standard form（标准形式下的凸优化问题）

凸优化问题是形如

```math
\begin{aligned}
\text{minimize} \quad & f_0(x) \\
\text{subject to} \quad & f_i(x) \le 0, \quad i = 1, \ldots, m \\
& a_i^T x = b_i, \quad i = 1, \ldots, p \qquad \text{(4.15)}
\end{aligned}
```

的问题，其中 $f_0, \ldots, f_m$ 都是 convex function。把 (4.15) 与一般标准形式问题 (4.1) 相比较，convex 问题多了三条要求：

- objective function 必须是 convex 的，

- inequality constraint functions 必须是 convex 的，

- equality constraint functions $h_i(x) = a_i^T x - b_i$ 必须是 affine 的。

我们立刻注意到一条重要性质：凸优化问题的 feasible set 是 convex 的，因为它是问题定义域

```math
\mathcal{D} = \bigcap_{i=0}^{m} \mathop{\bf dom} f_i
```

（它是 convex set）与 $m$ 个（convex 的）sublevel set $\{x \mid f_i(x) \le 0\}$ 以及 $p$ 个 hyperplane $\{x \mid a_i^T x = b_i\}$ 的交。（不失一般性可以假设 $a_i \ne 0$：若存在某个 $i$ 使 $a_i = 0$ 而 $b_i = 0$，则第 $i$ 个 equality constraint 可以删去；若 $a_i = 0$ 而 $b_i \ne 0$，则第 $i$ 个 equality constraint 是不相容的，问题是 infeasible 的。）因此，在凸优化问题中，我们是在一个 convex set 上最小化一个 convex objective function。

若 $f_0$ 是 quasiconvex 的而不是 convex 的，我们说问题 (4.15) 是（标准形式下的）quasiconvex optimization problem（拟凸优化问题）。由于 convex 或 quasiconvex 函数的 sublevel set 都是 convex 的，我们得出结论：对 convex 或 quasiconvex 优化问题，$\epsilon$-suboptimal set 是 convex 的。特别地，optimal set 是 convex 的。若 objective 是 strictly convex 的，则 optimal set 至多含一个点。

#### Concave maximization problems（凹最大化问题）

稍微滥用一点记号，当 objective function $f_0$ 是 concave 的、而 inequality constraint functions $f_1, \ldots, f_m$ 是 convex 的时，我们也把

```math
\begin{aligned}
\text{maximize} \quad & f_0(x) \\
\text{subject to} \quad & f_i(x) \le 0, \quad i = 1, \ldots, m \\
& a_i^T x = b_i, \quad i = 1, \ldots, p \qquad \text{(4.16)}
\end{aligned}
```

称为凸优化问题。这个 concave maximization problem（凹最大化问题）通过最小化 convex objective function $-f_0$ 就很容易求解。我们为 minimization 问题描述的一切结果、结论与算法都很容易搬运到 maximization 情形。类似地，若 $f_0$ 是 quasiconcave 的，则 maximization 问题 (4.16) 称为 quasiconvex 的。

#### Abstract form convex optimization problem（抽象形式的凸优化问题）

关于凸优化问题的定义，有一个微妙之处值得注意。考虑 $x \in \mathbb{R}^2$ 的例子

```math
\begin{aligned}
\text{minimize} \quad & f_0(x) = x_1^2 + x_2^2 \\
\text{subject to} \quad & f_1(x) = x_1/(1 + x_2^2) \le 0 \\
& h_1(x) = (x_1 + x_2)^2 = 0, \qquad \text{(4.17)}
\end{aligned}
```

它处于标准形式 (4.1) 之中。这个问题按我们的定义不是标准形式的凸优化问题，因为 equality constraint function $h_1$ 不是 affine 的，而 inequality constraint function $f_1$ 也不是 convex 的。然而它的 feasible set 是 $\{x \mid x_1 \le 0,\ x_1 + x_2 = 0\}$，是 convex 的。所以尽管在这个问题里我们是在一个 convex set 上最小化一个 convex function $f_0$，按我们的定义它并不算凸优化问题。

当然，这个问题可以立刻改写为

```math
\begin{aligned}
\text{minimize} \quad & f_0(x) = x_1^2 + x_2^2 \\
\text{subject to} \quad & \tilde f_1(x) = x_1 \le 0 \\
& \tilde h_1(x) = x_1 + x_2 = 0, \qquad \text{(4.18)}
\end{aligned}
```

它处于标准凸优化形式，因为 $f_0$ 与 $\tilde f_1$ 是 convex 的，而 $\tilde h_1$ 是 affine 的。

有些作者用 abstract convex optimization problem（抽象凸优化问题）这个 term 来描述「在 convex set 上最小化 convex function」这个（抽象的）问题。按这套术语，问题 (4.17) 是一个 abstract convex optimization problem。本书不使用这套术语。对我们来说，一个凸优化问题不只是「在 convex set 上最小化 convex function」；它还要求 feasible set 被**具体地**由一组涉及 convex function 的不等式与一组线性 equality constraint 描述出来。问题 (4.17) 不是凸优化问题，而问题 (4.18) 是凸优化问题。（不过这两个问题是 equivalent 的。）

我们采用这个更严格的凸优化问题定义，在实践中并不太要紧。要解「在 convex set 上最小化 convex function」这个抽象问题，我们需要用 convex inequality 与 linear equality constraint 找出该集合的一种描述。正如上面的例子所示，这通常是直截了当的。

### 4.2.2 Local and global optima（局部最优与全局最优）

凸优化问题的一条根本性质是：**任何 locally optimal point 同时也是（全局）optimal 的**。为看出这一点，设 $x$ 是某个凸优化问题的 locally optimal point，即 $x$ 是 feasible 的且

```math
f_0(x) = \inf\{f_0(z) \mid z \text{ feasible},\ \|z - x\|_2 \le R\}, \tag{4.19}
```

其中某个 $R \gt 0$。现在假设 $x$ 不是 globally optimal 的，即存在 feasible 的 $y$ 使 $f_0(y) \lt f_0(x)$。显然 $\|y - x\|_2 \gt R$，否则 $f_0(x) \le f_0(y)$。考虑由

```math
z = (1 - \theta) x + \theta y, \qquad \theta = \frac{R}{2 \|y - x\|_2}
```

给出的点 $z$。于是 $\|z - x\|_2 = R/2 \lt R$，且由 feasible set 的凸性，$z$ 是 feasible 的。由 $f_0$ 的凸性我们有

```math
f_0(z) \le (1 - \theta) f_0(x) + \theta f_0(y) \lt f_0(x),
```

这与 (4.19) 矛盾。因此不存在 feasible 的 $y$ 满足 $f_0(y) \lt f_0(x)$，即 $x$ 是 globally optimal 的。

<span style="color:#1e8449;">**[译注]**</span> 这条证明的关键只有两处：feasible set 凸（保证 $x$ 与 $y$ 之间的线段仍在可行集内）、以及 $f_0$ 凸（保证线段上的函数值不超过端点值的凸组合）。**这就是凸优化「局部即全局」的全部机制**——它不依赖任何光滑性或内点条件。反过来说，只要这两条中有任何一条失效，结论就可以崩掉：quasiconvex 优化问题就存在 locally optimal 但非 globally optimal 的点，见 §4.2.5。

[Figure 4.2：最优性条件 (4.21) 的几何解释。着色的区域是 feasible set $X$。$f_0$ 的若干 level curve 用虚线画出。点 $x$ 是 optimal 的：$-\nabla f_0(x)$ 定义了 $X$ 在 $x$ 处的一个支撑超平面（用实线画出）。]

注意 quasiconvex 优化问题的 locally optimal point 未必是 globally optimal 的；见 §4.2.5。

### 4.2.3 An optimality criterion for differentiable $f_0$（可微 $f_0$ 的最优性判据）

设凸优化问题中的 objective $f_0$ 可微，于是对一切 $x, y \in \mathop{\bf dom} f_0$，

```math
f_0(y) \ge f_0(x) + \nabla f_0(x)^T (y - x), \tag{4.20}
```

见 §3.1.3。令 $X$ 表示 feasible set，即

```math
X = \{x \mid f_i(x) \le 0,\ i = 1, \ldots, m,\ h_i(x) = 0,\ i = 1, \ldots, p\}.
```

那么 $x$ 是 optimal 的，当且仅当 $x \in X$ 且

```math
\nabla f_0(x)^T (y - x) \ge 0 \quad \text{for all } y \in X. \tag{4.21}
```

这个 optimality criterion（最优性判据）可以几何地理解：若 $\nabla f_0(x) \ne 0$，它意味着 $-\nabla f_0(x)$ 在 $x$ 处定义了 feasible set 的一个 supporting hyperplane（支撑超平面），见图 4.2。

#### <span style="color:#873600;">**[proof]**</span> <span style="color:#c0392b">Proof of optimality condition（最优性条件的证明）</span>

先设 $x \in X$ 且满足 (4.21)。那么对任意 $y \in X$，由 (4.20) 得 $f_0(y) \ge f_0(x)$。这说明 $x$ 是 (4.1) 的 optimal point。

反之，设 $x$ 是 optimal 的，但条件 (4.21) 不成立，即存在某个 $y \in X$ 使

```math
\nabla f_0(x)^T (y - x) \lt 0.
```

考虑点 $z(t) = t y + (1 - t) x$，其中 $t \in [0, 1]$ 是参数。由于 $z(t)$ 落在 $x$ 与 $y$ 之间的线段上，而 feasible set 是 convex 的，$z(t)$ 是 feasible 的。我们断言：对充分小的正 $t$ 有 $f_0(z(t)) \lt f_0(x)$，这将证明 $x$ 不是 optimal 的。为看出这一点，注意

```math
\left. \frac{d}{dt} f_0(z(t)) \right|_{t=0} = \nabla f_0(x)^T (y - x) \lt 0,
```

所以对充分小的正 $t$ 确有 $f_0(z(t)) \lt f_0(x)$。

我们将在第 5 章更深入地讨论 optimality condition 这一主题，这里先看几个简单例子。

#### Unconstrained problems（无约束问题）

对一个无约束问题（即 $m = p = 0$），条件 (4.21) 退化为那条众所周知的充分必要条件

```math
\nabla f_0(x) = 0 \tag{4.22}
```

即 $x$ 为 optimal 的条件。虽然这个 optimality condition 我们已经见过，但看它如何从 (4.21) 推出仍然有用。设 $x$ 是 optimal 的，这里的意思是 $x \in \mathop{\bf dom} f_0$，且对一切 feasible 的 $y$ 有 $\nabla f_0(x)^T (y - x) \ge 0$。由于 $f_0$ 可微，它的定义域（按定义）是开集，所以充分接近 $x$ 的一切 $y$ 都是 feasible 的。取 $y = x - t \nabla f_0(x)$，其中 $t \in \mathbb{R}$ 是参数。当 $t$ 是小正数时 $y$ 是 feasible 的，于是

```math
\nabla f_0(x)^T (y - x) = -t \|\nabla f_0(x)\|_2^2 \ge 0,
```

由此推出 $\nabla f_0(x) = 0$。

视 (4.22) 的解的个数不同，有几种可能的情形。若 (4.22) 无解，则不存在 optimal point；问题的 optimal value 取不到。这里又可分两种情况：问题 unbounded below，或 optimal value 有限但取不到。另一方面，方程 (4.22) 可能有多个解，此时每个解都是 $f_0$ 的一个 minimizer。

<span style="color:#1e8449;">**[译注]**</span> 这个「无约束 ⇒ 梯度为零」的推导有一处细节值得抠：**它依赖 $\mathop{\bf dom} f_0$ 是开集**。证明里取了 $y = x - t\nabla f_0(x)$ 并要求 $y$ 仍然 feasible，若 $x$ 落在定义域边界上，任意 $t \gt 0$ 都可能把 $y$ 推出定义域，整条论证就断。这也是 §4.2.4 里「把约束吸收进定义域会毁掉可微性」那段的同一条理由（原书 p.135）。可点开的坐标：§3.1.3 一阶条件 (3.3)、本页 (4.20)；进阶到约束情形时同一思路在 §5.5.3 的 KKT 条件里变成「$-\nabla f_0(x)$ 落在 normal cone 里」，那是 Strang 线代里「正交补 / 投影」的推广，不需要新工具。



> <span style="color:#7f8c8d;">原书 p.140｜例 4.5 无约束二次优化</span>

#### <span style="color:#6c3483;">**[example]**</span> <span style="color:#c0392b">例 4.5（无约束二次优化）</span>

考虑最小化二次函数

```math
f_0(x) = (1/2) x^T P x + q^T x + r,
```

其中 $P \in \mathbb{S}^n_+$（这使 $f_0$ 成为 convex 的）。$x$ 是 $f_0$ 的 minimizer 的充分必要条件是

```math
\nabla f_0(x) = P x + q = 0.
```

视这个（线性）方程无解、有唯一解还是有多个解，会出现几种情形。

- 若 $q \notin \mathcal{R}(P)$，则无解。此时 $f_0$ 是 unbounded below 的。

- 若 $P \succ 0$（这正是 $f_0$ 为 strictly convex 的条件），则 minimizer 唯一，为 $x = -P^{-1} q$。

- 若 $P$ 奇异，但 $q \in \mathcal{R}(P)$，则 optimal point 的集合是（affine 的）集合 $X_{\text{opt}} = -P^{\dagger} q + \mathcal{N}(P)$，其中 $P^{\dagger}$ 表示 $P$ 的 pseudo-inverse（伪逆），见 §A.5.4。

#### <span style="color:#6c3483;">**[example]**</span> <span style="color:#c0392b">例 4.6（Analytic centering，解析中心）</span>

考虑最小化下面这个（convex 的）函数 $f_0 : \mathbb{R}^n \to \mathbb{R}$ 的（无约束）问题：

```math
f_0(x) = -\sum_{i=1}^{m} \log\left(b_i - a_i^T x\right), \qquad \mathop{\bf dom} f_0 = \{x \mid A x \prec b\},
```

其中 $a_1^T, \ldots, a_m^T$ 是 $A$ 的各行。函数 $f_0$ 可微，所以 $x$ 为 optimal 的充分必要条件是

```math
A x \prec b, \qquad \nabla f_0(x) = \sum_{i=1}^{m} \frac{1}{b_i - a_i^T x} a_i = 0. \tag{4.23}
```

（条件 $A x \prec b$ 只是 $x \in \mathop{\bf dom} f_0$。）若 $A x \prec b$ 不可行，则 $f_0$ 的定义域为空。假设 $A x \prec b$ 可行，仍有几种可能的情形（见习题 4.2）：

- (4.23) 无解，于是问题没有 optimal point。这当且仅当 $f_0$ 是 unbounded below 时发生。

- (4.23) 有很多解。此时可以证明这些解构成一个 affine set。

- (4.23) 有唯一解，即 $f_0$ 的唯一 minimizer。这当且仅当开多面体 $\{x \mid A x \prec b\}$ 非空且有界时发生。



我们用记号

```math
\begin{aligned}
\text{minimize}\quad & f_0(x)\\
\text{subject to}\quad & f_i(x)\le0, && i=1,\dots,m\\
& h_i(x)=0, && i=1,\dots,p
\end{aligned} \tag{4.1}
```

描述「在所有满足 $f_i(x)\le0$（$i=1,\dots,m$）与 $h_i(x)=0$（$i=1,\dots,p$）的 $x$ 中，找出使 $f_0(x)$ 最小的 $x$」这一问题。我们称 $x\in\mathbb{R}^n$ 为 optimization variable（优化变量），$f_0:\mathbb{R}^n\to\mathbb{R}$ 为 objective function（目标函数）或 cost function（成本函数）。不等式 $f_i(x)\le0$ 称为 inequality constraints（不等式约束），相应函数 $f_i:\mathbb{R}^n\to\mathbb{R}$ 称为 inequality constraint functions（不等式约束函数）。等式 $h_i(x)=0$ 称为 equality constraints（等式约束），函数 $h_i:\mathbb{R}^n\to\mathbb{R}$ 称为 equality constraint functions（等式约束函数）。若没有约束（即 $m=p=0$），则称问题 (4.1) 是 unconstrained（无约束）的。

目标函数与所有约束函数都有定义的点集

```math
\mathcal{D}=\bigcap_{i=0}^m\mathbf{dom}\,f_i\ \cap\ \bigcap_{i=1}^p\mathbf{dom}\,h_i
```

称为优化问题 (4.1) 的 domain（定义域）。点 $x\in\mathcal{D}$ 是 feasible（可行）的，如果它满足约束 $f_i(x)\le0$（$i=1,\dots,m$）与 $h_i(x)=0$（$i=1,\dots,p$）。若至少存在一个可行点，则称问题 (4.1) 是 feasible（可行）的，否则 infeasible（不可行）。所有可行点的集合称为 feasible set（可行集）或 constraint set（约束集）。



问题 (4.1) 的 optimal value（最优值）$p^\star$ 定义为

```math
p^\star=\inf\{f_0(x) \mid f_i(x)\le0,\ i=1,\dots,m,\; h_i(x)=0,\ i=1,\dots,p\}.
```

我们允许 $p^\star$ 取扩值 $\pm\infty$。若问题不可行，则 $p^\star=\infty$（遵循空集下确界为 $\infty$ 的标准约定）。若存在可行点 $x_k$ 使 $f_0(x_k)\to-\infty$（$k\to\infty$），则 $p^\star=-\infty$，称问题 (4.1) 是 unbounded below（无下界）的。

**最优点与局部最优点。** 若 $x^\star$ 可行且 $f_0(x^\star)=p^\star$，则称 $x^\star$ 是一个 optimal point（最优点），或称它 solves（求解）问题 (4.1)。所有最优点的集合是 optimal set（最优集）：

```math
X_{\mathrm{opt}}=\{x \mid f_i(x)\le0,\ i=1,\dots,m,\; h_i(x)=0,\ i=1,\dots,p,\; f_0(x)=p^\star\}.
```

若问题 (4.1) 存在最优点，则称最优值 is attained 或 achieved（被达到），问题 solvable（可解）。若 $X_{\mathrm{opt}}$ 为空，则称最优值 not attained（未被达到）。（问题无下界时总会发生。）满足 $f_0(x)\le p^\star+\epsilon$（$\epsilon>0$）的可行点 $x$ 称为 ǫ-suboptimal（$\epsilon$-次优）点，所有 $\epsilon$-次优点的集合称为问题 (4.1) 的 ǫ-suboptimal set（$\epsilon$-次优集）。

我们称可行点 $x$ 是 locally optimal（局部最优）的，若存在 $R>0$ 使

```math
f_0(x)=\inf\{f_0(z) \mid f_i(z)\le0,\ i=1,\dots,m,\; h_i(z)=0,\ i=1,\dots,p,\; \|z-x\|_2\le R\},
```

换言之，$x$ 求解了把额外约束 $\|z-x\|_2\le R$ 加入后的优化问题。粗略地说，$x$ 在可行集的邻近点上最小化 $f_0$。术语 globally optimal（全局最优）有时用来区分「局部最优」与「最优」。本书中 optimal 一律指全局最优。

若 $x$ 可行且 $f_i(x)=0$，则称第 $i$ 个不等式约束 $f_i(x)\le0$ 在 $x$ 处是 active（起作用/激活）的；若 $f_i(x)<0$，则称该约束 inactive（不起作用）的。（等式约束在所有可行点处都起作用。）若删去某个约束不改变可行集，则称该约束 redundant（冗余）。

<span style="color:#00838f;">**[例 4.1]** 用几个简单的无约束优化问题（变量 $x\in\mathbb{R}$，$\mathbf{dom}\,f_0=\mathbb{R}_{++}$）说明这些定义：

- $f_0(x)=1/x$：$p^\star=0$，但最优值未被达到。
- $f_0(x)=-\log x$：$p^\star=-\infty$，问题无下界。
- $f_0(x)=x\log x$：$p^\star=-1/e$，在唯一最优点 $x^\star=1/e$ 处达到。

<!-- p.142/143 -->

**可行性问题（Feasibility problems）。** 若目标函数恒为零，则最优值要么为零（可行集非空），要么为 $\infty$（可行集为空）。这称为 feasibility problem（可行性问题），有时写作

```math
\begin{aligned}
\text{find}\quad & x\\
\text{subject to}\quad & f_i(x)\le0, && i=1,\dots,m\\
& h_i(x)=0, && i=1,\dots,p.
\end{aligned}
```

可行性问题就是判定约束是否 consistent（相容），若相容则找出一个满足它们的点。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">4.1.2 Expressing problems in standard form（以标准形式表达问题）</span>

我们把 (4.1) 称为 standard form（标准形式）的优化问题。标准形式约定不等式与等式约束的右端为零。这总可以通过减去非零右端来安排：例如把等式约束 $g_i(x)=\tilde{g}_i(x)$ 表示为 $h_i(x)=0$，其中 $h_i(x)=g_i(x)-\tilde{g}_i(x)$。类似地把形如 $f_i(x)\ge0$ 的不等式表示为 $-f_i(x)\le0$。

<span style="color:#00838f;">**[例 4.2]** **箱约束（box constraints）。** 考虑优化问题

```math
\begin{aligned}
\text{minimize}\quad & f_0(x)\\
\text{subject to}\quad & l_i\le x_i\le u_i,\quad i=1,\dots,n,
\end{aligned}
```

其中 $x\in\mathbb{R}^n$ 是变量。这些约束称为 variable bounds（变量界，因为它们给出每个 $x_i$ 的上下界）或 box constraints（箱约束，因为可行集是一个 box（箱））。用标准形式表达为

```math
\begin{aligned}
\text{minimize}\quad & f_0(x)\\
\text{subject to}\quad & l_i-x_i\le0, && i=1,\dots,n\\
& x_i-u_i\le0, && i=1,\dots,n.
\end{aligned}
```

共有 $2n$ 个不等式约束函数：$f_i(x)=l_i-x_i$（$i=1,\dots,n$）与 $f_i(x)=x_{i-n}-u_{i-n}$（$i=n+1,\dots,2n$）。

<!-- p.143/144 -->

**最大化问题。** 按惯例我们集中讨论最小化问题。最大化问题

```math
\begin{aligned}
\text{maximize}\quad & f_0(x)\\
\text{subject to}\quad & f_i(x)\le0,\; i=1,\dots,m\\
& h_i(x)=0,\; i=1,\dots,p
\end{aligned} \tag{4.2}
```

可以通过在相同约束下最小化 $-f_0$ 来求解。借助这种对应，可以为最大化问题 (4.2) 定义上面的所有术语。例如 (4.2) 的最优值定义为

```math
p^\star=\sup\{f_0(x) \mid f_i(x)\le0,\ i=1,\dots,m,\; h_i(x)=0,\ i=1,\dots,p\},
```

可行点 $x$ 满足 $f_0(x)\ge p^\star-\epsilon$ 时称为 $\epsilon$-次优。考虑最大化问题时，目标有时不称 cost（成本）而称 utility（效用）或 satisfaction level（满意度）。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">4.1.3 Equivalent problems（等价问题）</span>



> <span style="color:#7f8c8d;">原书 p.143｜epigraph form 的用途、对部分变量极小化</span>

objective 是线性的（因而 convex），而新的 constraint function $f_0(x) - t$ 关于 $(x, t)$ 也是 convex 的，所以 epigraph form 问题同样是 convex 的。

有人常说线性 objective 对凸优化而言是 universal（万能的），因为任何凸优化问题都很容易变换成 objective 为线性的问题。凸问题的 epigraph form 有几项实际用途。通过假定凸优化问题的 objective 是线性的，我们可以简化理论分析；它也能简化算法开发，因为一个能解线性 objective 凸优化问题的算法，用上面的变换就能解任何凸优化问题（前提是它能处理约束 $f_0(x) - t \le 0$）。

#### Minimizing over some variables（对部分变量极小化）

对部分变量极小化 convex function 会保持 convexity。因此若 (4.9) 中的 $f_0$ 关于 $x_1, x_2$ 联合 convex，且 $f_i$（$i = 1, \ldots, m_1$）与 $\tilde f_i$（$i = 1, \ldots, m_2$）都是 convex 的，则等价问题 (4.10) 是 convex 的。

<span style="color:#1e8449;">**[译注]**</span> 这一小节实际上给出了一张「变换后 convexity 是否幸存」的判定表，判据统一是 §3.2.2 的两条保凸运算：**convex 与 affine 复合仍 convex**（所以消去／引入线性等式约束安全、epigraph form 的 $f_0(x)-t$ 仍 convex）、**部分极小化保凸**（§3.2.3 的 inf-projection）。反过来，nonlinear 的 equality constraint 一引入就会毁掉凸性——这正是 (4.17) 那个反例的机制。可点开坐标：§3.2.2（composition）、§3.2.3（minimization）、§3.2.6（perspective）；这条判据在第 5 章的对偶化与 §11 的内点法里每天都用：任何把问题改写成「$t$ + 线性 objective + convex 不等式」的操作，都是这里 epigraph form 的直接应用。



本书以非正式的方式使用「优化问题等价」的概念：若从一个问题的解能容易地得到另一个问题的解，反之亦然，则称两个问题 equivalent（等价）。（给出等价的正式定义是可能的，但很复杂。）

举一个简单例子。考虑问题

```math
\begin{aligned}
\text{minimize}\quad & \tilde{f}(x)=\alpha_0f_0(x)\\
\text{subject to}\quad & \tilde{f}_i(x)=\alpha_if_i(x)\le0, && i=1,\dots,m\\
& \tilde{h}_i(x)=\beta_ih_i(x)=0, && i=1,\dots,p,
\end{aligned} \tag{4.3}
```

其中 $\alpha_i>0$（$i=0,\dots,m$），$\beta_i\neq0$（$i=1,\dots,p$）。这个问题由标准形式问题 (4.1) 通过把目标与不等式约束函数乘正的常数、把等式约束函数乘非零常数得到。因此问题 (4.3) 与原问题 (4.1) 的可行集相同；$x$ 对原问题 (4.1) 最优当且仅当它对缩放后的问题 (4.3) 最优，所以两个问题等价。但两个问题 (4.1) 与 (4.3) 并不相同（除非所有 $\alpha_i,\beta_i$ 等于 1），因为目标与约束函数不同。

下面描述一些产生等价问题的一般变换。

**变量替换（Change of variables）。** 设 $\phi:\mathbb{R}^n\to\mathbb{R}^n$ 是一一映射，其像覆盖问题定义域 $\mathcal{D}$，即 $\phi(\mathbf{dom}\,\phi)\supseteq\mathcal{D}$。定义函数 $\tilde{f}_i$ 与 $\tilde{h}_i$：

```math
\tilde{f}_i(z)=f_i(\phi(z)),\ i=0,\dots,m;\qquad \tilde{h}_i(z)=h_i(\phi(z)),\ i=1,\dots,p.
```

考虑问题

```math
\begin{aligned}
\text{minimize}\quad & \tilde{f}_0(z)\\
\text{subject to}\quad & \tilde{f}_i(z)\le0, && i=1,\dots,m\\
& \tilde{h}_i(z)=0, && i=1,\dots,p,
\end{aligned} \tag{4.4}
```

变量为 $z$。我们说标准形式问题 (4.1) 与问题 (4.4) 通过 change of variable（变量替换）或 substitution of variable $x=\phi(z)$ 相联系。两个问题显然等价：若 $x$ 求解 (4.1)，则 $z=\phi^{-1}(x)$ 求解 (4.4)；若 $z$ 求解 (4.4)，则 $x=\phi(z)$ 求解 (4.1)。



**目标与约束函数的变换。** 设 $\psi_0:\mathbb{R}\to\mathbb{R}$ 单调递增，$\psi_1,\dots,\psi_m:\mathbb{R}\to\mathbb{R}$ 满足 $\psi_i(u)\le0$ 当且仅当 $u\le0$，$\psi_{m+1},\dots,\psi_{m+p}:\mathbb{R}\to\mathbb{R}$ 满足 $\psi_i(u)=0$ 当且仅当 $u=0$。定义复合函数

```math
\tilde{f}_i(x)=\psi_i(f_i(x)),\ i=0,\dots,m;\qquad \tilde{h}_i(x)=\psi_{m+i}(h_i(x)),\ i=1,\dots,p.
```

显然相应的问题与标准形式问题 (4.1) 等价：可行集相同，最优点相同。（上面例 (4.3) 中用适当常数缩放目标与约束函数，是所有 $\psi_i$ 均为线性的特例。）

<span style="color:#00838f;">**[例 4.3]** **最小范数与最小范数平方问题。** 一个简单的例子是无约束欧氏范数最小化问题

```math
\text{minimize}\quad \|Ax-b\|_2, \tag{4.5}
```

变量 $x\in\mathbb{R}^n$。由于范数总是非负的，我们同样可以求解

```math
\text{minimize}\quad \|Ax-b\|_2^2=(Ax-b)^T(Ax-b), \tag{4.6}
```

即最小化欧氏范数的平方。问题 (4.5) 与 (4.6) 显然等价，最优点相同。但两个问题不同：例如 (4.5) 的目标在任何满足 $Ax-b=0$ 的 $x$ 处不可微，而 (4.6) 的目标对所有 $x$ 可微（其实是二次的）。

**松弛变量（Slack variables）。** 一个简单变换基于观察：$f_i(x)\le0$ 当且仅当存在 $s_i\ge0$ 满足 $f_i(x)+s_i=0$。利用这个变换得到问题

```math
\begin{aligned}
\text{minimize}\quad & f_0(x)\\
\text{subject to}\quad & s_i\ge0, && i=1,\dots,m\\
& f_i(x)+s_i=0, && i=1,\dots,m\\
& h_i(x)=0, && i=1,\dots,p,
\end{aligned} \tag{4.7}
```

变量为 $x\in\mathbb{R}^n$ 与 $s\in\mathbb{R}^m$。这个问题有 $n+m$ 个变量、$m$ 个不等式约束（$s_i$ 的非负性）与 $m+p$ 个等式约束。新变量 $s_i$ 称为与原不等式约束 $f_i(x)\le0$ 相关联的 slack variable（松弛变量）。引入松弛变量把每个不等式约束替换为一个等式约束加一个非负性约束。问题 (4.7) 与原标准形式问题 (4.1) 等价：若 $(x,s)$ 对 (4.7) 可行，则 $x$ 对原问题可行（因为 $s_i=-f_i(x)\ge0$）；反之若 $x$ 对原问题可行，则 $(x,s)$ 对 (4.7) 可行（取 $s_i=-f_i(x)$）。类似地，$x$ 对原问题 (4.1) 最优当且仅当 $(x,s)$（$s_i=-f_i(x)$）对问题 (4.7) 最优。



**消去等式约束（Eliminating equality constraints）。** 若能用某个参数 $z\in\mathbb{R}^k$ 显式参数化等式约束

```math
h_i(x)=0,\qquad i=1,\dots,p \tag{4.8}
```

的所有解，则可以按下述方法从问题中消去等式约束。设函数 $\phi:\mathbb{R}^k\to\mathbb{R}^n$ 满足：$x$ 满足 (4.8) 当且仅当存在某个 $z\in\mathbb{R}^k$ 使 $x=\phi(z)$。则优化问题

```math
\begin{aligned}
\text{minimize}\quad & \tilde{f}_0(z)=f_0(\phi(z))\\
\text{subject to}\quad & \tilde{f}_i(z)=f_i(\phi(z))\le0,\quad i=1,\dots,m
\end{aligned}
```

与原问题 (4.1) 等价。这个变换后的问题变量为 $z\in\mathbb{R}^k$，有 $m$ 个不等式约束、没有等式约束。若 $z$ 对变换后的问题最优，则 $x=\phi(z)$ 对原问题最优。反之若 $x$ 对原问题最优，则（$x$ 可行）至少存在一个 $z$ 使 $x=\phi(z)$；任何这样的 $z$ 都对变换后的问题最优。

**消去线性等式约束。** 当等式约束都是线性的（形如 $Ax=b$）时，消去变量的过程可以更显式地描述，也容易数值执行。若 $Ax=b$ 不相容（即 $b\notin\mathcal{R}(A)$），则原问题不可行。假设不是这种情况，令 $x_0$ 表示等式约束的任一解，$F\in\mathbb{R}^{n\times k}$ 是任何满足 $\mathcal{R}(F)=\mathcal{N}(A)$ 的矩阵，则线性方程 $Ax=b$ 的一般解为 $Fz+x_0$（$z\in\mathbb{R}^k$）。（可取 $F$ 满秩，此时 $k=n-\mathbf{rank}A$。）把 $x=Fz+x_0$ 代入原问题，得到问题

```math
\begin{aligned}
\text{minimize}\quad & f_0(Fz+x_0)\\
\text{subject to}\quad & f_i(Fz+x_0)\le0,\quad i=1,\dots,m,
\end{aligned}
```

变量为 $z$，它与原问题等价，没有等式约束，变量减少了 $\mathbf{rank}A$ 个。

**引入等式约束。** 我们也可以向问题中引入等式约束与新变量。一般情形复杂且启发不大，我们给出一个后面有用的典型例子。考虑问题

```math
\begin{aligned}
\text{minimize}\quad & f_0(A_0x+b_0)\\
\text{subject to}\quad & f_i(A_ix+b_i)\le0, && i=1,\dots,m\\
& h_i(x)=0, && i=1,\dots,p,
\end{aligned}
```



其中 $x\in\mathbb{R}^n$，$A_i\in\mathbb{R}^{k_i\times n}$，$f_i:\mathbb{R}^{k_i}\to\mathbb{R}$。此问题中目标与约束函数是 $f_i$ 与由 $A_ix+b_i$ 定义的仿射变换的复合。

引入新变量 $y_i\in\mathbb{R}^{k_i}$ 与新等式约束 $y_i=A_ix+b_i$（$i=0,\dots,m$），构成等价问题

```math
\begin{aligned}
\text{minimize}\quad & f_0(y_0)\\
\text{subject to}\quad & f_i(y_i)\le0, && i=1,\dots,m\\
& y_i=A_ix+b_i, && i=0,\dots,m\\
& h_i(x)=0, && i=1,\dots,p.
\end{aligned}
```

此问题有 $k_0+\cdots+k_m$ 个新变量 $y_0\in\mathbb{R}^{k_0},\dots,y_m\in\mathbb{R}^{k_m}$，以及 $k_0+\cdots+k_m$ 个新等式约束 $y_0=A_0x+b_0,\dots,y_m=A_mx+b_m$。此问题的目标与不等式约束是 independent（相互独立）的，即涉及不同的优化变量。

**对部分变量优化（Optimizing over some variables）。** 我们总有

```math
\inf_{x,y}f(x,y)=\inf_x\tilde{f}(x),\qquad \tilde{f}(x)=\inf_y f(x,y).
```

换言之，总可以先对部分变量最小化，再对剩余变量最小化。这个简单而一般的原则可用于把问题变换为等价形式。一般情形繁琐且无启发，我们描述一个例子。

设变量 $x\in\mathbb{R}^n$ 划分为 $x=(x_1,x_2)$，$x_1\in\mathbb{R}^{n_1}$，$x_2\in\mathbb{R}^{n_2}$，$n_1+n_2=n$。考虑问题

```math
\begin{aligned}
\text{minimize}\quad & f_0(x_1,x_2)\\
\text{subject to}\quad & f_i(x_1)\le0, && i=1,\dots,m_1\\
& \tilde{f}_i(x_2)\le0, && i=1,\dots,m_2,
\end{aligned} \tag{4.9}
```

其中约束是 independent（独立）的：每个约束函数只依赖 $x_1$ 或 $x_2$。先对 $x_2$ 最小化。定义 $x_1$ 的函数

```math
\tilde{f}_0(x_1)=\inf\{f_0(x_1,z) \mid \tilde{f}_i(z)\le0,\ i=1,\dots,m_2\}.
```

则问题 (4.9) 等价于

```math
\begin{aligned}
\text{minimize}\quad & \tilde{f}_0(x_1)\\
\text{subject to}\quad & f_i(x_1)\le0,\quad i=1,\dots,m_1. \tag{4.10}
\end{aligned}
```



<span style="color:#00838f;">**[例 4.4]** **带部分变量约束的二次函数最小化。** 考虑严格凸二次目标、部分变量无约束的问题：

```math
\begin{aligned}
\text{minimize}\quad & x_1^TP_{11}x_1+2x_1^TP_{12}x_2+x_2^TP_{22}x_2\\
\text{subject to}\quad & f_i(x_1)\le0,\quad i=1,\dots,m,
\end{aligned}
```

其中 $P_{11}$、$P_{22}$ 对称。这里可以对 $x_2$ 解析地最小化：

```math
\inf_{x_2}\bigl(x_1^TP_{11}x_1+2x_1^TP_{12}x_2+x_2^TP_{22}x_2\bigr)=x_1^T\bigl(P_{11}-P_{12}P_{22}^{-1}P_{12}^T\bigr)x_1
```

（见 §A.5.5）。因此原问题等价于

```math
\begin{aligned}
\text{minimize}\quad & x_1^T\bigl(P_{11}-P_{12}P_{22}^{-1}P_{12}^T\bigr)x_1\\
\text{subject to}\quad & f_i(x_1)\le0,\quad i=1,\dots,m.
\end{aligned}
```

**上图形式（Epigraph form）。** 标准问题 (4.1) 的 epigraph form（上图形式）是问题

```math
\begin{aligned}
\text{minimize}\quad & t\\
\text{subject to}\quad & f_0(x)-t\le0\\
& f_i(x)\le0, && i=1,\dots,m\\
& h_i(x)=0, && i=1,\dots,p,
\end{aligned} \tag{4.11}
```

变量为 $x\in\mathbb{R}^n$ 与 $t\in\mathbb{R}$。容易看出它与原问题等价：$(x,t)$ 对 (4.11) 最优当且仅当 $x$ 对 (4.1) 最优且 $t=f_0(x)$。注意上图形式问题的目标函数是变量 $x,t$ 的 linear function（线性函数）。

上图形式问题 (4.11) 可以几何化地解释为「graph space（图像空间）」$(x,t)$ 中的优化问题：我们在 $f_0$ 的 epigraph（上图）上最小化 $t$，受 $x$ 上的约束（见图 4.1）。

**隐式与显式约束。** 通过 §3.1.2 已提到的简单技巧，可以通过重新定义目标函数的定义域把任何约束隐式地并入目标函数。极端例子：标准形式问题可以表示为无约束问题

```math
\text{minimize}\quad F(x), \tag{4.12}
```

其中把 $F$ 定义为 $f_0$ 但定义域限制到可行集：

```math
\mathbf{dom}\,F=\{x\in\mathbf{dom}\,f_0 \mid f_i(x)\le0,\ i=1,\dots,m,\; h_i(x)=0,\ i=1,\dots,p\},
```

且对 $x\in\mathbf{dom}\,F$ 有 $F(x)=f_0(x)$。（等价地，可定义 $F(x)$ 在不可行点取值 $\infty$。）问题 (4.1) 与 (4.12) 显然等价：可行集、最优点、最优值都相同。



当然这个变换不过是一个记号把戏。把约束隐式化并没有使问题更易分析或求解——尽管问题 (4.12) 名义上无约束，变换在某些方面反而使问题更难。例如设原问题的目标 $f_0$ 可微（从而其定义域开），受限的目标函数 $F$ 可能不可微，因为其定义域很可能不开。

反过来，我们也会遇到带隐式约束的问题，然后可以把它显式化。简单例子：考虑无约束问题

```math
\text{minimize}\quad f(x), \tag{4.13}
```

其中

```math
f(x)=\begin{cases}x^Tx & Ax=b\\ \infty & \text{否则}.\end{cases}
```

于是目标函数在 $Ax=b$ 定义的仿射集上等于二次型 $x^Tx$，在仿射集外为 $\infty$。既然显然只需关注满足 $Ax=b$ 的点，我们说问题 (4.13) 的目标中隐藏着一个 implicit equality constraint（隐式等式约束）$Ax=b$。可以通过构造等价问题把隐式等式约束显式化：

```math
\begin{aligned}
\text{minimize}\quad & x^Tx\\
\text{subject to}\quad & Ax=b. \tag{4.14}
\end{aligned}
```

问题 (4.13) 与 (4.14) 显然等价但不相同：(4.13) 无约束但目标不可微；(4.14) 有等式约束但目标与约束函数可微。



### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">4.1.4 Parameter and oracle problem descriptions（参数描述与神谕描述）</span>

对标准形式 (4.1) 的问题，还有一个问题：目标与约束函数是如何规定的。许多情形这些函数有解析或 closed form（闭式）表达，即由涉及变量 $x$ 与一些参数的公式给出。例如目标为二次的：$f_0(x)=(1/2)x^TPx+q^Tx+r$。为规定目标函数，给出系数（也称 problem parameters 问题参数或 problem data 问题数据）$P\in\mathbf{S}^n$、$q\in\mathbb{R}^n$、$r\in\mathbb{R}$。我们称之为 parameter problem description（参数问题描述）：要解的具体问题（即 problem instance 问题实例）通过给出目标与约束函数表达式中各参数的值来规定。

其他情形目标与约束函数由 oracle models（神谕模型，也称 black box 黑箱或 subroutine models 子程序模型）描述。在神谕模型中，我们不显式知道 $f$，但可以在任何 $x\in\mathbf{dom}\,f$ 处求值 $f(x)$（通常还有某些导数）。这称为 querying the oracle（询问神谕），通常伴随某种代价（如时间）。我们还会得到关于函数的一些 prior information（先验信息），如凸性与值的界。神谕模型的具体例子：无约束问题中最小化函数 $f$。函数值 $f(x)$ 与梯度 $\nabla f(x)$ 在一个子程序中求值；我们可以在任何 $x\in\mathbf{dom}\,f$ 调用该子程序，但看不到其源代码。以 $x$ 为参数调用子程序会返回 $f(x)$ 与 $\nabla f(x)$。注意在神谕模型中，我们从不知道函数本身，只知道询问过的点上的函数值（与某些导数）。（我们也知道一些给定的先验信息，如可微性与凸性。）

实际中参数描述与神谕描述的区分并不截然。给定参数描述，可以为它构造一个神谕（询问时求值所需函数与导数即可）。第三部分研究的大多数算法以神谕模型工作，但当限制到特定的参数化问题族时可以更高效。

## <span style="color:#c0392b;">4.2 Convex optimization（凸优化）</span>

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">4.2.1 Convex optimization problems in standard form（标准形式凸优化问题）</span>

<!-- p.150/151 -->

convex optimization problem（凸优化问题）是形如

```math
\begin{aligned}
\text{minimize}\quad & f_0(x)\\
\text{subject to}\quad & f_i(x)\le0, && i=1,\dots,m\\
& a_i^Tx=b_i, && i=1,\dots,p
\end{aligned} \tag{4.15}
```

的问题，其中 $f_0,\dots,f_m$ 是凸函数。与一般标准形式问题 (4.1) 比较，凸问题有三个附加要求：



- 目标函数必须是凸的；
- 不等式约束函数必须是凸的；
- 等式约束函数 $h_i(x)=a_i^Tx-b_i$ 必须是仿射的。

我们立即注意到一个重要性质：凸优化问题的可行集是凸的，因为它是问题定义域

```math
\mathcal{D}=\bigcap_{i=0}^m\mathbf{dom}\,f_i
```

（凸集）与 $m$ 个（凸的）下水平集 $\{x \mid f_i(x)\le0\}$ 及 $p$ 个超平面 $\{x \mid a_i^Tx=b_i\}$ 的交。（不失一般性可设 $a_i\neq0$：若某 $i$ 有 $a_i=0,b_i=0$，则第 $i$ 个等式约束可删去；若 $a_i=0,b_i\neq0$，则第 $i$ 个等式约束不相容，问题不可行。）因此，在凸优化问题中，我们在一个凸集上最小化一个凸目标函数。

若 $f_0$ 是 quasiconvex（拟凸）而非凸，则称问题 (4.15) 是（标准形式的）quasiconvex optimization problem（拟凸优化问题）。由于凸或拟凸函数的下水平集凸，我们得出：对凸或拟凸优化问题，$\epsilon$-次优集是凸的；特别地最优集凸。若目标严格凸，则最优集至多包含一个点。

**凹最大化问题。** 稍微滥用记号，若目标函数 $f_0$ 凹、不等式约束函数 $f_1,\dots,f_m$ 凸，我们也把

```math
\begin{aligned}
\text{maximize}\quad & f_0(x)\\
\text{subject to}\quad & f_i(x)\le0, && i=1,\dots,m\\
& a_i^Tx=b_i, && i=1,\dots,p
\end{aligned} \tag{4.16}
```

称为凸优化问题。这个 concave maximization problem（凹最大化问题）很容易通过最小化凸目标 $-f_0$ 来求解。我们为最小化问题描述的所有结果、结论与算法都容易移植到最大化情形。类似地，最大化问题 (4.16) 当 $f_0$ 拟凹时称为拟凸的。

<!-- p.151/152 -->

**抽象形式凸优化问题。** 注意凸优化问题定义中的一个 subtlety（微妙之处）。考虑 $x\in\mathbb{R}^2$ 的例子：

```math
\begin{aligned}
\text{minimize}\quad & f_0(x)=x_1^2+x_2^2\\
\text{subject to}\quad & f_1(x)=x_1/(1+x_2^2)\le0\\
& h_1(x)=(x_1+x_2)^2=0,
\end{aligned} \tag{4.17}
```

它是标准形式 (4.1) 的。这个问题不是标准形式的凸优化问题，因为等式约束函数 $h_1$ 不是仿射的，



不等式约束函数 $f_1$ 不凸。尽管如此，可行集 $\{x \mid x_1\le0,\ x_1+x_2=0\}$ 是凸的。所以虽然此问题是在凸集上最小化凸函数 $f_0$，按我们的定义它不是凸优化问题。

当然，这个问题很容易重新表述为

```math
\begin{aligned}
\text{minimize}\quad & f_0(x)=x_1^2+x_2^2\\
\text{subject to}\quad & \tilde{f}_1(x)=x_1\le0\\
& \tilde{h}_1(x)=x_1+x_2=0,
\end{aligned} \tag{4.18}
```

它是标准凸优化形式：$f_0$ 与 $\tilde{f}_1$ 凸，$\tilde{h}_1$ 仿射。

一些作者用术语 abstract convex optimization problem（抽象凸优化问题）描述「在凸集上最小化凸函数」这一（抽象的）问题。按这种术语，问题 (4.17) 是抽象凸优化问题。本书不使用这种术语。对我们而言，凸优化问题不只是「在凸集上最小化凸函数」；还要求可行集具体地由涉及凸函数的不等式组与线性等式约束描述。问题 (4.17) 不是凸优化问题，而问题 (4.18) 是。（不过两个问题等价。）

我们采用较严格的凸优化问题定义在实践中无碍。要求解「在凸集上最小化凸函数」的抽象问题，需要找到该集合用凸不等式与线性等式约束的描述。如上面的例子所示，这通常很直接。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">4.2.2 Local and global optima（局部与全局最优）</span>

凸优化问题的一个基本性质：任何局部最优点也是（全局）最优的。为看出这一点，设 $x$ 是凸优化问题的局部最优点，即 $x$ 可行且对某个 $R>0$：

```math
f_0(x)=\inf\{f_0(z) \mid z \text{ 可行}，\ \|z-x\|_2\le R\}. \tag{4.19}
```

再设 $x$ 不是全局最优，即存在可行 $y$ 使 $f_0(y)\lt f_0(x)$。显然 $\|y-x\|_2>R$（否则 $f_0(x)\le f_0(y)$）。考虑点

```math
z=(1-\theta)x+\theta y,\qquad \theta=\frac{R}{2\|y-x\|_2}.
```

则 $\|z-x\|_2=R/2\lt R$，且由可行集凸性，$z$ 可行。由 $f_0$ 凸性：

```math
f_0(z)\le(1-\theta)f_0(x)+\theta f_0(y)<f_0(x),
```

与 (4.19) 矛盾。因此不存在满足 $f_0(y)\lt f_0(x)$ 的可行 $y$，即 $x$ 全局最优。



拟凸优化问题的局部最优点并不都是全局最优的；见 §4.2.5。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">4.2.3 An optimality criterion for differentiable f₀（可微目标的最优性判据）</span>

设凸优化问题的目标 $f_0$ 可微，则对所有 $x,y\in\mathbf{dom}\,f_0$：

```math
f_0(y)\ge f_0(x)+\nabla f_0(x)^T(y-x) \tag{4.20}
```

（见 §3.1.3）。令 $\mathcal{X}$ 表示可行集：

```math
\mathcal{X}=\{x \mid f_i(x)\le0,\ i=1,\dots,m,\; h_i(x)=0,\ i=1,\dots,p\}.
```

则 **$x$ 最优当且仅当 $x\in\mathcal{X}$ 且**

```math
\nabla f_0(x)^T(y-x)\ge0 \text{ 对所有 } y\in\mathcal{X}. \tag{4.21}
```

这个最优性判据可以几何化理解：若 $\nabla f_0(x)\neq0$，它意味着 $-\nabla f_0(x)$ 定义了可行集在 $x$ 处的支撑超平面（见图 4.2）。

**最优性条件的证明。** 先设 $x\in\mathcal{X}$ 且满足 (4.21)。则若 $y\in\mathcal{X}$，由 (4.20) 得 $f_0(y)\ge f_0(x)$，即 $x$ 是 (4.1) 的最优点。

反之设 $x$ 最优，但条件 (4.21) 不成立，即对某个 $y\in\mathcal{X}$ 有

```math
\nabla f_0(x)^T(y-x)<0.
```



考虑点 $z(t)=ty+(1-t)x$（$t\in[0,1]$ 参数）。由于 $z(t)$ 在 $x$ 与 $y$ 的线段上且可行集凸，$z(t)$ 可行。我们断言对小的正 $t$ 有 $f_0(z(t))\lt f_0(x)$，这将证明 $x$ 非最优。为此注意

```math
\left.\frac{d}{dt}f_0(z(t))\right|_{t=0}=\nabla f_0(x)^T(y-x)<0,
```

所以对小的正 $t$ 有 $f_0(z(t))\lt f_0(x)$。

我们将在第 5 章更深入地研究最优性条件，这里先看几个简单例子。

**无约束问题。** 对无约束问题（$m=p=0$），条件 (4.21) 退化为著名充要条件

```math
\nabla f_0(x)=0 \tag{4.22}
```

（$x$ 最优）。虽然我们已见过这个最优性条件，看看它如何从 (4.21) 推出仍有用。设 $x$ 最优（即 $x\in\mathbf{dom}\,f_0$），且对所有可行 $y$ 有 $\nabla f_0(x)^T(y-x)\ge0$。由于 $f_0$ 可微，其定义域（按定义）是开的，所以所有充分接近 $x$ 的 $y$ 都可行。取 $y=x-t\nabla f_0(x)$（$t\in\mathbb{R}$ 参数）。对小的正 $t$，$y$ 可行，故

```math
\nabla f_0(x)^T(y-x)=-t\|\nabla f_0(x)\|_2^2\ge0,
```

由此得 $\nabla f_0(x)=0$。

根据方程 (4.22) 解的个数有几种可能的情形。若 (4.22) 无解，则没有最优点，问题最优值未被达到。这里可区分两种情形：问题无下界；或最优值有限但未达到。另一方面方程 (4.22) 可能有多个解，此时每个解都是 $f_0$ 的最小化点。

<span style="color:#00838f;">**[例 4.5]** **无约束二次优化。** 考虑最小化二次函数

```math
f_0(x)=(1/2)x^TPx+q^Tx+r
```

的问题，其中 $P\in\mathbf{S}^n_+$（这使 $f_0$ 凸）。$x$ 是 $f_0$ 最小化点的充要条件为

```math
\nabla f_0(x)=Px+q=0.
```

视这个（线性）方程无解、一解或多解有几种情形：

- 若 $q\notin\mathcal{R}(P)$，则无解。此时 $f_0$ 无下界。
- 若 $P\succ0$（即 $f_0$ 严格凸的条件），则有唯一最小化点 $x^\star=-P^{-1}q$。



- 若 $P$ 奇异但 $q\in\mathcal{R}(P)$，则最优集是（仿射）集合 $X_{\mathrm{opt}}=-P^\dagger q+\mathcal{N}(P)$，其中 $P^\dagger$ 表示 $P$ 的 pseudo-inverse（伪逆）（见 §A.5.4）。

<span style="color:#00838f;">**[例 4.6]** **解析中心（analytic centering）。** 考虑（无约束）最小化（凸）函数 $f_0:\mathbb{R}^n\to\mathbb{R}$ 的问题：

```math
f_0(x)=-\sum_{i=1}^m\log(b_i-a_i^Tx),\qquad \mathbf{dom}\,f_0=\{x \mid Ax\prec b\},
```

其中 $a_1^T,\dots,a_m^T$ 是 $A$ 的行。$f_0$ 可微，所以 $x$ 最优的充要条件是

```math
Ax\prec b,\qquad \nabla f_0(x)=\sum_{i=1}^m\frac{1}{b_i-a_i^Tx}a_i=0. \tag{4.23}
```

（条件 $Ax\prec b$ 就是 $x\in\mathbf{dom}\,f_0$。）若 $Ax\prec b$ 不可行，则 $f_0$ 的定义域为空。设 $Ax\prec b$ 可行，仍有几种可能的情形（见习题 4.2）：

- (4.23) 无解，故问题没有最优点。这当且仅当 $f_0$ 无下界时发生。
- (4.23) 有多个解。此时可以证明解构成一个仿射集。
- (4.23) 有唯一解，即 $f_0$ 有唯一最小化点。这当且仅当开多面体 $\{x \mid Ax\prec b\}$ 非空且有界时发生。

<!-- p.155/156 -->

**只有等式约束的问题。** 考虑只有等式约束、没有不等式约束的情形：

```math
\begin{aligned}
\text{minimize}\quad & f_0(x)\\
\text{subject to}\quad & Ax=b.
\end{aligned}
```

此时可行集是仿射的。设它非空（否则问题不可行）。可行 $x$ 的最优性条件是

```math
\nabla f_0(x)^T(y-x)\ge0
```

必须对所有满足 $Ay=b$ 的 $y$ 成立。由于 $x$ 可行，每个可行 $y$ 形如 $y=x+v$（某个 $v\in\mathcal{N}(A)$）。最优性条件因此可表达为：$\nabla f_0(x)^Tv\ge0$ 对所有 $v\in\mathcal{N}(A)$。线性函数在子空间上非负则必在该子空间上为零，所以 $\nabla f_0(x)^Tv=0$ 对所有 $v\in\mathcal{N}(A)$。换言之，$\nabla f_0(x)\perp\mathcal{N}(A)$。

<!-- p.156/157 -->

利用 $\mathcal{N}(A)^\perp=\mathcal{R}(A^T)$，这个最优性条件可表达为 $\nabla f_0(x)\in\mathcal{R}(A^T)$，即存在 $\nu\in\mathbb{R}^p$ 使

```math
\nabla f_0(x)+A^T\nu=0.
```

连同 $Ax=b$（即 $x$ 可行）的要求，这就是经典的 Lagrange multiplier optimality condition（拉格朗日乘子最优性条件），我们将在第 5 章更详细地研究。

**在非负卦限上最小化。** 再举一个例子：问题

```math
\begin{aligned}
\text{minimize}\quad & f_0(x)\\
\text{subject to}\quad & x\succeq0,
\end{aligned}
```

唯一的不等式约束是变量的非负性。最优性条件 (4.21) 为

```math
x\succeq0,\qquad \nabla f_0(x)^T(y-x)\ge0 \text{ 对所有 } y\succeq0.
```

项 $\nabla f_0(x)^Ty$ 是 $y$ 的线性函数，除非 $\nabla f_0(x)\succeq0$，它在 $y\succeq0$ 上无下界。于是条件退化为 $-\nabla f_0(x)^Tx\ge0$。但 $x\succeq0$ 且 $\nabla f_0(x)\succeq0$，故必有 $\nabla f_0(x)^Tx=0$，即

```math
\sum_{i=1}^n(\nabla f_0(x))_ix_i=0.
```

此和中每项都是两个非负数之积，故每项必为零，即 $(\nabla f_0(x))_ix_i=0$（$i=1,\dots,n$）。最优性条件因此可表达为

```math
x\succeq0,\qquad \nabla f_0(x)\succeq0,\qquad x_i(\nabla f_0(x))_i=0,\ i=1,\dots,n.
```

最后一个条件称为 complementarity（互补性），因为它意味着向量 $x$ 与 $\nabla f_0(x)$ 的 sparsity patterns（稀疏模式，即非零分量的下标集合）complementary（互补，交为空）。我们将在第 5 章再次遇到互补性条件。

> <span style="color:#2471a3;">**[译者注｜第一性原理]** §4.2 是全书的枢纽：局部最优 = 全局最优（4.2.2）+ 一阶最优判据 (4.21)（几何上：负梯度是可行集的支撑超平面）。把这两条记牢，第 5 章的 KKT 条件只是它们在拉格朗日函数上的推广。</span>

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">4.2.4 Equivalent convex problems（等价的凸问题）</span>

<!-- p.156/157 -->

看看 §4.1.3 描述的变换中哪些保持凸性是有用的。

**消去等式约束。** 对凸问题，等式约束必须是线性的（形如 $Ax=b$）。此时可通过找出 $Ax=b$ 的一个特解 $x_0$ 与一个张成 $A$ 零空间的矩阵 $F$ 来消去它们，得到问题

```math
\begin{aligned}
\text{minimize}\quad & f_0(Fz+x_0)\\
\text{subject to}\quad & f_i(Fz+x_0)\le0,\quad i=1,\dots,m,
\end{aligned}
```



可以做许多扩展。例如，一种标准扩展是允许 short position，即 $x_i \lt 0$。为此我们引入变量 $x_{\mathrm{long}}$ 与 $x_{\mathrm{short}}$，满足

```math
x_{\mathrm{long}} \succeq 0, \quad x_{\mathrm{short}} \succeq 0, \qquad x = x_{\mathrm{long}} - x_{\mathrm{short}}, \qquad \mathbf{1}^T x_{\mathrm{short}} \le \eta \mathbf{1}^T x_{\mathrm{long}}.
```

最后那条约束把时期开始时的总 short position，限制为时期开始时总 long position 的某个比例 $\eta$。

作为另一种扩展，我们可以在 portfolio optimization problem 中纳入 linear transaction cost（线性交易成本）。从一个给定的初始 portfolio $x_{\mathrm{init}}$ 出发，我们买卖 asset 以达到 portfolio $x$，然后如上所述在整个时期内持有它。买卖 asset 要交手续费，手续费与买或卖的数量成比例。

为处理这一点，我们引入变量 $u_{\mathrm{buy}}$ 与 $u_{\mathrm{sell}}$，它们决定在持有期之前我们买入与卖出每种 asset 的数量。我们有约束

```math
x = x_{\mathrm{init}} + u_{\mathrm{buy}} - u_{\mathrm{sell}}, \qquad u_{\mathrm{buy}} \succeq 0, \qquad u_{\mathrm{sell}} \succeq 0.
```

我们把那个简单的 budget 约束 $\mathbf{1}^T x = 1$ 替换成如下条件：初始的买入与卖出（含手续费）的净现金为零：

```math
(1 - f_{\mathrm{sell}}) \mathbf{1}^T u_{\mathrm{sell}} = (1 + f_{\mathrm{buy}}) \mathbf{1}^T u_{\mathrm{buy}}.
```

这里左端是卖出 asset 的总收入减去卖出交易费用，右端是买入 asset 的总成本（含交易费用）。常数 $f_{\mathrm{buy}} \ge 0$ 与 $f_{\mathrm{sell}} \ge 0$ 分别是买入与卖出的 transaction fee rate（交易费率）（为简单起见假定各 asset 相同）。

在最低 mean return、以及 budget 与 trading 约束下 minimize return variance 的问题，是一个 QP，其 variable 是 $x$、$u_{\mathrm{buy}}$、$u_{\mathrm{sell}}$。

### 4.4.2 Second-order cone programming（二阶锥规划）

与 quadratic programming 密切相关的一类问题是 second-order cone program（SOCP，二阶锥规划）：

```math
\begin{array}{ll}
\text{minimize} & f^T x \\
\text{subject to} & \|A_i x + b_i\|_2 \le c_i^T x + d_i, \quad i = 1, \ldots, m \\
& F x = g,
\end{array}
\qquad (4.36)
```

其中 $x \in \mathbf{R}^n$ 是 optimization variable，$A_i \in \mathbf{R}^{n_i \times n}$，$F \in \mathbf{R}^{p \times n}$。我们把形如

```math
\|Ax + b\|_2 \le c^T x + d
```

的约束（其中 $A \in \mathbf{R}^{k \times n}$）称为 second-order cone constraint（二阶锥约束），因为它等同于要求 affine function $(Ax + b,\ c^T x + d)$ 落在 $\mathbf{R}^{k+1}$ 中的 second-order cone（二阶锥）里。

当 $c_i = 0$，$i = 1, \ldots, m$ 时，SOCP (4.36) 等价于一个 QCQP（把每条约束平方即得）。类似地，若 $A_i = 0$，$i = 1, \ldots, m$，则 SOCP (4.36) 退化成（一般的）LP。然而 second-order cone program 比 QCQP（当然也比 LP）更一般。



变量为 $z$。由于凸函数与仿射函数的复合是凸的，消去等式约束保持问题的凸性。而且消去等式约束（以及从变换后问题的解重构原问题的解）只涉及标准线性代数运算。

至少在原则上，这意味着我们可以只关注没有等式约束的凸优化问题。然而许多情况下保留等式约束更好：消去它们可能使问题更难理解与分析，或破坏求解算法的效率。当变量 $x$ 维数很大、消去等式约束会破坏稀疏性或其他有用结构时尤其如此。

**引入等式约束。** 可以向凸优化问题引入新变量与新等式约束，只要等式约束是线性的，所得问题也凸。例如若某个目标或约束函数形如 $f_i(A_ix+b_i)$（$A_i\in\mathbb{R}^{k_i\times n}$），可引入新变量 $y_i\in\mathbb{R}^{k_i}$，把 $f_i(A_ix+b_i)$ 换成 $f_i(y_i)$，并添加线性等式约束 $y_i=A_ix+b_i$。

**松弛变量。** 引入松弛变量得到新约束 $f_i(x)+s_i=0$。由于凸问题中等式约束函数必须是仿射的，必须有 $f_i$ 仿射。换言之：为线性不等式引入松弛变量保持问题的凸性。

**上图问题形式。** 凸优化问题 (4.15) 的上图形式是

```math
\begin{aligned}
\text{minimize}\quad & t\\
\text{subject to}\quad & f_0(x)-t\le0\\
& f_i(x)\le0, && i=1,\dots,m\\
& a_i^Tx=b_i, && i=1,\dots,p.
\end{aligned}
```

目标是线性（从而凸）的，新约束函数 $f_0(x)-t$ 关于 $(x,t)$ 也凸，所以上图形式问题也是凸的。

<!-- p.157/158 -->

有时人们说 linear objective（线性目标）对凸优化是 universal（普适）的，因为任何凸优化问题都容易变换为线性目标的问题。凸问题的上图形式有若干实际用途：假设凸优化问题的目标是线性的，可以简化理论分析；也可以简化算法开发，因为一个能求解线性目标凸优化问题的算法，用上述变换就能求解任何凸优化问题（只要它能处理约束 $f_0(x)-t\le0$）。

**对部分变量最小化。** 对部分变量最小化凸函数保持凸性。因此若 (4.9) 中的 $f_0$ 关于 $x_1,x_2$ 联合凸，$f_i$（$i=1,\dots,m_1$）与 $\tilde{f}_i$（$i=1,\dots,m_2$）凸，则等价问题 (4.10) 凸。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">4.2.5 Quasiconvex optimization（拟凸优化）</span>



回顾：quasiconvex optimization problem（拟凸优化问题）具有标准形式

```math
\begin{aligned}
\text{minimize}\quad & f_0(x)\\
\text{subject to}\quad & f_i(x)\le0, && i=1,\dots,m\\
& Ax=b,
\end{aligned} \tag{4.24}
```

其中不等式约束函数 $f_1,\dots,f_m$ 凸，目标 $f_0$ 是拟凸的（而非凸优化问题中的凸）。（拟凸约束函数可以替换为等价的凸约束函数，即凸且具有相同 0-下水平集的约束函数，如 §3.4.5。）

本节指出凸与拟凸优化问题的一些基本差异，并展示如何把求解拟凸优化问题约化为求解一列凸优化问题。

**局部最优解与最优性条件。** 凸优化与拟凸优化最重要的差异：拟凸优化问题可以有不是（全局）最优的局部最优解。这一现象甚至在 $\mathbb{R}$ 上拟凸函数无约束最小化的简单情形就能看到（图 4.3）。

尽管如此，§4.2.3 给出的最优性条件 (4.21) 的一个变体对目标可微的拟凸优化问题成立。令 $\mathcal{X}$ 表示拟凸优化问题 (4.24) 的可行集。由拟凸性的一阶条件 (3.20) 得：若

```math
x\in\mathcal{X},\qquad \nabla f_0(x)^T(y-x)>0 \text{ 对所有 } y\in\mathcal{X}\setminus\{x\}, \tag{4.25}
```



则 $x$ 最优。

这个判据与凸优化中类似的判据 (4.21) 有两个重要差异：

- 条件 (4.25) 只是最优性的 sufficient（充分）条件；简单例子表明它对最优点未必成立。相比之下，条件 (4.21) 对 $x$ 求解凸问题是必要且充分的。
- 条件 (4.25) 要求 $f_0$ 的梯度非零，而条件 (4.21) 不要求。事实上凸情形下 $\nabla f_0(x)=0$ 时条件 (4.21) 满足且 $x$ 最优。

<!-- p.159/160 -->

**借助凸可行性问题求解拟凸优化。** 求解拟凸优化的一种一般方法依赖 §3.4.5 描述的「用一族凸不等式表示拟凸函数的下水平集」。设 $\phi_t:\mathbb{R}^n\to\mathbb{R}$（$t\in\mathbb{R}$）是满足

```math
f_0(x)\le t \iff \phi_t(x)\le0
```

的凸函数族，且对每个 $x$，$\phi_t(x)$ 是 $t$ 的非增函数（$s\ge t$ 时 $\phi_s(x)\le\phi_t(x)$）。

设 $p^\star$ 表示拟凸优化问题 (4.24) 的最优值。若可行性问题

```math
\begin{aligned}
\text{find}\quad & x\\
\text{subject to}\quad & \phi_t(x)\le0\\
& f_i(x)\le0, && i=1,\dots,m\\
& Ax=b
\end{aligned} \tag{4.26}
```

可行，则 $p^\star\le t$。反之若问题 (4.26) 不可行，则可断定 $p^\star\ge t$。问题 (4.26) 是 convex feasibility problem（凸可行性问题），因为不等式约束函数全凸、等式约束线性。

于是，我们可以通过求解凸可行性问题 (4.26) 来检验拟凸优化问题的最优值 $p^\star$ 是小于还是大于给定值 $t$。若凸可行性问题可行，则 $p^\star\le t$，且任何可行点 $x$ 对拟凸问题可行并满足 $f_0(x)\le t$；若不可行，则 $p^\star\ge t$。



这个观察可以作为用 bisection（二分法）求解拟凸优化问题 (4.24) 的简单算法的基础：每步求解一个凸可行性问题。设问题可行，从已知包含最优值 $p^\star$ 的区间 $[l,u]$ 出发。在区间中点 $t=(l+u)/2$ 处求解凸可行性问题，判定最优值在区间的下半还是上半，并相应更新区间。这产生一个仍包含最优值但宽度为初始区间一半的新区间。重复直到区间宽度足够小：

<span style="color:#00838f;">**[算法 4.1]** **拟凸优化的二分法。** 给定 $l\le p^\star$，$u\ge p^\star$，容差 $\epsilon>0$。

重复：
1. $t:=(l+u)/2$。
2. 求解凸可行性问题 (4.26)。
3. 若 (4.26) 可行，则 $u:=t$；否则 $l:=t$。

直到 $u-l\le\epsilon$。

区间 $[l,u]$ 保证包含 $p^\star$，即每步都有 $l\le p^\star\le u$。每次迭代区间被分成两半（bisected），所以 $k$ 次迭代后区间长度为 $2^{-k}(u-l)$（$u-l$ 为初始区间长度）。因此算法终止前恰好需要 $\lceil\log_2((u-l)/\epsilon)\rceil$ 次迭代。每步涉及求解凸可行性问题 (4.26)。



当目标与约束函数全为仿射时，问题称为 linear program（线性规划，LP）。一般线性规划形如

```math
\begin{aligned}
\text{minimize}\quad & c^Tx+d\\
\text{subject to}\quad & Gx\preceq h\\
& Ax=b,
\end{aligned} \tag{4.27}
```

其中 $G\in\mathbb{R}^{m\times n}$，$A\in\mathbb{R}^{p\times n}$。线性规划当然是凸优化问题。目标中的常数 $d$ 常被省略，因为它不影响最优（或可行）集。由于可以通过最小化 $-c^Tx-d$（仍是凸的）来最大化仿射目标 $c^Tx+d$，我们也把目标与约束函数都为仿射的最大化问题称为 LP。

LP 的几何解释见图 4.4：LP (4.27) 的可行集是一个多面体 $\mathcal{P}$；问题是在 $\mathcal{P}$ 上最小化仿射函数 $c^Tx+d$（或等价地线性函数 $c^Tx$）。

**标准形式与不等式形式线性规划。** LP (4.27) 的两个特例如此常见以致有专名。standard form LP（标准形式 LP）中唯一的不等式是逐分量非负约束 $x\succeq0$：

```math
\begin{aligned}
\text{minimize}\quad & c^Tx\\
\text{subject to}\quad & Ax=b\\
& x\succeq0.
\end{aligned} \tag{4.28}
```



若 LP 没有等式约束，则称为 inequality form LP（不等式形式 LP），通常写作

```math
\begin{aligned}
\text{minimize}\quad & c^Tx\\
\text{subject to}\quad & Ax\preceq b. \tag{4.29}
\end{aligned}
```

**把 LP 转换为标准形式。** 有时把一般 LP (4.27) 变换为标准形式 (4.28) 有用（例如为了使用标准形式 LP 的算法）。第一步为不等式引入 slack variables（松弛变量）$s_i$，得到

```math
\begin{aligned}
\text{minimize}\quad & c^Tx+d\\
\text{subject to}\quad & Gx+s=h\\
& Ax=b\\
& s\succeq0.
\end{aligned}
```

第二步把变量 $x$ 表示为两个非负变量之差：$x=x^+-x^-$，$x^+,x^-\succeq0$。这产生问题

```math
\begin{aligned}
\text{minimize}\quad & c^Tx^+-c^Tx^-+d\\
\text{subject to}\quad & Gx^+-Gx^-+s=h\\
& Ax^+-Ax^-=b\\
& x^+\succeq0,\; x^-\succeq0,\; s\succeq0,
\end{aligned}
```

它是标准形式 LP，变量为 $x^+,x^-,s$。（此问题与原问题 (4.27) 的等价性见习题 4.10。）

这些（以及例题与习题中的许多其他）操作问题的技巧，可用于把大量问题表述为线性规划。稍微滥用术语，人们常把能表述为 LP 的问题称为 LP，即使它不具有 (4.27) 的形式。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">4.3.1 Examples（例子）</span>



LP 出现在大量领域与应用中；这里给几个典型例子。

**膳食问题（Diet problem）。** 健康膳食包含 $m$ 种 nutrients（营养素），数量至少为 $b_1,\dots,b_m$。我们可以通过选择 $n$ 种不同食物的非负数量 $x_1,\dots,x_n$ 来组成这样的膳食。一单位食物 $j$ 含营养素 $i$ 的量为 $a_{ij}$，成本为 $c_j$。我们要确定满足营养要求的最便宜膳食。此问题可表述为 LP：

```math
\begin{aligned}
\text{minimize}\quad & c^Tx\\
\text{subject to}\quad & Ax\succeq b\\
& x\succeq0.
\end{aligned}
```

这个问题的几种变体也可表述为 LP。例如可以要求膳食中某营养素恰为一定量（给出线性等式约束），或在上界之外再对某营养素加上界。

**多面体的 Chebyshev 中心。** 考虑找位于由线性不等式描述的多面体

```math
\mathcal{P}=\{x\in\mathbb{R}^n \mid a_i^Tx\le b_i,\ i=1,\dots,m\}
```

内的最大欧氏球的问题。（最优球的中心称为多面体的 Chebyshev center（切比雪夫中心）；它是多面体内最深的点，即离边界最远；见 §8.5.1。）我们把球表示为

```math
\mathcal{B}=\{x_c+u \mid \|u\|_2\le r\}.
```

问题变量是中心 $x_c\in\mathbb{R}^n$ 与半径 $r$；我们希望在约束 $\mathcal{B}\subseteq\mathcal{P}$ 下最大化 $r$。

<!-- p.162/163 -->

先考虑较简单的约束：$\mathcal{B}$ 位于半空间 $a_i^Tx\le b_i$ 内，即

```math
\|u\|_2\le r \implies a_i^T(x_c+u)\le b_i. \tag{4.30}
```

由于

```math
\sup\{a_i^Tu \mid \|u\|_2\le r\}=r\|a_i\|_2,
```



可以把 (4.30) 写成

```math
a_i^Tx_c+r\|a_i\|_2\le b_i, \tag{4.31}
```

这是关于 $x_c$ 与 $r$ 的线性不等式。换言之，「球位于不等式 $a_i^Tx\le b_i$ 确定的半空间内」这一约束可以写成一个线性不等式。因此 $\mathcal{B}\subseteq\mathcal{P}$ 当且仅当 (4.31) 对所有 $i=1,\dots,m$ 成立。于是 Chebyshev 中心可以通过求解 LP

```math
\begin{aligned}
\text{maximize}\quad & r\\
\text{subject to}\quad & a_i^Tx_c+r\|a_i\|_2\le b_i,\quad i=1,\dots,m
\end{aligned}
```

确定，变量为 $r$ 与 $x_c$。（更多关于 Chebyshev 中心的内容见 §8.5.1。）

**动态活动规划（Dynamic activity planning）。** 考虑在 $N$ 个时间周期上选择（规划）经济中 $n$ 个活动（或部门）的 activity levels（活动水平）的问题。令 $x_j(t)\ge0$（$t=1,\dots,N$）表示部门 $j$ 在周期 $t$ 的活动水平。活动按其活动水平的比例消耗与生产产品或 goods（商品）。每单位活动 $j$ 生产商品 $i$ 的量是 $a_{ij}$；类似地每单位活动 $j$ 消耗商品 $i$ 的量是 $b_{ij}$。周期 $t$ 生产的商品总量是 $Ax(t)\in\mathbb{R}^m$，消耗量是 $Bx(t)\in\mathbb{R}^m$。（虽然我们称这些为「商品」，它们也可包括污染物等 unwanted products（不需要的产品）。）

一周期消耗的商品不能超过上一周期生产的：必须对所有 $t=1,\dots,N$ 有 $Bx(t+1)\preceq Ax(t)$。初始商品向量 $g_0\in\mathbb{R}^m$ 给定，它约束第一周期的活动水平：$Bx(1)\preceq g_0$。活动未消耗的 excess goods（剩余商品）向量为

```math
\begin{aligned}
s(0)&=g_0-Bx(1)\\
s(t)&=Ax(t)-Bx(t+1),\quad t=1,\dots,N-1\\
s(N)&=Ax(N).
\end{aligned}
```

目标是最大化剩余商品的 discounted total value（贴现总值）：

```math
c^Ts(0)+\gamma c^Ts(1)+\cdots+\gamma^Nc^Ts(N),
```

其中 $c\in\mathbb{R}^m$ 给出商品的价值，$\gamma>0$ 是 discount factor（贴现因子）。（若第 $i$ 种产品不需要（如污染物），$c_i$ 为负；$|c_i|$ 是单位处置成本。）

<!-- p.163/164 -->

合起来得到 LP：

```math
\begin{aligned}
\text{maximize}\quad & c^Ts(0)+\gamma c^Ts(1)+\cdots+\gamma^Nc^Ts(N)\\
\text{subject to}\quad & x(t)\succeq0, && t=1,\dots,N\\
& s(t)\succeq0, && t=0,\dots,N\\
& s(0)=g_0-Bx(1)\\
& s(t)=Ax(t)-Bx(t+1), && t=1,\dots,N-1\\
& s(N)=Ax(N),
\end{aligned}
```

变量为 $x(1),\dots,x(N)$，$s(0),\dots,s(N)$。这是一个标准形式 LP；变量 $s(t)$ 是约束 $Bx(t+1)\preceq Ax(t)$ 相关联的松弛变量。



**Chebyshev 不等式。** 考虑离散随机变量 $x$ 在 $\{u_1,\dots,u_n\}\subseteq\mathbb{R}$（$n$ 个元素）上的概率分布。我们用向量 $p\in\mathbb{R}^n$ 描述 $x$ 的分布：

```math
p_i=\mathrm{prob}(x=u_i),
```

所以 $p$ 满足 $p\succeq0$、$\mathbf{1}^Tp=1$。反之，满足这两条的 $p$ 定义 $x$ 的一个概率分布。我们假设 $u_i$ 已知且固定，但分布 $p$ 未知。

若 $f$ 是 $x$ 的任意函数，则

```math
\mathbb{E}\,f=\sum_{i=1}^np_if(u_i)
```

是 $p$ 的线性函数。若 $S$ 是 $\mathbb{R}$ 的任意子集，则

```math
\mathrm{prob}(x\in S)=\sum_{u_i\in S}p_i
```

也是 $p$ 的线性函数。

虽然不知道 $p$，但我们有如下形式的先验知识：知道 $x$ 的某些函数的期望的上下界，以及 $\mathbb{R}$ 某些子集的概率。这些先验知识可表示为关于 $p$ 的线性不等式约束：

```math
\alpha_i\le a_i^Tp\le\beta_i,\qquad i=1,\dots,m.
```

问题是给出 $\mathbb{E}\,f_0(x)=a_0^Tp$ 的上下界（$f_0$ 是 $x$ 的某个函数）。找下界时求解 LP：

```math
\begin{aligned}
\text{minimize}\quad & a_0^Tp\\
\text{subject to}\quad & p\succeq0,\quad \mathbf{1}^Tp=1\\
& \alpha_i\le a_i^Tp\le\beta_i,\quad i=1,\dots,m,
\end{aligned}
```

变量 $p$。这个 LP 的最优值给出：在所有与先验信息一致的分布中 $\mathbb{E}\,f_0(X)$ 的最低可能值。而且 bound 是 sharp（尖锐）的：最优解给出一个与先验信息一致且达到下界的分布。类似地，可在相同约束下最大化 $a_0^Tp$ 找到最佳上界。（§7.4.1 将更详细地考虑 Chebyshev 不等式。）

<!-- p.164/165 -->

**分段线性最小化。** 考虑（无约束）最小化分段线性凸函数

```math
f(x)=\max_{i=1,\dots,m}(a_i^Tx+b_i)
```

的问题。可以把它变换为等价 LP：先构造上图问题

```math
\begin{aligned}
\text{minimize}\quad & t\\
\text{subject to}\quad & \max_{i=1,\dots,m}(a_i^Tx+b_i)\le t,
\end{aligned}
```
