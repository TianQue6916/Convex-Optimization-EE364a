# Chapter 5 Duality（对偶）

## 5.1 The Lagrange dual function（Lagrange 对偶函数）

### 5.1.1 The Lagrangian（Lagrangian 函数）

我们考虑标准形式 (4.1) 的 optimization problem：

```math
\begin{array}{ll}
\text{minimize} & f_0(x) \\
\text{subject to} & f_i(x) \le 0, \quad i = 1, \ldots, m \\
& h_i(x) = 0, \quad i = 1, \ldots, p,
\end{array}
\qquad (5.1)
```

其 variable 为 $x \in \mathbf{R}^n$。我们假定其 domain $D = \bigcap_{i=0}^{m}\operatorname{dom} f_i \cap \bigcap_{i=1}^{p}\operatorname{dom} h_i$ 非空，并把 (5.1) 的 optimal value 记作 $p^\star$。**我们并不假定问题 (5.1) 是 convex 的。**

Lagrangian duality 的基本想法是：把 (5.1) 中的约束**纳入目标函数**，做法是给目标加上约束函数的加权和。我们把与问题 (5.1) 关联的 Lagrangian $L : \mathbf{R}^n \times \mathbf{R}^m \times \mathbf{R}^p \to \mathbf{R}$ 定义为

```math
L(x, \lambda, \nu) = f_0(x) + \sum_{i=1}^{m}\lambda_i f_i(x) + \sum_{i=1}^{p}\nu_i h_i(x),
```

其 domain 为 $\operatorname{dom} L = D \times \mathbf{R}^m \times \mathbf{R}^p$。我们把 $\lambda_i$ 称为与第 $i$ 条 inequality constraint $f_i(x) \le 0$ 关联的 Lagrange multiplier（Lagrange 乘子）；类似地，把 $\nu_i$ 称为与第 $i$ 条 equality constraint $h_i(x) = 0$ 关联的 Lagrange multiplier。向量 $\lambda$ 与 $\nu$ 合称与问题 (5.1) 关联的 dual variables（对偶变量）或 Lagrange multiplier vectors（Lagrange 乘子向量）。

<span style="color:#1e8449;">**[译注]** 这里最该注意的是那句「**我们并不假定问题 (5.1) 是 convex 的**」——它是整章的地基，也是多数教材讲漏的一句。Lagrangian 的构造完全不依赖 convexity：它只是把「$f_i(x) \le 0$ 这条硬约束」换成「给 $f_i(x)$ 的非正性打一个非负价格 $\lambda_i \ge 0$」，于是约束违反得越多，罚得越重。**抽掉「不假定 convex」这句话，会崩掉后面两个结论**：① §5.1.2 说 dual function 是 affine functions 的 pointwise infimum、因而**总**是 concave——这与 primal 凸不凸无关；② §5.2.2 的 weak duality $d^\star \le p^\star$ 对**任何**问题成立。整章唯一需要 convexity 的地方是 strong duality（§5.2.3，配 Slater 条件）。挂载点：这套「拉格朗日量 = 目标 + 乘子×约束」的构造，你在 Strang 线代的 least-squares 正规方程里已经见过一次（那里的乘子就是 residual 的对偶变量），在 6.042J 的 LP duality 单元里见过第二次（那里的 $\lambda$ 叫 dual weight）；本节的贡献是把它推广到 nonlinear 情形。一手坐标：Boyd §5.1.1 与 §5.2.2；历史侧见 Kuhn & Tucker 1951 的 *Nonlinear programming*（Berkeley Symposium），以及 Lagrange 1797 的解析力学（那里的乘子是约束力）。</span>



### 5.1.2 The Lagrange dual function（Lagrange 对偶函数）

我们把 Lagrange dual function（或简称 dual function）$g : \mathbf{R}^m \times \mathbf{R}^p \to \mathbf{R}$ 定义为 Lagrangian 在 $x$ 上的最小值：对 $\lambda \in \mathbf{R}^m$、$\nu \in \mathbf{R}^p$，

```math
g(\lambda, \nu) = \inf_{x \in D} L(x, \lambda, \nu) = \inf_{x \in D}\left( f_0(x) + \sum_{i=1}^{m}\lambda_i f_i(x) + \sum_{i=1}^{p}\nu_i h_i(x) \right).
```

当 Lagrangian 在 $x$ 上下无界时，dual function 取值为 $-\infty$。由于 dual function 是 $(\lambda, \nu)$ 的一族 affine functions 的 pointwise infimum（逐点下确界），所以它是 concave 的——**即使问题 (5.1) 不是 convex 的**。

<span style="color:#1e8449;">**[译注]** 这一句值得单独拆开，因为「为什么 dual function 一定 concave」是第 5 章最容易被当成口诀背过去的一处。机制只有两步：① 固定 $x$ 时，$L(x,\lambda,\nu) = f_0(x) + \lambda^Tf(x) + \nu^Th(x)$ 是 $(\lambda,\nu)$ 的 **affine function**（$x$ 只是它的系数）；② **一族 affine functions 的逐点下确界必 concave**，因为对任意 $\theta \in [0,1]$，$g(\theta\lambda_1 + (1-\theta)\lambda_2) = \inf_x L(x, \theta\lambda_1+(1-\theta)\lambda_2) = \inf_x[\theta L(x,\lambda_1) + (1-\theta)L(x,\lambda_2)] \ge \theta\inf_x L(x,\lambda_1) + (1-\theta)\inf_x L(x,\lambda_2)$——**不等号的方向恰好来自「$\inf$ 与加权和交换要付代价」**，这就是 concavity 的全部来源。**抽掉这条会崩的地方**：§5.2 说「dual problem 是 convex optimization problem」就无从论证了，于是「用对偶把难问题转成易问题」这条整个策略失去合法性。对偶的这条对偶性（affine in $(\lambda,\nu)$、inf over $x$）在别的领域也出现：6.006 的 min-max 定理（optimal strategy 的 value）、以及 CSAPP 第 5 章讲 loop 优化时「先取下界再优化」的思路。可点开的坐标：Boyd §3.2.3（pointwise supremum of convex functions is convex，本节是它的镜像）、§5.1.2；更系统的处理见 Rockafellar *Convex Analysis* (1970) §30–31 关于 biconjugate 的讨论。</span>

### 5.1.3 Lower bounds on optimal value（最优值的下界）

dual function 给出问题 (5.1) 的 optimal value $p^\star$ 的下界：对任意 $\lambda \succeq 0$ 与任意 $\nu$，有

```math
g(\lambda, \nu) \le p^\star.
\qquad (5.2)
```

这条重要性质很容易验证。设 $\tilde{x}$ 是问题 (5.1) 的 feasible point，即 $f_i(\tilde{x}) \le 0$ 且 $h_i(\tilde{x}) = 0$，并设 $\lambda \succeq 0$。那么有

```math
\sum_{i=1}^{m}\lambda_i f_i(\tilde{x}) + \sum_{i=1}^{p}\nu_i h_i(\tilde{x}) \le 0,
```

因为第一个和中每一项都非正、第二个和中每一项都为零，因此

```math
L(\tilde{x}, \lambda, \nu) = f_0(\tilde{x}) + \sum_{i=1}^{m}\lambda_i f_i(\tilde{x}) + \sum_{i=1}^{p}\nu_i h_i(\tilde{x}) \le f_0(\tilde{x}).
```

于是

```math
g(\lambda, \nu) = \inf_{x \in D} L(x, \lambda, \nu) \le L(\tilde{x}, \lambda, \nu) \le f_0(\tilde{x}).
```

由于 $g(\lambda,\nu) \le f_0(\tilde{x})$ 对**每个** feasible point $\tilde{x}$ 都成立，不等式 (5.2) 得证。下界 (5.2) 由 Figure 5.1 图解，那里是一个 $x \in \mathbf{R}$、带一条 inequality constraint 的简单问题。

当 $g(\lambda,\nu) = -\infty$ 时，不等式 (5.2) 成立但没有意义。只有当 $\lambda \succeq 0$ 且 $(\lambda,\nu) \in \operatorname{dom} g$（即 $g(\lambda,\nu) \gt -\infty$）时，dual function 才给出 $p^\star$ 的**非平凡**下界。我们把满足 $\lambda \succeq 0$ 且 $(\lambda,\nu) \in \operatorname{dom} g$ 的 $(\lambda,\nu)$ 称为 dual feasible，理由在稍后就会清楚。

<span style="color:#1e8449;">**[译注]** §5.1.3 的证明只有四行，但**不等号链条的方向**是整章最该记牢的东西，值得逐环标出来：$g(\lambda,\nu) = \inf_x L \le L(\tilde{x})$（inf 是最小，故 $\le$ 任意取值）$\le f_0(\tilde{x})$（因为 $\lambda^Tf(\tilde x) + \nu^Th(\tilde x) \le 0$，**这一环靠 $\lambda \succeq 0$ 与 $\tilde{x}$ feasible 两个条件**）。两个推论直接得到：① $\lambda \succeq 0$ 若去掉，第一环的 $\le$ 会翻成 $\ge$，下界立刻失效——**这就是 dual problem 为什么必须带 $\lambda \succeq 0$ 这条约束**；② 若问题没有 feasible point，则整条链无法启动，此时 (5.2) 的任何非平凡取值都是「vacuous bound」（$p^\star = +\infty$ 时空洞地成立）。这个「$p^\star$ 可能取 $\pm\infty$」的细节正是习题 4.1 要你先分清「值」与「解」的原因。跨学科落点：这条链与 Strang 线代里「least-squares 的 normal equation 给出下界」是同一件事的连续版本；在 6.042J 的 LP duality 里，同一个论证叫 weak duality，那里 $\lambda$ 的每个分量都是「打包价」。可点开的坐标：Boyd §5.1.3（本段）与 §5.2.2（weak duality，把 5.2 在 $\lambda$ 上取 sup 即得）。</span>

Lagrangian 与下界性质可以给出一个简单解释，它基于集合 $\{0\}$ 与 $-\mathbf{R}_+$ 的 indicator functions 的线性近似。

<span style="color:#1e8449;">**[译注]** Figure 5.2 是本册最值得看的一张图，因为它把「**dual function 的 concavity 与 primal 的 convexity 无关**」变成了肉眼可见的事实：$f_0$ 与 $f_1$ 在 Figure 5.1 里一个是非凸的波浪曲线、一个是非凸的约束曲线（那个可行区间 $[-0.46,0.46]$ 完全不像 convex set），而 Figure 5.2 里的 $g(\lambda)$ 却是**一条干净的凹曲线**。为什么？因为 $g$ 不是从 $f_0$ 的形状得来的，而是从「一族关于 $\lambda$ 的直线取逐点下确界」得来的——那些直线来自对不同的 $\lambda$ 求 $\inf_x L(x,\lambda)$，$x$ 只是积分变量，被 inf 消掉了。**抽掉这张图，会崩的地方**：你会误以为「对偶只对凸问题有用」；而恰恰相反，对偶最有价值的用处之一就是给**非凸**问题（如图中的问题、或 §5.1.5 的 two-way partitioning）提供可计算的下界，这是 branch-and-bound 的界的来源。跨学科落点：这套「非凸对象 → 凸的包络」的结构在 6.042J 的 LP duality 里对应「任意 LP 的对偶都是 LP」，在 Thomson 实分析里对应「affine 族的上/下包络仍是 affine/convex 类」；更硬的坐标是 Boyd §5.1.5 的 two-way partitioning 例子（那里 $p^\star \ge n\lambda_{\min}(W)$ 是这条思路的可计算公式）。</span>



我们先把原问题 (5.1) 改写成无约束问题：

```math
\text{minimize} \quad f_0(x) + \sum_{i=1}^{m} I_-(f_i(x)) + \sum_{i=1}^{p} I_0(h_i(x)),
\qquad (5.3)
```

其中 $I_- : \mathbf{R} \to \mathbf{R}$ 是非正实数集的 indicator function（指示函数），

```math
I_-(u) = \begin{cases} 0 & u \le 0 \\ \infty & u \gt 0, \end{cases}
```

类似地，$I_0$ 是 $\{0\}$ 的 indicator function。在 (5.3) 这种写法里，$I_-(u)$ 可以解释为表达我们对 constraint function 取值 $u = f_i(x)$ 的「不快」或「不满」：$f_i(x) \le 0$ 时它为零，$f_i(x) \gt 0$ 时为无穷。类似地，$I_0(u)$ 给出我们对 equality constraint 取值 $u = h_i(x)$ 的不快。我们可以把 $I_-$ 想成一面「砖墙」或「无限硬」的不快函数：当 $f_i(x)$ 从非正过渡到正时，我们的不快从零升到无穷。

现在假定在 (5.3) 中，我们把 $I_-(u)$ 换成线性函数 $\lambda_i u$（其中 $\lambda_i \succeq 0$），把 $I_0(u)$ 换成 $\nu_i u$。目标就变成 Lagrangian $L(x,\lambda,\nu)$，而 dual function 取值 $g(\lambda,\nu)$ 就是问题

```math
\text{minimize} \quad L(x, \lambda, \nu) = f_0(x) + \sum_{i=1}^{m}\lambda_i f_i(x) + \sum_{i=1}^{p}\nu_i h_i(x)
\qquad (5.4)
```

的 optimal value。在这种写法里，我们用线性（「软」）的不快函数替代 $I_-$ 与 $I_0$。对 inequality constraint 而言，$f_i(x) = 0$ 时不快为零，$f_i(x) \gt 0$ 时为正（假定 $\lambda_i \gt 0$）；约束被违反得越多，不快越大。与原写法不同——原写法里 $f_i(x)$ 的任何非正值都可接受——在「软」写法里，我们反而从有裕量的约束（即 $f_i(x) \lt 0$）中获得**快感**。

显然，用线性函数 $\lambda_i u$ 近似 indicator function $I_-(u)$ 相当粗糙。但线性函数至少是 indicator function 的**下估计**：由于对一切 $u$ 有 $\lambda_i u \le I_-(u)$ 与 $\nu_i u \le I_0(u)$，我们立刻看出 dual function 给出原问题 optimal value 的下界。

把「硬」约束换成「软」版本的想法，在考虑 interior-point methods 时会再次出现（§11.2.1）。

<span style="color:#1e8449;">**[译注]** §5.1.4 这一节的措辞（irritation / displeasure / brick wall / derive pleasure）看着像玩笑，其实是全章最精确的一段，因为它把 Lagrangian **为什么是那个形状**讲清了。逻辑链是：把约束写成 indicator function ⇒ 问题变成无约束 ⇒ indicator 是「无限硬的惩罚」⇒ 用一个**不超过它的**线性惩罚替代 ⇒ 得到的是**原问题的一个下估计**（relaxation）⇒ 对下估计求最小值自然是原问题最优值的下界。**这条「换惩罚函数 → 得到界」的链条是全章的骨架**，而且它解释了为什么 $\lambda_i$ 必须 $\ge 0$：若 $\lambda_i \lt 0$，线性函数 $\lambda_iu$ 在 $u \gt 0$ 时会变成负的、不再 $u \le 0$ 区间的下估计（$I_-(u)$ 在 $u \le 0$ 处取 0，任何正斜率直线在该区间都是 0 的下方），整个「下估计」性质就破了。**抽掉这一段会崩的地方**：你只会记住「$L = f_0 + \lambda^Tf + \nu^Th$」这个公式，却不知道它为什么能给出界；而到了 §11.2.1 的 barrier method，「用 log barrier 近似 indicator」会显得像凭空冒出来的技巧——其实它就是本节「软惩罚」的第二次使用（那里用 $-(1/t)\log(-u)$ 替代 $I_-(u)$，同样是下估计）。跨学科落点：CSAPP 第 5 章讲「把分支预测失败当 penalty」与本节的「把约束违反当 penalty」是同一建模手法，6.006 的 Lagrangian relaxation（TSP 的 1-tree bound）用的正是本节这套「软约束 + 下界」。一手坐标：Boyd §5.1.4 与 §11.2.1；对偶视角的系统处理见 Bertsekas *Nonlinear Programming* (2nd ed., 1999) §5.1。</span>

### 5.1.5 Examples（例）

本节给出几个可以解析地写出 Lagrange dual function 的例子。

**Least-squares solution of linear equations（线性方程组的最小二乘解）**

我们考虑问题

```math
\begin{array}{ll}
\text{minimize} & x^T x \\
\text{subject to} & Ax = b,
\end{array}
\qquad (5.5)
```

其中 $A \in \mathbf{R}^{p \times n}$。这个问题没有 inequality constraint，只有 $p$ 条（linear）equality constraint。Lagrangian 为 $L(x,\nu) = x^Tx + \nu^T(Ax - b)$，其 domain 为 $\mathbf{R}^n \times \mathbf{R}^p$。



dual function 由 $g(\nu) = \inf_x L(x,\nu)$ 给出。由于 $L(x,\nu)$ 是 $x$ 的 convex quadratic function，我们可由 optimality condition

```math
\nabla_x L(x, \nu) = 2x + A^T\nu = 0
```

求出使 $L$ 最小的 $x$，得 $x = -(1/2)A^T\nu$。因此 dual function 为

```math
g(\nu) = L(-(1/2)A^T\nu, \nu) = -(1/4)\nu^T AA^T \nu - b^T\nu,
```

它是 concave quadratic function，domain 为 $\mathbf{R}^p$。下界性质 (5.2) 断言：对任意 $\nu \in \mathbf{R}^p$，有

```math
-(1/4)\nu^TAA^T\nu - b^T\nu \le \inf\{x^Tx \mid Ax = b\}.
```

**Standard form LP（标准形式的 LP）**

考虑标准形式的 LP，

```math
\begin{array}{ll}
\text{minimize} & c^T x \\
\text{subject to} & Ax = b \\
& x \succeq 0,
\end{array}
\qquad (5.6)
```

它有 inequality constraint functions $f_i(x) = -x_i$，$i = 1, \ldots, n$。为构造 Lagrangian，我们对 $n$ 条 inequality constraint 引入乘子 $\lambda_i$，对 equality constraint 引入乘子 $\nu$，得到

```math
L(x, \lambda, \nu) = c^T x - \sum_{i=1}^{n}\lambda_i x_i + \nu^T(Ax - b) = -b^T\nu + (c + A^T\nu - \lambda)^T x.
```

dual function 为

```math
g(\lambda, \nu) = \inf_x L(x, \lambda, \nu) = -b^T\nu + \inf_x (c + A^T\nu - \lambda)^T x,
```

它很容易解析确定，因为线性函数只有当它恒为零时才有下界。因此，除 $c + A^T\nu - \lambda = 0$ 的情形（此时为 $-b^T\nu$）之外，$g(\lambda,\nu) = -\infty$：

```math
g(\lambda, \nu) = \begin{cases} -b^T\nu & A^T\nu - \lambda + c = 0 \\ -\infty & \text{otherwise}. \end{cases}
```

注意 dual function $g$ 只在 $\mathbf{R}^m \times \mathbf{R}^p$ 的一个 proper affine subset 上有限。我们将会看到这是常见现象。

下界性质 (5.2) 只有在 $\lambda$ 与 $\nu$ 满足 $\lambda \succeq 0$ 与 $A^T\nu - \lambda + c = 0$ 时才非平凡。此时 $-b^T\nu$ 是 LP (5.6) 的 optimal value 的一个下界。

**Two-way partitioning problem（双向划分问题）**

我们考虑（非凸的）问题

```math
\begin{array}{ll}
\text{minimize} & x^T W x \\
\text{subject to} & x_i^2 = 1, \quad i = 1, \ldots, n,
\end{array}
\qquad (5.7)
```



其中 $W \in \mathbf{S}^n$。这些约束把 $x_i$ 的取值限制为 $1$ 或 $-1$，所以该问题等价于：找出分量为 $\pm 1$ 的向量，使 $x^TWx$ 最小。此处 feasible set 是有限的（含 $2^n$ 个点），因此原则上可以逐个检查每个 feasible point 的目标值来求解。但 feasible point 的数目随 $n$ 指数增长，所以只有小问题（比如说 $n \le 30$）才可行。一般情形（以及 $n$ 大于比如说 50 时），问题 (5.7) 极难求解。

我们可以把 (5.7) 解释为 $n$ 个元素（比如说 $\{1, \ldots, n\}$）上的 two-way partitioning problem：一个 feasible $x$ 对应划分

```math
\{1, \ldots, n\} = \{i \mid x_i = -1\} \cup \{i \mid x_i = 1\}.
```

矩阵系数 $W_{ij}$ 可以解释为「元素 $i$ 与 $j$ 落在同一侧」的代价，而 $-W_{ij}$ 是「$i$ 与 $j$ 落在不同侧」的代价。式 (5.7) 中的目标是所有元素对上的代价总和，而 (5.7) 就是要找出总代价最小的划分。

现在来推导这个问题的 dual function。Lagrangian 为

```math
L(x, \lambda) = x^T W x + \sum_{i=1}^{n}\lambda_i(x_i^2 - 1) = x^T(W + \operatorname{\mathbf{diag}}(\lambda))x - \mathbf{1}^T\lambda.
```

在 $x$ 上最小化即得 Lagrange dual function：

```math
g(\lambda) = \inf_x \left( x^T(W + \operatorname{\mathbf{diag}}(\lambda))x - \mathbf{1}^T\lambda \right) = \begin{cases} -\mathbf{1}^T\lambda & W + \operatorname{\mathbf{diag}}(\lambda) \succeq 0 \\ -\infty & \text{otherwise}, \end{cases}
```

这里用到的事实是：quadratic form 的下确界要么为零（当该二次型 positive semidefinite 时），要么为 $-\infty$（当它不是 positive semidefinite 时）。

这个 dual function 给出难问题 (5.7) 之 optimal value 的下界。例如，我们可以取 dual variable 的具体取值

```math
\lambda = -\lambda_{\min}(W)\mathbf{1},
```

它是 dual feasible 的，因为

```math
W + \operatorname{\mathbf{diag}}(\lambda) = W - \lambda_{\min}(W)I \succeq 0.
```

于是得到 optimal value $p^\star$ 的界

```math
p^\star \ge -\mathbf{1}^T\lambda = n\lambda_{\min}(W).
\qquad (5.8)
```

<span style="color:#7d6608;">**[remark 5.1]**</span> <span style="color:#c0392b;">这个 $p^\star$ 的下界也可以不用 Lagrange dual function 得到。首先，我们把约束 $x_1^2 = 1, \ldots, x_n^2 = 1$ 换成 $\sum_{i=1}^{n}x_i^2 = n$，得到修改后的问题

```math
\begin{array}{ll}
\text{minimize} & x^T W x \\
\text{subject to} & \sum_{i=1}^{n}x_i^2 = n.
\end{array}
\qquad (5.9)
```



原问题 (5.7) 的约束蕴含这里的约束，所以问题 (5.9) 的 optimal value 是 $p^\star$（即 (5.7) 的 optimal value）的一个下界。但修改后的问题 (5.9) 很容易作为 eigenvalue problem 求解，其 optimal value 为 $n\lambda_{\min}(W)$。</span>

<span style="color:#1e8449;">**[译注]** two-way partitioning 这个例子（§5.1.5 与 Remark 5.1）值得下重注，因为它是**「对偶给非凸难问题可计算下界」的唯一完整小模型**。三个要点：① 问题 (5.7) 是 NP-hard（等价于 max-cut 的补问题），$n = 50$ 就不可穷举；② 取 $\lambda = -\lambda_{\min}(W)\mathbf{1}$ 这条**特定的** dual feasible point，一步就得到 $p^\star \ge n\lambda_{\min}(W)$，而算 $\lambda_{\min}$ 只要一次 symmetric eigenvalue 分解（Strang 线代第 6 章的做法，$O(n^3)$）；③ Remark 5.1 展示了一个**完全不用对偶**的推导：把 $n$ 条 $x_i^2=1$ 松成一条 $\sum x_i^2 = n$（这是「约束聚合」relaxation），得到的恰好是同一个界。**抽掉 ③ 会崩的地方**：你会以为「对偶是个独立的魔法」，其实对偶与约束聚合在这里给出同一个界，说明这个界的来源是 **$W$ 的谱**而不是乘子技巧；而 $n\lambda_{\min}(W)$ 这个界正是后来 Goemans–Williamson 的 SDP relaxation 的出发点（把 $x_i \in \{\pm1\}$ 松成 $\|u_i\|_2 = 1$，$x^TWx$ 变成 $\operatorname{tr}(WV)$ 的 SDP，界严格优于 $n\lambda_{\min}$）。跨学科落点：Strang 线代第 6 章的 Rayleigh quotient 极值定理就是 $n\lambda_{\min}(W)$ 的出处，6.006 里 max-cut 的近似算法就是这条线的下游。可点开的坐标：Boyd §5.1.5 本段与 Remark 5.1；Goemans & Williamson 1995 的 *Improved approximation algorithms for maximum cut and satisfiability problems using semidefinite programming*（JACM 42(6), 1115–1145, DOI 10.1145/227683.227684）。可运行验证：$n=3$、$W$ 为随机对称矩阵，暴力枚举 $2^3=8$ 个 $\pm1$ 向量得 $p^\star$，与 $3\lambda_{\min}(W)$ 比较，应满足 $n\lambda_{\min}(W) \le p^\star$（等号当且仅当最优解是 $\lambda_{\min}$ 的特征向量且为 $\pm1$ 向量）。</span>

### 5.1.6 The Lagrange dual function and conjugate functions（Lagrange 对偶函数与共轭函数）

回忆 §3.3：函数 $f : \mathbf{R}^n \to \mathbf{R}$ 的 conjugate（共轭函数）$f^*$ 由下式给出

```math
f^*(y) = \sup_{x \in \operatorname{dom} f}\left( y^T x - f(x) \right).
```

conjugate function 与 Lagrange dual function 关系密切。先看一个简单联系：考虑问题

```math
\begin{array}{ll}
\text{minimize} & f(x) \\
\text{subject to} & x = 0
\end{array}
```

（这个问题不太有趣，一眼就能解出）。其 Lagrangian 为 $L(x,\nu) = f(x) + \nu^Tx$，dual function 为

```math
g(\nu) = \inf_x \left( f(x) + \nu^T x \right) = -\sup_x\left( (-\nu)^T x - f(x) \right) = -f^*(-\nu).
```

更一般（也更有用）地，考虑带 linear inequality 与 equality constraint 的 optimization problem

```math
\begin{array}{ll}
\text{minimize} & f_0(x) \\
\text{subject to} & Ax \preceq b \\
& Cx = d.
\end{array}
\qquad (5.10)
```

利用 $f_0$ 的 conjugate，我们可以把问题 (5.10) 的 dual function写成

```math
\begin{aligned}
g(\lambda, \nu) &= \inf_x \left( f_0(x) + \lambda^T(Ax - b) + \nu^T(Cx - d) \right) \\
&= -b^T\lambda - d^T\nu + \inf_x \left( f_0(x) + (A^T\lambda + C^T\nu)^T x \right) \\
&= -b^T\lambda - d^T\nu - f_0^*(-A^T\lambda - C^T\nu).
\end{aligned}
\qquad (5.11)
```

$g$ 的 domain 由 $f_0^*$ 的 domain 给出：

```math
\operatorname{dom} g = \{(\lambda, \nu) \mid -A^T\lambda - C^T\nu \in \operatorname{dom} f_0^*\}.
```

我们用几个例子来说明这一点。

**Equality constrained norm minimization（带等式约束的范数最小化）**

考虑问题

```math
\begin{array}{ll}
\text{minimize} & \|x\| \\
\text{subject to} & Ax = b,
\end{array}
\qquad (5.12)
```



其中 $\|\cdot\|$ 是任意 norm（范数）。回忆（原书 p.93 的例 3.26）：$f_0 = \|\cdot\|$ 的 conjugate 由

```math
f_0^*(y) = \begin{cases} 0 & \|y\|_* \le 1 \\ \infty & \text{otherwise} \end{cases}
```

给出，即 dual norm unit ball（对偶范数单位球）的 indicator function。

用上面的结果 (5.11)，问题 (5.12) 的 dual function 由

```math
g(\nu) = -b^T\nu - f_0^*(-A^T\nu) = \begin{cases} -b^T\nu & \|A^T\nu\|_* \le 1 \\ -\infty & \text{otherwise} \end{cases}
```

给出。

**Entropy maximization（熵最大化）**

考虑 entropy maximization problem

```math
\begin{array}{ll}
\text{minimize} & f_0(x) = \sum_{i=1}^{n} x_i\log x_i \\
\text{subject to} & Ax \preceq b \\
& \mathbf{1}^T x = 1,
\end{array}
\qquad (5.13)
```

其中 $\operatorname{dom} f_0 = \mathbf{R}_{++}^n$。negative entropy function $u\log u$（标量变量 $u$）的 conjugate 为 $e^{v-1}$（见原书 p.91 的例 3.21）。由于 $f_0$ 是不同变量的 negative entropy function 之和，我们断定其 conjugate 为

```math
f_0^*(y) = \sum_{i=1}^{n} e^{y_i - 1},
```

其 $\operatorname{dom} f_0^* = \mathbf{R}^n$。用上面的结果 (5.11)，(5.13) 的 dual function 由

```math
g(\lambda, \nu) = -b^T\lambda - \nu - \sum_{i=1}^{n} e^{-a_i^T\lambda - \nu - 1} = -b^T\lambda - \nu - e^{-\nu-1}\sum_{i=1}^{n} e^{-a_i^T\lambda}
```

给出，其中 $a_i$ 是 $A$ 的第 $i$ 列。

**Minimum volume covering ellipsoid（最小体积覆盖椭球）**

考虑变量为 $X \in \mathbf{S}^n$ 的问题

```math
\begin{array}{ll}
\text{minimize} & f_0(X) = \log\det X^{-1} \\
\text{subject to} & a_i^T X a_i \le 1, \quad i = 1, \ldots, m,
\end{array}
\qquad (5.14)
```

其中 $\operatorname{dom} f_0 = \mathbf{S}_{++}^n$。问题 (5.14) 有一个简单的几何解释。



对每个 $X \in \mathbf{S}_{++}^n$，我们关联以原点为中心的椭球

```math
\mathcal{E}_X = \{z \mid z^T X z \le 1\}.
```

这个椭球的体积正比于 $(\det X^{-1})^{1/2}$，所以 (5.14) 的目标（除一个常数与因子二之外）就是 $\mathcal{E}_X$ 体积的对数。



问题 (5.14) 的约束是 $a_i \in \mathcal{E}_X$。因此问题 (5.14) 就是：求出包含点 $a_1, \ldots, a_m$ 的、以原点为中心的最小体积椭球。

问题 (5.14) 中的 inequality constraint 是 affine 的；它们可以写成

```math
\operatorname{\mathbf{tr}}(a_i a_i^T X) \le 1.
```

在例 3.23（原书 p.92）中我们求得 $f_0$ 的 conjugate 为

```math
f_0^*(Y) = \log\det(-Y)^{-1} - n,
```

其 $\operatorname{dom} f_0^* = -\mathbf{S}_{++}^n$。应用上面的结果 (5.11)，问题 (5.14) 的 dual function 由

```math
g(\lambda) = \begin{cases} \log\det\left(\sum_{i=1}^{m}\lambda_i a_i a_i^T\right) - \mathbf{1}^T\lambda + n & \sum_{i=1}^{m}\lambda_i a_i a_i^T \succ 0 \\ -\infty & \text{otherwise} \end{cases}
\qquad (5.15)
```

给出。因此，对任何满足 $\sum_{i=1}^{m}\lambda_i a_i a_i^T \succ 0$ 的 $\lambda \succeq 0$，数

```math
\log\det\left(\sum_{i=1}^{m}\lambda_i a_i a_i^T\right) - \mathbf{1}^T\lambda + n
```

都是问题 (5.14) 之 optimal value 的一个下界。

<span style="color:#1e8449;">**[译注]** (5.15) 值得单独验一遍符号，因为它是本章最容易抄错的一处。链条是：$f_0^*(Y) = \log\det(-Y)^{-1} - n$（例 3.23）代入 (5.11) 得 $g(\lambda) = -\mathbf{1}^T\lambda - f_0^*(-\sum_i\lambda_ia_ia_i^T)$，而 $-Y = \sum_i\lambda_ia_ia_i^T$ 是 **positive semidefinite 而非 negative definite**，所以必须先确认 $\sum_i\lambda_ia_ia_i^T \succ 0$ 才能用这个 conjugate——这正是 (5.15) 那个分段条件 $\sum_i\lambda_ia_ia_i^T \succ 0$ 的来历，而不是随手加的 regularizer。把 $\log\det(-Y)^{-1} = -\log\det(-Y)$ 里的负号提出来，两项负号相消，才得到正文的 $+\log\det(\sum_i\lambda_ia_ia_i^T)$。**抽掉「$\succ 0$ 才在 domain 内」这条会崩的地方**：dual function 在 $\sum_i\lambda_ia_ia_i^T$ 奇异处取值 $-\infty$，于是 dual problem 的可行域边界上会出现「目标跳变」；这也解释了为什么 dual problem 是 SDP 而不是无约束问题（$\succeq 0$ 是显式约束）。量纲检查建议：取 $m=1$、$a_1 = e_1$，此时 $\sum_i\lambda_ia_ia_i^T = \lambda_1e_1e_1^T$ 奇异，$g$ 应为 $-\infty$，与公式一致——这条最小反例能在 30 秒内验完。</span>

<span style="color:#1e8449;">**[译注]** §5.1.6 是整章「技术含量最高、但最容易被当成公式表背掉」的一节。要点只有一个：**对偶就是共轭的平移版**。看 (5.11) 最后一步 $g(\lambda,\nu) = -b^T\lambda - d^T\nu - f_0^*(-A^T\lambda - C^T\nu)$：$f_0^*$ 里的那个负号不是笔误，它来自 $\inf_x(\cdot) = -\sup_x(-(\cdot))$ 这一步；而 $f_0^*$ 的 argument 是 $-A^T\lambda - C^T\nu$，正好是「把约束的梯度按乘子加权求和再取负」。**抽掉这条恒等式会崩的地方**：① 你就无法快速写出任何 dual function——而 (5.11) 让「求对偶」变成「查一次 conjugate 表」，这是所有 practical duality 计算的做法；② §5.2.1 里「dual function 的 domain 很小、要显式写出隐含的等式约束」这个现象也无法解释——它正是 $f_0^*$ 的 domain 很窄（例如 norm 的 conjugate 只在 $\|y\|_*\le1$ 上有限）造成的。注意三个例子各展示了 conjugate 的一种「窄 domain」形态：norm → dual norm ball（有界），negative entropy → 全空间（$\mathbf{R}^n$），$\log\det X^{-1}$ → $-\mathbf{S}_{++}^n$（一个开锥）。跨学科落点：$f^*$ 的这套语言在 6.042J 里叫 Legendre 变换（热力学里叫 Legendre–Fenchel），在 Thomson 实分析里是「凸函数的支撑函数」；到了 §5.5 的 KKT，条件 $0 \in \partial f_0(x) + A^T\lambda + C^T\nu$ 就是 (5.11) 取到 inf 的 subgradient 版本。可点开的坐标：Boyd §3.3（conjugate 全表）、§5.1.6（本段）；一手来源是 Fenchel 1949 的 *On conjugate convex functions*（Canadian J. Math. 1, 73–77）。</span>

## 5.2 The Lagrange dual problem（Lagrange 对偶问题）

对每一对满足 $\lambda \succeq 0$ 的 $(\lambda,\nu)$，Lagrange dual function 都给出 optimization problem (5.1) 的 optimal value $p^\star$ 的一个下界。于是我们得到一族依赖参数 $\lambda,\nu$ 的下界。一个自然的问题是：从 Lagrange dual function 能得到的**最好**下界是什么？

这引出 optimization problem

```math
\begin{array}{ll}
\text{maximize} & g(\lambda, \nu) \\
\text{subject to} & \lambda \succeq 0.
\end{array}
\qquad (5.16)
```

这个问题称为与问题 (5.1) 关联的 Lagrange dual problem。在此语境下，原问题 (5.1) 有时称为 primal problem（原问题）。用 dual feasible 来描述满足 $\lambda \succeq 0$ 且 $g(\lambda,\nu) \gt -\infty$ 的 $(\lambda,\nu)$，现在就说得通了：顾名思义，它意味着 $(\lambda,\nu)$ 是 dual problem (5.16) 的 feasible point。若 $(\lambda,\nu)$ 是问题 (5.16) 的 optimal point，我们称之为 dual optimal 或 optimal Lagrange multipliers。

Lagrange dual problem (5.16) 是一个 convex optimization problem，因为要最大化的目标是 concave 的、约束是 convex 的。**这一点无论 primal problem (5.1) 是否 convex 都成立。**



### 5.2.1 Making dual constraints explicit（把对偶约束显式化）

上面的例子表明，dual function 的 domain

```math
\operatorname{dom} g = \{(\lambda, \nu) \mid g(\lambda, \nu) \gt -\infty\}
```

的维数小于 $m + p$ 是**不罕见**的。许多情形下我们可以识别出 $\operatorname{dom} g$ 的 affine hull，并把它描述成一组 linear equality constraint。粗略地说，这意味着我们可以识别出「隐藏在 dual problem (5.16) 的目标 $g$ 之中」的等式约束。此时我们可以构造一个等价问题，把这些等式约束显式地作为约束给出。下面的例子展示这一想法。

**Lagrange dual of standard form LP（标准形式 LP 的 Lagrange 对偶）**

在原书 p.219 我们求得标准形式 LP

```math
\begin{array}{ll}
\text{minimize} & c^T x \\
\text{subject to} & Ax = b \\
& x \succeq 0
\end{array}
\qquad (5.17)
```

的 Lagrange dual function 为

```math
g(\lambda, \nu) = \begin{cases} -b^T\nu & A^T\nu - \lambda + c = 0 \\ -\infty & \text{otherwise}. \end{cases}
```

严格说来，标准形式 LP 的 Lagrange dual problem 是：在 $\lambda \succeq 0$ 的约束下最大化这个 dual function $g$，即

```math
\begin{array}{ll}
\text{maximize} & g(\lambda, \nu) = \begin{cases} -b^T\nu & A^T\nu - \lambda + c = 0 \\ -\infty & \text{otherwise} \end{cases} \\
\text{subject to} & \lambda \succeq 0.
\end{array}
\qquad (5.18)
```

这里 $g$ 只在 $A^T\nu - \lambda + c = 0$ 时有限。我们可以把这些等式约束显式化，构造出等价问题：

```math
\begin{array}{ll}
\text{maximize} & -b^T\nu \\
\text{subject to} & A^T\nu - \lambda + c = 0 \\
& \lambda \succeq 0.
\end{array}
\qquad (5.19)
```

这个问题又可以写成

```math
\begin{array}{ll}
\text{maximize} & -b^T\nu \\
\text{subject to} & A^T\nu + c \succeq 0,
\end{array}
\qquad (5.20)
```

它是一个 inequality form 的 LP。

注意这三个问题之间的细微区别。标准形式 LP (5.17) 的 Lagrange dual 是问题 (5.18)，它与问题 (5.19)、(5.20) 等价（但**不同**）。在术语上有些滥用地说，我们把问题 (5.19) 或 (5.20) 称为标准形式 LP (5.17) 的 Lagrange dual。

**Lagrange dual of inequality form LP（不等式形式 LP 的 Lagrange 对偶）**

用类似方式，我们可以求出 inequality form 的 linear program 的 Lagrange dual problem：

```math
\begin{array}{ll}
\text{minimize} & c^T x \\
\text{subject to} & Ax \preceq b.
\end{array}
\qquad (5.21)
```

Lagrangian 为

```math
L(x, \lambda) = c^T x + \lambda^T(Ax - b) = -b^T\lambda + (A^T\lambda + c)^T x,
```

所以 dual function 为

```math
g(\lambda) = \inf_x L(x, \lambda) = -b^T\lambda + \inf_x (A^T\lambda + c)^T x.
```

线性函数的下确界为 $-\infty$，除非它恒为零，因此 dual function 为

```math
g(\lambda) = \begin{cases} -b^T\lambda & A^T\lambda + c = 0 \\ -\infty & \text{otherwise}. \end{cases}
```

dual variable $\lambda$ 是 dual feasible 的，当 $\lambda \succeq 0$ 且 $A^T\lambda + c = 0$。

LP (5.21) 的 Lagrange dual 是：在所有 $\lambda \succeq 0$ 上最大化 $g$。同样地，我们可以把这些 dual feasibility 条件显式地作为约束加入，重新表述为

```math
\begin{array}{ll}
\text{maximize} & -b^T\lambda \\
\text{subject to} & A^T\lambda + c = 0 \\
& \lambda \succeq 0,
\end{array}
\qquad (5.22)
```

它是一个 standard form 的 LP。

注意 standard form 与 inequality form 的 LP 及其对偶之间有有趣的对称性：standard form LP 的对偶是只有 inequality constraint 的 LP，反之亦然。还可以验证：(5.22) 的 Lagrange dual 就是（等价于）原问题 (5.21)。

<span style="color:#1e8449;">**[译注]** §5.2.1 的价值在于它消灭了一个常见的误会：「对偶函数的 domain 不是全部 $\mathbf{R}^{m+p}$，但这不是缺陷，而是**隐含的等式约束**」。机制很清楚：dual function 之所以在 $A^T\nu - \lambda + c \ne 0$ 时取 $-\infty$，是因为那时 $\inf_x$ 是一个非零的线性函数（线性函数只有恒零才有下界）。把这个「$-\infty$ 区域」显式写成等式约束，就得到 (5.19)——一个**干净的 LP**。**抽掉这一步会崩的地方**：你会把 (5.18) 这种「目标里带分段函数」的问题当成非标准形式，于是既写不出对偶的标准形，也无法做灵敏度分析；而实际上 (5.20) 与 (5.22) 才是有用的形态，它们让「standard form ↔ inequality form」的对称性浮出水面——这正是 **LP 对偶定理**的骨架：primary 的变量数 = dual 的约束数，primary 的约束数 = dual 的变量数。跨学科落点：这套「变量 ↔ 约束」的对应在 6.042J 的 LP duality 单元被反复演练（那里叫 primal/dual 互换），在 Strang 线代的四个基本子空间里对应 row space ↔ null space 的正交补关系（$A^T\nu + c = 0$ 就是「dual variable 必须落在 $A^T$ 的列空间里」）。可点开的坐标：Boyd §5.2.1（本段）与 §5.6.1（对偶的敏感性解释）；教材侧可对照 Bertsimas & Tsitsiklis *Introduction to Linear Optimization* (1997) 第 4 章。</span>

### 5.2.2 Weak duality（弱对偶）

Lagrange dual problem 的 optimal value 记作 $d^\star$，按定义它是由 Lagrange dual function 能得到的最好下界。特别地，我们有这条简单但重要的不等式

```math
d^\star \le p^\star,
\qquad (5.23)
```

它**即使在原问题非凸时也成立**。这条性质称为 weak duality（弱对偶）。

weak duality 不等式 (5.23) 在 $d^\star$ 与 $p^\star$ 取无穷值时也成立。例如，若 primal problem 下无界，即 $p^\star = -\infty$，则必有 $d^\star = -\infty$，即 Lagrange dual problem infeasible。反之，若 dual problem 上无界，即 $d^\star = \infty$，则必有 $p^\star = \infty$，即 primal problem infeasible。



我们把差 $p^\star - d^\star$ 称为原问题的 optimal duality gap（最优对偶间隙），因为它给出 primal problem 的 optimal value 与「由 Lagrange dual function 能得到的最好（即最大）下界」之间的间隙。optimal duality gap 总是非负的。

不等式 (5.23) 有时可用来给难解问题的 optimal value 找一个下界，因为 dual problem 总是 convex 的，且在很多情形下可以高效求解，从而求出 $d^\star$。作为例子，考虑原书 p.219 描述的 two-way partitioning problem (5.7)。其 dual problem 是一个 SDP

```math
\begin{array}{ll}
\text{maximize} & -\mathbf{1}^T\lambda \\
\text{subject to} & W + \operatorname{\mathbf{diag}}(\lambda) \succeq 0,
\end{array}
```

其 variable 为 $\lambda \in \mathbf{R}^n$。即使对相当大的 $n$（比如 $n = 1000$）这个问题也能高效求解。它的 optimal value 是 two-way partitioning problem 之 optimal value 的下界，且总是至少与基于 $\lambda_{\min}(W)$ 的下界 (5.8) 一样好。

### 5.2.3 Strong duality and Slater's constraint qualification（强对偶与 Slater 约束资格）

若等式

```math
d^\star = p^\star
\qquad (5.24)
```

成立，即 optimal duality gap 为零，我们就说 strong duality（强对偶）成立。这意味着由 Lagrange dual function 能得到的最好界是紧的。

strong duality 一般并不成立。但如果 primal problem (5.1) 是 convex 的，即形如

```math
\begin{array}{ll}
\text{minimize} & f_0(x) \\
\text{subject to} & f_i(x) \le 0, \quad i = 1, \ldots, m, \\
& Ax = b,
\end{array}
\qquad (5.25)
```

且 $f_0, \ldots, f_m$ 为 convex，则我们**通常**（但并非总是）有 strong duality。有许多结果给出了「在 convexity 之外还需要什么条件才能保证 strong duality」。这些条件称为 constraint qualifications（约束资格）。

一个简单的 constraint qualification 是 Slater's condition：存在 $x \in \operatorname{\mathbf{relint}} D$ 使

```math
f_i(x) \lt 0, \quad i = 1, \ldots, m, \qquad Ax = b.
\qquad (5.26)
```

这样的点有时称为 strictly feasible（严格可行），因为 inequality constraint 以严格不等式成立。Slater's theorem 指出：若 Slater's condition 成立（且问题是 convex 的），则 strong duality 成立。

当某些 inequality constraint function $f_i$ 是 affine 时，Slater's condition 可以放宽。若前 $k$ 个约束函数 $f_1, \ldots, f_k$ 是 affine 的，则只要下述更弱的条件成立，strong duality 就成立：存在 $x \in \operatorname{\mathbf{relint}} D$ 使

```math
f_i(x) \le 0, \; i = 1, \ldots, k, \qquad f_i(x) \lt 0, \; i = k+1, \ldots, m, \qquad Ax = b.
\qquad (5.27)
```

<span style="color:#1e8449;">**[译注]** §5.2.3 是整章最该下注的地方，因为「Slater 条件到底保证什么」这个问题有精确答案，而多数笔记只说「Slater 是充分条件」，把它答错了。精确答案是：**Slater 保证 duality gap 为零，且 dual optimal 被 attain（在凸问题下）**；它**不**保证 primal optimal 被 attain，也**不**是必要条件（很多问题上 gap 为零但没有 strictly feasible point）。为什么「strictly feasible」这一条这么关键？看证明思路：把 feasible set 与 epigraph 合成一个集合，用第 2 章的 **separating hyperplane theorem** 分离它；分离定理需要一个**内部非空**或至少相对内部有交的条件，否则超平面可能贴在所有点上而取不到非平凡的乘子。「$f_i(x) \lt 0$ 对所有 $i$」提供的正是这个「内部性」。**抽掉它（即只有 $f_i(x) \le 0$）会崩的地方**：反例是 §5.5.3 的「gap 不为零的凸问题」（两个相交圆盘上的最小范数点问题，$d^\star \lt p^\star$）——那里 feasible set 是一个线段，没有内部，分离定理只能给出退化的乘子，于是强对偶失效。另外要记住放宽版 (5.27) 为什么允许 affine 约束取等号：affine 函数的可行集自带相对内部，不需要严格不等式来「撑开」它。跨学科落点：这套「需要内部性的分离定理」正是 **Thomson 实分析**里 Hahn–Banach / 凸集分离定理的条件结构（要求凸集有非空内部），而 6.042J 的 LP duality 里它退化成「LP 只要 feasible 且 bounded 就强对偶」这一特例——LP 不需要 Slater，因为 polyhedron 结构太强。可点开的坐标：Boyd §5.2.3（本段）、§5.3.2（geometric interpretation，分离超平面的证明）、§5.5.3（gap 不为零的例子）；一手出处是 Slater 1950 的 *Lagrange multipliers revisited*（Cowles Commission Discussion Paper, Math. 403）与 Rockafellar *Convex Analysis* §28（relative interior 的作用）。可运行验证：对 (5.26) 的 strict feasibility 做数值检查——取 §5.5.3 的 intersecting disks 例子（$f_1(x) = \|x-a\|^2_2 - 1$、$f_2(x) = \|x-b\|^2_2-1$，$a=(1.73,1)$、$b=(-1.73,1)$），求 $\max_x\min_i(-f_i(x))$ 得 $0$（不可严格可行），而 dual optimal value 与 primal optimal value 之差约为 $0.13$，与 §5.5.3 给出的数一致。</span>



<!-- 书页 227 -->

换言之，那些 affine inequality 不必以严格不等号成立。注意：当所有 constraint 都是线性的 equality 与 inequality、且 $\mathbf{dom}\, f_0$ 是开集时，refined Slater condition (5.27) 退化为 feasibility。

Slater's condition（以及它的 refinement (5.27)）对凸问题不仅蕴含 strong duality。它还蕴含：当 $d^{\star} \gt -\infty$ 时 dual optimal value 会被取到，即存在 dual feasible 的 $(\lambda^{\star}, \nu^{\star})$ 使 $g(\lambda^{\star}, \nu^{\star}) = d^{\star} = p^{\star}$。「当 primal problem 为凸且 Slater's condition 成立时 strong duality 成立」这一点的证明放在 §5.3.2。

### 5.2.4 Examples（例子）

### Least-squares solution of linear equations（线性方程组的最小二乘解）

回忆问题 (5.5)：

```math
\begin{array}{ll}
\text{minimize} & x^T x \\
\text{subject to} & Ax = b.
\end{array}
```

与之相联系的 dual problem 是

```math
\text{maximize} \quad -(1/4)\nu^T A A^T \nu - b^T \nu,
```

这是一个无约束的 concave quadratic maximization problem。Slater's condition 在这里就是「primal problem 是 feasible 的」，于是只要 $b \in \mathcal{R}(A)$（即 $p^{\star} \lt \infty$）就有 $p^{\star} = d^{\star}$。事实上对这个问题的**恒**成立 strong duality，即使 $p^{\star} = \infty$ 也成立。$p^{\star} = \infty$ 出现在 $b \notin \mathcal{R}(A)$ 的情形，此时存在 $z$ 使 $A^T z = 0$、$b^T z \ne 0$。由此可知 dual function 沿直线 $\{ tz \mid t \in \mathbf{R} \}$ 无上界，于是也有 $d^{\star} = \infty$。

### Lagrange dual of LP（LP 的 Lagrange dual）

由 Slater's condition 的弱形式可得：任何 LP（standard form 或 inequality form）只要 primal problem 是 feasible 的，就成立 strong duality。把这个结果用到对偶问题上，可断言：只要 dual 是 feasible 的，LP 就成立 strong duality。这样就只剩下唯一一种 strong duality 对 LP 可能失败的情形：primal 与 dual **都** infeasible。这种病态情形事实上是可能出现的；见习题 5.23。

### Lagrange dual of QCQP（QCQP 的 Lagrange dual）

我们考虑 QCQP

```math
\begin{array}{ll}
\text{minimize} & (1/2) x^T P_0 x + q_0^T x + r_0 \\
\text{subject to} & (1/2) x^T P_i x + q_i^T x + r_i \le 0, \quad i = 1, \ldots, m,
\end{array}
\qquad (5.28)
```

其中 $P_0 \in \mathbf{S}^{n}_{++}$，$P_i \in \mathbf{S}^{n}_{+}$（$i = 1, \ldots, m$）。Lagrangian 是

```math
L(x, \lambda) = (1/2) x^T P(\lambda) x + q(\lambda)^T x + r(\lambda),
```

其中

```math
P(\lambda) = P_0 + \sum_{i=1}^{m} \lambda_i P_i, \qquad q(\lambda) = q_0 + \sum_{i=1}^{m} \lambda_i q_i, \qquad r(\lambda) = r_0 + \sum_{i=1}^{m} \lambda_i r_i.
```



<!-- 书页 228 -->

（QCQP 的 dual function 续）对一般的 $\lambda$ 也可以导出 $g(\lambda)$ 的表达式，但它相当复杂。不过当 $\lambda \succeq 0$ 时有 $P(\lambda) \succ 0$，于是

```math
g(\lambda) = \inf_x L(x, \lambda) = -(1/2) q(\lambda)^T P(\lambda)^{-1} q(\lambda) + r(\lambda).
```

因此可以把 dual problem 写成

```math
\begin{array}{ll}
\text{maximize} & -(1/2) q(\lambda)^T P(\lambda)^{-1} q(\lambda) + r(\lambda) \\
\text{subject to} & \lambda \succeq 0.
\end{array}
\qquad (5.29)
```

Slater condition 说的是：(5.29) 与 (5.28) 之间成立 strong duality，只要那些 quadratic inequality constraint 是 strictly feasible 的，即存在 $x$ 使

```math
(1/2) x^T P_i x + q_i^T x + r_i \lt 0, \quad i = 1, \ldots, m.
```

### Entropy maximization（熵最大化）

下一个例子是 entropy maximization problem (5.13)：

```math
\begin{array}{ll}
\text{minimize} & \sum_{i=1}^{n} x_i \log x_i \\
\text{subject to} & Ax \preceq b \\
& \mathbf{1}^T x = 1,
\end{array}
```

其 domain 为 $D = \mathbf{R}^n_{+}$。Lagrange dual function 已在原书 p.222 导出；dual problem 是

```math
\begin{array}{ll}
\text{maximize} & -b^T \lambda - \nu - e^{-\nu - 1} \sum_{i=1}^{n} e^{-a_i^T \lambda} \\
\text{subject to} & \lambda \succeq 0,
\end{array}
\qquad (5.30)
```

其 variable 是 $\lambda \in \mathbf{R}^m$、$\nu \in \mathbf{R}$。(5.13) 的（较弱形式的）Slater condition 告诉我们：只要存在 $x \succ 0$ 使 $Ax \preceq b$ 且 $\mathbf{1}^T x = 1$，optimal duality gap 就是零。

把 dual variable $\nu$ 解析地 maximize 掉，可以简化 dual problem (5.30)。固定 $\lambda$ 时，objective function 在它关于 $\nu$ 的导数为零处取到最大，即

```math
\nu = \log \sum_{i=1}^{n} e^{-a_i^T \lambda} - 1.
```

把这个最优的 $\nu$ 代回 dual problem，得到

```math
\begin{array}{ll}
\text{maximize} & -b^T \lambda - \log \left( \sum_{i=1}^{n} e^{-a_i^T \lambda} \right) \\
\text{subject to} & \lambda \succeq 0,
\end{array}
```

这是一个带 nonnegativity constraint 的 geometric program（取 convex form）。

### Minimum volume covering ellipsoid（最小体积覆盖椭球）

我们考虑问题 (5.14)：

```math
\begin{array}{ll}
\text{minimize} & \log \det X^{-1} \\
\text{subject to} & a_i^T X a_i \le 1, \quad i = 1, \ldots, m,
\end{array}
```



考虑标准形式 (4.1) 的优化问题：

```math
\begin{aligned}
\text{minimize}\quad & f_0(x)\\
\text{subject to}\quad & f_i(x)\le0,\quad i=1,\dots,m\\
& h_i(x)=0,\quad i=1,\dots,p,
\end{aligned} \tag{5.1}
```

变量 $x\in\mathbb{R}^n$。我们假设其定义域 $\mathcal{D}=\bigcap_{i=0}^m\mathbf{dom}\,f_i\cap\bigcap_{i=1}^p\mathbf{dom}\,h_i$ 非空，记 (5.1) 的最优值为 $p^\star$。我们不假设问题 (5.1) 凸。

Lagrangian duality（拉格朗日对偶）的基本想法是：把约束以约束函数的加权和加到目标函数上，从而把 (5.1) 的约束纳入考虑。我们定义与问题 (5.1) 相关联的 Lagrangian（拉格朗日函数）$L:\mathbb{R}^n\times\mathbb{R}^m\times\mathbb{R}^p\to\mathbb{R}$：

```math
L(x,\lambda,\nu)=f_0(x)+\sum_{i=1}^m\lambda_if_i(x)+\sum_{i=1}^p\nu_ih_i(x),
```

定义域 $\mathbf{dom}\,L=\mathcal{D}\times\mathbb{R}^m\times\mathbb{R}^p$。我们把 $\lambda_i$ 称为与第 $i$ 个不等式约束 $f_i(x)\le0$ 相关联的 Lagrange multiplier（拉格朗日乘子）；类似地 $\nu_i$ 称为与第 $i$ 个等式约束 $h_i(x)=0$ 相关联的拉格朗日乘子。向量 $\lambda$ 与 $\nu$ 称为与问题 (5.1) 相关联的 dual variables（对偶变量）或 Lagrange multiplier vectors（拉格朗日乘子向量）。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">5.1.2 The Lagrange dual function（拉格朗日对偶函数）</span>



我们定义 Lagrange dual function（拉格朗日对偶函数，或简称 dual function，对偶函数）$g:\mathbb{R}^m\times\mathbb{R}^p\to\mathbb{R}$ 为拉格朗日函数关于 $x$ 的最小值：对 $\lambda\in\mathbb{R}^m$、$\nu\in\mathbb{R}^p$，

```math
g(\lambda,\nu)=\inf_{x\in\mathcal{D}}L(x,\lambda,\nu)=\inf_{x\in\mathcal{D}}\Bigl(f_0(x)+\sum_{i=1}^m\lambda_if_i(x)+\sum_{i=1}^p\nu_ih_i(x)\Bigr).
```

当拉格朗日函数关于 $x$ 无下界时，对偶函数取值 $-\infty$。由于对偶函数是 $(\lambda,\nu)$ 的一族仿射函数的逐点下确界，它是 concave（凹）的——即使问题 (5.1) 不凸。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">5.1.3 Lower bounds on optimal value（最优值的下界）</span>

对偶函数给出问题 (5.1) 最优值 $p^\star$ 的下界：对任何 $\lambda\succeq0$ 与任何 $\nu$，

```math
g(\lambda,\nu)\le p^\star. \tag{5.2}
```

这个重要性质容易验证。设 $\tilde{x}$ 是问题 (5.1) 的可行点（即 $f_i(\tilde{x})\le0$、$h_i(\tilde{x})=0$），且 $\lambda\succeq0$。则

```math
\sum_{i=1}^m\lambda_if_i(\tilde{x})+\sum_{i=1}^p\nu_ih_i(\tilde{x})\le0,
```

因为第一个和中每项非正、第二个和中每项为零，于是

```math
L(\tilde{x},\lambda,\nu)=f_0(\tilde{x})+\sum_{i=1}^m\lambda_if_i(\tilde{x})+\sum_{i=1}^p\nu_ih_i(\tilde{x})\le f_0(\tilde{x}).
```

因此

```math
g(\lambda,\nu)=\inf_{x\in\mathcal{D}}L(x,\lambda,\nu)\le L(\tilde{x},\lambda,\nu)\le f_0(\tilde{x}).
```

由于 $g(\lambda,\nu)\le f_0(\tilde{x})$ 对每个可行点 $\tilde{x}$ 成立，不等式 (5.2) 得证。

<!-- p.230/231 -->

下界 (5.2) 见图 5.1（一个 $x\in\mathbb{R}$、单不等式约束的简单问题）。当 $g(\lambda,\nu)=-\infty$ 时，不等式 (5.2) 成立但 vacuous（空洞）。只有当 $\lambda\succeq0$ 且 $(\lambda,\nu)\in\mathbf{dom}\,g$（即 $g(\lambda,\nu)>-\infty$）时，对偶函数才给出 $p^\star$ 的 nontrivial lower bound（非平凡下界）。我们把满足 $\lambda\succeq0$ 且 $(\lambda,\nu)\in\mathbf{dom}\,g$ 的数对 $(\lambda,\nu)$ 称为 dual feasible（对偶可行）的——原因后面会明白。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">5.1.4 Linear approximation interpretation（线性近似解释）</span>



<!-- 书页 231 -->

的策略 $v$；这是另一个 convex optimization problem，其 objective 是 piecewise-linear（且 concave）的。把该问题的 optimal value 记作 $p^{\star}_2$。它是在「player 1 知道 player 2 的策略」的假定下，player 2 能保证拿到的最大 expected payoff。

直觉上很明显：知道对手的策略会带来优势（至少不会有害），而且确实可以轻易证明我们恒有 $p^{\star}_1 \ge p^{\star}_2$。差值 $p^{\star}_1 - p^{\star}_2$ 非负，可以解释为「知道对手策略」给一位 player 带来的优势。

借助 duality，我们可以建立一条初看令人惊讶的结果：$p^{\star}_1 = p^{\star}_2$。换言之，在带 mixed strategy 的 matrix game 中，知道对手的策略并没有好处。我们通过证明 (5.34) 与 (5.35) 互为 Lagrange dual problem、且其间成立 strong duality 来建立这条结果。

先把 (5.34) 写成 LP：

```math
\begin{array}{ll}
\text{minimize} & t \\
\text{subject to} & u \succeq 0, \quad \mathbf{1}^T u = 1 \\
& P^T u \preceq t \mathbf{1},
\end{array}
```

其中多引入了一个 variable $t \in \mathbf{R}$。对 $P^T u \preceq t\mathbf{1}$ 引入 multiplier $\lambda$，对 $u \succeq 0$ 引入 $\mu$，对 $\mathbf{1}^T u = 1$ 引入 $\nu$，Lagrangian 是

```math
t + \lambda^T (P^T u - t \mathbf{1}) - \mu^T u + \nu (1 - \mathbf{1}^T u) = \nu + (1 - \mathbf{1}^T \lambda) t + (P \lambda - \nu \mathbf{1} - \mu)^T u,
```

于是 dual function 为

```math
g(\lambda, \mu, \nu) =
\begin{cases}
\nu & \mathbf{1}^T \lambda = 1, \; P \lambda - \nu \mathbf{1} = \mu \\
-\infty & \text{otherwise}.
\end{cases}
```

Dual problem 于是是

```math
\begin{array}{ll}
\text{maximize} & \nu \\
\text{subject to} & \lambda \succeq 0, \quad \mathbf{1}^T \lambda = 1, \quad \mu \succeq 0 \\
& P \lambda - \nu \mathbf{1} = \mu.
\end{array}
```

消去 $\mu$，得到 (5.34) 的如下 Lagrange dual：

```math
\begin{array}{ll}
\text{maximize} & \nu \\
\text{subject to} & \lambda \succeq 0, \quad \mathbf{1}^T \lambda = 1 \\
& P \lambda \succeq \nu \mathbf{1},
\end{array}
```

其 variable 是 $\lambda$、$\nu$。但这显然等价于 (5.35)。由于这两个 LP 都是 feasible 的，故成立 strong duality；(5.34) 与 (5.35) 的 optimal value 相等。



拉格朗日函数与下界性质可以基于集合 $\{0\}$ 与 $-\mathbb{R}_+$ 的示性函数的 linear approximation（线性近似）给出简单解释。

先把原问题 (5.1) 重写为无约束问题：

```math
\text{minimize}\quad f_0(x)+\sum_{i=1}^mI_-(f_i(x))+\sum_{i=1}^pI_0(h_i(x)), \tag{5.3}
```

其中 $I_-:\mathbb{R}\to\mathbb{R}$ 是非正实数的示性函数：

```math
I_-(u)=\begin{cases}0 & u\le0\\ \infty & u>0,\end{cases}
```

类似地 $I_0$ 是 $\{0\}$ 的示性函数。在表述 (5.3) 中，函数 $I_-(u)$ 可以解释为表达我们对约束函数值 $u=f_i(x)$ 的 irritation（恼怒）或 displeasure（不快）：$f_i(x)\le0$ 时为零，$f_i(x)>0$ 时为无穷。类似地，$I_0(u)$ 给出我们对等式约束值 $u=h_i(x)$ 的不快。可以把 $I_-$ 想成「brick wall（砖墙）」或「infinitely hard（无限硬）」的不快函数：当 $f_i(x)$ 从非正变为正时，我们的不快从零跳到无穷。

现在在表述 (5.3) 中，把函数 $I_-(u)$ 替换为线性函数 $\lambda_iu$（$\lambda_i\ge0$），把 $I_0(u)$ 替换为 $\nu_iu$。目标变为拉格朗日函数 $L(x,\lambda,\nu)$，而对偶函数值 $g(\lambda,\nu)$ 是问题

```math
\text{minimize}\quad L(x,\lambda,\nu)=f_0(x)+\sum_{i=1}^m\lambda_if_i(x)+\sum_{i=1}^p\nu_ih_i(x) \tag{5.4}
```

的最优值。在这个表述中，我们用 linear 或「soft（软）」的不快函数代替 $I_-$ 与 $I_0$。对不等式约束，$f_i(x)=0$ 时不快为零，$f_i(x)>0$ 时不快为正（设 $\lambda_i>0$）；约束「违反得越多」不快越大。与原表述（任何非正的 $f_i(x)$ 都可接受）不同，在软表述中，我们从有 margin（裕量）的约束（即 $f_i(x)<0$）中实际上获得 pleasure（快感）。

显然用线性函数 $\lambda_iu$ 近似示性函数 $I_-(u)$ 相当粗糙。但线性函数至少是示性函数的 underestimator（低估器）。由于对所有 $u$ 有 $\lambda_iu\le I_-(u)$、$\nu_iu\le I_0(u)$，我们立即看到对偶函数给出原问题最优值的下界。



用「软」版本替换「硬」约束的想法在考虑 interior-point methods（内点法，§11.2.1）时会再次出现。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">5.1.5 Examples（例子）</span>

本节给出几个能推导拉格朗日对偶函数解析表达式的例子。

**线性方程组的最小二乘解。** 考虑问题

```math
\begin{aligned}
\text{minimize}\quad & x^Tx\\
\text{subject to}\quad & Ax=b,
\end{aligned} \tag{5.5}
```

其中 $A\in\mathbb{R}^{p\times n}$。此问题没有不等式约束，有 $p$ 个（线性）等式约束。拉格朗日函数为 $L(x,\nu)=x^Tx+\nu^T(Ax-b)$，定义域 $\mathbb{R}^n\times\mathbb{R}^p$。



对偶函数为 $g(\nu)=\inf_xL(x,\nu)$。由于 $L(x,\nu)$ 是 $x$ 的凸二次函数，可以从最优性条件 $\nabla_xL(x,\nu)=2x+A^T\nu=0$ 找到最小化点，得 $x=-(1/2)A^T\nu$。因此对偶函数为

```math
g(\nu)=L(-(1/2)A^T\nu,\nu)=-(1/4)\nu^TAA^T\nu-b^T\nu,
```

它是凹二次函数，定义域 $\mathbb{R}^p$。下界性质 (5.2) 陈述：对任何 $\nu\in\mathbb{R}^p$，

```math
-(1/4)\nu^TAA^T\nu-b^T\nu\le\inf\{x^Tx \mid Ax=b\}.
```

**标准形式 LP。** 考虑标准形式的 LP：

```math
\begin{aligned}
\text{minimize}\quad & c^Tx\\
\text{subject to}\quad & Ax=b\\
& x\succeq0,
\end{aligned} \tag{5.6}
```

它有不等式约束函数 $f_i(x)=-x_i$（$i=1,\dots,n$）。为构造拉格朗日函数，为 $n$ 个不等式约束引入乘子 $\lambda_i$、为等式约束引入乘子 $\nu_i$，得

```math
L(x,\lambda,\nu)=c^Tx-\sum_{i=1}^n\lambda_ix_i+\nu^T(Ax-b)=-b^T\nu+(c+A^T\nu-\lambda)^Tx.
```

对偶函数为

```math
g(\lambda,\nu)=\inf_xL(x,\lambda,\nu)=-b^T\nu+\inf_x(c+A^T\nu-\lambda)^Tx,
```

解析地容易确定，因为线性函数只在恒为零时有下界。于是 $g(\lambda,\nu)=-\infty$，除非 $c+A^T\nu-\lambda=0$，此时为 $-b^T\nu$：

```math
g(\lambda,\nu)=\begin{cases}-b^T\nu & A^T\nu-\lambda+c=0\\ -\infty & \text{否则}.\end{cases}
```

注意对偶函数 $g$ 只在 $\mathbb{R}^m\times\mathbb{R}^p$ 的一个 proper affine subset（真仿射子集）上有限。我们会看到这很常见。

<!-- p.233/234 -->

下界性质 (5.2) 只在 $\lambda$ 与 $\nu$ 满足 $\lambda\succeq0$ 与 $A^T\nu-\lambda+c=0$ 时非平凡。此时 $-b^T\nu$ 是 LP (5.6) 最优值的下界。

**双向划分问题。** 考虑（非凸）问题

```math
\begin{aligned}
\text{minimize}\quad & x^TWx\\
\text{subject to}\quad & x_i^2=1,\quad i=1,\dots,n,
\end{aligned} \tag{5.7}
```

其中 $W\in\mathbf{S}^n$。约束把 $x_i$ 限制为 $1$ 或 $-1$，所以问题等价于找分量为 $\pm1$ 的向量最小化 $x^TWx$。可行集有限（含 $2^n$ 个点），所以原则上可以通过检查每个可行点的目标值来求解。但可行点数指数增长，这只有小问题（比如 $n\le30$）可行。一般（比如 $n>50$）问题 (5.7) 非常难解。



可以把问题 (5.7) 解释为 $n$ 个元素集合（比如 $\{1,\dots,n\}$）上的 two-way partitioning problem（双向划分问题）：可行 $x$ 对应划分

```math
\{1,\dots,n\}=\{i \mid x_i=-1\}\cup\{i \mid x_i=1\}.
```

矩阵系数 $W_{ij}$ 可解释为元素 $i$ 与 $j$ 在同一划分的成本，$-W_{ij}$ 是 $i$ 与 $j$ 在不同划分的成本。(5.7) 的目标是所有元素对的总成本，问题 (5.7) 就是找总成本最小的划分。

现在推导此问题的对偶函数。拉格朗日函数为

```math
L(x,\nu)=x^TWx+\sum_{i=1}^n\nu_i(x_i^2-1)=x^T(W+\mathbf{diag}(\nu))x-\mathbf{1}^T\nu.
```

对 $x$ 最小化得拉格朗日对偶函数：

```math
g(\nu)=\inf_x\bigl(x^T(W+\mathbf{diag}(\nu))x-\mathbf{1}^T\nu\bigr)=\begin{cases}-\mathbf{1}^T\nu & W+\mathbf{diag}(\nu)\succeq0\\ -\infty & \text{否则}，\end{cases}
```

这里用了「二次型的下确界要么为零（型半正定时）要么为 $-\infty$（型非半正定时）」这一事实。

这个对偶函数给困难问题 (5.7) 的最优值提供下界。例如可取对偶变量的具体值

```math
\nu=-\lambda_{\min}(W)\mathbf{1},
```

它对偶可行，因为 $W+\mathbf{diag}(\nu)=W-\lambda_{\min}(W)I\succeq0$。这给出最优值 $p^\star$ 的界：

```math
p^\star\ge-\mathbf{1}^T\nu=n\lambda_{\min}(W). \tag{5.8}
```

<span style="color:#00838f;">**[注 5.1]** 这个 $p^\star$ 的下界也可以不用拉格朗日对偶函数得到。先把约束 $x_1^2=1,\dots,x_n^2=1$ 替换为 $\sum_{i=1}^nx_i^2=n$，得到修改的问题

```math
\begin{aligned}
\text{minimize}\quad & x^TWx\\
\text{subject to}\quad & \sum_{i=1}^nx_i^2=n.
\end{aligned} \tag{5.9}
```

原问题 (5.7) 的约束蕴含这里的约束，所以问题 (5.9) 的最优值是 (5.7) 最优值 $p^\star$ 的下界。而修改后的问题 (5.9) 容易作为 eigenvalue problem（特征值问题）求解，最优值为 $n\lambda_{\min}(W)$。



### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">5.1.6 The Lagrange dual function and conjugate functions（拉格朗日对偶函数与共轭函数）</span>

回顾 §3.3：函数 $f:\mathbb{R}^n\to\mathbb{R}$ 的 conjugate（共轭）$f^*$ 为

```math
f^*(y)=\sup_{x\in\mathbf{dom}\,f}\bigl(y^Tx-f(x)\bigr).
```

共轭函数与拉格朗日对偶函数密切相关。一个简单联系：考虑问题

```math
\begin{aligned}
\text{minimize}\quad & f(x)\\
\text{subject to}\quad & x=0
\end{aligned}
```

（不太有趣，一眼可解）。此问题的拉格朗日函数为 $L(x,\nu)=f(x)+\nu^Tx$，对偶函数为

```math
g(\nu)=\inf_x\bigl(f(x)+\nu^Tx\bigr)=-\sup_x\bigl((-\nu)^Tx-f(x)\bigr)=-f^*(-\nu).
```

更一般（也更有用）地，考虑带线性不等式与等式约束的优化问题：

```math
\begin{aligned}
\text{minimize}\quad & f_0(x)\\
\text{subject to}\quad & Ax\preceq b\\
& Cx=d.
\end{aligned} \tag{5.10}
```

用 $f_0$ 的共轭可以把问题 (5.10) 的对偶函数写为

```math
\begin{aligned}
g(\lambda,\nu)&=\inf_x\bigl(f_0(x)+\lambda^T(Ax-b)+\nu^T(Cx-d)\bigr)\\
&=-b^T\lambda-d^T\nu+\inf_x\bigl(f_0(x)+(A^T\lambda+C^T\nu)^Tx\bigr)\\
&=-b^T\lambda-d^T\nu-f_0^*(-A^T\lambda-C^T\nu). \tag{5.11}
\end{aligned}
```

$g$ 的定义域由 $f_0^*$ 的定义域得出：

```math
\mathbf{dom}\,g=\{(\lambda,\nu) \mid -A^T\lambda-C^T\nu\in\mathbf{dom}\,f_0^*\}.
```

用几个例子说明。

<!-- p.235/236 -->

**等式约束的范数最小化。** 考虑问题

```math
\begin{aligned}
\text{minimize}\quad & \|x\|\\
\text{subject to}\quad & Ax=b,
\end{aligned} \tag{5.12}
```

其中 $\|\cdot\|$ 是任意范数。回顾（例 3.26，第 93 页）$f_0=\|\cdot\|$ 的共轭为

```math
f_0^*(y)=\begin{cases}0 & \|y\|_*\le1\\ \infty & \text{否则}，\end{cases}
```

即对偶范数单位球的示性函数。用上面结果 (5.11)，问题 (5.12) 的对偶函数为

```math
g(\nu)=-b^T\nu-f_0^*(-A^T\nu)=\begin{cases}-b^T\nu & \|A^T\nu\|_*\le1\\ -\infty & \text{否则}.\end{cases}
```



**熵最大化。** 考虑 entropy maximization problem（熵最大化问题）

```math
\begin{aligned}
\text{minimize}\quad & f_0(x)=\sum_{i=1}^nx_i\log x_i\\
\text{subject to}\quad & Ax\preceq b\\
& \mathbf{1}^Tx=1
\end{aligned} \tag{5.13}
```

（$\mathbf{dom}\,f_0=\mathbb{R}^n_{++}$）。负熵函数 $u\log u$（标量变量 $u$）的共轭是 $e^{v-1}$（见例 3.21，第 91 页）。由于 $f_0$ 是不同变量的负熵函数之和，其共轭为

```math
f_0^*(y)=\sum_{i=1}^ne^{y_i-1},
```

$\mathbf{dom}\,f_0^*=\mathbb{R}^n$。用结果 (5.11)，(5.13) 的对偶函数为

```math
g(\lambda,\nu)=-b^T\lambda-\nu-\sum_{i=1}^ne^{-a_i^T\lambda-\nu-1}=-b^T\lambda-\nu-e^{-\nu-1}\sum_{i=1}^ne^{-a_i^T\lambda},
```

其中 $a_i$ 是 $A$ 的第 $i$ 列。

**最小体积覆盖椭球。** 考虑变量 $X\in\mathbf{S}^n$ 的问题：

```math
\begin{aligned}
\text{minimize}\quad & f_0(X)=\log\det X^{-1}\\
\text{subject to}\quad & a_i^TXa_i\le1,\quad i=1,\dots,m,
\end{aligned} \tag{5.14}
```

$\mathbf{dom}\,f_0=\mathbf{S}^n_{++}$。问题 (5.14) 有简单的几何解释：给每个 $X\in\mathbf{S}^n_{++}$ 关联以原点为中心的椭球 $\mathcal{E}_X=\{z \mid z^TXz\le1\}$。椭球体积正比于 $(\det X^{-1})^{1/2}$，所以 (5.14) 的目标（除常数与因子 2 外）是 $\mathcal{E}_X$ 体积的对数。

<!-- p.236/237 -->

问题 (5.14) 的约束是 $a_i\in\mathcal{E}_X$。因此问题 (5.14) 是确定以原点为中心、包含点 $a_1,\dots,a_m$ 的最小体积椭球。

问题 (5.14) 的不等式约束是仿射的；可表达为 $\mathbf{tr}\bigl((a_ia_i^T)X\bigr)\le1$。例 3.23（第 92 页）中已找到 $f_0$ 的共轭：

```math
f_0^*(Y)=\log\det(-Y)^{-1}-n,\qquad \mathbf{dom}\,f_0^*=-\mathbf{S}^n_{++}.
```

应用结果 (5.11)，问题 (5.14) 的对偶函数为

```math
g(\lambda)=\begin{cases}\log\det\bigl(\sum_{i=1}^m\lambda_ia_ia_i^T\bigr)-\mathbf{1}^T\lambda+n & \sum_{i=1}^m\lambda_ia_ia_i^T\succ0\\ -\infty & \text{否则}，\end{cases} \tag{5.15}
```



于是对任何满足 $\lambda\succeq0$ 且 $\sum_{i=1}^m\lambda_ia_ia_i^T\succ0$ 的 $\lambda$，数

```math
\log\det\Bigl(\sum_{i=1}^m\lambda_ia_ia_i^T\Bigr)-\mathbf{1}^T\lambda+n
```

是问题 (5.14) 最优值的下界。

## <span style="color:#c0392b;">5.2 The Lagrange dual problem（拉格朗日对偶问题）</span>

对每对满足 $\lambda\succeq0$ 的 $(\lambda,\nu)$，拉格朗日对偶函数给出优化问题 (5.1) 最优值 $p^\star$ 的下界。于是我们有了依赖参数 $\lambda,\nu$ 的下界。一个自然的问题是：从拉格朗日对偶函数能得到的最好下界是什么？这导出优化问题

```math
\begin{aligned}
\text{maximize}\quad & g(\lambda,\nu)\\
\text{subject to}\quad & \lambda\succeq0.
\end{aligned} \tag{5.16}
```

此问题称为与问题 (5.1) 相关联的 Lagrange dual problem（拉格朗日对偶问题）。在此语境下，原问题 (5.1) 有时称为 primal problem（原始问题/主问题）。描述满足 $\lambda\succeq0$ 且 $g(\lambda,\nu)>-\infty$ 的数对 $(\lambda,\nu)$ 的术语 dual feasible（对偶可行）现在说得通了：正如其名，它意味着 $(\lambda,\nu)$ 对对偶问题 (5.16) 可行。若 $(\lambda^\star,\nu^\star)$ 对问题 (5.16) 最优，我们称它们为 dual optimal（对偶最优）或 optimal Lagrange multipliers（最优拉格朗日乘子）。

拉格朗日对偶问题 (5.16) 是凸优化问题：要最大化的目标凹、约束凸。无论原始问题 (5.1) 是否凸都如此。



### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">5.2.1 Making dual constraints explicit（使对偶约束显式化）</span>

上面的例子表明：对偶函数的定义域

```math
\mathbf{dom}\,g=\{(\lambda,\nu) \mid g(\lambda,\nu)>-\infty\}
```

的维数小于 $m+p$ 并不少见。许多情形我们能识别 $\mathbf{dom}\,g$ 的仿射包，并把它描述为一组线性等式约束。粗略地说，这意味着我们能识别对偶问题 (5.16) 的目标 $g$ 中「隐藏」或「隐式」的等式约束。此时可以构造等价问题，把这些等式约束显式地作为约束给出。下面的例子演示这个想法。

**标准形式 LP 的拉格朗日对偶。** 第 219 页我们找到标准形式 LP

```math
\begin{aligned}
\text{minimize}\quad & c^Tx\\
\text{subject to}\quad & Ax=b\\
& x\succeq0
\end{aligned} \tag{5.17}
```

的拉格朗日对偶函数：

```math
g(\lambda,\nu)=\begin{cases}-b^T\nu & A^T\nu-\lambda+c=0\\ -\infty & \text{否则}.\end{cases}
```

严格地说，标准形式 LP 的拉格朗日对偶问题是：在 $\lambda\succeq0$ 下最大化这个对偶函数 $g$，即

```math
\begin{aligned}
\text{maximize}\quad & g(\lambda,\nu)=\begin{cases}-b^T\nu & A^T\nu-\lambda+c=0\\ -\infty & \text{否则}\end{cases}\\
\text{subject to}\quad & \lambda\succeq0.
\end{aligned} \tag{5.18}
```

这里 $g$ 只在 $A^T\nu-\lambda+c=0$ 时有限。可以构造等价问题，把这些等式约束显式化：

```math
\begin{aligned}
\text{maximize}\quad & -b^T\nu\\
\text{subject to}\quad & A^T\nu-\lambda+c=0\\
& \lambda\succeq0.
\end{aligned} \tag{5.19}
```

<!-- p.238/239 -->

这个问题又可以表达为

```math
\begin{aligned}
\text{maximize}\quad & -b^T\nu\\
\text{subject to}\quad & A^T\nu+c\succeq0,
\end{aligned} \tag{5.20}
```

是不等式形式的 LP。



注意这三个问题间的微妙区别。标准形式 LP (5.17) 的拉格朗日对偶是问题 (5.18)，它与 (5.19)、(5.20) 等价（但不相同）。稍微滥用术语，我们把问题 (5.19) 或 (5.20) 称为标准形式 LP (5.17) 的拉格朗日对偶。

**不等式形式 LP 的拉格朗日对偶。** 类似地可以找不等式形式线性规划

```math
\begin{aligned}
\text{minimize}\quad & c^Tx\\
\text{subject to}\quad & Ax\preceq b
\end{aligned} \tag{5.21}
```

的拉格朗日对偶问题。拉格朗日函数为

```math
L(x,\lambda)=c^Tx+\lambda^T(Ax-b)=-b^T\lambda+(A^T\lambda+c)^Tx,
```

所以对偶函数为

```math
g(\lambda)=\inf_xL(x,\lambda)=-b^T\lambda+\inf_x(A^T\lambda+c)^Tx.
```

线性函数的下确界为 $-\infty$，除非它恒为零，所以对偶函数为

```math
g(\lambda)=\begin{cases}-b^T\lambda & A^T\lambda+c=0\\ -\infty & \text{否则}.\end{cases}
```

对偶变量 $\lambda$ 对偶可行，若 $\lambda\succeq0$ 且 $A^T\lambda+c=0$。

LP (5.21) 的拉格朗日对偶是在所有 $\lambda\succeq0$ 上最大化 $g$。同样可以通过显式包含对偶可行性条件重新表述：

```math
\begin{aligned}
\text{maximize}\quad & -b^T\lambda\\
\text{subject to}\quad & A^T\lambda+c=0\\
& \lambda\succeq0,
\end{aligned} \tag{5.22}
```

它是标准形式的 LP。

注意标准形式与不等式形式 LP 及其对偶之间有趣的对称性：标准形式 LP 的对偶是只有不等式约束的 LP，反之亦然。还可以验证 (5.22) 的拉格朗日对偶（等价于）原问题 (5.21)。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">5.2.2 Weak duality（弱对偶性）</span>

<!-- p.239/240 -->

拉格朗日对偶问题的最优值记作 $d^\star$，按定义它是从拉格朗日对偶函数能得到的 $p^\star$ 的最好下界。特别地，有简单而重要的不等式

```math
d^\star\le p^\star, \tag{5.23}
```

即使原问题不凸也成立。这个性质称为 weak duality（弱对偶性）。

弱对偶不等式 (5.23) 在 $d^\star$、$p^\star$ 为无穷时也成立。例如若原始问题无下界（$p^\star=-\infty$），则必有 $d^\star=-\infty$，即拉格朗日对偶问题不可行。反之若对偶问题无上界（$d^\star=\infty$），则必有 $p^\star=\infty$，即原始问题不可行。



我们把差 $p^\star-d^\star$ 称为原问题的 optimal duality gap（最优对偶间隙），它给出原始问题最优值与从拉格朗日对偶函数能得到的最好（即最大）下界之间的 gap（间隙）。最优对偶间隙总是非负。

界 (5.23) 有时可用于给难解问题的最优值找下界，因为对偶问题总是凸的，许多情形能高效求解得到 $d^\star$。例如考虑第 219 页描述的双向划分问题 (5.7)。其对偶问题是 SDP：

```math
\begin{aligned}
\text{maximize}\quad & -\mathbf{1}^T\nu\\
\text{subject to}\quad & W+\mathbf{diag}(\nu)\succeq0,
\end{aligned}
```

变量 $\nu\in\mathbb{R}^n$。这个问题即使 $n$ 相当大（如 $n=1000$）也能高效求解。其最优值是双向划分问题最优值的下界，且总不差于基于 $\lambda_{\min}(W)$ 的下界 (5.8)。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">5.2.3 Strong duality and Slater's constraint qualification（强对偶性与 Slater 约束规格）</span>

若等式

```math
d^\star=p^\star \tag{5.24}
```

成立（即最优对偶间隙为零），则称 strong duality（强对偶性）成立。这意味着从拉格朗日对偶函数能得到的最好界是 tight（紧的）。

强对偶性一般不成立。但若原始问题 (5.1) 凸，即形如

```math
\begin{aligned}
\text{minimize}\quad & f_0(x)\\
\text{subject to}\quad & f_i(x)\le0,\quad i=1,\dots,m,\\
& Ax=b
\end{aligned} \tag{5.25}
```

（$f_0,\dots,f_m$ 凸），我们通常（但非总是）有强对偶性。有许多结果确立凸性之外、使强对偶性成立的条件。这些条件称为 constraint qualifications（约束规格）。一个简单的约束规格是 Slater's condition（Slater 条件）：存在 $x\in\mathbf{relint}\,\mathcal{D}$ 使

```math
f_i(x)<0,\quad i=1,\dots,m,\qquad Ax=b. \tag{5.26}
```

这样的点有时称为 strictly feasible（严格可行）的，因为不等式约束以严格不等号成立。Slater's theorem（Slater 定理）陈述：若 Slater 条件成立（且问题凸），则强对偶性成立。

当某些不等式约束函数 $f_i$ 是仿射时，Slater 条件可以精化。若前 $k$ 个约束函数 $f_1,\dots,f_k$ 仿射，则只要下面较弱的条件成立强对偶性就成立：存在 $x\in\mathbf{relint}\,\mathcal{D}$ 使

```math
\begin{aligned}
f_i(x)\le0,&\quad i=1,\dots,k,\\
f_i(x)<0,&\quad i=k+1,\dots,m,\\
Ax=b.&\end{aligned} \tag{5.27}
```

<!-- p.240/241 -->

换言之，仿射不等式不需要严格成立。注意当约束全是线性等式与不等式、且 $\mathbf{dom}\,f_0$ 开时，精化的 Slater 条件 (5.27) 退化为可行性。



Slater 条件（及精化 (5.27)）不仅蕴含凸问题的强对偶性，还蕴含：当 $d^\star>-\infty$ 时对偶最优值被达到，即存在对偶可行的 $(\lambda^\star,\nu^\star)$ 使 $g(\lambda^\star,\nu^\star)=d^\star=p^\star$。我们将在 §5.3.2 证明：当原始问题凸且 Slater 条件成立时强对偶性成立。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">5.2.4 Examples（例子）</span>

**线性方程组的最小二乘解。** 回顾问题 (5.5)：$\min x^Tx\ \text{s.t.}\ Ax=b$。相应的对偶问题是

```math
\text{maximize}\quad -(1/4)\nu^TAA^T\nu-b^T\nu,
```

是无约束的凹二次最大化问题。Slater 条件就是原始问题可行，所以只要 $b\in\mathcal{R}(A)$（即 $p^\star<\infty$）就有 $p^\star=d^\star$。事实上这个问题总有强对偶性，即使 $p^\star=\infty$：那是 $b\notin\mathcal{R}(A)$ 的情形，此时存在 $z$ 使 $A^Tz=0$、$b^Tz\neq0$，于是对偶函数沿直线 $\{tz \mid t\in\mathbb{R}\}$ 无上界，故 $d^\star=\infty$。

**LP 的拉格朗日对偶。** 由 Slater 条件的较弱形式：对任何 LP（标准或不等式形式），只要原始问题可行就有强对偶性。把这个结果应用到对偶上，得出：只要对偶可行，LP 强对偶性成立。这只剩下强对偶性可能失效的一种情形：原始与对偶问题都不可行。这种 pathological case（病态情形）确实可能发生；见习题 5.23。

<!-- p.241/242 -->

**QCQP 的拉格朗日对偶。** 考虑 QCQP

```math
\begin{aligned}
\text{minimize}\quad & (1/2)x^TP_0x+q_0^Tx+r_0\\
\text{subject to}\quad & (1/2)x^TP_ix+q_i^Tx+r_i\le0,\quad i=1,\dots,m,
\end{aligned} \tag{5.28}
```

$P_0\in\mathbf{S}^n_{++}$，$P_i\in\mathbf{S}^n_+$（$i=1,\dots,m$）。拉格朗日函数为

```math
L(x,\lambda)=(1/2)x^TP(\lambda)x+q(\lambda)^Tx+r(\lambda),
```

其中

```math
P(\lambda)=P_0+\sum_{i=1}^m\lambda_iP_i,\qquad q(\lambda)=q_0+\sum_{i=1}^m\lambda_iq_i,\qquad r(\lambda)=r_0+\sum_{i=1}^m\lambda_ir_i.
```



对一般的 $\lambda$ 可以推导 $g(\lambda)$ 的表达式，但相当复杂。不过若 $\lambda\succeq0$，则 $P(\lambda)\succ0$，且

```math
g(\lambda)=\inf_xL(x,\lambda)=-(1/2)q(\lambda)^TP(\lambda)^{-1}q(\lambda)+r(\lambda).
```

因此可以把对偶问题表达为

```math
\begin{aligned}
\text{maximize}\quad & -(1/2)q(\lambda)^TP(\lambda)^{-1}q(\lambda)+r(\lambda)\\
\text{subject to}\quad & \lambda\succeq0.
\end{aligned} \tag{5.29}
```

Slater 条件说：若二次不等式约束严格可行，即存在 $x$ 使 $(1/2)x^TP_ix+q_i^Tx+r_i<0$（$i=1,\dots,m$），则 (5.29) 与 (5.28) 之间强对偶性成立。

**熵最大化。** 下一个例子是熵最大化问题 (5.13)：$\min\sum_{i=1}^nx_i\log x_i\ \text{s.t.}\ Ax\preceq b,\ \mathbf{1}^Tx=1$，定义域 $\mathcal{D}=\mathbb{R}^n_+$。拉格朗日对偶函数已在第 222 页推导；对偶问题为

```math
\begin{aligned}
\text{maximize}\quad & -b^T\lambda-\nu-e^{-\nu-1}\sum_{i=1}^ne^{-a_i^T\lambda}\\
\text{subject to}\quad & \lambda\succeq0,
\end{aligned} \tag{5.30}
```

变量 $\lambda\in\mathbb{R}^m$、$\nu\in\mathbb{R}$。(5.13) 的（较弱）Slater 条件告诉我们：若存在 $x\succ0$ 满足 $Ax\preceq b$ 与 $\mathbf{1}^Tx=1$，则最优对偶间隙为零。

可以对偶变量 $\nu$ 解析地最大化来简化对偶问题 (5.30)。固定 $\lambda$，目标函数在关于 $\nu$ 的导数为零时最大：

```math
\nu=\log\sum_{i=1}^ne^{-a_i^T\lambda}-1.
```

把这个 $\nu$ 的最优值代入对偶问题得

```math
\begin{aligned}
\text{maximize}\quad & -b^T\lambda-\log\Bigl(\sum_{i=1}^ne^{-a_i^T\lambda}\Bigr)\\
\text{subject to}\quad & \lambda\succeq0,
\end{aligned}
```

这是带非负性约束的 geometric program（几何规划，凸形式）。

<!-- p.242/243 -->

**最小体积覆盖椭球。** 考虑问题 (5.14)：$\min\log\det X^{-1}\ \text{s.t.}\ a_i^TXa_i\le1$（$i=1,\dots,m$），定义域 $\mathcal{D}=\mathbf{S}^n_{++}$。拉格朗日对偶函数由 (5.15) 给出，所以对偶问题可表达为

```math
\begin{aligned}
\text{maximize}\quad & \log\det\Bigl(\sum_{i=1}^m\lambda_ia_ia_i^T\Bigr)-\mathbf{1}^T\lambda+n\\
\text{subject to}\quad & \lambda\succeq0
\end{aligned} \tag{5.31}
```



（当 $X\not\succ0$ 时取 $\log\det X=-\infty$）。问题 (5.14) 的（较弱）Slater 条件是存在 $X\in\mathbf{S}^n_{++}$ 使 $a_i^TXa_i\le1$（$i=1,\dots,m$）。这总满足，所以 (5.14) 与对偶问题 (5.31) 之间强对偶性总成立。

**有强对偶性的非凸二次问题。** 在罕见情形下非凸问题也有强对偶性。一个重要例子：在单位球上最小化非凸二次函数：

```math
\begin{aligned}
\text{minimize}\quad & x^TAx+2b^Tx\\
\text{subject to}\quad & x^Tx\le1,
\end{aligned} \tag{5.32}
```

$A\in\mathbf{S}^n$、$A\not\succeq0$、$b\in\mathbb{R}^n$。由于 $A\not\succeq0$，这不是凸问题。这个问题有时称为 trust region problem（信赖域问题），出现在「在单位球上（假设近似在该区域内大致有效）最小化函数的二阶近似」中。

拉格朗日函数为

```math
L(x,\lambda)=x^TAx+2b^Tx+\lambda(x^Tx-1)=x^T(A+\lambda I)x+2b^Tx-\lambda,
```

所以对偶函数为

```math
g(\lambda)=\begin{cases}-b^T(A+\lambda I)^\dagger b-\lambda & A+\lambda I\succeq0,\ b\in\mathcal{R}(A+\lambda I)\\ -\infty & \text{otherwise},\end{cases}
```

其中 $(A+\lambda I)^\dagger$ 是 $A+\lambda I$ 的伪逆。因此拉格朗日对偶问题为

```math
\begin{aligned}
\text{maximize}\quad & -b^T(A+\lambda I)^\dagger b-\lambda\\
\text{subject to}\quad & A+\lambda I\succeq0,\quad b\in\mathcal{R}(A+\lambda I),
\end{aligned} \tag{5.33}
```

变量 $\lambda\in\mathbb{R}$。虽然从这个表达式看不出来，这是一个凸优化问题。事实上它容易求解，因为可表达为

```math
\begin{aligned}
\text{maximize}\quad & -\sum_{i=1}^n(q_i^Tb)^2/(\lambda_i+\lambda)-\lambda\\
\text{subject to}\quad & \lambda\ge-\lambda_{\min}(A),
\end{aligned}
```

其中 $\lambda_i$ 与 $q_i$ 是 $A$ 的特征值与相应（正交归一）特征向量，且当 $q_i^Tb=0$ 时 $(q_i^Tb)^2/0$ 解释为 0，否则为 $\infty$。

<!-- p.243/244 -->

尽管原问题 (5.32) 不凸，此问题的最优对偶间隙总为零：问题 (5.32) 与 (5.33) 的最优值总是相同。事实上更一般的结果成立：对任何「二次目标 + 一个二次不等式约束」的优化问题，只要 Slater 条件成立，强对偶性成立；见 §B.1。



### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">5.2.5 Mixed strategies for matrix games（矩阵博弈的混合策略）</span>

本节用强对偶性推导 zero-sum matrix games（零和矩阵博弈）的一个基本结果。考虑两人博弈：玩家 1 选择（走子）$k\in\{1,\dots,n\}$，玩家 2 选择 $l\in\{1,\dots,m\}$。然后玩家 1 向玩家 2 支付 $P_{kl}$，$P\in\mathbb{R}^{n\times m}$ 是博弈的 payoff matrix（支付矩阵）。玩家 1 的目标是支付尽量小，玩家 2 的目标是最大化支付。

玩家使用 randomized 或 mixed strategies（随机化或混合策略）：每个玩家按概率分布随机、独立地选择：

```math
\mathrm{prob}(k=i)=u_i,\ i=1,\dots,n;\qquad \mathrm{prob}(l=i)=v_i,\ i=1,\dots,m.
```

这里 $u$ 与 $v$ 给出两个玩家选择的概率分布，即其相应的 strategies（策略）。玩家 1 向玩家 2 的 expected payoff（期望支付）为

```math
\sum_{k=1}^n\sum_{l=1}^mu_kv_lP_{kl}=u^TPv.
```

玩家 1 想选 $u$ 最小化 $u^TPv$，玩家 2 想选 $v$ 最大化 $u^TPv$。

先从玩家 1 的角度分析博弈，假设她的策略 $u$ 被玩家 2 知道（显然给玩家 2 优势）。玩家 2 会选 $v$ 最大化 $u^TPv$，产生期望支付

```math
\sup\{u^TPv \mid v\succeq0,\ \mathbf{1}^Tv=1\}=\max_{i=1,\dots,m}(P^Tu)_i.
```

玩家 1 能做的最好是选 $u$ 最小化这个最坏情况支付，即选策略 $u$ 求解问题

```math
\begin{aligned}
\text{minimize}\quad & \max_{i=1,\dots,m}(P^Tu)_i\\
\text{subject to}\quad & u\succeq0,\quad \mathbf{1}^Tu=1,
\end{aligned} \tag{5.34}
```

它是分段线性凸优化问题。记其最优值为 $p_1^\star$。这是玩家 1 能安排的最小期望支付——假设玩家 2 知道玩家 1 的策略并按自己最大优势行动。

<!-- p.244/245 -->

类似地可以考虑玩家 2 的策略 $v$ 被玩家 1 知道的情形（给玩家 1 优势）。此时玩家 1 选 $u$ 最小化 $u^TPv$，产生期望支付

```math
\inf\{u^TPv \mid u\succeq0,\ \mathbf{1}^Tu=1\}=\min_{i=1,\dots,n}(Pv)_i.
```

玩家 2 选 $v$ 最大化它，即选策略 $v$ 求解问题

```math
\begin{aligned}
\text{maximize}\quad & \min_{i=1,\dots,n}(Pv)_i\\
\text{subject to}\quad & v\succeq0,\quad \mathbf{1}^Tv=1,
\end{aligned} \tag{5.35}
```



这是另一个凸优化问题，目标分段线性（凹）。记其最优值为 $p_2^\star$。这是玩家 2 能保证获得的最大期望支付——假设玩家 1 知道玩家 2 的策略。

直觉上显然：知道对手的策略有优势（至少不会有害），而且容易证明总有 $p_1^\star\ge p_2^\star$。可以把差 $p_1^\star-p_2^\star$（非负）解释为「知道对手策略」赋予玩家的优势。

用对偶性可以建立一个初看令人惊讶的结果：$p_1^\star=p_2^\star$。换言之，在带混合策略的矩阵博弈中，知道对手的策略没有优势。我们将通过证明问题 (5.34) 与 (5.35) 是强对偶性成立的拉格朗日对偶问题来确立这个结果。

先把 (5.34) 表述为 LP：

```math
\begin{aligned}
\text{minimize}\quad & t\\
\text{subject to}\quad & u\succeq0,\quad \mathbf{1}^Tu=1\\
& P^Tu\preceq t\mathbf{1},
\end{aligned}
```

额外变量 $t\in\mathbb{R}$。为 $P^Tu\preceq t\mathbf{1}$ 引入乘子 $\lambda$、为 $u\succeq0$ 引入 $\mu$、为 $\mathbf{1}^Tu=1$ 引入 $\nu$，拉格朗日函数为

```math
t+\lambda^T(P^Tu-t\mathbf{1})-\mu^Tu+\nu(1-\mathbf{1}^Tu)=\nu+(1-\mathbf{1}^T\lambda)t+(P\lambda-\nu\mathbf{1}-\mu)^Tu,
```

所以对偶函数为

```math
g(\lambda,\mu,\nu)=\begin{cases}\nu & \mathbf{1}^T\lambda=1,\ P\lambda-\nu\mathbf{1}=\mu\\ -\infty & \text{否则}.\end{cases}
```

对偶问题为

```math
\begin{aligned}
\text{maximize}\quad & \nu\\
\text{subject to}\quad & \lambda\succeq0,\ \mathbf{1}^T\lambda=1,\ \mu\succeq0\\
& P\lambda-\nu\mathbf{1}=\mu.
\end{aligned}
```

消去 $\mu$ 得 (5.34) 的拉格朗日对偶：

```math
\begin{aligned}
\text{maximize}\quad & \nu\\
\text{subject to}\quad & \lambda\succeq0,\ \mathbf{1}^T\lambda=1\\
& P\lambda\succeq\nu\mathbf{1},
\end{aligned}
```

变量 $\lambda,\nu$。但显然它等价于 (5.35)。由于 LP 可行，强对偶性成立：问题 (5.34) 与 (5.35) 的最优值相等。

> <span style="color:#2471a3;">**[译者注｜跨课程连接]** 本节的 minimax 定理是博弈论的基石，也直接通向 CLRS 里「随机算法对最坏情况输入的期望性能」的思想：先手劣势 = 弱对偶间隙 = $p_1^\star-p_2^\star$，而混合策略使间隙归零。</span>

## <span style="color:#c0392b;">5.3 Geometric interpretation（几何解释）</span>

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">5.3.1 Weak and strong duality via set of values（借助值集合的弱与强对偶）</span>



可以用集合

```math
\mathcal{G}=\{(f_1(x),\dots,f_m(x),\,h_1(x),\dots,h_p(x),\,f_0(x))\in\mathbb{R}^m\times\mathbb{R}^p\times\mathbb{R} \mid x\in\mathcal{D}\} \tag{5.36}
```

（约束与目标函数取值的集合）给出对偶函数的简单几何解释。(5.1) 的最优值 $p^\star$ 用 $\mathcal{G}$ 容易表达为

```math
p^\star=\inf\{t \mid (u,v,t)\in\mathcal{G},\ u\preceq0,\ v=0\}.
```

求对偶函数在 $(\lambda,\nu)$ 处的值，就是在 $(u,v,t)\in\mathcal{G}$ 上最小化仿射函数

```math
(\lambda,\nu,1)^T(u,v,t)=\sum_{i=1}^m\lambda_iu_i+\sum_{i=1}^p\nu_iv_i+t,
```

即

```math
g(\lambda,\nu)=\inf\{(\lambda,\nu,1)^T(u,v,t) \mid (u,v,t)\in\mathcal{G}\}.
```

特别地，若下确界有限，则不等式

```math
(\lambda,\nu,1)^T(u,v,t)\ge g(\lambda,\nu)
```

定义 $\mathcal{G}$ 的一个支撑超平面。这有时称为 nonvertical supporting hyperplane（非竖直支撑超平面），因为法向量的最后一个分量非零。

<!-- p.246/247 -->

现在设 $\lambda\succeq0$。则显然：若 $u\preceq0$、$v=0$，有 $t\ge(\lambda,\nu,1)^T(u,v,t)$。因此

```math
\begin{aligned}
p^\star&=\inf\{t \mid (u,v,t)\in\mathcal{G},\ u\preceq0,\ v=0\}\\
&\ge \inf\{(\lambda,\nu,1)^T(u,v,t) \mid (u,v,t)\in\mathcal{G},\ u\preceq0,\ v=0\}\\
&\ge \inf\{(\lambda,\nu,1)^T(u,v,t) \mid (u,v,t)\in\mathcal{G}\}\\
&= g(\lambda,\nu),
\end{aligned}
```

即得到弱对偶性。这个解释见图 5.3 与 5.4（单不等式约束的简单问题）。

<!-- p.247/248 -->

**上图变体。** 本节描述基于 $\mathcal{G}$ 的对偶几何解释的一个变体，它解释了为什么（大多数）凸问题有强对偶性。定义集合 $\mathcal{A}\subseteq\mathbb{R}^m\times\mathbb{R}^p\times\mathbb{R}$：

```math
\mathcal{A}=\mathcal{G}+\bigl(\mathbb{R}^m_+\times\{0\}\times\mathbb{R}_+\bigr), \tag{5.37}
```

更显式地：

```math
\mathcal{A}=\{(u,v,t) \mid \exists x\in\mathcal{D},\ f_i(x)\le u_i,\ i=1,\dots,m,\ h_i(x)=v_i,\ i=1,\dots,p,\ f_0(x)\le t\}.
```



<!-- 书页 247 -->

[Figure 5.9：方块-弹簧系统的受力分析。每个方块所受的总力（来自弹簧以及接触力）必须为零。图上方示出的 Lagrange multiplier 是墙与方块之间的 contact force（接触力），下方示出的是弹簧力。图中标注：左块上的 $\lambda_1$ 与 $k_1 x_1$，两方块之间的 $\lambda_2$、$k_2(x_2 - x_1)$，右块上的 $\lambda_2$、$\lambda_3$ 与 $k_3(l - x_2)$。]

这些约束称为 kinematic constraint（运动学约束），它们表达的是：方块宽度为 $w \gt 0$，且不能互相穿透、也不能穿透墙壁。因此 equilibrium position 由下面这个 optimization problem 的解给出：

```math
\begin{array}{ll}
\text{minimize} & (1/2)\left( k_1 x_1^2 + k_2 (x_2 - x_1)^2 + k_3 (l - x_2)^2 \right) \\
\text{subject to} & w/2 - x_1 \le 0 \\
& w + x_1 - x_2 \le 0 \\
& w/2 - l + x_2 \le 0,
\end{array}
\qquad (5.52)
```

这是一个 QP。

以 $\lambda_1, \lambda_2, \lambda_3$ 为 Lagrange multiplier，该问题的 KKT 条件包括：kinematic constraint (5.51)、nonnegativity constraint $\lambda_i \ge 0$、complementary slackness 条件

```math
\lambda_1 (w/2 - x_1) = 0, \quad \lambda_2 (w - x_2 + x_1) = 0, \quad \lambda_3 (w/2 - l + x_2) = 0,
\qquad (5.53)
```

以及 zero gradient 条件

```math
\begin{bmatrix} k_1 x_1 - k_2 (x_2 - x_1) \\ k_2 (x_2 - x_1) - k_3 (l - x_2) \end{bmatrix} + \lambda_1 \begin{bmatrix} -1 \\ 0 \end{bmatrix} + \lambda_2 \begin{bmatrix} 1 \\ -1 \end{bmatrix} + \lambda_3 \begin{bmatrix} 0 \\ 1 \end{bmatrix} = 0.
\qquad (5.54)
```

只要我们把 Lagrange multiplier 解释为墙与方块之间作用的 contact force（接触力），方程 (5.54) 就可以解释为两个方块的力平衡方程，如 Figure 5.9 所示。第一个方程说的是第一个方块上诸力之和为零：项 $-k_1 x_1$ 是左弹簧作用在左方块上的力，项 $k_2 (x_2 - x_1)$ 是中间弹簧作用的力，$\lambda_1$ 是左壁作用的力，而 $-\lambda_2$ 是右方块作用的力。Contact force 必须背离接触面（如 constraint $\lambda_1 \ge 0$ 与 $-\lambda_2 \le 0$ 所表达的），且只在有接触时非零（如前两条 complementary slackness 条件 (5.53) 所表达的）。类似地，(5.54) 的第二个方程是第二个方块的力平衡，而 (5.53) 的最后一个条件说明：除非右方块贴到墙上，否则 $\lambda_3$ 为零。

在这个例子里，potential energy 与 kinematic constraint function 都是凸的，而（精化形式的）Slater's constraint qualification 只要 $2w \le l$ 就成立，即两壁之间的空间足以容纳两个方块；于是可以断言：由 (5.52) 给出的 equilibrium 的能量表述，与由 KKT 条件给出的力平衡表述，给出相同的结果。

用 $\mathcal{A}$ 可以把最优值表达为

```math
p^\star=\inf\{t \mid (0,0,t)\in\mathcal{A}\}.
```

在点 $(\lambda,\nu)$（$\lambda\succeq0$）处求对偶函数，可以在 $\mathcal{A}$ 上最小化仿射函数 $(\lambda,\nu,1)^T(u,v,t)$：若 $\lambda\succeq0$，则

```math
g(\lambda,\nu)=\inf\{(\lambda,\nu,1)^T(u,v,t) \mid (u,v,t)\in\mathcal{A}\}.
```

```math
(\lambda,\nu,1)^T(u,v,t)\ge g(\lambda,\nu)
```

定义 $\mathcal{A}$ 的一个非竖直支撑超平面。特别地，由于 $(0,0,p^\star)\in\mathbf{bd}\,\mathcal{A}$，有

```math
p^\star=(\lambda,\nu,1)^T(0,0,p^\star)\ge g(\lambda,\nu), \tag{5.38}
```

即弱对偶下界。强对偶性成立当且仅当 (5.38) 对某个对偶可行的 $(\lambda,\nu)$ 取等，即 $\mathcal{A}$ 在其边界点 $(0,0,p^\star)$ 处存在非竖直支撑超平面。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">5.3.2 Proof of strong duality under constraint qualification（约束规格下强对偶性的证明）</span>

<!-- p.248/249 -->

本节证明：对凸问题，Slater 约束规格保证强对偶性（且对偶最优达到）。考虑原始问题 (5.25)（$f_0,\dots,f_m$ 凸），设 Slater 条件成立：存在 $\tilde{x}\in\mathbf{relint}\,\mathcal{D}$ 使 $f_i(\tilde{x})<0$（$i=1,\dots,m$）且 $A\tilde{x}=b$。为简化证明，再加两个假设：$\mathcal{D}$ 有非空内部（故 $\mathbf{relint}\,\mathcal{D}=\mathbf{int}\,\mathcal{D}$），以及 $\mathbf{rank}A=p$。设 $p^\star$ 有限。（由于有可行点，只可能 $p^\star=-\infty$ 或 $p^\star$ 有限；若 $p^\star=-\infty$，则由弱对偶性 $d^\star=-\infty$。）



集合 $\mathcal{A}$（由 (5.37) 定义）在底层问题凸时容易证明是凸的。定义第二个凸集

```math
\mathcal{B}=\{(0,0,s)\in\mathbb{R}^m\times\mathbb{R}^p\times\mathbb{R} \mid s<p^\star\}.
```

集合 $\mathcal{A}$ 与 $\mathcal{B}$ 不相交。为看出这一点，设 $(u,v,t)\in\mathcal{A}\cap\mathcal{B}$。由 $(u,v,t)\in\mathcal{B}$ 得 $u=0$、$v=0$、$t\lt p^\star$。由 $(u,v,t)\in\mathcal{A}$，存在 $x$ 满足 $f_i(x)\le0$（$i=1,\dots,m$）、$Ax-b=0$、$f_0(x)\le t\lt p^\star$，这与 $p^\star$ 是原始问题最优值矛盾。

由 §2.5.1 的分离超平面定理，存在 $(\tilde{\lambda},\tilde{\nu},\mu)\neq0$ 与 $\alpha$ 使

```math
(u,v,t)\in\mathcal{A} \implies \tilde{\lambda}^Tu+\tilde{\nu}^Tv+\mu t\ge\alpha, \tag{5.39}
```

```math
(u,v,t)\in\mathcal{B} \implies \tilde{\lambda}^Tu+\tilde{\nu}^Tv+\mu t\le\alpha. \tag{5.40}
```

由 (5.39) 得 $\tilde{\lambda}\succeq0$ 且 $\mu\ge0$（否则 $\tilde{\lambda}^Tu+\mu t$ 在 $\mathcal{A}$ 上无下界，与 (5.39) 矛盾）。条件 (5.40) 只意味着 $\mu t\le\alpha$ 对所有 $t\lt p^\star$，故 $\mu p^\star\le\alpha$。结合 (5.39)，对任何 $x\in\mathcal{D}$：

```math
\sum_{i=1}^m\tilde{\lambda}_if_i(x)+\tilde{\nu}^T(Ax-b)+\mu f_0(x)\ge\alpha\ge\mu p^\star. \tag{5.41}
```

设 $\mu>0$。此时可把 (5.41) 除以 $\mu$ 得

```math
L(x,\tilde{\lambda}/\mu,\tilde{\nu}/\mu)\ge p^\star
```

对所有 $x\in\mathcal{D}$，由此对 $x$ 最小化得 $g(\lambda,\nu)\ge p^\star$，其中定义

```math
\lambda=\tilde{\lambda}/\mu,\qquad \nu=\tilde{\nu}/\mu.
```

由弱对偶性 $g(\lambda,\nu)\le p^\star$，所以事实上 $g(\lambda,\nu)=p^\star$。这表明强对偶性成立且对偶最优达到——至少在 $\mu>0$ 的情形。



现在考虑 $\mu=0$ 的情形。由 (5.41)，对所有 $x\in\mathcal{D}$：

```math
\sum_{i=1}^m\tilde{\lambda}_if_i(x)+\tilde{\nu}^T(Ax-b)\ge0. \tag{5.42}
```

把它应用于满足 Slater 条件的点 $\tilde{x}$，得

```math
\sum_{i=1}^m\tilde{\lambda}_if_i(\tilde{x})\ge0.
```

<!-- p.250/251 -->

由于 $f_i(\tilde{x})<0$ 且 $\tilde{\lambda}_i\ge0$，得 $\tilde{\lambda}=0$。由 $(\tilde{\lambda},\tilde{\nu},\mu)\neq0$ 且 $\tilde{\lambda}=0$、$\mu=0$，得 $\tilde{\nu}\neq0$。于是 (5.42) 蕴含对所有 $x\in\mathcal{D}$ 有 $\tilde{\nu}^T(Ax-b)\ge0$。但 $\tilde{x}$ 满足 $\tilde{\nu}^T(A\tilde{x}-b)=0$，且由于 $\tilde{x}\in\mathbf{int}\,\mathcal{D}$，$\mathcal{D}$ 中存在使 $\tilde{\nu}^T(Ax-b)<0$ 的点——除非 $A^T\tilde{\nu}=0$。当然这与 $\mathbf{rank}A=p$ 的假设矛盾。



证明背后的几何思想见图 5.6（单不等式约束的简单问题）。分离 $\mathcal{A}$ 与 $\mathcal{B}$ 的超平面定义了 $\mathcal{A}$ 在 $(0,p^\star)$ 处的支撑超平面。Slater 约束规格用来确立该超平面必非竖直（即法向量形如 $(\lambda^\star,1)$）。（凸问题单不等式约束但强对偶性失效的简单例子见习题 5.21。）

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">5.3.3 Multicriterion interpretation（多准则解释）</span>



没有等式约束的问题

```math
\begin{aligned}
\text{minimize}\quad & f_0(x)\\
\text{subject to}\quad & f_i(x)\le0,\quad i=1,\dots,m
\end{aligned} \tag{5.43}
```

的拉格朗日对偶，与（无约束）多准则问题

```math
\text{minimize (w.r.t. }\mathbb{R}^{m+1}_+)\quad F(x)=(f_1(x),\dots,f_m(x),f_0(x)) \tag{5.44}
```

的标量化方法（见 §4.7.4）之间有自然的联系。在标量化中，选正向量 $\tilde{\lambda}$ 并最小化标量函数 $\tilde{\lambda}^TF(x)$；任何最小化点保证 Pareto 最优。由于可以用正常数缩放 $\tilde{\lambda}$ 而不影响最小化点，不失一般性取 $\tilde{\lambda}=(\lambda,1)$。于是标量化中最小化的函数是

```math
\tilde{\lambda}^TF(x)=f_0(x)+\sum_{i=1}^m\lambda_if_i(x),
```

它正是问题 (5.43) 的拉格朗日函数。

为确立「凸多准则问题的每个 Pareto 最优点都对某个非负权重向量 $\tilde{\lambda}$ 最小化 $\tilde{\lambda}^TF(x)$」，我们考虑集合 $\mathcal{A}$（由 (4.62) 定义）：

```math
\mathcal{A}=\{t\in\mathbb{R}^{m+1} \mid \exists x\in\mathcal{D},\ f_i(x)\le t_i,\ i=0,\dots,m\},
```

它与拉格朗日对偶中出现的集合 $\mathcal{A}$（(5.37) 定义）完全相同。这里也是把所需的权重向量为构造为集合在任意 Pareto 最优点处的支撑超平面。在多准则优化中，我们把权重向量的分量解释为目标函数之间的相对权重。当我们把权重向量与 $f_0$ 相关联的最后一个分量固定为 1 时，其他权重的解释是相对 $f_0$ 的成本，即相对目标的成本。

## <span style="color:#c0392b;">5.4 Saddle-point interpretation（鞍点解释）</span>

<!-- p.251/252 -->

本节给出拉格朗日对偶的几种解释。本节材料后面不会用到。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">5.4.1 Max-min characterization of weak and strong duality（弱与强对偶的 max-min 刻画）</span>

可以把原始与对偶优化问题表达为更对称的形式。为简化讨论假设没有等式约束；结果容易扩展。先注意

```math
\sup_{\lambda\succeq0}L(x,\lambda)=\sup_{\lambda\succeq0}\Bigl(f_0(x)+\sum_{i=1}^m\lambda_if_i(x)\Bigr)=\begin{cases}f_0(x) & f_i(x)\le0,\ i=1,\dots,m\\ \infty & \text{otherwise}.\end{cases}
```



事实上，设 $x$ 不可行且某 $i$ 有 $f_i(x)>0$，则取 $\lambda_j=0$（$j\neq i$）且 $\lambda_i\to\infty$ 可见 $\sup_{\lambda\succeq0}L(x,\lambda)=\infty$。另一方面若 $f_i(x)\le0$（$i=1,\dots,m$），则 $\lambda$ 的最优选择是 $\lambda=0$，$\sup_{\lambda\succeq0}L(x,\lambda)=f_0(x)$。这意味着可以把原始问题的最优值表达为

```math
p^\star=\inf_x\sup_{\lambda\succeq0}L(x,\lambda).
```

由对偶函数的定义，也有

```math
d^\star=\sup_{\lambda\succeq0}\inf_xL(x,\lambda).
```

于是弱对偶性可表达为不等式

```math
\sup_{\lambda\succeq0}\inf_xL(x,\lambda)\le\inf_x\sup_{\lambda\succeq0}L(x,\lambda), \tag{5.45}
```

强对偶性表达为等式

```math
\sup_{\lambda\succeq0}\inf_xL(x,\lambda)=\inf_x\sup_{\lambda\succeq0}L(x,\lambda).
```

强对偶性意味着关于 $x$ 的最小化与关于 $\lambda\succeq0$ 的最大化可以交换次序而不影响结果。

事实上，不等式 (5.45) 不依赖 $L$ 的任何性质：对任何 $f:\mathbb{R}^n\times\mathbb{R}^m\to\mathbb{R}$（及任何 $W\subseteq\mathbb{R}^n$、$Z\subseteq\mathbb{R}^m$），有

```math
\sup_{z\in Z}\inf_{w\in W}f(w,z)\le\inf_{w\in W}\sup_{z\in Z}f(w,z). \tag{5.46}
```

这个一般不等式称为 max-min inequality（max-min 不等式）。当等号成立时，即

```math
\sup_{z\in Z}\inf_{w\in W}f(w,z)=\inf_{w\in W}\sup_{z\in Z}f(w,z), \tag{5.47}
```

我们说 $f$（与 $W$、$Z$）满足 strong max-min property（强 max-min 性质）或 saddle-point property（鞍点性质）。当然强 max-min 性质只在特殊情形成立，例如当 $f:\mathbb{R}^n\times\mathbb{R}^m\to\mathbb{R}$ 是强对偶性成立的问题的拉格朗日函数、$W=\mathbb{R}^n$、$Z=\mathbb{R}^m_+$。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">5.4.2 Saddle-point interpretation（鞍点解释）</span>

<!-- p.252/253 -->

我们称数对 $\tilde{w}\in W$、$\tilde{z}\in Z$ 是 $f$（与 $W$、$Z$）的 saddle-point（鞍点），如果

```math
f(\tilde{w},z)\le f(\tilde{w},\tilde{z})\le f(w,\tilde{z})
```

对所有 $w\in W$、$z\in Z$。换言之，$\tilde{w}$ 最小化 $f(w,\tilde{z})$（在 $w\in W$ 上），$\tilde{z}$ 最大化 $f(\tilde{w},z)$（在 $z\in Z$ 上）：

```math
f(\tilde{w},\tilde{z})=\inf_{w\in W}f(w,\tilde{z}),\qquad f(\tilde{w},\tilde{z})=\sup_{z\in Z}f(\tilde{w},z).
```



这意味着强 max-min 性质 (5.47) 成立，且公共值为 $f(\tilde{w},\tilde{z})$。

回到拉格朗日对偶的讨论：若 $x^\star$ 与 $\lambda^\star$ 是强对偶性成立问题的原始与对偶最优点，则它们构成拉格朗日函数的鞍点。逆命题也成立：若 $(x,\lambda)$ 是拉格朗日函数的鞍点，则 $x$ 原始最优、$\lambda$ 对偶最优、最优对偶间隙为零。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">5.4.3 Game interpretation（博弈解释）</span>

可以用 continuous zero-sum game（连续零和博弈）解释 max-min 不等式 (5.46)、max-min 等式 (5.47) 与鞍点性质。若第一个玩家选 $w\in W$，第二个玩家选 $z\in Z$，则玩家 1 向玩家 2 支付 $f(w,z)$。玩家 1 因此想最小化 $f$，玩家 2 想最大化 $f$。（博弈称为连续的，因为选择是向量而非离散的。）

设玩家 1 先选，然后玩家 2 在得知玩家 1 的选择后选。玩家 2 想最大化支付 $f(w,z)$，所以会选 $z\in Z$ 最大化 $f(w,z)$。所得支付为 $\sup_{z\in Z}f(w,z)$，依赖第一个玩家的选择 $w$。（这里假设上确界达到；若不然最优支付可任意接近 $\sup_{z\in Z}f(w,z)$。）玩家 1 知道（或假设）玩家 2 会遵循这一策略，所以会选 $w\in W$ 使这个给玩家 2 的最坏情况支付尽量小。于是玩家 1 选

```math
\operatorname*{argmin}_{w\in W}\sup_{z\in Z}f(w,z),
```

产生玩家 1 向玩家 2 的支付

```math
\inf_{w\in W}\sup_{z\in Z}f(w,z).
```

现在设出牌次序颠倒：玩家 2 必须先选 $z\in Z$，然后玩家 1（知道 $z$）选 $w\in W$。按类似论证，若玩家遵循最优策略，玩家 2 应选 $z\in Z$ 最大化 $\inf_{w\in W}f(w,z)$，产生支付

```math
\sup_{z\in Z}\inf_{w\in W}f(w,z).
```

max-min 不等式 (5.46) 陈述（直觉上显然的）事实：后手更好，或更准确地说，玩家在选择前知道对手的选择更好。换言之，若玩家 1 必须先选，玩家 2 的支付更大。当鞍点性质 (5.47) 成立时，后手没有优势。

<!-- p.253/254 -->

若 $(\tilde{w},\tilde{z})$ 是 $f$（与 $W$、$Z$）的鞍点，则它称为博弈的 solution（解）；$\tilde{w}$ 称为玩家 1 的 optimal choice（最优选择）或 strategy（策略），$\tilde{z}$ 称为玩家 2 的最优选择或策略。此情形后手无优势。



考虑支付函数是拉格朗日函数、$W=\mathbb{R}^n$、$Z=\mathbb{R}^m_+$ 的特例。此时玩家 1 选择原始变量 $x$，玩家 2 选择对偶变量 $\lambda\succeq0$。按上述论证，玩家 2 若必须先选，其最优选择是任何对偶最优的 $\lambda^\star$，产生支付 $d^\star$；反之若玩家 1 必须先选，其最优选择是任何原始最优的 $x^\star$，产生支付 $p^\star$。

问题的最优对偶间隙恰等于后手玩家获得的优势，即在选择前知道对手选择的优势。若强对偶性成立，则知道对手的选择对玩家没有优势。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">5.4.4 Price or tax interpretation（价格或税收解释）</span>

拉格朗日对偶有一个有趣的经济解释。设变量 $x$ 表示企业如何运营，$f_0(x)$ 表示在 $x$ 运营的成本，即 $-f_0(x)$ 是在运营条件 $x$ 的 profit（利润，比如以美元计）。每个约束 $f_i(x)\le0$ 表示某种 limit（限制），如资源限制（仓库空间、劳动力）或监管限制（环境）。在尊重限制下最大化利润的运营条件可以通过求解问题

```math
\begin{aligned}
\text{minimize}\quad & f_0(x)\\
\text{subject to}\quad & f_i(x)\le0,\quad i=1,\dots,m
\end{aligned}
```

找到。最优利润为 $-p^\star$。

现在想象第二种情形：限制可以被违反，但要支付与违反量（由 $f_i$ 度量）成线性的额外成本。于是企业为第 $i$ 个限制或约束支付 $\lambda_if_i(x)$。对不紧的约束企业还获得支付：若 $f_i(x)<0$，则 $\lambda_if_i(x)$ 代表给企业的支付。系数 $\lambda_i$ 的解释是违反 $f_i(x)\le0$ 的 price（价格）；其单位是每单位违反（按 $f_i$ 度量）多少美元。同样的价格下，企业可以出售第 $i$ 个约束的任何「未用」部分。设 $\lambda_i\ge0$，即企业必须为违反付费（约束不紧时获得收入）。

举例：设原问题的第一个约束 $f_1(x)\le0$ 表示仓库空间限制（如平方米）。在这种新安排下，开放企业以每平方米 $\lambda_1$ 美元的价格租用额外仓库空间、并以同样价格出租未用空间的可能性。

<!-- p.254/255 -->

企业在运营条件 $x$、约束价格 $\lambda_i$ 下的总成本是 $L(x,\lambda)=f_0(x)+\sum_{i=1}^m\lambda_if_i(x)$。企业显然会运营得使总成本 $L(x,\lambda)$ 最小，产生成本 $g(\lambda)$。因此对偶函数表示作为约束价格向量 $\lambda$ 的函数的企业最优成本。最优对偶值 $d^\star$ 是企业在最不利价格集下的最优成本。



用这个解释可以把弱对偶性改述为：第二种情形（约束违反可以买卖）下企业的最优成本小于等于第一种情形（约束不可违反）下的成本——即使价格最不利。这很显然：若 $x^\star$ 在第一种情形最优，则 $x^\star$ 在第二种情形的运营成本将低于 $f_0(x^\star)$，因为可以从不紧的约束获得一些收入。最优对偶间隙则是「允许企业为约束违反付费（并为不紧约束收款）」能给企业带来的最小可能优势。

现在设强对偶性成立且对偶最优达到。可以把对偶最优的 $\lambda^\star$ 解释为一组价格：在此价格下，允许企业为约束违反付费（或为不紧约束收款）没有优势。因此对偶最优的 $\lambda^\star$ 有时称为原问题的 shadow prices（影子价格）。

若能找到对偶可行的 $(\lambda,\nu)$，就确立了原始问题最优值的下界：$p^\star\ge g(\lambda,\nu)$。因此对偶可行点 $(\lambda,\nu)$ 提供 $p^\star\ge g(\lambda,\nu)$ 的 proof（证明）或 certificate（证书）。强对偶性意味着存在任意好的证书。

对偶可行点使我们能在不知道 $p^\star$ 精确值的情况下，界定给定可行点的次优程度。事实上若 $x$ 原始可行、$(\lambda,\nu)$ 对偶可行，则

```math
f_0(x)-p^\star\le f_0(x)-g(\lambda,\nu).
```

特别地，这确立 $x$ 是 $\epsilon$-次优的，$\epsilon=f_0(x)-g(\lambda,\nu)$。（也确立 $(\lambda,\nu)$ 对对偶问题 $\epsilon$-次优。）

我们把原始与对偶目标之间的 gap（间隙）

```math
f_0(x)-g(\lambda,\nu)
```

称为与原始可行点 $x$、对偶可行点 $(\lambda,\nu)$ 相关联的 duality gap（对偶间隙）。原始-对偶可行对 $x,(\lambda,\nu)$ 把原始（与对偶）问题的最优值限定在一个区间内：

```math
p^\star\in[g(\lambda,\nu),f_0(x)],\qquad d^\star\in[g(\lambda,\nu),f_0(x)],
```

区间宽度就是对偶间隙。

若原始-对偶可行对 $x,(\lambda,\nu)$ 的对偶间隙为零，即 $f_0(x)=g(\lambda,\nu)$，则 $x$ 原始最优、$(\lambda,\nu)$ 对偶最优。可以把 $(\lambda,\nu)$ 想成证明 $x$ 最优的证书（类似地可以把 $x$ 想成证明 $(\lambda,\nu)$ 对偶最优的证书）。

<!-- p.255/256 -->

这些观察可用于优化算法以提供 nonheuristic stopping criteria（非启发式停止准则）。设算法产生原始可行的 $x^{(k)}$ 与对偶可行的 $(\lambda^{(k)},\nu^{(k)})$ 序列（$k=1,2,\dots$），$\epsilon_{\mathrm{abs}}>0$ 是给定的要求绝对精度。则停止准则（即算法终止条件）

```math
f_0(x^{(k)})-g(\lambda^{(k)},\nu^{(k)})\le\epsilon_{\mathrm{abs}}
```



保证算法终止时 $x^{(k)}$ 是 $\epsilon_{\mathrm{abs}}$-次优的。事实上 $(\lambda^{(k)},\nu^{(k)})$ 是证明它的证书。（当然，若此方法要用于任意小的容差 $\epsilon_{\mathrm{abs}}$，强对偶性必须成立。）

类似的条件可用于保证给定的相对精度 $\epsilon_{\mathrm{rel}}>0$。若

```math
g(\lambda^{(k)},\nu^{(k)})>0,\qquad \frac{f_0(x^{(k)})-g(\lambda^{(k)},\nu^{(k)})}{g(\lambda^{(k)},\nu^{(k)})}\le\epsilon_{\mathrm{rel}}
```

成立，或

```math
f_0(x^{(k)})<0,\qquad \frac{f_0(x^{(k)})-g(\lambda^{(k)},\nu^{(k)})}{-f_0(x^{(k)})}\le\epsilon_{\mathrm{rel}}
```

成立，则 $p^\star\neq0$ 且相对误差 $\dfrac{f_0(x^{(k)})-p^\star}{|p^\star|}$ 保证小于等于 $\epsilon_{\mathrm{rel}}$。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">5.5.2 Complementary slackness（互补松弛性）</span>

<!-- p.256/257 -->

设原始与对偶最优值被达到且相等（特别地，强对偶性成立）。设 $x^\star$ 是原始最优、$(\lambda^\star,\nu^\star)$ 是对偶最优点。这意味着

```math
\begin{aligned}
f_0(x^\star)&=g(\lambda^\star,\nu^\star)\\
&=\inf_x\Bigl(f_0(x)+\sum_{i=1}^m\lambda_i^\star f_i(x)+\sum_{i=1}^p\nu_i^\star h_i(x)\Bigr)\\
&\le f_0(x^\star)+\sum_{i=1}^m\lambda_i^\star f_i(x^\star)+\sum_{i=1}^p\nu_i^\star h_i(x^\star)\\
&\le f_0(x^\star).
\end{aligned}
```

第一行陈述最优对偶间隙为零，第二行是对偶函数的定义。第三行成立因为拉格朗日函数关于 $x$ 的下确界小于等于其在 $x=x^\star$ 处的值。最后一个不等式由 $\lambda_i^\star\ge0$、$f_i(x^\star)\le0$（$i=1,\dots,m$）与 $h_i(x^\star)=0$（$i=1,\dots,p$）得出。我们得出：这个链中的两个不等式都取等号。



由此可以得出几个有趣的结论。例如，由于第三行的等式成立，$x^\star$ 在 $x$ 上最小化 $L(x,\lambda^\star,\nu^\star)$。（拉格朗日函数 $L(x,\lambda^\star,\nu^\star)$ 可以有其他最小化点；$x^\star$ 只是一个最小化点。）

另一个重要结论是

```math
\sum_{i=1}^m\lambda_i^\star f_i(x^\star)=0.
```

由于和中每项非正，得出

```math
\lambda_i^\star f_i(x^\star)=0,\qquad i=1,\dots,m. \tag{5.48}
```

这个条件称为 complementary slackness（互补松弛性）；它对任何原始最优 $x^\star$ 与任何对偶最优 $(\lambda^\star,\nu^\star)$ 成立（强对偶性成立时）。可以把互补松弛条件表达为

```math
\lambda_i^\star>0 \implies f_i(x^\star)=0,
```

或等价地

```math
f_i(x^\star)<0 \implies \lambda_i^\star=0.
```

粗略地说：第 $i$ 个最优拉格朗日乘子为零，除非第 $i$ 个约束在最优点处起作用。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">5.5.3 KKT optimality conditions（KKT 最优性条件）</span>



现在假设函数 $f_0,\dots,f_m,h_1,\dots,h_p$ 可微（从而定义域开），但暂不对凸性做假设。

**非凸问题的 KKT 条件。** 如上，设 $x^\star$ 与 $(\lambda^\star,\nu^\star)$ 是任何对偶间隙为零的原始与对偶最优点。由于 $x^\star$ 在 $x$ 上最小化 $L(x,\lambda^\star,\nu^\star)$，其梯度在 $x^\star$ 必为零：

```math
\nabla f_0(x^\star)+\sum_{i=1}^m\lambda_i^\star\nabla f_i(x^\star)+\sum_{i=1}^p\nu_i^\star\nabla h_i(x^\star)=0.
```

于是有

```math
\begin{aligned}
f_i(x^\star)&\le0,&& i=1,\dots,m\\
h_i(x^\star)&=0,&& i=1,\dots,p\\
\lambda_i^\star&\ge0,&& i=1,\dots,m\\
\lambda_i^\star f_i(x^\star)&=0,&& i=1,\dots,m\\
\nabla f_0(x^\star)+\sum_{i=1}^m\lambda_i^\star\nabla f_i(x^\star)+\sum_{i=1}^p\nu_i^\star\nabla h_i(x^\star)&=0,
\end{aligned} \tag{5.49}
```

称为 Karush-Kuhn-Tucker (KKT) conditions（KKT 条件）。总结：对任何目标与约束函数可微、且强对偶性成立的优化问题，任何原始与对偶最优点对必须满足 KKT 条件 (5.49)。



**凸问题的 KKT 条件。** 当原始问题凸时，KKT 条件对「点是原始与对偶最优」也是 sufficient（充分）的。换言之，若 $f_i$ 凸、$h_i$ 仿射，且 $\tilde{x},\tilde{\lambda},\tilde{\nu}$ 是满足 KKT 条件

```math
\begin{aligned}
f_i(\tilde{x})&\le0,&& i=1,\dots,m\\
h_i(\tilde{x})&=0,&& i=1,\dots,p\\
\tilde{\lambda}_i&\ge0,&& i=1,\dots,m\\
\tilde{\lambda}_if_i(\tilde{x})&=0,&& i=1,\dots,m\\
\nabla f_0(\tilde{x})+\sum_{i=1}^m\tilde{\lambda}_i\nabla f_i(\tilde{x})+\sum_{i=1}^p\tilde{\nu}_i\nabla h_i(\tilde{x})&=0
\end{aligned}
```

的任何点，则 $\tilde{x}$ 与 $(\tilde{\lambda},\tilde{\nu})$ 原始与对偶最优，对偶间隙为零。

为看出这一点，注意前两个条件说明 $\tilde{x}$ 原始可行。由于 $\tilde{\lambda}_i\ge0$，$L(x,\tilde{\lambda},\tilde{\nu})$ 关于 $x$ 凸；最后一个 KKT 条件说明其关于 $x$ 的梯度在 $x=\tilde{x}$ 为零，故 $\tilde{x}$ 在 $x$ 上最小化 $L(x,\tilde{\lambda},\tilde{\nu})$。由此得

```math
g(\tilde{\lambda},\tilde{\nu})=L(\tilde{x},\tilde{\lambda},\tilde{\nu})=f_0(\tilde{x})+\sum_{i=1}^m\tilde{\lambda}_if_i(\tilde{x})+\sum_{i=1}^p\tilde{\nu}_ih_i(\tilde{x})=f_0(\tilde{x}),
```

最后一行用 $h_i(\tilde{x})=0$ 与 $\tilde{\lambda}_if_i(\tilde{x})=0$。这表明 $\tilde{x}$ 与 $(\tilde{\lambda},\tilde{\nu})$ 对偶间隙为零，因此原始与对偶最优。总结：对任何目标与约束函数可微的凸优化问题，满足 KKT 条件的任何点都原始与对偶最优、对偶间隙为零。

若带可微目标与约束函数的凸优化问题满足 Slater 条件，则 KKT 条件提供最优性的充要条件：Slater 条件蕴含最优对偶间隙为零且对偶最优达到，所以 $x$ 最优当且仅当存在 $(\lambda,\nu)$ 与 $x$ 一起满足 KKT 条件。

KKT 条件在优化中扮演重要角色。少数特殊情形可以解析地求解 KKT 条件（从而求解优化问题）。更一般地，许多凸优化算法被构思为（或可解释为）求解 KKT 条件的方法。

<span style="color:#00838f;">**[例 5.1]** **等式约束的凸二次最小化。** 考虑问题

```math
\begin{aligned}
\text{minimize}\quad & (1/2)x^TPx+q^Tx+r\\
\text{subject to}\quad & Ax=b,
\end{aligned} \tag{5.50}
```

$P\in\mathbf{S}^n_+$。此问题的 KKT 条件为

```math
Ax^\star=b,\qquad Px^\star+q+A^T\nu^\star=0,
```

可以写成

```math
\begin{bmatrix}P&A^T\\A&0\end{bmatrix}\begin{bmatrix}x^\star\\\nu^\star\end{bmatrix}=\begin{bmatrix}-q\\b\end{bmatrix}.
```



解这组关于 $m+n$ 个变量 $x^\star,\nu^\star$ 的 $m+n$ 个方程，给出 (5.50) 的最优原始与对偶变量。

<span style="color:#00838f;">**[例 5.2]** **注水（water-filling）。** 考虑凸优化问题

```math
\begin{aligned}
\text{minimize}\quad & -\sum_{i=1}^n\log(\alpha_i+x_i)\\
\text{subject to}\quad & x\succeq0,\quad \mathbf{1}^Tx=1,
\end{aligned}
```

$\alpha_i>0$。此问题出现在 information theory（信息论）中：给 $n$ 个通信信道分配功率。变量 $x_i$ 表示分配给第 $i$ 个信道的发射功率，$\log(\alpha_i+x_i)$ 给出信道的 capacity（容量）或通信速率，所以问题是把总功率 1 分配给各信道以最大化总通信速率。

为不等式约束 $x^\star\succeq0$ 引入拉格朗日乘子 $\lambda^\star\in\mathbb{R}^n$、为等式约束 $\mathbf{1}^Tx=1$ 引入乘子 $\nu^\star\in\mathbb{R}$，得 KKT 条件：

```math
\begin{aligned}
&x^\star\succeq0,\qquad \mathbf{1}^Tx^\star=1,\\
&\lambda^\star\succeq0,\qquad \lambda_i^\star x_i^\star=0,\quad i=1,\dots,n,\\
&-1/(\alpha_i+x_i^\star)-\lambda_i^\star+\nu^\star=0,\quad i=1,\dots,n.
\end{aligned}
```

我们可以直接解这些方程求 $x^\star,\lambda^\star,\nu^\star$。先注意 $\lambda^\star$ 在最后一个方程中充当 slack variable（松弛变量），可以消去，留下

```math
\begin{aligned}
&x^\star\succeq0,\qquad \mathbf{1}^Tx^\star=1,\\
&x_i^\star(\nu^\star-1/(\alpha_i+x_i^\star))=0,\quad i=1,\dots,n,\\
&\nu^\star\ge1/(\alpha_i+x_i^\star),\quad i=1,\dots,n.
\end{aligned}
```

若 $\nu^\star<1/\alpha_i$，最后这个条件只有 $x_i^\star>0$ 才能成立，而这由第三个条件蕴含 $\nu^\star=1/(\alpha_i+x_i^\star)$。解 $x_i^\star$ 得：$\nu^\star<1/\alpha_i$ 时 $x_i^\star=1/\nu^\star-\alpha_i$。若 $\nu^\star\ge1/\alpha_i$，则 $x_i^\star>0$ 不可能，因为它会蕴含 $\nu^\star\ge1/\alpha_i>1/(\alpha_i+x_i^\star)$，违反互补松弛条件。因此 $\nu^\star\ge1/\alpha_i$ 时 $x_i^\star=0$。于是

```math
x_i^\star=\begin{cases}1/\nu^\star-\alpha_i & \nu^\star<1/\alpha_i\\ 0 & \nu^\star\ge1/\alpha_i,\end{cases}
```

<!-- p.259/260 -->

更简单地：$x_i^\star=\max\{0,\ 1/\nu^\star-\alpha_i\}$。把这个 $x_i^\star$ 表达式代入条件 $\mathbf{1}^Tx^\star=1$ 得

```math
\sum_{i=1}^n\max\{0,\ 1/\nu^\star-\alpha_i\}=1.
```

左边是 $1/\nu^\star$ 的分段线性递增函数，breakpoints（断点）在 $\alpha_i$，所以方程有唯一解，容易确定。



这个解法称为 water-filling（注水），原因如下：把 $\alpha_i$ 想成地块 $i$ 上方的地面高度，然后把区域注水到深度 $1/\nu$（图 5.7）。用水总量为 $\sum_{i=1}^n\max\{0,1/\nu^\star-\alpha_i\}$。然后提高水位直到用水总量等于 1。地块 $i$ 上方的水深就是最优值 $x_i^\star$。

> <span style="color:#2471a3;">**[译者注｜跨课程连接]** 例 5.2 是信息论的正门！注水解就是平行高斯信道的容量分配（Cover & Thomas / MacKay 书的内容），「注水算法」将出现在你 MacKay 信息论讲义 L2-L3 与通信课中。KKT 条件在此把凸优化与 Shannon 容量直接连了起来。</span>

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">5.5.4 Mechanics interpretation of KKT conditions（KKT 条件的力学解释）</span>

KKT 条件在力学中有漂亮的解释（这确实是拉格朗日的主要动机之一）。用简单例子说明。图 5.8 的系统由两个块组成，它们彼此相连、并通过三个弹簧连接到左右墙壁。块的位置由 $x\in\mathbb{R}^2$ 给出，$x_1$ 是左块（中部）的位移，$x_2$ 是右块的位移。左墙位于位置 0，右墙位于位置 $l$。



弹簧的势能作为块位置的函数为

```math
f_0(x_1,x_2)=\frac{1}{2}k_1x_1^2+\frac{1}{2}k_2(x_2-x_1)^2+\frac{1}{2}k_3(l-x_2)^2,
```

其中 $k_i>0$ 是三个弹簧的 stiffness constants（刚度常数）。平衡位置 $x^\star$ 是在不等式约束

```math
w/2-x_1\le0,\qquad w+x_1-x_2\le0,\qquad w/2-l+x_2\le0 \tag{5.51}
```

下最小化势能的位置。这些约束称为 kinematic constraints（运动学约束），表达块有宽度 $w>0$、不能彼此穿透也不能穿墙的事实。

<!-- p.261/262 -->

平衡位置因此由优化问题

```math
\begin{aligned}
\text{minimize}\quad & (1/2)\bigl(k_1x_1^2+k_2(x_2-x_1)^2+k_3(l-x_2)^2\bigr)\\
\text{subject to}\quad & w/2-x_1\le0\\
& w+x_1-x_2\le0\\
& w/2-l+x_2\le0
\end{aligned} \tag{5.52}
```

的解给出，它是一个 QP。

以 $\lambda_1,\lambda_2,\lambda_3$ 为拉格朗日乘子，此问题的 KKT 条件由运动学约束 (5.51)、非负性约束 $\lambda_i\ge0$、互补松弛条件

```math
\lambda_1(w/2-x_1)=0,\qquad \lambda_2(w-x_2+x_1)=0,\qquad \lambda_3(w/2-l+x_2)=0, \tag{5.53}
```

以及零梯度条件

```math
\begin{bmatrix}k_1x_1-k_2(x_2-x_1)\\ k_2(x_2-x_1)-k_3(l-x_2)\end{bmatrix}+\lambda_1\begin{bmatrix}-1\\0\end{bmatrix}+\lambda_2\begin{bmatrix}1\\-1\end{bmatrix}+\lambda_3\begin{bmatrix}0\\1\end{bmatrix}=0 \tag{5.54}
```



组成。方程 (5.54) 可以解释为两个块的 force balance equations（力平衡方程），只要把拉格朗日乘子解释为作用在墙壁与块之间的 contact forces（接触力）（图 5.9）。第一个方程说明第一个块上的合力为零：$-k_1x_1$ 是左弹簧施加在左块上的力，$k_2(x_2-x_1)$ 是中间弹簧施加的力，$\lambda_1$ 是左墙施加的力，$-\lambda_2$ 是右块施加的力。接触力必须背离接触面（由约束 $\lambda_1\ge0$ 与 $-\lambda_2\le0$ 表达），且只在有接触时非零（由前两个互补松弛条件 (5.53) 表达）。类似地，(5.54) 的第二个方程是第二个块的力平衡，(5.53) 的最后一个条件说明除非右块接触墙壁，$\lambda_3$ 为零。

此例中势能与运动学约束函数凸，且（精化形式的）Slater 约束规格在 $2w\le l$（即墙之间有足够空间容纳两个块）时成立，所以我们可以断定：由 (5.52) 给出的平衡的能量表述与由 KKT 条件给出的力平衡表述给出相同结果。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">5.5.5 Solving the primal problem via the dual（借助对偶求解原始问题）</span>

§5.5.3 开头提到过：若强对偶性成立且存在对偶最优解 $(\lambda^\star,\nu^\star)$，则任何原始最优点也是 $L(x,\lambda^\star,\nu^\star)$ 的最小化点。这一事实有时允许我们从对偶最优解计算原始最优解。

更精确地：设我们有强对偶性且已知最优的 $(\lambda^\star,\nu^\star)$。设 $L(x,\lambda^\star,\nu^\star)$ 的最小化点（即问题

```math
\text{minimize}\quad f_0(x)+\sum_{i=1}^m\lambda_i^\star f_i(x)+\sum_{i=1}^p\nu_i^\star h_i(x), \tag{5.55}
```

的解）是唯一的。（对凸问题，例如当 $L(x,\lambda^\star,\nu^\star)$ 关于 $x$ 严格凸时会发生。）那么若 (5.55) 的解原始可行，它必是原始最优的；若它不原始可行，则不可能存在原始最优点，即可以断定原始最优未被达到。当对偶问题比原始问题更容易求解时（例如可解析求解，或有可利用的特殊结构），这个观察很有意思。

<span style="color:#00838f;">**[例 5.3]** **熵最大化。** 考虑熵最大化问题

```math
\begin{aligned}
\text{minimize}\quad & f_0(x)=\sum_{i=1}^nx_i\log x_i\\
\text{subject to}\quad & Ax\preceq b,\quad \mathbf{1}^Tx=1
\end{aligned}
```

（$\mathbb{R}^n_{++}$ 上）及其对偶问题

```math
\begin{aligned}
\text{maximize}\quad & -b^T\lambda-\nu-e^{-\nu-1}\sum_{i=1}^ne^{-a_i^T\lambda}\\
\text{subject to}\quad & \lambda\succeq0
\end{aligned}
```

（$a_i$ 是 $A$ 的列；见第 222、228 页）。设（弱形式的）Slater 条件成立，即存在 $x\succ0$ 满足 $Ax\preceq b$ 与 $\mathbf{1}^Tx=1$，故强对偶性成立且存在最优解 $(\lambda^\star,\nu^\star)$。



设我们已解出对偶问题。$(\lambda^\star,\nu^\star)$ 处的拉格朗日函数为

```math
L(x,\lambda^\star,\nu^\star)=\sum_{i=1}^nx_i\log x_i+\lambda^{\star T}(Ax-b)+\nu^\star(\mathbf{1}^Tx-1),
```

它在 $\mathcal{D}$ 上严格凸且有下界，所以有唯一解 $x^\star$：

```math
x_i^\star=1/\exp(a_i^T\lambda^\star+\nu^\star+1),\qquad i=1,\dots,n.
```

若 $x^\star$ 原始可行，它必是原始问题 (5.13) 的最优解。若 $x^\star$ 不原始可行，则可断定原始最优未被达到。

<span style="color:#00838f;">**[例 5.4]** **等式约束下最小化可分函数。** 考虑问题

```math
\begin{aligned}
\text{minimize}\quad & f_0(x)=\sum_{i=1}^nf_i(x_i)\\
\text{subject to}\quad & a^Tx=b,
\end{aligned}
```

$a\in\mathbb{R}^n$、$b\in\mathbb{R}$、$f_i:\mathbb{R}\to\mathbb{R}$ 可微且严格凸。目标函数称为 separable（可分）的，因为它是单个变量 $x_1,\dots,x_n$ 的函数之和。设 $f_0$ 的定义域与约束集相交，即存在 $x_0\in\mathbf{dom}\,f_0$ 满足 $a^Tx_0=b$。这蕴含问题有唯一最优点 $x^\star$。

拉格朗日函数为

```math
L(x,\nu)=\sum_{i=1}^nf_i(x_i)+\nu(a^Tx-b)=-b\nu+\sum_{i=1}^n(f_i(x_i)+\nu a_ix_i),
```

也可分，所以对偶函数为

```math
\begin{aligned}
g(\nu)&=-b\nu+\inf_x\Bigl(\sum_{i=1}^n(f_i(x_i)+\nu a_ix_i)\Bigr)\\
&=-b\nu+\sum_{i=1}^n\inf_{x_i}(f_i(x_i)+\nu a_ix_i)\\
&=-b\nu-\sum_{i=1}^nf_i^*(-\nu a_i).
\end{aligned}
```

对偶问题为

```math
\text{maximize}\quad -b\nu-\sum_{i=1}^nf_i^*(-\nu a_i),
```

（标量）变量 $\nu\in\mathbb{R}$。

现在设我们找到了最优对偶变量 $\nu^\star$。（有几种求解单标量变量凸问题的简单方法，如二分法。）由于每个 $f_i$ 严格凸，$L(x,\nu^\star)$ 关于 $x$ 严格凸，有唯一最小化点 $\tilde{x}$。但我们还知道 $x^\star$ 最小化 $L(x,\nu^\star)$，所以必有 $\tilde{x}=x^\star$。可以从 $\nabla_xL(x,\nu^\star)=0$ 恢复 $x^\star$，即解方程 $f_i'(x_i^\star)=-\nu^\star a_i$。

## <span style="color:#c0392b;">5.6 Perturbation and sensitivity analysis（扰动与敏感性分析）</span>

当强对偶性成立时，最优对偶变量给出关于最优值对约束扰动的敏感性的非常有用的信息。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">5.6.1 The perturbed problem（扰动问题）</span>

考虑原优化问题 (5.1) 的如下 perturbed（扰动）版本：

```math
\begin{aligned}
\text{minimize}\quad & f_0(x)\\
\text{subject to}\quad & f_i(x)\le u_i,\quad i=1,\dots,m\\
& h_i(x)=v_i,\quad i=1,\dots,p,
\end{aligned} \tag{5.56}
```



变量 $x\in\mathbb{R}^n$。当 $u=0,v=0$ 时此问题与原问题 (5.1) 一致。$u_i$ 为正表示放宽了第 $i$ 个不等式约束；$u_i$ 为负表示收紧了约束。因此扰动问题 (5.56) 是把每个不等式约束收紧或放宽 $u_i$、把等式约束右端改变 $v_i$ 后的原问题 (5.1)。

我们定义 $p^\star(u,v)$ 为扰动问题 (5.56) 的最优值：

```math
p^\star(u,v)=\inf\{f_0(x) \mid \exists x\in\mathcal{D},\ f_i(x)\le u_i,\ i=1,\dots,m,\ h_i(x)=v_i,\ i=1,\dots,p\}.
```

可能有 $p^\star(u,v)=\infty$，对应导致不可行的约束扰动。注意 $p^\star(0,0)=p^\star$（未扰动问题 (5.1) 的最优值）。（希望这点轻微的记号滥用不会引起混淆。）粗略地说，函数 $p^\star:\mathbb{R}^m\times\mathbb{R}^p\to\mathbb{R}$ 给出问题最优值作为约束右端扰动的函数。

原问题凸时，函数 $p^\star$ 是 $u,v$ 的凸函数；事实上它的上图正是 (5.37) 定义的集合 $\mathcal{A}$ 的闭包（见习题 5.32）。

### <span style="color:#2471a3;">**[section]**</span> <span style="color:#c0392b;">5.6.2 A global inequality（全局不等式）</span>

<!-- p.264/265 -->

现在设强对偶性成立且对偶最优达到。（原问题凸且满足 Slater 条件时即如此。）设 $(\lambda^\star,\nu^\star)$ 对未扰动问题的对偶 (5.16) 最优。则对所有 $u,v$：

```math
p^\star(u,v)\ge p^\star(0,0)-\lambda^{\star T}u-\nu^{\star T}v. \tag{5.57}
```

为确立此不等式，设 $x$ 是扰动问题的任何可行点（即 $f_i(x)\le u_i$（$i=1,\dots,m$）、$h_i(x)=v_i$（$i=1,\dots,p$））。则由强对偶性：

```math
\begin{aligned}
p^\star(0,0)=g(\lambda^\star,\nu^\star)&\le f_0(x)+\sum_{i=1}^m\lambda_i^\star f_i(x)+\sum_{i=1}^p\nu_i^\star h_i(x)\\
&\le f_0(x)+\lambda^{\star T}u+\nu^{\star T}v.
\end{aligned}
```

（第一个不等式由 $g(\lambda^\star,\nu^\star)$ 的定义；第二个由 $\lambda^\star\succeq0$。）我们得出：对扰动问题的任何可行 $x$，

```math
f_0(x)\ge p^\star(0,0)-\lambda^{\star T}u-\nu^{\star T}v,
```

由得 (5.57)。
