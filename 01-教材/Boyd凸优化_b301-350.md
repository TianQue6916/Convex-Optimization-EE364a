<span style="color:#1e8449;">**[译注]** 这一页给出了一个判断标准：**好的重建不是「更平滑」，而是「在正确的惩罚下更平滑」**。要理解 $\ell_1$ 类正则为什么能保边，得先看两把尺子的差别。

**机制（几何版）。** 目标 $f(x) = \|Ax-b\|_2^2 + \gamma\|x\|_1$ 与约束版 $\min \|Ax-b\|_2^2\ \text{s.t.}\ \|x\|_1 \le t$ 是同一件事的两种写法（Lagrange 乘子 $\gamma$ 与 $t$ 一一对应，因为 $\|x\|_1$ 凸，见原书 §5.5.4 关于 scalarization 的讨论）。关键几何事实：$\ell_2$ 单位球是光滑曲面，$\ell_1$ 单位球的二维截面是**菱形**；菱形有顶点，而顶点恰好在坐标轴上（$(\pm 1, 0)$、$(0, \pm 1)$）。least-squares 的等值椭球从外面收缩进来，最先接触到的往往就是某个顶点所在的低维面——于是解里出现**整块为 0 的分量**。这是「稀疏」的全部来源，没有更神秘的机制。把 $\ell_2$ 换成 $\ell_1$ 之后，惩罚函数在坐标轴方向不可微，最优性条件从 $\nabla f = 0$ 变成 $0 \in \partial f$；代价是闭式解没了，收益是解落在低维面上。

**可直接验证的 3 行推导。** 取 $A = I$（相当于逐分量独立），问题退化为 $\min_x \tfrac{1}{2}\|x-b\|_2^2 + \gamma\|x\|_1$。对每个分量独立写 subgradient 条件 $0 \in x_i - b_i + \gamma\,\partial|x_i|$，解得 soft-thresholding（软阈值）$x_i = \mathbf{sign}(b_i)\max(|b_i| - \gamma, 0)$：小于 $\gamma$ 的分量被**精确压成 0**，而不是「变小」。这解释了问题 (6.11) 为什么能用扫描 $\gamma$ 的办法去「数」非零元个数（例 6.4 的做法）：$\gamma$ 每跨过某个 $|b_i|$，就有一个分量掉到 0，$\mathbf{card}(x)$ 单调下降。

**消失测试。** 抽掉 $\ell_1$ 惩罚、只留 Tikhonov（$\|x\|_2^2$）：解是 $(\bar A^T\bar A + \delta I)^{-1}\bar A^T b$，一般**每个分量都非零**。于是例 6.4 那个「恰用 $k$ 个回归量」的问题根本写不出来——$\mathbf{card}(x)$ 是整数值函数且非凸，进不了凸问题的 constraint；剩下的办法只有枚举 $\binom{n}{k}$ 个 sparsity pattern（原书正是这么说的：$n!/(k!(n-k)!)$ 次 least-squares）。$n = 20$、$k = 1$ 时是 20 次，还好；$n = 10000$、$k = 50$ 时是 $10^{108}$ 量级，彻底不可行。也就是说：**去掉 $\ell_1$，稀疏建模这一整条线（压缩感知、Lasso、稀疏回归）从「多项式时间可解的凸问题」退化回「组合爆炸」。**

**$\ell_1$ 与 $\ell_0$ 的关系（这条最容易被教程讲错）。** 严格的稀疏目标是 $\|x\|_0 = \mathbf{card}(x)$，属 NP-hard。$\ell_1$ 在单位球意义上与它的**convex hull 精确对应**：$\{x : \|x\|_1 \le 1\} = \mathbf{conv}\{\pm e_1, \ldots, \pm e_n\}$，而 $\ell_0$ 的「单位球」只有那 $2n$ 个点。所以「用 $\ell_1$ 代替 $\ell_0$」不是拍脑袋的松弛，而是取凸包；Kashin–Temlyakov、Donoho–Tao（2004–2005）把「什么时候这个凸包松弛给出与原 $\ell_0$ 解**完全相同**的解」变成了可判定条件（spark / RIP / incoherence），这是压缩感知成立与否的分界线，而不是宣传语。

**落点（可点开）**：Boyd §6.3.2 的 (6.11) 与原书 p.310 的例 6.4；§6.5.4 basis pursuit；§11.4「$\ell_1$-norm approximation 的内点法」；习题 6.8（$\ell_1/\ell_\infty$ 的 sum-of-norms 化为 LP）；EE364a lecture 10（$\ell_1$ methods）与 lecture 19–20。上游挂点：Strang 线代的「凸多面体顶点 = 基本可行解」给你「最优解落在顶点」的直觉；Thomson 实分析里 $\ell_p$ 空间随 $p$ 减小而「更尖」的范数包含关系，是同一几何事实的分析版。下游实验：把 soft-thresholding 写成 5 行 NumPy 与 `sklearn.linear_model.Lasso` 对拍，就能看到扫描 $\gamma$ 时 $\mathbf{card}(x)$ 的阶梯式下降。</span>

## 6.4 Robust approximation（鲁棒近似）

### 6.4.1 Stochastic robust approximation（随机鲁棒近似）

我们考虑一个 basic objective 为 $\|Ax-b\|$ 的 approximation problem，但同时希望把数据矩阵 $A$ 的某种 uncertainty（不确定性）或可能的 variation 考虑进去。（同样的想法可以推广到 $A$ 与 $b$ 都有 uncertainty 的情形。）本节考虑 $A$ 变动的几种统计模型。

我们假定 $A$ 是取值在 $\mathbf{R}^{m\times n}$ 中的 random variable（随机变量），均值为 $\bar A$，于是可以把 $A$ 描述为

```math
A = \bar A + U,
```

其中 $U$ 是零均值的 random matrix（随机矩阵）。这里常数矩阵 $\bar A$ 给出 $A$ 的平均值，$U$ 描述它的统计变动。

自然地，我们用 $\|Ax-b\|$ 的 expected value（期望值）作为 objective：

```math
\begin{array}{ll}
\text{minimize} & \mathbf{E}\|Ax - b\|.
\end{array}
\qquad (6.13)
```

我们把它称为 stochastic robust approximation problem（随机鲁棒近似问题）。它**总是** convex optimization problem，但通常**不可 tractable**，因为多数情况下计算目标函数或其导数极为困难。

能够求解 stochastic robust approximation problem (6.13) 的一个简单情形，是 $A$ 只取有限个值，也就是

```math
\mathbf{prob}(A = A_i) = p_i, \qquad i = 1, \ldots, k,
```

其中 $A_i \in \mathbf{R}^{m\times n}$、$\mathbf{1}^T p = 1$、$p \succeq 0$。此时问题 (6.13) 具有形式

```math
\begin{array}{ll}
\text{minimize} & p_1\|A_1 x - b\| + \cdots + p_k\|A_k x - b\|,
\end{array}
```

这通常称为 sum-of-norms problem（范数之和问题）。它可以表述为

```math
\begin{array}{ll}
\text{minimize} & p^T t \\
\text{subject to} & \|A_i x - b\| \le t_i, \qquad i = 1, \ldots, k,
\end{array}
```

其中 variable 是 $x \in \mathbf{R}^n$ 与 $t \in \mathbf{R}^k$。若该 norm 取 Euclidean norm，这个 sum-of-norms problem 是 SOCP；若取 $\ell_1$- 或 $\ell_\infty$-norm，则它可以表述为 LP；见 exercise 6.8。

stochastic robust approximation problem (6.13) 的某些变体是 tractable 的。举一例，考虑 stochastic robust least-squares problem（随机鲁棒最小二乘问题）

```math
\begin{array}{ll}
\text{minimize} & \mathbf{E}\|Ax - b\|_2^2,
\end{array}
```

其中 norm 取 Euclidean norm。我们可以把 objective 写成

```math
\begin{aligned}
\mathbf{E}\|Ax - b\|_2^2
&= \mathbf{E}(\bar A x - b + Ux)^T(\bar A x - b + Ux) \\
&= (\bar A x - b)^T(\bar A x - b) + \mathbf{E}\, x^T U^T U x \\
&= \|\bar A x - b\|_2^2 + x^T P x,
\end{aligned}
```



（页眉：6.4 Robust approximation · 原书 p.319）

其中 $P = \mathbf{E}\,U^T U$。于是 stochastic robust approximation problem 具有 regularized least-squares problem 的形式

```math
\begin{array}{ll}
\text{minimize} & \|\bar A x - b\|_2^2 + \|P^{1/2}x\|_2^2,
\end{array}
```

其解为

```math
x = (\bar A^T \bar A + P)^{-1}\bar A^T b.
```

这完全说得通：当矩阵 $A$ 存在变动时，$x$ 越大，向量 $Ax$ 的变动就越大；而 Jensen's inequality（Jensen 不等式）告诉我们，$Ax$ 的变动会抬高 $\|Ax-b\|_2^2$ 的平均值。所以我们要在「使 $\bar A x - b$ 小」与「希望 $x$ 小」（从而让 $Ax$ 的变动小）之间取得平衡，这正是 regularization 的本质思想。

这个观察给出 Tikhonov regularized least-squares problem (6.10) 的另一种解释：把它看成一个把矩阵 $A$ 可能的 variation 考虑在内的 robust least-squares problem。Tikhonov 正则最小二乘问题 (6.10) 的解，minimize 的是 $\mathbf{E}\|(A+U)x-b\|_2^2$，其中 $U_{ij}$ 是零均值、互不相关的 random variable，方差为 $\delta/m$（而这里 $A$ 是确定性的）。

### 6.4.2 Worst-case robust approximation（最坏情形鲁棒近似）

我们也可以用基于集合的、worst-case（最坏情形）的方式来建模矩阵 $A$ 的变动。用一个 $A$ 的可能取值集合来描述这种 uncertainty：

```math
A \in \mathcal{A} \subseteq \mathbf{R}^{m\times n},
```

并假定该集合非空且有界。我们定义 candidate approximate solution（候选近似解）$x \in \mathbf{R}^n$ 所对应的 worst-case error（最坏情形误差）为

```math
e_{\mathrm{wc}}(x) = \sup\{\|Ax - b\| \mid A \in \mathcal{A}\},
```

它总是 $x$ 的 convex 函数。(worst-case) robust approximation problem 就是 minimize 最坏情形误差：

```math
\begin{array}{ll}
\text{minimize} & e_{\mathrm{wc}}(x) = \sup\{\|Ax - b\| \mid A \in \mathcal{A}\},
\end{array}
\qquad (6.14)
```

其中 variable 是 $x$，problem data 是 $b$ 与集合 $\mathcal{A}$。当 $\mathcal{A}$ 是单点集 $\mathcal{A} = \{A\}$ 时，robust approximation problem (6.14) 退化为基本的 norm approximation problem (6.1)。robust approximation problem 总是 convex optimization problem，但它的 tractability 取决于所用的 norm 以及 uncertainty set $\mathcal{A}$ 的描述方式。

robust approximation problem (6.14) 出现在许多背景与应用中。在 estimation（估计）的语境里，集合 $\mathcal{A}$ 给出的是我们对「待估向量与测量向量之间的线性关系」的不确定性。有时模型 $y = Ax + v$ 中的噪声项 $v$ 被称为 additive noise（加性噪声）或 additive error（加性误差），因为它是加到「理想」测量值 $Ax$ 上去的。相比之下，$A$ 的变动被称为 multiplicative error（乘性误差），因为它乘在 variable $x$ 上。

在 optimal design（最优设计）的语境里，这种变动可以表示「把 design variable $x$ 与 results vector $Ax$ 联系起来的那些线性方程」的不确定性（比如说，来源于制造过程）。此时 robust approximation problem (6.14) 被解释为 robust design problem（鲁棒设计问题）：在所有可能的 $A$ 取值上，找出使 $Ax$ 与 $b$ 之间最坏失配最小的 design variable $x$。

**Finite set（有限集）。** 这里 $\mathcal{A} = \{A_1, \ldots, A_k\}$，robust approximation problem 为

```math
\begin{array}{ll}
\text{minimize} & \max_{i=1,\ldots,k}\|A_i x - b\|.
\end{array}
```

这个问题等价于以多面体集 $\mathcal{A} = \mathbf{conv}\{A_1, \ldots, A_k\}$ 为 uncertainty set 的 robust approximation problem：

```math
\begin{array}{ll}
\text{minimize} & \sup\left\{\|Ax - b\| \mid A \in \mathbf{conv}\{A_1, \ldots, A_k\}\right\}.
\end{array}
```

我们可以把这个问题写成 epigraph form（上境图形式）：

```math
\begin{array}{ll}
\text{minimize} & t \\
\text{subject to} & \|A_i x - b\| \le t, \qquad i = 1, \ldots, k,
\end{array}
```

它可以按所用 norm 的不同、用多种方式求解。若 norm 是 Euclidean norm，这是 SOCP；若用 $\ell_1$- 或 $\ell_\infty$-norm，我们可以把它表述为 LP。

**Norm bound error（范数界误差）。** 这里 uncertainty set $\mathcal{A}$ 是一个 norm ball（范数球），$\mathcal{A} = \{\bar A + U \mid \|U\| \le a\}$，其中 $\|\cdot\|$ 是 $\mathbf{R}^{m\times n}$ 上的一个 norm。此时

```math
e_{\mathrm{wc}}(x) = \sup\{\|\bar A x - b + Ux\| \mid \|U\| \le a\},
```

这个式子必须小心解读：出现的第一个 norm 是在 $\mathbf{R}^m$ 上的（用来度量 residual 的大小），出现的第二个 norm 是在 $\mathbf{R}^{m\times n}$ 上的（用来定义 norm ball $\mathcal{A}$）。

在若干情形下，$e_{\mathrm{wc}}(x)$ 的这个表达式可以化简。举例来说，取 $\mathbf{R}^n$ 上的 Euclidean norm 与 $\mathbf{R}^{m\times n}$ 上相应的 induced norm（诱导范数），也就是最大 singular value（奇异值）。若 $\bar A x - b \neq 0$ 且 $x \neq 0$，则 $e_{\mathrm{wc}}(x)$ 表达式中的 supremum 在 $U = auv^T$ 处取到，其中

```math
u = \frac{\bar A x - b}{\|\bar A x - b\|_2}, \qquad v = \frac{x}{\|x\|_2},
```

而相应的 worst-case error 为

```math
e_{\mathrm{wc}}(x) = \|\bar A x - b\|_2 + a\|x\|_2.
```



（页眉：Chapter 6 Approximation and fitting · 原书 p.322）

（容易验证：当 $x$ 或 $\bar A x - b$ 为零时，这个表达式同样成立。）于是 robust approximation problem (6.14) 成为

```math
\begin{array}{ll}
\text{minimize} & \|\bar A x - b\|_2 + a\|x\|_2,
\end{array}
```

这是一个 regularized norm problem（正则化范数问题），可以作为 SOCP 求解：

```math
\begin{array}{ll}
\text{minimize} & t_1 + at_2 \\
\text{subject to} & \|\bar A x - b\|_2 \le t_1, \\
& \|x\|_2 \le t_2.
\end{array}
```

由于这个问题的最优解与 regularized least-squares problem

```math
\begin{array}{ll}
\text{minimize} & \|\bar A x - b\|_2^2 + \delta\|x\|_2^2
\end{array}
```

在某个 regularization parameter $\delta$ 取值下的解相同，我们便得到 regularized least-squares problem 的又一重解释：它可以看成一个 worst-case robust approximation problem。

**Uncertainty ellipsoids（不确定椭球）。** 我们也可以用「每一行各给一个可能取值的 ellipsoid（椭球）」来描述 $A$ 的变动：

```math
\mathcal{A} = \left\{[a_1\ \cdots\ a_m]^T \mid a_i \in \mathcal{E}_i,\ i = 1, \ldots, m\right\},
```

其中

```math
\mathcal{E}_i = \{\bar a_i + P_i u \mid \|u\|_2 \le 1\}.
```

矩阵 $P_i \in \mathbf{R}^{n\times n}$ 描述 $a_i$ 的变动。我们允许 $P_i$ 有非平凡的 nullspace（零空间），以便建模「$a_i$ 的变动被限制在某个子空间内」这种情形。作为极端情形，若 $a_i$ 没有不确定性，就取 $P_i = 0$。

在这种椭球型 uncertainty 描述下，我们可以给出每个 residual 的最坏情形大小的显式表达式：

```math
\begin{aligned}
\sup_{a_i \in \mathcal{E}_i}|a_i^T x - b_i|
&= \sup\left\{|\bar a_i^T x - b_i + (P_i u)^T x| \mid \|u\|_2 \le 1\right\} \\
&= |\bar a_i^T x - b_i| + \|P_i^T x\|_2.
\end{aligned}
```

利用这个结果，我们可以求解若干 robust approximation problem。例如 robust $\ell_2$-norm approximation problem

```math
\begin{array}{ll}
\text{minimize} & e_{\mathrm{wc}}(x) = \sup\left\{\|Ax - b\|_2 \mid a_i \in \mathcal{E}_i,\ i = 1, \ldots, m\right\}
\end{array}
```

可以归约为一个 SOCP，做法如下。worst-case error 的显式表达式为

```math
\begin{aligned}
e_{\mathrm{wc}}(x)
&= \left(\sum_{i=1}^{m}\left(\sup_{a_i \in \mathcal{E}_i}|a_i^T x - b_i|\right)^2\right)^{1/2} \\
&= \left(\sum_{i=1}^{m}\left(|\bar a_i^T x - b_i| + \|P_i^T x\|_2\right)^2\right)^{1/2}.
\end{aligned}
```

为 minimize $e_{\mathrm{wc}}(x)$，我们可以求解

```math
\begin{array}{ll}
\text{minimize} & \|t\|_2 \\
\text{subject to} & |\bar a_i^T x - b_i| + \|P_i^T x\|_2 \le t_i, \qquad i = 1, \ldots, m,
\end{array}
```



（页眉：6.4 Robust approximation · 原书 p.323）

这里我们引入了新 variable $t_1, \ldots, t_m$。这个问题可以写成

```math
\begin{array}{ll}
\text{minimize} & \|t\|_2 \\
\text{subject to} & \bar a_i^T x - b_i + \|P_i^T x\|_2 \le t_i, \qquad i = 1, \ldots, m \\
& -\bar a_i^T x + b_i + \|P_i^T x\|_2 \le t_i, \qquad i = 1, \ldots, m,
\end{array}
```

把它放进 epigraph form 之后，就成为一个 SOCP。

**Norm bounded error with linear structure（带线性结构的范数界误差）。** 作为 norm bound 描述 $\mathcal{A} = \{\bar A + U \mid \|U\| \le a\}$ 的推广，我们可以把 $\mathcal{A}$ 定义为 norm ball 在一个 affine transformation（仿射变换）下的像：

```math
\mathcal{A} = \{\bar A + u_1 A_1 + u_2 A_2 + \cdots + u_p A_p \mid \|u\| \le 1\},
```

其中 $\|\cdot\|$ 是 $\mathbf{R}^p$ 上的一个 norm，$p+1$ 个矩阵 $\bar A, A_1, \ldots, A_p \in \mathbf{R}^{m\times n}$ 给定。worst-case error 可以表述为

```math
\begin{aligned}
e_{\mathrm{wc}}(x)
&= \sup_{\|u\| \le 1}\|(\bar A + u_1 A_1 + \cdots + u_p A_p)x - b\| \\
&= \sup_{\|u\| \le 1}\|P(x)u + q(x)\|,
\end{aligned}
```

其中 $P$ 与 $q$ 定义为

```math
P(x) = \begin{bmatrix} A_1 x & A_2 x & \cdots & A_p x \end{bmatrix} \in \mathbf{R}^{m\times p}, \qquad q(x) = \bar A x - b \in \mathbf{R}^m.
```

作为第一个例子，我们考虑 robust Chebyshev approximation problem（鲁棒 Chebyshev 近似问题）

```math
\begin{array}{ll}
\text{minimize} & e_{\mathrm{wc}}(x) = \sup_{\|u\|_\infty \le 1}\|(\bar A + u_1 A_1 + \cdots + u_p A_p)x - b\|_\infty.
\end{array}
```

在这个情形下我们可以导出 worst-case error 的显式表达式。设 $p_i(x)^T$ 表示 $P(x)$ 的第 $i$ 行，则

```math
\begin{aligned}
e_{\mathrm{wc}}(x)
&= \sup_{\|u\|_\infty \le 1}\|P(x)u + q(x)\|_\infty \\
&= \max_{i=1,\ldots,m}\ \sup_{\|u\|_\infty \le 1}|p_i(x)^T u + q_i(x)| \\
&= \max_{i=1,\ldots,m}\left(\|p_i(x)\|_1 + |q_i(x)|\right).
\end{aligned}
```

因此 robust Chebyshev approximation problem 可以写成 LP

```math
\begin{array}{ll}
\text{minimize} & t \\
\text{subject to} & -y_0 \preceq \bar A x - b \preceq y_0 \\
& -y_k \preceq A_k x \preceq y_k, \qquad k = 1, \ldots, p \\
& y_0 + \sum_{k=1}^{p} y_k \preceq t\mathbf{1},
\end{array}
```

其中 variable 是 $x \in \mathbf{R}^n$、$y_k \in \mathbf{R}^m$、$t \in \mathbf{R}$。

作为另一个例子，我们考虑 robust least-squares problem

```math
\begin{array}{ll}
\text{minimize} & e_{\mathrm{wc}}(x) = \sup_{\|u\|_2 \le 1}\|(\bar A + u_1 A_1 + \cdots + u_p A_p)x - b\|_2.
\end{array}
```



（页眉：Chapter 6 Approximation and fitting · 原书 p.324）

这里我们用 Lagrange duality（Lagrange 对偶）来计算 $e_{\mathrm{wc}}$。worst-case error $e_{\mathrm{wc}}(x)$ 是（非凸的）二次优化问题

```math
\begin{array}{ll}
\text{maximize} & \|P(x)u + q(x)\|_2^2 \\
\text{subject to} & u^T u \le 1
\end{array}
```

（variable 为 $u$）的 optimal value 的平方根。这个问题的 Lagrange dual 可以表述为 SDP

```math
\begin{array}{ll}
\text{minimize} & t + \lambda \\
\text{subject to} & \begin{bmatrix} I & P(x) & q(x) \\ P(x)^T & \lambda I & 0 \\ q(x)^T & 0 & t \end{bmatrix} \succeq 0
\end{array}
\qquad (6.15)
```

其中 variable 是 $t, \lambda \in \mathbf{R}$。而且，正如 §5.2 与 §B.1 中所说（并在 §B.4 中证明），这一对 primal 与 dual 问题之间强对偶成立。换言之，对固定的 $x$，我们可以通过求解以 $t$、$\lambda$ 为 variable 的 SDP (6.15) 来算出 $e_{\mathrm{wc}}(x)^2$。对 $t$、$\lambda$、$x$ 联合优化，等价于 minimize $e_{\mathrm{wc}}(x)^2$。于是我们得出结论：robust least-squares problem 等价于以 $x, \lambda, t$ 为 variable 的 SDP (6.15)。

### 6.5.1 Function families（函数族）

我们考虑一族函数 $f_1, \ldots, f_n : \mathbf{R}^k \to \mathbf{R}$，它们有共同的 domain（定义域）$\mathbf{dom}\,f_i = D$。对每个 $x \in \mathbf{R}^n$，我们联系一个函数 $f : \mathbf{R}^k \to \mathbf{R}$，定义为

```math
f(u) = x_1 f_1(u) + \cdots + x_n f_n(u)
\qquad (6.17)
```

且 $\mathbf{dom}\,f = D$。函数族 $\{f_1, \ldots, f_n\}$ 有时称为（该拟合问题的）basis function（基函数）集合，即使这些函数并不相互独立。用来参数化这个函数子空间的向量 $x \in \mathbf{R}^n$ 是我们的 optimization variable，有时称为 coefficient vector（系数向量）。这些 basis function 生成 $D$ 上函数的一个子空间 $F$。

在许多应用中，basis function 是借助先验知识或经验特意挑选的，目的是用这个有限维函数子空间合理地建模所关心的函数。在另外一些情况下，则使用更通用的 function family。下面介绍其中几种。

**Polynomials（多项式）。** $\mathbf{R}$ 上常见的函数子空间之一，是次数小于 $n$ 的多项式。最简单的基由各次幂构成，即 $f_i(t) = t^{i-1}$，$i = 1, \ldots, n$。在许多应用中，同一个子空间会用另一组基来描述，例如用一组次数小于 $n$ 的多项式 $f_1, \ldots, f_n$，它们关于某个正函数（或测度）$\varphi$ 是 orthonormal（标准正交）的，即

```math
\int f_i(t) f_j(t) \varphi(t)\, dt = \begin{cases} 1 & i = j \\ 0 & i \neq j. \end{cases}
```

†（原文此处把 $\varphi$ 定义域写作 $\mathbf{R}^n \to \mathbf{R}_+$，而积分是对标量 $t$ 进行的，定义域应为 $\mathbf{R}$（或 $D \subset \mathbf{R}$）；这里按积分式语义推定，标 † 说明。）

多项式的另一组常用基，是与互异点 $t_1, \ldots, t_n$ 相关联的 Lagrange basis（Lagrange 基）$f_1, \ldots, f_n$，它们满足

```math
f_i(t_j) = \begin{cases} 1 & i = j \\ 0 & i \neq j. \end{cases}
```

我们也可以考虑 $\mathbf{R}^k$ 上的多项式，取最大总次数受限，或每个变量的最大次数受限。

作为相关的例子，我们有次数小于 $n$ 的三角多项式（trigonometric polynomial），其基为

```math
\sin kt, \quad k = 1, \ldots, n-1; \qquad \cos kt, \quad k = 0, \ldots, n-1.
```

**Piecewise-linear functions（分段线性函数）。** 我们从区域 $D$ 的一个 triangularization（三角剖分）出发，它的意思是：我们有一组 mesh（网格）点或 grid point $g_1, \ldots, g_n \in \mathbf{R}^k$，以及把 $D$ 分成一集 simplex（单纯形）的划分

```math
D = S_1 \cup \cdots \cup S_m, \qquad \mathbf{int}(S_i \cap S_j) = \emptyset \ \text{对}\ i \neq j.
```



（页眉：6.5 Function fitting and interpolation · 原书 p.327）

[Figure 6.17：单位方格上的一个二元 piecewise-linear（分段线性）函数。该 triangularization（三角剖分）由 98 个 simplex 和单位方格上 64 个点的均匀 grid 构成。坐标为 $u_1, u_2 \in [0,1]$，竖轴为 $f(u_1, u_2)$；三个坐标轴的刻度均残留 0/1。曲面形状未从文字层恢复。]

每个 simplex 是 $k+1$ 个 grid point 的 convex hull（凸包），并且我们要求每个 grid point 都是包含它的任何 simplex 的 vertex（顶点）。

给定一个 triangularization，我们可以构造 piecewise-linear（更准确地说，piecewise-affine，分片仿射）函数 $f$：把函数值 $f(g_i) = x_i$ 赋给各 grid point，然后在每个 simplex 上把函数 affine（仿射）地延拓出去。这个函数 $f$ 可以写成 (6.17) 的形式，其中 basis function $f_i$ 在每个 simplex 上是 affine 的，并由下列条件定义

```math
f_i(g_j) = \begin{cases} 1 & i = j \\ 0 & i \neq j. \end{cases}
```

按此构造，这样的函数是连续的。Figure 6.17 给出 $k = 2$ 的一个例子。

**Piecewise polynomials and splines（分片多项式与样条）。** 在已三角剖分的区域上定义 piecewise-affine 函数的想法，很容易推广到 piecewise polynomial（分片多项式）与其他函数。

piecewise polynomial 定义为：在 triangulation 的每个 simplex 上是（某个最高次数的）多项式，并且是连续的，也就是说，这些多项式在 simplex 之间的边界上取值一致。若进一步要求 piecewise polynomial 的导数直到某一阶都连续，就可以定义各种 spline function（样条函数）类。Figure 6.18 给出一个 cubic spline（三次样条）的例子，即 $\mathbf{R}$ 上次数为 3 的分片多项式，其一阶与二阶导数连续。

### 6.5.2 Constraints（约束）

本节描述一些可以加在函数 $f$ 上、因而也加在 variable $x \in \mathbf{R}^n$ 上的约束。

**Function value interpolation and inequalities（函数值插值与不等式）。** 设 $v$ 是 $D$ 中的一点。$f$ 在 $v$ 处的值

```math
f(v) = \sum_{i=1}^{n} x_i f_i(v)
```

是 $x$ 的线性函数。因此，插值条件

```math
f(v_j) = z_j, \qquad j = 1, \ldots, m,
```

（它要求函数 $f$ 在指定点 $v_j \in D$ 处取给定值 $z_j \in \mathbf{R}$）构成 $x$ 的一组线性等式。更一般地，对给定点处函数值的不等式，例如 $l \le f(v) \le u$，是 variable $x$ 上的线性不等式。

还有许多其他有意思的、涉及有限个点 $v_1, \ldots, v_N$ 处函数值的凸约束可以加在 $f$（因而加在 $x$）上。例如，Lipschitz 约束

```math
|f(v_j) - f(v_k)| \le L\|v_j - v_k\|, \qquad j, k = 1, \ldots, m,
```

构成 $x$ 的一组线性不等式。

我们也可以对无限多个点处的函数值施加不等式。例如，考虑 nonnegativity constraint（非负约束）

```math
f(u) \ge 0 \quad \text{对所有}\ u \in D.
```

这是 $x$ 上的凸约束（因为它是无限多个 halfspace 的交），但除非在能利用函数特殊结构的特殊情形下，它可能不可 tractable。一个简单的例子出现在函数为 piecewise-linear 时：此时若函数值在各 grid point 处非负，则函数处处非负，于是我们得到一个简单（有限）的线性不等式组。

作为不那么平凡的例子，考虑函数是 $\mathbf{R}$ 上的多项式、且最高次数为偶数 $2k$（即 $n = 2k+1$）、$D = \mathbf{R}$ 的情形。如习题 2.37（原书 p.65）所示，非负约束

```math
p(u) = x_1 + x_2 u + \cdots + x_{2k+1}u^{2k} \ge 0 \quad \text{对所有}\ u \in \mathbf{R}
```

等价于

```math
x_i = \sum_{m+n=i+1} Y_{mn}, \qquad i = 1, \ldots, 2k+1, \qquad Y \succeq 0,
```

其中 $Y \in \mathbf{S}^{k+1}$ 是 auxiliary variable（辅助变量）。



（页眉：Chapter 6 Approximation and fitting · 原书 p.330）

**Derivative constraints（导数约束）。** 假定 basis function $f_i$ 在某点 $v \in D$ 处可微。gradient

```math
\nabla f(v) = \sum_{i=1}^{n} x_i \nabla f_i(v)
```

是 $x$ 的线性函数，所以关于 $f$ 在 $v$ 处导数的插值条件归结为 $x$ 上的线性等式约束。要求 $v$ 处 gradient 的 norm 不超过给定限值，即

```math
\|\nabla f(v)\| = \left\|\sum_{i=1}^{n} x_i \nabla f_i(v)\right\| \le M,
```

是 $x$ 上的凸约束。同样的想法可以推广到高阶导数。例如，若 $f$ 在 $v$ 处二次可微，则要求

```math
lI \preceq \nabla^2 f(v) \preceq uI
```

是 $x$ 上的 linear matrix inequality（线性矩阵不等式），因而 convex。

†（本式的 $l$ 与 $u$ 是 Hessian 的下界与上界，与同页前面 $l \le f(v) \le u$ 里的 $l$、$u$ 只是符号重用、并无关联；原文未加区分，按位置理解为界常数。）

我们也可以对无限多个点处的导数施加约束。例如，要求 $f$ 单调：

```math
f(u) \ge f(v) \quad \text{对所有}\ u, v \in D,\ u \succeq v.
```

这是 $x$ 上的凸约束，但除非在特殊情形下可能不可 tractable。例如当 $f$ 是 piecewise affine 时，单调性约束等价于在每个 simplex 内部都有 $\nabla f(v) \succeq 0$。由于 gradient 是各 grid point 值的线性函数，这就给出一个简单（有限）的线性不等式组。

又如，我们可以要求函数是 convex 的，即满足

```math
f((u+v)/2) \le (f(u) + f(v))/2 \quad \text{对所有}\ u, v \in D
```

（当 $f$ 连续时，这足以保证 convexity）。这是一个凸约束，在某些情形下有 tractable 的表述。一个明显的例子是 $f$ 为二次函数：此时 convexity 约束归结为要求 $f$ 的二次部分非负，这是一个 LMI。另一个「convexity 约束可化成 tractable 问题」的例子在 §6.5.5 中有更详细的描述。

**Integral constraints（积分约束）。** 函数子空间上的任何 linear functional（线性泛函）$L$ 都可以表示为 $x$ 的线性函数，即 $L(f) = c^T x$。在某点处对 $f$（或某个导数）取值只是其特例。另一个例子是 linear functional

```math
L(f) = \int_D \varphi(u) f(u)\, du,
```



（页眉：6.5 Function fitting and interpolation · 原书 p.331）

其中 $\varphi : \mathbf{R}^k \to \mathbf{R}$，它可以表示为 $L(f) = c^T x$，其中

```math
c_i = \int_D \varphi(u) f_i(u)\, du.
```

于是形如 $L(f) = a$ 的约束就是 $x$ 上的线性等式约束。这类约束的一个例子是 moment constraint（矩约束）

```math
\int_D t^m f(t)\, dt = a
```

（其中 $f : \mathbf{R} \to \mathbf{R}$）。

### 6.5.3 Fitting and interpolation problems（拟合与插值问题）

**Minimum norm function fitting（最小范数函数拟合）。** 在 fitting problem 中，给定数据

```math
(u_1, y_1), \ldots, (u_m, y_m)
```

（$u_i \in D$、$y_i \in \mathbf{R}$），要求找一个函数 $f \in F$，尽可能好地匹配这些数据。例如在 least-squares fitting 中，我们考虑问题

```math
\begin{array}{ll}
\text{minimize} & \sum_{i=1}^{m}(f(u_i) - y_i)^2,
\end{array}
```

它是关于 variable $x$ 的一个简单 least-squares 问题。我们可以加入各种约束，例如 $f$ 在各个点必须满足的线性不等式、对 $f$ 导数的约束、单调性约束，或矩约束。

<span style="color:#6c3483;">**例 6.7　Polynomial fitting（多项式拟合）。** 给定数据 $u_1, \ldots, u_m \in \mathbf{R}$ 与 $v_1, \ldots, v_m \in \mathbf{R}$，希望用形如</span>

```math
p(u) = x_1 + x_2 u + \cdots + x_n u^{n-1}
```

<span style="color:#6c3483;">的多项式去近似拟合这些数据。对每个 $x$，构造误差向量</span>

```math
\end{array}
```

<span style="color:#6c3483;">其中 variable 是 $x \in \mathbf{R}^n$，$A_{ij} = u_i^{j-1}$，$i = 1, \ldots, m$、$j = 1, \ldots, n$。</span>

在最简单的 function fitting 形式中，有 $m \gg n$，即数据点个数远大于函数子空间的维数。smoothing 会自动完成，因为子空间的每个成员都是光滑的。

**Least-norm interpolation（最小范数插值）。** 在 function fitting 的另一种变形中，数据点个数少于函数子空间的维数。在最简单的情形下，我们要求所选的函数必须满足插值条件

```math
f(u_i) = y_i, \qquad i = 1, \ldots, m,
```

这些是 $x$ 上的线性等式约束。在满足这些插值条件的函数中，我们可能希望找最光滑的、或最小的一个。这就引出 least-norm 问题。

在最一般的 function fitting 问题中，我们可以优化某个 objective（例如误差 $e$ 的某种度量），同时服从各种凸约束，这些约束表示我们对底层函数的先验知识。

**Interpolation, extrapolation, and bounding（插值、外推与界）。** 通过在原始数据集合之外的点 $v$ 处对最优函数拟合 $\hat f$ 取值，我们得到底层函数在点 $v$ 处取值的猜测。当 $v$ 位于给定数据点之间或附近（例如 $v \in \mathbf{conv}\{v_1, \ldots, v_m\}$）时，这称为 interpolation（插值）；否则称为 extrapolation（外推）。

我们也可以给出一段区间，使得 $f(v)$ 的取值必在其中：约束不变，maximize 与 minimize（线性函数）$f(v)$ 即可。我们还可以用函数拟合来帮助找出错误数据或 outlier（离群点）。例如，此时可以用 $\ell_1$-norm 拟合，然后寻找误差大的数据点。

### 6.5.4 Sparse descriptions and basis pursuit（稀疏描述与基追踪）

在 basis pursuit（基追踪）中，basis function 的数量非常多，目标是找出「用少数几个 basis function 的 linear combination 就能很好拟合给定数据」的方案。（在这个语境下，该函数族是线性相关的，有时称为 over-complete basis（过完备基）或 dictionary（字典）。）之所以叫 basis pursuit，是因为我们从一个给定的过完备基中挑出一个远小于它的 basis 来建模这些数据。



（页眉：Chapter 6 Approximation and fitting · 原书 p.334）

于是我们要找一个函数 $f \in F$，它很好地拟合数据

```math
f(u_i) \approx y_i, \qquad i = 1, \ldots, m,
```

且 coefficient vector $x$ 稀疏，即 $\mathbf{card}(x)$ 小。此时我们把

```math
f = x_1 f_1 + \cdots + x_n f_n = \sum_{i \in \mathcal{B}} x_i f_i
```

（其中 $\mathcal{B} = \{i \mid x_i \neq 0\}$ 是被选中的 basis element 的下标集合）称为数据的 sparse description（稀疏描述）。从数学上看，basis pursuit 与 regressor selection problem 是同一个问题（见 §6.4†），但优化问题的解释（以及规模）不同。

†（原文两处均写「see §6.4」「described in §6.4」。按本书实际结构，regressor selection problem（例 6.4）位于 **§6.3.2 ℓ1-norm regularization**（原书 p.310），而 §6.4 是 Robust approximation。此处应指 §6.3.2，原文交叉引用有误。）

sparse description 与 basis pursuit 有许多用途。它们可用于 de-noising 或 smoothing，或用于数据压缩，以便高效地传输或存储信号。在数据压缩中，发送方与接收方都知道该 dictionary（即各 basis element）。为把信号发给接收方，发送方先求出该信号的一个稀疏表示，然后只把非零系数（到某个精度）发送出去。利用这些系数，接收方可以重建原信号的（一个近似）。

basis pursuit 的一种常用做法与 §6.4† 中描述的 regressor selection 方法相同，都是基于把 $\ell_1$-norm regularization 作为寻找稀疏描述的 heuristic。我们先求解凸问题

```math
\begin{array}{ll}
\text{minimize} & \sum_{i=1}^{m}(f(u_i) - y_i)^2 + \gamma\|x\|_1,
\end{array}
\qquad (6.18)
```

其中 $\gamma \gt 0$ 是一个参数，用来在拟合数据的质量与 coefficient vector 的稀疏性之间折衷。这个问题的解可以直接使用，也可以再接一个 refinement（精修）步骤：用 (6.18) 的解的 sparsity pattern 去求最佳拟合。换言之，我们先解 (6.18) 得到 $\hat x$；然后取 $\mathcal{B} = \{i \mid \hat x_i \neq 0\}$，即非零系数对应的下标集合；再求解 least-squares 问题

```math
\begin{array}{ll}
\text{minimize} & \sum_{i=1}^{m}(f(u_i) - y_i)^2
\end{array}
```

其中 variable 是 $x_i$（$i \in \mathcal{B}$），而 $x_i = 0$（$i \notin \mathcal{B}$）。

### 6.5.5 Interpolation with convex functions（用凸函数插值）

在某些特殊情形下，我们可以用有限维凸优化来求解涉及无穷维函数集合的插值问题。本节描述一个例子。

我们从下面的问题出发：什么时候存在一个 convex 函数 $f : \mathbf{R}^k \to \mathbf{R}$（$\mathbf{dom}\,f = \mathbf{R}^k$），满足插值条件

```math
f(u_i) = y_i, \qquad i = 1, \ldots, m,
```



（页眉：Chapter 6 Approximation and fitting · 原书 p.338）

其中 $u_i \in \mathbf{R}^k$ 给定？（这里我们**不**把 $f$ 限制在任何有限维函数子空间内。）答案是：当且仅当存在 $g_1, \ldots, g_m$ 使

```math
y_j \ge y_i + g_i^T(u_j - u_i), \qquad i, j = 1, \ldots, m.
\qquad (6.19)
```

先看必要性：设 $f$ 是 convex 的、$\mathbf{dom}\,f = \mathbf{R}^k$ 且 $f(u_i) = y_i$（$i = 1, \ldots, m$）。在每个 $u_i$ 处我们能找到一个向量 $g_i$，使得

```math
f(z) \ge f(u_i) + g_i^T(z - u_i)
\qquad (6.20)
```

对一切 $z$ 成立。若 $f$ 可微，可取 $g_i = \nabla f(u_i)$；在更一般的情形下，可以通过求 $\mathbf{epi}\,f$ 在 $(u_i, y_i)$ 处的支撑超平面来构造 $g_i$。（这些向量 $g_i$ 称为 subgradient。）把 (6.20) 用于 $z = u_j$ 即得 (6.19)。

反过来，设 $g_1, \ldots, g_m$ 满足 (6.19)。定义 $f$ 为

```math
f(z) = \max_{i=1,\ldots,m}\left(y_i + g_i^T(z - u_i)\right), \qquad \text{对所有}\ z \in \mathbf{R}^k.
```

显然 $f$ 是（piecewise-linear 的）convex 函数；(6.19) 中的不等式蕴含 $f(u_i) = y_i$（$i = 1, \ldots, m$）。

我们可以用这个结果求解若干涉及 convex 函数插值、近似或求界的问题。

**Fitting a convex function to given data（用凸函数拟合给定数据）。** 最简单的应用大概是：对给定数据 $(u_i, y_i)$（$i = 1, \ldots, m$）计算 convex 函数的 least-squares 拟合：

```math
\begin{array}{ll}
\text{minimize} & \sum_{i=1}^{m}(y_i - f(u_i))^2 \\
\text{subject to} & f : \mathbf{R}^k \to \mathbf{R}\ \text{是 convex 的}, \quad \mathbf{dom}\,f = \mathbf{R}^k.
\end{array}
```

这是一个无穷维问题，因为 variable 是 $f$，而 $f$ 位于 $\mathbf{R}^k$ 上连续实值函数构成的空间中。利用上面的结果，我们可以把它表述为

```math
\begin{array}{ll}
\text{minimize} & \sum_{i=1}^{m}(y_i - \hat y_i)^2 \\
\text{subject to} & \hat y_j \ge \hat y_i + g_i^T(u_j - u_i), \qquad i, j = 1, \ldots, m,
\end{array}
```

这是一个 QP，variable 为 $\hat y \in \mathbf{R}^m$ 与 $g_1, \ldots, g_m \in \mathbf{R}^k$。这个问题的 optimal value 为零，当且仅当给定数据能被某个 convex 函数插值，即存在满足 $f(u_i) = y_i$ 的 convex 函数。一个例子见 Figure 6.24。

**Bounding values of an interpolating convex function（给插值凸函数的取值定界）。** 作为另一个简单例子，设给定数据 $(u_i, y_i)$（$i = 1, \ldots, m$）可以被某个 convex 函数插值。我们希望确定 $f(u_0)$ 可能取值的范围，其中 $u_0$ 是 $\mathbf{R}^k$ 中的另一点，$f$ 是任何能插值给定数据的 convex 函数。为求 $f(u_0)$ 的最小可能值，我们求解 LP

```math
\begin{array}{ll}
\text{minimize} & y_0 \\
\text{subject to} & y_j \ge y_i + g_i^T(u_j - u_i), \qquad i, j = 0, \ldots, m,
\end{array}
```

<span style="color:#1e8449;">**[译注]** (6.19) 是全节的技术心脏：它把「存在一个**无限维**凸函数 $f$」这个可行性问题，压成 $m^2$ 条关于 $m(k+1)$ 个实数的线性不等式。机制是凸性的支撑超平面刻画——凸性等价于「每点都有一张支撑超平面」，即存在 subgradient $g_i$ 使 (6.20) 对一切 $z$ 成立；而 $z$ 只需取到其余数据点 $u_j$，无限多条条件立刻坍缩为 $m(m-1)$ 条。反过来 $f(z)=\max_i\left(y_i+g_i^T(z-u_i)\right)$ 的构造保证这组必要条件也充分，且给出的恰是 piecewise-linear 凸函数。**消失测试**：抽掉 (6.19)，本节三个应用全部失去可解形式——凸函数最小二乘拟合（QP）、$f(u_0)$ 的上下界（两个 LP）、单调凸插值 (6.21)（多出 $g_i \succeq 0$）、消费者偏好 (6.25)（一个 LP 可行性问题）——都只能退回对函数空间做网格离散，而网格一加密，$m^2$ 条约束就变成 $N^2$，且离散化本身会破坏「凸」这个约束的精确性。**方向感**：从无限维锥规划降到 $m^2$ 条线性不等式（$m=40$ 时 1600 条，LP 瞬间可解）。落点：§6.5.5 本页、习题 6.12；实分析侧即「凸函数在每点有支撑线（次梯度）」，Thomson 的 convex function 一节，[节号未定位]。</span>

这是一个 LP，variable 为 $y_0 \in \mathbf{R}$ 与 $g_0, \ldots, g_m \in \mathbf{R}^k$。通过 maximize $y_0$（同样是一个 LP），我们得到「能插值给定数据的 convex 函数」在 $u_0$ 处可能取到的最大值。

**Interpolation with monotone convex functions（用单调凸函数插值）。** 作为 convex 插值的推广，我们可以考虑用既 convex 又单调非减的函数来插值。可以证明：存在 convex 函数 $f : \mathbf{R}^k \to \mathbf{R}$（$\mathbf{dom}\,f = \mathbf{R}^k$）满足插值条件

```math
f(u_i) = y_i, \qquad i = 1, \ldots, m,
```

并且是单调非减的（即 $u \succeq v$ 时 $f(u) \ge f(v)$），当且仅当存在 $g_1, \ldots, g_m \in \mathbf{R}^k$ 使

```math
g_i \succeq 0,\quad i = 1, \ldots, m; \qquad y_j \ge y_i + g_i^T(u_j - u_i),\quad i, j = 1, \ldots, m.
\qquad (6.21)
```

换言之，我们在 convex 插值条件 (6.19) 之上，再加上「所有 subgradient $g_i$ 都非负」这一条件。（见 exercise 6.12。）

**Bounding consumer preference（给消费者偏好定界）。** 作为一个应用，我们考虑预测消费者偏好的问题。我们考虑不同的商品组合（basket of goods），它们由 $n$ 种消费品的不同数量构成。一个商品组合由向量 $x \in [0,1]^n$ 刻画，其中 $x_i$ 表示第 $i$ 种消费品的数量。我们假定数量已归一化，使 $0 \le x_i \le 1$，即 $x_i = 0$ 是第 $i$ 种商品可能的最小数量，$x_i = 1$ 是最大数量。给定两个商品组合 $x$ 与 $\tilde x$，一个消费者可以偏好 $x$ 胜过 $\tilde x$，或偏好 $\tilde x$ 胜过 $x$，或认为两者同样有吸引力。我们考虑一个模型消费者，其选择是可重复的。



（页眉：Chapter 6 Approximation and fitting · 原书 p.340）

我们按如下方式建模消费者偏好。假定存在一个底层 utility function（效用函数）$u : \mathbf{R}^n \to \mathbf{R}$，定义域为 $[0,1]^n$；$u(x)$ 给出消费者从商品组合 $x$ 中获得的效用的度量。在两个商品组合之间做选择时，消费者选效用较大的那个；当两个组合效用相等时他会无所谓。假定 $u$ 单调非减是合理的：这意味着在其他商品数量不变时，消费者总偏好任何一种商品更多。假定 $u$ 是 concave 的同样合理：这建模了 satiation（饱和），即随商品数量增加而出现的 marginal utility（边际效用）递减。

现在设给定了一些消费者偏好数据，但我们不知道底层的 utility function $u$。具体地说，我们有一组商品组合 $a_1, \ldots, a_m \in [0,1]^n$，以及关于它们之间偏好的一些信息：

```math
u(a_i) \gt u(a_j)\ \text{对}\ (i,j) \in P, \qquad u(a_i) \ge u(a_j)\ \text{对}\ (i,j) \in P_{\mathrm{weak}},
\qquad (6.22)
```

其中 $P, P_{\mathrm{weak}} \subseteq \{1,\ldots,m\}\times\{1,\ldots,m\}$ 给定。这里 $P$ 给出已知偏好的集合：$(i,j) \in P$ 表示已知组合 $a_i$ 优于组合 $a_j$；$P_{\mathrm{weak}}$ 给出已知弱偏好的集合：$(i,j) \in P_{\mathrm{weak}}$ 表示组合 $a_i$ 优于组合 $a_j$，或两个组合同样有吸引力。

我们先考虑下面的问题：如何判定给定数据是否一致，即是否存在一个 concave 非减的 utility function $u$ 使 (6.22) 成立？这等价于求解 feasibility problem（可行性问题）

```math
\begin{array}{ll}
\text{find} & u \\
\text{subject to} & u : \mathbf{R}^n \to \mathbf{R}\ \text{concave 且非减} \\
& u(a_i) \gt u(a_j), \quad (i,j) \in P \\
& u(a_i) \ge u(a_j), \quad (i,j) \in P_{\mathrm{weak}},
\end{array}
\qquad (6.23)
```

其中函数 $u$ 是（无穷维的）optimization variable。由于 (6.23) 中的约束都是齐次的，我们可以把问题写成等价形式

```math
\begin{array}{ll}
\text{find} & u \\
\text{subject to} & u : \mathbf{R}^n \to \mathbf{R}\ \text{concave 且非减} \\
& u(a_i) \ge u(a_j) + 1, \quad (i,j) \in P \\
& u(a_i) \ge u(a_j), \quad (i,j) \in P_{\mathrm{weak}},
\end{array}
\qquad (6.24)
```

它只使用非严格不等式。（显然，若 $u$ 满足 (6.24)，它必满足 (6.23)；反之，若 $u$ 满足 (6.23)，可以通过缩放使它满足 (6.24)。）这个问题又可以借助原书 p.339 的插值结果，写成一个（有限维）linear programming feasibility problem：

```math
\begin{array}{ll}
\text{find} & u_1, \ldots, u_m, g_1, \ldots, g_m \\
\text{subject to} & g_i \succeq 0, \quad i = 1, \ldots, m \\
& u_j \le u_i + g_i^T(a_j - a_i), \quad i, j = 1, \ldots, m \\
& u_i \ge u_j + 1, \quad (i,j) \in P \\
& u_i \ge u_j, \quad (i,j) \in P_{\mathrm{weak}}.
\end{array}
\qquad (6.25)
```

通过求解这个 linear programming feasibility problem，我们可以判定是否存在与



（页眉：6.5 Function fitting and interpolation · 原书 p.341）

给定的严格偏好集与非严格偏好集都一致的 concave 非减 utility function。若 (6.25) 可行，则至少存在一个这样的 utility function（而且确实可以从一个可行的 $u_1, \ldots, u_m, g_1, \ldots, g_m$ 出发，构造出一个 piecewise-linear 的 utility function）。若 (6.25) 不可行，则可以断定：不存在与给定的严格偏好集、非严格偏好集都一致的 concave 递增 utility function。

举例来说，设 $P$ 与 $P_{\mathrm{weak}}$ 是已知与至少一个 concave 递增 utility function 一致的消费者偏好。考虑一对 $(k,l)$ 不在 $P$ 或 $P_{\mathrm{weak}}$ 中，即组合 $k$ 与 $l$ 之间的消费者偏好未知。在某些情形下，即使不知道底层偏好函数，我们也能断定组合 $k$ 与 $l$ 之间存在偏好关系。做法是：把不等式 $u(a_k) \le u(a_l)$（意思是偏好组合 $l$ 胜过组合 $k$，或两者同样有吸引力）加到已知偏好 (6.22) 上，然后求解包含这条额外弱偏好的 feasibility linear program (6.25)。若扩充后的偏好集合不可行，就意味着：任何与原始给定消费者偏好数据一致的 concave 非减 utility function 都必须满足 $u(a_k) \gt u(a_l)$。换言之，在不知道底层 utility function 的情况下，我们可以断定组合 $k$ 优于组合 $l$。

**消失测试（抽掉 Huber 会怎样）**：$\ell_2$ 惩罚对 outlier 的梯度随残差线性增长，一个 100 倍大的错点会把整个解拉走；$\ell_1$ 惩罚的 subgradient 有界（大小恒为 1），解对 outlier 免疫，代价是残差为 0 处不可微、对偶里出现 box 约束、牛顿法不能直接用。Huber 是这两者的**连续插值**：残差小时是 $\ell_2$（保精度、二阶可微），残差大时是 $\ell_1$（抗污染）。工程上所有「robust loss」家族（pseudo-Huber、Tukey biweight、Cauchy）都是同一条思路的不同插值方式，源码层可直接对照 `scipy.optimize.least_squares(loss='huber')` 或 Ceres Solver 的 `HuberLoss`。

## <span style="color:#c0392b;">Chapter 7 Statistical estimation（统计估计）</span>

本章的全部内容都可以读成一句话：**统计估计里的常见方法，目标函数几乎都是某个似然的 log，而「log 似然是 concave」这件事把整个估计问题推回 convex optimization 的地盘**。所以本章不是新数学，而是第 6 章的 approximation 在概率语言下的重写：penalty function（惩罚函数）就是负 log 概率密度，residual 就是噪声，robustness 就是对 tails 的假设。

### 7.1 <span style="color:#c0392b;">Parametric distribution estimation（参数化分布估计）</span>

#### 7.1.1 <span style="color:#c0392b;">Maximum likelihood estimation（最大似然估计）</span>

考虑一族 $\mathbf{R}^m$ 上的 probability distribution（概率分布），由一个向量 $x \in \mathbf{R}^n$ 索引，密度记为 $p_x(\cdot)$。当我们把 $p_x(y)$ 看成 $x$ 的函数、而 $y \in \mathbf{R}^m$ 固定时，得到的函数称为 likelihood function（似然函数）。更方便的是取它的对数，称为 log-likelihood function（对数似然函数），记作 $l$：

```math
l(x) = \log p_x(y).
```

对参数 $x$ 的取值常常有约束：它们可以表示关于 $x$ 的 prior knowledge（先验知识），也可以是似然函数的定义域。这些约束可以显式给出，也可以隐式地并入似然函数——只要 $x$ 不满足先验约束，就令 $p_x(y) = 0$（对一切 $y$）。（因此，对违反先验约束的参数 $x$，log-likelihood 函数可赋值为 $-\infty$。）

现在考虑这个问题：在观测到分布的一个样本 $y$ 之后，如何估计参数 $x$ 的取值。一个被广泛使用的方法叫 maximum likelihood（ML）estimation（最大似然估计），它把 $x$ 估计为

```math
\hat{x}_{\text{ml}} = \arg\max_x p_x(y) = \arg\max_x l(x),
```

也就是：在所有可能的参数值里，取那个使观测值 $y$ 的似然（或 log-likelihood）最大的值作为我们的估计。若我们已有关于 $x$ 的先验信息，比如 $x \in C \subseteq \mathbf{R}^n$，我们可以显式加上约束 $x \in C$，也可以隐式地施加它——把 $x \notin C$ 时的 $p_x(y)$ 重新定义成零。

于是，求参数向量 $x$ 的最大似然估计这个问题可以写成

```math
\begin{array}{ll}
\text{maximize} & l(x) = \log p_x(y) \\
\text{subject to} & x \in C,
\end{array} \qquad \text{(7.1)}
```

其中 $x \in C$ 给出参数向量 $x$ 的先验信息或其他约束。在这个优化问题里，向量 $x \in \mathbf{R}^n$（出现在 probability density 里，即概率密度里的那个量）是变量，而向量 $y \in \mathbf{R}^m$（观测到的样本）是问题参数。

---



（页眉：352 · 7 Statistical estimation · 原书 p.352）

若 log-likelihood 函数 $l$ 对每个 $y$ 取值都是 concave 的，且集合 $C$ 能由一组线性等式约束与 convex 不等式约束描述，则最大似然估计问题 (7.1) 是一个 convex optimization 问题——许多估计问题正落在这种情形。对这些问题，我们可以用 convex optimization 算出 ML 估计。

##### Linear measurements with IID noise（带 IID 噪声的线性测量）

考虑线性测量模型

```math
y_i = a_i^T x + v_i, \qquad i = 1,\ldots,m,
```

其中 $x \in \mathbf{R}^n$ 是待估计的参数向量，$y_i \in \mathbf{R}$ 是测得的（观测到的）量，$v_i$ 是 measurement error（测量误差）或 noise（噪声）。我们假设 $v_i$ 是 independent, identically distributed（IID，独立同分布）的，$\mathbf{R}$ 上有密度 $p$。于是 likelihood function 是

```math
p_x(y) = \prod_{i=1}^{m} p(y_i - a_i^T x),
```

而 log-likelihood 函数是

```math
l(x) = \log p_x(y) = \sum_{i=1}^{m} \log p(y_i - a_i^T x).
```

于是 ML 估计就是下列问题的任一最优解

```math
\begin{array}{ll}
\text{maximize} & \sum_{i=1}^{m} \log p(y_i - a_i^T x),
\end{array} \qquad \text{(7.2)}
```

变量是 $x$。若密度 $p$ 是 log-concave（对数凹）的，这个问题就是 convex 的，并且具有 penalty approximation problem（惩罚函数近似问题）的形式（(6.2)，原书 p.294），其 penalty function 为 $-\log p$。

<span style="color:#2471a3;">**[example]**</span> <span style="color:#c0392b;">Example 7.1 ML estimation for some common noise densities.（几种常见噪声密度下的最大似然估计）</span>

- **Gaussian noise（高斯噪声）**。$v_i$ 为零均值、方差 $\sigma^2$ 的 Gaussian 时，密度为 $p(z) = (2\pi\sigma^2)^{-1/2} e^{-z^2/2\sigma^2}$，log-likelihood 函数是

```math
l(x) = -(m/2)\log(2\pi\sigma^2) - \frac{1}{2\sigma^2}\|Ax - y\|_2^2,
```

其中 $A$ 是以 $a_1^T,\ldots,a_m^T$ 为行的矩阵。因此 $x$ 的 ML 估计是 $x_{\text{ml}} = \arg\min_x \|Ax-y\|_2^2$，即一个 least-squares approximation（最小二乘近似）问题的解。

- **Laplacian noise（拉普拉斯噪声）**。$v_i$ 为 Laplacian 分布、密度 $p(z) = (1/2a) e^{-|z|/a}$（$a \gt 0$）时，ML 估计是 $\hat{x} = \arg\min_x \|Ax-y\|_1$，即 $\ell_1$-norm approximation 问题的解。

- **Uniform noise（均匀噪声）**。$v_i$ 在 $[-a,a]$ 上均匀分布时，$p(z) = 1/(2a)$ 于 $[-a,a]$，一个 ML 估计是任何满足 $\|Ax-y\|_\infty \le a$ 的 $x$。

<span style="color:#1e8449;">**[译注]** 这一页是全书把「统计」与「优化」焊在一起的那颗螺栓：**penalty function 与噪声密度是同一个东西的两种写法**，$p(z) = e^{-\varphi(z)} / \int e^{-\varphi(u)}\,du$。抽掉这条对应，第 6 章整章就只能当几何练习读——你无法解释为什么 $\ell_1$ 抗 outliers：$\ell_1$ 对应 Laplacian，其 tails 是 $e^{-|z|/a}$，比 Gaussian 的 $e^{-z^2/2\sigma^2}$ 厚得多，所以「出现大 residual」这件事在 Laplacian 假设下概率高得多，ML 不会为了一个大误差把整条直线拉歪。反过来，这条对应也是可检验的：把 $\sigma$ 改掉（Gaussian 情形下 $l(x)$ 里全是 $-1/(2\sigma^2)$ 这个公共因子），(7.2) 的**最优解 $\hat x$ 一点不变**——ML 只吃密度的形状，不吃尺度。失效模式很具体：若 $p$ 不是 log-concave（例如双峰混合），(7.2) 立刻变成非凸，Newton 法失去二次收敛的保证，只能靠多起点局部搜索。落点：Boyd §6.1.2（penalty approximation 的形式）、§6.4.1 的统计解释、exercise 7.2/7.3。</span>

##### ML interpretation of penalty function approximation（惩罚函数近似的 ML 解释）

反过来，任何 penalty function approximation 问题

```math
\begin{array}{ll}
\text{minimize} & \sum_{i=1}^{m} \varphi(b_i - a_i^T x)
\end{array}
```

都可以解释成一个 maximum likelihood estimation 问题，其噪声密度为

```math
p(z) = \frac{e^{-\varphi(z)}}{\int e^{-\varphi(u)}\,du},
```

测量值为 $b$。这个观察给了 penalty function approximation 问题一个统计学解释。例如，假设 penalty function $\varphi$ 在取值很大时增长得非常快，这意味着我们对大的 residual（残差）施加了极大的代价或惩罚。相应的噪声密度函数 $p$ 会有极薄的 tails，于是 ML 估计器会（如果可能）避开任何带大 residual 的估计，因为那些估计对应着极不可能发生的事件。

我们也可以用 maximum likelihood estimation 来理解 $\ell_1$-norm approximation 对大误差的 robustness（鲁棒性）。把 $\ell_1$-norm approximation 解释成噪声密度为 Laplacian 的最大似然估计；把 $\ell_2$-norm approximation 解释成噪声密度为 Gaussian 的最大似然估计。Laplacian 密度比 Gaussian 的 tails 更厚，即 $v_i$ 取极大值的概率在 Laplacian 下远大于 Gaussian。结果是：相应的方法**预期**看到更多的大 residual，因而不会为一个离群点牺牲整体拟合。

##### Counting problems with Poisson distribution（Poisson 分布下的计数问题）

在各种各样的应用里，随机变量 $y$ 取非负整数值，服从均值为 $\mu \gt 0$ 的 Poisson 分布：

```math
\operatorname{prob}(y = k) = \frac{e^{-\mu}\mu^k}{k!}.
```

$y$ 常常表示某个 Poisson process（Poisson 过程）在一段时间内的事件计数或数目（如 photon arrivals（光子到达）、traffic accidents（交通事故）等）。

在一个简单的统计模型中，均值 $\mu$ 被建模为向量 $u \in \mathbf{R}^n$ 的 affine 函数：

```math
\mu = a^T u + b.
```

这里 $u$ 称为 explanatory variables（解释变量）组成的向量，向量 $a \in \mathbf{R}^n$ 与数 $b \in \mathbf{R}$ 称为 model parameters（模型参数）。例如，若 $y$ 是某地区某时段内的交通事故数，$u_1$ 可以是该时段通过该地区的总车流量，$u_2$ 可以是该时段该地区的降雨量，如此等等。

给定若干观测，它们由成对的 $(u_i,y_i)$ 组成，$i = 1,\ldots,m$，其中 $y_i$ 是在解释变量取 $u_i \in \mathbf{R}^n$ 时观测到的 $y$ 值。我们的任务是从这些数据求模型参数 $a \in \mathbf{R}^n$ 与 $b \in \mathbf{R}$ 的最大似然估计。

这时 likelihood function 具有形式

```math
\prod_{i=1}^{m} \frac{(a^T u_i + b)^{y_i} \exp(-(a^T u_i + b))}{y_i!},
```

因此 log-likelihood 函数是

```math
l(a,b) = \sum_{i=1}^{m} \left( y_i \log(a^T u_i + b) - (a^T u_i + b) - \log(y_i!) \right).
```

通过求解 convex optimization 问题

```math
\begin{array}{ll}
\text{maximize} & \sum_{i=1}^{m} \left( y_i \log(a^T u_i + b) - (a^T u_i + b) \right),
\end{array}
```

可以求出 $a$ 与 $b$ 的 ML 估计，其中变量是 $a$ 与 $b$。

##### Logistic regression（逻辑回归）

考虑取值为 $\{0,1\}$ 的随机变量 $y$，满足

```math
\operatorname{prob}(y = 1) = p, \qquad \operatorname{prob}(y = 0) = 1 - p,
```

其中 $p \in [0,1]$，并假定它依赖于一个 explanatory variables 向量 $u \in \mathbf{R}^n$。例如，$y = 1$ 可以表示人群中某个体患了某种病。患病的概率是 $p$，它被建模为某些解释变量 $u$ 的函数——这些变量可能代表体重、年龄、身高、血压以及其他与医学相关的量。

而 logistic model（逻辑模型）具有形式

```math
p = \frac{\exp(a^T u + b)}{1 + \exp(a^T u + b)}, \qquad \text{(7.3)}
```

其中 $a \in \mathbf{R}^n$ 与 $b \in \mathbf{R}$ 是模型参数，它们决定了概率 $p$ 如何随解释变量 $u$ 变化。

现在假设给定一批数据，由解释变量的一组取值 $u_1,\ldots,u_m \in \mathbf{R}^n$ 以及相应的结果 $y_1,\ldots,y_m \in \{0,1\}$ 组成。我们的任务是求模型参数 $a \in \mathbf{R}^n$ 与 $b \in \mathbf{R}$ 的最大似然估计。求 $a$、$b$ 的 ML 估计有时就被称为 logistic regression。

我们可以重排数据，使对 $u_1,\ldots,u_q$ 结果为 $y = 1$，对 $u_{q+1},\ldots,u_m$ 结果为 $y = 0$。于是 likelihood function 具有形式

```math
\prod_{i=1}^{q} p_i \prod_{i=q+1}^{m} (1 - p_i),
```

其中 $p_i$ 由以 $u_i$ 为解释变量的 logistic model 给出。log-likelihood 函数具有形式

```math
\begin{array}{ll}
l(a,b) & = \sum_{i=1}^{q} \log p_i + \sum_{i=q+1}^{m} \log(1 - p_i)
\end{array}
```

```math
\begin{array}{ll}
& = \sum_{i=1}^{q} \log \dfrac{\exp(a^T u_i + b)}{1 + \exp(a^T u_i + b)} + \sum_{i=q+1}^{m} \log \dfrac{1}{1 + \exp(a^T u_i + b)} \\
& = \sum_{i=1}^{q} (a^T u_i + b) - \sum_{i=1}^{m} \log\left(1 + \exp(a^T u_i + b)\right).
\end{array}
```

##### Covariance estimation for Gaussian variables（Gaussian 变量的协方差估计）

假设 $y \in \mathbf{R}^n$ 是零均值 Gaussian 随机变量，covariance matrix（协方差矩阵）为 $R = \mathbf{E}\, yy^T$，于是其密度为

```math
p_R(y) = (2\pi)^{-n/2} \det(R)^{-1/2} \exp\left(-y^T R^{-1} y / 2\right),
```

其中 $R \in \mathbf{S}^n_{++}$。我们希望基于从该分布独立抽取的 $N$ 个样本 $y_1,\ldots,y_N \in \mathbf{R}^n$，并利用关于 $R$ 的先验知识，来估计协方差矩阵 $R$。

于是 log-likelihood 函数具有形式

```math
\begin{array}{ll}
l(R) & = \log p_R(y_1,\ldots,y_N)
\end{array}
```

---



（页眉：356 · 7 Statistical estimation · 原书 p.356）

```math
\begin{array}{ll}
& = -(Nn/2)\log(2\pi) - (N/2)\log\det R - (1/2)\sum_{k=1}^{N} y_k^T R^{-1} y_k \\
& = -(Nn/2)\log(2\pi) - (N/2)\log\det R - (N/2)\operatorname{\mathbf{tr}}(R^{-1} Y),
\end{array}
```

其中

```math
Y = \frac{1}{N}\sum_{k=1}^{N} y_k y_k^T
```

是 $y_1,\ldots,y_N$ 的 sample covariance（样本协方差）。这个 log-likelihood 函数不是 $R$ 的 concave 函数（尽管它在自己定义域 $\mathbf{S}^n_{++}$ 的一个子集上是 concave 的；见 exercise 7.4），但一次变量替换就能得到 concave 的 log-likelihood 函数。令 $S$ 表示协方差矩阵的逆，$S = R^{-1}$（它被称为 information matrix（信息矩阵））。用 $S$ 代替 $R$ 作为新参数，log-likelihood 函数具有形式

```math
l(S) = -(Nn/2)\log(2\pi) + (N/2)\log\det S - (N/2)\operatorname{\mathbf{tr}}(S Y),
```

它是 $S$ 的 concave 函数。

因此，$S$（从而 $R$）的 ML 估计通过求解下列问题得到

```math
\begin{array}{ll}
\text{maximize} & \log\det S - \operatorname{\mathbf{tr}}(S Y) \\
\text{subject to} & S \in \mathcal{S},
\end{array} \qquad \text{(7.4)}
```

其中 $\mathcal{S}$ 是我们关于 $S = R^{-1}$ 的先验知识。（我们还有隐含约束 $S \in \mathbf{S}^n_{++}$。）由于目标函数是 concave 的，只要集合 $\mathcal{S}$ 能由一组线性等式约束与 convex 不等式约束描述，这就是一个 convex 问题。

先考察对 $R$（从而 $S$）除 $R \succ 0$ 之外没有任何先验假设的情形。此时问题 (7.4) 可以解析求解。目标函数的梯度是 $S^{-1} - Y$，故最优 $S$ 在 $Y \in \mathbf{S}^n_{++}$ 时满足 $S^{-1} = Y$。（若 $Y \notin \mathbf{S}^n_{++}$，则 log-likelihood 函数上没有界。）因此，当我们对 $R$ 没有先验假设时，协方差的最大似然估计就是 sample covariance：$\hat{R}_{\text{ml}} = Y$。

下面考虑几个例子，说明关于 $R$ 的哪些约束可以表达成关于 information matrix $S$ 的 convex 约束。形如

```math
L \preceq R \preceq U
```

的 $R$ 的上下（矩阵）界，其中 $L$ 与 $U$ 对称正定，可以写成

```math
U^{-1} \preceq R^{-1} \preceq L^{-1}.
```

关于 $R$ 的 condition number（条件数）约束

```math
\lambda_{\max}(R) \le \kappa_{\max} \lambda_{\min}(R),
```

可以写成

```math
\lambda_{\max}(S) \le \kappa_{\max} \lambda_{\min}(S).
```

<span style="color:#1e8449;">**[译注]** 整节最锋利的一步是那个换变量：$S = R^{-1}$。**「$-\log\det R$ 究竟哪里不对」值得算清楚，失效对象很具体**：不换变量时 (7.4) 的目标是 $-\frac{N}{2}\log\det R - \frac{N}{2}\operatorname{\mathbf{tr}}(R^{-1}Y)$，前一项在 $R$ 上是 convex（$-\log\det$ convex，§3.1.5），后一项 $\operatorname{\mathbf{tr}}(R^{-1}Y)$ 也是 convex，convex 减去 convex 无定号 ⇒ 整体既非 convex 也非 concave，KKT 退化成必要条件，§5.5.3 的「$\hat{R}_{\text{ml}} = Y$ 就是最优解」这句话失去全局最优的担保，局部 Newton 只能给你一个驻点。换到 $S$ 后 $\log\det S$ concave、$\operatorname{\mathbf{tr}}(SY)$ linear，和仍是 concave，于是「maximize concave」= convex problem，KKT 充要，才能套上 $\phi(S) = -\log\det S$ 这个自带内点性质的 barrier。规模上这不是形式主义：$n \times n$ 协方差矩阵有 $n(n+1)/2$ 个独立变量，$n = 100$ 就是 5050 维；一般 nonlinear programming 每个 Newton 步都要投影回 $\mathbf{S}^n_{++}$ 并防 $\det R \to 0$ 时的数值爆炸。附带一处容易写错的地方：换变量后不等式界变成 $U^{-1} \preceq S \preceq L^{-1}$，端点顺序翻转（inverse 在 PSD 序上反序：$A \preceq B \Rightarrow B^{-1} \preceq A^{-1}$），写反不报错，只会给出错的最优值。</span>

**消失测试 + 一个数**：抽掉变量替换，无先验情形下连解析解都写不出；保留它，答案是 $\hat R_{\text{ml}} = Y$，一行取梯度就完。更硬的一条：**当 $N \lt n$（样本数少于维数）时，$Y$ 的 rank $\le N \lt n$，必不满秩，此时沿 $Y$ 的零空间方向 $v$（$v^T Y v = 0$）取 $S_t = Y + t\,vv^T$，$t \to \infty$ 有 $\operatorname{\mathbf{tr}}(S_t Y)$ 不变而 $\log\det S_t \to \infty$，log-likelihood **上无界**，ML 估计根本不存在**。这不是数值病态，是统计不可辨识：$n$ 维协方差有 $n(n+1)/2$ 个参数，$N$ 个样本最多给 $Nn$ 个数，$N \lt n$ 时信息不够。**落点**：$\log\det$ 凹性见 §3.1.5；max-det 问题的内点法见 §11.4；exercise 7.4 让你验证 $l(R)$ 在某个子集上凹；同一套 $\log\det$ 手法在 §7.5 的 experiment design 里再出现一次。</span>

这等价于存在 $u \gt 0$ 使得 $uI \preceq S \preceq \kappa_{\max} u I$。于是，带 $R$ 的 condition number 约束的 ML 问题，可以通过求解下列 convex 问题来解决

```math
\begin{array}{ll}
\text{maximize} & \log\det S - \operatorname{\mathbf{tr}}(S Y) \\
\text{subject to} & uI \preceq S \preceq \kappa_{\max} u I,
\end{array} \qquad \text{(7.5)}
```

其中变量是 $S \in \mathbf{S}^n$ 与 $u \in \mathbf{R}$。

再举一例，假设给定了 $y$ 的某些线性函数的方差上界，

```math
\mathbf{E}(c_i^T y)^2 \le \alpha_i, \qquad i = 1,\ldots,K.
```

这些先验假设可以写成

```math
\mathbf{E}(c_i^T y)^2 = c_i^T R c_i = c_i^T S^{-1} c_i \le \alpha_i, \qquad i = 1,\ldots,K.
```

由于 $c_i^T S^{-1} c_i$ 是 $S$ 的 convex 函数（只要 $S \succ 0$，此处成立），这些界可以加进 ML 问题里。

#### 7.1.2 <span style="color:#c0392b;">Maximum a posteriori probability estimation（最大后验概率估计）</span>

maximum a posteriori probability (MAP) estimation（最大后验概率估计）可以看成 maximum likelihood estimation 的 Bayes 版本，它在底层参数 $x$ 上带一个 prior probability density（先验概率密度）。我们假设 $x$（待估计的向量）与 $y$（观测）是随机变量，具有联合概率密度 $p(x,y)$。这与统计估计的框架形成对照：在那里 $x$ 是参数，不是随机变量。

$x$ 的先验密度由

```math
p_x(x) = \int p(x,y)\, dy
```

给出。这个密度表示在观测到向量 $y$ 之前，我们对向量 $x$ 可能取什么值的先验信息。类似地，$y$ 的先验密度由

```math
p_y(y) = \int p(x,y)\, dx
```

给出。这个密度表示关于测量（观测）向量 $y$ 会是什么的先验信息。

给定 $x$ 时 $y$ 的条件密度由

```math
p_{y|x}(x,y) = \frac{p(x,y)}{p_x(x)}
```

给出。在 MAP 估计方法里，$p_{y|x}$ 扮演的正是最大似然框架中那个依赖参数的密度 $p_x$ 的角色。给定 $y$ 时 $x$ 的条件密度由

```math
p_{x|y}(x,y) = \frac{p(x,y)}{p_y(y)} = \frac{p_{y|x}(x,y) p_x(x)}{p_y(y)}
```

给出。

---



（页眉：358 · 7 Statistical estimation · 原书 p.358）

把观测值 $y$ 代入 $p_{x|y}$，得到 $x$ 的 posterior density（后验密度）。它表示观测之后我们对 $x$ 的知识。

在 MAP 估计方法里，给定观测 $y$ 后我们对 $x$ 的估计为

```math
\begin{array}{ll}
\hat{x}_{\text{map}} & = \arg\max_x p_{x|y}(x,y) \\
& = \arg\max_x p_{y|x}(x,y) p_x(x) \\
& = \arg\max_x p(x,y).
\end{array}
```

换言之，我们取使 $x$ 的条件密度（在给定观测值 $y$ 时）最大的那个 $x$ 值作为估计。这个估计与 maximum likelihood 估计的唯一差别，就是这里出现的第二项 $p_x(x)$。这一项可以解释为把我们对 $x$ 的先验知识考虑了进去。

注意：若 $x$ 的先验密度在某个集合 $C$ 上是均匀的，则求 MAP 估计等价于在约束 $x \in C$ 下最大化 likelihood function，也就是 ML 估计问题 (7.1)。

取对数，MAP 估计可以写成

```math
\hat{x}_{\text{map}} = \arg\max_x \left( \log p_{y|x}(x,y) + \log p_x(x) \right). \qquad \text{(7.6)}
```

第一项本质上就是 log-likelihood 函数；第二项惩罚那些按先验密度不太可能的 $x$ 选择（即 $p_x(x)$ 很小的 $x$）。

撇开建模哲学上的差别不谈，求 MAP 估计（经由 (7.6)）与求 ML 估计（经由 (7.1)）的唯一差别，就是优化问题里多了一项，它与 $x$ 的先验密度有关。因此，对任何 log-likelihood 函数 concave 的最大似然估计问题，我们都可以给 $x$ 加一个 log-concave 的先验密度，所得的 MAP 估计问题仍然是 convex 的。

##### Linear measurements with IID noise（带 IID 噪声的线性测量）

假设 $x \in \mathbf{R}^n$ 与 $y \in \mathbf{R}^m$ 由

```math
y_i = a_i^T x + v_i, \qquad i = 1,\ldots,m
```

相联系，其中 $v_i$ 是 IID 的、$\mathbf{R}$ 上密度为 $p_v$，且 $x$ 在 $\mathbf{R}^n$ 上有先验密度 $p_x$。于是 $x$ 与 $y$ 的联合密度是

```math
p(x,y) = p_x(x) \prod_{i=1}^{m} p_v(y_i - a_i^T x),
```

而 MAP 估计可以通过求解下列优化问题得到

```math
\begin{array}{ll}
\text{maximize} & \log p_x(x) + \sum_{i=1}^{m} \log p_v(y_i - a_i^T x).
\end{array} \qquad \text{(7.7)}
```

若 $p_x$ 与 $p_v$ 都是 log-concave 的，这个问题就是 convex 的。MAP 估计问题 (7.7) 与相应的 ML 估计问题 (7.2) 的唯一差别，就是多出的那一项 $\log p_x(x)$。

---



（页眉：7.2 Nonparametric distribution estimation · 原书 p.359）

例如，若 $v_i$ 在 $[-a,a]$ 上均匀分布，且 $x$ 的先验分布是均值为 $\bar{x}$、协方差为 $\Sigma$ 的 Gaussian，则 MAP 估计通过求解下列 QP 得到

```math
\begin{array}{ll}
\text{minimize} & (x - \bar{x})^T \Sigma^{-1} (x - \bar{x}) \\
\text{subject to} & \|Ax - y\|_\infty \le a,
\end{array}
```

变量是 $x$。

##### MAP with perfect linear measurements（带精确线性测量的 MAP）

假设 $x \in \mathbf{R}^n$ 是待估计的参数向量，先验密度为 $p_x$。我们有 $m$ 个精确（无噪声、确定性）的线性测量，即 $y = Ax$。换句话说，给定 $x$ 时 $y$ 的条件分布是在点 $Ax$ 处取值 1 的一个 point mass（点质量）。MAP 估计可通过求解

```math
\begin{array}{ll}
\text{maximize} & \log p_x(x) \\
\text{subject to} & Ax = y
\end{array}
```

得到。若 $p_x$ 是 log-concave 的，这是 convex 问题。

若在先验分布下各参数 $x_i$ 是 IID 的、$\mathbf{R}$ 上密度为 $p$，则 MAP 估计问题具有形式

```math
\begin{array}{ll}
\text{maximize} & \sum_{i=1}^{n} \log p(x_i) \\
\text{subject to} & Ax = y,
\end{array}
```

这是一个 least-penalty problem（(6.6)，原书 p.304），其 penalty function 为 $\varphi(u) = -\log p(u)$。

反过来，任何 least-penalty 问题

```math
\begin{array}{ll}
\text{minimize} & \varphi(x_1) + \cdots + \varphi(x_n) \\
\text{subject to} & Ax = b
\end{array}
```

都可以解释成一个 MAP 估计问题：$m$ 个精确线性测量（即 $Ax = b$），$x_i$ 是 IID 的、密度为

```math
p(z) = \frac{e^{-\varphi(z)}}{\int e^{-\varphi(u)}\,du}.
```

### 7.2 <span style="color:#c0392b;">Nonparametric distribution estimation（非参数分布估计）</span>

考虑取值于有限集 $\{\alpha_1,\ldots,\alpha_n\} \subseteq \mathbf{R}$ 的随机变量 $X$。（为简单起见我们取值为 $\mathbf{R}$ 中的数；当取值为 $\mathbf{R}^k$ 中的向量时，同样的想法也适用。）

$X$ 的分布由 $p \in \mathbf{R}^n$ 刻画，其中 $\operatorname{prob}(X = \alpha_k) = p_k$。显然 $p$ 满足 $p \succeq 0$、$\mathbf{1}^T p = 1$。反之，若 $p \in \mathbf{R}^n$ 满足 $p \succeq 0$、$\mathbf{1}^T p = 1$，则它定义了一个随机变量 $X$ 的概率分布，定义为 $\operatorname{prob}(X = \alpha_k) = p_k$。于是 probability simplex（概率单纯形）

```math
\{p \in \mathbf{R}^n \mid p \succeq 0,\ \mathbf{1}^T p = 1\}
```

---



（页眉：360 · 7 Statistical estimation · 原书 p.360）

与取值于 $\{\alpha_1,\ldots,\alpha_n\}$ 的随机变量 $X$ 的所有可能概率分布一一对应。

本节讨论在「先验信息 +（可能的）观测与测量」的组合基础上估计分布 $p$ 的方法。

##### Prior information（先验信息）

许多关于 $p$ 的先验信息都能表示成线性等式约束或不等式。

若 $f : \mathbf{R} \to \mathbf{R}$ 是任意函数，则

```math
\mathbf{E} f(X) = \sum_{i=1}^{n} p_i f(\alpha_i)
```

是 $p$ 的线性函数。作为特例，若 $C \subseteq \mathbf{R}$，则 $\operatorname{prob}(X \in C)$ 是 $p$ 的线性函数：

```math
\operatorname{prob}(X \in C) = c^T p, \qquad
c_i = \begin{cases} 1 & \alpha_i \in C \\ 0 & \alpha_i \notin C. \end{cases}
```

由此可见，某些函数的已知期望值（例如 moments（矩））或某些集合的已知概率，可以作为 $p \in \mathbf{R}^n$ 上的线性等式约束纳入；关于期望值或概率的不等式则可以表示成 $p \in \mathbf{R}^n$ 上的线性不等式。

例如，假设我们知道 $X$ 的均值 $\mathbf{E} X = \alpha$、二阶矩 $\mathbf{E} X^2 = \beta$，以及 $\operatorname{prob}(X \ge 0) \le 0.3$。这些先验信息可以写成

```math
\mathbf{E} X = \sum_{i=1}^{n} \alpha_i p_i = \alpha, \qquad
\mathbf{E} X^2 = \sum_{i=1}^{n} \alpha_i^2 p_i = \beta, \qquad
\sum_{\alpha_i \ge 0} p_i \le 0.3,
```

即 $p$ 上的两个线性等式与一个线性不等式。

我们也可以纳入一些涉及 $p$ 的非线性函数的先验约束。例如，$X$ 的 variance（方差）由

```math
\operatorname{\mathbf{var}}(X) = \mathbf{E} X^2 - (\mathbf{E} X)^2 = \sum_{i=1}^{n} \alpha_i^2 p_i - \left( \sum_{i=1}^{n} \alpha_i p_i \right)^2
```

给出。第一项是 $p$ 的线性函数，第二项是 $p$ 的 concave 二次函数，故 $X$ 的方差是 $p$ 的 concave 函数。于是，方差的一个下界可以表示成 $p$ 上的 convex 二次不等式。

再举一例，假设 $A$ 与 $B$ 是 $\mathbf{R}$ 的子集，考虑给定 $B$ 时 $A$ 的条件概率：

```math
\operatorname{prob}(X \in A \mid X \in B) = \frac{\operatorname{prob}(X \in A \cap B)}{\operatorname{prob}(X \in B)}.
```

这个函数关于 $p \in \mathbf{R}^n$ 是 linear-fractional（线性分式）的：它可以写成

```math
\operatorname{prob}(X \in A \mid X \in B) = c^T p / d^T p,
```

其中

```math
c_i = \begin{cases} 1 & \alpha_i \in A \cap B \\ 0 & \alpha_i \notin A \cap B, \end{cases} \qquad
d_i = \begin{cases} 1 & \alpha_i \in B \\ 0 & \alpha_i \notin B. \end{cases}
```

---



（页眉：7.2 Nonparametric distribution estimation · 原书 p.361）

因此，先验约束

```math
l \le \operatorname{prob}(X \in A \mid X \in B) \le u
```

可以表示成 $p$ 上的线性不等式约束

```math
l\, d^T p \le c^T p \le u\, d^T p.
```

另外几类先验信息可以表示成非线性 convex 不等式。例如，$X$ 的 entropy（熵），由

```math
-\sum_{i=1}^{n} p_i \log p_i
```

给出，是 $p$ 的 concave 函数，于是我们可以把 entropy 的一个最小值作为 $p$ 上的 convex 不等式施加。若 $q$ 表示另一个分布，即 $q \succeq 0$、$\mathbf{1}^T q = 1$，则分布 $q$ 与分布 $p$ 之间的 Kullback-Leibler divergence（KL 散度）由

```math
\sum_{i=1}^{n} p_i \log(p_i / q_i)
```

给出，它对 $p$ 是 convex 的（对 $q$ 也是；见 example 3.19，原书 p.90）。由此可见，我们可以把 $p$ 与给定分布 $q$ 之间的最大 Kullback-Leibler divergence 作为 $p$ 上的 convex 不等式施加。

在接下来的几段里，我们把关于分布 $p$ 的先验信息表示成 $p \in \mathcal{P}$。我们假设 $\mathcal{P}$ 能由一组线性等式与 convex 不等式描述。我们把基本约束 $p \succeq 0$、$\mathbf{1}^T p = 1$ 也包含在先验信息 $\mathcal{P}$ 中。

##### Bounding probabilities and expected values（界定概率与期望值）

给定关于分布的先验信息，比如 $p \in \mathcal{P}$，我们可以计算某个函数的期望值、或某个集合的概率的上界或下界。例如，为了确定 $\mathbf{E} f(X)$ 在所有满足先验信息 $p \in \mathcal{P}$ 的分布上的下界，我们求解 convex 问题

```math
\begin{array}{ll}
\text{minimize} & \sum_{i=1}^{n} f(\alpha_i) p_i \\
\text{subject to} & p \in \mathcal{P}.
\end{array}
```

##### Maximum likelihood estimation（最大似然估计）

我们可以用 maximum likelihood estimation 基于来自该分布的观测来估计 $p$。假设我们观测到 $N$ 个来自该分布的独立样本 $x_1,\ldots,x_N$。令 $k_i$ 表示这些样本中取值为 $\alpha_i$ 的个数，于是 $k_1 + \cdots + k_n = N$，即观测样本总数。log-likelihood 函数于是为

```math
l(p) = \sum_{i=1}^{n} k_i \log p_i,
```

---



（页眉：362 · 7 Statistical estimation · 原书 p.362）

它是 $p$ 的 concave 函数。$p$ 的最大似然估计可以通过求解下列 convex 问题得到

```math
\begin{array}{ll}
\text{maximize} & l(p) = \sum_{i=1}^{n} k_i \log p_i \\
\text{subject to} & p \in \mathcal{P},
\end{array}
```

变量是 $p$。

##### Maximum entropy（最大熵）

与先验假设一致的最大熵分布可以通过求解下列 convex 问题得到

```math
\begin{array}{ll}
\text{minimize} & \sum_{i=1}^{n} p_i \log p_i \\
\text{subject to} & p \in \mathcal{P}.
\end{array}
```

热心的人会把 maximum entropy distribution（最大熵分布）描述成：在与先验信息一致的所有分布中，最含糊、最随机的那一个。

##### Minimum Kullback-Leibler divergence（最小 KL 散度）

在与先验信息一致的所有分布中，我们可以求出与给定先验分布 $q$ 的 Kullback-Leibler divergence 最小的分布 $p$，办法是求解 convex 问题

```math
\begin{array}{ll}
\text{minimize} & \sum_{i=1}^{n} p_i \log(p_i / q_i) \\
\text{subject to} & p \in \mathcal{P}.
\end{array}
```

注意，当先验分布是均匀分布时，即 $q = (1/n)\mathbf{1}$，这个问题退化成最大熵问题。

假设 $X$ 与 $Y$ 是两个随机变量，给出两项投资的回报。我们假设 $X$ 取值于 $\{\alpha_1,\ldots,\alpha_n\} \subseteq \mathbf{R}$，$Y$ 取值于 $\{\beta_1,\ldots,\beta_m\} \subseteq \mathbf{R}$，$p_{ij} = \operatorname{prob}(X = \alpha_i, Y = \beta_j)$。两个回报 $X$ 与 $Y$ 的 marginal distribution（边缘分布）已知，即

```math
\sum_{j=1}^{m} p_{ij} = r_i, \quad i = 1,\ldots,n, \qquad
\sum_{i=1}^{n} p_{ij} = q_j, \quad j = 1,\ldots,m, \qquad \text{(7.9)}
```

除此之外，关于联合分布 $p$ 一无所知。这定义了一个与给定边缘分布一致的联合分布 polyhedron。

现在假设我们把两项投资都做了，于是总回报是随机变量 $X + Y$。我们希望计算某个亏损（或低回报）水平的概率上界，即 $\operatorname{prob}(X + Y \lt \gamma)$。通过求解 LP

```math
\begin{array}{ll}
\text{maximize} & \sum \left\{ p_{ij} \mid \alpha_i + \beta_j \lt \gamma \right\} \\
\text{subject to} & \text{(7.9)},\ p_{ij} \ge 0,\ i = 1,\ldots,n,\ j = 1,\ldots,m,
\end{array}
```

可以算出这个概率的紧上界。这个 LP 的最优值就是亏损的最大概率。最优解 $p^\star$ 是与给定边缘分布一致、且使亏损概率最大的那个联合分布。

```math
\sum \left\{ p_{ij} \mid R(\alpha_i, \beta_j) \lt \gamma \right\},
```

并对其分别取最小与最大，我们可以算出 $\operatorname{prob}(R \lt \gamma)$ 的紧下界与紧上界。

### 7.3 <span style="color:#c0392b;">Optimal detector design and hypothesis testing（最优检测器设计与假设检验）</span>

假设 $X$ 是取值于 $\{1,\ldots,n\}$ 的随机变量，其分布依赖于参数 $\theta \in \{1,\ldots,m\}$。对 $\theta$ 的 $m$ 个可能取值，$X$ 的分布可以用矩阵 $P \in \mathbf{R}^{n \times m}$ 表示，其元素为

```math
p_{kj} = \operatorname{prob}(X = k \mid \theta = j).
```

$P$ 的第 $j$ 列给出与参数值 $\theta = j$ 相关联的概率分布。

我们考虑基于 $X$ 的一个观测样本来估计 $\theta$ 的问题。换句话说，样本 $X$ 由 $m$ 个可能分布之一生成，我们要猜是哪一个。$\theta$ 的这 $m$ 个取值称为 hypotheses（假设），猜哪个假设是正确的（即哪个分布生成了观测样本 $X$）称为 hypothesis testing（假设检验）。许多情况下，其中一个假设对应某种正常状态，其余每个假设对应某种异常事件。此时假设检验可以理解为：观测 $X$ 的一个值，然后猜是否发生了异常事件，若发生了，是哪一个。

---
