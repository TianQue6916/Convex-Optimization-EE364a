出于这个原因，hypothesis testing 也被称为 detection（检测）。

多数情况下假设之间的排序没有意义：它们只是 $m$ 个不同的假设，被任意标为 $\theta = 1,\ldots,m$。若 $\hat{\theta} = \theta$（$\hat{\theta}$ 表示 $\theta$ 的估计），我们就正确猜出了参数值 $\theta$；若 $\hat{\theta} \ne \theta$，我们就（错误地）猜了参数值 $\theta$，即把 $\hat\theta$ 误当成了 $\theta$。另一些情况下，假设的排序是有意义的。此时像 $\hat{\theta} \gt \theta$ 这样的事件（即我们高估了 $\theta$）是有含义的。

也可以用 $\{1,\ldots,m\}$ 之外的值来参数化 $\theta$，比如 $\theta \in \{\theta_1,\ldots,\theta_m\}$，其中 $\theta_i$ 是（互不相同的）取值。这些值可以是实数，也可以是向量，例如指定第 $k$ 个分布的均值与方差。此时像 $\|\hat{\theta} - \theta\|$ 这样的量（参数估计误差的范数）是有意义的。

#### 7.3.1 <span style="color:#c0392b;">Deterministic and randomized detectors（确定性与随机化检测器）</span>

一个（确定性）estimator（估计器）或 detector（检测器）是从 $\{1,\ldots,n\}$（可能观测值之集）到 $\{1,\ldots,m\}$（假设之集）的函数 $\psi$。若观测到 $X$ 取值为 $k$，则我们对 $\theta$ 的猜测是 $\hat{\theta} = \psi(k)$。一个显然的确定性检测器是 maximum likelihood detector（最大似然检测器）：

```math
\hat{\theta} = \psi_{\text{ml}}(k) = \arg\max_j p_{kj}. \qquad \text{(7.10)}
```

当观测到 $X = k$ 时，$\theta$ 的最大似然估计就是在所有可能分布上使「观测到 $X = k$」的概率最大的那个值。

我们将考虑确定性检测器的一个推广：给定 $X$ 的观测值时，$\theta$ 的估计是随机的。$\theta$ 的一个 randomized detector（随机化检测器）是一个随机变量 $\hat{\theta} \in \{1,\ldots,m\}$，其分布依赖于 $X$ 的观测值。随机化检测器可以用矩阵 $T \in \mathbf{R}^{m \times n}$ 定义，其元素为

```math
t_{ik} = \operatorname{prob}(\hat{\theta} = i \mid X = k).
```

解释如下：若我们观测到 $X = k$，则检测器以概率 $t_{ik}$ 给出 $\hat{\theta} = i$。$T$ 的第 $k$ 列（记作 $t_k$）在观测到 $X = k$ 时给出 $\hat{\theta}$ 的概率分布。若 $T$ 的每一列都是 unit vector（单位向量），则随机化检测器就是确定性检测器，即 $\hat{\theta}$ 是观测值 $X$ 的（确定性）函数。

初看之下，在估计或检测过程中有意引入额外的随机化，似乎只会让估计器变差。但下面我们会看到一些例子，其中随机化检测器优于所有确定性估计器。

我们关心的是设计定义随机化检测器的矩阵 $T$。显然 $T$ 的各列 $t_k$ 必须满足（线性等式与不等式）约束

```math
t_k \succeq 0, \qquad \mathbf{1}^T t_k = 1. \qquad \text{(7.11)}
```

<span style="color:#1e8449;">**[译注]** 「随机化怎么可能更好」这个反直觉结论，**边界条件可以精确写出来**，别只记结论。设 $D = TP$。(7.11) 说明 $T$ 的可行集是 $n$ 个概率单纯形（第 $k$ 个对应观测值 $X=k$，维数 $m$）的乘积，顶点集恰好是「每列取单位向量」的那些 $T$——**也就是全部确定性 detector**，个数 $m^n$（$\psi$ 把 $n$ 个观测值各映到 $m$ 个假设之一）。于是：**只要目标是 $D$ 的 affine 函数、约束是线性的，LP 必在顶点取最优 ⇒ 随机化一点用都没有**，且这个论断可被反驳：找一个反例就能推翻它。真正能让随机化严格取胜的，是目标非 affine——例如 minimize $\max_i P^e_i$（convex piecewise-linear），或同时压低多个 $P^e_i$：一个确定性 detector 只能把误差「集中」到少数几个 hypothesis 上，而 $T$ 的内点可以把误差**分摊**到几列之间，把 $\max$ 压下来。Boyd 在 §7.3.4 给出显式反例（那里还会证明 minimax 随机化 detector 可由 LP 求出）。这个「顶点 vs 内点」的判据在 §7.5 experiment design 里会以同样面目再出现：那里也是「确定性的选点 = 顶点，随机化的选点 = 内点」。</span>

#### 7.3.2 <span style="color:#c0392b;">Detection probability matrix（检测概率矩阵）</span>

对由矩阵 $T$ 定义的随机化检测器，我们定义 detection probability matrix（检测概率矩阵）为 $D = TP$。有

```math
D_{ij} = (TP)_{ij} = \operatorname{prob}(\hat{\theta} = i \mid \theta = j),
```

于是 $D_{ij}$ 是「当实际上 $\theta = j$ 时猜 $\hat{\theta} = i$」的概率。$m \times m$ 的检测概率矩阵 $D$ 刻画了由 $T$ 定义的随机化检测器的性能。对角元 $D_{ii}$ 是「当 $\theta = i$ 时猜 $\hat{\theta} = i$」的概率，即正确检测出 $\theta = i$ 的概率。非对角元 $D_{ij}$（$i \ne j$）是「把 $\theta = i$ 误当成 $\theta = j$」的概率，即当实际上 $\theta = j$ 时我们的猜测是 $\hat{\theta} = i$ 的概率。若 $D = I$，则检测器是完美的：无论参数 $\theta$ 是什么，我们都正确猜到 $\hat{\theta} = \theta$。

$D$ 的对角元排成一个向量，称为 detection probabilities（检测概率），记作 $P^{\text{d}}$：

```math
P^{\text{d}}_i = D_{ii} = \operatorname{prob}(\hat{\theta} = i \mid \theta = i).
```

而 error probability（错误概率）是它们的补，记作 $P^{\text{e}}$：

```math
P^{\text{e}}_i = 1 - D_{ii} = \operatorname{prob}(\hat{\theta} \ne i \mid \theta = i).
```

由于检测概率矩阵 $D$ 的各列之和为 1，错误概率可以写成

```math
P^{\text{e}}_i = \sum_{j \ne i} D_{ji}.
```

（读法提示，非原文错误）本式下标方向：$P^{\text{e}}_i$ 的定义是「$\theta = i$ 时判错」，同一列内应为 $\sum_{j \ne i} D_{ji}$，其中 $D_{ji} = \operatorname{prob}(\hat{\theta}=j \mid \theta=i)$——下标顺序与上面的 $D_{ij}$ 定义一致（第一个下标是猜测，第二个是真值），读者容易把 $j,i$ 看反。

#### 7.3.3 <span style="color:#c0392b;">Optimal detector design（最优检测器设计）</span>

本节我们要说明：检测器设计的许多目标，都是 $D$（从而是 $T$，即优化变量）的 linear、affine 或 convex piecewise-linear 函数；同样，检测器设计的许多约束都可以表示成 $D$ 上的线性不等式。由此可知，各种各样的最优检测器设计问题都可以写成 LP。§7.3.4 会看到其中一些 LP 有简单解；本节只把问题列出来。

##### Limits on errors and detection probabilities（误差与检测概率的限制）

我们可以对正确检测第 $j$ 个假设的概率加下界

```math
P^{\text{d}}_j = D_{jj} \ge L_j,
```

这是 $D$（从而是 $T$）上的线性不等式。类似地，我们可以对「把 $\theta = i$ 误当成 $\theta = j$」的概率加上限：

```math
D_{ij} \le U_{ij},
```

……这些同样是对 $T$ 的线性约束。我们可以把任意一个 detection probability（检测概率）取作要最大化的目标，也可以把任意一个 error probability（错误概率）取作要最小化的目标。

#### <span style="color:#2471a3;">Minimax detector design（minimax 检测器设计）</span>

我们可以把 minimax 错误概率 $\max_j P^{\text{e}}_j$ 取作（要最小化的）目标；它是 $D$（从而是 $T$）的 piecewise-linear convex function（分段线性凸函数）。只留这一个目标，就得到「最小化最大检测错误概率」的问题

```math
\begin{array}{ll}
\text{minimize} & \max_j P^{\text{e}}_j \\
\text{subject to} & t_k \succeq 0, \quad \mathbf{1}^T t_k = 1, \quad k = 1,\ldots,n,
\end{array}
```

其中变量是 $t_1,\ldots,t_n \in \mathbf{R}^m$。这个问题可以重排成一个 LP。minimax 检测器在全部 $m$ 个 hypothesis 上最小化最坏情况（最大）错误概率。

当然，我们可以往 minimax 检测器设计问题里再加别的约束。

#### <span style="color:#2471a3;">Bayes detector design（Bayes 检测器设计）</span>

在 Bayes 检测器设计里，我们有一个 hypothesis 的 prior distribution（先验分布），由 $q \in \mathbf{R}^m$ 给出，其中

```math
q_i = \operatorname{prob}(\theta = i).
```

此时 $p_{ij}$ 被解释为「给定 $\theta$ 时 $X$ 的条件概率」。检测器的错误概率则由 $q^T P^{\text{e}}$ 给出，它是 $T$ 的 affine function（仿射函数）。Bayes 最优检测器是如下 LP 的解

```math
\begin{array}{ll}
\text{minimize} & q^T P^{\text{e}} \\
\text{subject to} & t_k \succeq 0, \quad \mathbf{1}^T t_k = 1, \quad k = 1,\ldots,n.
\end{array}
```

§7.3.4 会看到这个问题有简单的解析解。

一个特例是 $q = (1/m)\mathbf{1}$。此时 Bayes 最优检测器最小化的是平均错误概率，这个（不加权的）平均是对 hypothesis 取的。§7.3.4 会看到 maximum likelihood detector (7.10) 对这个间题最优。

#### <span style="color:#2471a3;">Bias, mean-square error, and other quantities（偏差、均方误差及其他量）</span>

本节我们假设 $\theta$ 各取值的先后顺序是有意义的，即当 $i \gt j$ 时，$\theta = i$ 可以解释成参数值比 $\theta = j$ 更大。比如 $\theta = i$ 对应「已发生 $i$ 个事件」这个 hypothesis 时就属于这种情况。此时我们可能关心

```math
\operatorname{prob}(\hat{\theta} \gt \theta \mid \theta = i),
```

即在 $\theta = i$ 时我们高估 $\theta$ 的概率。

它是 $D$ 的 affine function：

```math
\operatorname{prob}(\hat{\theta} \gt \theta \mid \theta = i) = \sum_{j \gt i} D_{ji}.
```



（页眉：7 Statistical estimation · 原书 p.368）

于是这个概率的允许上限，可以写成 $D$（从而是 $T$）上的线性不等式。另一个例子是：当 $\theta = i$ 时把 $\theta$ 误分类超过 1 的概率

```math
\operatorname{prob}(|\hat{\theta} - \theta| \gt 1 \mid \theta = i) = \sum_{|j - i| \gt 1} D_{ji},
```

它同样是 $D$ 的线性函数。

现在设参数取值为 $\{\theta_1,\ldots,\theta_m\} \subseteq \mathbf{R}$。此时估计或检测的（参数）误差由 $\hat{\theta} - \theta$ 给出，而若干我们关心的量都是 $D$ 的线性函数。例子包括：

- **Bias（偏差）**：当 $\theta = \theta_i$ 时，检测器的 bias 由线性函数

```math
\mathbf{E}_i(\hat{\theta} - \theta) = \sum_{j=1}^{m} (\theta_j - \theta_i) D_{ji}
```

  给出，其中 $\mathbf{E}$ 的下标表示期望是对 hypothesis $\theta = \theta_i$ 的分布取的。

- **Mean square error（均方误差）**：当 $\theta = \theta_i$ 时，检测器的均方误差由线性函数

```math
\mathbf{E}_i(\hat{\theta} - \theta)^2 = \sum_{j=1}^{m} (\theta_j - \theta_i)^2 D_{ji}
```

  给出。

- **Average absolute error（平均绝对误差）**：当 $\theta = \theta_i$ 时，检测器的平均绝对误差由线性函数

```math
\mathbf{E}_i|\hat{\theta} - \theta| = \sum_{j=1}^{m} |\theta_j - \theta_i| D_{ji}
```

  给出。

### 7.3.4 <span style="color:#c0392b;">Multicriterion formulation and scalarization（多目标表述与标量化）</span>

最优检测器设计问题可以看成一个 multicriterion problem（多目标问题）：约束是 (7.11)，目标则是 $D$ 的 $m(m-1)$ 个非对角元素，它们就是各类检测错误的概率：

```math
\begin{array}{ll}
\text{minimize} \ (\text{w.r.t. } \mathbf{R}^{m(m-1)}_+) & D_{ij}, \quad i,j = 1,\ldots,m, \ i \ne j \\
\text{subject to} & t_k \succeq 0, \quad \mathbf{1}^T t_k = 1, \quad k = 1,\ldots,n,
\end{array}
\qquad (7.12)
```

其中变量是 $t_1,\ldots,t_n \in \mathbf{R}^m$。由于每个目标 $D_{ij}$ 都是变量的线性函数，这是一个 multicriterion linear program（多目标线性规划）。

我们可以用加权和目标来标量化这个多目标问题

```math
\sum_{i,j=1}^{m} W_{ij} D_{ij} = \operatorname{tr}(W^T D)
```



（页眉：§7.3 Optimal detector design and hypothesis testing · 原书 p.369）

其中权重矩阵 $W \in \mathbf{R}^{m \times m}$ 满足

```math
W_{ii} = 0, \quad i = 1,\ldots,m, \qquad W_{ij} \gt 0, \quad i,j = 1,\ldots,m, \ i \ne j.
```

这个目标是 $m(m-1)$ 个错误概率的加权和，权重 $W_{ij}$ 对应「实际上 $\theta = j$、却猜成 $\hat{\theta} = i$」这一错误。这个权重矩阵有时被称为 loss matrix（损失矩阵）。

为求多目标问题 (7.12) 的一个 Pareto optimal point（Pareto 最优点），我们构造标量优化问题

```math
\begin{array}{ll}
\text{minimize} & \operatorname{tr}(W^T D) \\
\text{subject to} & t_k \succeq 0, \quad \mathbf{1}^T t_k = 1, \quad k = 1,\ldots,n,
\end{array}
\qquad (7.13)
```

这是一个 LP。该 LP 对变量 $t_1,\ldots,t_n$ 是可分离的。目标可以写成各个 $t_k$ 的（线性）函数之和：

```math
\operatorname{tr}(W^T D) = \operatorname{tr}(W^T T P) = \operatorname{tr}(P W^T T) = \sum_{k=1}^{n} c_k^T t_k,
```

其中 $c_k$ 是 $W P^T$ 的第 $k$ 列。约束也是可分离的（即每个 $t_i$ 上的约束各自独立）。因此我们可以通过分别求解

```math
\begin{array}{ll}
\text{minimize} & c_k^T t_k \\
\text{subject to} & t_k \succeq 0, \quad \mathbf{1}^T t_k = 1,
\end{array}
```

（$k = 1,\ldots,n$）来解 LP (7.13)。这些 LP 每一个都有简单的解析解（见 exercise 4.8）：先找一个下标 $q$，使 $c_{kq} = \min_j c_{kj}$，然后取 $t^{\star}_k = e_q$。

这个最优点对应一个确定性检测器：当观测到 $X = k$ 时，我们的估计是

```math
\hat{\theta} = \arg\min_j (W P^T)_{jk}.
\qquad (7.14)
```

于是，对每一个非对角元素为正的权重矩阵 $W$，我们都能找到一个最小化加权和目标函数的确定性检测器。这看起来像是说明随机化检测器并不需要，但我们会看到并非如此。多目标 LP (7.12) 的 Pareto 最优 trade-off surface（权衡曲面）是 piecewise-linear 的；(7.14) 形式的确定性检测器对应这张 Pareto 最优曲面上的顶点。

#### <span style="color:#2471a3;">MAP and ML detectors（MAP 与 ML 检测器）</span>

考虑先验分布为 $q$ 的 Bayes 检测器设计。平均错误概率是

```math
q^T P^{\text{e}} = \sum_{j=1}^{m} q_j \sum_{i \ne j} D_{ij} = \sum_{i,j=1}^{m} W_{ij} D_{ij},
```

只要我们把权重矩阵 $W$ 定义为

```math
W_{ij} = q_j, \quad i,j = 1,\ldots,m, \ i \ne j, \qquad W_{ii} = 0, \quad i = 1,\ldots,m.
```



（页眉：7 Statistical estimation · 原书 p.370）

于是，Bayes 最优检测器由确定性检测器 (7.14) 给出，其中

```math
(W P^T)_{jk} = \sum_{i \ne j} q_i p_{ki} = \sum_{i=1}^{m} q_i p_{ki} - q_j p_{kj}.
```

第一项与 $j$ 无关，所以最优检测器简单地就是

```math
\hat{\theta} = \arg\max_j (p_{kj} q_j),
```

（当观测到 $X = k$ 时）。这个解有很简单的解释：由于 $p_{kj} q_j$ 给出的是「$\theta = j$ 且 $X = k$」的概率，这个检测器就是一个 maximum a posteriori probability（最大后验概率，MAP）检测器。

对特例 $q = (1/m)\mathbf{1}$，即 $\theta$ 上均匀的 prior distribution，这个 MAP 检测器退化为 maximum likelihood（最大似然，ML）检测器：

```math
\hat{\theta} = \arg\max_j p_{kj}.
```

因此，maximum likelihood 检测器最小化（不加权的）平均即均值错误概率。

### 7.3.5 <span style="color:#c0392b;">Binary hypothesis testing（二元假设检验）</span>

作为例示，我们考虑 $m = 2$ 这一特例，它被称为 binary hypothesis testing。随机变量 $X$ 由两个分布之一生成，为简化记号我们把它们记作 $p \in \mathbf{R}^n$ 与 $q \in \mathbf{R}^n$。通常 hypothesis $\theta = 1$ 对应某种正常情形，hypothesis $\theta = 2$ 对应我们想要检测的某种异常事件。若 $\hat{\theta} = 1$，我们说 test is negative（检验为阴性，即猜事件没发生）；若 $\hat{\theta} = 2$，我们说 test is positive（检验为阳性，即猜事件发生了）。

detection probability matrix $D \in \mathbf{R}^{2 \times 2}$ 传统上写作

```math
D = \begin{bmatrix} 1 - P_{\text{fp}} & P_{\text{fn}} \\ P_{\text{fp}} & 1 - P_{\text{fn}} \end{bmatrix}.
```

这里 $P_{\text{fn}}$ 是 false negative（假阴性）的概率（即事件事实上发生了、检验却为阴性），$P_{\text{fp}}$ 是 false positive（假阳性）的概率（即事件事实上没发生、检验却为阳性），后者也叫 false alarm probability（虚警概率）。最优检测器设计问题是一个 bi-criterion problem（双目标问题），目标是 $P_{\text{fn}}$ 与 $P_{\text{fp}}$。

$P_{\text{fn}}$ 与 $P_{\text{fp}}$ 之间的最优 trade-off curve 称为 receiver operating characteristic（接收者操作特征曲线，ROC），它由分布 $p$ 与 $q$ 决定。ROC 可以通过对双目标问题做标量化求得，做法即 §7.3.4 所述。对权重矩阵 $W$，最优检测器 (7.14) 是

```math
\hat{\theta} = \begin{cases} 1 & W_{21} p_k \gt W_{12} q_k \\ 2 & W_{21} p_k \le W_{12} q_k \end{cases}
```



（页眉：§7.3 Optimal detector design and hypothesis testing · 原书 p.371）

（当观测到 $X = k$ 时。）

这就叫 likelihood ratio threshold test（似然比阈值检验）：若比值 $p_k/q_k$ 超过阈值 $W_{12}/W_{21}$，检验为阴性（即 $\hat{\theta} = 1$）；否则检验为阳性。通过选取不同的阈值，我们得到一批（确定性）Pareto 最优检测器，它们给出不同水平的 false positive 与 false negative 错误概率。

这个结果就是所谓的 Neyman-Pearson lemma（Neyman-Pearson 引理）。

likelihood ratio 检测器并不给出全部 Pareto 最优检测器；它们是那条最优 trade-off curve 的顶点，而这条曲线是 piecewise-linear 的。

<span style="color:#c0392b;">**Example 7.4**</span> 我们考虑一个 $n = 4$ 的 binary hypothesis testing 例子，取

\qquad (7.15)
```

T^{(2)} = \begin{bmatrix} 1 & 1 & 0 & 0 \\ 0 & 0 & 1 & 1 \end{bmatrix},
```



（页眉：7 Statistical estimation · 原书 p.372）

### 7.3.6 <span style="color:#c0392b;">Robust detectors（鲁棒检测器）</span>

到目前为止我们都假设 $P$ 是已知的—— $P$ 给出的是对每个参数值 $\theta$，被观测变量 $X$ 的分布。本节考虑这些分布未知、但给出了关于它们的某些先验信息的情形。我们假设 $P \in \mathcal{P}$，其中 $\mathcal{P}$ 是可能的分布的集合。

对一个由 $T$ 表征的随机化检测器，检测概率矩阵 $D$ 现在依赖于 $P$ 的具体取值。我们将用错误概率在最坏情况下的值来评判它们，即在 $P \in \mathcal{P}$ 上取最坏。我们定义 worst-case detection probability matrix（最坏情况检测概率矩阵）$D^{\text{wc}}$ 为

```math
D^{\text{wc}}_{ij} = \sup_{P \in \mathcal{P}} D_{ij}, \quad i,j = 1,\ldots,m, \ i \ne j, \qquad
D^{\text{wc}}_{ii} = \inf_{P \in \mathcal{P}} D_{ii}, \quad i = 1,\ldots,m.
```

非对角元素给出在 $P \in \mathcal{P}$ 上可能的最大错误概率，对角元素给出可能的最小检测概率。注意 $\sum_{i=1}^{m} D^{\text{wc}}_{ij} \ne 1$ 一般成立，也就是说，最坏情况检测概率矩阵的各列不一定加起来等于 1。

我们定义 worst-case probability of error（最坏情况错误概率）为

```math
P^{\text{wc,e}}_i = 1 - D^{\text{wc}}_{ii}.
```

于是 $P^{\text{wc,e}}_i$ 就是当 $\theta = i$ 时，在 $\mathcal{P}$ 中所有可能的分布上取到的最大错误概率。

用最坏情况检测概率矩阵，或者用最坏情况错误概率向量，我们可以发展出检测器设计问题的多种鲁棒版本。本节余下部分集中讨论 robust minimax detector design problem（鲁棒 minimax 检测器设计问题），把它作为一个能说明这些想法的通用例子。

我们把 robust minimax detector 定义为在所有 hypothesis 上最小化最坏情况错误概率的检测器，即最小化目标

```math
\max_i P^{\text{wc,e}}_i = \max_{i=1,\ldots,m} \sup_{P \in \mathcal{P}} \left(1 - (TP)_{ii}\right) = 1 - \min_{i=1,\ldots,m} \inf_{P \in \mathcal{P}} (TP)_{ii}.
```

robust minimax 检测器在所有 $m$ 个 hypothesis 上、并在所有 $P \in \mathcal{P}$ 上，最小化可能的最坏错误概率。



（页眉：§7.3 Optimal detector design and hypothesis testing · 原书 p.373）

#### <span style="color:#2471a3;">Robust minimax detector for finite $\mathcal{P}$（有限 $\mathcal{P}$ 下的鲁棒 minimax 检测器）</span>

当可能分布的集合是有限集时，鲁棒 minimax 检测器设计问题很容易写成 LP。取 $\mathcal{P} = \{P_1,\ldots,P_k\}$，我们可通过求解

```math
\begin{array}{ll}
\text{maximize} & \min_{i=1,\ldots,m} \inf_{P \in \mathcal{P}} (TP)_{ii} = \min_{i=1,\ldots,m} \min_{j=1,\ldots,k} (TP_j)_{ii} \\
\text{subject to} & t_i \succeq 0, \quad \mathbf{1}^T t_i = 1, \quad i = 1,\ldots,n,
\end{array}
```

来得到 robust minimax 检测器。目标函数是 piecewise-linear 且 concave 的，所以这个问题可以写成 LP。注意我们完全可以把 $\mathcal{P}$ 换成多面体 $\operatorname{conv}\mathcal{P}$；与之关联的最坏情况检测矩阵与 robust minimax 检测器都不变。

#### <span style="color:#2471a3;">Robust minimax detector for polyhedral $\mathcal{P}$（多面体 $\mathcal{P}$ 下的鲁棒 minimax 检测器）</span>

当 $\mathcal{P}$ 是由线性等式与不等式约束描述的多面体时，也能高效地把鲁棒 minimax 检测器问题写成 LP。这个表述不那么显然，它依赖 $\mathcal{P}$ 的对偶表示。

为简化讨论，我们假设 $\mathcal{P}$ 具有如下形式

```math
\mathcal{P} = \left\{ P = \begin{bmatrix} p_1 & \cdots & p_m \end{bmatrix} \ \middle| \ A_k p_k = b_k,\ \mathbf{1}^T p_k = 1,\ p_k \succeq 0 \right\}.
\qquad (7.16)
```

换句话说，对每个分布 $p_k$，我们已知某些期望值 $A_k p_k = b_k$（这些可以代表已知的矩、概率等等）。推广到「已知的是期望值上的不等式」的情形是直接的。

robust minimax 设计问题是

```math
\begin{array}{ll}
\text{maximize} & \gamma \\
\text{subject to} & \inf\{\tilde{t}_i^T p \mid A_i p = b_i,\ \mathbf{1}^T p = 1,\ p \succeq 0\} \ge \gamma, \quad i = 1,\ldots,m \\
& t_i \succeq 0, \quad \mathbf{1}^T t_i = 1, \quad i = 1,\ldots,n,
\end{array}
```

其中 $\tilde{t}_i^T$ 表示 $T$ 的第 $i$ 行（于是 $(TP)_{ii} = \tilde{t}_i^T p_i$）。由 LP duality，

```math
\inf\{\tilde{t}_i^T p \mid A_i p = b_i,\ \mathbf{1}^T p = 1,\ p \succeq 0\} = \sup\{\nu^T b_i + \mu \mid A_i^T \nu + \mu \mathbf{1} \preceq \tilde{t}_i\}.
```

利用这一点，鲁棒 minimax 检测器设计问题可以写成 LP

```math
\begin{array}{ll}
\text{maximize} & \gamma \\
\text{subject to} & \nu_i^T b_i + \mu_i \ge \gamma, \quad i = 1,\ldots,m \\
& A_i^T \nu_i + \mu_i \mathbf{1} \preceq \tilde{t}_i, \quad i = 1,\ldots,m \\
& t_i \succeq 0, \quad \mathbf{1}^T t_i = 1, \quad i = 1,\ldots,n,
\end{array}
```

其中变量是 $\nu_1,\ldots,\nu_m$、$\mu_1,\ldots,\mu_n$ 以及 $T$（它的列为 $t_i$、行为 $\tilde{t}_i^T$）。

† 原文自身的不一致：上一式组的约束是「对每个 $i = 1,\ldots,m$」，$\mu$ 的下标应只有 $m$ 个；这里写成「$\mu_1,\ldots,\mu_n$」是把 $m$ 与 $n$ 串了（$\nu$ 的下标由 $m$ 个 hypothesis 决定，$t_i$ 的下标才是 $1..n$）。按上下文应为 $\mu_1,\ldots,\mu_m$。

<span style="color:#c0392b;">**Example 7.5**</span> **Robust binary hypothesis testing（鲁棒二元假设检验）.** 设 $m = 2$，且 (7.16) 中的集合 $\mathcal{P}$ 由

```math
A_1 = A_2 = A = \begin{bmatrix} a_1 & a_2 & \cdots & a_n \\ a_1^2 & a_2^2 & \cdots & a_n^2 \end{bmatrix}, \quad
b_1 = \begin{bmatrix} \alpha_1 \\ \alpha_2 \end{bmatrix}, \quad
b_2 = \begin{bmatrix} \beta_1 \\ \beta_2 \end{bmatrix}
```

定义。为这个集合 $\mathcal{P}$ 设计鲁棒 minimax 检测器，可以解释成下面这个 binary hypothesis testing 问题：基于对随机变量 $X \in \{a_1,\ldots,a_n\}$ 的一次观测，在以下两个 hypothesis 之间做选择：



（页眉：7 Statistical estimation · 原书 p.374）

1. $\mathbf{E} X = \alpha_1,\ \mathbf{E} X^2 = \alpha_2$
2. $\mathbf{E} X = \beta_1,\ \mathbf{E} X^2 = \beta_2$

记 $\tilde{t}^T$ 为 $T$ 的第一行（于是 $(1-\tilde{t})^T$ 是第二行）。对给定的 $\tilde{t}$，最坏情况下的正确检测概率是

```math
\begin{aligned}
D^{\text{wc}}_{11} &= \inf\left\{\tilde{t}^T p \ \middle|\ \sum_{i=1}^{n} a_i p_i = \alpha_1,\ \sum_{i=1}^{n} a_i^2 p_i = \alpha_2,\ \mathbf{1}^T p = 1,\ p \succeq 0\right\} \\
D^{\text{wc}}_{22} &= \inf\left\{(1-\tilde{t})^T p \ \middle|\ \sum_{i=1}^{n} a_i p_i = \beta_1,\ \sum_{i=1}^{n} a_i^2 p_i = \beta_2,\ \mathbf{1}^T p = 1,\ p \succeq 0\right\}.
\end{aligned}
```

利用 LP 对偶，我们可以把 $D^{\text{wc}}_{11}$ 表示成 LP

```math
\begin{array}{ll}
\text{maximize} & z_0 + z_1 \alpha_1 + z_2 \alpha_2 \\
\text{subject to} & z_0 + a_i z_1 + a_i^2 z_2 \le \tilde{t}_i, \quad i = 1,\ldots,n,
\end{array}
```

的最优值，其中变量是 $z_0,z_1,z_2 \in \mathbf{R}$。类似地，$D^{\text{wc}}_{22}$ 是 LP

```math
\begin{array}{ll}
\text{maximize} & w_0 + w_1 \beta_1 + w_2 \beta_2 \\
\text{subject to} & w_0 + a_i w_1 + a_i^2 w_2 \le 1 - \tilde{t}_i, \quad i = 1,\ldots,n,
\end{array}
```

的最优值，其中变量是 $w_0,w_1,w_2 \in \mathbf{R}$。要得到 minimax 检测器，我们要最大化 $D^{\text{wc}}_{11}$ 与 $D^{\text{wc}}_{22}$ 的较小者，即求解 LP

```math
\begin{array}{ll}
\text{maximize} & \gamma \\
\text{subject to} & z_0 + z_1 \alpha_1 + z_2 \alpha_2 \ge \gamma \\
& w_0 + \beta_1 w_1 + \beta_2 w_2 \ge \gamma \\
& z_0 + z_1 a_i + z_2 a_i^2 \le \tilde{t}_i, \quad i = 1,\ldots,n \\
& w_0 + w_1 a_i + w_2 a_i^2 \le 1 - \tilde{t}_i, \quad i = 1,\ldots,n \\
& 0 \preceq \tilde{t} \preceq \mathbf{1}.
\end{array}
```

变量是 $z_0,z_1,z_2,w_0,w_1,w_2$ 以及 $\tilde{t}$。

† 文字层此处第一个约束印成 `z0 + z1α2 + z2α2 ≥ γ`，即 $\alpha_1$ 位置上是 $\alpha_2$；由上一式组的 $z_1\alpha_1$ 与 $b_1 = (\alpha_1,\alpha_2)^T$ 判定为 OCR 重影，已改回 $\alpha_1$。

### 7.4 <span style="color:#c0392b;">Chebyshev and Chernoff bounds（Chebyshev 界与 Chernoff 界）</span>

本节我们考虑两类经典的概率上界，并说明两者的推广都可以写成 convex optimization problem。原本的经典界对应的是有解析解的简单凸优化问题；而一般情形的凸优化表述，则让我们能算出更好的界，或者为更复杂的情形算出界。

### 7.4.1 <span style="color:#c0392b;">Chebyshev bounds（Chebyshev 界）</span>

Chebyshev 界在已知某些函数的期望值（例如均值与方差）的基础上，给出一个集合的概率上界。最简单的例子是 Markov's inequality（Markov 不等式）：如果 $X$ 是 $\mathbf{R}_+$ 上的随机变量，$\mathbf{E} X = \mu$，



（页眉：§7.4 Chebyshev and Chernoff bounds · 原书 p.375）

那么 $\operatorname{prob}(X \ge 1) \le \mu$，无论 $X$ 的分布是什么。另一个简单例子是 Chebyshev's bound：如果 $X$ 是 $\mathbf{R}$ 上的随机变量，$\mathbf{E} X = \mu$、$\mathbf{E}(X-\mu)^2 = \sigma^2$，那么我们就有 $\operatorname{prob}(|X-\mu| \ge 1) \le \sigma^2$，同样无论 $X$ 的分布是什么。这些简单界背后的想法可以推广到一个用凸优化来计算概率界的框架里。

设 $X$ 是 $S \subseteq \mathbf{R}^m$ 上的随机变量，$C \subseteq S$ 是我们想界定 $\operatorname{prob}(X \in C)$ 的集合。记 $\mathbf{1}_C$ 为集合 $C$ 的 0-1 indicator function（指示函数），即 $z \in C$ 时 $\mathbf{1}_C(z) = 1$、$z \notin C$ 时 $\mathbf{1}_C(z) = 0$。

我们对分布的已有知识，由某些函数的已知期望值构成：

```math
\mathbf{E} f_i(X) = a_i, \quad i = 1,\ldots,n,
```

其中 $f_i : \mathbf{R}^m \to \mathbf{R}$。我们取 $f_0$ 为取值恒等于 1 的常函数，对它恒有 $\mathbf{E} f_0(X) = a_0 = 1$。考虑这些 $f_i$ 的线性组合

```math
f(z) = \sum_{i=0}^{n} x_i f_i(z),
```

其中 $x_i \in \mathbf{R}$，$i = 0,\ldots,n$。由我们对 $\mathbf{E} f_i(X)$ 的知识，有 $\mathbf{E} f(X) = a^T x$。

现在假设 $f$ 满足条件：对所有 $z \in S$ 都有 $f(z) \ge \mathbf{1}_C(z)$，即 $f$ 在 $S$ 上逐点不小于 $C$ 的指示函数。那么

```math
\mathbf{E} f(X) = a^T x \ge \mathbf{E} \mathbf{1}_C(X) = \operatorname{prob}(X \in C).
```

换句话说，$a^T x$ 是 $\operatorname{prob}(X \in C)$ 的一个上界，它对所有支撑在 $S$ 上、且满足 $\mathbf{E} f_i(X) = a_i$ 的分布都成立。

我们可以通过求解下述问题，来找 $\operatorname{prob}(X \in C)$ 最好的这类上界

```math
\begin{array}{ll}
\text{minimize} & x_0 + a_1 x_1 + \cdots + a_n x_n \\
\text{subject to} & f(z) = \sum_{i=0}^{n} x_i f_i(z) \ge 1 \quad \text{for} \ z \in C \\
& f(z) = \sum_{i=0}^{n} x_i f_i(z) \ge 0 \quad \text{for} \ z \in S,\ z \notin C,
\end{array}
\qquad (7.17)
```

其中变量是 $x \in \mathbf{R}^{n+1}$。这个问题永远是凸的，因为约束可以写成

```math
g_1(x) = 1 - \inf_{z \in C} f(z) \le 0, \qquad g_2(x) = -\inf_{z \in S \setminus C} f(z) \le 0
```

（$g_1$ 与 $g_2$ 都是凸的）。问题 (7.17) 也可以看成一个 semi-infinite linear program（半无限线性规划），即一个具有线性目标、以及无限多条线性不等式的优化问题——每个 $z \in S$ 对应一条。

在简单的情形里我们可以解析地求解问题 (7.17)。作为例子，取 $S = \mathbf{R}_+$、$C = [1,\infty)$、$f_0(z) = 1$、$f_1(z) = z$，先验信息为 $\mathbf{E} f_1(X) = \mathbf{E} X = \mu \le 1$。$z \in S$ 上的约束 $f(z) \ge 0$ 简化为 $x_0 \ge 0$、$x_1 \ge 0$。$z \in C$ 上的约束 $f(z) \ge 1$，即对所有 $z \ge 1$ 有 $x_0 + x_1 z \ge 1$，简化为 $x_0 + x_1 \ge 1$。于是问题 (7.17) 成为

```math
\begin{array}{ll}
\text{minimize} & x_0 + \mu x_1 \\
\text{subject to} & x_0 \ge 0, \quad x_1 \ge 0 \\
& x_0 + x_1 \ge 1.
\end{array}
```



（页眉：7 Statistical estimation · 原书 p.376）

由于 $0 \le \mu \le 1$，这个简单 LP 的最优点为 $x_0 = 0$、$x_1 = 1$。这就给出经典的 Markov 界 $\operatorname{prob}(X \ge 1) \le \mu$。

在别的情形里，我们可以用凸优化来求解问题 (7.17)。

<span style="color:#2471a3;">**Remark 7.1 Duality and the Chebyshev bound problem（对偶性与 Chebyshev 界问题）.**</span> Chebyshev 界问题 (7.17) 对**所有**满足给定期望值约束的概率测度，给出 $\operatorname{prob}(X \in C)$ 的一个界。因此我们可以把 Chebyshev 界问题 (7.17) 看成是在为下述无限维问题的最优值构造上界

```math
\begin{array}{ll}
\text{maximize} & \int_C \pi(dz) \\
\text{subject to} & \int_S f_i(z) \pi(dz) = a_i, \quad i = 1,\ldots,n \\
& \int_S \pi(dz) = 1 \\
& \pi \ge 0,
\end{array}
\qquad (7.18)
```

其中变量是测度 $\pi$，而 $\pi \ge 0$ 表示该测度非负。

既然 Chebyshev 问题 (7.17) 为问题 (7.18) 给出一个界，那么它们之间由对偶相联系就不足为奇了。虽然 semi-infinite 与无限维问题超出本书范围，我们仍然可以形式地构造问题 (7.17) 的对偶：引入 Lagrange multiplier function（拉格朗日乘子函数）$p : S \to \mathbf{R}$，其中 $p(z)$ 是与不等式 $f(z) \ge 1$（对 $z \in C$）或 $f(z) \ge 0$（对 $z \in S \setminus C$）相关联的 Lagrange multiplier。在有限维情形里是求和的地方，这里改用对 $z$ 的积分，于是得到形式对偶

```math
\begin{array}{ll}
\text{maximize} & \int_C p(z)\, dz \\
\text{subject to} & \int_S f_i(z) p(z)\, dz = a_i, \quad i = 1,\ldots,n \\
& \int_S p(z)\, dz = 1 \\
& p(z) \ge 0 \quad \text{for all} \ z \in S,
\end{array}
```

其中优化变量是函数 $p$。

这本质上与 (7.18) 是同一个问题。

#### <span style="color:#2471a3;">Probability bounds with known first and second moments（已知一阶二阶矩时的概率界）</span>

作为例子，设 $S = \mathbf{R}^m$，并且已知随机变量 $X$ 的一阶与二阶矩：

```math
\mathbf{E} X = a \in \mathbf{R}^m, \qquad \mathbf{E} XX^T = \Sigma \in \mathbf{S}^m.
```

换句话说，我们已知 $m$ 个函数 $z_i$（$i = 1,\ldots,m$）与 $m(m+1)/2$ 个函数 $z_i z_j$（$i,j = 1,\ldots,m$）的期望值，关于分布没有别的信息。

此时我们可以把 $f$ 写成一般的二次函数

```math
f(z) = z^T P z + 2 q^T z + r,
```

其中（也就是上面讨论中的向量 $x$）变量是 $P \in \mathbf{S}^m$、$q \in \mathbf{R}^m$ 与 $r \in \mathbf{R}$。由我们对一阶二阶矩的知识，可得

```math
\begin{aligned}
\mathbf{E} f(X) &= \mathbf{E}(X^T P X + 2 q^T X + r) \\
&= \mathbf{E}\operatorname{tr}(P X X^T) + 2\mathbf{E} q^T X + r \\
&= \operatorname{tr}(\Sigma P) + 2 q^T a + r.
\end{aligned}
```

<span style="color:#1e8449;">**[译注]** 这一步是整节的技术心脏，也是「为什么 Chebyshev 界能用凸优化算」的全部理由：**把「对无限多个分布取最坏」换成了「对有限个矩约束取最优」**。概率问题是 $\max_\pi \int_C \pi(dz)$，变量 $\pi$ 是测度空间里的元素，维数无穷，直接不可算；但一旦把 $\mathbf{1}_C$ 换成它的多项式上界 $f = \sum x_i f_i$，就只剩 $n+1$ 个变量 $x$，而且约束 $f \ge \mathbf{1}_C$ 关于 $x$ 是凸的（$g_1(x) = 1 - \inf_{z \in C} f(z) \le 0$ 是仿射函数的下确界，因此是凸函数）。

**消失测试**：没有 (7.17) 这一转化，就只剩「用 Chebyshev 不等式 $\operatorname{prob}(|X-\mu| \ge 1) \le \sigma^2$ 硬套」这一条路。用本页的一阶二阶矩框架，取 $f(z) = (z^T u - u^T a)^2 / (u^T \Sigma u)$ 就能得到**每个方向 $u$ 各自最优**的界，即 $\operatorname{prob}(u^T(X-a) \ge 1) \le u^T\Sigma u$；二次型 $f$ 比标量方差多用了 $m(m+1)/2$ 个矩约束，$m$ 维时用到的信息量是标量情形的 $m(m+1)/2$ 倍。

**落点**：Boyd §7.4.1 与 §7.4.2（Chernoff 界，用指数族 $f(z) = e^{u^T z}$ 代替二次型）；$g_1$ 的凸性见 §3.2.1；测度形式 (7.18) 与本页 Remark 7.1 的形式对偶是同一件事的两种写法，**别把它当两个新定理**。</span>



（页眉：§7.4 Chebyshev and Chernoff bounds · 原书 p.377）

「对所有 $z$ 都有 $f(z) \ge 0$」这一约束可以写成 linear matrix inequality（线性矩阵不等式）

```math
\begin{bmatrix} P & q \\ q^T & r \end{bmatrix} \succeq 0.
```

特别地，由此可得 $P \succeq 0$。

现在假设集合 $C$ 是一个开多面体的补集，

```math
C = \mathbf{R}^m \setminus \mathcal{P}, \qquad \mathcal{P} = \{z \mid a_i^T z \lt b_i,\ i = 1,\ldots,k\}.
```

「对所有 $z \in C$ 都有 $f(z) \ge 1$」这个条件，等同于要求

```math
a_i^T z \ge b_i \ \Longrightarrow\ z^T P z + 2 q^T z + r \ge 1
```

对 $i = 1,\ldots,k$ 成立。这又可以写成：存在 $\tau_1,\ldots,\tau_k \ge 0$ 使得

```math
\begin{bmatrix} P & q \\ q^T & r - 1 \end{bmatrix} \succeq \tau_i \begin{bmatrix} 0 & a_i/2 \\ a_i^T/2 & -b_i \end{bmatrix}, \qquad i = 1,\ldots,k
```

（见 §B.2）。

把这些合起来，Chebyshev 界问题 (7.17) 可以写成

```math
\begin{array}{ll}
\text{minimize} & \operatorname{tr}(\Sigma P) + 2 q^T a + r \\
\text{subject to} & \begin{bmatrix} P & q \\ q^T & r - 1 \end{bmatrix} \succeq \tau_i \begin{bmatrix} 0 & a_i/2 \\ a_i^T/2 & -b_i \end{bmatrix}, \quad i = 1,\ldots,k \\
& \tau_i \ge 0, \quad i = 1,\ldots,k \\
& \begin{bmatrix} P & q \\ q^T & r \end{bmatrix} \succeq 0,
\end{array}
\qquad (7.19)
```

这是变量为 $P$、$q$、$r$ 与 $\tau_1,\ldots,\tau_k$ 的一个 semidefinite program（半定规划）。它的最优值记作 $\alpha$，是所有均值为 $a$、二阶矩为 $\Sigma$ 的分布上 $\operatorname{prob}(X \in C)$ 的上界。换个方向说，$1-\alpha$ 是 $\operatorname{prob}(X \in \mathcal{P})$ 的下界。

<span style="color:#2471a3;">**Remark 7.2 Duality and the Chebyshev bound problem（对偶性与 Chebyshev 界问题）.**</span> 与 (7.19) 相关联的对偶 SDP 可以写成

```math
\begin{array}{ll}
\text{maximize} & \sum_{i=1}^{k} \lambda_i \\
\text{subject to} & a_i^T z_i \ge b_i \lambda_i, \quad i = 1,\ldots,k \\
& \sum_{i=1}^{k} \begin{bmatrix} Z_i & z_i \\ z_i^T & \lambda_i \end{bmatrix} \preceq \begin{bmatrix} \Sigma & a \\ a^T & 1 \end{bmatrix} \\
& \begin{bmatrix} Z_i & z_i \\ z_i^T & \lambda_i \end{bmatrix} \succeq 0, \quad i = 1,\ldots,k.
\end{array}
```

† 文字层把第二个约束印成 `aT_i zi ≥ bλi`，漏掉了 $b$ 的下标；由上式的 $b_i$ 与量纲（$a_i^T z_i$ 与 $b_i \lambda_i$ 同为一次齐次）判定应为 $b_i \lambda_i$，已补。

其中变量是 $Z_i \in \mathbf{S}^m$、$z_i \in \mathbf{R}^m$ 与 $\lambda_i \in \mathbf{R}$，$i = 1,\ldots,k$。由于 SDP (7.19) 是严格可行的，strong duality 成立，且对偶最优值可达到。

我们可以给对偶问题一个很有意思的概率解释。假设 $Z_i, z_i, \lambda_i$ 对偶可行，且 $\lambda$ 的前 $r$ 个分量为正、其余为零。



（页眉：7 Statistical estimation · 原书 p.378）

为简单起见，我们再假设 $\sum_{i=1}^{k} \lambda_i \lt 1$。定义

```math
\begin{aligned}
x_i &= (1/\lambda_i) z_i, \quad i = 1,\ldots,r, \\
w_0 &= \frac{1}{\mu} \left(a - \sum_{i=1}^{r} \lambda_i x_i\right), \\
W &= \frac{1}{\mu} \left(\Sigma - \sum_{i=1}^{r} \lambda_i x_i x_i^T\right),
\end{aligned}
```

其中 $\mu = 1 - \sum_{i=1}^{k} \lambda_i$。作了这些定义之后，对偶可行约束可以写成

```math
a_i^T x_i \ge b_i, \quad i = 1,\ldots,r
```

以及

```math
\sum_{i=1}^{r} \lambda_i \begin{bmatrix} x_i x_i^T & x_i \\ x_i^T & 1 \end{bmatrix} + \mu \begin{bmatrix} W & w_0 \\ w_0^T & 1 \end{bmatrix} = \begin{bmatrix} \Sigma & a \\ a^T & 1 \end{bmatrix}.
```

进一步，由对偶可行性可得

```math
\begin{aligned}
\mu \begin{bmatrix} W & w_0 \\ w_0^T & 1 \end{bmatrix}
&= \begin{bmatrix} \Sigma & a \\ a^T & 1 \end{bmatrix} - \sum_{i=1}^{r} \lambda_i \begin{bmatrix} x_i x_i^T & x_i \\ x_i^T & 1 \end{bmatrix} \\
&= \begin{bmatrix} \Sigma & a \\ a^T & 1 \end{bmatrix} - \sum_{i=1}^{r} \begin{bmatrix} (1/\lambda_i) z_i z_i^T & z_i \\ z_i^T & \lambda_i \end{bmatrix} \\
&\succeq \begin{bmatrix} \Sigma & a \\ a^T & 1 \end{bmatrix} - \sum_{i=1}^{r} \begin{bmatrix} Z_i & z_i \\ z_i^T & \lambda_i \end{bmatrix} \succeq 0.
\end{aligned}
```

因此 $W \succeq w_0 w_0^T$，于是它可以分解成 $W - w_0 w_0^T = \sum_{i=1}^{s} w_i w_i^T$。现在考虑一个具有如下分布的离散随机变量 $X$。若 $s \ge 1$，我们取

```math
\begin{aligned}
X &= x_i && \text{with probability } \lambda_i, \quad i = 1,\ldots,r \\
X &= w_0 + \sqrt{s}\, w_i && \text{with probability } \mu/(2s), \quad i = 1,\ldots,s \\
X &= w_0 - \sqrt{s}\, w_i && \text{with probability } \mu/(2s), \quad i = 1,\ldots,s.
\end{aligned}
```

若 $s = 0$，我们取

```math
\begin{aligned}
X &= x_i && \text{with probability } \lambda_i, \quad i = 1,\ldots,r \\
X &= w_0 && \text{with probability } \mu.
\end{aligned}
```

容易验证 $\mathbf{E} X = a$ 且 $\mathbf{E} XX^T = \Sigma$，即这个分布与给定的矩相符。此外，由于 $x_i \in C$，

```math
\operatorname{prob}(X \in C) \ge \sum_{i=1}^{r} \lambda_i.
```

特别地，把这一解释用到对偶最优解上，我们就能构造出一个让 (7.19) 的 Chebyshev 界取等号的分布，这就说明 Chebyshev 界在这个情形下是 sharp（紧）的。

<span style="color:#1e8449;">**[译注]** 这一段是全书唯一一处**把 SDP 的对偶解翻译成一个具体分布**的地方，代价只有两个数的算术，回报却是「这个界不是保守估计，而是恰好紧的」。**消失测试**：没有这段构造，你只知道 (7.19) 给出的是一个**上界** $\alpha$（本例 $\alpha = 1 - 0.2048 = 0.7952$），于是只能说「正确检测概率至少 $0.2048$」，无法排除「真实下界其实是 $0.05$」这种可能；有了等号构造，$0.2048$ 就是**所有**零均值、协方差 $I$ 的噪声分布上的最小值，多一分都取不到。构造本身只用了三类点：$x_i$ 处（共 $r$ 个，总概率 $\sum\lambda_i$）、以及 $w_0 \pm \sqrt{s} w_i$ 处的 $2s$ 个对称点（总概率 $\mu = 1 - \sum\lambda_i$）。

**为什么必须是 $2s$ 个对称点**：约束 $\mathbf{E} XX^T = \Sigma$ 要求二阶矩精确匹配，而 $W - w_0w_0^T = \sum_{i=1}^{s} w_i w_i^T$ 的秩是 $s$；用 $\pm\sqrt{s}w_i$ 且各配 $\mu/(2s)$ 的概率，交叉项自动抵消、对角项正好凑出 $\mu W$。$s$ 个方向各摊 $\mu/(2s)$，概率一分为二，所以是 $2s$ 个点而不是 $s$ 个。

**落点**：figure 7.7（$\sigma = 1$ 时 $\mathcal{P}$ 上这个构造的图示化）；SDP 对偶的推导链见 §5.5 与 §B.2；LP 版本的同一构造在 §7.4.1 的 (7.18) 处（把矩阵换成向量即可）。**注意这里的方向**：$\lambda$ 越大界越松（下界越小），这是**对偶**目标的直觉，别拿它去和原问题的 $\min$ 混。</span>

### 7.4.2 <span style="color:#c0392b;">Chernoff bounds（Chernoff 界）</span>



（页眉：§7.4 Chebyshev and Chernoff bounds · 原书 p.379）

设 $X$ 是 $\mathbf{R}$ 上的随机变量。Chernoff 界说的是

```math
\operatorname{prob}(X \ge u) \le \inf_{\lambda \ge 0} \mathbf{E}\, e^{\lambda(X-u)},
```

它可以写成

```math
\log \operatorname{prob}(X \ge u) \le \inf_{\lambda \ge 0} \{-\lambda u + \log \mathbf{E}\, e^{\lambda X}\}.
\qquad (7.20)
```

回忆（例 3.41，p.106）右边那一项 $\log \mathbf{E}\, e^{\lambda X}$ 称为该分布的 cumulant generating function（累积量生成函数），它永远是凸的，因此要最小化的函数是凸的。当 cumulant generating function 有解析表达式、并且对 $\lambda$ 的最小化可以解析完成时，界 (7.20) 最好用。

例如，若 $X$ 是零均值、单位方差的 Gaussian 变量，cumulant generating function 是

```math
\log \mathbf{E}\, e^{\lambda X} = \lambda^2/2,
```

而 $-\lambda u + \lambda^2/2$ 在 $\lambda \ge 0$ 上的下确界在 $\lambda = u$ 处取得（若 $u \ge 0$），所以 Chernoff 界为（对 $u \ge 0$）

```math
\operatorname{prob}(X \ge u) \le e^{-u^2/2}.
```

Chernoff 界背后的想法可以推广到一个更一般的框架，在其中用凸优化来计算 $\mathbf{R}^m$ 中某个集合的概率的界。设 $C \subseteq \mathbf{R}^m$，并像上面讲 Chebyshev 界时那样，记 $\mathbf{1}_C$ 为 $C$ 的 0-1 指示函数。我们将导出 $\operatorname{prob}(X \in C)$ 的一个上界。（原则上我们可以算出 $\operatorname{prob}(X \in C)$，比如用 Monte Carlo 仿真或数值积分，但这两种都可能是令人望而生畏的计算任务，而且两者都不给出有保证的界。）

设 $\lambda \in \mathbf{R}^m$、$\mu \in \mathbf{R}$，考虑由下式给出的函数 $f : \mathbf{R}^m \to \mathbf{R}$

```math
f(z) = e^{\lambda^T z + \mu}.
```

与推导 Chebyshev 界时一样，若 $f$ 对所有 $z$ 满足 $f(z) \ge \mathbf{1}_C(z)$，那么我们可以断言

```math
\operatorname{prob}(X \in C) = \mathbf{E} \mathbf{1}_C(X) \le \mathbf{E} f(X).
```

显然对所有 $z$ 有 $f(z) \ge 0$；而要在 $z \in C$ 上有 $f(z) \ge 1$，等同于对所有 $z \in C$ 有 $\lambda^T z + \mu \ge 0$，即对所有 $z \in C$ 有 $-\lambda^T z \le \mu$。于是，若对所有 $z \in C$ 有 $-\lambda^T z \le \mu$，我们就得到界

```math
\operatorname{prob}(X \in C) \le \mathbf{E} \exp(\lambda^T X + \mu),
```

或者取对数，

```math
\log \operatorname{prob}(X \in C) \le \mu + \log \mathbf{E} \exp(\lambda^T X).
```



（页眉：7 Statistical estimation · 原书 p.380）

由此我们得到 Chernoff 界的一般形式：

```math
\begin{aligned}
\log \operatorname{prob}(X \in C) &\le \inf\{\mu + \log \mathbf{E} \exp(\lambda^T X) \mid -\lambda^T z \le \mu \ \text{for all} \ z \in C\} \\
&= \inf_{\lambda} \left(\sup_{z \in C} (-\lambda^T z) + \log \mathbf{E} \exp(\lambda^T X)\right) \\
&= \inf \left(S_C(-\lambda) + \log \mathbf{E} \exp(\lambda^T X)\right),
\end{aligned}
```

其中 $S_C$ 是 $C$ 的 support function（支撑函数）。注意第二项 $\log \mathbf{E} \exp(\lambda^T X)$ 是该分布的 cumulant generating function，它永远是凸的（见例 3.41，p.106）。计算这个界一般是一个凸优化问题。

#### <span style="color:#2471a3;">Chernoff bound for a Gaussian variable on a polyhedron（多面体上 Gaussian 变量的 Chernoff 界）</span>

作为一个具体例子，设 $X$ 是 $\mathbf{R}^m$ 上的 Gaussian 随机向量，零均值、协方差为 $I$，于是它的 cumulant generating function 是

```math
\log \mathbf{E} \exp(\lambda^T X) = \lambda^T \lambda/2.
```

我们取 $C$ 为由不等式描述的多面体：

```math
C = \{x \mid Ax \preceq b\},
```

并假设它非空。

为了在 Chernoff 界里使用，我们对 support function $S_C$ 使用一个对偶刻画：

```math
\begin{aligned}
S_C(y) &= \sup\{y^T x \mid Ax \preceq b\} \\
&= -\inf\{-y^T x \mid Ax \preceq b\} \\
&= -\sup\{-b^T u \mid A^T u = y,\ u \succeq 0\} \\
&= \inf\{b^T u \mid A^T u = y,\ u \succeq 0\},
\end{aligned}
```

其中第三行用了 LP duality：

```math
\inf\{c^T x \mid Ax \preceq b\} = \sup\{-b^T u \mid A^T u + c = 0,\ u \succeq 0\},
```

并取 $c = -y$。把这个 $S_C$ 的表达式代入 Chernoff 界，我们得到

```math
\begin{aligned}
\log \operatorname{prob}(X \in C) &\le \inf_{\lambda} \left(S_C(-\lambda) + \log \mathbf{E} \exp(\lambda^T X)\right) \\
&= \inf_{\lambda} \inf_{u} \{b^T u + \lambda^T \lambda/2 \mid u \succeq 0,\ A^T u + \lambda = 0\}.
\end{aligned}
```

于是，$\operatorname{prob}(X \in C)$ 的 Chernoff 界就是 QP

```math
\begin{array}{ll}
\text{minimize} & b^T u + \lambda^T \lambda/2 \\
\text{subject to} & u \succeq 0, \quad A^T u + \lambda = 0,
\end{array}
\qquad (7.21)
```

的最优值的指数，其中变量是 $u$ 与 $\lambda$。

<span style="color:#1e8449;">**[译注]** 这一步值得盯住：**「Chernoff 界」听上去是概率论的东西，这里却整段变成了一个 QP 的对偶与消元**。支撑函数那一串恒等式的实际作用是**把「$\sup$ over 一个多面体」换成「$\inf$ over 一个锥约束」**——$\sup\{y^Tx \mid Ax \preceq b\}$ 关于 $y$ 是凸的但不光滑，而 $\inf\{b^Tu \mid A^Tu = y, u \succeq 0\}$ 有显式的对偶变量，可以直接和 $\log \mathbf{E}\exp(\lambda^TX) = \lambda^T\lambda/2$ 拼成一个二次目标。

**落点与量的方向感**：$S_C$ 的定义见 §3.1.6 与 §A.1.6（那里叫 support function 并给出 $S_C = $ 对偶范数 × 半径的特例）；对偶在 §5.2。**消失测试**：如果没有这一步消元，$\log \operatorname{prob}(X\in C)$ 只能靠 Monte Carlo 估——估计的误差是 $O(1/\sqrt{N})$，要得到三位有效数字需 $N \approx 10^6$ 次采样，而且**估出来的是点值不是界**（原文在 §7.4.2 开头就明确说「neither method produces guaranteed bounds」）。有了 (7.21)，$m = 100$ 维的多面体也只要解一个 $O(m)$ 个约束的 QP，秒级出**严格上界**。

**一处易错**：$A^Tu + \lambda = 0$ 里的 $\lambda$ 是**自由变量**（可正可负），别因为 Chernoff 界在标量情形只要求 $\lambda \ge 0$ 就往上加 $\lambda \succeq 0$——那是 (7.20) 单变量的一个特例，加到 (7.21) 上会让对偶间隙非零、界变得无效地松。</span>



（页眉：§7.4 Chebyshev and Chernoff bounds · 原书 p.381）

这个问题有一个很有意思的几何解释。它等价于

```math
\begin{array}{ll}
\text{minimize} & b^T u + (1/2)\|A^T u\|_2^2 \\
\text{subject to} & u \succeq 0,
\end{array}
```

而后者是

```math
\begin{array}{ll}
\text{maximize} & -(1/2)\|x\|_2^2 \\
\text{subject to} & Ax \preceq b
\end{array}
```

的对偶。换句话说，Chernoff 界是

```math
\operatorname{prob}(X \in C) \le \exp(-\operatorname{dist}(0,C)^2/2),
\qquad (7.22)
```

其中 $\operatorname{dist}(0,C)$ 是原点到 $C$ 的 Euclidean 距离。

<span style="color:#2471a3;">**Remark 7.3**</span> 界 (7.22) 也可以不用 Chernoff 不等式导出。若 $0$ 到 $C$ 的距离为 $d$，则存在一个半空间 $H = \{z \mid a^T z \ge d\}$（其中 $\|a\|_2 = 1$）包含 $C$。随机变量 $a^T X$ 服从 $N(0,1)$，所以

```math
\operatorname{prob}(X \in C) \le \operatorname{prob}(X \in H) = \Phi(-d),
```

其中 $\Phi$ 是零均值、单位方差 Gaussian 的累积分布函数。由于对 $d \ge 0$ 有 $\Phi(-d) \le e^{-d^2/2}$，这个界至少和 Chernoff 界 (7.22) 一样 sharp。

### 7.4.3 <span style="color:#c0392b;">Example（例）</span>

本节我们用一个检测的例子来演示 Chebyshev 与 Chernoff 概率界方法。我们有一组 $m$ 个可能的符号或信号 $s \in \{s_1,s_2,\ldots,s_m\} \subseteq \mathbf{R}^n$，称为 signal constellation（信号星座）。其中一个信号经有噪信道发送出去。

接收信号是

```math
x = s + v,
```

其中 $v$ 是噪声，建模为一个随机变量。我们假设 $\mathbf{E} v = 0$ 且 $\mathbf{E} vv^T = \sigma^2 I$，即噪声分量 $v_1,\ldots,v_n$ 都是零均值、不相关的，方差为 $\sigma^2$。接收机必须依据收到的信号 $x = s + v$ 来估计发的是哪个信号。minimum distance detector（最小距离检测器）把离 $x$ 最近（Euclidean 范数意义下）的符号 $s_k$ 取作估计。（若噪声 $v$ 是 Gaussian 的，则最小距离译码与 maximum likelihood 译码相同。）

若发送的是信号 $s_k$，那么当给定 $x$ 时 $s_k$ 是估计值，就发生了正确检测。这等价于 $s_k$ 比其它信号更接近 $x$，即

```math
\|x - s_k\|_2 \lt \|x - s_j\|_2, \qquad j \ne k.
```

于是，符号 $s_k$ 的正确检测，发生在随机变量 $v$ 满足线性不等式

```math
2(s_j - s_k)^T (s_k + v) \lt \|s_j\|_2^2 - \|s_k\|_2^2, \qquad j \ne k
```

的时候。这些不等式定义了 $s_k$ 在信号星座中的 Voronoi region（Voronoi 区域）$V_k$，也就是比星座中任何其它信号都更接近 $s_k$ 的那些点组成的集合。$s_k$ 的正确检测概率就是 $\operatorname{prob}(s_k + v \in V_k)$。

Figure 7.5 给出了一个简单的例子，$m = 7$ 个信号，维数 $n = 2$。

### 7.5 <span style="color:#c0392b;">Experiment design（实验设计）</span>

我们考虑这样一个问题：从测量或实验

```math
y_i = a_i^T x + w_i, \qquad i = 1,\ldots,m
```

中估计向量 $x \in \mathbf{R}^n$，其中 $w_i$ 是测量噪声。

我们假设 $w_i$ 是相互独立的 Gaussian 随机变量，零均值、单位方差，且测量向量 $a_1,\ldots,a_m$ 张成 $\mathbf{R}^n$。$x$ 的 maximum likelihood 估计（它与 minimum variance 估计相同）由 least-squares 解给出

```math
\hat{x} = \left(\sum_{i=1}^{m} a_i a_i^T\right)^{-1} \sum_{i=1}^{m} y_i a_i.
```

相应的估计误差 $e = \hat{x} - x$ 是零均值的，协方差矩阵为

```math
E = \mathbf{E}\, ee^T = \left(\sum_{i=1}^{m} a_i a_i^T\right)^{-1}.
```

矩阵 $E$ 刻画了估计的精度，也就是实验的信息量。例如 $x$ 的 $\alpha$-confidence level ellipsoid（置信水平椭球）由

```math
\mathcal{E} = \{z \mid (z - \hat{x})^T E^{-1} (z - \hat{x}) \le \beta\}
```

给出，其中 $\beta$ 是依赖于 $n$ 与 $\alpha$ 的常数。

我们假设刻画测量的那些向量 $a_1,\ldots,a_m$ 可以从 $p$ 个可能的 test vector（测试向量）$v_1,\ldots,v_p \in \mathbf{R}^n$ 中选取，即每个 $a_i$ 是



（页眉：§7.5 Experiment design · 原书 p.385）

$v_j$ 之一。experiment design（实验设计）的目标是在这些可选值中挑选向量 $a_i$，使误差协方差 $E$ 在某种意义上小。换句话说，$m$ 个实验或测量中的每一个，都可以从 $p$ 个可能实验组成的固定菜单中选取；我们的任务是找一组（合起来）信息量最大的测量。

记 $m_j$ 为把 $a_i$ 取成 $v_j$ 的实验个数，于是有

```math
m_1 + \cdots + m_p = m.
```

我们可以把误差协方差矩阵写成

```math
E = \left(\sum_{i=1}^{m} a_i a_i^T\right)^{-1} = \left(\sum_{j=1}^{p} m_j v_j v_j^T\right)^{-1}.
```

这说明误差协方差只依赖于所选每一类实验的个数（即 $m_1,\ldots,m_p$）。

基本的 experiment design 问题如下。给定实验的可选菜单（即 $v_1,\ldots,v_p$）与要做的实验总数 $m$，选择每一类实验的个数 $m_1,\ldots,m_p$，使误差协方差 $E$ 在某种意义上小。当然，变量 $m_1,\ldots,m_p$ 必须是整数，且和等于给定的实验总数 $m$。这导致优化问题

```math
\begin{array}{ll}
\text{minimize (w.r.t. } \mathbf{S}^n_+) & E = \left(\sum_{j=1}^{p} m_j v_j v_j^T\right)^{-1} \\
\text{subject to} & m_i \ge 0, \quad m_1 + \cdots + m_p = m \\
& m_i \in \mathbf{Z},
\end{array}
\qquad (7.23)
```

其中变量是整数 $m_1,\ldots,m_p$。

基本的 experiment design 问题 (7.23) 是 positive semidefinite cone（半正定锥）上的一个 vector optimization problem（向量优化问题）。若一个实验设计给出 $E$、另一个给出 $\tilde{E}$，且 $E \preceq \tilde{E}$，那么第一个实验设计当然和第二个一样好或更好。例如，第一个实验设计的置信椭球（平移到原点以便比较）包含在第二个实验设计的置信椭球之内。我们也可以说，对任意向量 $q$，第一个实验设计都能让我们比第二个更好地（即方差更小地）估计 $q^T x$，因为对 $q^T x$ 的估计方差在第一个设计中是 $q^T E q$、在第二个设计中是 $q^T \tilde{E} q$。下面我们会看到这个问题的几种常用标量化。

### 7.5.1 <span style="color:#c0392b;">The relaxed experiment design problem（松弛实验设计问题）</span>

当实验总数 $m$ 与 $p$ 可比时，基本的 experiment design 问题 (7.23) 可能是一个困难的组合问题，因为此时 $m_i$ 都是很小的整数。然而当 $m$ 远大于 $p$ 时，可以通过忽略（或松弛）$m_i$ 为整数这一约束，为 (7.23) 找到一个好的近似解。

令 $\lambda_i = m_i/m$，它是



（页眉：7 Statistical estimation · 原书 p.386）

把 $a_j$ 取成 $v_i$ 的实验占总数的比例，也就是实验 $i$ 的相对频率。我们可以用 $\lambda_i$ 把误差协方差表示成

```math
E = \frac{1}{m} \left(\sum_{i=1}^{p} \lambda_i v_i v_i^T\right)^{-1}.
\qquad (7.24)
```

向量 $\lambda \in \mathbf{R}^p$ 满足 $\lambda \succeq 0$、$\mathbf{1}^T \lambda = 1$，并且每个 $\lambda_i$ 都是 $1/m$ 的整数倍。忽略最后这条约束，我们得到问题

```math
\begin{array}{ll}
\text{minimize (w.r.t. } \mathbf{S}^n_+) & E = (1/m)\left(\sum_{i=1}^{p} \lambda_i v_i v_i^T\right)^{-1} \\
\text{subject to} & \lambda \succeq 0, \quad \mathbf{1}^T \lambda = 1,
\end{array}
\qquad (7.25)
```

其中变量是 $\lambda \in \mathbf{R}^p$。为了把它与原来的组合 experiment design 问题 (7.23) 区分开，我们称它为 relaxed experiment design problem（松弛实验设计问题）。

松弛实验设计问题 (7.25) 是一个凸优化问题，因为目标 $E$ 是 $\lambda$ 的 $\mathbf{S}^n_+$-convex 函数。

关于（组合的）experiment design 问题 (7.23) 与松弛问题 (7.25) 之间的关系，可以给出若干论断。显然，松弛问题的最优值给出组合问题最优值的下界，因为组合问题多了一条约束。由松弛问题 (7.25) 的一个解，我们可以按下述方式构造组合问题 (7.23) 的一个次优解。首先做简单的四舍五入

```math
m_i = \operatorname{round}(m \lambda_i), \qquad i = 1,\ldots,p.
```

对应于这一组 $m_1,\ldots,m_p$ 的向量是 $\tilde{\lambda}$，

```math
\tilde{\lambda}_i = (1/m)\operatorname{round}(m \lambda_i), \qquad i = 1,\ldots,p.
```

向量 $\tilde{\lambda}$ 满足「每个分量都是 $1/m$ 的整数倍」这一约束。显然有 $|\lambda_i - \tilde{\lambda}_i| \le 1/(2m)$，所以当 $m$ 很大时 $\lambda \approx \tilde{\lambda}$。这意味着当 $m$ 很大时约束 $\mathbf{1}^T \tilde{\lambda} = 1$ 近似满足，而且与 $\tilde{\lambda}$ 和 $\lambda$ 相应的误差协方差矩阵也很接近。

我们还可以给出松弛实验设计问题 (7.25) 的另一种解释。我们可以把向量 $\lambda \in \mathbf{R}^p$ 看作在实验 $v_1,\ldots,v_p$ 上定义了一个概率分布。我们对 $\lambda$ 的选择相当于一个随机实验：每个实验 $a_i$ 以概率 $\lambda_j$ 取 $v_j$ 的形式。

在本节余下部分，我们只考虑松弛实验设计问题，因此讨论中省略「松弛」这一限定词。

### 7.5.2 <span style="color:#c0392b;">Scalarizations（标量化）</span>

针对 experiment design 问题 (7.25)——它是 positive semidefinite cone 上的一个向量优化问题——已经提出了好几种标量化。

<span style="color:#1e8449;">**[译注]** 这一页藏着全书最容易「**写反了不报错、只给错答案**」的一处符号陷阱，必须显式说清。$E$ 是 $\left(\sum_j m_j v_j v_j^T\right)^{-1}$，取逆会**反转** Loewner 序（PsD 序）的方向：

```math
U \preceq R \preceq L \ \Longrightarrow\ U^{-1} \succeq R^{-1} \succeq L^{-1}.
```

所以「多做实验 ⇒ 信息矩阵 $\sum m_j v_j v_j^T$ 变大 ⇒ $E$ 变小」是对的，但如果你按「$E$ 越大越好」去比较设计，就会挑出**最差**的那个。原文第 p.399 那句话（$E \preceq \tilde{E}$ 则第一个设计不劣）正是在说「$E$ 小者胜」——用 $q^T E q$ 看更直白：$q^T x$ 的估计方差就是 $q^T E q$，**方差小才是好**，与直觉的「越大越强」正好相反。

**消失测试**：把这条序方向搞反，误差会静默穿过整个 §7.5，症状是**最优化解退化到边界**——比如 D-optimal 的 $\min \log\det E$ 若被写成 $\max\log\det E$，解会给出把 $m$ 个实验全押在**最差**候选 $v_j$ 上的 $\lambda = e_j$（因为 $\det$ 随协方差增大而增大），而你只会看到「求解成功，目标值 $1.2$」，不会看到任何报错。

**落点**：§2.3.3 的 PsD 序定义；Strang 线代里「矩阵迹/行列式随特征值单调」的同一事实；本页 (7.24) 与 (7.25)；练习 7.5 让你直接验证这个单调方向。</span>



（页眉：§7.5 Experiment design · 原书 p.387）

#### <span style="color:#2471a3;">D-optimal design（D-最优设计）</span>

用得最广的一种标量化叫 D-optimal design，它最小化误差协方差矩阵 $E$ 的行列式。这相当于把实验设计成使所得置信椭球的体积最小（在固定置信水平下）。忽略 $E$ 中的常数因子 $1/m$，并对目标取对数，我们可以把这个问题写成

```math
\begin{array}{ll}
\text{minimize} & \log\det\left(\sum_{i=1}^{p} \lambda_i v_i v_i^T\right)^{-1} \\
\text{subject to} & \lambda \succeq 0, \quad \mathbf{1}^T \lambda = 1,
\end{array}
\qquad (7.26)
```

这是一个凸优化问题。

#### <span style="color:#2471a3;">E-optimal design（E-最优设计）</span>

在 E-optimal design 中，我们最小化误差协方差矩阵的范数，即 $E$ 的最大特征值。由于置信椭球 $\mathcal{E}$ 的直径（最长半轴的两倍）正比于 $\|E\|_2^{1/2}$，最小化 $\|E\|_2$ 在几何上可以解释为最小化置信椭球的直径。E-optimal design 也可以解释为：在所有满足 $\|q\|_2 = 1$ 的 $q$ 上，最小化 $q^T e$ 的最大方差。

E-optimal 实验设计问题是

```math
\begin{array}{ll}
\text{minimize} & \left\|\left(\sum_{i=1}^{p} \lambda_i v_i v_i^T\right)^{-1}\right\|_2 \\
\text{subject to} & \lambda \succeq 0, \quad \mathbf{1}^T \lambda = 1.
\end{array}
```

目标函数是 $\lambda$ 的凸函数，所以这是一个凸问题。E-optimal 实验设计问题可以写成 SDP

```math
\begin{array}{ll}
\text{maximize} & t \\
\text{subject to} & \sum_{i=1}^{p} \lambda_i v_i v_i^T \succeq t I \\
& \lambda \succeq 0, \quad \mathbf{1}^T \lambda = 1,
\end{array}
\qquad (7.27)
```

其中变量是 $\lambda \in \mathbf{R}^p$ 与 $t \in \mathbf{R}$。

#### <span style="color:#2471a3;">A-optimal design（A-最优设计）</span>

在 A-optimal experiment design 中，我们最小化 $\operatorname{tr} E$，即协方差矩阵的迹。这个目标其实就是误差平方范数的均值：

```math
\mathbf{E}\|e\|_2^2 = \mathbf{E}\operatorname{tr}(ee^T) = \operatorname{tr} E.
```

A-optimal 实验设计问题是

```math
\begin{array}{ll}
\text{minimize} & \operatorname{tr}\left(\sum_{i=1}^{p} \lambda_i v_i v_i^T\right)^{-1} \\
\text{subject to} & \lambda \succeq 0, \quad \mathbf{1}^T \lambda = 1.
\end{array}
\qquad (7.28)
```

这同样是一个凸问题。和 E-optimal 实验设计问题一样，它也可以写成 SDP：

```math
\begin{array}{ll}
\text{minimize} & \mathbf{1}^T u \\
\text{subject to} & \begin{bmatrix} \sum_{i=1}^{p} \lambda_i v_i v_i^T & e_k \\ e_k^T & u_k \end{bmatrix} \succeq 0, \quad k = 1,\ldots,n \\
& \lambda \succeq 0, \quad \mathbf{1}^T \lambda = 1,
\end{array}
```



（页眉：7 Statistical estimation · 原书 p.388）

其中变量是 $u \in \mathbf{R}^n$ 与 $\lambda \in \mathbf{R}^p$，这里 $e_k$ 是第 $k$ 个单位向量。

#### <span style="color:#2471a3;">Optimal experiment design and duality（最优实验设计与对偶）</span>

这三种标量化的 Lagrange 对偶都有很有意思的几何含义。

D-optimal 实验设计问题 (7.26) 的对偶可以写成

```math
\begin{array}{ll}
\text{maximize} & \log\det W + n\log n \\
\text{subject to} & v_i^T W v_i \le 1, \quad i = 1,\ldots,p,
\end{array}
```

其中变量是 $W \in \mathbf{S}^n$，定义域为 $\mathbf{S}^n_{++}$（见 exercise 5.10）。这个对偶问题有简单的解释：最优解 $W^{\star}$ 决定了以原点为中心、包含点 $v_1,\ldots,v_p$ 的**最小体积椭球** $\{x \mid x^T W^{\star} x \le 1\}$。（也可参看 p.222 对问题 (5.14) 的讨论。）由互补松弛性，

```math
\lambda^{\star}_i \left(1 - v_i^T W^{\star} v_i\right) = 0, \qquad i = 1,\ldots,p,
\qquad (7.29)
```

也就是说，最优实验设计只使用那些**落在最小体积椭球表面上**的实验 $v_i$。

E-optimal 与 A-optimal 设计的对偶可以有类似的解释。问题 (7.27) 与 (7.28) 的对偶分别可以写成

```math
\begin{array}{ll}
\text{maximize} & \operatorname{tr} W \\
\text{subject to} & v_i^T W v_i \le 1, \quad i = 1,\ldots,p \\
& W \succeq 0,
\end{array}
\qquad (7.30)
```

与

```math
\begin{array}{ll}
\text{maximize} & \left(\operatorname{tr} W^{1/2}\right)^2 \\
\text{subject to} & v_i^T W v_i \le 1, \quad i = 1,\ldots,p,
\end{array}
\qquad (7.31)
```

两个问题中的变量都是 $W \in \mathbf{S}^n$。第二个问题中有隐式约束 $W \in \mathbf{S}^n_+$。（见 exercise 5.40 与 5.10。）

与 D-optimal design 一样，最优解 $W^{\star}$ 决定了包含点 $v_1,\ldots,v_p$ 的最小椭球 $\{x \mid x^T W^{\star} x \le 1\}$。此外 $W^{\star}$ 与 $\lambda^{\star}$ 满足互补松弛条件 (7.29)，即最优设计只使用那些落在 $W^{\star}$ 所定义椭球表面上的实验 $v_i$。

### 7.5.3 <span style="color:#c0392b;">Extensions（推广）</span>

#### <span style="color:#2471a3;">Resource limits（资源限制）</span>

假设每个实验都关联一个代价 $c_i$，它可以代表用 $v_i$ 做一个实验的经济成本或所需时间。那么总成本（或者说所需总时间，如果实验是依次进行的话）就是

```math
m_1 c_1 + \cdots + m_p c_p = m c^T \lambda.
```

我们可以通过在基本实验设计问题中加一条线性不等式 $m c^T \lambda \le B$（其中 $B$ 是预算）来加上总成本的上限。我们也可以加多条线性不等式，代表对多种资源的限制。

#### <span style="color:#2471a3;">Multiple measurements per experiment（每个实验多次测量）</span>

我们还可以考虑一个推广：每个实验产出多个测量。换句话说，当我们用某个可能的选项做一次实验时，我们会得到若干个测量值。为建模这种情形，我们可以沿用与前面相同的记号，只把 $v_i$ 取成 $\mathbf{R}^{n \times k_i}$ 中的矩阵：

```math
v_i = \begin{bmatrix} u_{i1} & \cdots & u_{ik_i} \end{bmatrix},
```

其中 $k_i$ 是做实验 $v_i$ 时得到的（标量）测量个数。在这个更复杂的设定下，误差协方差矩阵具有完全一样的形式。

配合代表成本或时间限制的附加线性不等式，我们还可以为「同时做一组测量」所带的折扣或时间节省建模。比如，假设同时做（标量）测量 $v_1$ 与 $v_2$ 的成本小于分别做它们的成本之和。



（页眉：§7.5 Experiment design · 原书 p.391）

这时我们可以取 $v_3$ 为矩阵

```math
v_3 = \begin{bmatrix} v_1 & v_2 \end{bmatrix}
```

并分别赋予代价 $c_1$、$c_2$、$c_3$，对应「只做第一个测量」、「只做第二个测量」与「两个同时做」。

当我们求解这个实验设计问题时，$\lambda_1$ 会告诉我们应当以多大比例单独做第一个实验，$\lambda_2$ 告诉我们以多大比例单独做第二个实验，$\lambda_3$ 告诉我们以多大比例同时做这两个实验。（通常我们会期望这里出现一个选择；我们不会期望 $\lambda_1 \gt 0$、$\lambda_2 \gt 0$ 且 $\lambda_3 \gt 0$ 同时成立。）

where $T_i$ is a zero-one matrix with exactly one element equal to one per column, and $\theta_i \ge 0$, $\sum_{i=1}^{N}\theta_i = 1$. What is the maximum number of deterministic detectors $N$ we may need?

**7.12 Optimal action.** In detector design, we are given a matrix $P \in \mathbf{R}^{n \times m}$ (whose columns are probability distributions), and then design a matrix $T \in \mathbf{R}^{m \times n}$ (whose columns are probability distributions), so that $D = TP$ has large diagonal elements (and small off-diagonal elements). ## 8.1 <span style="color:#c0392b;">Projection on a set（集合上的投影）</span>

点 $x_0 \in \mathbf{R}^n$ 在范数 $\|\cdot\|$ 下到闭集 $C \subseteq \mathbf{R}^n$ 的**距离**定义为

```math
\operatorname{dist}(x_0,C) = \inf\{\|x_0 - x\| \mid x \in C\}.
```

这里的下确界总是能达到的。我们把任何离 $x_0$ 最近的点 $z \in C$（即满足 $\|z - x_0\| = \operatorname{dist}(x_0,C)$ 的点）称为 $x_0$ 在 $C$ 上的**投影**（projection）。一般来说，$x_0$ 在 $C$ 上的投影可能不止一个，即 $C$ 中可能有多个点都离 $x_0$ 最近。

在某些特殊情形下我们可以断言，一个点在集合上的投影是唯一的。例如，若 $C$ 是闭凸集，且范数是严格凸的（例如 Euclidean 范数），那么对任意 $x_0$，总存在唯一一个离 $x_0$ 最近的 $z \in C$。作为有趣的反面，我们有如下结果：若对每个 $x_0$，$x_0$ 在 $C$ 上的 Euclidean 投影都唯一，则 $C$ 是闭凸集（见 exercise 8.2）。

我们用记号 $P_C : \mathbf{R}^n \to \mathbf{R}^n$ 表示任何满足「$P_C(x_0)$ 是 $x_0$ 在 $C$ 上的一个投影」的函数，即对所有 $x_0$，

```math
P_C(x_0) \in C, \qquad \|x_0 - P_C(x_0)\| = \operatorname{dist}(x_0,C).
```

换句话说，我们有

```math
P_C(x_0) = \arg\min\{\|x - x_0\| \mid x \in C\}.
```

我们称 $P_C$ 为 $C$ 上的投影。

<span style="color:#c0392b;">**Example 8.1**</span> **Projection on the unit square in $\mathbf{R}^2$（$\mathbf{R}^2$ 中单位正方形上的投影）.** 考虑 $\mathbf{R}^2$ 中单位正方形的（边界），即 $C = \{x \in \mathbf{R}^2 \mid \|x\|_\infty = 1\}$。取 $x_0 = 0$。

在 $\ell_1$-范数下，四个点 $(1,0)$、$(0,-1)$、$(-1,0)$、$(0,1)$ 都离 $x_0 = 0$ 最近，距离为 $1$，所以在 $\ell_1$-范数下 $\operatorname{dist}(x_0,C) = 1$。同样的结论对 $\ell_2$-范数也成立。

在 $\ell_\infty$-范数下，$C$ 中所有点到 $x_0$ 的距离都是 $1$，且 $\operatorname{dist}(x_0,C) = 1$。



（页眉：8 Geometric problems · 原书 p.398）

<span style="color:#c0392b;">**Example 8.2**</span> **Projection onto rank-$k$ matrices（向秩不超过 $k$ 的矩阵集投影）.** 考虑秩不超过 $k$ 的 $m \times n$ 矩阵集合

```math
C = \{X \in \mathbf{R}^{m \times n} \mid \operatorname{rank} X \le k\},
```

其中 $k \le \min\{m,n\}$，并设 $X_0 \in \mathbf{R}^{m \times n}$。我们可以在（谱范数，即最大奇异值范数）$\|\cdot\|_2$ 下通过奇异值分解求出 $X_0$ 在 $C$ 上的一个投影。令

```math
X_0 = \sum_{i=1}^{r} \sigma_i u_i v_i^T
```

为 $X_0$ 的奇异值分解，其中 $r = \operatorname{rank} X_0$。那么矩阵 $Y = \sum_{i=1}^{\min\{k,r\}} \sigma_i u_i v_i^T$ 就是 $X_0$ 在 $C$ 上的一个投影。

### 8.1.1 <span style="color:#c0392b;">Projecting a point on a convex set（向凸集投影）</span>

若 $C$ 是凸集，那么我们可以通过求解一个凸优化问题来计算投影 $P_C(x_0)$ 与距离 $\operatorname{dist}(x_0,C)$。我们把集合 $C$ 用一组线性等式与凸不等式表示

```math
Ax = b, \qquad f_i(x) \le 0, \quad i = 1,\ldots,m,
\qquad (8.1)
```

并通过求解问题

```math
\begin{array}{ll}
\text{minimize} & \|x - x_0\| \\
\text{subject to} & f_i(x) \le 0, \quad i = 1,\ldots,m \\
& Ax = b,
\end{array}
\qquad (8.2)
```

来求 $x_0$ 在 $C$ 上的投影，其中变量是 $x$。这个问题可行当且仅当 $C$ 非空；当它可行时，其最优值是 $\operatorname{dist}(x_0,C)$，而任何最优点都是 $x_0$ 在 $C$ 上的一个投影。

#### <span style="color:#2471a3;">Euclidean projection on a polyhedron（向多面体的 Euclidean 投影）</span>

$x_0$ 在用线性不等式 $Ax \preceq b$ 描述的多面体上的投影，可以通过求解 QP

```math
\begin{array}{ll}
\text{minimize} & \|x - x_0\|_2^2 \\
\text{subject to} & Ax \preceq b
\end{array}
```

来计算。有些特殊情形有简单的解析解。

- $x_0$ 在超平面 $C = \{x \mid a^T x = b\}$ 上的 Euclidean 投影由

```math
P_C(x_0) = x_0 + (b - a^T x_0)a/\|a\|_2^2
```

  给出。

- $x_0$ 在半空间 $C = \{x \mid a^T x \le b\}$ 上的 Euclidean 投影由

```math
P_C(x_0) = \begin{cases} x_0 + (b - a^T x_0)a/\|a\|_2^2 & a^T x_0 \gt b \\ x_0 & a^T x_0 \le b \end{cases}
```

  给出。



（页眉：§8.1 Projection on a set · 原书 p.399）

- $x_0$ 在盒子 $C = \{x \mid l \preceq x \preceq u\}$（其中 $l \prec u$）上的 Euclidean 投影由

```math
P_C(x_0)_k = \begin{cases} l_k & x_{0k} \le l_k \\ x_{0k} & l_k \le x_{0k} \le u_k \\ u_k & x_{0k} \ge u_k \end{cases}
```

  给出。

#### <span style="color:#2471a3;">Euclidean projection on a proper cone（向 proper cone 的 Euclidean 投影）</span>

记 $x = P_K(x_0)$ 为点 $x_0$ 在 proper cone（正常锥）$K$ 上的 Euclidean 投影。问题

```math
\begin{array}{ll}
\text{minimize} & \|x - x_0\|_2^2 \\
\text{subject to} & x \succeq_K 0
\end{array}
```

的 KKT 条件为

```math
x \succeq_K 0, \qquad x - x_0 = z, \qquad z \succeq_{K^*} 0, \qquad z^T x = 0.
```

引入记号 $x_+ = x$ 与 $x_- = z$，我们可以把这些条件写成

```math
x_0 = x_+ - x_-, \qquad x_+ \succeq_K 0, \qquad x_- \succeq_{K^*} 0, \qquad x_+^T x_- = 0.
```

换句话说，把 $x_0$ 投影到锥 $K$ 上，就等于把它分解成两个**相互正交**的元素之差：一个关于 $K$ 非负（它就是 $x_0$ 在 $K$ 上的投影），另一个关于 $K^*$ 非负。

一些具体例子：

- 对 $K = \mathbf{R}^n_+$，有 $P_K(x_0)_k = \max\{x_{0k},0\}$。把向量 Euclidean 投影到非负象限，就是把每个负分量换成 $0$。
- 对 $K = \mathbf{S}^n_+$ 与 Euclidean（即 Frobenius）范数 $\|\cdot\|_F$，有 $P_K(X_0) = \sum_{i=1}^{n}\max\{0,\lambda_i\}v_i v_i^T$，其中 $X_0 = \sum_{i=1}^{n}\lambda_i v_i v_i^T$ 是 $X_0$ 的特征分解。把一个对称矩阵投影到正半定锥上，就是作它的特征展开并丢掉负特征值对应的项。这个矩阵同时也是在 $\ell_2$-范数（谱范数）下向正半定锥的投影。

<span style="color:#1e8449;">**[译注]** 这里藏着一个「**看起来是巧合、实质是必然**」的事实，值得单独拎出来：原书说 PsD 投影在 $\|\cdot\|_F$ 与 $\|\cdot\|_2$ 下是同一个矩阵，很多读者会记成「两种范数碰巧一致」。真正的机制是**谱分解把两个范数同时对角化**：对 $X_0 = \sum\lambda_i v_iv_i^T$，$\|\cdot\|_F^2 = \sum\lambda_i^2$、$\|\cdot\|_2 = \max_i|\lambda_i|$，两者都是 $\lambda$ 的**对称、单调**函数，而 PsD 锥在这些特征基下就是逐坐标的 $\lambda_i \ge 0$。所以最优点只能是 $\lambda_i^+ = \max\{0,\lambda_i\}$ 这唯一一个候选。

**消失测试**：把范数换成不酉不变的 $\ell_1$（即 $\sum_{ij}|X_{ij}|$），这个结论立刻失效——此时 PsD 投影不再是特征值截断，而要解一个 SDP，$n = 100$ 时变量数从 $n$ 个（特征值）涨到 $n(n+1)/2 = 5050$ 个。

**一处必须提醒的方向**：$x_+ \succeq_K 0$ 与 $x_- \succeq_{K^*} 0$ 用的是**两个不同的锥**（$K$ 与它的对偶 $K^*$），$x_+^T x_- = 0$ 才是正交性。若把 $x_-$ 也写成 $\succeq_K 0$，那在 $K = \mathbf{S}^n_+$ 时恰好不出错（自对偶），但在 $K$ 为二阶锥之外的一般 proper cone 上就会给出错误分解且**不报任何错**。

**落点**：§2.6.1（proper cone 与对偶锥）；Moreau 分解的名字与一般形式见 §A.1.6；$\mathbf{S}^n_+$ 的自对偶性见 §2.6.1 的例子；这道构造在 §8.1.1 之后立刻被 (8.2) 的一般框架覆盖，别当成新定理。</span>

### 8.1.2 <span style="color:#c0392b;">Separating a point and a convex set（分离一个点与一个凸集）</span>

设 $C$ 是由等式与不等式 (8.1) 描述的闭凸集。若 $x_0 \in C$，则 $\operatorname{dist}(x_0,C) = 0$，问题 (8.2) 的最优点就是 $x_0$。若 $x_0 \notin C$，则 $\operatorname{dist}(x_0,C) \gt 0$，问题 (8.2) 的最优值为正。此时我们会看到，任何一个对偶最优点都给出点 $x_0$ 与集合 $C$ 之间的一个分离超平面。

把点投影到凸集上，与找一张把两者（当点不在集合中时）分开的超平面，这两件事之间的联系并不令人意外。事实上，我们在 §2.5.1 中给出的 separating hyperplane theorem（分离超平面定理）的证明，正是依赖



（页眉：8 Geometric problems · 原书 p.400）

<span style="color:#2471a3;">**[Figure 8.1]**</span> Figure 8.1：一个点 $x_0$ 与它在凸集 $C$ 上的 Euclidean 投影 $P_C(x_0)$。位于两者正中间、法向量为 $P_C(x_0) - x_0$ 的那张超平面把点与集合严格分开。这个性质对一般范数不成立；见 exercise 8.4。

（图形不可从文字层复原：文字层只留下三个标签 $C$、$x_0$、$P_C(x_0)$ 与两个点的位置关系；点与集合的几何位置、超平面方向需读图。）

于求出两个集合之间的 Euclidean 距离。若记 $P_C(x_0)$ 为 $x_0$（$x_0 \notin C$）在 $C$ 上的 Euclidean 投影，则超平面

```math
(P_C(x_0) - x_0)^T\left(x - (1/2)(x_0 + P_C(x_0))\right) = 0
```

（严格地）把 $x_0$ 与 $C$ 分开，如 figure 8.1 所示。然而在别的范数下，投影问题与分离超平面问题之间最清楚的桥梁是 Lagrange 对偶。

我们先把 (8.2) 写成

```math
\begin{array}{ll}
\text{minimize} & \|y\| \\
\text{subject to} & f_i(x) \le 0, \quad i = 1,\ldots,m \\
& Ax = b \\
& x_0 - x = y,
\end{array}
```

其中变量是 $x$ 与 $y$。这个问题的 Lagrangian 是

```math
L(x,y,\lambda,\mu,\nu) = \|y\| + \sum_{i=1}^{m}\lambda_i f_i(x) + \nu^T(Ax - b) + \mu^T(x_0 - x - y),
```

而对偶函数是

```math
g(\lambda,\mu,\nu) = \begin{cases} \inf_x\left(\sum_{i=1}^{m}\lambda_i f_i(x) + \nu^T(Ax-b) + \mu^T(x_0 - x)\right) & \|\mu\|_* \le 1 \\ -\infty & \text{otherwise}, \end{cases}
```

于是得到对偶问题

```math
\begin{array}{ll}
\text{maximize} & \mu^T x_0 + \inf_x\left(\sum_{i=1}^{m}\lambda_i f_i(x) + \nu^T(Ax - b) - \mu^T x\right) \\
\text{subject to} & \lambda \succeq 0 \\
& \|\mu\|_* \le 1,
\end{array}
```

其中变量是 $\lambda$、$\mu$、$\nu$。我们可以这样解释这个对偶问题。假设 $\lambda$、$\mu$、$\nu$ 对偶可行、且对偶目标值为正，即 $\lambda \succeq 0$、$\|\mu\|_* \le 1$，



（页眉：§8.1 Projection on a set · 原书 p.401）

并且

```math
\mu^T x_0 - \mu^T x + \sum_{i=1}^{m}\lambda_i f_i(x) + \nu^T(Ax - b) \gt 0
```

对所有 $x$ 成立。这意味着对 $x \in C$ 有 $\mu^T x_0 \gt \mu^T x$，因此 $\mu$ 定义了一张严格分离超平面。特别地，假设 (8.2) 是严格可行的，于是 strong duality 成立。若 $x_0 \notin C$，最优值为正，而任何对偶最优解都定义一张严格分离超平面。

注意这个通过对偶来构造分离超平面的做法，**对任意范数都有效**。相比之下，前面描述的那个简单构造只对 Euclidean 范数有效。

#### <span style="color:#2471a3;">Separating a point from a polyhedron（把一个点与一个多面体分离）</span>

问题

```math
\begin{array}{ll}
\text{minimize} & \|y\| \\
\text{subject to} & Ax \preceq b \\
& x_0 - x = y
\end{array}
```

的对偶是

```math
\begin{array}{ll}
\text{maximize} & \mu^T x_0 - b^T\lambda \\
\text{subject to} & A^T\lambda = \mu \\
& \|\mu\|_* \le 1 \\
& \lambda \succeq 0,
\end{array}
```

它可以进一步简化成

```math
\begin{array}{ll}
\text{maximize} & (Ax_0 - b)^T\lambda \\
\text{subject to} & \|A^T\lambda\|_* \le 1 \\
& \lambda \succeq 0.
\end{array}
```

容易验证：若这个对偶目标值为正，则 $A^T\lambda$ 就是一张分离超平面的法向量。因为若 $Ax \preceq b$，则

```math
(A^T\lambda)^T x = \lambda^T(Ax) \le \lambda^T b \lt \lambda^T A x_0,
```

于是 $\mu = A^T\lambda$ 定义了一张分离超平面。

<span style="color:#1e8449;">**[译注]** 这一段的价值在于它**把「分离」从几何直觉降级成了一个 LP 的可行性判断**，而这件事对任意范数都成立——上一页那个中点超平面只在 $\ell_2$ 下对。**消失测试**：如果没有这条对偶路径，要在 $\ell_1$ 或 $\ell_\infty$ 下判断「点与多面体能否分开」，你只能靠几何作图或在范数球上做网格搜索；而 (8.3)/(8.5) 的对偶把它变成一个**单目标 LP**，$m$ 个约束、$n$ 个变量，单形法多项式时间（实际 $10^4$ 变量内秒级）。反过来，若你误以为中点超平面普遍成立而去用它，在 $\ell_\infty$ 下会得到一张**不分离**的超平面，而程序不会报错——你只会看到「点被判在集合外，但超平面没有把它分开」这个静默错误。

**量的方向感**：$\|\mu\|_* \le 1$ 是对偶范数约束。$\ell_2$ 时 $\|\cdot\|_* = \|\cdot\|_2$（自对偶）；$\ell_1$ 时 $\|\cdot\|_* = \|\cdot\|_\infty$，反之亦然。方向搞反（写成 $\|\mu\|_1 \le 1$ 却用了 $\ell_\infty$ 的原范数）会得到一个**更松**的对偶可行域，于是对偶最优值变大、分离判定变成假阳性。

**落点**：§2.5.1（分离超平面定理与证明）；§5.2（Lagrange 对偶的一般框架）；对偶范数定义见 §A.1.6；exercise 8.4 就是这条「Euclidean 特例不推广」的正面练习。</span>

### 8.1.3 <span style="color:#2471a3;">Projection and separation via indicator and support functions（用指示函数与支撑函数表述投影与分离）</span>

上面 §8.1.1 与 §8.1.2 描述的想法，可以用集合 $C$ 的指示函数 $I_C$ 与支撑函数 $S_C$ 紧凑地表述，它们定义为

```math
S_C(x) = \sup_{y \in C} x^T y, \qquad I_C(x) = \begin{cases} 0 & x \in C \\ +\infty & x \notin C. \end{cases}
```

把 $x_0$ 投影到一个闭凸集 $C$ 上的问题，可以紧凑地写成

```math
\begin{array}{ll}
\text{minimize} & \|x - x_0\| \\
\text{subject to} & I_C(x) \le 0,
\end{array}
```



（页眉：8 Geometric problems · 原书 p.402）

或者等价地写成

```math
\begin{array}{ll}
\text{minimize} & \|y\| \\
\text{subject to} & I_C(x) \le 0 \\
& x_0 - x = y,
\end{array}
```

其中变量是 $x$ 与 $y$。这个问题的对偶函数是

```math
\begin{aligned}
g(z,\lambda) &= \inf_{x,y}\left(\|y\| + \lambda I_C(x) + z^T(x_0 - x - y)\right) \\
&= \begin{cases} z^T x_0 + \inf_x\left(-z^T x + I_C(x)\right) & \|z\|_* \le 1,\ \lambda \ge 0 \\ -\infty & \text{otherwise} \end{cases} \\
&= \begin{cases} z^T x_0 - S_C(z) & \|z\|_* \le 1,\ \lambda \ge 0 \\ -\infty & \text{otherwise}, \end{cases}
\end{aligned}
```

于是得到对偶问题

```math
\begin{array}{ll}
\text{maximize} & z^T x_0 - S_C(z) \\
\text{subject to} & \|z\|_* \le 1.
\end{array}
```

若 $z$ 对偶最优且目标值为正，则对所有 $x \in C$ 有 $z^T x_0 \gt z^T x$，即 $z$ 定义了一张分离超平面。

## 8.2 <span style="color:#c0392b;">Distance between sets（集合之间的距离）</span>

在范数 $\|\cdot\|$ 下，两个集合 $C$ 与 $D$ 之间的距离定义为

```math
\operatorname{dist}(C,D) = \inf\{\|x - y\| \mid x \in C,\ y \in D\}.
```

两个集合 $C$ 与 $D$ 不相交，如果 $\operatorname{dist}(C,D) \gt 0$。它们相交，如果 $\operatorname{dist}(C,D) = 0$ 且定义中的下确界可达（例如当两个集合都闭、且其中一个有界时就是这种情况）。

集合之间的距离可以用点与集合之间的距离来表示，

```math
\operatorname{dist}(C,D) = \operatorname{dist}(0, D - C),
```

所以上一节的结果都可以直接用。不过本节我们会针对涉及集合间距离的问题专门推结果。这样我们就能利用 $C - D$ 的结构，也让解释更容易。

### 8.2.1 <span style="color:#c0392b;">Computing the distance between convex sets（计算凸集之间的距离）</span>

设 $C$ 与 $D$ 由两组凸不等式描述

```math
C = \{x \mid f_i(x) \le 0,\ i = 1,\ldots,m\}, \qquad D = \{x \mid g_i(x) \le 0,\ i = 1,\ldots,p\}.
```



（页眉：§8.2 Distance between sets · 原书 p.403）

<span style="color:#2471a3;">**[Figure 8.2]**</span> Figure 8.2：多面体 $C$ 与 $D$ 之间的 Euclidean 距离。虚线连接 $C$ 与 $D$ 中在 Euclidean 范数下彼此最近的那两点。这两点可以通过求解一个 QP 得到。

（图形不可从文字层复原：文字层只留下两个集合标签 $C$、$D$；两个多面体的形状、最近点的位置与虚线的走向需读图。）

（我们也可以加入线性等式，但这里为简单起见略去。）我们可以通过求解凸优化问题

```math
\begin{array}{ll}
\text{minimize} & \|x - y\| \\
\text{subject to} & f_i(x) \le 0, \quad i = 1,\ldots,m \\
& g_i(y) \le 0, \quad i = 1,\ldots,p
\end{array}
\qquad (8.3)
```

来求 $\operatorname{dist}(C,D)$。

#### <span style="color:#2471a3;">Euclidean distance between polyhedra（多面体之间的 Euclidean 距离）</span>

设 $C$ 与 $D$ 是由线性不等式组 $A_1 x \preceq b_1$ 与 $A_2 x \preceq b_2$ 分别描述的两个多面体。$C$ 与 $D$ 之间的距离就是最近的一对点（一个在 $C$ 中、另一个在 $D$ 中）之间的距离，如 figure 8.2 所示。它们之间的距离是问题

```math
\begin{array}{ll}
\text{minimize} & \|x - y\|_2 \\
\text{subject to} & A_1 x \preceq b_1 \\
& A_2 y \preceq b_2
\end{array}
\qquad (8.4)
```

的最优值。我们可以把目标平方，得到一个等价的 QP。

### 8.2.2 <span style="color:#c0392b;">Separating convex sets（分离凸集）</span>

求两个凸集之间距离的问题 (8.3) 的对偶，有一种很有意思的几何解释，即用集合之间的分离超平面来解释。我们先把问题写成下面这个等价形式：

```math
\begin{array}{ll}
\text{minimize} & \|w\| \\
\text{subject to} & f_i(x) \le 0, \quad i = 1,\ldots,m \\
& g_i(y) \le 0, \quad i = 1,\ldots,p \\
& x - y = w.
\end{array}
\qquad (8.5)
```

对偶函数是

```math
g(\lambda,z,\mu) = \inf_{x,y,w}\left(\|w\| + \sum_{i=1}^{m}\lambda_i f_i(x) + \sum_{i=1}^{p}\mu_i g_i(y) + z^T(x - y - w)\right)
```



（页眉：8 Geometric problems · 原书 p.404）

```math
= \begin{cases} \inf_x\left(\sum_{i=1}^{m}\lambda_i f_i(x) + z^T x\right) + \inf_y\left(\sum_{i=1}^{p}\mu_i g_i(y) - z^T y\right) & \|z\|_* \le 1 \\ -\infty & \text{otherwise}, \end{cases}
```

于是得到对偶问题

```math
\begin{array}{ll}
\text{maximize} & \inf_x\left(\sum_{i=1}^{m}\lambda_i f_i(x) + z^T x\right) + \inf_y\left(\sum_{i=1}^{p}\mu_i g_i(y) - z^T y\right) \\
\text{subject to} & \|z\|_* \le 1 \\
& \lambda \succeq 0, \quad \mu \succeq 0.
\end{array}
\qquad (8.6)
```

我们可以这样在几何上解释它。若 $\lambda$、$\mu$ 对偶可行且目标值为正，则

```math
\sum_{i=1}^{m}\lambda_i f_i(x) + z^T x + \sum_{i=1}^{p}\mu_i g_i(y) - z^T y \gt 0
```

对所有 $x$ 与 $y$ 成立。特别地，对 $x \in C$ 与 $y \in D$，有 $z^T x - z^T y \gt 0$，于是我们看到 $z$ 定义了一张严格分离 $C$ 与 $D$ 的超平面。

因此，若问题 (8.5) 与 (8.6) 之间 strong duality 成立（当 (8.5) 严格可行时就是这种情况），我们可以得到如下结论。若两个集合之间的距离为正，则它们可以被一张超平面严格分离。

#### <span style="color:#2471a3;">Separating polyhedra（分离多面体）</span>

把这些对偶结果用到由线性不等式 $A_1 x \preceq b_1$ 与 $A_2 x \preceq b_2$ 定义的集合上，我们得到对偶问题

```math
\begin{array}{ll}
\text{maximize} & -b_1^T\lambda - b_2^T\mu \\
\text{subject to} & A_1^T\lambda + z = 0 \\
& A_2^T\mu - z = 0 \\
& \|z\|_* \le 1 \\
& \lambda \succeq 0, \quad \mu \succeq 0.
\end{array}
```

若 $\lambda$、$\mu$、$z$ 对偶可行，则对所有 $x \in C$、$y \in D$，

```math
z^T x = -\lambda^T A_1 x \ge -\lambda^T b_1, \qquad z^T y = \mu^T A_2 x \le \mu^T b_2,
```

并且若对偶目标值为正，则

```math
z^T x - z^T y \ge -\lambda^T b_1 - \mu^T b_2 \gt 0,
```

即 $z$ 定义了一张分离超平面。

† 原文自身的小错：这里第二式印成 `z^T y = \mu^T A_2 x`，右边用的是 $x$ 而不是 $y$；由 $y \in D$ 与 $A_2 y \preceq b_2$ 的上下文判定应为 $\mu^T A_2 y$。照抄会得到「$y$ 被换成 $x$」的错式，但仍能推出相同结论，属于不报错只错中间步骤的类型。

### 8.2.3 <span style="color:#2471a3;">Distance and separation via indicator and support functions（用指示函数与支撑函数表述距离与分离）</span>

上面 §8.2.1 与 §8.2.2 描述的想法，可以用指示函数与支撑函数紧凑地表述。求两个凸集之间距离的问题可以写成凸问题

```math
\begin{array}{ll}
\text{minimize} & \|x - y\| \\
\text{subject to} & I_C(x) \le 0 \\
& I_D(y) \le 0,
\end{array}
```



（页眉：§8.3 Euclidean distance and angle problems · 原书 p.405）

它等价于

```math
\begin{array}{ll}
\text{minimize} & \|w\| \\
\text{subject to} & I_C(x) \le 0 \\
& I_D(y) \le 0 \\
& x - y = w.
\end{array}
```

这个问题的对偶是

```math
\begin{array}{ll}
\text{maximize} & -S_C(-z) - S_D(z) \\
\text{subject to} & \|z\|_* \le 1.
\end{array}
```

若 $z$ 对偶可行且目标值为正，则 $S_D(z) \lt -S_C(-z)$，即

```math
\sup_{x \in D} z^T x \lt \inf_{x \in C} z^T x.
```

换句话说，$z$ 定义了一张严格分离 $C$ 与 $D$ 的超平面。

## 8.3 <span style="color:#c0392b;">Euclidean distance and angle problems（Euclidean 距离与角度问题）</span>

设 $a_1,\ldots,a_n$ 是 $\mathbf{R}^n$ 中的一组向量，我们（暂时）假设它们的 Euclidean 长度是已知的

```math
l_1 = \|a_1\|_2, \quad \ldots, \quad l_n = \|a_n\|_2.
```

我们称这组向量为一个 configuration（构型），当它们线性无关时则称为一个 basis（基）。本节考虑涉及构型各种几何性质的优化问题，例如向量两两之间的 Euclidean 距离、两两之间的夹角，以及度量基的条件的各种几何量。

### 8.3.1 <span style="color:#c0392b;">Gram matrix and realizability（Gram 矩阵与可实现性）</span>

长度、距离与角度都可以用与向量 $a_1,\ldots,a_n$ 相关联的 Gram matrix（Gram 矩阵）来表示，它由

```math
G = A^T A, \qquad A = \begin{bmatrix} a_1 & \cdots & a_n \end{bmatrix}
```

给出，于是 $G_{ij} = a_i^T a_j$。$G$ 的对角元素由

```math
G_{ii} = l_i^2, \qquad i = 1,\ldots,n
```

给出，我们（暂时）假设它们是已知且固定的。$a_i$ 与 $a_j$ 之间的距离 $d_{ij}$ 是

```math
\begin{aligned}
d_{ij} &= \|a_i - a_j\|_2 \\
&= (l_i^2 + l_j^2 - 2a_i^T a_j)^{1/2} \\
&= (l_i^2 + l_j^2 - 2G_{ij})^{1/2}.
\end{aligned}
```



（页眉：8 Geometric problems · 原书 p.406）

反过来，我们可以用 $d_{ij}$ 表示 $G_{ij}$，

```math
G_{ij} = \frac{l_i^2 + l_j^2 - d_{ij}^2}{2},
```

注意（供后文使用）它是 $d_{ij}^2$ 的 affine function。

（非零的）$a_i$ 与 $a_j$ 之间的 correlation coefficient（相关系数）$\rho_{ij}$ 由

```math
\rho_{ij} = \frac{a_i^T a_j}{\|a_i\|_2\|a_j\|_2} = \frac{G_{ij}}{l_i l_j}
```

给出，于是 $G_{ij} = l_i l_j \rho_{ij}$ 是 $\rho_{ij}$ 的线性函数。（非零的）$a_i$ 与 $a_j$ 之间的夹角 $\theta_{ij}$ 由

```math
\theta_{ij} = \cos^{-1}\rho_{ij} = \cos^{-1}(G_{ij}/(l_i l_j))
```

给出，其中我们取 $\cos^{-1}\rho \in [0,\pi]$。于是有 $G_{ij} = l_i l_j \cos\theta_{ij}$。

长度、距离与角度在正交变换下不变：若 $Q \in \mathbf{R}^{n \times n}$ 是正交矩阵，则向量组 $Qa_i,\ldots,Qa_n$ 有相同的 Gram 矩阵，因此有相同的长度、距离与角度。

#### <span style="color:#2471a3;">Realizability（可实现性）</span>

Gram 矩阵 $G = A^T A$ 当然是**对称且半正定**的。反过来是一个线性代数的基本结论：一个矩阵 $G \in \mathbf{S}^n$ 是某组向量 $a_1,\ldots,a_n$ 的 Gram 矩阵，当且仅当 $G \succeq 0$。当 $G \succeq 0$ 时，我们可以通过找矩阵 $A$ 使 $A^T A = G$ 来构造一个 Gram 矩阵为 $G$ 的构型。这个方程的一个解是对称平方根 $A = G^{1/2}$。当 $G \succ 0$ 时，我们可以通过 $G$ 的 Cholesky 分解找到解：若 $LL^T = G$，则可取 $A = L^T$。此外，给定任何一个解 $A$，我们可以通过正交变换构造出所有具有相同 Gram 矩阵 $G$ 的构型：若 $\tilde{A}^T\tilde{A} = G$ 是任何解，则 $\tilde{A} = QA$ 对某个正交矩阵 $Q$ 成立。

于是，一组长度、距离与角度（即相关系数）是**可实现的**（即它们是某个构型的长度、距离与角度），当且仅当相应的 Gram 矩阵 $G$ 是半正定的，且对角元素为 $l_1^2,\ldots,l_n^2$。

我们可以利用这一事实，把若干几何问题表述为以 $G \in \mathbf{S}^n$ 为优化变量的凸优化问题。可实现性给出约束 $G \succeq 0$ 与 $G_{ii} = l_i^2$（$i = 1,\ldots,n$）；下面我们列出另外一些凸约束与目标。

#### <span style="color:#2471a3;">Angle and distance constraints（角度与距离约束）</span>

我们可以用线性等式约束 $G_{ij} = l_i l_j \cos\alpha$ 把某个角固定为给定值 $\theta_{ij} = \alpha$。更一般地，我们可以用约束

```math
l_i l_j \cos\alpha \ge G_{ij} \ge l_i l_j \cos\beta
```

给一个角加上下界 $\alpha \le \theta_{ij} \le \beta$，这是 $G$ 上的一对线性不等式。（这里我们用到 $\cos^{-1}$ 单调递减。）我们可以通过最小化或最大化 $G_{ij}$ 来最大化或最小化某个特定的角 $\theta_{ij}$（同样利用 $\cos^{-1}$ 的单调性）。

<span style="color:#1e8449;">**[译注]** 这一小段是**整个 distance geometry（距离几何）能被凸优化接管的那一步**，一句话概括就是：**「一堆长度和角度是否真来自某个构型」不是几何问题，而是一个矩阵的 PSD 判定**。$G \succeq 0$ 加 $G_{ii} = l_i^2$ 把「存在 $A$ 使 $A^TA = G$」（一个 $n \times n$ 个变量的非线性方程组问题）变成了一个 LMI，SDP 求解器直接吃。

**消失测试**：没有可实现性判据，你只能对给定的 $d_{ij}$ 去**直接搜索**点集 $a_i \in \mathbf{R}^n$，这是一个 $n^2$ 维非凸问题，$n = 30$ 时搜索空间 $900$ 维，且目标的局部极小与全局极小没有关系；有了 $G$ 变量，同一个问题上界可写成 SDP，$n = 30$ 时变量数 $n(n+1)/2 = 465$，现代 SDP 秒级求到全局最优。**量的方向感**：从「解非线性方程组」变成「判定矩阵半正定」，复杂度从指数/局部搜索降到**多项式时间**（内点法 $O(n^{3.5})$ 量级）。

**一处必须提醒的换算陷阱**：$G_{ij} = (l_i^2 + l_j^2 - d_{ij}^2)/2$ 是 $d_{ij}^2$ 的仿射函数，**不是 $d_{ij}$ 的仿射函数**。所以「距离平方的上下界」是 $G$ 的线性约束，而「距离本身的上下界」要开根号，变成二阶锥约束（SOC）——写成 $G$ 的线性约束会**静默地给错可行域**，而且方向取决于 $d \ge 0$ 所以看不出异常。

**落点**：§8.3.2–§8.3.3（后面继续用 $G$ 表述，含最坏情况与欧氏距离矩阵）；§4.6.1 的 Cholesky 因子所对应的 $G \succ 0$ 情形；Strang 线代中「$A^TA$ 半正定且 $\operatorname{rank}(A^TA) = \operatorname{rank}A$」这一条是本节唯一用到的事实；$\theta_{ij}$ 与 $\rho_{ij}$ 的单调换来换去，全部依赖 $\cos^{-1}$ 在 $[0,\pi]$ 上递减。</span>



（页眉：§8.3 Euclidean distance and angle problems · 原书 p.407）

用类似的方式，我们也可以对距离施加约束。要要求 $d_{ij}$ 落在某个区间内，我们利用

```math
d_{\min} \le d_{ij} \le d_{\max}
\iff d_{\min}^2 \le d_{ij}^2 \le d_{\max}^2
\iff d_{\min}^2 \le l_i^2 + l_j^2 - 2G_{ij} \le d_{\max}^2,
```

而这是 $G$ 上的一对线性不等式。我们可以通过最小化或最大化距离的平方来最小化或最大化距离，而距离的平方是 $G$ 的仿射函数。

举一个简单的例子：假定给定某些角度与某些距离的取值范围（即可能取值构成的区间）。那么，我们可以在所有 configuration 上，求出另一个角度或另一个距离的最小可能值与最大可能值，办法是求解两个 SDP。求出后，把所得的最优 Gram matrix 做分解（factoring），就能重构出这两个极值 configuration。

#### <span style="color:#2471a3;">Singular value and condition number constraints（奇异值与条件数约束）</span>

$A$ 的奇异值 $\sigma_1 \ge \cdots \ge \sigma_n$ 是 $G$ 的特征值 $\lambda_1 \ge \cdots \ge \lambda_n$ 的平方根。因此 $\sigma_1^2$ 是 $G$ 的凸函数，而 $\sigma_n^2$ 是 $G$ 的凹函数。于是，我们可以对 $A$ 的最大奇异值施加一个上界，或者把它最小化；我们也可以对最小奇异值施加一个下界，或者把它最大化。$A$ 的条件数（condition number）$\sigma_1/\sigma_n$ 是 $G$ 的拟凸函数（quasiconvex function），所以我们既可以给它规定一个允许的最大值，也可以在满足其余几何约束的所有 configuration 上把它最小化——用的是 quasiconvex optimization。

粗略地说，凡是能写成 $G$ 上的凸约束的那些约束，都是要求 $a_1,\dots,a_n$ 构成一个 well conditioned basis（良态基）的约束。

#### <span style="color:#2471a3;">Dual basis（对偶基）</span>

当 $G \succ 0$ 时，$a_1,\dots,a_n$ 构成 $\mathbf{R}^n$ 的一组基。与之关联的对偶基（dual basis）是 $b_1,\dots,b_n$，其中

```math
b_i^T a_j =
\begin{cases}
1, & i = j \\
0, & i \ne j.
\end{cases}
```

对偶基向量 $b_1,\dots,b_n$ 恰好就是矩阵 $A^{-1}$ 的各行。于是，与对偶基关联的 Gram matrix 是 $G^{-1}$。

我们可以把对偶基上的若干几何条件，表达成 $G$ 上的凸约束。对偶基向量长度的平方

```math
\|b_i\|_2^2 = e_i^T G^{-1} e_i
```

是 $G$ 的凸函数，因此可以最小化。$\operatorname{tr} G^{-1}$ 也是 $G$ 的凸函数，它给出对偶基向量长度平方之和（这也是衡量基良态程度的另一个指标）。

<span style="color:#1e8449;">**[译注]** 这里藏着本页最容易被抄错、而且**抄错之后 SDP 照跑不误、只是悄悄给出反方向答案**的地方：$\|b_i\|_2^2 = e_i^T G^{-1} e_i$ 是 $G$ 的**凸**函数，而 $\|a_i\|_2^2 = G_{ii}$ 是 $G$ 的**线性**函数——同一个「长度平方」，在 $G$ 与 $G^{-1}$ 两个变量下凸凹性相反。原因是 PsD 序下取逆会**翻转不等式方向**：对 $U, R, L \succ 0$，
```math
U \preceq R \preceq L \ \Longrightarrow\ U^{-1} \succeq R^{-1} \succeq L^{-1},
```
即「夹在两个矩阵之间」在取逆后仍然夹住，但上下换了位。**消失测试**：如果你按直觉把 $\operatorname{tr}G^{-1}$ 当成「$G$ 越大越好」的单调量去写 $\operatorname{tr} G^{-1} \le \gamma$ 这类约束，代码不会报 infeasible——它会解出一个 $G$ 把所有 $a_i$ 压得极短的解（因为 $G \to 0$ 时 $G^{-1} \to \infty$ 被约束压住的方式与你的意图相反），最终 Gram matrix 对应的 configuration 全部退化成原点附近一团。正确做法只有一条：写 $\operatorname{tr}G^{-1} \le \gamma$ 时明确这是**凸**约束（$G^{-1}$ 在 $G\succ0$ 上凸，见 §3.1.7 的 matrix fractional 视角），与 $\operatorname{tr}G \le \gamma$ 是两个不同的可行域。量上的对照能把它钉死：取 $A = \operatorname{diag}(1, 100)$，则 $G = \operatorname{diag}(1, 10^4)$、$G^{-1} = \operatorname{diag}(1, 10^{-4})$，于是 $\operatorname{tr}G = 10001$ 而 $\operatorname{tr}G^{-1} = 1.0001$；若你对 $\operatorname{tr}G^{-1}$ 施加 $\le 2$ 这类上界，展开就是 $1/G_{11} + 1/G_{22} \le 2$，即 $G_{11}$ 与 $G_{22}$ 各自都不能小于 $0.5$ —— 它压住的是「$G$ 不能太小」，与 $\operatorname{tr}G \le 2$ 压住的「$G$ 不能太大」几乎正交。顺带记住它与条件数的联系：$\|b_i\|_2 = \|e_i^T A^{-1}\|_2 \le \sigma_{\min}(A)^{-1}$，所以「对偶基最短」等价于「最小奇异值最大」，正是本节开头把条件数写成 $G$ 的 quasiconvex 函数的那件事。 **落点**：Boyd §8.3.1（本页）、§A.5.5（矩阵凸性）、exercise 8.8；线代侧挂 Strang 的 operator norm 与条件数定义。</span>

#### <span style="color:#2471a3;">Ellipsoid and simplex volume（椭球与单纯形的体积）</span>

椭球 $\{Au \mid \|u\|_2 \le 1\}$ 的体积由下式给出，这是衡量基良态程度的又一个指标：

```math
\gamma\,(\det(A^T A))^{1/2} = \gamma\,(\det G)^{1/2},
```



（页眉：Chapter 8 Geometric problems · 原书 p.408）

其中 $\gamma$ 是 $\mathbf{R}^n$ 中单位球的体积。因此对数体积（log volume）是 $\log\gamma + (1/2)\log\det G$，它是 $G$ 的凹函数。于是，我们可以在一个凸的 configuration 集合上，通过最大化 $\log\det G$ 来最大化像椭球的体积。

对 $\mathbf{R}^n$ 中的任意集合，同样的结论都成立。任意集合在 $A$ 下的像，其体积等于原体积乘以因子 $(\det G)^{1/2}$。例如，考虑单位单纯形 $\operatorname{conv}\{0, e_1, \dots, e_n\}$ 在 $A$ 下的像，也就是单纯形 $\operatorname{conv}\{0, a_1, \dots, a_n\}$。这个单纯形的体积由 $\gamma(\det G)^{1/2}$ 给出，其中 $\gamma$ 是 $\mathbf{R}^n$ 中单位单纯形的体积。于是，我们可以通过最大化 $\log\det G$ 来最大化这个单纯形的体积。

### <span style="color:#c0392b;">8.3.2 Problems involving angles only（只涉及角度的问题）</span>

假定我们只关心向量之间的角度（也就是相关系数），而不指定它们的长度或它们之间的距离。在这种情况下，直觉上很清楚：我们可以干脆假定向量 $a_i$ 的长度都取 $l_i = 1$。这一点很容易验证：Gram matrix 具有形式 $G = \operatorname{diag}(l)\, C \operatorname{diag}(l)$，其中 $l$ 是长度向量，$C$ 是相关矩阵（correlation matrix），即 $C_{ij} = \cos\theta_{ij}$。由此可知：若对某一组正长度有 $G \succeq 0$，则对**所有**正长度组都有 $G \succeq 0$；特别地，这发生当且仅当 $C \succeq 0$（后者等同于假定所有长度都为一）。

因此，一组角度 $\theta_{ij} \in [0, \pi]$，$i,j = 1,\dots,n$ 是可实现的（realizable），当且仅当 $C \succeq 0$，而后者是相关系数上的一个线性矩阵不等式。

举一个例子：假定给定某些角度的下界与上界（这等价于对相关系数施加下界与上界）。那么，我们可以在所有 configuration 上求出另一个角度的最小可能值与最大可能值，办法是求解两个 SDP。

<span style="color:#c0392b;">**Example 8.3 Bounding correlation coefficients（界定相关系数）**</span> 我们考虑 $\mathbf{R}^4$ 中的一个例子，其中给定

```math
0.6 \le \rho_{12} \le 0.9, \qquad 0.8 \le \rho_{13} \le 0.9, \qquad 0.5 \le \rho_{24} \le 0.7, \qquad -0.8 \le \rho_{34} \le -0.4.
\qquad (8.7)
```

为求出 $\rho_{14}$ 的最小可能值与最大可能值，我们求解下面两个 SDP：

```math
\begin{array}{ll}
\text{minimize/maximize} & \rho_{14} \\
\text{subject to} & (8.7), \quad
\begin{bmatrix}
1 & \rho_{12} & \rho_{13} & \rho_{14} \\
\rho_{12} & 1 & \rho_{23} & \rho_{24} \\
\rho_{13} & \rho_{23} & 1 & \rho_{34} \\
\rho_{14} & \rho_{24} & \rho_{34} & 1
\end{bmatrix} \succeq 0,
\end{array}
```

变量是 $\rho_{12}, \rho_{13}, \rho_{14}, \rho_{23}, \rho_{24}, \rho_{34}$。最小值和最大值（保留两位有效数字）分别是 $-0.39$ 与 $0.23$，对应的相关矩阵为

```math
\begin{bmatrix}
1.00 & 0.60 & 0.87 & -0.39 \\
0.60 & 1.00 & 0.33 & 0.50 \\
0.87 & 0.33 & 1.00 & -0.55 \\
-0.39 & 0.50 & -0.55 & 1.00
\end{bmatrix},
\qquad
\begin{bmatrix}
1.00 & 0.71 & 0.80 & 0.23 \\
0.71 & 1.00 & 0.31 & 0.59 \\
0.80 & 0.31 & 1.00 & -0.40 \\
0.23 & 0.59 & -0.40 & 1.00
\end{bmatrix}.
```

<span style="color:#1e8449;">**[译注]** 「只有角度」这一段的核心不是「可以令 $l_i=1$」（那只是便利），而是 $G = \operatorname{diag}(l)\,C\operatorname{diag}(l)$ 这个**合同变换**：右乘左乘一个正对角矩阵不改变半定性，$\det$ 的符号也不变，所以 $G \succeq 0 \iff C \succeq 0$——角度可实现性因此完全脱离长度，退化成一个**与 $l$ 无关**的 LMI。**消失测试**：如果长度不自由（比如题目同时给了 $l_i$ 的区间），这个等价立刻断掉，可行域变成 $\{\rho \mid \exists l \gt 0:\ \operatorname{diag}(l)C\operatorname{diag}(l) \succeq 0\}$ 的投影，而投影一般**不是** LMI 可描述的，你就只能对 $\rho_{14}$ 做网格搜索。**可复算验证**：Example 8.3 给的两个极值可以自己核——取 $\rho_{14}=-0.39$ 那个矩阵，用 Schur 补把 $4\times4$ 化成 $3\times3$，应得 $\operatorname{rank} = 3$（即最小特征值为 $0$）；$0.23$ 那个同理。若你的 SDP 解出的矩阵最小特征值是 $-10^{-3}$ 而不是 $\sim -10^{-9}$，说明约束写成了松弛形式。**注意方向**：这里 min 与 max 只差目标里一个负号，把 $\min$ 写成 $\max$（或反过来）不会报错，只会把 $[-0.39, 0.23]$ 悄悄换成同一个数两次。**落点**：Boyd §8.3.2 与 §4.6（correlation matrix 的 PsD 刻画）；exercise 8.3；EE364a lecture 8。</span>



（页眉：§8.3 Euclidean distance and angle problems · 原书 p.409）

### <span style="color:#c0392b;">8.3.3 Euclidean distance problems（欧氏距离问题）</span>

在欧氏距离问题（Euclidean distance problem）中，我们只关心向量之间的距离 $d_{ij}$，而不关心向量的长度，也不关心向量之间的夹角。当然，这些距离不仅在正交变换下不变，在平移下也不变：对任意 $b \in \mathbf{R}^n$，configuration $\tilde a_1 = a_1 + b, \dots, \tilde a_n = a_n + b$ 与原 configuration 具有相同的距离。特别地，若取

```math
b = -(1/n)\sum_{i=1}^{n} a_i = -(1/n)A\mathbf{1},
```

则 $\tilde a_i$ 与原 configuration 具有相同的距离，并且还满足 $\sum_{i=1}^{n} \tilde a_i = 0$。由此可知，在欧氏距离问题中我们可以不失一般性地假定向量 $a_1,\dots,a_n$ 的平均值为零，即 $A\mathbf{1} = 0$。

我们可以通过把长度当作优化问题中的自由变量，来求解欧氏距离问题（长度不可能出现在欧氏距离问题的目标函数或约束里）。这里依赖的事实是：存在具有距离 $d_{ij} \ge 0$ 的 configuration，当且仅当存在长度 $l_1,\dots,l_n$ 使得 $G \succeq 0$，其中 $G_{ij} = (l_i^2 + l_j^2 - d_{ij}^2)/2$。

定义 $z \in \mathbf{R}^n$ 为 $z_i = l_i^2$，以及 $D \in \mathbf{S}^n$ 为 $D_{ij} = d_{ij}^2$（当然 $D_{ii} = 0$）。「存在某个长度选择使 $G \succeq 0$」这个条件可以写成

```math
G = (z\mathbf{1}^T + \mathbf{1}z^T - D)/2 \succeq 0, \quad \text{for some } z \succeq 0,
\qquad (8.8)
```

这是 $D$ 与 $z$ 上的一个 LMI。

元素非负、对角为零、并且满足 (8.8) 的矩阵 $D \in \mathbf{S}^n$，称为 Euclidean distance matrix（欧氏距离矩阵）。一个矩阵是欧氏距离矩阵，当且仅当其元素是某个 configuration 中各向量之间欧氏距离的平方。（给定一个欧氏距离矩阵 $D$ 与关联的长度平方向量 $z$，我们可以用上面描述的方法，重构出一个、或全部具有这些两两距离的 configuration。）

条件 (8.8) 等价于一个更简单的条件：$D$ 在 $\mathbf{1}^\perp$ 上是负半定的，即

```math
(8.8) \iff u^T D u \le 0 \text{ for all } u \text{ with } \mathbf{1}^T u = 0
\iff (I - (1/n)\mathbf{1}\mathbf{1}^T) D (I - (1/n)\mathbf{1}\mathbf{1}^T) \preceq 0.
```

这个简单的矩阵不等式，连同 $D_{ij} \ge 0$、$D_{ii} = 0$，就是欧氏距离矩阵的经典刻画。为看出这个等价性，回想我们可以假定 $A\mathbf{1} = 0$，这意味着 $\mathbf{1}^T G\mathbf{1} = \mathbf{1}^T A^T A \mathbf{1} = 0$。由此可知 $G \succeq 0$ 当且仅当 $G$ 在 $\mathbf{1}^\perp$ 上是半正定的，即

```math
0 \preceq (I - (1/n)\mathbf{1}\mathbf{1}^T) G (I - (1/n)\mathbf{1}\mathbf{1}^T)
= (1/2)(I - (1/n)\mathbf{1}\mathbf{1}^T)(z\mathbf{1}^T + \mathbf{1}z^T - D)(I - (1/n)\mathbf{1}\mathbf{1}^T)
= -(1/2)(I - (1/n)\mathbf{1}\mathbf{1}^T) D (I - (1/n)\mathbf{1}\mathbf{1}^T),
```

这正是简化后的条件。

<span style="color:#1e8449;">**[译注]** 这一页是全章最容易「写反却不报错」的地方，因为 **$D$ 本身的定号与 $\mathbf{1}^\perp$ 上的定号正相反**。距离矩阵 $D$ 的元素是距离平方，全都 $\ge 0$，它的常规特征值当然有正的；正确的刻画是 $PDP \preceq 0$ 而**绝不是** $D \preceq 0$——写成 $D \preceq 0$ 时，除了退化情形（所有点重合）几乎永远 infeasible，求解器只会吐一句 `infeasible`，你会误以为数据有问题。反过来把 $PDP \preceq 0$ 写成 $PDP \succeq 0$ 更危险：此时 $D_{ij} = d_{ij}^2$ 换成「反距离」空间里的度量，SDP 会**照常给出一个最优解**，只是它对应的 configuration 在 $\mathbf{R}^n$ 里根本嵌不进去。**可复算验证**：取 $n=3$、三点共线且 $d_{12}=1,\ d_{23}=1,\ d_{13}=2$，则
```math
D = \begin{bmatrix} 0 & 1 & 4 \\ 1 & 0 & 1 \\ 4 & 1 & 0 \end{bmatrix},
```
其特征值为 $-4,\,2,\,2$——**有正特征值**，但它确实是合法的 EDM；而 $PDP$（$P = I - \frac13\mathbf{1}\mathbf{1}^T$）的特征值为 $-3,\,0,\,0$，恰好 $\preceq 0$。这一对数字就是判据：若你的代码对 $D$ 检查 $\lambda_{\max} \le 0$，它会把所有非退化例子判死。**落点**：Boyd §8.3.3、§A.5.5；EDM 的原始来源见本份 p420 之后 §8 的 Bibliography（Schoenberg [Sch35]）；练习 exercise 8.9。</span>



（页眉：Chapter 8 Geometric problems · 原书 p.410）

总结起来，矩阵 $D \in \mathbf{S}^n$ 是欧氏距离矩阵，即给出 $\mathbf{R}^n$ 中 $n$ 个向量之间距离的平方，当且仅当

```math
\begin{array}{ll}
D_{ii} = 0, & i = 1,\dots,n, \\
D_{ij} \ge 0, & i,j = 1,\dots,n, \\
(I - (1/n)\mathbf{1}\mathbf{1}^T) D (I - (1/n)\mathbf{1}\mathbf{1}^T) \preceq 0,
\end{array}
```

而这是 $D$ 上的一组线性等式、线性不等式与一个矩阵不等式。因此，凡是关于距离平方为凸的欧氏距离问题，我们都可以把它表达成以 $D \in \mathbf{S}^n$ 为变量的凸问题。

### <span style="color:#c0392b;">8.4 Extremal volume ellipsoids（极值体积椭球）</span>

假定 $\mathcal{C} \subseteq \mathbf{R}^n$ 有界且内部非空。本节考虑两个问题：求位于 $\mathcal{C}$ 内部的体积最大的椭球，以及求覆盖 $\mathcal{C}$ 的体积最小的椭球。这两个问题都能表达成凸规划问题，但只在特殊情形下才是可解的（tractable）。

### <span style="color:#c0392b;">8.4.1 The Löwner-John ellipsoid（Löwner-John 椭球）</span>

包含集合 $\mathcal{C}$ 的体积最小的椭球，称为集合 $\mathcal{C}$ 的 Löwner-John 椭球，记作 $E_{lj}$。为刻画 $E_{lj}$，把一般的椭球参数化成

```math
\mathcal{E} = \{v \mid \|Av + b\|_2 \le 1\},
\qquad (8.9)
```

即欧氏单位球在一个仿射映射下的原像（inverse image），会比较方便。我们可以不失一般性地假定 $A \in \mathbf{S}^n_{++}$，此时 $\mathcal{E}$ 的体积正比于 $\det A^{-1}$。计算包含 $\mathcal{C}$ 的最小体积椭球的问题可以表达成

```math
\begin{array}{ll}
\text{minimize} & \log\det A^{-1} \\
\text{subject to} & \sup_{v \in \mathcal{C}} \|Av + b\|_2 \le 1,
\end{array}
\qquad (8.10)
```

变量是 $A \in \mathbf{S}^n$ 与 $b \in \mathbf{R}^n$，并且有一个隐含约束 $A \succ 0$。目标函数与约束函数都是 $A$ 与 $b$ 的凸函数，所以问题 (8.10) 是凸的。然而，计算 (8.10) 中的约束函数，需要求解一个凸最大化问题，因此只在某些特殊情形下才是可解的。

#### <span style="color:#2471a3;">Minimum volume ellipsoid covering a finite set（覆盖有限集的最小体积椭球）</span>

我们来考虑求包含有限集 $\mathcal{C} = \{x_1,\dots,x_m\} \subseteq \mathbf{R}^n$ 的最小体积椭球这个问题。一个椭球覆盖 $\mathcal{C}$，当且仅当它覆盖 $\mathcal{C}$ 的凸包，所以求覆盖 $\mathcal{C}$ 的最小体积椭球，



（页眉：§8.4 Extremal volume ellipsoids · 原书 p.411）

等同于求包含多面体 $\operatorname{conv}\{x_1,\dots,x_m\}$ 的最小体积椭球。应用 (8.10)，我们可以把这个题写成

```math
\begin{array}{ll}
\text{minimize} & \log\det A^{-1} \\
\text{subject to} & \|Ax_i + b\|_2 \le 1, \quad i = 1,\dots,m,
\end{array}
\qquad (8.11)
```

变量是 $A \in \mathbf{S}^n$ 与 $b \in \mathbf{R}^n$，并且有隐含约束 $A \succ 0$。范数约束 $\|Ax_i + b\|_2 \le 1$，$i = 1,\dots,m$，是变量 $A$ 与 $b$ 的凸不等式。它们可以替换成平方版本 $\|Ax_i + b\|_2^2 \le 1$，而后者是 $A$ 与 $b$ 的凸二次不等式。

#### <span style="color:#2471a3;">Minimum volume ellipsoid covering union of ellipsoids（覆盖椭球之并的最小体积椭球）</span>

对某些由二次不等式定义的集合 $\mathcal{C}$，最小体积覆盖椭球也可以高效地计算出来。特别地，对于椭球的并（union）或和（sum），是可以算出其 Löwner-John 椭球的。

举一个例子：考虑求包含椭球 $\mathcal{E}_1,\dots,\mathcal{E}_m$（因而也包含它们之并的凸包）的最小体积椭球 $E_{lj}$ 这个问题。椭球 $\mathcal{E}_1,\dots,\mathcal{E}_m$ 由（凸）二次不等式描述：

```math
\mathcal{E}_i = \{x \mid x^T A_i x + 2b_i^T x + c_i \le 0\}, \quad i = 1,\dots,m,
```

其中 $A_i \in \mathbf{S}^n_{++}$。我们把椭球 $E_{lj}$ 参数化成

```math
E_{lj} = \{x \mid \|Ax + b\|_2 \le 1\} = \{x \mid x^T A^T A x + 2(A^T b)^T x + b^T b - 1 \le 0\},
```

其中 $A \in \mathbf{S}^n$、$b \in \mathbf{R}^n$。现在使用 §B.2 中的一个结果：$\mathcal{E}_i \subseteq E_{lj}$ 当且仅当存在 $\tau \ge 0$ 使得

```math
\begin{bmatrix}
A^2 - \tau A_i & Ab - \tau b_i \\
(Ab - \tau b_i)^T & b^T b - 1 - \tau c_i
\end{bmatrix} \preceq 0.
```

$E_{lj}$ 的体积正比于 $\det A^{-1}$，所以我们可以通过求解下面这个问题来求出包含 $\mathcal{E}_1,\dots,\mathcal{E}_m$ 的最小体积椭球：

```math
\begin{array}{ll}
\text{minimize} & \log\det A^{-1} \\
\text{subject to} & \tau_1 \ge 0,\ \dots,\ \tau_m \ge 0, \\
& \begin{bmatrix}
A^2 - \tau_i A_i & Ab - \tau_i b_i \\
(Ab - \tau_i b_i)^T & b^T b - 1 - \tau_i c_i
\end{bmatrix} \preceq 0, \quad i = 1,\dots,m,
\end{array}
```

或者，把变量 $b$ 换成 $\tilde b = Ab$：

```math
\begin{array}{ll}
\text{minimize} & \log\det A^{-1} \\
\text{subject to} & \tau_1 \ge 0,\ \dots,\ \tau_m \ge 0, \\
& \begin{bmatrix}
A^2 - \tau_i A_i & \tilde b - \tau_i b_i & 0 \\
(\tilde b - \tau_i b_i)^T & -1 - \tau_i c_i & \tilde b^T \\
0 & \tilde b & -A^2
\end{bmatrix} \preceq 0, \quad i = 1,\dots,m,
\end{array}
```

而这个问题在变量 $A^2 \in \mathbf{S}^n$、$\tilde b$、$\tau_1,\dots,\tau_m$ 上是凸的。

<span style="color:#1e8449;">**[译注]** 这一步的机制值得单独拆开：**把「$b$」换成「$\tilde b = Ab$」，$2\times2$ 分块就变成 $3\times3$ 且对 $A^2$ 线性**。原因是 $(Ab-\tau b_i)$ 与 $b^Tb-1-\tau c_i$ 里都含 $b$，而 $b$ 在 $A$ 未知时不是凸变量；一旦引入 $\tilde b = Ab$，剩下的非线性只有 $b^Tb = \tilde b^T A^{-2}\tilde b$，用 Schur 补把它塞进第三行第三列的 $-A^2$ 块，就得到对 $(A^2, \tilde b, \tau)$ 的 LMI。**消失测试**：不做这个替换，问题在 $A,b$ 上不是凸的（$\log\det A^{-1}$ 对 $A$ 凸，但约束里 $b$ 与 $A$ 乘在一起），你只能用 alternating minimization 或逐次线性化，收敛到局部解；做了替换后是一次 SDP。**代价**：$A^2$ 出现意味着「解出的是 $A^2$ 而不是 $A$」，重构 $A$ 需要一次矩阵平方根，若 $A^2$ 的数值最小特征值掉到 $-10^{-8}$ 量级，`sqrtm` 会给出复数——这是本段在实现侧最常见的崩溃点。**落点**：Boyd §8.4.1、§B.2（S-procedure 的矩阵版本）、§A.5.5；exercise 8.11。同类分块技巧在 §4.2.3（$\mathcal{E}_1 \subseteq \mathcal{E}_2$ 的 LMI）已出现过。</span>



（页眉：Chapter 8 Geometric problems · 原书 p.412）

#### <span style="color:#2471a3;">Efficiency of Löwner-John ellipsoidal approximation（Löwner-John 椭球逼近的效率）</span>

设 $E_{lj}$ 是凸集 $\mathcal{C} \subseteq \mathbf{R}^n$ 的 Löwner-John 椭球（$\mathcal{C}$ 有界且内部非空），$x_0$ 是它的中心。若把 Löwner-John 椭球绕其中心按因子 $n$ 收缩，就得到一个落在集合 $\mathcal{C}$ 内部的椭球：

```math
x_0 + (1/n)(E_{lj} - x_0) \subseteq \mathcal{C} \subseteq E_{lj}.
```

换句话说，Löwner-John 椭球能以只依赖维数 $n$ 的因子，逼近任意凸集。图 8.3 给了一个简单的例子。

如果没有对 $\mathcal{C}$ 的额外假设，因子 $1/n$ 不能再改进。例如 $\mathbf{R}^n$ 中任意单纯形都具有这样的性质：它的 Löwner-John 椭球必须按因子 $n$ 收缩后才能放进去（见 exercise 8.13）。

我们只对特殊情形 $\mathcal{C} = \operatorname{conv}\{x_1,\dots,x_m\}$ 证明这个效率结果。把 (8.11) 中的范数约束平方，并引入变量 $\tilde A = A^2$、$\tilde b = Ab$，得到问题

```math
\begin{array}{ll}
\text{minimize} & \log\det \tilde A^{-1} \\
\text{subject to} & x_i^T \tilde A x_i - 2\tilde b^T x_i + \tilde b^T \tilde A^{-1} \tilde b \le 1, \quad i = 1,\dots,m.
\end{array}
\qquad (8.12)
```

这个问题的 KKT 条件是

```math
\begin{array}{l}
\sum_{i=1}^{m} \lambda_i\left(x_i x_i^T - \tilde A^{-1}\tilde b\tilde b^T \tilde A^{-1}\right) = \tilde A^{-1}, \\
\sum_{i=1}^{m} \lambda_i\left(x_i - \tilde A^{-1}\tilde b\right) = 0, \\
\lambda_i \ge 0, \quad x_i^T \tilde A x_i - 2\tilde b^T x_i + \tilde b^T \tilde A^{-1}\tilde b \le 1, \quad i = 1,\dots,m, \\
\lambda_i\left(1 - x_i^T \tilde A x_i + 2\tilde b^T x_i - \tilde b^T \tilde A^{-1}\tilde b\right) = 0, \quad i = 1,\dots,m.
\end{array}
```

通过一个适当的仿射坐标变换，我们可以假定 $\tilde A = I$、$\tilde b = 0$，即最小体积椭球是以原点为中心的单位球。于是 KKT



（页眉：§8.4 Extremal volume ellipsoids · 原书 p.413）

条件化简为

```math
\sum_{i=1}^{m} \lambda_i x_i x_i^T = I, \qquad \sum_{i=1}^{m} \lambda_i x_i = 0, \qquad \lambda_i(1 - x_i^T x_i) = 0, \quad i = 1,\dots,m,
```

再加上可行性条件 $\|x_i\|_2 \le 1$ 与 $\lambda_i \ge 0$。对第一个等式两边取迹（trace），并利用互补松弛（complementary slackness），我们还得到 $\sum_{i=1}^{m} \lambda_i = n$。

在新坐标下，收缩后的椭球是一个半径为 $1/n$、以原点为中心的球。我们需要证明

```math
\|x\|_2 \le 1/n \ \Longrightarrow\ x \in \mathcal{C} = \operatorname{conv}\{x_1,\dots,x_m\}.
```

假定 $\|x\|_2 \le 1/n$。由 KKT 条件可以看出

```math
x = \sum_{i=1}^{m} \lambda_i (x^T x_i) x_i = \sum_{i=1}^{m} \lambda_i\left(x^T x_i + 1/n\right) x_i = \sum_{i=1}^{m} \mu_i x_i,
\qquad (8.13)
```

其中 $\mu_i = \lambda_i(x^T x_i + 1/n)$。由 Cauchy-Schwartz 不等式，我们注意到

```math
\mu_i = \lambda_i(x^T x_i + 1/n) \ge \lambda_i\left(-\|x\|_2\|x_i\|_2 + 1/n\right) \ge \lambda_i\left(-1/n + 1/n\right) = 0.
```

进一步

```math
\sum_{i=1}^{m} \mu_i = \sum_{i=1}^{m} \lambda_i\left(x^T x_i + 1/n\right) = \sum_{i=1}^{m} \lambda_i/n = 1.
```

这与 (8.13) 一起表明 $x$ 是 $x_1,\dots,x_m$ 的凸组合，因此 $x \in \mathcal{C}$。

<span style="color:#1e8449;">**[译注]** 这段证明的真正机关是 $\sum_i \lambda_i = n$ 这一步：**对 $\sum_i\lambda_i x_ix_i^T = I$ 两边取迹，左边得到 $\sum_i\lambda_i\|x_i\|_2^2$，再用互补松弛把 $\|x_i\|_2^2 = 1$（只有起作用的 $i$ 有 $\lambda_i \gt 0$）代进去**，于是 $\sum\lambda_i = \operatorname{tr}I = n$。这个数 $n$ 后面两处都要用到：一是把 $\mu_i$ 归一化成 $1$（没有它 $x$ 只是凸组合的「缩放版」，证不出 $x\in\mathcal{C}$），二是它决定了收缩因子只能是 $1/n$ 而不是 $1/\sqrt{n}$。**可复算验证**：$n=2$、$\mathcal{C} = [-1,1]^2$ 时 $E_{lj}$ 是半径 $\sqrt2$ 的圆，其中心处 KKT 的 $\lambda_i$ 落在四个顶点上，$\sum\lambda_i = 2 = n$；按 $1/n$ 收缩得半径 $\sqrt2/2 \approx 0.707$ 的圆——它**确实**在正方形内。而单位立方体 $n$ 维时 $E_{lj}$ 半径 $\sqrt n$，按 $1/\sqrt n$ 收缩得半径 $1$ 的球，恰好内切（在 $\pm e_i$ 处相切），所以对称情形的因子 $\sqrt n$ 是紧的——这两个因子差 $\sqrt n$ 倍，$n=100$ 时是 10 倍体积差 $10^{100}$ 量级。**注意方向**：把 $1/n$ 与 $1/\sqrt n$ 记反不会报错，只会让你算出「保证在内部」的椭球其实溢出 $\mathcal{C}$。**落点**：Boyd §8.4.1、exercise 8.13（单纯形紧性）、§4.2.2 的 Löwner-John 提法；John [Joh85] 见本份 p420 之后的 §8 Bibliography。</span>

#### <span style="color:#2471a3;">Efficiency of Löwner-John ellipsoidal approximation for symmetric sets（对称集的 Löwner-John 球逼近效率）</span>

如果集合 $\mathcal{C}$ 关于某点 $x_0$ 对称，那么因子 $1/n$ 可以收紧到 $1/\sqrt{n}$：

```math
x_0 + (1/\sqrt{n})(E_{lj} - x_0) \subseteq \mathcal{C} \subseteq E_{lj}.
```

同样，因子 $1/\sqrt{n}$ 是紧的。立方体

```math
\mathcal{C} = \{x \in \mathbf{R}^n \mid -\mathbf{1} \preceq x \preceq \mathbf{1}\}
```

的 Löwner-John 椭球是半径为 $\sqrt{n}$ 的球。把它按 $1/\sqrt{n}$ 缩小，得到一个包含在 $\mathcal{C}$ 内的球，并在 $x = \pm e_i$ 处触及边界。

#### <span style="color:#2471a3;">Approximating a norm by a quadratic norm（用二次范数逼近范数）</span>

设 $\|\cdot\|$ 是 $\mathbf{R}^n$ 上任一范数，$\mathcal{C} = \{x \mid \|x\| \le 1\}$ 是它的单位球。设 $E_{lj} = \{x \mid x^T A x \le 1\}$（其中 $A \in \mathbf{S}^n_{++}$）是 $\mathcal{C}$ 的 Löwner-John 椭球。由于 $\mathcal{C}$ 关于原点对称，上面的结果告诉我们 $(1/\sqrt{n})E_{lj} \subseteq \mathcal{C} \subseteq E_{lj}$。记 $\|\cdot\|_{lj}$ 为二次范数

```math
\|z\|_{lj} = (z^T A z)^{1/2},
```



（页眉：Chapter 8 Geometric problems · 原书 p.414）

它的单位球是 $E_{lj}$。包含关系 $(1/\sqrt{n})E_{lj} \subseteq \mathcal{C} \subseteq E_{lj}$ 等价于不等式

```math
\|z\|_{lj} \le \|z\| \le \sqrt{n}\,\|z\|_{lj}
```

对一切 $z \in \mathbf{R}^n$ 成立。换句话说，二次范数 $\|\cdot\|_{lj}$ 在因子 $\sqrt{n}$ 以内逼近范数 $\|\cdot\|$。特别地我们看到，$\mathbf{R}^n$ 上任一范数都能被某个二次范数在因子 $\sqrt{n}$ 以内逼近。

### <span style="color:#c0392b;">8.4.2 Maximum volume inscribed ellipsoid（最大体积内接椭球）</span>

现在我们考虑求位于凸集 $\mathcal{C}$ 内部的体积最大的椭球这个问题（假定 $\mathcal{C}$ 有界且内部非空）。为把这个问题形式化，我们把椭球参数化成单位球在一个仿射变换下的像，即

```math
\mathcal{E} = \{Bu + d \mid \|u\|_2 \le 1\}.
```

同样可以假定 $B \in \mathbf{S}^n_{++}$，于是体积正比于 $\det B$。我们可以通过求解凸优化问题

```math
\begin{array}{ll}
\text{maximize} & \log\det B \\
\text{subject to} & \sup_{\|u\|_2 \le 1} I_{\mathcal{C}}(Bu + d) \le 0
\end{array}
\qquad (8.14)
```

来求 $\mathcal{C}$ 内部的最大体积椭球，变量是 $B \in \mathbf{S}^n$ 与 $d \in \mathbf{R}^n$，隐含约束 $B \succ 0$。

#### <span style="color:#2471a3;">Maximum volume ellipsoid in a polyhedron（多面体中的最大体积椭球）</span>

我们考虑 $\mathcal{C}$ 是由一组线性不等式描述的多面体这一情形：

```math
\mathcal{C} = \{x \mid a_i^T x \le b_i, \ i = 1,\dots,m\}.
```

为应用 (8.14)，先把约束写成更方便的形式：

```math
\begin{array}{rcl}
\sup_{\|u\|_2 \le 1} I_{\mathcal{C}}(Bu + d) \le 0
&\iff& \sup_{\|u\|_2 \le 1} a_i^T (Bu + d) \le b_i, \quad i = 1,\dots,m \\
&\iff& \|B a_i\|_2 + a_i^T d \le b_i, \quad i = 1,\dots,m.
\end{array}
```

因此我们可以把 (8.14) 写成变量 $B$ 与 $d$ 上的凸优化问题：

```math
\begin{array}{ll}
\text{minimize} & \log\det B^{-1} \\
\text{subject to} & \|B a_i\|_2 + a_i^T d \le b_i, \quad i = 1,\dots,m.
\end{array}
\qquad (8.15)
```

<span style="color:#1e8449;">**[译注]** 「$\sup_{\|u\|_2\le1} a_i^T(Bu+d) \le b_i \iff \|Ba_i\|_2 + a_i^Td \le b_i$」这一行的全部内容是 **support function（支撑函数）恒等式**：$\sup_{\|u\|_2\le1} g^T u = \|g\|_2$，取 $g = B^T a_i$ 即得。它是整节从「对内层 $u$ 求 sup」变成「一条 SOC 约束」的唯一桥梁。**消失测试**：没有这个恒等式，(8.14) 里的 $\sup$ 是一个**无穷多条约束**的东西（$u$ 遍历单位球整个连续统），任何求解器都吃不下；只能退化成对 $u$ 做网格离散，$n=10$ 时 $10^{10}$ 个方向，且离散化后的最优 $B$ 会贴着离散误差漂移。**方向提醒**：$\|\cdot\|_2$ 与 $\|\cdot\|_*$ 别混——p431 的 Chebyshev 中心用的是**对偶范数** $\|a_i\|_*$（因为那里的 $u$ 在 $\|\cdot\|$ 球里、$a_i$ 不在 $\ell_2$ 下），而这里 $\|Ba_i\|_2$ 是 $\ell_2$。两种写法长得像，混用后代码照跑、可行域却错，表现为「椭球大了 $10\%$ 却越过某个面」。**落点**：Boyd §8.4.2、§A.1.6（support function 与对偶范数）、§4.2.2；p421 那段 dual basis 的 $\|b_i\|_2^2$ 与本页的 $\|Ba_i\|_2$ 是同一个恒等式的两次使用。</span>

#### <span style="color:#2471a3;">Maximum volume ellipsoid in an intersection of ellipsoids（椭球交集中的最大体积椭球）</span>

我们也可以求位于 $m$ 个椭球 $\mathcal{E}_1,\dots,\mathcal{E}_m$ 的交集中的最大体积椭球 $\mathcal{E}$。我们把 $\mathcal{E}$ 写成 $\mathcal{E} = \{Bu + d \mid \|u\|_2 \le 1\}$，$B \in \mathbf{S}^n_{++}$，其余椭球用凸二次不等式描述，

```math
\mathcal{E}_i = \{x \mid x^T A_i x + 2b_i^T x + c_i \le 0\}, \quad i = 1,\dots,m,
```
