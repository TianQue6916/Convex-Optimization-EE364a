```math
\end{array}
```

```math
0 & \lambda_i I & B \\
d + A_i^{-1} b_i & B & A_i^{-1}
\end{bmatrix} \succeq 0, \quad i = 1,\dots,m.
\end{array}
```

### <span style="color:#c0392b;">8.5 Centering（定心）</span>

### <span style="color:#c0392b;">8.5.1 Chebyshev center（Chebyshev 中心）</span>

设 $\mathcal{C} \subseteq \mathbf{R}^n$ 有界且内部非空，$x \in \mathcal{C}$。点 $x \in \mathcal{C}$ 的深度（depth）定义为

```math
\operatorname{depth}(x, \mathcal{C}) = \operatorname{dist}(x, \mathbf{R}^n \setminus \mathcal{C}),
```

即到 $\mathcal{C}$ 外部最近点的距离。深度给出以 $x$ 为中心、落在 $\mathcal{C}$ 内部的最大球的半径。集合 $\mathcal{C}$ 的 Chebyshev 中心定义为 $\mathcal{C}$ 中深度最大的任意一点：

```math
x_{\text{cheb}}(\mathcal{C}) = \arg\max \operatorname{depth}(x, \mathcal{C}) = \arg\max \operatorname{dist}(x, \mathbf{R}^n \setminus \mathcal{C}).
```

Chebyshev 中心是 $\mathcal{C}$ 内部离 $\mathcal{C}$ 的外部最远的点；它也是落在 $\mathcal{C}$ 内部的最大球的中心。图 8.5 给了一个例子，其中 $\mathcal{C}$ 是多面体，范数是欧氏范数。



（页眉：§8.5 Centering · 原书 p.417）

#### <span style="color:#2471a3;">Chebyshev center of a convex set（凸集的 Chebyshev 中心）</span>

当集合 $\mathcal{C}$ 是凸集时，深度在 $x \in \mathcal{C}$ 上是凹函数，所以计算 Chebyshev 中心是一个凸优化问题（见 exercise 8.5）。更具体地，假定 $\mathcal{C} \subseteq \mathbf{R}^n$ 由一组凸不等式定义：

```math
\mathcal{C} = \{x \mid f_1(x) \le 0, \dots, f_m(x) \le 0\}.
```

我们可以通过求解

```math
\begin{array}{ll}
\text{maximize} & R \\
\text{subject to} & g_i(x, R) \le 0, \quad i = 1,\dots,m,
\end{array}
\qquad (8.16)
```

来求一个 Chebyshev 中心，其中 $g_i$ 定义为

```math
g_i(x, R) = \sup_{\|u\| \le 1} f_i(x + Ru).
```

问题 (8.16) 是一个凸优化问题，因为每个函数 $g_i$ 都是「$x$ 与 $R$ 的一族凸函数」的逐点最大（pointwise maximum），因而凸。然而，计算 $g_i$ 需要求解一个凸最大化问题（数值上或解析上），这可能非常困难。在实践中，只有在 $g_i$ 容易计算的情形下，我们才能求出 Chebyshev 中心。

#### <span style="color:#2471a3;">Chebyshev center of a polyhedron（多面体的 Chebyshev 中心）</span>

假定 $\mathcal{C}$ 由一组线性不等式 $a_i^T x \le b_i$，$i = 1,\dots,m$ 定义。此时

```math
g_i(x, R) = \sup_{\|u\| \le 1} a_i^T (x + Ru) - b_i = a_i^T x + R\|a_i\|_* - b_i
```

<span style="color:#1e8449;">**[译注]** Chebyshev center 这一段的教益全在 **(8.16) 里那个 $\sup$ 的内外换位**：外问题是 maximize $R$（凸，因为 $R$ 在约束右侧），内问题是 $\sup_{\|u\|\le1} f_i(x+Ru)$ —— 对 $x,R$ 而言这是**凸最大化**，不是最小化，所以内层一般**没有高效算法**。判据很清楚：只有当内层 $\sup$ 有闭式解，(8.16) 才落地。多面体给闭式（支撑函数 $\|a_i\|_*$，一条线性约束）；椭球交（p432）给闭式（一条 LMI + 一个 $\lambda$）；一般的 $f_i$（比如 $f_i$ 是 $\max$ 的复合，或 $f_i$ 由黑箱给出）**没有闭式**，此时你只能在外层做切平面、内层做半无限规划，收敛率无保证。**可复算验证**：$\mathcal{C} = \{x \in \mathbf{R}^2 \mid \pm x_1 \le 1, \pm x_2 \le 1\}$（单位正方形）在欧氏范数下，四条边对应 $\|a_i\|_* = 1$，LP 给出 $R^\star = 1$、$x^\star = (0,0)$；把范数换成 $\ell_\infty$ 后 $\|a_i\|_* = \|a_i\|_1 = 1$，解不变——**但在 $\ell_\infty$ 范数下「最大 $\ell_\infty$ 球」是边长 $2R$ 的正方形，它与 $\mathcal{C}$ 完全重合**，$R^\star$ 仍为 $1$。若你把 $\|\cdot\|_*$ 误写成 $\|\cdot\|_2$，正方形例子恰好不变（都是 1），换成倾斜的多面体（如 $a_1 = (3,4)/5$）才会露馅：$\ell_2$ 给 $1$，$\ell_* = \ell_2$ 给 $1$，而 $\ell_1$ 范数下应给 $\|a_1\|_\infty = 0.8 \ne 1$。**落点**：Boyd §8.5.1、§A.1.6（对偶范数）、exercise 8.5；EE364a lecture 8 的 Chebyshev center 页。</span>



（页眉：Chapter 8 Geometric problems · 原书 p.418）

（当 $R \ge 0$ 时），于是 Chebyshev 中心可以通过求解下面的 LP 得到：

```math
\begin{array}{ll}
\text{maximize} & R \\
\text{subject to} & a_i^T x + R\|a_i\|_* \le b_i, \quad i = 1,\dots,m \\
& R \ge 0,
\end{array}
```

变量是 $x$ 与 $R$。

#### <span style="color:#2471a3;">Euclidean Chebyshev center of intersection of ellipsoids（椭球交集的欧氏 Chebyshev 中心）</span>

设 $\mathcal{C}$ 是 $m$ 个椭球的交集，由二次不等式定义，

```math
\mathcal{C} = \{x \mid x^T A_i x + 2b_i^T x + c_i \le 0, \ i = 1,\dots,m\},
```

其中 $A_i \in \mathbf{S}^n_{++}$。我们有

```math
\begin{array}{rcl}
g_i(x, R) &=& \sup_{\|u\|_2 \le 1}\left((x + Ru)^T A_i (x + Ru) + 2b_i^T (x + Ru) + c_i\right) \\
&=& x^T A_i x + 2b_i^T x + c_i + \sup_{\|u\|_2 \le 1}\left(R^2 u^T A_i u + 2R(A_i x + b_i)^T u\right).
\end{array}
```

由 §B.1，$g_i(x, R) \le 0$ 当且仅当存在 $\lambda_i$ 使得矩阵不等式

```math
\begin{bmatrix}
-x^T A_i x - 2b_i^T x - c_i - \lambda_i & R(A_i x + b_i)^T \\
R(A_i x + b_i) & \lambda_i I - R^2 A_i
\end{bmatrix} \succeq 0
\qquad (8.17)
```

成立。利用这个结果，我们可以把 Chebyshev 定心问题表达成

```math
\begin{array}{ll}
\text{maximize} & R \\
\text{subject to} & \begin{bmatrix}
-\lambda_i - c_i + b_i^T A_i^{-1} b_i & 0 & (x + A_i^{-1} b_i)^T \\
0 & \lambda_i I & R I \\
x + A_i^{-1} b_i & R I & A_i^{-1}
\end{bmatrix} \succeq 0, \quad i = 1,\dots,m,
\end{array}
```

这是一个以 $R$、$\lambda$ 与 $x$ 为变量的 SDP。注意：LMI 约束中 $A_i^{-1}$ 的 Schur 补（Schur complement）恰好等于 (8.17) 的左边。

### <span style="color:#c0392b;">8.5.3 Analytic center of a set of inequalities（一组不等式的解析中心）</span>

给定一组凸不等式与线性等式

```math
f_i(x) \le 0, \quad i = 1,\dots,m, \qquad Fx = g,
```

它们的解析中心（analytic center）$x_{\text{ac}}$ 定义为（凸）问题

```math
\begin{array}{ll}
\text{minimize} & -\sum_{i=1}^{m} \log(-f_i(x)) \\
\text{subject to} & Fx = g,
\end{array}
\qquad (8.18)
```

的一个最优点，变量是 $x \in \mathbf{R}^n$，隐含约束是 $f_i(x) \lt 0$，$i = 1,\dots,m$。(8.18) 中的目标函数称为与这组不等式关联的对数障碍（logarithmic barrier）。这里我们假定对数障碍的定义域与等式定义的仿射集相交，即严格不等式系统

```math
f_i(x) \lt 0, \quad i = 1,\dots,m, \qquad Fx = g
```

是可行的。若 $\mathcal{C}$ 有界，则对数障碍在可行集

```math
\mathcal{C} = \{x \mid f_i(x) \lt 0, \ i = 1,\dots,m, \ Fx = g\}
```

上有下界。

当 $x$ 严格可行（即 $Fx = g$ 且 $f_i(x) \lt 0$，$i = 1,\dots,m$）时，我们可以把 $-f_i(x)$ 解释为第 $i$ 个不等式的余量（margin）或松弛（slack）。解析中心 $x_{\text{ac}}$ 就是在等式约束 $Fx = g$ 与隐含约束 $f_i(x) \lt 0$ 下，使这些松弛或余量的乘积（或几何平均）最大的点。

解析中心不是「由不等式与等式所描述的集合 $\mathcal{C}$」的函数；两组不等式与等式可以定义同一个集合，却有不同的解析中心。不过，人们常常不怎么严谨地用「集合 $\mathcal{C}$ 的解析中心」这种说法，来指



（页眉：Chapter 8 Geometric problems · 原书 p.420）

某个特定定义 $\mathcal{C}$ 的等式与不等式组的解析中心。

然而，解析中心与仿射坐标变换无关。它在不等式函数乘以（正）缩放因子下、以及对等式约束的任意重新参数化下也保持不变。换句话说，若 $\tilde F$、$\tilde g$ 满足「$\tilde Fx = \tilde g$ 当且仅当 $Fx = g$」，且 $\alpha_1,\dots,\alpha_m \gt 0$，则

```math
\alpha_i f_i(x) \le 0, \quad i = 1,\dots,m, \qquad \tilde F x = \tilde g
```

的解析中心与

```math
f_i(x) \le 0, \quad i = 1,\dots,m, \qquad Fx = g
```

的解析中心相同（见 exercise 8.17）。

#### <span style="color:#2471a3;">Analytic center of a set of linear inequalities（一组线性不等式的解析中心）</span>

一组线性不等式

```math
a_i^T x \le b_i, \quad i = 1,\dots,m
```

的解析中心，是无约束最小化问题

```math
\text{minimize} \quad -\sum_{i=1}^{m} \log\left(b_i - a_i^T x\right)
\qquad (8.19)
```

的解，隐含约束为 $b_i - a_i^T x \gt 0$，$i = 1,\dots,m$。若线性不等式定义的多面体有界，则对数障碍有下界且严格凸，因此解析中心唯一。（见 exercise 4.2。）

我们可以给一组线性不等式的解析中心一个几何解释。由于解析中心与约束函数的正缩放无关，我们可以不失一般性地假定 $\|a_i\|_2 = 1$。此时松弛 $b_i - a_i^T x$ 就是到超平面 $H_i = \{x \mid a_i^T x = b_i\}$ 的距离。因此解析中心 $x_{\text{ac}}$ 是使到各定义超平面的距离之乘积最大的点。

#### <span style="color:#2471a3;">Inner and outer ellipsoids from analytic center of linear inequalities（由线性不等式的解析中心得到的内外椭球）</span>

一组线性不等式的解析中心隐含地定义了一个内接椭球与一个覆盖椭球，它们由对数障碍函数

```math
-\sum_{i=1}^{m} \log\left(b_i - a_i^T x\right)
```

在解析中心处求值的 Hessian 给出，即

```math
H = \sum_{i=1}^{m} d_i^2\, a_i a_i^T, \qquad d_i = \frac{1}{b_i - a_i^T x_{\text{ac}}}, \quad i = 1,\dots,m.
```

我们有 $E_{\text{inner}} \subseteq P \subseteq E_{\text{outer}}$，其中

```math
\begin{array}{rcl}
P &=& \{x \mid a_i^T x \le b_i, \ i = 1,\dots,m\}, \\
E_{\text{inner}} &=& \{x \mid (x - x_{\text{ac}})^T H (x - x_{\text{ac}}) \le 1\}, \\
E_{\text{outer}} &=& \{x \mid (x - x_{\text{ac}})^T H (x - x_{\text{ac}}) \le m(m-1)\}. \qquad \dagger
\end{array}
```

（† 原文 p.420 的 $E_{\text{outer}}$ 一行漏了左括号，写作 $x - x_{\text{ac}})^T H(x - x_{\text{ac}})$；此处按上下文补全。）



（页眉：§8.5 Centering · 原书 p.421）

<span style="color:#2471a3;">**[Figure 8.7]**</span> Figure 8.7：虚线显示定义图 8.5 中多面体 $\mathcal{C}$ 的那些不等式的对数障碍函数的五条等值线（level curve）。对数障碍函数的最小点标记为 $x_{\text{ac}}$，它就是这些不等式的解析中心。内椭球 $E_{\text{inner}} = \{x \mid (x - x_{\text{ac}})^T H (x - x_{\text{ac}}) \le 1\}$ 画成阴影，其中 $H$ 是对数障碍函数在 $x_{\text{ac}}$ 处的 Hessian。

（文字层只剩「five level curves」的描述与标注 $x_{\text{ac}}$；五条等值线的具体位置不可复原。）

这个结果比最大体积内接椭球那个结果更弱：后者放大因子 $n$ 后就覆盖多面体，而由对数障碍的 Hessian 定义的内椭球与外椭球，其比例因子是 $(m(m-1))^{1/2}$，它总是不小于 $n$ 的。

为证明 $E_{\text{inner}} \subseteq P$，假定 $x \in E_{\text{inner}}$，即

```math
(x - x_{\text{ac}})^T H (x - x_{\text{ac}}) = \sum_{i=1}^{m}\left(d_i a_i^T (x - x_{\text{ac}})\right)^2 \le 1.
```

这意味着

```math
a_i^T (x - x_{\text{ac}}) \le 1/d_i = b_i - a_i^T x_{\text{ac}}, \quad i = 1,\dots,m,
```

因此 $a_i^T x \le b_i$，$i = 1,\dots,m$。（我们没有用到「$x_{\text{ac}}$ 是解析中心」这一事实，所以把 $x_{\text{ac}}$ 换成任何严格可行点，这个结果仍然成立。）

为证明 $P \subseteq E_{\text{outer}}$，我们需要用到「$x_{\text{ac}}$ 是解析中心」这一事实，即对数障碍的梯度为零：

```math
\sum_{i=1}^{m} d_i a_i = 0.
```

现在假定 $x \in P$。那么

```math
(x - x_{\text{ac}})^T H (x - x_{\text{ac}}) = \sum_{i=1}^{m}\left(d_i a_i^T (x - x_{\text{ac}})\right)^2
```



（页眉：Chapter 8 Geometric problems · 原书 p.422）

```math
\begin{array}{rcl}
&=& \displaystyle\sum_{i=1}^{m} d_i^2\left(1/d_i - a_i^T (x - x_{\text{ac}})\right)^2 - m \\
&=& \displaystyle\sum_{i=1}^{m} d_i^2\left(b_i - a_i^T x\right)^2 - m \\
&\le& \left(\displaystyle\sum_{i=1}^{m} d_i\left(b_i - a_i^T x\right)\right)^2 - m \\
&=& \left(\displaystyle\sum_{i=1}^{m} d_i\left(b_i - a_i^T x_{\text{ac}}\right) + \sum_{i=1}^{m} d_i a_i^T (x_{\text{ac}} - x)\right)^2 - m \\
&=& m^2 - m,
\end{array}
```

这就证明了 $x \in E_{\text{outer}}$。（第二个等式来自 $\sum_{i=1}^{m} d_i a_i = 0$。不等式来自 $\sum_{i=1}^{m} y_i^2 \le \left(\sum_{i=1}^{m} y_i\right)^2$ 对 $y \succeq 0$ 成立。最后一个等式来自 $\sum_{i=1}^{m} d_i a_i = 0$ 与 $d_i$ 的定义。）

#### <span style="color:#2471a3;">Analytic center of a linear matrix inequality（线性矩阵不等式的解析中心）</span>

如果把「对数」定义在锥 $K$ 上，解析中心的定义可以推广到由相对于锥 $K$ 的广义不等式所描述的集合。例如，线性矩阵不等式

```math
x_1 A_1 + x_2 A_2 + \cdots + x_n A_n \preceq B
```

的解析中心定义为

```math
\text{minimize} \quad -\log\det\left(B - x_1 A_1 - \cdots - x_n A_n\right)
```

的解。

<span style="color:#1e8449;">**[译注]** 这里有个在文献里被反复引用的对照：由**对数障碍 Hessian 定义的内外椭球** 与 **mve（最大体积内接椭球）** 不是同一个东西，二者只差一个常数，但那个常数是 $m$ 与 $n$ 的混合量。具体地，$E_{\text{inner}}$ 放大 $n$ 倍覆盖 $P$（§8.4.2），而 $H$ 定义的内外椭球之比是 $\sqrt{m(m-1)}$；因为 $m \ge n$（多面体至少 $n+1$ 个面才能有界），所以
```math
\sqrt{m(m-1)} \;\ge\; \sqrt{n(n+1)} \;\gt\; n \quad (n \ge 1),
```
即 Hessian 椭球对永远「更松」。**消失测试**：这个差别不是审美——Dikin 椭球（= $E_{\text{inner}}$）每一步只需一次 Newton 求解 $H$，代价 $O(mn^2)$；而重新解一次 (8.15) 求 mve 需要 SDP，代价高一个量级，所以内点法里用 Dikin 步而不用 mve 步。但如果你的算法把 $E_{\text{outer}}$ 的因子写成 $m$ 而不是 $m(m-1)$，自乘 $m^2$ 会**低估**多面体直径，导致信任域过小、收敛变慢（不报错，只是慢）。顺带把 $E_{\text{inner}}$ 的几何写死：它也能看成「沿每个方向把最紧的那个超平面顶到」的椭球，半轴长 $1/\sqrt{\lambda_i(H)}$，而 $\lambda_i(H)$ 正好是该方向上「到各超平面距离的加权平方和」的曲率。数上再看两档：$m = 100$、$n = 10$ 时 $\sqrt{9900} \approx 99.5$，是 $n$ 的近 $10$ 倍；而 $m = n+1$（单纯形，最省面的情形）时 $\sqrt{n(n+1)} \approx n + 0.5$，只比 $n$ 大半个单位。也就是说，Hessian 椭球对在**面数接近维数**时几乎和 mve 一样紧，在**面数远大于维数**（$m \gg n$）时才明显变松——这解释了为什么 Dikin 步在高维多面体上需要额外的信任域限制。

### <span style="color:#c0392b;">8.6 Classification（分类）</span>

在模式识别与分类问题中，给定 $\mathbf{R}^n$ 中的两组点 $\{x_1,\dots,x_N\}$ 与 $\{y_1,\dots,y_M\}$，我们希望（在某个给定的函数族中）找到一个函数 $f : \mathbf{R}^n \to \mathbf{R}$，它在第一组点上为正、在第二组点上为负，即

```math
f(x_i) \gt 0, \quad i = 1,\dots,N, \qquad f(y_i) \lt 0, \quad i = 1,\dots,M.
```

若这些不等式成立，我们说 $f$、或它的零水平集 $\{x \mid f(x) = 0\}$，把这两组点分离（separates）、分类（classifies）或判别（discriminates）开来。有时我们也考虑弱分离（weak separation），此时成立的是这些不等式的弱版本。



（页眉：§8.6 Classification · 原书 p.423）

### <span style="color:#c0392b;">8.6.1 Linear discrimination（线性判别）</span>

在线性判别中，我们寻找一个仿射函数 $f(x) = a^T x - b$ 来分类这些点，即

```math
a^T x_i - b \gt 0, \quad i = 1,\dots,N, \qquad a^T y_i - b \lt 0, \quad i = 1,\dots,M.
\qquad (8.20)
```

从几何上看，我们是在找一个超平面来分离这两组点。由于严格不等式 (8.20) 关于 $a$ 与 $b$ 是齐次的（homogeneous），它们可行当且仅当（变量为 $a,b$ 的）非严格线性不等式组

```math
a^T x_i - b \ge 1, \quad i = 1,\dots,N, \qquad a^T y_i - b \le -1, \quad i = 1,\dots,M
\qquad (8.21)
```

可行。图 8.8 给出两组点与一个线性判别函数的简单例子。

#### <span style="color:#2471a3;">Linear discrimination alternative（线性判别的择一定理）</span>

严格不等式组 (8.20) 的强择一（strong alternative）是存在 $\lambda$、$\tilde\lambda$ 使得

```math
\lambda \succeq 0, \quad \tilde\lambda \succeq 0, \quad (\lambda,\tilde\lambda) \ne \mathbf{0}, \quad \sum_{i=1}^{N} \lambda_i x_i = \sum_{i=1}^{M} \tilde\lambda_i y_i, \quad \mathbf{1}^T\lambda = \mathbf{1}^T\tilde\lambda
\qquad (8.22)
```

（见 §5.8.3）。利用第三个与最后一个条件，我们可以把这些择一条件写成

```math
\lambda \succeq 0, \quad \mathbf{1}^T\lambda = 1, \quad \tilde\lambda \succeq 0, \quad \mathbf{1}^T\tilde\lambda = 1, \quad \sum_{i=1}^{N} \lambda_i x_i = \sum_{i=1}^{M} \tilde\lambda_i y_i
```



（页眉：Chapter 8 Geometric problems · 原书 p.424）

（做法是除以 $\mathbf{1}^T\lambda$，它为正，并对归一化后的 $\lambda$ 与 $\tilde\lambda$ 沿用同样的符号）。这些条件有一个简单的几何解释：它们说明存在一个点，同时属于 $\{x_1,\dots,x_N\}$ 与 $\{y_1,\dots,y_M\}$ 的凸包。换句话说：两组点可以被线性判别（即被一个仿射函数判别）当且仅当它们的凸包不相交。这个结果我们此前已经见过好几次了。

#### <span style="color:#2471a3;">Robust linear discrimination（鲁棒线性判别）</span>

存在仿射分类函数 $f(x) = a^T x - b$ 这件事，等价于定义 $f$ 的变量 $a$ 与 $b$ 上的一组线性不等式。若两组点可以被线性判别，则存在一个仿射函数的多面体，其中每个函数都能判别它们；于是我们可以挑一个使某种鲁棒性度量最优的函数。例如，我们可以找那个使 $x_i$ 处的（正）值与 $y_i$ 处的（负）值之间的「间隙」（gap）尽可能大的函数。为此我们必须对 $a$ 与 $b$ 做归一化，否则可以把 $a$、$b$ 同时乘以一个正常数，使取值间隙任意大。这导致问题

```math
\begin{array}{ll}
\text{maximize} & t \\
\text{subject to} & a^T x_i - b \ge t, \quad i = 1,\dots,N \\
& a^T y_i - b \le -t, \quad i = 1,\dots,M \\
& \|a\|_2 \le 1,
\end{array}
\qquad (8.23)
```

变量是 $a$、$b$ 与 $t$。这个凸问题（线性目标、线性不等式、一个二次不等式）的最优值 $t^\star$ 为正，当且仅当两组点可以被线性判别。在此情形下，不等式 $\|a\|_2 \le 1$ 在最优处总是紧的，即 $\|a^\star\|_2 = 1$。（见 exercise 8.23。）

我们可以给鲁棒线性判别问题 (8.23) 一个简单的几何解释。若 $\|a\|_2 = 1$（在任一最优点处都是这样），则 $a^T x_i - b$ 是点 $x_i$ 到分离超平面 $H = \{z \mid a^T z = b\}$ 的欧氏距离。类似地，$b - a^T y_i$ 是点 $y_i$ 到该超平面的距离。因此问题 (8.23) 找出的是分离这两组点、并且到两组点距离最大的那个超平面。换句话说，它找出分离两组点的最厚 slab（thickest slab）。

正如 figure 8.9 所示例子提示的那样，最优值 $t^\star$（它是 slab 厚度的一半）恰好等于两组点凸包之间距离的一半。这从鲁棒线性判别问题 (8.23) 的对偶可以看得很清楚。Lagrangian（对最小化 $-t$ 这个问题而言）是

```math
-t + \sum_{i=1}^{N} u_i\left(t + b - a^T x_i\right) + \sum_{i=1}^{M} v_i\left(t - b + a^T y_i\right) + \lambda\left(\|a\|_2 - 1\right).
```

关于 $b$ 与 $t$ 最小化，得到条件 $\mathbf{1}^T u = 1/2$、$\mathbf{1}^T v = 1/2$。当这些条件成立时，我们有

```math
g(u, v, \lambda) = \inf_{a}\left(a^T\left(\sum_{i=1}^{M} v_i y_i - \sum_{i=1}^{N} u_i x_i\right) + \lambda\|a\|_2 - \lambda\right)
```



（页眉：§8.6 Classification · 原书 p.425）

<span style="color:#2471a3;">**[Figure 8.9]**</span> Figure 8.9：通过求解鲁棒线性判别问题 (8.23)，我们得到一个仿射函数，它使两组点之间的取值间隙最大（对函数的线性部分加了归一化界）。从几何上看，我们是在找分离这两组点的最厚 slab。

（文字层只剩图注与标注；两组点的坐标与两条边界直线的位置不可复原。）

```math
= \begin{cases}
-\lambda, & \left\|\sum_{i=1}^{M} v_i y_i - \sum_{i=1}^{N} u_i x_i\right\|_2 \le \lambda, \\
-\infty, & \text{otherwise}.
\end{cases}
```

于是对偶问题可以写成

```math
\begin{array}{ll}
\text{maximize} & -\left\|\sum_{i=1}^{M} v_i y_i - \sum_{i=1}^{N} u_i x_i\right\|_2 \\
\text{subject to} & u \succeq 0, \quad \mathbf{1}^T u = 1/2 \\
& v \succeq 0, \quad \mathbf{1}^T v = 1/2.
\end{array}
```

我们可以把 $2\sum_{i=1}^{N} u_i x_i$ 解释为 $\{x_1,\dots,x_N\}$ 凸包中的一点，把 $2\sum_{i=1}^{M} v_i y_i$ 解释为 $\{y_1,\dots,y_M\}$ 凸包中的一点。对偶目标是把这两点之间的距离（的一半）最小化，即求出两组点凸包之间的距离（的一半）。

<span style="color:#1e8449;">**[译注]** 这一步的价值在于它把 **一个 SDP/SOCP 的 primal 解** 与 **§8.2 的距离几何** 缝在一起：primal 的 $t^\star$ 是 slab 半厚度，对偶的 $-\|\cdot\|_2$ 是两点距离，而 $\mathbf{1}^Tu = 1/2$ 恰好让 $2\sum u_ix_i$ 成为**凸组合**（权重和 $1$），于是对偶就是对「两凸包间最近点对」求最小距离——即 $\operatorname{dist}(\operatorname{conv}X, \operatorname{conv}Y)$。**消失测试**：如果没有这个归一化，$\sum u_i x_i$ 只是凸包里的一个**凸组合的 $1/2$ 缩放**，对偶目标退化成「$2$ 倍缩放的距离」，$t^\star$ 与 $\operatorname{dist}$ 的因子 $2$ 关系就断了；你会在数值上看到 $t^\star = \operatorname{dist}$ 而不是 $\operatorname{dist}/2$，图 8.9 的 slab 厚度也会算成两倍。**方向提醒**：对偶是 $\max -\|\cdot\|_2$，即 $\min \|\cdot\|_2$，负号去掉不报错但会把「最近点对」解成「最远点对」，两组几乎贴着的数据会给出巨大间隙。**可复算验证**：$X = \{(-1,0)\}$、$Y = \{(1,0)\}$ 时 $\operatorname{dist} = 2$，故 $t^\star = 1$，$\|a^\star\|_2 = 1$、$b = 0$ 满足 $a^Tx_1 - b = 1$、$a^Ty_1 - b = -1$，slab $\{z \mid -1 \le z_1 \le 1\}$ 的厚度正是 $2 = 2t^\star$。**落点**：Boyd §8.6.1、§5.8.3（择一定理）、§8.2.1（两集合距离）、exercise 8.23。</span>

#### <span style="color:#2471a3;">Support vector classifier（支持向量分类器）</span>

当两组点无法被线性分离时，我们可能要找某个仿射函数来近似地分类它们，例如使误分类点数最少的那一个。遗憾的是，这通常是困难的组合优化问题。一种用于近似线性判别的启发式基于支持向量分类器（support vector classifier），本节介绍它。我们从可行性问题 (8.21) 出发。首先通过引入非负变量 $u_1,\dots,u_N$ 与 $v_1,\dots,v_M^{\dagger}$，并构造不等式

```math
a^T x_i - b \ge 1 - u_i, \quad i = 1,\dots,N, \qquad a^T y_i - b \le -(1 - v_i), \quad i = 1,\dots,M
\qquad (8.24)
```

来松弛约束。

（† 原文 p.425 此处把 $v_1,\dots,v_M$ 误印成 $v_1,\dots,u_M$，按上下文应为 $v$。）



（页眉：Chapter 8 Geometric problems · 原书 p.426）

<span style="color:#2471a3;">**[Figure 8.10]**</span> Figure 8.10：通过线性规划做近似线性判别。点 $x_1,\dots,x_{50}$（空心圆）无法与点 $y_1,\dots,y_{50}$（实心圆）被线性分离。实线所示的分类器由求解 LP (8.25) 得到。这个分类器误分类一个点。虚线是超平面 $a^T z - b = \pm 1$。有四个点被正确分类，但落在虚线定义的 slab 内。

（文字层给出了 $50/50$、误分类 $1$ 个、slab 内 $4$ 个这三组数；点位与直线位置不可复原。）

当 $u = v = 0$ 时，我们恢复原来的约束；只要把 $u$ 与 $v$ 取得足够大，这些不等式总能变成可行。我们可以把 $u_i$ 看作约束 $a^T x_i - b \ge 1$ 被违反的程度，$v_i$ 类似。我们的目标是找 $a$、$b$，以及稀疏的非负 $u$ 与 $v$，使不等式 (8.24) 成立。作为一个启发式，我们可以通过求解 LP

```math
\begin{array}{ll}
\text{minimize} & \mathbf{1}^T u + \mathbf{1}^T v \\
\text{subject to} & a^T x_i - b \ge 1 - u_i, \quad i = 1,\dots,N \\
& a^T y_i - b \le -(1 - v_i), \quad i = 1,\dots,M \\
& u \succeq 0, \quad v \succeq 0,
\end{array}
\qquad (8.25)
```

来最小化变量 $u_i$ 与 $v_i$ 之和。图 8.10 给了一个例子。在这个例子里，仿射函数 $a^T z - b$ 把 $100$ 个点中的 $1$ 个误分类。但要注意，当 $0 \lt u_i \lt 1$ 时，点 $x_i$ 被仿射函数 $a^T z - b$ 正确分类，却违反了不等式 $a^T x_i - b \ge 1$；对 $y_i$ 情况类似。LP (8.25) 的目标函数可以解释为「违反 $a^T x_i - b \ge 1$ 的点 $x_i$ 的个数」加上「违反 $a^T y_i - b \le -1$ 的点 $y_i$ 的个数」的一个松弛。换句话说，它是「被函数 $a^T z - b$ 误分类的点数」加上「被正确分类但落在 $-1 \lt a^T z - b \lt 1$ 定义的 slab 内的点数」的一个松弛。

更一般地，我们可以考虑误分类点数与 slab $\{z \mid -1 \le a^T z - b \le 1\}$ 的宽度之间的折中，而该宽度由 $2/\|a\|_2$ 给出。对集合 $\{x_1,\dots,x_N\}$ 与

<span style="color:#1e8449;">**[译注]** 这个 LP 松弛的「计数对象」要说准，否则整节读歪：$\mathbf{1}^Tu + \mathbf{1}^Tv$ 数的**不是**误分类数，而是「误分类点数 $+$ 落在 slab 内的点数」，即它把「分类正确但不够自信」也计入代价。**消失测试**：若把 slab 项丢掉（只罚 $u_i \gt 1$ 的部分，即退化成 hinge 变体），图 8.10 里那「四个正确但在 slab 内」的点就不再受罚，LP 会把 slab 拉宽以容纳更多点，误分类数可能不变但几何上不再是最厚 slab——而那四个点正是 SVC 与「最小误分类 LP」的唯一区别所在（前者罚全部 $u$，后者只罚越界的部分）。**量的方向**：$0 \lt u_i \lt 1$ 时 $u_i$ 是「欠自信」的度量，$u_i \gt 1$ 时才是真误分类，所以一个有 $k$ 个误分类的解，其目标值 $\ge k$，实际可达 $k + 4$（本图 $1 + 4 = 5$ 的量级）。**可复算验证**：单点 $x_1 = (0,0)$、$y_1 = (0.5,0)$，取 $a = (2,0)$、$b = -1$ 时 $a^Tx_1 - b = 1$（在边界）、$a^Ty_1 - b = 2$——同号，说明 $y_1$ 落在错侧，此时 $v_1 = 1 + 2 = 3$，目标值 $3$，与「$u=v=0$ 时不可行」一致。**落点**：Boyd §8.6.1、§7.1.1（hinge 与 logistic 的关系）、exercise 8.24；SVC 的统计学习侧对照见 §8 Bibliography 的 Vapnik [Vap00] 与 Schölkopf–Smola [SS01]。</span>



（页眉：§8.6 Classification · 原书 p.427）

<span style="color:#2471a3;">**[Figure 8.11]**</span> Figure 8.11：通过支持向量分类器做近似线性判别，取 $\gamma = 0.1$。实线所示的 support vector classifier 误分类三个点。有十五个点被正确分类，但落在虚线定义的 $-1 \lt a^T z - b \lt 1$ 的 slab 内。

（文字层给出了 $\gamma = 0.1$、误分类 $3$ 个、slab 内 $15$ 个这三组数；点位与三条直线位置不可复原。）

$\{y_1,\dots,y_M\}$ 的标准支持向量分类器，定义为下面问题的解：

```math
\begin{array}{ll}
\text{minimize} & \|a\|_2 + \gamma\left(\mathbf{1}^T u + \mathbf{1}^T v\right) \\
\text{subject to} & a^T x_i - b \ge 1 - u_i, \quad i = 1,\dots,N \\
& a^T y_i - b \le -(1 - v_i), \quad i = 1,\dots,M \\
& u \succeq 0, \quad v \succeq 0.
\end{array}
```

第一项正比于由 $-1 \le a^T z - b \le 1$ 定义的 slab 宽度的倒数。第二项的解释与前面相同，即它是误分类点数（含 slab 内的点）的凸松弛。参数 $\gamma$ 为正，它给出「误分类点数（我们希望最小化）」相对于「slab 宽度（我们希望最大化）」的相对权重。图 8.11 给了一个例子。

<span style="color:#1e8449;">**[译注]** 这个问题的两个目标在**量纲上打架**，$\gamma$ 就是为了让它们可比：slab 宽度是 $2/\|a\|_2$，所以「最大化宽度」写成「最小化 $\|a\|_2$」；而 $\mathbf 1^Tu + \mathbf 1^Tv$ 是**计数**（无量纲），两者相加必须先约定尺度。**消失测试**：若取 $\gamma = 0$，问题退化成 $\text{minimize } \|a\|_2$ s.t. $a^Tx_i - b\ge1-u_i,\ u\succeq0$——此时最优总是 $u = v = 0$、$a = 0$（目标 $0$ 是下界），分类器完全消失；反过来 $\gamma \to \infty$ 时第一项被压成零，问题退化成 (8.25) 那个纯 LP。所以 $\gamma$ 不是「精度旋钮」，它是**在「最大间隔」与「最小误分类」两个退化解之间选点**。**量的方向**：$\gamma = 0.1$ 时的典型平衡是 $\|a\|_2 \approx 1$、$u,v$ 之和在个位数（本图 $3 + 15$ 的量级），若你的解给出 $\|a\|_2 \sim 10^3$，说明 $\gamma$ 太小、slab 被压成一条线。**可复算验证**：可分数据下取 $\gamma = 0$，最优解满足 $\|a\|_2$ 最小、$u=v=0$，与 (8.23) 的鲁棒线性判别同解（两者只差归一化 $\|a\|_2 \le 1$），可直接比对 $t^\star = 1/\|a^\star\|_2$。**落点**：Boyd §8.6.1、§8.6.1 的 (8.23)(8.25)、exercise 8.25；统计学习侧的对照见 §8 Bibliography 的 Vapnik [Vap00] 与 Schölkopf–Smola [SS01]，那里 $\gamma$ 记为 $1/C$。</span>

#### <span style="color:#2471a3;">Approximate linear discrimination via logistic modeling（通过 logistic 建模做近似线性判别）</span>

另一种为无法线性分离的两组点寻找近似分类仿射函数的办法，基于 §7.1.1 描述的 logistic model。我们先把这两组点用一个 logistic model 拟合。假定 $z$ 是取值 $0$ 或 $1$ 的随机变量，其分布通过如下形式的 logistic model 依赖于某个（确定的）解释变量（explanatory variable）$u \in \mathbf{R}^n$：

```math
\operatorname{prob}(z = 1) = \frac{\exp(a^T u - b)}{1 + \exp(a^T u - b)}, \qquad \operatorname{prob}(z = 0) = \frac{1}{1 + \exp(a^T u - b)}.
\qquad (8.26)
```

现在假定给定的两组点 $\{x_1,\dots,x_N\}$ 与 $\{y_1,\dots,y_M\}$ 是来自这个 logistic model 的样本。具体地说，$\{x_1,\dots,x_N\}$ 是



（页眉：Chapter 8 Geometric problems · 原书 p.428）

$z = 1$ 的那 $N$ 个样本的 $u$ 取值，$\{y_1,\dots,y_M\}$ 是 $z = 0$ 的那 $M$ 个样本的 $u$ 取值。（这允许出现 $x_i = y_j$，而那种情形会排除两组点之间的判别。在 logistic model 里，它只意味着我们有两个样本，解释变量取值相同但结果不同。）

我们可以通过对观测样本做最大似然估计（maximum likelihood estimation）来确定 $a$ 与 $b$，即求解凸优化问题

```math
\text{minimize} \quad -l(a, b)
\qquad (8.27)
```

变量是 $a$、$b$，其中 $l$ 是对数似然函数（log-likelihood function）

```math
l(a,b) = \sum_{i=1}^{N}\left(a^T x_i - b\right) - \sum_{i=1}^{N}\log\left(1 + \exp(a^T x_i - b)\right) - \sum_{i=1}^{M}\log\left(1 + \exp(a^T y_i - b)\right)
```

（见 §7.1.1）。如果两组点可以被线性分离，即存在 $a$、$b$ 使 $a^T x_i \gt b$ 且 $a^T y_i \lt b$，则优化问题 (8.27) 无下界（unbounded below）。

一旦求出 $a$ 与 $b$ 的最大似然值，我们就可以为这两组点构造一个线性分类器 $f(x) = a^T x - b$。这个分类器具有如下性质：假定数据点确实是由参数为 $a$ 与 $b$ 的 logistic model 生成的，则它在所有线性分类器中具有最小的误分类概率。超平面 $a^T u = b$ 对应那些 $\operatorname{prob}(z = 1) = 1/2$ 的点，即两种结果等可能的点。一个例子见图 8.12。

<span style="color:#c0392b;">**Remark 8.1 Bayesian interpretation（贝叶斯解释）**</span> 设 $x$ 与 $z$ 是两个随机变量，分别取值于 $\mathbf{R}^n$ 与 $\{0,1\}$。假定

```math
\operatorname{prob}(z = 1) = \operatorname{prob}(z = 0) = 1/2,
```

并用 $p_0(x)$、$p_1(x)$ 分别表示在 $z = 0$ 与 $z = 1$ 条件下 $x$ 的条件概率密度。假定 $p_0$ 与 $p_1$ 满足

```math
\frac{p_1(x)}{p_0(x)} = e^{a^T x - b}
```

（对某对 $a$、$b$）。许多常见分布都满足这个性质。例如，$p_0$ 与 $p_1$ 可以是 $\mathbf{R}^n$ 上两个均值不同、协方差矩阵相同的正态密度，也可以是 $\mathbf{R}^n_+$ 上两个指数密度。由 Bayes 法则可得

```math
\operatorname{prob}(z = 1 \mid x = u) = \frac{p_1(u)}{p_1(u) + p_0(u)}, \qquad \operatorname{prob}(z = 0 \mid x = u) = \frac{p_0(u)}{p_1(u) + p_0(u)},
```

由此得到

```math
\operatorname{prob}(z = 1 \mid x = u) = \frac{\exp(a^T u - b)}{1 + \exp(a^T u - b)}, \qquad \operatorname{prob}(z = 0 \mid x = u) = \frac{1}{1 + \exp(a^T u - b)}.
```

<span style="color:#1e8449;">**[译注]** 「(8.27) 在可分时无下界」这一句是本节最实用的告警，因为**它是「不报错、只给错答案」的教科书案例**：逻辑回归在完全可分数据上，$a$ 的范数会沿着某个方向趋于无穷、$-\ell$ 单调下降趋于 $0$（不是趋于 $-\infty$，注意目标本身有下界 $0$，无界的是 $a$ 而非目标），于是求解器会在 `max_iter` 用尽后返回一个 $\|a\|_2 \approx 10^4$ 的「解」，权重巨大、概率近乎 $0/1$、分类边界看起来完美——但数值上完全不可用（换一份数据就翻向）。判据：若你的 $-\ell \lt 10^{-6}$ 且 $\|a\|_2 \gt 10^3$，就是这条路。**消失测试**：加入 $\ell_2$ 正则（即 maximize $\ell - \lambda\|a\|_2^2$）后问题严格凸，无界现象消失——这正是所有实现都默认加正则的真实原因，不是「防止过拟合」的口号。**可复算验证**：$x_1 = 0$（$z=1$）、$y_1 = 1$（$z=0$）的二维可分例，$b = 0$ 时 $-\ell(a) = \log(1+e^{0}) + \log(1+e^{-a})$，$a\to\infty$ 时 $-\ell \to \log 2 \approx 0.693$ 而**不是** $0$；要 $-\ell \to 0$ 需同时放大 $b$ 使 $a^Tx_i - b \to +\infty$、$a^Ty_i - b \to -\infty$。这两个数的差别正好暴露「无界」究竟落在哪个变量上。**落点**：Boyd §8.6.1、§7.1.1（logistic regression 的凸性）、exercise 8.26。</span>



（页眉：§8.6 Classification · 原书 p.429）

### <span style="color:#c0392b;">8.6.2 Nonlinear discrimination（非线性判别）</span>

我们完全可以同样地在给定的函数子空间中寻找一个非线性函数 $f$，使其在一组点上为正、在另一组上为负：

```math
f(x_i) \gt 0, \quad i = 1,\dots,N, \qquad f(y_i) \lt 0, \quad i = 1,\dots,M.
```

只要 $f$ 在定义它的那些参数上是线性（或仿射）的，这些不等式就可以用与线性判别完全相同的方式求解。本节考察几个有意思的特殊情形。

#### <span style="color:#2471a3;">Quadratic discrimination（二次判别）</span>

假定取 $f$ 为二次函数：$f(x) = x^T P x + q^T x + r$。参数 $P \in \mathbf{S}^n$、$q \in \mathbf{R}^n$、$r \in \mathbf{R}$ 必须满足不等式

```math
x_i^T P x_i + q^T x_i + r \gt 0, \quad i = 1,\dots,N \qquad y_i^T P y_i + q^T y_i + r \lt 0, \quad i = 1,\dots,M,
```



（页眉：Chapter 8 Geometric problems · 原书 p.430）

这是变量 $P$、$q$、$r$ 上的一组严格线性不等式。与线性判别一样，我们注意到 $f$ 关于 $P$、$q$、$r$ 是齐次的，所以可以通过求解非严格可行性问题

```math
x_i^T P x_i + q^T x_i + r \ge 1, \quad i = 1,\dots,N \qquad y_i^T P y_i + q^T y_i + r \le -1, \quad i = 1,\dots,M
```

来求出严格不等式组的一个解。分离曲面 $\{z \mid z^T P z + q^T z + r = 0\}$ 是一个二次曲面，而两个分类区域

```math
\{z \mid z^T P z + q^T z + r \le 0\}, \qquad \{z \mid z^T P z + q^T z + r \ge 0\}
```

由二次不等式定义。于是，求解二次判别问题，等同于判定两组点能否被一个二次曲面分离。

我们可以通过对 $P$、$q$、$r$ 添加约束，来对分离曲面或分类区域的形状施加条件。例如，我们可以要求 $P \prec 0$，这意味着分离曲面是椭球形的。更具体地说，它意味着我们寻找一个包含所有点 $x_1,\dots,x_N$、但不含任何点 $y_1,\dots,y_M$ 的椭球。这个二次判别问题可以作为 SDP 可行性问题求解：

```math
\begin{array}{ll}
\text{find} & P, q, r \\
\text{subject to} & x_i^T P x_i + q^T x_i + r \ge 1, \quad i = 1,\dots,N \\
& y_i^T P y_i + q^T y_i + r \le -1, \quad i = 1,\dots,M \\
& P \preceq -I,
\end{array}
```

变量是 $P \in \mathbf{S}^n$、$q \in \mathbf{R}^n$ 与 $r \in \mathbf{R}$。（这里我们用 $P,q,r$ 的齐次性，把约束 $P \prec 0$ 表达成 $P \preceq -I$。）图 8.13 给了一个例子。

<span style="color:#1e8449;">**[译注]** $P \prec 0$ 这一步是「**写反不报错、只换个几何对象**」的典型：$P \prec 0$ 时 $\{z \mid z^TPz + q^Tz + r \le 0\}$ 是椭球**外部**，$\ge 0$ 那一支才是椭球**内部**（因为 $z^TPz$ 负定，加一次项配方后二次型的等号集是有界椭球面）；于是「含全部 $x_i$、不含 $y_i$」就变成用**一个椭球同时装下 $x$ 类、排掉 $y$ 类**。若你把 $P \prec 0$ 写成 $P \succ 0$，SDP 依然 feasible，只是解出的 $P$ 正定，等号集变成双曲面（$n \ge 3$）或双曲线（$n=2$），分类区域变成无界双曲区域——它**照样能把 $x$ 与 $y$ 分开**，所以你的可行性检验通过、但图与论文里的「椭球」完全不符。**量的方向**：$P \preceq -I$ 而不是 $P \preceq 0$，是因为齐次性只让 $P$ 定到正常数倍，必须用一个绝对尺度把「负定」钉死，否则 $P$ 可以沿 $-P$ 无限缩小而不违反任何约束；$-I$ 是最省事的规范。**可复算验证**：$n=2$、$x_i$ 全在单位圆盘、$y_i$ 在圆外，则 $P = -I,\ q = 0,\ r = 1$ 满足 $x_i^TPx_i + r = 1 - \|x_i\|_2^2 \ge 0$；要让它 $\ge 1$ 需 $r = 2$，这就是齐次化时「$\ge 1$ 而非 $\ge 0$」带来的常数平移。**落点**：Boyd §8.6.2、§4.4（二次型不等式的 SDP 检验）、exercise 8.27。</span>

#### <span style="color:#2471a3;">Polynomial discrimination（多项式判别）</span>

我们考虑 $\mathbf{R}^n$ 上次数不超过 $d$ 的多项式集合：

```math
f(x) = \sum_{i_1 + \cdots + i_n \le d} a_{i_1\cdots i_n}\, x_1^{i_1}\cdots x_n^{i_n}. \qquad \dagger
```

（† 原文 p.430 此处把系数下标误印成 $a_{i_1\cdots i_d}$，与求和指标 $i_1+\cdots+i_n \le d$ 不符，按上下文应为 $a_{i_1\cdots i_n}$。）

我们可以通过求解变量 $a_{i_1\cdots i_n}$ 上的一组线性不等式，来判定两组点 $\{x_1,\dots,x_N\}$ 与 $\{y_1,\dots,y_M\}$ 能否被这样的多项式分离。从几何上看，我们是在检验这两组点能否被一个代数曲面（algebraic surface，由次数不超过 $d$ 的多项式定义）分离。

作为一个推广，求分离两组点的 $\mathbf{R}^n$ 上最低次多项式这个问题，可以通过 quasiconvex programming 求解，因为多项式的次数是系数的拟凸函数。这可以对 $d$ 做二分（bisection）来实现，每一步求解一个可行性线性规划。一个例子见图 8.14。

### <span style="color:#c0392b;">8.7 Placement and location（布局与选址）</span>

本节讨论下面这个问题的一些变体。我们在 $\mathbf{R}^2$ 或 $\mathbf{R}^3$ 中有 $N$ 个点，以及一张列出「必须用连线连接」的点对的表。这 $N$ 个点中有一部分位置是固定的；我们的任务是确定其余点的位置，即把其余点摆放（place）好。目标是在对位置施加某些附加约束的前提下摆放这些点，使某种「连线总长度」的度量最小。

作为应用示例，我们可以把这些点想成公司工厂或仓库的位置，把连线想成货物运输的路线。目标是找出使总运输成本最小的位置。在另一个应用里，这些点表示集成电路上模块或单元（cell）的位置，连线表示连接成对单元的导线。这里的目标可能是：摆放这些单元，使互连所用的导线总长度最小。

这个问题可以用一个 $N$ 个节点的无向图来描述，节点代表这 $N$ 个点。我们给每个节点关联一个变量 $x_i \in \mathbf{R}^k$，其中 $k = 2$ 或 $k = 3$，它表示该节点的位置。问题就是

```math
\text{minimize} \quad \sum_{(i,j) \in A} f_{ij}(x_i, x_j)
```

其中 $A$ 是图中所有连线的集合，$f_{ij} : \mathbf{R}^k \times \mathbf{R}^k \to \mathbf{R}$ 是与弧 $(i,j)$ 关联的代价函数。（另一种写法是对所有 $i$ 与 $j$ 求和、或对 $i \lt j$ 求和，并在 $i$ 与 $j$ 未连接时直接取 $f_{ij} = 0$。）有些坐标向量 $x_i$ 是给定的。优化变量是其余的坐标。只要函数 $f_{ij}$ 是凸的，这就是一个凸优化问题。

### <span style="color:#c0392b;">8.7.1 Linear facility location problems（线性设施选址问题）</span>

在这个问题最简单的版本里，与弧 $(i,j)$ 关联的代价是节点 $i$ 与 $j$ 之间的距离：$f_{ij}(x_i,x_j) = \|x_i - x_j\|$，即我们最小化

```math
\sum_{(i,j) \in A} \|x_i - x_j\|.
```

我们可以用任何范数，但最常见的应用涉及欧氏范数或 $\ell_1$-范数。例如，在电路设计中，通常沿分段线性路径（piecewise-linear path）在单元之间布线路，其中每一段不是水平就是竖直。（这称为 Manhattan routing，因为矩形网格城市里沿街道的路径也是分段线性的，每条街都与两条正交轴之一对齐。）在这种情况下，连接单元 $i$ 与单元 $j$ 所需的导线长度由 $\|x_i - x_j\|_1$ 给出。

我们可以引入非负权重，以反映沿不同弧的单位距离成本的差异：


（页眉：§8.7 Placement and location · 原书 p.433）

```math
\sum_{(i,j) \in A} w_{ij}\|x_i - x_j\|.
```

通过对未连接的节点对赋予权重 $w_{ij} = 0$，我们可以用目标函数

```math
\sum_{i \lt j} w_{ij}\|x_i - x_j\|
\qquad (8.28)
```

更简洁地表达这个问题。这个 placement 问题是凸的。

<span style="color:#c0392b;">**Example 8.4 One free point（单个自由点）**</span> 考虑只有一个点 $(u,v) \in \mathbf{R}^2$ 自由、而我们最小化到固定点 $(u_1,v_1),\dots,(u_K,v_K)$ 的距离之和的情形。

- **$\ell_1$-范数**。我们可以解析地求出使

```math
\sum_{i=1}^{K}\left(|u - u_i| + |v - v_i|\right)
```

最小的点。一个最优点就是这些固定点的任意一个中位数（median）。换句话说，$u$ 可以取点集 $\{u_1,\dots,u_K\}$ 的任一 median，$v$ 可以取点集 $\{v_1,\dots,v_K\}$ 的任一 median。（若 $K$ 为奇数，最小点唯一；若 $K$ 为偶数，可能存在一个由最优点构成的矩形。）

- **欧氏范数**。使欧氏距离之和

```math
\sum_{i=1}^{K}\left((u - u_i)^2 + (v - v_i)^2\right)^{1/2}
```

最小的点 $(u,v)$，称为这些给定固定点的 Weber point。

<span style="color:#1e8449;">**[译注]** 这个例子的对比价值在于**同一个「单自由点最小化距离和」在两个范数下是可算与不可算的分界**：$\ell_1$ 的目标可分离成 $u$ 与 $v$ 两个独立的一维问题，每个都是一维分段线性凸函数，其最小值必在某个数据点的坐标处取得（因为斜率的跳跃只发生在 $u_i$ 上），所以 $\{u_i\}$ 的中位数就是解——复杂度 $O(K\log K)$（排序）。欧氏范数不行：目标 $\sum\sqrt{(u-u_i)^2+(v-v_i)^2}$ 不可分离，梯度是 $\sum (x - x_i)/\|x - x_i\|$，令其为零得到一个**非线性方程组**，没有闭式解。**消失测试**：如果没有「凸性 + 一阶条件即充要」这一条，Weber point 就只能靠网格搜索（$n=2$、每维 $10^3$ 格是 $10^6$ 次求值）；有了凸性，它可以写成 SOCP 一次解出，或用以 Weiszfeld 迭代（$x^{(t+1)} = \sum w_i x_i / \sum w_i$，$w_i = 1/\|x^{(t)}-x_i\|$）线性收敛，代价 $O(K)$/步。**可复算验证**：$K = 3$、固定点 $(0,0),(1,0),(0,1)$ 时 $\ell_1$ 解为 $u = 0,\ v = 0$（$u$ 的中位数集是 $[0,0]$，$v$ 同理），目标值 $0+1+1 = 2$；欧氏解则是三角形的 Fermat 点，对称性给出 $u = v = t$，解 $\frac{\partial}{\partial t}\left(2\sqrt2\,t + \sqrt{2}(1-t)\right) = 0$ 得 $t = 1/2$ 处不可微但最小，$u = v = 0.5$，目标值 $2\times 0.7071 + 0.7071 = 2.1213 \gt 2$——**同一组点，两个范数的最优值差 $6\%$**，足以说明不能混用。**落点**：Boyd §8.7.1、exercise 8.29；Weber 的原始出处见 §8 Bibliography（Weber [Web71]）。</span>

### <span style="color:#c0392b;">8.7.2 Placement constraints（布局约束）</span>

现在列出一些可以加到基本 placement 问题上、并且保持凸性不变的有意思的约束。我们可以要求某些位置 $x_i$ 落在指定的凸集里，例如某条直线、某个区间、某个正方形或某个椭球里。我们可以约束一个点相对于一个或多个其他点的相对位置，例如限制一对点之间的距离。我们可以施加相对位置约束，例如某个点必须位于另一个点的左侧。

一组点的 bounding box（包围盒）是包含这些点的最小矩形。我们可以施加约束，把点 $x_1,\dots,x_p$（比方说）限制在一个周长不超过 $P_{\max}$ 的 bounding box 内，办法是添加约束

```math
u \preceq x_i \preceq v, \quad i = 1,\dots,p, \qquad 2\,\mathbf{1}^T(v - u) \le P_{\max},
```

其中 $u$、$v$ 是附加变量。

### <span style="color:#c0392b;">8.7.3 Nonlinear facility location problems（非线性设施选址问题）</span>

更一般地，我们可以给每条弧关联一个「长度」的非线性递增函数的代价，即

```math
\text{minimize} \quad \sum_{i \lt j} w_{ij}\, h\left(\|x_i - x_j\|\right)
```

其中 $h$ 是（在 $\mathbf{R}_+$ 上）递增且凸的函数，$w_{ij} \ge 0$。我们称之为非线性 placement 问题或非线性设施选址（nonlinear facility location）问题。

一个常见的例子用欧氏范数与函数 $h(z) = z^2$，即我们最小化

```math
\sum_{i \lt j} w_{ij}\|x_i - x_j\|_2^2.
```

这称为 quadratic placement 问题。当唯一的约束是线性等式时，quadratic placement 问题可以解析求解；当约束是线性等式与不等式时，它可以作为 QP 求解。

<span style="color:#c0392b;">**Example 8.5 One free point（单个自由点）**</span> 考虑只有一个点 $x$ 自由、而我们最小化到固定点 $x_1,\dots,x_K$ 的欧氏距离平方和的情形：

```math
\|x - x_1\|_2^2 + \|x - x_2\|_2^2 + \cdots + \|x - x_K\|_2^2.
```

求导可知最优的 $x$ 由

```math
\frac{1}{K}\left(x_1 + x_2 + \cdots + x_K\right)
```

给出，即这些固定点的平均值。

另外一些有意思的可能性是 deadzone function（死区函数）$h$——死区宽度为 $2\gamma$，定义为

```math
h(z) = \begin{cases} 0, & |z| \le \gamma \\ |z - \gamma|, & |z| \ge \gamma, \end{cases}
```

以及「二次-线性」（quadratic-linear）函数 $h$，定义为

```math
h(z) = \begin{cases} z^2, & |z| \le \gamma \\ 2\gamma|z| - \gamma^2, & |z| \ge \gamma. \end{cases}
```

<span style="color:#c0392b;">**Example 8.6**</span> 我们考虑 $\mathbf{R}^2$ 中一个 placement 问题，有 $6$ 个自由点、$8$ 个固定点、$27$ 条连线。图 8.15–8.17 显示了在判据


### <span style="color:#c0392b;">8.7.4 Location problems with path constraints（带路径约束的选址问题）</span>

#### <span style="color:#2471a3;">Path constraints（路径约束）</span>

沿点 $x_1,\dots,x_N$ 的一条 $p$-link path，由节点序列 $i_0,\dots,i_p \in \{1,\dots,N\}$ 描述。这条路径的长度由

```math
\|x_{i_1} - x_{i_0}\| + \|x_{i_2} - x_{i_1}\| + \cdots + \|x_{i_p} - x_{i_{p-1}}\|
```

给出，它是 $x_1,\dots,x_N$ 的凸函数，所以对路径长度施加一个上界是一个凸约束。若干有意思的 placement 问题都涉及路径约束，或者以路径长度为基础构造目标。我们描述一个典型的例子，其中的目标基于一组路径上的最大路径长度。

#### <span style="color:#2471a3;">Minimax delay placement（极小极大延迟布局）</span>

我们考虑一个有向无环图，节点为 $1,\dots,N$，弧或连线由有序对的集合 $A$ 表示：$(i,j) \in A$ 当且仅当有一条从 $i$ 指向 $j$ 的弧。若没有弧从 $A$ 指向节点 $i$，我们说节点 $i$ 是源节点（source node）；若没有弧从它离开，则称它是汇节点（sink node）或



（页眉：§8.7 Placement and location · 原书 p.437）

目的节点（destination node）。我们关心图中的极大路径（maximal path），它们从某个源节点出发、到某个汇节点结束。

图的弧用来建模某种流，比如货物或信息在一个节点位于 $x_1,\dots,x_N$ 的网络中的流动。流从源节点出发，沿路径从一个节点移动到另一个节点，终止于某个汇节点或目的节点。我们用相邻节点之间的距离来建模货物在节点之间的传播时间或运输时间；一条路径的总延迟或传播时间（正比于）相邻节点之间距离之和。

现在我们可以描述极小极大延迟布局（minimax delay placement）问题了。有些节点位置是固定的，其余是自由的，即优化变量。目标是通过选择自由节点的位置，使从任一源节点到任一汇节点的路径上的最大总延迟最小。显然这是一个凸问题，因为目标

```math
T_{\max} = \max\left\{\|x_{i_1} - x_{i_0}\| + \cdots + \|x_{i_p} - x_{i_{p-1}}\| \mid i_0,\dots,i_p \text{ is a source-sink path}\right\}
\qquad (8.29)
```

是位置 $x_1,\dots,x_N$ 的凸函数。

虽然最小化 (8.29) 的问题是凸的，但源-汇路径的数目可能非常大，随节点数或弧数呈指数增长。这个问题有一个有用的重新表述，可以避免枚举所有汇-源路径。

我们首先解释如何**远比「对每条源-汇路径求延迟再取最大」高效得多地**计算最大延迟 $T_{\max}$。设 $\tau_k$ 为从节点 $k$ 到某个汇节点的任一路径的最大总延迟。显然，当 $k$ 是汇节点时 $\tau_k = 0$。考虑一个节点 $k$，它有指向节点 $j_1,\dots,j_p$ 的出弧。对于一条从节点 $k$ 出发、终止于某个汇节点的路径，它的第一条弧必然指向 $j_1,\dots,j_p$ 之一。若这样一条路径先走通向 $j_i$ 的那条弧，再从那里走通向汇节点的最长路径，则总长度为

```math
\|x_{j_i} - x_k\| + \tau_{j_i},
```

即通向 $j_i$ 的弧长，加上从 $j_i$ 到汇节点的最长路径的总长。由此可知，从节点 $k$ 出发到汇节点的路径的最大延迟满足

```math
\tau_k = \max\left\{\|x_{j_1} - x_k\| + \tau_{j_1}, \dots, \|x_{j_p} - x_k\| + \tau_{j_p}\right\}.
\qquad (8.30)
```

（这是一个简单的动态规划论证。）

方程组 (8.30) 给出求任一节点最大延迟的递推：我们从汇节点（最大延迟为零）开始，用 (8.30) 反向计算，直到覆盖所有源节点。任一条这类路径上的最大延迟，就是所有 $\tau_k$ 的最大值，它会在某个源节点处取得。这个动态规划递推表明：沿任一源-汇路径的最大延迟可以递推地计算，无需枚举所有路径。这个递推所需的算术运算次数大约等于连线的数目。

现在我们来展示如何用基于 (8.30) 的递推来表述 minimax delay placement 问题。我们可以把问题表达成

```math
\begin{array}{ll}
\text{minimize} & \max\{\tau_k \mid k \text{ a source node}\} \\
\text{subject to} & \tau_k = 0, \quad k \text{ a sink node} \\
& \tau_k = \max\{\|x_j - x_k\| + \tau_j \mid \text{there is an arc from } k \text{ to } j\},
\end{array}
```



（页眉：Chapter 8 Geometric problems · 原书 p.438）

变量是 $\tau_1,\dots,\tau_N$ 与自由位置。这个问题不是凸的，但我们可以把它表达成一个等价的凸形式：把等式约束换成不等式。我们引入新变量 $T_1,\dots,T_N$，它们将分别是 $\tau_1,\dots,\tau_N$ 的上界。我们令所有汇节点处 $T_k = 0$，并用不等式

```math
T_k \ge \max\left\{\|x_{j_1} - x_k\| + T_{j_1}, \dots, \|x_{j_p} - x_k\| + T_{j_p}\right\}
```

代替 (8.30)。若这些不等式满足，则 $T_k \ge \tau_k$。现在构造问题

```math
\begin{array}{ll}
\text{minimize} & \max\{T_k \mid k \text{ a source node}\} \\
\text{subject to} & T_k = 0, \quad k \text{ a sink node} \\
& T_k \ge \max\{\|x_j - x_k\| + T_j \mid \text{there is an arc from } k \text{ to } j\}.
\end{array}
```

这个问题以 $T_1,\dots,T_N$ 与自由位置为变量，是凸的，并且解出了 minimax delay 选址问题。

<span style="color:#1e8449;">**[译注]** 「把 $=$ 换成 $\ge$ 仍然精确」这一步值得单独拆，因为它**只对 minimize 方向成立**：目标把 $T$ 往小压，而 $T_k \ge \tau_k$ 把 $T$ 往大撑，两侧对撞在 $T_k = \tau_k$ 处达到平衡——这是「松弛 + 单调目标 = 精确」的标准论证。**消失测试**：若目标改成 maximize（比如求「最坏情况下的最小延迟」这类反向问题），这个替换立刻失效：optimal $T$ 会顶到它的上界而不受 (8.30) 约束，你解出的是无关的数，而且**求解器不报错**。**量的方向**：枚举法的代价是路径数 $\pi$（节点数 $N$ 时 $\pi$ 可指数大，$20$ 层、每层 $3$ 个并行分支 ⇒ $\pi \approx 3^{20} \approx 3.5\times10^9$），DP 的代价是弧数 $|A|$（同图约 $60$ 条）；比率约 $6\times10^7$。**可复算验证**：三点链 $1\to2\to3$、$x_1 = (0,0)$、$x_2 = (1,0)$、$x_3 = (3,0)$，则 $\tau_3 = 0$、$\tau_2 = 2$、$\tau_1 = 1 + 2 = 3$；整图最大延迟 $3$，等于从 $x_1$ 到 $x_3$ 的直接距离，验证了 $\tau$ 递推与「路径长度」定义一致。**落点**：Boyd §8.7.4、(8.29)(8.30)、exercise 8.31；动态规划侧的挂载点是 6.006 的 DAG shortest/longest path（这里是「最长路」，因为代价是延迟不是距离）——注意 **DAG 上最长路可多项式求解，一般图上不可**（NP-hard），这正是原文强调 directed acyclic 的原因。</span>

### <span style="color:#c0392b;">8.8 Floor planning（布图规划）</span>

在 placement 问题中，变量表示的是一些点的坐标，这些点要被最优地摆放。floor planning 问题可以看作 placement 问题在两个方向上的推广：

- 要摆放的对象是与坐标轴对齐的矩形或长方体（而不是点），并且它们不允许重叠。
- 每个要摆放的矩形或长方体可以在一定限度内重新配置。例如，我们可以固定每个矩形的面积，但不单独固定它的长度与高度。

目标通常是使包围盒的尺寸（例如面积、体积、周长）最小，而包围盒是包含所有待配置与摆放的盒子的最小盒子。

非重叠约束使一般 floor planning 问题成为复杂的组合优化问题，或者说矩形装箱（rectangle packing）问题。然而，如果盒子的相对位置是给定的，若干类 floor planning 问题就可以表达成凸优化问题。本节探讨其中一些。我们考虑二维情形，并对高维推广作一些评注（在推广不明显的时候）。

我们有 $N$ 个单元或模块 $C_1,\dots,C_N$，它们要被配置并摆放在一个宽为 $W$、高为 $H$、左下角位于 $(0,0)$ 的矩形内。第 $i$ 个单元的几何与位置由它的宽 $w_i$ 与高 $h_i$、以及其左下角坐标 $(x_i,y_i)$ 确定。图 8.18 对此作了图示。

问题中的变量是 $x_i, y_i, w_i, h_i$（$i = 1,\dots,N$），以及包围矩形的宽 $W$ 与高 $H$。在所有 floor planning 问题中，我们都要求单元落在包围矩形内部，即

```math
x_i \ge 0, \quad y_i \ge 0, \quad x_i + w_i \le W, \quad y_i + h_i \le H, \quad i = 1,\dots,N.
\qquad (8.31)
```



（页眉：§8.8 Floor planning · 原书 p.439）

我们还要求这些单元不重叠，至多可以在边界上相接触：

```math
\operatorname{int}\left(C_i \cap C_j\right) = \emptyset \quad \text{for } i \ne j.
```

（也可以要求单元之间具有正的最小间隙（clearance）。）非重叠约束 $\operatorname{int}(C_i \cap C_j) = \emptyset$ 成立，当且仅当对 $i \ne j$，有

```math
C_i \text{ 在 } C_j \text{ 左边，或 } C_i \text{ 在 } C_j \text{ 右边，或 } C_i \text{ 在 } C_j \text{ 下方，或 } C_i \text{ 在 } C_j \text{ 上方}.
```

这四个几何条件对应不等式

```math
x_i + w_i \le x_j, \quad \text{or} \quad x_j + w_j \le x_i, \quad \text{or} \quad y_i + h_i \le y_j, \quad \text{or} \quad y_j + h_j \le y_i,
\qquad (8.32)
```

对每个 $i \ne j$，其中至少有一个必须成立。注意这些约束的组合性质：对每一对 $i \ne j$，上面四个不等式中至少有一个必须成立。

### <span style="color:#c0392b;">8.8.1 Relative positioning constraints（相对定位约束）</span>

相对定位约束的想法是：对每一对单元，指定四种可能的相对定位条件之一，即左、右、上、下。指定这些约束的一种简单方法，是给出 $\{1,\dots,N\}$ 上的两个关系：$L$（表示「在……左边」）与 $B$（表示「在……下方」）。然后我们施加约束：若 $(i,j) \in L$ 则 $C_i$ 在 $C_j$ 左边，若 $(i,j) \in B$ 则 $C_i$ 在 $C_j$ 下方。这给出约束

```math
x_i + w_i \le x_j \text{ for } (i,j) \in L, \qquad y_i + h_i \le y_j \text{ for } (i,j) \in B,
\qquad (8.33)
```


（页眉：Chapter 8 Geometric problems · 原书 p.440）

对 $i,j = 1,\dots,N$。为确保关系 $L$ 与 $B$ 确实指定了每一对单元的相对定位，我们要求对每个 $i \ne j$ 的 $(i,j)$，下面之一成立：

```math
(i,j) \in L, \quad (j,i) \in L, \quad (i,j) \in B, \quad (j,i) \in B,
```

并且 $(i,i) \notin L$、$(i,i) \notin B$。不等式 (8.33) 是变量上的一组 $N(N-1)/2$ 个线性不等式。这些不等式隐含了非重叠不等式 (8.32)，而后者是 $N(N-1)/2$ 个「四个线性不等式之析取」（disjunction）。

我们可以假定关系 $L$ 与 $B$ 是反对称的（anti-symmetric，即 $(i,j) \in L \Rightarrow (j,i) \notin L$）与传递的（transitive，即 $(i,j) \in L,\ (j,k) \in L \Rightarrow (i,k) \in L$）。（若不成立，相对定位约束显然不可行。）传递性对应一个显然的条件：若单元 $C_i$ 在单元 $C_j$ 左边，而 $C_j$ 在 $C_k$ 左边，则 $C_i$ 必在 $C_k$ 左边。此时对应 $(i,k) \in L$ 的那个不等式是冗余的；它由另外两个隐含。通过利用关系 $L$ 与 $B$ 的传递性，我们可以去掉冗余约束，得到一组紧凑的相对定位不等式。

一组极小的相对定位约束，可以方便地用两个有向无环图 $H$ 与 $V$（分别对应水平与竖直）来描述。两个图都有 $N$ 个节点，与 floor planning 问题中的 $N$ 个单元对应。图 $H$ 如下生成关系 $L$：$(i,j) \in L$ 当且仅当 $H$ 中存在从 $i$ 到 $j$ 的（有向）路径。类似地，图 $V$ 生成关系 $B$：$(i,j) \in B$ 当且仅当 $V$ 中存在从 $i$ 到 $j$ 的（有向）路径。为确保每一对单元都有相对定位约束，我们要求：对每一对单元，在其中一个图中存在从一个到另一个的有向路径。

显然，我们只需施加与图 $H$ 和 $V$ 的边相对应的那些不等式；其余由传递性推得。我们得到不等式组

```math
x_i + w_i \le x_j \text{ for } (i,j) \in H, \qquad y_i + h_i \le y_j \text{ for } (i,j) \in V,
\qquad (8.34)
```

它是一组线性不等式，$H$ 与 $V$ 中每条边对应一个。不等式组 (8.34) 是不等式组 (8.33) 的子集，且与它等价。

用类似的方式，$4N$ 个不等式 (8.31) 也可以化简成一组极小的等价集合。约束 $x_i \ge 0$ 只需施加在最左侧的那些单元上，即在关系 $L$ 中极小的那些 $i$ 上。它们对应图 $H$ 中的源点，即没有边指向它们的那些节点。类似地，不等式 $x_i + w_i \le W$ 只需对最右侧的单元施加。用同样的方式，竖直方向的包围盒不等式也可以裁剪成极小集。这给出极小等价的包围盒不等式组

```math
\begin{array}{ll}
x_i \ge 0 & \text{for } i \text{ } L \text{ minimal}, \\
x_i + w_i \le W & \text{for } i \text{ } L \text{ maximal}, \\
y_i \ge 0 & \text{for } i \text{ } B \text{ minimal}, \\
y_i + h_i \le H & \text{for } i \text{ } B \text{ maximal}.
\end{array}
\qquad (8.35)
```

一个简单的例子见图 8.19。在这个例子里，$L$ 极小（即最左）的单元是 $C_1$、$C_2$、$C_4$，而唯一的 $L$ 极大（最右）单元是 $C_5$。指定水平方向相对定位的极小不等式组由

```math
x_1 \ge 0, \quad x_2 \ge 0, \quad x_4 \ge 0, \quad x_5 + w_5 \le W, \quad x_1 + w_1 \le x_3, \quad x_2 + w_2 \le x_3, \quad x_3 + w_3 \le x_5, \quad x_4 + w_4 \le x_5
```

给出。

### <span style="color:#c0392b;">8.8.2 Floor planning via convex optimization（通过凸优化做布图规划）</span>

在这个表述中，变量是包围盒的宽与高 $W$ 与 $H$，以及各单元的宽、高与位置：$w_i$、$h_i$、$x_i$ 与 $y_i^{\dagger}$，$i = 1,\dots,N$。我们施加包围盒约束 (8.35) 与相对定位约束 (8.34)，它们都是线性不等式。作为目标，我们取包围盒的周长，即 $2(W + H)$，它是变量的线性函数。

（† 原文 p.441 此处把 $y_i$ 误印成第二个 $w_i$——「$w_i, h_i, x_i$, and $w_i$」，与 (8.31) 的变量表不符。）

下面列出一些可以表达成变量上的凸不等式或线性等式的约束。

#### <span style="color:#2471a3;">Minimum spacing（最小间隙）</span>

我们可以通过把相对定位约束从 $x_i + w_i \le x_j$（$(i,j) \in H$）改成 $x_i + w_i + \rho \le x_j$（$(i,j) \in H$）来施加单元之间最小间隙 $\rho \gt 0$，竖直图同理。我们可以让 $H$ 与 $V$ 的每条边关联不同的最小间隙。另一种可能是固定 $W$ 与 $H$，把最大化最小间隙 $\rho$ 作为目标。



（页眉：Chapter 8 Geometric problems · 原书 p.442）

#### <span style="color:#2471a3;">Minimum cell area（最小单元面积）</span>

对每个单元我们指定一个最小面积，即要求 $w_i h_i \ge A_i$，其中 $A_i \gt 0$。这些最小单元面积约束可以用若干种方式表达成凸不等式，例如 $w_i \ge A_i/h_i$、$(w_i h_i)^{1/2} \ge A_i^{1/2}$，或 $\log w_i + \log h_i \ge \log A_i$。

#### <span style="color:#2471a3;">Aspect ratio constraints（长宽比约束）</span>

我们可以对每个单元的长宽比（aspect ratio）施加下界与上界，即

```math
l_i \le h_i/w_i \le u_i.
```

两边乘以 $w_i$ 就把这些约束变成线性不等式。我们也可以固定某个单元的长宽比，那会得到一个线性等式约束。

#### <span style="color:#2471a3;">Alignment constraints（对齐约束）</span>

我们可以施加约束：两个单元的两条边、或中心线是对齐的。例如，单元 $i$ 的水平中心线与单元 $j$ 的顶边对齐，当

```math
y_i + h_i/2 = y_j + h_j.
```

这些是线性等式约束。用类似方式，我们可以要求某个单元紧贴包围盒边界。

#### <span style="color:#2471a3;">Symmetry constraints（对称约束）</span>

我们可以要求成对的单元关于某条竖直或水平轴对称，而这条轴可以固定，也可以浮动（即它的位置固定或不固定）。例如，要指定单元 $i$ 与 $j$ 关于竖直轴 $x = x_{\text{axis}}$ 对称，我们施加线性等式约束

```math
x_{\text{axis}} - (x_i + w_i/2) = x_j + w_j/2 - x_{\text{axis}}.
```

我们可以要求若干对单元关于一条未指定的竖直轴对称：施加这些等式约束，并把 $x_{\text{axis}}$ 作为新变量引入即可。

#### <span style="color:#2471a3;">Similarity constraints（相似约束）</span>

我们可以用等式约束 $w_i = a w_j$、$h_i = a h_j$ 要求单元 $i$ 是单元 $j$ 的 $a$ 倍缩放平移。这里的缩放因子 $a$ 必须固定。只施加其中一个约束，就要求某个单元的宽（或高）是另一个单元宽（或高）的给定倍数。

#### <span style="color:#2471a3;">Containment constraints（包含约束）</span>

我们可以要求某个特定单元包含一个给定点，这施加两个线性不等式。我们可以要求某个特定单元落在给定的多面体内，同样通过施加线性不等式实现。



（页眉：§8.8 Floor planning · 原书 p.443）

#### <span style="color:#2471a3;">Distance constraints（距离约束）</span>

我们可以施加各种各样的约束，限制成对单元之间的距离。在最简单的情形下，我们可以限制单元 $i$ 与 $j$ 中心点之间（或单元上任何其他固定点，例如左下角）的距离。例如，要限制单元 $i$ 与 $j$ 中心之间的距离，我们使用（凸）不等式

```math
\left\|\left(x_i + w_i/2,\ y_i + h_i/2\right) - \left(x_j + w_j/2,\ y_j + h_j/2\right)\right\| \le D_{ij}.
```

与 placement 问题一样，我们可以限制距离之和，或者把距离之和作为目标。

我们也可以限制单元 $i$ 与单元 $j$ 之间的距离 $\operatorname{dist}(C_i, C_j)$，即单元 $i$ 中一点与单元 $j$ 中一点之间的最小距离。在一般情形下这可以这样做：要按范数 $\|\cdot\|$ 限制单元 $i$ 与 $j$ 之间的距离，我们引入四个新变量 $u_i, v_i, u_j, v_j$。对 $(u_i, v_i)$ 将表示 $C_i$ 中的一点，对 $(u_j, v_j)$ 将表示 $C_j$ 中的一点。为确保这一点，我们施加线性不等式

```math
x_i \le u_i \le x_i + w_i, \qquad y_i \le v_i \le y_i + h_i,
```

对单元 $j$ 类似。最后，为限制 $\operatorname{dist}(C_i, C_j)$，我们添加凸不等式

```math
\left\|(u_i, v_i) - (u_j, v_j)\right\| \le D_{ij}.
```

在许多具体情形下，我们可以更高效地表达这些距离约束：利用相对定位约束，或推导出更显式的表述。作为一个例子，考虑 $\ell_\infty$-范数，并假定（由某个相对定位约束）单元 $i$ 位于单元 $j$ 左侧。两个单元之间的水平位移是 $x_j - (x_i + w_i)$。于是 $\operatorname{dist}(C_i, C_j) \le D_{ij}$ 当且仅当

```math
x_j - (x_i + w_i) \le D_{ij}, \qquad y_j - (y_i + h_i) \le D_{ij}, \qquad y_i - (y_j + h_j) \le D_{ij}.
```

第一个不等式说明单元 $i$ 的右边缘与单元 $j$ 的左边缘之间的水平位移不超过 $D_{ij}$。第二个不等式要求单元 $j$ 的底边不超过单元 $i$ 的顶边 $D_{ij}$ 以上。第三个不等式要求单元 $i$ 的底边不超过单元 $j$ 的顶边 $D_{ij}$ 以上。这三条不等式合起来等价于 $\operatorname{dist}(C_i, C_j) \le D_{ij}$。在这种情形下，我们不需要引入任何新变量。

我们可以用类似方式限制两个单元之间的 $\ell_1$-（或 $\ell_2$-）距离。这里我们引入一个新变量 $d_v$，它将作为单元之间竖直位移的界。要限制 $\ell_1$-距离，我们添加约束

```math
y_j - (y_i + h_i) \le d_v, \qquad y_i - (y_j + h_j) \le d_v, \qquad d_v \ge 0
```

以及约束

```math
x_j - (x_i + w_i) + d_v \le D_{ij}.
```

（第一项是水平位移，第二项是竖直位移的上界。）要限制两个单元之间的欧氏距离，我们把最后一个约束换成

```math
\left(x_j - (x_i + w_i)\right)^2 + d_v^2 \le D_{ij}^2.
```

<span style="color:#1e8449;">**[译注]** 这里有个**「约束的强度依赖于范数」**的细节，很容易抄错：$\operatorname{dist}(C_i,C_j) \le D_{ij}$ 是**两集合间的下确界**（最近点对），不是一个凸函数的下水平集，所以不能直接写；原文的辅助变量法把它转成「存在一点对，其距离 $\le D_{ij}$」——**这是 $\exists$ 而不是 $\forall$**，因此放松了原意（真正的 $\operatorname{dist} \le D$ 需要 min over pairs，而 min 的下水平集恰好可以用 $\exists$ 表达：$\min \|p-q\| \le D \iff \exists p,q: \|p-q\|\le D$，这一步是精确的，不是放松）。**消失测试**：$n=2$ 用 $\ell_\infty$ 时原文只用 $3$ 条不等式、$0$ 个新变量；换成 $\ell_2$ 时若照抄那 $3$ 条会得到**过强**的约束（$\ell_\infty$ 球比 $\ell_2$ 球大，$\ell_\infty$ 距离 $\le D$ 不蕴含 $\ell_2$ 距离 $\le D$），解出的 floorplan 比可行的小，可能报 infeasible；正确做法是加 $d_v$ 与二次约束 $\left(x_j-(x_i+w_i)\right)^2 + d_v^2 \le D_{ij}^2$（一条 SOC 约束）。**量的方向**：$\ell_\infty$ 到 $\ell_2$ 的范数比是 $1 \le \|\cdot\|_2/\|\cdot\|_\infty \le \sqrt2$（$n=2$），所以照抄 $\ell_\infty$ 的三条不等式在 $\ell_2$ 意义上最紧会**低估**允许位移最多 $\sqrt2$ 倍——$D_{ij}=1$ 时差 $0.414$，足以让一个本来放得下的 floorplan 被判不可行。**可复算验证**：两单元中心距要求 $\le D$，取 $D = 1$、$w_i = w_j = h_i = h_j = 0.5$，则水平间隙 $x_j - (x_i+w_i)$ 最多 $1 - 0.5 = 0.5$；若用 $\ell_1$ 版本（$d_v$ 法）且 $d_v = 0$，得到 $x_j - (x_i+w_i) \le 1$，比真实可行值 $0.5$ 松一倍——这就是 $\ell_1$ 与 $\ell_2$ 在同一 $D$ 下允许的位移不同。**落点**：Boyd §8.8.2、exercise 8.34；VLSI 侧的对照见 §8 Bibliography 的 Sherwani [She99]。</span>



（页眉：Chapter 8 Geometric problems · 原书 p.444）

### <span style="color:#c0392b;">8.8.3 Floor planning via geometric programming（通过 geometric programming 做布图规划）</span>

floor planning 问题也可以表述成以 $x_i, y_i, w_i, h_i, W, H$ 为变量的 geometric program。在这个表述中能处理的目标与约束，与能在凸表述中表达的那些略有不同。

首先我们注意到，包围盒约束 (8.35) 与相对定



（页眉：§8.8 Floor planning · 原书 p.445）

位约束 (8.34) 都是 posynomial 不等式，因为它们的左边是变量之和，而右边是单个变量，因而是 monomial。把这些不等式除以右边，就得到标准的 posynomial 不等式。

在 geometric programming 表述中，我们可以最小化包围盒面积，因为 $WH$ 是 monomial，从而是 posynomial。我们也可以精确指定每个单元的面积，因为 $w_i h_i = A_i$ 是 monomial 等式约束。另一方面，对齐、对称与距离约束无法在 geometric programming 表述中处理。但相似约束可以；事实上，可以要求一个单元与另一个单元相似，而不指定缩放比（它可以被当作又一个变量）。

<span style="color:#1e8449;">**[译注]** 这一节把 convex formulation 与 GP 的分界线划得很清楚，而这条线由**单项式的封闭性**决定：posynomial（正系数单项式之和）对加法、乘法、正幂封闭，于是判定一条约束能否进 GP 只需一句判据——取对数后是**线性**，才能进 GP 的等式；是 $\log\sum\exp$ 形状，才能进 GP 的不等式。

```math
w_i h_i = A_i \quad(\text{monomial} = \text{monomial}) \quad\Longrightarrow\quad \log w_i + \log h_i = \log A_i,
```

取对数后是线性等式，这就是 $w_i h_i = A_i$ 能在 GP 里**精确**表达的原因（凸表述里写成 $w_i \ge A_i/h_i$，二者其实同解）。同理 $WH$ 是 monomial、$W+H$ 是 posynomial，故 $\log W + \log H$ 与 $\log(e^{\log W} + e^{\log H})$ 都合法——GP 既能最小化包围盒面积，也能约束周长。

**消失测试**：alignment 进不去 GP 的真正原因是 $y_i + h_i/2 = y_j + h_j$ 取对数后**两边都是** $\log\sum\exp$ 形状，而 GP 只允许等式一侧是单个 monomial（不是「系数 $1/2$」这种表面理由）；强行写成 GP 会得到比真解更紧的可行域，可能 infeasible。**量的方向**：GP 比凸表述多处理「面积恒等式」、少处理对齐/对称/距离三类约束，即 §8.8.2 列的六类里只有最小面积与相似约束能进 GP。**可复算验证**：$w_i h_i = A_i$ 取 $w_i = 2, h_i = 3$ 得 $A_i = 6$；对 $w_i \ge A_i/h_i$ 取 $h_i = 3$ 得 $w_i \ge 2$，两式在 $w_i = 2$ 处同时取等号——说明 $\ge$ 形式与 $=$ 形式是同一可行域的两种写法。**落点**：Boyd §8.8.3、§4.5（geometric programming 的标准形与变换）、exercise 8.35；术语不译：posynomial / monomial / geometric programming。</span>

### Projection on a set（集合上的投影）

**8.1 Uniqueness of projection.** `[exercise]` Show that if $C \subseteq \mathbf{R}^n$ is nonempty, closed and convex, and the norm $\|\cdot\|$ is strictly convex, then for every $x_0$ there is exactly one $x \in C$ closest to $x_0$. In other words the projection of $x_0$ on $C$ is unique.

**话题**：严格凸范数（strictly convex norm）给投影唯一性上保险 —— 若只要求 $C$ 闭凸而范数任意（例如 $\|\cdot\|_\infty$），最近点可能是一整段面，投影变成 set-valued。

**8.2 [Web94, Val64] Chebyshev characterization of convexity.** `[exercise]` A set $C \in \mathbf{R}^n$ is called a Chebyshev set if for every $x_0 \in \mathbf{R}^n$, there is a unique point in $C$ closest (in Euclidean norm) to $x_0$. From the result in exercise 8.1, every nonempty, closed, convex set is a Chebyshev set. In this problem we show the converse, which is known as Motzkin's theorem.

Let $C \in \mathbf{R}^n$ be a Chebyshev set.

(a) Show that $C$ is nonempty and closed.

(b) Show that $P_C$, the Euclidean projection on $C$, is continuous.

(c) Suppose $x_0 \notin C$. Show that $P_C(x) = P_C(x_0)$ for all $x = \theta x_0 + (1-\theta)P_C(x_0)$ with $0 \le \theta \le 1$.

(d) Suppose $x_0 \notin C$. Show that $P_C(x) = P_C(x_0)$ for all $x = \theta x_0 + (1-\theta)P_C(x_0)$ with $\theta \ge 1$.

(e) Combining parts (c) and (d), we can conclude that all points on the ray with base $P_C(x_0)$ and direction $x_0 - P_C(x_0)$ have projection $P_C(x_0)$. Show that this implies that $C$ is convex.

**话题**：8.1 的逆命题 —— 投影唯一性反过来强制凸性。这是 Motzkin's theorem，证明骨架是「沿一条射线的投影恒定 ⇒ 集合被这条射线从外部托住 ⇒ 取两点连线不会跑出去」。

**8.3 Euclidean projection on proper cones.** `[exercise]`

(a) Nonnegative orthant. Show that Euclidean projection onto the nonnegative orthant is given by the expression on page 399.

(b) Positive semidefinite cone. Show that Euclidean projection onto the positive semidefinite cone is given by the expression on page 399.

(c) Second-order cone. Show that the Euclidean projection of $(x_0, t_0)$ on the second-order cone $K = \{(x,t) \in \mathbf{R}^{n+1} \mid \|x\|_2 \le t\}$ is given by

```math
P_K(x_0,t_0) =
\begin{cases}
(0,\,0) & \|x_0\|_2 \le -t_0 \\
(x_0,\,t_0) & \|x_0\|_2 \le t_0 \\
\dfrac{1}{2}\left(1 + \dfrac{t_0}{\|x_0\|_2}\right)\left(x_0,\, \|x_0\|_2\right) & \|x_0\|_2 \ge |t_0|
\end{cases}
```

**话题**：三类 proper cone 的投影都有闭式：非负象限是逐坐标截断 $\max(x_i,0)$，PSD 锥是特征值截断 $U\mathrm{diag}(\max(\lambda_i,0))U^T$，SOC 是三支分段公式 —— 三支恰好对应「点在锥的对偶内部 / 点在锥内 / 点在锥壁附近」。

**8.4** `[exercise]` The Euclidean projection of a point on a convex set yields a simple separating hyperplane

```math
\left(P_C(x_0) - x_0\right)^T\left(x - \tfrac{1}{2}\left(x_0 + P_C(x_0)\right)\right) = 0 .
```

Find a counterexample that shows that this construction does not work for general norms.

**话题**：投影与投影点之间的中点连线的垂直平分面分离了 $x_0$ 与 $C$ —— 这条「用二分点构造分离超平面」的技巧只对 Euclidean norm 成立，换成 $\|\cdot\|_\infty$ 就失效，因为分离超平面需要内积与范数的配对（support function 与 dual norm 的配对关系）。

**8.5 [HUL93, volume 1, page 154] Depth function and signed distance to boundary.** `[exercise]` Let $C \subseteq \mathbf{R}^n$ be a nonempty convex set, and let $\mathrm{dist}(x,C)$ be the distance of $x$ to $C$ in some norm. We already know that $\mathrm{dist}(x,C)$ is a convex function of $x$.

(a) Show that the depth function,

```math
\mathrm{depth}(x,C) = \mathrm{dist}(x,\, \mathbf{R}^n \setminus C),
```

is concave for $x \in C$.

(b) The signed distance to the boundary of $C$ is defined as

```math
s(x) =
\begin{cases}
\mathrm{dist}(x,C) & x \notin C \\
-\mathrm{depth}(x,C) & x \in C
\end{cases}
```

Thus, $s(x)$ is positive outside $C$, zero on its boundary, and negative on its interior. Show that $s$ is a convex function.

**话题**：距离函数在 $C$ 外凸、depth 在 $C$ 内凹，两者拼成的 signed distance $s$ 整体仍是凸函数 —— 这是「凸集的边界把 $\mathbf{R}^n$ 分成内外两半，而同一函数在两侧保持凸性」的一个具体样本。

<span style="color:#1e8449;">**[译注]** 8.1–8.2 这两题合在一起才是这条线的全部承重。**严格凸范数** 的定义是：$\|u\| = \|v\| = 1$、$u \ne v$、$\lambda \in (0,1)$ 时必有 $\|\lambda u + (1-\lambda)v\| \lt 1$。投影唯一性的证明只用一行：设 $x,y$ 都是最近点，则中点 $z = (x+y)/2$ 满足 $\|z - x_0\| \le (\|x-x_0\| + \|y-x_0\|)/2 = d$，等号成立必须 $x-x_0$ 与 $y-x_0$ 同向且等长，故 $x = y$。**失效对象很明确**：把二范数换成 $\|\cdot\|_\infty$，取 $C = \{(t,t) \mid t \in \mathbf{R}\}$、$x_0 = (1,-1)$，则 $\|x_0 - (t,t)\|_\infty = \max(|1-t|,|1+t|)$ 在整个 $t \in [-1,1]$ 上恒等于 $2$ —— 最近点是一整段，投影非唯一；此时 8.2(b) 要求的 $P_C$ 连续性直接崩掉（$P_C$ 成了多值映射），Motzkin 定理的证明链从第一步就断。**量的方向感**：最近点集合的维数从 $0$ 直接跳到 $1$ —— 8.2(b) 要求的连续单值映射在这种 $C$ 上根本不存在。

**落点**：Boyd §8.1.1（$C = \{x \mid Ax \preceq b,\ Fx = g\}$ 的 projection 的 QP 形式）；$\|\cdot\|_\infty$ 的反例对应 §8.1 中「projection 不是仿射不变量」的讨论；线代侧挂 Strang 的 ellipsoid 与椭球范数一节（同一件事的二次型版本）。</span>

### Distance between sets（集合间的距离）

**8.6** `[exercise]` Let $C$, $D$ be convex sets.

(a) Show that $\mathrm{dist}(C, x+D)$ is a convex function of $x$.

(b) Show that $\mathrm{dist}(tC, x+tD)$ is a convex function of $(x,t)$ for $t \gt 0$.

**话题**：(a) 是「凸函数的 infimal convolution 仍凸」的最小样本：$\mathrm{dist}(C,x+D) = \inf_{u \in C, v \in D}\|u - x - v\|$；(b) 把尺度 $t$ 也当变量后仍是凸函数（joint convexity），这是透视函数（perspective function）性质的应用。

**8.7 Separation of ellipsoids.** `[exercise]` Let $E_1$ and $E_2$ be two ellipsoids defined as

```math
E_1 = \left\{x \mid (x-x_1)^T P_1^{-1}(x-x_1) \le 1\right\}, \qquad
E_2 = \left\{x \mid (x-x_2)^T P_2^{-1}(x-x_2) \le 1\right\},
```

where $P_1, P_2 \in \mathbf{S}^n_{++}$. Show that $E_1 \cap E_2 = \varnothing$ if and only if there exists an $a \in \mathbf{R}^n$ with

```math
\left\|P_2^{1/2} a\right\|_2 + \left\|P_1^{1/2} a\right\|_2 \lt a^T(x_1 - x_2).
```

**话题**：椭球分离判据 $\Leftrightarrow$ 存在 $a$ 使「两个椭球的 support function 之和小于中心距在 $a$ 上的投影」—— 这就是用 §8.2.2 的 separation 定理把几何分离翻译成一个 SOCP feasibility。

**8.8 Intersection and containment of polyhedra.** `[exercise]` Let $P_1$ and $P_2$ be two polyhedra defined as

```math
P_1 = \{x \mid Ax \preceq b\}, \qquad P_2 = \{x \mid Fx \preceq g\},
```

with $A \in \mathbf{R}^{m \times n}$, $b \in \mathbf{R}^m$, $F \in \mathbf{R}^{p \times n}$, $g \in \mathbf{R}^p$. Explain how to carry out the tasks below by solving one or a modest number of LP feasibility problems.

(a) Find a point in the intersection $P_1 \cap P_2$.

(b) Determine whether $P_1 \subseteq P_2$.

Repeat the question for two polyhedra defined as

```math
P_1 = \mathrm{conv}\{v_1, \dots, v_K\}, \qquad P_2 = \mathrm{conv}\{w_1, \dots, w_L\},
```

with $v_1, \dots, v_K, w_1, \dots, w_L \in \mathbf{R}^n$.

**话题**：(a) 一个 LP feasibility；(b) $\preceq$ 形式的包含检验要对 $P_2$ 的每条约束解一个 LP（共 $p$ 个），而 vertex 形式换成解「每个 $v_k$ 能否写成 $w$ 的凸组合」的 $K$ 个 LP —— 两种表示的对偶性（H-representation vs V-representation）决定的是 LP 个数而不是难度。

**8.9 Closest Euclidean distance matrix to given data.** `[exercise]` We are given data $\hat d_{ij}$, for $i,j = 1,\dots,n$, which are corrupted measurements of the Euclidean distances between vectors in $\mathbf{R}^k$:

```math
\hat d_{ij} = \|x_i - x_j\|_2 + v_{ij}, \qquad i,j = 1,\dots,n,
```

where $v_{ij}$ is some noise or error. These data satisfy $\hat d_{ij} \ge 0$ and $\hat d_{ij} = \hat d_{ji}$, for all $i,j$. The dimension $k$ is not specified.

Show how to solve the following problem using convex optimization. Find a dimension $k$ and $x_1,\dots,x_n \in \mathbf{R}^k$ so that $\sum_{i,j=1}^{n}(d_{ij} - \hat d_{ij})^2$ is minimized, where $d_{ij} = \|x_i - x_j\|_2$, $i,j = 1,\dots,n$. In other words, given some data that are approximate Euclidean distances, you are to find the closest set of actual Euclidean distances, in the least-squares sense.

**话题**：这是 EDM（Euclidean distance matrix）的最近点问题。直接对 $x$ 做 least-squares 是非凸的，正确路线是把 $d_{ij}^2$ 写成 Gram 矩阵的线性泛函 $d_{ij}^2 = G_{ii} + G_{jj} - 2G_{ij}$，松弛成「$G \succeq 0$ + 线性目标」的 SDP。

**8.10 Minimax angle fitting.** `[exercise]` Suppose that $y_1,\dots,y_m \in \mathbf{R}^k$ are affine functions of a variable $x \in \mathbf{R}^n$:

```math
y_i = A_i x + b_i, \qquad i = 1,\dots,m,
```

and $z_1,\dots,z_m \in \mathbf{R}^k$ are given nonzero vectors. We want to choose the variable $x$, subject to some convex constraints, (e.g., linear inequalities) to minimize the maximum angle between $y_i$ and $z_i$,

```math
\max\left\{\angle(y_1,z_1),\ \dots,\ \angle(y_m,z_m)\right\}.
```

The angle between nonzero vectors is defined as usual:

```math
\angle(u,v) = \cos^{-1}\left(\frac{u^T v}{\|u\|_2 \|v\|_2}\right),
```

where we take $\cos^{-1}(a) \in [0,\pi]$. We are only interested in the case when the optimal objective value does not exceed $\pi/2$. Formulate this problem as a convex or quasiconvex optimization problem. When the constraints on $x$ are linear inequalities, what kind of problem (or problems) do you have to solve?

**话题**：把「角度」上的 minimax 转成 quasiconvex 问题：$\angle(y_i,z_i) \le \theta$ 在 $\theta \le \pi/2$ 时等价于 $y_i^T z_i \ge \cos\theta \cdot \|y_i\|_2\|z_i\|_2$ 且 $y_i^T z_i \ge 0$，后者是 SOC 约束；因此解法是对 $\theta$ 做二分 + 每步一个 SOCP。

**8.11 Smallest Euclidean cone containing given points.** `[exercise]` In $\mathbf{R}^n$, we define a Euclidean cone, with center direction $c \ne 0$, and angular radius $\theta$, with $0 \le \theta \le \pi/2$, as the set

```math
\{x \in \mathbf{R}^n \mid \angle(c,x) \le \theta\}.
```

(A Euclidean cone is a second-order cone, i.e., it can be represented as the image of the second-order cone under a nonsingular linear mapping.)

Let $a_1,\dots,a_m \in \mathbf{R}^n$. How would you find the Euclidean cone, of smallest angular radius, that contains $a_1,\dots,a_m$? (In particular, you should explain how to solve the feasibility problem, i.e., how to determine whether there is a Euclidean cone which contains the points.)

### Extremal volume ellipsoids（极值体积椭球）

**8.12** `[exercise]` Show that the maximum volume ellipsoid enclosed in a set is unique. Show that the Löwner-John ellipsoid of a set is unique.

**话题**：唯一性来自 $\log\det$ 的严格凹性 —— 若两个最大体积椭球并列，它们的「几何平均」体积相同且仍包含在内，违反正定性下的严格凹。

**8.13 Löwner-John ellipsoid of a simplex.** `[exercise]` In this exercise we show that the Löwner-John ellipsoid of a simplex in $\mathbf{R}^n$ must be shrunk by a factor $n$ to fit inside the simplex. Since the Löwner-John ellipsoid is affinely invariant, it is sufficient to show the result for one particular simplex. Derive the Löwner-John ellipsoid $E_{\mathrm{lj}}$ for the simplex $C = \mathrm{conv}\{0, e_1,\dots,e_n\}$. Show that $E_{\mathrm{lj}}$ must be shrunk by a factor $1/n$ to fit inside the simplex. †

**话题**：单位 simplex 的最小外接椭球是球心 $c = \frac{1}{n+1}\mathbf{1}$、半径 $r = \frac{\sqrt{n}}{n+1}$ 的球（即 $\mathbf{S}^n_{++}$ 里 $A = r^2 I$），把它按中心缩 $n$ 倍才落进 simplex —— 这个 $n$ 就是 John's theorem 里 polytope 情形的最坏因子。† 题干第一句写「shrunk by a factor $n$」、最后一句写「by a factor $1/n$」，两句方向相反；按标准结论（$C \subseteq E$ 且 $\frac{1}{n}E \subseteq C$）应为**缩到 $1/n$**，此处原文用词不一致。

(b) Show that if $C$ is symmetric about the origin, i.e., of the form $C = \{x \mid -\mathbf{1} \preceq Ax \preceq \mathbf{1}\}$, then expanding the maximum volume inscribed ellipsoid by a factor $\sqrt n$ gives an ellipsoid that contains $C$.

**话题**：8.13 的逆向使用 —— 内切椭球放大 $n$ 倍就外接（一般凸体）、对称情形只需 $\sqrt n$。这给出「用椭球代替多面体」时体积误差的上界：整体从 $1/n$ 的线性因子变成 $\sqrt n$ 的平方根因子。

**8.16 Maximum volume rectangle inside a polyhedron.** `[exercise]` Formulate the following problem as a convex optimization problem. Find the rectangle

```math
R = \{x \in \mathbf{R}^n \mid l \preceq x \preceq u\}
```

## 9 Unconstrained minimization（第 9 章 无约束极小化）

### 9.1 Unconstrained minimization problems（无约束极小化问题）

本章讨论求解 unconstrained optimization problem（无约束优化问题）的方法：

**式 (9.1)**
```math
\text{minimize} \quad f(x)
```

其中 $f : \mathbf{R}^n \to \mathbf{R}$ 是 convex 且 twice continuously differentiable（二次连续可微）的 —— 这蕴含 $\mathrm{dom}\,f$ 是开集。我们假定问题是 solvable（可解）的，即存在 optimal point（最优点）$x^\star$。（更精确地说，本章后面引入的假设会蕴含 $x^\star$ 存在并且唯一。）最优值记作 $p^\star = \inf_x f(x) = f(x^\star)$。

由于 $f$ 可微且 convex，$x^\star$ 最优的 necessary and sufficient condition（充要条件）是

**式 (9.2)**
```math
\nabla f(x^\star) = 0
```

（见 §4.2.3）。于是，求解无约束极小化问题 (9.1) 等价于求 (9.2) 的解 —— 后者是关于 $n$ 个变量 $x_1,\dots,x_n$ 的 $n$ 个方程。

在少数特殊情形里，我们可以通过解析地求解 optimality equation（最优性方程）(9.2) 得到 (9.1) 的解，但通常问题必须用 iterative algorithm（迭代算法）求解。所谓迭代算法，是指计算一个点列 $x^{(0)}, x^{(1)}, \dots \in \mathrm{dom}\,f$，使得 $k \to \infty$ 时 $f(x^{(k)}) \to p^\star$。这样的点列称为问题 (9.1) 的 minimizing sequence（极小化序列）。算法在

```math
f(x^{(k)}) - p^\star \le \varepsilon
```

时终止，其中 $\varepsilon \gt 0$ 是某个指定的 tolerance（容差）。

#### Initial point and sublevel set（初始点与下水平集）

本章描述的方法都需要一个合适的 starting point（初始点）$x^{(0)}$。这个起点必须落在 $\mathrm{dom}\,f$ 里，并且 sublevel set（下水平集）

**式 (9.3)**
```math
S = \left\{x \in \mathrm{dom}\,f \mid f(x) \le f(x^{(0)})\right\}
```

必须是闭的。若函数 $f$ 是 closed（闭函数），即它的所有 sublevel set 都闭（见 §A.3.3），则该条件对每个 $x^{(0)} \in \mathrm{dom}\,f$ 都满足。

$\mathrm{dom}\,f = \mathbf{R}^n$ 的连续函数都是闭的，因此当 $\mathrm{dom}\,f = \mathbf{R}^n$ 时，初始 sublevel set 条件对任意 $x^{(0)}$ 都成立。另一类重要的闭函数是定义域为开集的连续函数，并且当 $x$ 逼近 $\mathrm{bd}\,\mathrm{dom}\,f$ 时 $f(x)$ 趋于无穷。

#### 9.1.1 Examples（例子）

**Quadratic minimization and least-squares（二次极小化与最小二乘）**

一般的 convex quadratic minimization problem（凸二次极小化问题）形如

**式 (9.4)**
```math
\text{minimize} \quad \tfrac{1}{2}x^T P x + q^T x + r,
```

其中 $P \in \mathbf{S}^n_+$、$q \in \mathbf{R}^n$、$r \in \mathbf{R}$。这个问题可以通过最优性条件 $Px^\star + q = 0$ 求解，后者是一组线性方程。当 $P \succ 0$ 时存在唯一解 $x^\star = -P^{-1}q$。在更一般的情形（$P$ 不必正定）下，任何满足 $Px^\star = -q$ 的 $x^\star$ 都是 (9.4) 的最优解；若 $Px^\star = -q$ 无解，则问题 (9.4) 下方无界（见习题 9.1）。我们能够解析地求解二次极小化问题 (9.4)，这一点正是 Newton's method（牛顿法）的基础 —— 后者是 §9.5 描述的一个强有力的无约束极小化方法。

二次极小化问题中出现得非常频繁的一个特例是 least-squares problem（最小二乘问题）：

```math
\text{minimize} \quad \|Ax - b\|_2^2 = x^T\left(A^TA\right)x - 2\left(A^Tb\right)^T x + b^Tb .
```

其最优性条件

```math
A^TAx^\star = A^Tb
```

称为最小二乘问题的 normal equations（正规方程）。

**Unconstrained geometric programming（无约束几何规划）**

作为第二个例子，考虑 convex form（凸形式）的无约束 geometric program（几何规划）：

```math
\text{minimize} \quad f(x) = \log\left(\sum_{i=1}^{m}\exp\left(a_i^T x + b_i\right)\right).
```

最优性条件是

```math
\nabla f(x^\star) = \frac{1}{\sum_{j=1}^{m}\exp\left(a_j^T x^\star + b_j\right)}\sum_{i=1}^{m}\exp\left(a_i^T x^\star + b_i\right)a_i = 0,
```

它一般没有解析解，因此这里必须改用迭代算法。对这个目标函数 $\mathrm{dom}\,f = \mathbf{R}^n$，所以任意点都可以选作初始点 $x^{(0)}$。

**Analytic center of linear inequalities（线性不等式的解析中心）**

考虑优化问题

**式 (9.5)**
```math
\text{minimize} \quad f(x) = -\sum_{i=1}^{m}\log\left(b_i - a_i^T x\right),
```

其中 $f$ 的定义域是开集

#### 9.1.2 Strong convexity and implications（强凸性及其推论）

本章的绝大部分（§9.6 除外）都假定目标函数在 $S$ 上是 strongly convex（强凸）的，意思是存在常数 $m \gt 0$ 使

**式 (9.7)**
```math
\nabla^2 f(x) \succeq mI
```

对所有 $x \in S$ 成立。强凸性有几个有意思的推论。对 $x, y \in S$，有

```math
f(y) = f(x) + \nabla f(x)^T(y - x) + \tfrac{1}{2}(y-x)^T\nabla^2 f(z)(y-x),
```

其中 $z$ 落在线段 $[x,y]$ 上。由强凸性假设 (9.7)，右端最后一项至少是 $(m/2)\|y-x\|_2^2$，于是得到不等式

**式 (9.8)**
```math
f(y) \ge f(x) + \nabla f(x)^T(y-x) + \tfrac{m}{2}\|y-x\|_2^2
```

对 $S$ 中所有 $x$ 与 $y$ 成立。当 $m = 0$ 时，(9.8) 还原为刻画凸性的基本不等式；当 $m \gt 0$ 时，我们得到比单靠凸性更强的 $f(y)$ 下界。

我们先说明不等式 (9.8) 可以用来把 $f(x) - p^\star$（即点 $x$ 的 suboptimality，次优量）用 $\|\nabla f(x)\|_2$ 界住。(9.8) 的右端（固定 $x$ 时）是 $y$ 的凸二次函数。让它对 $y$ 的梯度等于零，求得 $\tilde y = x - (1/m)\nabla f(x)$ 最小化右端。因此

```math
\begin{array}{rcl}
f(y) & \ge & f(x) + \nabla f(x)^T(y-x) + \dfrac{m}{2}\|y-x\|_2^2 \\
& \ge & f(x) + \nabla f(x)^T(\tilde y - x) + \dfrac{m}{2}\|\tilde y - x\|_2^2 \\
& = & f(x) - \dfrac{1}{2m}\|\nabla f(x)\|_2^2 .
\end{array}
```

由于这对任意 $y \in S$ 成立，我们有

**式 (9.9)**
```math
p^\star \ge f(x) - \frac{1}{2m}\|\nabla f(x)\|_2^2 .
```

这个不等式表明：若某点处梯度很小，则该点近似最优。不等式 (9.9) 也可以解读为次优性的一个判据，它推广了最优性条件 (9.2)：

**式 (9.10)**
```math
\|\nabla f(x)\|_2 \le (2m\varepsilon)^{1/2} \;\Longrightarrow\; f(x) - p^\star \le \varepsilon .
```

我们还可以用 $\|\nabla f(x)\|_2$ 界住 $\|x - x^\star\|_2$，即 $x$ 与任一最优点 $x^\star$ 之间的距离：

**式 (9.11)**
```math
\|x - x^\star\|_2 \le \frac{2}{m}\|\nabla f(x)\|_2 .
```

为看出这一点，把 (9.8) 用于 $y = x^\star$，得

```math
\begin{array}{rcl}
p^\star = f(x^\star) & \ge & f(x) + \nabla f(x)^T(x^\star - x) + \dfrac{m}{2}\|x^\star - x\|_2^2 \\
& \ge & f(x) - \|\nabla f(x)\|_2\|x^\star - x\|_2 + \dfrac{m}{2}\|x^\star - x\|_2^2,
\end{array}
```

其中第二个不等号用了 Cauchy-Schwarz inequality。由于 $p^\star \le f(x)$，必须有

```math
-\|\nabla f(x)\|_2\|x^\star - x\|_2 + \frac{m}{2}\|x^\star - x\|_2^2 \le 0,
```

(9.11) 由此推出。(9.11) 的一个推论是：最优点 $x^\star$ 是唯一的。

#### Upper bound on $\nabla^2 f(x)$（Hessian 的上界）

不等式 (9.8) 蕴含含于 $S$ 内的 sublevel set 都是有界的，因此特别地 $S$ 有界。于是 $\nabla^2 f(x)$ 的最大 eigenvalue（它是 $x$ 在 $S$ 上的连续函数）在 $S$ 上有上界，即存在常数 $M$ 使

**式 (9.12)**
```math
\nabla^2 f(x) \preceq MI
```

<span style="color:#1e8449;">**[译注]** (9.8)–(9.11) 这一串才是 §9.1.2 的技术承重：它把**不可观测的量**换成**可计算的量**。$f(x) - p^\star$ 是真正的次优量，但 $p^\star$ 未知，任何实现都算不出它；而 $\|\nabla f(x)\|_2$ 每一轮都能算。中间那座桥就是 (9.8) 右端对 $y$ 的配平方：$\tilde y = x - (1/m)\nabla f(x)$ 处取得最小值 $-(1/(2m))\|\nabla f(x)\|_2^2$，于是 $p^\star \ge f(x) - \frac{1}{2m}\|\nabla f(x)\|_2^2$，误差的绝对尺度被 $1/(2m)$ 定死。

**落点**：Boyd §9.1.2 式 (9.9)–(9.11)；§9.6（self-concordant 给出不依赖未知常数的收敛分析）；§4.2.3（(9.2) 的充要性）；EE364a 中对同一式子的「梯度停止准则」讨论。</span>

#### Condition number of sublevel sets（下水平集的条件数）

由强凸性不等式 (9.7) 与不等式 (9.12)，我们得到

**式 (9.15)**
```math
mI \preceq \nabla^2 f(x) \preceq MI
```

对所有 $x \in S$ 成立。于是比值 $\kappa = M/m$ 是矩阵 $\nabla^2 f(x)$ 的 condition number（条件数）的一个上界 —— 所谓条件数，即其最大 eigenvalue 与最小 eigenvalue 之比。我们也可以给 (9.15) 一个用 $f$ 的 sublevel set 表述的几何解释。

对一个凸集 $C \subseteq \mathbf{R}^n$，定义它在方向 $q$ 上的 width（宽度），其中 $\|q\|_2 = 1$：

```math
W(C,q) = \sup_{z \in C} q^Tz - \inf_{z \in C} q^Tz .
```

$C$ 的最小宽度与最大宽度分别是

```math
W_{\min} = \inf_{\|q\|_2 = 1} W(C,q), \qquad W_{\max} = \sup_{\|q\|_2 = 1} W(C,q) .
```

凸集 $C$ 的 condition number 定义为

```math
\mathrm{cond}(C) = \frac{W_{\max}^2}{W_{\min}^2},
```

即最大宽度与最小宽度之比的平方。$C$ 的条件数度量它的 anisotropy（各向异性）或 eccentricity（离心率）。若一个集合 $C$ 的条件数很小（比如说接近一），意味着它在所有方向上宽度大致相同，即几乎是球形的；若条件数很大，意味着它在某些方向上比另一些方向宽得多。

**例 9.1 椭球的条件数。** 设 $E$ 是椭球

```math
E = \left\{x \mid (x-x_0)^T A^{-1}(x-x_0) \le 1\right\},
```

其中 $A \in \mathbf{S}^n_{++}$。$E$ 在方向 $q$ 上的宽度是

```math
\begin{array}{rcl}
\sup_{z \in E} q^Tz - \inf_{z \in E} q^Tz & = & \left(\|A^{1/2}q\|_2 + q^Tx_0\right) - \left(-\|A^{1/2}q\|_2 + q^Tx_0\right) \\
& = & 2\|A^{1/2}q\|_2 .
\end{array}
```

#### The strong convexity constants（强凸性常数）

必须记住：常数 $m$ 与 $M$ 只在很少的情形下是已知的，因此不等式 (9.10) 不能当作实用的停止准则使用。它可以被视为一个 conceptual stopping criterion（概念性停止准则）：它说明若 $f$ 在 $x$ 处的梯度足够小，则 $f(x)$ 与 $p^\star$ 之差也小。若我们在 $\|\nabla f(x^{(k)})\|_2 \le \eta$ 时终止算法，而 $\eta$ 取得足够小、使得它（极有可能）小于 $(m\varepsilon)^{1/2}$，那么就有 $f(x^{(k)}) - p^\star \le \varepsilon$（极有可能）。

在接下来几节里，我们给出算法的收敛性证明，其中包含「在 $f(x^{(k)}) - p^\star \le \varepsilon$ 之前需要的迭代次数」的界，$\varepsilon$ 是某个正的 tolerance。这些界里很多都涉及（通常未知的）常数 $m$ 与 $M$，所以上面的评注同样适用。这些结果至少在概念上是有用的：它们确立了算法确实收敛，即便达到给定精度所需迭代次数的界依赖未知常数。

我们会遇到这种情况的一个重要例外。在 §9.6 中我们会研究一类特殊的凸函数，称为 self-concordant（自和谐），对它们可以给出完全不依赖任何未知常数的完整收敛分析（针对 Newton's method）。

### 9.2 Descent methods（下降方法）

本章描述的算法产生极小化序列 $x^{(k)}$，$k = 1,\dots$，其中

```math
x^{(k+1)} = x^{(k)} + t^{(k)}\Delta x^{(k)}
```

且 $t^{(k)} \gt 0$（$x^{(k)}$ 已最优时除外）。这里把拼在一起的符号 $\Delta$ 与 $x$ 读作单一实体，即一个 $\mathbf{R}^n$ 中的向量，称为 step（步）或 search direction（搜索方向）（尽管它的范数不必为一）；$k = 0,1,\dots$ 表示迭代序号。标量 $t^{(k)} \ge 0$ 称为第 $k$ 次迭代的 step size（步长）或 step length（步长）（尽管除非 $\|\Delta x^{(k)}\| = 1$，它并不等于 $\|x^{(k+1)} - x^{(k)}\|$）。「search step」与「scale factor」是更准确的叫法，但被广泛使用的是「search direction」与「step length」。当我们只关注算法的某一次迭代时，有时会省掉上标，用更轻的记号 $x^+ = x + t\Delta x$，或 $x := x + t\Delta x$，来代替 $x^{(k+1)} = x^{(k)} + t^{(k)}\Delta x^{(k)}$。

我们研究的全部方法都是 descent method（下降方法），意思是

```math
f(x^{(k+1)}) \lt f(x^{(k)}),
```

除 $x^{(k)}$ 已最优的情形。这蕴含对一切 $k$ 有 $x^{(k)} \in S$（初始 sublevel set），特别地 $x^{(k)} \in \mathrm{dom}\,f$。由凸性知 $\nabla f(x^{(k)})^T(y - x^{(k)}) \ge 0$ 蕴含 $f(y) \ge f(x^{(k)})$，因此下降方法中的搜索方向必须满足

```math
\nabla f(x^{(k)})^T \Delta x^{(k)} \lt 0,
```

也就是说，它必须与负梯度成锐角。我们称这样的方向为（$f$ 在 $x^{(k)}$ 处的）descent direction（下降方向）。

---

一般 descent method 的轮廓如下。它在两步之间交替：确定一个下降方向 $\Delta x$，以及选定一个步长 $t$。

**Algorithm 9.1 General descent method（一般下降方法）。**
```
given a starting point x in dom f.
repeat
1. Determine a descent direction Delta x.
2. Line search. Choose a step size t > 0.
3. Update. x := x + t Delta x.
until stopping criterion is satisfied.
```

第二步称为 line search（线搜索），因为步长 $t$ 的选取决定了下一个迭代点落在直线 $\{x + t\Delta x \mid t \in \mathbf{R}_+\}$ 的哪个位置。（更准确的叫法也许是 ray search，射线搜索。）

实用的下降方法具有相同的一般结构，但组织方式可能不同。例如，停止准则常常在计算下降方向 $\Delta x$ 的过程中或紧接着之后检查。如次优性条件 (9.9) 所示，停止准则常常取 $\|\nabla f(x)\|_2 \le \eta$ 的形式，其中 $\eta$ 是小的正数。

#### Exact line search（精确线搜索）

实践中偶尔使用的一种线搜索方法是 exact line search（精确线搜索），其中 $t$ 取为使 $f$ 沿射线 $\{x + t\Delta x \mid t \ge 0\}$ 最小的值：

**式 (9.16)**
```math
t = \arg\min_{s \ge 0} f(x + s\Delta x).
```

当 (9.16) 所需的单变量极小化问题的代价相对于计算搜索方向本身的代价较低时，就采用精确线搜索。在某些特殊情形下，沿射线的最小点可以解析地求出；在另一些情形下则可以高效地计算。（§9.7.1 对此有讨论。）

#### Backtracking line search（回溯线搜索）

实践中使用的线搜索大多是不精确的：步长被选为使 $f$ 沿射线 $\{x + t\Delta x \mid t \ge 0\}$ 近似最小，或者只是让 $f$「足够地」下降。已经提出过许多不精确线搜索方法。其中一种非常简单且相当有效的方法称为 backtracking line search（回溯线搜索）。它依赖两个常数 $\alpha, \beta$，满足 $0 \lt \alpha \lt 0.5$、$0 \lt \beta \lt 1$。

**Algorithm 9.2 Backtracking line search（回溯线搜索）。**
```
given a descent direction Delta x for f at x in dom f, alpha in (0, 0.5), beta in (0, 1).
t := 1.
while f(x + t Delta x) > f(x) + alpha t grad f(x)^T Delta x,
t := beta t.
```
