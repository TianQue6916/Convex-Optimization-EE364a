line search 之所以叫 backtracking（回溯），是因为它从单位步长开始，然后按因子 $\beta$ 不断缩减，直到停止条件 $f(x + t\Delta x) \le f(x) + \alpha t\nabla f(x)^T\Delta x$ 成立。由于 $\Delta x$ 是下降方向，有 $\nabla f(x)^T\Delta x \lt 0$，所以对足够小的 $t$，

```math
f(x + t\Delta x) \approx f(x) + t\nabla f(x)^T\Delta x \lt f(x) + \alpha t\nabla f(x)^T\Delta x,
```

这表明回溯线搜索终究会终止。常数 $\alpha$ 可以解释为：线性外推所预测的 $f$ 的下降量中，我们愿意接受的那个比例。（要求 $\alpha$ 小于 $0.5$ 的理由后面会变得清楚。）

回溯条件在 Figure 9.1 中给出图示。这张图提示（并且可以证明）：回溯退出不等式 $f(x + t\Delta x) \le f(x) + \alpha t\nabla f(x)^T\Delta x$ 对 $t \ge 0$ 在一个区间 $(0, t_0]$ 上成立。由此可知回溯线搜索停止时的步长 $t$ 满足

```math
t = 1, \qquad \text{或} \qquad t \in (\beta t_0,\, t_0] .
```

第一种情形出现在步长 $t = 1$ 满足回溯条件时，即 $1 \le t_0$。特别地，我们可以说回溯线搜索得到的步长满足

**式 (9.18)**
```math
t \ge \min\{1,\, \beta t_0\} .
```

当 $\mathrm{dom}\,f$ 不是整个 $\mathbf{R}^n$ 时，回溯线搜索中的条件 $f(x + t\Delta x) \le f(x) + \alpha t\nabla f(x)^T\Delta x$ 必须小心解读。按照我们的约定（$f$ 在其定义域外取无穷大），这个不等式蕴含 $x + t\Delta x \in \mathrm{dom}\,f$。在实际实现中，我们先反复把 $t$ 乘 $\beta$，直到 $x + t\Delta x \in \mathrm{dom}\,f$；

### 9.3 Gradient descent method（梯度下降法）

搜索方向的一个自然选择是负梯度 $\Delta x = -\nabla f(x)$。由此得到的算法称为 gradient algorithm（梯度算法）或 gradient descent method（梯度下降法）。

**Algorithm 9.3 Gradient descent method（梯度下降法）。**
```
given a starting point x in dom f.
repeat
1. Delta x := -grad f(x).
2. Line search. Choose step size t via exact or backtracking line search.
3. Update. x := x + t Delta x.
until stopping criterion is satisfied.
```

停止准则通常取 $\|\nabla f(x)\|_2 \le \eta$ 的形式，其中 $\eta$ 是小的正数。在大多数实现中，这个条件在第 1 步之后检查，而不是更新之后检查。

#### 9.3.1 Convergence analysis（收敛性分析）

本节给出梯度法的一个简单收敛性分析，其中使用更轻的记号 $x^+ = x + t\Delta x$ 代替 $x^{(k+1)} = x^{(k)} + t^{(k)}\Delta x^{(k)}$，且 $\Delta x = -\nabla f(x)$。我们假定 $f$ 在 $S$ 上强凸，于是存在正常数 $m$ 与 $M$ 使 $mI \preceq \nabla^2 f(x) \preceq MI$ 对所有 $x \in S$ 成立。定义函数 $\tilde f : \mathbf{R} \to \mathbf{R}$ 为 $\tilde f(t) = f(x - t\nabla f(x))$，即把 $f$ 看成沿负梯度方向的步长 $t$ 的函数。下面的讨论中我们只考虑使 $x - t\nabla f(x) \in S$ 的 $t$。由不等式 (9.13)（取 $y = x - t\nabla f(x)$），得到 $\tilde f$ 的一个二次上界：

**式 (9.17)**
```math
\tilde f(t) \le f(x) - t\|\nabla f(x)\|_2^2 + \frac{Mt^2}{2}\|\nabla f(x)\|_2^2 .
```

**Analysis for exact line search（精确线搜索的分析）**

现在假定使用精确线搜索，把不等式 (9.17) 的两边对 $t$ 取极小。左端得到 $\tilde f(t_{\mathrm{exact}})$，其中 $t_{\mathrm{exact}}$ 是

<span style="color:#1e8449;">**[译注]** $\alpha \lt 0.5$ 这个约束不是风格选择，它只做一件事：**让步长下界与 $\alpha$ 脱钩**。把 (9.17) 与回溯接受条件相减即可看出机制。梯度方向下 $\nabla f(x)^T\Delta x = -\|\nabla f(x)\|_2^2$，于是 (9.17) 右端比 $f(x)$ 少了 $t\|\nabla f\|^2 - \frac{Mt^2}{2}\|\nabla f\|^2$，而回溯要求它至少少 $\alpha t\|\nabla f\|^2$；两式相除时约掉 $\|\nabla f\|^2$，得充分条件

```math
t \le \frac{2(1-\alpha)}{M} .
```

所以在区间 $(0, \min\{1, 2(1-\alpha)/M\}]$ 上回溯条件必然成立，即 $t_0 \ge \min\{1, 2(1-\alpha)/M\}$。当且仅当 $\alpha \lt 0.5$ 时有 $2(1-\alpha) \gt 1$，从而 $t_0 \ge \min\{1, 1/M\}$，代回 (9.18) 得到与 $\alpha$ 无关的下界 $t \ge \beta\min\{1, 1/M\}$。

**失效对象**：取 $\alpha = 0.9$（读代码的人常随手把 α 调到接近 1 以求「更省步数」），下界塌成 $0.2\beta/M$，比 $\alpha = 0.3$ 时（$\beta \cdot \min\{1, 1.4/M\} = \beta/M$）**差 5 倍**；每步下降量 $\alpha t\|\nabla f\|^2$ 的正系数随之缩水，收敛率证明里的 $\frac{1}{t}$ 不再有统一常数。实测后果不是发散，而是「收敛慢到你以为卡住」——比报错更难查。

**落点**：Boyd §9.3.1（backtracking 情形的定理，式中出现 $\alpha$ 与 $\beta$）；§9.5.1（Newton decrement 版本，同样的 $\alpha \lt 1/2$ 条件）；(9.18) 本身。</span>

使 $\tilde{f}$ 取最小的那个 step length（步长）。右端是一个简单的 quadratic（二次式），它在 $t = 1/M$ 处取极小，最小值为 $f(x) - \dfrac{1}{2M}\|\nabla f(x)\|_2^2$。因此有

```math
f(x^{+}) = \tilde{f}(t_{\text{exact}}) \le f(x) - \frac{1}{2M}\|\nabla f(x)\|_2^2.
```

两边同时减去 $p^{\star}$，得

```math
f(x^{+}) - p^{\star} \le f(x) - p^{\star} - \frac{1}{2M}\|\nabla f(x)\|_2^2.
```

把它与 $\|\nabla f(x)\|_2^2 \ge 2m\,(f(x) - p^{\star})$（该式由 (9.9) 推出）合并，可得

```math
f(x^{+}) - p^{\star} \le \left(1 - \frac{m}{M}\right)\bigl(f(x) - p^{\star}\bigr).
```

把这个不等式递归地施加下去，就得到

```math
f(x^{(k)}) - p^{\star} \le c^{k}\bigl(f(x^{(0)}) - p^{\star}\bigr), \qquad (9.18)
```

其中 $c = 1 - m/M \lt 1$。这条式子说明 $f(x^{(k)})$ 当 $k \to \infty$ 时收敛到 $p^{\star}$。特别地，用 exact line search（精确线搜索）的 gradient method，至多经过

```math
\frac{\log\bigl((f(x^{(0)}) - p^{\star})/\epsilon\bigr)}{\log(1/c)} \qquad (9.19)
```

次迭代，就必有 $f(x^{(k)}) - p^{\star} \le \epsilon$。

这个关于所需迭代次数的界虽然粗糙，但仍能对 gradient method 给出一些洞见。分子

```math
\log\bigl((f(x^{(0)}) - p^{\star})/\epsilon\bigr)
```

可以解释成「初始次优性（即 $f(x^{(0)})$ 与 $p^{\star}$ 之间的 gap）与最终次优性（即小于 $\epsilon$）」之比的对数。这一项说明迭代次数取决于初始点有多好，以及最终要求多高的精度。

出现在界 (9.19) 中的分母 $\log(1/c)$ 是 $M/m$ 的函数；而我们已经看到，$M/m$ 是 $\nabla^{2}f(x)$ 在 $S$ 上的 condition number（条件数）的一个界，也是 sublevel set（下水平集）$\{z \mid f(z) \le \alpha\}$ 的 condition number 的一个界。当 condition number 的界 $M/m$ 很大时，

```math
\log(1/c) = -\log(1 - m/M) \approx m/M,
```

于是我们得到的所需迭代次数上界，随 $M/m$ 的增大而近似**线性**地增长。

后面我们会看到，当 $f$ 的 Hessian（Hessian 矩阵）在 $x^{\star}$ 附近具有很大的 condition number 时，gradient method 确实需要很多次迭代。反过来，当 $f$ 的 sublevel set 比较各向同性（isotropic），因而 condition number 的界 $M/m$ 可以取得比较小时，界 (9.18) 说明收敛很快，因为此时 $c$ 很小，或者至少不接近 1。

界 (9.18) 说明误差 $f(x^{(k)}) - p^{\star}$ 至少以等比级数（geometric series）的速度收敛到零。在迭代数值方法的语境里，这被称作 linear convergence（线性收敛），因为在「误差对迭代次数」的 log-linear 图上，误差落在那条直线之下。

<span style="color:#1e8449;">**[译注]** 这里的 linear convergence 是一处高频误读点，值得钉死：它说的**不是**误差每步减少一个固定量（那才是中文语境里「线性」的直觉），而是误差每步乘以一个固定因子 $c \lt 1$。在 log-linear 图上取对数，$\log\bigl(f(x^{(k)})-p^{\star}\bigr) \le k\log c + \text{const}$，右边的 $k$ 系数是常数，**所以画出来是直线**——直线来自对数坐标，而不是来自误差本身。失效对象很具体：如果把 (9.18) 读成「每步减掉一个固定的绝对量 $(1-c)\cdot\text{gap}_0$」，那么当 $c = 0.9$、初始 gap 为 $10^{3}$ 时，你会算出每步减 $100$、**10 步就把 gap 打到 0**，于是预测「10 次迭代收敛」；而真实是指数衰减，要把 gap 从 $10^{3}$ 压到 $10^{-6}$（跨 9 个数量级）需要 $k \approx \ln(10^{-9})/\ln(0.9) \approx 196.7$，即约 197 步——**错误读法把迭代数低估了 20 倍，而且方向是乐观的**（你以为 10 次跑完，实际跑了 197 次）。反过来看另一端：$k = 1000$ 时的真实 gap 是 $10^{3}\times 0.9^{1000} \approx 10^{-43}$，早已把要求甩开几十个数量级。这个区分在工程上承重于「迭代预算」：convex optimization 的 solver 里，`stopping criterion` 通常就是按 gap 降到 $\epsilon$ 相对初始 gap 的比值来判断的，Boyd §9.3.1 与 §11.3 的 barrier method 阶段估计都直接复用 (9.19)。落点：Boyd §9.3.1（本页）、式 (9.18)/(9.19)、exercise 9.5。</span>

### Analysis for backtracking line search（backtracking line search 下的分析）

现在考虑在 gradient descent method 中使用 backtracking line search 的情形。我们将会证明：只要 $0 \le t \le 1/M$，backtracking 的退出条件

```math
\tilde{f}(t) \le f(x) - \alpha t\|\nabla f(x)\|_2^2
```

就一定成立。首先注意到

```math
0 \le t \le 1/M \;\Longrightarrow\; -t + \frac{Mt^{2}}{2} \le -t/2
```

（这由 $-t + Mt^{2}/2$ 的凸性推出）。利用这个结果以及界 (9.17)，对 $0 \le t \le 1/M$ 我们有

```math
\begin{aligned}
\tilde{f}(t) &\le f(x) - t\|\nabla f(x)\|_2^2 + \frac{Mt^{2}}{2}\|\nabla f(x)\|_2^2 \\
&\le f(x) - (t/2)\|\nabla f(x)\|_2^2 \\
&\le f(x) - \alpha t\|\nabla f(x)\|_2^2,
\end{aligned}
```

最后一步用到 $\alpha \lt 1/2$。因此，backtracking line search 要么以 $t = 1$ 终止，要么以某个 $t \ge \beta/M$ 终止。这给出了目标函数下降量的一个下界。第一种情形下

```math
f(x^{+}) \le f(x) - \alpha\|\nabla f(x)\|_2^2,
```

第二种情形下

```math
f(x^{+}) \le f(x) - (\beta\alpha/M)\|\nabla f(x)\|_2^2.
```

把这两种情形合在一起，我们总有

```math
f(x^{+}) \le f(x) - \min\{\alpha,\; \beta\alpha/M\}\,\|\nabla f(x)\|_2^2.
```

现在就可以完全照 exact line search 的做法往下走。两边减去 $p^{\star}$ 得

```math
f(x^{+}) - p^{\star} \le f(x) - p^{\star} - \min\{\alpha,\; \beta\alpha/M\}\,\|\nabla f(x)\|_2^2,
```

再把它与 $\|\nabla f(x)\|_2^2 \ge 2m\,(f(x) - p^{\star})$ 合并，得到

```math
f(x^{+}) - p^{\star} \le \bigl(1 - \min\{2m\alpha,\; 2\beta\alpha m/M\}\bigr)\bigl(f(x) - p^{\star}\bigr).
```

由此得出结论

```math
f(x^{(k)}) - p^{\star} \le c^{k}\bigl(f(x^{(0)}) - p^{\star}\bigr),
```

其中

```math
c = 1 - \min\{2m\alpha,\; 2\beta\alpha m/M\} \lt 1.
```

特别地，$f(x^{(k)})$ 至少以等比级数的速度收敛到 $p^{\star}$，而这个级数的比值（至少部分地）取决于 condition number 的界 $M/m$。用迭代方法的术语说，这一收敛至少是 linear 的。

<span style="color:#1e8449;">**[译注]** 这一段里 $\alpha \lt 1/2$ 是**推导的支点**，不是随手取的经验常数；把 $\alpha$ 取得 $\ge 1/2$ 会静默破坏整条链。看上面的第三行不等式：它要成立只需 $t/2 \ge \alpha t$，即 $\alpha \le 1/2$。当 $\alpha = 1/2$ 时两者是等号，浮点误差一次就能让 exit condition 在 $t = 1/M$ 处恰好不成立，此时 line search 只能一路回溯 —— 步长下界从 $\beta/M$ 退化成「找到为止」，$t$ 可能落到 $M^{-1}\beta^{m}$ 量级。失效对象是可观测的：Boyd 在 §9.2 里推荐 $\alpha \in [0.01, 0.3]$、$\beta \in [0.1, 0.8]$，取 $\alpha = 0.5$ 时，上面这段推导给出的 $c = 1 - \min\{2m\alpha,\, 2\beta\alpha m/M\}$ 里第一项 $2m\alpha$ 恰好取到 $m$，于是 $c = 1 - \min\{m,\, \beta m/M\}$；当 $m \lt 1$ 时 $c$ 仍然 $\lt 1$，界看起来「没坏」——**但你的 solver 会在靠近最优点的最后几十步里步长消失**，因为那里 $\|\nabla f\|_2^2$ 本身就小，而 backtracking 一直在「$-t + Mt^2/2$ 的凸性」不再保证的区间里打转。一个可复算的例子：$f(x) = \tfrac{1}{2}x^{2}$（$m = M = 1$）、$x = 1$、$\alpha = 0.5$、$\beta = 0.5$。$t=1$ 时 $\tilde f(1) = 0 = f(x) - 0.5\cdot 1 = 0$，退出条件**恰好**取等，加一个 $10^{-16}$ 的舍入就变成不满足，于是 $t \to 0.5$、$0.25$、…，每步只下降 $O(t^{2})$ 而不是 $O(t)$。落点：Boyd §9.2（backtracking line search 的参数建议）、式 (9.17)、exercise 9.4。</span>

```math

\frac{\max\{1,\, \gamma\}}{\min\{1,\, \gamma\}} = \max\{\gamma,\; 1/\gamma\}.
```

```math
m = \min\{1,\, \gamma\}, \qquad M = \max\{1,\, \gamma\}.
```

```math
x_2^{(k)} = \left(-\frac{\gamma - 1}{\gamma + 1}\right)^{k},
```

缩小。当 $m/M$ 很小（对应大 condition number）时，上界 (9.19) 蕴含：达到给定精度所需的迭代次数最多按 $M/m$ 的量级增长。对本例而言，精确的所需迭代次数大致按 $(M/m)/4$ 增长，也就是界值的四分之一。这说明对这个简单例子，我们在朴素分析里推出的迭代次数界，只保守了大约 4 倍（而且这已经用了 $m$、$M$ 的最不保守取值）。特别地，

<span style="color:#1e8449;">**[译注]** 「只保守 4 倍」这句话是全书少有的、把**界与真值摆在一起量化**的地方，值得记住它的机制而不是数字本身。机制是：分析里用了两个各自松弛的步骤 —— ① 把 $\|\nabla f\|_2^{2} \ge 2m(f - p^{\star})$ 当作等式来合并；② 用 $c = 1 - m/M$ 而不是真实的 $\left(\frac{1-m/M}{1+m/M}\right)^{2}$。注意真实的收缩因子恒**小于** $c$：因为 $\left(\frac{1-r}{1+r}\right)^{2} \lt (1-r)$ 对任何 $r \in (0,1)$ 成立（把两边展开即可），所以在 $\kappa = M/m = 10$ 处，界给 $c = 0.9$，真值给 $\left(\frac{9}{11}\right)^{2} \approx 0.669$。两者之比在对数尺度上是 $\log 0.9 / \log 0.669 \approx 3.8$ ——这就是「4 倍」的来源，且它随 $\kappa \to \infty$ 时比值稳定在 4 附近（$\log(1-r) \approx -r$，$\log\left(\frac{1-r}{1+r}\right)^{2} \approx -4r$，比值为 4）。失效对象：若把这个 4 倍当成普适常数去估算 solver 的运行时间，遇到 $\kappa$ 由**非二次**目标函数引起的情形就会错得离谱 —— §9.3 后面 p.473 的 $\mathbf{R}^{100}$ 对数障碍例子（式 9.21）里，界反而相当准（$\kappa \approx 100$ 时界给约 1150 次，实测超过 1000 次），因为那里的 Hessian 在最优点附近**变**了，$(M/m)/4$ 的前提（常 Hessian）不成立。落点：Boyd §9.3.2（p.469–470）、式 (9.18)/(9.19)、exercise 9.6。</span>
**特别地，收敛速度（以及它的上界）都极其依赖 sublevel set 的 condition number。**

#### 结论

从上面展示的数值例子（以及其他例子）可以得出下面几条结论。

- gradient method 常常表现出近似 linear 的收敛，即误差 $f(x^{(k)}) - p^{\star}$ 近似按等比级数收敛到零。
- backtracking 参数 $\alpha$、$\beta$ 的选取对收敛有可察觉但不算剧烈的影响。exact line search 有时能改善 gradient method 的收敛，但效果不大（而且大概不值得为了它去承担实现 exact line search 的麻烦）。
- 收敛速率极大地依赖 Hessian（或 sublevel set）的 condition number。即使对条件数只能算中等的（比如说，condition number 在几百这个量级）问题，收敛也可能非常慢。当 condition number 更大（比如说 1000 或以上）时，gradient method 慢到在实践中没用。

gradient method 的主要优点是简单。它的主要缺点是收敛速率如此关键地依赖 Hessian 或 sublevel set 的 condition number。

## 9.4 Steepest descent method（最速下降法）

$f(x + v)$ 在 $x$ 附近的一阶 Taylor 近似是

```math
f(x + v) \approx \hat{f}(x + v) = f(x) + \nabla f(x)^{T}v.
```

右端第二项 $\nabla f(x)^{T}v$ 是 $f$ 在 $x$ 处沿方向 $v$ 的 directional derivative（方向导数）。它给出走一小步 $v$ 时 $f$ 的近似变化量。若该方向导数为负，则这一步 $v$ 是 descent direction（下降方向）。

现在我们要处理的问题是：怎样选取 $v$，使方向导数尽可能负。由于方向导数 $\nabla f(x)^{T}v$ 关于 $v$ 是线性的，只要把 $v$ 取得足够大，它就可以任意负（前提是 $v$ 确实是 descent direction，即 $\nabla f(x)^{T}v \lt 0$）。为了让这个问题有意义，我们必须限制 $v$ 的大小，或者用 $v$ 的长度作归一化。

设 $\|\cdot\|$ 是 $\mathbf{R}^{n}$ 上的任意一个 norm（范数）。我们把 normalized steepest descent direction（归一化最速下降方向，关于 norm $\|\cdot\|$）定义为

```math
\Delta x_{\text{nsd}} = \arg\min\bigl\{\nabla f(x)^{T}v \;\big|\; \|v\| = 1\bigr\}. \qquad (9.23)
```

（我们说「一个」steepest descent direction，是因为极小点可能不止一个。）



476 · 9 Unconstrained minimization

归一化最速下降方向 $\Delta x_{\text{nsd}}$ 是一个单位 norm 的步，它使 $f$ 的 linear approximation 下降得最多。

归一化最速下降方向可以这样几何地解释：我们同样可以把 $\Delta x_{\text{nsd}}$ 定义为

```math
\Delta x_{\text{nsd}} = \arg\min\bigl\{\nabla f(x)^{T}v \;\big|\; \|v\| \le 1\bigr\},
```

也就是「$\|\cdot\|$ 的单位球里，朝 $-\nabla f(x)$ 方向伸得最远的那个方向」。

同时，考虑一个 unnormalized（未归一化）的 steepest descent step 也是方便的，做法是把 normalized 方向按特定方式缩放：

```math
\Delta x_{\text{sd}} = \|\nabla f(x)\|_{*}\,\Delta x_{\text{nsd}}, \qquad (9.24)
```

其中 $\|\cdot\|_{*}$ 表示 dual norm（对偶范数）。注意对 steepest descent step 有

```math
\nabla f(x)^{T}\Delta x_{\text{sd}} = \|\nabla f(x)\|_{*}\,\nabla f(x)^{T}\Delta x_{\text{nsd}} = -\|\nabla f(x)\|_{*}^{2}
```

（见 exercise 9.7）。

steepest descent method 就是把 steepest descent direction 当作 search direction 来用。

<span style="color:#1f618d;">**Algorithm 9.4　Steepest descent method（最速下降法）**</span>

<span style="color:#1f618d;">given a starting point $x \in \operatorname{dom} f$.</span>

<span style="color:#1f618d;">**repeat**</span>

<span style="color:#1f618d;">1. Compute steepest descent direction $\Delta x_{\text{sd}}$.</span>

<span style="color:#1f618d;">2. **Line search.** Choose $t$ via backtracking or exact line search.</span>

<span style="color:#1f618d;">3. **Update.** $x := x + t\Delta x_{\text{sd}}$.</span>

<span style="color:#1f618d;">**until** stopping criterion is satisfied.</span>

使用 exact line search 时，descent direction 的缩放因子没有影响，因此用归一化方向或未归一化方向都可以。

### 9.4.1 Steepest descent for Euclidean and quadratic norms

#### Euclidean norm 下的 steepest descent

若取 norm 为 Euclidean norm，我们会发现 steepest descent direction 就简单地是负梯度，即 $\Delta x_{\text{sd}} = -\nabla f(x)$。对 Euclidean norm 而言，steepest descent method 与 gradient descent method 重合。

#### Quadratic norm 下的 steepest descent

考虑 quadratic norm（二次范数）

```math
\|z\|_{P} = \bigl(z^{T}Pz\bigr)^{1/2} = \|P^{1/2}z\|_{2},
```

其中 $P \in \mathbf{S}_{++}^{n}$。归一化最速下降方向为

```math
\Delta x_{\text{nsd}} = -\Bigl(\nabla f(x)^{T}P^{-1}\nabla f(x)\Bigr)^{-1/2}P^{-1}\nabla f(x).
```

对偶范数为 $\|z\|_{*} = \|P^{-1/2}z\|_{2}$，因此关于 $\|\cdot\|_{P}$ 的 steepest descent step 为

```math
\Delta x_{\text{sd}} = -P^{-1}\nabla f(x). \qquad (9.25)
```

quadratic norm 下的归一化最速下降方向见 Figure 9.9。

<span style="color:#1e8449;">**[译注]** (9.24) 里那个 $\|\nabla f(x)\|_{*}$ 不是装饰，它正是让「步长的量纲」自洽的唯一选择。(9.23) 定义的是单位 norm 的方向，长度按定义是 1；(9.24) 把它乘上 $\|\nabla f\|_{*}$ 之后，$\nabla f^{T}\Delta x_{\text{sd}} = -\|\nabla f\|_{*}^{2}$ 这一步才成立——这个等式是整个 §9.4.3 收敛证明的支点，因为 p.479 的 (9.26) 与 (9.27) 全靠把二次项写成 $\frac{M}{2\gamma^{2}}t^{2}\|\nabla f\|_{*}^{2}$、把线性项写成 $-t\|\nabla f\|_{*}^{2}$，二者同量纲才能配方求出最优步长 $\hat{t} = \gamma^{2}/M$。失效对象：如果把缩放写成 $\|\nabla f\|_{2}$（拿原 norm 去乘）而不是 dual norm，$\ell_{1}$ 情形立刻出错——$\|\nabla f\|_{1}$ 与 $\|\nabla f\|_{\infty}$ 差 $n$ 倍，$n = 100$ 时步长差 100 倍，backtracking 的初值 $t = 1$ 完全失去意义，算法会在第一步回溯几十次才勉强下降。一个可复算的检查：$\Delta x_{\text{nsd}} = -e_1$（p.478 的 $\ell_{1}$ 结果），$\nabla f = (\partial_1 f, 0, \ldots, 0)$，则 $\nabla f^{T}\Delta x_{\text{sd}} = |\partial_1 f| \cdot \|\nabla f\|_{\infty} = \|\nabla f\|_{\infty}^{2}$，取负号后正是 $-\|\nabla f\|_{\infty}^{2}$；若换成 $\|\nabla f\|_{2}$ 则得到 $-\|\nabla f\|_{\infty}\|\nabla f\|_{2}$，除非 $\nabla f$ 只有一个非零分量，否则两者不等。落点：Boyd §9.4（式 9.23–9.25）、§A.1.6（dual norm 与 $\ell_{p}$–$\ell_{q}$ 配对）、exercise 9.7。</span>

#### 借助坐标变换的解释

我们还可以给 steepest descent direction $\Delta x_{\text{sd}}$ 一个有意思的替代解释：它就是对这个问题的坐标做一次变换之后，再作 gradient search 所得到的方向。定义 $\bar{u} = P^{1/2}u$，于是有 $\|u\|_{P} = \|\bar{u}\|_{2}$。利用这个坐标变换，原先极小化 $f$ 的问题，可以等价地改写成极小化函数 $\bar{f} : \mathbf{R}^{n} \to \mathbf{R}$ 的问题：

```math
\bar{f}(\bar{u}) = f(P^{-1/2}\bar{u}) = f(u).
```

若把 gradient method 施加到 $\bar{f}$ 上，则在一个点 $\bar{x}$ 处（它对应原问题中的点 $x = P^{-1/2}\bar{x}$）的 search direction 为

```math
\Delta\bar{x} = -\nabla\bar{f}(\bar{x}) = -P^{-1/2}\nabla f(P^{-1/2}\bar{x}) = -P^{-1/2}\nabla f(x).
```

这个 gradient search direction 对应到原始变量 $x$ 上的方向是

```math
\Delta x = P^{-1/2}\left(-P^{-1/2}\nabla f(x)\right) = -P^{-1}\nabla f(x).
```

换句话说，quadratic norm $\|\cdot\|_{P}$ 下的 steepest descent method，可以看成是对原问题作了坐标变换 $\bar{x} = P^{1/2}x$ 之后施用 gradient method。

### 9.4.3 Convergence analysis（收敛性分析）

本节把 gradient method 在 backtracking line search 下的收敛分析，推广到任意 norm 下的 steepest descent method。我们将用到这样一个事实：任何 norm 都可以用 Euclidean norm 给出上下界，即存在常数 $\gamma, \tilde{\gamma} \in (0, 1]$ 使得

```math
\|x\| \ge \gamma\|x\|_{2}, \qquad \|x\|_{*} \ge \tilde{\gamma}\|x\|_{2}
```

（见 §A.1.4）。

我们同样假设 $f$ 在初始 sublevel set $S$ 上 strongly convex。上界 $\nabla^{2}f(x) \preceq MI$ 蕴含了函数 $f(x + t\Delta x_{\text{sd}})$ 作为 $t$ 的函数的一个上界：

```math
\begin{aligned}
f(x + t\Delta x_{\text{sd}}) &\le f(x) + t\nabla f(x)^{T}\Delta x_{\text{sd}} + \frac{M\|\Delta x_{\text{sd}}\|_{2}^{2}}{2}t^{2} \\
&\le f(x) + t\nabla f(x)^{T}\Delta x_{\text{sd}} + \frac{M\|\Delta x_{\text{sd}}\|_{2}^{2}}{2\gamma^{2}}t^{2} \\
&= f(x) - t\|\nabla f(x)\|_{*}^{2} + \frac{M}{2\gamma^{2}}t^{2}\|\nabla f(x)\|_{*}^{2}. \qquad (9.26)
\end{aligned}
```

步长 $\hat{t} = \gamma^{2}/M$（它使二次上界 (9.26) 取极小）满足 backtracking line search 的退出条件：

```math
f(x + \hat{t}\Delta x_{\text{sd}}) \le f(x) - \frac{\gamma^{2}}{2M}\|\nabla f(x)\|_{*}^{2} \le f(x) + \frac{\alpha\gamma^{2}}{M}\nabla f(x)^{T}\Delta x_{\text{sd}} \qquad (9.27)
```

因为 $\alpha \lt 1/2$ 且 $\nabla f(x)^{T}\Delta x_{\text{sd}} = -\|\nabla f(x)\|_{*}^{2}$。因此 line search 返回的步长 $t \ge \min\{1,\, \beta\gamma^{2}/M\}$，于是有

```math
\begin{aligned}

&\le f(x) - \alpha\tilde{\gamma}^{2}\min\{1,\, \beta\gamma^{2}/M\}\|\nabla f(x)\|_{2}^{2}.
\end{aligned}
```

两边减去 $p^{\star}$ 并利用 (9.9)，得到



也就是说，与 gradient method 完全一样，是 linear convergence。

### 9.4.4 Discussion and examples（讨论与例子）

#### steepest descent 中 norm 的选取

用来定义 steepest descent direction 的那个 norm 的选取，可能对收敛速率产生戏剧性的影响。为简单起见，我们考虑 quadratic $P$-norm 下的 steepest descent。在 §9.4.1 中我们已经证明：quadratic $P$-norm 下的 steepest descent method，等同于对问题作坐标变换 $\bar{x} = P^{1/2}x$ 之后施用 gradient method。我们知道 gradient method 在 sublevel set（或最优点附近的 Hessian）condition number 中等时表现良好，在 condition number 很大时表现很差。由此可知：当 sublevel set 经过坐标变换 $\bar{x} = P^{1/2}x$ 之后条件变成中等时，steepest descent method 会表现良好。

这个观察给出了选取 $P$ 的一份处方：应当选得让 $f$ 的 sublevel set 经过 $P^{-1/2}$ 变换之后条件良好。例如，若已知最优点处 Hessian $H(x^{\star})$ 的一个近似 $\hat{H}$，那么非常好的选择是 $P = \hat{H}$，因为此时 $\tilde{f}$ 在最优点处的 Hessian 是

```math
\hat{H}^{-1/2}\nabla^{2}f(x^{\star})\hat{H}^{-1/2} \approx I,
```

因而不大可能有大的 condition number。

同一个想法也可以不借助坐标变换来表述。「sublevel set 在坐标变换 $\bar{x} = P^{1/2}x$ 之后 condition number 低」这句话，等价于说椭球

```math
E = \bigl\{x \;\big|\; x^{T}Px \le 1\bigr\}
```

近似了该 sublevel set 的形状。（换句话说，经过适当的缩放和平移之后，它给出了一个很好的近似。）

## 9.5 Newton's method（牛顿法）

### 9.5.1 The Newton step（Newton 步）

对 $x \in \operatorname{dom} f$，向量

```math
\Delta x_{\text{nt}} = -\nabla^{2}f(x)^{-1}\nabla f(x)
```

称为（$f$ 在 $x$ 处的）Newton step。$\nabla^{2}f(x)$ 的正定性蕴含

```math
\nabla f(x)^{T}\Delta x_{\text{nt}} = -\nabla f(x)^{T}\nabla^{2}f(x)^{-1}\nabla f(x) \lt 0
```

除非 $\nabla f(x) = 0$；因此 Newton step 是一个 descent direction（除非 $x$ 已经是最优点）。

Newton step 可以有几种解释与动机。

#### 二阶近似式的极小点

$f$ 在 $x$ 处的二阶 Taylor 近似（或模型）$\hat{f}$ 为

```math
\hat{f}(x + v) = f(x) + \nabla f(x)^{T}v + \frac{1}{2}v^{T}\nabla^{2}f(x)v, \qquad (9.28)
```

它是 $v$ 的一个凸二次函数，在 $v = \Delta x_{\text{nt}}$ 处取极小。因此，Newton step $\Delta x_{\text{nt}}$ 就是为了极小化 $f$ 在 $x$ 处的二阶近似所应当加到点 $x$ 上的量。这一点见 Figure 9.16。

这个解释给了我们关于 Newton step 的一些洞见。如果函数 $f$ 本身就是二次的，那么 $x + \Delta x_{\text{nt}}$ 就是 $f$ 的精确极小点。如果 $f$ 近似是二次的，直觉提示 $x + \Delta x_{\text{nt}}$ 应当是 $f$ 的极小点（即 $x^{\star}$）的一个非常好的估计。由于 $f$ 二次可微，当 $x$ 靠近 $x^{\star}$ 时 $f$ 的二次模型会非常准确。由此可知，当 $x$ 靠近 $x^{\star}$ 时，点 $x + \Delta x_{\text{nt}}$ 应当是 $x^{\star}$ 的非常好的估计。后面我们会看到，这个直觉是对的。

所以 $T^{T}$ 与 $T^{-T}$ 精确抵消掉。失效对象是可以直接观测的：把这条性质拿掉，Newton's method 的收敛结果就不再是「与坐标无关的 $\eta$、$\theta$ 常数」，而会像 p.470 的 gradient method 那样显式带一个 condition number —— **同一个问题，只要把变量 $x_2$ 换成 $10^{3}x_2$，gradient method 的迭代数就变，Newton method 的迭代数不变**。这是一个非常硬的判据：拿 $f(x) = \frac{1}{2}(x_1^{2} + \kappa x_2^{2})$，$\kappa = 10^{6}$，从 $x^{(0)} = (1,1)$ 出发，gradient method 每步误差只缩到 $1 - 1/\kappa = 1 - 10^{-6}$ 倍，要做到 $10^{-6}$ 的精度需要约 $1.4\times 10^{7}$ 次；Newton method 从任何点**一步**就到 $x^{\star} = 0$（二次函数，二阶模型精确）。**同一页上 $T$ 的幂次差一个符号（写成 $T$ 而不是 $T^{-1}$），后果是 Newton step 在新坐标里方向反了一半**：以 $T = \operatorname{diag}(2,1)$、$\Delta x_{\text{nt}} = (1,1)$ 为例，正确结果是 $T^{-1}\Delta x_{\text{nt}} = (0.5, 1)$，写错成 $T\Delta x_{\text{nt}} = (2,1)$ 会让第一步就冲过最优点。也正因为这个性质，Newton step 的量纲分析才合法——$\lambda^{2}(x) = \nabla f^{T}\nabla^{2}f^{-1}\nabla f$ 在 $T$ 变换下不变，可以当「以函数值为单位」的停止判据用。落点：Boyd §9.5.1（本页 affine invariance 与 Newton decrement 定义）、§9.5.2 起用 $\lambda$ 做 stopping criterion、exercise 9.9；Strang 线代的 similar matrices / congruence transformation（$\bigl(T^{T}AT\bigr)^{-1}$ 与 $T^{-1}A^{-1}T^{-T}$）是这条抵消的线性代数原形。</span>

#### 续：Newton decrement 作为 stopping criterion

我们可以把 Newton decrement 与量 $f(x) - \inf_{y}\hat{f}(y)$ 联系起来，其中 $\hat{f}$ 是 $f$ 在 $x$ 处的 second-order approximation（二阶近似）：

```math
f(x) - \inf_{y}\hat{f}(y) = f(x) - \hat{f}(x + \Delta x_{\text{nt}}) = \frac{1}{2}\lambda(x)^{2}.
```

因此，$\lambda^{2}/2$ 是基于 $f$ 在 $x$ 处的 quadratic approximation（二次近似）对 $f(x) - p^{\star}$ 作出的一个估计。

我们还可以把 Newton decrement 写成

```math
\lambda(x) = \Bigl(\Delta x_{\text{nt}}^{T}\nabla^{2}f(x)\Delta x_{\text{nt}}\Bigr)^{1/2}. \qquad (9.29)
```

这说明 $\lambda$ 是 Newton step 在以 Hessian 定义的 quadratic norm（二次范数）下的长度，即范数

```math
\|u\|_{\nabla^{2}f(x)} = \Bigl(u^{T}\nabla^{2}f(x)u\Bigr)^{1/2}.
```

Newton decrement 也同样出现在 backtracking line search（回溯线搜索）里，因为我们有

```math
\nabla f(x)^{T}\Delta x_{\text{nt}} = -\lambda(x)^{2}. \qquad (9.30)
```

这个量正是 backtracking line search 里用到的那个常数，它可以解释为 $f$ 在 $x$ 处沿 Newton step 方向的 directional derivative（方向导数）：

```math
-\lambda(x)^{2} = \nabla f(x)^{T}\Delta x_{\text{nt}} = \left.\frac{d}{dt}f(x + \Delta x_{\text{nt}}t)\right|_{t=0}.
```

最后，我们指出：Newton decrement 与 Newton step 一样是 affine invariant（仿射不变的）。也就是说，设 $T$ 非奇异，$\bar{f}(y) = f(Ty)$，则 $\bar{f}$ 在 $y$ 处的 Newton decrement 与 $f$ 在 $x = Ty$ 处的 Newton decrement 相同。

<span style="color:#1e8449;">**[译注]** (9.29) 与 (9.30) 合起来是一条**恒等式链**，它把 §9.5 的全部后续内容串成一句话：$\lambda^{2} = \Delta x_{\text{nt}}^{T}\nabla^{2}f(x)\Delta x_{\text{nt}} = -\nabla f(x)^{T}\Delta x_{\text{nt}} = 2\bigl(f(x) - \hat{f}(x + \Delta x_{\text{nt}})\bigr)$。**四者相等，缺任何一个环节，停止判据就失去物理含义**：如果只有 $\nabla f(x)^{T}\Delta x_{\text{nt}}$ 而不知道它等于 $-\lambda^{2}$，那么 backtracking 的 sufficient decrease 条件 $f(x + t\Delta x) \le f(x) + \alpha t\nabla f^{T}\Delta x$ 就无法改写成 $f(x) - \alpha t\lambda^{2}$，p.490 的 $\gamma = \alpha\beta\eta^{2}m/M^{2}$ 也就推不出来——**整个 §9.5.3 的收敛分析在第一步就断**。这条链有一个可立刻验算的实例：取 $f(t) = e^{t} - t$，在 $t = 1$ 处 $f' = e - 1$、$f'' = e$，于是 $\Delta x_{\text{nt}} = -(e-1)/e = -0.632121$，$\lambda^{2} = e\cdot(0.632121)^{2} = 1.086161$，$\lambda = 1.042191$，而 $\lambda^{2}/2 = 0.543081$；直接算 $f(1) - \hat{f}(1 + \Delta x_{\text{nt}}) = 1.718282 - 1.175201 = 0.543081$，**小数后六位完全一致**。这个 $\lambda = 1.042$ 还大于 1，说明在 $t=1$ 处 $f$ 离最优点还很远（$\lambda \lt 1$ 才是 §9.6 里可用的判据门槛，见 (9.50)）。这条链还有一个不显眼但必需的推论：$\lambda^{2}$ 与 $f$ 同量纲。因为 $\lambda^{2}/2 = f(x) - \hat{f}(x+\Delta x_{\text{nt}})$ 是两个函数值之差，所以 Algorithm 9.5 里「$\lambda^{2}/2 \le \epsilon$」这句比较才合法；换用 (9.29) 的读法，$\Delta x_{\text{nt}}^{T}\nabla^{2}f\Delta x_{\text{nt}}$ 的量纲是 $(x)^{2}\cdot(U/x^{2}) = U$，**两条路给出同一个量纲，这不是巧合，而是 (9.29) 与 (9.30) 等价的必然结果**。反例只需一步：若在 $n = 1$ 上把 $\lambda$ 误写成 $f''\Delta x$（漏掉平方根），量纲变成 $U/x$，「$\lambda^{2}/2 \le \epsilon$」就成了 $U^{2}/x^{2} \le \epsilon$——**换一套长度单位，停机点就漂移，而程序不会报任何错**。落点：Boyd §9.5.1（本页 (9.29)/(9.30) 三处等价）、§9.6.3 的 (9.50)、exercise 9.9；Strang 线代里 $A$-norm $\|u\|_{A} = (u^{T}Au)^{1/2}$ 就是这里 quadratic norm 的线性代数原形。</span>

<span style="color:#1f618d;">**9.5.2　Newton's method（Newton 法）**</span>

下面叙述的 Newton's method，有时被称为 damped Newton method（阻尼 Newton 法）或 guarded Newton method（带防护的 Newton 法），以区别于使用固定 step size $t = 1$ 的 pure Newton method（纯 Newton 法）。

<span style="color:#1f618d;">**Algorithm 9.5　Newton's method（Newton 法）**</span>

<span style="color:#1f618d;">given a starting point $x \in \operatorname{dom} f$, tolerance $\epsilon \gt 0$.</span>

<span style="color:#1f618d;">**repeat**</span>

<span style="color:#1f618d;">1. **Compute the Newton step and decrement.**（算 Newton step 与 decrement）</span>

```math
\Delta x_{\text{nt}} := -\nabla^{2}f(x)^{-1}\nabla f(x), \qquad \lambda^{2} := \nabla f(x)^{T}\nabla^{2}f(x)^{-1}\nabla f(x).
```

<span style="color:#1f618d;">2. **Stopping criterion.** quit if $\lambda^{2}/2 \le \epsilon$.（停止判据）</span>

<span style="color:#1f618d;">3. **Line search.** Choose step size $t$ by backtracking line search.</span>

<span style="color:#1f618d;">4. **Update.** $x := x + t\Delta x_{\text{nt}}$.</span>

<span style="color:#1f618d;">**until** the stopping criterion is satisfied.</span>

这实质上就是 §9.2 中描述的 general descent method（一般下降法），只是把 search direction 取成了 Newton step。唯一的差别（而且非常次要）是：stopping criterion 在算完 search direction 之后检查，而不是在 update 之后检查。

### 9.5.3 Convergence analysis（收敛性分析）

与前面一样，我们假设 $f$ 是 twice continuously differentiable（二阶连续可微）的，并且以常数 $m$ strong convex（强凸），即对 $x \in S$ 有 $\nabla^{2}f(x) \succeq mI$。我们已经看到，这也蕴含存在 $M \gt 0$，使得对一切 $x \in S$ 有 $\nabla^{2}f(x) \preceq MI$。

此外，我们假设 $f$ 的 Hessian 在 $S$ 上以常数 $L$ Lipschitz continuous（Lipschitz 连续），即

```math
\|\nabla^{2}f(x) - \nabla^{2}f(y)\|_{2} \le L\|x - y\|_{2} \qquad (9.31)
```

对一切 $x, y \in S$ 成立。系数 $L$ 可以解释为对 $f$ 的三阶导数的一个界；对 quadratic function（二次函数）而言可以取 $L = 0$。更一般地，$L$ 度量 $f$ 能被 quadratic model（二次模型）逼近到什么程度，因此可以预期 Lipschitz 常数 $L$ 在 Newton's method 的表现中起决定性作用。直觉上，若一个函数的二次模型变化缓慢（即 $L$ 很小），Newton's method 应当对它表现得非常好。

#### 收敛证明的想法与提纲

我们先给出收敛性证明的想法与提纲，以及主要结论，然后再给证明的细节。我们将证明存在数 $\eta$ 与 $\gamma$，满足 $0 \lt \eta \le m^{2}/L$ 且 $\gamma \gt 0$，使得下面两条成立。

- 若 $\|\nabla f(x^{(k)})\|_{2} \ge \eta$，则

```math
f(x^{(k+1)}) - f(x^{(k)}) \le -\gamma. \qquad (9.32)
```

- 若 $\|\nabla f(x^{(k)})\|_{2} \lt \eta$，则 backtracking line search 选取 $t^{(k)} = 1$，且

```math
\frac{L}{2m^{2}}\|\nabla f(x^{(k+1)})\|_{2} \le \left(\frac{L}{2m^{2}}\|\nabla f(x^{(k)})\|_{2}\right)^{2}. \qquad (9.33)
```

我们来分析第二个条件的推论。设它在第 $k$ 次迭代成立，即 $\|\nabla f(x^{(k)})\|_{2} \lt \eta$。由于 $\eta \le m^{2}/L$，我们有 $\|\nabla f(x^{(k+1)})\|_{2} \lt \eta$，也就是说第二个条件在第 $k+1$ 次迭代也成立。递归地继续下去，我们得出结论：一旦第二个条件成立，它对所有未来的迭代点都成立，即对一切 $l \ge k$ 有 $\|\nabla f(x^{(l)})\|_{2} \lt \eta$。因此对一切 $l \ge k$，算法都取 full Newton step（全 Newton 步）$t = 1$，并且

```math
\frac{L}{2m^{2}}\|\nabla f(x^{(l+1)})\|_{2} \le \left(\frac{L}{2m^{2}}\|\nabla f(x^{(l)})\|_{2}\right)^{2}. \qquad (9.34)
```

把这个不等式递归地施加，我们得到对 $l \ge k$

```math
\frac{L}{2m^{2}}\|\nabla f(x^{(l)})\|_{2} \le \left(\frac{L}{2m^{2}}\|\nabla f(x^{(k)})\|_{2}\right)^{2^{l-k}} \le \left(\frac{1}{2}\right)^{2^{l-k}},
```

从而

```math
f(x^{(l)}) - p^{\star} \le \frac{1}{2m}\|\nabla f(x^{(l)})\|_{2}^{2} \le \frac{2m^{3}}{L^{2}}\left(\frac{1}{2}\right)^{2^{l-k+1}}. \qquad (9.35)
```

<span style="color:#1e8449;">**[译注]** $\eta \le m^{2}/L$ 这个门槛不是随手取的比例，它是**量纲上唯一可能的组合**，值得单独算一遍，因为后面 (9.40) 里 $m$ 的五次幂全从这里来。设目标函数值的量纲记为 $U$，变量的量纲记为 $x$，那么 $\nabla f$ 的量纲是 $U/x$，$\nabla^{2}f$ 是 $U/x^{2}$，三阶导是 $U/x^{3}$；于是 $m$、$M$ 的量纲是 $U/x^{2}$，$L$ 的量纲是 $U/x^{3}$，而 $m^{2}/L$ 的量纲是 $(U/x^{2})^{2}/(U/x^{3}) = U/x$——**恰好与 $\|\nabla f\|_{2}$ 同量纲**。所以「$\|\nabla f\|_{2} \lt \eta$」这种比较在量纲上合法，而 $\eta$ 若写成 $m/L$（量纲 $1/x$）就毫无意义。**失效对象是可观测的**：$L = 0$（二次函数）时 $\eta$ 形式上取到 $+\infty$，这意味着 (9.32) 那条「每步至少下降 $\gamma$」的分支永远不会被触发，算法从第一次迭代起就在第二分支里，且 (9.33) 给出 $0 \le 0$——**二次函数一步收敛这件事，(9.33) 只有在 $L=0$ 的退化读法下才看得出来**，用 (9.32) 是永远看不到的。一个可复算的实例：$f(x) = -\log x$ 在 $x = 1$ 附近，$f'' = 1/x^{2}$ 取 $m = 1$，$|f'''(x)| = 2/x^{3}$ 给出 $L = 2$，于是 $m^{2}/L = 1/2$，$\eta \le 0.5$；再用 (9.46) 的 $1/(1 + tf''(0)^{1/2})^{2}$，$t = 1$ 时 $f''(1)$ 的下界是 $1/4$——**二次信息在一单位步长内最多塌掉 4 倍**，这正是 $L \ne 0$ 的代价。落点：Boyd §9.1.4（$m$、$M$ 的定义）、§9.5.3 的 (9.31) 与 (9.35)、exercise 9.9；实分析侧挂 Thomson 的 Lipschitz 条件（$\|\nabla^{2}f(x) - \nabla^{2}f(y)\| \le L\|x-y\|$ 与一维 $\lvert g(x)-g(y)\rvert \le L\lvert x-y\rvert$ 是同一个定义）。</span>

最后一个不等式说明：一旦第二个条件成立，收敛是极其迅速的。这一现象称为 quadratic convergence（二次收敛）。粗略地说，(9.35) 意味着在迭代次数足够多之后，每次迭代中正确数字的个数会翻倍。

Newton's method 的迭代自然地分成两个阶段。第二阶段在条件 $\|\nabla f(x)\|_{2} \le \eta$ 成立之后出现，称为 quadratically convergent stage（二次收敛阶段）。我们把第一阶段称为 damped Newton phase（阻尼 Newton 阶段），因为算法可以选择 $t \lt 1$ 的 step size。二次收敛阶段也称 pure Newton phase（纯 Newton 阶段），因为在这些迭代里 step size 总是取 $t = 1$。

现在我们可以估计总复杂度。首先导出 damped Newton phase 迭代次数的上界。由于 $f$ 每次迭代至少下降 $\gamma$，damped Newton 步数不可能超过

```math
\frac{f(x^{(0)}) - p^{\star}}{\gamma},
```

因为如果超过了，$f$ 就会小于 $p^{\star}$，而这是不可能的。

```math
\log_{2}\log_{2}(\epsilon_{0}/\epsilon)
```

次迭代，就必有 $f(x) - p^{\star} \le \epsilon$，其中 $\epsilon_{0} = 2m^{3}/L^{2}$。

于是总体来看，达到 $f(x) - p^{\star} \le \epsilon$ 所需的迭代次数的上界是

```math
\frac{f(x^{(0)}) - p^{\star}}{\gamma} + \log_{2}\log_{2}(\epsilon_{0}/\epsilon). \qquad (9.36)
```

项 $\log_{2}\log_{2}(\epsilon_{0}/\epsilon)$ 给出的是二次收敛阶段迭代次数的界，它随所需精度 $\epsilon$ 增长得极慢，实际应用中可以当作常数，比如五或六。（二次收敛阶段迭代六次给出的精度约为 $\epsilon \approx 5\cdot10^{-20}\epsilon_{0}$。）

```math
\begin{aligned}
\tilde{f}'(t) &\le \tilde{f}'(0) + t\lambda(x)^{2} + t^{2}\frac{L}{2m^{3/2}}\lambda(x)^{3} \\
&= -\lambda(x)^{2} + t\lambda(x)^{2} + t^{2}\frac{L}{2m^{3/2}}\lambda(x)^{3},
\end{aligned}
```

这里用了 $\tilde{f}'(0) = -\lambda(x)^{2}$。再积分一次，得

```math
\tilde{f}(t) \le \tilde{f}(0) - t\lambda(x)^{2} + t^{2}\frac{1}{2}\lambda(x)^{2} + t^{3}\frac{L}{6m^{3/2}}\lambda(x)^{3}.
```

最后取 $t = 1$，得到

```math
f(x + \Delta x_{\text{nt}}) \le f(x) - \frac{1}{2}\lambda(x)^{2} + \frac{L}{6m^{3/2}}\lambda(x)^{3}. \qquad (9.39)
```

现在设 $\|\nabla f(x)\|_{2} \le \eta \le 3(1 - 2\alpha)m^{2}/L$。由 strong convexity 我们有

```math
\lambda(x) \le 3(1 - 2\alpha)\frac{m^{3/2}}{L},
```

再由 (9.39) 得

```math
\begin{aligned}
f(x + \Delta x_{\text{nt}}) &\le f(x) - \lambda(x)^{2}\left(\frac{1}{2} - \frac{L\lambda(x)}{6m^{3/2}}\right) \\
&\le f(x) - \alpha\lambda(x)^{2} \\
&= f(x) + \alpha\nabla f(x)^{T}\Delta x_{\text{nt}},
\end{aligned}
```

这说明单位步长 $t = 1$ 会被 backtracking line search 接受。

现在来看收敛速率。应用 Lipschitz 条件，我们有

```math
\begin{aligned}
\|\nabla f(x^{+})\|_{2} &= \left\|\nabla f(x + \Delta x_{\text{nt}}) - \nabla f(x) - \nabla^{2}f(x)\Delta x_{\text{nt}}\right\|_{2} \\
&= \left\|\int_{0}^{1}\Bigl(\nabla^{2}f(x + t\Delta x_{\text{nt}}) - \nabla^{2}f(x)\Bigr)\Delta x_{\text{nt}}\;dt\right\|_{2} \\
&\le \frac{L}{2}\|\Delta x_{\text{nt}}\|_{2}^{2} \\
&= \frac{L}{2}\left\|\nabla^{2}f(x)^{-1}\nabla f(x)\right\|_{2}^{2} \\
&\le \frac{L}{2m^{2}}\|\nabla f(x)\|_{2}^{2},
\end{aligned}
```

即不等式 (9.33)。

总之，若 $\|\nabla f(x^{(k)})\|_{2} \lt \eta$，算法就选单位步长并满足条件 (9.33)，其中

```math
\eta = \min\{1,\,3(1 - 2\alpha)\}\,\frac{m^{2}}{L}.
```

把这个界与 (9.38) 代入 (9.37)，我们发现迭代次数的上界为

```math
6 + \frac{M^{2}L^{2}/m^{5}}{\alpha\beta\min\{1,\,9(1 - 2\alpha)^{2}\}}\bigl(f(x^{(0)}) - p^{\star}\bigr). \qquad (9.40)
```

<span style="color:#1e8449;">**[译注]** (9.40) 里那个 $m^{5}$ 与两个 $\min$ 是三个不同来源的常数被硬塞进同一个式子，逐项追一遍就知道为什么不能记成别的幂次。$\gamma = \alpha\beta\eta^{2}m/M^{2}$ 给出 $1/\gamma = M^{2}/(\alpha\beta\eta^{2}m)$；把 $\eta = \min\{1, 3(1-2\alpha)\}m^{2}/L$ 平方后 $\eta^{2} = \min\{1, 9(1-2\alpha)^{2}\}m^{4}/L^{2}$ 代入，分母的 $m$ 变成 $m^{4}\cdot m = m^{5}$——**$m^{5}$ 是 $m^{4}$（来自 $\eta^{2}$）乘 $m$（来自 $1/\gamma$ 的分母）**。两个 $\min$ 分别管两件事：外层 $\min\{1, 3(1-2\alpha)\}$ 保证 $\eta \le m^{2}/L$（(9.33) 递归成立的前提），内层 $\min\{1, 9(1-2\alpha)^{2}\}$ 是它平方后的结果，不能独立地写成 $9(1-2\alpha)^{2}$。**可复算验证**：取 $\alpha = 0.1$，则 $3(1-2\alpha) = 2.4$、$9(1-2\alpha)^{2} = 5.76$，两个 $\min$ 都取 $1$，也就是 $\alpha$ 在 $[0, 1/2)$ 的一个宽区间上界形如 $6 + (M^{2}L^{2}/m^{5})(f(x^{(0)}) - p^{\star})/(\alpha\beta)$；**若有人漏掉外层 $\min$ 而直接写 $(3(1-2\alpha))^{2} = 5.76$，界会凭空变小 5.76 倍**（对 $\alpha=0.1$ 这种常见取值是不可能的乐观）。反向检查：只有当 $3(1-2\alpha) \lt 1$，即 $\alpha \gt 1/3$ 时 $\min$ 才真正起作用，而 backtracking 通常取 $\alpha = 0.01$ 或 $0.1$——**这意味着 (9.40) 的实际形式几乎总是 $6 + M^{2}L^{2}(f(x^{(0)}) - p^{\star})/(\alpha\beta m^{5})$**。落点：Boyd §9.5.3 本页 (9.38)/(9.40)、p.505 的 (9.56)（self-concordant 版本，常数小得多）、exercise 9.12。</span>

#### Summary（小结）

与 gradient method 和 steepest descent method 相比，Newton's method 有几项非常强的优势：

- Newton's method 的收敛在一般情况下是快的，在 $x^{\star}$ 附近是二次的。一旦进入 quadratic convergence 阶段，至多需要六次左右的迭代就能给出非常高精度的解。
- Newton's method 是 affine invariant 的。它对坐标的选择、或目标函数 sublevel set 的 condition number 不敏感。
- Newton's method 在问题规模上扩展得好。它在 $\mathbf{R}^{10000}$ 上的表现与在 $\mathbf{R}^{10}$ 上的表现相似，所需步数只有适度的增加。
- Newton's method 的良好表现不依赖于算法参数的选择。相比之下，steepest descent 中 norm 的选取对其表现起决定性的作用。

Newton's method 的主要缺点在于 forming and storing the Hessian（构造并存储 Hessian）的代价，以及计算 Newton step 的代价——后者需要解一个线性方程组。我们将在 §9.7 中看到，很多情况下可以利用问题的结构来大幅降低计算 Newton step 的代价。

另一种替代方案是由一类称为 quasi-Newton method（拟 Newton 法）的无约束优化算法提供的。这些方法构造 search direction 所需的计算量更小，但它们保留了 Newton 类方法的一部分强优势，比如在 $x^{\star}$ 附近的快速收敛。由于 quasi-Newton 方法在许多书中都有讲述，而且与本书的主题只是相切，我们不在这里讨论它们。

## 9.6 Self-concordance（自和谐性）

§9.5.3 给出的 Newton's method 的经典收敛分析有两个主要缺陷。

第一个是实践上的：由此得到的复杂度估计涉及三个常数 $m$、$M$、$L$，而它们在实践中几乎从来不是已知的。结果是，关于所需 Newton 步数的界 (9.40) 几乎从来无法具体算出来，因为它依赖于三个一般未知的常数。当然，收敛分析与复杂度估计在概念上仍然有用。

第二个缺陷是：虽然 Newton's method 是 affine invariant 的，但对它的经典分析却非常依赖于所使用的坐标系。若改变坐标，常数 $m$、$M$、$L$ 全都会变。哪怕仅仅出于美学上的理由，我们也应当去寻找一种与 Newton's method 本身一样、与仿射坐标变换无关的分析。



### 9.6 Self-concordance ｜ 497

换句话说，我们要找一组替代以下两条假设的东西

```math
mI \preceq \nabla^{2}f(x) \preceq MI, \qquad \|\nabla^{2}f(x) - \nabla^{2}f(y)\|_{2} \le L\|x - y\|_{2},
```

它既与仿射坐标变换无关，又能让我们分析 Newton's method。

Nesterov 与 Nemirovski 发现的一个简单而优雅的假设实现了这一目标，他们把自己的条件命名为 self-concordance。self-concordant function（自和谐函数）之所以重要，有几个原因。

- 它们包含许多在求解凸优化问题的 interior-point method（内点法）中起重要作用的 logarithmic barrier function（对数障碍函数）。
- 对 self-concordant function 的 Newton's method 分析不依赖于任何未知常数。
- self-concordance 是 affine-invariant 的性质，即：若对自变量施加线性变换，得到的函数仍然 self-concordant。因此，对 self-concordant function 应用 Newton's method 所得到的复杂度估计与仿射坐标变换无关。

### 9.6.1 Definition and examples（定义与例子）

#### $\mathbf{R}$ 上的 self-concordant function

我们先考虑 $\mathbf{R}$ 上的函数。凸函数 $f : \mathbf{R} \to \mathbf{R}$ 称为 self-concordant，若

```math
|f'''(x)| \le 2f''(x)^{3/2} \qquad (9.41)
```

对一切 $x \in \operatorname{dom} f$ 成立。由于 linear function 与（凸的）quadratic function 的三阶导为零，它们显然是 self-concordant 的。下面给出一些更有意思的例子。

<span style="color:#b9770e;">**Example 9.3　Logarithm and entropy（对数与熵）**</span>

- **Negative logarithm（负对数）**。函数 $f(x) = -\log x$ 是 self-concordant 的。利用 $f''(x) = 1/x^{2}$、$f'''(x) = -2/x^{3}$，我们得到

```math
\frac{|f'''(x)|}{2f''(x)^{3/2}} = \frac{2/x^{3}}{2(1/x^{2})^{3/2}} = 1,
```

所以定义不等式 (9.41) 以等号成立。

- **Negative entropy plus negative logarithm（负熵加负对数）**。函数 $f(x) = x\log x - \log x$ 是 self-concordant 的。为验证这一点，我们用

```math
f''(x) = \frac{x + 1}{x^{2}}, \qquad f'''(x) = -\frac{x + 2}{x^{3}},
```

得到

```math
\frac{|f'''(x)|}{2f''(x)^{3/2}} = \frac{x + 2}{2(x + 1)^{3/2}}.
```

关于 self-concordance 的定义 (9.41)，我们应当作两点重要的说明。第一点关于定义中出现的那个神秘常数 $2$。事实上，这个常数是为方便而选的，目的是简化后面的公式；换成任何别的正常数也行。例如，假设凸函数 $f : \mathbf{R} \to \mathbf{R}$ 满足

```math
|f'''(x)| \le kf''(x)^{3/2} \qquad (9.42)
```

其中 $k$ 是某个正常数。那么函数 $\tilde{f}(x) = (k^{2}/4)f(x)$ 满足

```math
\begin{aligned}
|\tilde{f}'''(x)| &= (k^{2}/4)|f'''(x)| \le (k^{3}/4)f''(x)^{3/2} \\
&= (k^{3}/4)\Bigl((4/k^{2})\tilde{f}''(x)\Bigr)^{3/2} = 2\tilde{f}''(x)^{3/2},
\end{aligned}
```

因而它是 self-concordant 的。这说明：一个满足 (9.42)（某正常数 $k$）的函数，可以通过缩放使其满足标准的 self-concordance 不等式 (9.41)。所以真正重要的是：**函数的三阶导被其二阶导的 $3/2$ 次幂的某个倍数所界定**。通过对函数作适当的缩放，我们可以把这个倍数变成常数 $2$。

第二点说明是一个简单计算，它说明了 self-concordance 为何如此重要：它是 affine invariant 的。设由 $\tilde{f}(y) = f(ay + b)$ 定义函数 $\tilde{f}$，其中 $a \ne 0$。则 $\tilde{f}$ 是 self-concordant 的当且仅当 $f$ 是。为看出这一点，把

```math
\tilde{f}''(y) = a^{2}f''(x), \qquad \tilde{f}'''(y) = a^{3}f'''(x),
```

（其中 $x = ay + b$）代入 $\tilde{f}$ 的 self-concordance 不等式，即 $|\tilde{f}'''(y)| \le 2\tilde{f}''(y)^{3/2}$，得到

```math
|a^{3}f'''(x)| \le 2\bigl(a^{2}f''(x)\bigr)^{3/2},
```

两边除以 $a^{3}$ 后正是 $f$ 的 self-concordance 不等式。粗略地说，self-concordance 条件 (9.41) 是一种限制函数三阶导的方式，而这种方式与仿射坐标变换无关。

#### $\mathbf{R}^{n}$ 上的 self-concordant function

现在考虑 $n \gt 1$ 时 $\mathbf{R}^{n}$ 上的函数。我们说函数 $f : \mathbf{R}^{n} \to \mathbf{R}$ 是 self-concordant 的，若它沿其定义域内的每一条直线都是 self-concordant 的，即：对一切 $x \in \operatorname{dom} f$ 与一切 $v$，函数 $\tilde{f}(t) = f(x + tv)$ 都是 $t$ 的 self-concordant 函数。

### 9.6.2 Self-concordant calculus（self-concordant 运算）

#### Scaling and sum（缩放与求和）

self-concordance 在以大于一的因子缩放之下保持：若 $f$ 是 self-concordant 的且 $a \ge 1$，则 $af$ 是 self-concordant 的。self-concordance 在加法之下也保持：若 $f_{1}$、$f_{2}$ 是 self-concordant 的，则 $f_{1} + f_{2}$ 是 self-concordant 的。为说明这一点，只需考虑 $f_{1}, f_{2} : \mathbf{R} \to \mathbf{R}$。我们有

```math
\begin{aligned}
|f_{1}'''(x) + f_{2}'''(x)| &\le |f_{1}'''(x)| + |f_{2}'''(x)| \\
&\le 2\bigl(f_{1}''(x)^{3/2} + f_{2}''(x)^{3/2}\bigr) \\
&\le 2\bigl(f_{1}''(x) + f_{2}''(x)\bigr)^{3/2}.
\end{aligned}
```

最后一步我们用了不等式

```math
\bigl(u^{3/2} + v^{3/2}\bigr)^{2/3} \le u + v,
```

它对 $u, v \ge 0$ 成立。

#### Composition with affine function（与仿射函数复合）

若 $f : \mathbf{R}^{n} \to \mathbf{R}$ 是 self-concordant 的，$A \in \mathbf{R}^{n \times m}$、$b \in \mathbf{R}^{n}$，则 $f(Ax + b)$ 是 self-concordant 的。

<span style="color:#b9770e;">**Example 9.4　Log barrier for linear inequalities（线性不等式的对数障碍）**</span>

函数

```math
f(x) = -\sum_{i=1}^{m}\log(b_{i} - a_{i}^{T}x),
```

其定义域 $\operatorname{dom} f = \{x \mid a_{i}^{T}x \lt b_{i},\; i = 1, \dots, m\}$，是 self-concordant 的。每一项 $-\log(b_{i} - a_{i}^{T}x)$ 都是 $-\log y$ 与仿射变换 $y = b_{i} - a_{i}^{T}x$ 的复合，因此是 self-concordant 的。于是其和也 self-concordant。

<span style="color:#b9770e;">**Example 9.5　Log-determinant（对数行列式）**</span>

函数 $f(X) = -\log\det X$ 在 $\operatorname{dom} f = \mathbf{S}_{++}^{n}$ 上是 self-concordant 的。为说明这一点，我们考虑函数 $\tilde{f}(t) = f(X + tV)$，其中 $X \succ 0$、$V \in \mathbf{S}^{n}$。它可以写成

```math
\begin{aligned}
\tilde{f}(t) &= -\log\det\bigl(X^{1/2}(I + tX^{-1/2}VX^{-1/2})X^{1/2}\bigr) \\
&= -\log\det X - \log\det\bigl(I + tX^{-1/2}VX^{-1/2}\bigr) \\
&= -\log\det X - \sum_{i=1}^{n}\log(1 + t\lambda_{i}),
\end{aligned}
```

其中 $\lambda_{i}$ 是 $X^{-1/2}VX^{-1/2}$ 的 eigenvalues（特征值）。每一项 $-\log(1 + t\lambda_{i})$ 都是 $t$ 的 self-concordant 函数，故其和 $\tilde{f}$ 也是 self-concordant 的。由此可知 $f$ 是 self-concordant 的。

<span style="color:#b9770e;">**Example 9.6　Log of concave quadratic（凹二次式的对数）**</span>

函数

```math
f(x) = -\log(x^{T}Px + q^{T}x + r),
```

### 9.6.3 Properties of self-concordant functions（self-concordant 函数的性质）

在 §9.1.2 中我们用 strong convexity 导出了以 $x$ 处梯度范数表示的 suboptimality（次优性）的界。对严格凸的 self-concordant function，我们可以得到类似的界，但用 Newton decrement 表示：

```math
\lambda(x) = \Bigl(\nabla f(x)^{T}\nabla^{2}f(x)^{-1}\nabla f(x)\Bigr)^{1/2}.
```

为后面引用方便，我们指出 Newton decrement 还可以写成

```math
\lambda(x) = \sup_{v \ne 0}\frac{-v^{T}\nabla f(x)}{\bigl(v^{T}\nabla^{2}f(x)v\bigr)^{1/2}}
```

```math

```

等号在 $v = \Delta x_{\text{nt}}$ 处成立。

#### 二阶导的上界与下界

设 $f : \mathbf{R} \to \mathbf{R}$ 是严格凸的 self-concordant 函数。我们可以把 self-concordance 不等式 (9.41) 写成

```math
\left|\frac{d}{dt}\Bigl(f''(t)^{-1/2}\Bigr)\right| \le 1 \qquad (9.45)
```

对一切 $t \in \operatorname{dom} f$ 成立（见 exercise 9.16）。假设 $t \ge 0$ 且 $0$ 与 $t$ 之间的区间落在 $\operatorname{dom} f$ 内，我们可以把 (9.45) 在 $0$ 与 $t$ 之间积分，得到

```math
-t \le \int_{0}^{t}\frac{d}{d\tau}\Bigl(f''(\tau)^{-1/2}\Bigr)\,d\tau \le t,
```

即 $-t \le f''(t)^{-1/2} - f''(0)^{-1/2} \le t$。由此我们得到 $f''(t)$ 的下界与上界：

```math
\frac{f''(0)}{\bigl(1 + tf''(0)^{1/2}\bigr)^{2}} \le f''(t) \le \frac{f''(0)}{\bigl(1 - tf''(0)^{1/2}\bigr)^{2}}. \qquad (9.46)
```

#### Damped Newton phase（阻尼 Newton 阶段）

令 $\tilde{f}(t) = f(x + t\Delta x_{\text{nt}})$，于是


```math

\end{aligned}
```

对 $0 \le t \lt 1/\lambda(x)$ 成立。

```math

\end{aligned}
```


### self-concordance 的实际重要性（Practical importance of self-concordance）

我们已经观察到：Newton's method 对 strongly convex（强凸）的目标函数一般工作得很好。这个含糊的说法可以用经验支撑，也可以用 Newton's method 的经典分析支撑——后者给出一个复杂度界，但界里挂着几个几乎总是未知的常数。

对 self-concordant 函数我们能多说一点。我们有一个完全显式的复杂度界，不依赖任何未知常数。经验研究提示这个界还能收紧相当多，但它的总体形状——一个小常数加上 $f(x^{(0)}) - p^{\star}$ 的倍数——看来至少能粗略预测「最小化一个近似 minimally self-concordant 的函数需要多少 Newton step」。

目前还不清楚 self-concordant 函数在实践中是否真的比非 self-concordant 函数更容易被 Newton's method 最小化。（连怎么把这个陈述讲精确都还不清楚。）眼下能说的是：self-concordant 函数是这样一类函数——对它们，关于 Newton's method 复杂度的结论比非 self-concordant 情形多得多。

<span style="color:#1e8449;">**[译注]** 这一页是全书对「worst-case 界到底值不值得信」最诚实的一段，值得算一算差距。取 $f(x^{(0)}) - p^{\star} = 1$，界 (9.58) 说 $381$ 步；取 $f(x^{(0)}) - p^{\star} = 10$，界说 $3756$ 步。而 Boyd 说实测系数在 $1.5$ 附近，同一批问题大约 $8$ 到 $20$ 步就收敛。**界比实测大 20 到 250 倍**，这不是常数松，是量级松。

**为什么这个「松」仍然值得要**：经典 Newton 分析的界长这样——用 $\frac{M}{2m^2}\|\nabla f(x^{(0)})\|$ 之类量控制进入二次收敛区的步数，其中 $m$ 是 strong convexity 常数（$mI \preceq \nabla^2 f(x)$）、$M$ 是 Hessian 的 Lipschitz 常数。**这两个数在真实问题里几乎从不已知**，于是界虽然真，却不能被任何人用来做预算。self-concordance 的条件 (9.41) 只用三阶/二阶导数的比值，是纯局部的，所以推出来的界里没有任何外部常数——这就是它的全部价值。

**消失测试**：抽掉 self-concordance 假设，(9.58) 里那个 $375$ 就退化成一个依赖未知 $M/m$ 的表达式，于是你无法在跑 solver 之前回答「这个 LMI 的 analytic center 需要多少步、要不要上 8 核并行」这类工程问题，只剩「跑跑看」。反过来，minimally self-concordant 这个附带概念封掉了一条捷径：若允许缩放，把 $f$ 乘上任意小 $\alpha$ 就能让 $f(x^{(0)}) - p^{\star}$ 任意小，界就变成一句废话；(9.58) 的成立恰恰依赖「不能再缩」这一条。

**落点**：界 (9.58) 与 §9.6.4；经典分析见 §9.5.3；「含未知常数的收敛结果有什么用」的评论见 Polyak [Pol87, §1.6]；把 $\alpha, \beta$ 调到使界最小正是习题 9.21。**可复算**：$f(x^{(0)}) - p^{\star} = 1 \Rightarrow 375 + 6 = 381$；$= 10 \Rightarrow 3750 + 6 = 3756$；与实测 $8$–$20$ 步的比值分别是 $19$ 与 $188$。</span>

### 9.7.1 Pre-computation for line searches

在最简单的 line search 实现里，对每个 $t$ 取值都按「对任意 $z \in \operatorname{dom} f$ 求 $f(z)$」的同一套办法去求 $f(x + t\Delta x)$。但在某些情形下，我们可以利用一个事实：$f$（以及 exact line search 中的导数）要在射线 $\{x + t\Delta x \mid t \ge 0\}$ 上的许多点求值，从而压低总计算量。这通常需要一些 pre-computation（预计算），它的代价常常与在任意一点求一次 $f$ 同阶；此后沿这条射线求 $f$（及其导数）就便宜得多。

设 $x \in \operatorname{dom} f$、$\Delta x \in \mathbf{R}^n$，并定义 $\tilde f$ 为 $f$ 限制在由 $x$ 与 $\Delta x$ 确定的直线（或射线）上：

```math
\tilde f(t) = f(x + t\Delta x).
```

在 backtracking line search 里，我们必须对若干个、可能很多个 $t$ 求 $\tilde f$；在 exact line search 里，必须在若干 $t$ 上求 $\tilde f$ 以及一阶或多阶导数。按上面说的朴素做法，求 $\tilde f(t)$ 是先组出 $z = x + t\Delta x$，再求 $f(z)$；求 $\tilde f'(t)$ 是先组出 $z = x + t\Delta x$，再求 $\nabla f(z)$，然后算

```math
\tilde f'(t) = \nabla f(z)^T \Delta x.
```

下面几个有代表性的例子说明，怎样在许多 $t$ 上更省地算 $\tilde f$。

#### 与仿射函数复合（Composition with an affine function）

预计算能加速 line search 的一个非常一般的情形是：目标函数形如 $f(x) = \varphi(Ax + b)$，其中 $A \in \mathbf{R}^{p \times n}$，而 $\varphi$ 容易求值（例如可分离）。要用朴素办法对 $k$ 个 $t$ 求 $\tilde f(t) = f(x + t\Delta x)$，就得对每个 $t$ 组出 $A(x + t\Delta x) + b$（$2kpn$ flops），再对每个 $t$ 求 $\varphi(A(x + t\Delta x) + b)$。

更省的做法是先算 $Ax + b$ 与 $A\Delta x$（$4pn$ flops），然后对每个 $t$ 用

```math
A(x + t\Delta x) + b = (Ax + b) + t(A\Delta x)
```

组出 $A(x + t\Delta x) + b$，这只要 $2kp$ flops。只保留主导项，总代价是 $4pn + 2kp$ flops，而朴素做法是 $2kpn$。

#### 线性矩阵不等式的 analytic center

这里给一个更具体、也更完整的例子。考虑问题 (9.6) ——计算一个 linear matrix inequality（线性矩阵不等式）的 analytic center，即最小化 $\log\det F(x)^{-1}$，其中 $x \in \mathbf{R}^n$，$F : \mathbf{R}^n \to \mathbf{S}^p$ 是仿射的。沿过 $x$、方向为 $\Delta x$ 的那条直线，有

```math
\tilde f(t) = \log\det\bigl(F(x + t\Delta x)\bigr)^{-1} = -\log\det(A + tB)
```

其中 $A, B$ 的定义见下一页。注意 $\tilde f$ 是 $t$ 的一元函数：一旦把它写清，整条 line search 就退化成「一元凸函数上的回溯」，这一步是 §9.7.1 所有加速的前提。



其中

```math
A = F(x), \qquad B = \Delta x_1 F_1 + \cdots + \Delta x_n F_n \in \mathbf{S}^p.
```

由于 $A \succ 0$，它有 Cholesky factorization $A = LL^T$，其中 $L$ 下三角且非奇异。因此可以把 $\tilde f$ 写成

```math
\tilde f(t) = -\log\det\bigl(L(I + tL^{-1}BL^{-T})L^T\bigr) = -\log\det A - \sum_{i=1}^{p}\log(1 + t\lambda_i) \qquad (9.59)
```

其中 $\lambda_1, \dots, \lambda_p$ 是 $L^{-1}BL^{-T}$ 的特征值。这些特征值一旦算出，对任意 $t$ 都可用 (9.59) 右端以 $4p$ 次简单算术运算求出 $\tilde f(t)$。导数 $\tilde f'(t)$（以及同样地任意高阶导数）也能以 $4p$ 次运算求出：

```math
\tilde f'(t) = -\sum_{i=1}^{p}\frac{\lambda_i}{1 + t\lambda_i}.
```

现在比较完成同一条 line search 的两种做法，假设需要对 $k$ 个 $t$ 求 $f(x + t\Delta x)$。在朴素做法里，对每个 $t$ 组出 $F(x + t\Delta x)$，再以 $-\log\det F(x + t\Delta x)$ 求 $f(x + t\Delta x)$：例如对 $F(x + t\Delta x) = LL^T$ 做 Cholesky 分解，然后算

```math
-\log\det F(x + t\Delta x) = -2\sum_{i=1}^{p}\log L_{ii}.
```

组出 $F(x + t\Delta x)$ 要 $np^2$，Cholesky 分解要 $(1/3)p^3$，所以整条 line search 的代价是

```math
k\bigl(np^2 + (1/3)p^3\bigr) = knp^2 + (1/3)kp^3.
```

用上面勾出的办法，先组出 $A$（$np^2$）并分解它（$(1/3)p^3$）；再组出 $B$（$np^2$）与 $L^{-1}BL^{-T}$（$2p^3$）；然后算这个矩阵的特征值，代价约 $(4/3)p^3$ flops。预计算共需 $2np^2 + (11/3)p^3$ flops。做完预计算后，每个 $t$ 只需 $4p$ flops 就能求得 $\tilde f(t)$，总代价为

```math
2np^2 + \frac{11}{3}p^3 + 4kp.
```

只要 $k$ 相对 $p\bigl(2n + (11/3)p\bigr)$ 不大，整条 line search 的花费就与「单纯求一次 $f$」同量级。按 $k, p, n$ 的具体取值，相对朴素做法的节省可以达到 $k$ 这一阶。

> **可复算验证。** 取 $n=100$、$p=50$、$k=20$。朴素做法 $20\bigl(100\cdot 2500 + 125000/3\bigr) = 20 \times 291{,}667 \approx 5.83\times 10^6$ flops；预计算做法 $2\cdot 100\cdot 2500 + \frac{11}{3}\cdot 125000 + 4\cdot 20\cdot 50 = 500{,}000 + 458{,}333 + 4{,}000 \approx 9.62\times 10^5$ flops，比值 $6.05$，落在「$k$ 这一阶」的下方，因为 $k=20$ 还不够小。
> 谱表示独立核对：取 $A = \operatorname{diag}(2, 1)$、$B = \operatorname{diag}(1, 0)$，则 $\det(A + tB) = 2 + t$，直接得 $\tilde f(t) = -\log(2+t)$。用 (9.59)：$L = \operatorname{diag}(\sqrt2, 1)$，$L^{-1}BL^{-T} = \operatorname{diag}(1/2, 0)$，故 $-\log\det A - \sum_i \log(1 + t\lambda_i) = -\log 2 - \log(1 + t/2) = -\log(2 + t)$，两端一致。

### 9.7.2 Computing the Newton step

本节简述实现 Newton's method 时会遇到的问题。多数情形下，计算 Newton step $\Delta x_{\mathrm{nt}}$ 的工作量支配 line search 的工作量。

<span style="color:#1e8449;">**[译注]** (9.59) 这个式子看着只是「把一个行列式拆成特征值乘积」，但它决定了 §9.7.1 的加速能不能存在，值得拆开看。$\det(A + tB) = \det(A)\prod_i (1 + t\lambda_i)$ 是 Strang 线代里 $\det$ 与特征值关系 $\det M = \prod \lambda_i$ 的一个直接套用：把 $A + tB$ 写成 $L(I + tL^{-1}BL^{-T})L^T$，$\det L$ 与 $\det L^T$ 相乘抵消成 $\det A$，剩下的就是 $I + tM$ 的特征值积，而 $I + tM$ 的特征值恰是 $1 + t\lambda_i(M)$。

**消失测试**：没有这个谱分解，line search 就得对每个候选 $t$ 重新做一次 Cholesky——每次 Cholesky 的主元都不同，无法复用。对 $n=100, p=50$，单次求值从 $(1/3)p^3 + np^2 \approx 291{,}667$ flops 降到 $4p = 200$ flops，**约 1458 倍**；而 backtracking 每次迭代通常要试 $1$ 到 $5$ 个 $t$，exact line search 要试更多。这就是「line search 的代价从与算 $f$ 同阶降到可忽略」的全部来源。

**这条注最该被反驳的地方**：$\lambda_i$ 有正有负。若某个 $\lambda_i \lt 0$，则 $1 + t\lambda_i \gt 0$ 要求 $t \lt -1/\lambda_i$；一旦 $t$ 越过这个界，$\log(1 + t\lambda_i)$ 对负的辐角无定义，$A + tB$ 也不再正定。**可观测现象**：朴素做法在 $t$ 过大时 Cholesky 会因为主元非正而失败（`np.linalg.cholesky` 抛 `LinAlgError`），(9.59) 的做法则直接在 NaN 上静默算出 $-\texttt{inf}$ 或 `nan`——后者更危险，因为没有异常。所以用 (9.59) 做 line search 时必须把 $t$ 夹在 $t \lt -1/\min_i \lambda_i$ 之内，这个上界正是 $\operatorname{dom} \tilde f$ 的边界，不是数值技巧而是数学约束。

**落点**：(9.59)；成本对比在 §9.7.1 同页；Cholesky 与 $\log\det$ 的数值细节见附录 C.3.2；同类推导在 EE364a 的 analytic centering 讲义里出现过一次（同一件事的多变量版本）。</span>



要计算 Newton step $\Delta x_{\mathrm{nt}}$，我们先在 $x$ 处求值并组出 Hessian 矩阵 $H = \nabla^2 f(x)$ 与梯度 $g = \nabla f(x)$，然后解线性方程组

```math
H\Delta x_{\mathrm{nt}} = -g
```

得到 Newton step。这组方程有时称为 Newton system（因为它解出来就是 Newton step），有时称为 normal equations（因为最小二乘问题里会出现同类型的方程，见 §9.1.1）。

虽然可以调用通用线性方程求解器，但更好的做法是利用 $H$ 的对称性与正定性。最常见的方式是做 $H$ 的 Cholesky factorization：算出满足 $LL^T = H$ 的下三角矩阵 $L$（见 §C.3.2）。然后用前代解 $Lw = -g$ 得 $w = -L^{-1}g$，再用回代解 $L^T\Delta x_{\mathrm{nt}} = w$ 得

```math
\Delta x_{\mathrm{nt}} = L^{-T}w = -L^{-T}L^{-1}g = -H^{-1}g.
```

Newton decrement 可以按 $\lambda^2 = -\Delta x_{\mathrm{nt}}^T g$ 算，也可以改用公式

```math
\lambda^2 = g^T H^{-1}g = \lVert L^{-1}g \rVert_2^2 = \lVert w \rVert_2^2.
```

若使用稠密（无结构）Cholesky 分解，前代与回代的代价被 Cholesky 分解的代价 $(1/3)n^3$ flops 支配。于是计算 Newton step $\Delta x_{\mathrm{nt}}$ 的总代价是 $F + (1/3)n^3$ flops，其中 $F$ 是组出 $H$ 与 $g$ 的代价。

通常还可能更省地解 Newton system $H\Delta x_{\mathrm{nt}} = -g$：利用 $H$ 的特殊结构，例如带宽结构或稀疏结构。这里「$H$ 的结构」指的是对一切 $x$ 都相同的结构。例如我们说「$H$ 是三对角的」，指的是对每个 $x \in \operatorname{dom} f$，$\nabla^2 f(x)$ 都是三对角的。

#### 带宽结构（Band structure）

若 Hessian $H$ 是带宽为 $k$ 的带状矩阵，即 $|i - j| \gt k$ 时 $H_{ij} = 0$，则可用带状 Cholesky 分解，以及带状前代与回代。此时计算 Newton step $\Delta x_{\mathrm{nt}} = -H^{-1}g$ 的代价是 $F + nk^2$ flops（假设 $k \ll n$），而稠密分解加代换是 $F + (1/3)n^3$。

Hessian 的带状条件

```math
\nabla^2 f(x)_{ij} = \frac{\partial^2 f(x)}{\partial x_i \partial x_j} = 0 \quad \text{for } |i - j| \gt k, \qquad \text{for all } x \in \operatorname{dom} f,
```

对目标函数 $f$ 有一个有意思的解释。粗略地说，它意味着目标函数里每个变量 $x_i$ 只与 $2k+1$ 个变量 $x_j$（$j = i-k, \dots, i+k$）发生非线性耦合。当 $f$ 具有 partial separability（部分可分离）形式时就会出现这种情况：

```math
f(x) = \psi_1(x_1, \dots, x_{k+1}) + \psi_2(x_2, \dots, x_{k+2}) + \cdots + \psi_{n-k}(x_{n-k}, \dots, x_n),
```

其中 $\psi_i : \mathbf{R}^{k+1} \to \mathbf{R}$。换句话说，$f$ 可以写成若干个「$k$ 个连续变量之函数」的和。

> **可复算验证。** $n = 10^4$、$k = 3$：稠密 $(1/3)n^3 = 3.3\times 10^{11}$ flops，带状 $nk^2 = 9\times 10^4$ flops，比值约 $3.7\times 10^6$，即少 $6.6$ 个数量级。这个数只依赖 $n$ 与 $k$，可以直接按公式对拍。



<span style="background:#eaf2f8;color:#1a5276;padding:1px 6px;border-radius:3px;">Example 9.9</span> 考虑最小化 $f : \mathbf{R}^n \to \mathbf{R}$，其形式为

```math
f(x) = \psi_1(x_1, x_2) + \psi_2(x_2, x_3) + \cdots + \psi_{n-1}(x_{n-1}, x_n),
```

其中 $\psi_i : \mathbf{R}^2 \to \mathbf{R}$ 凸且二次可微。由于这个形式，Hessian $\nabla^2 f$ 是三对角的，因为 $|i - j| \gt 1$ 时 $\partial^2 f/\partial x_i \partial x_j = 0$。（反过来，若一个函数的 Hessian 对一切 $x$ 都是三对角的，则它必有这个形式。）

使用三对角矩阵的 Cholesky 分解与前代、回代算法，我们可以在 order $n$ flops 内解出这个问题对应的 Newton system。若不利用 $f$ 的特殊形式，则应对比的是 order $n^3$ flops。

#### 稀疏结构（Sparse structure）

更一般地，解 Newton system 时可以利用 Hessian $H$ 的稀疏性。每当每个变量 $x_i$ 在目标函数中只与少数几个别的变量非线性耦合，等价地说，每当目标函数能写成若干个「只依赖少数变量」的函数之和、而每个变量只出现在其中少数几个函数里时，就出现这种稀疏结构。

当 $H$ 稀疏时，用稀疏 Cholesky 分解求 $H\Delta x = -g$：算出置换矩阵 $P$ 与下三角矩阵 $L$，使

```math
H = PLL^T P^T.
```

这个分解的代价取决于具体的稀疏模式，但通常远小于 $(1/3)n^3$；对大的 $n$，「经验复杂度为 order $n$」并不罕见。前代与回代和基本做法非常相似，只是多了置换：用前代解 $Lw = -P^Tg$，再用回代解 $L^Tv = w$，得

```math
v = L^{-T}w = -L^{-T}L^{-1}P^T g.
```

于是 Newton step 是 $\Delta x = Pv$。

由于 $H$ 的稀疏模式不随 $x$ 变化（更准确地说，我们只利用不随 $x$ 变化的稀疏性），可以对每个 Newton step 复用同一个置换矩阵 $P$。确定一个好的置换矩阵 $P$ 这一步称为 symbolic factorization，它可以对整个 Newton 过程只做一次。

#### 对角加低秩（Diagonal plus low rank）

在解 Newton system $H\Delta x_{\mathrm{nt}} = -g$ 时还能利用许多其它类型的结构。这里简述一种，更多细节见附录 C。设 Hessian $H$ 可表示为对角矩阵加一个秩为 $p$ 的低秩矩阵。当目标函数 $f$ 具有特殊形式

```math
f(x) = \sum_{i=1}^{n}\psi_i(x_i) + \psi_0(Ax + b) \qquad (9.60)
```

时就会出现这种情况。

<span style="color:#1e8449;">**[译注]** 带宽 $k$ 那条结论（$F + nk^2$ 而不是 $F + (1/3)n^3$）不是数值技巧，它等价于对 $f$ 的**结构性断言**：$\nabla^2 f$ 的带状 $\iff$ $f$ 是「$k+1$ 个连续变量之函数」的和。这一步值得验一遍，因为它把线性代数条件翻译成了建模条件。若 $f = \sum_i \psi_i(x_i, \dots, x_{i+k})$，则 $\partial^2 f/\partial x_a \partial x_b \ne 0$ 只可能来自某个 $\psi_i$，而该 $\psi_i$ 只涉及下标区间 $[i, i+k]$，故 $|a - b| \gt k$ 时必有偏导为零；反向由 Hessian 带状直接读出耦合图。

**消失测试**：不作 partial separability 假设，就无法把「$H$ 带状」当成先验知识——因为在通用的 $f$ 上，$\nabla^2 f(x)$ 的稀疏模式会随 $x$ 变，于是 symbolic factorization 每步都要重做，§9.7.2 里「同一个置换矩阵 $P$ 对整个 Newton 过程复用」这句就崩了，退化成每步一次 $O(n^3)$ 排序加分解。这个失效是可观测的：跑 `scipy.sparse.linalg.splu` 时若每步重建，profile 里 `splu` 会占掉几乎全部时间。

**量的方向感**：$n = 10^4$、$k = 3$ 时 $nk^2 = 9\times 10^4$ 对 $(1/3)n^3 = 3.3\times 10^{11}$，比值 $3.7\times 10^6$；换成 $k = 3$、$n = 10^6$（时序平滑这类问题的真实规模）差距会拉到 $10^{13}$ 以上。**这正是「稀疏直接法 + Cholesky 仍然打得过迭代法」的适用边界**：一旦 $k$ 或填充（fill-in）使 $L$ 不再带状，优势立刻消失。

**落点**：Example 9.9、§9.7.2「带宽结构」、附录 C.3.2（带状 Cholesky）；习题 9.24（block diagonal 版本）、9.25（二维平滑拟合，其 Hessian 是分块三对角）；Strang 线代侧对应「三对角矩阵的 LU 不产生填充」这一条。**可复算**：Example 9.9 里 $n-1$ 个 $\psi_i$，每个依赖 $2$ 个变量，故 $H$ 的非零带宽恰为 $1$，代入 $nk^2$ 得 $n$，与文中「order $n$ flops」一致。</span>



其中 $A \in \mathbf{R}^{p \times n}$，$\psi_1, \dots, \psi_n : \mathbf{R} \to \mathbf{R}$，$\psi_0 : \mathbf{R}^p \to \mathbf{R}$。换句话说，$f$ 是一个可分离函数，加上一个依赖 $x$ 的低维仿射函数。

要求 (9.60) 的 Newton step $\Delta x_{\mathrm{nt}}$，须解 Newton system $H\Delta x_{\mathrm{nt}} = -g$，其中

```math
H = D + A^T H_0 A.
```

这里 $D = \operatorname{diag}\bigl(\psi_1''(x_1), \dots, \psi_n''(x_n)\bigr)$ 是对角的，$H_0 = \nabla^2\psi_0(Ax + b)$ 是 $\psi_0$ 的 Hessian。若不利用结构去算 Newton step，解 Newton system 的代价是 $(1/3)n^3$ flops。

设 $H_0 = L_0L_0^T$ 为 $H_0$ 的 Cholesky 分解。引入临时变量 $w = L_0^TA\Delta x_{\mathrm{nt}} \in \mathbf{R}^p$，把 Newton system 写成

```math
D\Delta x_{\mathrm{nt}} + A^TL_0w = -g, \qquad w = L_0^TA\Delta x_{\mathrm{nt}}.
```

把第一式给出的 $\Delta x_{\mathrm{nt}} = -D^{-1}(A^TL_0w + g)$ 代入第二式，得到

```math
\bigl(I + L_0^TAD^{-1}A^TL_0\bigr)w = -L_0^TAD^{-1}g, \qquad (9.61)
```

这是由 $p$ 个线性方程构成的方程组。

接着按如下步骤计算 Newton step $\Delta x_{\mathrm{nt}}$。先做 $H_0$ 的 Cholesky 分解，代价 $(1/3)p^3$；再组出 (9.61) 左端那个稠密、对称正定的矩阵，代价 $2p^2n$；然后用 Cholesky 分解加回代、前代解 (9.61) 得 $w$，代价 $(1/3)p^3$ flops；最后用

```math
\Delta x_{\mathrm{nt}} = -D^{-1}(A^TL_0w + g)
```

算出 $\Delta x_{\mathrm{nt}}$，代价 $2np$ flops。于是计算 $\Delta x_{\mathrm{nt}}$ 的总代价（只留主导项）是 $2p^2n$ flops——在 $p \ll n$ 时远小于 $(1/3)n^3$。

> **可复算验证。** $n = 1000$、$p = 10$：稠密 $(1/3)n^3 = 3.33\times 10^8$ flops，本方法 $2p^2n = 2\times 100 \times 1000 = 2\times 10^5$ flops，比值 $1667$（约 $3.2$ 个数量级）。把 $p$ 从 $10$ 抬到 $50$ 时比值降到 $66.7$——优势按 $p^2$ 衰减，这条曲线可以直接用公式画出来对拍。

<span style="color:#1e8449;">**[译注]** (9.61) 值得单拎出来，因为它是全书里「低秩结构把 $n$ 维问题压成 $p$ 维问题」最干净的一次显形。它本质上是 matrix inversion lemma（Woodbury identity）的一次具体落地：$H = D + A^TH_0A$ 的逆可以直接写成 $D^{-1} - D^{-1}A^T(H_0^{-1} + AD^{-1}A^T)^{-1}AD^{-1}$，用 (9.61) 只是把它组织成「先解 $p \times p$ 系统、再回代」的形式，避免显式求逆。习题 9.11 的 hint 指向的 §C.4.3 就是这条引理。

**量的方向感**：整个 Newton system 的维数从 $n$ 掉到 $p$，成本从 $O(n^3)$ 掉到 $O(p^2n)$，当 $p$ 是「低秩」意义上的小量时这是真正的降维，不是常数优化。按上面的数：$n=1000, p=10$ 是 $1667$ 倍。

**消失测试（一个真会被踩的边界）**：(9.61) 的全部推导都用了 $D^{-1}$，即每个 $\psi_i''(x_i) \gt 0$。若目标函数里有任何一个 $\psi_i$ 是线性的（$\psi_i'' \equiv 0$），$D$ 奇异，这一步直接崩。可观测现象：`numpy.linalg.inv(D)` 抛 `LinAlgError: Singular matrix`，而如果你改用伪逆糊过去，得到的是最小范数解而非 Newton step，收敛阶立刻从二次掉到线性甚至不收敛。同样的坑在习题 9.4 的 (9.62) 里更隐蔽——那里 $f = \sum (a_i^Tx - b_i)^2/y_i + \mathbf{1}^Ty$ 对 $y$ 的二次导是 $2(a_i^Tx - b_i)^2/y_i^3$，在最优点 $a_i^Tx = b_i$ 附近它趋于 $0$，于是「用 Newton's method 解 (9.62)」这个提议在最优解附近退化，这正是习题 9.4 要你反驳那句话的技术理由。

**落点**：(9.60)、(9.61)；矩阵求逆引理见 §C.4.3；同族的加速出现在习题 9.23(c)（$(Ax-b)^T(P_0 + \sum x_iP_i)^{-1}(Ax - b)$ 的 line search 预计算）与习题 9.26（linear structure 下 $H = \sum A_i^TH_iA_i$，$n \gg m_i$）。</span>

### Unconstrained minimization

<span style="background:#fdf2e9;color:#7e5109;padding:1px 6px;border-radius:3px;">[exercise]</span> **9.1 Minimizing a quadratic function.** Consider the problem of minimizing a quadratic function:

```math
\operatorname{minimize} \quad f(x) = (1/2)x^T Px + q^T x + r,
```

where $P \in \mathbf{S}^n$ (but we do not assume $P \succeq 0$).

(a) Show that if $P \not\succeq 0$, i.e., the objective function $f$ is not convex, then the problem is unbounded below.
(b) Now suppose that $P \succeq 0$ (so the objective function is convex), but the optimality condition $Px^{\star} = -q$ does not have a solution. Show that the problem is unbounded below.

<span style="background:#fdf2e9;color:#7e5109;padding:1px 6px;border-radius:3px;">[exercise]</span> **9.2 Minimizing a quadratic-over-linear fractional function.** Consider $f : \mathbf{R}^n \to \mathbf{R}$ defined as

```math
f(x) = \frac{\lVert Ax - b \rVert_2^2}{c^T x + d}, \qquad \operatorname{dom} f = \{x \mid c^T x + d \gt 0\}.
```

We assume $\operatorname{\mathbf{rank}} A = n$ and $b \notin \mathcal{R}(A)$.

(a) Show that $f$ is closed.
(b) Show that the minimizer $x^{\star}$ of $f$ is given by $x^{\star} = x_1 + tx_2$ where $x_1 = (A^TA)^{-1}A^Tb$, $x_2 = (A^TA)^{-1}c$, and $t \in \mathbf{R}$ can be calculated by solving a quadratic equation.

<span style="background:#fdf2e9;color:#7e5109;padding:1px 6px;border-radius:3px;">[exercise]</span> **9.3 Initial point and sublevel set condition.** Consider the function $f(x) = x_1^2 + x_2^2$ with domain $\operatorname{dom} f = \{(x_1, x_2) \mid x_1 \gt 1\}$.

<span style="background:#fdf2e9;color:#7e5109;padding:1px 6px;border-radius:3px;">[exercise]</span> **9.4 Do you agree with the following argument?** The $\ell_1$-norm of a vector $x \in \mathbf{R}^m$ can be expressed as

```math
\lVert x \rVert_1 = (1/2)\inf_{y \succ 0}\left(\sum_{i=1}^{m} x_i^2/y_i + \mathbf{1}^T y\right).
```

Therefore the $\ell_1$-norm approximation problem $\operatorname{minimize} \lVert Ax - b \rVert_1$ is equivalent to the minimization problem

```math
\operatorname{minimize} \quad f(x, y) = \sum_{i=1}^{m}(a_i^T x - b_i)^2/y_i + \mathbf{1}^T y, \qquad (9.62)
```

with $\operatorname{dom} f = \{(x, y) \in \mathbf{R}^n \times \mathbf{R}^m \mid y \succ 0\}$, where $a_i^T$ is the $i$th row of $A$. Since $f$ is twice differentiable and convex, we can solve the $\ell_1$-norm approximation problem by applying Newton's method to (9.62).

> 中文话题：一个「看起来没错」的推理——把 $\ell_1$ 问题改写成 (9.62) 再上 Newton；要你判断它错在哪。

<span style="background:#fdf2e9;color:#7e5109;padding:1px 6px;border-radius:3px;">[exercise]</span> **9.5 Backtracking line search.** Suppose $f$ is strongly convex with $mI \preceq \nabla^2 f(x) \preceq MI$. ```

Use this to give an upper bound on the number of backtracking iterations.
