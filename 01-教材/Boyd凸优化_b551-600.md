<span style="color:#b45309;">**[Example 11.1]**</span> **Inequality form linear programming（不等式形式线性规划）。**

对不等式形式的 LP

```math
\begin{aligned}
\text{minimize}\quad & c^Tx\\
\text{subject to}\quad & Ax \preceq b,
\end{aligned}
\qquad (11.8)
```

logarithmic barrier function 由

```math
\varphi(x) = -\sum_{i=1}^{m}\log\left(b_i - a_i^Tx\right),\qquad \operatorname{dom}\varphi = \{x \mid Ax \prec b\}
```

给出，其中 $a_1^T, \ldots, a_m^T$ 是 $A$ 的各行。barrier function 的 gradient 与 Hessian 是

```math
\nabla\varphi(x) = \sum_{i=1}^{m}\frac{1}{b_i - a_i^Tx}a_i,\qquad
\nabla^2\varphi(x) = \sum_{i=1}^{m}\frac{1}{\left(b_i - a_i^Tx\right)^2}a_ia_i^T,
```

或更紧凑地写作

```math
\nabla\varphi(x) = A^Td,\qquad \nabla^2\varphi(x) = A^T\operatorname{diag}(d)^2A,
```

其中 $d \in \mathbf{R}^m$ 的各分量由 $d_i = 1/\left(b_i - a_i^Tx\right)$ 给出。由于 $x$ 是 strictly feasible 的，故 $d \succ 0$，于是 $\varphi$ 的 Hessian 非奇异当且仅当 $A$ 的秩为 $n$。

centrality condition (11.7) 是

```math
tc + \sum_{i=1}^{m}\frac{1}{b_i - a_i^Tx}a_i = tc + A^Td = 0.
\qquad (11.9)
```

我们可以给 centrality condition 一个简单的几何解释。在 central path 上的点 $x^\star(t)$ 处，梯度 $\nabla\varphi(x^\star(t))$ 垂直于过 $x^\star(t)$ 的 $\varphi$ 的 level set，它必须与 $-c$ 平行。换句话说，超平面 $c^Tx = c^Tx^\star(t)$ 与过 $x^\star(t)$ 的 $\varphi$ 的 level set 相切。Figure 11.2 给出 $m = 6$、$n = 2$ 的一个例子。

### Dual points from central path（从中心路径得到对偶点）

由 (11.7) 可以推出 central path 的一条重要性质：**每个 central point 都给出一个 dual feasible point，从而给出最优值 $p^\star$ 的一个下界。** 更具体地，定义

```math
\lambda_i^\star(t) = -\frac{1}{tf_i\left(x^\star(t)\right)},\quad i = 1, \ldots, m,\qquad \nu^\star(t) = \hat{\nu}/t.
\qquad (11.10)
```

我们断言对 $\left(\lambda^\star(t), \nu^\star(t)\right)$ 是 dual feasible 的。

首先，显然 $\lambda^\star(t) \succ 0$，因为 $f_i\left(x^\star(t)\right) \lt 0$（$i = 1, \ldots, m$）。把 optimality conditions (11.7) 写成

```math
\nabla f_0\left(x^\star(t)\right) + \sum_{i=1}^{m}\lambda_i^\star(t)\nabla f_i\left(x^\star(t)\right) + A^T\nu^\star(t) = 0,
```



[Figure 11.2：它演示的是**central path 在二维 LP 上的几何形态**，以及 (11.9) 的切触解释。图中 $n = 2$、$m = 6$：$-c$ 方向用一个箭头标出；$x^\star$ 是 LP 的最优解；$x^\star(10)$ 是 $t = 10$ 处的 central point；虚线是 logarithmic barrier $\varphi$ 的三条等值线。图注的主张是：$t \to \infty$ 时 central path 收敛到 $x^\star$，且在 $x^\star(10)$ 处直线 $c^Tx = c^Tx^\star(10)$ 与过该点的 $\varphi$ 等值线相切。**等值线的具体形状与坐标无法从 PDF 复原**，此处只记录几何关系，不编造数值。]

我们便看到 $x^\star(t)$ 极小化 Lagrangian

```math
L(x, \lambda, \nu) = f_0(x) + \sum_{i=1}^{m}\lambda_if_i(x) + \nu^T(Ax - b),
```

取 $\lambda = \lambda^\star(t)$、$\nu = \nu^\star(t)$，这意味着 $\left(\lambda^\star(t), \nu^\star(t)\right)$ 是一个 dual feasible pair。因此对偶函数 $g\left(\lambda^\star(t), \nu^\star(t)\right)$ 有限，且

```math
\begin{aligned}
g\left(\lambda^\star(t), \nu^\star(t)\right) &= f_0\left(x^\star(t)\right) + \sum_{i=1}^{m}\lambda_i^\star(t)f_i\left(x^\star(t)\right) + \nu^\star(t)^T\left(Ax^\star(t) - b\right)\\
&= f_0\left(x^\star(t)\right) - m/t.
\end{aligned}
```

特别地，$x^\star(t)$ 与 dual feasible pair $\lambda^\star(t)$、$\nu^\star(t)$ 所对应的 duality gap 恰好就是 $m/t$。作为一条重要推论，我们有

```math
f_0\left(x^\star(t)\right) - p^\star \le m/t,
```

即 $x^\star(t)$ 的次优性不超过 $m/t$。这证实了「$t \to \infty$ 时 $x^\star(t)$ 收敛到最优点」这一直觉。

<span style="color:#1e8449;">**[译注]** $m/t$ 这个数不是估计出来的余项，它是**一条精确的恒等式**：$g(\lambda^\star(t),\nu^\star(t)) = f_0(x^\star(t)) - m/t$。能写成这样，全靠 (11.10) 那个 $\lambda_i^\star(t) = -1/\left(tf_i(x^\star(t))\right)$ 的选取——代入后 $\sum_i\lambda_i^\star f_i = \sum_i(-1/t) = -m/t$，$m$ 条约束，每条正好贡献 $1/t$。

**可复算验证**：取 $m = 100,\ t = 10$ 时 gap $= 10$，$t = 10^4$ 时 gap $= 10^{-2}$，$t = 10^6$ 时 gap $= 10^{-4}$。要让 $f_0(x^\star(t)) - p^\star \le 10^{-6}$，需要 $t \ge 10^8$。

**消失测试**：没有这条恒等式，barrier method 就**没有停机准则**——你只能靠「相邻两次迭代的解几乎不变」这种启发式判据（在外层 $t$ 增大时永远成立，判别力为零），或者白算到底。有了它，算法有了一个可证明的停止条件 $m/t \le \epsilon$，外层迭代数也因此可以**提前算出来**：$\lceil\log(m/(\epsilon t_0))/\log\mu\rceil$，取 $m = 100,\ \epsilon = 10^{-6},\ t_0 = 1,\ \mu = 10$ 得 8 次。

**一个必须自己核对的细节**：$m/t$ 里的 $m$ 是**不等式约束的个数**，不是变量数 $n$。这个下界对 $m$ 线性增长——$m = 10^4$ 条约束时，要 $10^{-6}$ 的精度需要 $t \ge 10^{10}$，而这恰恰踩上前一条译注说的 Hessian 病态。**这就是 §11.5 必须引入更精细的复杂度分析（而不是「取大 $t$ 就行」）的理由**。

**落点**：Boyd §11.2.2 的 (11.10) 与上式；停止准则用在外层，见 §11.3.1 的 Algorithm 11.1 第 4 行；$O(\sqrt{m})$ 阶的改进见 §11.5.3。</span>

## 11.2（续）Logarithmic barrier function and central path · 对数障碍函数与 central path

是 dual feasible（对偶可行）的，其对偶目标值为

```math
-b^T\lambda^\star(t) = c^Tx^\star(t) + \left(Ax^\star(t) - b\right)^T\lambda^\star(t) = c^Tx^\star(t) - m/t.
```

### Interpretation via KKT conditions · 用 KKT 条件解释

我们也可以把 central path 条件 (11.7) 解释为 KKT 最优性条件 (11.2) 的一种**连续变形**（continuous deformation）。点 $x$ 等于 $x^\star(t)$，当且仅当存在 $\lambda,\nu$ 使

```math
\begin{aligned}
Ax &= b,\\
f_i(x) &\le 0, \quad i = 1,\ldots,m\\
\lambda &\succeq 0\\
\nabla f_0(x) + \sum_{i=1}^{m}\lambda_i\nabla f_i(x) + A^T\nu &= 0\\
-\lambda_i f_i(x) &= 1/t, \quad i = 1,\ldots,m.
\end{aligned}
\qquad (11.11)
```

KKT 条件 (11.2) 与 centrality 条件 (11.11) 的**唯一差别**是：complementarity 条件 $-\lambda_i f_i(x) = 0$ 被换成了 $-\lambda_i f_i(x) = 1/t$。

特别地，对很大的 $t$，$x^\star(t)$ 与相伴的 dual point $\lambda^\star(t),\nu^\star(t)$「几乎」满足 (11.1) 的 KKT 最优性条件。

<span style="color:#1e8449;">**[译注]** (11.11) 与 (11.2) 只差一行，但这一行把**二值逻辑换成了连续量**：complementarity 说「要么约束起作用（$f_i = 0$）、要么它的乘子为零（$\lambda_i = 0$）」，centrality 说「每条约束都留一点互补余量，且余量之和恰好是 $m$ 条约束对应的 $m/t$」。后者可直接验算：$\sum_i(-\lambda_i f_i) = -\sum_i(1/t) = -m/t$，再代入对偶目标 $g(\lambda,\nu) = f_0 + \sum_i\lambda_i f_i$ 就得到开头那条 $g = f_0(x^\star(t)) - m/t$。

**这里必须钉死一个符号冲突**：本章 $\lambda_i^\star(t) = -1/\left(t f_i(x^\star(t))\right)$ 是 **dual variable**，恒为正；而第 10 章起反复出现的 $\lambda(x)^2/2$（本块 p.572 还会再出现一次，作 stopping criterion）是 **Newton decrement** 的平方。同一个字母 $\lambda$ 在 (11.11) 里是乘子、在 (10.13) 里是标量度量，读者若按符号检索必然对不上。

**消失测试**：若强行取 $t\to\infty$（即 $1/t\to 0$）一步到位，就退回 (11.2)，而 (11.2) 的 complementarity 是非线性的「二选一」，没有 Newton 能直接解的解析形式——这正是 §11.3 必须用**递增序列** $t^{(k)} = \mu^k t^{(0)}$ 逐点逼近的原因。

**落点**：Boyd §11.2.2 的 (11.10)(11.11)；$m/t$ 的精确性见本块 p.567 首式与 §11.3.3 的 (11.13)；Newton decrement 的定义回到 §9.6.3。**排版细节**：本页首句 "is dual feasible" 是 p.566 末句的续行（主语是上一页的 $\lambda^\star(t),\nu^\star(t)$），fitz 抽页时被切到了新页；译文照原文保留这个断裂并在此点名，以免被读成新的一句话。</span>

### Force field interpretation · 力场解释

我们可以给 central path 一个简单的力学解释：把它看成作用在 strictly feasible set $C$ 中一个粒子上的势能力（potential force）。为简单起见，假设没有 equality constraints。

对每条约束，我们关联一个力

```math
F_i(x) = -\nabla\left(-\log\left(-f_i(x)\right)\right) = \frac{1}{f_i(x)}\nabla f_i(x),
```

它作用在位于位置 $x$ 的粒子上。约束所产生的总力场对应的势，就是 logarithmic barrier $\varphi$。当粒子朝可行集边界移动时，它会被约束产生的力强烈地**排斥**回去。

现在再设想另一个力作用在粒子上：

```math
F_0(x) = -t\nabla f_0(x),
```

它在粒子处于位置 $x$ 时起作用。这个 objective force field 把粒子往负梯度方向拉，即朝更小的 $f_0$ 拉。参数 $t$ 决定 objective force 相对于 constraint forces 的**标度**。

Central point $x^\star(t)$ 就是 constraint forces 与 objective force 恰好**平衡**的那个位置。当 $t$ 增大，粒子被更有力地拉向最优点，但它始终被 barrier potential 困在 $C$ 内——因为粒子接近边界时这个势会趋于无穷。

<span style="color:#b45309;">**[Example 11.3]**</span> **Force field interpretation for inequality form LP（不等式形式 LP 的力场解释）。** LP (11.8) 的第 $i$ 条约束对应的力场是

```math
F_i(x) = \frac{-a_i}{b_i - a_i^Tx}.
```



这个力沿约束平面 $H_i = \{x \mid a_i^Tx = b_i\}$ 的**内向法向**，大小与到 $H_i$ 的距离成反比：

```math
\|F_i(x)\|_2 = \frac{\|a_i\|_2}{b_i - a_i^Tx} = \frac{1}{\operatorname{dist}(x,H_i)}.
```

换句话说，每个约束超平面都关联一个**排斥力**，大小由到该超平面的逆距离给出。

项 $tc^Tx$ 就是作用在粒子上的常力 $-tc$ 所对应的势。这个 objective force 把粒子推向低 cost 的方向。因此 $x^\star(t)$ 是粒子在逆距离 constraint forces 与 objective force $-tc$ 共同作用下的**平衡位置**。当 $t$ 很大时，粒子被推到几乎就是最优点；强 objective force 由反向的 constraint forces 平衡——后者之所以很大，是因为我们已在可行边界附近。

Figure 11.3 用 $n = 2$、$m = 5$ 的小 LP 演示了这一解释。

[Figure 11.3：central path 的力场解释。虚线是 central path；左图与右图分别用圆点标出 $x^\star(1)$ 与 $x^\star(3)$。objective force 分别等于 $-c$ 与 $-3c$，画成粗箭头；其余箭头是 constraint forces，服从逆距离律。objective force 的强度变化时，粒子的平衡位置就描出 central path。]

左图给出 $t = 1$ 时的 $x^\star(t)$ 以及作用在其上、与 objective force 相平衡的 constraint forces；右图给出 $t = 3$ 时的 $x^\star(t)$ 与相应各力。objective force 更大，粒子就被推得更靠近最优点。

<span style="color:#1e8449;">**[译注]** 力场说法不是修辞，它把「barrier method 在解什么」翻译成一句可验算的话：**平衡点 = 中心点**。机制是逐项对的——势 $U_i = -\log(-f_i)$ 的梯度取反得 $F_i = \nabla f_i/f_i$，因 $f_i \lt 0$，它指向可行域内部；对 LP 用 $f_i = a_i^Tx - b_i$ 代入，立刻得到 Example 11.3 的 $F_i = -a_i/(b_i - a_i^Tx)$。

**而且「平衡」不是比喻，它就是中心路径条件本身**：平衡要求各力之和为零，即 $-t\nabla f_0 + \nabla\varphi = 0$，与 (11.7) 的 first-order 条件**逐项相同**（有等式约束时再加一个 $A^T\nu$ 的法向分量）。所以「物理解释」与「KKT 条件」是同一个方程组的两种读法。大小也对：$\operatorname{dist}(x,H_i) = (b_i - a_i^Tx)/\|a_i\|_2$，故 $\|F_i\|_2 = 1/\operatorname{dist}$，这就是原文那句 "inverse-distance law"。

**消失测试**：如果这个力不是 $1/\operatorname{dist}$ 而是常数强度，那么远离边界时排斥力仍为常数，粒子会被 objective force 一步推出可行域——Newton 迭代必须靠 backtracking 反复折半才停得下来，收敛从「二次」退化成「每次只缩 $\beta = 0.5$ 的线性」。逆距离律让势在边界处 $+\infty$，**这一步免费的「无限墙」正是 barrier 不需要显式约束处理的全部理由**。

**可复算验证**：取 $a_i = (1,0)$、$b_i = 1$、$x = (0.5, 0)$，则 $\operatorname{dist} = 0.5$，$\|F_i\|_2 = 1/0.5 = 2$；$x = (0.99,0)$ 时 $\|F_i\|_2 = 100$。距离缩小 50 倍，力增大 50 倍。

**落点**：Boyd §11.2.2 末与 Figure 11.3；$t$ 增大的极限见 §11.3.3 的 (11.13)；同一思路在电势（Coulomb 律 $1/r^2$）与引力势里都出现过，但这里只有**一维距离**，故是 $1/r$ 而非 $1/r^2$。</span>



## 11.3 The barrier method · barrier method

我们已看到：点 $x^\star(t)$ 是 $m/t$-suboptimal，且这一精度的**证书**由 dual feasible pair $\lambda^\star(t),\nu^\star(t)$ 提供。这提示一个非常直接的方法，用来以**保证的**指定精度 $\epsilon$ 求解原问题 (11.1)：直接取 $t = m/\epsilon$，然后用 Newton 法求解等式约束问题

```math
\begin{aligned}
\text{minimize}\quad & (m/\epsilon)f_0(x) + \varphi(x)\\
\text{subject to}\quad & Ax = b.
\end{aligned}
```

这个方法可以称为 unconstrained minimization method，因为它让我们通过求解一个无约束（或线性约束）问题，以**有保证的**精度求解不等式约束问题 (11.1)。尽管对小问题、好的起始点、以及中等精度（即 $\epsilon$ 不太小）它表现尚可，其他情形下它并不好用。因此它**极少被使用**（rarely, if ever, used）。

<span style="color:#1e8449;">**[译注]** 这一页真正要读者记住的是**为什么「一步取 $t = m/\epsilon$」不行**——Boyd 只说 "rarely, if ever, used"，没给量级，补上：$t$ 越大，最优点越贴近边界，因为 (11.11) 给出 $f_i(x^\star(t)) = -1/\left(t\lambda_i^\star(t)\right)$。代入 barrier 的 Hessian

```math
\nabla^2\varphi(x) = \sum_{i=1}^{m}\frac{1}{f_i(x)^2}\nabla f_i(x)\nabla f_i(x)^T - \sum_{i=1}^{m}\frac{1}{f_i(x)}\nabla^2 f_i(x),
```

第一项的量级是 $1/f_i^2 \sim t^2\lambda_i^2$，于是 $H$ 的条件数 $\kappa \asymp t^2$。要 $\epsilon = 10^{-6}$ 且 $m = 100$，$t = 10^8$，$\kappa \sim 10^{16}$。**double 的机器精度 $1/\epsilon_{\text{mach}} \approx 4.5\times 10^{15}$，条件数已经超过它**——此时 Newton 方向由舍入误差主导，算出来的 $\Delta x_{\text{nt}}$ 与真方向可以完全无关，残差不再下降。

**消失测试**：没有「递增 $t$」这一层 homotopy，就只能在条件数 $10^{16}$ 的病态问题上直接下 Newton——看不到任何报错，只看到残差停在 $10^{-4}$ 量级不动，然后被误判成「已收敛」。递增序列的作用是把「一次跨 $10^{16}$」换成几十次「每次跨 $\mu$」——取 $\mu = 10$、起点 $\kappa_0 = 10^{2}$（初始点给的是 $\epsilon = 10^{-1}$ 的精度），到 $10^{16}$ 只需 $\log_{10}(10^{14}) = 14$ 次外层，每次条件数只涨 10 倍，Newton 二次收敛保住。

顺带一提，这个病态障碍在 §11.5 被**正式量化**：内层步数的上界里显式出现 $\mu$ 与 $H$ 的相对变化量，而不只是 $t$ 本身。

**落点**：Boyd §11.3 首段与 §11.3.1；条件数与 $\epsilon$ 的关系在 §11.3.3；内层步数上界见 §11.5.3；数值线性代数的侧证见 §10.3 对 singular $H$ 的讨论。</span>

### 11.3.1 The barrier method · barrier method

unconstrained minimization method 的一个简单**扩展**就好用了：它基于求解**一串**无约束（或线性约束）最小化问题，把上一次找到的点作为下一次的起始点。换句话说，对一串递增的 $t$ 值计算 $x^\star(t)$，直到 $t \ge m/\epsilon$——此时可保证得到了原问题的 $\epsilon$-suboptimal solution。

这个方法 1960 年代由 Fiacco 与 McCormick 首次提出时叫 sequential unconstrained minimization technique（SUMT）；今天通常叫 barrier method 或 path-following method。简单版本如下。

<span style="color:#b45309;">**[Algorithm 11.1]**</span> **Barrier method.**

```text
given strictly feasible x, t := t(0) > 0, mu > 1, tolerance eps > 0.
repeat
  1. Centering step.
     Compute x*(t) by minimizing t*f0 + phi, subject to Ax = b, starting at x.
  2. Update.  x := x*(t).
  3. Stopping criterion.  quit if m/t < eps.
  4. Increase t.  t := mu*t.
```

在每次迭代（除第一次外），我们从上一个已算出的 central point 出发计算 $x^\star(t)$，然后把 $t$ 增大一个因子 $\mu \gt 1$。算法也可以返回 $\lambda = \lambda^\star(t)$ 与 $\nu = \nu^\star(t)$，即 $x$ 的一个 dual $\epsilon$-suboptimal point（对偶证书）。

我们把第 1 步的每次执行称为一次 centering step（因为此时在计算一个 central point），或称为一次 outer iteration；把第一次 centering step（计算 $x^\star(t^{(0)})$）称为 initial centering step。（因此，取 $t^{(0)} = m/\epsilon$ 的那个简单算法只包含 initial centering step。）尽管第 1 步可用任何线性约束最小化方法，我们假定用 Newton 法。centering step 中执行的 Newton 迭代称为 inner iteration。**在每个 inner step 我们都有一个 primal feasible point；但只有每次 outer（centering）step 结束时才有一个 dual feasible point。**



### Accuracy of centering · centering 的精度

关于 centering 问题的求解精度应当说几句。**精确**计算 $x^\star(t)$ 并无必要：central path 除了「$t\to\infty$ 时引向原问题的解」之外没有别的意义；不精确的 centering 仍会给出收敛到最优点的序列 $x^{(k)}$。但不精确的 centering 意味着由 (11.10) 算出的 $\lambda^\star(t),\nu^\star(t)$ **并非严格 dual feasible**。这可以修正：在 (11.10) 上加一个修正项，只要算出的 $x$ 靠近 central path 即 $x^\star(t)$，就得到一个 dual feasible point（见 exercise 11.9）。

另一方面，把 $tf_0 + \varphi$ 的最小化器算得**极其精确**，相比只算一个「好」的最小化器，代价只是**边缘性地**多一点，至多多几步 Newton。因此假定 exact centering 并不算不合理。

### Choice of $\mu$ · $\mu$ 的选取

$\mu$ 的选取涉及 inner iteration 与 outer iteration 次数之间的 **trade-off**。若 $\mu$ 小（即接近 1），则每次 outer iteration 中 $t$ 只增大一小点。于是 Newton 过程的起始点（即上一个迭代点 $x$）是很好的起点，计算下一个迭代点所需的 Newton 步数少。因此 $\mu$ 小意味着**每次 outer iteration 的 Newton 步数少，但 outer iteration 次数多**——因为每次 outer iteration 只把 gap 减小一点点。此时迭代点（包括 inner iteration 的迭代点）**紧贴** central path 前进；这正是它又叫 path-following method 的原因。

反之，$\mu$ 大就是相反的情形：每次 outer iteration 后 $t$ 增大很多，当前迭代点大概不再是下一个迭代点的好近似，于是需要多得多的 inner iteration。这种 **aggressive** 的 $t$ 更新带来更少的 outer iteration（每次把 duality gap 缩小 $\mu$ 倍），但更多 inner iteration。$\mu$ 大时，迭代点之间在 central path 上隔得很远，inner iterates 会**大幅偏离** central path。

这个 trade-off 在实践中与（下文将看到的）理论上都被确认。实践中，小的 $\mu$（接近 1）导致很多 outer iteration，每次只需几步 Newton。而对 $\mu$ 在相当宽的范围内——大约 3 到 100 ——两种效应几乎**相互抵消**，总 Newton 步数近似保持不变。这意味着 $\mu$ 的选取并不特别关键；10 到 20 左右似乎表现很好。而当目标是使总 Newton 步数的**最坏情形界**最优时，所用的 $\mu$ 接近 1。

### Choice of $t^{(0)}$ · $t^{(0)}$ 的选取

另一个重要问题是 $t$ 的初值。这里 trade-off 很直接：若 $t^{(0)}$ 选得太大，第一次 outer iteration 需要太多迭代；若 $t^{(0)}$ 选得太小，算法需要额外的 outer iteration，且第一次 centering step 中可能需要过多 inner iteration。

由于 $m/t^{(0)}$ 正是第一次 centering step 将要产生的 duality gap，一个合理的做法是取 $t^{(0)}$ 使 $m/t^{(0)}$ 与 $f_0(x^{(0)}) - p^\star$ **同阶**，或是它的 $\mu$ 倍。

<span style="color:#1e8449;">**[译注]** 「$\mu$ 从 3 到 100 几乎不影响总步数」这句话可以算出来，不必信直觉。总 Newton 步数拆成两个因子：outer 次数由 (11.13) 给，$\left\lceil \log\left(m/(\epsilon t^{(0)})\right)/\log\mu\right\rceil$；inner 次数随 $\mu$ 增大。把它们乘起来，用本块 p.572 Figure 11.4 的真实设置（gap 从 $100$ 降到 $10^{-6}$，即比值 $10^8$，$\ln 10^8 = 18.42$）：

```math
\begin{aligned}
\mu = 2:&\quad \frac{18.42}{0.693} = 26.6 \to 27\ \text{outer},\quad 27\times 3 \approx 81\ \text{steps}\\
\mu = 50:&\quad \frac{18.42}{3.912} = 4.7 \to 5\ \text{outer},\quad 5\times 7 \approx 35\ \text{steps}\\
\mu = 150:&\quad \frac{18.42}{5.011} = 3.7 \to 4\ \text{outer},\quad 4\times 7 \approx 28\ \text{steps}
\end{aligned}
```

$\mu = 50$ 与 $\mu = 150$ 都落在图上的 35-40 步区间、$\mu = 2$ 明显更多，**与 Figure 11.4 的台阶图逐格吻合**。平台出现的机制是：outer 次数的下降速率是 $1/\log\mu$（对数级、很快就平），而 inner 步数的上升在 $\mu$ 超过约 10 之后也趋于饱和——两个缓慢变化的量相乘，总步数就对 $\mu$ 不敏感。这就是为什么「$\mu$ in the range 10-100」不是经验口诀，而是**两条对数曲线交叉处的平坦区**。

还有一处细节值得量：踏面宽度在 $\mu = 150$ 时于 4 到 11 步之间摆动（Figure 11.4 最右那条曲线），方差明显大于 $\mu = 50$。这说明大 $\mu$ 的代价不只是均值上升，更是**不可预测**——某次 centering 可能突然要 11 步，而紧邻的前一次只用了 4 步；对需要预算墙钟时间的部署，这一点比均值更麻烦。

**消失测试**：若没有 (11.13) 这个等比结构，改用「$t$ 加倍直到 gap 达标」的任意策略，$\mu$ 就退化成纯调参旋钮，平台区无从预测，部署时只能对 $\mu$ 做网格扫描——Figure 11.5 那 25 个点（$\mu$ 从 1.2 到 200）正是这种扫描的产物。

**落点**：Boyd §11.3.1 的 Choice of $\mu$ 与 p.572-573 的 Figure 11.4/11.5；闭式 (11.13) 见本块 p.577；$\mu \approx 1$ 的最坏情形最优性见 §11.5.3。</span>



例如，若已知 dual feasible point $\lambda,\nu$，其对偶 gap 为 $\eta = f_0(x^{(0)}) - g(\lambda,\nu)$，则取 $t^{(0)} = m/\eta$。这样在第一次 outer iteration 中，算出的点与原初对偶可行对具有**相同的 duality gap**。

另一种可能由 central path 条件 (11.7) 提示：可以把

```math
\inf_{\nu}\left\| t\nabla f_0(x^{(0)}) + \nabla\varphi(x^{(0)}) + A^T\nu \right\|_2
\qquad (11.12)
```

解释为 $x^{(0)}$ 偏离 $x^\star(t)$ 的**度量**，并取使 (11.12) 最小的 $t$ 作为 $t^{(0)}$。（这个 $t$ 与对应的 $\nu$ 可通过解一个 least-squares 问题得到。）

该做法的一个变体用 **affine-invariant** 的偏离度量代替 Euclidean norm：取使下式最小的 $t$ 与 $\nu$，

```math
\alpha(t,\nu) = \left(t\nabla f_0(x^{(0)}) + \nabla\varphi(x^{(0)}) + A^T\nu\right)^T H_0^{-1}\left(t\nabla f_0(x^{(0)}) + \nabla\varphi(x^{(0)}) + A^T\nu\right),
```

其中

```math
H_0 = t\nabla^2 f_0(x^{(0)}) + \nabla^2\varphi(x^{(0)}).
```

（可以证明 $\inf_\nu\alpha(t,\nu)$ 就是 $tf_0 + \varphi$ 在 $x^{(0)}$ 处的 Newton decrement 的平方。）由于 $\alpha$ 是 $\nu$ 与 $t$ 的 quadratic-over-linear 函数，它是凸的。

<span style="color:#1e8449;">**[译注]** (11.12) 与下面的 $\alpha$ 只差一个 $H_0^{-1}$，但这个差决定 t 的初值是否有**物理意义**。$\|r\|_2$（$r$ 为残差 $t\nabla f_0 + \nabla\varphi + A^T\nu$）不是仿射不变量：把变量换成 $x' = Tx$，同一个问题的残差范数被 $\|T\|$ 缩放，于是同一个数学模型只因单位取「伏」还是「毫伏」就会选出相差 $10^6$ 倍的 $t^{(0)}$，外层次数随之差 $\log(10^6)/\log\mu \approx 6$ 次（$\mu = 10$）。而 $\alpha = r^TH_0^{-1}r$ 在 $x' = Tx$ 下不变：$r$ 变 $T^{-T}r$、$H_0$ 变 $T^{-T}H_0T^{-1}$，两者夹起来正好抵消。

**这里还藏着一个身份**：$\inf_\nu\alpha(t,\nu)$ **就是 Newton decrement 的平方** $\lambda(x^{(0)})^2$（对 $\nu$ 求最小即解 (11.12) 加权的 least-squares，解的残差正是 KKT 残量的最小范数部分）。所以「取使 (11.12) 最小的 $t^{(0)}$」等价于「取使初始点离中心最近的 $t^{(0)}$」，这条原则与 (11.13) 的外层计数用的是同一个量。

顺带纠正一种常见误读：(11.12) 是 $(t,\nu)$ 上的**联合**最小化，不是「先定 $t$ 再解 $\nu$」。固定 $t$ 时 $\nu$ 取加权 least-squares 解，代回即得 $t$ 的一元凸二次，有闭式解；若反过来先随便定 $t$ 再解 $\nu$，残差偏大的一侧惩罚轻、偏小的一侧重，得到的 $t^{(0)}$ 会系统性偏大，第一次 centering 就要多花步数。

**消失测试**：没有这个缩放，$t^{(0)}$ 就退化成靠「$m/\eta$ 猜一个」——在 $\eta$ 未知（无 dual feasible point）时只能取 $t^{(0)} = 1$，而若问题已按 $10^6$ 尺度缩放，第一次 centering 就要多花约 $\log(10^6)/\log\mu$ 个外层。

**落点**：Boyd §11.3.1 的 Choice of $t^{(0)}$ 与 (11.12)；$\lambda(x)^2$ 的仿射不变性见 §9.6.3；quadratic-over-linear 凸性见 §3.2.6。</span>

### Infeasible start Newton method · infeasible start Newton 变体

barrier method 的一种变体是：centering step 用 infeasible start Newton method（§10.3 描述）。于是 barrier method 用点 $x^{(0)}$ 初始化，满足 $x^{(0)} \in \operatorname{dom} f_0$ 且 $f_i(x^{(0)}) \lt 0,\ i = 1,\ldots,m$，但**不必**满足 $Ax^{(0)} = b$。假定问题 strictly feasible，则第一次 centering step 过程中某个时刻会走一个 full Newton step，此后所有迭代点都 primal feasible，算法与（标准的）barrier method **重合**。

本节考察 barrier method 的表现**作为问题维度的函数**。考虑标准形 LP

```math
\begin{aligned}
\text{minimize}\quad & c^Tx\\
\text{subject to}\quad & Ax = b,\quad x \succeq 0
\end{aligned}
```

其中 $A \in \mathbf{R}^{m\times n}$，并针对一族随机生成的问题实例，考察所需总 Newton 步数作为变量数 $n$ 与等式约束数 $m$ 的函数。取 $n = 2m$，即变量数为约束数的两倍。

问题按如下方式生成。$A$ 的元素独立同分布，服从零均值、单位方差的 normal distribution $N(0,1)$。取 $b = Ax^{(0)}$，其中 $x^{(0)}$ 的元素独立且均匀分布于 $[0,1]$。这保证问题**严格 primal feasible**（因为 $x^{(0)} \succ 0$ 可行）。为构造 cost 向量 $c$，先算一个元素服从 $N(0,1)$ 的向量 $z \in \mathbf{R}^m$ 与一个元素在 $[0,1]$ 上均匀分布的向量 $s \in \mathbf{R}^n$，再取 $c = A^Tz + s$。这保证问题**严格 dual feasible**，因为 $A^Tz \prec c$。

所用算法参数为 $\mu = 100$，centering step 的参数与上面各例相同：backtracking 参数 $\alpha = 0.01$、$\beta = 0.5$，停止准则 $\lambda(x)^2/2 \le 10^{-5}$。初始点在 central path 上，$t^{(0)} = 1$（即 gap 为 $n$）。当初始 duality gap 被缩小 $10^4$ 倍时终止——也就是**完成两次 outer iteration** 之后。

Figure 11.7 给出三个问题实例（$m = 50$、$m = 500$、$m = 1000$）的 duality gap 对迭代次数。图与其他几张很像，duality gap 近似线性收敛。从 50 条约束（100 个变量）增到 1000 条约束（2000 个变量），所需 Newton 步数只有**小幅增加**。

为考察问题规模对 Newton 步数的影响，我们对 $m$ 的 20 个取值（从 $m = 10$ 到 $m = 1000$）各生成 100 个实例，共 2000 个问题，用 barrier method 逐一求解并记录 Newton 步数。结果汇总在 Figure 11.8，给出每个 $m$ 上 Newton 步数的均值与标准差。

首先要说的是：标准差约为 $2$ 次迭代，且近似**与问题规模无关**。由于所需步数均值接近 $25$，这意味着所需 Newton 步数的波动只有 $\pm 10\%$ 左右。

图还显示：问题维度增大 $100$ 倍时，所需 Newton 步数只从约 $21$ 微增到约 $27$。这是 barrier method 的一般典型行为：**所需 Newton 步数随问题维度增长极慢，几乎总在几十步左右**。当然，执行一步 Newton 的计算量随问题维度增长。

### 11.3.3 Convergence analysis · 收敛性分析

barrier method 的收敛性分析是直接的。假定对 $t = t^{(0)}, \mu t^{(0)}, \mu^2t^{(0)},\ldots$，$tf_0 + \varphi$ 都能被 Newton 法最小化，则 initial centering step 之后、再加上 $k$ 次额外的 centering step 之后，duality gap 为 $m/\left(\mu^kt^{(0)}\right)$。因此要达到期望精度 $\epsilon$，恰好需要

```math
\left\lceil \frac{\log\left(m/(\epsilon t^{(0)})\right)}{\log\mu} \right\rceil
\qquad (11.13)
```

次 centering step，外加 initial centering step。

由此可知：只要对 $t \ge t^{(0)}$，centering 问题 (11.6) 能被 Newton 法求解，barrier method 就有效。对标准 Newton 法，只需对 $t \ge t^{(0)}$，函数 $tf_0 + \varphi$ 满足 §10.2.4（p.529）给出的条件：其初始 sublevel set 是闭的、相应的 inverse KKT matrix 有界、且 Hessian 满足 Lipschitz 条件。（另一组充分条件基于 self-concordance，将在 §11.5 详细讨论。）若 centering 用 infeasible start Newton method，则 §10.3.3（p.536）列出的条件足以保证收敛。

假定 $f_0,\ldots,f_m$ 都是闭的，对原问题做一个简单改动即可保证上述条件成立：向问题中加入形如 $\|x\|_2^2 \le R^2$ 的约束，于是 $tf_0 + \varphi$ 对每个 $t \ge 0$ 都是 strongly convex 的，特别地，centering step 中 Newton 法的收敛性得到保证。（见 exercise 11.4。）

这一分析虽然表明 barrier method 在合理假设下**确实**收敛，却没有回答一个基本问题：**$t$ 增大时，centering 问题是否会变得更难（因而需要越来越多迭代）？** 数值证据表明，对各种各样的问题，答案是否定的——即使 $t$ 增大，centering 问题似乎也只需**近乎常数**的 Newton 步数。我们将在 §11.5 看到，对满足某些 self-concordance 条件的问题，这一疑问可以彻底解决。

<span style="color:#1e8449;">**[译注]** (11.13) 是全块唯一的**闭式**计数，也是 §11.5 复杂度定理的骨架，值得逐符号读一遍。它断言 gap 走 $m/t^{(0)} \to m/\left(\mu t^{(0)}\right) \to \cdots$ 的等比序列，故 $k$ 次之后 gap $= m/\left(\mu^k t^{(0)}\right)$；要求它 $\le \epsilon$ 即 $\mu^k \ge m/(\epsilon t^{(0)})$，取对数并向上取整即得上式。

**代真数核一遍**：$m = 100$、$\epsilon = 10^{-6}$、$t^{(0)} = 1$、$\mu = 10$，得 $\left\lceil 8/\log_{10}10 \right\rceil = 8$ 次外层；$\mu = 2$ 时 $\left\lceil 8/0.301 \right\rceil = 27$；$\mu = 100$ 时 4 次。这与本块 p.570 那条按 Figure 11.4 反推的数字**完全一致**（27 次与图上 $\mu = 2$ 的台阶数吻合）。

**关键的隐藏前提**：公式里唯一不含迭代次数的部分是「每次 centering 都能被 Newton 解出来」——它被写成假设，而不是结论。§11.5 用 self-concordance 填的正是这个空：证明内层步数 $\le C$（常数，与 $t$ 无关），于是总步数 $\asymp C\log(m/(\epsilon t^{(0)}))/\log\mu$ 才成为真正的**复杂度**，而不是「步数统计」。取最坏情形最优的 $\mu$ 时得到 $O(\sqrt{m}\log(1/\epsilon))$ 阶——这条链的起点就是本式的对数结构。

**消失测试**：没有 (11.13)，你无法在跑之前回答「要不要跑 5 分钟还是 5 小时」；也无法解释为什么 $\mu$ 从 10 改成 100 只省一半外层而内层会涨。

**落点**：Boyd §11.3.3 的 (11.13)；充分条件列于 §10.2.4（p.529）与 §10.3.3（p.536）；$\sqrt{m}$ 阶见 §11.5.3 与 §11.5.5。</span>

### 11.3.4 Newton step for modified KKT equations · modified KKT 方程的 Newton 步

在 barrier method 中，Newton 步 $\Delta x_{\text{nt}}$ 与相应的对偶变量由线性方程给出：

```math
\begin{bmatrix}
t\nabla^2f_0(x) + \nabla^2\varphi(x) & A^T\\
A & 0
\end{bmatrix}
\begin{bmatrix}
\Delta x_{\text{nt}}\\
\nu_{\text{nt}}
\end{bmatrix}
= -
\begin{bmatrix}
t\nabla f_0(x) + \nabla\varphi(x)\\
0
\end{bmatrix}.
\qquad (11.14)
```

本节说明：centering 问题的这些 Newton 步，如何可以按一种**特定方式**解释成直接求解 modified KKT equations

```math
\begin{aligned}
\nabla f_0(x) + \sum_{i=1}^{m}\lambda_i\nabla f_i(x) + A^T\nu &= 0\\
-\lambda_i f_i(x) &= 1/t, \quad i = 1,\ldots,m\\
Ax &= b
\end{aligned}
\qquad (11.15)
```

的 Newton 步。



为求解 modified KKT 方程 (11.15)——这是 $n + p + m$ 个变量 $x,\nu,\lambda$ 上的 $n + p + m$ 个非线性方程——我们先利用 $\lambda_i = -1/\left(tf_i(x)\right)$ 消去变量 $\lambda_i$，得到

```math
\nabla f_0(x) + \sum_{i=1}^{m}\frac{1}{-tf_i(x)}\nabla f_i(x) + A^T\nu = 0,\qquad Ax = b,
\qquad (11.16)
```

这是 $n + p$ 个变量 $x,\nu$ 上的 $n + p$ 个方程。

为求求解非线性方程组 (11.16) 的 Newton 步，我们对第一式中出现的非线性项作 Taylor 近似。$v$ 很小时有

```math
\begin{aligned}
&\nabla f_0(x + v) + \sum_{i=1}^{m}\frac{1}{-tf_i(x + v)}\nabla f_i(x + v)\\
\approx\ & \nabla f_0(x) + \sum_{i=1}^{m}\frac{1}{-tf_i(x)}\nabla f_i(x) + \nabla^2f_0(x)v\\
&+ \sum_{i=1}^{m}\frac{1}{-tf_i(x)}\nabla^2f_i(x)v + \sum_{i=1}^{m}\frac{1}{tf_i(x)^2}\nabla f_i(x)\nabla f_i(x)^Tv.
\end{aligned}
```

把 (11.16) 中的非线性项用这个 Taylor 近似替换，即得 Newton 步所满足的线性方程

```math
Hv + A^T\nu = -g,\qquad Av = 0,
\qquad (11.17)
```

其中

```math
\begin{aligned}
H &= \nabla^2f_0(x) + \sum_{i=1}^{m}\frac{1}{-tf_i(x)}\nabla^2f_i(x) + \sum_{i=1}^{m}\frac{1}{tf_i(x)^2}\nabla f_i(x)\nabla f_i(x)^T\\
g &= \nabla f_0(x) + \sum_{i=1}^{m}\frac{1}{-tf_i(x)}\nabla f_i(x).
\end{aligned}
```

现在注意到

```math
H = \nabla^2f_0(x) + (1/t)\nabla^2\varphi(x),\qquad g = \nabla f_0(x) + (1/t)\nabla\varphi(x),
```

于是由 (11.14)，barrier method 的 centering step 中的 Newton 步 $\Delta x_{\text{nt}}$ 与 $\nu_{\text{nt}}$ 满足

```math
tH\Delta x_{\text{nt}} + A^T\nu_{\text{nt}} = -tg,\qquad A\Delta x_{\text{nt}} = 0.
```

与 (11.17) 比较可知

```math
v = \Delta x_{\text{nt}},\qquad \nu = (1/t)\nu_{\text{nt}}.
```

这表明：centering 问题 (11.6) 的 Newton 步，在**对偶变量缩放**之后，可以解释为求解 modified KKT 方程 (11.16) 的 Newton 步。

在这个做法中，我们先从 modified KKT 方程中**消去**变量 $\lambda$，再对所得方程组应用 Newton 法。这一做法的另一个变体是：不先消去 $\lambda$，直接对 modified KKT 方程应用 Newton 法。该变体给出所谓的 **primal-dual search direction**，将在 §11.7 讨论。

<span style="color:#1e8449;">**[译注]** 这一段的作用是**给后面 §11.7 的 primal-dual 方法预先埋下坐标**，而它的技术内容只有一个等式：$\nu = (1/t)\nu_{\text{nt}}$。这个 $1/t$ 不是笔误：代 $H = \nabla^2f_0 + (1/t)\nabla^2\varphi$、$g = \nabla f_0 + (1/t)\nabla\varphi$ 进 (11.17)，再整体乘 $t$，得 $tHv + A^T(t\nu) = -tg$——与 (11.14) 逐项相同，故 $v$ 一样而 $\nu$ 差一个 $t$。

**它的后果是可算的**：双变量在 barrier method 里被**高估 $t$ 倍**，这正是 (11.10) 要写 $\lambda_i^\star(t) = 1/\left(t\left(b_i - a_i^Tx^\star(t)\right)\right)$ 而**不是** $1/(b_i - a_i^Tx)$ 的原因。取 $t = 10^6$、某条约束的 slack 为 $10^{-3}$：不缩放的「乘子」是 $10^{3}$，缩放后是 $10^{-3}$——差 $10^6$ 倍。若读者拿未缩放的内部量当对偶解，duality gap $m/t$ 的恒等式立刻不成立。

**消失测试**：如果消去 $\lambda$ 后再解 Newton 方程（本页做法），得到的搜索方向对 $\lambda$ 的变化**不敏感**——因为 $\lambda$ 已被 $1/(tf_i)$ 硬绑定在 $x$ 上；而在远离 central path 的早期阶段这绑定是错的，方向质量差。§11.7 不消去 $\lambda$、把它当独立变量并加一个 centering 残差项，正是为了在 $x$ 离中心远时也能用好方向。

另一个后果落在实现上：因为 $\lambda$ 已被 $1/(tf_i)$ 绑定，barrier method 的**内部**没有独立的乘子自由度，外层每换一次 $t$ 就必须重算全部乘子；§11.7 的 primal-dual 方法保留 $\lambda$ 为独立变量，换来的是它不必做这个缩放，代价是要同时维护 $x,\lambda,\nu$ 三组量。

**落点**：Boyd §11.3.4 的 (11.14)-(11.17)；$\lambda_i^\star(t)$ 的 $1/t$ 见本块 p.567 与 (11.10)；primal-dual 方向见 §11.7；KKT matrix 的 block elimination 见 §10.4.1。</span>



## 11.4 Feasibility and phase I methods · 可行性与 phase I 方法

barrier method 需要一个 strictly feasible 的起始点 $x^{(0)}$。当这样的点未知时，barrier method 之前要有一个预备阶段，称为 **phase I**：在其中计算出一个 strictly feasible 点（或判定约束不可行）。phase I 中找到的 strictly feasible 点随后用作 barrier method 的起始点，而后者称为 **phase II** 阶段。本节描述几种 phase I 方法。

### 11.4.1 Basic phase I method · 基本 phase I 方法

考虑变量 $x \in \mathbf{R}^n$ 上的一组不等式与等式：

```math
f_i(x) \le 0,\quad i = 1,\ldots,m,\qquad Ax = b,
\qquad (11.18)
```

其中 $f_i : \mathbf{R}^n \to \mathbf{R}$ 是凸的，二阶导数连续。假定已给定点 $x^{(0)} \in \operatorname{dom} f_1 \cap \cdots \cap \operatorname{dom} f_m$，且 $Ax^{(0)} = b$。

目标是找出这些不等式与等式的一个 strictly feasible 解，或判定其不存在。为此构造如下优化问题：

```math
\begin{aligned}
\text{minimize}\quad & s\\
\text{subject to}\quad & f_i(x) \le s,\quad i = 1,\ldots,m\\
& Ax = b,
\end{aligned}
\qquad (11.19)
```

变量为 $x \in \mathbf{R}^n$、$s \in \mathbf{R}$。变量 $s$ 可解释为不等式**最大不可行度**（maximum infeasibility）的上界；目标是把最大不可行度压到零以下。

这个问题**总是** strictly feasible 的：对 $x$ 可取 $x^{(0)}$ 作起点，对 $s$ 可取任何大于 $\max_{i=1,\ldots,m}f_i(x^{(0)})$ 的数。因此可以对问题 (11.19) 应用 barrier method；该问题称为与不等式与等式系统 (11.18) 相关联的 **phase I optimization problem**。

> † 原文此处写作 "associated with the inequality and equality system (11.19)"，但 (11.19) 正是刚构造出来的 phase I 问题本身，被约束的那个系统是 (11.18)。按上下文，本译本改为 (11.18)（依据：同段前一句「我们的目标是找这些不等式与等式的一个 strictly feasible 解」指的只能是 (11.18)）。

按 (11.19) 的最优值 $\bar p^\star$ 的符号，可分三种情形。

1. 若 $\bar p^\star \lt 0$，则 (11.18) 有 strictly feasible 解。而且若 $(x,s)$ 对 (11.19) 可行且 $s \lt 0$，则 $x$ 满足 $f_i(x) \lt 0$。这意味着**不需要**把 (11.19) 解得很精确；只要 $s \lt 0$ 就可以终止。
2. 若 $\bar p^\star \gt 0$，则 (11.18) 不可行。与情形 1 一样，不需把 phase I 问题 (11.19) 解得很精确；一旦找到对偶目标为正的 dual feasible point（这证明了 $\bar p^\star \gt 0$）即可终止。此时还能从这个 dual feasible point 构造出证明 (11.18) 不可行的 **alternative**（Farkas 型证书）。
3. 若 $\bar p^\star = 0$ 且最小值在 $x^\star$、$s^\star = 0$ 处取到，则不等式组可行，但**不是 strictly** feasible。若 $\bar p^\star = 0$ 且最小值取不到，则不等式组不可行。



实践中不可能精确判定 $\bar p^\star = 0$。实际情形是：对 (11.19) 施行的优化算法会以「$|\bar p^\star| \lt \epsilon$（某个小的正数）」这一结论终止。于是可以断定：不等式 $f_i(x) \le -\epsilon$ 不可行，而不等式 $f_i(x) \le \epsilon$ 可行。

### Sum of infeasibilities · 不可行度之和

对刚描述的基本 phase I 方法有许多变体。其中一种基于最小化**不可行度之和**，而非最大不可行度。构造问题

```math
\begin{aligned}
\text{minimize}\quad & \mathbf{1}^Ts\\
\text{subject to}\quad & f_i(x) \le s_i,\quad i = 1,\ldots,m\\
& Ax = b\\
& s \succeq 0.
\end{aligned}
\qquad (11.20)
```

对固定的 $x$，$s_i$ 的最优值是 $\max\{f_i(x), 0\}$，故这个问题在最小化不可行度之和。(11.20) 的最优值为零，**当且仅当**原等式与不等式组可行时取到。

当等式与不等式系统不可行时，这个 sum-of-infeasibilities phase I 方法有一个很有趣的性质：此时 phase I 问题 (11.20) 的最优点常常只**违反少数几条**（设为 $r$ 条）不等式。因此我们算出的点满足其中很多（$m - r$）条不等式——也就是说，我们识别出了不等式的一个**大的可行子集**。此时，与被严格满足的那些不等式相关联的对偶变量为零，故我们同时证明了这些不等式**子集**的不可行性。这比「$m$ 条不等式合在一起互相冲突」这一结论信息量更大。（这一现象与 $\ell_1$-norm regularization、即用来求稀疏近似解的 basis pursuit 密切相关；见 §6.1.2 与 §6.5.4。）

<span style="color:#b45309;">**[Example 11.4]**</span> **Comparison of phase I methods（两种 phase I 方法的比较）。** 对一个不可行的不等式组 $Ax \preceq b$（$m = 100$、$n = 50$）应用两种 phase I 方法。第一种是 basic phase I 方法

```math
\text{minimize}\quad s \quad\text{subject to}\quad Ax \preceq b + \mathbf{1}s,
```

它最小化最大不可行度。第二种最小化不可行度之和，即求解 LP

```math
\begin{aligned}
\text{minimize}\quad & \mathbf{1}^Ts\\
\text{subject to}\quad & Ax \preceq b + s\\
& s \succeq 0.
\end{aligned}
```

Figure 11.9 给出两种解 $x$（分别记为 $x_{\text{max}}$ 与 $x_{\text{sum}}$）下不可行度 $b_i - a_i^Tx$ 的分布。点 $x_{\text{max}}$ 满足 100 条不等式中的 39 条，而 $x_{\text{sum}}$ 满足其中 79 条。

<span style="color:#1e8449;">**[译注]** 这一页最容易被读滑过去的是「**不需要把 phase I 解精确**」这句话的分量：它把 phase I 从「求最优值」降格为「**判号**」，代价随之从 $O(\log(1/\epsilon))$ 的迭代降到「首次越过 $s \lt 0$ 即停」。反面说明也在这里：当 $\bar p^\star$ 真就是 $0$（可行但非严格可行）时，判号原则**失效**——本块 p.583 明说此时 cost 变成无穷。

**第二个可算的点是 $x_{\text{sum}}$ 为什么更「有用」**。$\mathbf{1}^Ts$ 在 $\{s \ge f(x),\ s \ge 0\}$ 下的最优是 $\sum_i\max\{f_i(x),0\}$，这是一个 $\ell_1$ 型目标，它的等值面在原点有**尖角**——最优点因此倾向于把尽量多的分量压到**恰好为零**。这就是 39 对 79 的机制：$x_{\text{max}}$ 由 $\ell_\infty$ 型目标（只盯最坏一条，其余随便）选出，通常只有 39 条被满足；$x_{\text{sum}}$ 由 $\ell_1$ 型目标选出，尖角把 79 条压在 0 上。

**消失测试**：换成 $\sum_i s_i^2$（$\ell_2$）则没有尖角，最优解把误差**均摊**到 100 条上，一条也不严格满足——你得不到「哪 79 条能同时成立」这个信息，而这正是发现「约束集互相冲突的只是少数几条」的唯一入口。

**落点**：Boyd §11.4.1 与 Figure 11.9；$\ell_1$ 稀疏性与 basis pursuit 见 §6.1.2、§6.5.4；$\bar p^\star = 0$ 的退化见本块 p.583 末段。</span>

### Termination near the phase II central path · 终止在 phase II 的 central path 附近

basic phase I 方法的一个简单变体（用 barrier method 求解）具有这样的性质：当等式与不等式 strictly feasible 时，**phase I 问题的 central path 与原始优化问题 (11.1) 的 central path 相交**。

假定给定点 $x^{(0)} \in \mathcal{D} = \operatorname{dom} f_0 \cap \operatorname{dom} f_1 \cap \cdots \cap \operatorname{dom} f_m$，且 $Ax^{(0)} = b$。构造 phase I 优化问题

```math
\begin{aligned}
\text{minimize}\quad & s\\
\text{subject to}\quad & f_i(x) \le s,\quad i = 1,\ldots,m\\
& f_0(x) \le M\\
& Ax = b,
\end{aligned}
\qquad (11.21)
```

其中常数 $M$ 取为大于 $\max\{f_0(x^{(0)}), p^\star\}$。

现在假定原问题 (11.1) strictly feasible，于是 (11.21) 的最优值 $\bar p^\star$ 为负。(11.21) 的 central path 由下式刻画：

```math
\sum_{i=1}^{m}\frac{1}{s - f_i(x)} = \bar t,
```

以及

```math
\frac{1}{M - f_0(x)}\nabla f_0(x) + \sum_{i=1}^{m}\frac{1}{s - f_i(x)}\nabla f_i(x) + A^T\nu = 0,
```

其中 $\bar t$ 是参数。若 $(x,s)$ 在 central path 上且 $s = 0$，则 $x$ 与 $\nu$ 满足

```math
t\nabla f_0(x) + \sum_{i=1}^{m}\frac{1}{-f_i(x)}\nabla f_i(x) + A^T\nu = 0
```

其中 $t = 1/\left(M - f_0(x)\right)$。这意味着 $x$ 位于原问题 (11.1) 的 central path 上，相应的 duality gap 为……（续下页）

<span style="color:#1e8449;">**[译注]** 这个变体值得单独记，因为它把 phase I 的**收尾**变成了一件近乎免费的事：只要 $s = 0$ 那一刻 $x$ 落在 **phase II 的 central path 上**，那么 phase II 的 initial centering step 几乎零迭代就完成——对比之下，若 phase I 只给你一个任意可行点（可能在可行域深处、离中心很远），phase II 的第一步就要跑几十个 Newton 步。

**机制可以逐项核对**：phase I 的 barrier 是 $-\log(s - f_i)$，其对 $x$ 的梯度贡献是 $\nabla f_i/(s - f_i)$；在 $s = 0$ 处化为 $\nabla f_i/(-f_i)$，与原问题 barrier 的梯度**逐项相同**。剩下唯一的差别是对 $f_0$ 那一项：phase I 里它是 $\nabla f_0/(M - f_0)$，原问题是 $t\nabla f_0$，两者相等当且仅当

```math
t = \frac{1}{M - f_0(x)}.
```

于是 (11.22) 的 gap 上界 $m\left(M - f_0(x)\right) = m/t$ 就是原问题在这个 $t$ 下的 gap——**上下游的 $m/t$ 完全接上**。

**量的方向感**：$M$ 每取大一点，$t = 1/(M - f_0)$ 就小一点，落到 phase II 上的 $t$ 也更小，后续要爬的外层次数按 $\log\mu$ 增加。故 $M$ 不该乱取大，取 $\max\{f_0(x^{(0)}), p^\star\}$ 稍上方即可。

**消失测试**：不加 $f_0(x) \le M$ 这条约束，phase I 的 central path 是纯可行性问题的，它与原问题的 central path 一般**不相交**（原问题的 center 只由 $f_0$ 的等值面决定），上述「免费交接」全部失效。

**落点**：Boyd §11.4.1 的 (11.21) 与 (11.22)；$m/t$ 恒等式见本块 p.567 与本块 p.570 起 §11.3。</span>



```math
m\left(M - f_0(x)\right) \le m\left(M - p^\star\right).
\qquad (11.22)
```

### 11.4.2 Phase I via infeasible start Newton method · 用 infeasible start Newton 方法做 phase I

也可以用 infeasible start Newton method 来完成 phase I 阶段，把它应用到原问题的一个改动版本

```math
\begin{aligned}
\text{minimize}\quad & f_0(x)\\
\text{subject to}\quad & f_i(x) \le 0,\quad i = 1,\ldots,m\\
& Ax = b.
\end{aligned}
```

先把问题写成（显然等价的）形式

```math
\begin{aligned}
\text{minimize}\quad & f_0(x)\\
\text{subject to}\quad & f_i(x) \le s,\quad i = 1,\ldots,m\\
& Ax = b,\quad s = 0,
\end{aligned}
```

多引入一个变量 $s \in \mathbf{R}$。为启动 barrier method，用 infeasible start Newton method 求解

```math
\begin{aligned}
\text{minimize}\quad & t^{(0)}f_0(x) - \sum_{i=1}^{m}\log\left(s - f_i(x)\right)\\
\text{subject to}\quad & Ax = b,\quad s = 0.
\end{aligned}
```

它可以由任意 $x \in \mathcal{D}$ 与任意 $s \gt \max_i f_i(x)$ 初始化。只要问题 strictly feasible，infeasible start Newton method 最终会走一个**无阻尼步**（undamped step），此后就有 $s = 0$，即 $x$ strictly feasible。

若连函数公共定义域 $\mathcal{D}$ 中的一点都不知，同一技巧仍可用：直接对问题

```math
\begin{aligned}
\text{minimize}\quad & t^{(0)}f_0(x + z_0) - \sum_{i=1}^{m}\log\left(s - f_i(x + z_i)\right)\\
\text{subject to}\quad & Ax = b,\quad s = 0,\quad z_0 = 0,\ \ldots,\ z_m = 0
\end{aligned}
```

应用 infeasible start Newton method，变量为 $x, z_0,\ldots,z_m$ 与 $s \in \mathbf{R}$，并把 $z_i$ 初始化为使 $x + z_i \in \operatorname{dom} f_i$。

这种 phase I 做法的主要**缺点**是：问题不可行时**没有好的 stopping criterion**——残差只是不收敛到零而已。

## 11.5 Complexity analysis via self-concordance · 经由 self-concordance 的复杂度分析

利用 self-concordant 函数上 Newton 法的复杂度分析（§9.6.4，p.503；§10.2.4，p.531），可以给出 barrier method 的复杂度分析。该分析适用于许多常见问题，并引出几个有趣结论：它给出用 barrier method 求解一个问题所需总 Newton 步数的**严格上界**，并且**证实**了我们此前的观察——centering 问题不会随 $t$ 增大而变难。



### 11.5.1 Self-concordance assumption · self-concordance 假设

我们作两个假设。

- 函数 $tf_0 + \varphi$ 对所有 $t \ge t^{(0)}$ 是闭的且 **self-concordant**。
- (11.1) 的 sublevel sets 有界。

第二个假设意味着 centering 问题具有有界的 sublevel sets（见 exercise 11.3），因此 centering 问题可解。有界 sublevel set 假设还意味着 $tf_0 + \varphi$ 的 Hessian 处处正定（见 exercise 11.14）。虽然 self-concordance 假设把复杂度分析限制在一类特定问题上，但必须强调：**无论 self-concordance 假设是否成立，barrier method 一般都能工作得很好**。

self-concordance 假设对多种问题成立，包括所有线性与二次问题。若 $f_i$ 是线性或二次的，则

```math
tf_0 - \sum_{i=1}^{m}\log(-f_i)
```

对所有 $t \ge 0$ 都是 self-concordant（见 §9.6）。因此下面的复杂度分析适用于 LP、QP 与 QCQP。

其他情形下，可以把问题**改写**使 self-concordance 假设成立。例如考虑线性不等式约束的 entropy maximization 问题

```math
\begin{aligned}
\text{minimize}\quad & \sum_{i=1}^{n}x_i\log x_i\\
\text{subject to}\quad & Fx \preceq g\\
& Ax = b.
\end{aligned}
```

函数

```math
tf_0(x) + \varphi(x) = t\sum_{i=1}^{n}x_i\log x_i - \sum_{i=1}^{m}\log\left(g_i - f_i^Tx\right),
```

其中 $f_1^T,\ldots,f_m^T$ 是 $F$ 的各行，**既不是闭的**（除非 $Fx \preceq g$ 蕴含 $x \succeq 0$），**也不是 self-concordant** 的。然而，我们可以加上冗余的不等式约束 $x \succeq 0$，得到等价问题

```math
\begin{aligned}
\text{minimize}\quad & \sum_{i=1}^{n}x_i\log x_i\\
\text{subject to}\quad & Fx \preceq g\\
& Ax = b\\
& x \succeq 0.
\end{aligned}
\qquad (11.23)
```

对这个新问题有

```math
tf_0(x) + \varphi(x) = t\sum_{i=1}^{n}x_i\log x_i - \sum_{i=1}^{n}\log x_i - \sum_{i=1}^{m}\log\left(g_i - f_i^Tx\right),
```

它在 $t$ 足够大时是 self-concordant 的（原书下一页给出确切的 $t$ 下界，此处不复述以免与原文冲突），从而 §11.5 余下的复杂度结论对其适用。

（原文在此页末句中断，续于 p.587；函数值的界与内层步数上界见 §11.5.2 起。）

<span style="color:#1e8449;">**[译注]** 这里「**加冗余约束**」这一步是全章最反直觉、也最有工程价值的技巧：加上去的 $x \succeq 0$ 在数学上完全多余（$x_i\log x_i$ 的定义域里本来就有 $x_i \ge 0$），但它把 barrier 从 $m$ 项变成 $n + m$ 项，从而让 $tf_0 + \varphi$ 变成 **self-concordant**。

**机制可以点明**：$- \sum_i \log x_i$ 是 $-\sum_i\log(g_i - f_i^Tx)$ 的「同族」障碍项，而 $tf_0 = t\sum x_i\log x_i$ 的二阶导是 $\operatorname{diag}(t/x_i) \succ 0$；两项合起来，三阶导被二阶导**控制**（Section 9.6 的 self-concordance 判据是 $|f'''| \le 2f''^{3/2}$），对数项恰好满足等号。少了 $-\sum\log x_i$，函数在 $x_i \to 0^+$ 处不闭，self-concordance 判据在边界失效。

**代价是可算的**：约束数从 $m$ 变成 $m + n$。若 $n = 100$、$m = 100$，$m/t$ 的 gap 系数翻倍，同一精度要多花 $\log 2/\log\mu$ 个外层（$\mu = 10$ 时是 0.3 次，可忽略）；但每步 Newton 的矩阵只多 $n$ 个对角块，成本几乎不变。**用「约束数翻倍」换「复杂度定理可用」，这笔交易极其划算**——这也是内点法实现里到处能看到冗余非负约束的原因。

**消失测试**：不加 $x \succeq 0$，§11.5.2 的复杂度界不能直接引用；工程上你仍能跑（Boyd 明说 "barrier method works well in general"），但你失去了**跑之前**就能断言步数的唯一依据。

**落点**：Boyd §11.5.1 与 (11.23)；self-concordance 判据与三阶导数界见 §9.6.1-§9.6.3（p.496 起）；entropy maximization 的原始形式见 §7.2。</span>

```math
\begin{aligned}
\text{minimize} \quad & f_0(x) = \log\left(\sum_{k=1}^{K_0}\exp(a_{0k}^Tx + b_{0k})\right)\\
\text{subject to} \quad & \log\left(\sum_{k=1}^{K_i}\exp(a_{ik}^Tx + b_{ik})\right) \le 0, \quad i = 1,\ldots,m.
\end{aligned}
```

并不清楚函数

```math
\begin{aligned}
tf_0(x) + \varphi(x) = {} & t\log\left(\sum_{k=1}^{K_0}\exp(a_{0k}^Tx + b_{0k})\right)\\
& - \sum_{i=1}^{m}\log\left(-\log\left(\sum_{k=1}^{K_i}\exp(a_{ik}^Tx + b_{ik})\right)\right)
\end{aligned}
```

是否 self-concordant，所以尽管 barrier method 能用，这一节的 complexity analysis 却**不一定成立**。

不过我们可以把该 GP 改写成一个**肯定**满足 self-concordance 假设的形式。对每个（monomial）项 $\exp(a_{ik}^Tx + b_{ik})$ 引入一个新变量 $y_{ik}$ 充当它的上界，

```math
\exp(a_{ik}^Tx + b_{ik}) \le y_{ik}.
```

用这些新变量，可把该 GP 写成

```math
\begin{aligned}
\text{minimize} \quad & \sum_{k=1}^{K_0} y_{0k}\\
\text{subject to} \quad & \sum_{k=1}^{K_i} y_{ik} \le 1, \quad i = 1,\ldots,m\\
& a_{ik}^Tx + b_{ik} - \log y_{ik} \le 0, \quad i = 0,\ldots,m,\ k = 1,\ldots,K_i\\
& y_{ik} \ge 0, \quad i = 0,\ldots,m,\ k = 1,\ldots,K_i.
\end{aligned}
```

相应的 logarithmic barrier 是

```math
\sum_{i=0}^{m}\sum_{k=1}^{K_i}\left(-\log y_{ik} - \log(\log y_{ik} - a_{ik}^Tx - b_{ik})\right) - \sum_{i=1}^{m}\log\left(1 - \sum_{k=1}^{K_i} y_{ik}\right),
```

它是 closed 且 self-concordant 的（example 9.8，page 500）。由于目标函数是线性的，于是 $tf_0 + \varphi$ 对任何 $t$ 都 closed 且 self-concordant。

<span style="color:#1e8449;">**[译注]** 这个改写是本节唯一一处**为了拿到复杂度界而改变问题本身**的动作，值得把机制讲透。原式里每一项都被包进 $\log\sum\exp$，再被包进 $-\log(-\cdot)$，构成三层复合；而 self-concordance 判据是三阶导被二阶导控制（$|f'''| \le 2f''^{3/2}$，§9.6.1）。当某条约束趋于 active 时，内层 $\log\sum\exp \to 0^-$，外层 $-\log$ 的三阶导增长快过 $f''^{3/2}$，判据失效——书中说"并不清楚"，准确含义是**已知判据套不上**，不是没试过。

引入 $y_{ik}$ 后，每条 monomial 独立成 $-\log y_{ik} - \log(\log y_{ik} - a_{ik}^Tx - b_{ik})$，两项各自是 example 9.8 里核过的标准组件，再用 §3.6.2 的 composition rule 保 convexity。

**代价可数**：变量数从 $n$ 涨到 $n + \sum_{i=0}^{m}K_i$；若每条约束有 10 个 monomial、$m = 100$，就是 $n + 1010$ 个新变量，问题规模涨约一个数量级。

**消失测试**：不改写，你只剩 "barrier method works" 这句实践说法，拿不到 (11.26) 那种"连改 $\mu$ 也不涨"的统一界，也就无法在跑之前断言步数。

**方向感**：无论 $K_i$ 多大，改写后每一维新变量只增加 2 项 barrier，且不引入任何新的 self-concordance 判定负担——这正是“标准组件 + composition rule”的工程价值：复杂度是**加法**而不是重新证明。

**落点**：Boyd §9.6.1-§9.6.3（判据与组件，p.496 起）；example 9.8（p.500）；§4.5（GP 标准形与 monomial 记号）；exercise 11.13。</span>

### 11.5.2 Newton iterations per centering step · 每个 centering step 的 Newton 迭代数

§9.6.4（page 503）与 §10.2.4（page 531）建立的、针对 self-concordant 函数的 Newton 法复杂度理论表明：要最小化一个 closed、strictly convex、self-concordant 的函数 $f$，所需 Newton 迭代数有上界

```math
\frac{f(x)-p^\star}{\gamma} + c.
\qquad (11.24)
```



这里 $x$ 是 Newton 法的起点，$p^\star = \inf_x f(x)$ 是最优值。常数 $\gamma$ 只依赖 backtracking 参数 $\alpha$ 与 $\beta$，由下式给出：

```math
\frac{1}{\gamma} = \frac{20 - 8\alpha}{\alpha\beta(1 - 2\alpha)^2}.
```

常数 $c$ 只依赖容差 $\epsilon_{\mathrm{nt}}$，

```math
c = \log_2\log_2(1/\epsilon_{\mathrm{nt}}),
```

并且可以合理地近似取 $c = 6$。表达式 (11.24) 是对所需 Newton 步数**相当保守**的界，但本节兴趣只在建立 complexity bound，关心它如何随问题规模与算法参数增长。

本节用这个结果导出 barrier method **一次 outer iteration**（即从 $x^\star(t)$ 出发算出 $x^\star(\mu t)$）所需 Newton 步数的界。为减轻记号负担，用 $x$ 表示 $x^\star(t)$（当前迭代点），用 $x^+$ 表示 $x^\star(\mu t)$（下一个迭代点）；用 $\lambda$ 与 $\nu$ 分别表示 $\lambda^\star(t)$ 与 $\nu^\star(t)$。

self-concordance 假设蕴含

```math
\frac{\mu tf_0(x) + \varphi(x) - \mu tf_0(x^+) - \varphi(x^+)}{\gamma} + c
\qquad (11.25)
```

是从 $x = x^\star(t)$ 出发计算 $x^+ = x^\star(\mu t)$ 所需 Newton 步数的上界。不幸的是，在真正算出 $x^+$ 之前我们并不知道 $x^+$，因而也不知道上界 (11.25)——而一旦真把 Newton 算法跑完，就已经知道精确步数了，正好消解了这个界的意义。不过我们可以如下推出 (11.25) 的一个上界：

```math
\begin{aligned}
&\mu tf_0(x) + \varphi(x) - \mu tf_0(x^+) - \varphi(x^+)\\
={}& \mu tf_0(x) - \mu tf_0(x^+) + \sum_{i=1}^{m}\log\left(-\mu t\lambda_i f_i(x^+)\right) - m\log\mu\\
\le{}& \mu tf_0(x) - \mu tf_0(x^+) - \mu t\sum_{i=1}^{m}\lambda_i f_i(x^+) - m - m\log\mu\\
={}& \mu tf_0(x) - \mu t\left(f_0(x^+) + \sum_{i=1}^{m}\lambda_i f_i(x^+) + \nu^T(Ax^+ - b)\right) - m - m\log\mu\\
\le{}& \mu tf_0(x) - \mu t\,g(\lambda,\nu) - m - m\log\mu\\
={}& m(\mu - 1 - \log\mu).
\end{aligned}
```

这一串等式与不等式需要解释。要由第一行得到第二行，用 $\lambda_i = -1/\left(tf_i(x)\right)$。第一个不等式中用事实 $\log a \le a - 1$（$a \gt 0$）。要由第三行得到第四行，用 $Ax^+ = b$，于是多出来的项 $\nu^T(Ax^+ - b)$ 为零。第二个不等式来自对偶函数的定义：

```math
\begin{aligned}
g(\lambda,\nu)
={}& \inf_z\left(f_0(z) + \sum_{i=1}^{m}\lambda_i f_i(z) + \nu^T(Az - b)\right)\\
\le{}& f_0(x^+) + \sum_{i=1}^{m}\lambda_i f_i(x^+) + \nu^T(Ax^+ - b).
\end{aligned}
```

末行由 $g(\lambda,\nu) = f_0(x) - m/t$ 得到。（续下页）

<span style="color:#1e8449;">**[译注]** 这段的技术心脏是**破除自指**：上界 (11.25) 里含着尚未算出的 $x^+$，直接用它等于"先算完再声明界"。作者用三件**已知**事实把它换成闭式——① centrality 条件给的 $\lambda_i = -1/\left(tf_i(x)\right)$；② 等式约束的可行性 $Ax^+ = b$；③ central point 的对偶值 $g(\lambda,\nu) = f_0(x) - m/t$。

第一行到第二行是唯一"不显然"的一步，拆开算：$\varphi(x)-\varphi(x^+) = \sum_i\log\frac{-f_i(x^+)}{-f_i(x)}$，而 $-f_i(x) = 1/(t\lambda_i)$，故比值为 $-t\lambda_i f_i(x^+)$，再乘 $\mu$ 除 $\mu$ 就得到 $\sum_i\log\left(-\mu t\lambda_i f_i(x^+)\right) - m\log\mu$。

最后一行给出可数的量：$\mu = 10$ 时 $10 - 1 - \log 10 = 6.697$；$\mu = 100$ 时是 $94.395$；$\mu = 1.5$ 时只有 $0.0945$。这个函数在 $\mu \to 1$ 时按 $\frac{(\mu-1)^2}{2}$ 衰减、在 $\mu$ 大时按 $\mu$ 线性增长，正好量化了"$t$ 一次跳太远，内层就还债"。

**消失测试**：没有这一步，(11.26) 写不出来，§11.5.3 的 (11.27) 就少了一个因子，§11.5 的总步数界塌回"每步都可能是无穷"。

**方向感**：五步链条把界从“含未知 $x^+$ 的量”压成“只含 $\mu$ 与 $m$ 的闭式”，代价是界变松——第一处 $\log a \le a-1$ 在 $a$ 远离 1 时就差出常数倍，这是 (11.26) 与实测差三个数量级的第一个来源。

**落点**：Boyd §11.3.3 的 (11.13)（外层步数）；§11.2 的 (11.6)（central path 的 $\lambda_i(t) = -1/(tf_i(x))$）；§9.6.4 里 (11.24) 的原始定理。</span>



[Figure 11.13：$\mu - 1 - \log\mu$ 关于 $\mu$ 的曲线，横轴 $\mu$ 取 $1$ 到 $3$（刻度 1、1.5、2、2.5、3），纵轴 $0$ 到 $1$。曲线在 $\mu = 1$ 处取 $0$，$\mu = 1.5$ 处约 $0.095$，$\mu = 2$ 处约 $0.307$，$\mu = 3$ 处约 $0.901$。这条曲线就是 barrier method 一次 outer iteration 的 Newton 步数上界 $\frac{m}{\gamma}(\mu - 1 - \log\mu) + c$ 里那个因子——它把"$\mu$ 取多大"这个超参数选择变成一条可读的曲线：$\mu$ 靠近 1 时因子按 $(\mu-1)^2/2$ 抛物线式趋零，但外层数按 $1/\log\mu$ 发散；$\mu$ 大时因子近似线性增长。图上数值按曲线可读位置给出，非原书标注。]

**Figure 11.13** The function $\mu - 1 - \log\mu$, versus $\mu$. The number of Newton steps required for one outer iteration of the barrier method is bounded by $\frac{m}{\gamma}(\mu - 1 - \log\mu) + c$.
（图 11.13：函数 $\mu - 1 - \log\mu$ 关于 $\mu$ 的图象。barrier method 一次 outer iteration 所需 Newton 步数以 $\frac{m}{\gamma}(\mu - 1 - \log\mu) + c$ 为上界。）

结论是

```math
\frac{m(\mu - 1 - \log\mu)}{\gamma} + c
\qquad (11.26)
```

是 (11.25) 的上界，因而也是 barrier method 一次 outer iteration 所需 Newton 步数的上界。函数 $\mu - 1 - \log\mu$ 见图 11.13：$\mu$ 小时它近似二次，$\mu$ 大时近似线性增长。这与直觉吻合——$\mu$ 接近 1 时把点"居中"（center）所需的 Newton 步数很小，而 $\mu$ 很大时步数完全可能涨上去。

界 (11.26) 表明：每个 centering step 所需 Newton 步数被一个量界住，该量**主要**依赖 $\mu$（outer step 中更新 $t$ 的倍率）与 $m$（inequality constraint 的个数）；它也（弱地）依赖内层迭代 line search 用的参数 $\alpha$ 与 $\beta$，并以**很弱**的方式依赖终止内层迭代所用的容差。值得一提的是：这个界不依赖变量维数 $n$，不依赖 equality constraint 个数 $p$，也不依赖问题数据（目标函数与约束函数）的具体取值——只要 §11.5.1 的 self-concordance 假设成立。最后要注意它也不依赖 $t$；特别地，当 $t \to \infty$ 时，每个 outer iteration 的 Newton 步数仍有**一致的界**。

<span style="color:#1e8449;">**[译注]** 这里必须替读者做一次**数值对账**，因为书里两个 $\gamma$ 的取值相差一个量级而正文没点破。代入 §11.3.2 实际用的 backtracking 参数 $\alpha = 0.01$、$\beta = 0.5$：

```math
\frac{1}{\gamma} = \frac{20 - 8(0.01)}{0.01 \cdot 0.5 \cdot (1 - 0.02)^2} = \frac{19.92}{0.004802} \approx 4148,
```

即 $\gamma \approx 2.41\times10^{-4}$。而 p590 画 Figure 11.14 时取的是 $\gamma = 1/375$，即 $\frac{1}{\gamma} = 375$——**比标准参数下的值乐观约 11 倍**。（反解可见：$\beta = 0.5$ 时 $\frac{1}{\gamma}$ 随 $\alpha$ 变化的最小值约 503，出现在 $\alpha \approx 0.175$，永远到不了 375；要凑出 375 需要 $\beta \approx 0.68$ 一类的参数。）于是 Figure 11.14 上"最小上界约 8000 步"在 $\alpha = 0.01,\beta = 0.5$ 下应放大到约 $8.8\times10^4$ 步。

**方向感**：界对 $\gamma$ 是**线性**进入的（$\frac{m}{\gamma}$ 项主导，$c = 6$ 可忽略），所以 $\gamma$ 差 11 倍、步数界就差 11 倍；而实测总步数始终在几十量级（§11.3.2 的 LP 例、本块图 11.20 的 SDP 例）。差三个数量级，正是 §11.5.6 说"这些界远高于实际观测"的算术来源。

**消失测试**：若 (11.26) 不依赖 $t$ 这一点不成立，那么随着 $t^{(k)} = \mu^k t^{(0)}$ 增长，没人能排除"越到后期每步越难"，barrier method 的总步数就退化成不可预测的和式。

**落点**：Boyd §9.6.4（$\gamma$ 的原定义）；本块 p588 的 $\frac{1}{\gamma}$ 公式；§11.3.2（$\alpha = 0.01$、$\beta = 0.5$）；p590 的 Figure 11.14 参数行。</span>



### 11.5.3 Total number of Newton iterations · Newton 迭代总数

现在可以给出 barrier method 中 Newton 步数**总数**的上界（不计最初的 centering step，那一步留到 phase I 里分析）。把界住每次 outer iteration 步数的 (11.26) 乘以界住 outer step 个数的 (11.13)，得到

```math
N = \left\lceil \frac{\log\left(m/(t^{(0)}\epsilon)\right)}{\log\mu} \right\rceil \left(\frac{m(\mu - 1 - \log\mu)}{\gamma} + c\right),
\qquad (11.27)
```

即所需 Newton 步数总数的上界。这个公式说明：当 self-concordance 假设成立时，对**任何** $\mu \gt 1$ 的取值，我们都能界住 barrier method 所需的 Newton 步数。

若固定 $\mu$ 与 $m$，界 $N$ 正比于 $\log\left(m/(t^{(0)}\epsilon)\right)$，即初始 duality gap $m/t^{(0)}$ 与最终 duality gap $\epsilon$ 之比的对数——也就是所需 duality gap 缩减倍率的对数。因此可以说 barrier method **至少线性收敛**：达到给定精度所需步数只随精度的倒数**对数**增长。

若固定 $\mu$ 与所需 duality gap 缩减因子，则界 $N$ 随 $m$（不等式个数）**线性**增长。界 $N$ 与其他问题维数 $n$、$p$ 无关，也与具体问题数据或函数无关。下面会看到：只要 $\mu$ 的取法依赖 $m$，就能让 Newton 步数的界只按 $\sqrt{m}$ 增长，而不是按 $m$ 增长。

最后分析界 $N$ 作为算法参数 $\mu$ 的函数。当 $\mu$ 趋向 1，$N$ 中第一项变大，$N$ 随之变大——这与直觉和观测一致：$\mu$ 接近 1 时 outer iteration 数非常多。当 $\mu$ 变大，$N$ 近似按 $\mu/\log\mu$ 增长，这一次来源是"每次 outer iteration 所需的 Newton 步数上界"在增长。这也与观测一致。因此界 $N$ 作为 $\mu$ 的函数存在**最小值**。

界随参数 $\mu$ 的变化见图 11.14，它画的是 (11.27) 在下列取值下关于 $\mu$ 的曲线：

```math
c = 6, \qquad \gamma = 1/375, \qquad m/(t^{(0)}\epsilon) = 10^5, \qquad m = 100.
```

这个界在定性上与直觉和观测一致：$\mu$ 趋近 1 时它变得非常大，$\mu$ 变大时它（较缓慢地）上升。界 $N$ 在 $\mu \approx 1.02$ 处取到最小值，对应 Newton 迭代总数上界约 8000。Newton 法的 complexity analysis 偏保守，但 **$\mu$ 取值上的那个基本权衡**在图里被如实反映了。（实践中大得多的 $\mu$——大约从 2 到 100——工作得很好，所需 Newton 迭代总数在几十的量级。）

#### Choosing $\mu$ as a function of $m$ · 把 $\mu$ 取成 $m$ 的函数

当 $\mu$（以及所需 duality gap 缩减）固定时，界 (11.27) 随 $m$（不等式个数）线性增长。可以做到更好的

……$m$ 的指数。只要让 $\mu$ 成为 $m$ 的函数：取

```math
\mu = 1 + 1/\sqrt{m}.
\qquad (11.28)
```

那么我们能把 (11.27) 中第二个因子界住：

```math
\begin{aligned}
\mu - 1 - \log\mu
={}& 1/\sqrt{m} - \log(1 + 1/\sqrt{m})\\
\le{}& 1/\sqrt{m} - 1/\sqrt{m} + 1/(2m)\\
={}& 1/(2m)
\end{aligned}
```

（用的是 $\log(1+a) \le a - a^2/2$，$a \ge 0$ 时成立）。利用对数的 concavity，还有

```math
\log\mu = \log(1 + 1/\sqrt{m}) \ge (\log 2)/\sqrt{m}.
```

用这两条不等式，可把 Newton 步数总数界住：

```math
\begin{aligned}
N
&\le \left\lceil \frac{\log\left(m/(t^{(0)}\epsilon)\right)}{\log\mu} \right\rceil \left(\frac{m(\mu - 1 - \log\mu)}{\gamma} + c\right)\\
&\le \left\lceil \frac{\sqrt{m}\log\left(m/(t^{(0)}\epsilon)\right)}{\log 2} \right\rceil \left(\frac{1}{2\gamma} + c\right)\\
&= \left\lceil \sqrt{m}\log_2\left(m/(t^{(0)}\epsilon)\right) \right\rceil \left(\frac{1}{2\gamma} + c\right)\\
&\le c_1 + c_2\sqrt{m},
\end{aligned}
\qquad (11.29)
```

其中

```math
c_1 = \frac{1}{2\gamma} + c, \qquad c_2 = \log_2\left(m/(t^{(0)}\epsilon)\right)\left(\frac{1}{2\gamma} + c\right).
```

<span style="color:#1e8449;">**[译注]** 这里两条不等式分工明确，值得逐个验算，因为**第二条才是全部技巧所在**。第一条是标准 Taylor 上界：对 $a \ge 0$ 有 $\log(1+a) \le a - a^2/2$，取 $a = 1/\sqrt{m}$ 得 $\mu - 1 - \log\mu \le \frac{1}{2m}$，于是 $m(\mu - 1 - \log\mu) \le \frac{1}{2}$——**$m$ 被彻底消掉**，这才是 (11.28) 的真实用意：不是让 $\mu$ 变小，而是让 $\mu$ 趋近 1 的速度恰好抵消 $m$ 的增长。

第二条要的是**反方向**的下界，否则分母 $\log\mu$ 会失控。$\log$ 在 $[1,2]$ 上 concave，图象在端点连线上方；端点 $(1,0)$、$(2,\log 2)$ 连线斜率为 $\log 2$，故

```math
\log(1+a) \ge a\log 2, \qquad 0 \le a \le 1.
```

取 $a = 1/\sqrt{m} \le 1$（$m \ge 1$）即得。两条合起来：外层数乘上 $\frac{\sqrt{m}}{\log 2}$，内层数只到 $\frac{1}{2\gamma}+c$，乘积就是 (11.29) 的 $\sqrt{m}$ 阶。

**方向感可数**：$m = 10^4$ 时，$m$ 线性界给 $10^4\left(\frac{1}{2\gamma}+c\right)$，$\sqrt{m}$ 界给 $100\left(\frac{1}{2\gamma}+c\right)$，差**两个数量级**。这就是 "order $\sqrt{m}$ method" 这个名字的来源。

**消失测试**：不给 (11.28) 这种 $m$-依赖取法，$N$ 永远是 $O(m)$，10 万条约束的内点法在理论上要多付 $10^2$ 倍步数预算，早期内点法论文里 "polynomial time" 就只剩 $O(m)$ 这一档。

（顺带一句：$c_2$ 里也含 $\log_2(m/(t^{(0)}\epsilon))$，所以“$\sqrt m$ 阶”严格说是 $\sqrt m$ 乘以问题的位数。）

**落点**：Boyd §11.5.3 的 (11.27)；$\log$ 的 concavity 在这里的用法与 6.042J 的 chord 论证是同一件事；实际推荐值见 §11.3.3（$\mu = 10$ 量级）。</span>



这里 $c_1$ 依赖（且只弱依赖）centering 那批 Newton 步的算法参数，$c_2$ 则同时依赖这些参数与所需的 duality gap 缩减。注意 $\log_2\left(m/(t^{(0)}\epsilon)\right)$ 这一项恰好就是所需 duality gap 缩减的**比特数**。

若 duality gap 缩减固定，界 (11.29) 按 $\sqrt{m}$ 增长；而参数 $\mu$ 固定时，(11.27) 里的界 $N$ 按 $m$ 增长。正因为如此，取参数值 (11.28) 的 barrier method 被称为 **order $\sqrt{m}$ method**。

实践中我们不会真去用 $\mu = 1 + 1/\sqrt{m}$ 这个值——它太小了——更不会把 $\mu$ 当作 $m$ 的函数去**减小**它。我们对这个 $\mu$ 取值的唯一兴趣在于：它（近似地）最小化我们对 Newton 步数的那个（非常保守的）上界，从而给出一个按 $\sqrt{m}$ 而非按 $m$ 增长的整体估计。

### 11.5.4 Feasibility problems · 可行性问题

本节分析 §11.4.1 描述的基本 phase I method 的一个（较小的）变体，它用来解一组 convex inequality

```math
f_1(x) \le 0, \quad \ldots, \quad f_m(x) \le 0,
\qquad (11.30)
```

其中 $f_1,\ldots,f_m$ 为凸、二阶连续可微。（equality constraint 的情况稍后再考虑。）我们假定 phase I problem

```math
\begin{aligned}
\text{minimize} \quad & s\\
\text{subject to} \quad & f_i(x) \le s, \quad i = 1,\ldots,m
\end{aligned}
\qquad (11.31)
```

满足 §11.5.1 中的条件。特别地，假定不等式组 (11.30) 的可行集（当然可能是空集）含在一个半径为 $R$ 的 Euclidean ball 内：

```math
\{x \mid f_i(x) \le 0,\ i = 1,\ldots,m\} \subseteq \{x \mid \|x\|_2 \le R\}.
```

我们可以把 $R$ 理解为"不等式组可行集内任意一点的范数的**先验界**"。这个假设蕴含 phase I problem 的 sublevel set 有界。不失一般性，把 phase I method 的起点取在 $x = 0$。定义 $F = \max_i f_i(0)$，即最大约束违背量，并假定它为正（否则 $x = 0$ 就已满足 (11.30)）。

定义 $\bar p^\star$ 为 phase I 优化问题 (11.31) 的最优值。$\bar p^\star$ 的**符号**决定不等式组 (11.30) 是否 feasible。

$\bar p^\star$ 的**大小**也有含义。若 $\bar p^\star$ 为正且大（比如说接近 $F$，即它可能取到的最大值），说明这组不等式**相当不可行**：对每个 $x$，至少有一条不等式被实质性违背（违背量至少 $\bar p^\star$）。反之，若 $\bar p^\star$ 为负且绝对值大，说明这组不等式**相当可行**：不但存在使所有 $f_i(x) \le 0$ 的 $x$，而且存在使所有 $f_i(x)$ 都相当负（不超过 $\bar p^\star$）的 $x$。因此 $|\bar p^\star|$ 是"这组不等式究竟有多明确地可行或不可行"的度量，从而关系到判定可行性的难度。

<span style="color:#1e8449;">**[译注]** 这个 $R$ 不是数学装饰，它是**整套复杂度分析的地基**。phase I 把"是否存在 $x$ 使 $f_i(x)\le 0$"改写成"$\min s$ 是否 $\le 0$"；若可行集无界，$s$ 的最优值可能在 $s = 0$ 处都取不到，$f_i(x) - s$ 的 sublevel set 就无界，而 §11.5.1 要求的 bounded sublevel set 与 closedness 同时失效，于是 (11.24) 那套 Newton 步数界**一步都用不上**。

有了 $\|x\|_2 \le R$，紧接着 p593 就能造出一条**冗余**线性不等式 $a^Tx \le 1$，把 feasible 区域整体套进一个已知的仿射半空间。这条约束在数学上完全多余（它是被 $\|x\|_2\le R$ 蕴含的），但它含有**一个可自由选择的 $a$**，而 $a$ 同时出现在 central path 的一阶条件里——这就给了我们一个旋钮，把起点 $x = 0$ 强行摆到 central path 上。换句话说：$R$ 先买来"有界"，再由"有界"换来"起点可构造"。

**消失测试**：不给 $R$，初始 duality gap 就是一个未知量，只能写 $N = O(\sqrt{m}\log(G R/|\bar p^\star|))$ 中的 $R$ 换成 $\infty$，整个 (11.35) 变成空话；工程上的表现是 phase I 的 Newton 迭代不收敛或跑到 $s$ 上无界地涨。

**落点**：Boyd §11.5.1（closedness + bounded sublevel set 两条假设）；(11.31)；p593 用 $R$ 构造 $a$ 的那一步；§11.4.1 的 sum-of-infeasibilities。</span>



为判定不等式组 (11.30) 是否 feasible，我们使用基本 phase I problem (11.31) 的一个变体：加上一条冗余线性不等式 $a^Tx \le 1$，得到

```math
\begin{aligned}
\text{minimize} \quad & s\\
\text{subject to} \quad & f_i(x) \le s, \quad i = 1,\ldots,m\\
& a^Tx \le 1.
\end{aligned}
\qquad (11.32)
```

$a$ 的具体取值稍后给出。我们的取法将满足 $\|a\|_2 \le 1/R$，于是 $\|x\|_2 \le R$ 蕴含 $a^Tx \le 1$，即这条额外约束是冗余的。

我们还将选取 $a$ 与 $s_0$，使 $x = 0,\ s = s_0$ 落在问题 (11.32) 的 central path 上，参数值为 $t^{(0)}$——换句话说，它们最小化

```math
t^{(0)}s - \sum_{i=1}^{m}\log(s - f_i(x)) - \log(1 - a^Tx).
```

令对 $s$ 的导数为零，得

```math
t^{(0)} = \sum_{i=1}^{m}\frac{1}{s_0 - f_i(0)}.
\qquad (11.33)
```

令对 $x$ 的梯度为零，得

```math
a = -\sum_{i=1}^{m}\frac{1}{s_0 - f_i(0)}\nabla f_i(0).
\qquad (11.34)
```

于是只剩 $s_0$ 待定：一旦选定 $s_0$，向量 $a$ 由 (11.34) 给出，参数 $t^{(0)}$ 由 (11.33) 给出。由于 $x = 0$ 与 $s = s_0$ 必须是 phase I problem (11.32) 的 strictly feasible 点，必须取 $s_0 \gt F$。

我们还须选取 $s_0$ 以保证 $\|a\|_2 \le 1/R$。由 (11.34) 有

```math
\|a\|_2 \le \sum_{i=1}^{m}\frac{1}{s_0 - f_i(0)}\|\nabla f_i(0)\| \le \frac{mG}{s_0 - F},
```

其中 $G = \max_i\|\nabla f_i(0)\|_2$。因此取 $s_0 = mGR + F$ 即可保证 $\|a\|_2 \le 1/R$，于是那条额外线性不等式确实冗余。

再用 (11.33)：

```math
t^{(0)} = \sum_{i=1}^{m}\frac{1}{mGR + F - f_i(0)} \ge \frac{1}{mGR},
```

因为 $F = \max_i f_i(0)$。于是 $x = 0,\ s = s_0$ 落在 phase I problem (11.32) 的 central path 上，初始 duality gap 为

```math
\frac{m+1}{t^{(0)}} \le (m+1)mGR.
```

<span style="color:#1e8449;">**[译注]** 这三行公式是**把"起点"从随机输入变成可计算对象**的标准手法，也是 §11.4 的 phase I 能进复杂度分析的原因。三个待定量 $a\in\mathbf{R}^n$、$s_0$、$t^{(0)}$ 恰好被三条条件钉死：central path 上的一阶条件给出 (11.33)（对 $s$ 求导）与 (11.34)（对 $x$ 求导），而 $s_0$ 的自由度被"额外约束必须冗余"（$\|a\|_2\le 1/R$）与"必须 strictly feasible"（$s_0 \gt F$）两个要求同时挤压。

取 $s_0 = mGR + F$ 之后链条是**纯代数**：$s_0 - f_i(0) \ge s_0 - F = mGR$，故 $\|a\|_2 \le \frac{mG}{mGR} = 1/R$；又因存在 $i$ 使 $f_i(0) = F$，那一项恰好是 $\frac{1}{mGR}$，所以 $t^{(0)} \ge \frac{1}{mGR}$。

**另一个细节**：那条冗余约束带来 $-\log(1-a^Tx)$ 这一项，使 barrier 项数从 $m$ 变成 $m+1$——这正是初始 gap 分子上写 $m+1$ 而不写 $m$ 的出处，也正是 (11.35) 里 $\sqrt{m+1}$ 与 $\log_2\frac{m(m+1)GR}{|\bar p^\star|}$ 两处下标"错位"的来源。

**量的方向感**：初始 gap 从"未知的 $m/t^{(0)}$"变成 $\le (m+1)mGR$——一个只含 $m$、$G$、$R$ 的先验量。拿 $m = 100$、$G = 1$、$R = 10$ 试算：$(m+1)mGR = 101 \cdot 100 \cdot 1 \cdot 10 = 1.01\times10^5$，正好对得上 (11.35) 中 $\log_2$ 里的 $m(m+1)GR/|\bar p^\star|$。

**消失测试**：不这样构造起点，phase I 自己也要先做一次 centering，(11.35) 里就得再套一层"未知初始 gap"，界退化成 $"O(\sqrt m \log(\infty))"$，写不出闭式。

**落点**：Boyd §11.4.1（basic phase I）；(11.32)-(11.35)；$G$ 与 $R$ 的定义就紧接在上文 p592。</span>



要判定原始不等式组 (11.30) 的可行性，需要确定 $\bar p^\star$ 的**符号**。当 (11.32) 的原目标值为负、或其对偶目标值为正时，就可以停。当 (11.32) 的 duality gap 小于 $|\bar p^\star|$ 时，这两种情形必有一种发生。

我们用 barrier method 解 (11.32)：从一个 duality gap 不超过 $(m+1)mGR$ 的 central point 出发，当 duality gap 小于 $|\bar p^\star|$ 时（或之前）终止。用上一节的结果，这至多需要

```math
\left\lceil \sqrt{m+1}\log_2\left(\frac{m(m+1)GR}{|\bar p^\star|}\right) \right\rceil \left(\frac{1}{2\gamma} + c\right)
\qquad (11.35)
```

个 Newton 步。（这里取 $\mu = 1 + 1/\sqrt{m+1}$，它对 $m$ 给出的复杂度指数比固定的 $\mu$ 更好。）

界 (11.35) 的增长只比 $\sqrt{m}$ 稍快，而它对 centering step 里用到的算法参数依赖很弱。它近似正比于 $\log_2\left((GR)/|\bar p^\star|\right)$——这个量可解释为该特定可行性问题有多难，或者它离"可行/不可行"的边界有多近。

#### Feasibility problems with equality constraints · 带 equality constraint 的可行性问题

同一套分析可用于含 equality constraint 的可行性问题，办法是**消去**这些 equality constraint。这不影响问题的 self-concordance，但它意味着 $G$ 与 $R$ 指的是**消元后**那个问题的量。

### 11.5.5 Combined phase I/phase II complexity · phase I / phase II 合并复杂度

本节给出求解问题

```math
\begin{aligned}
\text{minimize} \quad & f_0(x)\\
\text{subject to} \quad & f_i(x) \le 0, \quad i = 1,\ldots,m\\
& Ax = b
\end{aligned}
```

的**端到端**复杂度分析，用的是 barrier method 的一个变体。先解 phase I problem

```math
\begin{aligned}
\text{minimize} \quad & s\\
\text{subject to} \quad & f_i(x) \le s, \quad i = 1,\ldots,m\\
& f_0(x) \le M\\
& Ax = b\\
& a^Tx \le 1,
\end{aligned}
```

并假定它满足 §11.5.1 的 self-concordance 与 bounded sublevel set 假设。这里我们向基本 phase I problem 加了两条冗余不等式。约束 $f_0(x) \le M$ 的加入，是为保证 phase I 的 central path 与 phase II 的 central path 相交，如 §11.4.1 所述（见 (11.21)）。数 $M$ 是问题最优值的一个先验界。第二条加进去的约束是线性不等式 $a^Tx \le 1$，其中 $a$ 的取法



如 §11.5.4 所述。我们用 barrier method 解这个问题，取 $\mu = 1 + 1/\sqrt{m+2}$，起点取 §11.5.4 给出的 $x = 0,\ s = s_0$。

要"找到一个 strictly feasible 点"或"判定问题不可行"，至多需要

```math
N_{\mathrm{I}} = \left\lceil \sqrt{m+2}\log_2\left(\frac{(m+1)(m+2)GR}{|\bar p^\star|}\right) \right\rceil \left(\frac{1}{2\gamma} + c\right)
\qquad (11.36)
```

个 Newton 步，其中 $G$ 与 $R$ 同 §11.5.4。若问题不可行，到此结束；若可行，则 phase I 找到的那个对应 $s = 0$ 的点，落在 phase II problem

```math
\begin{aligned}
\text{minimize} \quad & f_0(x)\\
\text{subject to} \quad & f_i(x) \le 0, \quad i = 1,\ldots,m\\
& Ax = b\\
& a^Tx \le 1
\end{aligned}
```

的 central path 上。这个初始点的 duality gap 不超过 $(m+1)(M - p^\star)$（见 (11.22)）。我们假定 phase II problem 也满足 §11.5.1 的 self-concordance 与 bounded sublevel set 假设。

现在进入 phase II，仍用 barrier method。我们必须把 duality gap 从初值（不超过 $(m+1)(M - p^\star)$）降到某个容差 $\epsilon \gt 0$。这至多花

```math
N_{\mathrm{II}} = \left\lceil \sqrt{m+1}\log_2\left(\frac{(m+1)(M - p^\star)}{\epsilon}\right) \right\rceil \left(\frac{1}{2\gamma} + c\right)
\qquad (11.37)
```

个 Newton 步。因此 Newton 步数总数不超过 $N_{\mathrm{I}} + N_{\mathrm{II}}$。这个界随不等式个数 $m$ 大致按 $\sqrt{m}$ 增长，并且含有两个依赖**具体问题实例**的项：

```math
\log_2\left(\frac{GR}{|\bar p^\star|}\right), \qquad \log_2\left(\frac{M - p^\star}{\epsilon}\right).
```

### 11.5.6 Summary · 小结

本节给出的 complexity analysis 大体上只具有**理论**意义。特别要提醒读者：本节讨论的 $\mu = 1 + 1/\sqrt{m}$ 这个取值，拿到实践中会是很糟的选择；它的唯一优点是把界变成按 $\sqrt{m}$ 而不是按 $m$ 增长。同样地，我们**不**建议在实践中真去加那条冗余不等式 $a^Tx \le 1$。

由这里的分析得到的实际界，远高于真正观测到的迭代数。就连界里的**阶**看起来都偏保守：最好的界按 $\sqrt{m}$ 增长，而实践经验表明 Newton 步数**几乎完全**不随 $m$ 增长（事实上也不随任何其他参数增长）。

尽管如此，知道在 self-concordance 条件成立时我们能给出"每个 centering step 所需 Newton 步数"的一致界，仍然令人安心。barrier method 一个显而易见的隐患是：随着 $t$ 增大，相应的 centering problem 可能变得更难、需要更多 Newton 步。实践经验表明这并未发生，而这个一致界则进一步支持了"它不可能发生"的信心。

最后要提一句：把问题改写成满足 self-concordance 条件的形式，是否真有**实践**上的好处，目前还不清楚。我们能说的只是：当 self-concordance 条件成立时，barrier method 在实践中会工作得很好，而我们能给出一个 worst case complexity bound。

<span style="color:#1e8449;">**[译注]** 这一节是全章唯一一处作者**自己拆自己的台**：刚花 6 页推出 $O(\sqrt m)$ 的界，转头就说"这只有理论意义"。把落差量化一下就明白他为何要这么说——界 (11.29) 里 $m$ 的指数是 $\frac{1}{2}$，$m$ 从 100 涨到 10 万时 $\sqrt m$ 涨 31.6 倍；而 p605-606 的实测（Figure 11.20）是：问题维数 $n$ 从 10 涨到 1000（**100:1**）、每个 $n$ 跑 100 个随机 SDP，平均 Newton 步数只从约 20 涨到约 26（**1.3 倍**）。

**这不是"理论暂时没跟上实践"的礼貌说法，而是一个可反证的量**：若界是紧的，求解 $n = 1000$ 的 SDP 应比 $n = 10$ 多花 31 倍时间，LAPACK 时代的经验会立刻把它证伪。

**因此 (11.26) 的正确用法是"防崩"而不是"预测"**：它保证 $\frac{m(\mu-1-\log\mu)}{\gamma}+c$ 与 $t$ 无关，从而排除"$t\to\infty$ 时内层发散"这一灾难；至于跑多快，得看实测。

**消失测试**：没有这个一致界，就无法反驳"随 $t$ 增大 centering 会越来越难"的疑惧——而这正是 barrier method 从 1984 到 1994 十年间被质疑最多的点，也是 §11.7 的 primal-dual 方法最终绕开 $t$-依赖的动机（把 centering 与更新合并成一步）。

**落点**：Boyd §11.5.6 本节；实测数据见本块 p605 与 Figure 11.20；`μ` 的实践取值见 §11.3.3；primal-dual 的动机见 §11.7。</span>



（续上页末句）……barrier method 每个 centering step 所需 Newton 步数的一致界。

### 11.6 Problems with generalized inequalities · 带 generalized inequality 的问题

本节说明如何把 barrier method 推广到带 generalized inequality 的问题。考虑

```math
\begin{aligned}
\text{minimize} \quad & f_0(x)\\
\text{subject to} \quad & f_i(x) \preceq_{K_i} 0, \quad i = 1,\ldots,m\\
& Ax = b,
\end{aligned}
\qquad (11.38)
```

其中 $f_0:\mathbf{R}^n\to\mathbf{R}$ 凸，$f_i:\mathbf{R}^n\to\mathbf{R}^{k_i}$（$i = 1,\ldots,m$）为 $K_i$-convex，且 $K_i \subseteq \mathbf{R}^{k_i}$ 是 proper cone。与 §11.1 一样，假定 $f_i$ 二阶连续可微，$A \in \mathbf{R}^{p\times n}$ 且 $\operatorname{rank}A = p$，并假定问题可解。

问题 (11.38) 的 KKT 条件为

```math
\begin{aligned}
Ax^\star &= b\\
f_i(x^\star) &\preceq_{K_i} 0, \quad i = 1,\ldots,m\\
\lambda_i^\star &\succeq_{K_i^\star} 0, \quad i = 1,\ldots,m\\
\nabla f_0(x^\star) + \sum_{i=1}^{m}Df_i(x^\star)^T\lambda_i^\star + A^T\nu^\star &= 0\\
\lambda_i^{\star T} f_i(x^\star) &= 0, \quad i = 1,\ldots,m,
\end{aligned}
\qquad (11.39)
```

其中 $Df_i(x^\star) \in \mathbf{R}^{k_i\times n}$ 是 $f_i$ 在 $x^\star$ 处的导数。我们假定问题 (11.38) strictly feasible，于是 KKT 条件成为 $x^\star$ 最优的**充要**条件。

整个方法的推导与标量约束情形平行。一旦为一般 proper cone 建立起 log 函数的推广，我们就可为问题 (11.38) 定义 logarithmic barrier function。此后推导与标量情形基本相同：central path、barrier method、complexity analysis 都极其相似。

<span style="color:#1e8449;">**[译注]** (11.39) 里有一处极易读错：$\lambda_i^{\star T} f_i(x^\star) = 0$ 是**两个 $k_i$ 维向量的内积**，不是逐分量互补。在标量情形 $\lambda_i f_i = 0$ 意味着"两者至多一个非零"；向量情形下它只意味着 $\lambda_i^\star \perp f_i(x^\star)$，而 $f_i \preceq_{K_i}0$、$\lambda_i^\star \succeq_{K_i^\star}0$ 才是把这两个向量锁在各自锥里的部分。

这一步的实质由 §2.6 的锥对偶给出：$K_i$ 与 $K_i^\star$ 之间的内积 $\lambda^T f$ 只要两个向量都在各自锥里就 $\le 0$，互补条件说这个上界被取到等号。于是 $-\theta_i/t = \lambda_i^{\star T}f_i(x^\star)$（本块 p599 的 (11.43)）就是"离互补还差多少"的连续度量，和标量情形的 $-\lambda_i f_i = 1/t$ 一一对应。

**失败模式很具体**：若把 (11.39) 末行当成"逐分量互补"去实现，SOCP 的 $\lambda_i$ 会被错误地当成 $m$ 个标量。而 example 11.8 的正确结论是 $\lambda_i$（即 $(z_i^\star,w_i^\star)$）整体满足 $\|z_i\|_2 \le w_i$，此时 $f_i$ 与 $\lambda_i$ 两个向量的分量可以**同时非零**——用标量逻辑写出的代码会给出"这个点不最优"的假警报。

**消失测试**：没有 (11.39) 这版向量内积互补，$-\lambda_i^Tf_i = \theta_i/t$ 就无法与标量情形的 $m/t$ 对齐，central path 上的 duality gap 也就不会从 $m/t$ 平滑变成 $\theta/t$。

**方向感**：(11.39) 里 $\lambda_i^\star$ 的维数是 $k_i$，与 $f_i$ 的输出同维；若把它当标量，SOCP 就丢掉 $(z_i,w_i)$ 这一整块自由度，SDP 则丢掉整个矩阵变量 $Z$。

**落点**：Boyd §5.9（generalized inequality 的 KKT 条件）；§2.6.2（proper cone 与对偶锥 $K^\star$）；本块 p599 的 (11.43)；example 11.8 的 $(z_i^\star,w_i^\star)$。</span>



### 11.6.1 Logarithmic barrier and central path · 对数障碍与 central path

#### Generalized logarithm for a proper cone · proper cone 的广义对数

我们首先为 proper cone $K \subseteq \mathbf{R}^q$ 定义 $\log x$ 的类比物。称 $\psi:\mathbf{R}^q\to\mathbf{R}$ 是 $K$ 的 **generalized logarithm**，如果

- $\psi$ 是 concave、closed、二阶连续可微的，$\operatorname{dom}\psi = \operatorname{int}K$，且对 $y \in \operatorname{int}K$ 有 $\nabla^2\psi(y) \prec 0$；
- 存在常数 $\theta \gt 0$，使得对一切 $y \succ_K 0$ 与一切 $s \gt 0$ 有

```math
\psi(sy) = \psi(y) + \theta\log s.
```

换句话说，$\psi$ 沿锥 $K$ 中任何一条射线都表现得像对数。我们称常数 $\theta$ 为 $\psi$ 的 **degree**（因为 $\exp\psi$ 是 degree 为 $\theta$ 的齐次函数）。注意 generalized logarithm 只在"相差一个可加常数"的意义下确定：若 $\psi$ 是 $K$ 的 generalized logarithm，则 $\psi + a$（$a \in \mathbf{R}$）也是。当然，普通的 logarithm 就是 $\mathbf{R}_+$ 的 generalized logarithm。

我们将用到下面两条性质，任何 generalized logarithm 都满足。若 $y \succ_K 0$，则

```math
\nabla\psi(y) \succ_{K^\star} 0,
\qquad (11.40)
```

它蕴含 $\psi$ 是 $K$-increasing 的（见 §3.6.1）；并且

```math
y^T\nabla\psi(y) = \theta.
```

第一条性质在 exercise 11.15 中证明。第二条性质由 $\psi(sy) = \psi(y) + \theta\log s$ 对 $s$ 求导立即得到。

<span style="color:#b45309;">**[Example 11.5]**</span> **Nonnegative orthant（非负象限）。** 函数 $\psi(x) = \sum_{i=1}^{n}\log x_i$ 是 $K = \mathbf{R}^n_+$ 的 generalized logarithm，degree 为 $n$。对 $x \succ 0$，

```math
\nabla\psi(x) = \left(1/x_1,\ldots,1/x_n\right),
```

于是 $\nabla\psi(x) \succ 0$，且 $x^T\nabla\psi(x) = n$。

<span style="color:#b45309;">**[Example 11.6]**</span> **Second-order cone（二阶锥）。** 函数

```math
\psi(x) = \log\left(x_{n+1}^2 - \sum_{i=1}^{n}x_i^2\right)
```

是 second-order cone

```math
K = \left\{x \in \mathbf{R}^{n+1} \;\middle|\; \left(\sum_{i=1}^{n}x_i^2\right)^{1/2} \le x_{n+1}\right\}
```



的 generalized logarithm，degree 为 2。$\psi$ 在点 $x \in \operatorname{int}K$ 处的梯度由下式给出：

```math
\begin{aligned}
\frac{\partial\psi(x)}{\partial x_j} &= \frac{-2x_j}{x_{n+1}^2 - \sum_{i=1}^{n}x_i^2}, \quad j = 1,\ldots,n\\
\frac{\partial\psi(x)}{\partial x_{n+1}} &= \frac{2x_{n+1}}{x_{n+1}^2 - \sum_{i=1}^{n}x_i^2}.
\end{aligned}
```

恒等式 $\nabla\psi(x) \in \operatorname{int}K^\star = \operatorname{int}K$ 与 $x^T\nabla\psi(x) = 2$ 都容易验证。

<span style="color:#b45309;">**[Example 11.7]**</span> **Positive semidefinite cone（半正定锥）。** 函数 $\psi(X) = \log\det X$ 是锥 $\mathbf{S}^p_+$ 的 generalized logarithm。它的 degree 为 $p$，因为对 $s \gt 0$ 有

```math
\log\det(sX) = \log\det X + p\log s.
```

$\psi$ 在点 $X \in \mathbf{S}^p_{++}$ 处的梯度等于

```math
\nabla\psi(X) = X^{-1}.
```

于是 $\nabla\psi(X) = X^{-1} \succ 0$，而 $X$ 与 $\nabla\psi(X)$ 的内积等于 $\operatorname{tr}(XX^{-1}) = p$。

#### Logarithmic barrier functions for generalized inequalities · generalized inequality 的对数障碍函数

回到问题 (11.38)。设 $\psi_1,\ldots,\psi_m$ 分别是锥 $K_1,\ldots,K_m$ 的 generalized logarithm，degree 为 $\theta_1,\ldots,\theta_m$。我们为问题 (11.38) 定义 logarithmic barrier function

```math
\varphi(x) = -\sum_{i=1}^{m}\psi_i\left(-f_i(x)\right), \quad \operatorname{dom}\varphi = \left\{x \mid f_i(x) \prec_{K_i} 0,\ i = 1,\ldots,m\right\}.
```

$\varphi$ 的 convexity 来自两件事：$\psi_i$ 是 $K_i$-increasing 的，而 $f_i$ 是 $K_i$-convex 的（见 §3.6.2 的 composition rule）。

#### The central path · central path

下一步是为问题 (11.38) 定义 central path。对 $t \ge 0$，定义 central point $x^\star(t)$ 为 $tf_0 + \varphi$ 在 $Ax = b$ 约束下的最小化点，即

```math
\begin{aligned}
\text{minimize} \quad & tf_0(x) - \sum_{i=1}^{m}\psi_i\left(-f_i(x)\right)\\
\text{subject to} \quad & Ax = b
\end{aligned}
```

的解（假定该最小化点存在且唯一）。Central point 由最优性条件刻画：

```math
\begin{aligned}
t\nabla f_0(x) + \nabla\varphi(x) + A^T\nu
={}& t\nabla f_0(x) + \sum_{i=1}^{m}Df_i(x)^T\nabla\psi_i\left(-f_i(x)\right) + A^T\nu\\
={}& 0,
\end{aligned}
\qquad (11.41)
```

其中某个 $\nu \in \mathbf{R}^p$，$Df_i(x)$ 是 $f_i$ 在 $x$ 处的导数。

<span style="color:#1e8449;">**[译注]** 这条定义里的 $\psi(sy)=\psi(y)+\theta\log s$ 是**唯一一条真正需要"发明"的公理**，其余（concavity、closedness、$\nabla^2\psi\prec0$）都是标量 $\log$ 性质的逐条搬运。它的作用是让 $y^T\nabla\psi(y) = \theta$ **自动成立**：沿射线求导，$\frac{d}{ds}\psi(sy)\big|_{s=1} = \nabla\psi(y)^Ty$，而右边求导得 $\theta/s\big|_{s=1} = \theta$，两边相等。

这个 $\theta$ 就是标量情形——“一条约束贡献 $1/t$”的推广：标量 $-\log(-f_i)$ 的 degree 是 $1$，$m$ 条约束加起来是 $m$；锥情形每条约束贡献 $\theta_i$，加起来是 $\theta = \sum_i\theta_i$。所以 p599 的 gap $\theta/t$ **不是新结论，而是 $m/t$ 换字母**。

**不可省的一点**：$\psi$ 必须严格 concave（$\nabla^2\psi \prec 0$），否则 central point 不唯一，$x^\star(t)$ 作为函数就没有定义，barrier method 的整条迭代序列失去唯一性。

**消失测试**：没有"沿射线按 $\theta\log s$ 缩放"这条公理，$\psi$ 就只是个 concave 函数，$y^T\nabla\psi(y)$ 会是随 $y$ 变化的量，$-\lambda_i^Tf_i = \theta_i/t$ 就不成立，duality gap 不再是 $\theta/t$ 这种**与 $t$ 成纯反比**的形式，§11.6.2 的外层步数 $\lceil\log(\theta/(t^{(0)}\epsilon))/\log\mu\rceil$ 也就写不出来。

**另一条** $\nabla\psi(y)\succ_{K^\star}0$（exercise 11.15）保证 (11.42) 的 $\lambda^\star$ 落在对偶锥内部——没有它，dual feasible 里最关键的“严格可行”就断了，$g(\lambda^\star,\nu^\star)$ 会贴着边界算，$-\lambda^Tf = \theta_i/t$ 变成 $\le$ 而非等号。

**落点**：Boyd §3.6.1（$K$-increasing 与 $K$-convex）；§3.6.2（composition rule）；example 11.6 与 11.7 给出三个锥的 $\theta$ 分别是 $n$、$2$、$p$；本块 p599 的 (11.43)。</span>



#### Dual points on central path · central path 上的对偶点

与标量情形一样，central path 上的点给出问题 (11.38) 的 dual feasible point。对 $i = 1,\ldots,m$，定义

```math
\lambda_i^\star(t) = \frac{1}{t}\nabla\psi_i\left(-f_i(x^\star(t))\right),
\qquad (11.42)
```

并令 $\nu^\star(t) = \nu/t$，其中 $\nu$ 是 (11.41) 中的最优对偶变量。下面证明 $\lambda_1^\star(t),\ldots,\lambda_m^\star(t)$ 连同 $\nu^\star(t)$ 对原问题 (11.38) 是 dual feasible 的。

首先，由 generalized logarithm 的单调性 (11.40) 得 $\lambda_i^\star(t) \succ_{K_i^\star} 0$。其次，由 (11.41) 可推出 Lagrangian

```math
L\left(x,\lambda^\star(t),\nu^\star(t)\right) = f_0(x) + \sum_{i=1}^{m}\lambda_i^\star(t)^Tf_i(x) + \nu^\star(t)^T(Ax - b)
```

在 $x = x^\star(t)$ 处取得对 $x$ 的最小值。因此对偶函数 $g$ 在 $(\lambda^\star(t),\nu^\star(t))$ 处的值等于

```math
\begin{aligned}
g\left(\lambda^\star(t),\nu^\star(t)\right)
={}& f_0(x^\star(t)) + \sum_{i=1}^{m}\lambda_i^\star(t)^Tf_i(x^\star(t)) + \nu^\star(t)^T\left(Ax^\star(t) - b\right)\\
={}& f_0(x^\star(t)) + (1/t)\sum_{i=1}^{m}\nabla\psi_i\left(-f_i(x^\star(t))\right)^Tf_i(x^\star(t))\\
={}& f_0(x^\star(t)) - (1/t)\sum_{i=1}^{m}\theta_i,
\end{aligned}
```

其中 $\theta_i$ 是 $\psi_i$ 的 degree。末行用到事实：对 $y \succ_{K_i} 0$ 有 $y^T\nabla\psi_i(y) = \theta_i$，因此

```math
\lambda_i^\star(t)^Tf_i(x^\star(t)) = -\theta_i/t, \quad i = 1,\ldots,m.
\qquad (11.43)
```

于是，若定义

```math
\theta = \sum_{i=1}^{m}\theta_i,
```

则 primal feasible 点 $x^\star(t)$ 与 dual feasible 点 $(\lambda^\star(t),\nu^\star(t))$ 的 duality gap 为 $\theta/t$。这与标量情形完全类似，只是出现在 $m$（不等式个数）位置上的是 $\theta$——各锥 generalized logarithm 的 degree 之和。

<span style="color:#b45309;">**[Example 11.8]**</span> **Second-order cone programming（二阶锥规划）。** 考虑变量为 $x \in \mathbf{R}^n$ 的 SOCP：

```math
\begin{aligned}
\text{minimize} \quad & f^Tx\\
\text{subject to} \quad & \|A_ix + b_i\|_2 \le c_i^Tx + d_i, \quad i = 1,\ldots,m,
\end{aligned}
\qquad (11.44)
```

其中 $A_i \in \mathbf{R}^{n_i\times n}$。如 example 11.6 所见，函数

```math
\psi(y) = \log\left(y_{p+1}^2 - \sum_{i=1}^{p}y_i^2\right)
```



是 $\mathbf{R}^{p+1}$ 中 second-order cone 的 generalized logarithm，degree 为 2。(11.44) 相应的 logarithmic barrier function 是

```math
\varphi(x) = -\sum_{i=1}^{m}\log\left(\left(c_i^Tx + d_i\right)^2 - \|A_ix + b_i\|_2^2\right),
\qquad (11.45)
```

其定义域为 $\operatorname{dom}\varphi = \left\{x \mid \|A_ix + b_i\|_2 \lt c_i^Tx + d_i,\ i = 1,\ldots,m\right\}$。central path 上的最优性条件为 $tf + \nabla\varphi(x^\star(t)) = 0$，其中

```math
\nabla\varphi(x) = -2\sum_{i=1}^{m}\frac{1}{\left(c_i^Tx + d_i\right)^2 - \|A_ix + b_i\|_2^2}\left(\left(c_i^Tx + d_i\right)c_i - A_i^T\left(A_ix + b_i\right)\right).
```

由此可知点

```math
z_i^\star(t) = -\frac{2}{t\alpha_i}\left(A_ix^\star(t) + b_i\right), \qquad w_i^\star(t) = \frac{2}{t\alpha_i}\left(c_i^Tx^\star(t) + d_i\right), \quad i = 1,\ldots,m,
```

其中 $\alpha_i = \left(c_i^Tx^\star(t) + d_i\right)^2 - \|A_ix^\star(t) + b_i\|_2^2$，在对偶问题

```math
\begin{aligned}
\text{maximize} \quad & -\sum_{i=1}^{m}\left(b_i^Tz_i + d_iw_i\right)\\
\text{subject to} \quad & \sum_{i=1}^{m}\left(A_i^Tz_i + c_iw_i\right) = f\\
& \|z_i\|_2 \le w_i, \quad i = 1,\ldots,m
\end{aligned}
```

中是 strictly feasible 的。与 $x^\star(t)$ 及 $(z^\star(t),w^\star(t))$ 相关联的 duality gap 为

```math
\sum_{i=1}^{m}\left(\left(A_ix^\star(t) + b_i\right)^Tz_i^\star(t) + \left(c_i^Tx^\star(t) + d_i\right)w_i^\star(t)\right) = \frac{2m}{t},
```

这与一般公式 $\theta/t$ 一致，因为 $\theta_i = 2$。

<span style="color:#b45309;">**[Example 11.9]**</span> **Semidefinite programming in inequality form（不等式形式的半定规划）。** 考虑变量为 $x \in \mathbf{R}^n$ 的 SDP

```math
\begin{aligned}
\text{minimize} \quad & c^Tx\\
\text{subject to} \quad & F(x) = x_1F_1 + \cdots + x_nF_n + G \preceq 0,
\end{aligned}
```

其中 $G,F_1,\ldots,F_n \in \mathbf{S}^p$。对偶问题是

```math
\begin{aligned}
\text{maximize} \quad & \operatorname{tr}(GZ)\\
\text{subject to} \quad & \operatorname{tr}(F_iZ) + c_i = 0, \quad i = 1,\ldots,n\\
& Z \succeq 0.
\end{aligned}
```

用正半定锥 $\mathbf{S}^p_+$ 的 generalized logarithm $\log\det X$，可得（原问题的）障碍函数

```math
\varphi(x) = \log\det\left(-F(x)^{-1}\right),
```

其定义域为 $\operatorname{dom}\varphi = \{x \mid F(x) \prec 0\}$。对 strictly feasible 的 $x$，$\varphi$ 的梯度等于

```math
\frac{\partial\varphi(x)}{\partial x_i} = \operatorname{tr}\left(-F(x)^{-1}F_i\right), \quad i = 1,\ldots,n,
```

由此得到刻画 central point 的最优性条件：

```math
tc_i + \operatorname{tr}\left(-F(x^\star(t))^{-1}F_i\right) = 0, \quad i = 1,\ldots,n.
```

于是矩阵

```math
Z^\star(t) = \frac{1}{t}\left(-F(x^\star(t))\right)^{-1}
```

是 strictly dual feasible 的，而与 $x^\star(t)$、$Z^\star(t)$ 相关联的 duality gap 为 $p/t$。

<span style="color:#1e8449;">**[译注]** Example 11.8 值得逐项对账，因为它把"$\theta$ 替代 $m$"这件事从口号变成算式。取 $\alpha_i = (c_i^Tx^\star + d_i)^2 - \|A_ix^\star+b_i\|_2^2$（这是 SOC 约束的 slack 的平方），构造出的 $z_i^\star,w_i^\star$ 满足**两个关键不等式**：$\|z_i^\star\|_2 = \frac{2}{t\alpha_i}\|A_ix^\star+b_i\|_2 \lt \frac{2}{t\alpha_i}(c_i^Tx^\star+d_i) = w_i^\star$，即严格落在对偶 SOC 内部；gap 每项算下来是 $(A_ix^\star+b_i)^Tz_i^\star + (c_i^Tx^\star+d_i)w_i^\star = \frac{2}{t\alpha_i}\left[-(c_i^Tx^\star+d_i)^2 + \|A_ix^\star+b_i\|_2^2\right] + \frac{2}{t\alpha_i}(c_i^Tx^\star+d_i)^2$ 中的两块相消后恰为 $2/t$。

**顺带**：$\alpha_i$ 就是该条 SOC 约束 slack 的平方，它取正值这一点保证了对偶点严格可行。

**方向感是可数的**：$m = 50$ 条 SOC 约束时 gap 是 $\frac{100}{t}$，而不是 $\frac{50}{t}$——**约束条数与 gap 系数不成正比，比例因子是每个锥的 degree**。Example 11.9 里更极端：整块 SDP 只有 1 条矩阵约束 $F(x)\preceq0$，但 gap 是 $\frac{p}{t}$；$p = 100$ 时相当于 100 条标量约束的代价。所以把 $n$ 维 LP 改写成 SDP 之前，得先看 $p$。

**消失测试**：若错把 gap 记成 $m/t$，Example 11.9 的 $p/t$ 与 Example 11.8 的 $2m/t$ 都会被算错，外层迭代数 $\lceil\log(\theta/(t^{(0)}\epsilon))/\log\mu\rceil$ 里 $\theta$ 一错，终止条件 $2m/t \le \epsilon$ 就会提前或滞后整整 $\log_2 2 = 1$ 个外层。

**顺带说明**：$w_i^\star$ 是标量、$z_i^\star$ 是 $n_i$ 维，而 degree 只有 2——**$\theta$ 不是锥的维数 $n_i+1$**，它是“沿射线缩放的指数”，这两个概念在 SOC 上刚好不相等。

**落点**：Boyd example 11.6（degree 2 的来源）；§2.6.2（SOC 与其对偶是同一个锥）；example 11.9 的 $p/t$；本块 p601 的 phase I 版。</span>



### 11.6.2 Barrier method · 障碍法

我们已经看到，central path 的关键性质可以推广到带 generalized inequality 的问题：

- 计算 central path 上的一个点，等价于在 equality constraint 下最小化一个二阶可微的凸函数（可用 Newton 法完成）；
- 与 central point $x^\star(t)$ 可关联一个 dual feasible point $(\lambda^\star(t),\nu^\star(t))$，其 duality gap 为 $\theta/t$。特别地，$x^\star(t)$ 至多是 $\theta/t$-suboptimal 的。

这意味着我们可以把 §11.3 描述的 barrier method **原样**搬到问题 (11.38) 上。从 $x^\star(t^{(0)})$ 出发、要算出一个 duality gap 为 $\epsilon$ 的 central point，所需 outer iteration（即 centering step）数等于

```math
\left\lceil \frac{\log\left(\theta/(t^{(0)}\epsilon)\right)}{\log\mu} \right\rceil,
```

再加上一次初始 centering step。这个结果与标量情形相应结果的唯一差别，就是 $\theta$ 出现在 $m$ 的位置上。

#### Phase I and feasibility problems · phase I 与可行性问题

§11.4 描述的 phase I method 可以顺利推广到带 generalized inequality 的问题。取定 $e_i \succ_{K_i} 0$（$i = 1,\ldots,m$）为给定的 $K_i$-positive 向量。要判定 equality constraint 与 generalized inequality

```math
f_1(x) \preceq_{K_1} 0, \quad \ldots, \quad f_m(x) \preceq_{K_m} 0, \quad Ax = b
```

组成的系统是否可行，我们求解

```math
\begin{aligned}
\text{minimize} \quad & s\\
\text{subject to} \quad & f_i(x) \preceq_{K_i} se_i, \quad i = 1,\ldots,m\\
& Ax = b,
\end{aligned}
```

变量为 $x$ 与 $s \in \mathbf{R}$。最优值 $\bar p^\star$ 决定这组 equality constraint 与 generalized inequality 的可行性，其机理与普通不等式情形完全相同。当 $\bar p^\star$ 为正时，任何目标值为正的对偶可行点都给出一个 **alternative**，证明这组 equality constraint 与 generalized inequality 不可行（见 page 270）。

> **† 原文校订**：本页原文把该系统写成 "$f_1(x) \preceq_{K_1} 0,\ \ldots,\ f_L(x) \preceq_{K_m} 0$"，下标 $L$ 与前文的 $i = 1,\ldots,m$ 不一致，应为 $f_m(x) \preceq_{K_m} 0$。译本按 $m$ 处理。

### 11.6.3 Examples · 例题

#### A small SOCP · 一个小的 SOCP

我们求解 SOCP

```math
\begin{aligned}
\text{minimize} \quad & f^Tx\\
\text{subject to} \quad & \|A_ix + b_i\|_2 \le c_i^Tx + d_i, \quad i = 1,\ldots,m,
\end{aligned}
```

<span style="color:#b45309;">**[Example 11.10]**</span> **Second-order cone programming。** 函数

```math
-\psi(x) = -\log\left(x_{p+1}^2 - \sum_{i=1}^{p}x_i^2\right)
```

是 self-concordant 的（见 example 9.8），因此 logarithmic barrier function (11.45) 对 SOCP (11.44) 满足 closedness 与 self-concordance 假设。

<span style="color:#b45309;">**[Example 11.11]**</span> **Semidefinite programming。** 对一般的半定规划，self-concordance 假设成立，用的正是 $\log\det X$ 作为正半定锥的 generalized logarithm。例如对标准形式的 SDP

```math
\begin{aligned}
\text{minimize} \quad & \operatorname{tr}(CX)\\
\text{subject to} \quad & \operatorname{tr}(A_iX) = b_i, \quad i = 1,\ldots,p\\
& X \succeq 0,
\end{aligned}
```

变量为 $X \in \mathbf{S}^n$，函数 $t^{(0)}\operatorname{tr}(CX) - \log\det X$ 对任何 $t^{(0)} \ge 0$ 都是 self-concordant（且 closed）的。

<span style="color:#1e8449;">**[译注]** §11.6.4 只干了三件事，但每一件都必须有：① 外层数公式里 $m$ 换成 $\theta$（唯一的新东西，来自 §11.6.1）；② 内层步数**不用重推**，因为 (11.26) 只用到"$tf_0+\varphi$ 是 closed self-concordant"，与约束是标量还是锥无关；③ 于是总界仍是 $O(\sqrt\theta\log(\cdot))$，只是 $m \to \theta$。

Example 11.10 与 11.11 正是为了把 ② 的前提**兑现到具体锥上**：SOC 的 $-\log(y_{p+1}^2-\sum y_i^2)$ 与 PSD 锥的 $-\log\det X$ 都已在 §9.6 的 example 9.8 中验过 triplet 不等式。

**量的方向感**：$n\times n$ 矩阵的 PSD 锥 degree 是 $n$，所以标准形 SDP 的界是 $O(\sqrt n\log(1/\epsilon))$；把它与 §11.5.3 的 $O(\sqrt m)$ 并列，就看出**SDP 的"约束条数"实际是矩阵维数 $n$**，而不是显式写出的 $p$ 条 equality constraint。

**失败模式**：若不管锥结构，把 SDP 展开成 $n^2$ 条标量不等式再跑 LP 型 barrier，$\theta$ 就从 $n$ 变成 $n^2$，界从 $O(\sqrt n)$ 恶化到 $O(n)$——**同一个问题，两种建模，复杂度阶不同**。

**消失测试**：没有 example 9.8 那两条已证的 self-concordance，§11.6.4 的"assumption holds"就只是假定，$O(\sqrt\theta)$ 的界对 SOCP/SDP 无法落地。

**方向感补一条**：把 (11.38) 的 $K_i$ 全取成非负象限、$\theta_i = 1$，则 $\theta = m$，界退回 §11.5.3 的 $O(\sqrt m)$——**锥版本是标量版本的严格推广，不是另一套方法论**。

## 11.6.4（续）Complexity analysis via self-concordance · 通过 self-concordance 的复杂度分析（续）

（承接 p606 末句。上一块停在「剩下的就是界住每个 centering step 所需的 Newton 步数」，本节给出该界，并说明它为什么与普通不等式情形逐字相同。）

我们会看到，与标量情形完全一样，有

```math
\mu t f_0(x^\star(t)) + \varphi(x^\star(t)) - \mu t f_0(x^\star(\mu t)) - \varphi(x^\star(\mu t)) \le \theta(\mu - 1 - \log\mu).
\qquad (11.48)
```

因此，当 self-concordance 条件与有界 sublevel set 条件成立时，每个 centering step 的 Newton 步数不超过

```math
\frac{\theta(\mu - 1 - \log\mu)}{\gamma} + c,
```

与普通不等式问题的 barrier method 完全一样。一旦建立起基本界 (11.48)，广义不等式问题的 complexity analysis 就与普通不等式问题的分析**逐字相同**，只有一个例外：$\theta$ 取各锥 degree 之和，而不再是约束的条数 $m$。

### Generalized logarithm for dual cone · 对偶锥的 generalized logarithm

我们将用 conjugate（共轭）来证明界 (11.48)。设 $\psi$ 是 proper cone $K$ 的 generalized logarithm，degree 为 $\theta$。凸函数 $-\psi$ 的 conjugate 是

```math
(-\psi)^\star(v) = \sup_{u}\left(v^T u + \psi(u)\right).
```

这个函数是凸的，定义域为 $-K^\star = \{v \mid v \prec_{K^\star} 0\}$。定义 $\bar\psi$ 为

```math
\bar\psi(v) = -(-\psi)^\star(-v) = \inf_{u}\left(v^T u - \psi(u)\right), \qquad \operatorname{dom}\bar\psi = \operatorname{int}K^\star.
\qquad (11.49)
```

函数 $\bar\psi$ 是凹的，而且它确实是 dual cone $K^\star$ 的 generalized logarithm，参数同样是 $\theta$（见 exercise 11.17）。我们称 $\bar\psi$ 为**与 generalized logarithm $\psi$ 相伴的 dual logarithm（对偶对数）**。

由 (11.49) 得到不等式

```math
\bar\psi(v) + \psi(u) \le u^T v,
\qquad (11.50)
```

它对任意 $u \succ_K 0$、$v \succ_{K^\star} 0$ 成立，且等号成立当且仅当 $\nabla\psi(u) = v$（等价地，$\nabla\bar\psi(v) = u$）†。（这个不等式只是 Young 不等式在凹函数情形下的一个变体。）

<span style="color:#b45309;">**[Example 11.12]**</span> **Second-order cone（二阶锥）。** Second-order cone 的 generalized logarithm 是

```math
\psi(x) = \log\left(x_{p+1}^2 - \sum_{i=1}^{p}x_i^2\right), \qquad \operatorname{dom}\psi = \left\{x \in \mathbf{R}^{p+1} \;\middle|\; x_{p+1} \gt \left(\sum_{i=1}^{p}x_i^2\right)^{1/2}\right\}.
```

相伴的 dual logarithm 是

```math
\bar\psi(y) = \log\left(y_{p+1}^2 - \sum_{i=1}^{p}y_i^2\right) + 2 - \log 4,
```

其定义域为 $\operatorname{dom}\bar\psi = \{y \in \mathbf{R}^{p+1} \mid y_{p+1} \gt (\sum_{i=1}^{p}y_i^2)^{1/2}\}$（见 exercise 3.36）。除一个常数之外，它与 second-order cone 原来的 generalized logarithm 是同一个函数。

<span style="color:#1e8449;">**[译注]** 这一页真正被用到的只有 (11.50) 一条不等式，而 (11.48) 的全部内容都压在它的**取等条件**上。取等条件说：只要 $u$ 取在当前点、$v$ 取成 $\nabla\psi(u)$，(11.50) 就由不等式退化成恒等式；而 §11.6.1 的性质 $t\lambda_i = \nabla\psi_i(-f_i(x))$（(11.43)）正是把 $v$ 钉成梯度的机制，于是 (11.51) 右端 $\psi_i(-f_i(x)) + \bar\psi_i(t\lambda_i) = -t\lambda_i^T f_i(x) = \theta_i$ 是一个**与 $x$ 无关的常数** $\theta_i$。这一点是整条证明的关键：$\theta_i$ 只依赖 degree，所以在相减时能把 $x$ 依赖项全部消掉。

**消失测试**：若 $\bar\psi$ 与 $\psi$ 的 degree 不同（例如 $\theta$ 换成 $\theta' \ne \theta$），(11.51) 右端就不再是 $\theta_i$，相减后 (11.48) 右端会多出 $(\theta_i - \theta_i')\log\mu$ 项，界随之变成 $\theta(\mu - 1 - \log\mu) + \Delta\theta\log\mu$，对 $\mu$ 的最优取值（§11.5.3 的 $\mu \approx 1 + 1/\sqrt{m}$ 那一族结论）全部失效。

**量的方向感**：Example 11.12 与 11.13 的结论值得记住——SOC 与 PSD 锥的 dual logarithm 与原来的 generalized logarithm **只差一个可加常数**（SOC 差 $2 - \log 4$，PSD 差 $p$）。常数不影响 (11.50) 的取等条件，也不影响 degree，所以这两类锥在整个证明里可以"自己与自己配对"，无需另找对偶函数。

**落点**：Boyd §11.6.1 的 (11.40)-(11.43)；exercise 11.17（$\bar\psi$ 的 degree 仍为 $\theta$）；Example 3.23 与 exercise 3.36（$\log\det$ 与 SOC 的 conjugate 显式形式，$2-\log 4$ 与 $p$ 两个常数的出处）；本节 $\theta = \sum_i\theta_i$ 与 §11.5.3 $m$ 的对应。</span>



<span style="color:#b45309;">**[Example 11.13]**</span> **Positive semidefinite cone（半正定锥）。** 与 $\psi(X) = \log\det X$（$\operatorname{dom}\psi = \mathbf{S}^p_{++}$）相伴的 dual logarithm 是

```math
\bar\psi(Y) = \log\det Y + p,
```

其定义域为 $\operatorname{dom}\bar\psi = \mathbf{S}^p_{++}$（见 example 3.23）。同样地，除一个常数之外它与原来的 generalized logarithm 是同一个函数。

### Derivation of the basic bound · 基本界的推导

为简化记号，把 $x^\star(t)$ 记为 $x$，把 $x^\star(\mu t)$ 记为 $x^+$，把 $\lambda_i^\star(t)$ 记为 $\lambda_i$，把 $\nu^\star(t)$ 记为 $\nu$。由 $t\lambda_i = \nabla\psi_i(-f_i(x))$（见 (11.42)）与性质 (11.43)，可得

```math
\psi_i(-f_i(x)) + \bar\psi_i(t\lambda_i) = -t\lambda_i^T f_i(x) = \theta_i,
\qquad (11.51)
```

也就是说，不等式 (11.50) 对 $u = -f_i(x)$、$v = t\lambda_i$ 这一对取等号。

对 $u = -f_i(x^+)$、$v = \mu t\lambda_i$ 这一对写同一个不等式，得到

```math
\bar\psi_i(\mu t\lambda_i) + \psi_i(-f_i(x^+)) \le -\mu t\lambda_i^T f_i(x^+),
```

利用 $\bar\psi_i$ 的 logarithmic homogeneity（对数齐性），它化为

```math
\bar\psi_i(t\lambda_i) + \theta_i\log\mu + \psi_i(-f_i(x^+)) \le -\mu t\lambda_i^T f_i(x^+).
```

从这个不等式减去等式 (11.51)，得到

```math
\psi_i(-f_i(x^+)) - \psi_i(-f_i(x)) + \theta_i\log\mu \le -\theta_i - \mu t\lambda_i^T f_i(x^+),
```

再对 $i$ 求和（$\varphi(x) = -\sum_i\psi_i(-f_i(x))$）就得到

```math
\varphi(x) - \varphi(x^+) + \theta\log\mu \le -\theta - \mu t\sum_{i=1}^{m}\lambda_i^T f_i(x^+).
\qquad (11.52)
```

另一方面，由 dual function 的定义有

```math
\begin{aligned}
f_0(x) - \theta/t &= g(\lambda,\nu)\\
&\le f_0(x^+) + \sum_{i=1}^{m}\lambda_i^T f_i(x^+) + \nu^T(Ax^+ - b)\\
&= f_0(x^+) + \sum_{i=1}^{m}\lambda_i^T f_i(x^+).
\end{aligned}
```

（最后一步用了 $x^+$ 可行，即 $Ax^+ = b$。）把这个不等式乘以 $\mu t$ 再与 (11.52) 相加，得到

```math
\varphi(x) - \varphi(x^+) + \theta\log\mu + \mu t f_0(x) - \mu\theta \le \mu t f_0(x^+) - \theta,
```

整理即得

```math
\mu t f_0(x) + \varphi(x) - \mu t f_0(x^+) - \varphi(x^+) \le \theta(\mu - 1 - \log\mu),
```

这就是所要的界 (11.48)。

<span style="color:#1e8449;">**[译注]** 这段推导的结构值得单独记住，因为它是**整个第 11 章唯一一处"用对偶信息换复杂度界"的技术**。

三步：① (11.51) 给出一个**恰好取等**的关系，右端是常数 $\theta_i$；② 在**下一个** centering 点 $x^+$ 处写同一条不等式，得到方向性；③ 两式相减，把 $\psi_i(-f_i(x^+))$ 的系数固定为 $+1$、$\psi_i(-f_i(x))$ 的系数固定为 $-1$，于是求和正好凑出 $\varphi(x) - \varphi(x^+)$。

**量的方向感**：$\mu$ 每增大一个因子，$\varphi$ 的漂移被 $-\theta\log\mu$ 吸收掉，剩下的净损失是 $\theta(\mu - 1 - \log\mu)$；在 $\mu = 1$ 处该式展开为 $\theta\mu^2/2 + O(\mu^3)$，所以小 $\mu$ 时损失是二阶小量，这也是 §11.5.3 "$\mu$ 不能取得太小（每步几乎不前进）、也不能太大（Newton 步数涨）"的定量来源。

**失败模式**：若把 (11.51) 写成不等式而非等式（即不把 $\lambda_i$ 取成梯度），则相减后右端会留下 $-\mu t\sum_i\lambda_i^Tf_i(x^+)$ 这一项无法与 dual function 的界对消，(11.48) 就退化成"每步只减一个与当前点有关的量"，外层迭代次数不再有 $O(\log(1/\epsilon))$ 的界。

**落点**：Boyd §11.6.1 的 (11.42)(11.43)；§11.5.2 的 (11.26) 是同一推导在标量情形下的版本；exercise 11.17。</span>



## 11.7 Primal-dual interior-point methods · primal-dual 内点法

本节介绍一个基本的 primal-dual interior-point method（primal-dual 内点法）。primal-dual 内点法与 barrier method 非常相似，但有若干差别。

- 它只有**一层**循环，即没有 barrier method 中 inner iteration 与 outer iteration 的区分。每次迭代同时更新 primal 变量与 dual 变量。
- primal-dual 内点法中的 search direction 由 Newton 法给出，而 Newton 法作用在**修正后的 KKT 方程**（即 logarithmic barrier centering problem 的最优性条件）上。primal-dual search direction 与 barrier method 中的 search direction 相似，但并不完全相同。
- 在 primal-dual 内点法中，primal 迭代点与 dual 迭代点**不必可行**。

primal-dual 内点法往往比 barrier method 更有效率，尤其是在要求高精度时，因为它可以表现出优于线性的收敛（better than linear convergence）。对若干基本问题类——linear、quadratic、second-order cone、geometric、semidefinite programming——定制化的 primal-dual 方法都优于 barrier method。对一般的非线性凸优化问题，primal-dual 内点法仍是活跃的研究课题，但显示出很大潜力。primal-dual 算法相对 barrier method 的另一个好处是：当问题**可行但不 strictly feasible** 时它们仍然可用（本节不追究这一点）。

本节给出针对 (11.1) 的基本 primal-dual 方法，不含收敛性分析。关于 primal-dual 方法及其收敛性分析的更完整处理，请读者参阅文献。

### 11.7.1 Primal-dual search direction · primal-dual 搜索方向

与 barrier method 一样，我们从修正后的 KKT 条件 (11.15) 出发，把它写成 $r_t(x,\lambda,\nu) = 0$，其中定义

```math
r_t(x,\lambda,\nu) = \begin{bmatrix} \nabla f_0(x) + Df(x)^T\lambda + A^T\nu \\ -\operatorname{diag}(\lambda)f(x) - (1/t)\mathbf{1} \\ Ax - b \end{bmatrix},
\qquad (11.53)
```

且 $t \gt 0$。这里 $f : \mathbf{R}^n \to \mathbf{R}^m$，其导数矩阵 $Df$ 为

```math
f(x) = \begin{bmatrix} f_1(x) \\ \vdots \\ f_m(x) \end{bmatrix}, \qquad Df(x) = \begin{bmatrix} \nabla f_1(x)^T \\ \vdots \\ \nabla f_m(x)^T \end{bmatrix}.
```

若 $x,\lambda,\nu$ 满足 $r_t(x,\lambda,\nu) = 0$（且 $f_i(x) \lt 0$），则 $x = x^\star(t)$、$\lambda = \lambda^\star(t)$、$\nu = \nu^\star(t)$。特别地，$x$ 是 primal feasible 的，$\lambda,\nu$ 是 dual feasible 的，duality gap 为 $m/t$。

<span style="color:#1e8449;">**[译注]** 三条差别里，第一条和第三条才是实质性的，第二条只是技术后果。

**第一条**决定了复杂度记账方式的变化：barrier method 的迭代次数是 $N_{\text{outer}} \times N_{\text{inner}}$ 两个乘积（(11.27) 那一族界），而 primal-dual 只有一个计数 $k$，所以 (11.55) 与 (11.57) 虽然解的是同一类方程，**代价模型却不同**——不能把 §11.5.3 的 $O(\sqrt m\log(1/\epsilon))$ 直接搬过来当迭代数上界。

**第三条**（迭代点不必可行）是 primal-dual 能在 $1/\epsilon$ 精度上胜出的原因：barrier method 每步都在可行域内部，越靠近边界 $-\log(-f_i)$ 的 Hessian 越病态；primal-dual 允许 $r_{pri} \ne 0$，于是可以选择在**内点与外点之间**走，不必贴着边界爬。

**量的方向感**：p613 给的实测是 LP 上 24 次迭代把 residual 打到数值零、约 28 次把 surrogate gap 打到极小，而 barrier method 在同一问题上要几十到上百次 centering 步（每步还含若干 Newton 步）。

**失败模式**：第一条若实现时仍按 barrier 的两层结构去写（外层加 $\mu$、内层跑 Newton 到 $\lambda = -1/(tf)$），得到的就是 Algorithm 11.1 而不是 11.2，$r_{pri}$ 恒为 0、$r_{dual}$ 永不出现，也就永远拿不到超线性收敛。

**落点**：Boyd §11.3（Algorithm 11.1 的两层结构）与本节 Algorithm 11.2 的对照；§11.5.3 的 (11.29)；p613 的 Figure 11.21。</span>



$r_t$ 的第一个分块分量

```math
r_{\text{dual}} = \nabla f_0(x) + Df(x)^T\lambda + A^T\nu
```

称为 **dual residual**，最后一个分块分量 $r_{\text{pri}} = Ax - b$ 称为 **primal residual**。中间那个分块

```math
r_{\text{cent}} = -\operatorname{diag}(\lambda)f(x) - (1/t)\mathbf{1}
```

是 **centrality residual**，即修正后的 complementarity condition 的残差。

现在考虑求解非线性方程组 $r_t(x,\lambda,\nu) = 0$ 的 Newton 步（对固定 $t$，且不像 §11.3.4 那样先把 $\lambda$ 消去），取在当前点 $(x,\lambda,\nu)$，该点满足 $f(x) \prec 0$、$\lambda \succ 0$†。把当前点与 Newton 步分别记为

```math
y = (x,\lambda,\nu), \qquad \Delta y = (\Delta x, \Delta\lambda, \Delta\nu).
```

Newton 步由线性方程刻画：

```math
r_t(y + \Delta y) \approx r_t(y) + Dr_t(y)\Delta y = 0,
```

即 $\Delta y = -Dr_t(y)^{-1}r_t(y)$。用 $x,\lambda,\nu$ 写出，就是

```math
\begin{bmatrix} \nabla^2 f_0(x) + \sum_{i=1}^{m}\lambda_i\nabla^2 f_i(x) & Df(x)^T & A^T \\ -\operatorname{diag}(\lambda)Df(x) & -\operatorname{diag}(f(x)) & 0 \\ A & 0 & 0 \end{bmatrix}\begin{bmatrix} \Delta x \\ \Delta\lambda \\ \Delta\nu \end{bmatrix} = -\begin{bmatrix} r_{\text{dual}} \\ r_{\text{cent}} \\ r_{\text{pri}} \end{bmatrix}.
\qquad (11.54)
```

primal-dual search direction $\Delta y_{\text{pd}} = (\Delta x_{\text{pd}}, \Delta\lambda_{\text{pd}}, \Delta\nu_{\text{pd}})$ 就定义为 (11.54) 的解。

primal search direction 与 dual search direction 是**耦合的**：既通过系数矩阵耦合，也通过残差耦合。例如 primal search direction $\Delta x_{\text{pd}}$ 依赖 dual 变量 $\lambda,\nu$ 的当前值，也依赖 $x$。还要注意：若 $x$ 满足 $Ax = b$，即 primal feasibility residual $r_{\text{pri}}$ 为零，则 $A\Delta x_{\text{pd}} = 0$，于是 $\Delta x_{\text{pd}}$ 给出一个（primal）可行方向：对任何 $s$，$x + s\Delta x_{\text{pd}}$ 都满足 $A(x + s\Delta x_{\text{pd}}) = b$。

### Comparison with barrier method search directions · 与 barrier method 搜索方向的比较

primal-dual search direction 与 barrier method 中用的 search direction 关系密切，但并不相同。我们从定义 primal-dual search direction 的线性方程 (11.54) 出发，先消去变量 $\Delta\lambda_{\text{pd}}$：

```math
\Delta\lambda_{\text{pd}} = -\operatorname{diag}(f(x))^{-1}\operatorname{diag}(\lambda)Df(x)\Delta x_{\text{pd}} + \operatorname{diag}(f(x))^{-1}r_{\text{cent}},
```

它来自方程组的第二个分块。把它代入第一个分块，得到

```math
\begin{bmatrix} H_{\text{pd}} & A^T \\ A & 0 \end{bmatrix}\begin{bmatrix} \Delta x_{\text{pd}} \\ \Delta\nu_{\text{pd}} \end{bmatrix} = -\begin{bmatrix} r_{\text{dual}} + Df(x)^T\operatorname{diag}(f(x))^{-1}r_{\text{cent}} \\ r_{\text{pri}} \end{bmatrix} = -\begin{bmatrix} \nabla f_0(x) + (1/t)\sum_{i=1}^{m}\dfrac{1}{-f_i(x)}\nabla f_i(x) + A^T\nu \\ r_{\text{pri}} \end{bmatrix},
\qquad (11.55)
```

<span style="color:#1e8449;">**[译注]** (11.54) 的系数矩阵把三块残差**摆在同一条方程的右侧**，这不是排版选择而是方法本身：barrier method 里 $r_{\text{cent}}$ 被"设为零"（centering 就是解 $r_{\text{cent}} = 0$），所以从来不需要给它一个独立的容差；primal-dual 里它是有量纲的量，与 $r_{\text{dual}}$、$r_{\text{pri}}$ 一起决定步长——这正是 Algorithm 11.2 的 line search 用**整体范数** $\|r_t\|_2$ 而不是分层判据的原因（p613）。

**量的方向感**：$r_{\text{cent}}$ 的第 $i$ 个分量是 $-\lambda_i f_i(x) - 1/t$，它的绝对值越小表示越接近 central path；在 central path 上有 $-\lambda_i f_i(x) = 1/t$，即 $t = 1/(-\lambda_i f_i(x))$，于是 surrogate gap $\hat\eta = \sum_i(-\lambda_i f_i(x)) = m/t$——这就是 p612 那个 $t := \mu m/\hat\eta$ 的出处。

**消失测试**：没有 (11.54) 这一步"不解耦、直接对 $r_t = 0$ 做 Newton"，就只能像 §11.3.4 那样先消去 $\lambda$，得到的是 $H_{\text{bar}}$ 而不是 $H_{\text{pd}}$；两者的唯一差别是 1,1 块里 $-\lambda_i f_i(x)$ 与 $1/t$ 这两个因子的相对位置，而正是这个差别决定了能否对 $\lambda$ 做迭代。

**量的方向感**：(11.54) 是 $(n + 2m + p) \times (n + 2m + p)$ 规模的系统（$p$ 为 equality constraint 条数），比 barrier method 消元后的 (11.55) 大了 $2m$ 行；**规模大是刻意的**，因为多出来的 $2m$ 维正是让 $\lambda$ 能独立迭代的空间。中间那块的两条对角矩阵使第二块恰好是 $m$ 个解耦的标量方程 $\lambda_i(-f_i(x)) + r_{\text{cent},i} = 1/t$——一个 $(\lambda_i, f_i)$ 对一个方程，互不干扰。

**落点**：Boyd §11.3.4（barrier method 的消元版本）与本节 (11.55)-(11.58) 的逐块对照；Algorithm 11.2 第 3 步的残差范数判据。</span>



其中

```math
H_{\text{pd}} = \nabla^2 f_0(x) + \sum_{i=1}^{m}\lambda_i\nabla^2 f_i(x) + \sum_{i=1}^{m}\frac{\lambda_i}{-f_i(x)}\nabla f_i(x)\nabla f_i(x)^T.
\qquad (11.56)
```

我们可以把 (11.55) 与定义 barrier method 中参数为 $t$ 的 centering problem 的 Newton 步的方程 (11.14) 相比较。后者可写成

```math
\begin{bmatrix} H_{\text{bar}} & A^T \\ A & 0 \end{bmatrix}\begin{bmatrix} \Delta x_{\text{bar}} \\ \nu_{\text{bar}} \end{bmatrix} = -\begin{bmatrix} t\nabla f_0(x) + \nabla\varphi(x) \\ r_{\text{pri}} \end{bmatrix} = -\begin{bmatrix} t\nabla f_0(x) + \sum_{i=1}^{m}\dfrac{1}{-f_i(x)}\nabla f_i(x) \\ r_{\text{pri}} \end{bmatrix},
\qquad (11.57)
```

其中

```math
H_{\text{bar}} = t\nabla^2 f_0(x) + \sum_{i=1}^{m}\frac{1}{-f_i(x)}\nabla^2 f_i(x) + \sum_{i=1}^{m}\frac{1}{f_i(x)^2}\nabla f_i(x)\nabla f_i(x)^T.
\qquad (11.58)
```

（这里给出的是 infeasible Newton step 的一般表达式；若当前 $x$ 可行，即 $r_{\text{pri}} = 0$，则 $\Delta x_{\text{bar}}$ 与 (11.14) 定义的可行 Newton 步 $\Delta x_{\text{nt}}$ 相同。）

第一个观察是：两个方程组 (11.55) 与 (11.57) 非常相似。它们的系数矩阵具有相同的结构；事实上 $H_{\text{pd}}$ 与 $H_{\text{bar}}$ 都是下列矩阵的正线性组合：

```math
\nabla^2 f_0(x),\; \nabla^2 f_1(x),\; \ldots,\; \nabla^2 f_m(x),\; \nabla f_1(x)\nabla f_1(x)^T,\; \ldots,\; \nabla f_m(x)\nabla f_m(x)^T.
```

这意味着：可以用**同一套方法**来计算 primal-dual search direction 与 barrier method 的 Newton 步。

关于 primal-dual 方程 (11.55) 与 barrier method 方程 (11.57) 的关系，还能说得更多。把方程 (11.57) 的第一个分块除以 $t$，并定义变量 $\Delta\bar\nu_{\text{bar}} = (1/t)\nu_{\text{bar}} - \nu$（$\nu$ 任取），就得到†

```math
\begin{bmatrix} (1/t)H_{\text{bar}} & A^T \\ A & 0 \end{bmatrix}\begin{bmatrix} \Delta x_{\text{bar}} \\ \Delta\bar\nu_{\text{bar}} \end{bmatrix} = -\begin{bmatrix} \nabla f_0(x) + (1/t)\sum_{i=1}^{m}\dfrac{1}{-f_i(x)}\nabla f_i(x) + A^T\nu \\ r_{\text{pri}} \end{bmatrix}.
```

在这个形式下，右端与 primal-dual 方程的右端（在同一点 $x,\lambda,\nu$ 处取值）**完全相同**。系数矩阵只在 1,1 块上不同：

```math
\begin{aligned}
H_{\text{pd}} &= \nabla^2 f_0(x) + \sum_{i=1}^{m}\lambda_i\nabla^2 f_i(x) + \sum_{i=1}^{m}\frac{\lambda_i}{-f_i(x)}\nabla f_i(x)\nabla f_i(x)^T,\\
(1/t)H_{\text{bar}} &= \nabla^2 f_0(x) + \sum_{i=1}^{m}\frac{1}{-tf_i(x)}\nabla^2 f_i(x) + \sum_{i=1}^{m}\frac{1}{tf_i(x)^2}\nabla f_i(x)\nabla f_i(x)^T.
\end{aligned}
```

当 $x$ 与 $\lambda$ 满足 $-f_i(x)\lambda_i = 1/t$ 时，两个系数矩阵（因而 search direction 本身）重合。

<span style="color:#1e8449;">**[译注]** 这一页给出的是**同一条方程组的两种参数化**，把它当成"两种算法"去读会丢掉关键信息。

正确的读法是：(11.55) 与除以 $t$ 之后的 (11.57) 共享同一个右端、共享 $A$ 块，只在 1,1 块上不同。当 $-\lambda_i f_i(x) = 1/t$ 对所有 $i$ 成立时，$H_{\text{pd}}$ 与 $(1/t)H_{\text{bar}}$ **逐项相等**：$-\lambda_i f_i = 1/t \Rightarrow \lambda_i = 1/(-tf_i)$，代入第一式即得第二式。换句话说，primal-dual 方法在"恰好落在 central path 上"时与 barrier method 的 Newton 步完全一致，差别只在**偏离 central path 时如何处理**：barrier 直接把 $\lambda$ 重置成 $-1/(tf)$，primal-dual 则让 $\lambda$ 自己走。

**消失测试**：若没有 $-\lambda_i f_i(x) = 1/t$ 这个对照点，(11.55) 与 (11.56) 就只是"另一个看起来很像的方程"，无法解释为什么 §11.8 的实现技术（KKT 消元、稀疏 Cholesky、low-rank 修正）可以**原封不动**地在两个算法之间搬用。

**量的方向感**：$H_{\text{pd}}$ 的第三项权重是 $\lambda_i/(-f_i)$，$H_{\text{bar}}$ 对应权重是 $1/f_i^2$；两者之比为 $-t\lambda_i f_i$，即"偏离 central path 的倍数"。数值后果也在这里：$1/f_i(x)^2$ 在 $x$ 靠近边界时趋于 $+\infty$，而 $\lambda_i/(-f_i)$ 只有当 $\lambda_i$ 同时变大才发散。

**落点**：Boyd §11.3.4 与 (11.14)；本页 (11.55)-(11.58)；§11.8 开头 (11.60) 明说"primal-dual 的 Newton 方程结构完全相同"。</span>



### 11.7.2 The surrogate duality gap · 替代对偶间隙

在 primal-dual 内点法中，迭代点 $x^{(k)},\lambda^{(k)},\nu^{(k)}$ 不必可行——除算法收敛的极限情形外。这意味着我们无法像（barrier method 的外层迭代）那样，轻松算出与第 $k$ 步相关联的 duality gap $\eta^{(k)}$。取而代之的是定义 **surrogate duality gap（替代对偶间隙）**：对任何满足 $f(x) \prec 0$ 且 $\lambda \succeq 0$ 的 $x$，令

```math
\hat\eta(x,\lambda) = -f(x)^T\lambda.
\qquad (11.59)
```

如果 $x$ 是 primal feasible 且 $\lambda,\nu$ 是 dual feasible，即 $r_{\text{pri}} = 0$ 且 $r_{\text{dual}} = 0$，那么 surrogate gap $\hat\eta$ **就会**是 duality gap。注意，与 surrogate duality gap $\hat\eta$ 相对应的参数 $t$ 的值是 $m/\hat\eta$。

### 11.7.3 Primal-dual interior-point method · primal-dual 内点法（算法）

现在可以描述基本的 primal-dual 内点算法了。

<span style="color:#2471a3;">**[Algorithm 11.2]**</span> **Primal-dual interior-point method（primal-dual 内点法）。**

> **given** $x$ 满足 $f_1(x) \lt 0,\ \ldots,\ f_m(x) \lt 0$，$\lambda \succ 0$，$\mu \gt 1$，$\epsilon_{\text{feas}} \gt 0$，$\epsilon \gt 0$。
>
> **repeat**
>
> 1. **Determine $t$.** 置 $t := \mu m/\hat\eta$。
> 2. **Compute primal-dual search direction（计算 primal-dual 搜索方向）** $\Delta y_{\text{pd}}$。
> 3. **Line search and update（线搜索并更新）.** 确定步长 $s \gt 0$，置 $y := y + s\Delta y_{\text{pd}}$。
>
> **until** $\|r_{\text{pri}}\|_2 \le \epsilon_{\text{feas}}$，$\|r_{\text{dual}}\|_2 \le \epsilon_{\text{feas}}$，且 $\hat\eta \le \epsilon$。

在第 1 步中，参数 $t$ 被置为 $m/\hat\eta$ 的 $\mu$ 倍，而 $m/\hat\eta$ 正是与当前 surrogate duality gap $\hat\eta$ 相对应的 $t$ 值。如果 $x,\lambda,\nu$ 恰好是参数为 $t$ 的 central point（因而 duality gap 为 $m/t$），那么第 1 步就是把 $t$ 增大 $\mu$ 倍——这正是 barrier method 所用的更新。参数 $\mu$ 取 10 这一量级似乎效果很好。

primal-dual 内点算法在下面三条同时成立时终止：$x$ 是 primal feasible、$\lambda,\nu$ 是 dual feasible（在容差 $\epsilon_{\text{feas}}$ 之内），且 surrogate gap 小于容差 $\epsilon$。由于 primal-dual 内点法常具有优于线性的收敛速度，把 $\epsilon_{\text{feas}}$ 与 $\epsilon$ 取得很小是常见做法。

### Line search · 线搜索

primal-dual 内点法中的 line search 是标准的 backtracking line search，基于残差的范数，并加以修正以保证 $\lambda \succ 0$ 与 $f(x) \prec 0$。把当前迭代点记为 $x,\lambda,\nu$，下一个迭代点记为 $x^+,\lambda^+,\nu^+$，即

```math
x^+ = x + s\Delta x_{\text{pd}}, \qquad \lambda^+ = \lambda + s\Delta\lambda_{\text{pd}}, \qquad \nu^+ = \nu + s\Delta\nu_{\text{pd}}.
```

<span style="color:#1e8449;">**[译注]** surrogate gap 这个名字本身就是提示：它**不是** $\eta$，而是 $\eta$ 的一个替代量（surrogate），成立的只是"两点都可行时它就等于 $\eta$"这一条件命题。

定义式 (11.59) 的动机可以从 barrier 的 (11.16) 直接读出：在 dual feasible 的 $\lambda_i = -1/(tf_i(x))$ 处，$-\sum_i f_i(x)\lambda_i = \sum_i 1/t = m/t$ 正好是 duality gap；primal-dual 把 $\lambda_i$ 从"由 $t$ 决定"改成"自己迭代"，于是 $-f(x)^T\lambda$ 就是同一表达式在 $\lambda$ 不再 dual feasible 时的自然替代品。

**量的方向感**：$\hat\eta = -f(x)^T\lambda$ 在初始点取 $\lambda_i = -1/f_i(x^{(0)})$ 时等于 $m$，而 p613 的实测给 $\hat\eta^{(0)} = 100$ 恰好对应 $m = 100$ 条不等式——**指数 2 的巧合是 $m$ 决定的**，不是调参结果。另一处差别在于 $t$ 的来历：barrier method 的 $t$ 是几何序列 $\mu^k t^{(0)}$，与迭代点无关；这里的 $t = \mu m/\hat\eta$ **依赖当前迭代点**，所以每步都在重估。

**消失测试**：没有 surrogate gap，就只剩两条残差判据，算法无法知道"离最优还有多远"，终止条件退化成只能靠 $\|r_{\text{dual}}\|$ 与 $\|r_{\text{pri}}\|$ 都小——但在不可行迭代点上这两者小并不蕴含次优性小（例如 $\lambda = 0$、$x$ 满足 $Ax = b$ 时两条残差都可以构造得很小）。

**落点**：Boyd §11.3.1 的 (11.16)（duality gap $m/t$ 的来历）；(11.59) 与 Algorithm 11.2 第 1 步、终止条件；p613 的 $\hat\eta^{(0)} = 100$。</span>



在 $y^+$ 处取值的残差记为 $r^+$。我们先算出不超过 1 的、使 $\lambda^+ \succeq 0$ 成立的最大正步长，即

```math
s_{\max} = \sup\{s \in [0,1] \mid \lambda + s\Delta\lambda \succeq 0\} = \min\left\{1,\ \min\{-\lambda_i/\Delta\lambda_i \mid \Delta\lambda_i \lt 0\}\right\}.
```

我们从 $s = 0.99s_{\max}$ 开始 backtracking，把 $s$ 乘以 $\beta \in (0,1)$ 直到 $f(x^+) \prec 0$ 成立；然后继续把 $s$ 乘以 $\beta$，直到

```math
\|r_t(x^+,\lambda^+,\nu^+)\|_2 \le (1 - \alpha s)\|r_t(x,\lambda,\nu)\|_2.
```

backtracking 参数 $\alpha$ 与 $\beta$ 的常用取法与 Newton 法相同：$\alpha$ 通常取在 $0.01$ 到 $0.1$ 之间，$\beta$ 通常取在 $0.3$ 到 $0.8$ 之间。

primal-dual 内点算法的一次迭代，等同于把 infeasible Newton method 用于求解 $r_t(x,\lambda,\nu) = 0$ 的一步，只是加以修正以保证 $\lambda \succ 0$ 与 $f(x) \prec 0$（等价地说，把 $\operatorname{dom}r_t$ 限制在 $\lambda \succ 0$、$f(x) \prec 0$ 上）。用证明 infeasible start Newton method 收敛性时的同一套论证可以说明：primal-dual 方法的 line search 总在有限步内终止。

### 11.7.4 Examples · 例子

我们用 §11.3.2 中考虑过的同一批问题来展示 primal-dual 内点法的表现。唯一的差别是：不再像 §11.3.2 那样从 central path 上的点出发，而是在随机生成的、满足 $f(x) \prec 0$ 的 $x^{(0)}$ 处启动 primal-dual 内点法，并取 $\lambda_i^{(0)} = -1/f_i(x^{(0)})$，于是 surrogate gap 的初值为 $\hat\eta = 100$。我们对 primal-dual 内点法采用的参数是

```math
\mu = 10, \qquad \beta = 0.5, \qquad \epsilon = 10^{-8}, \qquad \alpha = 0.01.
```

二者都对着迭代次数画。（初始点是 primal feasible 的，所以图上实际显示的是 dual feasibility residual 的范数†。）图显示：residual 迅速收敛到零，在 24 次迭代内就达到数值精度意义下的零；surrogate gap 也迅速收敛。与 barrier method 相比，primal-dual 内点法更快，尤其是在要求高精度时。Figure 11.22 展示 primal-dual 内点法在 §11.3.2 所考虑的那个 GP 上的进展，收敛情况与 LP 例子类似。

<span style="color:#1e8449;">**[译注]** 这一段有两个地方容易读错，都与"参数看起来是随手取的"有关。

**第一**，$s$ 的起点是 $0.99s_{\max}$ 而不是 $s_{\max}$：$s_{\max}$ 由 $\lambda_i + s\Delta\lambda_i = 0$ 的那个 $i$ 给出，取到 $s_{\max}$ 会让某个 $\lambda_i$ **恰好等于 0**，从而把 dual 迭代点推到边界上、$r_{\text{cent}}$ 里出现 $-\lambda_i f_i = 0$ 的退化；乘 $0.99$ 是把它拉回严格内部。

**第二**，$\alpha,\beta$ 的区间 $[0.01,0.1]$ 与 $[0.3,0.8]$ 与 Newton 法完全相同，这不是省事而是同一条件：line search 判据 $\|r_t^+\|_2 \le (1 - \alpha s)\|r_t\|_2$ 就是 Newton decrement 的 Armijo 条件在**残差**而非目标函数上的版本，收敛性来自"$\|r_t\|_2$ 单调下降到 $10^{-8}$ 量级"这件事本身。另外 $s_{\max}$ 只由 $\lambda_i$ 与 $\Delta\lambda_i$ 决定、与 $f$ 无关，所以 $x$ 侧的可行性必须靠第二次缩放单独保证，两步不能合并。

**量的方向感**：$\epsilon = 10^{-8}$ 对应的 duality gap 是 $10^{-8}$，而 barrier method 常取 $\epsilon = 10^{-6}$（§11.3.2）；也就是说本节的对比是**在精度高两个数量级的前提下**仍然更快。

**失败模式**：若把 $\epsilon_{\text{feas}}$ 与 $\epsilon$ 取成同一个很松的值（如 $10^{-3}$），$\hat\eta \le \epsilon$ 会先被满足而退出，此时 $\lambda$ 可能还不 dual feasible，代回去的目标值 $f_0(x)$ 与真最优的差可达 $m/\hat\eta$ 量级——即 $10^5 \times 10^{-3}$ 的假精度。

**落点**：Boyd §11.3.2（$\epsilon = 10^{-6}$ 的 barrier 实测）与本页参数；Algorithm 11.2 第 3 步；p614 的 Figure 11.21。</span>

$r_{\text{feas}}$ 曲线在大约 10 次迭代之后进入"每步下降固定倍数"的区间——在双对数坐标下是直线，斜率对应**线性收敛**；$\hat\eta$ 曲线在末段会继续变陡，对应**优于线性（superlinear）**。这正是 §11.7 开头那句"can exhibit better than linear convergence"的来源，也是为什么同样的 $10^{-8}$ 精度，barrier method 需要几十次 centering 步而这里只要 24-28 次迭代。

**量的方向感**：$r_{\text{feas}}$ 的起点量级 $10^{5}$，终点量级 $10^{-15}$，比值 $10^{20}$；在 24 次迭代内完成意味着平均每次迭代下降近一个数量级（$10^{20/24} \approx 6.8$ 倍/次）。线性收敛的定义要求这个倍数**有常数下界**，而这里在末段还在增大，故称 superlinear。

**失败模式**：若只报告 $\hat\eta$ 而不报告 $r_{\text{feas}}$（或反之），会看不到"两者不是同步到零"这一事实——本题里 residual 先到零（24 次），gap 后到（28 次），说明**中途退出会让 surrogate gap 虚高**，即你以为解得很准而实际次优性还差一个量级。
