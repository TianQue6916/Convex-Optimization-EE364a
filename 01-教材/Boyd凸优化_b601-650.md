## 11.8 Implementation · 实现

barrier method 中的主要工作量在于计算 centering problem 的 Newton 步，也就是求解形如

```math
\begin{bmatrix} H & A^T \\ A & 0 \end{bmatrix}\begin{bmatrix} \Delta x_{\text{nt}} \\ \nu_{\text{nt}} \end{bmatrix} = -\begin{bmatrix} g \\ 0 \end{bmatrix}
\qquad (11.60)
```

的线性方程组，其中

```math
H = t\nabla^2 f_0(x) + \sum_{i=1}^{m}\frac{1}{f_i(x)^2}\nabla f_i(x)\nabla f_i(x)^T + \sum_{i=1}^{m}\frac{1}{-f_i(x)}\nabla^2 f_i(x),
```

<span style="color:#1e8449;">**[译注]** Figure 11.23 与 Figure 11.8（barrier method 的同一族实验）的对照是本章最值得记住的一条**定量事实**：不可行起点 + 高两个数量级的精度，换来的是迭代次数只增加约 10–30%。

这看起来违反直觉——不可行起点意味着前若干步要先"修可行性"，通常以为会白白浪费迭代。真实的机制是：primal-dual 的每一步**同时**在修 $r_{\text{pri}}$、$r_{\text{dual}}$、$r_{\text{cent}}$，三条残差共享同一个 Newton 系统，所以"修可行性"不是独立的 phase I，而是与中心化同一批步数完成；barrier method 若从不可行点出发则必须先跑 §11.4 的 phase I，那部分步数是**额外加上去**的。

**量的方向感**：迭代次数 15 到 35，跨越 $m$ 从 $10^{1}$ 到 $10^{3}$（100:1）只涨了约 2.3 倍，而 $\log_{10}(1000/10) = 2$，与"近似对数增长"一致；对比 §11.5.3 的理论界 $O(\sqrt m\log(1/\epsilon))$，$\sqrt{100} = 10$ 倍的维度增长理论上允许 3.2 倍步数增长——**实测比最坏界好得多**，因为那是最坏情形界。

**消失测试**：若没有这张图，"primal-dual 比 barrier 更实用"就只是文献断言；有了它才能看到：图 11.8 的 barrier 在同一族上迭代数与之相近，但 barrier 那组是可行起点 + $\epsilon = 10^{-6}$，两个条件都更宽松。

**落点**：Boyd §11.3.2 与 Figure 11.8（barrier 的同族实验）；§11.5.3 的 (11.29)（理论界）；本页的实测区间 15–35。</span>



```math
g = t\nabla f_0(x) + \sum_{i=1}^{m}\frac{1}{-f_i(x)}\nabla f_i(x).
```

primal-dual 方法的 Newton 方程具有**完全相同**的结构，因此本节的所有观察同样适用于 primal-dual 方法。

方程组 (11.60) 的系数矩阵具有 KKT 结构，所以 §9.7 与 §10.4 的全部讨论在这里都适用。特别地，这些方程可以用消元法求解，而稀疏性、或"对角加低秩"这类结构可以被利用。

下面给出几个一般性的例子，说明 KKT 方程的特殊结构如何被用来更高效地计算 Newton 步。

### Sparse problems · 稀疏问题

若原问题是稀疏的——意思是目标函数与每条约束函数都只依赖适当多个变量——那么目标函数与约束函数的梯度、Hessian 矩阵都是稀疏的，系数矩阵 $A$ 也是。只要 $m$ 不太大，矩阵 $H$ 很可能也是稀疏的，于是可以用 sparse matrix method 来计算 Newton 步。若 KKT 矩阵中有少数相对稠密的行与列（例如存在少量涉及大量变量的 equality constraint 时就会出现这种情况），该方法往往仍然工作良好。

### Separable objective and a few linear inequality constraints · 可分离目标 + 少量线性不等式约束

设目标函数可分离，并且只有相对少量的线性 equality 与 inequality 约束。这时 $\nabla^2 f_0(x)$ 是对角的，而 $\nabla^2 f_i(x)$ 这些项消失，于是矩阵 $H$ 是"对角加低秩"。由于 $H$ 易于求逆，KKT 方程可以高效求解。只要 $\nabla^2 f_0(x)$ 易于求逆（例如 banded（带状）、sparse、或 block diagonal（分块对角）），同样的方法都可以用。

### 11.8.1 Standard form linear programming · 标准形线性规划

先讨论 barrier method 在标准形 LP

```math
\begin{array}{ll}
\text{minimize} & c^T x\\
\text{subject to} & Ax = b,\\
& x \succeq 0,
\end{array}
```

（其中 $A \in \mathbf{R}^{m \times n}$）上的实现。centering problem

```math
\begin{array}{ll}
\text{minimize} & tc^T x - \sum_{i=1}^{n}\log x_i\\
\text{subject to} & Ax = b
\end{array}
```

的 Newton 方程是

```math
\begin{bmatrix} \operatorname{diag}(x)^{-2} & A^T \\ A & 0 \end{bmatrix}\begin{bmatrix} \Delta x_{\text{nt}} \\ \nu_{\text{nt}} \end{bmatrix} = \begin{bmatrix} -tc + \operatorname{diag}(x)^{-1}\mathbf{1} \\ 0 \end{bmatrix}.
```

<span style="color:#1e8449;">**[译注]** §11.8 的位置很容易被低估：它排在两个算法之后，看起来像"工程细节"。但这一节决定了**第 11 章的理论能不能落地**。

关键句是「primal-dual 的 Newton 方程具有完全相同的结构」。回想 p611 的结论：$H_{\text{pd}}$ 与 $H_{\text{bar}}$ 只在 1,1 块上不同，且都是同一组矩阵 $\{\nabla^2f_i\}$、$\{\nabla f_i\nabla f_i^T\}$ 的正线性组合。这意味着所有**只看结构不看系数**的技术——KKT 消元、稀疏 Cholesky、low-rank 修正、block diagonal 分解——在两个算法之间可以整段搬用。

**量的方向感**：标准形 LP 里 $H = \operatorname{diag}(x)^{-2}$，代入 (11.60) 后消元得到 $A\operatorname{diag}(x)^2A^T\nu_{\text{nt}} = \cdots$（p617），每次 Newton 步的代价从解 $n \times n$ 系统降为解 $m \times m$ 系统；当 $n \gg m$（典型 LP 是 $n = 2m$）时省的不是常数而是**一个数量级以上的规模**。

**消失测试**：若 Hessian 不具 KKT 结构，就只能把 $(n+m) \times (n+m)$ 的矩阵整体分解，代价 $O((n+m)^3)$；有了结构才能做 block elimination，代价降到 $O(nm^2 + m^3)$ 量级。SDP 情形下这个差别更残酷（p619：$\max\{np^3, n^2p^2, n^3\}$ 中每一项都来自结构利用）。

**落点**：Boyd §9.7（KKT 系统的一般消元）、§10.4（network flow 的 KKT 结构）；p611 的 (11.55)-(11.58) 结构对照；本块 p617-p620 的四个具体情形。</span>



这些方程通常用对 $\Delta x_{\text{nt}}$ 的 block elimination 来求解。由第一个方程得

```math
\begin{aligned}
\Delta x_{\text{nt}} &= \operatorname{diag}(x)^2\left(-tc + \operatorname{diag}(x)^{-1}\mathbf{1} - A^T\nu_{\text{nt}}\right)\\
&= -t\operatorname{diag}(x)^2 c + x - \operatorname{diag}(x)^2 A^T\nu_{\text{nt}}.
\end{aligned}
```

代入第二个方程得到

```math
A\operatorname{diag}(x)^2A^T\nu_{\text{nt}} = -tA\operatorname{diag}(x)^2c + b.
```

由假设 $\operatorname{rank}A = m$，该系数矩阵是正定的。此外，若 $A$ 稀疏，则 $A\operatorname{diag}(x)^2A^T$ 通常也稀疏，于是可以用 sparse Cholesky factorization。

### 11.8.2 $\ell_1$-norm approximation · $\ell_1$-范数逼近

考虑 $\ell_1$-norm approximation 问题

```math
\text{minimize} \quad \|Ax - b\|_1
```

其中 $A \in \mathbf{R}^{m \times n}$。我们假定 $m$ 与 $n$ 都很大、且 $A$ 有结构（例如稀疏）来讨论其实现，并与相应的 least-squares 问题

```math
\text{minimize} \quad \|Ax - b\|_2^2
```

的代价作比较。

首先引入辅助变量 $y \in \mathbf{R}^m$，把 $\ell_1$-norm approximation 问题写成 LP：

```math
\begin{array}{ll}
\text{minimize} & \mathbf{1}^T y\\
\text{subject to} & \begin{bmatrix} A & -I\\ -A & -I \end{bmatrix}\begin{bmatrix} x\\ y \end{bmatrix} \preceq \begin{bmatrix} b\\ -b \end{bmatrix}.
\end{array}
```

centering problem 的 Newton 方程是

```math
\begin{bmatrix} A^T & -A^T\\ -I & -I \end{bmatrix}\begin{bmatrix} D_1 & 0\\ 0 & D_2 \end{bmatrix}\begin{bmatrix} A & -I\\ -A & -I \end{bmatrix}\begin{bmatrix} \Delta x_{\text{nt}}\\ \Delta y_{\text{nt}} \end{bmatrix} = -\begin{bmatrix} A^T g_1\\ g_2 \end{bmatrix},
```

其中

```math
D_1 = \operatorname{diag}(b - Ax + y)^{-2}, \qquad D_2 = \operatorname{diag}(-b + Ax + y)^{-2},
```

并且

```math
\begin{aligned}
g_1 &= \operatorname{diag}(b - Ax + y)^{-1}\mathbf{1} - \operatorname{diag}(-b + Ax + y)^{-1}\mathbf{1}\\
g_2 &= t\mathbf{1} - \operatorname{diag}(b - Ax + y)^{-1}\mathbf{1} - \operatorname{diag}(-b + Ax + y)^{-1}\mathbf{1}.
\end{aligned}
```

把左端乘开，可以简化为

```math
\begin{bmatrix} A^T(D_1 + D_2)A & -A^T(D_1 - D_2)\\ -(D_1 - D_2)A & D_1 + D_2 \end{bmatrix}\begin{bmatrix} \Delta x_{\text{nt}}\\ \Delta y_{\text{nt}} \end{bmatrix} = -\begin{bmatrix} A^T g_1\\ g_2 \end{bmatrix}.
```

<span style="color:#1e8449;">**[译注]** 这两页给的是**同一件事在两个建模层面的对照**：LP 形式的 $\ell_1$ 问题有 $n + m$ 个变量、$2m$ 条不等式，Newton 系统看起来是 $(n+m) \times (n+m)$；但它的系数矩阵写成 $J^TDJ$ 的形式（$J$ 是约束的 Jacobian），于是 block elimination 之后只剩一个 $n \times n$ 的 $A^TDA$。

**量的方向感**：$A^TDA$ 是 $n \times n$，而原始系统是 $(n+m) \times (n+m)$；在典型的压缩感知式设定（$m \approx n/4$、$n$ 很大）里，这一步把线性代数规模压掉约 $(1.25)^3 \approx 2$ 倍；真正的好处不是这个常数，而是**$A^TDA$ 继承 $A$ 的稀疏性**（p618 明说），于是可以走 sparse Cholesky。

**消失测试**：没有"把 $\ell_1$ 问题写成带辅助变量的 LP"这一步，$\|\cdot\|_1$ 不可微，barrier method 连 centering problem 都写不出（$\varphi$ 需要 $2m$ 个光滑的 $-\log$ 项）；而引入 $y$ 后每条不等式都是 affine 的，代价是把变量数从 $n$ 加到 $n+m$。

**失败模式**：若直接对 $\|\cdot\|_1$ 做光滑近似（例如 $\sqrt{x^2 + \epsilon}$），Hessian 的元素在 $|Ax - b| \ll \epsilon$ 的坐标上会退化到 $1/\epsilon$ 量级，条件数从 $O(1/\epsilon_{\text{opt}})$ 恶化到 $O(1/\epsilon^2)$——这是 §11.8 之前时代"罚函数法"的经典困境。

**落点**：Boyd §6.1.1（$\ell_1$ 的 LP 形式与辅助变量）；§11.3.1（barrier 的构造）；p618 的 (11.61) 与 normal equations 解释。</span>



对 $\Delta y_{\text{nt}}$ 做 block elimination，可把它化为

```math
A^TDA\Delta x_{\text{nt}} = -A^T g
\qquad (11.61)
```

其中

```math
D = 4D_1D_2(D_1 + D_2)^{-1} = 2\left(\operatorname{diag}(y)^2 + \operatorname{diag}(b - Ax)^2\right)^{-1}
```

并且

```math
g = g_1 + (D_1 - D_2)(D_1 + D_2)^{-1}g_2.
```

解出 $\Delta x_{\text{nt}}$ 之后，再由

```math
\Delta y_{\text{nt}} = (D_1 + D_2)^{-1}\left(-g_2 + (D_1 - D_2)A\Delta x_{\text{nt}}\right)
```

得到 $\Delta y_{\text{nt}}$。

值得注意的是：(11.61) 恰是某个 weighted least-squares 问题

```math
\text{minimize} \quad \|D^{1/2}(A\Delta x + D^{-1}g)\|^2
```

的 normal equations。换句话说，求解 $\ell_1$-norm approximation 问题的代价，等于求解**一批** weighted least-squares 问题的代价：矩阵 $A$ 相同、个数不多、而权重每次迭代都变。如果 $A$ 的结构允许快速求解 least-squares 问题（例如利用稀疏性），那么 (11.61) 也能快速求解。

### 11.8.3 Semidefinite programming in inequality form · 不等式形式的半定规划

考虑 SDP

```math
\begin{array}{ll}
\text{minimize} & c^T x\\
\text{subject to} & \sum_{i=1}^{n}x_iF_i + G \preceq 0,
\end{array}
```

变量为 $x \in \mathbf{R}^n$，参数为 $F_1,\ldots,F_n,G \in \mathbf{S}^p$。使用 log-determinant barrier function 时，相应的 centering problem 是

```math
\text{minimize} \quad tc^T x - \log\det\left(-\sum_{i=1}^{n}x_iF_i - G\right).
```

Newton 步 $\Delta x_{\text{nt}}$ 由 $H\Delta x_{\text{nt}} = -g$ 求出，其中 Hessian 与梯度为

```math
\begin{aligned}
H_{ij} &= \operatorname{tr}\left(S^{-1}F_iS^{-1}F_j\right), \quad i,j = 1,\ldots,n\\
g_i &= tc_i + \operatorname{tr}\left(S^{-1}F_i\right), \quad i = 1,\ldots,n,
\end{aligned}
```

这里 $S = -\sum_{i=1}^{n}x_iF_i - G$。一种标准做法是先形成 $H$（以及 $g$），再通过 Cholesky factorization 求解 Newton 方程。

先考虑非结构情形，即假定所有矩阵都是稠密的；并且只跟踪 flop count 的阶，自变量是问题维数 $n$ 与 $p$。先形成 $S$，代价为 $np^2$ 阶。然后对每个 $i$ 计算矩阵 $S^{-1}F_i$：通过对 $S$ 作 Cholesky factorization，再对 $F_i$ 的各列作回代（或者直接形成 $S^{-1}$ 再乘 $F_i$）。对每个 $i$ 这一步是 $p^3$ 阶，故总代价是 $np^3$ 阶。最后，

<span style="color:#1e8449;">**[译注]** (11.61) 与"weighted least-squares 的 normal equations"这句话是全节最可操作的一个结论。

它说的是：$\ell_1$ 的 barrier method 每一步，本质上是解同一个 least-squares 黑箱，只换权重 $D$。于是工程上的推论非常直接：**如果你已有稀疏 QR / Cholesky，就基本免费得到了 $\ell_1$ 求解器**，不需要为 $\ell_1$ 单独写线性代数。

**量的方向感**：$D = 2(\operatorname{diag}(y)^2 + \operatorname{diag}(b-Ax)^2)^{-1}$，当残差 $b - Ax$ 的某个分量趋于 0 时 $D$ 的对应元素趋于 $2/y_i^2$（有界）；反之当残差很大时 $D \to 0$，那一行几乎被"关掉"。这解释了 $\ell_1$ 解为什么稀疏：**残差大的样本在 Newton 系统里被自动降权**，等价于把它们从 active set 里剔除。

**消失测试**：若 $D$ 不是对角正定（例如换成一般对称正定矩阵），(11.61) 就不再是 normal equations，无法用 Cholesky 也不用最小二乘黑箱，只能对 $A^TDA$ 做一般分解，代价从"复用 least-squares 求解器"退化到"每次重新分解 $n \times n$ 矩阵"。

**失败模式**：$D_1 + D_2$ 中出现 $y_i = 0$ 或 $|b - Ax|_i = 0$ 时 $D$ 的元素会到 $2/y_i^2$；若实现时不加保护（$y_i$ 被约束为 $\gt 0$ 但可任意小），$D$ 的量级可到 $10^{16}$，$A^TDA$ 的条件数随之爆炸，Cholesky 报 "not positive definite"（数值上）而算法假失败。

**落点**：Boyd §11.8.2 的 (11.61)；§6.3.2（$\ell_1$ 与 robust regression 的关系）；本块 p619 起 SDP 的 flop 记账是同一套"先形成再分解"的方法论。</span>



我们把 $H_{ij}$ 形成为矩阵 $S^{-1}F_i$ 与 $S^{-1}F_j$ 的内积，代价为 $p^2$ 阶 flop。由于要对 $n(n+1)/2$ 个这样的矩阵对做这件事，代价是 $n^2p^2$ 阶。求解 Newton 方向是 $n^3$ 阶。因此主导阶是 $\max\{np^3,\ n^2p^2,\ n^3\}$。

一般说来，**不可能**利用 $F_i$ 与 $G$ 的稀疏性，因为即使 $F_i$ 与 $G$ 稀疏，$H$ 往往也是稠密的。一个例外是 $F_i$ 与 $G$ 具有共同的 block diagonal 结构，此时上述所有运算都可以逐块进行。

不过，常有可能利用 $F_i$ 与 $G$ 的（共同）稀疏性来**更高效地形成**（稠密的）Hessian $H$：只要能找到一个排序使 $S$ 的 Cholesky 因子相当稀疏，就能高效地算出 $S^{-1}F_i$，从而以低得多的代价形成 $H_{ij}$。

一个常见而有趣、且经常出现的例子是带矩阵不等式 $\operatorname{diag}(x) \preceq B$ 的 SDP†。它对应 $F_i = E_{ii}$，其中 $E_{ii}$ 是 $i,i$ 元素为 1、其余为 0 的矩阵。此时矩阵 $H$ 可以极高效地求出：

```math
H_{ij} = (S^{-1})^2_{ij},
```

其中 $S = B - \operatorname{diag}(x)$。于是形成 $H$ 的代价就是形成 $S^{-1}$ 的代价，最坏（即不利用任何其他结构时）为 $n^3$ 阶。

### 11.8.4 Network rate optimization · 网络速率优化

考虑 §10.4.3（第 550 页）所述 optimal network flow 问题的一个变体，它有时被称为 **network rate optimization problem（网络速率优化问题）**。网络用一个有 $L$ 条弧或链路的 directed graph 描述。货物（或信息包）在网络中传输，经过各链路。网络承载 $n$ 个 flow，其（非负）速率 $x_1,\ldots,x_n$ 是优化变量。每个 flow 沿网络中一条固定（预先给定）的 path（路线）从源节点走向目的节点。每条链路可以承载多个经过它的 flow。链路的总流量是经过该链路的所有 flow 速率之和。每条链路有一个正容量，即它能承受的最大总流量。

可以用 flow-link incidence matrix（流量-链路关联矩阵）$A \in \mathbf{R}^{L \times n}$ 来描述这些链路容量限制，其定义为

```math
A_{ij} = \begin{cases} 1 & \text{flow } j \text{ 经过 link } i\\ 0 & \text{其他}\end{cases}
```

于是链路 $i$ 上的总流量为 $(Ax)_i$，链路容量约束可写为 $Ax \preceq c$，其中 $c_i$ 是链路 $i$ 的容量。通常每条 path 只经过全部链路中很小的一部分，因此矩阵 $A$ 是稀疏的。

在 network rate 问题中，path 是固定的（已编码进矩阵 $A$，而 $A$ 是问题参数）；变量是 flow 速率 $x_i$。目标是

<span style="color:#1e8449;">**[译注]** $\max\{np^3,\ n^2p^2,\ n^3\}$ 这个式子本身没什么，但它逼出一个**建模层面的判断**：SDP 的代价由 $n$ 与 $p$ 的相对大小决定，三者对应三种算法瓶颈，而"哪一种主导"决定了你该优化哪一段代码。

- $np^3$ 主导：瓶颈在"对 $p \times p$ 矩阵求逆、再乘 $n$ 个 $F_i$"，即**大矩阵、少变量**；
- $n^2p^2$ 主导：瓶颈在"形成 $n(n+1)/2$ 个内积"，即 **Hessian 的自由度**；
- $n^3$ 主导：瓶颈在"解 $n \times n$ 系统"，即**变量多**。

**量的方向感**：$n = 100$、$p = 10$ 时三项是 $10^5$、$10^6$、$10^6$，后两者并列主导；$n = 10$、$p = 100$ 时是 $10^7$、$10^6$、$10^3$，$np^3$ 主导——同一个代码换个问题规模，优化目标就换了。

**消失测试**：若不知道这个分解，看到 SDP 慢就只能笼统说"Hessian 太稠密"；知道之后才能判断在 $\operatorname{diag}(x) \preceq B$ 这类特例里 $H_{ij} = (S^{-1})^2_{ij}$，于是**形成 $H$ 的全部代价塌缩为一次 $S^{-1}$**，三项里的 $n^2p^2$ 直接消失。

**失败模式**：对 $F_i = E_{ii}$ 这种极端稀疏的 $F_i$，若仍按"$S^{-1}F_i$ 再求内积"的老路走，每个 $i$ 都要 $p^3$，总计 $np^3$；而利用 $H_{ij} = (S^{-1})^2_{ij}$ 只需 $n^3$ 一次——当 $p \gg n$ 时两者差 $p^3/n^2$ 倍，实测里能到三个数量级。

**落点**：Boyd §11.8.3 的三项；diag 情形的 $H_{ij} = (S^{-1})^2_{ij}$（可直接按定义验：$\operatorname{tr}(S^{-1}E_{ii}S^{-1}E_{jj}) = (S^{-1})_{ij}(S^{-1})_{ji} = (S^{-1})^2_{ij}$）；§9.7 的稀疏排序讨论。</span>



选取 flow 速率以最大化一个可分离效用函数 $U$，即

```math
U(x) = U_1(x_1) + \cdots + U_n(x_n).
```

我们假定每个 $U_i$（从而 $U$）是凹的且非减。可以把 $U_i(x_i)$ 看作以速率 $x_i$ 支撑第 $i$ 个 flow 所获得的收益；$U(x)$ 就是这些 flow 带来的总收益。于是 network rate optimization 问题为

```math
\begin{array}{ll}
\text{maximize} & U(x)\\
\text{subject to} & Ax \preceq c,\\
& x \succeq 0,
\end{array}
\qquad (11.62)
```

这是一个凸优化问题。

我们来用 barrier method 求解该问题。每一步都要用 Newton 法极小化形如

```math
-tU(x) - \sum_{i=1}^{L}\log(c - Ax)_i - \sum_{j=1}^{n}\log x_j
```

的函数。Newton 步 $\Delta x_{\text{nt}}$ 通过求解线性方程

```math
(D_0 + A^TD_1A + D_2)\Delta x_{\text{nt}} = -g
```

得到，其中

```math
\begin{aligned}
D_0 &= -t\operatorname{diag}\left(U_1''(x_1),\ldots,U_n''(x_n)\right)\\
D_1 &= \operatorname{diag}\left(1/(c - Ax)_1^2,\ldots,1/(c - Ax)_L^2\right)\\
D_2 &= \operatorname{diag}\left(1/x_1^2,\ldots,1/x_n^2\right)
\end{aligned}
```

都是对角矩阵，且 $g \in \mathbf{R}^n$†。这个 $n \times n$ 系数矩阵的稀疏结构可以精确描述：

```math
(D_0 + A^TD_1A + D_2)_{ij} \ne 0
```

当且仅当 flow $i$ 与 flow $j$ 共用某条链路。若各 path 相对较短、且每条链路经过的 path 相对较少，则该矩阵是稀疏的，于是可以用 sparse Cholesky factorization。当有部分（但不太多）行与列相对稠密时，Newton 系统也能高效求解：这出现在少数几个 flow 与大量其他 flow 相交的时候，例如少数几个 flow 相对较长时。

我们也可以用 matrix inversion lemma 来计算 Newton 步，改为求解一个 $L \times L$ 系数矩阵的系统

```math
\left(D_1^{-1} + A(D_0 + D_2)^{-1}A^T\right)y = -A(D_0 + D_2)^{-1}g,
```

然后再算

```math
\Delta x_{\text{nt}} = -(D_0 + D_2)^{-1}(g + A^Ty).
```

这里的稀疏模式同样可以精确描述：

```math
\left(D_1^{-1} + A(D_0 + D_2)^{-1}A^T\right)_{ij} \ne 0
```

当且仅当存在一条同时经过 link $i$ 与 link $j$ 的 path。若大多数 path 都短，这个矩阵是稀疏的。若存在少数瓶颈（即少数链路被大量 flow 穿过），这个矩阵就会稀疏但仍带少数稠密行与列。

<span style="color:#1e8449;">**[译注]** 这一页的干货是**两个互斥的消元方向**，而它们的适用条件由网络的形状决定。

方向 A（对 $x$ 消元后解 $n \times n$）：矩阵 $D_0 + A^TD_1A + D_2$ 的非零结构由"两 flow 共享链路"决定——**按 flow 计的冲突图**。
方向 B（matrix inversion lemma 后解 $L \times L$）：矩阵的非零结构由"两链路被同一 path 穿过"决定——**按链路计的冲突图**。

两者是同一个 Schur 补的两面，代价分别是 $O(n^3)$ 与 $O(L^3)$ 加一次 $n \times n$ 求逆；所以选哪个取决于 $n$ 与 $L$ 谁小，以及各自的稀疏图是否稀疏。

**量的方向感**：典型 ISP 拓扑里 $n$（flow 数）可达 $10^5$、$L$（链路数）$10^3$ 量级，比值 100，于是方向 B 的线性代数规模小 $10^6$ 倍（立方意义下），这是实际实现普遍用方向 B 的原因。

**消失测试**：没有 matrix inversion lemma，$A^TD_1A$ 这种"$L$ 项之和"的结构就只能整体解，$n \gg L$ 时白扔掉一个数量级的规模优势。

**失败模式**：若 $D_0 + D_2$ 不可逆（某个 $x_i = 0$，即 flow $i$ 速率恰好停在边界），方向 B 里的 $(D_0+D_2)^{-1}$ 直接发散；实现上必须保证 $x \succ 0$（barrier 保证了这点，但 line search 的 $s_{\max}$ 要按 $x$ 也算一遍）。

**落点**：Boyd §11.8.4 的两个稀疏判据；§10.4.3（optimal network flow 与 $A$ 的含义）；Sherman-Morrison-Woodbury 的标准形式见 §A.5.5 附近的 matrix inversion lemma。</span>



## Bibliography · 文献注记（第 11 章）

barrier method 的早期历史由 Fiacco 与 McCormick [FM90, §1.2] 详细记述。1960 年代，该方法是凸优化的常用算法之一，与若干密切相关的技术并列：method of centers（Liê˜u 与 Huard [LH66]；另见 exercise 11.11）、以及 penalty（或 exterior-point）方法 [FM90, §4]。1970 年代兴趣消退，原因是人们担心当 $t$ 取大值时 centering problem (11.6) 的 Newton 方程会病态（ill-conditioning）。

1980 年代 barrier method 重新流行：Gill、Murray、Saunders、Tomlin 与 Wright [GMS+86] 指出它与 Karmarkar 的线性规划多项式时间 projective algorithm [Kar84] 有密切联系。整个 1980 年代的研究重点仍在 linear（其次是 quadratic）programming，产生了基本内点法的各种变体以及改进的最坏情形复杂度结果（见 Gonzaga [Gon92]）。primal-dual 方法逐渐成为实际实现中的首选算法（见 Mehrotra [Meh92]，Lustig、Marsten 与 Shanno [LMS94]，Wright [Wri97]）。

在 1994 年的著作中，Nesterov 与 Nemirovski 借助 self-concordant 函数的 Newton 法收敛理论，把线性规划内点法的复杂度理论推广到非线性凸优化问题。他们还发展了处理广义不等式问题的内点法，并讨论了把问题重述以满足 self-concordance 假设的各种途径。例如第 587 页的 geometric programming 重述就来自 [NN94, §6.3.1]。

正如第 585 页所述，complexity analysis 表明：与可能预期相反，至少在精确算术下，barrier method 中的 centering problem **不会**随 $t$ 增大而变得更难。实践经验以及理论结果（Forsgren、Gill 与 Wright [FGW02, §4.3.2]，Nocedal 与 Wright [NW99, 第 525 页]）也表明：ill-conditioning 对 Newton 系统**计算解**的影响比早先认为的更温和。

近年关于内点法的研究集中于：把线性规划中收敛更快、精度更高（相对 primal barrier 方法）的 primal-dual 方法推广到非线性凸问题。一条流行的路线沿 §11.7 的简单 primal-dual 方法展开，基于把标准形凸优化问题（即问题 (11.1)）的修正 KKT 方程线性化。更精细的此类算法与 Algorithm 11.2 的差别在于 $t$ 的选取策略（这对获得超线性渐近收敛至关重要）以及 line search。细节与文献见 Wright [Wri97, 第 8 章]，Ralph 与 Wright [RW97]，den Hertog [dH93]，Terlaky [Ter96]，以及 Forsgren、Gill 与 Wright 的综述 [FGW02, §5]。

<span style="color:#1e8449;">**[译注]** 这段文献注记里唯一有**技术含量**的一句是"ill-conditioning 对计算解的影响比早先认为的更温和"，它解释了为什么 1970 年代放弃 barrier method 的理由后来被推翻。

机制：barrier method 的 Newton 方程在 $t$ 大时条件数按 $t$ 增长（$H_{\text{bar}}$ 的第一项是 $t\nabla^2f_0$，其余两项与 $t$ 无关），所以"精确求解会损失 $t$ 位有效数字"是对的；但**迭代法只需要方向对**——Newton 步对系数矩阵的扰动是 $O(\kappa\epsilon_{\text{mach}})$，而这个扰动只影响收敛速率，不影响收敛到的点。

**量的方向感**：若条件数 $\kappa \approx 10^{12}$ 且 $\epsilon_{\text{mach}} \approx 10^{-16}$，则解出的方向相对误差约 $10^{-4}$；superlinear 收敛下这个误差只让步数增加常数个，而**不是**让算法失效。对比之下，若把 $t$ 限制在 $10^{4}$ 以保精度，外层迭代数会按 $1/\log\mu$ 增加数倍。

**消失测试**：没有这条纠正，barrier method 就只能用于小 $t$，而 duality gap 是 $m/t$，于是精度被卡在 $10^{-4}$ 量级——这正是 1970 年代的实际处境。

**落点**：Boyd §11.3.3（conditioning 的讨论，第 585 页）；[FGW02, §4.3.2] 与 [NW99, p.525]；本块的 §11.5.2（(11.26) 表明步数与 $t$ 无关，与"条件数增长但方向仍可用"一致）。</span>



其他作者则以 cone programming 框架作为把线性规划的 primal-dual 内点法推广到凸优化的出发点（例如见 Nesterov 与 Todd [NT98]）。这条路线产出了用于 semidefinite 与 second-order programming 的高效、高精度 primal-dual 方法（见 Todd [Tod01] 与 Alizadeh、Goldfarb [AG03] 的综述）。

与线性规划一样，半定规划的 primal-dual 方法通常被描述为把 Newton 法施加到修正 KKT 方程上的各种变体。但与线性规划不同，这里线性化可以有许多种做法，从而导出不同的 search direction 与不同的算法；见 Helmberg、Rendl、Vanderbei 与 Wolkowicz [HRVW96]，Kojima、Shindo 与 Harah [KSH97]，Monteiro [Mon97]，Nesterov 与 Todd [NT98]，Zhang [Zha98]，Alizadeh、Haeberly 与 Overton [AHO98]，以及 Todd、Toh 与 Tütüncü [TTT98]。

在初始化与不可行性检测（infeasibility detection）方面也取得了很大进展。homogeneous self-dual formulation（齐次自对偶表述）为 §11.4 的经典两阶段做法提供了一个优雅而高效的替代方案；细节见 Ye、Todd 与 Mizuno [YTM94]，Xu、Hung 与 Ye [XHY96]，Andersen 与 Ye [AY98]，以及 Luo、Sturm 与 Zhang [LSZ00]。

用于 semidefinite 与 second-order cone programming 的 primal-dual 内点法已经在许多软件包中实现，包括 SeDuMi [Stu99]、SDPT3 [TTT02]、SDPA [FKN98]、CSDP [Bor02] 与 DSDP [BY02]；其中若干代码的友好接口由 YALMIP [Löf04] 提供。

下面这些著作更详细地记录了这一快速发展的领域中的近期进展：Vanderbei [Van96]，Wright [Wri97]，Roos、Terlaky 与 Vial [RTV97]，Ye [Ye97]，Wolkowicz、Saigal 与 Vandenberghe [WSV00]，Ben-Tal 与 Nemirovski [BTN01]，Renegar [Ren01]，以及 Peng、Roos 与 Terlaky [PRT02]。

<span style="color:#1e8449;">**[译注]** 最后两段给出了**实现层面的现状坐标**，这在读一本 2004 年的教材时特别有用：教材正文只讲 Algorithm 11.2 的原型，而实际求解器（SeDuMi / SDPT3 / CSDP）用的都是 Mehrotra 型 predictor-corrector（对应 exercise 11.8 的推广）加 homogeneous self-dual embedding。

**量的方向感**：原型 Algorithm 11.2 在 LP 上的迭代数是 15–35（p615 实测）；Mehrotra 型实现在同一类问题上典型是 5–15 次迭代，差别全部来自 `centering parameter` 的自适应选取（本节固定 $\mu = 10$，而 Mehrotra 每步重估）。这就是正文那句"更精细的算法与 Algorithm 11.2 的差别在于 $t$ 的选取策略"的定量含义。

**消失测试**：若不知道 homogeneous self-dual embedding 这条路，遇到**不可行**问题（例如 $Ax \preceq b$ 与 $x \succeq 0$ 无交）时，只能靠 §11.4 的 phase I 先判可行性；而 self-dual 表述把"可行性判定 + 求解"合成一次内点迭代，返回 certificate（$y$ 使 $A^Ty \succeq 0$、$b^Ty \lt 0$ 之类）。

**失败模式**：用固定 $\mu = 10$ 的实现去跑高精度需求（$\epsilon = 10^{-12}$），迭代数按 $\log(1/\epsilon)/\log\mu$ 增长，会看到末段"每步只把 gap 压 10 倍"，而 Mehrotra 型的末段是 superlinear，二者在 $10^{-12}$ 处差 5–10 次迭代。

**落点**：Boyd §11.7（Algorithm 11.2 与 $\mu$ 的取法）；exercise 11.8（predictor-corrector）；本页列的 SeDuMi [Stu99] 与 SDPT3 [TTT02] 是实现对照。</span>

### <span style="color:#943126;">**[exercise]**</span> The barrier method（barrier method 部分）

<span style="color:#943126;">**[exercise]**</span> **11.1** *Barrier method example.* Consider the simple problem

```math
\begin{array}{ll}
\text{minimize} & x^2 + 1\\
\text{subject to} & 2 \le x \le 4,
\end{array}
```

which has feasible set $[2,4]$, and optimal point $x^\star = 2$. Plot $f_0$, and $tf_0 + \varphi$, for several values of $t \gt 0$, versus $x$. Label $x^\star(t)$.

> 话题摘要：一维区间问题上看 barrier 族 $tf_0+\varphi$ 随 $t$ 增大如何逼近原目标，并标出 central point $x^\star(t)$ 的移动。

<span style="color:#943126;">**[exercise]**</span> **11.2** What happens if the barrier method is applied to the LP

```math
\begin{array}{ll}
\text{minimize} & x_2\\
\text{subject to} & x_1 \le x_2,\\
& 0 \le x_2,
\end{array}
```

with variable $x \in \mathbf{R}^2$?

> 话题摘要：可行但无严格内部、且目标沿某方向无下界的退化 LP 上，logarithmic barrier 的 centering problem 会失去最优解。

<span style="color:#943126;">**[exercise]**</span> **11.3** *Boundedness of centering problem.* Suppose the sublevel sets of (11.1),

```math
\begin{array}{ll}
\text{minimize} & f_0(x)\\
\text{subject to} & f_i(x) \le 0, \quad i = 1,\ldots,m\\
& Ax = b,
\end{array}
```

are bounded. Show that the sublevel sets of the associated centering problem,

```math
\begin{array}{ll}
\text{minimize} & tf_0(x) + \varphi(x)\\
\text{subject to} & Ax = b,
\end{array}
```

are bounded.

> 话题摘要：证明原问题 sublevel set 有界 ⇒ centering problem 的 sublevel set 有界，即 barrier 不会引入新的无界方向。

<span style="color:#943126;">**[exercise]**</span> **11.4** *Adding a norm bound to ensure strong convexity of the centering problem.* Suppose we add the constraint $x^Tx \le R^2$ to the problem (11.1):

```math
\begin{array}{ll}
\text{minimize} & f_0(x)\\
\text{subject to} & f_i(x) \le 0, \quad i = 1,\ldots,m\\
& Ax = b\\
& x^Tx \le R^2.
\end{array}
```

Let $\tilde\varphi$ denote the logarithmic barrier function for this modified problem. Find $a \gt 0$ for which $\nabla^2(tf_0(x) + \tilde\varphi(x)) \succeq aI$, for all feasible $x$.

> 话题摘要：加一条 $\ell_2$ 球约束后，barrier 的 Hessian 具有一致下界 $aI$，从而 centering problem 强凸——这给出了 $x^\star(t)$ 唯一性与 Newton 收敛的一个充分条件。

<span style="color:#943126;">**[exercise]**</span> **11.5** *Barrier method for second-order cone programming.* Consider the SOCP (without equality constraints, for simplicity)

```math
\begin{array}{ll}
\text{minimize} & f^T x\\
\text{subject to} & \|A_ix + b_i\|_2 \le c_i^T x + d_i, \quad i = 1,\ldots,m.
\end{array}
\qquad (11.63)
```

The constraint functions in this problem are not differentiable (since the Euclidean norm $\|u\|_2$ is not differentiable at $u = 0$) so the (standard) barrier method cannot be applied. In §11.6, we saw that this SOCP can be solved by an extension of the barrier method that handles generalized inequalities. (See example 11.8, page 599, and page 601.) In this exercise, we show how the standard barrier method (with scalar constraint functions) can be used to solve the SOCP.

We first reformulate the SOCP as

```math
\begin{array}{ll}
\text{minimize} & f^T x\\
\text{subject to} & \|A_ix + b_i\|_2^2/(c_i^T x + d_i) \le c_i^T x + d_i, \quad i = 1,\ldots,m\\
& c_i^T x + d_i \ge 0, \quad i = 1,\ldots,m.
\end{array}
\qquad (11.64)
```

> 话题摘要：把二阶锥约束改写成 quadratic-over-linear 的标量不等式，使标准 barrier method（只需标量函数可微）也能解 SOCP，代价是两者的可行域不完全等价。



The constraint function

```math
f_i(x) = \frac{\|A_ix + b_i\|_2^2}{c_i^T x + d_i} - c_i^T x - d_i
```

is the composition of a quadratic-over-linear function with an affine function, and is twice differentiable (and convex), provided we define its domain as $\operatorname{dom}f_i = \{x \mid c_i^Tx + d_i \gt 0\}$. Note that the two problems (11.63) and (11.64) are not exactly equivalent. If $c_i^Tx^\star + d_i = 0$ for some $i$, where $x^\star$ is the optimal solution of the SOCP (11.63), then the reformulated problem (11.64) is not solvable; $x^\star$ is not in its domain. Nevertheless we will see that the barrier method, applied to (11.64), produces arbitrarily accurate suboptimal solutions of (11.64), and hence also for (11.63).

**(a)** Form the log barrier $\varphi$ for the problem (11.64). Compare it to the log barrier that arises when the SOCP (11.63) is solved using the barrier method for generalized inequalities (in §11.6).

**(b)** Show that if $tf^Tx + \varphi(x)$ is minimized, the minimizer $x^\star(t)$ is $2m/t$-suboptimal for the problem (11.63). It follows that the standard barrier method, applied to the reformulated problem (11.64), solves the SOCP (11.63), in the sense of producing arbitrarily accurate suboptimal solutions. This is the case even though the optimal point $x^\star$ need not be in the domain of the reformulated problem (11.64).

> 话题摘要：(a) 比较重述前后的 log barrier 形状；(b) 证 $x^\star(t)$ 是 $2m/t$-suboptimal，即在域不等价的情形下仍能逼到任意精度。

<span style="color:#943126;">**[exercise]**</span> **11.6** *General barriers.* The log barrier is based on the approximation $-(1/t)\log(-u)$ of the indicator function $\tilde I_-(u)$ (see §11.2.1, page 563). We can also construct barriers from other approximations, which in turn yield generalizations of the central path and barrier method. Let $h : \mathbf{R} \to \mathbf{R}$ be a twice differentiable, closed, increasing convex function, with $\operatorname{dom}h = -\mathbf{R}_{++}$. (This implies $h(u) \to \infty$ as $u \to 0$.) One such function is $h(u) = -\log(-u)$; another example is $h(u) = -1/u$ (for $u \lt 0$).

Now consider the optimization problem (without equality constraints, for simplicity)

```math
\begin{array}{ll}
\text{minimize} & f_0(x)\\
\text{subject to} & f_i(x) \le 0, \quad i = 1,\ldots,m,
\end{array}
```

where $f_i$ are twice differentiable. We define the $h$-barrier for this problem as

```math
\varphi_h(x) = \sum_{i=1}^{m}h(f_i(x)),
```

with domain $\{x \mid f_i(x) \lt 0,\ i = 1,\ldots,m\}$. When $h(u) = -\log(-u)$, this is the usual logarithmic barrier; when $h(u) = -1/u$, $\varphi_h$ is called the inverse barrier. We define the $h$-central path as

```math
x^\star(t) = \operatorname{argmin}\ tf_0(x) + \varphi_h(x),
```

where $t \gt 0$ is a parameter. (We assume that for each $t$, the minimizer exists and is unique.)

**(a)** Explain why $tf_0(x) + \varphi_h(x)$ is convex in $x$, for each $t \gt 0$.

**(b)** Show how to construct a dual feasible $\lambda$ from $x^\star(t)$. Find the associated duality gap.

**(c)** For what functions $h$ does the duality gap found in part (b) depend only on $t$ and $m$ (and no other problem data)?

> 话题摘要：把 $-\log(-u)$ 换成一般凸增函数 $h$，看 central path 与 duality gap $m/t$ 这一整条链中哪一步依赖 log 的特殊形式（答案落在这题 (c)：只有"gap 只依赖 $t,m$"这一性质挑出 log 族）。

<span style="color:#943126;">**[exercise]**</span> **11.7** *Tangent to central path.* This problem concerns $dx^\star(t)/dt$, which gives the tangent to the central path at the point $x^\star(t)$. For simplicity, we consider a problem without equality constraints; the results readily generalize to problems with equality constraints.

**(a)** Find an explicit expression for $dx^\star(t)/dt$. *Hint.* Differentiate the centrality equations (11.7) with respect to $t$.

> 话题摘要：对 centrality 方程关于 $t$ 求导，解出 central path 的切向量——这是 exercise 11.8 一阶 predictor 的基础。

> 话题摘要：(b) 证明 $f_0(x^\star(t))$ 关于 $t$ 单调下降，即"提高 $t$ 一定改进当前目标值"，与 gap $m/t$ 单调下降是两件事。

<span style="color:#943126;">**[exercise]**</span> **11.8** *Predictor-corrector method for centering problems.* In the standard barrier method, $x^\star(\mu t)$ is computed using Newton's method, starting from the initial point $x^\star(t)$. One alternative that has been proposed is to make an approximation or prediction $\hat x$ of $x^\star(\mu t)$, and then start the Newton method for computing $x^\star(\mu t)$ from $\hat x$. The idea is that this should reduce the number of Newton steps, since $\hat x$ is (presumably) a better initial point than $x^\star(t)$. This method of centering is called a predictor-corrector method, since it first makes a prediction of what $x^\star(\mu t)$ is, then corrects the prediction using Newton's method.

The most widely used predictor is the first-order predictor, based on the tangent to the central path, explored in exercise 11.7. This predictor is given by

```math
\hat x = x^\star(t) + \frac{dx^\star(t)}{dt}(\mu t - t).
```

Derive an expression for the first-order predictor $\hat x$. Compare it to the Newton update obtained, i.e., $x^\star(t) + \Delta x_{\text{nt}}$, where $\Delta x_{\text{nt}}$ is the Newton step for $\mu tf_0(x) + \varphi(x)$, at $x^\star(t)$. What can you say when the objective $f_0$ is linear? (For simplicity, you can consider a problem without equality constraints.)

> 话题摘要：用 central path 的一阶切向做 predictor，再与"直接用 Newton 一步"作对比；$f_0$ 线性时两者关系退化出额外结构。

<span style="color:#943126;">**[exercise]**</span> **11.9** *Dual feasible points near the central path.* Consider the problem

```math
\begin{array}{ll}
\text{minimize} & f_0(x)\\
\text{subject to} & f_i(x) \le 0, \quad i = 1,\ldots,m,
\end{array}
```

with variable $x \in \mathbf{R}^n$. We assume the functions $f_i$ are convex and twice differentiable. (We assume for simplicity there are no equality constraints.) Recall (from §11.2.2, page 565) that $\lambda_i = -1/(tf_i(x^\star(t)))$, $i = 1,\ldots,m$, is dual feasible, and in fact, $x^\star(t)$ minimizes $L(x,\lambda)$. This allows us to evaluate the dual function for $\lambda$, which turns out to be $g(\lambda) = f_0(x^\star(t)) - m/t$. In particular, we conclude that $x^\star(t)$ is $m/t$-suboptimal.

In this problem we consider what happens when a point $x$ is close to $x^\star(t)$, but not quite centered. (This would occur if the centering steps were terminated early, or not carried out to full accuracy.) In this case, of course, we cannot claim that $\lambda_i = -1/(tf_i(x))$, $i = 1,\ldots,m$, is dual feasible, or that $x$ is $m/t$-suboptimal. However, it turns out that a slightly more complicated formula does yield a dual feasible point, provided $x$ is close enough to centered.

Let $\Delta x_{\text{nt}}$ be the Newton step at $x$ of the centering problem

```math
\text{minimize} \quad tf_0(x) - \sum_{i=1}^{m}\log(-f_i(x)).
```

A formula that often gives a dual feasible point when $\Delta x_{\text{nt}}$ is small (i.e., for $x$ nearly centered) is

```math
\lambda_i = \frac{1}{-tf_i(x)}\left(1 + \frac{\nabla f_i(x)^T\Delta x_{\text{nt}}}{-f_i(x)}\right), \quad i = 1,\ldots,m.
```

In this case, the vector $x$ does not minimize $L(x,\lambda)$, so there is no general formula for the dual function value $g(\lambda)$ associated with $\lambda$. (If we have an analytical expression for the dual objective, however, we can simply evaluate $g(\lambda)$.)

Verify that for a QCQP

```math
\begin{array}{ll}
\text{minimize} & (1/2)x^TP_0x + q_0^Tx + r_0\\
\text{subject to} & (1/2)x^TP_ix + q_i^Tx + r_i \le 0, \quad i = 1,\ldots,m,
\end{array}
```

the formula for $\lambda$ yields a dual feasible point (i.e., $\lambda \succeq 0$ and $L(x,\lambda)$ is bounded below) when $\Delta x_{\text{nt}}$ is sufficiently small.

> 话题摘要：当中心化没做满（$\Delta x_{\text{nt}}$ 不小但也不大）时，用带一阶修正的 $\lambda$ 公式仍能造出 dual feasible point，从而在 QCQP 上把"提前终止 centering"的代价界定住。



*Hint.* Define

```math
x_0 = x + \Delta x_{\text{nt}}, \qquad x_i = x - \frac{1}{t\lambda_if_i(x)}\Delta x_{\text{nt}}, \quad i = 1,\ldots,m.
```

Show that

```math
\nabla f_0(x_0) + \sum_{i=1}^{m}\lambda_i\nabla f_i(x_i) = 0.
```

Now use $f_i(z) \ge f_i(x_i) + \nabla f_i(x_i)^T(z - x_i)$, $i = 0,\ldots,m$, to derive a lower bound on $L(z,\lambda)$.

> 话题摘要：提示给出构造——把 $\nabla f_i$ 分别在不同点 $x_i$ 处取值，用一阶下估计得到 $L(z,\lambda)$ 的下界，$L$ 有下界即 dual feasible。

<span style="color:#943126;">**[exercise]**</span> **11.10** *Another parametrization of the central path.* We consider the problem (11.1), with central path $x^\star(t)$ for $t \gt 0$, defined as the solution of

```math
\begin{array}{ll}
\text{minimize} & tf_0(x) - \sum_{i=1}^{m}\log(-f_i(x))\\
\text{subject to} & Ax = b.
\end{array}
```

```math
\begin{array}{ll}

\text{subject to} & Ax = b.
\end{array}
```

> 话题摘要：把 central path 用"目标值上界 $u$"重新参数化，证明所得曲线与原参数化 $t$ 的曲线是同一条——两种参数化一一对应。

<span style="color:#943126;">**[exercise]**</span> **11.11** *Method of analytic centers.* In this problem we consider a variation on the barrier method, based on the parametrization of the central path described in exercise 11.10. For simplicity, we consider a problem with no equality constraints,

```math
\begin{array}{ll}
\text{minimize} & f_0(x)\\
\text{subject to} & f_i(x) \le 0, \quad i = 1,\ldots,m.
\end{array}
```

The method of analytic centers starts with any strictly feasible initial point $x^{(0)}$, and any $u^{(0)} \gt f_0(x^{(0)})$. We then set

```math
u^{(1)} = \theta u^{(0)} + (1 - \theta)f_0(x^{(0)}),
```

where $\theta \in (0,1)$ is an algorithm parameter (usually chosen small), and then compute the next iterate as $x^{(1)} = z^\star(u^{(1)})$ (using Newton's method, starting from $x^{(0)}$). Here $z^\star(s)$ denotes the minimizer of

```math
-\log(s - f_0(x)) - \sum_{i=1}^{m}\log(-f_i(x)),
```

which we assume exists and is unique. This process is then repeated.

The point $z^\star(s)$ is the analytic center of the inequalities

```math
f_0(x) \le s, \qquad f_1(x) \le 0,\ \ldots,\ f_m(x) \le 0,
```

hence the algorithm name.

Show that the method of centers works, i.e., $x^{(k)}$ converges to an optimal point. Find a stopping criterion that guarantees that $x$ is $\epsilon$-suboptimal, where $\epsilon \gt 0$. *Hint.* The points $x^{(k)}$ are on the central path; see exercise 11.10. Use this to show that

```math
u^+ - p^\star \le \frac{m + \theta}{m + 1}(u - p^\star),
```

where $u$ and $u^+$ are the values of $u$ on consecutive iterations.

> 话题摘要：analytic center 法用 $u \mapsto \theta u + (1-\theta)f_0(x)$ 把目标上界按固定比值 $(m+\theta)/(m+1)$ 压缩，据此给出 $u - p^\star$ 的几何收敛与 $\epsilon$-suboptimal 的停机判据。

<span style="color:#943126;">**[exercise]**</span> **11.12** *Barrier method for convex-concave games.* We consider a convex-concave game with inequality constraints,

```math
\begin{array}{ll}
\text{minimize}_w \; \text{maximize}_z & f_0(w,z)\\
\text{subject to} & f_i(w) \le 0, \quad i = 1,\ldots,m\\
& \tilde{f}_i(z) \le 0, \quad i = 1,\ldots,\tilde{m}.
\end{array}
```

Here $w \in \mathbf{R}^n$ is the variable associated with minimizing the objective, and $z \in \mathbf{R}^{\tilde n}$ is the variable associated with maximizing the objective. The constraint functions $f_i$ and $\tilde f_i$ are convex and differentiable, and the objective function $f_0$ is differentiable and convex-concave, i.e., convex in $w$, for each $z$, and concave in $z$, for each $w$. We assume for simplicity that $\operatorname{dom} f_0 = \mathbf{R}^n \times \mathbf{R}^{\tilde n}$.

A **solution** or **saddle-point** for the game is a pair $w^\star, z^\star$, for which

```math
f_0(w^\star, z) \le f_0(w^\star, z^\star) \le f_0(w, z^\star)
```

holds for every feasible $w$ and $z$. (For background on convex-concave games and functions, see §5.4.3, §10.3.4 and exercises 3.14, 5.24, 5.25, 10.10, and 10.13.) In this exercise we show how to solve this game using an extension of the barrier method, and the infeasible start Newton method (see §10.3).

**(a)** Let $t \gt 0$. Explain why the function

```math
t f_0(w,z) - \sum_{i=1}^{m}\log(-f_i(w)) + \sum_{i=1}^{\tilde m}\log(-\tilde f_i(z))
```

is convex-concave in $(w,z)$. We will assume that it has a unique saddle-point, $(w^\star(t), z^\star(t))$, which can be found using the infeasible start Newton method.

**(b)** As in the barrier method for solving a convex optimization problem, we can derive a simple bound on the suboptimality of $(w^\star(t), z^\star(t))$, which depends only on the problem dimensions, and decreases to zero as $t$ increases. Let $W$ and $Z$ denote the feasible sets for $w$ and $z$,

```math
W = \{w \mid f_i(w) \le 0,\ i = 1,\ldots,m\}, \qquad Z = \{z \mid \tilde f_i(z) \le 0,\ i = 1,\ldots,\tilde m\}.
```

Show that

```math
f_0(w^\star(t), z^\star(t)) \le \inf_{w \in W} f_0(w, z^\star(t)) + \frac{m}{t}, \qquad f_0(w^\star(t), z^\star(t)) \ge \sup_{z \in Z} f_0(w^\star(t), z) - \frac{\tilde m}{t},
```

and therefore

```math
\sup_{z \in Z} f_0(w^\star(t), z) - \inf_{w \in W} f_0(w, z^\star(t)) \le \frac{m + \tilde m}{t}.
```

> 话题摘要：把 barrier method 从「单目标」推广到 convex-concave game，并用同一条 $(m+\tilde m)/t$ 界说明 saddle-point 的两侧残差同时被压到零——两侧界恰好可以**相减**，这是单目标情形没有的结构。

<span style="color:#1e8449;">**[译注]** 这一小题的全部内容在**最后那一行相减**上，而相减之所以合法，靠的是两侧界的不等号方向相反：(11.12-a) 给出 $f_0(w^\star(t),z^\star(t))$ 的一个**上**界（用 $\inf_w$），(11.12-b) 给出同一个数的**下**界（用 $\sup_z$）。夹住同一个标量之后，把两式相减就消掉了 $f_0(w^\star(t),z^\star(t))$ 本身，只剩两个**可在 $t$ 固定时独立计算**的量之差。这个差就是 game 的 optimality gap 的代理量（surrogate），量级 $O((m+\tilde m)/t)$，与问题维数无关、只与约束条数成正比。

**消失测试**：抽掉「$f_0$ 对 $w$ 凸、对 $z$ 凹」这一条，barrier 后的函数就不再是 convex-concave，Sion 型极小极大交换失效，$w^\star(t),z^\star(t)$ 作为 saddle-point 不再唯一存在，于是两个界都无从写起；退化成对 $w$ 与 $z$ 各自做坐标下降（alternating minimization），收敛性没有任何保证，只能靠固定 $t$ 反复跑初值扫描。

<span style="color:#943126;">**[exercise]**</span> **11.13** *Self-concordance and negative entropy.* **(a)** Show that the negative entropy function $x\log x$ (on $\mathbf{R}_{++}$) is not self-concordant. **(b)** Show that for any $t \gt 0$, $t x \log x - \log x$ is self-concordant (on $\mathbf{R}_{++}$).

<span style="color:#943126;">**[exercise]**</span> **11.14** *Self-concordance and the centering problem.* Let $\varphi$ be the logarithmic barrier function of problem (11.1). Suppose that the sublevel sets of (11.1) are bounded, and that $t f_0 + \varphi$ is closed and self-concordant. Show that

```math
t\nabla^2 f_0(x) + \nabla^2\varphi(x) \succ 0, \qquad \text{for all } x \in \operatorname{dom}\varphi.
```

*Hint.* See exercises 9.17 and 11.3.

> 话题摘要：由「$tf_0+\varphi$ closed 且 self-concordant」推出 centering problem 的 Hessian 处处严格正定，即 centering problem 是**严格凸**的——这是 §11.6.4 里 Newton 步有定义、且 $x^\star(t)$ 唯一的前提。

<span style="color:#1e8449;">**[译注]** 11.13 与 11.14 是成对的，它们共同撑起第 11 章复杂度理论里最脆弱的一块：**self-concordance 不是自动成立的**。负熵 $x\log x$ 在 $\mathbf{R}_{++}$ 上二阶导为 $1/x$，三阶导为 $-1/x^2$，self-concordance 要求

```math
|f'''(x)| \le 2\, (f''(x))^{3/2},
```

代入得 $\dfrac{1}{x^2} \le \dfrac{2}{x^{3/2}}$，即 $x^{1/2} \le 2$，只在 $x \le 4$ 时成立——所以负熵**不是** self-concordant。但 $t x\log x - \log x$ 的二阶导是 $\frac{t}{x} + \frac{1}{x^2} = \frac{tx+1}{x^2}$，三阶导是 $-\frac{t}{x^2} - \frac{2}{x^3}$，两者代入后不等式对**所有** $x \gt 0$ 与所有 $t \gt 0$ 成立，这一条正是 barrier 项 $-\log x$「兜住」了熵项在 $x \to 0$ 处的坏行为。

**量的方向感**：11.14 的结论 $t\nabla^2f_0(x) + \nabla^2\varphi(x) \succ 0$ 是两个矩阵相**加**后正定，而 $t\nabla^2f_0$ 单独在 $f_0$ 平坦处可以奇异（$f_0$ 为线性时它恒为零矩阵）。所以 barrier 项在这里承担的不是「修正」而是「保证非奇异」：$\nabla^2\varphi(x) \succ 0$ 处处成立，量级 $\Theta(1/s_i^2(x))$（$s_i$ 是到第 $i$ 个约束边界的距离），越靠近边界越强、在内部反而弱。这同时解释了中心路径上 $t$ 增大时 Hessian 条件数为何恶化：$t\nabla^2f_0$ 主导之后，$\nabla^2\varphi$ 的相对贡献按 $1/t$ 衰减。可观测后果是 Newton 系统的 Cholesky 因子在 $t \gtrsim 10^{7}$ 附近开始丢有效位。

**消失测试**：抽掉 $- \log x$ 项的兜底作用，$\max$ entropy 问题（$\sum x_i\log x_i$，约束 $Ax = b, x \succ 0$）就失去 self-concordance，§11.6.4 的 $(11.48)$ 界与「每个 centering step 不超过 $\theta(\mu-1-\log\mu)/\gamma + c$ 步 Newton」的结论全部作废，只能退回到 empirical 的「调参看残差曲线」。

**落点**：Boyd §11.6.4（self-concordance 的复杂度界）、exercise 9.17（closed function 与 sublevel set）、exercise 11.3（sublevel set 有界性）；§11.2.1 的 $-\log(-u)$ 与 indicator 的关系是同一类「barrier 兜底」论证。</span>

<span style="color:#943126;">**[exercise]**</span> **11.19** *Yet another method for computing the Newton step.* Show that the Newton step for the barrier method, which is given by the solution of the linear equations (11.14), can be found by solving a larger set of linear equations with coefficient matrix

```math
\begin{bmatrix}

Df(x) & -\operatorname{diag}(f(x))^{2} & 0\\
A & 0 & 0
\end{bmatrix}
```

where $f(x) = (f_1(x),\ldots,f_m(x))$. For what types of problem structure might solving this larger system be interesting?

> 话题摘要：把 barrier method 的 Newton 系统（原本要显式形成并求解 $J^T D J$ 型正定系统）改写成**不定号的 KKT 大系统**，代价是规模变大、收益是保留稀疏性；问的是「什么样的结构下这个交换划算」。

<span style="color:#1e8449;">**[译注]** 这道题的要点不在那个 $3\times 3$ 分块矩阵长什么样，而在**为什么有人愿意解一个更大、更不定号的系统**。原系统（(11.14)）的系数矩阵是

```math
H = t\nabla^2 f_0(x) + \sum_{i=1}^{m}\frac{1}{-f_i(x)}\nabla^2 f_i(x)
```

的**限制在 $\{d \mid Ad = 0\}$ 上**的形式，实际求解要先形成 $A H^{-1}A^T$ 或做 Cholesky 分解再消元；而 $H$ 里的 $\nabla^2 f_i$ 往往**稠密**，一旦稠密，$H$ 的 Cholesky 就是 $O(n^3)$ 且极难并行。上式的 $\begin{bmatrix} H & Df^T & A^T\\ Df & -\operatorname{diag}(f)^2 & 0\\ A & 0 & 0\end{bmatrix}$ 把 $f$ 的 Jacobian 与 $A$ 都留成**原始稀疏块**，任何稀疏 LU / 迭代求解器都能直接用。

**消失测试**：没有这个改写，§11.8 里所有「按 $A^TA$ 稀疏还是 $AA^T$ 稀疏分两种情形讨论 flop」的分析全部失去对象——因为那些讨论的对象是**稀疏结构**，而稠密的 $H$ 一旦形成，结构信息已经丢了；退化后果是：网络流、结构力学这类 $A$ 极度稀疏但 $n$ 上万的实例只能按稠密路径跑，实际复杂度从「与 nnz 成正比」退回 $O(n^3)$。

<span style="color:#943126;">**[exercise]**</span> **11.21** *Log-Chebyshev approximation with bounds.* We consider an approximation problem: find $x \in \mathbf{R}^n$, that satisfies the variable bounds $l \preceq x \preceq u$, and yields $Ax \approx b$, where $b \in \mathbf{R}^m$. You can assume that $l \prec u$, and $b \succ 0$ (for reasons we explain below). We let $a_i^T$ denote the $i$th row of the matrix $A$.

We judge the approximation $Ax \approx b$ by the maximum **fractional deviation**, which is

```math
\max_{i=1,\ldots,m}\max\left\{(a_i^Tx)/b_i,\ b_i/(a_i^Tx)\right\} = \max_{i=1,\ldots,m}\frac{\max\{a_i^Tx,\,b_i\}}{\min\{a_i^Tx,\,b_i\}},
```

when $Ax \succ 0$; we define the maximum fractional deviation as $\infty$ if $Ax \not\succ 0$. The problem of minimizing the maximum fractional deviation is called the **fractional Chebyshev approximation problem**, or the **logarithmic Chebyshev approximation problem**, since it is equivalent to minimizing the objective

```math
\max_{i=1,\ldots,m}\left|\log a_i^Tx - \log b_i\right|.
```

(See also exercise 6.3, part (c).)

**(a)** Formulate the fractional Chebyshev approximation problem (with variable bounds) as a convex optimization problem with twice differentiable objective and constraint functions.

**(b)** Implement a barrier method that solves the fractional Chebyshev approximation problem. You can assume an initial point $x^{(0)}$, satisfying $l \prec x^{(0)} \prec u$, $Ax^{(0)} \succ 0$, is known.

> 话题摘要：以「最大相对偏差」取代 $\ell_\infty$ 残差做 Chebyshev 逼近，并用变量上下界把它化成可二阶可微的凸问题，再用 barrier method 求解。

<span style="color:#1e8449;">**[译注]** 这一步的关键是**为什么取对数之后才叫 Chebyshev**。$\ell_\infty$ 逼近最小化 $\max_i |a_i^Tx - b_i|$，衡量的是**绝对**误差；而这里 $\max_i\max\{r_i, 1/r_i\}$（$r_i = a_i^Tx/b_i$）衡量的是**相对**误差，两者在任何尺度变换下行为完全不同：把 $b$ 整体乘 $10^6$，$\ell_\infty$ 残差跟着乘 $10^6$，相对偏差不变。取 $\log$ 之后

```math
\max_i\left|\log a_i^Tx - \log b_i\right| = \log\left(\max_i \max\{r_i, 1/r_i\}\right),
```

即「最小化最大相对偏差」与「最小化 $\log$ 域上的 $\ell_\infty$ 残差」**逐字等价**，而后者是凸问题（$-\log(a_i^Tx)$ 凸，$\log$ 单调）。

**消失测试**：不取对数，「最小化最大相对偏差」的目标是 $\max_i \frac{\max\{a_i^Tx,b_i\}}{\min\{a_i^Tx,b_i\}}$，它是**分段分式**的极大值，既不凸也不可微（在 $a_i^Tx = b_i$ 处左右导数不同）；于是 §11.5 的 barrier method 连同 Newton 步全部不适用，只能退化成在 $(t, x)$ 上做 log-scale 的网格搜索——维数一过 3 就不现实。

**量的方向感**：相对误差判据还有一个必须记住的非对称性：$\max\{r_i, 1/r_i\}$ 在 $r_i = 1$ 处取最小值 $1$，而 $r_i = 10$ 与 $r_i = 0.1$ 给出**同一个**惩罚 $10$。也就是说这个判据对「高估 $b$ 一个数量级」与「低估一个数量级」完全等价，差别只在 log 域里变号（$\pm \log 10$）。这条性质在实现里很实用：fitting 的结果必然把 $|\log r_i|$ 摊平到同一条带上，所以残差图上看到的是等宽的带而不是单调衰减的曲线，若你的代码画出衰减曲线，说明归一化写错了（多半漏除了 $b_i$）。

**落点**：Boyd §7.6（geometric programming 与 posynomial，正是「取 $\log$ 后变凸」的同一手法）、exercise 6.3(c)、§11.5（barrier method）、§11.5.3（$\ell_1$ 型逼近的 QP 形式，同一类「换一个损失函数」的手法）；线代侧挂 Strang 的 weighted least squares——把 $\log$ 域的问题在 $a_i^Tx \approx b_i$ 附近线性化后正是它。</span>

## A.1 · Norms（范数）

### A.1.1 · Inner product, Euclidean norm, and angle（内积、Euclidean norm 与夹角）

```math
\langle x, y\rangle = x^T y = \sum_{i=1}^{n} x_i y_i,
```

对 $\mathbf{R}^n$（实 $n$-向量之集合）上标准的 inner product（内积），上式给出定义，其中 $x,y \in \mathbf{R}^n$。本书一律写 $x^Ty$，而不用 $\langle x,y\rangle$ 这套括号记号。

```math
\|x\|_2 = (x^Tx)^{1/2} = (x_1^2 + \cdots + x_n^2)^{1/2}.
\qquad (A.1)
```

向量 $x$ 的 Euclidean norm（欧几里得范数），也称 $\ell_2$-norm，按 (A.1) 定义：等于 $x^Tx$ 的平方根。

Cauchy-Schwartz 不等式（Cauchy–Schwarz inequality 的原文拼写，见文末「原文自身问题」第 ① 条 `†`）断言：对任意 $x,y \in \mathbf{R}^n$，都有 $|x^Ty| \le \|x\|_2\|y\|_2$。

```math
\angle(x,y) = \cos^{-1}\left(\frac{x^Ty}{\|x\|_2\|y\|_2}\right),
```

非零向量 $x,y$ 之间的（无向）夹角按上式定义，其中反余弦取主值 $\cos^{-1}(u) \in [0,\pi]$（值域是 $[0,\pi]$，所以夹角永远非负）。当 $x^Ty=0$ 时称 $x$ 与 $y$ orthogonal（正交）。

```math
\langle X, Y\rangle = \operatorname{tr}(X^TY) = \sum_{i=1}^{m}\sum_{j=1}^{n} X_{ij}Y_{ij},
```

对 $\mathbf{R}^{m\times n}$（$m\times n$ 实矩阵之集合）上标准的 inner product，上式给出定义，其中 $\operatorname{tr}$ 表示矩阵的 trace（迹），即对角线元素之和。本书写 $\operatorname{tr}(X^TY)$，不写 $\langle X,Y\rangle$。注意：两个矩阵的内积**就是**把它们的系数按某种次序（例如 row major，行优先）排成 $\mathbf{R}^{mn}$ 中的向量之后的内积——所以矩阵内积没有任何额外结构，只是同一件事换个写法。

<!-- ===== p633 · 续 ===== -->

<span style="color:#1e8449;">**[译注]** 这一页看似只是记号约定，但有两个地方是**后面全部计算的接口**，漏掉会直接读错第 11 章的 Hessian。

**落点**：Boyd §A.4.1（gradient 的行列约定）、p634 的 $\mathbf{S}^n$ 内积、§A.4.3（Hessian 作为 $\mathbf{S}^n$ 上的二次型）。线代侧挂 Strang 的 inner product space 一节，同一件事在有限维的表述。</span>



```math
\|X\|_F = \left(\operatorname{tr}(X^TX)\right)^{1/2} = \left(\sum_{i=1}^{m}\sum_{j=1}^{n} X_{ij}^2\right)^{1/2}.
\qquad (A.2)
```

矩阵 $X$ 的 Frobenius norm（Frobenius 范数）按 (A.2) 定义。它就是 $\operatorname{tr}(X^TX)$ 的平方根，也等于所有元素平方和开根号。

Frobenius norm 等于「把矩阵系数排成向量」之后的 Euclidean norm。注意括号里的提醒：矩阵的 $\ell_2$-norm 是**另一个**范数（即 spectral norm，见 §A.1.5），不要混。

```math
\langle X, Y\rangle = \operatorname{tr}(XY) = \sum_{i=1}^{n}\sum_{j=1}^{n}X_{ij}Y_{ij} = \sum_{i=1}^{n}X_{ii}Y_{ii} + 2\sum_{i \lt j}X_{ij}Y_{ij}.
```

对 $\mathbf{S}^n$（对称矩阵集合）上标准的 inner product，上式给出三种等价写法。第二种与第三种之间的转化正是「对称性把 $(i,j)$ 与 $(j,i)$ 两项合成一项」的结果，因此出现系数 $2$。

### A.1.2 · Norms, distance, and unit ball（范数、距离与单位球）

- **nonnegative（非负）**：$f(x) \ge 0$，对一切 $x \in \mathbf{R}^n$
- **definite（定）**：$f(x) = 0$ 仅当 $x = 0$
- **homogeneous（齐次）**：$f(tx) = |t|f(x)$，对一切 $x \in \mathbf{R}^n$ 与 $t \in \mathbf{R}$
- **triangle inequality（三角不等式）**：$f(x+y) \le f(x) + f(y)$，对一切 $x, y \in \mathbf{R}^n$

定义域为全空间 $\mathbf{R}^n$ 的函数 $f$ 称为 norm（范数），当且仅当上面四条同时成立。四条里最容易被忽略的是齐次性里的绝对值：写成 $f(tx) = t f(x)$ 的话，负标量会让范数变号，「长度」这个语义立刻崩掉，三角不等式也随之失效——按 p636 的 operator norm 语言说，$\|\cdot\|$ 就不再是 $\mathbf{R}^n$ 上「关于原点对称」的 unit ball 所对应的那把尺子。

我们用记号 $f(x) = \|x\|$，这个写法本身就提示了「norm 是 $\mathbf{R}$ 上绝对值（absolute value）的推广」；要指明具体某个范数时写 $\|x\|_{\text{symb}}$，下标是助记符（mnemonic），用来标明指的是哪一个范数。

```math
\operatorname{dist}(x,y) = \|x - y\|.
```

norm 是向量 $x$ 的「长度」度量；两个向量之间的距离（distance）取它们差向量的长度，即上式。

我们把这个量称为「在范数 $\|\cdot\|$ 之下 $x$ 与 $y$ 的距离」。注意「在哪个范数下」不能省，换范数距离就换。

```math
\mathcal{B} = \{x \in \mathbf{R}^n \mid \|x\| \le 1\},
```

- **关于原点对称**：$x \in \mathcal{B}$ 当且仅当 $-x \in \mathcal{B}$
- **凸**（convex）
- **闭、有界、内部非空**（closed, bounded, nonempty interior）

范数不超过 $1$ 的全部向量构成集合 $\mathcal{B}$，称为该范数的 unit ball（单位球）。unit ball 恰好满足上面三条性质——而下面的反推式说明这三条**既必要又充分**。

```math
\|x\| = \left(\sup\{t \ge 0 \mid tx \in C\}\right)^{-1}.
```

反之，任何满足这三条性质的集合 $C$ 都是某个范数的 unit ball，该范数由上式的 Minkowski functional（此处原文未命名，只给公式）给出：取「$tx$ 仍落在 $C$ 内」的最大 $t$，再取倒数。

<!-- ===== p634 · 续 ===== -->

<span style="color:#1e8449;">**[译注]** 这一页最容易被读成「集合论练习」的是最后那个反函数式，但它在第 11 章有**实打实的用处**：barrier method 的 self-concordance 全部建立在「Hessian 定义了一个局部范数」之上。

### A.1.3 · Examples（例子）

```math
\|x\|_1 = |x_1| + \cdots + |x_n|,
```

```math
\|x\|_\infty = \max\{|x_1|,\ldots,|x_n|\}.
```

最简单的范数是 $\mathbf{R}$ 上的绝对值。另一个简单例子是 (A.1) 已给的 $\ell_2$-norm。$\mathbf{R}^n$ 上另外两个常用范数：sum-absolute-value（绝对值和）即 $\ell_1$-norm，以及 Chebyshev norm 即 $\ell_\infty$-norm（取各分量绝对值的最大值）。

```math
\|x\|_p = (|x_1|^p + \cdots + |x_n|^p)^{1/p}.
```

这三个范数属于同一个族，由传统的常数 $p$（$p \ge 1$）参数化，即 $\ell_p$-norm。$p$ 必须 $\ge 1$，否则三角不等式不成立。

```math
\lim_{p \to \infty}\|x\|_p = \max\{|x_1|,\ldots,|x_n|\},
```

$p=1$ 给出 $\ell_1$-norm，$p=2$ 给出 Euclidean norm。而上式说明 $p\to\infty$ 的极限正是 $\ell_\infty$-norm，所以 $\ell_\infty$ 也属于这一族，只不过是以**极限**的方式属于（$p=\infty$ 本身不是一个实数参数）。

```math
\|x\|_P = (x^TPx)^{1/2} = \|P^{1/2}x\|_2.
```

另一族重要范数是 quadratic norm（二次型范数）。对 $P \in \mathbf{S}^n_{++}$（对称正定），$P$-quadratic norm 如上定义；等式右端说明它就是「先做 $P^{1/2}$ 变换再看 $\ell_2$-norm」。$P$ 必须正定，否则 $x^TPx$ 可取负值、开根号无意义。

quadratic norm 的 unit ball 是一个 ellipsoid（椭球）；反之，若某范数的 unit ball 是椭球，则它一定是 quadratic norm。这是一个真正的「当且仅当」。

```math
\|X\|_{\text{sav}} = \sum_{i=1}^{m}\sum_{j=1}^{n}|X_{ij}|,
```

```math
\|X\|_{\text{mav}} = \max\{|X_{ij}| \mid i=1,\ldots,m,\ j=1,\ldots,n\}.
```

$\mathbf{R}^{m\times n}$ 上几个常用范数：Frobenius norm（(A.2) 已给）、sum-absolute-value norm（记 $\|\cdot\|_{\text{sav}}$，全部元素绝对值之和）、maximum-absolute-value norm（记 $\|\cdot\|_{\text{mav}}$，取最大元素绝对值）。这两个正是 $\ell_1$ 与 $\ell_\infty$ 在矩阵上的逐元素版本。

矩阵的另外几个重要范数将在 §A.1.5 遇到（那里讲 operator norm，即由向量范数诱导出的矩阵范数，与这里的逐元素版本不同）。

### A.1.4 · Equivalence of norms（范数的等价性）

```math
\alpha\|x\|_a \le \|x\|_b \le \beta\|x\|_a.
```

设 $\|\cdot\|_a$ 与 $\|\cdot\|_b$ 是 $\mathbf{R}^n$ 上两个范数。分析学的一条基本结论是：存在正常数 $\alpha,\beta$ 使上式对**所有** $x$ 成立。



```math
\|x\|_P \le \|x\| \le \sqrt{n}\,\|x\|_P
```

这表示两个范数 equivalent（等价）：它们定义**同一套**开集、同一套收敛序列，等等（见 §A.2）。由此可以断定：任何有限维向量空间上的任何两个范数都等价；但在无限维向量空间上这一结论不一定成立。用凸分析还能给出更精确的结论：若 $\|\cdot\|$ 是 $\mathbf{R}^n$ 上任意范数，则存在 quadratic norm $\|\cdot\|_P$ 使上式对所有 $x$ 成立，即任何范数都能被某个 quadratic norm **一致逼近**，误差因子不超过 $\sqrt{n}$（见 §8.4.1）。

### A.1.5 · Operator norms（算子范数）

```math
\|X\|_{a,b} = \sup\{\|Xu\|_a \mid \|u\|_b \le 1\}.
```

设 $\|\cdot\|_a$ 是 $\mathbf{R}^m$ 上的范数、$\|\cdot\|_b$ 是 $\mathbf{R}^n$ 上的范数（注意两者在不同的空间上）。由它们诱导出的矩阵 $X \in \mathbf{R}^{m\times n}$ 的 operator norm（算子范数）如上定义：在 input 侧单位球上取 $\|Xu\|_a$ 的上确界。

可以证明这个定义确实给出 $\mathbf{R}^{m\times n}$ 上的一个范数（即满足 p634 的四条性质）。

```math
\|X\|_2 = \sigma_{\max}(X) = \left(\lambda_{\max}(X^TX)\right)^{1/2}.
```

当 $\|\cdot\|_a$ 与 $\|\cdot\|_b$ 都取 Euclidean norm 时，$X$ 的 operator norm 就是它的 maximum singular value（最大奇异值），记作 $\|X\|_2$，也等于 $(X^TX)$ 的最大特征值开根号。

括号里说明记号不会冲突：当 $X \in \mathbf{R}^{m\times 1}$（即 $X$ 退化成单个列向量）时，operator norm $\|X\|_2$ 与 (A.1) 的 Euclidean norm 完全一致。这个范数也称 spectral norm（谱范数）或 $X$ 的 $\ell_2$-norm。

<!-- ===== p636 · 续 ===== -->

```math
\|X\|_\infty = \sup\{\|Xu\|_\infty \mid \|u\|_\infty \le 1\} = \max_{i=1,\ldots,m}\sum_{j=1}^{n}|X_{ij}|.
```

另一个例子：$\mathbf{R}^m$ 与 $\mathbf{R}^n$ 上都取 $\ell_\infty$-norm 时，诱导出的 $\|X\|_\infty$ 是 max-row-sum norm（最大行和范数），如上式。

```math
\|X\|_1 = \max_{j=1,\ldots,n}\sum_{i=1}^{m}|X_{ij}|.
```

两端都取 $\ell_1$-norm 时，诱导出的 $\|X\|_1$ 是 max-column-sum norm（最大列和范数）。注意一个容易记反的对照：$\ell_\infty$ 诱导**行和**，$\ell_1$ 诱导**列和**，两者恰好对偶。

### A.1.6 · Dual norm（对偶范数）

```math
\|z\|_\star = \sup\{z^Tx \mid \|x\| \le 1\}.
```

设 $\|\cdot\|$ 是 $\mathbf{R}^n$ 上的范数。与之相伴的 dual norm（对偶范数）记 $\|\cdot\|_\star$，按上式定义（在 $\|\cdot\|$ 的单位球上取 $z^Tx$ 的上确界）。

```math
\|z\|_\star = \sup\{|z^Tx| \mid \|x\| \le 1\}.
```

可以证明它确实是范数。dual norm 也可以理解成「把 $z^T$ 看成一个 $1\times n$ 矩阵」的 operator norm：input 侧用 $\|\cdot\|$（$\mathbf{R}^n$ 上），output 侧用绝对值（$\mathbf{R}$ 上）。两种写法等价，因为 $z^Tx$ 关于 $x$ 的符号可以自由翻转（单位球关于原点对称），所以上确界会自动取到 $|z^Tx|$。

<!-- ===== p636 · 续 · 译注 ===== -->

<span style="color:#1e8449;">**[译注]** 这一页的三个 operator norm 里，只有 $\|X\|_2$ 真正被第 11 章反复使用（Algorithm 11.2 的 residual 范数 $\|r_t\|_2$），但 $\|\cdot\|_\infty$ 与 $\|\cdot\|_1$ 的**行列对偶**关系值得记，它解释了一个常见实现错误。

准确地说，(A.1.5) 的两条给出的是同一个基本原理的两个侧面：operator norm 的转置关系是

```math
\|X\|_{a,b} = \|X^T\|_{b_\star,\,a_\star},
```

于是「$\ell_\infty$ 诱导行和」与「$\ell_1$ 诱导列和」互为转置版本：$\|X\|_1 = \|X^T\|_\infty$。这解释了一个可观测的现象——**当你在代码里把 $A$ 与 $A^T$ 传反**（例如 §11.8.4 网络问题里 constraint matrix 与它的转置），残余量的范数从「行和」变成「列和」，数值量级差可达 $\max_i\sum_j$ 与 $\max_j\sum_i$ 之比，在度分布极不均匀的图上相差一个数量级以上，而 KKT 系统**照样解得出**、残差**照样很小**，只是优化的是另一个问题。

## A.2 · Analysis（分析）

### A.2.1 · Open and closed sets（开集与闭集）

```math
\{y \mid \|y - x\|_2 \le \epsilon\} \subseteq C,
```

若存在 $\epsilon \gt 0$ 使上式成立（即存在以 $x$ 为心、完全落在 $C$ 内的球），则 $x \in C$ 称为 $C$ 的 interior point（内点）。

$C$ 的全部内点构成 $C$ 的 interior（内部），记 $\operatorname{int}C$。括号里补了一句关键的相容性：因为 $\mathbf{R}^n$ 上一切范数都与 Euclidean norm 等价（§A.1.4），所以换成任何范数都不会改变内点集合——内点的定义看似依赖范数，实际上不依赖。

若 $\operatorname{int} C = C$（即 $C$ 中每一点都是内点），称 $C$ open（开集）。若 $C$ 的补集 $\mathbf{R}^n\setminus C$ 是开集，称 $C$ closed（闭集）。注意这是**补定义**，不是「不是开集就是闭集」——既开又闭（如 $\emptyset$ 与 $\mathbf{R}^n$）与既不开也不闭的集合都存在。

注意上面这三个定义里出现了三种不同强度的量词结构，混淆它们是实分析里最常见的错。
$x$ 是 interior point 要求 $\exists \epsilon \gt 0$ 使整个球落入 $C$——**一个**球就够，且 $\epsilon$ 可以依赖 $x$；而 $x$ 是 boundary point 要求对**每个** $\epsilon \gt 0$ 都能在球内同时找到 $C$ 内与 $C$ 外的点——这是「无论怎么放大都能看到两侧」，量词从 $\exists$ 翻成 $\forall$，结论就从「$x$ 在最里面」变成「$x$ 恰在分界上」。$\operatorname{int}C$ 是第一条成立的点的集合，$\operatorname{bd}C$ 是第二条成立的点的集合，两者互斥。

还有一处值得点明：interior 的定义显式用了 $\|\cdot\|_2$，但结论（哪些点是内点）与范数无关。理由就是 §A.1.4 的等价性——换一个范数 $\|\cdot\|$ 后，$\|\cdot\|_2$ 球与 $\|\cdot\|$ 球互相包含（$\alpha\|y-x\| \le \|y-x\|_2 \le \beta\|y-x\|$），所以「存在某个球落入 $C$」这一命题的真假不变，只是 $\epsilon$ 的大小跟着换。这也是为什么本书后面写 $\operatorname{int}\operatorname{dom}f$ 时从不指明用哪个范数——在有限维里这个选择不携带信息。



```math
\operatorname{cl} C = \mathbf{R}^n \setminus \operatorname{int}\left(\mathbf{R}^n \setminus C\right),
```

集合 $C$ 的 closure（闭包）按上式定义：先取补集，再取内部，再取补集，也就是「补集的内部之补」。另一种等价刻画：$x$ 属于 $C$ 的闭包，当且仅当对**每个** $\epsilon \gt 0$ 都存在 $y \in C$ 使 $\|x-y\|_2 \le \epsilon$（即 $x$ 与 $C$ 的任意小邻域都相交）。

闭集与闭包还可以用收敛序列（convergent sequence）与极限点（limit point）来刻画：$C$ 是闭集，当且仅当它包含其中每个收敛序列的极限点；换句说，若 $x_1,x_2,\ldots$ 收敛到 $x$ 且 $x_i \in C$，则 $x \in C$。而 $C$ 的闭包就是 $C$ 中收敛序列的全部极限点之集。这个刻画在证明里比补定义好用，因为它把「闭」直接翻成「极限不逃出去」。

```math
\operatorname{bd} C = \operatorname{cl} C \setminus \operatorname{int} C.
```

$C$ 的 boundary（边界）按上式定义：闭包减去内部。

```math
\|y - x\|_2 \le \epsilon, \qquad \|z - x\|_2 \le \epsilon,
```

边界点 $x$ 的性质是：对任意 $\epsilon \gt 0$，都能找到 $y \in C$ 与 $z \notin C$ 同时落在 $x$ 的 $\epsilon$-邻域内，即「任意靠近的点在 $C$ 内」与「任意靠近的点不在 $C$ 内」**同时**成立。这正是边界点与内点、与外点的区别。

用 boundary 可以刻画闭集与开集：$C$ 是闭集当且仅当它包含自己的边界（$\operatorname{bd}C \subseteq C$）；$C$ 是开集当且仅当它不含任何边界点（$C\cap\operatorname{bd}C = \emptyset$）。

### A.2.2 · Supremum and infimum（上确界与下确界）

设 $C \subseteq \mathbf{R}$。若对每个 $x \in C$ 都有 $x \le a$，则 $a$ 是 $C$ 的 upper bound（上界）。

$C$ 的上界之集只有三种可能：空集（此时称 $C$ unbounded above，无上界）、整个 $\mathbf{R}$（仅在 $C = \emptyset$ 时出现）、或一个闭的无穷区间 $[b,\infty)$。这三分类的用处在于：第三种情形里的 $b$ 是**唯一**的，所以下面可以给它命名。

这个 $b$ 称为 $C$ 的 least upper bound（最小上界）或 supremum（上确界），记 $\sup C$。约定 $\sup\emptyset = -\infty$；若 $C$ 无上界则 $\sup C = \infty$。当 $\sup C \in C$ 时，称该上确界被 attained（达到）或 achieved。

当 $C$ 有限时，$\sup C$ 就是元素的最大值。有些作者在确界能取到时也用 $\max C$ 表示 supremum；本书遵循标准数学约定：**只有 $C$ 有限时才写 $\max C$**。这条约定在后面很要紧——例如 $\sup\{z^Tx \mid \|x\| \le 1\}$ 是范数（总有定义），但它写不成 $\max$，因为单位球是紧的却只在有限维才保证 $z^Tx$ 的最大值可达（此处实际上可达，但书里统一不用 $\max$）。

下界（lower bound）与下确界（infimum，或 greatest lower bound）用对称的方式定义：$a$ 是 $C$ 的下界，当且仅当对每个 $x\in C$ 有 $a \le x$；而 $\inf C = -\sup(-C)$——把问题翻到负号上去借上确界的存在性，这是最省事的定义方式。$C$ 有限时 infimum 就是最小值。

约定 $\inf\emptyset = \infty$；若 $C$ 无下界（unbounded below，即没有下界），则 $\inf C = -\infty$。

## A.3 · Functions（函数）

### A.3.1 · Function notation（函数记号）

```math
f : A \to B
```

本书的函数记号基本是标准的，只有一处例外。写 $f: A\to B$ 时，我们的意思是：$f$ 是以 $\operatorname{dom}f \subseteq A$ 为定义域、取值于 $B$ 的函数；特别地，$\operatorname{dom}f$ 允许是 $A$ 的**真子集**（proper subset）。

所以 $f:\mathbf{R}^n\to\mathbf{R}^m$ 只表示「$f$ 把（某些）$n$-向量映到 $m$-向量」，**不**表示 $f(x)$ 对每个 $x \in \mathbf{R}^n$ 都有定义。这个约定类似编程语言里的函数声明（function declaration）：声明参数与返回值的类型只给出**语法**（syntax），不保证任何符合类型的实际参数都合法。

```math
f(X) = \log\det X,
\qquad (A.3)
```

举例：$f:\mathbf{S}^n\to\mathbf{R}$ 由 (A.3) 定义，其定义域为 $\mathbf{S}^n_{++}$（对称正定矩阵之集）。

$f:\mathbf{S}^n\to\mathbf{R}$ 交代的是 $f$ 的语法：吃一个对称 $n\times n$ 矩阵，吐一个实数。$\operatorname{dom}f = \mathbf{S}^n_{++}$ 交代的是**哪些**对称矩阵是合法实参（只有正定的那些）。而 (A.3) 的公式交代的是「当 $X \in \operatorname{dom}f$ 时 $f(X)$ 具体等于什么」。三件事合起来才是完整定义。

### A.3.2 · Continuity（连续性）

```math
y \in \operatorname{dom} f, \quad \|y - x\|_2 \le \delta \quad \Longrightarrow \quad \|f(y) - f(x)\|_2 \le \epsilon.
```

若对任意 $\epsilon \gt 0$ 都存在 $\delta$（一般依赖 $\epsilon$ 与 $x$），使上式成立，则称 $f$ 在 $x \in \operatorname{dom}f$ 处 continuous（连续）。注意第一句 $y \in \operatorname{dom}f$ 不能省：只考虑定义域内的点。

```math
\lim_{i\to\infty} f(x_i) = f\left(\lim_{i\to\infty} x_i\right).
```

连续性也可以用极限描述：只要 $\operatorname{dom}f$ 中的序列 $x_1,x_2,\ldots$ 收敛到**仍在定义域内**的点 $x$，则 $f(x_1),f(x_2),\ldots$ 必收敛到 $f(x)$，即上式——极限可以与函数交换次序。

若 $f$ 在定义域内每一点都连续，则称 $f$ continuous。

### A.3.3 · Closed functions（闭函数）

```math
\{x \in \operatorname{dom} f \mid f(x) \le \alpha\}
```

若对每个 $\alpha \in \mathbf{R}$，sublevel set（下水平集，定义如上式）都是闭集，则称 $f$ closed（闭函数）。

<!-- ===== p639 · 续 ===== -->

```math
\operatorname{epi} f = \{(x,t) \in \mathbf{R}^{n+1} \mid x \in \operatorname{dom} f,\ f(x) \le t\},
```

这等价于说 $f$ 的 epigraph（上图像，定义如上式）是闭集。括号里的提醒：定义本身对任何函数都成立，但实际几乎只对凸函数使用——因为凸函数的 epigraph 是凸集，「闭 + 凸」才凑出「closed proper convex function」这个统一框架。



两条判据：若 $f$ 连续且 $\operatorname{dom}f$ 闭，则 $f$ 闭。若 $f$ 连续且 $\operatorname{dom}f$ **开**，则 $f$ 闭当且仅当「沿任何趋于定义域边界点的序列，$f$ 都趋于 $\infty$」；换言之，若 $\lim_i x_i = x \in \operatorname{bd}\operatorname{dom}f$ 而所有 $x_i \in \operatorname{dom}f$，则 $\lim_i f(x_i) = \infty$。

<span style="color:#b45309;">**[Example A.1]**</span> **Examples on $\mathbf{R}$（$\mathbf{R}$ 上的例子）。**

- 函数 $f : \mathbf{R} \to \mathbf{R}$，$f(x) = x\log x$，$\operatorname{dom} f = \mathbf{R}_{++}$，**不**闭。
- 函数 $f : \mathbf{R} \to \mathbf{R}$，取

```math
f(x) = \begin{cases} x\log x & x \gt 0\\ 0 & x = 0,\end{cases} \qquad \operatorname{dom} f = \mathbf{R}_+,
```

- 函数 $f(x) = -\log x$，$\operatorname{dom} f = \mathbf{R}_{++}$，闭。

三个例子刚好把判据用一遍。① $x\log x$ 在 $\mathbf{R}_{++}$ 上：$x \to 0^{+}$ 时 $x\log x \to 0$ **有穷**，不趋于 $\infty$，且 $0$ 是边界点而 $0 \notin \operatorname{dom}f$，故**不闭**。② 把 $0$ 补进定义域并赋值为 $0$（下闭包，lower closure），边界消失，故闭。③ $-\log x$ 在 $x\to0^{+}$ 时趋于 $+\infty$，满足上面的判据，故闭。

## A.4 · Derivatives（导数）

### A.4.1 · Derivative and gradient（导数与梯度）

```math
\lim_{z \in \operatorname{dom} f,\ z \ne x,\ z \to x}\frac{\|f(z) - f(x) - Df(x)(z-x)\|_2}{\|z - x\|_2} = 0,
\qquad (A.4)
```

设 $f:\mathbf{R}^n\to\mathbf{R}^m$ 且 $x \in \operatorname{int}\operatorname{dom}f$（注意要求 $x$ 在内点，否则差商可能没有定义的两个方向都不在定义域里）。若存在矩阵 $Df(x) \in \mathbf{R}^{m\times n}$ 使 (A.4) 成立，则称 $f$ 在 $x$ 处 differentiable（可微），并称 $Df(x)$ 为 $f$ 在 $x$ 处的 derivative（导数）或 Jacobian（雅可比矩阵）。括号里指出：满足 (A.4) 的矩阵**至多一个**（唯一性），这正是「导数」一词能站住的前提。

若 $\operatorname{dom}f$ 开，且 $f$ 在定义域内每一点都可微，则称 $f$ differentiable。要求定义域开是为了让「$x$ 是内点」对所有点成立。

```math
f(x) + Df(x)(z-x)
```

由 $z$ 的仿射函数 $f(x) + Df(x)(z-x)$ 称为 $f$ 在 $x$ 处（或附近）的 first-order approximation（一阶近似）。显然它在 $z = x$ 处与 $f$ 取值相同；当 $z$ 靠近 $x$ 时，这个仿射函数与 $f$ 非常接近——「接近」的量化形式正是 (A.4) 里分子是 $o(\|z-x\|_2)$ 而非 $O(\|z-x\|_2)$。

```math
Df(x)_{ij} = \frac{\partial f_i(x)}{\partial x_j}, \qquad i = 1,\ldots,m,\quad j = 1,\ldots,n.
```

求导数有两条路：一是直接推 $f$ 在 $x$ 处的一阶近似（即找出满足 (A.4) 的 $Df(x)$）；二是走偏导数（partial derivative），按上式逐元素填——第 $i$ 行第 $j$ 列放 $\partial f_i/\partial x_j$。



**Gradient（梯度）。** 定义如下：

```math
\nabla f(x) = Df(x)^T,
```

```math
\nabla f(x)_i = \frac{\partial f(x)}{\partial x_i}, \qquad i = 1,\ldots,n.
```

当 $f$ 取实值（$f:\mathbf{R}^n\to\mathbf{R}$）时，导数 $Df(x)$ 是 $1\times n$ 矩阵，即**行**向量；它的转置称为函数的 gradient（梯度），记 $\nabla f(x) = Df(x)^T$，是一个（列）向量，属于 $\mathbf{R}^n$，其分量就是 $f$ 的各偏导数。

```math
f(x) + \nabla f(x)^T(z-x).
```

$f$ 在 $x \in \operatorname{int}\operatorname{dom}f$ 处的一阶近似可写成 $z$ 的仿射函数 $f(x) + \nabla f(x)^T(z-x)$——与上一页的 $f(x)+Df(x)(z-x)$ 是同一个东西，只是把行向量 $Df$ 换成了列向量 $\nabla f$ 加转置，写成内积形式。

**Examples（例子）。** 先看二次函数 $f : \mathbf{R}^n \to \mathbf{R}$，

```math
f(x) = (1/2)x^TPx + q^Tx + r,
```

```math
\nabla f(x) = Px + q.
```

简单例子：二次函数 $f(x) = (1/2)x^TPx + q^Tx + r$（$P$ 对称，$q \in \mathbf{R}^n$，$r \in \mathbf{R}$），其在 $x$ 处的导数（行向量）为 $Df(x) = x^TP + q^T$，梯度为 $\nabla f(x) = Px + q$。注意这里已经用了 $P$ 的对称性：$\frac{1}{2}(P + P^T) = P$；若 $P$ 不对称，梯度会是 $\frac{1}{2}(P+P^T)x + q$。

```math
f(X) = \log\det X, \qquad \operatorname{dom} f = \mathbf{S}^n_{++}.
```

更有意思的例子是 $f(X) = \log\det X$，定义域 $\mathbf{S}^n_{++}$。

```math
\begin{aligned}
\log\det Z &= \log\det(X + \Delta X)\\
&= \log\det\left(X^{1/2}\left(I + X^{-1/2}\Delta XX^{-1/2}\right)X^{1/2}\right)\\
&= \log\det X + \log\det\left(I + X^{-1/2}\Delta XX^{-1/2}\right)\\
&= \log\det X + \sum_{i=1}^{n}\log(1 + \lambda_i),
\end{aligned}
```

求梯度有一条（繁琐的）路：为 $\mathbf{S}^n$ 引入一组基，先求出对应函数的梯度，再把结果翻译回 $\mathbf{S}^n$。本书不走这条路，而是**直接**求 $f$ 在 $X$ 处的一阶近似。取靠近 $X$ 的 $Z \in \mathbf{S}^n_{++}$，记 $\Delta X = Z-X$（假定很小），展开四步如上：第一步是移项，第二步把 $X$ 写成 $X^{1/2}X^{1/2}$ 并把 $\Delta X$ 夹进去、两侧同时做相似变换（这一步是把对称矩阵变成「单位阵 + 小扰动」的标准手法），第三步拆出 $\log\det X$，第四步把 $\det$ 换成特征值之积再取 $\log$——其中 $\lambda_i$ 是 $X^{-1/2}\Delta XX^{-1/2}$ 的第 $i$ 个特征值。

```math
f(Z) \approx f(X) + \operatorname{tr}\left(X^{-1}(Z - X)\right).
```

```math
\nabla f(X) = X^{-1}.
```

注意右端第二项正是 $X^{-1}$ 与 $Z-X$ 的 standard inner product（p634 的 $\operatorname{tr}(UV)$），于是可以**辨认**出 $X^{-1}$ 就是 $f$ 在 $X$ 处的梯度，写成简洁公式 $\nabla f(X) = X^{-1}$。

这个结果并不意外：$\log x$ 在 $\mathbf{R}_{++}$ 上的导数就是 $1/x$——矩阵情形只是把 $x \mapsto 1/x$ 换成了 $X \mapsto X^{-1}$。

### A.4.2 · Chain rule（链式法则）

```math
Dh(x) = Dg(f(x))Df(x).
\qquad (A.5)
```

设 $f$ 在 $x$ 处可微、$g$ 在 $f(x)$ 处可微，复合 $h(z) = g(f(z))$。则 $h$ 在 $x$ 处可微，其导数按 (A.5) 给出——即矩阵乘积 $Dg(f(x))Df(x)$，次序由维数 $p\times m$ 乘 $m\times n$ 唯一确定。

```math
\nabla h(x) = g'(f(x))\nabla f(x).
\qquad (A.6)
```

举例：$f:\mathbf{R}^n\to\mathbf{R}$，$g:\mathbf{R}\to\mathbf{R}$，$h = g\circ f$。把 $Dh(x) = Dg(f(x))Df(x)$ 转置，得到 (A.6)：$\nabla h(x) = g'(f(x))\nabla f(x)$。这里 $g'(f(x))$ 是标量，所以它可以提到前面——这是标量外层函数独有的便利。

与仿射函数复合：设 $f$ 可微、$A \in \mathbf{R}^{n\times p}$、$b \in \mathbf{R}^n$，定义 $g(x) = f(Ax+b)$，其定义域为 $\{x \mid Ax+b \in \operatorname{dom}f\}$。按链式法则 (A.5)，$Dg(x) = Df(Ax+b)A$。

```math
\nabla g(x) = A^T\nabla f(Ax + b).
```

当 $f$ 取实值（$m=1$）时，得到「函数与仿射函数复合」的梯度公式 $\nabla g(x) = A^T\nabla f(Ax+b)$。这个 $A^T$ 出现的位置是全部矩阵微分里最常写错的地方：**外层梯度左乘 $A^T$**，而 $Df$ 情形是**右乘 $A$**。

```math
D\tilde f(t) = \tilde f'(t) = \nabla f(x + tv)^Tv.
```

举例：取 $f:\mathbf{R}^n\to\mathbf{R}$、$x,v\in\mathbf{R}^n$，定义 $\tilde f(t) = f(x+tv)$——粗略地说，$\tilde f$ 是 $f$ 限制到直线 $\{x+tv \mid t\in\mathbf{R}\}$ 上（restriction to a line）。于是 $D\tilde f(t) = \tilde f'(t) = \nabla f(x+tv)^Tv$。

标量 $\tilde f'(0)$ 就是 $f$ 在 $x$ 处沿方向 $v$ 的 directional derivative（方向导数）。

<span style="color:#b45309;">**[Example A.2]**</span> Consider the function $f : \mathbf{R}^n \to \mathbf{R}$, with $\operatorname{dom} f = \mathbf{R}^n$ and

```math
f(x) = \log\sum_{i=1}^{m}\exp(a_i^Tx + b_i),
```

考虑 $f:\mathbf{R}^n\to\mathbf{R}$，定义域为全空间，函数值为 $\log\sum_{i=1}^{m}\exp(a_i^Tx+b_i)$——即 log-sum-exp，全书出现频率最高的光滑凸函数。



其中 $a_1,\ldots,a_m \in \mathbf{R}^n$，$b_1,\ldots,b_m \in \mathbf{R}$。求其梯度的简洁表达式的办法是把它认成复合：内层是仿射函数 $Ax+b$（$A \in \mathbf{R}^{m\times n}$，各行依次为 $a_1^T,\ldots,a_m^T$），外层是 $g(y) = \log\left(\sum_{i=1}^m \exp y_i\right)$。

```math
\nabla g(y) = \frac{1}{\sum_{i=1}^{m}\exp y_i}\begin{bmatrix}\exp y_1\\ \vdots\\ \exp y_m\end{bmatrix},
\qquad (A.7)
```

简单求导（或直接用 (A.6)）给出 (A.7)：$\nabla g(y)$ 等于「各 $\exp y_i$ 归一化后的向量」，即 softmax。注意分母是**标量** $\sum_i \exp y_i$，所以整体是一个列向量。

```math
\nabla f(x) = \frac{1}{\mathbf{1}^Tz}A^Tz
```

于是按复合公式（即 $\nabla(Ax+b)$ 的 $A^T$ 左乘公式），得 $\nabla f(x) = \frac{1}{\mathbf{1}^Tz}A^Tz$，其中 $z_i = \exp(a_i^Tx+b_i)$。这就是为什么 log-sum-exp 在机器学习里到处出现：它的梯度就是 softmax 加权平均，二阶导（p645）就是 $A^T(\operatorname{diag}(p)-pp^T)A$，$p$ 是 softmax 概率向量。

<span style="color:#b45309;">**[Example A.3]**</span> 下面推导 $\nabla f(x)$ 的表达式，其中

```math
f(x) = \log\det(F_0 + x_1F_1 + \cdots + x_nF_n),
```

```math
\operatorname{dom} f = \{x \in \mathbf{R}^n \mid F_0 + x_1F_1 + \cdots + x_nF_n \succ 0\}.
```

我们推导 $\nabla f(x)$ 的表达式，其中 $f(x) = \log\det(F_0 + x_1F_1 + \cdots + x_nF_n)$，各 $F_i \in \mathbf{S}^p$，定义域为「使该线性矩阵不等式严格成立」的 $x$ 之集。注意这里是 $n$ 个标量变量驱动一个 $p\times p$ 矩阵——即 log-det 的**仿射矩阵族**形式，SDP 的原型。

```math
\frac{\partial f(x)}{\partial x_i} = \operatorname{tr}\left(F_i\nabla\log\det(F)\right) = \operatorname{tr}\left(F^{-1}F_i\right),
```

```math
\nabla f(x) = \begin{bmatrix}\operatorname{tr}(F^{-1}F_1)\\ \vdots\\ \operatorname{tr}(F^{-1}F_n)\end{bmatrix}.
```

$f$ 是「$x \mapsto F_0 + x_1F_1 + \cdots + x_nF_n \in \mathbf{S}^p$」这个仿射映射与 $\log\det X$ 的复合。用链式法则算出 $\partial f/\partial x_i = \operatorname{tr}(F_i\nabla\log\det(F)) = \operatorname{tr}(F^{-1}F_i)$，其中 $F = F_0 + \sum_i x_iF_i$。于是梯度如上式：第 $i$ 个分量就是 $F^{-1}F_i$ 的迹。这里 $\operatorname{tr}(F_iF^{-1})$ 与 $\operatorname{tr}(F^{-1}F_i)$ 相等是循环移位，不是交换性。

### A.4.3 · Second derivative（二阶导数）

```math
\nabla^2f(x)_{ij} = \frac{\partial^2 f(x)}{\partial x_i\partial x_j}, \qquad i = 1,\ldots,n,\quad j = 1,\ldots,n,
```

本节回顾实值函数 $f:\mathbf{R}^n\to\mathbf{R}$ 的二阶导数。$f$ 在 $x \in \operatorname{int}\operatorname{dom}f$ 处的 second derivative（二阶导数）或 Hessian matrix（Hessian 矩阵）记 $\nabla^2f(x)$，其 $(i,j)$ 元为 $\partial^2f/\partial x_i\partial x_j$（在 $x$ 处取值），前提是 $f$ 在 $x$ 处二次可微（twice differentiable）。$f$ 二次可微时该矩阵对称。

```math
\hat f(z) = f(x) + \nabla f(x)^T(z-x) + (1/2)(z-x)^T\nabla^2f(x)(z-x).
```

$f$ 在 $x$ 处（或附近）的 second-order approximation（二阶近似）是 $z$ 的二次函数 $\hat f(z)$，如上式。系数 $1/2$ 是必要的：否则二次型的导数会是 $2\nabla^2f(x)(z-x)$，与 Taylor 展开不匹配。



```math
\lim_{z \in \operatorname{dom} f,\ z \ne x,\ z\to x}\frac{|f(z) - \hat f(z)|}{\|z - x\|_2^2} = 0.
```

这个二阶近似满足上式：误差是 $o(\|z-x\|_2^2)$，比一阶近似的 $o(\|z-x\|_2)$ 高一阶。注意分母是**平方**的范数。

```math
D\nabla f(x) = \nabla^2f(x).
```

不出意料，二阶导数可以看成「导数的导数」：若 $f$ 可微，则 gradient mapping（梯度映射）是函数 $\nabla f:\mathbf{R}^n\to\mathbf{R}^n$，定义域同 $f$，在 $x$ 处取值 $\nabla f(x)$；这个映射的导数就是 $D\nabla f(x) = \nabla^2f(x)$。

**Examples（例子）。** 先看二次函数 $f : \mathbf{R}^n \to \mathbf{R}$，

```math
f(x) = (1/2)x^TPx + q^Tx + r,
```

简单例子仍是二次函数 $f(x) = (1/2)x^TPx+q^Tx+r$。其梯度为 $Px+q$，故 Hessian 就是 $P$。**二次函数的二阶近似就是它自身**（因为它是二次的，Taylor 展开二阶精确）。

```math
\begin{aligned}
Z^{-1} &= (X + \Delta X)^{-1}\\
&= \left(X^{1/2}\left(I + X^{-1/2}\Delta XX^{-1/2}\right)X^{1/2}\right)^{-1}\\
&= X^{-1/2}\left(I + X^{-1/2}\Delta XX^{-1/2}\right)^{-1}X^{-1/2}\\
&\approx X^{-1/2}\left(I - X^{-1/2}\Delta XX^{-1/2}\right)X^{-1/2}\\
&= X^{-1} - X^{-1}\Delta XX^{-1},
\end{aligned}
```

更复杂的例子仍是 $f(X) = \log\det X$。要得到二阶近似（从而得到 Hessian），先去求**梯度** $\nabla f(X) = X^{-1}$ 的一阶近似：取靠近 $X$ 的 $Z$，令 $\Delta X = Z-X$，五步展开如上。第二步与第三步是把 $X$ 拆成 $X^{1/2}X^{1/2}$ 并在逆运算里分别进退；第四步用 $(I+A)^{-1} \approx I - A$（$A$ 小时的 first-order approximation）；第五步把 $X^{-1/2}$ 乘进去，两个交叉项合成 $X^{-1}\Delta XX^{-1}$。

```math
-\operatorname{tr}\left(X^{-1}UX^{-1}V\right),
```

这个近似足以**辨认**出 $f$ 在 $X$ 处的 Hessian。Hessian 是 $\mathbf{S}^n$ 上的二次型（quadratic form）；一般情形下这种二次型描述起来很笨拙，因为它需要**四个下标**（$\nabla^2f$ 若写成张量是 $n\times n\times n\times n$）。但由上面梯度的一阶近似，二次型可以写成 $-\operatorname{tr}(X^{-1}UX^{-1}V)$，其中 $U,V\in\mathbf{S}^n$ 是该二次型的两个自变量。

括号指出这个式子推广了标量情形：$(\log x)'' = -1/x^2$。把 $X = x$、$U = V = 1$（一维）代入，$-x^{-1}\cdot1\cdot x^{-1}\cdot1 = -1/x^2$，与标量公式一致。

```math
\begin{aligned}
f(Z) &= f(X + \Delta X)\\
&\approx f(X) + \operatorname{tr}(X^{-1}\Delta X) - (1/2)\operatorname{tr}\left(X^{-1}\Delta XX^{-1}\Delta X\right)\\
&\approx f(X) + \operatorname{tr}\left(X^{-1}(Z - X)\right) - (1/2)\operatorname{tr}\left(X^{-1}(Z - X)X^{-1}(Z - X)\right).
\end{aligned}
```

于是得到 $f$ 在 $X$ 附近的二阶近似：第一行是一阶项（p642 已得），第二行是二阶项，来自梯度一阶近似里的 $-X^{-1}\Delta XX^{-1}$ 与 $\Delta X$ 做内积、前缀系数 $1/2$。

### A.4.4 · Chain rule for second derivative（二阶导数的链式法则）

二阶导数的一般链式法则在多数情形下都很笨拙（还会引入三阶张量），所以本书只给出我们将要用到的几个特殊情形。

**Composition with scalar function（与标量函数复合）。** 设 $f : \mathbf{R}^n \to \mathbf{R}$、$g : \mathbf{R} \to \mathbf{R}$、$h(x) = g(f(x))$。把偏导数直接算出来即得

```math
\nabla^2h(x) = g'(f(x))\nabla^2f(x) + g''(f(x))\nabla f(x)\nabla f(x)^T.
\qquad (A.8)
```

设 $f:\mathbf{R}^n\to\mathbf{R}$、$g:\mathbf{R}\to\mathbf{R}$、$h(x) = g(f(x))$。把偏导数直接算出来即得 (A.8)：第一项是外层一阶导乘内层 Hessian，第二项是外层二阶导乘**内层梯度的外积** $\nabla f\nabla f^T$（一个秩一矩阵）。第二项常被漏掉，漏掉的后果是可观测的：复合后函数的曲率被低估，Newton 步过大。

**Composition with affine function（与仿射函数复合）。** 设 $f : \mathbf{R}^n \to \mathbf{R}$、$A \in \mathbf{R}^{n\times m}$、$b \in \mathbf{R}^n$，定义 $g : \mathbf{R}^m \to \mathbf{R}$ 为 $g(x) = f(Ax + b)$，则

```math
\nabla^2g(x) = A^T\nabla^2f(Ax + b)A.
```

设 $f:\mathbf{R}^n\to\mathbf{R}$、$A \in \mathbf{R}^{n\times m}$、$b\in\mathbf{R}^n$，$g(x) = f(Ax+b)$。则 $\nabla^2g(x) = A^T\nabla^2f(Ax+b)A$——两侧各夹一个 $A$，与一阶情形只夹一个 $A^T$ 不同。

```math
\nabla^2\tilde f(t) = \tilde f''(t) = v^T\nabla^2f(x + tv)v.
```

举例：把实值函数 $f$ 限制到一条直线上，即 $\tilde f(t) = f(x+tv)$（$x$ 与 $v$ 固定）。则 $\nabla^2\tilde f(t) = \tilde f''(t) = v^T\nabla^2f(x+tv)v$——一维二阶导就是 Hessian 在 $v$ 方向上的二次型，这是「方向曲率」的定义。

<span style="color:#b45309;">**[Example A.4]**</span> 考虑 Example A.2 中的函数 $f : \mathbf{R}^n \to \mathbf{R}$：

```math
f(x) = \log\sum_{i=1}^{m}\exp(a_i^Tx + b_i),
```

考虑 Example A.2 中的 $f(x) = \log\sum_{i=1}^m\exp(a_i^Tx+b_i)$，其中 $a_i \in \mathbf{R}^n$、$b_i \in \mathbf{R}$。

```math
\nabla^2g(y) = \operatorname{diag}(\nabla g(y)) - \nabla g(y)\nabla g(y)^T,
```

注意 $f(x) = g(Ax+b)$（$g(y) = \log\sum_i \exp y_i$），即可得 $f$ 的 Hessian 的简洁公式。直接求偏导，或用 (A.8)（注意 $g$ 是 $\log$ 与 $\sum_i\exp y_i$ 的复合），得到 $\nabla^2g(y) = \operatorname{diag}(\nabla g(y)) - \nabla g(y)\nabla g(y)^T$，其中 $\nabla g(y)$ 见 (A.7)。注意这个式子读法：$\operatorname{diag}(p) - pp^T$，$p$ 是 softmax——这正是「概率向量的协方差」，半正定且零空间由 $\mathbf{1}$ 张成。

```math
\nabla^2f(x) = A^T\left(\frac{1}{\mathbf{1}^Tz}\operatorname{diag}(z) - \frac{1}{(\mathbf{1}^Tz)^2}zz^T\right)A,
```

按复合公式得 $\nabla^2f(x) = A^T\left(\frac{1}{\mathbf{1}^Tz}\operatorname{diag}(z) - \frac{1}{(\mathbf{1}^Tz)^2}zz^T\right)A$，其中 $z_i = \exp(a_i^Tx+b_i)$。把 $p = z/(\mathbf{1}^Tz)$ 代入，括号里正是 $\operatorname{diag}(p) - pp^T$ 的缩放版本，量纲与 $A$ 的尺度一致。

## A.5 · Linear algebra（线性代数）

### A.5.1 · Range and nullspace（值域与零空间）



```math
\mathcal{R}(A) = \{Ax \mid x \in \mathbf{R}^n\}.
```

设 $A \in \mathbf{R}^{m\times n}$（$m$ 行 $n$ 列实矩阵）。$A$ 的 range（值域）记 $\mathcal{R}(A)$，是 $\mathbf{R}^m$ 中所有可写成 $A$ 的列之线性组合的向量之集，即 $\mathcal{R}(A) = \{Ax \mid x\in\mathbf{R}^n\}$。

$\mathcal{R}(A)$ 是 $\mathbf{R}^m$ 的 subspace（子空间），本身就是一个向量空间；它的维数称为 $A$ 的 rank（秩），记 $\operatorname{rank}A$。秩永远不会大于 $m$ 与 $n$ 的最小值。当 $\operatorname{rank}A = \min\{m,n\}$ 时称 $A$ full rank（满秩）。

```math
\mathcal{N}(A) = \{x \mid Ax = 0\}.
```

$A$ 的 nullspace（零空间），也称 kernel（核），记 $\mathcal{N}(A)$，是被 $A$ 映为零的全部向量之集：$\mathcal{N}(A) = \{x \mid Ax=0\}$。

nullspace 是 $\mathbf{R}^n$ 的子空间。

**正交分解（orthogonal decomposition induced by $A$）。** 若 $V$ 是 $\mathbf{R}^n$ 的子空间，其 **orthogonal complement**（正交补）记 $V^\perp$，定义为

```math
V^\perp = \{x \mid z^Tx = 0 \text{ for all } z \in V\}.
```

若 $V$ 是 $\mathbf{R}^n$ 的子空间，其 orthogonal complement（正交补）记 $V^\perp$，定义为「与 $V$ 中所有向量都正交的向量之集」。

括号指出：正如「补」这个名称所暗示的，有 $V^{\perp\perp} = V$。这在有限维空间里总成立（对偶是 reflexive 的）；在无限维的一般内积空间里需要对 $V$ 是闭子空间。

```math
\mathcal{N}(A) = \mathcal{R}(A^T)^\perp.
```

线性代数的一条基本结论是：对任何 $A \in \mathbf{R}^{m\times n}$，都有 $\mathcal{N}(A) = \mathcal{R}(A^T)^\perp$——$A$ 的零空间恰是 $A^T$ 的值域的正交补。

```math
\mathcal{N}(A) \overset{\perp}{\oplus} \mathcal{R}(A^T) = \mathbf{R}^n.
\qquad (A.9)
```

把结论用于 $A^T$ 还得到 $\mathcal{R}(A) = \mathcal{N}(A^T)^\perp$。这条结论常写成 (A.9)：这里 $\overset{\perp}{\oplus}$ 记号表示 orthogonal direct sum（正交直和），即「两个互相正交的子空间之和」。$\mathbf{R}^n$ 的这个分解 (A.9) 称为由 $A$ 诱导的 orthogonal decomposition（正交分解）。它的实用读法：任何一个 $x$ 都能**唯一**拆成「零空间分量 + 值域分量」两部分，且这两部分的内积为零。

### A.5.2 · Symmetric eigenvalue decomposition（对称特征值分解）

```math
A = Q\Lambda Q^T,
\qquad (A.10)
```

设 $A \in \mathbf{S}^n$（实对称 $n\times n$ 矩阵）。则 $A$ 可分解为 (A.10)：其中 $Q \in \mathbf{R}^{n\times n}$ 是 orthogonal（正交）矩阵，即满足 $Q^TQ = I$；$\Lambda = \operatorname{diag}(\lambda_1,\ldots,\lambda_n)$ 是对角矩阵。

这些（实）数 $\lambda_i$ 是 $A$ 的 eigenvalues（特征值），也是特征多项式（characteristic polynomial）$\det(sI-A)$ 的根。$Q$ 的各列构成 $A$ 的一组 orthonormal（标准正交）eigenvectors（特征向量）。分解 (A.10) 称为 $A$ 的 spectral decomposition（谱分解）或（对称）eigenvalue decomposition（特征值分解）。注意三角色齐备：特征值是实、特征向量正交、$Q$ 可逆且 $Q^{-1} = Q^T$——这三条同时成立**只**对对称矩阵成立。

我们把特征值按 $\lambda_1 \ge \lambda_2 \ge \cdots \ge \lambda_n$ 排序。用记号 $\lambda_i(A)$ 表示 $A$ 的第 $i$ 大特征值（†原文此处写 "$A \in \mathbf{S}$"，缺上标 $n$，见文末「原文自身问题」）。最大特征值常写 $\lambda_1(A) = \lambda_{\max}(A)$，最小特征值常写 $\lambda_n(A) = \lambda_{\min}(A)$。

## A.5 · Linear algebra（线性代数，续）

### A.5.2 · 谱分解的推论：不变量与范数

determinant（行列式）与 trace（迹）都能用 eigenvalues 写出来：

```math
\det A = \prod_{i=1}^{n} \lambda_i, \qquad \operatorname{tr} A = \sum_{i=1}^{n} \lambda_i,
```

spectral norm 与 Frobenius norm 同样是特征值的函数：

```math
\|A\|_2 = \max_{i=1,\ldots,n} |\lambda_i| = \max\{\lambda_1, -\lambda_n\}, \qquad \|A\|_F = \left(\sum_{i=1}^{n} \lambda_i^2\right)^{1/2}.
```

第一式依赖特征值已按 $\lambda_1 \ge \lambda_2 \ge \cdots \ge \lambda_n$ 的非增序排好，换成 `max{λ_1, −λ_n}` 这种写法时排序是前提，否则要退回 $\max_i |\lambda_i|$。第二式——用特征值平方和开方算 Frobenius norm——只在 symmetric 矩阵上成立；一般矩阵要改用 A.5.4 的 singular value，因为非对称矩阵的特征值可以是复数，平方和不再是 Frobenius norm 的平方。

### Definiteness and matrix inequalities（定性与矩阵不等式）

最大与最小特征值有变分刻画：

```math
\lambda_{\max}(A) = \sup_{x \neq 0} \frac{x^{T} A x}{x^{T} x}, \qquad \lambda_{\min}(A) = \inf_{x \neq 0} \frac{x^{T} A x}{x^{T} x}.
```

这两条就是 Rayleigh quotient（瑞利商）的极值。它们把「特征值」从一个解多项式的代数对象换成了「在单位球上取二次型的极值」这个几何对象——后面所有关于 definiteness 的判据都从这里来。

特别地，对任意 $x$ 有

```math
\lambda_{\min}(A) x^{T} x \le x^{T} A x \le \lambda_{\max}(A) x^{T} x,
```

且两个不等号都能取到等号（分别由不同的 $x$ 取到，即对应的 eigenvector）。

称 $A \in \mathbf{S}^n$ positive definite（正定），若对所有 $x \neq 0$ 都有 $x^{T} A x \gt 0$，记作 $A \succ 0$。由上面的夹逼式立刻得到等价判据：$A \succ 0$ 当且仅当其全部特征值为正，即 $\lambda_{\min}(A) \gt 0$。若 $-A$ 正定，则称 $A$ negative definite（负定），记作 $A \prec 0$。用 $\mathbf{S}^n_{++}$ 表示 $\mathbf{S}^n$ 中正定矩阵之集。

若 $A$ 对所有 $x$ 满足 $x^{T} A x \ge 0$，则称 $A$ positive semidefinite（半正定）或 nonnegative definite。若 $-A$ 半正定，即 $x^{T} A x \le 0$ 对一切 $x$ 成立，则称 $A$ negative semidefinite（负半正定）或 nonpositive definite。用 $\mathbf{S}^n_{+}$ 表示 $\mathbf{S}^n$ 中半正定矩阵之集。

对 $A, B \in \mathbf{S}^n$，$A \prec B$ 的含义是 $B - A \succ 0$，其余记号同理。这类不等式称为 matrix inequality（矩阵不等式），或 positive semidefinite cone（半正定锥）诱导的 generalized inequality（广义不等式）。

一个必须记住的语义差别：$A \preceq B$ **不是**逐元素比较。$\begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix} \preceq \begin{bmatrix} 2 & 0 \\ 0 & 0 \end{bmatrix}$ 是假的（差矩阵有负特征值 $-1$），尽管逐元素看每个位置都不小。$A \preceq B$ 问的是「对所有 $x$，$x^T Ax \le x^T Bx$」，这是一族无穷多条线性约束，不可约化为有限条。

**为什么在这里出现**：A.5.2 的谱分解刚把 $A$ 写成 $Q\Lambda Q^T$，λ 是实数的这件事使得 $\preceq$ 能通过 $\Lambda$ 落到实数序上，于是「矩阵不等式」才可能是个可判定的关系。再往后一步（p650）Schur complement 就是这套记号下的主要运算技巧。</span>


### Symmetric squareroot（对称平方根）

设 $A \in \mathbf{S}^n_{+}$，eigenvalue decomposition 为 $A = Q \operatorname{diag}(\lambda_1, \ldots, \lambda_n) Q^{T}$。则 $A$ 的（对称）squareroot 定义为

```math
A^{1/2} = Q \operatorname{diag}\left(\lambda_1^{1/2}, \ldots, \lambda_n^{1/2}\right) Q^{T}.
```

$A^{1/2}$ 是方程 $X^{2} = A$ 的**唯一**对称半正定解。注意「唯一」两字去不得：$X^2 = A$ 在对称阵里一般有很多解（例如 $-A^{1/2}$ 也是解，二维时还有大量非交换的旋转型解），但把解限制在 $\mathbf{S}^n_{+}$ 内就只剩一个。这个唯一性是后面写 $B^{-1/2} A B^{-1/2}$ 时不必加括号解释的前提。

### A.5.3 · Generalized eigenvalue decomposition（广义特征值分解）

一对对称矩阵 $(A, B) \in \mathbf{S}^n \times \mathbf{S}^n$ 的 generalized eigenvalues（广义特征值）定义为多项式 $\det(sB - A)$ 的根。



我们通常只关心 $B \in \mathbf{S}^n_{++}$ 的矩阵对。此时 generalized eigenvalue 也等于 $B^{-1/2} A B^{-1/2}$ 的 eigenvalues，而后者是实对称阵，故广义特征值全为实数。与标准 eigenvalue decomposition 一样，把广义特征值按非增序排成 $\lambda_1 \ge \lambda_2 \ge \cdots \ge \lambda_n$，并把最大广义特征值记作 $\lambda_{\max}(A, B)$。

当 $B \in \mathbf{S}^n_{++}$ 时，矩阵对可分解为

```math
A = V \Lambda V^{T}, \qquad B = V V^{T}, \qquad (A.11)
```

其中 $V \in \mathbf{R}^{n \times n}$ 非奇异，$\Lambda = \operatorname{diag}(\lambda_1, \ldots, \lambda_n)$ 的对角元即 $(A, B)$ 的广义特征值。分解 (A.11) 称为 generalized eigenvalue decomposition（广义特征值分解）。

它与 $B^{-1/2} A B^{-1/2}$ 的标准 eigenvalue decomposition 直接相关：若 $Q \Lambda Q^{T}$ 是 $B^{-1/2} A B^{-1/2}$ 的 eigenvalue decomposition，则 (A.11) 取 $V = B^{1/2} Q$ 即成立。

代入验证一次就明白为什么 $V = B^{1/2}Q$：$V V^T = B^{1/2} Q Q^T B^{1/2} = B^{1/2} B^{1/2} = B$，$V \Lambda V^T = B^{1/2} Q \Lambda Q^T B^{1/2} = B^{1/2}(B^{-1/2} A B^{-1/2})B^{1/2} = A$。整个构造只用了 $B^{1/2}$ 存在这一件事，而它由 $B \succ 0$ 保证。

### A.5.4 · Singular value decomposition（奇异值分解）

设 $A \in \mathbf{R}^{m \times n}$，$\operatorname{rank} A = r$。则 $A$ 可分解为

```math
A = U \Sigma V^{T}, \qquad (A.12)
```

其中 $U \in \mathbf{R}^{m \times r}$ 满足 $U^{T} U = I$，$V \in \mathbf{R}^{n \times r}$ 满足 $V^{T} V = I$，$\Sigma = \operatorname{diag}(\sigma_1, \ldots, \sigma_r)$ 且

```math
\sigma_1 \ge \sigma_2 \ge \cdots \ge \sigma_r \gt 0.
```

分解 (A.12) 称为 $A$ 的 singular value decomposition（奇异值分解，SVD）。$U$ 的列称为 $A$ 的 left singular vectors（左奇异向量），$V$ 的列称为 right singular vectors（右奇异向量），$\sigma_i$ 称为 singular values（奇异值）。SVD 还可写成外积求和的形式

```math
A = \sum_{i=1}^{r} \sigma_i u_i v_i^{T},
```

其中 $u_i \in \mathbf{R}^m$ 是左奇异向量，$v_i \in \mathbf{R}^n$ 是右奇异向量。这个和式与 eigenvalue decomposition 的 $\sum_i \lambda_i q_i q_i^T$ 是同一种「秩一项加权叠加」的结构，区别只在两侧的向量不共线：$u_i$ 与 $v_i$ 分处两个空间。

矩阵 $A$ 的 SVD 与（对称、半正定的）矩阵 $A^{T} A$ 的 eigenvalue decomposition 密切相关。由 (A.12) 可写

```math
A^{T} A = V \Sigma^{2} V^{T} = \begin{bmatrix} V & \tilde{V} \end{bmatrix} \begin{bmatrix} \Sigma^{2} & 0 \\ 0 & 0 \end{bmatrix} \begin{bmatrix} V & \tilde{V} \end{bmatrix}^{T},
```

其中 $\tilde{V}$ 是使 $[V\ \tilde{V}]$ orthogonal（正交）的任意矩阵。右端的表达式正是 $A^{T} A$ 的 eigenvalue decomposition，于是得出：$A^{T} A$ 的非零特征值是 $A$ 的奇异值的平方，而对应的 $A^{T} A$ 的 eigenvectors 是 $A$ 的右奇异向量。对 $A A^{T}$ 作类似分析可见，其非零



特征值同样是 $A$ 的奇异值的平方，而对应的 eigenvectors 是 $A$ 的左奇异向量。

第一个、也就是最大的奇异值也记作 $\sigma_{\max}(A)$。它可以写成

```math
\sigma_{\max}(A) = \sup_{x, y \neq 0} \frac{x^{T} A y}{\|x\|_2 \|y\|_2} = \sup_{y \neq 0} \frac{\|A y\|_2}{\|y\|_2}.
```

右端的式子说明：最大奇异值就是 $A$ 的 $\ell_2$ operator norm。这不是巧合——operator norm 的定义 $\sup_{y\neq 0}\|Ay\|_2/\|y\|_2$ 与 $\sigma_{\max}$ 的定义在数学上是同一条，SVD 只是给了它一个可算的闭式：把 $A$ 乘到 $A^TA$ 的 eigenvector 上再取范数。

$A \in \mathbf{R}^{m \times n}$ 的最小奇异值由下式给出：

```math
\sigma_{\min}(A) = \begin{cases} \sigma_r(A) & r = \min\{m, n\}, \\ 0 & r \lt \min\{m, n\}, \end{cases}
```

它是正的当且仅当 $A$ full rank（满秩）。也就是说，$\sigma_{\min}$ 是「离奇异有多远」的一个直接度量：$\sigma_{\min} = 0$ 就是奇异，$\sigma_{\min}$ 很小就是接近奇异。

symmetric 矩阵的奇异值等于其非零特征值的绝对值，按降序排列；symmetric positive semidefinite 矩阵的奇异值则等于其非零特征值本身（因为此时特征值本就非负）。

非奇异矩阵 $A \in \mathbf{R}^{n \times n}$ 的 condition number（条件数），记作 $\operatorname{cond}(A)$ 或 $\kappa(A)$，定义为

```math
\operatorname{cond}(A) = \|A\|_2 \|A^{-1}\|_2 = \sigma_{\max}(A) / \sigma_{\min}(A).
```

### Pseudo-inverse（伪逆）

设 $A = U \Sigma V^{T}$ 是 $A \in \mathbf{R}^{m \times n}$ 的 SVD，$\operatorname{rank} A = r$。定义 $A$ 的 pseudo-inverse（伪逆），又称 Moore-Penrose inverse，为

```math
A^{\dagger} = V \Sigma^{-1} U^{T} \in \mathbf{R}^{n \times m}.
```

等价表达式还有

```math
A^{\dagger} = \lim_{\epsilon \to 0} \left(A^{T} A + \epsilon I\right)^{-1} A^{T} = \lim_{\epsilon \to 0} A^{T} \left(A A^{T} + \epsilon I\right)^{-1},
```

取极限时 $\epsilon \gt 0$，以保证式中各逆存在（$\epsilon \gt 0$ 时 $A^TA + \epsilon I$ 与 $AA^T + \epsilon I$ 均正定）。$A$ 的秩不同时伪逆退回不同的简单形式：若 $\operatorname{rank} A = n$，则 $A^{\dagger} = (A^{T} A)^{-1} A^{T}$；若 $\operatorname{rank} A = m$，则 $A^{\dagger} = A^{T}(A A^{T})^{-1}$；若 $A$ 是方阵且非奇异，则 $A^{\dagger} = A^{-1}$。

pseudo-inverse 出现在 least-squares、minimum norm、二次极小化与（Euclidean）projection 这几类问题里。举一例：$A^{\dagger} b$ 一般地就是 least-squares 问题

```math
\text{minimize} \quad \|A x - b\|_2^{2}
```

的解；当解不唯一时，$A^{\dagger} b$ 给出其中（Euclidean）norm 最小的那个。再举一例：矩阵 $A A^{\dagger} = U U^{T}$ 给出到 $\mathcal{R}(A)$ 上的（Euclidean）projection，而 $A^{\dagger} A = V V^{T}$ 给出到 $\mathcal{R}(A^{T})$ 上的（Euclidean）projection。

（一般、非凸的）二次优化问题

```math
\text{minimize} \quad (1/2) x^{T} P x + q^{T} x + r,
```

其中 $P \in \mathbf{S}^n$，其最优值 $p^{\star}$ 可写成

```math
p^{\star} = \begin{cases} -(1/2) q^{T} P^{\dagger} q + r & P \succeq 0, \ q \in \mathcal{R}(P), \\ -\infty & \text{otherwise}. \end{cases}
```

这是 $P \succ 0$ 时成立的 $p^{\star} = -(1/2) q^{T} P^{-1} q + r$ 的推广：把 $P^{-1}$ 换成 $P^{\dagger}$，同时必须补上 $q \in \mathcal{R}(P)$ 这个可解性条件，否则最优值是 $-\infty$（沿 $P$ 的零空间方向走，二次项不变而线性项线性发散）。注意这里 $P \succeq 0$ 是前提的一部分——$P$ 若不定，问题有下界都成问题，上式不适用。

### A.5.5 · Schur complement（Schur 补）

考虑按如下方式分块（partitioned）的矩阵 $X \in \mathbf{S}^n$：

```math
X = \begin{bmatrix} A & B \\ B^{T} & C \end{bmatrix},
```

其中 $A \in \mathbf{S}^k$。若 $\det A \neq 0$，则矩阵

```math
S = C - B^{T} A^{-1} B
```

称为 $A$ 在 $X$ 中的 Schur complement。Schur complement 出现在若干不同语境里，也是许多重要公式与定理的组成部分。例如

```math
\det X = \det A \det S.
```

这条行列式恒等式是 Schur complement 的招牌性质：它把 $n \times n$ 的行列式拆成两个更小矩阵的行列式之积，从而把「$X$ 非奇异」的判据从 $\mathbf{R}^{n \times n}$ 降到 $\mathbf{R}^{k\times k}$ 与 $\mathbf{R}^{(n-k)\times(n-k)}$。

### Inverse of block matrix（分块矩阵的逆）

Schur complement 在解线性方程时出现，方式是通过消去一组变量。从

```math
\begin{bmatrix} A & B \\ B^{T} & C \end{bmatrix} \begin{bmatrix} x \\ y \end{bmatrix} = \begin{bmatrix} u \\ v \end{bmatrix},
```

出发，假设 $\det A \neq 0$。若从上面那块方程里解出 $x$ 并代入下面那块方程，得到 $v = B^{T} A^{-1} u + S y$，于是

```math
y = S^{-1} \left(v - B^{T} A^{-1} u\right).
```

把此式回代到第一个方程，得

```math
x = \left(A^{-1} + A^{-1} B S^{-1} B^{T} A^{-1}\right) u - A^{-1} B S^{-1} v.
```

这两个式子合起来就是分块矩阵求逆的公式：

```math
\begin{bmatrix} A & B \\ B^{T} & C \end{bmatrix}^{-1} = \begin{bmatrix} A^{-1} + A^{-1} B S^{-1} B^{T} A^{-1} & -A^{-1} B S^{-1} \\ -S^{-1} B^{T} A^{-1} & S^{-1} \end{bmatrix}.
```

特别地可见，Schur complement $S$ 正是 $X^{-1}$ 的 $(2,2)$ 分块之逆。这就是「Schur complement = 消元后剩下的那个算子」的代数表述：$y$ 的方程里 $B^T A^{-1} B$ 就是消掉 $x$ 时被扣掉的那一部分。

### Minimization and definiteness（极小化与定性）

Schur complement 还出现在「对一部分变量极小化一个二次型」的场合。设 $A \succ 0$，考虑极小化问题

```math
\text{minimize} \quad u^{T} A u + 2 v^{T} B^{T} u + v^{T} C v, \qquad (A.13)
```

变量为 $u$。其解为 $u = -A^{-1} B v$，最优值为

```math
\inf_{u} \begin{bmatrix} u \\ v \end{bmatrix}^{T} \begin{bmatrix} A & B \\ B^{T} & C \end{bmatrix} \begin{bmatrix} u \\ v \end{bmatrix} = v^{T} S v. \qquad (A.14)
```

由此可导出分块矩阵 $X$ 的正定 / 半正定的如下判据：

- $X \succ 0$ 当且仅当 $A \succ 0$ 且 $S \succ 0$。
- 若 $A \succ 0$，则 $X \succeq 0$ 当且仅当 $S \succeq 0$。



### Schur complement with singular A（$A$ 奇异时的 Schur complement）

部分 Schur complement 的结论可以推广到 $A$ 奇异的情形，只是细节更复杂。作为一个例子：若 $A \succeq 0$ 且 $B v \in \mathcal{R}(A)$，则二次极小化问题 (A.13)（变量为 $u$）可解，最优值为

```math
v^{T} \left(C - B^{T} A^{\dagger} B\right) v,
```

其中 $A^{\dagger}$ 是 $A$ 的 pseudo-inverse。若 $B v \notin \mathcal{R}(A)$，或 $A \not\succeq 0$，则该问题 unbounded（无界）。

对照 $A \succ 0$ 的 (A.14) 看：$v^T S v = v^T C v - v^T B^T A^{-1} B v$，中间那项由 $u^\star = -A^{-1}Bv$ 贡献。$A$ 奇异后 $A^{-1}$ 不存在，但极小化仍有解——只要 $Bv$ 落在 $A$ 的 range 里，沿 $A$ 零空间方向 $u$ 一动二次项为零而线性项不为零，唯一的选择是那一步不许动；用 $A^\dagger$ 正好实现这个「只沿非零特征方向取反」的操作。

range 条件 $B v \in \mathcal{R}(A)$ 也可写成 $(I - A A^{\dagger}) B v = 0$，于是得到分块矩阵 $X$ 半正定的如下判据：

```math
X \succeq 0 \iff A \succeq 0, \quad (I - A A^{\dagger}) B = 0, \quad C - B^{T} A^{\dagger} B \succeq 0.
```

这里矩阵 $C - B^{T} A^{\dagger} B$ 充当 $A$ 奇异时 Schur complement 的推广。三条缺一不可：少了第一条 $X \succeq 0$ 显然不成立；少了第二条（即 $B$ 的列必须落在 $\mathcal{R}(A)$ 里）就出现上面说的 unbounded 情形；少了第三条则 $(1,1)$ 与 $(2,2)$ 各自半正定而整体不定，例如 $\begin{bmatrix} 1 & 2 \\ 2 & 1 \end{bmatrix}$ 对角均为正而特征值为 $3, -1$。

## Appendix B · Problems involving two quadratic functions（含两个二次函数的问题）



本附录考虑若干涉及**两个**二次（但不必是 convex）函数的优化问题。这类问题有几个很强的结论成立，即便它们**不是**凸的。

这句开场值得停一下：为什么「两个二次函数」是一个独立的题材？因为约束的个数为 1 时，Lagrange 对偶的变量只有一个 $\lambda \ge 0$，于是对偶问题本身是一个「一维参数 + 一个矩阵不等式」的 SDP，可以画成一条关于 $\lambda$ 的曲线来读；而约束一旦变两个，对偶变量变成 $(\lambda_1,\lambda_2)$，结构立刻复杂化。B.2 的 S-procedure 处理的正是「两约束」的情形，且它只在二次这个特定代数结构下才有如此干净的形式。

### B.1 · Single constraint quadratic optimization（单约束二次优化）

考虑带一个约束的问题

```math
\begin{array}{ll}
\text{minimize} & x^{T} A_0 x + 2 b_0^{T} x + c_0 \\
\text{subject to} & x^{T} A_1 x + 2 b_1^{T} x + c_1 \le 0,
\end{array} \qquad (B.1)
```

变量为 $x \in \mathbf{R}^n$，问题参数 $A_i \in \mathbf{S}^n$、$b_i \in \mathbf{R}^n$、$c_i \in \mathbf{R}$。我们**不**假设 $A_i \succeq 0$，所以问题 (B.1) 不是凸优化问题。

(B.1) 的 Lagrangian 为

```math
L(x, \lambda) = x^{T} (A_0 + \lambda A_1) x + 2 (b_0 + \lambda b_1)^{T} x + c_0 + \lambda c_1,
```

关键在于 $\lambda$ 只与 $x$ 的二次项系数**相加**，并不产生新的交叉项——这是「只有一个约束」的直接后果，也是整个 B.1 能算出闭式对偶函数的原因。

dual function（对偶函数）为

```math
g(\lambda) = \inf_{x} L(x, \lambda) = \begin{cases} c_0 + \lambda c_1 - (b_0 + \lambda b_1)^{T} (A_0 + \lambda A_1)^{\dagger} (b_0 + \lambda b_1) & A_0 + \lambda A_1 \succeq 0, \ b_0 + \lambda b_1 \in \mathcal{R}(A_0 + \lambda A_1), \\ -\infty & \text{otherwise} \end{cases}
```

（见 §A.5.4 的 $p^{\star}$ 闭式）。这里的两个条件与 p649 那条 $p^{\star}$ 公式里的条件逐字对应：有效二次型系数 $A_0 + \lambda A_1$ 必须半正定，线性项系数必须落在它的 range 里，两条都满足时最优值是「常数项减去二次项贡献」。

利用 Schur complement，可把对偶问题写成

```math
\begin{array}{ll}
\text{maximize} & \gamma \\
\text{subject to} & \lambda \ge 0 \\
& \begin{bmatrix} A_0 + \lambda A_1 & b_0 + \lambda b_1 \\ (b_0 + \lambda b_1)^{T} & c_0 + \lambda c_1 - \gamma \end{bmatrix} \succeq 0,
\end{array} \qquad (B.2)
```



这是一个含两个变量 $\gamma, \lambda \in \mathbf{R}$ 的 SDP。

第一步变换的机制：把 $g(\lambda)$ 的分段表达式统一成一条 LMI。由 p650 的判据，$\begin{bmatrix} A & b \\ b^T & c - \gamma\end{bmatrix} \succeq 0$ 在 $A \succ 0$ 时当且仅当 $c - \gamma - b^T A^{-1} b \ge 0$，即 $\gamma \le c - b^T A^{-1} b$；而 $A$ 奇异的情形由 p651 的三条件版本接管，正好也覆盖了 $g(\lambda) = -\infty$ 的那些 $\lambda$。于是「最大化 $\gamma$」自动把 $\gamma$ 顶到 $g(\lambda)$，分段写法被一个半正定约束吸收。

第一个结果是：若 Slater's constraint qualification 成立，即存在 $x$ 使 $x^{T} A_1 x + 2 b_1^{T} x + c_1 \lt 0$，则问题 (B.1) 与其 Lagrange dual (B.2) 之间强对偶成立。换句话说，若 (B.1) 是 strictly feasible（严格可行）的，则 (B.1) 与 (B.2) 的最优值相等。（证明见 §B.4。）

注意这里强对偶成立**不要求凸性**——$A_0, A_1$ 可以不定。这是二次问题的特殊馈赠：对偶间隙为零的原因是「两约束的择一定理」在二次情形恰好无间隙，而不是因为凸性。

### Relaxation interpretation（松弛解释）

SDP (B.2) 的对偶是

```math
\begin{array}{ll}
\text{minimize} & \operatorname{tr}(A_0 X) + 2 b_0^{T} x + c_0 \\
\text{subject to} & \operatorname{tr}(A_1 X) + 2 b_1^{T} x + c_1 \le 0 \\
& \begin{bmatrix} X & x \\ x^{T} & 1 \end{bmatrix} \succeq 0,
\end{array} \qquad (B.3)
```

变量为 $X \in \mathbf{S}^n$、$x \in \mathbf{R}^n$ 的 SDP。这个对偶 SDP 有一个相对原问题 (B.1) 而言很有意思的解释。

先注意 (B.1) 等价于

```math
\begin{array}{ll}
\text{minimize} & \operatorname{tr}(A_0 X) + 2 b_0^{T} x + c_0 \\
\text{subject to} & \operatorname{tr}(A_1 X) + 2 b_1^{T} x + c_1 \le 0 \\
& X = x x^{T}.
\end{array} \qquad (B.4)
```

在这个写法里，把二次项 $x^{T} A_i x$ 写成 $\operatorname{tr}(A_i x x^{T})$，然后引入新变量 $X = x x^{T}$。问题 (B.4) 有一个线性目标函数、一个线性不等式约束、以及一个非线性等式约束 $X = x x^{T}$。下一步是把等式约束换成不等式 $X \succeq x x^{T}$：

```math
\begin{array}{ll}
\text{minimize} & \operatorname{tr}(A_0 X) + b_0^{T} x + c_0 \\
\text{subject to} & \operatorname{tr}(A_1 X) + b_1^{T} x + c_1 \le 0 \\
& X \succeq x x^{T}.
\end{array} \qquad (B.5)
```

<sup>†</sup> (B.5) 的两处线性项原文写成了 $b_0^{T} x$ 与 $b_1^{T} x$，漏掉系数 $2$。对照紧邻的 (B.3)、(B.4)（均写 $2 b_0^{T} x$、$2 b_1^{T} x$）以及 (B.1) 的 $2 b_0^T x$，可确证 (B.5) 应为 $2 b_0^{T} x$、$2 b_1^{T} x$；若照原样抄进代码，目标函数与约束的线性部分会整体缩水一半，输出的松弛值与真实值相差一个随着 $b$ 增大而增大的量。此处按标准结论重建为 $2b^{T}x$。

该问题称为 (B.4) 的 relaxation（松弛），因为把一个约束换成了更松的约束。最后注意到 (B.5) 中的不等式可利用 Schur complement 写成 linear matrix inequality，由此得到 (B.3)。

把 (B.3) 解释成 (B.1) 的松弛，立刻可以得到一批有意思的事实。第一，显然 (B.3) 的最优值小于或等于 (B.1) 的最优值，因为我们在一个更大的集合上极小化同一个目标函数。第二，可以断定：若在 (B.3) 的最优处有 $X = x x^{T}$，则对应的 $x$ 必在 (B.1) 中最优。

把上面的结果——(B.1) 与 (B.2) 之间强对偶成立（在 (B.1) 严格可行时）——与两个对偶 SDP (B.2)、(B.3) 之间的强对偶结合起来，可断定：原始的非凸二次问题 (B.1) 与 SDP relaxation (B.3) 之间强对偶成立，只要 (B.1) 严格可行。

这条结论之所以重要，是因为它在最优化文献里被反复借用：一个非凸 QCQP **只要只有一个二次约束**，就可以无损地（间隙为零）用 SDP 求解。约束个数从一增加到二，这个性质就立刻消失——那时一般需要 $(n+1)$ 维以上的 lifting，或引入 rank 条件。

### B.2 · The S-procedure（S-过程）

下一个结果是一对（非凸）二次不等式的 theorem of alternatives（择一定理）。设 $A_1, A_2 \in \mathbf{S}^n$、$b_1, b_2 \in \mathbf{R}^n$、$c_1, c_2 \in \mathbf{R}$，并设存在 $\hat{x}$ 使

```math
\hat{x}^{T} A_2 \hat{x} + 2 b_2^{T} \hat{x} + c_2 \lt 0.
```

则存在 $x \in \mathbf{R}^n$ 满足

```math
x^{T} A_1 x + 2 b_1^{T} x + c_1 \lt 0, \qquad x^{T} A_2 x + 2 b_2^{T} x + c_2 \le 0, \qquad (B.6)
```

**当且仅当**不存在 $\lambda$ 使

```math
\lambda \ge 0, \qquad \begin{bmatrix} A_1 & b_1 \\ b_1^{T} & c_1 \end{bmatrix} + \lambda \begin{bmatrix} A_2 & b_2 \\ b_2^{T} & c_2 \end{bmatrix} \succeq 0. \qquad (B.7)
```

换句话说，(B.6) 与 (B.7) 是 strong alternatives（强择一）：两者恰有一个成立，而且不是靠凸性，而是靠一个二次恒等式的代数结构。

这个结果很容易证明与 §B.1 的结果等价，证明见 §B.4。此处先指出：两个不等式系统显然是 weak alternatives（弱择一），因为 (B.6) 与 (B.7) 同时成立会导致矛盾：

```math
0 \le \begin{bmatrix} x \\ 1 \end{bmatrix}^{T} \left( \begin{bmatrix} A_1 & b_1 \\ b_1^{T} & c_1 \end{bmatrix} + \lambda \begin{bmatrix} A_2 & b_2 \\ b_2^{T} & c_2 \end{bmatrix} \right) \begin{bmatrix} x \\ 1 \end{bmatrix} = x^{T} A_1 x + 2 b_1^{T} x + c_1 + \lambda \left(x^{T} A_2 x + 2 b_2^{T} x + c_2\right) \lt 0.
```

矛盾的两端分别是「半正定二次型取非负」与「严格负 + 非正」；中间那个 $[x;1]$ 的齐次化写法是全部技巧所在，它把「二次式 + 线性项 + 常数」三件东西压成一次内积。

该择一定理有时被称为 S-procedure，通常以下面的形式陈述：蕴含

```math
x^{T} F_1 x + 2 g_1^{T} x + h_1 \le 0 \quad \Longrightarrow \quad x^{T} F_2 x + 2 g_2^{T} x + h_2 \le 0,
```

其中 $F_i \in \mathbf{S}^n$、$g_i \in \mathbf{R}^n$、$h_i \in \mathbf{R}$，成立当且仅当存在 $\lambda$ 使

```math
\lambda \ge 0, \qquad \begin{bmatrix} F_2 & g_2 \\ g_2^{T} & h_2 \end{bmatrix} \preceq \lambda \begin{bmatrix} F_1 & g_1 \\ g_1^{T} & h_1 \end{bmatrix},
```

前提是存在点 $\hat{x}$ 使 $\hat{x}^{T} F_1 \hat{x} + 2 g_1^{T} \hat{x} + h_1 \lt 0$。（注意充分性显然：把两个二次型分别展开代入即可。）这个等价说法的用法与 (B.6)/(B.7) 相反——它把「对每个 $x$ 都要成立的一个蕴含」换成了「存在一个 $\lambda$」的有限维可行性问题。方向的转换是这套工具的唯一价值：左边是无穷多条蕴含，右边是一个矩阵不等式。

### Example B.1 · Ellipsoid containment（椭球包含）

内部非空的椭球 $\mathcal{E} \subseteq \mathbf{R}^n$ 可表示为某个二次函数的下水平集：

```math
\mathcal{E} = \{x \mid x^{T} F x + 2 g^{T} x + h \le 0\},
```

其中 $F \in \mathbf{S}^n_{++}$、$h - g^{T} F^{-1} g \lt 0$。设 $\tilde{\mathcal{E}}$ 是另一个类似表示的椭球，

```math
\tilde{\mathcal{E}} = \{x \mid x^{T} \tilde{F} x + 2 \tilde{g}^{T} x + \tilde{h} \le 0\},
```

其中 $\tilde{F} \in \mathbf{S}^n_{++}$、$\tilde{h} - \tilde{g}^{T} \tilde{F}^{-1} \tilde{g} \lt 0$。由 S-procedure 可知，$\mathcal{E} \subseteq \tilde{\mathcal{E}}$ 当且仅当存在 $\lambda \gt 0$ 使

```math
\begin{bmatrix} \tilde{F} & \tilde{g} \\ \tilde{g}^{T} & \tilde{h} \end{bmatrix} \preceq \lambda \begin{bmatrix} F & g \\ g^{T} & h \end{bmatrix}.
```

这条判据把「两个椭球的包含关系」从一个带量词的几何陈述（对每个 $x$，若 $x$ 在 $\mathcal{E}$ 里则 $x$ 在 $\tilde{\mathcal{E}}$ 里）化成了一条 LMI 的可行性。注意 $h - g^T F^{-1} g \lt 0$ 这个条件正是「内部非空」的判据：椭球的中心是 $-F^{-1}g$，把 $x = -F^{-1}g$ 代入二次式得 $h - g^T F^{-1}g$，它必须严格小于零，椭球才有内点。

<span style="color:#1e8449;">**[译注]** (B.7) 那条 LMI 的形状值得单独读一遍：它要求 $\begin{bmatrix} A_1 & b_1 \\ b_1^{T} & c_1\end{bmatrix} + \lambda \begin{bmatrix} A_2 & b_2 \\ b_2^{T} & c_2\end{bmatrix} \succeq 0$，也就是**两个二次型的矩阵表示必须按同一个 $\lambda$ 线性拼起来**。这就是为什么 S-procedure 在控制里被反复警告「两个约束时才无损，三个以上就保守」。

落点：Boyd §B.2（本页）、§B.4 的证明、Example B.1；线性代数侧挂 joint diagonalization（Calabi [Cal64]、Uhlig [Uhl79]，p659 已列）。</span>



### B.3 · The field of values of two symmetric matrices（两个对称矩阵的值域）

下面这个结果是 §B.1 强对偶结论与 §B.2 S-procedure 的证明基础。若 $A, B \in \mathbf{S}^n$，则对任意 $X \in \mathbf{S}^n_{+}$，存在 $x \in \mathbf{R}^n$ 使

```math
x^{T} A x = \operatorname{tr}(A X), \qquad x^{T} B x = \operatorname{tr}(B X). \qquad (B.8)
```

一般情形下这件事是**假**的：给定 $X \in \mathbf{S}^n_{+}$，一般找不到单个 $x$ 使两个二次型同时配对。$n$ 个自由度的 $x$ 要满足两个方程看起来应该有余量，实际问题在于 $x$ 只能给出 rank-one 的 $X$，而给定 $X$ 的秩可能远大于一。定理说的是：在「只关心两个二次型」这个二维投影下，秩一不足的困难恰好不出现。

**Remark B.1 · 几何解释。** 这个结果对集合

```math
W(A, B) = \left\{\left(x^{T} A x,\, x^{T} B x\right) \mid x \in \mathbf{R}^n\right\}
```

有一个有意思的解释，它是 $\mathbf{R}^2$ 中的一个锥。它是由集合

```math
F(A, B) = \left\{\left(x^{T} A x,\, x^{T} B x\right) \mid \|x\|_2 = 1\right\}
```

生成的锥，后者称为矩阵对 $(A, B)$ 的 2-dimensional field of values（二维值域）。几何上，$W(A, B)$ 是 rank-one 半正定矩阵之集在线性变换 $f : \mathbf{S}^n \to \mathbf{R}^2$ 下的像，其中

```math
f(X) = \left(\operatorname{tr}(A X),\, \operatorname{tr}(B X)\right).
```

「对每个 $X \in \mathbf{S}^n_{+}$ 都存在 $x$ 满足 (B.8)」这一结论意味着

```math
W(A, B) = f\left(\mathbf{S}^n_{+}\right).
```

换句话说，$W(A, B)$ 是凸锥。**这一步才是 S-procedure 成立的全部秘密**：$f$ 把凸集 $\mathbf{S}^n_+$ 线性映到 $\mathbf{R}^2$，像是凸的；而 $W$ 的定义里只有 rank-one 点，本来没有理由凸。等式 $W = f(\mathbf{S}^n_+)$ 说「rank-one 点已经铺满了整个像」。

该证明是构造性的，对 $X$ 的秩做归纳。设命题对所有满足 $1 \le \operatorname{rank} X \le k$ 的 $X \in \mathbf{S}^n_{+}$ 成立（其中 $k \ge 2$），即存在 $x$ 使 (B.8) 成立。则当 $\operatorname{rank} X = k + 1$ 时结论仍成立，理由如下。秩为 $k+1$ 的 $X \in \mathbf{S}^n_{+}$ 可写成 $X = y y^{T} + Z$，其中 $y \neq 0$、$Z \in \mathbf{S}^n_{+}$ 且 $\operatorname{rank} Z = k$。按归纳假设，存在 $z$ 使 $\operatorname{tr}(A Z) = z^{T} A z$、$\operatorname{tr}(B Z) = z^{T} B z$。于是

```math
\operatorname{tr}(A X) = \operatorname{tr}\left(A (y y^{T} + z z^{T})\right), \qquad \operatorname{tr}(B X) = \operatorname{tr}\left(B (y y^{T} + z z^{T})\right).
```

而 $y y^{T} + z z^{T}$ 的秩为一或二，故再次由归纳假设，存在 $x$ 使 (B.8) 成立。

因此只需对 $\operatorname{rank} X \le 2$ 证明该结论。$\operatorname{rank} X = 0$ 与 $\operatorname{rank} X = 1$ 时无需证明（此时 $X = xx^T$ 或 $X = 0$，取对应的 $x$ 即可）。$\operatorname{rank} X = 2$ 时，可把 $X$ 分解为 $X = V V^{T}$，其中 $V \in \mathbf{R}^{n \times 2}$，两列 $v_1, v_2$ 线性无关。不妨设 $V^{T} A V$ 为对角阵（若 $V^{T} A V$ 非对角，就把 $V$ 换成 $V P$，其中 $V^{T} A V = P \operatorname{diag}(\lambda) P^{T}$ 是 $V^{T} A V$ 的 eigenvalue decomposition）。于是可把 $V^{T} A V$ 与 $V^{T} B V$ 写成

```math
V^{T} A V = \begin{bmatrix} \lambda_1 & 0 \\ 0 & \lambda_2 \end{bmatrix}, \qquad V^{T} B V = \begin{bmatrix} \sigma_1 & \gamma \\ \gamma & \sigma_2 \end{bmatrix},
```

并定义

```math
w = \begin{bmatrix} \operatorname{tr}(A X) \\ \operatorname{tr}(B X) \end{bmatrix} = \begin{bmatrix} \lambda_1 + \lambda_2 \\ \sigma_1 + \sigma_2 \end{bmatrix}.
```



需要证明存在某个 $x$ 使 $w = (x^{T} A x, x^{T} B x)$。

分两种情形。第一，设 $(0, \gamma)$ 是向量 $(\lambda_1, \sigma_1)$ 与 $(\lambda_2, \sigma_2)$ 的线性组合：

```math
0 = z_1 \lambda_1 + z_2 \lambda_2, \qquad \gamma = z_1 \sigma_1 + z_2 \sigma_2,
```

其中 $z_1, z_2$ 为某两个数。此时取 $x = \alpha v_1 + \beta v_2$，其中 $\alpha$ 与 $\beta$ 由求解如下两个二元二次方程确定：

```math
\alpha^{2} + 2 \alpha \beta z_1 = 1, \qquad \beta^{2} + 2 \alpha \beta z_2 = 1. \qquad (B.9)
```

这样即得到所需结论，因为

```math
\begin{aligned}
\begin{bmatrix} (\alpha v_1 + \beta v_2)^{T} A (\alpha v_1 + \beta v_2) \\ (\alpha v_1 + \beta v_2)^{T} B (\alpha v_1 + \beta v_2) \end{bmatrix} &= \alpha^{2} \begin{bmatrix} \lambda_1 \\ \sigma_1 \end{bmatrix} + 2 \alpha \beta \begin{bmatrix} 0 \\ \gamma \end{bmatrix} + \beta^{2} \begin{bmatrix} \lambda_2 \\ \sigma_2 \end{bmatrix} \\
&= \left(\alpha^{2} + 2 \alpha \beta z_1\right) \begin{bmatrix} \lambda_1 \\ \sigma_1 \end{bmatrix} + \left(\beta^{2} + 2 \alpha \beta z_2\right) \begin{bmatrix} \lambda_2 \\ \sigma_2 \end{bmatrix} \\
&= \begin{bmatrix} \lambda_1 + \lambda_2 \\ \sigma_1 + \sigma_2 \end{bmatrix}.
\end{aligned}
```

剩下的问题是证明方程 (B.9) 可解。先注意 $\alpha$ 与 $\beta$ 必须非零，因此可把方程等价地写成

```math
\alpha^{2}\left(1 + 2 (\beta / \alpha) z_1\right) = 1, \qquad (\beta / \alpha)^{2} + 2 (\beta / \alpha) (z_2 - z_1) = 1.
```

方程 $t^{2} + 2 t (z_2 - z_1) = 1$ 有一正根与一负根。这两个根中至少有一个（即与 $z_1$ 同号的那个）满足 $1 + 2 t z_1 \gt 0$，于是可取

```math
\alpha = \pm 1 / \sqrt{1 + 2 t z_1}, \qquad \beta = t \alpha.
```

这给出两个满足 (B.9) 的解 $(\alpha, \beta)$。（若 $t^{2} + 2t(z_2 - z_1) = 1$ 的两个根都满足 $1 + 2 t z_1 \gt 0$，则得到四个解。）

这一段的技术点是「至少有一个根可用」而不是「所有根都可用」：$1 + 2tz_1$ 必须为正才能开平方，而 $t$ 的两根异号、$z_1$ 定号，于是与 $z_1$ 同号的那个根给出 $2tz_1 \gt 0$，保证开方合法。这就是为什么原文要强调「the root with the same sign as $z_1$」。

接下来，设 $(0, \gamma)$ **不是** $(\lambda_1, \sigma_1)$ 与 $(\lambda_2, \sigma_2)$ 的线性组合。特别地，这意味着 $(\lambda_1, \sigma_1)$ 与 $(\lambda_2, \sigma_2)$ 线性相关。因此它们的和 $w = (\lambda_1 + \lambda_2, \sigma_1 + \sigma_2)$ 是 $(\lambda_1, \sigma_1)$ 或 $(\lambda_2, \sigma_2)$（或两者）的非负倍数。若 $w = \alpha^{2}(\lambda_1, \sigma_1)$，取 $x = \alpha v_1$；若 $w = \beta^{2}(\lambda_2, \sigma_2)$，取 $x = \beta v_2$。

### B.4 · Proofs of the strong duality results（强对偶结论的证明）

先证明 §B.2 给出的 S-procedure 结果。$\hat{x}$ 严格可行的假设蕴含矩阵

```math
\begin{bmatrix} A_2 & b_2 \\ b_2^{T} & c_2 \end{bmatrix}
```



至少有一个负特征值。因此

```math
\tau \ge 0, \quad \tau \begin{bmatrix} A_2 & b_2 \\ b_2^{T} & c_2 \end{bmatrix} \succeq 0 \quad \Longrightarrow \quad \tau = 0.
```

这个观察的作用是排除「$\tau$ 可以取正」这一支：$\tau \gt 0$ 时 $\tau M_2$ 的特征值与 $M_2$ 同号，既然 $M_2$ 有负特征值，$\tau M_2$ 就不可能半正定，故只有 $\tau = 0$ 可行。

可以应用 example 5.14 中关于非严格 linear matrix inequality 的择一定理，它断言：(B.7) 不可行当且仅当

```math
X \succeq 0, \quad \operatorname{tr}\left(X \begin{bmatrix} A_1 & b_1 \\ b_1^{T} & c_1 \end{bmatrix}\right) \lt 0, \quad \operatorname{tr}\left(X \begin{bmatrix} A_2 & b_2 \\ b_2^{T} & c_2 \end{bmatrix}\right) \le 0
```

是可行的。由 §B.3 的结果，这等价于下述可行性：

```math
\begin{bmatrix} v \\ w \end{bmatrix}^{T} \begin{bmatrix} A_1 & b_1 \\ b_1^{T} & c_1 \end{bmatrix} \begin{bmatrix} v \\ w \end{bmatrix} \lt 0, \qquad \begin{bmatrix} v \\ w \end{bmatrix}^{T} \begin{bmatrix} A_2 & b_2 \\ b_2^{T} & c_2 \end{bmatrix} \begin{bmatrix} v \\ w \end{bmatrix} \le 0.
```

这一步是 (B.8) 的直接应用：把 $X$ 上的两条迹不等式换成同一对 $(v, w)$ 上的两条二次型不等式，秩一性由 §B.3 保证存在。

若 $w \neq 0$，则 $x = v / w$ 在 (B.6) 中可行（把 $[v;w]$ 整体除以 $w$，齐次化后正好还原成 $[x;1]$）。若 $w = 0$，则有 $v^{T} A_1 v \lt 0$、$v^{T} A_2 v \le 0$，于是 $x = \hat{x} + t v$ 满足

```math
\begin{aligned}
x^{T} A_1 x + 2 b_1^{T} x + c_1 &= \hat{x}^{T} A_1 \hat{x} + 2 b_1^{T} \hat{x} + c_1 + t^{2} v^{T} A_1 v + 2 t (A_1 \hat{x} + b_1)^{T} v, \\
x^{T} A_2 x + 2 b_2^{T} x + c_2 &= \hat{x}^{T} A_2 \hat{x} + 2 b_2^{T} \hat{x} + c_2 + t^{2} v^{T} A_2 v + 2 t (A_2 \hat{x} + b_2)^{T} v \\
&\lt 2 t (A_2 \hat{x} + b_2)^{T} v,
\end{aligned}
```

也就是说，取决于 $(A_2 \hat{x} + b_2)^{T} v$ 的符号，当 $t \to \pm\infty$ 时 $x$ 变得可行。这一支的几何含义：$w = 0$ 意味着可行方向在「常数层」上没有分量，故要顺着一条射线走到无穷远处才把第二个二次型压到负值以下。

最后证明 §B.1 的结果，即：若 (B.1) 严格可行，则 (B.1) 与 (B.2) 的最优值相等。为此注意到，若

```math
x^{T} A_1 x + b_1^{T} x + c_1 \le 0 \quad \Longrightarrow \quad x^{T} A_0 x + b_0^{T} x + c_0 \ge \gamma,
```

<sup>†</sup> 此处两个二次型原文同样漏掉线性项的系数 $2$（应与 (B.1) 的 $2b_0^{T}x$、$2b_1^{T}x$ 一致）。这是 (B.5) 处同一笔误的第二处；两处合起来看，凡在 §B.1 后续推导中把 $2b^{T}x$ 写成 $b^{T}x$ 的地方，都应照 (B.1) 的标准形式补齐。

则 $\gamma$ 是 (B.1) 最优值的一个下界。由 S-procedure，这一点成立当且仅当存在 $\lambda \ge 0$ 使

```math
\begin{bmatrix} A_0 & b_0 \\ b_0^{T} & c_0 - \gamma \end{bmatrix} + \lambda \begin{bmatrix} A_1 & b_1 \\ b_1^{T} & c_1 \end{bmatrix} \succeq 0,
```

即 $\gamma, \lambda$ 在 (B.2) 中可行。这就闭合了整个循环：B.1 的强对偶 ⇒ B.2 的择一定理 ⇒ B.3 的 (B.8) ⇒ B.4 的证明，四条互相支撑，缺任何一条都断链。

### C.1 · Matrix structure and algorithm complexity（矩阵结构与算法复杂度）

我们集中讨论求解线性方程组

```math
A x = b \qquad (C.1)
```

的方法，其中 $A \in \mathbf{R}^{n \times n}$、$b \in \mathbf{R}^{n}$。假设 $A$ 非奇异，故对任意 $b$ 解唯一，且由 $x = A^{-1} b$ 给出。这个基本问题出现在许多优化算法中，往往占据计算量的大部分。在求解线性方程 (C.1) 的语境下，矩阵 $A$ 常称为 coefficient matrix（系数矩阵），向量 $b$ 称为 righthand side（右端项）。

求解 (C.1) 的标准通用方法所需的计算量大约按 $n^{3}$ 增长。这些方法对 $A$ 的假设仅是非奇异，因此一般适用。当 $n$ 为几百或更小时，除最苛刻的实时应用之外，这些通用方法大概就是该用的方法。当 $n$ 超过一千左右，求解 $A x = b$ 的通用方法就变得不那么实用了。

「一千左右」这个门槛不是随意给的：$n = 1000$ 时 $n^3 = 10^{9}$，按当代单核 $10^{10}$ flop/s 量级算约 $0.1$ 秒，看起来还能忍；但 $n$ 再翻十倍到 $10^{4}$ 就是 $10^{12}$ flops，约 $100$ 秒，而实际优化问题里 $n = 10^{4}$ 只是中等规模。门槛真正的位置由「$n^3$ 的增长速度」与「问题规模的实际分布」共同决定，不是由某一台机器的常数决定。



### Coefficient matrix structure（系数矩阵的结构）

许多情形下 coefficient matrix $A$ 具有某种特殊结构或形式，可以利用针对该结构的专门方法来更高效地求解 $A x = b$。

例如，在 Newton system $\nabla^{2} f(x) \Delta x_{\text{nt}} = -\nabla f(x)$ 中，系数矩阵是对称正定的，这允许我们用一个比通用方法快约两倍的解法（并且舍入误差（roundoff）性质也更好）。还有许多其他类型可被利用的结构，其计算节省（或算法加速）通常远超两倍。很多情形下计算量降到正比于 $n^{2}$ 甚至 $n$，相比之下通用方法要 $n^{3}$。由于这些方法通常用在 $n$ 至少一百、且常常远大于一百的场合，节省可以非常可观。

可被利用的系数矩阵结构种类繁多。与 sparsity pattern（稀疏模式，即矩阵中零元素与非零元素的分布）有关的简单例子包括 banded（带状）、block diagonal（分块对角）、以及 sparse（稀疏）矩阵。更微妙的一种可利用结构是 diagonal plus low rank（对角加低秩）。许多常见形式的凸优化问题导出的线性方程，其系数矩阵正具有这些可利用结构。（此外还有许多可被利用的矩阵结构，例如 Toeplitz、Hankel、circulant（循环）矩阵，本附录不予讨论。）

「diagonal plus low rank」值得单独记一笔，因为它是 §11.x 里最常出现的形状：目标函数的 Hessian 常写成 $H = D + U C U^{T}$，其中 $D$ 对角、$U$ 只有 $p$ 列、$p \ll n$。此时用 Sherman-Morrison-Woodbury 公式，把 $n \times n$ 的求逆变成 $p \times p$ 的求逆，代价从 $O(n^{3})$ 降到 $O(n p^{2} + p^{3})$。

我们把不利用矩阵中任何稀疏模式的通用方法称为针对 dense matrices（稠密矩阵）的方法；把完全不利用矩阵中任何结构的方法称为针对 unstructured matrices（无结构矩阵）的方法。注意这两个称呼都针对「方法」，不是针对矩阵：同一个矩阵，用带 pivoting 的稠密 LU 解是 dense 方法，用稀疏消去解就是 sparse 方法。

### C.1.1 · Complexity analysis via flop count（用 flop 数做复杂度分析）

数值线性代数算法的代价，常用执行它所需的 floating-point operations（浮点运算）总数来表示，写成各问题维数的函数。我们定义一个 flop 为两个浮点数的**一次**加、减、乘、或除。（有些作者把 flop 定义为一个乘法后接一个加法，故其 flop 数比我们的最多小两倍。）为评估算法复杂度，我们数出总 flop 数，把它写成所涉矩阵与向量维数的函数（通常是多项式），再通过忽略除首项（即最高阶或主导项）之外的所有项来化简表达式。

作为例子，设某算法总共需要

```math
m^{3} + 3 m^{2} n + m n + 4 m n^{2} + 5 m + 22
```

个 flop，其中 $m$ 与 $n$ 是问题维数。通常会把这个 flop 数化简为

```math
m^{3} + 3 m^{2} n + 4 m n^{2}
```

个 flop，因为它们是问题维数 $m$ 与 $n$ 的高阶项。若此外再假设 $m \ll n$，则会进一步把 flop 数化简为 $4 m n^{2}$。



flop 数在浮点运算相对缓慢的年代流行起来，那时数一数运算次数就能很好地估计总计算时间。情况已不再如此：cache boundaries（缓存边界）与 locality of reference（引用局部性）这类问题能显著影响数值算法的计算时间。不过 flop 数仍能给出数值算法计算时间的一个不错粗略估计，以及时间如何随问题规模增长。既然 flop 数不再能准确预测算法的计算时间，我们通常最关注它的阶（order），即最大的那些指数，而忽略 flop 数中小于约两倍的差别。例如，flop 数为 $5 n^{2}$ 的算法被认为与 flop 数为 $4 n^{2}$ 的算法相当，但比 flop 数为 $(1/3) n^{3}$ 的算法快。

「小于约两倍不算差别」这条约定有明确的来源：同一 flop 数的两个实现在真实机器上差 2 倍是常态（向量化、寄存器分配、循环顺序都能造成），而阶的差别在 $n$ 增大时会单调放大，无法用实现技巧追平。所以 $5n^{2}$ 与 $4n^{2}$ 之争要靠工程手段解决，$n^{2}$ 与 $n^{3}$ 之争要靠换算法。

<!-- ===== p663 · 续 · 译注 ===== -->

<span style="color:#1e8449;">**[译注]** p663 那句「flop 数不再能准确预测计算时间」是本附录唯一一处作者主动放弃自己的度量，值得把它当成一条工程纪律来读，而不是一段免责声明。

机制在存储层次上：一个 $n \times n$ 矩阵乘法的 flop 数恒为 $2n^{3}$，但实际耗时取决于每一个操作数是否已经在 cache 里。按行主序朴素三重循环，内层每次都要跨 $n$ 个元素取 $B$ 的一列，cache line 命中率极低；改成按块（block）分块，使每块放得进 L1，同一批数据被复用 $\sqrt{n}$ 次，flop 数**完全相同**而实测可以差 2 到 10 倍。这就是 $5n^{2}$ 与 $4n^{2}$ 被作者判为「相当」而 $n^{2}$ 与 $n^{3}$ 必须分开的原因。

量的方向可以给一个本机可复核的例子：在同一台机器上对 102 MB 文本数关键字，`bytes.count`（C 层、顺序扫描、cache 友好）耗时 12 ms，而 PowerShell 的 `Select-String`（逐行解释执行、反复分配）耗时 2754 ms——**229 倍**，两者的「运算次数」在同一量级。可见 flop 数只约束了增长阶，不约束常数。

消失测试：若只按 flop 数选算法，实践中会在两个方向上都吃亏。一是选了理论最优而访存极差的实现（如朴素 Strassen 在小 $n$ 上反而不如朴素乘法，因为其递归边界与 cache 不匹配）；二是把 $5n^2$ 与 $4n^2$ 的实现优劣当成结论去优化，浪费的工程量与收益之比极差。

落点：Boyd §C.1.1（本页）；CSAPP 第 6 章 storage hierarchy（cache line 与 locality）；BLAS 的 `dgemm` 分块实现是最直接的可读实例。</span>


### C.1.2 · Cost of basic matrix-vector operations（基本矩阵-向量运算的代价）

**Vector operations（向量运算）。** 为计算两个向量 $x, y \in \mathbf{R}^{n}$ 的内积 $x^{T} y$，我们逐项形成乘积 $x_i y_i$ 再把它们加起来，这需要 $n$ 次乘法与 $n - 1$ 次加法，即 $2 n - 1$ 个 flop。如上所述，我们只保留首项，于是说内积需要 $2 n$ 个 flop，或者更粗略地说需要 order $n$ 个 flop。scalar-vector multiplication（标量-向量乘法）$\alpha x$，其中 $\alpha \in \mathbf{R}$、$x \in \mathbf{R}^{n}$，需要 $n$ 个 flop。两个向量 $x, y \in \mathbf{R}^{n}$ 的加法 $x + y$ 也需要 $n$ 个 flop。

若向量 $x$ 与 $y$ 是稀疏的，即只有少数非零项，则这些基本运算可以更快完成（假设向量用合适的数据结构存储）。例如，若 $x$ 是有 $N$ 个非零元的稀疏向量，则内积 $x^{T} y$ 可用 $2 N$ 个 flop 算出。

**Matrix-vector multiplication（矩阵-向量乘法）。** 矩阵-向量乘法 $y = A x$，其中 $A \in \mathbf{R}^{m \times n}$，需要 $2 m n$ 个 flop：我们要算出 $y$ 的 $m$ 个分量，每个分量是 $A$ 的一行与 $x$ 的乘积，即 $\mathbf{R}^{n}$ 中两个向量的内积。

矩阵-向量乘法常常可以通过利用 $A$ 的结构来加速。例如，若 $A$ 是对角阵，则 $A x$ 可用 $n$ 个 flop 算出，而乘以一个一般的 $n \times n$ 矩阵要 $2 n^{2}$ 个 flop。更一般地，若 $A$ 稀疏、只有 $N$ 个非零元（总共 $m n$ 个位置），则形成 $A x$ 需要 $2 N$ 个 flop，因为与零相乘、相加都可以跳过。

作为不那么显然的例子，设矩阵 $A$ 的秩为 $p \ll \min\{m, n\}$，并以分解形式 $A = U V$ 表示（存储），其中 $U \in \mathbf{R}^{m \times p}$、$V \in \mathbf{R}^{p \times n}$。此时可以这样算 $A x$：先算 $V x$（需 $2 p n$ 个 flop），再算 $U (V x)$（需 $2 m p$ 个 flop），故总共 $2 p (m + n)$ 个 flop。由于 $p \ll \min\{m, n\}$，这与 $2 m n$ 相比很小。

**Matrix-matrix multiplication（矩阵-矩阵乘法）。** 矩阵-矩阵乘积 $C = A B$，其中 $A \in \mathbf{R}^{m \times n}$、$B \in \mathbf{R}^{n \times p}$，需要 $2 m n p$ 个 flop。$C$ 中有 $m p$ 个元素要算，每个是



两个长度为 $n$ 的向量的内积。同样，常常可以通过利用 $A$ 与 $B$ 的结构实现可观的节省。例如，若 $A$ 与 $B$ 稀疏，则可以跳过与零的加法与乘法来加速乘法。

若 $m = p$ 且已知 $C$ 对称，则可用 $m^{2} n$ 个 flop 算出该矩阵乘积，因为只需计算下三角部分中的 $(1/2) m (m + 1)$ 个元素。

为形成多个矩阵的乘积，可以用不同方式依次做矩阵-矩阵乘法，它们的 flop 数一般不同。最简单的例子是计算乘积 $D = A B C$，其中 $A \in \mathbf{R}^{m \times n}$、$B \in \mathbf{R}^{n \times p}$、$C \in \mathbf{R}^{p \times q}$。这里可以用两种方式通过两次矩阵-矩阵乘法算出 $D$。一种方法是先形成乘积 $A B$（$2 m n p$ 个 flop），再形成 $D = (A B) C$（$2 m p q$ 个 flop），故总共 $2 m p (n + q)$ 个 flop。另一种方法是先形成乘积 $B C$（$2 n p q$ 个 flop），再形成 $D = A (B C)$（$2 m n q$ 个 flop），总共 $2 n q (m + p)$ 个 flop。当 $2 m p (n + q) \lt 2 n q (m + p)$，即

```math
\frac{1}{n} + \frac{1}{q} \lt \frac{1}{m} + \frac{1}{p}
```

时，第一种方法更好。这假设在做矩阵-矩阵乘积时不利用矩阵的任何结构。

注意这个判据的形状：两边都是「两个倒数之和」，比较的是**哪一侧的中间矩阵更大**。把 $D = ABC$ 想成「先合并小的那个中间维度」——$(AB)$ 的中间维度是 $p$，$(BC)$ 的中间维度是 $n$，故当 $p \lt n$ 且 $q, m$ 差不多时先乘 $AB$ 更省。这是乘法结合律与 flop 计数的直接后果，与矩阵内容无关，可以纯看形状决定。

对于三个以上矩阵的乘积，把乘积解析成一系列矩阵-矩阵乘法的方式有很多。虽然给定矩阵维数后，写一个确定最优解析（即所需 flop 数最少）的算法并不困难，但在多数应用中最优解析是显然的。

### C.2 · Solving linear equations with factored matrices（用分解后的矩阵解线性方程）

### C.2.1 · Linear equations that are easy to solve（易于求解的线性方程）

我们先考察若干 $A x = b$ 易于求解、即 $x = A^{-1} b$ 易于计算的情形。

**Diagonal matrices（对角矩阵）。** 设 $A$ 对角且非奇异（即对所有 $i$ 有 $a_{ii} \neq 0$）。线性方程组 $A x = b$ 可写成 $a_{ii} x_i = b_i$，$i = 1, \ldots, n$。解由 $x_i = b_i / a_{ii}$ 给出，可用 $n$ 个 flop 算出。

**Lower triangular matrices（下三角矩阵）。** 称 $A \in \mathbf{R}^{n \times n}$ 为 lower triangular，若 $j \gt i$ 时 $a_{ij} = 0$。若对角元全等于一，则称下三角矩阵为 unit lower triangular（单位下三角）。下三角矩阵非奇异当且仅当对所有 $i$ 有 $a_{ii} \neq 0$。
