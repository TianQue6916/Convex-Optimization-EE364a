# 凸优化 题解目录说明

## HW 解答：两版并存（同一份 PDF 的两次渲染，题号完全一致）

| 文件 | 特点 | 何时用 |
|---|---|---|
| `HWn 解答（双语对照）.md` | 保留英文原文 + 彩色 `<span>` 结构 + `[note] 译者注`（5 行/篇） | 想对照原文、看术语怎么落地时 |
| `HWn 解答（纯中文）.md` | 纯中文译文 + `† 原文 typo` 注解 + 来源块 | 只想快速看懂解法时 |

两版 containment 实测 0.26–0.40（不是同一文本的短长版，而是「留英文」vs「全译中文」两种呈现），
故并列保留，不互相覆盖。要合并需逐段对读，属另一轮工作。
