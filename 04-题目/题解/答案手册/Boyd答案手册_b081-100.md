### Exercise 4.8 (a) 续：仿射集上的线性函数最小化

**（三种情形的收尾）**

- **情形一：问题不可行**，即 $b \notin R(A)$（$R(A)$ 记 $A$ 的 range（值域））。此时最优值取 $p^\star = +\infty$。

- **情形二：问题可行，且 $c$ 与 $A$ 的 nullspace（零空间）正交。** 此时可把 $c$ 分解为

```math
c = A^{T}\lambda + \hat{c}, \qquad A\hat{c} = 0 .
```

其中 $\hat{c}$ 是 $c$ 落在 $A$ 的 nullspace 里的分量，而 $A^{T}\lambda$ 与 nullspace 正交。若 $\hat{c} = 0$，则在可行集上目标函数退化为一个常数：

```math
c^{T}x = \lambda^{T}Ax + \hat{c}^{T}x = \lambda^{T}b .
```

于是最优值为 $\lambda^{T}b$，并且**所有可行解都是最优解**。

- **情形三：问题可行，而 $c$ 不在 $A^{T}$ 的 range 中（即 $\hat{c} \neq 0$）。** 此时问题 unbounded（无界），$p^\star = -\infty$。验证办法：取 $x = x_0 - t\hat{c}$，它对一切 $t$ 都可行（因为 $A\hat{c} = 0$，$Ax = Ax_0 = b$）；令 $t \to \infty$，目标值无界下降（因为 $c^{T}\hat{c} = \|\hat{c}\|_2^{2} \gt 0$）。

汇总起来：

```math
p^\star = \begin{cases}
+\infty, & b \notin R(A),\\
\lambda^{T}b, & c = A^{T}\lambda \ \text{for some } \lambda,\\
-\infty, & \text{otherwise}.
\end{cases}
```

> 逐条复算：情形一的 $+\infty$ 是「不可行」的常规约定；情形二把 $c^{T}x$ 在两行内化掉，靠的正是 $Ax = b$；情形三的构造 $x_0 - t\hat{c}$ 只用到 $A\hat{c} = 0$，$t$ 可任意大，所以确实无界。三段都对，**此处原文无误**。

### Exercise 4.8 (b) 在 halfspace 上最小化线性函数

> 话题：单条半空间约束下的 LP，答案是「要么 $-a$ 方向跑到无穷，要么最优值就是 $\lambda b$」——几何上就是看 $c$ 与约束法向 $a$ 的夹角。

```math
\begin{aligned}
\text{minimize}\quad & c^{T}x \\
\text{subject to}\quad & a^{T}x \le b,
\end{aligned}
```

其中 $a \neq 0$。

**Solution.** 这个问题总是可行的（任何 $a \neq 0$ 的半空间都非空）。可以把 $c$ 分解为平行于 $a$ 的分量加上正交于 $a$ 的分量：

```math
c = a\lambda + \hat{c}, \qquad a^{T}\hat{c} = 0 .
```

- **若 $\lambda \gt 0$，问题下方无界。** 取 $x = -ta$，令 $t \to \infty$：

```math
c^{T}x = -t\,c^{T}a = -t\lambda a^{T}a \to -\infty
```

同时

```math
a^{T}x - b = -t\,a^{T}a - b \le 0
```

对足够大的 $t$ 成立，所以 $x$ 对大的 $t$ 是可行的。直觉上：沿着 $-a$ 方向走得很远，就能找到目标值任意负的可行点。

- **若 $\hat{c} \neq 0$，问题下方无界。** 取 $x = \dfrac{b}{\|a\|_2^{2}}a - t\hat{c}$ 并令 $t \to \infty$。

> † **原文此处排版塌缩**：PDF 文本层给出的是 `x = ba −tĉ`，把系数 $\dfrac{b}{\|a\|_2^{2}}$ 折成了裸的 $b$。
> 正确式子是

```math
x = \frac{b}{\|a\|_2^{2}}\,a - t\hat{c},\qquad \text{so that}\quad a^{T}x = b - t\,a^{T}\hat{c} = b .
```

> **数值反例**（$n=2$）：取 $a = (1,0)^{T}$、$b = 1$、$c = \hat{c} = (0,1)^{T}$（即 $\lambda = 0$）。按正确式子 $x = (1,-t)^{T}$，$a^{T}x = 1 = b$ 可行，目标 $c^{T}x = -t \to -\infty$。若照原文取 $x = b\,a = (1,0)^{T}$，这个点根本不含 $t$，$t \to \infty$ 时 $x$ 不动、目标恒为 $0$——「无界」的整个论证随之失效。**为什么会写错**：$\LaTeX$ 源里 $\frac{b}{\|a\|_2^2}$ 行内被排成小分子小分母，PDF 抽取时分子分母整块丢掉，只剩斜杠前的 $b$。

- **若 $c = a\lambda$ 对某个 $\lambda \le 0$ 成立（此时 $\hat{c} = 0$），最优值为 $c^{T}a\dfrac{b}{\|a\|_2^{2}} = \lambda b$。**

汇总，最优值为

```math
p^\star = \begin{cases}
\lambda b, & c = a\lambda \ \text{for some } \lambda \le 0,\\
-\infty, & \text{otherwise}.
\end{cases}
```

> 复算：$\lambda \le 0$ 时沿 $a$ 方向目标系数非正，取最远的可行点 $x = \frac{b}{\|a\|_2^2}a$ 得 $\lambda a^{T}\frac{b}{\|a\|_2^2}a = \lambda b$ ✓；$\lambda \gt 0$ 时同方向改成 $-a$ 即无界 ✓；$\hat{c} \neq 0$ 时沿 $\hat{c}$ 的负方向平移可行集，目标线性下降 ✓。三种情形穷尽（$\lambda$ 的符号 × $\hat{c}$ 是否为零），**结论本身无误**，只有上面那处塌缩式。

### Exercise 4.8 (c) 在 rectangle 上最小化线性函数

> 话题：箱约束下 LP 的可分性——每个坐标独立取端点，所以答案是「正系数配下界、负系数配上界」。

```math
\begin{aligned}
\text{minimize}\quad & c^{T}x \\
\text{subject to}\quad & l \preceq x \preceq u,
\end{aligned}
```

其中 $l$ 与 $u$ 满足 $l \preceq u$。

**Solution.** 目标与约束都是 separable（可分）的：目标是各项 $c_ix_i$ 之和，每项只依赖一个变量；每条约束也只依赖一个变量。

<!-- ===== p082 ===== -->

于是我们可以对 $x$ 的每个分量独立地做最小化。最优的 $x_i^\star$ 在约束 $l_i \le x_i \le u_i$ 下最小化 $c_ix_i$。

- 若 $c_i \gt 0$，则 $x_i^\star = l_i$；
- 若 $c_i \lt 0$，则 $x_i^\star = u_i$；
- 若 $c_i = 0$，则区间 $[l_i, u_i]$ 中的任意 $x_i$ 都是最优的。

因此，问题的最优值是

```math
p^\star = l^{T}c^{+} - u^{T}c^{-},
\qquad \text{where}\quad c_i^{+} = \max\{c_i, 0\},\ \ c_i^{-} = \max\{-c_i, 0\} .
```

> † **原文符号错（可验算硬错）**。PDF 文本层给出的是 `p⋆= lT c+ + uT c−`，**第二项是加号**。
> **错在哪**：$c_i \lt 0$ 的那一批坐标，最优取 $x_i = u_i$，贡献是 $c_iu_i \lt 0$。而 $c_i = -c_i^{-}$，所以贡献是 $-u_ic_i^{-}$。加号一写，负贡献被翻成正贡献。
> **正确式子**：$p^\star = l^{T}c^{+} - u^{T}c^{-}$（等价写法：$p^\star = l^{T}c^{+} + u^{T}\min\{c,0\}$，其中 $\min$ 逐分量取）。
> **数值反例**（$n=1$，手算一行）：$c = -1$、$l = 0$、$u = 2$。目标 $-x$ 在 $[0,2]$ 上的最小值为 $-2$（在 $x=2$ 取到）。原文公式给 $l\,c^{+} + u\,c^{-} = 0\cdot 0 + 2\cdot 1 = +2$，**符号整体反了，差 $4$**。
> **为什么会写错**：$c^{-}$ 被定义成 $\max\{-c_i,0\}$（非负），作者却按「$c^{-}$ 是 $c$ 的负部（本来就带负号）」的直觉直接相加；定义与使用之间差了这一个负号。

### Exercise 4.8 (d) 在 probability simplex 上最小化线性函数

> 话题：单纯形上 LP 的最优解一定落在顶点；放宽预算约束后多出一个「不投资」的选项，最优值就变成 $\min\{0, c_{\min}\}$。

```math
\begin{aligned}
\text{minimize}\quad & c^{T}x \\
\text{subject to}\quad & \mathbf{1}^{T}x = 1, \qquad x \succeq 0 .
\end{aligned}
```

若把等式约束换成不等式 $\mathbf{1}^{T}x \le 1$，会发生什么？

可以把这条 LP 解释成一个朴素的 portfolio optimization（投资组合优化）问题。向量 $x$ 表示把总预算分配在不同资产上，$x_i$ 是投在资产 $i$ 上的比例。每项投资的收益是固定的，等于 $-c_i$，于是我们的总收益（要最大化）是 $-c^{T}x$。若把预算约束 $\mathbf{1}^{T}x = 1$ 换成不等式 $\mathbf{1}^{T}x \le 1$，我们就多了一个「有一部分预算不投出去」的选项。

**Solution.** 设 $c$ 的分量已按升序排好：

```math
c_1 = c_2 = \cdots = c_k \lt c_{k+1} \le \cdots \le c_n .
```

对所有可行 $x$ 有

```math
c^{T}x \ge c_1(\mathbf{1}^{T}x) = c_{\min},
```

等号成立当且仅当

```math
x_1 + \cdots + x_k = 1,\qquad x_1 \ge 0,\ \ldots,\ x_k \ge 0,\qquad x_{k+1} = \cdots = x_n = 0 .
```

由此得最优值 $p^\star = c_1 = c_{\min}$。回到投资解释，这个选择非常显然：若收益固定且已知，就把全部预算投在收益最高的那项上。

若把等式换成不等式，最优值等于

```math
p^\star = \min\{0,\, c_{\min}\}.
```

（若 $c_{\min} \le 0$，取与上面相同的 $x$；否则取 $x = 0$。）

> 复算：$c^{T}x \ge c_1\mathbf{1}^{T}x$ 逐项成立，因为 $c_i \ge c_1$ 且 $x_i \ge 0$（$x \succeq 0$ 这一步是必需的）。不等式版的两支——$x = 0$ 给 $0$，单纯形给 $c_{\min}$——都对。**此处原文无误**。

### Exercise 4.8 (e) 在带总预算约束的 unit box 上最小化线性函数

> 话题：$\alpha$ 整数时贪心取最小的 $\alpha$ 个分量，非整数时最后一个分量只取小数部分——这是 LP 顶点解的教科书例子。

```math
\begin{aligned}
\text{minimize}\quad & c^{T}x \\
\text{subject to}\quad & \mathbf{1}^{T}x = \alpha, \qquad 0 \preceq x \preceq \mathbf{1},
\end{aligned}
```

其中 $\alpha$ 是 $0$ 与 $n$ 之间的整数。若 $\alpha$ 不是整数（但仍满足 $0 \le \alpha \le n$）会怎样？若把等式换成不等式 $\mathbf{1}^{T}x \le \alpha$ 又会怎样？

**Solution.** 先看 $\alpha$ 为整数的情形。设

```math
c_1 \le \cdots \le c_{i-1} \lt c_i = \cdots = c_\alpha = \cdots = c_k \lt c_{k+1} \le \cdots \le c_n .
```

最优值为

```math
c_1 + c_2 + \cdots + c_\alpha,
```

也就是 $c$ 中最小的 $\alpha$ 个元素之和。$x$ 最优当且仅当

```math
x_1 = \cdots = x_{i-1} = 1,\qquad x_i + \cdots + x_k = \alpha - i + 1,\qquad x_{k+1} = \cdots = x_n = 0 .
```

若 $\alpha$ 不是整数，最优值为

```math
p^\star = c_1 + c_2 + \cdots + c_{\lfloor \alpha \rfloor} + c_{1+\lfloor \alpha \rfloor}\,\bigl(\alpha - \lfloor \alpha \rfloor\bigr).
```

在不等式约束 $\mathbf{1}^{T}x \le \alpha$（$\alpha$ 为 $0$ 到 $n$ 之间的整数）的情形，最优值是 $c$ 中最小的 $\alpha$ 个**非正**系数之和。

> 复算：整数情形是标准的 exchange argument——若 $x_j \gt 0$ 而 $x_i \lt 1$ 且 $c_i \lt c_j$，把质量从 $j$ 挪到 $i$ 目标不增。等值块 $[i,k]$ 内的任意分配都最优，所以原文给的「$x_i + \cdots + x_k = \alpha - i + 1$」正是「不要打破平局」的条件，对。非整数情形相当于把第 $\lfloor\alpha\rfloor + 1$ 小的分量填上小数部分 $\alpha - \lfloor\alpha\rfloor \in [0,1)$，可行且最优。不等式版只肯吃非正系数（吃正系数会让目标上升，不如 $x = 0$）。**三处都对，原文无误**。

### Exercise 4.8 (f) 在带加权预算约束的 unit box 上最小化线性函数

> 话题：加权预算把「按 $c_i$ 排序」换成「按 $c_i/d_i$ 排序」——单位成本收益比，和背包的贪心同一套逻辑。

```math
\begin{aligned}
\text{minimize}\quad & c^{T}x \\
\text{subject to}\quad & d^{T}x = \alpha, \qquad 0 \preceq x \preceq \mathbf{1},
\end{aligned}
```

其中 $d \succ 0$，$0 \le \alpha \le \mathbf{1}^{T}d$。

**Solution.** 做变量替换 $y_i = d_ix_i$，并考虑问题

```math
\begin{aligned}
\text{minimize}\quad & \sum_{i=1}^{n}(c_i/d_i)\,y_i \\
\text{subject to}\quad & \mathbf{1}^{T}y = \alpha, \qquad 0 \preceq y \preceq d .
\end{aligned}
```

> † 原文把约束写成 `1T x = α`、`0 ⪯y ⪯d`——**同一行里左边是 $x$、右边是 $y$**。既然已经声明替换 $y_i = d_ix_i$，约束必须是 $\mathbf{1}^{T}y = \alpha$（否则 $\mathbf{1}^{T}x = \alpha$ 与 $0 \preceq y \preceq d$ 里出现两套变量，替换就白做了）。**数值对照**：$n=2$、$d=(2,3)$、$x=(0.5,0)$ 时 $\mathbf{1}^{T}x = 0.5$，而 $\mathbf{1}^{T}y = 1$；两者只有在 $d = \mathbf{1}$ 时才碰巧相等。属排版级符号错，代入即矛盾。

设比值 $c_i/d_i$ 已按升序排好：

```math
\frac{c_1}{d_1} \le \frac{c_2}{d_2} \le \cdots \le \frac{c_n}{d_n} .
```

为最小化目标，取

```math
y_1 = d_1,\ y_2 = d_2,\ \ldots,\ y_k = d_k,\quad
y_{k+1} = \alpha - (d_1 + \cdots + d_k),\quad
y_{k+2} = \cdots = y_n = 0,
```

其中 $k = \max\{i \in \{1,\ldots,n\} \mid d_1 + \cdots + d_i \le \alpha\}$（若 $d_1 \gt \alpha$ 则取 $k = 0$）。回到原始变量：

```math
x_1 = \cdots = x_k = 1,\quad
x_{k+1} = \frac{\alpha - (d_1 + \cdots + d_k)}{d_{k+1}},\quad
x_{k+2} = \cdots = x_n = 0 .
```

> 复算：这是「单位预算收益」意义下的贪心——先把预算 $\alpha$ 花在 $c_i/d_i$ 最小的坐标上，因为在那里每花一单位 $d$ 只付最便宜的 $c$。$y \preceq d$ 给出每个坐标的上限 $d_i$，全部填满后剩余 $\alpha - \sum_{i\le k}d_i \lt d_{k+1}$ 只能填进第 $k+1$ 个坐标，小数部分 $\in [0,1)$ 自动满足 $x_{k+1} \le 1$。**解本身正确**，只有上面那处 `1T x` 的笔误。

### Exercise 4.9 Square LP

> 话题：方阵、非奇异的 $A$ 把 $\{x \mid Ax \preceq b\}$ 拉成「对角化的盒子」，于是判据退化成一条对偶锥条件 $A^{-T}c \preceq 0$。

**Consider the LP**

```math
\begin{aligned}
\text{minimize}\quad & c^{T}x \\
\text{subject to}\quad & Ax \preceq b
\end{aligned}
```

with $A$ square and nonsingular. Show that the optimal value is given by

```math
p^\star = \begin{cases}
c^{T}A^{-1}b, & A^{-T}c \preceq 0,\\
-\infty, & \text{otherwise}.
\end{cases}
```

**Solution.** 做变量替换 $y = Ax$。问题等价于

```math
\begin{aligned}
\text{minimize}\quad & c^{T}A^{-1}y \\
\text{subject to}\quad & y \preceq b .
\end{aligned}
```

若 $A^{-T}c \preceq 0$，最优解是 $y = b$，$p^\star = c^{T}A^{-1}b$；否则该 LP 下方无界。

> 复算：目标是对 $y$ 的线性函数 $\tilde c^{T}y$，$\tilde c = A^{-T}c$。只有上界约束 $y \preceq b$，所以每个坐标要么被顶到 $b_i$（当 $\tilde c_i \le 0$），要么可以放到 $-\infty$（当 $\tilde c_i \gt 0$）。全部分量都 $\le 0$ 时唯一的最优是 $y = b$。**判据与结论一致，原文无误**。一个边界细节：$\tilde c = 0$ 时 $p^\star = 0 = c^{T}A^{-1}b$ 仍成立（$A^{-T}c = 0 \Rightarrow c = 0$），被 $\preceq 0$ 覆盖。

### Exercise 4.10 Converting general LP to standard form

> 话题：把 $Ax \preceq b$ 型 LP 拆成 $x = x^{+} - x^{-}$、补 slack $s$ 的标准形式；核心是双向映射保持目标值，所以最优值不变。

**Work out the details on page 147 of §4.3. Explain in detail the relation between the feasible sets, the optimal solutions, and the optimal values of the standard form LP and the original LP.**

**Solution.** 设 $x$ 是 (4.27) 的可行点。定义

```math
x_i^{+} = \max\{0,\, x_i\},\qquad x_i^{-} = \max\{0,\, -x_i\},\qquad s = h - Gx .
```

> † **原文这里是 `min`（可验算硬错）**。PDF 文本层给 `x+i = min{0, xi}, x−i = min{0, −xi}`。
> **错在哪**：标准形式要求新变量 $x^{+}, x^{-}, s$ 全部非负（$x^{+} \succeq 0$、$x^{-} \succeq 0$、$s \succeq 0$）。而 $\min\{0,\cdot\}$ 永远给出**非正**值。
> **数值反例**（$n=1$）：$x = 3$，按原文 $x^{+} = \min\{0,3\} = 0$、$x^{-} = \min\{0,-3\} = -3$。于是 $x^{+} \ge 0$ ✓ 但 $x^{-} = -3 \lt 0$ ✗ ——直接违反标准形式的非负约束，任何 simplex 实现第一步做比值检验就会拿到负的右端项，报 infeasible 或除零。取 $x = -3$ 时对称地坏在 $x^{+} = -3$。
> **为什么会写错**：$\max$/$\min$ 在 PDF 里字形相近，抽取时被识别成同一个符号；同时作者在下一行用了 $c^{T}x^{+} - c^{T}x^{-}$ 的差，恰好让符号错误在代数上**自我抵消**（$\min\{0,x\} = -\max\{0,-x\}$），所以只看那一行等式反而看不出来。

容易验证 $x^{+}$、$x^{-}$、$s$ 在标准形式 LP 中可行，且目标值为

```math
c^{T}x^{+} - c^{T}x^{-} + d = c^{T}x + d .
```

> † **原文第二处符号错**：`cT x+ −cT x−+ d = cT x −d`，等式右边写成了减 $d$。
> **正确**：$c^{T}x^{+} - c^{T}x^{-} + d = c^{T}x + d$（因为 $x^{+} - x^{-} = x$ 逐分量成立）。
> **数值反例**（$n=1$）：$c = 1$、$d = 1$、$x = 3$。真值 $c^{T}x + d = 4$；原文右端 $c^{T}x - d = 2$。两者差 $2d$，$d \ne 0$ 时立刻对不上。
> **为什么会写错**：$x^{+} - x^{-}$ 这一项的负号被误抄到了常数 $d$ 上，属于同一行里两处符号的串扰。

因此，对 (4.27) 的每个可行点，我们都能在标准形式 LP 中找到一个可行点，且目标值相同。特别地，这推出标准形式 LP 的最优值**小于或等于** (4.27) 的最优值。

<!-- ===== p084 ===== -->

反过来，设 $x^{+}$、$x^{-}$、$s$ 在标准形式 LP 中可行。定义 $x = x^{+} - x^{-}$。显然 $x$ 对 (4.27) 可行，且目标值 $c^{T}x + d = c^{T}x^{+} - c^{T}x^{-} + d$。

于是，标准形式 LP 的每个可行点都能找到一个 (4.27) 的可行点，目标值相同。这推出标准形式 LP 的最优值**大于或等于** (4.27) 的最优值。

两个方向合起来，最优值相等。

<span style="color:#1e8449;">**[译注]** 这一题的价值不在结论，而在「为什么 $x^{\pm}$ 必须取 $\max$」——它是 standard form（标准形式）存在的前提。标准形式的一切算法（simplex、interior-point）都默认变量 $\succeq 0$：simplex 的比值检验要在 $B^{-1}b \ge 0$ 下才选得出离开基的变量，interior-point 要在开正象限里放 barrier。所以

```math
x_i^{+} = \max\{0, x_i\},\quad x_i^{-} = \max\{0, -x_i\} \;\Longrightarrow\; x^{+} \succeq 0,\ x^{-} \succeq 0
```

不是写法偏好，而是**可行域被搬到哪个空间的声明**。$\min$ 版本给出的是 $x^{+} = -x^{-}_{\text{真}}$、$x^{-} = -x^{+}_{\text{真}}$，两者都 $\preceq 0$；把它交给任何 LP solver，第一个单纯形表就有负的右端项，要么报 infeasible、要么在 pivot 时取到负步长，把迭代送出可行域。

**消失测试**：抽掉「取 $\max$」这个正确化，$x^{\pm}$ 不再非负，$\{x \mid Ax \preceq b\}$ 到 $\{(x^{+},x^{-},s) \mid \tilde Ax = \tilde b,\ (x^{+},x^{-},s) \succeq 0\}$ 的映射就不落在目标集里，于是「两个可行集之间目标值一一对应」这一步断掉，$p^\star_{\text{std}} = p^\star_{\text{orig}}$ 失去证明；实测后果是 solver 报 unbounded 或 infeasible 而原问题明明有最优解。

**量的方向感**：这一步把变量数从 $n$ 涨到 $2n + m$（$x^{\pm}$ 各 $n$ 个、slack $m$ 个），约束数不变仍是 $m$ 条等式——代价是**维数翻倍**，换来的是所有算法都能直接吃。这也是为什么现代 solver 内部反而用「$l \preceq x \preceq u$ 的有界变量形式」，避免翻倍。

**落点**：Boyd §4.3（p.147 的 (4.27)）；标准形式的定义见 §4.1；Strang 线代的 column space / nullspace 章节给的是同一件事的几何图像（$\{x \mid Ax = b\}$ 是一个仿射集，$x^{\pm}$ 是把仿射集换成两个非负象限的乘积）。</span>

### Exercise 4.11 Problems involving $\ell_1$- and $\ell_\infty$-norms

> 话题：范数逼近的 LP 化——$\ell_\infty$ 用「一个 $t$ 卡住所有残差」，$\ell_1$ 用「每个残差配一个 $s_k$ 再求和」，都是 epigraph 技巧的具体化。

**Formulate the following problems as LPs. Explain in detail the relation between the optimal solution of each problem and the solution of its equivalent LP.**

**(a) Minimize $\|Ax - b\|_\infty$（$\ell_\infty$-norm approximation）**
**(b) Minimize $\|Ax - b\|_1$（$\ell_1$-norm approximation）**
**(c) Minimize $\|Ax - b\|_1$ subject to $\|x\|_\infty \le 1$**
**(d) Minimize $\|x\|_1$ subject to $\|Ax - b\|_\infty \le 1$**
**(e) Minimize $\|Ax - b\|_1 + \|x\|_\infty$**

In each problem, $A \in \mathbf{R}^{m\times n}$ and $b \in \mathbf{R}^m$ are given.

**Solution.**

**(a)** 等价于 LP

```math
\begin{aligned}
\text{minimize}\quad & t \\
\text{subject to}\quad & Ax - b \preceq t\mathbf{1}\\
& Ax - b \succeq -t\mathbf{1},
\end{aligned}
```

变量为 $x, t$。要看等价性，先固定 $x$、只对 $t$ 优化。约束说的是

```math
-t \le a_k^{T}x - b_k \le t
```

对每个 $k$ 成立，即 $t \ge |a_k^{T}x - b_k|$，也就是

```math
t \ge \max_k |a_k^{T}x - b_k| = \|Ax - b\|_\infty .
```

显然，固定 $x$ 时 LP 的最优值是 $p^\star(x) = \|Ax - b\|_\infty$。因此同时对 $t$ 与 $x$ 优化，就等价于原问题。

> 复算：$t$ 在约束里只出现「越大越松」，所以在最小化下必然被顶到 $t = \|Ax-b\|_\infty$，两层优化可交换（$\min_{x,t} = \min_x \min_{t}$，内层有显式解）。$t \ge 0$ 自动成立，不必单列约束。**原文无误**。

**(b)** 等价于 LP

```math
\begin{aligned}
\text{minimize}\quad & \mathbf{1}^{T}s \\
\text{subject to}\quad & Ax - b \preceq s\\
& Ax - b \succeq -s .
\end{aligned}
```

先固定 $x$、只对 $s$ 优化。约束说的是

```math
-s_k \le a_k^{T}x - b_k \le s_k
```

对每个 $k$ 成立，即 $s_k \ge |a_k^{T}x - b_k|$。LP 的目标函数是 separable 的，所以对 $s$ 的最优取法是

```math
s_k = |a_k^{T}x - b_k|,
```

从而最优值 $p^\star(x) = \|Ax - b\|_1$。因此同时对 $s$ 与 $x$ 优化，就等价于原问题。

> † 原文末句写 `Therefore optimizing over t and s simultaneously`——**(b) 里根本没有 $t$**，$t$ 是 (a) 的变量。属复制上一段留下的变量名残留：不影响式子，但会让读者去找一个不存在的 $t \ge \max|a_k^Tx - b_k|$ 约束。正确应写「同时对 $s$ 与 $x$ 优化」。

**(c)** 等价于 LP

```math
\begin{aligned}
\text{minimize}\quad & \mathbf{1}^{T}y \\
\text{subject to}\quad & -y \preceq Ax - b \preceq y\\
& -\mathbf{1} \preceq x \preceq \mathbf{1},
\end{aligned}
```

变量为 $x \in \mathbf{R}^n$ 与 $y \in \mathbf{R}^m$。

> † 原文末行写成 `−1 ≤x ≤1`（标量不等号）。$x \in \mathbf{R}^n$，$n \gt 1$ 时标量不等号无定义，必须写分量式 $-\mathbf{1} \preceq x \preceq \mathbf{1}$。**数值反例**：$n = 2$、$x = (1, 5)$，按标量式无从判定，按分量式立刻看到 $x_2 = 5 \gt 1$ 违约。

<!-- ===== p085 ===== -->

**(d)** 等价于 LP

```math
\begin{aligned}
\text{minimize}\quad & \mathbf{1}^{T}y \\
\text{subject to}\quad & -y \preceq x \preceq y\\
& -\mathbf{1} \preceq Ax - b \preceq \mathbf{1},
\end{aligned}
```

变量为 $x$ 与 $y$。

另一个同样好的解法是：把 $x$ 写成两个非负向量之差 $x = x^{+} - x^{-}$，并把问题表达为

```math
\begin{aligned}
\text{minimize}\quad & \mathbf{1}^{T}x^{+} + \mathbf{1}^{T}x^{-} \\
\text{subject to}\quad & -\mathbf{1} \preceq Ax^{+} - Ax^{-} - b \preceq \mathbf{1}\\
& x^{+} \succeq 0,\qquad x^{-} \succeq 0,
\end{aligned}
```

变量为 $x^{+} \in \mathbf{R}^n$ 与 $x^{-} \in \mathbf{R}^n$。

> 复算：两种写法都是把 $\|x\|_1$（绝对值之和）用「$x$ 的上下界」或「$x^{\pm}$ 的线性部分和」替代。第二种写法在最优解处必然有 $x_i^{+}x_i^{-} = 0$（否则同时抬高两者会增大目标却不改善可行性，可把公共部分移到另一侧），所以 $\mathbf{1}^{T}x^{+} + \mathbf{1}^{T}x^{-} = \|x\|_1$ ✓。**原文无误**。

**(e)** 等价于

```math
\begin{aligned}
\text{minimize}\quad & \mathbf{1}^{T}y + t \\
\text{subject to}\quad & -y \preceq Ax - b \preceq y\\
& -t\mathbf{1} \preceq x \preceq t\mathbf{1},
\end{aligned}
```

变量为 $x$、$y$ 与 $t$。

> 复算：(e) 是 (b) 与 (d) 的组合，$\|x\|_\infty \le t$ 与 $-t\mathbf{1} \preceq x \preceq t\mathbf{1}$ 完全同义。**原文无误**。

<span style="color:#1e8449;">**[译注]** 这一题的 (a)(b) 是同一个套路的两副面孔，值得记住它们**差别在哪里**：$\ell_\infty$ 是「一个数管住所有残差」，所以引入**单个**标量 $t$；$\ell_1$ 是「每个残差各付各的账」，所以引入**一个向量** $s \in \mathbf{R}^m$。这个不对称决定了 LP 的规模：

```math
\ell_\infty:\ \text{vars} = n + 1,\quad \text{ineq} = 2m
\qquad
\ell_1:\ \text{vars} = n + m,\quad \text{ineq} = 2m
```

变量数差 $m-1$，在大规模拟合（$m \gg n$）里是实打实的差别。

**消失测试**：没有 $\max_k$ 可以写进线性目标这一事实（即 $\|\cdot\|_\infty$ 的 epigraph 是有限条线性不等式），$\ell_\infty$ 逼近就只能做非线性最小二乘的迭代重加权，每步都要解一个非线性子问题；而 $\ell_1$ 若无 $s_k$ 这个 slack 向量，符号函数 $\operatorname{sign}$ 进入目标，一阶条件里出现不连续项，subgradient 方法只能给 $O(1/\sqrt{k})$ 收敛率，换成 LP 之后是有限步终止（simplex 最坏指数，实践中多项式）。

**量的方向感**：$\ell_\infty$ 的 LP 变量数只比原问题多 **1**，$\ell_1$ 的多 $m$——这就是为什么统计里的 $\ell_1$ 正则（lasoo 类）在大 $m$ 时要专门的结构（dual 化后变量降到 $n$）。

**落点**：Boyd §6.1.1（$\ell_\infty$ 与 $\ell_1$ 逼近的标准处理）；(c)(d) 的等价形式见 §4.4 的 LP 片段；Strang 线代的最小二乘章给 $\ell_2$ 情形作对照（$\ell_2$ 不需要 LP，直接正规方程 $A^{T}Ax = A^{T}b$）。</span>

### Exercise 4.12 Network flow problem

> 话题：网络流的 LP 表述——每个节点一条守恒式，边上是双边界；这是 LP 里最经典的 incidence matrix 实例。

**Consider a network of $n$ nodes, with directed links connecting each pair of nodes. The variables in the problem are the flows on each link: $x_{ij}$ will denote the flow from node $i$ to node $j$. The cost of the flow along the link from node $i$ to node $j$ is given by $c_{ij}x_{ij}$, where $c_{ij}$ are given constants. The total cost across the network is**

```math
C = \sum_{i,j=1}^{n} c_{ij}x_{ij}.
```

**Each link flow $x_{ij}$ is also subject to a given lower bound $l_{ij}$ (usually assumed to be nonnegative) and an upper bound $u_{ij}$.**

**The external supply at node $i$ is given by $b_i$, where $b_i \gt 0$ means an external flow enters the network at node $i$, and $b_i \lt 0$ means that at node $i$, an amount $|b_i|$ flows out of the network. We assume that $\mathbf{1}^{T}b = 0$, i.e., the total external supply equals total external demand. At each node we have conservation of flow: the total flow into node $i$ along links and the external supply, minus the total flow out along the links, equals zero.**

**The problem is to minimize the total cost of flow through the network, subject to the constraints described above. Formulate this problem as an LP.**

**Solution.** 可以表述为 LP

```math
\begin{aligned}
\text{minimize}\quad & C = \sum_{i,j=1}^{n} c_{ij}x_{ij} \\
\text{subject to}\quad & b_i + \sum_{j=1}^{n} x_{ji} - \sum_{j=1}^{n} x_{ij} = 0, \quad i = 1,\ldots,n \\
& l_{ij} \le x_{ij} \le u_{ij}.
\end{aligned}
```

> † **原文守恒式的两个求和写反了（可验算硬错）**。PDF 文本层给出
>
> ```math
> b_i + \sum_{j=1}^{n} x_{ij} - \sum_{j=1}^{n} x_{ji} = 0 .
> ```
>
> **错在哪**：按原题自己的定义，$x_{ij}$ 是「从 $i$ 流向 $j$」的流，所以对节点 $i$ 而言，$\sum_j x_{ij}$ 是**流出**、$\sum_j x_{ji}$ 是**流入**。守恒式必须是「流入 $-$ 流出 $+$ 外部供给 $= 0$」，即 $\sum_j x_{ji} - \sum_j x_{ij}$。原文把两项交换，等于说「流出 $-$ 流入 $+$ 供给 $= 0$」，每个节点都被取了反号。
> **数值反例**（$n = 2$，一行手算）：取 $b = (1,-1)$、$x_{12} = 1$、$x_{21} = 0$（节点 1 供 1 单位、经边 $1\to 2$ 送出、节点 2 消耗）。物理上守恒。按正确式子，节点 1：$b_1 + x_{21} - x_{12} = 1 + 0 - 1 = 0$ ✓。按原文：$1 + x_{12} - x_{21} = 1 + 1 - 0 = 2 \ne 0$ ✗ ——所有可行流都会被判违约，LP 直接 infeasible。
> **为什么会写错**：$x_{ij}$ 的指标顺序（前出后入）与守恒式的「入减出」正好相反，作者在写求和时按「先写 $x_{ij}$ 再写 $x_{ji}$」的视觉顺序落笔，没有回到定义去核方向。

<span style="color:#1e8449;">**[译注]** 这条守恒约束写成矩阵就是 incidence matrix（关联矩阵）$A \in \mathbf{R}^{n\times n^2}$：每列对应一条边 $(i,j)$，在第 $i$ 行取 $-1$、第 $j$ 行取 $+1$，其余为零。于是整个网络流 LP 就是

```math
\min\ c^{T}x \quad \text{s.t.}\quad Ax = b,\ \ l \preceq x \preceq u .
```

它的关键性质是 $A$ 的**每个子方阵行列式为 $0$ 或 $\pm 1$**（total unimodularity（全幺模性）的直接后果），于是任何顶点解的每个分量都是整数只要 $b$ 是整数——这就是「网络流 LP 自动给整数解」的全部秘密，不需要任何 branch-and-bound。

**消失测试**：抽掉 total unimodularity，同一张图的 LP（比如加上一个上界之外的耦合约束）顶点解立刻可以是分数，最短路的 integrality 论证崩掉，Dijkstra 输出的路径不再对应 LP 的最优基本解；复杂度上从 $O(m\log n)$ 的最短路退回一般 LP 的 $O(n^{3.5}L)$ 量级。

**量的方向感**：$n$ 个节点、$n^2$ 条有向边时约束只有 $n$ 条（但秩为 $n-1$，因为 $\mathbf{1}^{T}Ax = 0$ 恒成立），变量 $n^2$ 个——**约束比变量少一个数量级**，这正是网络单纯形（network simplex）比通用 simplex 快得多的结构性原因。

**落点**：Boyd §4.3 的 LP 片段；§5.6 的对偶里这题的 dual 是一个 potential 问题；图论侧挂 6.006 的 max-flow / min-cut 章节与 CSAPP 无关；total unimodularity 的严格判据见 Schrijver *Combinatorial Optimization* 第 4 章。</span>

### Exercise 4.13 Robust LP with interval coefficients

> 话题：系数在区间里任意取值都要满足约束 ⇒ 只需 worst case 满足；而 worst case 恰好写成 $\bar Ax + V|x| \preceq b$，绝对值再拆成 $y$ 就回到 LP。

**Consider the problem, with variable $x \in \mathbf{R}^n$,**

```math
\begin{aligned}
\text{minimize}\quad & c^{T}x \\
\text{subject to}\quad & Ax \preceq b \ \ \text{for all } A \in \mathcal{A},
\end{aligned}
```

**where $\mathcal{A} \subseteq \mathbf{R}^{m\times n}$ is the set**

```math
\mathcal{A} = \{A \in \mathbf{R}^{m\times n} \mid \bar{A}_{ij} - V_{ij} \le A_{ij} \le \bar{A}_{ij} + V_{ij},\ i = 1,\ldots,m,\ j = 1,\ldots,n\}.
```

<!-- ===== p086 ===== -->

**(The matrices $\bar{A}$ and $V$ are given.) This problem can be interpreted as an LP where each coefficient of $A$ is only known to lie in an interval, and we require that $x$ must satisfy the constraints for all possible values of the coefficients.**

**Express this problem as an LP. The LP you construct should be efficient, i.e., it should not have dimensions that grow exponentially with $n$ or $m$.**

**Solution.** 问题等价于

```math
\begin{aligned}
\text{minimize}\quad & c^{T}x \\
\text{subject to}\quad & \bar{A}x + V|x| \preceq b,
\end{aligned}
```

其中 $|x| = (|x_1|, |x_2|, \ldots, |x_n|)$。这又等价于 LP

```math
\begin{aligned}
\text{minimize}\quad & c^{T}x \\
\text{subject to}\quad & \bar{A}x + Vy \preceq b\\
& -y \preceq x \preceq y,
\end{aligned}
```

变量为 $x \in \mathbf{R}^n$、$y \in \mathbf{R}^n$。

> 复算：第 $i$ 行的 worst case 是 $\max_{A_i \in \mathcal{A}_i} A_i x = \bar{A}_i x + \sum_j V_{ij}|x_j|$（每项独立取到 $+V_{ij}|x_j|$，因为 $x_j$ 的符号可以是任意，取 $A_{ij} = \bar A_{ij} + V_{ij}\operatorname{sign}(x_j)$）。要求「对所有 $A$ 成立」等价于「对 worst case 成立」，一步到位。$|x_j|$ 拆成 $y_j$：$y_j \ge x_j$、$y_j \ge -x_j$，最小化下的 $y_j$ 有动力贴到 $|x_j|$（$V \succeq 0$ 时 $y$ 越大越紧），所以等号自动。规模 $2n$ 变量、$m + 2n$ 条不等式，$n$ 的多项式 ✓（避开了对 $2^{mn}$ 个顶点枚举）。**原文无误**。

### Exercise 4.14 Approximating a matrix in infinity norm

> 话题：max-row-sum norm 的逼近——引入一个与 $A(x)$ **同形**的松弛矩阵 $S$，再用行和条件把 $t$ 顶到范数值。

**The $\ell_\infty$-norm induced norm of a matrix $A \in \mathbf{R}^{m\times n}$, denoted $\|A\|_\infty$, is given by**

```math
\|A\|_\infty = \sup_{x \neq 0}\frac{\|Ax\|_\infty}{\|x\|_\infty} = \max_{i=1,\ldots,m}\sum_{j=1}^{n}|a_{ij}| .
```

**This norm is sometimes called the max-row-sum norm, for obvious reasons (see §A.1.5).**

**Consider the problem of approximating a matrix, in the max-row-sum norm, by a linear combination of other matrices. That is, we are given $k+1$ matrices $A_0,\ldots,A_k \in \mathbf{R}^{m\times n}$, and need to find $x \in \mathbf{R}^k$ that minimizes**

```math
\|A_0 + x_1A_1 + \cdots + x_kA_k\|_\infty .
```

**Express this problem as a linear program. Explain the significance of any extra variables in your LP. Carefully explain how your LP formulation solves this problem, e.g., what is the relation between the feasible set for your LP and this problem?**

**Solution.** 问题可表述为 LP

```math
\begin{aligned}
\text{minimize}\quad & t \\
\text{subject to}\quad & -S \preceq_{K} A_0 + x_1A_1 + \cdots + x_kA_k \preceq_{K} S\\
& S\mathbf{1} \preceq t\mathbf{1},
\end{aligned}
```

变量为 $S \in \mathbf{R}^{m\times n}$、$t \in \mathbf{R}$ 与 $x \in \mathbf{R}^k$。记号 $\preceq_K$ 表示矩阵之间的逐元素不等式，即相对于锥

```math
K = \{X \in \mathbf{R}^{m\times n} \mid X_{ij} \ge 0,\ i = 1,\ldots,m,\ j = 1,\ldots,n\}.
```

> † 原文此式里写的是 `x_1A_1 + ··· + x_k a_k`——**最后一项掉成小写 $a_k$**。$a_k$ 在全书别处一律是「$A$ 的第 $k$ 行」，这里却当作第 $k$ 个矩阵用；若照字面理解，$x_ka_k$ 是 $n$ 维向量，与 $A_0 + x_1A_1 + \cdots$（$m\times n$ 矩阵）无法相加。**正确**：$A_0 + x_1A_1 + \cdots + x_kA_k$。同一处错误在下一页的「$A(x)$ 的展开」里重复了一次（`x_kak`），是同一个 $\LaTeX$ 源的复制粘贴。

要看等价性，设 $x$ 与 $S$ 在 LP 中可行。最后一条约束意味着

```math
t \ge \sum_{j=1}^{n} s_{ij},\qquad i = 1,\ldots,m,
```

所以 $t$ 的最优取法是

```math
t = \max_i \sum_{j=1}^{n} S_{ij} .
```

<!-- ===== p087 ===== -->

这说明 LP 等价于

```math
\begin{aligned}
\text{minimize}\quad & \max_i \Bigl(\sum_{j=1}^{n} S_{ij}\Bigr) \\
\text{subject to}\quad & -S \preceq_K A_0 + x_1A_1 + \cdots + x_kA_k \preceq_K S .
\end{aligned}
```

设此问题中 $x$ 已给定，我们只对 $S$ 优化。LP 的约束说的是

```math
-S_{ij} \le A(x)_{ij} \le S_{ij},
```

（其中 $A(x) = A_0 + x_1A_1 + \cdots + x_kA_k$），而目标对 $S_{ij}$ 单调递增，所以 $S_{ij}$ 的最优取法是

```math
S_{ij} = |A(x)_{ij}| .
```

于是问题回到最初的形式

```math
\text{minimize}\quad \max_{i=1,\ldots,m}\sum_{j=1}^{n}|A(x)_{ij}| .
```

> 复算：$S$ 只在目标里以行和出现、在约束里以「上界」出现——$S_{ij}$ 越大目标越大、约束越松，所以在最小化下被压到紧贴 $|A(x)_{ij}|$，此时 $t = \max_i \sum_j |A(x)_{ij}|$ 就是 max-row-sum norm。$S$ 这个**额外变量**的意义正是把范数里的 $\max$ 挪到目标里、把绝对值挪成线性双边界，这是 epigraph + 逐元素松弛的组合。**原文逻辑无误**（除上面那个大小写）。

### Exercise 4.15 Relaxation of Boolean LP

> 话题：Boolean LP 的 LP relaxation——把 $x_i \in \{0,1\}$ 放成 $0 \le x_i \le 1$；这条松驰只给下界，唯一的例外是「松驰解恰好落在顶点」。

**In a Boolean linear program, the variable $x$ is constrained to have components equal to zero or one:**

```math
\begin{aligned}
\text{minimize}\quad & c^{T}x \\
\text{subject to}\quad & Ax \preceq b\\
& x_i \in \{0,1\},\qquad i = 1,\ldots,n .
\end{aligned}
\qquad \text{(4.67)}
```

**In general, such problems are very difficult to solve, even though the feasible set is finite (containing at most $2^n$ points).**

**In a general method called relaxation, the constraint that $x_i$ be zero or one is replaced with the linear inequalities $0 \le x_i \le 1$:**

```math
\begin{aligned}
\text{minimize}\quad & c^{T}x \\
\text{subject to}\quad & Ax \preceq b\\
& 0 \le x_i \le 1,\qquad i = 1,\ldots,n .
\end{aligned}
\qquad \text{(4.68)}
```

**We refer to this problem as the LP relaxation of the Boolean LP (4.67). The LP relaxation is far easier to solve than the original Boolean LP.**

**(a) Show that the optimal value of the LP relaxation (4.68) is a lower bound on the optimal value of the Boolean LP (4.67). What can you say about the Boolean LP if the LP relaxation is infeasible?**

**(b) It sometimes happens that the LP relaxation has a solution with $x_i \in \{0,1\}$. What can you say in this case?**

**Solution.**

**(a)** 松驰的可行集包含了 Boolean LP 的可行集。由此可得：若松驰不可行，则 Boolean LP 也不可行；且松驰的最优值小于或等于 Boolean LP 的最优值。

**(b)** 若松驰的最优解本身也是 Boolean LP 的可行点（各分量取 $0$ 或 $1$），那么它同时也是 Boolean LP 的最优解。

> 复算：$S_{\text{bool}} \subseteq S_{\text{relax}}$ 是集合包含，于是 $\min_{S_{\text{relax}}} \le \min_{S_{\text{bool}}}$（扩大可行集只能让最小值不增）；不可行的反向传导同理。**(b) 的理由**：若松驰最优解 $x^\star \in S_{\text{bool}}$，则 $c^{T}x^\star = p^\star_{\text{relax}} \le p^\star_{\text{bool}} \le c^{T}x^\star$，三面夹住故相等。**原文无误**。

<span style="color:#1e8449;">**[译注]** 这一题短，但它是整本凸优化「松驰」这条主线的入口，值得把**它到底没证明什么**说清楚。设

```math
p^\star_{\text{relax}} \le p^\star_{\text{bool}} \qquad (\text{always})
```

这就是 (a)。差距 $p^\star_{\text{bool}} - p^\star_{\text{relax}}$ 叫 integrality gap（整数间隙），它可以任意大：$c = (-1,-1)$、约束 $x_1 + x_2 = 1$、$x \in \{0,1\}^2$ 时 $p^\star_{\text{bool}} = -1$，而松驰取 $x = (1/2,1/2)$ 得 $-1$——这个例子间隙为 $0$。换成 $c = (1,1)$、约束 $2x_1 + 2x_2 \ge 1$ 则松驰给 $x = (1/4,1/4)$、值 $0.5$，整数解给 $1$，间隙 $0.5$。

**消失测试**：抽掉「松驰可行集包含整数可行集」这一步，(a) 的下界就无从建立，于是 branch-and-bound 的定界剪枝失去依据，整个搜索树退化成 $2^n$ 全枚举——$n = 60$ 时约 $10^{18}$ 个节点，任何机器都跑不完。

**量的方向感**：松驰把可行点数从至多 $2^n$ 降到 $\{x \mid 0 \le x \le 1\}$ 的连续多面体，于是从「最坏指数」降到「LP 的多项式」；代价是下界可能严格松，间隙大时剪枝无效。

**落点**：Boyd §4.2.5（LP 及其松弛）/ §1.3.2（Boolean LP 的例子）；对偶侧的对偶间隙见 §5.5.2（Ch.5 马上要读）；6.042J 的 partial order 与 6.006 的 max-flow 都不能直接给这个界，真正的一手来源是 Wolsey *Integer Programming* §2.1 的 LP relaxation 定理。</span>

### Exercise 4.16 Minimum fuel optimal control

> 话题：燃料函数 $f$ 是凸的分段线性函数，所以「最小燃料」写成 LP 只需两条 epigraph 约束 $t \succeq y$、$t \succeq 2y - \mathbf{1}$。

**We consider a linear dynamical system with state $x(t) \in \mathbf{R}^n$, $t = 0,\ldots,N$, and actuator or input signal $u(t) \in \mathbf{R}$, for $t = 0,\ldots,N-1$. The dynamics of the system is given by the linear recurrence**

```math
x(t+1) = Ax(t) + bu(t),\qquad t = 0,\ldots,N-1,
```

**where $A \in \mathbf{R}^{n\times n}$ and $b \in \mathbf{R}^n$ are given. We assume that the initial state is zero, i.e., $x(0) = 0$.**

<!-- ===== p088 ===== -->

**The minimum fuel optimal control problem is to choose the inputs $u(0),\ldots,u(N-1)$ so as to minimize the total fuel consumed, which is given by**

```math
F = \sum_{t=0}^{N-1} f(u(t)),
```

**subject to the constraint that $x(N) = x_{\text{des}}$, where $N$ is the (given) time horizon, and $x_{\text{des}} \in \mathbf{R}^n$ is the (given) desired final or target state. The function $f : \mathbf{R} \to \mathbf{R}$ is the fuel use map for the actuator, and gives the amount of fuel used as a function of the actuator signal amplitude. In this problem we use**

```math
f(a) = \begin{cases}
|a|, & |a| \le 1,\\
2|a| - 1, & |a| \gt 1.
\end{cases}
```

**This means that fuel use is proportional to the absolute value of the actuator signal, for actuator signals between $-1$ and $1$; for larger actuator signals the marginal fuel efficiency is half.**

**Formulate the minimum fuel optimal control problem as an LP.**

**Solution.**

```math
\begin{aligned}
\text{minimize}\quad & \mathbf{1}^{T}t \\
\text{subject to}\quad & Hu = x_{\text{des}}\\
& -y \preceq u \preceq y\\
& t \succeq y\\
& t \succeq 2y - \mathbf{1},
\end{aligned}
```

其中

```math
H = \begin{bmatrix} A^{N-1}b & A^{N-2}b & \cdots & Ab & b \end{bmatrix}.
```

> 复算：把 $x(0) = 0$ 的递归展开，$x(N) = \sum_{t=0}^{N-1}A^{N-1-t}bu(t) = Hu$ ✓，$H$ 的列顺序与 $u(0),\ldots,u(N-1)$ 对应 ✓。约束 $-y \preceq u \preceq y$ 在最小化 $t$ 的驱动下把 $y$ 顶到 $|u|$；而 $t \ge \max(|u|, 2|u|-1) = f(u)$（当 $|u| \le 1$ 时 $|u| \ge 2|u|-1$，当 $|u| \ge 1$ 时反过来）✓。$f$ 是两段线性凸函数，所以它的 epigraph 恰好由两条线性不等式刻画——这就是「凸分段线性 ⇒ 一个额外变量一行」的标准手法。**原文无误**。

### Exercise 4.17 Optimal activity levels

> 话题：收益是分段线性凹函数，最大化时用「两条下界约束把 $u_j$ 顶到 $r_j(x_j)$」——注意这里是 maximization，所以 epigraph 换成 hypograph。

**We consider the selection of $n$ nonnegative activity levels, denoted $x_1,\ldots,x_n$. These activities consume $m$ resources, which are limited. Activity $j$ consumes $A_{ij}x_j$ of resource $i$, where $A_{ij}$ are given. The total resource consumption is additive, so the total of resource $i$ consumed is $c_i = \sum_{j=1}^{n}A_{ij}x_j$. (Ordinarily we have $A_{ij} \ge 0$, i.e., activity $j$ consumes resource $i$. But we allow the possibility that $A_{ij} \lt 0$, which means that activity $j$ actually generates resource $i$ as a by-product.) Each resource consumption is limited: we must have $c_i \le c_i^{\max}$, where $c_i^{\max}$ are given. Each activity generates revenue, which is a piecewise-linear concave function of the activity level:**

```math
r_j(x_j) = \begin{cases}
p_jx_j, & 0 \le x_j \le q_j,\\
p_jq_j + p_j^{\text{disc}}(x_j - q_j), & x_j \ge q_j .
\end{cases}
```

**Here $p_j \gt 0$ is the basic price, $q_j \gt 0$ is the quantity discount level, and $p_j^{\text{disc}}$ is the quantity discount price, for (the product of) activity $j$. (We have $0 \lt p_j^{\text{disc}} \lt p_j$.) The total revenue is the sum of the revenues associated with each activity, i.e., $\sum_{j=1}^{n}r_j(x_j)$. The goal is to choose activity levels that maximize the total revenue while respecting the resource limits. Show how to formulate this problem as an LP.**

**Solution.** 基本问题可以表述为

```math
\begin{aligned}
\text{maximize}\quad & \sum_{j=1}^{n}r_j(x_j) \\
\text{subject to}\quad & x \succeq 0\\
& Ax \preceq c^{\max}.
\end{aligned}
```

由于目标是 concave（凹）的、约束是一组线性不等式，这是一个凸优化问题。为把它转成等价的 LP，先注意收益函数可以写成

```math
r_j(x_j) = \min\{p_jx_j,\ p_jq_j + p_j^{\text{disc}}(x_j - q_j)\},
```

<!-- ===== p089 ===== -->

该等式成立是因为 $r_j$ 是凹的。由它可得 $r_j(x_j) \ge u_j$ 当且仅当

```math
p_jx_j \ge u_j,\qquad p_jq_j + p_j^{\text{disc}}(x_j - q_j) \ge u_j .
```

于是可以构造 LP

```math
\begin{aligned}
\text{maximize}\quad & \mathbf{1}^{T}u \\
\text{subject to}\quad & x \succeq 0\\
& Ax \preceq c^{\max}\\
& p_jx_j \ge u_j,\\
& p_jq_j + p_j^{\text{disc}}(x_j - q_j) \ge u_j,\qquad j = 1,\ldots,n,
\end{aligned}
```

变量为 $x$ 与 $u$。

要说明该 LP 与原问题等价，先固定 $x$。LP 中最后两组约束保证 $u_i \le r_i(x)$，所以对 LP 的每个可行 $(x,u)$，LP 的目标都小于或等于总收益。另一方面，我们总可以取 $u_i = r_i(x)$，此时两个目标相等。

> 复算：$r_j$ 的两段斜率分别是 $p_j$ 与 $p_j^{\text{disc}}$，且 $0 \lt p_j^{\text{disc}} \lt p_j$，所以 $r_j$ 确实是 $\min$ 而不是 $\max$（第二条直线在 $x_j \gt q_j$ 处更低）✓；$r_j$ 在 $x_j = q_j$ 处连续（$p_jq_j = p_jq_j$）✓。最大化下 $u_j$ 被上推到 $\min\{\cdots\} = r_j(x_j)$ ✓，等价性成立。**原文无误**。

<span style="color:#1e8449;">**[译注]** 这一题与 4.16 是同一台机器的两个朝向，值得并排记住：**最小化凸分段线性函数用 epigraph（$t \ge$ 每段），最大化凹分段线性函数用 hypograph（$u \le$ 每段）**。写成一条通则：

```math
\min f(x) = \min\{\eta \mid \eta \ge L_k(x)\ \forall k\},\qquad
\max g(x) = \max\{\nu \mid \nu \le L_k(x)\ \forall k\}
```

其中 $L_k$ 是各段的仿射函数。这里 $r_j$ 的两段 $L_1 = p_jx_j$、$L_2 = p_jq_j + p_j^{\text{disc}}(x_j - q_j)$，凹 ⇒ $r_j = \min_k L_k$ ⇒ hypograph 是「$\nu \le L_1$ 且 $\nu \le L_2$」的交，两条不等式即可，与 4.16 的两条 $t \ge y$、$t \ge 2y - \mathbf{1}$ 完全同构。

**消失测试**：抽掉 $0 \lt p_j^{\text{disc}} \lt p_j$ 这个排序（比如让折扣价高于原价），$r_j$ 就不再是凹函数——它变成 $\max_k L_k$，其 hypograph 非凸，LP 的两条约束变成「$\nu \le$ 其中至少一条」的析取，必须引入 $2^n$ 个 0-1 变量才能表达；这就是「批量折扣定价反了会让问题变成 NP-hard」的具体机制。

**量的方向感**：分段线性凹目标转 LP 后变量只增加 $n$ 个（每个活动一个 $u_j$）、约束增加 $2n$ 条，与原始规模同阶；若改用通用凸规划求解器（如 interior-point 处理一般 $\min$ 形式），每步要算 $n$ 个 $\min$ 的次梯度，迭代数随精度 $\epsilon$ 呈 $O(\log(1/\epsilon))$ 但每步代价高一个量级。

**落点**：Boyd §4.3.2（分段线性凸函数的 LP 表述，正是这一题的来源）；4.16 是同一手法的 actuator 版本；运营研究侧的一手来源是 Bertsimas & Tsitsiklis *Introduction to Linear Optimization* §1.2 的 production planning 例子（同一结构）。</span>


```math
\operatorname{\mathbf{rank}}\begin{bmatrix} v^1 & v^2 & \cdots & v^K & w^1 & w^2 & \cdots & w^L\\ 1 & 1 & \cdots & 1 & 1 & 1 & \cdots & 1\end{bmatrix} = n+1
```

```math
\|v^{i} - x_c\|_2 \le R,\quad i = 1,\ldots,K,\qquad \|w^{i} - x_c\|_2 \ge R,\quad i = 1,\ldots,L .
```


### Exercise 4.19

> 话题：目标是非线性的比值 $\|Ax-b\|_1/(c^Tx+d)$，但它 quasiconvex（拟凸），且可用一次变量替换 $y = x/\tau$ 把分母吸收掉——这是 perspective（透视）手法的前身。

**Consider the problem**

```math
\begin{aligned}
\text{minimize}\quad & \|Ax - b\|_1/(c^{T}x + d) \\
\text{subject to}\quad & \|x\|_\infty \le 1,
\end{aligned}
```

**where $A \in \mathbf{R}^{m\times n}$, $b \in \mathbf{R}^m$, $c \in \mathbf{R}^n$, and $d \in \mathbf{R}$. We assume that $d \gt \|c\|_1$, which implies that $c^{T}x + d \gt 0$ for all feasible $x$.**

**(a) Show that this is a quasiconvex optimization problem.**

**(b) Show that it is equivalent to the convex optimization problem**

```math
\begin{aligned}
\text{minimize}\quad & \|Ay - bt\|_1 \\
\text{subject to}\quad & \|y\|_\infty \le t\\
& c^{T}y + dt = 1,
\end{aligned}
```

**with variables $y \in \mathbf{R}^n$, $t \in \mathbf{R}$.**

**(a)** $f_0(x) \le \alpha$ 当且仅当

```math
\|Ax - b\|_1 - \alpha(c^{T}x + d) \le 0,
```

这是一个凸约束。

> 复算：把分子分母同时乘上正的 $c^{T}x + d$（$d \gt \|c\|_1$ 保证它恒正：$c^{T}x \ge -\|c\|_1\|x\|_\infty \ge -\|c\|_1$，故 $c^{T}x + d \ge d - \|c\|_1 \gt 0$）✓。对每个固定 $\alpha$，左端是 $(x,\alpha)$ 的联合凸函数，因此 sublevel set 关于 $x$ 是凸的，quasiconvex（拟凸）成立 ✓。**原文无误**，只是没写出「分母为正」这一步为何必要——若 $c^{T}x + d$ 可变号，乘过去会翻转不等号。

**(b)** 设 $\|x\|_\infty \le 1$。由 $d \gt \|c\|_1$ 得 $c^{T}x + d \gt 0$。定义

```math
y = x/(c^{T}x + d),\qquad t = 1/(c^{T}x + d).
```

那么 $y$ 与 $t$ 在凸问题中可行，且目标值为

```math
\|Ay - bt\|_1 = \|Ax - b\|_1/(c^{T}x + d).
```

<!-- ===== p091 ===== -->

反过来，设 $y, t$ 对凸问题可行。必须有 $t \gt 0$：若 $t = 0$，则 $\|y\|_\infty \le 0$ 给出 $y = 0$，而 $c^{T}y + dt = 0$ 与 $c^{T}y + dt = 1$ 矛盾。定义

```math
x = y/t .
```

那么 $\|x\|_\infty \le 1$，且 $c^{T}x + d = 1/t$，于是

```math
\|Ax - b\|_1/(c^{T}x + d) = \|Ay - bt\|_1 .
```

> 复算：正向 $t = 1/(c^{T}x+d) \gt 0$ ✓，$\|y\|_\infty = \|x\|_\infty/(c^{T}x+d) \le t$ ✓，$c^{T}y + dt = (c^{T}x+d)/(c^{T}x+d) = 1$ ✓。反向 $c^{T}x + d = c^{T}y/t + d = (c^{T}y + dt)/t = 1/t$ ✓，$\|Ay - bt\|_1 = \|A(y/t) - b\|_1\cdot t = \|Ax - b\|_1/(c^{T}x+d)$ ✓。这是**双向一一对应的同构**，所以原问题的最优解与凸问题的最优解可以互相算出来。**原文无误**。

### Exercise 4.20 Power assignment in a wireless communication system

> 话题：SINR 最大化写成 generalized linear-fractional program（广义线性分式规划）——分子分母都是仿射，取 max 之后仍然是拟凸的。

**We consider $n$ transmitters with powers $p_1,\ldots,p_n \ge 0$, transmitting to $n$ receivers. These powers are the optimization variables in the problem. We let $G \in \mathbf{R}^{n\times n}$ denote the matrix of path gains from the transmitters to the receivers; $G_{ij} \ge 0$ is the path gain from transmitter $j$ to receiver $i$. The signal power at receiver $i$ is then $S_i = G_{ii}p_i$, and the interference power at receiver $i$ is $I_i = \sum_{k \neq i}G_{ik}p_k$. The signal to interference plus noise ratio, denoted SINR, at receiver $i$, is given by $S_i/(I_i + \sigma_i)$, where $\sigma_i \gt 0$ is the (self-) noise power in receiver $i$. The objective in the problem is to maximize the minimum SINR ratio, over all receivers, i.e., to maximize**

```math
\min_{i=1,\ldots,n}\frac{S_i}{I_i + \sigma_i} .
```

**There are a number of constraints on the powers that must be satisfied, in addition to the obvious one $p_i \ge 0$. The first is a maximum allowable power for each transmitter, i.e., $p_i \le P_i^{\max}$, where $P_i^{\max} \gt 0$ is given. In addition, the transmitters are partitioned into groups, with each group sharing the same power supply, so there is a total power constraint for each group of transmitter powers. More precisely, we have subsets $K_1,\ldots,K_m$ of $\{1,\ldots,n\}$ with $K_1 \cup \cdots \cup K_m = \{1,\ldots,n\}$, and $K_j \cap K_l = \emptyset$ if $j \neq l$. For each group $K_l$, the total associated transmitter power cannot exceed $P_l^{\text{gp}} \gt 0$:**

```math
\sum_{k \in K_l}p_k \le P_l^{\text{gp}},\qquad l = 1,\ldots,m .
```

**Finally, we have a limit $P_k^{\text{rc}} \gt 0$ on the total received power at each receiver:**

```math
\sum_{k=1}^{n}G_{ik}p_k \le P_i^{\text{rc}},\qquad i = 1,\ldots,n .
```

**(This constraint reflects the fact that the receivers will saturate if the total received power is too large.)**

**Formulate the SINR maximization problem as a generalized linear-fractional program.**

**Solution.**

```math
\begin{aligned}
\text{minimize}\quad & \max_i \Bigl(\sum_{k \neq i}G_{ik}p_k + \sigma_i\Bigr)/(G_{ii}p_i)\\
\text{subject to}\quad & 0 \le p_i \le P_i^{\max},\quad i = 1,\ldots,n\\
& \sum_{k \in K_l}p_k \le P_l^{\text{gp}},\quad l = 1,\ldots,m\\
& \sum_{k=1}^{n}G_{ik}p_k \le P_i^{\text{rc}},\quad i = 1,\ldots,n
\end{aligned}
```

> † 这一处是**排版级**问题，不是数学错：原文用两个 `array` 环境右对齐拼出这一段，PDF 抽取后约束的指标范围（$i = 1,\ldots,n$、$l = 1,\ldots,m$）全部丢失，读起来像三条无名约束。上表已补全指标。数学内容（分子 = 干扰加噪声、分母 = 信号、取 max 后最小化）与原题等价 ✓。
>
> 复算：$\max_i \frac{I_i + \sigma_i}{G_{ii}p_i} = 1/\bigl(\min_i \frac{G_{ii}p_i}{I_i+\sigma_i}\bigr)$，所以「最大化最小 SINR」与「最小化 max 的倒数」同一件事 ✓。每个比值分子分母都是 $p$ 的仿射函数，分母 $G_{ii}p_i \ge 0$，所以整题是 generalized linear-fractional program ✓——理论上可再用 Chiappori–Horn 式的变量替换（$q = p/\theta$）转成 LP，但原题只要求到这个形式。

**(c) Minimizing a quadratic form over an ellipsoid centered at the origin.**

```math
\begin{aligned}
\text{minimize}\quad & x^{T}Bx \\
\text{subject to}\quad & x^{T}Ax \le 1,
\end{aligned}
```

**Solution.** 若 $B \succeq 0$，最优值显然是零（因为对所有 $x$ 有 $x^{T}Bx \ge 0$，且 $x = 0$ 时取等号）。

在一般情形下，用到线性代数里的如下事实。对 $B \in \mathbf{S}^n$，最小特征值可刻画为

```math
\lambda_{\min}(B) = \inf_{x^{T}x = 1}x^{T}Bx .
```

为求解优化问题

```math
\begin{aligned}
\text{minimize}\quad & x^{T}Bx \\
\text{subject to}\quad & x^{T}Ax \le 1,
\end{aligned}
```

（其中 $A \succ 0$），做变量替换 $y = A^{1/2}x$。这一步之所以可行，是因为 $A \succ 0$，所以 $A^{1/2}$ 有定义且非奇异。在新变量下问题变成

```math
\begin{aligned}
\text{minimize}\quad & y^{T}A^{-1/2}BA^{-1/2}y \\
\text{subject to}\quad & y^{T}y \le 1 .
\end{aligned}
```

若约束 $y^{T}y \le 1$ 在最优处是 active 的（即 $y^{T}y = 1$），则由上面提到的结论，最优值为

```math
\lambda_{\min}(A^{-1/2}BA^{-1/2}).
```

若最优处 $y^{T}y \lt 1$，则最优处必是目标函数梯度为零的点，即 $By = 0$；此时最优值为零。

汇总，最优值为

```math
p^\star = \begin{cases}
\lambda_{\min}(A^{-1/2}BA^{-1/2}), & \lambda_{\min}(A^{-1/2}BA^{-1/2}) \le 0,\\
0, & \text{otherwise}.
\end{cases}
```

第一种情形下，$A^{-1/2}BA^{-1/2}$ 属于最小特征值的任意（单位化）特征向量都是最优的 $y$。第二种情形下 $y = 0$ 最优。

> 复算：$y^{T}A^{-1/2}BA^{-1/2}y$ 在单位球上的最小值就是 $M = A^{-1/2}BA^{-1/2}$ 的最小特征值（Rayleigh quotient 在 $\|y\| = 1$ 上的最小值），而 $y = 0$ 给 $0$。所以在 $y$ 只在球内取值的连续问题上，最小是 $\min\{\lambda_{\min}(M), 0\}$——因为 $0$ 总是可达（取 $y = 0$），且若 $\lambda_{\min}(M) \gt 0$ 则全空间非负。$\lambda_{\min}(M) \le 0$ 时最优在球面上取到，与「active」一致 ✓。**原文无误**。
>

```math
p^\star = \min\Bigl\{0,\ \lambda_{\min}(A^{-1/2}BA^{-1/2})\Bigr\}
```

而 $\lambda_{\min}(A^{-1/2}BA^{-1/2})$ 与「广义特征值 $\lambda$ 使 $Bz = \lambda Az$ 有非零解」的最小 $\lambda$ 是**同一个数**（两边左乘 $A^{-1/2}$ 即可看出）。也就是说：椭球 $x^{T}Ax \le 1$ 上二次型 $x^{T}Bx$ 的最小值，等于广义特征方程 $\det(B - \lambda A) = 0$ 的最小根。$B \succ 0$ 时这个根为正，于是 $p^\star = 0$ 被 $x = 0$ 独占——这就是为什么原文先说「$B \succeq 0$ 时最优值显然是零」。

**消失测试**：抽掉 $A \succ 0$ 这步（比如 $A$ 只有半正定），$A^{-1/2}$ 不存在，$y = A^{1/2}x$ 也不再可逆，整个「拉成单位球」的变换崩掉；此时约束集是退化的椭球柱，最优值可能 $-\infty$（沿 nullspace 方向 $B$ 取负值），前面「$p^\star = \min\{0,\lambda_{\min}\}$」的公式给不出这个 $-\infty$。$n = 1$、$A = 0$、$B = -1$ 即：约束 $0 \le 1$ 恒成立，目标 $-x^{2}$ 无界。

### Exercise 4.22

> 话题：球约束 QP 的 KKT 解——$\lambda$ 由一条一维单调方程定出，整个问题退化成「解一个非线性方程」。

**Consider the QCQP**

```math
\begin{aligned}
\text{minimize}\quad & (1/2)x^{T}Px + q^{T}x + r \\
\text{subject to}\quad & x^{T}x \le 1,
\end{aligned}
```

**with $P \in \mathbf{S}^n_{++}$. Show that $x^\star = -(P + \lambda I)^{-1}q$ where $\lambda = \max\{0,\bar\lambda\}$ and $\bar\lambda$ is the largest solution of the nonlinear equation**

```math
q^{T}(P + \lambda I)^{-2}q = 1 .
```

**Solution.** $x$ 最优当且仅当

```math
x^{T}x \lt 1,\quad Px + q = 0
```

或

```math
x^{T}x = 1,\quad Px + q = -\lambda x
```

<!-- ===== p094 ===== -->

对某个 $\lambda \ge 0$ 成立。（几何上：要么 $x$ 在球内部而梯度为零，要么 $x$ 在球面上，且负梯度与外法向平行。）

算法如下。先解 $Px = -q$。若该解的范数不超过 $1$（即 $\|P^{-1}q\|_2 \le 1$），它就是最优解。否则由最优性条件，$x$ 必须满足 $\|x\|_2 = 1$ 且 $(P + \lambda)x = -q$ 对某个 $\lambda \ge 0$ 成立。定义

```math
f(\lambda) = \|(P + \lambda)^{-1}q\|_2^{2} = \sum_{i=1}^{n}\frac{q_i^{2}}{(\lambda + \lambda_i)^{2}},
```

其中 $\lambda_i \gt 0$ 是 $P$ 的特征值。（注意对一切 $\lambda \ge 0$ 有 $P + \lambda I \succ 0$，因为 $P \succ 0$。）有 $f(0) = \|P^{-1}q\|_2^{2} \gt 1$。且当 $\lambda \to \infty$ 时 $f$ 单调下降趋于零。因此非线性方程 $f(\lambda) = 1$ 恰有一个非负解 $\bar\lambda$。解出 $\bar\lambda$ 后，最优解为 $x^\star = -(P + \bar\lambda I)^{-1}q$。

> 复算：$f$ 的每一项 $\frac{q_i^{2}}{(\lambda+\lambda_i)^{2}}$ 对 $\lambda \ge 0$ 严格递减（$\lambda_i \gt 0$，分母恒正），所以 $f$ 严格单调递减、从 $f(0) \gt 1$ 降到 $0$，故 $f(\lambda) = 1$ 在 $(0,\infty)$ 上**恰好一个根** ✓。原文说「the largest solution」其实是「唯一解」，这个措辞来自题面（题面写 largest，因为对一般 $P$ 可能多解），解答给出的单调性论证更强。$x^\star$ 处 $\|x^\star\|^{2} = f(\bar\lambda) = 1$ ✓。**原文无误**。
>
> 量的方向感（原文没写但值得知道）：$f$ 的求根用 Newton 一般 5–8 步到 double 精度；二分只需 $\log_2(10^{16}) \approx 53$ 步即可，因为 $f$ 的单调性保证二分必收敛。

### Exercise 4.23 $\ell_4$-norm approximation via QCQP

> 话题：$\ell_4$ 范数不是范数的平方那样直接二次，但 $(\sum y_i^{4})^{1/2}$ 是二次的——引入 $z_i$ 把四次幂摊成两个二次约束。

**Formulate the $\ell_4$-norm approximation problem**

```math
\text{minimize}\quad \|Ax - b\|_4 = \Bigl(\sum_{i=1}^{m}(a_i^{T}x - b_i)^{4}\Bigr)^{1/4}
```

**as a QCQP. The matrix $A \in \mathbf{R}^{m\times n}$ (with rows $a_i^{T}$) and the vector $b \in \mathbf{R}^m$ are given.**

**Solution.**

```math
\begin{aligned}
\text{minimize}\quad & \sum_{i=1}^{m}z_i^{2} \\
\text{subject to}\quad & a_i^{T}x - b_i = y_i,\quad i = 1,\ldots,m\\
& y_i^{2} \le z_i,\quad i = 1,\ldots,m
\end{aligned}
```

> 复算：约束 $y_i^{2} \le z_i$ 强推 $z_i \ge y_i^{2} \ge 0$，最小化 $\sum z_i^{2}$ 时 $z_i$ 被顶到 $y_i^{2}$，于是目标 $= \sum y_i^{4} = \|Ax-b\|_4^{4}$，而 $\|\cdot\|_4^{4}$ 与 $\|\cdot\|_4$ 同解（单调变换）✓。$y_i^{2} \le z_i$ 是旋转锥（rotated cone）的截面，凸 ✓；$\sum z_i^{2}$ 凸 ✓。所以这是一个 QCQP ✓。
>
> **原文的变量声明漏了**：$y, z$ 是额外变量（原文只在式子里出现，没有一句「variables are $x, y, z$」）。这不是数学错，但读者会以为 $y,z$ 是给定的。补：变量为 $x \in \mathbf{R}^n$、$y \in \mathbf{R}^m$、$z \in \mathbf{R}^m$，共 $n + 2m$ 个，约束 $2m$ 条。

### Exercise 4.24 Complex $\ell_1$-, $\ell_2$- and $\ell_\infty$-norm approximation

> 话题：复变量问题化实——把 $x$ 拆成 $[\Re x; \Im x]$，每个复数线性式就变成 $2\times 2$ 的实块矩阵。

**Consider the problem**

```math
\text{minimize}\quad \|Ax - b\|_p,
```

**where $A \in \mathbf{C}^{m\times n}$, $b \in \mathbf{C}^m$, and the variable is $x \in \mathbf{C}^n$. The complex $\ell_p$-norm is defined by**

```math
\|y\|_p = \Bigl(\sum_{i=1}^{m}|y_i|^{p}\Bigr)^{1/p}
```

**for $p \ge 1$, and $\|y\|_\infty = \max_{i=1,\ldots,m}|y_i|$. For $p = 1, 2$, and $\infty$, express the complex $\ell_p$-norm approximation problem as a QCQP or SOCP with real variables and data.**

**Solution.**

**(a)** 最小化 $\|Ax - b\|_2$ 等价于最小化它的平方。于是把 $\|Ax - b\|_2^{2}$ 按 $Ax - b$ 的实部与虚部展开：

```math
\begin{aligned}
\|Ax - b\|_2^{2}
&= \|\Re(Ax - b)\|_2^{2} + \|\Im(Ax - b)\|_2^{2}\\
&= \|\Re A\,\Re x - \Im A\,\Im x - \Re b\|_2^{2} + \|\Re A\,\Im x + \Im A\,\Re x - \Im b\|_2^{2}.
\end{aligned}
```

若按题目要求记 $z^{T} = [\,\Re x^{T}\ \ \Im x^{T}\,]$，上式变为

```math
\begin{aligned}
\|Ax - b\|_2^{2}
&= \|[\Re A\ \ -\Im A]z - \Re b\|_2^{2} + \|[\Im A\ \ \Re A]z - \Im b\|_2^{2}\\
&= \left\|\begin{bmatrix}\Re A & -\Im A\\ \Im A & \Re A\end{bmatrix}z - \begin{bmatrix}\Re b\\ \Im b\end{bmatrix}\right\|_2^{2}.
\end{aligned}
```

$F$ 与 $g$ 的取值可以由上式读出。

> † 原文此段的两个范数**丢了右下角下标 $2$**（`∥[ℜA −ℑA]z −ℜb∥2 + ∥[ℑA ℜA]z −ℑb∥2`，文本层里两个 $\|\cdot\|_2$ 的 $2$ 都没了），视觉核对只影响排版不影响数学。**但末句 `The values of F and g can be extracted from the above expression` 是残句**——这一段里从头到尾没有定义过 $F$ 与 $g$。它是从别处（应为 §4.5 的 complex $\ell_2$ 最小二乘，那里写成 $\|Fz - g\|_2$）抄来的收尾语。读者按 $F = \begin{bmatrix}\Re A & -\Im A\\ \Im A & \Re A\end{bmatrix}$、$g = \begin{bmatrix}\Re b\\ \Im b\end{bmatrix}$ 理解即可，**公式本身正确**。

<!-- ===== p095 ===== -->

**(b)** 先把优化问题逐项写出来：

```math
\text{minimize}\quad \|Ax - b\|_\infty
```

等价于

```math
\begin{aligned}
\text{minimize}\quad & t \\
\text{subject to}\quad & |a_i^{T}x - b_i| \le t,\qquad i = 1,\ldots,m,
\end{aligned}
```

其中 $a_1^{T},\ldots,a_m^{T}$ 是 $A$ 的各行。这里引入了一个新的优化变量 $t$。

现在每一项 $|a_i^{T}x - b_i|$ 都必须用实变量写出（用与前面相同的 $z$）：

```math
\begin{aligned}
|a_i^{T}x - b_i|^{2}
&= (\Re a_i^{T}\Re x - \Im a_i^{T}\Im x - \Re b_i)^{2} + (\Re a_i^{T}\Im x + \Im a_i^{T}\Re x - \Im b_i)^{2}\\
&= \left\|\begin{bmatrix}\Re a_i^{T} & -\Im a_i^{T}\\ \Im a_i^{T} & \Re a_i^{T}\end{bmatrix}z - \begin{bmatrix}\Re b_i\\ \Im b_i\end{bmatrix}\right\|_2^{2}.
\end{aligned}
```

于是问题归约为实的最小化

```math
\begin{aligned}
\text{minimize}\quad & t \\
\text{subject to}\quad & \left\|\begin{bmatrix}\Re a_i^{T} & -\Im a_i^{T}\\ \Im a_i^{T} & \Re a_i^{T}\end{bmatrix}z - \begin{bmatrix}\Re b_i\\ \Im b_i\end{bmatrix}\right\|_2 \le t,\qquad i = 1,\ldots,m .
\end{aligned}
```

这是在二阶锥上的最小化。还可以再转成 QCQP：把约束两边平方并定义 $\lambda = t^{2}$：

```math
\begin{aligned}
\text{minimize}\quad & \lambda \\
\text{subject to}\quad & \left\|\begin{bmatrix}\Re a_i^{T} & -\Im a_i^{T}\\ \Im a_i^{T} & \Re a_i^{T}\end{bmatrix}z - \begin{bmatrix}\Re b_i\\ \Im b_i\end{bmatrix}\right\|_2^{2} \le \lambda,\qquad i = 1,\ldots,m .
\end{aligned}
```

> † **原文这一支有两处错，一处硬、一处软。**
>
> **硬错（维度不匹配）**：原文把平方展开后的第二项减数写成整个向量 $\begin{bmatrix}\Re b\\ \Im b\end{bmatrix}$（$b \in \mathbf{C}^m$，即 $2m$ 维），而左边是 $2\times 2n$ 矩阵乘 $2n$ 向量得 $2$ 维向量。$m \gt 1$ 时 $2$ 与 $2m$ 无法相减。**正确**：逐项处理时减数是标量 $b_i$ 的实虚部，即 $\begin{bmatrix}\Re b_i\\ \Im b_i\end{bmatrix}$（$2$ 维）。
> **数值反例**：$m = 2$、$n = 1$、$A = (1;\,2)$、$b = (1;\,1)$。第 $i=1$ 项的 $|a_1x - b_1|^{2}$ 是标量，按原文要减去 $\begin{bmatrix}\Re b_1\\ \Im b_1\\ \Re b_2\\ \Im b_2\end{bmatrix}$ 四维向量，维度先是 2 vs 4 对不上；即便强行截断，第二项 $i=2$ 会用到 $b_1$ 的值，得到 $|2x - 1|^{2}$ 之外多算一项，等式立刻不成立。
> **软错（严格不等号）**：原文写 `|a_i^Tx − b_i| < t` 与 `... < t`，用了**严格**不等号。二阶锥 $\{(w,t) \mid \|w\|_2 \le t\}$ 是闭凸集，用 $\lt$ 把它挖成开集后可行域不再是闭集，最优值可能不可达（solver 报「无最优解」而不是给一个点）。**正确**：一律写 $\le$。
> **为什么会写错**：$\LaTeX$ 源里 `$b_i$` 与 `$b$` 在一处拖漏了下标 $i$（同一段的公式与文字里 $b_i$ 出现过 4 次、$b$ 出现过 1 次，恰好漏在最不能漏的位置）；$\lt$ 与 $\le$ 则是抄讲义时的习惯性宽松写法。

**(c)** $\ell_1$-范数最小化问题是

```math
\text{minimize}\quad \sum_{i=1}^{m}|a_i^{T}x - b_i| .
```

引入新变量 $t_1,\ldots,t_m$，把最小化改写为

```math
\begin{aligned}
\text{minimize}\quad & \sum_{i=1}^{m}t_i \\
\text{subject to}\quad & |a_i^{T}x - b_i| \le t_i,\qquad i = 1,\ldots,m .
\end{aligned}
```

化归为二阶锥约束的方式与 (b) 类似：

```math
\begin{aligned}
\text{minimize}\quad & \sum_{i=1}^{m}t_i \\
\text{subject to}\quad & \left\|\begin{bmatrix}\Re a_i^{T} & -\Im a_i^{T}\\ \Im a_i^{T} & \Re a_i^{T}\end{bmatrix}z - \begin{bmatrix}\Re b_i\\ \Im b_i\end{bmatrix}\right\|_2 \le t_i,\qquad i = 1,\ldots,m .
\end{aligned}
```

**(a) 与 (c) 的共同机制**：复数乘法的实矩阵表示 $\begin{bmatrix}\Re a^{T} & -\Im a^{T}\\ \Im a^{T} & \Re a^{T}\end{bmatrix}$ 正是把复数乘法写成 $\mathbf{R}^2$ 上的 $2\times 2$ 旋转-伸缩矩阵（$a = \alpha + \beta i$ 时它就是 $\begin{bmatrix}\alpha & -\beta\\ \beta & \alpha\end{bmatrix}$）。于是 $|a^{T}x - b|_2 = \|Mz - g\|_2$ 逐项成立，(b)(c) 的 SOC 形式都靠它。

### Exercise 4.25 Linear separation of two sets of ellipsoids

> 话题：椭球族之间的严格分离——严格性用齐次性归一化成 $\pm 1$，椭球上的极值用 support function（支撑函数）$-r\|P^{T}a\| + a^{T}q$ 换成 SOC 约束。

**Suppose we are given $K+L$ ellipsoids**

```math
\mathcal{E}_i = \{P_iu + q_i \mid \|u\|_2 \le 1\},\qquad i = 1,\ldots,K+L,
```

**where $P_i \in \mathbf{S}^n$. We are interested in finding a hyperplane that strictly separates $\mathcal{E}_1,\ldots,\mathcal{E}_K$ from $\mathcal{E}_{K+1},\ldots,\mathcal{E}_{K+L}$, i.e., we want to compute $a \in \mathbf{R}^n$, $b \in \mathbf{R}$ such that**

```math
a^{T}x + b \gt 0 \ \ \text{for } x \in \mathcal{E}_1 \cup \cdots \cup \mathcal{E}_K,
```

```math
a^{T}x + b \lt 0 \ \ \text{for } x \in \mathcal{E}_{K+1} \cup \cdots \cup \mathcal{E}_{K+L},
```

<!-- ===== p096 ===== -->

**or prove that no such hyperplane exists. Express this problem as an SOCP feasibility problem.**

**Solution.** 先注意问题对 $a$ 与 $b$ 是**齐次**的，所以可以把严格不等式 $a^{T}x + b \gt 0$ 与 $a^{T}x + b \lt 0$ 分别换成 $a^{T}x + b \ge 1$ 与 $a^{T}x + b \le -1$。

变量 $a$ 与 $b$ 必须满足

```math
\inf_{\|u\|_2 \le 1}\bigl(a^{T}P_iu + a^{T}q_i\bigr) + b \ge 1,\qquad i = 1,\ldots,K,
```

以及

```math
\sup_{\|u\|_2 \le 1}\bigl(a^{T}P_iu + a^{T}q_i\bigr) + b \le -1,\qquad i = K+1,\ldots,K+L .
```

这些左端可以写成

```math
\inf_{\|u\|_2 \le 1}\bigl(a^{T}P_iu + a^{T}q_i\bigr) = -\|P_i^{T}a\|_2 + a^{T}q_i,
\qquad
\sup_{\|u\|_2 \le 1}\bigl(a^{T}P_iu + a^{T}q_i\bigr) = \|P_i^{T}a\|_2 + a^{T}q_i .
```

于是得到关于 $a, b$ 的一组二阶锥约束：

```math
-\|P_i^{T}a\|_2 + a^{T}q_i + b \ge 1,\qquad i = 1,\ldots,K,
```

```math
\|P_i^{T}a\|_2 + a^{T}q_i + b \le -1,\qquad i = K+1,\ldots,K+L .
```

> † **原文这一题有三处错**。
>
> **① 第一组的指标范围写成了 $L$（硬错）**。原文第一组下标是 `i = 1, . . . , L`，最后那组 SOC 约束也写成 `i = 1, . . . , L`。前 $K$ 个椭球才是要满足「$a^{T}x + b \ge 1$」的一侧，必须是 $i = 1,\ldots,K$。
> **数值反例**：$K = 3$、$L = 1$。按原文只对 $i = 1$ 施加下界，$\mathcal{E}_2, \mathcal{E}_3$ 完全没有被约束——解出来的「分离超平面」可能把 $\mathcal{E}_2$ 切成两半。$K \gt L$ 时漏掉 $K - L = 2$ 个椭球，$K \lt L$ 时又把本该在下界的椭球（$i = K+1,\ldots,L$）错当成上界处理，两种情形都错。
> **为什么会写错**：$K + L$ 个椭球被切成两段，写作时把第一段的右端点写成了第二段的「剩余段长度」$L$ 而不是「第一段长度」$K$。
>
> **② $\inf$ 那一行漏了 $+b$（硬错）**。原文写 $\inf_{\|u\|\le1}(a^{T}P_iu + a^{T}q_i) \ge 1$，左边不含 $b$，而它要表达的正是 $a^{T}x + b \ge 1$（$+b$ 在 $\inf$ 之外、与 $u$ 无关，可以提出来）。原文在往下算的两行里又把 $+b$ 补上了，前后不一致。
> **数值反例**（$n = 1$）：$P_1 = 2$、$q_1 = 0$、$a = 1$、$b = 3$。椭球族是 $\mathcal{E}_1 = [-2,2]$，加上 $b$ 之后 $a^{T}x + b$ 在 $\mathcal{E}_1$ 上的下确界是 $-2 + 3 = 1 \ge 1$ ✓ **可行**。按漏掉 $b$ 的原文：$\inf(a^{T}P_1u) = -2 \ge 1$ ✗ 判**不可行**。同一个点，两个结论相反。
> **为什么会写错**：$\inf$ 的括号里只放了 $u$ 依赖的两项，$b$ 被当成「后面再说」，结果在第一行忘了补。
>
> **③ 题面声明 $P_i \in \mathbf{S}^n$**（对称）。椭球 $\{Pu + q\}$ 的 $P$ 一般**不必对称**（只有 $PP^{T}$ 决定形状）；把 $P_i$ 限制在 $\mathbf{S}^n$ 会漏掉「旋转后的椭球」。这不是答案的错（原题就这么写），但按 $\mathbf{S}^n$ 去实现会得到偏保守的结果。
>
> 复算支撑函数那两行：$\sup_{\|u\|\le1}a^{T}P_iu = \|P_i^{T}a\|_2$（Cauchy–Schwarz，取 $u = P_i^{T}a/\|P_i^{T}a\|$）✓，$\inf$ 就是它的相反数 ✓。这一对式子是**对的**，只是被前面那个漏 $b$ 的版本拖累了。

### Exercise 4.26 Hyperbolic constraints as SOC constraints

> 话题：双曲约束 $x^{T}x \le yz$（$y,z \ge 0$）等价于一个 SOC——这是把几何平均、矩阵分式等一大批非线性约束拉进 SOCP 的**唯一通道**。

**Verify that $x \in \mathbf{R}^n$, $y, z \in \mathbf{R}$ satisfy**

```math
x^{T}x \le yz,\qquad y \ge 0,\qquad z \ge 0
```

**if and only if**

```math
\left\|\begin{bmatrix}2x\\ y - z\end{bmatrix}\right\|_2 \le y + z,\qquad y \ge 0,\qquad z \ge 0 .
```

**Use this observation to cast the following problems as SOCPs.**

**(a) Maximizing harmonic mean.**

```math
\text{maximize}\quad \Bigl(\sum_{i=1}^{m}1/(a_i^{T}x - b_i)\Bigr)^{-1},
```

**with domain $\{x \mid Ax \succ b\}$, where $a_i^{T}$ is the $i$th row of $A$.**

**(b) Maximizing geometric mean.**

```math
\text{maximize}\quad \Bigl(\prod_{i=1}^{m}(a_i^{T}x - b_i)\Bigr)^{1/m},
```

**with domain $\{x \mid Ax \succeq b\}$, where $a_i^{T}$ is the $i$th row of $A$.**

**Solution.**

**(a)** 问题等价于

```math
\begin{aligned}
\text{minimize}\quad & \mathbf{1}^{T}t \\
\text{subject to}\quad & t_i\,(a_i^{T}x - b_i) \ge 1,\quad i = 1,\ldots,m\\
& t \succeq 0 .
\end{aligned}
```

把双曲约束写成 SOC 约束，得到 SOCP

```math
\begin{aligned}
\text{minimize}\quad & \mathbf{1}^{T}t \\
\text{subject to}\quad & \left\|\begin{bmatrix}2\\ a_i^{T}x - b_i - t_i\end{bmatrix}\right\|_2 \le a_i^{T}x - b_i + t_i,\quad i = 1,\ldots,m\\
& t_i \ge 0,\qquad a_i^{T}x - b_i \ge 0,\quad i = 1,\ldots,m .
\end{aligned}
```

> † **原文这一支全篇把 $b_i$ 的符号写反了（可验算硬错）**。原文是 `ti(a_i^T x + b_i) ≥ 1`，以及 SOC 里的 `a_i^T x + b_i − t_i` 与 `a_i^T x + b_i + t_i`。题面自己定义的是 $y_i = a_i^{T}x - b_i$（domain $\{x \mid Ax \succ b\}$ 就是由 $a_i^{T}x \gt b_i$ 定义的），所以全部 $+b_i$ 都必须是 $-b_i$。
> **数值反例**（$n = m = 1$）：$A = 1$、$b = 1$、$x = 2$。真值 $y = a^{T}x - b = 1$，于是 $t \ge 1/y = 1$，目标值 $1$。按原文 $t\,(x + b) = 3t \ge 1 \Rightarrow t \ge 1/3$，目标值 $1/3$——**差 3 倍**，且随 $b$ 增大越差越大（$x = b$ 附近原文会给出 $t \ge 1/(2b) \to 0$ 而真值 $\to \infty$）。
> **为什么会写错**：题面用 `Ax ≻ b`，正文用 $a_i^{T}x + b_i$，两处差一个符号；这是把 4.11 一类「$Ax - b$ 型残差」的写法惯性带进来的（那里 $b$ 是被减数）。
>
> 至于 SOC 形式本身：$\left\|\begin{bmatrix}2\\ y_i - t_i\end{bmatrix}\right\|_2 \le y_i + t_i$ 平方后是 $4 + (y_i - t_i)^{2} \le (y_i + t_i)^{2}$，即 $4 \le 4y_it_i$，即 $y_it_i \ge 1$ ✓——这正是双曲约束在 $x$ 取 $1$ 维、$x = 1$ 时的特例。**形式正确，符号全反。**

<!-- ===== p097 ===== -->

**(b)** 不失一般性可以假设 $m = 2^{K}$ 对某个正整数 $K$ 成立。（若不然，对 $i = m+1,\ldots,2^{K}$ 取 $a_i = 0$、$b_i = -1$，其中 $2^{K}$ 是大于 $m$ 的最小 $2$ 的幂。）

先以 $m = 4$（$K = 2$）为例。问题等价于

```math
\begin{aligned}
\text{maximize}\quad & y_1y_2y_3y_4 \\
\text{subject to}\quad & y = Ax - b\\
& y \succeq 0,
\end{aligned}
```

它可以写成

```math
\begin{aligned}
\text{maximize}\quad & t_1t_2 \\
\text{subject to}\quad & y = Ax - b\\
& y_1y_2 \ge t_1^{2}\\
& y_3y_4 \ge t_2^{2}\\
& y \succeq 0,\qquad t_1 \ge 0,\ t_2 \ge 0,
\end{aligned}
```

再进一步写成

```math
\begin{aligned}
\text{maximize}\quad & t \\
\text{subject to}\quad & y = Ax - b\\
& y_1y_2 \ge t_1^{2}\\
& y_3y_4 \ge t_2^{2}\\
& t_1t_2 \ge t^{2}\\
& y \succeq 0,\qquad t_1, t_2, t \ge 0 .
\end{aligned}
```

把三条双曲约束

```math
y_1y_2 \ge t_1^{2},\qquad y_3y_4 \ge t_2^{2},\qquad t_1t_2 \ge t^{2}
```

写成 SOC 约束，得到 SOCP：

```math
\begin{aligned}
\text{minimize}\quad & -t \\
\text{subject to}\quad & \left\|\begin{bmatrix}2t_1\\ y_1 - y_2\end{bmatrix}\right\|_2 \le y_1 + y_2,\qquad y_1 \ge 0,\ y_2 \ge 0\\
& \left\|\begin{bmatrix}2t_2\\ y_3 - y_4\end{bmatrix}\right\|_2 \le y_3 + y_4,\qquad y_3 \ge 0,\ y_4 \ge 0\\
& \left\|\begin{bmatrix}2t\\ t_1 - t_2\end{bmatrix}\right\|_2 \le t_1 + t_2,\qquad t_1 \ge 0,\ t_2 \ge 0\\
& y = Ax - b .
\end{aligned}
```

于是可以把问题表达为

```math
\begin{aligned}
\text{maximize}\quad & y_{00} \\
\text{subject to}\quad & y_{K-1,j} = a_{j+1}^{T}x - b_{j+1},\qquad j = 0,\ldots,2^{K-1}-1\\
& y_{ik}^{2} \le y_{i+1,2k}\,y_{i+1,2k+1},\qquad i = 0,\ldots,K-2,\ \ k = 0,\ldots,2^{i}-1\\
& Ax \succeq b,
\end{aligned}
```

其中引入了辅助变量 $y_{ij}$，$i = 0,\ldots,K-1$、$j = 0,\ldots,2^{i}-1$。把双曲约束写成 SOC 约束即得一个 SOCP。

等价性可以通过递归展开目标函数来证明：

```math
\begin{aligned}
y_{00}
&\le y_{10}y_{11}\\
&\le (y_{20}y_{21})(y_{22}y_{23})\\

&\le (y_{30}y_{31})(y_{32}y_{33})(y_{34}y_{35})(y_{36}y_{37})\\
&\ \ \vdots\\
&\le y_{K-1,0}\,y_{K-1,1}\,\cdots\,y_{K-1,2^{K}-1}\\
&= (a_1^{T}x - b_1)\cdots(a_m^{T}x - b_m).
\end{aligned}
```

> † **原文的层级索引自相矛盾（硬错，可点数）**。同一段里三处不一致：
> (i) 变量声明写 $j = 0,\ldots,2^{i}-1$，$i \le K-1$，故底层有 $2^{K-1}$ 个变量；
> (ii) 底层的赋值行写成 `y_{K-1,j-1} = a_j^Tx - b_j`，$j = 1,\ldots,m$，要求底层有 $m = 2^{K}$ 个变量；
> (iii) 展开式的最后一行写 $y_{K-1,0}\cdots y_{K-1,2^{K}-1}$，又要求 $2^{K}$ 个。
> **$2^{K-1}$ 与 $2^{K}$ 差一倍，三者不可能同时成立。**
> **正确写法**：层数取 $i = 0,\ldots,K$（共 $K+1$ 层），第 $i$ 层有 $2^{i}$ 个元素；底层为 $i = K$，赋值 $y_{K,j} = a_{j+1}^{T}x - b_{j+1}$，$j = 0,\ldots,2^{K}-1$；递推 $y_{ik}^{2} \le y_{i+1,2k}y_{i+1,2k+1}$ 对 $i = 0,\ldots,K-1$。
> **点数反例**（$m = 4$、$K = 2$）：正确应有 $1 + 2 + 4 = 7$ 个 $y$ 变量（层 $0,1,2$）。按原文的 $i = 0,\ldots,K-1$ 只有 $1 + 2 = 3$ 个（层 $0,1$），底层 2 个；而 $m = 4$ 个残差无处安放——写进 $y_{1,0},y_{1,1}$ 就只剩 2 个格子装 4 个数。
> **为什么会写错**：作者把「层号」与「指数」错开了一位——直觉上「$2^{K}$ 个叶子」应该在第 $K$ 层，但声明里写成 $K-1$；而赋值行与展开式是按正确的第 $K$ 层写的，于是同一段里两套编号并存。原文 $m = 4$ 的显式例子（$y_1y_2\ge t_1^2$、$y_3y_4 \ge t_2^2$、$t_1t_2\ge t^2$）是**对的**，可以拿来校验通式：那里层数是 3（$y$、$t$、$t$ 各一层），恰好是 $K+1 = 3$。

<span style="color:#1e8449;">**[译注]** 这条「双曲约束 ⇔ SOC」是整个第 4 章最值得背下来的一条恒等式，因为它把**乘积**（非线性、非凸的直觉来源）变成**锥**（凸、可解）。核心只有一行：

```math
x^{T}x \le yz,\ \ y,z \ge 0 \iff \left\|\begin{bmatrix}2x\\ y-z\end{bmatrix}\right\|_2 \le y + z
```

验证只需两边平方：左边给 $4\|x\|^{2} + (y-z)^{2} \le (y+z)^{2} = (y-z)^{2} + 4yz$，约掉 $(y-z)^2$ 得 $4\|x\|^2 \le 4yz$，正是 $x^{T}x \le yz$。**注意 $y,z \ge 0$ 这个前提不能丢**：$y = z = -1$、$x = 0$ 时 $x^{T}x = 0 \le yz = 1$ 成立，但 $\|0\| \le -2$ 不成立——两个命题在不加非负条件时**并不等价**，原文的「if and only if」是靠后半句的 $y \ge 0, z \ge 0$ 撑住的。

**消失测试**：抽掉这条恒等式，几何平均最大化就没有任何 SOCP 表述——它是 $\prod y_i$ 的 $1/m$ 次幂，既非凸也非凹，只有靠「两两配对 + 递归」把它拆成 $m-1$ 条双曲约束才进入凸优化；实操上会退化成在 $y$ 上做网格搜索，$m$ 每加 1 搜索量乘一个因子，$m = 20$ 时完全不可算。

**量的方向感**：一条 $m$ 项几何平均约束经这套二分树后变成 $m-1$ 条 SOC 约束、$2m-1$ 个辅助变量，规模**线性**于 $m$（不是 $2^m$）——这正是把它称为「SOCP 可表示」的意义。

**落点**：Boyd §4.4.2 与 §4.6（几何规划的 SOCP 表示）；这条恒等式首次出现在 §3.2.6 的「二次锥的等价刻画」；EE364a 的 lecture 6 有同一推导；对偶侧（Ch.5）会用它证明 geometric programming 的 dual 仍是 GP。</span>

### Exercise 4.27 Matrix fractional minimization via SOCP

> 话题：矩阵分式 $(Ax+b)^{T}(I + B\,\mathbf{diag}(x)B^{T})^{-1}(Ax+b)$ 的 SOCP 化——先用 Schur complement（舒尔补）引入 $v,w$，再把 $w_i^{2}/x_i$ 这类双曲项转 SOC。

**Express the following problem as an SOCP:**

```math
\begin{aligned}
\text{minimize}\quad & (Ax + b)^{T}(I + B\operatorname{\mathbf{diag}}(x)B^{T})^{-1}(Ax + b) \\
\text{subject to}\quad & x \succeq 0,
\end{aligned}
```

**with $A \in \mathbf{R}^{m\times n}$, $b \in \mathbf{R}^m$, $B \in \mathbf{R}^{m\times n}$. The variable is $x \in \mathbf{R}^n$.**

**Hint. First show that the problem is equivalent to**

```math
\begin{aligned}
\text{minimize}\quad & v^{T}v + w^{T}\operatorname{\mathbf{diag}}(x)^{-1}w \\
\text{subject to}\quad & v + Bw = Ax + b\\
& x \succeq 0,
\end{aligned}
```

**with variables $v \in \mathbf{R}^m$, $w, x \in \mathbf{R}^n$. (If $x_i = 0$ we interpret $w_i^{2}/x_i$ as zero if $w_i = 0$ and as $\infty$ otherwise.) Then use the results of exercise 4.26.**

**Solution.** 为证明与提示中的问题等价，先固定 $x \succeq 0$，对 $v$ 与 $w$ 优化。这是一个带等式约束的二次问题。最优性条件为

```math
2v + \nu = 0,\qquad 2\,\operatorname{\mathbf{diag}}(x)^{-1}w + B^{T}\nu = 0
```

对某个 $\nu$ 成立。

> † 原文此处写的是 `v = ν`、`w = diag(x)B^Tν`，**把因子 $2$ 与负号一起吞掉了**。按目标 $v^{T}v + w^{T}\operatorname{\mathbf{diag}}(x)^{-1}w$ 与约束 $v + Bw = Ax + b$ 直接求导，正确的一阶条件是 $\partial_v:\ 2v + \nu = 0$、$\partial_w:\ 2D^{-1}w + B^{T}\nu = 0$（$D = \operatorname{\mathbf{diag}}(x)$），即 $v = -\nu/2$、$w = -DB^{T}\nu/2$。
> **为什么最终结论仍然对**：把 $\nu$ 当自由记号重新定义（$\mu := -\nu/2$）就得到原文那两行，后面的解 $v = (I + BDB^{T})^{-1}(Ax+b)$、$w = DB^{T}(I+BDB^{T})^{-1}(Ax+b)$ 与严格推导**逐字相同**，所以这是**跳步**而非**错结论**。但读者若照原文的一阶条件去算，会得到 $c = v + Bw = (I + BDB^{T})\nu$，与原文下一句「$\nu$ 必须满足 $(I + BDB^{T})\nu = Ax + b$」自相矛盾（差因子 $-2$）——必须把 $\nu$ 读成重定义后的量才自洽。

代回等式约束，可见 $\nu$ 必须满足

```math
(I + B\operatorname{\mathbf{diag}}(x)B^{T})\nu = Ax + b,
```

并且由于左端矩阵在 $x \succeq 0$ 时可逆，有

```math
v = \nu = (I + B\operatorname{\mathbf{diag}}(x)B^{T})^{-1}(Ax + b),
```

```math
w = \operatorname{\mathbf{diag}}(x)B^{T}(I + B\operatorname{\mathbf{diag}}(x)B^{T})^{-1}(Ax + b).
```

把这些代入提示中问题的目标，得

```math
v^{T}v + w^{T}\operatorname{\mathbf{diag}}(x)^{-1}w = (Ax + b)^{T}(I + B\operatorname{\mathbf{diag}}(x)B^{T})^{-1}(Ax + b).
```

这说明原问题与提示中的问题等价。

> 复算（这一步值得手推一遍）：记 $M = I + BDB^{T}$、$c = Ax + b$。则
> $v^{T}v = c^{T}M^{-2}c$，$w^{T}D^{-1}w = c^{T}M^{-1}BDB^{T}M^{-1}c$。用 $BDB^{T} = M - I$ 把第二项写成 $c^{T}(M^{-1} - M^{-2})c$。两项相加 $M^{-2}$ 抵消，只剩 $c^{T}M^{-1}c$ ✓。**结论正确**。

接着，与习题 4.26 一样引入双曲约束，可以把提示中的问题表述为

```math
\begin{aligned}
\text{minimize}\quad & t + \mathbf{1}^{T}s \\
\text{subject to}\quad & v^{T}v \le t\\
& w_i^{2} \le s_ix_i,\qquad i = 1,\ldots,n\\
& x \succeq 0,
\end{aligned}
```

变量为 $t \in \mathbf{R}$、$s, x, w \in \mathbf{R}^n$、$v \in \mathbf{R}^m$。把双曲约束转成 SOC 约束，即得 SOCP。

> 复算：$w_i^{2} \le s_ix_i$ 在最小化下把 $s_i$ 顶到 $w_i^{2}/x_i$（$x_i \gt 0$），于是 $\mathbf{1}^{T}s = w^{T}D^{-1}w$ ✓；$v^{T}v \le t$ 把 $t$ 顶到 $\|v\|^{2}$ ✓。
> **但这一步还不是 SOCP**：$v^{T}v \le t$ 是**二次**约束，标准 SOC 形式要求 $\left\|\begin{bmatrix}2v\\ t-1\end{bmatrix}\right\|_2 \le t+1$（或等价地 $\|v\|_2 \le \sqrt{t}$，再用 $t$ 与 $\sqrt{t}$ 之间的双曲约束）。原文说「转成 SOC 约束，即得 SOCP」但对这一条只给了 QCQP 形式，**论证停在半路**——严格说来需要补一条 $v^{T}v \le t \iff \left\|\begin{bmatrix}2v\\ t-1\end{bmatrix}\right\|_2 \le t+1$ 才能称为 SOCP。补上之后结论成立。

### Exercise 4.28 Robust quadratic programming

> 话题：只有 $P$ 有误差的鲁棒 QP——三种不确定性集合都给出凸问题：(a) 有限集给 QCQP，(b) 谱范数球给 QP（以 $\gamma$ 罚），(c) 椭球族给 SOCP。

**In §4.4.2 we discussed robust linear programming as an application of second-order cone programming. In this problem we consider a similar robust variation of the (convex) quadratic program**

```math
\begin{aligned}
\text{minimize}\quad & (1/2)x^{T}Px + q^{T}x + r \\
\text{subject to}\quad & Ax \preceq b .
\end{aligned}
```

**For simplicity we assume that only the matrix $P$ is subject to errors, and the other parameters ($q$, $r$, $A$, $b$) are exactly known. The robust quadratic program is defined as**

```math
\begin{aligned}
\text{minimize}\quad & \sup_{P \in \mathcal{E}}\bigl((1/2)x^{T}Px + q^{T}x + r\bigr) \\
\text{subject to}\quad & Ax \preceq b
\end{aligned}
```

<!-- ===== p099 ===== -->

**where $\mathcal{E}$ is the set of possible matrices $P$.**

**For each of the following sets $\mathcal{E}$, express the robust QP as a convex problem. Be as specific as you can. If the problem can be expressed in a standard form (e.g., QP, QCQP, SOCP, SDP), say so.**

**(a) A finite set of matrices: $\mathcal{E} = \{P_1,\ldots,P_K\}$, where $P_i \in \mathbf{S}^n_{+}$, $i = 1,\ldots,K$.**

**(b) A set specified by a nominal value $P_0 \in \mathbf{S}^n_{+}$ plus a bound on the eigenvalues of the deviation $P - P_0$:**

```math
\mathcal{E} = \{P \in \mathbf{S}^n \mid -\gamma I \preceq P - P_0 \preceq \gamma I\}
```

**where $\gamma \in \mathbf{R}$ and $P_0 \in \mathbf{S}^n_{+}$.**

**(c) An ellipsoid of matrices:**

```math
\mathcal{E} = \Bigl\{P_0 + \sum_{i=1}^{K}P_iu_i \ \Big|\ \|u\|_2 \le 1\Bigr\} .
```

**You can assume $P_i \in \mathbf{S}^n_{+}$, $i = 0,\ldots,K$.**

**Solution.**

**(a)** 目标函数是凸函数的最大值，因此是凸的。可以把问题写成

```math
\begin{aligned}
\text{minimize}\quad & t \\
\text{subject to}\quad & (1/2)x^{T}P_ix + q^{T}x + r \le t,\qquad i = 1,\ldots,K\\
& Ax \preceq b,
\end{aligned}
```

这是关于变量 $x$ 与 $t$ 的 QCQP。

> 复算：「凸函数族的上确界仍是凸函数」是逐点 supremum 的定义直接给出（对每个 $x$，$\sup_i f_i(x)$ 的 epigraph 是各 $\text{epi}\,f_i$ 的交，交仍凸）✓。$K$ 条二次约束，不需要离散化误差集 ✓。**原文无误**。

**(b)** 给定 $x$ 时，$x^{T}\Delta P\,x$ 在 $-\gamma I \preceq \Delta P \preceq \gamma I$ 上的上确界为

```math
\sup_{-\gamma I \preceq \Delta P \preceq \gamma I}x^{T}\Delta P\,x = \gamma x^{T}x .
```

因此可以把鲁棒 QP 表达为

```math
\begin{aligned}
\text{minimize}\quad & (1/2)x^{T}(P_0 + \gamma I)x + q^{T}x + r \\
\text{subject to}\quad & Ax \preceq b,
\end{aligned}
```

这是一个 QP。

> 复算：$x^{T}\Delta P\,x = \operatorname{tr}(\Delta P\,xx^{T})$。$\|\Delta P\|_2 \le \gamma$ 且 $xx^{T} \succeq 0$，对对称矩阵的迹内积，$\sup_{\|\Delta P\|_2\le\gamma}\operatorname{tr}(\Delta P\,xx^{T}) = \gamma\operatorname{tr}(xx^{T}) = \gamma\|x\|^{2}$，在 $\Delta P = \gamma I$ 处取到 ✓。**原文无误**。
> 一个值得注意的边界：$\gamma \lt 0$ 时这个 sup 是 $|\gamma|\|x\|^2$（因为取 $\Delta P = -\gamma I$），而原文写 $P_0 + \gamma I$ 会给出 $P_0 - |\gamma|I$。原题虽未明说，但「bound on the eigenvalues」隐含 $\gamma \ge 0$；若允许 $\gamma \lt 0$，应写成 $P_0 + |\gamma|I$。属边界情形未声明，不是主错。

**(c)** 给定 $x$ 时，二次目标函数为

```math
\begin{aligned}
& (1/2)\Bigl(x^{T}P_0x + \sup_{\|u\|_2 \le 1}\sum_{i=1}^{K}u_i\bigl(x^{T}P_ix\bigr)\Bigr) + q^{T}x + r\\
&\quad = (1/2)x^{T}P_0x + (1/2)\Bigl(\sum_{i=1}^{K}\bigl(x^{T}P_ix\bigr)^{2}\Bigr)^{1/2} + q^{T}x + r .
\end{aligned}
```

这是 $x$ 的凸函数：每个函数 $x^{T}P_ix$ 是凸的，因为 $P_i \succeq 0$。第二项是 $h(g_1(x),\ldots,g_K(x))$ 的复合，其中 $h(y) = \|y\|_2$、$g_i(x) = x^{T}P_ix$。函数 $g_i$ 凸且非负。函数 $h$ 凸，且在 $y \in \mathbf{R}^K_{+}$ 上对每个自变量非减。因此该复合是凸的。

得到的问题可以表述为

```math
\begin{aligned}
\text{minimize}\quad & (1/2)x^{T}P_0x + \|y\|_2 + q^{T}x + r \\
\text{subject to}\quad & (1/2)x^{T}P_ix \le y_i,\qquad i = 1,\ldots,K\\
& Ax \preceq b,
\end{aligned}
```

<!-- ===== p100 ===== -->

它可以进一步化成 SOCP

```math
\begin{aligned}
\text{minimize}\quad & u + t \\
\text{subject to}\quad & \left\|\begin{bmatrix}P_0^{1/2}x\\ 2u - 1/4\end{bmatrix}\right\|_2 \le 2u + 1/4\\
& \left\|\begin{bmatrix}P_i^{1/2}x\\ 2y_i - 1/4\end{bmatrix}\right\|_2 \le 2y_i + 1/4,\qquad i = 1,\ldots,K\\
& \|y\|_2 \le t\\
& Ax \preceq b .
\end{aligned}
```

变量为 $x$、$u$、$t$ 与 $y \in \mathbf{R}^K$。

注意若把第一条不等式的两边平方，得到

```math
x^{T}P_0x + (2u - 1/4)^{2} \le (2u + 1/4)^{2},
```

即 $x^{T}P_0x \le 2u$。同理，其余约束等价于 $(1/2)x^{T}P_ix \le y_i$。

> 复算（这是本页最值得手验的一处）：$\sup_{\|u\|_2\le1}\sum_i u_i(x^{T}P_ix) = \|(x^{T}P_ix)_{i}\|_2$（Cauchy–Schwarz，取 $u$ 与该向量同向）✓。SOC 化：$(2u + 1/4)^{2} - (2u - 1/4)^{2} = 2\cdot 2u\cdot \tfrac{1}{4}\cdot 2 = 2u$，所以平方后确实是 $x^{T}P_0x \le 2u$ ✓；同法 $x^{T}P_ix \le 2y_i$ ✓。
> 目标配平验证：由 $x^{T}P_0x \le 2u$ 得 $\tfrac{1}{2}x^{T}P_0x \le u$；由 $x^{T}P_ix \le 2y_i$ 得 $\tfrac{1}{2}x^{T}P_ix \le y_i$，即 $y_i \ge g_i(x)/2$，于是 $\|y\|_2 \ge \tfrac{1}{2}\|(x^{T}P_ix)_i\|_2$，再由 $\|y\|_2 \le t$ 得 $t = \|y\|_2$。三者相加正是 $\tfrac12 x^{T}P_0x + \tfrac12\|\cdot\|_2 + q^{T}x + r$ ✓——**系数 $1/2$ 与 $1/4$ 的偏移量配合正确，原文无误**。（我把这条按 $\min u + t$ 的字面重算了两遍：$u$ 承担 $\tfrac12 x^{T}P_0x$、$t$ 承担 $\tfrac12\|\cdot\|_2$，恰好抵消，没有因子 2 的错。）

### Exercise 4.29 Maximizing probability of satisfying a linear inequality

> 话题：正态扰动下「约束成立的极大似然」——把概率写成 $1 - \Phi(z)$，于是只要 $z$ 的符号固定，最大化概率就是最大化一个分式，得到 quasiconvex 问题（或退化成 QP）。

**Let $c$ be a random variable in $\mathbf{R}^n$, normally distributed with mean $\bar{c}$ and covariance matrix $R$. Consider the problem**

```math
\begin{aligned}
\text{maximize}\quad & \operatorname{\mathbf{prob}}(c^{T}x \ge \alpha) \\
\text{subject to}\quad & Fx \preceq g\\
& Ax = b .
\end{aligned}
```

**Find the conditions under which this is equivalent to a convex or quasiconvex optimization problem. When these conditions hold, formulate the problem as a QP, QCQP, or SOCP (if the problem is convex), or explain how you can solve it by solving a sequence of QP, QCQP, or SOCP feasibility problems (if the problem is quasiconvex).**

**Solution.** 若对所有可行 $x$ 都有 $\alpha \lt \bar{c}^{T}x$，则问题可以写成凸或拟凸问题。

在展开细节之前，先考虑 $\bar{c} = 0$ 的特殊情形。此时 $c^{T}x$ 是随机变量，正态分布，$\operatorname{\mathbf{E}}(c^{T}x) = 0$、$\operatorname{\mathbf{E}}(c^{T}x)^{2} = x^{T}Rx$。若 $\alpha \lt 0$，最大化 $\operatorname{\mathbf{prob}}(c^{T}x \ge \alpha)$ 意味着最小化方差，即在 $x$ 的约束下最小化 $x^{T}Rx$，这是一个凸问题（实际上是一个 QP）。另一方面，若 $\alpha \gt 0$，最大化 $\operatorname{\mathbf{prob}}(c^{T}x \ge \alpha)$ 要求最大化方差 $x^{T}Rx$，这非常困难。

现在转向 $\bar{c} \neq 0$ 的一般情形。定义标量随机变量 $u = c^{T}x$，它正态分布，$\operatorname{\mathbf{E}}u = \bar{c}^{T}x$、$\operatorname{\mathbf{E}}(u - \operatorname{\mathbf{E}}u)^{2} = x^{T}Rx$。随机变量

```math
\frac{u - \bar{c}^{T}x}{\sqrt{x^{T}Rx}}
```

服从均值为零、方差为单位的正态分布，因此

```math
\operatorname{\mathbf{prob}}(u \ge \alpha) = \operatorname{\mathbf{prob}}\left(\frac{u - \bar{c}^{T}x}{\sqrt{x^{T}Rx}} \ge \frac{\alpha - \bar{c}^{T}x}{\sqrt{x^{T}Rx}}\right) = 1 - \Phi\left(\frac{\alpha - \bar{c}^{T}x}{\sqrt{x^{T}Rx}}\right),
```

其中

```math
\Phi(z) = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{z}e^{-t^{2}/2}\,dt
```

是单调递增函数。

要最大化 $1 - \Phi$，可以最小化 $(\alpha - \bar{c}^{T}x)/\sqrt{x^{T}Rx}$，即求解问题

```math
\begin{aligned}
\text{maximize}\quad & (\bar{c}^{T}x - \alpha)/\sqrt{x^{T}Rx} \\
\text{subject to}\quad & Fx \preceq g\\
& Ax = b .
\end{aligned}
```

> **此处原文截断**：p100 是本份 PDF 的最后一页，解答停在这个式子，**后面应当出现的部分全缺**——题干要求的三件事中有两件没做：(i) 给出「凸或拟凸」的完整条件；(ii) 说明用 QP/SOCP 表述，或用一串可行性问题求解（bisection on $\gamma$）。
> 补全的方向（供下一块衔接）：目标 $(\bar{c}^{T}x - \alpha)/\sqrt{x^{T}Rx}$ 在分子恒正（即 $\alpha \lt \bar{c}^{T}x$ 对所有可行 $x$ 成立）时，等价于
>
> ```math
> \begin{aligned}
> \text{maximize}\quad & \eta \\
> \text{subject to}\quad & \bar{c}^{T}x - \alpha \ge \eta\sqrt{x^{T}Rx},\qquad Fx \preceq g,\ Ax = b,
> \end{aligned}
> ```
>
> 这是**拟凹**的（对 $\eta$ 的 superlevel set 是 SOC 约束：$\bar{c}^{T}x - \alpha \ge \eta\|R^{1/2}x\|_2$ 关于 $x$ 是线性的，$\eta$ 固定时是 SOCP 可行性问题），因此用 bisection on $\eta$ 求解，每步一个 SOCP。这正是题干说的「if the problem is quasiconvex」那条路径。

> 复算：$\operatorname{\mathbf{prob}}(u \ge \alpha) = 1 - \Phi\bigl(\frac{\alpha - \bar{c}^{T}x}{\sqrt{x^{T}Rx}}\bigr)$ ✓（把 $u$ 标准化）。因 $\Phi$ 单调增，最大化 $1 - \Phi$ ⇔ 最小化 $\frac{\alpha - \bar{c}^{T}x}{\sqrt{x^{T}Rx}}$ ⇔ 最大化 $\frac{\bar{c}^{T}x - \alpha}{\sqrt{x^{T}Rx}}$ ✓。$\bar c = 0$ 那一支：$\alpha \lt 0$ 时最大化 $\operatorname{\mathbf{prob}}$ = 把分子 $-\alpha \gt 0$ 除以尽量小的 $\sqrt{x^{T}Rx}$，即 min 方差 ✓；$\alpha \gt 0$ 时分子为负，要最大化就得让分母尽量大——max 方差，非凸 ✓。**已写的部分全部正确**，缺的是收尾。
