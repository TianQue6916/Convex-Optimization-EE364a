### Exercise 4.55（收尾）：多准则优化的 scalarization —— Pareto optimality 的最后一步

> **中文话题摘要**：把 4.55 主体（p120）的结论收尾——用任意 increasing 的 $\psi$ 做 scalarization 时，
> 「scalar 问题的最优解是 Pareto optimal」这句话到底依赖什么条件。

**解答（接 p120，这是 4.55 的最后三句）**。

注意 $\psi(u)=\lambda^{T}u$（其中 $\lambda \succ_{K^{*}} 0$）只是一个特例。作为一个相关例子，证明：在
multicriterion optimization problem（多准则优化问题）中——即目标为 $f_0=F:\mathbf{R}^{n}\to\mathbf{R}^{q}$、
锥为 $K=\mathbf{R}^{q}_{+}$ 的 vector optimization problem（向量优化问题）——标量优化问题

```math
\begin{aligned}
\text{minimize}\quad & \max_{i=1,\dots,q} F_i(x)\\
\text{subject to}\quad & f_i(x) \le 0,\quad i = 1,\dots,m\\
& h_i(x) = 0,\quad i = 1,\dots,p
\end{aligned}
```

的**唯一**解是 Pareto optimal 的。

**解答**。设 $x^{\star}$ 是该标量问题的解。现在假设存在

```math
u \in \mathcal{O},\qquad u \preceq_{K} f_0(x^{\star}),\qquad u \ne f_0(x^{\star}),
```

其中 $\mathcal{O}$ 是目标值的可达集。由于 $\psi$ 是 increasing 的，就有 $\psi(u) \lt \psi(f_0(x^{\star}))$。
然而这与「$x^{\star}$ 极小化 $\psi\circ f_0$」这一事实矛盾。

† **4.55 收尾处漏了严格性条件。** 原文写「Because $\psi$ is increasing, $\psi(u) \lt \psi(f_0(x^{\star}))$」——
这一步要成立，需要的不是「$\psi$ 是 $K$-increasing」，而是「$\psi$ 是**严格** $K$-increasing」（即
$u \preceq_{K} v$ 且 $u \ne v$ 时必须 $\psi(u) \lt \psi(v)$）。$K$-increasing 只给 $\psi(u) \le \psi(v)$，
等号可以成立，此时 $u$ 与 $f_0(x^{\star})$ 给出同一个标量值，矛盾链断掉。

**正确说法**：设 $\psi$ 严格 $K$-increasing，$x^{\star}$ 极小化 $\psi\circ f_0$，则 $f_0(x^{\star})$ 是
Pareto optimal 的。

**数值反例**（$q=2$，$K=\mathbf{R}^{2}_{+}$）：取 $\psi(u)=u_1$。它确实是 $K$-increasing 的
（$u \preceq v \Rightarrow u_1 \le v_1$），但**不严格**。取可达集
$\mathcal{O}=\{(1,5),(1,0)\}$。标量问题 $\text{minimize}\ \psi(f_0(x))$ 的最优值是 $1$，两个点都是最优解；
取 $f_0(x^{\star})=(1,5)$。但 $(1,0)\preceq_{\mathbf{R}^{2}_{+}}(1,5)$ 且 $(1,0)\ne(1,5)$，所以
$f_0(x^{\star})=(1,5)$ **不是** Pareto optimal。原文的推理在这一步会把 $(1,5)$ 判成 Pareto optimal，因为它算的是
$\psi(1,0)=1$ 与 $\psi(1,5)=1$，看不出差别。

**为什么会写错**：4.55 主体的 $\lambda^{T}u$ 情形自带严格性（$\lambda\succ_{K^{*}}0$ 时 $u\ne v$ 必给
$\lambda^{T}u \lt \lambda^{T}v$），作者把这一特例的性质顺手当成了 $\psi$ 的通性；再加上 $\max_i$ 这个
$\psi$ 本身确实是严格 increasing 的（$u \ne v$ 且 $u \preceq v$ 时某个坐标严格更小，max 也就严格更小），
于是「本题的真实对象」满足条件，掩盖了通性不成立这件事。

### Exercise 4.56 [P. Parrilo]：凸集并集的凸包上的最小化 —— 用 perspective 把它变成凸问题

> **中文话题摘要**：把 $\text{conv}(\bigcup_{i=1}^{q}C_i)$ 上的凸函数最小化写成一行凸约束——关键是引入
> 「权重 $s_i$ + 位移 $z_i$」两个变量，用 perspective $s_if_{ij}(z_i/s_i)$ 替掉非仿射的 $x=\sum\theta_ix_i$。

**题干（译）**。我们考虑这样一个问题：在若干凸集之并的 convex hull（凸包）
$\text{conv}\left(\bigcup_{i=1}^{q}C_i\right)$ 上最小化凸函数 $f_0:\mathbf{R}^{n}\to\mathbf{R}$。这些集合由凸不等式描述：

```math
C_i = \{x \mid f_{ij}(x) \le 0,\ j = 1,\dots,k_i\},
```

其中 $f_{ij}:\mathbf{R}^{n}\to\mathbf{R}$ 是凸函数。我们的目标是把这个问题表述成一个凸优化问题。

最显然的做法是引入变量 $x_1,\dots,x_q\in\mathbf{R}^{n}$（要求 $x_i\in C_i$）、$\theta\in\mathbf{R}^{q}$
（要求 $\theta \succeq 0$、$\mathbf{1}^{T}\theta=1$），以及变量 $x\in\mathbf{R}^{n}$，并令
$x=\theta_1x_1+\cdots+\theta_qx_q$。这个等式约束在变量里不是仿射的，所以这种做法得不到凸问题。

一个更精巧的表述是

```math
\begin{aligned}
\text{minimize}\quad & f_0(x)\\
\text{subject to}\quad & s_i f_{ij}(z_i/s_i) \le 0,\quad i = 1,\dots,q,\ j = 1,\dots,k_i\\
& \mathbf{1}^{T}s = 1,\quad s \succeq 0\\
& x = z_1 + \cdots + z_q,
\end{aligned}
```

变量为 $z_1,\dots,z_q\in\mathbf{R}^{n}$、$x\in\mathbf{R}^{n}$ 与 $s_1,\dots,s_q\in\mathbf{R}$。
（当 $s_i=0$ 时，我们把 $s_if_{ij}(z_i/s_i)$ 取为：若 $z_i=0$ 则取 $0$，若 $z_i\ne 0$ 则取 $+\infty$。）
解释为什么这个问题是凸的，以及它为什么与原问题等价。

**解答**。由于 $f_{ij}$ 是凸函数，它们的 perspective（透视）$s_if_{ij}(z_i/s_i)$ 也是凸函数。因此该问题是凸的。

下面证明它与原问题等价。首先，设 $x$ 对原问题可行，并且可以表成
$x=\theta_1x_1+\cdots+\theta_qx_q$，其中 $x_i\in C_i$，$\theta \succeq 0$，$\mathbf{1}^{T}\theta=1$。
令 $z_i=\theta_ix_i$，$s_i=\theta_i$。我们断言 $z_1,\dots,z_q,s_1,\dots,s_q,x$ 对新问题可行。显然
$x=z_1+\cdots+z_q$、$s \succeq 0$、$\mathbf{1}^{T}s=1$ 都成立。对 $s_i \gt 0$ 有 $z_i/s_i=x_i\in C_i$，故

```math
f_{ij}(z_i/s_i) \le 0,\qquad j = 1,\dots,k_i .
```

两边乘以 $s_i$ 就得到新问题中的那些不等式。对 $s_i=0$，由于我们取 $s_if_{ij}(z_i/s_i)=0$，不等式成立。

反过来，设 $z_1,\dots,z_q,s_1,\dots,s_q,x$ 对新问题可行。

<!-- ===== p122 ===== -->

**（承上页）** 当 $s_i=0$ 时必有 $z_i=0$，所以这些项可以扔掉；不妨设所有 $s_i \gt 0$。定义 $x_i=z_i/s_i$。
把不等式

```math
f_{ij}(z_i/s_i) \le 0,\qquad j = 1,\dots,k_i
```

两边除以 $s_i$，得到

```math
f_{ij}(x_i) \le 0,\qquad j = 1,\dots,k_i,
```

这说明 $x_i\in C_i$。又由

```math
x = z_1+\cdots+z_q = s_1x_1+\cdots+s_qx_q
```

可见 $x$ 是 $x_1,\dots,x_q$ 的凸组合，因此对原问题可行。

于是两个问题等价。

> **关于「不妨设所有 $s_i \gt 0$」这一步的补证**：$s_i=0$ 的项有 $z_i=0$，把它们从求和里删掉后，
> $\mathbf{1}^{T}s=1$ 仍然成立（被删的项贡献为 $0$），所以 $x=\sum_{s_i \gt 0}z_i=\sum_{s_i \gt 0}s_ix_i$
> 依然是权重和为 $1$ 的凸组合。原解答只说「可以扔掉」，没写这句「权重和仍为 $1$」，读者容易卡住。

<span style="color:#1e8449;">**[译注]** 这一题的全部技术含量在一个词上：perspective（透视）。它是把「$s$ 乘进函数内部」的合法工具，定义与唯一要害性质是

```math
g(z,s) = s\,f(z/s),\quad s \gt 0;\qquad g(z,0) = 0\ (\text{若}\ z=0),\qquad g(z,0)=+\infty\ (\text{若}\ z\ne 0),
```

$f$ 凸 $\Rightarrow g$ 凸（Boyd §3.2.6）。**为什么非它不可**：凸包的定义要求 $x=\sum\theta_ix_i$，而 $\theta_ix_i$ 是乘积——两个变量相乘，这在凸优化里是不可接受的非仿射结构。令 $z_i=\theta_ix_i$ 后，乘积被「吸收」进一个新变量，代价是 $x_i=z_i/\theta_i$ 变成了**分式**，于是约束 $f_{ij}(z_i/\theta_i)\le 0$ 含除法。perspective 的 $s_if_{ij}(z_i/s_i)$ 恰好把那个除法乘以 $s_i$ 又抵消掉，剩下的函数在 $(z_i,s_i)$ 上仍是凸的——「乘积」与「分式」两个难点被同一个操作同时消掉。

**消失测试**：没有 perspective 的凸性定理，这个 reformulation 只是一堆非凸约束的堆砌，求解只能退回原问题的组合结构：枚举「$x$ 落在哪个 $C_i$」——$q$ 个集合有 $2^{q}-1$ 种非空选择，每种再解一个 $n$ 维凸问题，总代价 $O(2^{q})$ 次凸求解；而 perspective 形式**一次**求解就够，$q$ 只进入变量维数（$n(q+1)+q$）。

**落点**：Boyd §3.2.6（perspective 的凸性）；§4.2.5 附近的 convex hull 表述；配套练习 4.56 本身、以及 §4.4 的 geometric program 里「$s_i$ 权重」同型的手法；线代侧挂 Strang 的齐次坐标（同一件事：把仿射/分式结构抬高一维变成线性）。</span>

### Exercise 4.57：信道容量 —— 把互信息写成「线性项减熵」从而得到凹目标

> **中文话题摘要**：Shannon 的 channel capacity 是一个 $\sup$ 形式，直接看不像凸问题；引入
> $y=Px$ 把 $\log$ 里的分母挪出来，目标变成「常数加 $y$ 的熵」，凹性一眼可见。

**题干（译）**。考虑一个通信信道，输入 $X(t)\in\{1,\dots,n\}$，输出 $Y(t)\in\{1,\dots,m\}$，$t=1,2,\dots$
（单位取秒）。输入与输出之间的关系由统计规律给出：

```math
p_{ij} = \mathbf{prob}(Y(t)=i \mid X(t)=j),\qquad i = 1,\dots,m,\quad j = 1,\dots,n .
```

矩阵 $P\in\mathbf{R}^{m\times n}$ 称为 channel transition matrix（信道转移矩阵），这样的信道称为
discrete memoryless channel（离散无记忆信道）。

Shannon 的一个著名结果表明：以任意小的错误概率、以任何低于某个数 $C$ 的速率（bits per second）传输信息都是可能的，这个 $C$ 称为
channel capacity（信道容量）。Shannon 还证明，离散无记忆信道的容量可以通过求解一个优化问题得到。设 $X$ 有概率分布
$x\in\mathbf{R}^{n}$，即

```math
x_j = \mathbf{prob}(X=j),\qquad j = 1,\dots,n .
```

$X$ 与 $Y$ 之间的 mutual information（互信息）为

```math
I(X;Y) = \sum_{i=1}^{m}\sum_{j=1}^{n} x_jp_{ij}\log_2\frac{p_{ij}}{\sum_{k=1}^{n}x_kp_{ik}} .
```

于是信道容量 $C$ 由下式给出：

```math
C = \sup_{x} I(X;Y),
```

其中上确界取遍输入 $X$ 的一切可能概率分布，即取遍 $x \succeq 0$、$\mathbf{1}^{T}x=1$。

说明如何用凸优化计算信道容量。

**提示**。引入变量 $y=Px$——它给出输出 $Y$ 的概率分布——并证明互信息可以写成

```math
I(X;Y) = c^{T}x - \sum_{i=1}^{m}y_i\log_2 y_i,
```

其中 $c_j=\sum_{i=1}^{m}p_{ij}\log_2 p_{ij}$，$j=1,\dots,n$。

**解答**。容量是下述问题的最优值：

```math
\begin{aligned}
\text{maximize}\quad & f_0(x) = \sum_{i=1}^{n}\sum_{j=1}^{m} x_jp_{ij}\log\frac{p_{ij}}{\sum_{k=1}^{m}x_kp_{ik}}\\
\text{subject to}\quad & x \succeq 0,\quad \mathbf{1}^{T}x = 1,
\end{aligned}
```

† **4.57 解答里三个求和上限全部写错。** 题干（上一段）是对的：$\sum_{i=1}^{m}\sum_{j=1}^{n}$ 且分母
$\sum_{k=1}^{n}$。解答里却写成 $\sum_{i=1}^{n}\sum_{j=1}^{m}$（两个上限互换）、分母 $\sum_{k=1}^{m}$。
$i$ 是**输出**指标，取值 $1..m$；$j$ 是**输入**指标，取值 $1..n$；分母 $\sum_k x_kp_{ik}$ 里的 $k$ 也是输入指标，
必须到 $n$。

**正确式子**：

```math
f_0(x) = \sum_{i=1}^{m}\sum_{j=1}^{n} x_jp_{ij}\log\frac{p_{ij}}{\sum_{k=1}^{n}x_kp_{ik}}
```

**数值反例**：取 $m=2$（两个输出）、$n=3$（三个输入）。按原文的 $\sum_{i=1}^{n}=\sum_{i=1}^{3}$，要访问
$p_{3j}$——但 $P$ 只有两行，**下标越界**，式子根本算不出来；同样分母 $\sum_{k=1}^{2}x_kp_{ik}$ 漏掉了第三个
输入的概率质量 $x_3p_{i3}$，于是 $\sum_j$ 这一侧（到 $m=2$，漏掉 $j=3$）与分母的遗漏**不对称**，算出的
「互信息」可以取负值。具体地取 $P=\begin{bmatrix}1&0&0\\1&1&1\end{bmatrix}$、$x=(1/3,1/3,1/3)$：
正确的 $I(X;Y)=0$（给定 $X$ 时 $Y$ 确定，$H(Y)=H(Y\mid X)$）；按原文的错式子只有 $i=1,2$、$j=1,2$、
$k=1,2$ 参与，与真值不同。

**为什么会写错**：$m$ 与 $n$ 在题面里只差一个字母，作者在誊写第二步（从题干抄到解答）时凭「先 $n$ 后 $m$」
的语感把两个上限对调了；而分母 $\sum_k$ 的上限则直接延续了前一个错误。这类错在答案手册里成片出现，
规避办法是**先写下标的语义**（$i$=输出 $\in[1,m]$，$j$=输入 $\in[1,n]$）再写求和。

下面直接论证目标 $f_0$（即 $X$ 与 $Y$ 之间的互信息）关于 $x$ 是凹的也是可行的。这可以有好几种做法，从例 3.19 出发即可。
<!-- ===== p123 ===== -->

**（承 p122 末）**

另一种（相关的）做法是照着提示走，把 $y=Px$ 也作为一个变量引入。这样可以用 $x$ 与 $y$ 把互信息写成

```math
\begin{aligned}
I(X;Y) &= \sum_{i,j} x_jp_{ij}\log\frac{p_{ij}}{\sum_{k}x_kp_{ik}}\\
&= \sum_{j}x_j\sum_{i}p_{ij}\log p_{ij} - \sum_{i}y_i\log y_i\\
&= -c^{T}x - \sum_{i}y_i\log y_i,
\end{aligned}
```

其中 $c_j=-\sum_{i}p_{ij}\log p_{ij}$。因此信道容量问题可以表述为

```math
\begin{aligned}
\text{maximize}\quad & I(X;Y) = -c^{T}x - \sum_{i}y_i\log y_i\\
\text{subject to}\quad & x \succeq 0,\quad \mathbf{1}^{T}x = 1\\
& y = Px,
\end{aligned}
```

变量为 $x$ 与 $y$。目标函数是一个常数加上 $y$ 的熵（entropy），因而是凹的，所以这是一个凸优化问题。

<span style="color:#1e8449;">**[译注]** 这一页的同一条式子里，符号 $c$ 被**定义了两次且方向相反**：提示里写 $c_j=\sum_ip_{ij}\log_2p_{ij}$，接着 $I=c^{T}x-\sum_iy_i\log_2y_i$；解答里写 $c_j=-\sum_ip_{ij}\log p_{ij}$，接着 $I=-c^{T}x-\sum_iy_i\log y_i$。两套都对，但它们是**两个不同的 $c$**，只差一个负号。这类「同名异义」在抄写时几乎必然出事——把提示的 $c$ 代进解答的式子，得到的 $I$ 会整体差 $2c^{T}x$，而 $c^{T}x$ 一般不为零。

**检查办法**：不要记符号，记**结构**。全部式的骨架只有一句

```math
I(X;Y) = H(Y) - H(Y\mid X),\qquad H(Y) = -\sum_{i}y_i\log y_i,\qquad H(Y\mid X) = -\sum_{j}x_j\sum_{i}p_{ij}\log p_{ij},
```

这是 Shannon 那套记号下的恒等式：互信息 = 输出熵减条件熵，而条件熵关于 $x$ 是**线性**的（$H(Y\mid X)=\sum_jx_jh_j$，$h_j$ 是第 $j$ 列信道噪声熵）。于是 $I$ 关于 $x$ 的凹性完全落在 $H(Y)$ 上，而 $H=Px$ 又是线性的。

**消失测试**：如果没有「条件熵线性」这一步，就得直接对 $\log\frac{p_{ij}}{\sum_kx_kp_{ik}}$ 这个含分式的对数式取二阶导来证凹性——那是 $m\times n$ 个 log 项的和，Hessian 是 $n\times n$ 的稠密矩阵，没有人能手推。有了这一步，凹性证明显式降到**零推导**：凹（熵）$\circ$ 线性（$P$）。数值上的差别是：直接证 $I$ 的凹性需要处理 $n^{2}$ 个二阶偏导，$n=50$ 时是 2500 项；换元后要处理的是 $m$ 维单纯形上的熵函数（已知凹）。

**落点**：Boyd 例 3.19（$f(x)=\sum_i x_i\log x_i$ 的凹性）与 §3.2.6；例 5.6 的对偶用到同一结构；信息论侧挂 Cover–Thomas 第 2 章（mutual information 的非负性与链式法则 $I(X;Y)=H(Y)-H(Y\mid X)$）；EE364a 的 capacity 例题与本题同源。</span>

### Exercise 4.58：最优消费 —— 把等式预算约束放松成不等式，再证最优处自动收紧

> **中文话题摘要**：预算递推 $k_{t+1}=k_t+f(k_t)-c_t$ 含非线性 $f$，是等式约束、非凸；把它换成
> $\le$ 立刻变凸，代价是「允许扔钱」——然后用「扔钱显然是浪费」把这个缺口补上。

**题干（译）**。本题研究如何在一段时间内最优地消费（花掉）一笔初始资金（或其他资产）$k_0$。变量是
$c_1,\dots,c_T$，其中 $c_t \ge 0$ 表示第 $t$ 期的消费量。消费水平 $c$ 带来的效用由 $u(c)$ 给出，其中
$u:\mathbf{R}\to\mathbf{R}$ 是 increasing concave function（递增凹函数）。消费所带来效用的现值（present value）为

```math
U = \sum_{t=1}^{T}\beta^{t}u(c_t),
```

其中 $0 \lt \beta \lt 1$ 是 discount factor（贴现因子）。

设 $k_t$ 表示第 $t$ 期可用于投资的资金量。假设它带来由 $f(k_t)$ 给出的投资收益，其中

### Exercise 4.59：Robust optimization —— stochastic 与 worst-case 两种建模为何都保凸

> **中文话题摘要**：把不确定性塞进目标与约束有两条路——取期望（$E_u$）或取最坏情形（$\sup_{u\in U}$）；

**题干（译）**。有些优化问题里，目标函数与约束函数存在不确定性或变化，来源是某些我们无法控制或未知的参数或因素。

```math

\text{subject to}\quad & E\,f_i(x,u) \le 0,\quad i = 1,\dots,m,
\end{aligned}
```

**（承上页）** 其中期望是对 $u$ 取的。证明：若对每个 $u$，$f_i$ 关于 $x$ 都是凸的，则该随机优化问题是凸的。

**(b) Worst-case optimization（最坏情形优化）**。考虑问题

```math
\begin{aligned}
\text{minimize}\quad & \sup_{u\in U}f_0(x,u)\\
```

**(a)** 由下述事实推出：不等式

```math
\begin{aligned}
\text{minimize}\quad & \sum_{i}p_kf_0(x,u_k)\\

\end{aligned}
```

两者必须严格相等。

Worst-case formulation（最坏情形表述）：

```math
\begin{aligned}
\text{minimize}\quad & \max_kf_0(x,u_k)\\
\text{subject to}\quad & \max_kf_i(x,u_k) \le 0,\quad i = 1,\dots,m .
\end{aligned}
```

### Exercise 4.60：Log-optimal investment —— 大数定律把「长期增长率」变成一个可算的凹函数

> **中文话题摘要**：$N$ 期复利的总增长是 $\prod_t\lambda(t)$；取对数、除以 $N$、让 $N\to\infty$，
> 大数定律把它换成 $E\log\lambda(t)$，而这个期望关于配置 $x$ 是凹的。

**题干（译）**。我们考虑一个在 $n$ 个资产上持有 $N$ 期的投资组合问题。每期开始时我们重新投资全部财富，
用一个固定不变、恒定的 allocation strategy（配置策略）$x\in\mathbf{R}^{n}$ 把财富重新分配到 $n$ 个资产上，
其中 $x \succeq 0$、$\mathbf{1}^{T}x=1$。换言之，若 $W(t-1)$ 是第 $t$ 期开始时的财富，则第 $t$ 期内我们在资产 $i$
上投入 $x_iW(t-1)$。用 $\lambda(t)$ 表示第 $t$ 期的总回报，即 $\lambda(t)=W(t)/W(t-1)$。经过 $N$ 期之后，
我们的财富被乘上了因子 $\prod_{t=1}^{N}\lambda(t)$。我们把

```math
\frac{1}{N}\sum_{t=1}^{N}\log\lambda(t)
```

称为这 $N$ 期投资的 growth rate（增长率）。我们希望确定一个配置策略 $x$，使得当 $N$ 很大时总财富的增长最大。

我们用离散随机模型来刻画回报中的不确定性。假设每期有 $m$ 种可能的情景（scenario），概率为 $\pi_j$，
$j=1,\dots,m$。在情景 $j$ 下，资产 $i$ 在一期内的回报由 $p_{ij}$ 给出。

**（承上页题干，p126 上半）** 因此，我们的组合在第 $t$ 期的回报 $\lambda(t)$ 是一个随机变量，有 $m$ 个可能取值
$p_1^{T}x,\dots,p_m^{T}x$，分布为

```math
\pi_j = \mathbf{prob}(\lambda(t) = p_j^{T}x),\qquad j = 1,\dots,m .
```

我们假定每期的情景相同，且（相同的）分布相互独立（identical independent distributions）。利用大数定律（law of large numbers），有

```math
\lim_{N\to\infty}\frac{1}{N}\log\left(\frac{W(N)}{W(0)}\right) = \lim_{N\to\infty}\frac{1}{N}\sum_{i=1}^{N}\log\lambda(t) = E\log\lambda(t) = \sum_{j=1}^{m}\pi_j\log(p_j^{T}x).
```

† **4.60 链条中间那个求和也是哑指标污染：$\sum_{i=1}^{N}\log\lambda(t)$ 应为 $\sum_{t=1}^{N}\log\lambda(t)$。**
求和指标写成 $i$，而被加项里出现的是 $t$——$i$ 在项内不出现。

**正确式子**：

```math
\lim_{N\to\infty}\frac{1}{N}\sum_{t=1}^{N}\log\lambda(t) = E\log\lambda(t)
```

**数值反例**：$N=2$，$\lambda(1)=2$、$\lambda(2)=1/2$。正确值 $\frac{1}{2}(\log 2+\log\frac12)=0$
（几何增长率 $1$）。按原文的 $\sum_{i=1}^{2}\log\lambda(t)$，$t$ 是自由指标，表达式不含 $i$，
于是它等于 $2\log\lambda(t)$——$t$ 取 $1$ 得 $2\log 2\approx1.386$，取 $2$ 得 $\approx-1.386$，
同一个数值给出两个互相矛盾的结果，且都不等于 $0$。

**为什么会写错**：上一行刚写完 $\lim_{N\to\infty}$，作者在写求和号时按「下标用 $i$」的肌肉记忆落笔，
而这项内部早就被写成 $\log\lambda(t)$。这类错在 4.59(c)、4.64、5.7(a) 里同型复发（见下一条译注）。

<span style="color:#1e8449;">**[译注]** 本块出现了**四处同一型的错**，值得当成一个检查动作固化下来：4.59(c) 的 $\sum_ip_kf_0(x,u_k)$、4.60 的 $\sum_{i=1}^{N}\log\lambda(t)$、4.64 的 $z_1,\dots,z_q$（应为 $z_1,\dots,z_S$）、5.7(a) 的 $t\lambda_k$（应为 $t\lambda_j$）。它们的共同结构是：**一个被绑定的指标（bind）与一个自由出现的指标对不上**。数学上这不是「笔误」这么轻——$\sum_i g(k)$ 在 $g$ 不含 $i$ 时等于「$g(k)$ 乘以 $i$ 的取值个数」，是一个**量级错**，而不是排版错。

① 每个自由指标都被某个算子绑定过；② 每个算子的指标在项内**至少出现一次**。这两条各一票否决。

换句话说，采用投资策略 $x$ 时，长期增长率由下式给出：

```math
R_{lt} = \sum_{j=1}^{m}\pi_j\log(p_j^{T}x).
```

使这个量最大的投资策略 $x$ 称为 log-optimal investment strategy（对数最优投资策略），它可以通过求解优化问题

```math
\begin{aligned}
\text{maximize}\quad & \sum_{j=1}^{m}\pi_j\log(p_j^{T}x)\\
\text{subject to}\quad & x \succeq 0,\quad \mathbf{1}^{T}x = 1,
\end{aligned}
```

**解答**。其实这道题没什么可做的。约束 $x \succeq 0$、$\mathbf{1}^{T}x=1$ 显然是凸的，所以只需说明目标是凹的
（因为它要被最大化）。几步就够了：首先，$\log$ 是凹的，所以 $\log(p_j^{T}x)$ 关于 $x$ 是凹的（在其定义域上，
即开半空间 $\{x \mid p_j^{T}x \gt 0\}$）。由于 $\pi_j \ge 0$，我们断定凹函数之和

```math
\sum_{j=1}^{m}\pi_j\log(p_j^{T}x)
```

是凹的。

> **补一句原文省略的边界**：这里「定义域」必须显式取 $p_j^{T}x \gt 0$ 对**所有** $j$ 成立，否则 $\log$ 无定义。
> 若某个 $p_j$ 有非负分量，则满足 $p_j^{T}x \gt 0$ 对一切 $j$ 的 $x$ 构成的集合与单纯形之交通常非空
> （取 $x$ 严格正即可）；但若存在 $p_j \le 0$（某情景下所有资产都亏），模型本身要改写（$\log$ 无意义），

### Exercise 4.61：Logistic 模型下的定价与利润 —— 单调变换与对数化

> **中文话题摘要**：购买概率是 logistic 形式 $p=e^{u}/(1+e^{u})$，$u=a^{T}x+b$。最大化 $p$ 是 LP；
> 最大化期望利润 $p(c^{T}x+d)$ 取对数后变成「线性 + 负 log-sum-exp + log-linear」的凹和。

**题干（译）**。随机变量 $X\in\{0,1\}$ 满足

```math
\mathbf{prob}(X=1) = p = \frac{\exp(a^{T}x+b)}{1+\exp(a^{T}x+b)},
```

其中 $x\in\mathbf{R}^{n}$ 是影响该概率的变量向量，$a$ 与 $b$ 是已知参数。我们可以把 $X=1$ 看作「消费者购买了某产品」
这一事件，把 $x$ 看作影响该概率的一组变量，例如广告投入、零售价、折扣价、包装费用以及其他因素。我们要优化的变量 $x$
受一组线性约束 $Fx \preceq g$ 限制。

把下述问题表述成凸优化问题。

**(a) 最大化购买概率**。目标是选择 $x$ 使 $p$ 最大。

**(b) 最大化期望利润**。设 $c^{T}x+d$ 是销售该产品所得的利润，并假定它对一切可行 $x$ 都为正。目标是最大化期望利润，
即 $p(c^{T}x+d)$。

**解答**。

**(a)** 函数 $e^{u}/(1+e^{u})$ 关于 $u$ 是单调递增的，所以我们可以通过最大化 $a^{T}x+b$ 来最大化
$\exp(a^{T}x+b)/(1+\exp(a^{T}x+b))$，这就给出 LP

```math
\begin{aligned}
\text{maximize}\quad & a^{T}x+b\\
\text{subject to}\quad & Fx \preceq g .
\end{aligned}
```

**(b)** 这里要最大化的是 $p(c^{T}x+d)$，或者等价地，取它的对数：

```math
\begin{aligned}
\text{maximize}\quad & a^{T}x+b-\log\left(1+\exp(a^{T}x+b)\right)+\log(c^{T}x+d)\\
\text{subject to}\quad & Fx \preceq g .
\end{aligned}
```

这是凸问题，因为目标函数是 $x$ 的凹函数。（回忆：$f(x)=\log\sum_{i=1}^{m}\exp(a_i^{T}x+b_i)$ 是凸的。）

> **（本页解答自查：无错。）** 逐项核对：(a) 的单调性用的是 $e^{u}/(1+e^{u})$ 的导数
> $e^{u}/(1+e^{u})^{2} \gt 0$，对一切 $u$ 成立，故「最大化 logistic 型概率 = 最大化 $a^{T}x+b$」严格成立，
> 而且这是**保序映射**（同一个 $x$ 上比较大小关系完全一致），不止是无约束最优值相同。(b) 的三段分解
> $\log p = u-\log(1+e^{u})$、$\log(c^{T}x+d)$ 分别是凹、凹，和仍凹；可行性上还需 $c^{T}x+d \gt 0$（题面已给），
> 与 $1+e^{u} \gt 0$（恒成立）。凸性成立，无需额外 constraint qualification。

### Exercise 4.62：Gaussian broadcast channel 的功率与带宽分配 —— perspective 的凹性与 rank-1 Hessian

> **中文话题摘要**：$R_i=\alpha_iW_i\log(1+\beta_iP_i/W_i)$ 是 $\log(1+\beta P)$ 的 perspective，
> 因此关于 $(P_i,W_i)$ 凹；配合「非降凹 $\circ$ 凹」与求和，总效用凹。Hessian 是一个 $\times$ 向量外积，

**题干（译）**。我们考虑一个通信系统：一个中心节点向 $n$ 个接收者发送消息。（「Gaussian」指的是污染传输的噪声类型。）
每个接收者信道由它的（发射）功率 $P_i \ge 0$ 与带宽 $W_i \ge 0$ 刻画。一个接收者信道的功率与带宽通过下式决定其
bit rate（比特率）$R_i$（可传输信息的速率）：

```math
R_i = \alpha_iW_i\log(1+\beta_iP_i/W_i),
```

其中 $\alpha_i$ 与 $\beta_i$ 是已知的正的常数。对 $W_i=0$ 我们取 $R_i=0$（这也正是令 $W_i\to 0$ 取极限所得的结果）。

功率必须满足总功率约束，其形式为

```math
P_1+\cdots+P_n = P_{tot},
```

其中 $P_{tot} \gt 0$ 是可在各信道间分配的总功率。类似地，带宽必须满足

```math
W_1+\cdots+W_n = W_{tot},
```

其中 $W_{tot} \gt 0$ 是（给定的）总可用带宽。本题的优化变量是功率与带宽，即 $P_1,\dots,P_n$ 与 $W_1,\dots,W_n$。

目标函数是最大化总效用

```math
\sum_{i=1}^{n}u_i(R_i),
```

其中 $u_i:\mathbf{R}\to\mathbf{R}$ 是与第 $i$ 个接收者相关联的效用函数。（可以把 $u_i(R_i)$ 看成向接收者 $i$

把这个问题表述成一个凸优化问题。

**解答**。把 $R_i$ 的表达式代入目标，得到

```math
\begin{aligned}
\text{maximize}\quad & \sum_{i=1}^{n}u_i\left(\alpha_iW_i\log(1+\beta_iP_i/W_i)\right)\\
\text{subject to}\quad & \mathbf{1}^{T}P = P_{tot},\quad \mathbf{1}^{T}W = W_{tot}\\
& P \succeq 0,\quad W \succeq 0,
\end{aligned}
```

变量为 $P,W\in\mathbf{R}^{n}$。我们来证明 $R_i$ 是 $(P_i,W_i)$ 的凹函数。由此可知 $u(R_i)$ 是凹的，
因为它是「凹函数的非降凹函数」。总效用 $U$ 于是也是凹的，因为它是凹函数之和。

**（承 p127 末）** 要证明 $R_i$ 关于 $(P_i,W_i)$ 是凹的，可以求 Hessian，它是

```math
\nabla^{2}R_i = -\frac{\alpha_i\beta_i^{2}}{W_i(1+\beta_iP_i/W_i)^{2}}
\begin{bmatrix}1\\ -P_i\end{bmatrix}
\begin{bmatrix}1\\ -P_i\end{bmatrix}^{T}.
```

由于 $\alpha_i$、$\beta_i$、$W_i$、$P_i$ 都是正的，$\nabla^{2}R_i$ 是 negative semidefinite（负半定）的。

† **4.62 的 Hessian rank-1 分解漏了 $W_i$：向量第二分量应为 $-P_i/W_i$，不是 $-P_i$。**

### Exercise 4.63：制造成本与良率的平衡 —— 非凸分式目标 + 一维搜索 + MM 下界

> **中文话题摘要**：$c^{T}x/Y(x)$（$Y$ log-concave）既非凸也非拟凸；但把 $a=c^{T}x$ 当参数后，
> 「最大良率 $f(a)$」是 log-concave 的，于是原问题降成 $a$ 上的**一维**搜索 $\max_a\left[\log f(a)-\log a\right]$。

**题干（译）**。向量 $x\in\mathbf{R}^{n}$ 表示制造过程中的标称参数。该过程的 yield（良率），即合格产品的比例，
由 $Y(x)$ 给出。我们假定 $Y$ 是 log-concave（对数凹）的（这通常是成立的；见例 3.43）。生产每件产品的成本由
$c^{T}x$ 给出，其中 $c\in\mathbf{R}^{n}$。每件**合格**产品的成本是 $c^{T}x/Y(x)$。我们要在 $x$ 上的一些凸约束
（例如线性不等式 $Ax \preceq b$）之下最小化 $c^{T}x/Y(x)$。（可以假定在可行集上 $c^{T}x \gt 0$ 且 $Y(x) \gt 0$。）

这个问题不是凸优化问题，也不是拟凸优化问题，但可以用凸优化加一维搜索来解。基本思路如下；所有细节与论证由你补充。

**(a)** 证明由下式给出的函数 $f:\mathbf{R}\to\mathbf{R}$

```math
f(a) = \sup\{Y(x) \mid Ax \preceq b,\ c^{T}x = a\},
```

即「最大良率对成本」的函数，是 log-concave 的。这意味着通过求解一个（关于 $x$ 的）凸优化问题就能求值 $f$。

**(b)** 假设我们在足够多的 $a$ 值上求值 $f$，使之在关心的区间上给出良好近似。说明如何用这些数据（近似地）求解
「最小化每件合格产品成本」的问题。

<!-- ===== p129 ===== -->

**解答**。先验证目标既不是凸的也不是拟凸的。要使 $c^{T}x/Y(x)$ 是拟凸的，需要约束

```math
c^{T}x/Y(x) \le t \iff \log(c^{T}x)-\log Y(x) \le \log t
```

是凸的。按假设，$-\log Y(x)$ 是凸的，但一般不能假定它与 $\log(c^{T}x)$ 之和也是凸的。

**(a)** 函数 $f(a)$ 是 log-concave 的，因为

```math
\log f(a) = \sup_{a}F(x,a)
```

其中

```math
F(x,a) =
\begin{cases}
\log Y(x), & Ax \preceq b,\ c^{T}x = a\\
-\infty, & \text{otherwise}
\end{cases}
```

† **4.63(a) 的哑变量被同名覆盖：$\log f(a)=\sup_{a}F(x,a)$ 应为 $\sup_{x}F(x,a)$。** 左边是 $a$ 的函数，
右边却把 $a$ 用 $\sup$ 绑定掉了，此时右边变成「对一切 $a$ 取上确界」的常数——与左边矛盾。

**正确式子**：

```math
\log f(a) = \sup_{x}F(x,a)
```

紧接的下一句「maximizing over a gives another concave function」同样应为「maximizing over **$x$**」：
$F(x,a)$ 是关于 $(x,a)$ 的凹函数，对**部分变量** $x$ 取上确界后，剩下的 $a$ 的函数仍凹（这是
「infimal projection 保凸性」的对偶版本，Boyd §3.2.5）。若真对 $a$ 取上确界，结果与 $a$ 无关，
$f$ 就不是 $a$ 的函数，题目 (b) 的「一维搜索」也无从谈起——**这个错会让整题的方法论崩塌**。

**数值反例**：取 $n=1$，$Y(x)=\exp(-x^{2})$（log-concave，$\log Y=-x^{2}$），可行集取整条实轴、
$c=1$（于是 $a=x$）。正确做法：$\log f(a)=\sup_x\{\log Y(x) : x=a\}=-a^{2}$，即 $f(a)=e^{-a^{2}}$，
$f(1)=e^{-1}\approx0.368$、$f(2)=e^{-4}\approx0.018$，两点不同 ✓。按原文的 $\sup_a F(x,a)$：
$a$ 被绑定，剩下自由变量 $x$，$\sup_{a}\{-a^{2}:a=x\}=-x^{2}$，得到的是 $x$ 的函数而非 $a$ 的函数；
把它当作 $f(a)$ 就要求对所有 $x$ 都成立，取 $x=0$ 得 $\sup$ 值为 $0$，于是「$f(a)=e^{0}=1$ 对一切 $a$」——
$f(1)$ 从 $0.368$ 变成 $1$，与真实最大良率相差 $1/e^{1}$ 倍。

**为什么会写错**：$f$ 的自变量叫 $a$，而 $F$ 的第二个参数也叫 $a$，作者写 $\sup$ 时眼睛盯着「要对第二个参数优化」
就顺手填了 $a$——这在数学上等于把外层的自由变量 $a$ 用内层的绑定变量遮蔽掉（shadowing），
和编程里 `for (a in ...) { use a }` 覆盖外层变量是同一种事故。**规避办法**：写 $\sup$ 前先问「优化的是哪个变量」，
且保证该变量**不被同时用作输出的名字**；若冲突，先把外层改名（这里写成 $\log f(\alpha)=\sup_{x}F(x,\alpha)$ 就不会错）。

$F$ 的定义域是 $\{(x,a) \mid Ax \preceq b,\ c^{T}x=a\}$，这是一个凸集。在其定义域上它等于 $\log Y(x)$，
而后者是凹函数。因此 $F$ 是凹的，于是对 $x$ 取最大值之后得到的仍是凹函数。

**(b)** 我们想求解问题

```math
\begin{aligned}
\text{maximize}\quad & \log\left(Y(x)/c^{T}x\right)\\
\text{subject to}\quad & Ax \preceq b,
\end{aligned}
```

或者等价地

```math
\begin{aligned}
\text{maximize}\quad & \log Y(x)-\log a\\
\text{subject to}\quad & Ax \preceq b\\
& c^{T}x = a,
\end{aligned}
```

变量为 $x$ 与 $a$。先对 $x$ 优化、再对 $a$ 优化，就可以把问题写成

```math
\text{maximize}\quad \log f(a)-\log a,
```

变量为 $a$。目标函数是一个凹函数与一个凸函数之和。通过在大量 $a$ 值上求值 $\log f(a)-\log a$，
我们可以近似地求解该问题。

另一个有用的观察如下。若我们在某个 $a=\hat{a}$ 处求值该目标函数，这不仅能给出函数值，还能给出一个凹的下界

```math
\begin{aligned}
\log f(a)-\log a &\ge \log f(a)-\log\hat{a}-(a-\hat{a})/\hat{a}\\
&= \log f(a)-a/\hat{a}-\log\hat{a}+1 .
\end{aligned}
```

通过反复地最大化这个下界并做线性化，我们可以找到 $f(a)/a$ 的一个局部最大值。

> **（本页推导自查）** 下界的来源是 $\log$ 在 $\hat a$ 处的一阶 Taylor 上界
> $\log a \le \log\hat a+(a-\hat a)/\hat a$，取负得 $-\log a \ge -\log\hat a-(a-\hat a)/\hat a$ ✓；
> 展开后 $-\log\hat a+(\hat a/\hat a)-a/\hat a = -a/\hat a-\log\hat a+1$ ✓ 与原文一致。
> 下界是 $a$ 的凹函数（$\log f$ 凹、$-a/\hat a$ 线性），所以「最大化下界」是可解的凸问题——
> 这套「用可解的下界替代不可解的目标、再把下界在最优点重新线性化」的迭代就是 MM 算法
> （minorize–maximize），与 EM 是同一族。另注意原文 (b) 开头「$\log Y(x)-\log a$ 中 $a=c^{T}x$」
> 与「先对 $x$ 后对 $a$」这两步的顺序不能颠倒：先 $a$ 后 $x$ 会得到 $\sup_a[\log f(a)]$，是一堆
> 关于 $x$ 的约束的联合放松，不再等价。

### Exercise 4.64：Optimization with recourse —— 两阶段决策为什么天然是凸的

> **中文话题摘要**：第一阶段变量 $x$ 在情景未知时定下，第二阶段变量 $z_i$ 依情景分别取；
> 把 $S$ 份 $z_i$ 并列成变量后，期望成本只是 $S$ 个凸函数之和，维数 $n+Sq$。

**题干（译）**。在 optimization with recourse（带补救的优化，也叫 two-stage optimization，两阶段优化）中，
成本函数与约束不仅依赖我们对变量的选择，还依赖一个离散随机变量 $s\in\{1,\dots,S\}$，它被解释为「$S$ 种情景中
哪一种发生了」。情景随机变量 $s$ 有已知的概率分布 $\pi$，其中 $\pi_i=\mathbf{prob}(s=i)$，$i=1,\dots,S$。

在两阶段优化中，我们要选两组变量 $x\in\mathbf{R}^{n}$ 与 $z\in\mathbf{R}^{q}$。变量 $x$ 必须在情景 $s$ 具体未知之前选定；
而变量 $z$ 则是在情景随机变量的值已知之后才选。换言之，$z$ 是情景随机变量 $s$ 的函数。为了描述我们的选择 $z$，
我们列出在不同情景下会取的值，即列出向量 $z_1,\dots,z_S\in\mathbf{R}^{q}$。这里 $z_3$ 就是 $s=3$ 发生时我们对 $z$
的选择，依此类推。取值集合

```math
x\in\mathbf{R}^{n},\qquad z_1,\dots,z_S\in\mathbf{R}^{q}
```

称为 policy（策略），因为它告诉我们 $x$ 该取什么（与发生哪种情景无关），以及在每种可能情景下 $z$ 该取什么。

变量 $z$ 称为 recourse variable（补救变量，或第二阶段变量），因为它让我们在知道发生了什么情景之后采取行动或做出选择。
相比之下，我们对 $x$ 的选择（称为 first-stage variable，第一阶段变量）必须在完全不知道情景的情况下做出。

<!-- ===== p130 ===== -->

**（承上页）** 为简化起见，我们考虑没有约束的情形。成本函数由
$f:\mathbf{R}^{n}\times\mathbf{R}^{q}\times\{1,\dots,S\}\to\mathbf{R}$ 给出，其中 $f(x,z,i)$ 表示「第一阶段选择 $x$、
第二阶段选择 $z$、且发生情景 $i$」时的成本。我们把在整个策略集上最小化的总体目标取为期望成本

```math
E\,f(x,z_s,s) = \sum_{i=1}^{S}\pi_if(x,z_i,i).
```

假设对每个情景 $i=1,\dots,S$，$f$ 都是 $(x,z)$ 的凸函数。说明如何用凸优化求出一个最优策略，
即在所有可能策略上使期望成本最小的策略。

**解答**。问题的变量是

```math
x,\quad z_1,\dots,z_q,
```

† **4.64 的变量列表写成了 $z_1,\dots,z_q$，应为 $z_1,\dots,z_S$。** $q$ 是每个第二阶段变量的**维数**，
不是它的**个数**；个数是情景数 $S$。

**正确式子**：

```math
x\in\mathbf{R}^{n},\qquad z_1,\dots,z_S\in\mathbf{R}^{q}
```

紧接着的下一句「变量的（总）维数是 $n+Sq$」正好自证了这一点：若变量是 $z_1,\dots,z_q$，总维数应是 $n+q^{2}$。

**数值反例**：取 $S=3$（三种情景）、$q=1$（$z$ 是标量）。正确变量是 $x$ 与 $z_1,z_2,z_3$，共 $n+3$ 维。
按原文的 $z_1,\dots,z_q=z_1$，只有 $z_1$ 一个补救变量——但目标 $\sum_{i=1}^{3}\pi_if(x,z_i,i)$ 里出现了
$z_2,z_3$，它们是**自由变量**，期望成本可以取到 $-\infty$（取 $z_2,z_3$ 使各 $f$ 任意小，只要 $f$ 沿某方向
无下界），问题退化成 unbounded。$q=1$ 这个最简情形立刻暴露错误。

**为什么会写错**：题干里 $z\in\mathbf{R}^{q}$ 出现得比 $z_1,\dots,z_S$ 更早、更醒目，作者写变量列表时
按「$z$ 的上标范围」直接填了 $q$。同型的错在同一页密度极高（4.59(c)、4.60、5.7(a)），
共同点是**下标名与上标名混用**。

即整个策略 $x,z_1,\dots,z_S$。变量的（总）维数是 $n+Sq$。我们的问题不是别的，就是

```math
\text{minimize}\quad F(x) = \sum_{i=1}^{S}\pi_if(x,z_i,i),
```

它是凸的，因为对每个 $i$，$f(x,z,i)$ 关于 $(x,z_i)$ 是凸的，且 $\pi_i \ge 0$。

> **（本页推导自查：无误）** 「$S$ 个凸函数以非负权重求和仍凸」是凸性的保运算（Boyd §3.2.1），
> 而且这里**不要求** $f(\cdot,\cdot,i)$ 与 $f(\cdot,\cdot,j)$ 之间有任何关系——这正是两阶段的本质：
> 每份 $z_i$ 各自独立地进入一个凸项，$x$ 是它们唯一的耦合。原文把 $F$ 写成 $F(x)$（而非 $F(x,z_1,\dots,z_S)$）
> 属于记号上的随意，读作 $F(x,z)$ 即可，不构成数学错。

### Exercise 4.65：混合动力车的能量管理 —— 绝对值的分片展开与「扔能量」论证

> **中文话题摘要**：功率平衡与油箱/电池约束都是线性的，唯一非凸项是电池递推里的 $-p_{mg}-\eta|p_{mg}|$；
> 把它放松成 $\le$ 之后变成两条线性不等式（因为 $-|p|=\min$ 两条线性），再用「扔能量必然浪费」收回等号。

**题干（译）**。混合动力车有内燃机、与储能电池相连的电机/发电机，以及常规（摩擦）制动器。本题考虑一个
（高度简化的）并联式混合动力车模型，其中电机/发电机与内燃机都直接连到驱动轮上。内燃机可以向车轮提供功率，

我们通过在一条已知的、固定的测试跑道上驾驶该车来评估其燃油经济性。

```math
E(t+1) = E(t)-p_{mg}(t)-\eta|p_{mg}(t)|,\qquad t = 1,\dots,T .
```

$T$ 条递推从 $E(1)$ 推出 $E(2),\dots,E(T+1)$，正好对上 $T+1$ 个电池状态，与「$E(1)=E(T+1)$ 固定净变化为零」

**（承 p131 末）** 本题的目标是内燃机消耗的总燃油量：

```math
F_{total} = \sum_{t=1}^{T}F(p_{eng}(t)),
```

其中 $F:\mathbf{R}\to\mathbf{R}$ 是内燃机的燃油消耗特性。我们假定 $F$ 是正的、递增的、且凸的。

把这个问题表述成一个凸优化问题，变量为 $t=1,\dots,T$ 的 $p_{eng}(t)$、$p_{mg}(t)$、$p_{br}(t)$，
以及 $t=1,\dots,T+1$ 的 $E(t)$。解释你的表述为什么与上面描述的问题等价。

**解答**。我们先把给定的目标与约束收集起来，构成问题

```math
\begin{aligned}
\text{minimize}\quad & \sum_{t=1}^{T}F(p_{eng}(t))\\
\text{subject to}\quad & p_{req}(t) = p_{eng}(t)+p_{mg}(t)-p_{br}(t)\\
& E(t+1) = E(t)-p_{mg}(t)-\eta|p_{mg}(t)|\\
& 0 \le E(t) \le E^{max}_{batt}\\
& E(1) = E(T+1)\\
& 0 \le p_{eng}(t) \le P^{max}_{eng}\\
& P^{min}_{mg} \le p_{mg}(t) \le P^{max}_{mg}\\
& 0 \le p_{br}(t),
\end{aligned}
```

其中每条约束都在相应的 $t$ 范围上施加。燃油消耗函数 $F$ 是凸的，所以目标函数是凸的。除电池电量

**（p132 续）** 方程之外，每条约束都是线性等式或线性不等式。所以在这个形式下问题不是凸的。

我们需要说明如何处理那些非凸约束

```math
E(t+1) = E(t)-p_{mg}(t)-\eta|p_{mg}(t)| .
```

一种办法是把它替换成放松后的约束

```math
E(t+1) \le E(t)-p_{mg}(t)-\eta|p_{mg}(t)|,
```

它是凸的——事实上是两条线性不等式。直观上，这个放松意味着我们打开了一个可能性：每一步都可以把电池里的能量扔掉。
当目标是燃油经济性时，这听起来是个坏主意；而确实容易看出，若我们用放松后的电池电量约束求解该问题，
最优解 $E^{\star}$ 满足

```math
E^{\star}(t+1) = E^{\star}(t)-p_{mg}(t)-\eta|p_{mg}(t)|,
```

从而也解出了原问题。要正式论证这一点，假设放松后问题的解在某一步 $t$ 确实扔掉了一些能量。那么我们构造一条新的轨迹：
不扔掉那些多余的能量，而是用它来驱动车轮，并减少内燃机功率。由于燃油消耗特性是递增的，这降低了燃油消耗，
从而说明原来的解不可能是最优的。

<span style="color:#1e8449;">**[译注]** 这一页的**技术核心**只有一行：$-\eta|p_{mg}|$ 这个东西把等式约束变成非凸，但

```math
-y \le a \iff -y \le a \ \text{且}\ -y \le -a \iff y \ge |a|
```

的反向用法——即「$E(t+1)-E(t)+p_{mg}+\eta|p_{mg}| \le 0$」——可以写成两条线性不等式，因为
$-|p|=\min(-p,\,p)$ 而「$y \le \min(u,v)$」等价于「$y \le u$ 且 $y \le v$」。展开后：

```math
E(t+1) \le E(t)-(1+\eta)p_{mg}(t),\qquad E(t+1) \le E(t)+(\eta-1)p_{mg}(t).
```

**验证**：$p_{mg} \ge 0$（电机，放电）时第一式更紧，给出 $E$ 的下降斜率 $1+\eta$；$p_{mg} \lt 0$（发电机，充电）时
第二式更紧，给出上升斜率 $1-\eta$——充电只收回 $1-\eta$ 比例的能量，正对应题面 $\eta \gt 0$ 的效率损失。
**消失测试**：不拆成两式，这题就停在「不是凸问题」，$T=1000$ 的跑道只能用 MINLP 分支定界，规模 $2^{T}$ 级别的
组合搜索；拆开后是一个 $T$ 段 LP/GP 规模的凸问题，内点法在 $O(T^{3})$ 以内。

**注意原文论证的一个边界**（**此处不作为 `†`**，因为结论在本题参数下仍成立，但论证不完整）：作者说
「扔能量意味着可以拿去驱动车轮、减少内燃机功率」。若该期电池已经顶到 $E^{max}_{batt}$，充电无处可去时，
「扔能量」是**被迫的**而非浪费，此时严格不等式可能出现；但那种情形下把 $E(1)$ 整体下移同样多即可消除
（$E(1)$ 是自由变量，只有 $E(1)=E(T+1)$ 一个约束），目标值不变，所以「存在一个取等的最优解」仍然成立——
而这正是题面所需要的（等价性只需最优值相同，不必每个最优解都取等）。原解答把「存在」讲成了「必然」，
措辞强于事实。

### Exercise 5.2：unbounded 与 infeasible 两种退化情形下，weak duality 仍然成立

> **中文话题摘要**：$d^{\star}\le p^{\star}$ 在 $d^{\star}=-\infty$ 或 $p^{\star}=\infty$ 时显然成立；
> 本题补另外两个方向：$p^{\star}=-\infty \Rightarrow d^{\star}=-\infty$，$d^{\star}=\infty \Rightarrow p^{\star}=\infty$。

**题干（译）**。weak duality 不等式 $d^{\star}\le p^{\star}$ 在 $d^{\star}=-\infty$ 或 $p^{\star}=\infty$ 时显然成立。
证明它在另外两种情形下也成立：若 $p^{\star}=-\infty$，则必有 $d^{\star}=-\infty$；并且，若 $d^{\star}=\infty$，则必有 $p^{\star}=\infty$。

**解答**。

**(a) $p^{\star}=-\infty$**。原问题是 unbound 的，即存在可行的 $x$ 使 $f_0(x)$ 任意小。这意味着

```math
L(x,\lambda) = f_0(x)+\sum_{i=1}^{m}\lambda_if_i(x)
```

对一切 $\lambda \succeq 0$ 都是下方无界的，即对 $\lambda \succeq 0$ 有 $g(\lambda)=-\infty$。因此对偶问题不可行（$d^{\star}=-\infty$）。

**(b) $d^{\star}=\infty$**。对偶问题上方无界。这只有在原问题不可行时才有可能。若它可行，且有 $f_i(\tilde{x})\le0$（$i=1,\dots,m$），则对一切 $\lambda \succeq 0$ 有

```math
g(\lambda) = \inf\left(f_0(x)+\sum_{i}\lambda_if_i(x)\right) \le f_0(\tilde{x})+\sum_{i}\lambda_if_i(\tilde{x}),
```

于是对偶问题是上方有界的。

> **（本页推导自查：无误，但补两条原文省略的关键推理）**
> ① (a) 里「$L$ 下方无界」依赖 **可行点存在**：$p^{\star}=-\infty$ 蕴含原问题可行（否则 $p^{\star}=+\infty$），
> 而 $\lambda \succeq 0$ 加上 $f_i(x)\le0$ 给 $\lambda_if_i(x)\le0$，于是 $L(x,\lambda)\le f_0(x)$；
> 让 $f_0(x)\to-\infty$ 就得到 $L\to-\infty$。**符号方向**：正是 $\lambda_if_i(x)\le0$（而不是 $\ge 0$）
> 让 $L$ 成为 $f_0$ 的**下界**——这是整章所有弱对偶证明的唯一依赖，翻向立刻失效。
> ② (b) 的结论比原文更强：$d^{\star}=\infty$ 时不仅有 $p^{\star}=\infty$，而且 $p^{\star}\ne-\infty$ 正是由
> 上述界保证的（否则 $g(\lambda)\le f_0(\tilde x)$ 与 $g$ 无界矛盾）。所以「primal infeasible」与
> 「$d^{\star}=\infty$」在弱对偶下互为充分必要（当 $p^{\star}\ne-\infty$ 时）。

### Exercise 5.3：单不等式约束的对偶 —— 用 conjugate 写出一维问题

> **中文话题摘要**：对 $\min c^{T}x$ s.t. $f(x)\le0$，对偶函数是 $-g(\lambda)=\lambda f^{*}(-c/\lambda)$
> （即 $f^{*}$ 的 perspective），于是对偶问题是一维的凸问题——**即使 $f$ 不凸**。

**题干（译）**。把问题

```math
\begin{aligned}
\text{minimize}\quad & c^{T}x\\
\text{subject to}\quad & f(x) \le 0,
\end{aligned}
```

（其中 $c\ne0$）的对偶问题用 conjugate（共轭函数）$f^{*}$ 表达出来。解释你给出的问题为什么是凸的。
我们**不**假定 $f$ 是凸的。

<!-- ===== p137 ===== -->

**解答**。对 $\lambda=0$，$g(\lambda)=\inf c^{T}x=-\infty$。对 $\lambda \gt 0$，

```math
\begin{aligned}
g(\lambda) &= \inf\left(c^{T}x+\lambda f(x)\right)\\
&= \lambda\inf\left((c/\lambda)^{T}x+\lambda f(x)\right)\\
&= -\lambda f^{*}(-c/\lambda),
\end{aligned}
```

† **5.3 第一处：提取 $\lambda$ 时把 $f$ 也乘了一次——$\lambda\inf((c/\lambda)^{T}x+\lambda f(x))$ 应为 $\lambda\inf((c/\lambda)^{T}x+f(x))$。**

**正确式子**：

```math
c^{T}x+\lambda f(x) = \lambda\left[(c/\lambda)^{T}x+f(x)\right]\qquad(\lambda \gt 0),
```

所以

```math
g(\lambda) = \lambda\inf_x\left[(c/\lambda)^{T}x+f(x)\right] = -\lambda f^{*}(-c/\lambda).
```

**数值反例**：取 $f(x)=x^{2}$、$c=1$、$\lambda=2$、$x=1$。
左端 $c x+\lambda f(x)=1+2=3$；原文右端 $\lambda\left[(c/\lambda)x+\lambda f(x)\right]=2\left[0.5+2\right]=5$。
差 $2$ 倍的关系不是巧合：原文的式子实际算的是 $c x+\lambda^{2}f(x)$，与真实 Lagrangian 差 $(\lambda^{2}-\lambda)f(x)$，
在 $\lambda=2$ 时差 $2f(x)$。**后果**：随后那个漂亮的结论 $g(\lambda)=-\lambda f^{*}(-c/\lambda)$ 会变成
$g(\lambda)=-\lambda f^{*}(-c/\lambda^{2})$ 之类，conjugate 的自变量错位。

**为什么会写错**：从 $\inf(c^{T}x+\lambda f(x))$ 提 $\lambda$ 出来，括号内每一项都要除 $\lambda$；
作者对 $c^{T}x$ 做了（得到 $(c/\lambda)^{T}x$），对 $\lambda f(x)$ 忘了做（保留原样）——**半途而废的齐次化**。
检查动作：提取公因子后回乘一遍，逐项对数。

† **5.3 第二处：对偶问题写成了 minimize，应为 maximize。** 由上一步 $g(\lambda)=-\lambda f^{*}(-c/\lambda)$，
dual problem 是「最大化 $g$」：

```math
\text{maximize}\quad -\lambda f^{*}(-c/\lambda)\qquad\text{subject to}\quad \lambda \ge 0 .
```

原文写成 `minimize $-λf^{*}(-c/λ)$`，方向翻了一次。（等价写法：`minimize $\lambda f^{*}(-c/\lambda)$` 也行，
就是把 $-g$ 最小化；但「minimize $-g$」与「minimize $g$」是两件相反的事。）

**数值反例**（可手算到底）：取 $f(x)=x^{2}$、$c=1$。此时 $f^{*}(y)=y^{2}/4$，于是
$g(\lambda)=-\lambda\cdot(1/\lambda)^{2}/4=-1/(4\lambda)$。
① 原问题：$\min x$ s.t. $x^{2}\le0 \Rightarrow x^{\star}=0$，$p^{\star}=0$。
② 正确的对偶：$\max_{\lambda\ge0}(-1/(4\lambda))=\sup_{\lambda\to\infty}(-1/(4\lambda))=0=d^{\star}$ ✓ 强对偶。
③ 按原文的 minimize：$\min_{\lambda\ge0}(-1/(4\lambda))=-\infty$——给出一个**完全不存在的负无穷对偶值**，
并会诱使你判定「weak duality 被违反」。

**为什么会写错**：$\min$ 型原问题的 dual 永远是 $\max$（dual function 是仿射函数的逐点下确界，本身凹，
故对上确界）；作者在同一行里既写了 $-\lambda f^{*}$（负号）又写了 minimize，等于把两次翻转叠加成了一次。
**一句话记法**：对偶问题的 $\min/\max$ 由对偶函数的凹凸决定，不由眼前的正负号决定；$g$ 凹 $\Rightarrow$ 必 maximize。

也就是说，对 $\lambda \ge 0$，$-g$ 是 $f^{*}$ 的 perspective，在 $-c/\lambda$ 处取值。对偶问题是

```math
\begin{aligned}
\text{maximize}\quad & -\lambda f^{*}(-c/\lambda)\\
\text{subject to}\quad & \lambda \ge 0 .
\end{aligned}
```

> **（修正后的完整答案）** 上式即正确形式。凸性来自两项：$f^{*}$ 恒为凸（conjugate 由一族仿射函数的
> 上确界定义，与 $f$ 是否凸无关——这正是题面强调「不假定 $f$ 凸」的原因，$f^{**}$ 才是 $f$ 的凸包），
> 而 $\lambda f^{*}(-c/\lambda)$ 是 $f^{*}$ 的 perspective，perspective 保凸；于是 $-g$ 是凸函数、
> $g$ 是凹函数，最大化凹函数是凸问题。定义域上要注意 $\lambda=0$ 处 $g=-\infty$（$c\ne0$），
> 等价于 $f^{*}$ 的 perspective 在 $t=0$ 处取 $+\infty$（因为 $x=-c/0$ 无定义且 $c\ne0$）。

### Exercise 5.4：LP 对偶的几何解释 —— 用半空间给下界，再把 $(λ,w)$ 重参数化成 $z$

> **中文话题摘要**：任何 $w \succeq 0$ 都把可行集裹进一个半空间 $H_w$；在 $H_w$ 上最小化得到 $p^{\star}$ 的下界；
> 在所有 $w$ 上最大化这些下界，与 (5.22) 的 LP 对偶是同一件事（换元 $z=-\lambda w$ 即可）。

**题干（译）**。考虑不等式形式的 LP

```math
\begin{aligned}
\text{minimize}\quad & c^{T}x\\
\text{subject to}\quad & Ax \preceq b,
\end{aligned}
```

其中 $A\in\mathbf{R}^{m\times n}$、$b\in\mathbf{R}^{m}$。本题给出对偶 LP (5.22) 的一个简单几何解释。

设 $w\in\mathbf{R}^{m}_{+}$。若 $x$ 对 LP 可行，即满足 $Ax \preceq b$，则它也满足不等式

```math
w^{T}Ax \le w^{T}b .
```

几何上，对任意 $w \succeq 0$，半空间 $H_w=\{x \mid w^{T}Ax \le w^{T}b\}$ 都包含该 LP 的可行集。因此若我们在半空间
$H_w$ 上最小化目标 $c^{T}x$，就得到 $p^{\star}$ 的一个下界。

**(a)** 推导 $c^{T}x$ 在半空间 $H_w$ 上的最小值表达式（它依赖于 $w \succeq 0$ 的选取）。

**(b)** 通过在 $w \succeq 0$ 上最大化该下界，把「寻找最好的这种界」表述成一个问题。

**(c)** 把 (a) 与 (b) 的结果与 (5.22) 给出的该 LP 的 Lagrange dual 联系起来。

**解答**。

**(a)** 最优值是

```math
\inf_{x\in H_w}c^{T}x =
\begin{cases}
\lambda w^{T}b, & c = \lambda A^{T}w\ \text{对某个}\ \lambda \le 0\\
-\infty, & \text{其他情形}
\end{cases}
```

（见练习 4.8。）

**(b)** 我们通过求解下式来最大化该下界：

```math
\begin{aligned}
\text{maximize}\quad & \lambda w^{T}b\\
\text{subject to}\quad & c = \lambda A^{T}w\\
& \lambda \le 0,\quad w \succeq 0,
\end{aligned}
```

变量为 $\lambda$ 与 $w$。注意，若按字面理解，这不是一个凸问题。

> **（(a)(b) 自查：正确，补两处方向核对）** ① 为什么必须 $\lambda \le 0$：$H_w$ 的法向是 $A^{T}w$，
> 半空间朝 $+A^{T}w$ 一侧；要在其上让 $c^{T}x$ 有下界，$c$ 必须指向**相反**方向，即 $c=\lambda A^{T}w$ 且 $\lambda \le 0$。
> 取 $\lambda \le 0$ 后由 $(A^{T}w)^{T}x \le w^{T}b$ 乘 $\lambda$ 得
> $\lambda(A^{T}w)^{T}x \ge \lambda w^{T}b$，取等当 $x$ 落在边界上，故 $\inf = \lambda w^{T}b$ ✓。
> ② 若 $\lambda \gt 0$，则 $c$ 与法向同侧，沿 $-A^{T}w$ 方向走到 $-\infty$，故无下界 ✓。这一步正是「$\preceq$ 方向」
> 在几何上的表现，与 §5.1 的代数判据一致。
> ③ (b) 非凸的根源是 $c=\lambda A^{T}w$ 里的**双线性**项 $\lambda w$；而 $\lambda \le 0$、$w \succeq 0$ 的可行域
> 本身是凸的（两个锥之交）。**判据**：非凸性来自约束的乘积结构，不来自集合形状。

**(c)** 令 $z=-\lambda w$，就得到等价问题

```math
\begin{aligned}
\text{maximize}\quad & -b^{T}z\\
\text{subject to}\quad & A^{T}z+c = 0\\

```

这正是原 LP 的对偶。

> **（(c) 自查：正确，逐式核对）** $z=-\lambda w$：$\lambda \le 0$ 与 $w \succeq 0$ 给 $z \succeq 0$ ✓；
> $\lambda w^{T}b = -\lambda\cdot(-w^{T}b)$… 更直接地：$\lambda w^{T}b = (-z)^{T}b = -b^{T}z$ ✓；
> $c=\lambda A^{T}w=-A^{T}z \iff A^{T}z+c=0$ ✓。与 Boyd (5.22) 的标准对偶
> ($\text{maximize}\ -b^{T}z$ s.t. $A^{T}z+c=0$, $z \succeq 0$) 完全一致。
> **这一步的技巧值得单独记住**：把一个「乘积型」非凸约束 $c=\lambda A^{T}w$ 通过**变量替换**
> $z=-\lambda w$ 变成线性约束，代价是丢失了 $(\lambda,w)$ 到 $z$ 的映射的可逆性（$z$ 只确定 $(\lambda,w)$ 的
> 一个射线，$\lambda=0$ 时退化为 $z=0$）。但因为目标与约束都只通过 $z$ 依赖 $(\lambda,w)$，
> 这个不可逆**无害**——这正是「等价 reformulation」与「变量替换」的分界：只要目标函数在等值面上常值，替换就安全。

### Exercise 5.5：一般 LP 的对偶 —— 隐式等式约束要显式化

> **中文话题摘要**：$L=c^{T}x+\lambda^{T}(Gx-h)+\nu^{T}(Ax-b)$ 关于 $x$ 仿射，故 $g$ 只在
> $c+G^{T}\lambda+A^{T}\nu=0$ 时有限，值为 $-\lambda^{T}h-\nu^{T}b$；这条「隐式」约束必须写进对偶问题。

**题干（译）**。求 LP

```math
\begin{aligned}
\text{minimize}\quad & c^{T}x\\
\text{subject to}\quad & Gx \preceq h\\
& Ax = b
\end{aligned}
```

的对偶函数。给出对偶问题，并把其中的隐式等式约束显式化。

**解答**。

**(a)** Lagrangian 为

```math
\begin{aligned}
L(x,\lambda,\nu) &= c^{T}x+\lambda^{T}(Gx-h)+\nu^{T}(Ax-b)\\
&= (c^{T}+\lambda^{T}G+\nu^{T}A)x-\lambda^{T}h-\nu^{T}b,
\end{aligned}
```

它是 $x$ 的仿射函数。由此，对偶函数由下式给出：

```math
g(\lambda,\nu) = \inf_xL(x,\lambda,\nu) =
\begin{cases}
-\lambda^{T}h-\nu^{T}b, & c+G^{T}\lambda+A^{T}\nu = 0\\
-\infty, & \text{其他情形}.
\end{cases}
```

† **5.5 的常数项写成 $h\lambda^{T}$，应为 $\lambda^{T}h$（形状错）。** 原文第二行末尾是「$-h\lambda^{T}-\nu^{T}b$」。
$h\in\mathbf{R}^{m}$、$\lambda\in\mathbf{R}^{m}$ 都是列向量时，$\lambda^{T}h$ 是**标量**（$1\times1$），
而 $h\lambda^{T}$ 是 **$m\times m$ 矩阵**（秩 1，元素 $h_i\lambda_j$）。它不能与标量 $\nu^{T}b$ 相减，
也无法作为 $g$ 的取值。

**正确式子**：

```math
L(x,\lambda,\nu) = (c^{T}+\lambda^{T}G+\nu^{T}A)x-\lambda^{T}h-\nu^{T}b .
```

**数值反例**：取 $m=2$，$h=(1,2)^{T}$，$\lambda=(3,4)^{T}$。则 $\lambda^{T}h=3+8=11$（标量）；
而 $h\lambda^{T}=\begin{bmatrix}3&4\\6&8\end{bmatrix}$ 是 $2\times2$ 矩阵。若再取 $\nu^{T}b=5$，
正确值是 $11+5=16$（可代入 $c=0$、$x=0$ 验：$L=\lambda^{T}(-h)+\nu^{T}(-b)=-11-5=-16$ ✓ 符号随提取方式变但有定义），
而原文的表达式连「减一个标量」都无法执行。

**为什么会写错**：$\lambda^{T}(Gx-h)$ 展开时 $\lambda^{T}Gx-\lambda^{T}h$，作者在誊写第二项时把 $\lambda^{T}$ 写到了
$h$ 后面——**转置位置在抄写时漂移**。同页下面 $g$ 的表达式又写对了（$-\lambda^{T}h$），说明这是局部失误而非理解错。
**检查动作**：任何 $u^{T}v$ 形式的项，写完立刻核「左边是行向量、右边是列向量」，或统一用内积记号 $\langle u,v\rangle$。

**(b)** 对偶问题是

```math
\begin{aligned}
\text{maximize}\quad & g(\lambda,\nu)\\
\text{subject to}\quad & \lambda \succeq 0 .
\end{aligned}
```

把隐式约束显式化之后，得到

```math
\begin{aligned}
\text{maximize}\quad & -\lambda^{T}h-\nu^{T}b\\
\text{subject to}\quad & c+G^{T}\lambda+A^{T}\nu = 0\\
& \lambda \succeq 0 .
\end{aligned}
```

> **（本页其余自查：无误）** ① 为什么 $\nu$ 无符号约束而 $\lambda \succeq 0$：等式约束的乘子可取任意实数
> （$Ax-b$ 两侧都能"罚"），不等式约束的乘子必须非负——否则 $g$ 不再是 $p^{\star}$ 的下界，weak duality 崩。
> ② 「隐式约束」指 $c+G^{T}\lambda+A^{T}\nu=0$ 原本只体现在 $g=-\infty$ 的**分片**里，不写成显式约束就会
> 在数值实现时把 $-\infty$ 当作合法目标值传下去。③ 该对偶与 Boyd (5.16)/(5.17) 一致。

### Exercise 5.6：用 least-squares 残差给 Chebyshev 问题造对偶下界

> **中文话题摘要**：$\ell_\infty$ 问题的最优值无从闭式求得，但 $\ell_2$ 的解 $x_{ls}$ 有闭式；
> 用 $r_{ls}$ 造两个对偶可行点，其中 $\tilde\nu=+r_{ls}/\|r_{ls}\|_1$ 给出更好的界，
> 且这个界严格优于 $\frac{1}{\sqrt{m}}\|Ax_{ls}-b\|_\infty$。

**题干（译）**。考虑 Chebyshev（切比雪夫）即 $\ell_\infty$-范数逼近问题

```math
\text{minimize}\quad \|Ax-b\|_\infty,
```

其中 $A\in\mathbf{R}^{m\times n}$ 且 $\mathrm{rank}\,A=n$。用 $x_{ch}$ 表示一个最优解（最优解可能不唯一；$x_{ch}$ 指其中之一）。

Chebyshev 问题没有闭式解，但相应的 least-squares 问题有。定义

```math
x_{ls} = \arg\min\|Ax-b\|_2 = (A^{T}A)^{-1}A^{T}b .
```

我们要回答的问题是：假设对某个具体的 $A$ 与 $b$ 我们算出了 least-squares 解 $x_{ls}$（但没算 $x_{ch}$），
那么 $x_{ls}$ 对 Chebyshev 问题有多 suboptimal？换句话说，$\|Ax_{ls}-b\|_\infty$ 比 $\|Ax_{ch}-b\|_\infty$ 大多少？

**(a)** 证明下界

```math
\|Ax_{ls}-b\|_\infty \le \sqrt{m}\,\|Ax_{ch}-b\|_\infty,
```

并利用「对一切 $z\in\mathbf{R}^{m}$ 有 $\frac{1}{\sqrt{m}}\|z\|_2 \le \|z\|_\infty \le \|z\|_2$」这一事实。

> **（对 (a) 结论方向的核对）** 这里的 $\le$ 方向是**正确的**：它断言的是「$\ell_2$ 解在 $\ell_\infty$ 意义下
> 最坏只差 $\sqrt{m}$ 倍」，是一个上界（题名叫「Lower bounds」指的是 (b) 用对偶给出的下界，不是这一条）。
> 检查链（原文在 p139 解答里给出）：
> $\|Ax_{ch}-b\|_\infty \ge \frac{1}{\sqrt{m}}\|Ax_{ch}-b\|_2 \ge \frac{1}{\sqrt{m}}\|Ax_{ls}-b\|_2 \ge \frac{1}{\sqrt{m}}\|Ax_{ls}-b\|_\infty$，
> 中间那个 $\ge$ 用 $x_{ls}$ 的 $\ell_2$ 最优性（$\|Ax_{ls}-b\|_2\le\|Ax_{ch}-b\|_2$）✓，
> 两端各用一个范数比较 ✓。三处不等号方向一致，整体成立。**$\sqrt{m}$ 是最优常数**：取 $A=I$、$b=(1,\dots,1)^{T}$ 时
> $x_{ls}=b$ 使左端为 $0$；取 $b$ 全等则两者相等，说明此界的紧性依赖于 $b$ 的结构，$m$ 维下 $\sqrt{m}$ 可达
> （$A$ 取一列、$b$ 取「一个 $+1$、其余 $-1/(m-1)$」型残差可逼近）。

**（承上页题干）**

**(b)** 在例 5.6（第 254 页）中我们推导了一般范数逼近问题的对偶。把那些结果用到 $\ell_\infty$-范数（及其对偶范数，
即 $\ell_1$-范数）上，可以写出 Chebyshev 逼近问题的如下对偶：

```math
\begin{aligned}
\text{maximize}\quad & b^{T}\nu\\
\text{subject to}\quad & \|\nu\|_1 \le 1\\
& A^{T}\nu = 0 .
\end{aligned}
```

（即 (5.104)。）任何可行的 $\nu$ 都对应 $\|Ax_{ch}-b\|_\infty$ 的一个下界 $b^{T}\nu$。

记 least-squares 残差为 $r_{ls}=b-Ax_{ls}$。假定 $r_{ls}\ne0$，证明

```math
\hat{\nu} = -r_{ls}/\|r_{ls}\|_1,\qquad \tilde{\nu} = r_{ls}/\|r_{ls}\|_1
```

在 (5.104) 中都可行。由对偶性，$b^{T}\hat{\nu}$ 与 $b^{T}\tilde{\nu}$ 都是 $\|Ax_{ch}-b\|_\infty$ 的下界。
哪一个界更好？这些界与 (a) 部分推出的界相比如何？

**解答**。

**(a)** 简单的推导给出

```math
\|Ax_{cheb}-b\|_\infty \ge \frac{1}{\sqrt{m}}\|Ax_{cheb}-b\|_2 \ge \frac{1}{\sqrt{m}}\|Ax_{ls}-b\|_2 \ge \frac{1}{\sqrt{m}}\|Ax_{ls}-b\|_\infty .
```

**(b)** 由表达式 $x_{ls}=(A^{T}A)^{-1}A^{T}b$，我们注意到

```math
A^{T}r_{ls} = A^{T}\left(b-A(A^{T}A)^{-1}b\right) = A^{T}b-A^{T}b = 0 .
```

† **5.6(b) 括号里少了一个 $A^{T}$：应为 $A(A^{T}A)^{-1}A^{T}b$。** 原文写 $A(A^{T}A)^{-1}b$。

**正确式子**：

```math
A^{T}r_{ls} = A^{T}\left(b-A(A^{T}A)^{-1}A^{T}b\right) = A^{T}b-A^{T}A(A^{T}A)^{-1}A^{T}b = A^{T}b-A^{T}b = 0 .
```

**数值反例（量纲即证）**：$A\in\mathbf{R}^{m\times n}$。则 $A^{T}A$ 是 $n\times n$，其逆是 $n\times n$；于是
$A(A^{T}A)^{-1}$ 是 $m\times n$，而 $b$ 是 $m\times 1$——**$m\times n$ 矩阵乘 $m\times 1$ 向量根本不合法**（除 $m=n$ 的方阵特例）。
正确式子 $A(A^{T}A)^{-1}A^{T}$ 是 $m\times m$（投影矩阵），乘 $b$ 得到 $m\times1$ ✓。
最省事的反例取 $m=2$、$n=1$：$A=(1,2)^{T}$、$b=(1,1)^{T}$。那么 $x_{ls}=3/5$，
$Ax_{ls}=(0.6,1.2)^{T}$，$r_{ls}=(0.4,-0.2)^{T}$，$A^{T}r_{ls}=0.4-0.4=0$ ✓；
而按原文的 $A(A^{T}A)^{-1}b$ 写出的是 $(1,2)^{T}\cdot\frac{1}{5}\cdot$（$2\times1$ 向量）——无法定义。

**为什么会写错**：$x_{ls}$ 的闭式 $(A^{T}A)^{-1}A^{T}b$ 里，最后那个 $A^{T}b$ 是一个整体（$n\times1$）；
作者把它代进 $Ax$ 时，写成 $A\Big[(A^{T}A)^{-1}A^{T}b\Big]$ 的过程中把内层的 $A^{T}$ 丢在了括号外——
**括号配对与矩阵因子同时出错，二者互相掩盖**（丢掉 $A^{T}$ 后视觉上更「对称」，$A(A^{T}A)^{-1}b$ 看着像
「$A$ 一次、$(A^{T}A)^{-1}$ 一次、$b$ 一次」）。检查动作：算一遍**每个中间量的形状**，这是线性代数里唯一
不依赖记忆的校验手段。

因此 $A^{T}\hat{\nu}=0$ 与 $A^{T}\tilde{\nu}=0$。显然我们还有 $\|\hat{\nu}\|_1=1$ 与 $\|\tilde{\nu}\|_1=1$，
所以 $\hat{\nu}$ 与 $\tilde{\nu}$ 都是对偶可行的。

我们可以把 $\hat{\nu}$ 处的对偶目标值写成

```math
b^{T}\hat{\nu} = \frac{-b^{T}r_{ls}}{\|r_{ls}\|_1} = \frac{(Ax_{ls}-b)^{T}r_{ls}}{\|r_{ls}\|_1} = -\frac{\|r_{ls}\|_2^{2}}{\|r_{ls}\|_1}
```

并且类似地

```math
b^{T}\tilde{\nu} = \frac{\|r_{ls}\|_2^{2}}{\|r_{ls}\|_1} .
```

因此 $\tilde{\nu}$ 给出的界比 $\hat{\nu}$ 更好。

> **（此处原解答正确，值得逐符号固定下来——这是本块最容易误判成错的地方）** 关键恒等式是
> $b=Ax_{ls}+r_{ls}$（注意**加号**），于是
> $b^{T}r_{ls}=(Ax_{ls})^{T}r_{ls}+\|r_{ls}\|_2^{2}=0+\|r_{ls}\|_2^{2}$，
> 因为 $(Ax_{ls})^{T}r_{ls}=x_{ls}^{T}(A^{T}r_{ls})=0$。所以 $b^{T}r_{ls}=+\|r_{ls}\|_2^{2} \gt 0$。
> **上游警告的 `⪯` 方向陷阱在这里以「$b=Ax+r$ 还是 $b=Ax-r$」的形式出现**：若误把 $b$ 写成 $Ax_{ls}-r_{ls}$，
> 会得到 $b^{T}r_{ls}=-\|r_{ls}\|_2^{2}$，两个界全部反号，结论「$\tilde\nu$ 更好」也随之翻转成「$\hat\nu$ 更好」。
> 我用 $A=(1,2)^{T}$、$b=(1,1)^{T}$ 实测：$r_{ls}=(0.4,-0.2)$、$\|r_{ls}\|_1=0.6$、$\|r_{ls}\|_2^{2}=0.2$，
> 于是 $b^{T}\hat\nu=-1/3$、$b^{T}\tilde\nu=+1/3$，而 Chebyshev 真值（暴力搜索）$p^{\star}=1/3$。
> 正号那个恰好取到 $p^{\star}$（强对偶 + 该 $\nu$ 就是最优对偶解），负号那个毫无用处——**界必须是正数才有意义**。
> 这也给出一条实操判据：**下界若为负，先查 $A^{T}\nu=0$ 与 $b$ 的符号约定，别急着怀疑不等式**。

最后，要说明所得的下界比 (a) 部分的界更好，我们必须验证

```math
\frac{\|r_{ls}\|_2^{2}}{\|r_{ls}\|_1} \ge \frac{1}{\sqrt{m}}\|r_{ls}\|_\infty .
```

这可由以下不等式推出：

```math
\|x\|_1 \le \sqrt{m}\,\|x\|_2,\qquad \|x\|_\infty \le \|x\|_2,
```

它们对一般的 $x\in\mathbf{R}^{m}$ 成立。

> **（该验证的完整链条，原解答只写了要用哪两条不等式）** 由 $\|r\|_1 \le \sqrt m\|r\|_2$ 得
> $\frac{\|r\|_2^2}{\|r\|_1} \ge \frac{\|r\|_2^2}{\sqrt m\|r\|_2}=\frac{1}{\sqrt m}\|r\|_2$，
> 再由 $\|r\|_\infty \le \|r\|_2$ 得右边的下界 $\ge \frac{1}{\sqrt m}\|r\|_\infty$ ✓。
> 也就是说**对偶界恒不弱于 (a) 的界，且等号条件要求 $\|r\|_1=\sqrt m\|r\|_2$ 与 $\|r\|_\infty=\|r\|_2$ 同时成立**
> （只在 $r$ 的 $m$ 个分量绝对值全相等时可能）。$m=2$、$r=(0.4,-0.2)$ 时：
> 对偶界 $1/3\approx0.3333$，(a) 的界 $0.4/\sqrt2\approx0.2828$——严格更好 ✓，与理论一致。

<span style="color:#1e8449;">**[译注]** 这题是整章「对偶即证书」思想的**最小可算实例**：你没有 Chebyshev 解，手里只有 least-squares 的残差，却能给出一个**可验证的**最优值下界 $1/3$——而且这个下界恰好等于真值，等于说残差向量本身就是最优性证书（certificate）。这正是 §5.5.2 的最优性条件在数值上的形态：$\nu^{\star}=\pm r/\|r\|_1$ 且 $A^{T}\nu^{\star}=0$ 就是在宣告「$x_{ch}$ 已经最优，别再找了」。

**这一族技巧的通用性**：任何 $\min_x\|Ax-b\|$（$\|\cdot\|$ 是任意范数）都有对偶
$\max\{b^{T}\nu \mid A^{T}\nu=0,\ \|\nu\|_{*}\le1\}$，于是**任何**「$A^{T}\nu=0$、对偶范数 $\le1$」的向量都是证书。
把 $\nu$ 归一化的成本是 $O(m)$，而求 $x_{ch}$ 是 LP（$O(m^{3}\log)$——这是「造证书 $O(m)$ 对求解 $O(m^3)$」的差距。

**消失测试**：没有这个对偶，你就**无法判断**一个近似的 $x$ 离最优有多远——$\ell_\infty$ 问题的最优值没有闭式，
而残差 $\|Ax-b\|_\infty$ 本身给不出任何最优性信息（它对任意 $x$ 都能算，但不与 $p^{\star}$ 比较）。
有了它，任何 $x$ 都给出夹逼：$b^{T}\tilde\nu \le p^{\star} \le \|Ax-b\|_\infty$，两侧之差就是 suboptimality 的**可证**上界。
本例中取 $x=x_{ls}$：下界 $1/3$、上界 $\|r_{ls}\|_\infty=0.4$，于是「$x_{ls}$ 至多差 $20\%$」这一句是被证明的，不是猜的。

### Exercise 5.7：Piecewise-linear 最小化 —— 三种等价建模各自的对偶

> **中文话题摘要**：$\min\max_i(a_i^{T}x+b_i)$ 可以按辅助变量 $y$ 的对偶做（得到 $\lambda$ 在单纯形上），
> 也可以写成 LP 再做 LP 对偶，两条路给出同一个问题；用 log-sum-exp 光滑化则额外引入 $\le\log m$ 的空隙。

**题干（译）**。我们考虑凸 piecewise-linear minimization（分段线性最小化）问题

```math
\text{minimize}\quad \max_{i=1,\dots,m}(a_i^{T}x+b_i),
```

（即 (5.105)。）变量为 $x\in\mathbf{R}^{n}$。

**(a)** 基于等价问题

```math
\begin{aligned}
\text{minimize}\quad & \max_{i=1,\dots,m}y_i\\
\text{subject to}\quad & a_i^{T}x+b_i = y_i,\quad i = 1,\dots,m,
\end{aligned}
```

的 Lagrange dual，推导出它的一个对偶问题，变量为 $x\in\mathbf{R}^{n}$、$y\in\mathbf{R}^{m}$。

**(b)** 把分段线性最小化问题 (5.105) 表述成一个 LP，再求该 LP 的对偶。把 LP 对偶与 (a) 中得到的对偶联系起来。

**(c)** 假设我们用光滑函数

```math
f_0(x) = \log\left(\sum_{i=1}^{m}\exp(a_i^{T}x+b_i)\right)
```

逼近 (5.105) 中的目标函数，并求解无约束的 geometric program

```math
\text{minimize}\quad \log\left(\sum_{i=1}^{m}\exp(a_i^{T}x+b_i)\right).
```

（即 (5.106)。）这个问题的一个对偶由 (5.62) 给出。设 $p^{\star}_{pwl}$ 与 $p^{\star}_{gp}$ 分别为 (5.105) 与 (5.106)
的最优值。证明

```math
0 \le p^{\star}_{gp}-p^{\star}_{pwl} \le \log m .
```

**(d)** 对 $p^{\star}_{pwl}$ 与

```math
\text{minimize}\quad \frac{1}{\gamma}\log\left(\sum_{i=1}^{m}\exp\left(\gamma(a_i^{T}x+b_i)\right)\right)
```

的最优值之差，推导出类似的界，其中 $\gamma \gt 0$ 是参数。当我们增大 $\gamma$ 时会发生什么？

**解答**。

**(a)** 对偶函数为

```math
g(\lambda) = \inf_{x,y}\left(\max_{i=1,\dots,m}y_i+\sum_{i=1}^{m}\lambda_i(a_i^{T}x+b_i-y_i)\right).
```

关于 $x$ 的下确界只有在 $\sum_i\lambda_ia_i=0$ 时才是有限的。要在 $y$ 上最小化，注意

```math
\inf_{y}\left(\max_{i}y_i-\lambda^{T}y\right) =
\begin{cases}
0, & \lambda \succeq 0,\ \mathbf{1}^{T}\lambda = 1\\
-\infty, & \text{其他情形}.
\end{cases}
```

要证明这一点，先注意若 $\lambda \succeq 0$、$\mathbf{1}^{T}\lambda=1$，则

```math
\lambda^{T}y = \sum_{j}\lambda_jy_j \le \sum_{j}\lambda_j\max_{i}y_i = \max_{i}y_i,
```

在 $y=0$ 时取等，所以此时

```math
\inf_{y}\left(\max_{i}y_i-\lambda^{T}y\right) = 0 .
```

若 $\lambda \not\succeq 0$，比如说 $\lambda_j \lt 0$，那么取 $y_i=0$（$i\ne j$）、$y_j=-t$（$t \ge 0$），
并让 $t$ 趋于无穷，就得到

```math
\max_{i}y_i-\lambda^{T}y = 0+t\lambda_k \to -\infty .
```

† **5.7(a) 的下标写成 $k$，应为 $j$。** 前一句刚说「say $\lambda_j \lt 0$」，此处却出现 $\lambda_k$——
$k$ 在本段内从未被绑定（它在本章别处是约束指标，这里也不是）。

**正确式子**（代入 $y_j=-t$、其余 $y_i=0$）：

```math
\max_{i}y_i-\lambda^{T}y = \max(0,-t)-\lambda_j(-t) = 0+t\lambda_j \to -\infty\quad(t\to\infty),
```

因为 $\lambda_j \lt 0$ 而 $t\to+\infty$，故 $t\lambda_j\to-\infty$ ✓。

**数值反例**：取 $m=2$、$\lambda=(-1,\,2)^{T}$（于是 $\lambda_j=\lambda_1=-1 \lt 0$、$j=1$）。
取 $y=(0,0)$：$\max_iy_i-\lambda^{T}y=0$。取 $y=(-t,0)$，$t=100$：
$\max(-100,0)=0$，$-\lambda^{T}y=-(-1\cdot(-100)+0)=-(100)=-100$，合计 $0-100=-100$。
按原文若把下标换成 $k=2$（$\lambda_2=2 \gt 0$），会写成 $0+t\cdot2=+200\to+\infty$——方向与真值相反，
从而把「$\lambda\not\succeq0$ 时 $g=-\infty$」错判成「$g=+\infty$」，对偶问题直接发散。

**为什么会写错**：这一段里 $i,j,k$ 三个指标同时在场（$i$ 是 max 的指标，$j$ 是被选出的负分量，$k$ 是本章
约束指标的习惯写法），作者在写 $t\lambda_{\cdot}$ 时按「随手取一个下标」的习惯填了 $k$。
这是本块第四例同型错误（另三例：4.59(c)、4.60、4.64）。**规避办法**：在纸上先写「$j$ = 唯一违反 $\lambda\succeq0$ 的分量」，
再把 $j$ 圈起来，此后每处下标都在圈内取值。

**本页至此结束；5.7(a) 的 dual problem 主体（$\text{maximize}\ -b^{T}\lambda$ s.t. $\sum_i\lambda_ia_i=0$、
$\lambda \succeq 0$、$\mathbf{1}^{T}\lambda=1$）与 (b)(c)(d) 从 p141 续起。**
