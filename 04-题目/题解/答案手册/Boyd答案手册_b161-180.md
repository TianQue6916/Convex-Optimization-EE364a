### Exercise 5.26 — QCQP 用两个圆盘卡到单点，KKT 却无解

> **[原文]** Consider the QCQP: minimize $x_1^2+x_2^2$ subject to $(x_1-1)^2+(x_2-1)^2\le 1$, $(x_1-1)^2+(x_2+1)^2\le 1$, with variable $x\in\mathbf{R}^2$. (a) Sketch the feasible set and level sets of the objective. Find the optimal point $x^\star$ and optimal value $p^\star$. (b) Give the KKT conditions. Do there exist Lagrange multipliers $\lambda^\star_1$ and $\lambda^\star_2$ that prove that $x^\star$ is optimal? (c) Derive and solve the Lagrange dual problem. Does strong duality hold?
> **[中文话题]** 二次约束二次规划（quadratic program with quadratic constraints，QCQP）；可行集退化为单点，用来演示「强对偶成立但 KKT 条件无解」。

**Solution.**

**(a)** 图给的是可行集（两个阴影圆盘的交）以及目标函数若干条 contour line（等值线）。可行集里**只有一个点** $(1,0)$，所以它就是原问题的最优点，且

```math
p^\star = 1^2 + 0^2 = 1.
```

（此处原书配图；本 PDF 无插图，等式约束的处理见下面的译注。）

**(b)** KKT 条件是

```math
\begin{aligned}
&(x_1-1)^2+(x_2-1)^2\le 1,\quad (x_1-1)^2+(x_2+1)^2\le 1,\\
&\lambda_1\ge 0,\quad \lambda_2\ge 0,\\
&2x_1+2\lambda_1(x_1-1)+2\lambda_2(x_1-1)=0,\\
&2x_2+2\lambda_1(x_2-1)+2\lambda_2(x_2+1)=0,\\
&\lambda_1\bigl((x_1-1)^2+(x_2-1)^2-1\bigr)=\lambda_2\bigl((x_1-1)^2+(x_2+1)^2-1\bigr)=0.
\end{aligned}
```

在 $x=(1,0)$ 处这些条件退化成

```math
\lambda_1\ge 0,\quad \lambda_2\ge 0,\quad 2=0,\quad -2\lambda_1+2\lambda_2=0,
```

第三个方程是 $2=0$，所以**无解**。

**(c)** Lagrange dual function 由

```math
g(\lambda_1,\lambda_2)=\inf_{x_1,x_2} L(x_1,x_2,\lambda_1,\lambda_2)
```

给出，其中

```math
\begin{aligned}
L(x_1,x_2,\lambda_1,\lambda_2)
&=x_1^2+x_2^2+\lambda_1\bigl((x_1-1)^2+(x_2-1)^2-1\bigr)+\lambda_2\bigl((x_1-1)^2+(x_2+1)^2-1\bigr)\\
&=(1+\lambda_1+\lambda_2)x_1^2+(1+\lambda_1+\lambda_2)x_2^2-2(\lambda_1+\lambda_2)x_1-2(\lambda_1-\lambda_2)x_2+\lambda_1+\lambda_2.
\end{aligned}
```

<!-- ===== p162 ===== -->

$L$ 在

```math
x_1=\frac{\lambda_1+\lambda_2}{1+\lambda_1+\lambda_2},\qquad
x_2=\frac{\lambda_1-\lambda_2}{1+\lambda_1+\lambda_2}
```

处取到最小值，代回得到

```math
g(\lambda_1,\lambda_2)=
\begin{cases}
-\dfrac{(\lambda_1+\lambda_2)^2+(\lambda_1-\lambda_2)^2}{1+\lambda_1+\lambda_2}+\lambda_1+\lambda_2, & 1+\lambda_1+\lambda_2\ge 0,\\
-\infty, & \text{otherwise},
\end{cases}
```

这里约定 $a/0=0$（当 $a=0$）、$a/0=-\infty$（当 $a\lt 0$）。由于 $\lambda_1,\lambda_2\ge 0$ 时恒有 $1+\lambda_1+\lambda_2\ge 1\gt 0$，第二种分支在本题实际不会触发。于是 Lagrange dual problem（拉格朗日对偶问题）是

```math
\text{maximize}\quad \lambda_1+\lambda_2-\frac{(\lambda_1+\lambda_2)^2+(\lambda_1-\lambda_2)^2}{1+\lambda_1+\lambda_2}\qquad \text{subject to}\quad \lambda_1,\lambda_2\ge 0
```

（以上是改正后的形式；原文这里有一处符号错，见 †1。）由于 $g$ 对称，最优点（若存在）出现在 $\lambda_1=\lambda_2$。此时 dual function 化简为

```math
g(\lambda_1,\lambda_1)=\frac{2\lambda_1}{2\lambda_1+1}.
```

可见 $\lambda_1\to\infty$ 时 $g(\lambda_1,\lambda_2)\to 1$。我们有 $d^\star=p^\star=1$，但**对偶最优值不 attain**（dual optimum is not attained）。

回顾一下：KKT 条件只在三件事同时成立时才等价于最优性——(1) strong duality 成立；(2) 原问题最优值达到；(3) 对偶最优值达到。本例 KKT 无解，恰恰因为第 (3) 条失败。

<span style="color:#1e8449;">**[译注]** †1 掏出的是本块最有教学价值的一处符号错：$g$ 的分子项。

**错在哪**。原式写作 $-\bigl[(\lambda_1+\lambda_2)^2-(...)\bigr]$ 这种形态，即两个平方项之间是**异号**：

```math
g_{\text{原文}}=\frac{-(\lambda_1+\lambda_2)^2+(\lambda_1-\lambda_2)^2}{1+\lambda_1+\lambda_2}+\lambda_1+\lambda_2 .
```

正确式子是**同号**：

```math
g_{\text{正确}}=\frac{-\bigl[(\lambda_1+\lambda_2)^2+(\lambda_1-\lambda_2)^2\bigr]}{1+\lambda_1+\lambda_2}+\lambda_1+\lambda_2 .
```

**数值反例（一行手算）**。取 $\lambda=(1,0)$，即 $\lambda_1+\lambda_2=1$、$\lambda_1-\lambda_2=1$：

- 正确式：$\dfrac{-(1+1)}{2}+1=-\dfrac{2}{2}+1=0$。
- 原文式：$\dfrac{-1+1}{2}+1=1$。

哪一个对？直接代 $L$：把 $\lambda=(1,0)$ 与驻点 $x_1=x_2=\tfrac12$ 代入，$L=\tfrac14+\tfrac14+\bigl(\tfrac14+\tfrac14-1\bigr)=\tfrac12-\tfrac12=0$。所以 $g(1,0)=0$，原文式给 $1$，**差 1**。

**为什么会写错**。作者把配方结果记成了平方差。正确的配方是「二次项系数 $1+\lambda_1+\lambda_2$ 分别吃掉 $x_1$、$x_2$ 的一次项」，两个完全平方的**和**：

```math
(1+a)\Bigl(x_1-\frac{a}{1+a}\Bigr)^2+(1+a)\Bigl(x_2-\frac{\lambda_1-\lambda_2}{1+a}\Bigr)^2
```

其中 $a=\lambda_1+\lambda_2$。 把两个平方的和转写成 $-\dfrac{a^2+(\lambda_1-\lambda_2)^2}{1+a}$ 时，「两个平方和」被误写成「平方差」——这是第 ② 类错型（$+/-$ 翻转）的典型：符号只在一个位置出错，但因为 $\lambda_1=\lambda_2$ 时该项恰为 $0$，**它在本例的自检点（$\lambda_1=\lambda_2$ 化简那一步）完全隐形**，作者自己的 $g(\lambda_1,\lambda_1)=\dfrac{2\lambda_1}{2\lambda_1+1}$ 是对的，掩盖了错误。

**落点与消失测试**。这条错误不改变结论（$d^\star=1$ 仍成立），但它破坏 $g\le p^\star$ 的验证——没有一个可手算的点能验出 $g\le 1$ 是紧的。Boyd §5.5.3 与 exercise 5.26 的官方解答用的是同号版本；若不改，任何按本手册复算的学生都会在 $\lambda=(1,0)$ 处与自己手算的 $0$ 打架。判据侧：正确版本在 $\lambda\to\infty$ 时给 $1$，原文版本给 $-\infty$，**极限行为直接判死**。</span>

<span style="color:#1e8449;">**[译注]** 「可行集只有一个点」这句话值得拆开验：把两个约束**相加**而非分别处理，

```math
2(x_1-1)^2+(x_2-1)^2+(x_2+1)^2\le 2
\;\Longrightarrow\;
2(x_1-1)^2+2x_2^2+2\le 2
\;\Longrightarrow\;
(x_1-1)^2+x_2^2\le 0,
```

右边是两个平方和 $\le 0$，只能都取 $0$，于是 $x_1=1,x_2=0$ —— 唯一可行点，且它同时落在两个圆的边界上（两个约束都 active）。这一步没有任何图读数，纯代数，所以本题**不依赖插图**。

**消失测试**：没有这个「相加配方」的技巧，你就得靠眼睛看两个圆盘切于一点，而本 PDF 无图（`get_images` 逐页为 0）——读图不可用，只能靠代数。这恰好是 Slater 条件的教科书反例：**两约束都是非严格的（都是等式成立）且不可行集有内点**，故 Slater 失效，KKT 因此可以无解。

**落点**：Boyd §5.5.3（KKT 的三个前提）；本例的对称版本见 exercise 5.26 本身；对偶侧的处理见 §5.5.2 的「dual optimum not attained」讨论与 §5.6 的 perturbation 视角。</span>

### Exercise 5.27 — 等式约束最小二乘：把 dual 的常数项算清楚

> **[原文]** Equality constrained least-squares. Consider minimize $\|Ax-b\|_2^2$ subject to $Gx=h$, where $A\in\mathbf{R}^{m\times n}$ with $\mathrm{rank}\,A=n$, and $G\in\mathbf{R}^{p\times n}$ with $\mathrm{rank}\,G=p$. Give the KKT conditions, and derive expressions for the primal solution $x^\star$ and the dual solution $\nu^\star$.
> **[中文话题]** 等式约束最小二乘（equality constrained least-squares）的 KKT 与闭式解；重点是 dual function 里那个容易被丢掉的常数项。

**Solution.**

**(a)** Lagrangian 为

```math
\begin{aligned}
L(x,\nu)&=\|Ax-b\|_2^2+\nu^T(Gx-h)\\
&=x^TA^TAx+\bigl(G^T\nu-2A^Tb\bigr)^Tx+b^Tb-\nu^Th,
\end{aligned}
```

其最小点在 $x=-\tfrac12(A^TA)^{-1}\bigl(G^T\nu-2A^Tb\bigr)$。其 dual function 为

```math
g(\nu)=-\frac14\bigl(G^T\nu-2A^Tb\bigr)^T(A^TA)^{-1}\bigl(G^T\nu-2A^Tb\bigr)+b^Tb-\nu^Th .
```

（原文漏了 $+b^Tb$，见 †2。）

**(b)** 最优性条件是

```math
2A^T(Ax^\star-b)+G^T\nu^\star=0,\qquad Gx^\star=h .
```

**(c)** 由第一式，

```math
x^\star=(A^TA)^{-1}\bigl(A^Tb-\tfrac12G^T\nu^\star\bigr).
```

把 $x^\star$ 的表达式代入第二式得

```math
G(A^TA)^{-1}A^Tb-\tfrac12G(A^TA)^{-1}G^T\nu^\star=h,
```

即

```math
\nu^\star=-2\bigl(G(A^TA)^{-1}G^T\bigr)^{-1}\bigl(h-G(A^TA)^{-1}A^Tb\bigr).
```

再代回第一式即得 $x^\star$ 的解析表达式。

<span style="color:#1e8449;">**[译注]** †2 被丢掉的常数项 $b^Tb$ 不是排版洁癖——它**会改 dual 的最优值**，从而让 strong duality 看起来失效。

**错在哪**。原式只写了二次型那项与 $-\nu^Th$：

```math
g_{\text{原文}}(\nu)=-\tfrac14(\cdots)^T(A^TA)^{-1}(\cdots)-\nu^Th .
```

正确式必须带上展开时产生的常数：

```math
g_{\text{正确}}(\nu)=-\tfrac14(\cdots)^T(A^TA)^{-1}(\cdots)+b^Tb-\nu^Th .
```

**数值反例（一维也算得动）**。取 $A=I_2$、$b=(1,0)^T$、$G=[1\ \ 0]$、$h=0$。原问题：$\min\|x-b\|_2^2$ 且 $x_1=0$，解是 $x^\star=(0,0)$，于是

```math
p^\star=\|(0,0)-(1,0)\|_2^2=1 .
```

对偶侧：$L=x_1^2-2x_1+1+x_2^2+\nu x_1$，对 $x_2$ 最小取 $x_2=0$，对 $x_1$ 最小取 $x_1=(2-\nu)/2$，代回

```math
g(\nu)=1-\frac{(2-\nu)^2}{4}.
```

在 $\nu=2$ 处 $g=1=p^\star$，strong duality 成立。而原文式给的是 $g_{\text{原文}}(\nu)=-\dfrac{(2-\nu)^2}{4}$，最大值 $\nu=2$ 处等于 $0$，**与 $p^\star=1$ 差整整 1**。

**为什么会写错**。展开 $\|Ax-b\|^2=x^TA^TAx-2b^TAx+b^Tb$ 时，作者把 $b^Tb$ 当成「不影响 minimizer 的常数」直接划掉了。这一步在**求 $x^\star$** 时合法（常数不影响驻点），但在**求 dual function 的值**时非法：$g$ 是 $L$ 的最小**值**，不是一个 minimizer，常数全额进入。

**消失测试与判据**。$b^Tb$ 的量纲就是目标函数的量纲；丢掉它，$g(\nu^\star)$ 与 $p^\star$ 就不再相等，于是「strong duality 是否成立」这个判断题会被误判为否。用形状与指数配平也能一秒定位：$\|Ax-b\|^2$ 展开三项，$x^TA^TAx$ 与 $-2b^TAx$ 都在，唯独第三项缺席——**三项变两项，是矩阵展开的缺口，不可能是真实的化简**。落点：Boyd §5.2.1 的 dual function 定义；同类缺口见 exercise 5.13 的 LP dual 推导（那里常数是 $-b^T\lambda$，作者没漏，可对比）。</span>

### Exercise 5.28 — 不给 LP solver，只给一张「最优性证书」

> **[原文]** Prove (without using any linear programming code) that the optimal solution of the LP is unique, and given by $x^\star=(1,1,1,1)$. Minimize $47x_1+93x_2+17x_3-93x_4$ subject to $Ax\preceq b$ with the data below.
> **[中文话题]** 用对偶可行点 + complementary slackness 构造 certificate（证书），证明一个 LP 的最优解唯一——这是「验证比求解便宜」的原型。

题给数据（按 `sort=True` 逐字核对，行内用 `|` 分隔 $b$）：

```math
A=\begin{bmatrix}-1&-6&1&3\\-1&-2&7&1\\0&3&-10&-1\\-6&-11&-2&12\\1&6&-1&-3\end{bmatrix},\qquad
b=\begin{bmatrix}-3\\5\\-8\\-7\\4\end{bmatrix},\qquad
c=\begin{bmatrix}47\\93\\17\\-93\end{bmatrix}.
```

**Solution.**

显然 $x^\star=(1,1,1,1)$ 可行（前四条约束以等号成立）。点 $z^\star=(3,2,2,7,0)$ 是 $x=(1,1,1,1)$ 的一个最优性证书（certificate of optimality）：

- $z^\star$ 对偶可行：$z^\star\succeq 0$ 且 $A^Tz^\star+c=0$。
- $z^\star$ 满足 complementary slackness（互补松弛）：

```math
z^\star_i\bigl(a_i^Tx-b_i\bigr)=0,\qquad i=1,\dots,m,
```

因为 $Ax-b$ 的前四个分量与 $z^\star$ 的最后一个分量都是零。

<!-- ===== p164 ===== -->

<span style="color:#1e8449;">**[译注]** 这道题值得逐分量验一遍，因为它是本块**唯一一处「数值全对、且可以用两种独立方式交叉验证」**的题，用它当基准能校准你对整章答案的信任。

**先把 $z^\star$ 塞进 $A^Tz^\star+c=0$**。逐列（$A$ 的四列）算：

```math
\begin{aligned}
\text{列 1}:&\ -1\cdot 3-1\cdot 2+0\cdot 2-6\cdot 7+1\cdot 0=-47,\\
\text{列 2}:&\ -6\cdot 3-2\cdot 2+3\cdot 2-11\cdot 7+6\cdot 0=-93,\\
\text{列 3}:&\ 1\cdot 3+7\cdot 2-10\cdot 2-2\cdot 7-1\cdot 0=-17,\\
\text{列 4}:&\ 3\cdot 3+1\cdot 2-1\cdot 2+12\cdot 7-3\cdot 0=93 .
\end{aligned}
```

四个数恰好是 $-c$，所以 $A^Tz^\star+c=0$ ✓。**第二重验证**：$p^\star=c^Tx=47+93+17-93=64$，而对偶目标 $-b^Tz^\star=-(-9+10-16-49)=64$ ✓ 两路对上。

**互补松弛为什么要看第 5 行**。$Ax-b$ 在 $x=\mathbf 1$ 处的值是 $(0,0,0,0,-1)$：前四行取等（约束 active），第五行严格（$3\lt 4$，slack 为 1）。所以 $z_5$ 必须为 $0$——答案确实给了 $0$。反过来，$z_1,z_2,z_3,z_4\gt 0$ 迫使前四行 active。这就是「唯一性」的来源：前四个等式把 $\mathbf R^4$ 中的点钉死了，**四个线性无关的等式，四个未知数**。

**消失测试**：没有 certificate 这套机制，你就得相信某个 solver 的输出；而一旦有证书，验证成本是 $O(mn)$ 的一次矩阵-向量乘，比重解一次 LP 便宜一个数量级。这就是 Boyd §5.5.2 那句 "certificate of optimality" 的实操含义，也是 5.33、5.34 两题反复用的套路。

**落点**：Boyd §5.5.2（LP 的最优性证书）、§5.8 Farkas 变体；对偶目标与原始目标相等的这一步是 exercise 5.1–5.4 的同一个恒等式。判据侧：任何声称「$x$ 最优」的答案，若给不出对偶可行点，在本题这样的构造题里算不合格。</span>

### Exercise 5.29 — 非凸问题为什么会有 strong duality，以及一个成体系的符号错

> **[原文]** The problem minimize $-3x_1^2+x_2^2+2x_3^2+2(x_1+x_2+x_3)$ subject to $x_1^2+x_2^2+x_3^2=1$ is a special case of (5.32), so strong duality holds even though the problem is not convex. Derive the KKT conditions. Find all solutions $x,\nu$ that satisfy the KKT conditions. Which pair corresponds to the optimum?
> **[中文话题]** 「球约束 + 二次目标」型非凸问题的 strong duality；KKT 有 4 组解时的筛选。

（题面的 `−3x2 + x2 + 2x2` 是上标退化，还原为 $-3x_1^2+x_2^2+2x_3^2$。）

**Solution.**

**(a)** KKT 条件是

```math
x_1^2+x_2^2+x_3^2=1,\quad (-3+\nu)x_1+1=0,\quad (1+\nu)x_2+1=0,\quad (2+\nu)x_3+1=0 .
```

**(b)** 第一个观察是：KKT 条件蕴含 $\nu\ne 2$、$\nu\ne -1$、$\nu\ne 3$。于是可以消掉 $x$，把 KKT 条件化成一个关于 $\nu$ 的非线性方程：

```math
\frac{1}{(-3+\nu)^2}+\frac{1}{(1+\nu)^2}+\frac{1}{(2+\nu)^2}=1 .
```

左端在图上画出（原书配图：$\nu\in[-8,8]$ 上四条竖直渐近线的四支曲线；本 PDF 无插图）。

有四个解：

```math
\nu=-3.15,\qquad \nu=0.22,\qquad \nu=1.89,\qquad \nu=4.04,
```

分别对应

```math
\begin{aligned}
x&=(0.16,\ 0.47,\ -0.87), & x&=(0.36,\ -0.82,\ -0.45),\\
x&=(0.90,\ -0.35,\ -0.26), & x&=(-0.97,\ -0.20,\ -0.17).
\end{aligned}
```

（原文这四个 $x$ 的第三个分量符号全错，见 †3。）

**(c)** $\nu^\star$ 是四个值里最大的那个：$\nu^\star=4.0352$。这有几条路子看出来。最简单的路子是比四个解的**目标值**：

```math
f_0(x)=4.65,\qquad f_0(x)=-1.13,\qquad f_0(x)=-1.59,\qquad f_0(x)=-5.37 .
```

也可以把四个候选 $\nu$ 代进 dual objective 比大小。最后一招是注意到必须满足

```math
\nabla^2 f_0(x^\star)+\nu^\star\nabla^2 f_1(x^\star)\succeq 0,
```

因为 $x^\star$ 是 $L(x,\nu^\star)$ 的最小点。换句话说

```math
\begin{bmatrix}-3&0&0\\0&1&0\\0&0&2\end{bmatrix}+\nu^\star\begin{bmatrix}1&0&0\\0&1&0\\0&0&1\end{bmatrix}\succeq 0,
```

因此 $\nu^\star\ge 3$。


<span style="color:#1e8449;">**[译注]** †3 是本块**传播最广**的一处错：一个符号错了，4 个 $x$ 和 4 个 $f_0$ 全部跟着错。

**错在哪**。KKT 第三式 $(2+\nu)x_3+1=0$ 唯一地给出

```math
x_3=\frac{-1}{2+\nu},
```

$2+\nu$ 在 $\nu\gt -2$ 时为正，所以三支正的 $\nu$ 对应的 $x_3$ **必为负**。原文的四个 $x$ 里，第三分量分别写成 $-0.87$、$+0.45$、$+0.26$、$+0.17$，其中后三个符号反了；第一个 $(-0.87)$ 恰好该是 $+0.87$ 也反了。也就是说**四个全反，方向一致**——这不是随机手误，是答案里把 $x_3=+1/(2+\nu)$ 当成了通式。

**正确式子与数值**。$\nu^\star=4.0352$ 时

```math
x^\star=\Bigl(\frac{-1}{4.0352-3},\ \frac{-1}{5.0352},\ \frac{-1}{6.0352}\Bigr)=(-0.966,\ -0.199,\ -0.166).
```

代进目标：

```math
\begin{aligned}
f_0(x^\star)&=-3(0.9332)+0.0394+2(0.0275)+2(-0.966-0.199-0.166)\\
&=-2.7996+0.0394+0.0549-2.6606=-5.366 .
\end{aligned}
```

而对偶侧独立算：$g(\nu)=-\nu-\dfrac{1}{\nu-3}-\dfrac{1}{\nu+1}-\dfrac{1}{\nu+2}$，在 $\nu=4.0352$ 处

```math
g=-4.0352-(0.966+0.199+0.166)=-5.366 .
```

两路对上，所以正确的 $f_0$ 是 $-5.37$，原文写的 $-4.70$。差值：

```math
-4.70-(-5.37)=0.67\approx 4x_3=4(0.166),
```

这 0.67 正好等于把 $x_3$ 的符号翻回去在 $f_0$ 里造成的改变量 $4x_3$（因为 $\partial f_0/\partial x_3=4x_3+2$，来回翻符号差 $4x_3$）。**用这个残差结构可以反推错误来源**，比逐项重算快得多。

**为什么会写错**。$\nu^\star=4.0352$ 本身是对的——它来自 $\sum 1/(\nu-a_i)^2=1$，那里只有平方，符号被抹掉了。作者从 $\nu$ 反解 $x$ 时用了「$x_i=1/(\nu-a_i)$」这个只对第一分量成立的记忆（$x_1=-1/(\nu-3)=1/(3-\nu)$，符号在 $\nu\gt 3$ 时为正的前面有个负号恰好抵消视觉直觉），于是把三条都写成「正的」。这是第 ② 类错型（符号翻转）叠加第 ① 类（哑指标/位置不一致）的复合。

**落点**：Boyd exercise 5.29 官方解答（同款四根结构）；非凸二次约束问题的强对偶见 §5.2.3 与 §B.1（S-lemma 邻域）；对偶侧 $g(\nu)$ 的闭式见 §5.6.1 的 perturbation 函数。</span>

<span style="color:#1e8449;">**[译注]** 为什么一个**非凸**问题会有 strong duality？这是本题的题眼，值得单独说清。

题目说它是 (5.32) 的特例。这类问题的骨架是：目标二次、约束是**单个**二次等式（这里是球面）。此时 Lagrangian

```math
L(x,\nu)=x^T(D+\nu I)x+2\mathbf 1^Tx-\nu,\qquad D=\mathrm{diag}(-3,1,2)
```

仍是 $x$ 的二次函数。它的 infimum 有限当且仅当 $D+\nu I\succeq 0$，即 $\nu\ge 3$；此时

```math
\mathbf 1^T(D+\nu I)^{-1}\mathbf 1-\nu .
```

对偶问题是**凹的**（$g$ 是一元函数，可直接求导），且原问题的可行集紧（球面）+ 目标连续 ⟹ 原问题有最优解；再由 §5.2.3 的结论（一个二次约束的 QCQP 满足 strong duality）得 $d^\star=p^\star$。

**消失测试**：如果约束换成两个二次不等式，这个结论立刻崩——5.26 就是活证据（两圆盘交集退化成点，Slater 失效，KKT 无解）。所以 strong duality 在这里**不是靠凸性，而是靠「约束个数 = 1 且是二次」这个代数巧合**。

**落点**：Boyd §5.2.3（`strong duality for QCQP with one quadratic constraint`）、§4.4 的 trust-region subproblem（同一个代数结构，出现在数值优化迭代步里）；线代侧挂 Strang 的 Rayleigh quotient：$\nu^\star$ 扮演的是「带位移的特征值参数」，$D+\nu I\succeq 0$ 就是位移后的正定性条件。</span>

### Exercise 5.30 — $\mathrm{tr}\,X-\log\det X$ 的 KKT 与一个 rank-2 更新

> **[原文]** Derive the KKT conditions for minimize $\mathrm{tr}\,X-\log\det X$ subject to $Xs=y$, with variable $X\in\mathbf{S}^n$ and domain $\mathbf{S}^n_{++}$. $y\in\mathbf{R}^n$ and $s\in\mathbf{R}^n$ are given, with $s^Ty=1$. Verify that the optimal solution is given by $X^\star=I+yy^T-\frac{1}{s^Ts}ss^T$.
> **[中文话题]** 矩阵变量问题的 KKT；$\log\det$ 的梯度与 $Xs=y$ 的对称化，以及如何验证一个「猜出来」的逆矩阵。

**Solution.** 对等式约束引入 Lagrange multiplier $z\in\mathbf{R}^n$。KKT 最优性条件是：

```math
X\succ 0,\qquad Xs=y,\qquad X^{-1}=I+\tfrac12\bigl(zs^T+sz^T\bigr).
```

<!-- ===== p165 ===== -->
我们先由条件 $Xs=y$ 定出 $z$。把梯度方程右乘 $y$，得

```math
s=X^{-1}y=y+\tfrac12\bigl(z+(z^Ty)s\bigr).
```

两边与 $y$ 取内积并化简，得 $z^Ty=1-y^Ty$。代回 (5.30.B) 得

```math
z=-2y+(1+y^Ty)s,
```

再把 $z$ 的这个表达式代进 (5.30.A)，得

```math
\begin{aligned}
X^{-1}&=I+\tfrac12\bigl(-2ys^T-2sy^T+2(1+y^Ty)ss^T\bigr)\\
&=I+(1+y^Ty)ss^T-ys^T-sy^T .
\end{aligned}
```

最后我们验证它就是上面那个 $X^\star$ 的逆。记 $\sigma=1/(s^Ts)$、$M=X^{-1}=I+(1+y^Ty)ss^T-ys^T-sy^T$、$P=I+yy^T-\sigma ss^T$，逐块作用（用 $s^Ty=y^Ts=1$ 消元）：

```math
\begin{aligned}
MP&=P+(1+y^Ty)(ss^TP)-ys^TP-sy^TP\\
&=P+(1+y^Ty)\,sy^T-yy^T-\bigl(sy^T+(y^Ty)sy^T-\sigma ss^T\bigr)\\
&=I+yy^T-\sigma ss^T+(1+y^Ty)sy^T-yy^T-sy^T-(y^Ty)sy^T+\sigma ss^T\\
&=I .
\end{aligned}
```

为把解答补完整，还要证明 $X^\star\succ 0$。一个简单看法是把它拆成

```math
X^\star=\underbrace{\Bigl(I-\frac{ss^T}{s^Ts}\Bigr)}_{Q\succeq 0,\ Qs=0}+yy^T .
```


<span style="color:#1e8449;">**[译注]** 这段「猜出 $X^\star$ 再验逆」的写法，是本手册里少见的**把答案当成定理来证**的样板，值得看清它的两条独立防线。

**第一条防线：$Xs=y$**。用拆解 $X^\star=Q+yy^T$（$Q=I-ss^T/s^Ts$ 是到 $s^\perp$ 的正交投影）立刻得到

```math
X^\star s=Qs+(y^Ts)y=0+y=y ,
```

一行完成。这一步证明了「$X^\star$ 确实满足等式约束」，也就解释了 $y^Ts=1$ 这个奇怪假设的来历：**它是让 $X^\star s=y$ 成立所必需的**，若 $y^Ts=\beta\ne 1$，就得写 $X^\star=I+\frac{1}{\beta}yy^T-\frac{1}{s^Ts}ss^T$。

**第二条防线：正定性**。$Q\succeq 0$ 是投影矩阵，$yy^T\succeq 0$，但两个半正定之和可能只是半正定。要判「$\succ$」必须验零空间：设 $v\ne 0$ 使 $v^TX^\star v=\|Qv\|_2^2+(y^Tv)^2=0$。两项都非负，故 $Qv=0$（即 $v=\alpha s$）且 $y^Tv=0$（即 $\alpha=0$）。矛盾，所以 $v=0$，$X^\star\succ 0$ ✓。

**消失测试**：没有第二步，$\log\det X$ 在 $X^\star$ 处无定义（domain 是 $\mathbf{S}^n_{++}$），整个 KKT 成立的前提就塌了；数值上，solver 会在 $X$ 逼近奇异时直接报 `Cholesky factorization failed` 或返回 `NaN` 的 barrier 项。

**落点**：Boyd §A.5.5（$\log\det$ 的梯度与 $-\log\det$ 的自-concordance）、exercise 5.30 的原始出处（Boyd 讲义 §5.1.6 的 `analytic center` 邻域）；线代侧挂 Strang 的 projection matrix（$Q^2=Q=Q^T$）。原文这一段的矩阵乘法展开了 8 个乘积项（提取时被打散成一行乱码），本质上就是上面那三行的合并——**按块作用比按项展开少写一半**，这是矩阵验算的唯一实用姿势。</span>

### Exercise 5.31 — KKT 条件的支撑超平面解释

> **[原文]** Supporting hyperplane interpretation of KKT conditions. Consider a convex problem with no equality constraints, minimize $f_0(x)$ subject to $f_i(x)\le 0$, $i=1,\dots,m$. Assume that $x^\star$ and $\lambda^\star$ satisfy the KKT conditions. Show that $\nabla f_0(x^\star)^T(x-x^\star)\ge 0$ for all feasible $x$. In other words the KKT conditions imply the simple optimality criterion of §4.2.3.
> **[中文话题]** 把 KKT 翻译成「目标梯度与可行方向夹角为钝角」——即 supporting hyperplane（支撑超平面）判据，这是 §4.2.3 的一阶最优性条件。

**Solution.** 设 $x$ 可行。由 $f_i$ 凸且 $f_i(x)\le 0$，对每个 $i$ 有

```math
0\ge f_i(x)\ge f_i(x^\star)+\nabla f_i(x^\star)^T(x-x^\star),\qquad i=1,\dots,m .
```

利用 $\lambda^\star_i\ge 0$ 得到

```math
\begin{aligned}
0&\ge\sum_{i=1}^m\lambda^\star_i\Bigl(f_i(x^\star)+\nabla f_i(x^\star)^T(x-x^\star)\Bigr)\\
&=\sum_{i=1}^m\lambda^\star_if_i(x^\star)+\sum_{i=1}^m\lambda^\star_i\nabla f_i(x^\star)^T(x-x^\star)\\
&=-\nabla f_0(x^\star)^T(x-x^\star).
\end{aligned}
```

最后一行同时用了 complementary slackness $\lambda^\star_if_i(x^\star)=0$ 与 KKT 的最后一条（$\nabla f_0+\sum\lambda^\star_i\nabla f_i=0$）。于是 $\nabla f_0(x^\star)^T(x-x^\star)\ge 0$，即 $\nabla f_0(x^\star)$ 在 $x^\star$ 处定义了一张支撑可行集超平面。

<span style="color:#1e8449;">**[译注]** 这个证明只有三行，但它的**逻辑方向**极易读反，值得钉死。

**关键在第一个 $\ge$**。凸性给的是 $f_i(x)\ge f_i(x^\star)+\nabla f_i(x^\star)^T(x-x^\star)$——**一阶 Taylor 是全局下界**，所以梯度项的符号是「左端大于右端」。又因为 $x$ 可行（$f_i(x)\le 0$），才有 $0\ge$ 那一串。两个不等号方向相反地拼在一起，才得出梯度和 $\le 0$。

**为什么必须 $\lambda^\star_i\ge 0$**。第 2 行到第 3 行是把 $\sum\lambda^\star_i(\cdot)\le 0$ 的每个括号乘上非负数再相加。若某个 $\lambda^\star_i\lt 0$，这一步方向翻转，整个论证崩溃。这就是 §5.5.2 里 $\lambda\succeq 0$ 不可省的代数原因——不是「惯例」。

**互补松弛在此处扮演什么**。$\lambda^\star_if_i(x^\star)=0$ 让 $\sum\lambda^\star_if_i(x^\star)$ 整项消失。如果没有它，剩下的就有 $-\sum\lambda^\star_i f_i(x^\star)$ 这一坨常数（在最优解处每个 $f_i(x^\star)\le 0$，是正的贡献），不等式变成 $\nabla f_0^T(x-x^\star)\ge \sum\lambda^\star_if_i(x^\star)\gt 0$，**结论弱化成严格不等式**，就不再是「支撑超平面」而是「超平面把可行集与 $x^\star$ 严格分开」——性质全变了。

**消失测试**：没有这条结论，§4.2.3 的一阶最优性条件与 §5.5.3 的 KKT 就是两套互不相干的东西，KKT 的「必要性」无从谈起；实践中投影梯度法（projected gradient）用 $\nabla f_0(x^\star)$ 做停止准则也将失去依据——你会不知道该看梯度本身还是看它到可行锥的投影。

**落点**：Boyd §4.2.3（最优性条件）、§5.5.3（KKT 的几何解释）、§2.1.3（支撑超平面定理）；对偶侧见 §5.5.2 的 saddle point（鞍点）刻画，同一件事的另一种写法。</span>

### Exercise 5.32 — 扰动后的最优值是凸函数

> **[原文]** Optimal value of perturbed problem. Let $f_0,f_1,\dots,f_m:\mathbf{R}^n\to\mathbf{R}$ be convex. Show that the function $p^\star(u,v)=\inf\{f_0(x)\mid \exists x\in\mathcal{D},\ f_i(x)\le u_i,\ i=1,\dots,m,\ Ax-b=v\}$ is convex. This function is the optimal cost of the perturbed problem, as a function of the perturbations $u$ and $v$ (see §5.6.1).
> **[中文话题]** perturbation function（扰动函数）的联合凸性——它是 §5.6 全部 sensitivity 结论的地基。

<!-- ===== p167 ===== -->

**Solution.** 定义

```math
G(x,u,v)=
\begin{cases}
f_0(x), & f_i(x)\le u_i\ (i=1,\dots,m),\ Ax-b=v,\\
\infty, & \text{otherwise}.
\end{cases}
```

$G$ 在其定义域

```math
\operatorname{dom}G=\{(x,u,v)\mid x\in\mathcal{D},\ f_i(x)\le u_i,\ i=1,\dots,m,\ Ax-b=v\}
```

上凸，而这个定义域本身容易验证是凸集。因此 $G$ 关于 $(x,u,v)$ **联合**凸。于是

```math
p^\star(u,v)=\inf_x G(x,u,v)
```

是凸函数。

<span style="color:#1e8449;">**[译注]** 「$p^\star(u,v)$ 是凸的」这句话本身不难，难的是**它凭什么管住 sensitivity**，也就是为什么它值得被单独出一题。

**先看它直接给了什么**。$p^\star$ 凸 ⟹ 存在次梯度，且由 §5.6.2 的推导，$-\lambda^\star$ 就是 $p^\star$ 在 $(0,0)$ 处关于 $u$ 的次梯度：

```math
p^\star(u,v)\ge p^\star(0,0)-\lambda^{\star T}u-\nu^{\star T}v .
```

这一条不等式把「放宽第 $i$ 条约束一点点，最优值能降多少」**解析地**框死了：上界是 $\lambda^\star_i u_i$，而且**这是一条对所有 $u$ 都成立的全局界**，不是局部近似。没有凸性，你只有一阶 Taylor 的局部近似，$u$ 一大就失效。

**证明里那个「$\infty$ 补全」是全题的技术点**。$p^\star$ 是 $\inf$，而 $\inf$ 本身并不保凸（$\inf$ 保的是**联合**凸的函数沿一个变量做部分最小化，见 §3.2.5）；麻烦出在原问题在不可行时无值。把「不可行」写成取值 $+\infty$ 的延长函数，$\operatorname{epi}G$ 才成为

```math
\{(x,u,v,t)\mid f_0(x)\le t,\ f_i(x)\le u_i,\ Ax-b=v\},
```

而这**恰是若干凸集与仿射集之交**，故凸——这是 epigraph（上图）判据的标准用法，比逐点验 Jensen 快得多。

**消失测试**：不做 $\infty$ 延长，$G$ 只是「定义域上的凸函数」，而 $\inf$ 沿部分变量取下去后定义域可能被投成一个**非凸**的集合（投影不保凸），于是 $p^\star$ 可能不凸，次梯度论证全线失效。数值后果：sensitivity 分析给出的界会在 $u$ 较大时被违反，你会看到「放宽约束反而让最优值变差」这种反直觉现象。

**落点**：Boyd §5.6.1（perturbation 与 sensitivity 的正式处理）、§3.2.5（部分最小化保凸）；上游是 §2.1.5 的 epigraph 判据。跨学科挂点：这一条在经济学里叫「价值函数的凸性」，是包络定理（envelope theorem）成立的前提条件。</span>

### Exercise 5.33 — 带参数 $\epsilon$ 的 $\ell_1$ 逼近：三态互补条件

> **[原文]** Parametrized $\ell_1$-norm approximation. Consider minimize $\|Ax+b+\epsilon d\|_1$ with variable $x\in\mathbf{R}^3$, and the data below. We denote by $p^\star(\epsilon)$ the optimal value as a function of $\epsilon$. (a) Suppose $\epsilon=0$. Prove that $x^\star=1$ is optimal. Are there any other optimal points? (b) Show that $p^\star(\epsilon)$ is affine on an interval that includes $\epsilon=0$.
> **[中文话题]** $\ell_1$ 逼近的 dual 与「三态」互补条件；参数化后最优值在区间上仿射（分段线性）。

题给数据（`sort=True` 逐行核对）：


```math
\text{minimize}\quad \|Ax+b\|_1
```

的对偶是

```math
\text{maximize}\quad b^Tz\qquad\text{subject to}\quad A^Tz=0,\ \ \|z\|_\infty\le 1 .
```

若 $x$ 与 $z$ 都可行，则

```math
\|Ax+b\|_1\ge z^T(Ax+b)=b^Tz
```

（这来自不等式 $u^Tv\le\|u\|_\infty\|v\|_1$）。等号 $\|Ax+b\|_1=b^Tz$ 成立当且仅当对每个 $i$ 都有 $z_i(Ax+b)_i=|(Ax+b)_i|$。换句话说，最优性条件是：$x$ 与 $z$ 最优，当且仅当 $A^Tz=0$、$\|z\|_\infty\le 1$，且下面的「互补条件」成立：

```math
\begin{aligned}
-1\lt z_i\lt 1 &\Longrightarrow (Ax+b)_i=0,\\
(Ax+b)_i\gt 0 &\Longrightarrow z_i=1,\\
(Ax+b)_i\lt 0 &\Longrightarrow z_i=-1 .
\end{aligned}
```

```math
\begin{bmatrix}1\\-1\\1\end{bmatrix}=0
```

这三个方程定出。解为 $z^\star=(1,-0.5,0.5,-1,0,1)$。按构造，$z^\star$ 满足 $A^Tz^\star=0$ 与互补条件；它同时满足 $\|z^\star\|_\infty\le 1$，因此是最优的。

这是三个变量上的三个线性无关方程，所以解唯一。

```math
(Ax^\star(\epsilon)+b+\epsilon d)_1&=2+10\epsilon\ge 0,\\
(Ax^\star(\epsilon)+b+\epsilon d)_4&=-1+\epsilon\le 0,\\
(Ax^\star(\epsilon)+b+\epsilon d)_6&=1-2\epsilon\ge 0,
\end{aligned}
```

即 $-1/5\le\epsilon\le 1/2$。最优值是

```math
p^\star(\epsilon)=(b+\epsilon d)^Tz^\star=4+7\epsilon .
```

<span style="color:#1e8449;">**[译注]** †4 是一处**指标错位**（第 ① 类错型），危害在于它让「三个未知数」这句话自相矛盾。

**错在哪**。原文写「必须满足 $z_1=1$、$z_4=-1$、$z_5=1$」，「剩下三个分量 $z_2,z_3,z_6$」。但 $b+Ax=(2,0,0,-1,0,1)$ 的第 5 个分量为 $0$、第 6 个为 $+1$，所以被钉死的是 $z_6=1$；$z_5$ 对应残差 $0$，属于自由分量。正确说法是：$z_1=1$、$z_4=-1$、$z_6=1$，自由量是 $z_2,z_3,z_5$。

**数值反证**。原文那个 3×3 系数矩阵的列标号恰好写的是 $(z_2,z_3,z_5)$（这一点原文是对的），与正文的「$z_2,z_3,z_6$」直接打架——**同一页里两个标号，必有一个错**。代正确解 $z^\star=(1,-0.5,0.5,-1,0,1)$ 验 $A^Tz^\star=0$，按列（$A$ 的第 2、3、5 列分别是 $(7,-1,3,4,5,-5)$、$(1,3,-5,-4,5,-1)$、$(1,5,5,0,-7,14)$…）逐项归零，得 $0$；若按原文把 $z_5$ 设为 $1$ 而 $z_6$ 自由，则 $A^Tz$ 的第一分量变成 $-2-5z_2-7z_3-z_4+z_5+2z_6$ 里的 $z_6$ 未定，**方程数不足**，所谓「唯一解」不成立。

**为什么会写错**。作者先看残差、后写标号，手上写着「三个非零残差在 1、4、6 位」，落笔时把 $b+Ax$ 的位次当成 $1..6$ 连续数到「第 5 个非零」——而实际上第 5 位是 $0$。这类错在下标从 1 开始、中间夹零的向量里高发。**形状与指数配平救不了它**（两处都是标量），只能靠「把向量逐位写出来再对着数」。

**落点**：Boyd exercise 5.33（原题无解答，本手册的解答）；三态互补条件见 §5.5.2 与 §6.1.2 的 $\ell_1$ 回归；同一套「大残差必须顶到 $\pm1$」的判据是 basis pursuit 里 $z$ 的符号模式的来源。消失测试：若不做这一步指标核对，后面 (b) 的「三式三变量 → 唯一」就无根基，而 $p^\star(\epsilon)=4+7\epsilon$ 的线性区间端点也会算错——端点正是由 $z_1,z_4,z_6$ 对应的三个残差符号保持来定的。</span>

<span style="color:#1e8449;">**[译注]** 单位分解式的验证：这题的每个数字都可以手算，值得当成「怎么验一份答案」的范本。

**先验 $z^\star$ 的可行性（一步）**。$b^Tz^\star=(-4)(1)+3(-0.5)+9(0.5)+0(-1)+(-11)(0)+5(1)=-4-1.5+4.5+0+0+5=4$，而 $d^Tz^\star=(-10)+6.5-13.5+10+0+14=7$，所以 $p^\star(\epsilon)=4+7\epsilon$ ✓ 与原文一致。

**再验 $x^\star(\epsilon)$ 的零残差**。$A(-3,2,0)^T$ 的第 2、3、5 分量分别为 $13、27、7$，而 $\epsilon d$ 的对应分量是 $-13\epsilon、-27\epsilon、-7\epsilon$，两者抵消 ⟹ 三式恒为 $0$，对**一切** $\epsilon$ 成立 ✓。这就是「$z^\star$ 对非零 $\epsilon$ 仍对偶可行」的代数内容：**活动约束集不变**。

**最后验区间端点**。三个不等式给出 $\epsilon\ge -0.2$、$\epsilon\le 1$、$\epsilon\le 0.5$，取交得 $[-1/5,1/2]$ ✓。注意上界是 $0.5$ 而不是 $1$——$1-2\epsilon\ge 0$ 比 $-1+\epsilon\le 0$ 更紧。**这一步最容易只写 $-1/5\le\epsilon\le1$**（原文在 5.34 里就犯过把两个上界写成一句话的毛病）。

**消失测试**：不做这三次核对，你就无法区分「答案 $4+7\epsilon$ 是真结论」和「系数凑巧对上」。实践中分段线性函数的 breakpoint 全由这类端点不等式给出；本手册 5.33 与 5.34 是同一个模板的两份实例，可以对照读。</span>

### Exercise 5.34 — 原始-对偶 LP 同时被扰动

> **[原文]** Consider the pair of primal and dual LPs, with $\epsilon$ a parameter. (a) Prove that $x^\star=(1,1,1,1)$ is optimal when $\epsilon=0$, by constructing a dual optimal point $z^\star$ that has the same objective value as $x^\star$. Are there any other primal or dual optimal solutions? (b) Give an explicit expression for the optimal value $p^\star(\epsilon)$ as a function of $\epsilon$ on an interval that contains $\epsilon=0$, and expressions for $x^\star(\epsilon)$、$z^\star(\epsilon)$ on the same interval.
> **[中文话题]** 原始与对偶**同时**被扰动（$c\to c+\epsilon d$、$b\to b+\epsilon f$）时的分段二次最优值；活动集（active set）在区间内不变。

原始与对偶分别为

```math
\text{minimize}\ (c+\epsilon d)^Tx\ \ \text{s.t.}\ Ax\preceq b+\epsilon f
```

```math
b=\begin{bmatrix}8\\13\\-4\\27\\-18\end{bmatrix},\quad
```

```math
\bar A^T\bar z+c=0,
```

其中

```math
\bar A=\begin{bmatrix}-17&12&7&11\\1&0&-6&1\\3&3&22&-1\\-11&2&-1&-8\end{bmatrix},\qquad
\bar z=\begin{bmatrix}z_2\\z_3\\z_4\\z_5\end{bmatrix}.
```

$\bar A$ 非奇异，所以 $\bar A^T\bar z+c=0$ 有唯一解：$\bar z=(2,1,2,2)$。所有分量非负，于是 $z=(0,2,1,2,2)$ 对偶可行。

<span style="color:#1e8449;">**[译注]** †5 是本块第二处「$f$ 与 $d$ 互换」的错，而且它能被**一行矩阵-向量乘**判死。

**错在哪**。扰动后的对偶等式约束是 $A^Tz+c+\epsilon d=0$（扰动 $c$ 的量是 $d$）。因此若 $z^\star(\epsilon)=z^\star+\epsilon\Delta z$，必有

```math
A^T\Delta z+d=0\quad(\text{不是}\ A^T\Delta z+f=0).
```

**数值反例**。$\Delta z=(0,-1,2,0,2)$，$A^T\Delta z$ 的四个分量为

```math
(-3,\,-8,\,-21,\,-25),
```

而 $d=(3,8,21,25)$，两者相加 $(0,0,0,0)$ ✓。若换成 $f=(6,15,-13,48,8)$，相加得 $(3,7,-34,23,-17)\ne 0$ ✗。**四个分量里三个非零，一眼判死。**

**为什么会写错**。这题的记号里 $d$ 与 $f$ 各出现两次（$c+\epsilon d$ 与 $b+\epsilon f$），而解答同时要处理「$x$ 侧的扰动」和「$z$ 侧的扰动」。$x$ 侧用 $f$（因为 $Ax\preceq b+\epsilon f$），$z$ 侧用 $d$——作者在两处都写了 $f$，是**同一页内两次同样的失误**，而且它自己下一句又写对了（`satisfies AT z⋆(ϵ) + c + ϵf = 0` 的原文里 $f$ 应为 $d$）。这类错误的判定不靠记忆，靠「扰动源对应哪个向量」的映射表：**约束右端扰动 ⟹ $f$；目标系数扰动 ⟹ $d$**。

**消失测试**：若按原文的 $A^T\Delta z+f=0$ 去解，会得到一组完全不同的 $\Delta z$，进而 $p^\star(\epsilon)$ 的线性项从 $-72$ 变成别的值；而 $(c+\epsilon d)^Tx^\star(\epsilon)$ 与 $-(b+\epsilon f)^Tz^\star(\epsilon)$ 这两个**独立算出来的**表达式将不再相等，strong duality 在 $\epsilon\ne 0$ 处被打破——这是最硬的自查信号。

**落点**：Boyd §5.6.1 的 perturbation 记号（$u$ 扰动不等式右端、$v$ 扰动等式右端）、§5.5.2 的互补松弛；同类模板见 exercise 5.33（只扰动 $b$）与本块 p169 的 5.35（GP 的相对扰动）。</span>

<span style="color:#1e8449;">**[译注]** 这题的真正内容是「**活动集不变 ⟹ 最优值分段二次**」，比公式本身重要。

**三步走的结构**。① 用互补松弛把 $\epsilon=0$ 的活动集钉死（除第一条外全 active）；② 假设 $\epsilon$ 小到活动集不变，于是 $x^\star$ 与 $z^\star$ 都是 $\epsilon$ 的**仿射**函数，各由一条线性方程组定出；③ 用**可行性**（不是最优性）反解出 $\epsilon$ 的合法区间，取交。

**第 ③ 步的算术**。三个约束给出：$7+7\epsilon\le 8+6\epsilon\Rightarrow\epsilon\le 1$；$z_2=2-\epsilon\ge0\Rightarrow\epsilon\le 2$；$z_3=1+2\epsilon\ge0\Rightarrow\epsilon\ge -1/2$。三者的交是 $[-1/2,\,1]$ ✓。**注意原文末句把区间写成 $-1/2\le\epsilon\le 1$（正确）却在上一自然段只说了 $-1/2\le\epsilon\le 2$**——两者合起来读才对：$[-1/2,2]$ 是「对偶可行」的区间，$[-1/2,1]$ 是「原始也可行」的区间，最终有效区间取交。

**为什么最优值是二次而不是线性**。因为**原始与对偶同时**被扰动：原始目标 $(c+\epsilon d)^Tx^\star(\epsilon)$ 中 $x^\star$ 已含 $\epsilon$，乘开后出现 $\epsilon^2 d^T\Delta x$ 项。手算：

```math
c^Tx^\star=-40,\quad c^T\Delta x=-129,\quad d^Tx^\star=57,\quad d^T\Delta x=25,
```

于是 $p^\star(\epsilon)=-40+\epsilon(-129+57)+25\epsilon^2=-40-72\epsilon+25\epsilon^2$ ✓ 与原文一致。若只扰动一侧（如 5.33），就没有 $\epsilon^2$ 项。

**消失测试**：只会背「$p^\star$ 是凸的」（5.32）不足以算出这两个系数；必须走完「活动集 ⟹ 仿射解 ⟹ 区间」这条流水线。反向的判据：$25\epsilon^2$ 的系数为正，与 $p^\star$ 凸一致——**符号本身就是一次免费的正确性检查**。

**落点**：Boyd §5.6.2（sensitivity 与 active set）、§4.3.2 的 LP 灵敏度分析；实现侧对应 simplex 的 basis 不变区间（一个 basis 就是一个活动集）。</span>

### Exercise 5.35 — GP 的 sensitivity：把 λ 读成百分比

> **[原文]** Sensitivity analysis for GPs. Consider a GP with posynomials $f_0,\dots,f_m$ and monomials $h_1,\dots,h_p$, domain $\mathbf{R}^n_{++}$. Define the perturbed GP with $f_i(x)\le e^{u_i}$ and $h_i(x)=e^{v_i}$, and denote its optimal value by $p^\star(u,v)$. Let $\lambda^\star,\nu^\star$ be optimal dual variables for the convex form GP. Assuming $p^\star(u,v)$ is differentiable at $u=0,v=0$, relate $\lambda^\star,\nu^\star$ to the derivatives of $p^\star$. Justify the statement "Relaxing the $i$th constraint by $\alpha$ percent will give an improvement in the objective of around $\alpha\lambda^\star_i$ percent, for $\alpha$ small."
> **[中文话题]** geometric program（几何规划）的 shadow price（影子价格）；对数坐标下 $\lambda^\star$ 直接等于**弹性**（elasticity）。

**Solution.** $-\lambda^\star,-\nu^\star$ 是扰动问题

```math
\text{minimize}\ \log f_0(y)\ \ \text{s.t.}\ \log f_i(y)\le u_i,\ \log h_i(y)=v_i
```

的「影子价格」；也就是说，若最优值 $\log p^\star(u,v)$ 在原点可微，它们就是最优值的导数：

```math
-\lambda^\star_i=\frac{\partial\log p^\star(0,0)}{\partial u_i}=\frac{\partial p^\star(0,0)/\partial u_i}{p^\star(0,0)},\qquad
-\nu^\star_i=\frac{\partial\log p^\star(0,0)}{\partial v_i}=\frac{\partial p^\star(0,0)/\partial v_i}{p^\star(0,0)} .
```

<!-- ===== p170 ===== -->

<span style="color:#1e8449;">**[译注]** 为什么 GP 的 $\lambda^\star$ 可以直接读成「百分比」？因为在 GP 里扰动**本来就写在指数上**。

**机制**。$f_i(x)\le e^{u_i}$ 取对数后是 $\log f_i(y)\le u_i$；当 $u_i=-0.01$ 时，约束被收紧约 $1\%$（严格说 $e^{-0.01}=0.99005$，即 $0.995\%$，误差 $O(u_i^2)$）。所以 $u_i$ 的**单位就是相对变化**，而 $\partial\log p^\star/\partial u_i$ 就是「$u_i$ 每变动 1（=100%）时 $\log p^\star$ 变动多少」。由链式法则

```math
\frac{\partial\log p^\star}{\partial u_i}=\frac{1}{p^\star}\frac{\partial p^\star}{\partial u_i},
```

右边正是**相对变化之比**——这就是弹性。因此 $\alpha\%$ 的约束放松给出约 $\alpha\lambda^\star_i\%$ 的目标改善，量纲天然配平，不需要像一般 LP 那样再乘一个 $b_i$。

**数值感觉**。取 $\lambda^\star_1=30$、$\alpha=1$，则放松第一条约束 $1\%$ 让目标改善约 $30\%$。这个数看起来荒唐，但它恰恰说明**该约束在本问题里是主导瓶颈**——工程上你会优先去改它。

**消失测试**：不做对数变换，$\lambda^\star$ 与「百分比」之间的换算要额外除 $f_i(x^\star)$、乘 $p^\star$，中间任何一项算错，得到的敏感性就差出几个数量级；而在 GP 里这些因子全被 $\log$ 吸收，**公式退化成同一个 $\lambda^\star$**，这正是 GP 在电路尺寸设计（sizing）里被大量使用的直接原因。

**落点**：Boyd §4.5.4（GP 的凸形式与对偶）、§5.6.2（sensitivity 的一般公式）、exercise 5.35 本身；跨学科挂点：经济学里的 Cobb–Douglas 生产函数与这里同构（$\log$ 线性 ⟹ 弹性为常数）。实现侧见 `ggplab` 的灵敏度输出字段 `lambda`。</span>

### Theorems of alternatives

### Exercise 5.36 — 从择一定理推出「$Ax=b$ 有解 ⟺ $b\perp\mathcal{N}(A^T)$」

> **[原文]** Alternatives for linear equalities. Consider the linear equations $Ax=b$, where $A\in\mathbf{R}^{m\times n}$. From linear algebra we know that this equation has a solution if and only if $b\in\mathcal{R}(A)$, which occurs if and only if $b\perp\mathcal{N}(A^T)$. In other words, $Ax=b$ has a solution if and only if there exists no $y\in\mathbf{R}^m$ such that $A^Ty=0$ and $b^Ty\ne 0$. Derive this result from the theorems of alternatives in §5.8.2.
> **[中文话题]** 用 Farkas 型择一定理重证线性代数里那条「列空间 = 零空间正交补」。

**Solution.** 先注意：不能直接套用形如 $f_i(x)\le 0,\ i=1,\dots,m,\ Ax=b$（或严格不等式版本）的 strong alternatives 结论，因为那些定理都假定 $Ax=b$ **可行**。

我们可以对

```math
t\lt -1,\qquad Ax+bt=b
```

应用严格不等式版本的定理。它可行当且仅当 $Ax=b$ 可行：事实上，若 $A\tilde x=b$ 可行，则 $A(3\tilde x)-2b=b$，故 $x=3\tilde x,\ t=-2$ 满足 (5.36.A)。反之，若 $(\tilde x,\tilde t)$ 满足 (5.36.A)，则 $1-\tilde t\gt 2$，且

```math
A\bigl(\tilde x/(1-\tilde t)\bigr)=b,
```

所以 $Ax=b$ 可行。

此外 $Ax+bt=b$ 恒可行（取 $x=0,t=1$），所以可以把严格不等式版本的择一定理用到 (5.36.A) 上。其 dual function 为

```math
g(\lambda,\nu)=
\begin{cases}
-2b^T\nu, & A^T\nu=0,\ \lambda+b^T\nu=0,\\
-\infty, & \text{otherwise}.
\end{cases}
```

（原文此处常数因子错，见 †6。）择一条件化简为

```math
A^T\nu=0,\qquad b^T\nu\lt 0 .
```

<span style="color:#1e8449;">**[译注]** †6 是本块**唯一一处「常数因子错」**，而它恰好能被一个两行的手算反例抓住——因为它给出一个**具体的 $g$ 值**。

**错在哪**。把 $L=\lambda(t+1)+\nu^T(Ax+bt-b)$ 展开：

```math
L=\bigl(\lambda+b^T\nu\bigr)t+\bigl(A^T\nu\bigr)^Tx+\lambda-b^T\nu .
```

在 $A^T\nu=0$、$\lambda+b^T\nu=0$（即 $\lambda=-b^T\nu$）时，$L$ 与 $x,t$ 无关，于是

```math
g(\lambda,\nu)=\lambda-b^T\nu=-b^T\nu-b^T\nu=-2b^T\nu .
```

原文只写了 $-b^T\nu$，**少了因子 2**。

**数值反例**。取 $A=\begin{bmatrix}1&0\\1&0\end{bmatrix}$（$2\times 2$，秩 1）、$b=(0,1)^T$。$\mathcal{N}(A^T)=\mathrm{span}\{(1,-1)^T\}$，故 $A^T\nu=0$ 要求 $\nu=(c,-c)$，$b^T\nu=-c$。取 $c=1$：$\nu=(1,-1)$，$\lambda=-b^T\nu=1\ge 0$，$( \lambda,\nu)$ 对偶可行。直接把 $(\lambda,\nu)$ 与任意 $(x,t)$ 代 $L$：

```math
L=1\cdot(t+1)+(1,-1)^T\Bigl(\begin{bmatrix}1&0\\1&0\end{bmatrix}\begin{bmatrix}x_1\\x_2\end{bmatrix}+\begin{bmatrix}0\\1\end{bmatrix}t-\begin{bmatrix}0\\1\end{bmatrix}\Bigr)
=(t+1)+x_1-x_1-t+1=2 .
```

$L$ 恒等于 $2$，所以 $g=2$。正确公式 $-2b^T\nu=2$ ✓；原文公式 $-b^T\nu=1$ ✗。**一次代入即定案。**

**为什么会写错**。$\lambda-b^T\nu$ 里两项都是 $-b^T\nu$ 的方向（因 $\lambda=-b^T\nu$），作者写到第二项时把第一项当成「已用掉的 $\lambda$」而只留下一份。这类错误的特征是**只在一个特定参数点（$\nu=0$）试算**——$\nu=0$ 时 $\lambda=0$，两个公式都给 $0$，**完全区分不开**。这是「自检点选得太对称」的典型代价。

### Exercise 5.37 — 有限状态 Markov 链的平稳分布：Farkas 的一行证法

> **[原文]** [BT97] Existence of equilibrium distribution in finite state Markov chain. Let $P\in\mathbf{R}^{n\times n}$ satisfy $p_{ij}\ge 0$、$P^T\mathbf{1}=\mathbf{1}$. Use Farkas' lemma to prove there exists $y\in\mathbf{R}^n$ such that $Py=y$、$y\succeq 0$、$\mathbf{1}^Ty=1$.
> **[中文话题]** 列和为 1 的非负矩阵必有平稳分布（equilibrium distribution）；用 Farkas lemma 的「反证 + 找分离向量」路线。

**Solution.** 反设不存在这样的 $y$，即系统

```math
\begin{bmatrix}P-I\\ \mathbf{1}^T\end{bmatrix}y=\begin{bmatrix}0\\1\end{bmatrix},\qquad y\succeq 0
```

不可行。由 Farkas lemma，存在 $z\in\mathbf{R}^n$ 与 $w\in\mathbf{R}$ 使

```math
(P-I)^Tz+w\mathbf{1}\succeq 0,\qquad w\lt 0,
```

即

```math
P^Tz\succ z .
```

由于 $P$ 的元素非负且列和为 1，必有

```math
(P^Tz)_i=\sum_j p_{ji}z_j\le\max_j z_j ,
```

这与 $P^Tz\succ z$ 矛盾（后者要求每个分量都严格大于对应的 $z_i$，从而最大值也必须严格增大）。

<!-- ===== p171 ===== -->

<span style="color:#1e8449;">**[译注]** 这个证明短到容易被当成「显然」，但中间那步「$\max$ 不能变大」是整题的支点，值得单独拆。

**为什么 $P^Tz\succ z$ 与「$\max$ 有界」矛盾**。$P^Tz\succ z$ 逐分量意味着存在 $\delta\gt 0$ 使 $P^Tz\succeq z+\delta\mathbf{1}$。取 $i^\star$ 使 $z_{i^\star}=\max_j z_j$，则

```math
(P^Tz)_{i^\star}=\sum_j p_{ji^\star}z_j\le z_{i^\star}\sum_j p_{ji^\star}=z_{i^\star},
```

最后一步用了列和等于 1。而 $P^Tz\succ z$ 要求 $(P^Tz)_{i^\star}\gt z_{i^\star}$，矛盾 ✓。**注意只用了列和 = 1**，没有用行和为 1——这正是原题为什么写 $P^T\mathbf{1}=\mathbf 1$（列和为 1）而不是 $P\mathbf 1=\mathbf 1$。

**Farkas 的哪一支**。标准 Farkas 有两支：$\{Ax=b,\ x\succeq0\}$ 与 $\{A^Ty\succeq0,\ b^Ty\lt0\}$ 恰有一个可行。这里 $A=\begin{bmatrix}P-I\\\mathbf{1}^T\end{bmatrix}$、$b=(0,1)^T$，于是另一支是

```math
(P-I)^Tz+w\mathbf{1}\succeq 0,\qquad \mathbf{1}^Ty\ \text{项给出}\ b^Ty'=w\lt 0 .
```

**消失测试**：没有这个「找分离向量」的路线，你得回去用 Perron–Frobenius 定理（需要不可约性假设）或 Brouwer 不动点定理（需要构造单纯形上的连续映射）。Farkas 版本的好处是**只假设非负与列和**，不需要不可约；代价是它只给存在性，不给唯一性（周期性链的平稳分布不唯一，如 $P=\begin{bmatrix}0&1\\1&0\end{bmatrix}$ 的 $y$ 可以是任意 $(t,1-t)$）。

**落点**：Boyd §5.8.3 的 Farkas lemma（式 (5.90) 邻域）；教材 [BT97] 的 Markov 链平稳分布；跨学科挂点：这与 PageRank 的线性方程组 $(I-\alpha P^T)y=(1-\alpha)\mathbf 1/n$ 是同一套线性代数，只是那里用幂迭代而不是 Farkas。判据侧：原文末句写「contradicts $P^Tz\succ\mathbf 1$」，应为「contradicts $P^Tz\succeq z+\delta\mathbf 1$」——$\succ z$ 的对象是 $z$ 不是 $\mathbf 1$，这是一处文字笔误，不影响证明。</span>

### Exercise 5.38 — 期权定价：为什么市场是 complete 的

> **[原文]** [BT97] Option pricing. We apply the results of example 5.10, page 263, to a simple problem with three assets: a riskless asset with fixed return $r\gt 1$, a stock, and an option on the stock. The option gives us the right to purchase the stock at the end of the period, for a predetermined price $K$. Show that for given $r,S,K,u,d$, the option price $C$ is uniquely determined by the no-arbitrage condition. In other words, the market for the option is complete.
> **[中文话题]** 用 example 5.10 的「无套利 ⟺ 存在正的状态价格向量 $y$」证明期权价格被唯一钉死，即 two-state 市场的 completeness（完备性）。

**Solution.** 条件 $V^Ty=p$ 化简为

```math
y_1+y_2=\frac1r,\qquad uy_1+dy_2=1,\qquad y_1\max\{0,Su-K\}+y_2\max\{0,Sd-K\}=C ,
```

其中

```math
V=\begin{bmatrix}r&r\\ uS&dS\\ \max\{0,Su-K\}&\max\{0,Sd-K\}\end{bmatrix},\qquad
p=\begin{bmatrix}1\\ S\\ C\end{bmatrix}.
```

前两个方程唯一地确定 $y_1,y_2$：

```math
y_1=\frac{r-d}{r(u-d)},\qquad y_2=\frac{u-r}{r(u-d)},
```

由于 $u\gt r\gt d$，这两个值都是正的。于是

```math
C=\frac{(r-d)\max\{0,Su-K\}+(u-r)\max\{0,Sd-K\}}{r(u-d)} .
```

<span style="color:#1e8449;">**[译注]** 这道题的答案只有三行，但「为什么 $C$ 被唯一确定」的逻辑链条值得完整走一遍，因为它是 §5.10 里对偶变量＝价格那一套的标准落地。

**第一步：三层资产、两个状态，方程数多于未知数**。$V$ 是 $3\times2$，$V^Ty=p$ 是 3 个方程、2 个未知数 $(y_1,y_2)$。**一般情况下这超定、无解**——但前两行（无风险资产与股票）恰好把 $y$ 唯一确定，第三行于是变成一条**约束**：$C$ 必须取那个值。这就是 completeness：期权是冗余资产，它的价格不是自由的。

**第二步：$y$ 的表达式**。解 $y_1+y_2=1/r$ 与 $uy_1+dy_2=1$：

```math
y_1=\frac{1-d/r}{u-d}=\frac{r-d}{r(u-d)},\qquad y_2=\frac1r-y_1=\frac{u-r}{r(u-d)} .
```

两个数都正，因为 $u\gt r\gt d$——这恰好就是「无套利区间」$d\lt r\lt u$ 的代数内容。反例：若 $r\ge u$，则 $y_2\le0$，意味着存在套利（无限借入无风险资产、买入股票）。

**第三步：$C$ 就是折现期望**。把 $y_i$ 理解成状态价格，则

```math
C=\frac{1}{r}\Bigl[q\max\{0,Su-K\}+(1-q)\max\{0,Sd-K\}\Bigr],\qquad q=\frac{r-d}{u-d},
```

这就是 Black–Scholes 单期离散版本：$q$ 是**风险中性概率**（risk-neutral probability），$C$ 是期权到期收益在 $q$ 下的期望按 $r$ 折现。$q$ 与真实的上涨概率无关——这就是「定价不依赖真实概率」的著名结论。

**数值反例（用来验算）**。取 $S=100$、$u=1.2$、$d=0.8$、$r=1.05$、$K=100$。则 $q=(1.05-0.8)/0.4=0.625$，收益为 $\max\{0,120-100\}=20$ 与 $\max\{0,80-100\}=0$，于是

```math
C=\frac{0.625\cdot20+0.375\cdot0}{1.05}=\frac{12.5}{1.05}=11.90 .
```

把它代回第三行：$y_1\cdot20+y_2\cdot0$，其中 $y_1=0.625/1.05=0.5952$，得 $0.5952\cdot20=11.90$ ✓ 两路一致。

**消失测试**：不去解那两行方程，$C$ 就完全自由——市场上任何报价都不违反「对偶可行」，也就没有 no-arbitrage 的约束力，期权无法被复制（incomplete market）。一旦市场不完备，$C$ 只能落在一个区间里，这就是「波动率微笑」在离散模型里的雏形。

**落点**：Boyd example 5.10（p.263，无套利的择一定理版）、exercise 5.38 本身；[BT97] 的 §2 与 §5；金融侧挂 Harrison–Pliska 的「无套利 ⟺ 存在等价鞅测度」，离散版就是本题的 $y$。</span>


### Exercise 5.40 — E-optimal 实验设计的对偶：$\sqrt{\operatorname{tr}Z}$ 从哪来

> **[原文]** E-optimal experiment design. A variation on the two optimal experiment design problems of exercise 5.10 is minimize $\lambda_{\max}\bigl(\sum_{i=1}^p x_iv_iv_i^T\bigr)^{-1}$ subject to $x\succeq 0$, $\mathbf{1}^Tx=1$. Derive a dual for this problem, by first reformulating it as minimize $1/t$ subject to $\sum_i x_iv_iv_i^T\succeq tI$, $x\succeq 0$, $\mathbf{1}^Tx=1$, with variables $t\in\mathbf R$, $x\in\mathbf R^p$ and domain $\mathbf R_{++}\times\mathbf R^p$, and applying Lagrange duality. Simplify the dual problem as much as you can.
> **[中文话题]** E-最优实验设计（E-optimal design）的对偶；核心技巧是 $\inf_{t\gt 0}(1/t+t\operatorname{tr}Z)=2\sqrt{\operatorname{tr}Z}$。

**Solution.**

```math
\text{minimize}\quad 1/t\qquad\text{subject to}\quad \sum_{i=1}^p x_iv_iv_i^T\succeq tI,\ \ x\succeq 0,\ \ \mathbf{1}^Tx=1 .
```

其 Lagrangian 为

```math
\begin{aligned}
L(t,x,Z,z,\nu)&=1/t-\operatorname{tr}\Bigl(Z\Bigl(\sum_{i=1}^px_iv_iv_i^T-tI\Bigr)\Bigr)-z^Tx+\nu(\mathbf{1}^Tx-1)\\
&=1/t+t\operatorname{tr}Z+\sum_{i=1}^px_i\bigl(-v_i^TZv_i-z_i+\nu\bigr)-\nu .
\end{aligned}
```

对 $x_i$ 的最小值下方有界，仅当 $-v_i^TZv_i-z_i+\nu=0$。对 $t$ 最小化时注意

```math
\inf_{t\gt 0}\bigl(1/t+t\operatorname{tr}Z\bigr)=
\begin{cases}
2\sqrt{\operatorname{tr}Z}, & Z\succeq 0,\\
-\infty, & \text{otherwise}.
\end{cases}
```

于是 其 dual function 为

```math
g(Z,z,\nu)=
\begin{cases}
2\sqrt{\operatorname{tr}Z}-\nu, & v_i^TZv_i+z_i=\nu,\ Z\succeq 0,\\
-\infty, & \text{otherwise}.
\end{cases}
```

对偶问题是

```math
\text{maximize}\quad 2\sqrt{\operatorname{tr}Z}-\nu\qquad\text{subject to}\quad v_i^TZv_i\le\nu,\ i=1,\dots,p,\ \ Z\succeq 0 .
```

令 $W=(1/\nu)Z$，得

```math
\text{maximize}\quad 2\sqrt{\nu}\sqrt{\operatorname{tr}W}-\nu\qquad\text{subject to}\quad v_i^TWv_i\le 1,\ i=1,\dots,p,\ \ W\succeq 0 .
```

（原文此处写成 $\ge 1$，见 †7。）最后对 $\nu$ 求最优给出 $\nu=\operatorname{tr}W$，于是问题进一步化简为

```math
\text{maximize}\quad \operatorname{tr}W\qquad\text{subject to}\quad v_i^TWv_i\le 1,\ i=1,\dots,p,\ \ W\succeq 0 .
```

<span style="color:#1e8449;">**[译注]** †7 是一处**不等号方向翻转**，而它被同一页后面两行自己否掉了——这类「自打脸」错最容易查，也最容易漏。

**错在哪**。从 $v_i^TZv_i\le\nu$ 换变量 $Z=\nu W$（$\nu\gt 0$），得

```math
\nu\,v_i^TWv_i\le\nu\ \Longrightarrow\ v_i^TWv_i\le 1 .
```

方向不变。原文写成 $v_i^TWv_i\ge1$ 是错的。

**数值反例**。取 $p=1$、$v_1=(1,0)^T$、$\nu=2$、$Z=\nu W=\begin{bmatrix}2&0\\0&0\end{bmatrix}$（即 $W=\begin{bmatrix}1&0\\0&0\end{bmatrix}$）。原约束 $v_1^TZv_1=2\le\nu=2$ ✓ 可行。换变量后 $v_1^TWv_1=1$ —— 恰好等于 1，**两个方向都满足**，所以这个点是「测不出错」的。要测出来必须取严格点：$Z=\begin{bmatrix}1&0\\0&0\end{bmatrix}$（$v_1^TZv_1=1\lt 2$，可行），则 $W=Z/\nu=\begin{bmatrix}0.5&0\\0&0\end{bmatrix}$，$v_1^TWv_1=0.5\lt 1$——**若约束写成 $\ge1$，这个合法点会被判不可行**，对偶可行域凭空缩小，下界变松。

**为什么会写错**。因为下一行要「对 $\nu$ 优化」，作者的心智模型从「$W$ 是归一化后的 $Z$」滑向了「$W$ 是倒数」，把 $1/\nu$ 与 $\nu$ 的乘法方向记反。**判据就在同一段里**：原文自己最后写的是 $v_i^TWv_i\le1$（正确），也就是说**同一条约束在同一页出现了两个方向**——发现这种自相矛盾不需要任何外部知识。

**消失测试**：方向错的反直觉后果是「最优值是 $-\infty$ 或上界失效」。取 $W=tI$、$t\to\infty$，$v_i^TWv_i=t\|v_i\|^2\ge1$ 恒满足，于是 $\operatorname{tr}W=tn\to\infty$：**对偶问题无界**，但原问题（$1/t$ 有下界 0）显然有界。弱对偶被打破，这就是硬判据。

**落点**：Boyd §7.5（experiment design 的三种最优性准则）、exercise 5.10（A-optimal 与 D-optimal 的对应版本）；本块的答案可直接对照 5.10 的 `(Σx_iv_iv_i^T)^{-1}` 写法。</span>

<span style="color:#1e8449;">**[译注]** 那个 $2\sqrt{\operatorname{tr}Z}$ 不是天上掉的，它是**一维凸优化**的结果，而这一招在凸优化里反复出现。

**推导（两行）**。设 $a=\operatorname{tr}Z\gt 0$，$f(t)=1/t+at$，$t\gt 0$。令 $f'(t)=-1/t^2+a=0$ 得 $t^\star=1/\sqrt a$，代回

```math
f(t^\star)=\sqrt a+\sqrt a=2\sqrt a .
```

二阶导 $f''=2/t^3\gt 0$ 保证这是极小。若 $a\lt 0$（即 $\operatorname{tr}Z\lt 0$）则 $t\to\infty$ 时 $f\to-\infty$，故 $\inf=-\infty$——这就是 $Z\succeq 0$ 这个条件进入 dual function 的**第二个入口**（第一个是 $\sqrt{\cdot}$ 需要非负）。

**为什么这个技巧值得单列**。$1/t$ 是凸的、$t\operatorname{tr}Z$ 是线性的，两者相加减少了「一个变量、两个方向」的鞍点结构，$\inf$ 一取就得到 $\sqrt{\cdot}$——**凸函数与它的共轭（conjugate）在互相转换**。同一个恒等式在 Boyd 里至少出现三次：§3.1.7 的 $\sqrt{xy}$ 型函数、§5.2.3 的 QCQP 对偶、以及本题。

**消失测试**：不做这个 $\inf$，dual function 里留下 $t$，对偶问题就变成「两层」的：$\max_{\nu,W}\min_t$，无法化成单一 SDP；而做完之后对偶是**一个 SDP + 一组二次不等式**（$v_i^TWv_i\le1$ 就是 SOC 约束），可以交给 CVX 直接解。

**落点**：Boyd §3.3.1（共轭函数）、§5.2.3、exercise 5.40；数值侧注意 $2\sqrt{\operatorname{tr}Z}$ 在 $Z$ 奇异处不可微——实现时要写 `2*sqrtm(trace(Z))` 或改写成 SOC（$\|(2,\ t-\operatorname{tr}Z)\|_2\le t+\operatorname{tr}Z$），否则 solver 会在 $Z$ 的秩下降时失步。</span>

### Exercise 5.41 — 最快混合 Markov 链的对偶：$\operatorname{tr}$ 配对与核范数

> **[原文]** Dual of fastest mixing Markov chain problem. On page 174, we encountered the SDP: minimize $t$ subject to $-tI\preceq P-(1/n)\mathbf{1}\mathbf{1}^T\preceq tI$, $P\mathbf{1}=\mathbf{1}$, $P_{ij}\ge0$, $P_{ij}=0$ for $(i,j)\notin E$, with variables $t\in\mathbf R$, $P\in\mathbf S^n$. The norm $\|\cdot\|_{2*}$ is the dual of the spectral norm on $\mathbf S^n$: $\|Y\|_{2*}=\sum_{i=1}^n|\lambda_i(Y)|$, the sum of the absolute values of the eigenvalues of $Y$.
> **[中文话题]** 谱范数的对偶——核范数（nuclear norm）——如何从 SDP 的对偶里自然浮出；以及 $\|\cdot\|_*$ 与 $\mathrm{tr}$ 的配对。

**Solution.** 把最后那条约束（$P_{ij}=0$ 当 $(i,j)\notin E$）的 Lagrange multiplier 记作 $\Lambda\in\mathbf S^n$，其中当 $(i,j)\in E$ 时 $\lambda_{ij}=0$。

<!-- ===== p174 ===== -->

其 Lagrangian 为

```math
\begin{aligned}
L(t,P,U,V,z,W,\Lambda)
={}&t+\operatorname{tr}\bigl(U(-tI-P+(1/n)\mathbf{1}\mathbf{1}^T)\bigr)+\operatorname{tr}\bigl(V(P-(1/n)\mathbf{1}\mathbf{1}^T-tI)\bigr)\\
&+z^T(\mathbf{1}-P\mathbf{1})-\operatorname{tr}(WP)+\operatorname{tr}(\Lambda P)\\
={}&(1-\operatorname{tr}U-\operatorname{tr}V)t+\operatorname{tr}\Bigl(P\bigl(-U+V-W+\Lambda-\tfrac12(\mathbf{1}z^T+z\mathbf{1}^T)\bigr)\Bigr)\\
&+\mathbf{1}^Tz+(1/n)\bigl(\mathbf{1}^TU\mathbf{1}-\mathbf{1}^TV\mathbf{1}\bigr).
\end{aligned}
```

对 $t$ 与 $P$ 最小化给出条件

```math
\operatorname{tr}U+\operatorname{tr}V=1,\qquad \tfrac12(\mathbf{1}z^T+z\mathbf{1}^T)=V-U-W+\Lambda .
```

对偶问题是

```math
\text{maximize}\quad \mathbf{1}^Tz-(1/n)\mathbf{1}^T(V-U)\mathbf{1}\qquad
\text{subject to}\quad U\succeq 0,\ V\succeq 0,\ \operatorname{tr}(U+V)=1,\ (z_i+z_j)\le V_{ij}-U_{ij}\ \text{for}\ (i,j)\in E .
```

它与下式等价：

```math
\text{maximize}\quad \mathbf{1}^Tz-(1/n)\mathbf{1}^TY\mathbf{1}\qquad
\text{subject to}\quad \|Y\|_*\le 1,\ (z_i+z_j)\le Y_{ij}\ \text{for}\ (i,j)\in E,
```

变量为 $z\in\mathbf R^n$、$Y\in\mathbf S^n$。

<span style="color:#1e8449;">**[译注]** 这段解答里有一处符号错（原文写成 $\mathbf 1z^T-z\mathbf 1^T$，正确的是和，见下面的自查），以及一处需要补的推理：**核范数从哪来**。

**自查那段符号**。$z^T(\mathbf 1-P\mathbf 1)=z^T\mathbf 1-\operatorname{tr}(P\mathbf 1z^T)$，所以 $P$ 的系数里出现 **$-z\mathbf 1^T$**。但 $P$ 是**对称**变量，$\operatorname{tr}(PM)$ 只看见 $M$ 的对称部分，故

```math
\operatorname{tr}(P\,\mathbf 1z^T)=\operatorname{tr}\Bigl(P\,\tfrac12(\mathbf 1z^T+z\mathbf 1^T)\Bigr),
```

系数因此必须是 $\tfrac12(\mathbf 1z^T+z\mathbf 1^T)$。原文第一处写成减号、第二处写成加号，**同一份解答里前后矛盾**；以第二处（加号）为准，它与 $P$ 对称、$z^T\mathbf 1$ 是标量这两点自洽。判据：把 $n=1$ 代入，$\mathbf 1z^T=z\mathbf 1^T=z$，减号版给 $0$，加号版给 $z$——而 $z^T(\mathbf 1-P\mathbf 1)=z(1-P)$ 里确实有 $-Pz$，故 $P$ 的系数是 $-z$，只有加号版（$\tfrac12(2z)=z$）对得上 ✓。

**核范数从哪来**。最后一步用了一个**表示定理**：对 $Y\in\mathbf S^n$，

```math
\|Y\|_*\le 1\iff \exists\,U\succeq 0,\ V\succeq 0:\ Y=V-U,\ \operatorname{tr}(U+V)=1 .
```

正向：把 $Y$ 做特征分解 $Y=\sum_i\lambda_iq_iq_i^T$，取 $U=\sum_{\lambda_i\lt0}(-\lambda_i)q_iq_i^T$、$V=\sum_{\lambda_i\gt0}\lambda_iq_iq_i^T$，则 $\operatorname{tr}(U+V)=\sum_i|\lambda_i|=\|Y\|_*$；若 $\|Y\|_*\le1$，再把 $(U,V)$ 整体除 $\operatorname{tr}(U+V)$ 归一。反向：$-U\preceq Y\preceq V$ 且 $\operatorname{tr}(U+V)=1$，由 Weyl 不等式 $|\lambda_i(Y)|\le\max(\lambda_i(U),\lambda_i(V))$ 求和得 $\|Y\|_*\le\operatorname{tr}(U+V)=1$ ✓。

**量化**：这一步把**两个半正定矩阵的变量对** $(U,V)$（维数 $2\binom{n+1}{2}$）压成一个**norm ball 约束**，变量数从 $O(n^2)$ 的矩阵对降到 $O(n^2)$ 的单个矩阵——规模同阶但约束从「两个 PSD」变成「一个范数球」，这正是 CVX 里 `norm_nuc(Y) <= 1` 那一行的来处。

**落点**：Boyd §4.6.3（fastest mixing Markov chain）、§A.1.6（对偶范数与谱范数）、§5.9.2；实现侧 `CVXPY` 的 `normNuc`。消失测试：不引入核范数，对偶就带着 $(U,V)$ 两个 PSD 约束，虽然仍可解，但**你无法看出下界与 $Y$ 的特征值绝对和之间的关系**——而后者正是「谱隙下界」的解析来源。</span>

### Exercise 5.42 — 锥形式的不等式形式：把隐式等式约束显式化

> **[原文]** Lagrange dual of conic form problem in inequality form. Find the Lagrange dual problem of minimize $c^Tx$ subject to $Ax\preceq_K b$, where $A\in\mathbf{R}^{m\times n}$, $b\in\mathbf R^m$, and $K$ is a proper cone in $\mathbf R^m$. Make any implicit equality constraints explicit.
> **[中文话题]** proper cone（真锥）与 dual cone（对偶锥）；为什么「不等式形式」里可能藏着等式约束，必须显式写出来。

**Solution.** 给这个不等式配一个乘子 $\lambda\in\mathbf R^m$，构造 Lagrangian

```math
L(x,\lambda)=c^Tx+\lambda^T(Ax-b).
```

其 dual function 为

```math
g(\lambda)=
\begin{cases}
-b^T\lambda, & A^T\lambda+c=0,\\
-\infty, & \text{otherwise},
\end{cases}
\qquad\text{其中 } g(\lambda)=\inf_x\bigl(c^Tx+\lambda^T(Ax-b)\bigr).
```

对偶问题是在所有 $\lambda\succeq_{K^*}0$ 上最大化 $g(\lambda)$，等价地写成

```math
\text{maximize}\quad -b^T\lambda\qquad\text{subject to}\quad A^T\lambda+c=0,\ \ \lambda\succeq_{K^*}0 .
```

<span style="color:#1e8449;">**[译注]** 题目最后那句「Make any implicit equality constraints explicit」是全题的**唯一难点**，而原文解答没有处理它——这里补上。

**什么叫隐式等式约束**。$\lambda\succeq_{K^*}0$ 说的是 $\lambda$ 落在对偶锥里。若 $K$ 不是满维的（例如 $K=\{0\}\times K'\subset\mathbf R^m$，第一个坐标被钉死），那么 $K^*$ 在该方向上**没有限制**：$\lambda$ 的第一个分量可正可负。这等价于一条**无约束的双向**变量，也就是一条看不见的等式约束——因为它由 $A^T\lambda+c=0$ 与目标一起决定，而 $-b^T\lambda$ 在该方向上可能无界。

**显式化的标准手法**。把 $\mathbf R^m$ 正交分解为 $\mathrm{span}\,K$ 与其正交补，记 $P$ 为到 $\mathrm{span}\,K$ 的正交投影。则：

- $\lambda\succeq_{K^*}0$ 只约束 $P\lambda$；
- $(I-P)\lambda$ 是自由变量，只出现在 $-b^T\lambda$ 与 $A^T\lambda$ 里。

于是最优性要求 $(I-P)b=0$（否则目标沿自由方向无界），并可以把 $(I-P)\lambda$ 消掉。**这就是「显式化」的产出：一条原问题可行性条件 $(I-P)b=0$，以及一组被消掉的变量。**

**判据与数值感觉**。取 $K=\{0\}\subset\mathbf R^1$（最退化的真锥，$\mathrm{span}K=\{0\}$），原问题是 $0\le b$（$Ax=0$ 的约束形式）。若 $b\lt0$，原问题不可行；而对偶侧 $\lambda$ 完全自由，目标 $-b\lambda$ 在 $b\lt0$ 时随 $\lambda\to-\infty$ 无界——**两侧同时暴露问题**，这正是「显式化」要提前做的事。

**消失测试**：不显式化，你会把 $\lambda\succeq_{K^*}0$ 当成「全分量非负」，于是漏掉自由方向，得到一个**过紧**的对偶，$d^\star\lt p^\star$ 而误以为 strong duality 失效。

**落点**：Boyd §5.9.1（锥形式问题的对偶）、§2.6.1（proper cone 与 dual cone）、§4.6.2（锥形式的 LP/SOCP/SDP 实例）；实现侧 CVX 的 `dual variable` 在非满维锥上会返回 `Infeasible` 或自由分量，需手工投影。原文另有一处符号笔误：写「maximize $g(\lambda)$ over all $\lambda\preceq_{K^*}0$」，方向应为 $\succeq_{K^*}0$（与紧随其后的等价形式自相矛盾）。</span>

### Exercise 5.43 — SOCP 的对偶：两条独立路线必须给出同一答案

> **[原文]** Dual of SOCP. Show that the dual of the SOCP minimize $f^Tx$ subject to $\|A_ix+b_i\|_2\le c_i^Tx+d_i$, $i=1,\dots,m$, with variables $x\in\mathbf R^n$, can be expressed as maximize $\sum_i(b_i^Tu_i+d_iv_i)$ subject to $\sum_i(A_i^Tu_i+c_iv_i)+f=0$, $\|u_i\|_2\le v_i$, with variables $u_i\in\mathbf R^{n_i}$, $v_i\in\mathbf R$. Derive the dual in the following two ways. (a) Introduce new variables $y_i$ and $t_i$ and equalities, and derive the Lagrange dual. (b) Start from the conic formulation and use the conic dual; use the fact that the second-order cone is self-dual.
> **[中文话题]** second-order cone（二阶锥）自对偶的两次应用；为什么两路推导必须逐项一致。

**Solution.**

**(a)** 引入新变量，把问题写成

```math
\text{minimize}\ c^Tx\quad\text{s.t.}\ \|y_i\|_2\le t_i,\ \ y_i=A_ix+b_i,\ \ t_i=c_i^Tx+d_i,\ \ i=1,\dots,m .
```

其 Lagrangian 为

```math
\begin{aligned}
L(x,y,t,\lambda,\nu,\mu)
={}&c^Tx+\sum_{i=1}^m\lambda_i\bigl(\|y_i\|_2-t_i\bigr)+\sum_{i=1}^m\nu_i^T(y_i-A_ix-b_i)\\
&+\sum_{i=1}^m\mu_i\bigl(t_i-c_i^Tx-d_i\bigr)\\
={}&\Bigl(c-\sum_{i=1}^mA_i^T\nu_i-\sum_{i=1}^m\mu_ic_i\Bigr)^Tx+\sum_{i=1}^m\bigl(\lambda_i\|y_i\|_2+\nu_i^Ty_i\bigr)\\
&+\sum_{i=1}^m(-\lambda_i+\mu_i)t_i-\sum_{i=1}^m\bigl(b_i^T\nu_i+d_i\mu_i\bigr).
\end{aligned}
```

对 $x$ 的最小值下方有界，当且仅当

```math
\sum_{i=1}^m\bigl(A_i^T\nu_i+\mu_ic_i\bigr)=c .
```

对 $y_i$ 最小化时注意

```math
\inf_{y_i}\bigl(\lambda_i\|y_i\|_2+\nu_i^Ty_i\bigr)=
\begin{cases}
0, & \|\nu_i\|_2\le\lambda_i,\\
-\infty, & \text{otherwise}.
\end{cases}
```

对 $t_i$ 的最小值下方有界当且仅当 $\lambda_i=\mu_i$。于是 Lagrangian（的极小值）是

```math
g(\lambda,\nu,\mu)=
\begin{cases}
-\sum_{i=1}^m\bigl(b_i^T\nu_i+d_i\mu_i\bigr), & \sum_{i=1}^m\bigl(A_i^T\nu_i+\mu_ic_i\bigr)=c,\ \|\nu_i\|_2\le\lambda_i,\ \mu=\lambda,\\
-\infty, & \text{otherwise},
\end{cases}
```

<!-- ===== p176 ===== -->

由此得到对偶问题

```math
\text{maximize}\quad -\sum_{i=1}^m\bigl(b_i^T\nu_i+d_i\lambda_i\bigr)\qquad
\text{subject to}\quad \sum_{i=1}^m\bigl(A_i^T\nu_i+\lambda_ic_i\bigr)=c,\ \ \|\nu_i\|_2\le\lambda_i,\ i=1,\dots,m .
```

**(b)** 把 SOCP 写成锥形式问题

```math
\text{minimize}\quad c^Tx\qquad\text{subject to}\quad -(A_ix+b_i,\ c_i^Tx+d_i)\preceq_{K_i}0,\ \ i=1,\dots,m .
```

锥对偶是

```math
\text{maximize}\quad -\sum_{i=1}^m\bigl(b_i^Tu_i+d_iv_i\bigr)\qquad
\text{subject to}\quad \sum_{i=1}^m\bigl(A_i^Tu_i+v_ic_i\bigr)=c,\ \ (u_i,v_i)\succeq_{K_i^*}0,\ i=1,\dots,m .
```

<span style="color:#1e8449;">**[译注]** 这题的价值全在「**两路必须一致**」这条纪律上，因为题目给的答案形式与 (a)(b) 的推导结果**差一个整体符号**，必须靠换变量把账算平。

**账怎么算平**。(a) 得到 maximize $-\sum(b_i^T\nu_i+d_i\lambda_i)$，约束 $\|\nu_i\|_2\le\lambda_i$。令

```math
u_i=-\nu_i,\qquad v_i=-\lambda_i\ \ (\lambda_i\ge0\ \Rightarrow\ v_i\le0),
```

则目标变成 $\sum(b_i^Tu_i+d_iv_i)$，约束变成 $\|u_i\|_2\le-v_i$；而等式约束变成 $\sum(-A_i^Tu_i-c_iv_i)=c$，即 $\sum(A_i^Tu_i+c_iv_i)=-c=-f$ ✓ 与题目给的 $\sum(A_i^Tu_i+c_iv_i)+f=0$ 完全一致。**注意 $v_i\le 0$ 是必然的**，但题目把约束写成 $\|u_i\|_2\le v_i$——这在 $v_i\ge0$ 时才有非常数解，所以在 $v_i=0$ 处两边同时为 $0$，两边自洽（这是个退化点，两类写法在该点重合）。

**二阶锥自对偶在这里怎么用**。$K_i=\{(y,t)\mid\|y\|_2\le t\}$ 的对偶锥是它自己：$K_i^*=K_i$（由 Cauchy–Schwarz 直接验：$\langle(z,s),(y,t)\rangle\ge0$ 对所有 $\|y\|\le t$ 成立 $\iff\|z\|\le s$）。所以 (b) 里 $(u_i,v_i)\succeq_{K_i^*}0$ 就是 $\|u_i\|\le v_i$ ✓ 与 (a) 的 $\|\nu_i\|\le\lambda_i$ 同型。

**量化差异**。(a) 引入 $2m$ 个新变量（$y_i,t_i$）作为代价，换来「全用等式与范数不等式」的初等形式；(b) 不需要新变量，但要求你会写锥形式并知道 $K^*=K$。**两路的输出必须逐项相同**——若不同，一定是在「(b) 的锥顺序是 $(y,t)$ 还是 $(t,y)$」上翻了车（本题 $\|y\|\le t$ 里 $t$ 的位置就是判据）。

**消失测试**：没有自对偶性，你就得显式计算 $K^*$——对 SOC 来说这件事还简单，但对 PSD 锥（$K=\mathbf S^n_+$）就必须用 $\operatorname{tr}$ 配对，这正是 5.39/5.41 的做法。**同一个模板，四种锥**。

**落点**：Boyd §4.4.2（SOCP 的标准形式）、§5.9.1（锥对偶）、§2.6.1；实现侧：SOCP 进 solver 时统一写成 $(y,t)\in K$，`CVXPY` 的 `SOC(t, y)` 就是这个顺序。原文 (a) 里把求和上限写成 $n$（应为 $m$），(b) 里锥指标写成 $K_i$ 而非统一的 $K$，两处都是记号层面的笔误，不影响结论。</span>

### Exercise 5.44 — 非严格 LMI 的强择一：条件 (5.118) 到底在挡什么

> **[原文]** Strong alternatives for nonstrict LMIs. In example 5.14, page 270, we mentioned that the system $Z\succeq0$, $\operatorname{tr}(GZ)\gt0$, $\operatorname{tr}(F_iZ)=0$, $i=1,\dots,n$ is a strong alternative for the nonstrict LMI $F(x)=x_1F_1+\dots+x_nF_n+G\preceq0$, if the matrices $F_i$ satisfy $\sum_i v_iF_i\succeq0\Rightarrow\sum_iv_iF_i=0$. In this exercise we prove this result, and give an example to illustrate that the systems are not always strong alternatives. (a) Suppose (5.118) holds, and that the optimal value of the auxiliary SDP minimize $s$ subject to $F(x)\preceq sI$ is positive. Show that the optimal value is attained. (b) Take $n=1$, and $G=\begin{bmatrix}0&1\\1&0\end{bmatrix}$, $F_1=\begin{bmatrix}0&0\\0&1\end{bmatrix}$. Show that (5.117) and (5.116) are both infeasible.
> **[中文话题]** 非严格 LMI（nonstrict LMI）的强择一（strong alternatives）；条件 (5.118) 排除了「零空间里的半正定方向」，从而让最优值可达。

**Solution.**

**(a)** 反设最优值有限但不可达，即存在序列 $(x^{(k)},s^{(k)})$，$k=0,1,2,\dots$，使

```math
x^{(k)}_1F_1+\dots+x^{(k)}_nF_n+G\preceq s^{(k)}I
```

对一切 $k$ 成立，且 $s^{(k)}\to s^\star\gt0$。我们来证明范数 $\|x^{(k)}\|_2$ 有界。

<!-- ===== p177 ===== -->

反设无界。把上式两边除以 $\|x^{(k)}\|_2$，得

```math
\frac{1}{\|x^{(k)}\|_2}G+v^{(k)}_1F_1+\dots+v^{(k)}_nF_n\preceq w^{(k)}I,
```

其中 $v^{(k)}=x^{(k)}/\|x^{(k)}\|_2$、$w^{(k)}=s^{(k)}/\|x^{(k)}\|_2$。序列 $(v^{(k)},w^{(k)})$ 有界，故有收敛子列。设其极限为 $(\bar v,\bar w)$。由于 $\bar w$ 必须为零，我们有

```math
\bar v_1F_1+\dots+\bar v_nF_n\preceq0 .
```

按假设，这蕴含 $\bar v=0$，与「序列 $x^{(k)}$ 无界」矛盾（因 $\|v^{(k)}\|=1$ 而极限为 $0$）。

既然有界，序列 $x^{(k)}$ 必有收敛子列。在 (5.44.A) 中取极限，得

```math
\bar x_1F_1+\dots+\bar x_nF_n+G\preceq s^\star I,
```

即最优值可达。

**(b)** LMI 是

```math
\begin{bmatrix}x_1&1\\1&0\end{bmatrix}\preceq 0,
```

它不可行。择一系统是

```math
\begin{bmatrix}z_{11}&z_{12}\\z_{12}&z_{22}\end{bmatrix}\succeq 0,\qquad z_{22}=0,\qquad z_{12}\gt0,
```

它也不可能成立。

<span style="color:#1e8449;">**[译注]** (b) 的两行结论都值得手算一遍——**它们各自不可行的原因完全不同**，这正是题目想让你看到的「不强」在哪里。

**LMI 为什么不可行**（纯特征值）。$x_1F_1+G=\begin{bmatrix}0&1\\1&x_1\end{bmatrix}$ 的特征值是

```math
\lambda_{1,2}=\frac{x_1\pm\sqrt{x_1^2+4}}{2}.
```

因为 $\sqrt{x_1^2+4}\gt|x_1|$ 恒成立，必有一个特征值为正——**对任何 $x_1$ 都不可行**。这一句不需要任何优化知识，纯粹是判别式。

**择一系统为什么不可行**（纯 PSD 结构）。$Z=\begin{bmatrix}z_{11}&z_{12}\\z_{12}&0\end{bmatrix}\succeq0$ 要求 $z_{11}\ge0$ 且行列式 $-z_{12}^2\ge0$，即 $z_{12}=0$。而要求 $z_{12}\gt0$，矛盾 ✓。

**条件 (5.118) 在这里失效了吗**。$n=1$ 时 (5.118) 说的是「$v_1F_1\succeq0\Rightarrow v_1F_1=0$」。而 $F_1=\begin{bmatrix}0&0\\0&1\end{bmatrix}$，$v_1=1$ 时 $v_1F_1=\mathrm{diag}(0,1)\succeq0$ 但 $\ne0$——**(5.118) 不成立**。所以本例恰是定理假设的**反面**：条件不满足时两系统可以同时不可行，这就是「不是 always strong alternatives」的确切含义。

**量化对照**。(a) 的证明只用了两件事：① $\|v^{(k)}\|=1$ 的紧性（球面紧）；② (5.118) 把极限的「$\preceq0$」升级为「$=0$」。**第二件事是全部技术内容**——如果没有 (5.118)，极限点只能得到 $\bar v_1F_1\preceq0$，而 $\bar v\ne0$ 是允许的，于是 $x^{(k)}$ 可以沿 $\bar v$ 方向逃逸，最优值只在下确界处不达。

**消失测试**：没有 (5.118)，辅助 SDP 的最优值可能是 $0$ 但不可达；§5.9.4 的 strong alternatives 结论随之失效，你会得到「原系统不可行」与「择一系统不可行」同时成立的诡异局面——(b) 就是这样的实例。

**落点**：Boyd §5.9.4（nonstrict inequalities 与强择一）、example 5.14（p.270）、§2.6.1 的半正定锥；线代侧挂 Strang 的「对称矩阵的 $\preceq$ 是按特征值排序的偏序」——本题所有推理都在这个偏序上做。</span>

### Exercise 6.1 — log barrier penalty 的二次上下界

> **[原文]** Quadratic bounds for log barrier penalty. Let $\phi:\mathbf R\to\mathbf R$ be the log barrier penalty function with limit $a\gt0$: $\phi(u)=-a^2\log(1-(u/a)^2)$ for $|u|\lt a$, $\infty$ otherwise. Show that if $u\in\mathbf R^m$ satisfies $\|u\|_\infty\lt a$, then $\|u\|_2^2\le\sum_{i=1}^m\phi(u_i)\le\dfrac{\phi(\|u\|_\infty)}{\|u\|_\infty^2}\|u\|_2^2$. This means that $\sum_i\phi(u_i)$ is well approximated by $\|u\|_2^2$ if $\|u\|_\infty$ is small compared to $a$. For example, if $\|u\|_\infty/a=0.25$, then $\|u\|_2^2\le\sum_i\phi(u_i)\le1.033\cdot\|u\|_2^2$.
> **[中文话题]** log barrier penalty（对数障碍罚）在原点附近的二次行为；两侧界都把 $\ell_2$ 范数卡在常数倍内，这就是「它像 $\ell_2^2$ 但不是 $\ell_2^2$」的定量说法。

**Solution.** 左不等式来自 $\log(1+x)\le x$（对一切 $x\gt -1$ 成立）。

右不等式来自 $-\log(1-x)$ 的凸性：

```math
-\log\bigl(1-u_i^2/a^2\bigr)\le-\frac{u_i^2}{\|u\|_\infty^2}\log\bigl(1-\|u\|_\infty^2/a^2\bigr),
```

于是

```math
-a^2\sum_{i=1}^m\log\bigl(1-u_i^2/a^2\bigr)\le-a^2\frac{\|u\|_2^2}{\|u\|_\infty^2}\log\bigl(1-\|u\|_\infty^2/a^2\bigr).
```

<span style="color:#1e8449;">**[译注]** 这两条界的**左右两侧用的是完全不同的工具**，分清它们比记住结论有用。

**左侧：一阶不等式**。令 $x=-u_i^2/a^2\gt -1$，则 $\log(1-u_i^2/a^2)\le -u_i^2/a^2$，两端乘 $-a^2$（负数，不等号翻转）得

```math
\phi(u_i)=-a^2\log\bigl(1-u_i^2/a^2\bigr)\ge u_i^2 .
```

求和即得左侧。**注意这个界与 $a$ 无关**——它是 $\phi$ 在原点的二阶 Taylor 系数被恰好取成 $1$ 的结果（$\phi''(0)=2$，故 $\phi(u)\approx u^2$）。

**右侧：凸性 + 端点插值**。$f(t)=-\log(1-t/a^2)$ 在 $t\lt a^2$ 上凸且 $f(0)=0$，于是对任意 $t\in[0,a^2)$，

```math
f(t)\le f(0)+\frac{t}{t_{\max}}\bigl(f(t_{\max})-f(0)\bigr)=\frac{t}{t_{\max}}f(t_{\max}),
```

取 $t=u_i^2$、$t_{\max}=\|u\|_\infty^2$。这一步是**凸函数在区间端点上的上界**（凸函数图像在弦下方），比「用二阶导估计」更紧且不需要可微性以外的假设（$t_{\max}=a^2$ 时对数为 $-\infty$，故必须 $\|u\|_\infty\lt a$，这正是题设）。

**那个 1.033 的来历**。$\|u\|_\infty/a=\rho=0.25$ 时

```math
\frac{\phi(\|u\|_\infty)}{\|u\|_\infty^2}=\frac{-a^2\log(1-\rho^2)}{\rho^2a^2}=\frac{-\log(1-0.0625)}{0.0625}=\frac{0.064539}{0.0625}=1.0326 .
```

四舍五入即 **1.033** ✓。可以自己验：$\rho=0.1$ 时这个常数是 $1.0050$，$\rho=0.5$ 时是 $1.0986$——**$\rho$ 越小，$\phi$ 越像 $\ell_2^2$**，这就是「well approximated」的量化含义。

**消失测试**：没有右侧这个界，你就不能把「用 $\phi$ 做 robust penalty」的问题近似成「用 $\ell_2^2$ 做 least squares」——而后者有闭式解、前者只有迭代解。实践中这会决定初始化策略：**先用 $\ell_2$ 解热启动**，再切到 $\phi$ 做 refinement，能省掉一半 iteration。

**落点**：Boyd §6.1.2（penalty function approximation）、exercise 6.1 与 exercise 4.26（geometric mean 的最大化）；实现侧：`scipy.optimize` 里没有 $\phi$ 的原生支持，需自己写 $-\log$ barrier 并给 `jac`；robust statistics 里 $\phi$ 是「redescending M-estimator」之前的标准选择。</span>

### Exercise 6.2 — 用常向量逼近 $b$：三种范数三个统计量

> **[原文]** $\ell_1$-, $\ell_2$-, and $\ell_\infty$-norm approximation by a constant vector. What is the solution of the norm approximation problem with one scalar variable $x\in\mathbf R$, minimize $\|x\mathbf 1-b\|$, for the $\ell_1$-, $\ell_2$-, and $\ell_\infty$-norms?
> **[中文话题]** 同一族问题在三种范数下的解分别是**中位数 / 均值 / 中列数**——这是「范数选择 = 统计量选择」的最短证据。

**Solution.**

**(a)** $\ell_2$-norm：平均值 $\mathbf 1^Tb/m$。

**(b)** $\ell_1$-norm：系数的（某个）中位数（median）。

**(c)** $\ell_\infty$-norm：中列数（midrange point）$\dfrac{\max b_i+\min b_i}{2}$。

（原文此处写作 $\dfrac{\max b_i-\min b_i}{2}$，见 †8。）

<span style="color:#1e8449;">**[译注]** †8 是本块最后一处硬错，而且它错得**特别有教学价值**：原文给出的是**最优值**，不是**最优点**。

**错在哪**。题目问的是「解」（the solution），即最优的 $x$。对 $\ell_\infty$：

```math
\min_x\ \max_i|x-b_i| .
```

设 $x$ 在 $[\min b_i,\max b_i]$ 内（越界只会让最大偏差更大），则

```math
\max_i|x-b_i|=\max\bigl(x-\min b_i,\ \max b_i-x\bigr).
```

这两项一个递增、一个递减，令其相等：

```math
x-\min b_i=\max b_i-x\ \Longrightarrow\ x^\star=\frac{\max b_i+\min b_i}{2},
```

此时最优值 $=\dfrac{\max b_i-\min b_i}{2}$。**原文把 $x^\star$ 写成了最优值**。

**数值反例（两行）**。取 $b=(2,10)$：

- 正确 $x^\star=(10+2)/2=6$，检验 $\max(|6-2|,|6-10|)=4$。
- 原文 $x=(10-2)/2=4$，检验 $\max(|4-2|,|4-10|)=6\gt4$ ✗ **不是最优**。

**为什么会写错**。$\min b_i=0$ 时两个公式恰好相等（$b=(0,10)$ 都给 $5$），而作者很可能只在这个对称点上试算过——这与 5.36 的 †6 是**同一个病因**：「自检点选得太特殊，错误被对称性掩盖」。**通用的防错做法**：用两个非对称数（且都不为零）做手算检验。

**三者的对照（记这张表比记公式有用）**：

| 范数 | 最优 $x^\star$ | 鲁棒性行为 |
|---|---|---|
| $\ell_2$ | 均值 $\frac1m\sum b_i$ | 对 outlier 敏感（平方放大） |
| $\ell_1$ | 中位数 | 对 outlier 稳健（只数个数） |
| $\ell_\infty$ | 中列数 $\frac{\max+\min}{2}$ | 只看两个极端值，最敏感 |

**消失测试**：不弄清 $\ell_\infty$ 的解是「中点」而非「半宽」，你就无法判断这个估计量的 breakdown point——它只看 $b$ 的最大最小值，**一个 outlier 就能把它拉到任意位置**（breakdown point $=0$），这正是 $\ell_\infty$ 拟合在统计上几乎不用的原因。

**落点**：Boyd §6.1.1（norm approximation 的例子）、exercise 6.2；统计侧挂「$L_p$ 估计的 breakdown point」表（均值 0、中位数 0.5、中列数 0）。</span>

### Exercise 6.3 — 五种罚函数的 LP / SOCP / 建模套路

> **[原文]** Formulate the following approximation problems as LPs, QPs, SOCPs, or SDPs. The problem data are $A\in\mathbf R^{m\times n}$ and $b\in\mathbf R^m$. The rows of $A$ are denoted $a_i^T$. (a) Deadzone-linear penalty. (b) Log-barrier penalty. (c) Huber penalty. (d) Log-Chebyshev approximation. (e) Minimizing the sum of the largest $k$ residuals.
> **[中文话题]** penalty function（罚函数）到锥规划的标准翻译表；每一条都靠「引入辅助变量 + 约束紧化」完成。

题给罚函数（逐字核对）：

```math
\phi(u)=
\begin{cases}
0, & |u|\le a,\\ |u|-a, & |u|\gt a,
\end{cases}\qquad
\phi(u)=
\begin{cases}
-a^2\log\bigl(1-(u/a)^2\bigr), & |u|\lt a,\\ \infty, & |u|\ge a,
\end{cases}
```

```math
\phi(u)=
\begin{cases}
u^2, & |u|\le M,\\ M(2|u|-M), & |u|\gt M .
\end{cases}
```

**(d) 的等价凸形式**：minimize $t$ subject to $1/t\le a_i^Tx/b_i\le t$，$i=1,\dots,m$，变量 $x\in\mathbf R^n$、$t\in\mathbf R$，定义域 $\mathbf R^n\times\mathbf R_{++}$。

**(e)** 最小化最大的 $k$ 个残差之和：minimize $\sum_{i=1}^k|r|_{[i]}$ subject to $r=Ax-b$，其中 $|r|_{[1]}\ge|r|_{[2]}\ge\dots\ge|r|_{[m]}$ 是 $|r_1|,\dots,|r_m|$ 按降序排列后的数（$k=1$ 退化为 $\ell_\infty$ 逼近，$k=m$ 退化为 $\ell_1$ 逼近）。Hint: 见 exercise 5.19。

**Solution.**

**(a)** Deadzone-linear（死区线性罚）。

```math
\text{minimize}\quad \mathbf 1^Ty\qquad\text{subject to}\quad -y-a\mathbf 1\preceq Ax-b\preceq y+a\mathbf 1,\ \ y\succeq 0 .
```

这是一个 LP，变量为 $y\in\mathbf R^m$、$x\in\mathbf R^n$。

**(b)** Log-barrier penalty。可以把问题写成

```math
\text{maximize}\quad \prod_{i=1}^m t_i^2\qquad
\text{subject to}\quad (1-y_i/a)(1+y_i/a)\ge t_i^2,\ \ -1\le y_i/a\le 1,\ \ y=Ax-b,
```

变量为 $t\in\mathbf R^m$、$y\in\mathbf R^m$、$x\in\mathbf R^n$。然后可以照 exercise 4.26（最大化 geometric mean）的做法，把问题化成 SOCP 或 SDP。

**(c)** Huber penalty。见 exercise 4.5(c)，以及 exercise 6.6。

**(d)** Log-Chebyshev approximation。

```math
\text{minimize}\quad t\qquad\text{subject to}\quad 1/t\le a_i^Tx/b_i\le t,\quad i=1,\dots,m,
```

关于 $x\in\mathbf R^n$ 与 $t\in\mathbf R$。左边的不等式是双曲约束

```math
ta_i^Tx\ge b_i,\qquad t\ge 0,\qquad a_i^Tx\ge 0 .
```

<!-- ===== p180 ===== -->

<span style="color:#1e8449;">**[译注]** 第 6 章的全部建模技巧可以压缩成一句：**「罚函数的非线性只能出现在约束里，不能出现在目标里」**。

**为什么必须这样**。(a)–(e) 的共同结构是 $\min_x\sum_i\phi(a_i^Tx-b_i)$。目标里 $\phi$ 是分段 / 不可微 / 带无穷的，直接交给 solver 会立刻失败。标准动作是：引入辅助变量 $y_i$ **代表残差**，把 $\phi$ 的每一段写成「$y_i$ 的下界约束」，目标改成 $y_i$ 的线性函数。由于 $\phi$ 是**不减**函数，$\min\sum y_i$ 会自动把 $y_i$ 压到 $\phi$ 的下包络上，**这就是「约束紧化」的合法性来源**。

**逐条对账**：

- **(a) 死区**：$y_i\ge|r_i|-a$ 且 $y_i\ge0$（等价于 $-y_i-a\le r_i\le y_i+a$）。$|r_i|\le a$ 时 $y_i=0$ ✓ 目标里没有 $\phi$。
- **(b) 对数障碍**：$\phi$ 确实是**凸**的——$-\log(1-s)$ 关于 $s$ 凸且单调递增，而 $s=(u/a)^2$ 关于 $u$ 凸且取值非负，凸增函数与凸函数复合仍凸。但它的 **domain 是开的**（$|y_i|<a$ 即在内），而且在边界上发散，所以「引入辅助变量 + 线性目标」那套 LP 技巧直接失效。这里 $\phi$ 在 $|u|\to a$ 时 $\to\infty$，**domain 是开的**，所以改用另一条路：最大化 $\prod t_i^2$ 这种 **geometric program** 形式（$\prod t_i^2$ 是单项式，$t_i^2\le1-(y_i/a)^2$ 是 posynomial 约束），再按 4.26 转 SOCP。**这是本块唯一一条不是 LP/SOCP 直接建模的题。**
- **(c) Huber**：$u^2$ 时是 QP，$M(2|u|-M)$ 时是线性，两者在 $|u|=M$ 处值与导数都连续（$M^2=M(2M-M)$ ✓，$2M=2M$ ✓）——**二阶连续**但二阶导跳变，故通常写成 QP + 约束或直接用 `huber` 的 SOCP 形式。
- **(d) Log-Chebyshev**：$|\log(a_i^Tx)-\log b_i|\le t$ 等价于 $1/t\le a_i^Tx/b_i\le t$（取 exp）。左半边 $1/t\le a_i^Tx/b_i$ 交叉相乘得 $b_i\le t\,a_i^Tx$，这是**双曲约束**（hyperbolic constraint），当 $t\gt0$、$a_i^Tx\gt0$ 时等价于 SOC：$\|(2b_i,\ ta_i^Tx-b_i)\|_2\le ta_i^Tx+b_i$。
- **(e) 最大的 $k$ 个**：这是唯一需要「排序」的一条，靠 5.19 的 LP：$\sum_{i=1}^k|r|_{[i]}=\max\{\sum_i\lambda_i|r_i|\mid 0\le\lambda_i\le1,\ \sum\lambda_i=k\}$，再用对偶把 $\max$ 写进目标。

**消失测试**：没有这套「辅助变量 + 紧化」，你就只剩下两条路——要么把 $\phi$ 硬塞进目标交给通用非线性 solver（无收敛保证、对初值敏感、$a$ 小时数值爆），要么放弃凸性。**量化差别**：本题 (a) 的 LP 形式在 $m=n=10^4$ 时用内点法约 1 秒；同一个问题用 BFGS 直接优化分段目标，通常要迭代上千次且经常停在 $|r_i|=a$ 的不可微点上。

**落点**：Boyd §6.1.2（penalty function approximation 全节）、exercise 4.5(c)（Huber 的 SOCP 形式）、exercise 4.26（geometric mean 最大化）、exercise 5.19（最大的 $k$ 个的 LP 表示）；实现侧 `CVXPY` 里分别对应 `cp.pos`、`cp.log`、`cp.huber`、`cp.hyperp`/`SOC`、`cp.sum_largest`。</span>

<span style="color:#1e8449;">**[译注]** (b) 里那个 `maximize ∏t_i²` 值得单独说，因为它是本块唯一出现 **geometric program（几何规划）** 的地方，且步骤容易被跳过。

**为什么不直接写 $\min\sum-a^2\log(1-(y_i/a)^2)$**。因为 $\log$ 不是锥可表示的（CVX 只认 $\log$ 作为**凹**目标或**凸**约束的成员，且要求定义域内严格正）。Boyd 的处理是把它转成「乘积最大化」：

```math
\min\sum_i\bigl(-a^2\log(1-y_i^2/a^2)\bigr)
\iff
\max\prod_i\bigl(1-y_i^2/a^2\bigr)
\iff
\max\prod_i t_i^2,\quad t_i^2\le 1-y_i^2/a^2 .
```

三步分别用：$\log$ 的单调性、$\log$ 把和变积、以及 $\prod$ 对每个 $t_i$ 单调递增（故最大化会自动把 $t_i^2$ 顶到上界）。**这正是 6.1 那条右不等式能成立的原因**：$(1-y^2/a^2)$ 全部接近 $1$ 时，$\prod$ 与 $\sum$ 的差别是二阶小量。

**然后怎么变 SOCP**。约束 $(1-y_i/a)(1+y_i/a)\ge t_i^2$ 是**双线性**的；把 $t_i$ 与 $y_i$ 同时开平方（$u_i=t_i^{1/2}$、$w_i=(1-y_i/a)^{1/2}$ 等）后变成 posynomial 约束，再用 §4.5.4 的 GP→凸变换（取对数）。**代价**：变量翻倍、需要 $y_i$ 严格在 $(-a,a)$ 内。**替代方案**：直接交给 SDP（把 $t_i^2\le(\cdot)(\cdot)$ 写成 $2\times2$ 的 PSD 约束，Schur complement），代价是求解慢一个数量级但不需要开方。

**消失测试**：跳过这一步，题目要求的「formulate as LP/QP/SOCP/SDP」就没有答案——你只能说「这是凸问题」，而凸问题的**表示形式**决定了 solver 能不能吃。**表示即算法**：同一个凸集，LP 表示用 1 秒，SDP 表示用 100 秒，这就是建模工作的全部价值。

**落点**：Boyd §4.5.4（GP 与凸形式）、§3.2.6（Schur complement）、exercise 4.26；实现侧 `CVXPY` 的 `cp.geo_mean` 直接支持 $\prod t_i^{1/m}$，避免手工开方。</span>
