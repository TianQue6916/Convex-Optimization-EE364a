### Exercise 7.4 多元正态分布协方差与均值的估计

**7.4 Estimation of covariance and mean of a multivariate normal distribution.** We consider the problem of estimating the covariance matrix $R$ and the mean $a$ of a Gaussian probability density function

```math
p_{R,a}(y) = (2\pi)^{-n/2}\det(R)^{-1/2}\exp\left(-\frac{1}{2}(y-a)^T R^{-1}(y-a)\right),
```

based on $N$ independent samples $y_1,y_2,\dots,y_N \in \mathbf{R}^n$.

**(a)** We first consider the estimation problem when there are no additional constraints on $R$ and $a$. Let $\mu$ and $Y$ be the sample mean and covariance, defined as

```math
\mu = \frac{1}{N}\sum_{k=1}^{N} y_k, \qquad Y = \frac{1}{N}\sum_{k=1}^{N}(y_k-\mu)(y_k-\mu)^T.
```

Show that the log-likelihood function

```math
l(R,a) = -\frac{Nn}{2}\log(2\pi) - \frac{N}{2}\log\det R - \frac{1}{2}\sum_{k=1}^{N}(y_k-a)^T R^{-1}(y_k-a)
```

can be expressed as

```math
l(R,a) = -\frac{N}{2}\left[n\log(2\pi) + \log\det R + \operatorname{tr}(R^{-1}Y) + (a-\mu)^T R^{-1}(a-\mu)\right].
```

Use this expression to show that if $Y \succ 0$, the ML estimates of $R$ and $a$ are unique, and given by

```math
a_{\mathrm{ml}} = \mu, \qquad R_{\mathrm{ml}} = Y.
```

**(b)** The log-likelihood function includes a convex term ($-\log\det R$), so it is not obviously concave. Show that $l$ is concave, jointly in $R$ and $a$, in the region defined by

```math
R \preceq 2Y.
```

This means we can use convex optimization to compute simultaneous ML estimates of $R$ and $a$, subject to convex constraints, as long as the constraints include $R \preceq 2Y$, i.e., the estimate $R$ must not exceed twice the unconstrained ML estimate.

**中文话题**：把 $N$ 个样本的 Gaussian log-likelihood 压成「$\log\det R$ + 一次迹 + 一个二次型」三段，于是 ML 解退化为样本矩；难点全在 (b)：$-\log\det R$ 是凸的，整体为什么还能在 $R \preceq 2Y$ 内变凹。

#### 解答

**(a)** 先证一个中心化恒等式：

```math
\sum_{k=1}^{N}(y_k-a)(y_k-a)^T = N\left(Y-(a-\mu)(a-\mu)^T\right).
```

把左端逐项展开，并用 $\sum_k y_k = N\mu$：

```math
\sum_{k=1}^{N}(y_k-a)(y_k-a)^T = \sum_{k=1}^{N} y_k y_k^T - N a\mu^T - N\mu a^T + N a a^T .
```

再把 $\sum_k y_k y_k^T$ 换写成 $\sum_k (y_k-\mu)(y_k-\mu)^T + N\mu\mu^T$（因为交叉项 $-2N\mu\mu^T$ 被补回一次），得到

```math
= \sum_{k=1}^{N}(y_k-\mu)(y_k-\mu)^T + N\mu\mu^T - N a\mu^T - N\mu a^T + N a a^T = NY + N(a-\mu)(a-\mu)^T .
```

两边同乘 $1/N$ 即为要证的恒等式（原文此处上标 $T$ 被排到括号内、写成 $(a-\mu^T)$，属排版漂移，非内容错误）。这也证明了 $l$ 的两个表达式等价。

接下来极大化 $l$。它（一般地）**不是** $R$ 的凹函数，所以要小心：我们只知道在全局最优处梯度为零（反之不真）。令关于 $R$ 与 $a$ 的梯度同时为零：

```math
-R^{-1} + R^{-1}\left(Y+(a-\mu)(a-\mu)^T\right)R^{-1} = 0, \qquad -2R^{-1}(a-\mu) = 0,
```

它只有一组解

```math
Y+(a-\mu)(a-\mu)^T = R, \qquad a = \mu .
```

这个驻点必是 $l$ 的全局最大点，因为 $l$ 上方有界。于是 $a_{\mathrm{ml}}=\mu$，$R_{\mathrm{ml}} = Y+(a-\mu)(a-\mu)^T = Y$；当 $Y \succ 0$ 时解唯一。

<span style="color:#1e8449;">**[译注]** 这一步的技术心脏是那个中心化恒等式，它把 $\sum_k (y_k-a)^T R^{-1}(y_k-a)$ 里的 $a$ 与 $R$ **解耦**成两个互不耦合的项：一个只含样本矩（$\operatorname{tr}(R^{-1}Y)$），一个只含参数偏差 $(a-\mu)^T R^{-1}(a-\mu)$。**消失测试**：没有这个拆分，$l$ 关于 $a$ 的梯度是 $\sum_{k=1}^{N} R^{-1}(y_k-a)$，你必须在 $N$ 项求和里重新做一遍中心化才能看出 $a=\mu$ 是唯一驻点；拆开后 $\nabla_a l = -N R^{-1}(a-\mu)$，一行得出。**量的方向感**：直接对 $N$ 项求和需要 $N$ 次 $n \times n$ 矩阵向量乘（每次 $n^2$ 次浮点乘），拆开后只需一次 $R^{-1}Y$，$\mathrm{Cost}$ 从 $O(Nn^2)$ 降到 $O(n^3)$；$N=10^6$、$n=10$ 时是 $10^8$ 对 $10^3$，相差五个数量级。**落点**：Boyd §7.1.1（ML 的样本矩形式）、§A.3.1（矩阵求导）；Strang 线代里同一个恒等式就是「方差分解」$\sum_i (x_i-\bar x)^2 = \sum_i x_i^2 - n\bar x^2$ 的矩阵版，连接路径是「把均值 $\bar x$ 看成使平方和最小的那个点」。不越级：全程只用 $(y-a)=(y-\mu)+(\mu-a)$ 的分配律。 **反例边界**：若样本**不是**独立同分布（例如时间序列有自相关），$Y$ 本身就带偏，$R_{\mathrm{ml}} = Y$ 只是「给定模型下的最优」，不能当作协方差的估计量来用。</span>

<span style="color:#1e8449;">**[译注]** 「梯度为零」在这个问题上**不构成证明**，原文多写一句「$l$ 上方有界」并非客套。**消失测试**：删掉这句，同样的论证对 $f(x)=x^3$ 在 $x=0$ 成立 —— 梯度为零但既非极大也非极小；$l(R,a)$ 关于 $R$ 非凹，唯一驻点完全可能是鞍点。**机制**：需要三条同时成立才能推结论 —— 驻点唯一 + $l$ 连续 + $l$ 上方有界；前两条只保证「驻点是局部极值候选」，第三条才把「逃向无穷」这条退路堵死，于是最大点只能在候选集里，而候选集只有一点。**数值**：取 $n=1$、$Y=1$、$\mu=0$，则 $l(R,1)=-\frac{N}{2}\left[\log(2\pi)+\log R + 2/R\right]$，驻点在 $R=2$；当 $R \to 0^{+}$ 时 $2/R \to +\infty$ 使 $l \to -\infty$，当 $R \to \infty$ 时 $\log R \to \infty$ 也使 $l \to -\infty$，两侧都被封住，$R=2$ 确实是最大点。注意这个验算特意避开了 $R=1$（那里 $\log R=0$ 会把两项的量级差异盖住）。**落点**：Boyd §4.2.3（无约束最优性条件）、§7.1.1。 **一句话记住**：非凸问题里「驻点唯一」永远要配一句「目标上方有界」，否则它只是一个候选。</span>

#### 7.4 续（b）

**(b)** 我们证明函数

```math
f(R) = -\log\det R - \operatorname{tr}(R^{-1}Y)
```

在 $0 \prec R \preceq 2Y$ 上关于 $R$ 凹。这就建立了 log-likelihood 的凹性，因为 $l$ 剩下的那一项关于 $a$ 与 $R$ 是凹的。

$f$ 的梯度与 Hessian 为

```math
\nabla f(R) = -R^{-1} + R^{-1} Y R^{-1},
```

```math
\nabla^2 f(R)[V] = R^{-1} V R^{-1} - R^{-1} V R^{-1} Y R^{-1} - R^{-1} Y R^{-1} V R^{-1},
```

这里 $\nabla^2 f(R)[V]$ 指

```math
\nabla^2 f(R)[V] = \left.\frac{d}{dt}\nabla f(R+tV)\right|_{t=0}.
```

我们证明对一切 $V$ 有

```math
\operatorname{tr}\left(V \nabla^2 f(R)[V]\right) = \left.\frac{d^2}{dt^2} f(R+tV)\right|_{t=0} \le 0 .
```

计算：

```math
\operatorname{tr}\left(V\nabla^2 f(R)[V]\right) = \operatorname{tr}(V R^{-1} V R^{-1}) - 2\operatorname{tr}(V R^{-1} V R^{-1} Y R^{-1})
```

```math
= \operatorname{tr}\left(\left(R^{-1/2} V R^{-1/2}\right)^2 \left(I - 2 R^{-1/2} Y R^{-1/2}\right)\right) \le 0
```

对一切 $V$ 成立，只要

```math
2 R^{-1/2} Y R^{-1/2} \succeq I,
```

也就是 $R \preceq 2Y$。

<span style="color:#1e8449;">**[译注]** 凹性区域 $R \preceq 2Y$ 不是猜的，是从 Hessian 里**读出来的**：把方向二阶导写成 $\operatorname{tr}(W^2 S)$，其中 $W = R^{-1/2}VR^{-1/2}$ 对称、$S = I - 2M$、$M = R^{-1/2}YR^{-1/2}$。由于 $W^2 \succeq 0$，只要 $S \preceq 0$ 就整项 $\le 0$，而 $S \preceq 0 \iff M \succeq \frac{1}{2}I \iff R \preceq 2Y$。**消失测试**：没有这条界，7.4(b) 的「同时估计 $R$ 与 $a$」就不能整体交给 convex solver —— 求解器会在 $R \succ 2Y$ 的非凹区给出伪驻点，表现为迭代目标值先升后降。**量的方向感**：以 $Y=1$、$n=1$ 为例，$S = 1 - 2/R$，可行区是 $R \le 2$；取 $R=2.5$（**故意避开 $R=1$**，那里 $S=-1$ 会让「凹」这个性质在任何 $Y$ 下都成立，看不出界的作用），$S = 0.2 \gt 0$，二阶导翻正，$f$ 变凸。**落点**：Boyd §7.4、§3.1.4（LMI 形式的约束）、exercise 7.4 本身；Strang 线代侧的挂载点是「二次型 $v^T H v$ 的符号由 $H$ 的谱决定」——这里 $H$ 是定义在矩阵空间上的算子，$V$ 是它的自变量。 **注意区域边界**：$R = 2Y$ 处 $S = 0$，Hessian 半负定而不满负定，$f$ 是凹但非严格凹 —— 这意味着最优解可能不唯一，求解器返回的可能是最优点集上的任意一点。</span>

### Exercise 7.5 Markov 链的估计

**7.5 Markov chain estimation.** Consider a Markov chain with $n$ states, and transition probability matrix $P \in \mathbf{R}^{n \times n}$ defined as

```math
P_{ij} = \mathbf{prob}(y(t+1)=i \mid y(t)=j), \qquad \sum_{i=1}^{n} P_{ij} = 1, \quad j = 1,\dots,n .
```

The transition probabilities must satisfy $P_{ij} \ge 0$. We consider the problem of estimating the transition probabilities, given an observed sample sequence $y(1)=k_1, y(2)=k_2, \dots, y(N)=k_N$.

**(a)** Show that if there are no other prior constraints on $P_{ij}$, then the ML estimates are the empirical transition frequencies: $\hat P_{ij}$ is the ratio of the number of times the state transitioned from $j$ into $i$, divided by the number of times it was $j$, in the observed sample.

**(b)** Suppose that an equilibrium distribution $p$ of the Markov chain is known, i.e., a vector $q \in \mathbf{R}^n_+$ satisfying $\mathbf{1}^T q = 1$ and $Pq = q$. Show that the problem of computing the ML estimate of $P$, given the observed sequence and knowledge of $q$, can be expressed as a convex optimization problem.

**中文话题**：Markov 链的 ML 就是数转移次数；加一条「稳态分布已知」的线性约束后仍然凸。

**† 原文错误（7.5 题干）**：序列末项写作 $y(N)=k_n$，应为 $y(N)=k_N$。$n$ 是状态数、$N$ 是序列长度，两个独立参数；把末项下标写成 $n$ 后，序列概率的最后一项 $P_{k_N,k_{N-1}}$ 无法写出，$N \ne n$ 时直接指向不存在的 $k_n$。**为什么会写错**：$k$ 的下标本该跟时间步 $t$，而 $n$ 在本题里到处都是「状态维数」，眼睛扫到行尾时把两个字母的语义合并了。数值反例：$n=3$（状态）、$N=5$（观测 5 步），原式只给出 $k_1,k_2,k_3$ 三个值却要乘 4 次转移。

#### 解答

**(a)** 给定起点 $y(1)$，序列 $y(2),\dots,y(N)$ 的概率是

```math
P_{k_2,k_1} P_{k_3,k_2} \cdots P_{k_N,k_{N-1}} = \prod_{i,j=1}^{n} P_{ij}^{\,c_{ij}},
```

其中 $c_{ij}$ 是状态从 $j$ 转移到 $i$ 的次数。于是 ML 估计问题为

```math
\begin{aligned}
\text{maximize} \quad & \sum_{i,j=1}^{n} c_{ij}\log P_{ij} \\
\text{subject to} \quad & \mathbf{1}^T P = \mathbf{1}^T .
\end{aligned}
```

这个问题**可分**，可以一列一列地解。令 $p_j = (P_{1j},\dots,P_{nj})$ 为 $P$ 的第 $j$ 列，它是

```math
\begin{aligned}
\text{maximize} \quad & \sum_{i=1}^{n} c_{ij}\log p_{ij} \\
\text{subject to} \quad & \mathbf{1}^T p_j = 1
\end{aligned}
```

的解。用 Lagrange 乘子可得

```math
P_{ij} = \frac{c_{ij}}{\sum_{i=1}^{n} c_{ij}} .
```

**(b)** ML 估计问题是

```math
\begin{aligned}
\text{maximize} \quad & \sum_{i,j=1}^{n} c_{ij}\log P_{ij} \\
\text{subject to} \quad & \mathbf{1}^T P = \mathbf{1}^T \\
& Pq = q .
\end{aligned}
```

目标函数是 $\log$ 的加权和，故凹；两条约束均为线性；再加上隐含的 $P \succeq 0$（$\log$ 的定义域），这就是一个凸优化问题。

<span style="color:#1e8449;">**[译注]** 「可分」两个字是本题全部计算量的来源。$P$ 有 $n^2$ 个变量、$n$ 条归一约束，看上去要在 $n$ 个单纯形的乘积（维数 $n(n-1)$）上做投影；按列拆开后，每一列只是一个 $n$ 维单纯形上的凹最大化，闭式解 $\hat P_{ij} = c_{ij}/c_{\cdot j}$ 立刻得到。**消失测试**：不做分解，就得在 $n \times n$ 的矩阵上跑一次约束优化，规模 $O(n^3)$ 每次迭代；分解后是 $n$ 个 $O(n)$ 的子问题，且每列有闭式。**数值**：$n=2$、观测序列 $y=(1,2,2,1)$，则 $c_{12}=1$、$c_{22}=1$、$c_{21}=1$、$c_{11}=0$；第 1 列和 $=1$ 给出 $(P_{11},P_{21})=(0,1)$，第 2 列和 $=2$ 给出 $(P_{12},P_{22})=(1/2,1/2)$。**落点**：Boyd §7.4（本节其余 ML 例题同构）、exercise 7.5；注意 (b) 里加上 $Pq=q$ 后**可分性被破坏**（同一行跨列耦合），这正是 (b) 只能给凸形式、拿不到闭式解的原因。 **一个副产品**：分解还说明每条「列和等于 1」的约束彼此**独立**，因此行随机的版本（约束换成 $P\mathbf{1} = \mathbf{1}$）同样可分，只是改成按行做。</span>

<span style="color:#1e8449;">**[译注]** (b) 值得单独说一句：很多人以为「加了约束就变难」，这里的机制恰好相反 —— 约束 $Pq=q$ 是**线性**的，它把可行集从「$n$ 个独立单纯形的乘积」切成交集，仍然是凸集；而目标函数 $\sum c_{ij}\log P_{ij}$ 是凹的（每一项都是凹的，凹函数之和仍凹）。**消失了会怎样**：如果先解 (a) 的无约束 ML 再「投影」到 $\{P: Pq=q\}$，得到的矩阵一般**不是** ML 估计 —— 距离投影与似然投影不一致，且投影后可能不再满足 $\mathbf{1}^TP=\mathbf{1}^T$（两个约束的投影不交换）。**量的方向感**：无约束解只需 $O(n^2)$ 次计数；带约束解需要一次 $n^2$ 变量的凸求解，迭代复杂度至少 $O(n^3)$ 每步，$n=100$ 时是 $10^6$ 对 $10^6$ 的同量级但失去闭式。**落点**：Boyd §7.4、§7.5(b)、§4.2.1；这个「线性约束 + 对数似然 = 凸」的模式在 §7.7（Poisson）与 §7.8（sign measurement）里反复出现，可当模板记。 **量的补充**：若真按「先解无约束再投影」来办，投影后的似然与真正最优似然之比在最坏情形可以掉到很低，实践中表现为拟合出的转移概率把小概率事件压成 0，随后预测立刻发散。</span>

### Exercise 7.6 均值与方差的估计

**7.6 Estimation of mean and variance.** Consider a random variable $x \in \mathbf{R}$ with density $p$, which is normalized, i.e., has zero mean and unit variance. Consider a random variable $y = (x+b)/a$ obtained by an affine transformation of $x$, where $a \gt 0$. The random variable $y$ has mean $b$ and variance $1/a^2$. As $a$ and $b$ vary over $\mathbf{R}_+$ and $\mathbf{R}$, respectively, we generate a family of densities obtained from $p$ by scaling and shifting, uniquely parametrized by mean and variance.

Show that if $p$ is log-concave, then finding the ML estimate of $a$ and $b$, given samples $y_1,\dots,y_n$ of $y$, is a convex problem.

As an example, work out an analytical solution for the ML estimates of $a$ and $b$, assuming $p$ is a normalized Laplacian density, $p(x) = e^{-2|x|}$.

**中文话题**：位置-尺度族（location-scale family）的 ML 估计在「标准化密度 log-concave」时是凸问题；Laplace 情形还能写出闭式。

**† 原文错误一（7.6 题干，均值）**：$y=(x+b)/a$ 且 $x$ 零均值时，$\mathbf{E} y = b/a$，不是 $b$。正确关系是：若要求均值恰为 $b$、方差为 $1/a^2$，变换必须写成 $y = x/a + b$（等价于 $y=(x+ab)/a$）。**为什么会写错**：作者把「加性偏移 $b$」和「分母里的 $a$」写在同一个分式的两侧，心里想的量是 $\mathbf{E}y$，手上写的是 $y$ 的表达式 —— 分子里的 $b$ 被当成「均值参数」，实际上它被 $a$ 又除了一次。**数值反例**：取 $a=2$、$b=1$，$x$ 零均值单位方差，则 $\mathbf{E} y = 0.5 \ne 1$，$\operatorname{Var} y = 1/4 = 1/a^2$（方差这一半是对的）。**佐证**：本页给出的密度式 $p_y(u) = a\,p(au-b)$ 只有按 $y=(x+b)/a$ 才对（$x = ay-b$，$dx/dy = a$），所以是**文字描述**与**公式**打架，公式站队 $y=(x+b)/a$，则 $\mathbf{E}y = b/a$。下文解答按公式走，故把 $b$ 读作「$a$ 倍均值」即可，全部推导不受影响。

**† 原文错误二（7.6 题干，Laplace 密度）**：$p(x)=e^{-2|x|}$ 满足 $\int p = 1$，但**方差是 $1/2$，不是 $1$**。正确写法是 $p(x) = \frac{1}{\sqrt{2}}e^{-\sqrt{2}|x|}$。**为什么会写错**：作者只核了归一化（$\int e^{-2|x|}\,dx = 2 \cdot \frac{1}{2} = 1$ ✓），漏了二阶矩；而题干自己在第一句就把 normalized 定义为「零均值、单位方差」，所以这里与自身定义冲突。**数值反例**：$\int_{-\infty}^{\infty} x^2 e^{-2|x|}dx = 2\int_0^\infty x^2 e^{-2x}dx = 2\cdot\frac{2}{2^3} = \frac{1}{2}$。这不是无关紧要的常数：它会让「$a$ 的估计量」带上 $\sqrt{2}$ 的系统偏差 —— 用 $e^{-2|x|}$ 拟合出的 $\hat a$ 与真值差一个 $\sqrt{2}$ 倍。

#### 解答

$y$ 的密度为

```math
p_y(u) = a\, p(au-b).
```

log-likelihood 为

```math
\log p_y(u) = \log a + \log p(au-b).
```

若 $p$ 是 log-concave，则这个 log-likelihood 是 $a$ 与 $b$ 的凹函数，于是可以计算「标准化密度为 log-concave」的随机变量的均值与方差之 ML 估计。

设 $y_1,\dots,y_n$ 抽自该分布。为求参数 $a$、$b$ 的 ML 估计，极大化凹函数

```math
\sum_{i=1}^{n} p_y(y_i) = n\log a + \sum_{i=1}^{n}\log p(a y_i - b).
```

对 Laplace 分布得到

```math
\sum_{i=1}^{n} p_y(y_i) = n\log a - 2\sum_{i=1}^{n}|a y_i - b|,
```

因此 ML 估计求解

```math
\text{minimize} \quad -n\log a + 2\sum_{i=1}^{n}|a y_i - b| .
```

定义 $c = b/a$，问题化为

```math
\text{minimize} \quad -n\log a + 2a\sum_{i=1}^{n}|y_i - c| .
```

<span style="color:#1e8449;">**[译注]** 凸性来自一条极简的复合规则：**凹函数与仿射映射复合仍是凹的**。这里 $\log p$ 凹，而 $(a,b) \mapsto a y_i - b$ 是 $(a,b)$ 的**仿射**函数（每固定一个样本 $y_i$，它就是平面上的一个线性函数），所以 $\log p(a y_i - b)$ 关于 $(a,b)$ 凹；再加上 $\log a$ 在 $a \gt 0$ 上凹，$n$ 项相加仍凹。**消失测试**：把 $p$ 换成双峰密度（如两个 Gaussians 的混合），$\log p$ 不再凹，目标出现两个局部极大 —— ML 变成非凸，梯度法只能落到其中一个峰，「$a$ 与 $b$ 的联合最大」不再可靠。**量的方向感**：凹性把「$n$ 个样本 × 2 个参数」的搜索问题从「需全局搜索、复杂度随初值恶化」降到「单次凸求解、对初值免疫」；反过来说，缺了 log-concavity，即使 $n$ 只有 50，也可能需要多起点重启才能找到全局最优。**落点**：Boyd §3.2.4（复合规则）、§3.5.1（log-concave 密度的定义与封闭性）、§7.1；挂到 Thomson 实分析的节点上是「凹函数的定义只需要沿线段的中值不等式」，而仿射映射把直线映成直线，所以中值不等式原样传下去。**注意** $\log p(au-b)$ 关于 $u$ 也是 log-concave（同一规则），这正是原文「$p_y$ 本身 log-concave」的用法。</span>

#### 7.6 续（闭式解）

解 $c$ 是 $y_i$ 的中位数。$a$ 由令导数为零求出：

```math
a = \frac{n}{2\sum_{i=1}^{n}|y_i-c|}.
```

<span style="color:#1e8449;">**[译注]** 这里「先定 $c=b/a$、再解 $a$」的两步法**看起来可疑，实则是合法的** —— 我第一遍复算时判过它「漏了联合最优」，错了。正确论证用 **profile likelihood**（剖面似然）：固定 $c$ 时 $a$ 的最优值是 $\hat a(c) = n/(2S(c))$，其中 $S(c)=\sum_i|y_i-c|$；代回目标得剖面值

```math
-n\log\frac{n}{2S} + 2\cdot\frac{n}{2S}\cdot S = n\log\frac{2S}{n} + n,
```

### Exercise 7.7 Poisson 分布的 ML 估计

**7.7 ML estimation of Poisson distributions.** Suppose $x_i$, $i=1,\dots,n$, are independent random variables with Poisson distributions

```math
\mathbf{prob}(x_i=k) = \frac{e^{-\mu_i}\mu_i^k}{k!},
```

with unknown means $\mu_i$. The variables $x_i$ represent the number of times that one of $n$ possible independent events occurs during a certain period. In emission tomography, for example, they might represent the number of photons emitted by $n$ sources.

We consider an experiment designed to determine the means $\mu_i$. The experiment involves $m$ detectors. If event $i$ occurs, it is detected by detector $j$ with probability $p_{ji}$. We assume the probabilities $p_{ji}$ are given (with $p_{ji} \ge 0$, $\sum_{j=1}^{m} p_{ji} \le 1$). The total number of events recorded by detector $j$ is denoted $y_j$,

```math
y_j = \sum_{i=1}^{n} y_{ji}, \qquad j = 1,\dots,m .
```

Formulate the ML estimation problem of estimating the means $\mu_i$, based on observed values of $y_j$, $j=1,\dots,m$, as a convex optimization problem.

**Hint.** The variables $y_{ji}$ have Poisson distributions with means $p_{ji}\mu_i$, i.e.,

```math
\mathbf{prob}(y_{ji}=k) = \frac{e^{-p_{ji}\mu_i}(p_{ji}\mu_i)^k}{k!}.
```

The sum of $n$ independent Poisson variables with means $\lambda_1,\dots,\lambda_n$ has a Poisson distribution with mean $\lambda_1+\cdots+\lambda_n$.

**中文话题**：发射断层成像（emission tomography）的计数模型 —— 「稀疏 Poisson + thinning + 可加性」三步把 $n$ 个未知均值压成 $m$ 条 $\log$ 和的凹目标。

#### 解答

由两个 hint 可知 $y_j$ 服从均值为

```math
\sum_{i=1}^{n} p_{ji}\mu_i = p_j^T\mu
```

的 Poisson 分布。因此

```math
\log\left(\mathbf{prob}(y_j=k)\right) = -p_j^T\mu + k\log\left(p_j^T\mu\right) - \log k! .
```

设 $y_j$ 的观测值为 $k_j$，$j=1,\dots,m$（**† 原文此处误写 $j=1,\dots,n$，见下条**）。则 ML 估计问题为

```math
\begin{aligned}
\text{maximize} \quad & -\sum_{j=1}^{m} p_j^T\mu + \sum_{j=1}^{m} k_j\log\left(p_j^T\mu\right) \\
\text{subject to} \quad & \mu \succeq 0,
\end{aligned}
```

它是 $\mu$ 的凹最大化问题，即凸问题。

**† 原文错误（7.7 解答中的指标范围）**：观测值写成「$y_j$ 的观测值为 $k_j$，$j=1,\dots,n$」，应为 $j = 1,\dots,m$。$j$ 是**探测器**下标，共 $m$ 个；$n$ 是**事件源**下标，属于 $i$。**为什么会写错**：题干里 $i=1,\dots,n$ 出现得比 $j=1,\dots,m$ 频繁（$n$ 个源是问题的主角），写解答时顺着「刚才那个 $n$」滑了过去。**数值反例**：$n=50$ 个源、$m=4$ 个探测器。原式只读入 $k_1,k_2,k_3,k_4$ 中的前… 不，原式要求给到 $k_{50}$，而探测器只输出 4 个数 —— 直接读越界；反过来若 $m \gt n$（如 $n=2$、$m=6$），原式只用了 2 个探测器的数据，其余 4 个探测器的观测被静默丢弃，ML 解虽仍可行但用错了数据量。

**† 原文表述瑕疵（同一行）**：原文紧接着写「which is convex in $\mu$」。严格说目标函数是**凹**的，问题才是凸的。这不影响任何推导（凸问题的定义是「极小化凸函数」或「极大化凹函数」），只是把「函数性质」与「问题性质」两个词混用；下文译作「凹最大化问题，即凸问题」。

```math
\mathbf{prob}(x=k) = \frac{e^{-\mu}\mu^k}{k!} = \lim_{n\to\infty,\; nq\to\mu} \binom{n}{k}q^k(1-q)^{n-k},
```

也就是说，可以把 $x$ 想成 $n$ 次 Bernoulli 试验（每试验成功概率 $q=\mu/n$）中的成功总数。

<span style="color:#1e8449;">**[译注]** 这套建模的关键不是 Poisson，而是 **thinning**：一个源发出的事件以概率 $p_{ji}$ 落到探测器 $j$，则探测器看到的仍是 Poisson，均值从 $\mu_i$ 变成 $p_{ji}\mu_i$。**消失测试**：若漏掉 thinning，直接用 $y_j \sim \text{Poisson}(\sum_i \mu_i)$（所有探测器均值相同），模型无法分辨各源的强度，ML 给不出唯一解（只有总和可观）—— 这正是本题必须写 $p_j^T\mu$ 而不能写常数的原因。**量的方向感**：数据维度从 $n$ 个源的完整计数 $(x_1,\dots,x_n)$ 压到 $m$ 个探测器计数，当 $m \lt n$ 时是**欠定**问题；凸形式并不能凭空补信息，它只保证「不引入额外伪解」。**数值**：$n=2$、$m=1$、$p_{11}=p_{12}=1/2$、观测 $k_1=10$，则 $10 = \frac{1}{2}(\mu_1+\mu_2)$ 只约束和；任何 $(\mu_1,\mu_2)$ 满足 $\mu_1+\mu_2=20$ 都是 ML 解（似然相同），解集是一条线段，不是单点。**落点**：Boyd exercise 7.7、§7.1.2（Poisson 的 ML）、§3.5.1；与 CSAPP 侧的挂载点是「计数器聚合会丢信息」，这里把「丢多少信息」量化成了「解集维数 $n-\operatorname{rank}(P)$」。 **建模检查表**：若允许「一个事件被多个探测器同时记录」（$p$ 的列和可以大于 1），thinning 仍成立（各探测器独立抽样），只是 $\sum_j p_{ji} \le 1$ 这条假设要放宽。</span>

### Exercise 7.8 用符号测量做估计

**7.8 Estimation using sign measurements.** We consider the measurement setup

```math
y_i = \operatorname{sign}(a_i^T x + b_i + v_i), \qquad i = 1,\dots,m,
```

where $x \in \mathbf{R}^n$ is the vector to be estimated, and $y_i \in \{-1,1\}$ are the measurements. The vectors $a_i \in \mathbf{R}^n$ and scalars $b_i \in \mathbf{R}$ are known, and $v_i$ are IID noises with a log-concave probability density. (You can assume that $a_i^T x + b_i + v_i = 0$ does not occur.) Show that maximum likelihood estimation of $x$ is a convex optimization problem.

**中文话题**：1-bit 量化观测（probit 型模型）的 ML 是凸问题，全部靠「log-concave 密度的积分仍 log-concave」。

#### 解答

我们把观测重新排序，使 $y_i = 1$ 对应 $i=1,\dots,k$，$y_i = -1$ 对应 $i=k+1,\dots,m$（**† 原文此处误写 $y_i=0$，见下条**）。这一事件的概率为

```math
\prod_{i=1}^{k}\mathbf{prob}(a_i^T x + b_i + v_i \gt 0)\cdot \prod_{i=k+1}^{m}\mathbf{prob}(a_i^T x + b_i + v_i \lt 0)
```

```math
= \prod_{i=1}^{k} F(-a_i^T x - b_i)\cdot \prod_{i=k+1}^{m}\left(1 - F(-a_i^T x - b_i)\right),
```

其中 $F$ 是噪声密度的累积分布。log-concave 函数的积分仍 log-concave，故 $F$ 是 log-concave，$1-F$ 也是。于是 log-likelihood 为

```math
l(x) = \sum_{i=1}^{k}\log F(-a_i^T x - b_i) + \sum_{i=k+1}^{m}\log\left(1 - F(-a_i^T x - b_i)\right),
```

它是凹的。因此极大化它就是凸问题。

**† 原文错误（7.8 解答，观测取值）**：重排后的第二组写成 $y_i = 0$ 对应 $i=k+1,\dots,m$，应为 $y_i = -1$。题干已把测量值域定死为 $y_i \in \{-1,1\}$，$0$ 不在值域内。**为什么会写错**：把「$y_i=1$ 的对立面」当成「$y_i=0$ 的对立面」—— 这是把逻辑命题的真假（$1/0$）与符号编码（$+1/-1$）混了；同一个段落里紧接着写的事件是 $a_i^Tx+b_i+v_i \lt 0$（负号侧），说明作者心里的集合没错，只是标签写成 0。**数值反例**：$m=4$、观测为 $(1,-1,1,-1)$，按原式应写成「$y=(1,1,0,0)$」—— 与题干的 $\{-1,1\}$ 值域直接冲突；若下游代码按 $y_i=0$ 判分支，第三条与第四条观测会被判成「符号不确定」而丢进错误的似然因子（$F$ 用错方向），$x$ 的估计整体偏移。**影响范围**：只在标签，式子本身（用 $\lt 0$ 事件）是对的，故结论「凸」不受影响。

<span style="color:#1e8449;">**[译注]** 本题的全部技术含量在「$F$ 与 $1-F$ 都 log-concave」这一句，它是 **Prékopa 定理**的连续版本：log-concave 函数沿某个方向的积分仍是 log-concave。$F(u)=\int_{-\infty}^{u}p(v)dv$ 是对 $p$ 的一次积分，$1-F(u)=\int_{u}^{\infty}p(v)dv$ 也是对 $p$ 的积分（沿相反方向），两者都继承 log-concavity。**消失测试**：删掉这条性质，probit 型 ML 立刻变成非凸问题 —— 因为 $1-F$ 若只是单调递减（例如重尾的 Cauchy 或 Student-$t$ 噪声），$-\log(1-F(u))$ 不再凸，负侧样本会造出第二个局部极大，梯度法从 $x=0$ 出发会停在错误一侧。**量的方向感**：log-concavity 把每个约束从「$m$ 个非线性不等式，需全局搜索」降到「一条凹约束，局部最优即全局最优」；对 $m=10^4$ 的 1-bit 传感阵列，这是「能否在线求解」的分界。**落点**：Boyd §3.5.1（log-concave 的积分封闭性）、exercise 7.8、§7.1.1；挂到 Thomson 实分析的节点上是「单调有界函数的积分」与「凸性在积分下保持」，不需要任何测度论术语。 **桥接提示**：$F$ 的 log-concavity 在离散实现里等价于「$F$ 的对数差分序列仍单调」，这条可以在一维数组上直接验证，不需要任何概率论工具。</span>

### Exercise 7.9 传感器非线性未知时的估计

**7.9 Estimation with unknown sensor nonlinearity.** We consider the measurement setup

```math
y_i = f(a_i^T x + b_i + v_i), \qquad i = 1,\dots,m,
```

where $x \in \mathbf{R}^n$ is the vector to be estimated, $y_i \in \mathbf{R}$ are the measurements, $a_i \in \mathbf{R}^n$, $b_i \in \mathbf{R}$ are known, and $v_i$ are IID noises with log-concave probability density. The function $f : \mathbf{R} \to \mathbf{R}$, which represents a measurement nonlinearity, is not known. However, it is known that $f'(t) \in [l,u]$ for all $t$, where $0 \lt l \lt u$ are given.

#### 7.9 续（解答）

解释如何用凸优化求 $x$ 与函数 $f$ 的 maximum likelihood 估计。（这是一个无穷维 ML 估计问题，但你的处理与解释可以是非正式的。）

**解答** 对固定的函数 $f$ 与向量 $x$，我们观测到 $y_1,\dots,y_m$ 当且仅当

```math
f^{-1}(y_i) - a_i^T x - b_i = v_i, \qquad i = 1,\dots,m .
```

（注意 $0 \lt l \lt u$ 蕴含 $f$ 可逆。）于是观测到 $y_1,\dots,y_m$ 的概率为

```math
\prod_{i=1}^{m} p_v\left(f^{-1}(y_i) - a_i^T x - b_i\right).
```

取对数，视作 $x$ 与函数 $f$ 的函数，即得 log-likelihood：

```math
l(x,f) = \sum_{i=1}^{m}\log p_v\left(z_i - a_i^T x - b_i\right),
```

其中 $z_i = f^{-1}(y_i)$。这是 $z$ 与 $x$ 的凹函数。

函数 $f$ 只通过那些数 $z_i$ 影响 log-likelihood。约束可以用反函数表述为

```math
\frac{d}{dt}f^{-1}(t) \in [1/u,\, 1/l],
```

于是得到

```math
\frac{1}{u}|y_i - y_j| \le |z_i - z_j| \le \frac{1}{l}|y_i - y_j|
```

对一切 $i,j$ 成立。反过来，若这些不等式成立，则存在满足条件的函数 $f$，且 $f^{-1}(y_i)=z_i$。（其实这一点只在极限意义下成立，这里不做严格处理。）

因此，求 ML 估计的办法是：极大化上面那个关于 $x$ 与 $z$ 的凹函数，约束为 $z$ 上的这些线性不等式。

<span style="color:#1e8449;">**[译注]** 这是全节最漂亮的一次「无穷维 → 有限维」压缩。原始的未知量是一个**函数** $f$（无穷维），但 $f$ 只通过 $m$ 个点值 $z_i=f^{-1}(y_i)$ 进入似然，于是「优化 $f$」被替换成「优化 $m$ 个实数 $z_i$」，无穷维消失。**消失测试**：若不做这个替换，问题没有可写的算法形式 —— 你无法对「所有 $C^1$ 函数」做数值搜索；替换后是一个 $n+m$ 变量的凸问题，直接可解。**关键的第二把刀**是 $f' \in [l,u]$ 与 $f^{-1}$ 导数的关系：由反函数求导，$(f^{-1})'(t) = 1/f'(f^{-1}(t)) \in [1/u,\,1/l]$，再对每对 $(i,j)$ 用中值定理就得到双侧 Lipschitz 带。**数值**：取 $l=1$、$u=2$，观测 $y_1=0$、$y_2=1$，则 $|z_1-z_2| \in [0.5,\,1]$ —— 带宽恰好是上下界之比的倒数。**落点**：Boyd exercise 7.9、§6.5.1（单调回归里同样的「用差分约束代替函数」技巧）、§7.1.1。注意原文诚实标注「这只在极限意义下成立」，因为任意给定的 $(y_i,z_i)$ 对可能不满足单调性（需要 $y_i \lt y_j \Rightarrow z_i \le z_j$）—— 这个隐含前提原文没写，属小瑕疵，已收入文末表。 **注意**：替换之后 $z$ 与 $x$ 是**同时**优化的，这一点很关键 —— 先定 $f$ 再估 $x$（或反过来）都会落到局部解，因为两步各自的最优并不构成联合最优。</span>

### Exercise 7.10 $\mathbf{R}^k$ 上的非参数分布

**7.10 Nonparametric distributions on $\mathbf{R}^k$.** We consider a random variable $x \in \mathbf{R}^k$ with values in a finite set $\{\alpha_1,\dots,\alpha_n\}$, and with distribution

```math
p_i = \mathbf{prob}(x = \alpha_i), \qquad i = 1,\dots,n .
```

Show that a lower bound on the covariance of $X$,

```math
S \preceq \mathbf{E}(X - \mathbf{E}X)(X - \mathbf{E}X)^T,
```

is a convex constraint in $p$.

**中文话题**：协方差矩阵的下界 $S$ 作为概率向量 $p$ 的约束是凸的 —— 因为「协方差」关于 $p$ 是凹的。

#### 解答

```math
\mathbf{E}(X-\mathbf{E}X)(X-\mathbf{E}X)^T = \sum_{i=1}^{n} p_i\alpha_i\alpha_i^T - \left(\sum_{i=1}^{n}p_i\alpha_i\right)\left(\sum_{i=1}^{n}p_i\alpha_i\right)^T \succeq S
```

当且仅当

```math
\begin{bmatrix}
\sum_{i=1}^{n} p_i\alpha_i\alpha_i^T - S & \sum_{i=1}^{n} p_i\alpha_i \\\\
\left(\sum_{i=1}^{n} p_i\alpha_i\right)^T & 1
\end{bmatrix} \succeq 0 .
```

<span style="color:#1e8449;">**[译注]** 这里的两步各有一个「为什么恰好成立」：**第一步**是协方差的 Minkowski 结构 —— $\operatorname{Cov}(p) = \sum_i p_i\alpha_i\alpha_i^T - m(p)m(p)^T$，第一项关于 $p$ 线性，第二项是 $m(p)m(p)^T$ 取负号；$m(p)$ 是 $p$ 的仿射函数，$vv^T$ 关于 $v$ 凸（对每个固定向量 $w$，$w^Tvv^Tw=\lVert w^Tv\rVert^2$ 是 $v$ 的凸函数），所以 $m m^T$ 凸、$-mm^T$ 凹。线性加凹仍凹，故 $\{\operatorname{Cov}(p) \succeq S\}$ 是凹函数的**上水平集**，是凸集。**第二步**是把矩阵不等式换成 $2\times 2$ 分块矩阵的 PSD —— Schur 补，条件恰好是右下角块 $1 \gt 0$。**消失测试**：不做这一步，$\operatorname{Cov}(p) \succeq S$ 是「矩阵变量的半定约束」，虽仍凸，但不能直接投喂线性锥求解器；化成分块 PSD 后可用 SDP 标准形。**数值**：$k=1$、$\alpha=(0,2)$、$p=(1/2,1/2)$，则 $m=1$、$\operatorname{Cov} = 2-1 = 1$，故 $S=0.9$ 可行、$S=1.1$ 不可行；取 $p=(1,0)$ 时 $\operatorname{Cov}=0$，$S=0.9$ 立刻不可行 —— 可见这个约束真的在限制「分布的散布」。**落点**：Boyd §2.2.5（Cov 的凹性）、§A.5.5（Schur 补）、exercise 7.10。 **一个容易忽略的点**：Schur 补那一跳要求右下块 $1 \gt 0$；换成 $\mathbf{1}^T\mathbf{1} = n$ 也成立，只是整块要除以 $n$ 重新缩放，结论不变。</span>

### Exercise 7.11 随机化检测器

**7.11 Randomized detectors.** Show that every randomized detector can be expressed as a convex combination of a set of deterministic detectors: If

```math
T = \begin{bmatrix} t_1 & t_2 & \cdots & t_n \end{bmatrix} \in \mathbf{R}^{m \times n}
```

satisfies $t_k \succeq 0$ and $\mathbf{1}^T t_k = 1$, then $T$ can be expressed as

```math
T = \theta_1 T_1 + \cdots + \theta_N T_N,
```

where $T_i$ is a zero-one matrix with exactly one element equal to one per column, and $\theta_i \ge 0$, $\sum_{i=1}^{N}\theta_i = 1$. What is the maximum number of deterministic detectors $N$ we may need?

We can interpret this convex decomposition as follows. The randomized detector can be realized as a bank of $N$ deterministic detectors. When we observe $X=k$, the estimator chooses a random index from the set $\{1,\dots,N\}$, with probability $\mathbf{prob}(j=i)=\theta_i$, and then uses deterministic detector $T_j$.

**中文话题**：随机化的 $T$（每列是概率向量）等于若干「确定性 $0/1$ 矩阵」的凸组合；数量上界是仿射维数加一，即 $n(m-1)+1$。

#### 解答

检测器 $T$ 可以如下表示成确定性检测器的凸组合：

```math
T = \sum_{i_1=1}^{m}\sum_{i_2=1}^{m}\cdots\sum_{i_n=1}^{m}\theta_{i_1,i_2,\dots,i_n}\begin{bmatrix} e_{i_1} & e_{i_2} & \cdots & e_{i_n}\end{bmatrix},
```

其中

```math
\theta_{i_1,i_2,\dots,i_n} = t_{i_1,1}t_{i_2,2}\cdots t_{i_n,n}.
```

为看出这一点，注意

```math
\sum_{i_1=1}^{m}\sum_{i_2=1}^{m}\cdots\sum_{i_n=1}^{m}\theta_{i_1,i_2,\dots,i_n}\begin{bmatrix} e_{i_1} & e_{i_2} & \cdots & e_{i_n}\end{bmatrix}
```

```math
= \sum_{i_n=1}^{m}\cdots\sum_{i_2=1}^{m}\left(t_{i_n,n}\cdots t_{i_2,2}\right)\sum_{i_1=1}^{m} t_{i_1,1}\begin{bmatrix} e_{i_1} & e_{i_2} & \cdots & e_{i_n}\end{bmatrix}
```

```math
= \sum_{i_n=1}^{m}\cdots\sum_{i_2=1}^{m}\left(t_{i_n,n}\cdots t_{i_2,2}\right)\begin{bmatrix} t_1 & e_{i_2} & \cdots & e_{i_n}\end{bmatrix}
```

```math
= \sum_{i_n=1}^{m}\cdots\sum_{i_3=1}^{m}\left(t_{i_n,n}\cdots t_{i_3,3}\right)\sum_{i_2=1}^{m} t_{i_2,2}\begin{bmatrix} t_1 & e_{i_2} & \cdots & e_{i_n}\end{bmatrix}
```

```math
= \sum_{i_n=1}^{m}\cdots\sum_{i_3=1}^{m}\left(t_{i_n,n}\cdots t_{i_3,3}\right)\begin{bmatrix} t_1 & t_2 & \cdots & e_{i_n}\end{bmatrix}
```

```math
\cdots
```

```math
= \sum_{i_n=1}^{m} t_{i_n,n}\begin{bmatrix} t_1 & t_2 & \cdots & t_{n-1} & e_{i_n}\end{bmatrix} = \begin{bmatrix} t_1 & t_2 & \cdots & t_{n-1} & t_n \end{bmatrix}.
```

同时显然有

```math
\sum_{i_1,i_2,\dots,i_n}\theta_{i_1,i_2,\dots,i_n} = 1 .
```

<span style="color:#1e8449;">**[译注]** 这个展开式的实质是**逐列剥离**：每一次把 $\sum_{i_k} t_{i_k,k}$ 收到一起，就用掉了该列「和为 1」这条归一化，于是 $e_{i_k}$ 被替换成真实的列 $t_k$，而剩余的系数恰好是其它列的乘积。**赏罚分明的验证手段是形状配平**：$\theta$ 有 $n$ 个下标、每个跑 $1..m$，$e_{i_k} \in \mathbf{R}^m$，$n$ 个拼起来是 $m \times n$，与 $T$ 同形 ✓；系数总和 $\prod_{k=1}^{n}\sum_{i_k}t_{i_k,k} = \prod_k 1 = 1$ ✓。**消失测试**：没有这个分解，随机化检测器只能用 $m \times n$ 个实数描述，而「确定性检测器」只有 $m^n$ 个孤立点，两者的凸关系无法显式写出 —— 随机化 detector 的「可实现性」（用确定性器件 + 随机数发生器实现）就只是口号。**量的方向感**：$\theta$ 的支撑最多 $m^n$ 个（$m=4,n=3$ 时 64 个），但下一段证明只需 $n(m-1)+1 = 10$ 个即可 —— 从 64 降到 10。**落点**：Boyd §7.3.1（randomized detector）、§2.2.4（convex hull）；挂到 6.042J 的节点上是「$m^n$ 个元组的笛卡尔积」，这里的和式就是在这个网格上做加权平均。</span>

下面的通用论证（线性规划里很熟悉）说明：每个检测器都能表示成**不超过** $n(m-1)+1$ 个确定性检测器的凸组合。

设 $v_1,\dots,v_N$ 是 $\mathbf{R}^p$ 中仿射相关（affinely dependent）的点，即

```math
\operatorname{rank}\begin{bmatrix} v_1 & v_2 & \cdots & v_N \\ 1 & 1 & \cdots & 1 \end{bmatrix} \lt N,
```

并设 $x$ 是这些点的严格凸组合：

```math
x = \theta_1 v_1 + \cdots + \theta_N v_N, \qquad 1 = \theta_1 + \cdots + \theta_N, \qquad \theta \succ 0 .
```

那么 $x$ 是其中某个子集的凸组合。为看出这一点，注意秩条件蕴含存在 $\lambda \ne 0$ 使

```math
\sum_{i=1}^{N}\lambda_i v_i = 0, \qquad \sum_{i=1}^{N}\lambda_i = 0 .
```

因此

```math
x = (\theta_1+t\lambda_1)v_1 + \cdots + (\theta_N+t\lambda_N)v_N, \qquad 1 = (\theta_1+t\lambda_1) + \cdots + (\theta_N+t\lambda_N),
```

对一切 $t$ 成立（**† 原文第二式误把 $v_i$ 又乘了一遍，见下条**）。由于 $\lambda$ 至少有一个负分量而 $\theta \succ 0$，数

```math
t_{\max} = \sup\{t \mid \theta + t\lambda \succeq 0\}
```

有限且为正。令 $\hat\theta = \theta + t_{\max}\lambda$，则

```math
x = \hat\theta_1 v_1 + \cdots + \hat\theta_N v_N, \qquad 1 = \hat\theta_1 + \cdots + \hat\theta_N, \qquad \hat\theta \succeq 0,
```

且 $\hat\theta$ 至少有一个系数为零（**† 原文此处写成 $\theta$，见下条**）。这就把 $x$ 表示成了某个子集的严格凸组合。重复这一论证，就能把 $x$ 表示成 $\{v_1,\dots,v_N\}$ 的某个**仿射无关**子集的严格凸组合。

用到检测器问题上：每个随机化检测器都能表示成仿射无关的确定性检测器的凸组合。由于全体检测器的仿射包维数为 $n(m-1)$，不可能找到多于 $n(m-1)+1$ 个仿射无关的确定性检测器。

**† 原文错误一（7.11，第二式重复粘贴）**：原文写

```math
1 = (\theta_1+t\lambda_1)v_1 + \cdots + (\theta_N+t\lambda_N)v_N ,
```

右端末尾多乘了整个向量组 —— 这句话本应是「**系数之和为 1**」，即 $1 = \sum_{i=1}^{N}(\theta_i+t\lambda_i)$。**为什么会写错**：上一行刚写完 $x=\sum(\theta_i+t\lambda_i)v_i$，复制粘贴时只改左端没删右端的 $v$；而且这个式子「看起来」也像向量等式，不容易一眼发现量纲不对。**数值反例**：取 $N=2$、$p=1$、$v_1=1$、$v_2=3$（$\mathbf{R}^1$ 中两点必仿射相关）、$\theta=(0.5,0.5)$、$\lambda=(1,-1)$（满足 $\sum\lambda_i=0$）、$t=0.1$。真值 $1 = 0.6+0.4 = 1$ ✓；原文式右端 $=0.6\times 1 + 0.4\times 3 = 1.8$，偏离 $0.8$。**影响**：推导链靠的是 $\sum\lambda_i=0$ 保证系数和恒为 1，原式写错后这一步的正确性看不出来（读者会以为需要额外条件），但结论未被破坏。

**† 原文错误二（7.11，变量遮蔽）**：原文写「at least one of the coefficients of $\theta$ is zero」，应为 $\hat\theta$。**为什么会写错**：$\hat\theta$ 是刚刚定义的「走到边界后的系数」，而 $\theta$ 是前提里那个**严格正**的向量；两者只差一个帽子，眼睛与手都容易漏。**数值反例**：前提明写 $\theta \succ 0$，例如 $\theta=(0.5,0.5)$，两个分量都非零 —— 「$\theta$ 至少一个系数为零」与已知条件**直接矛盾**，照字面读会让整段论证自毁。正确的陈述是 $\hat\theta$ 在 $t_{\max}$ 处触到边界，因而至少一个分量被推到 0（这正是「降维」发生的瞬间）。**影响**：结论（反复做可到仿射无关子集）是对的，只是这句陈述本身是错的。

<span style="color:#1e8449;">**[译注]** 这段是 **Carathéodory 定理的仿射版**，也是「取单纯形顶点最优」这类结论的几何引擎。它的机制只有一句话：**仿射相关 ⇒ 存在一条保和为零的方向 $\lambda$，沿它平移系数不改变 $x$ 与系数和，于是可以一路推到可行域的边界，直到某个分量归零**。**消失测试**：没有这个消元，检测器的凸分解需要把 $m^n$ 个确定性检测器全部枚举；有了它，$x$ 总能被压到仿射无关子集上，而仿射无关子集最多 $p+1 = n(m-1)+1$ 个。**量的方向感**：$\mathbf{R}^p$ 中仿射无关点至多 $p+1$ 个，这里 $p=n(m-1)$ 正是「$n$ 列 × 每列 $(m-1)$ 个自由度」，所以 $m=4,n=3$ 时上界 10，而原枚举空间 64 —— 降了 6.4 倍，且与 $m$ 的关系从指数 $m^n$ 变成线性 $nm$。**落点**：Boyd §2.2.4（Carathéodory）、§7.3.1；挂到 6.042J 的节点上是「线性方程组 $V\lambda=0$ 有非零解 ⟺ 列向量线性相关」，加上 $\mathbf{1}^T\lambda=0$ 就把「线性」升级成「仿射」。</span>

### Exercise 7.12 最优动作（对偶侧的检测器问题）

**7.12 Optimal action.** In detector design, we are given a matrix $P \in \mathbf{R}^{n \times m}$ (whose columns are probability distributions), and then design a matrix $T \in \mathbf{R}^{m \times n}$ (whose columns are probability distributions), so that $D = TP$ has large diagonal elements (and small off-diagonal elements). In this problem we study the dual problem: Given $P$, find a matrix $S \in \mathbf{R}^{m \times n}$ (whose columns are probability distributions), so that $\tilde D = PS$ has large diagonal elements (and small off-diagonal elements). To make the problem specific, we take the objective to be maximizing the minimum element of $\tilde D$ on the diagonal.

We can interpret this problem as follows. There are $n$ outcomes, which depend (stochastically) on which of $m$ inputs or actions we take: $P_{ij}$ is the probability that outcome $i$ occurs, given action $j$. Our goal is to find a (randomized) strategy that, to the extent possible, causes any specified outcome to occur. The strategy is given by the matrix $S$: $S_{ji}$ is the probability that we take action $j$, when we want outcome $i$ to occur. The matrix $\tilde D$ gives the action error probability matrix: $\tilde D_{ij}$ is the probability that outcome $i$ occurs, when we want outcome $j$ to occur. In particular, $\tilde D_{ii}$ is the probability that outcome $i$ occurs, when we want it to occur.

Show that this problem has a simple analytical solution. Show that (unlike the corresponding detector problem) there is always an optimal solution that is deterministic.

**Hint.** Show that the problem is separable in the columns of $S$.

**中文话题**：这是 detector design 的对偶视角 —— 给定 $P$ 求策略 $S$ 让「想要的结果」以最大概率出现；它的解是「每列取 $P$ 的最大元对应的单位向量」，故总存在确定性最优解。

#### 解答

设 $\tilde p_k^T$ 为 $P$ 的第 $k$ 行。问题于是写成

```math
\begin{aligned}
\text{maximize} \quad & \min_{k} \tilde p_k^T s_k \\
\text{subject to} \quad & s_k \succeq 0, \quad k = 1,\dots,n, \\
& \mathbf{1}^T s_k = 1, \quad k = 1,\dots,n .
\end{aligned}
```

（**† 原文此处范围误写 $k=1,\dots,m$，见下条。**）

这个问题是可分的（写成 epigraph 形式后更清楚）：我们完全可以独立地为每个 $k$ 选择 $s_k$，极大化 $\tilde p_k^T s_k$ 且满足 $s_k \succeq 0$、$\mathbf{1}^T s_k = 1$。而这很容易：取 $\tilde p_k$ 中取最大值的那个下标 $l$，令 $s_k = e_l$。

换言之，最优策略非常简单：当希望结果 $i$ 出现时，就（确定性地）选择使该结果概率最大的那个输入。

**† 原文错误（7.12，指标范围）**：约束与 $\min$ 的下标范围写作 $k = 1,\dots,m$，应为 $k = 1,\dots,n$。由题干，$P \in \mathbf{R}^{n \times m}$、$S \in \mathbf{R}^{m \times n}$，故 $S$ 有 $n$ 列，$\tilde D = PS \in \mathbf{R}^{n \times n}$ 有 $n$ 个对角元，$\tilde D_{kk} = \tilde p_k^T s_k$ 中的 $k$ 只能取 $1..n$。**为什么会写错**：$s_k$ 是 $\mathbf{R}^m$ 里的向量（长度 $m$），作者把「向量的行长 $m$」当成了「列的下标个数」；这是本 PDF 反复出现的一类漂移 —— 一个符号同时带着「长度」与「编号」两种角色。**数值反例**：$m=3$（动作）、$n=2$（结果）。真实情形是 $S \in \mathbf{R}^{3 \times 2}$、$\tilde D \in \mathbf{R}^{2 \times 2}$，只需 $s_1,s_2$ 两列。按原文取 $k=1,2,3$，则要求 $S$ 有 3 列即 $S \in \mathbf{R}^{3\times 3}$，此时 $PS \in \mathbf{R}^{2 \times 3}$ **不是方阵**，「$\tilde D$ 的对角元」根本无从定义；即便硬取前两个对角元，第三列 $s_3$ 也不对应任何目标项，纯属多余变量。**影响**：本段结论（可分 ⇒ 每列取顶点 ⇒ 确定性最优）不受影响，但照抄公式实现会在 $n \ne m$ 时直接崩掉。

<span style="color:#1e8449;">**[译注]** 为什么这里「总是存在确定性最优解」而检测器问题（7.3）却必须有随机化？差别只在**目标函数的结构**：本题目标是 $\min_k \tilde p_k^T s_k$，写成 epigraph 形式后是「$t \le \tilde p_k^T s_k$ 对每个 $k$」一组**线性**约束加上极大化 $t$ —— 线性目标在单纯形上的最优解必在**顶点**取到，而顶点就是确定性策略 $e_l$。检测器问题的目标是 $\max \operatorname{diag}(TP)$ 里的最小元，虽有同样形式，但它在 $T$ 上是**双线性**的（$T$ 与 $P$ 相乘），顶点性传不过来。**失去确定性会怎样**：若强制检测器确定性，最坏情况下的最小对角元会严格下降 —— 经典例子 $n=m=2$、$P = \begin{bmatrix} 0.9 & 0.2 \\ 0.1 & 0.8\end{bmatrix}$，确定性 $T$ 的两个选择给出 $\min$ 对角元 $0.8$ 或 $0.9$，而 $T$ 取半半混合可得 $0.85$ 附近更好的权衡（这正是 randomized detector 存在的理由）。**量的方向感**：确定性只需 $O(nm)$ 的逐行取最大值（一次扫描），随机化要解一个 $n^2 m$ 变量的 LP。**落点**：Boyd §7.3.1（detector）、§7.3.2（action 对偶）、exercise 7.12；挂到 6.006 的节点上是「线性规划最优解在顶点」，这里的顶点就是坐标向量。</span>

## Chebyshev and Chernoff bounds（Chebyshev 与 Chernoff 界）

### Exercise 7.13 有限集上的 Chebyshev 型不等式

**7.13 Chebyshev-type inequalities on a finite set.** Assume $X$ is a random variable taking values in the set $\{\alpha_1,\alpha_2,\dots,\alpha_m\}$, and let $S$ be a subset of $\{\alpha_1,\dots,\alpha_m\}$. The distribution of $X$ is unknown, but we are given the expected values of $n$ functions $f_i$:

```math
\mathbf{E} f_i(X) = b_i, \qquad i = 1,\dots,n . (7.32)
```

Show that the optimal value of the LP

```math
\begin{aligned}
\text{minimize} \quad & x_0 + \sum_{i=1}^{n} b_i x_i \\
\text{subject to} \quad & x_0 + \sum_{i=1}^{n} f_i(\alpha) x_i \ge 1, \quad \alpha \in S \\
& x_0 + \sum_{i=1}^{n} f_i(\alpha) x_i \ge 0, \quad \alpha \notin S,
\end{aligned}
```

with variables $x_0,\dots,x_n$, is an upper bound on $\mathbf{prob}(X \in S)$, valid for all distributions that satisfy (7.32). Show that there always exists a distribution that achieves the upper bound.

**中文话题**：已知若干矩，求 $\mathbf{prob}(X\in S)$ 的最坏情形上界 —— 原问题在分布上极大化，对偶正好是那个 LP，于是「界」与「见证」互为对偶。

#### 解答

$\mathbf{prob}(x \in S)$ 的最优上界是如下问题的**最优值**：

```math
\begin{aligned}
\text{maximize} \quad & \sum_{k:\,\alpha_k \in S} p_k \\
\text{subject to} \quad & \sum_{k=1}^{m} p_k = 1 \\
& \sum_{k=1}^{m} p_k f_i(\alpha_k) = b_i, \quad i = 1,\dots,n \\
& p \succeq 0 .
\end{aligned}
```

它的对偶问题是

```math
\begin{aligned}
\text{minimize} \quad & x_0 + \sum_{i=1}^{n} x_i b_i \\
\text{subject to} \quad & x_0 + \sum_{i=1}^{n} x_i f_i(\alpha) \ge 1, \quad \alpha \in S \\
& x_0 + \sum_{i=1}^{n} x_i f_i(\alpha) \ge 0, \quad \alpha \notin S .
\end{aligned}
```

对偶问题可行，故强对偶成立。又因对偶问题有下界，其最优值有限，因此原问题存在最优解。

<span style="color:#1e8449;">**[译注]** 这条 LP 的价值在于把「证明一个概率界」变成「提交一个可验证的证书」。**机制**：若你手上有一组 $(x_0,x_1,\dots,x_n)$ 满足那两条不等式，那么对任何满足 (7.32) 的分布 $p$，都有

```math
\mathbf{prob}(X\in S) = \sum_{\alpha_k\in S}p_k \le \sum_{k} p_k\left(x_0 + \sum_i x_i f_i(\alpha_k)\right) = x_0 + \sum_i x_i b_i,
```

中间那步只是因为 $\alpha\in S$ 时括号内 $\ge 1$、$\alpha\notin S$ 时 $\ge 0$ 且 $p\ge0$。**消失测试**：没有对偶，验证「某个上界成立」需要对**所有**满足矩约束的分布逐一检查（连续统个）；有了对偶，只需检查 $m$ 条线性不等式 —— 从不可枚举降到可机械验算。**量的方向感**：$m$ 个点、$n+1$ 个变量的一条 LP，与「分布空间上的无穷维优化」之间差的是强对偶这一跳。**数值**：$X\in\{0,1\}$、$\mathbf{E}X=0.5$（$f_1(x)=x$、$b_1=0.5$）、$S=\{1\}$。取 $x_0=0$、$x_1=2$：对 $\alpha=1$ 得 $2\times1=2\ge1$ ✓，对 $\alpha=0$ 得 $0\ge0$ ✓，目标值 $=2\times0.5=1$ —— 这是**有效但很松**的界（真值恰为 $0.5$）。再取 $x_0=0$、$x_1=1$ 得目标 $0.5$，正好取到真值，说明对偶最优解确实能给出紧界。**落点**：Boyd §5.2.3、§5.8（Farkas 与 alternatives）、exercise 7.13；挂到 6.042J 的节点上是「期望的线性性」，这里它被用来把「集合上的指示」换成「线性函数的组合」。</span>

## Projection on a set（集合上的投影）

### Exercise 8.1 投影的唯一性

**8.1 Uniqueness of projection.** Show that if $C \subseteq \mathbf{R}^n$ is nonempty, closed and convex, and the norm $\Vert\cdot\Vert$ is strictly convex, then for every $x_0$ there is exactly one $x \in C$ closest to $x_0$. In other words the projection of $x_0$ on $C$ is unique.

**中文话题**：非空闭凸集 + 严格凸范数 ⇒ 投影点存在且唯一。

#### 解答

投影至少存在一个（这对**任何**范数都成立）：取 $\hat x \in C$，则投影可通过在闭有界集

```math
C \cap \{x \mid \Vert x - x_0\Vert \le \Vert \hat x - x_0\Vert\}
```

上极小化连续函数 $\Vert x-x_0\Vert$ 求得，故最小值可达。

再证严格凸范数下的唯一性。设 $u,v \in C$，$u \ne v$，且 $\Vert u-x_0\Vert = \Vert v-x_0\Vert = D$。则 $(1/2)(u+v) \in C$，且

```math
\Vert (1/2)(u+v) - x_0\Vert = \Vert (1/2)(u-x_0) + (1/2)(v-x_0)\Vert
```

```math
\lt (1/2)\Vert u-x_0\Vert + (1/2)\Vert v-x_0\Vert = D,
```

所以 $u$ 与 $v$ 都不是 $x_0$ 在 $C$ 上的投影。

<span style="color:#1e8449;">**[译注]** 「严格凸范数」这个条件**不能省**，而且省了之后失效的方式很具体：三角不等式退化成等式。**消失测试**：取 $\ell_1$ 范数、$C = \{x \in \mathbf{R}^2 \mid x_1 + x_2 = 2\}$（凸，非空，闭）、$x_0 = 0$。对任意 $x \in C$ 有 $\Vert x\Vert_1 = |x_1|+|x_2| \ge |x_1+x_2| = 2$，且取 $x=(1,1)$ 时等号成立；于是 $C$ 上整条线段 $\{(\lambda, 2-\lambda) \mid 0 \le \lambda \le 2\}$ 上每个点的 $\ell_1$ 距离都恰为 2 —— **无穷多个投影**，唯一性彻底崩掉。$\ell_2$ 下同一问题的投影是唯一的 $(1,1)$。**机制**：严格凸性说的正是「$\Vert u+v\Vert = \Vert u\Vert+\Vert v\Vert$ 只在 $u,v$ 同向时发生」，把它代进上面的中值不等式，等号只能来自 $u=v$。**量的方向感**：投影从「一个点」退化成「一个 $(n-1)$ 维面」，下游凡是依赖「投影是单值映射」的算法（如投影梯度法、交替投影）在 $\ell_1$ 上就失去了确定的方向。**落点**：Boyd §8.1.1、§A.1.5（strictly convex norm 的定义）、exercise 8.1；挂到 Strang 线代的节点上是「$\ell_2$ 的单位球是严格凸的曲面，$\ell_1$ 的单位球有平面片」。</span>

### Exercise 8.2 凸性的 Chebyshev 刻画

**8.2 [Web94, Val64] Chebyshev characterization of convexity.** A set $C \in \mathbf{R}^n$ is called a Chebyshev set if for every $x_0 \in \mathbf{R}^n$, there is a unique point in $C$ closest (in Euclidean norm) to $x_0$. From the result in exercise 8.1, every nonempty, closed, convex set is a Chebyshev set. In this problem we show the converse, which is known as Motzkin's theorem.

Let $C \in \mathbf{R}^n$ be a Chebyshev set.

**(a)** Show that $C$ is nonempty and closed.

**(b)** Show that $P_C$, the Euclidean projection on $C$, is continuous.

**(c)** Suppose $x_0 \notin C$. Show that $P_C(x) = P_C(x_0)$ for all $x = \theta x_0 + (1-\theta)P_C(x_0)$ with $0 \le \theta \le 1$.

**(d)** Suppose $x_0 \notin C$. Show that $P_C(x) = P_C(x_0)$ for all $x = \theta x_0 + (1-\theta)P_C(x_0)$ with $\theta \ge 1$.

**(e)** Combining parts (c) and (d), we can conclude that all points on the ray with base $P_C(x_0)$ and direction $x_0 - P_C(x_0)$ have projection $P_C(x_0)$. Show that this implies that $C$ is convex.

**中文话题**：投影对每个点都唯一（Chebyshev 集）反过来蕴含凸性 —— Motzkin 定理；证明核心是「沿投影射线前进不改变投影点」。

#### 解答

**(a)** $C$ 非空，因为它包含任意点 $x_0 \in \mathbf{R}^n$ 的投影。

再证 $C$ 闭。设 $x_k$，$k=1,2,\dots$ 是 $C$ 中的点列，极限为 $\bar x$。由 $P_C(\bar x)$ 的定义有

```math
\Vert \bar x - P_C(\bar x)\Vert_2 \le \Vert \bar x - x_k\Vert_2
```

对一切 $k$ 成立。令 $k \to \infty$，右端趋于零，故 $\Vert \bar x - P_C(\bar x)\Vert_2 = 0$，于是 $\bar x = P_C(\bar x) \in C$。

**(b)** 设 $x_k$，$k=1,2,\dots$ 是收敛到 $\bar x$ 的点列。有

```math
\Vert x_k - P_C(x_k)\Vert_2 \le \Vert x_k - P_C(\bar x)\Vert_2 \le \Vert x_k - \bar x\Vert_2 + \Vert \bar x - P_C(\bar x)\Vert_2 .
```

两边取极限，得

```math
\lim_{k\to\infty}\Vert x_k - P_C(x_k)\Vert_2 = \lim_{k\to\infty}\Vert \bar x - P_C(x_k)\Vert_2 \le \Vert \bar x - P_C(\bar x)\Vert_2 .
```

而 $\bar x$ 的投影是唯一的，故 $P_C(\bar x)$ 是球 $\{x \mid \Vert x-\bar x\Vert_2 \le \operatorname{dist}(\bar x, C)\}$ 中 $C$ 的唯一元素；又 $C$ 是闭集。因此

```math
\lim_{k\to\infty}\Vert \bar x - P_C(x_k)\Vert_2 \le \Vert \bar x - P_C(\bar x)\Vert_2
```

只可能在 $P_C(x_k)$ 收敛到 $P_C(\bar x)$ 时成立。

<span style="color:#1e8449;">**[译注]** (b) 的证明有个容易被略过的细节：它先证「$\Vert x_k - P_C(x_k)\Vert$ 有界」，再证「$P_C(x_k)$ 落在一个半径已知的球里」，最后用**唯一性**把「极限点非 $P_C(\bar x)$ 不可」钉死。**消失测试**：如果取消唯一性（即 $C$ 只是闭集而非 Chebyshev 集），$P_C(x_k)$ 可能沿两个不同的极限点来回跳（例如 $C$ 是两个不交闭集的并，$x_k$ 在两支之间摆动），投影映射就不再连续 —— 这不是技术细节：投影梯度法收敛性证明的第一步就是「投影是 Lipschitz 连续的」。**量的方向感**：这里得到的是 $\Vert P_C(x) - P_C(y)\Vert_2 \le \Vert x-y\Vert_2$（1-Lipschitz，非扩张），后续所有交替投影算法的误差界都从这个常数 1 开始累乘。**数值**：$C = [0,1] \subset \mathbf{R}$，$x=0.3$、$y=0.7$ 时 $\Vert P_C(x)-P_C(y)\Vert = 0.4 = \Vert x-y\Vert$，等号取到（非扩张但非压缩）。**落点**：Boyd §8.1.2、§8.1.3；挂到 6.006 的节点上是「连续性的 $\varepsilon$-$\delta$ 定义」与「紧集上连续函数取到极值」（存在性那一步用的正是它）。</span>

#### 8.2 续

**(c)** 设 $x = \theta x_0 + (1-\theta)P_C(x_0)$，$0 \le \theta \lt 1$。有

```math
\Vert x_0 - P_C(x)\Vert_2 \le \Vert x_0 - x\Vert_2 + \Vert x - P_C(x)\Vert_2
```

```math
\le \Vert x_0 - x\Vert_2 + \Vert x - P_C(x_0)\Vert_2
```

```math
= \Vert (1-\theta)(x_0 - P_C(x_0))\Vert_2 + \Vert \theta(x_0 - P_C(x_0))\Vert_2 = \Vert x_0 - P_C(x_0)\Vert_2 .
```

（第一个不等式是三角不等式；第二个不等式来自 $P_C(x)$ 的定义。）由于 $C$ 是 Chebyshev 集，故 $P_C(x) = P_C(x_0)$。

**(d)** 我们先用一个由 Brouwer 不动点定理推出的事实：若 $g : \mathbf{R}^n \to \mathbf{R}^n$ 连续且对 $\Vert x\Vert_2 = 1$ 有 $g(x) \ne 0$，则存在 $\Vert x\Vert_2 = 1$ 的 $x$ 使 $g(x)/\Vert g(x)\Vert_2 = x$。

设 $x = \theta x_0 + (1-\theta)P_C(x_0)$，$\theta \gt 1$。为简化记号，设 $x_0 = 0$ 且

```math
\Vert x - x_0\Vert_2 = (\theta-1)\Vert P_C(x_0)\Vert_2 = 1 .
```

函数 $g(x) = -P_C(x)$ 连续（见 (b)）。由于 $x_0 = 0 \notin C$，故 $x \ne 0$ 时 $g(x) \ne 0$。用不动点定理可知存在 $\Vert y\Vert_2 = 1$ 的 $y$ 使

```math
y = -\frac{P_C(y)}{\Vert P_C(y)\Vert_2}.
```

这意味着 $x_0 = 0$ 落在 $P_C(y)$ 与 $y$ 之间的线段上。于是由 (c) 得 $P_C(x_0) = P_C(y)$，并且

```math
y = -\frac{P_C(x_0)}{\Vert P_C(x_0)\Vert_2} = (1-\theta)P_C(x_0) = x .
```

故 $P_C(x) = P_C(x_0)$。

**(e)** 只需证明 $C$ 是**中点凸**的。反设不然，即存在 $x_1, x_2 \in C$ 使 $x_0 = (1/2)(x_1+x_2) \notin C$。为简化，设 $\Vert x_1 - x_2\Vert_2 = 2$，于是 $\Vert x_0 - x_2\Vert_2 = \Vert x_0 - x_1\Vert_2 = 1$。

令 $D = \Vert x_0 - P_C(x_0)\Vert_2$。必有 $0 \lt D \lt 1$。（$D \gt 0$ 因为 $x_0 \notin C$ 且 $C$ 闭；$D \lt 1$ 否则 $x_0$ 会有两个投影 $x_1$ 与 $x_2$，与 Chebyshev 集矛盾。）

由 (c) 与 (d) 的结果，所有点 $x(\theta) = P_C(x_0) + \theta(x_0 - P_C(x_0))$ 的投影都是 $P_C(x_0)$，即

```math
\operatorname{dist}(x(\theta), C) = \Vert P_C(x_0) + \theta(x_0 - P_C(x_0)) - P_C(x_0)\Vert_2 = \theta\Vert x_0 - P_C(x_0)\Vert_2 = \theta D .
```

不失一般性，设

```math
(x_0 - P_C(x_0))^T (x_1 - x_0) \le 0
```

（否则交换 $x_1$ 与 $x_2$ 的角色）。对 $\theta \ge 1$ 有

```math
\theta^2 D^2 = \operatorname{dist}(x(\theta), C)^2
```

```math
\lt \Vert x(\theta) - x_1\Vert_2^2
```

```math
= \Vert x(\theta) - x_0\Vert_2^2 + \Vert x_0 - x_1\Vert_2^2 + 2(x(\theta) - x_0)^T(x_0 - x_1)
```

```math
= (\theta-1)^2 D^2 + 1 + 2(x(\theta) - x_0)^T(x_0 - x_1)
```

```math
= (\theta-1)^2 D^2 + 1 + 2(\theta-1)(x_0 - P_C(x_0))^T(x_0 - x_1)
```

```math
\le (\theta-1)^2 D^2 + 1 .
```

（第一个不等式来自 $P_C(x_0) \ne x_1$。）于是 $0 \lt (1-2\theta)D^2 + 1$，而它在 $\theta \ge (1/2)(1 + 1/D^2)$ 时为假。

#### 8.3(c) 续（解答）

二阶锥是自对偶的，故条件为


### Exercise 8.5 深度函数与到边界的带号距离

**8.5 [HUL93, volume 1, page 154] Depth function and signed distance to boundary.** Let $C \subseteq \mathbf{R}^n$ be a nonempty convex set, and let $\operatorname{dist}(x,C)$ be the distance of $x$ to $C$ in some norm. We already know that $\operatorname{dist}(x,C)$ is a convex function of $x$.

**(a)** Show that the depth function,

```math
\operatorname{depth}(x,C) = \operatorname{dist}(x, \mathbf{R}^n \setminus C),
```

is concave for $x \in C$.

**中文话题**：点到「补集」的距离（深度）是凹函数 —— 它是支撑函数族的下确界，即一族仿射函数的下确界。

#### 解答

我们证明深度函数可以写成

```math
\operatorname{depth}(x,C) = \inf_{\Vert y\Vert_* = 1}\left(S_C(y) - y^T x\right),
```

其中 $S_C$ 是 $C$ 的支撑函数。这就证明了深度函数是凹的，因为它是**一族仿射函数的下确界**。

先证一个结论：设 $a \ne 0$。在范数 $\Vert\cdot\Vert$ 下，点 $x_0$ 到超平面 $a^Tx = b$ 的距离为 $|a^Tx_0 - b|/\Vert a\Vert_*$。可用 Lagrange 对偶证明，考虑问题

```math
\begin{aligned}
\text{minimize} \quad & \Vert x - x_0\Vert \\
\text{subject to} \quad & a^T x = b .
\end{aligned}
```

对偶函数为

```math
g(\nu) = \inf_x\left(\Vert x - x_0\Vert + \nu(a^T x - b)\right)
```

```math
= \inf_x\left(\Vert x - x_0\Vert + \nu a^T(x - x_0)\right) + \nu(a^T x_0 - b) = \begin{cases} \nu(a^Tx_0 - b) & \Vert \nu a\Vert_* \le 1 \\ -\infty & \text{otherwise} \end{cases}
```

于是得到对偶问题

```math
\begin{aligned}
\text{maximize} \quad & \nu(a^T x_0 - b) \\
\text{subject to} \quad & |\nu| \le 1/\Vert a\Vert_* .
\end{aligned}
```

若 $a^Tx_0 \ge b$，解为 $\nu^\star = 1/\Vert a\Vert_*$；若 $a^Tx_0 \le b$，解为 $\nu^\star = -1/\Vert a\Vert_*$。两种情形的最优值都是 $|a^Tx_0 - b|/\Vert a\Vert_*$。

现在给出深度函数表达式的几何解释与证明。设 $\mathcal{H}$ 为由 $C$ 的支撑超平面定义、且包含 $C$ 的全体半空间的集合。任意 $H \in \mathcal{H}$ 都可用线性不等式 $x^Ty \le S_C(y)$ 描述，其中 $y$ 是 $\operatorname{dom} S_C(y)$ 中的非零向量。

设 $H \in \mathcal{H}$。函数 $\operatorname{dist}(x, \mathbf{R}^n \setminus H)$ 对一切 $x \in C$ 是仿射的：

```math
\operatorname{dist}(x, \mathbf{R}^n \setminus H) = \frac{S_C(y) - x^T y}{\Vert y\Vert_*} .
```

$\mathcal{H}$ 中所有 $H$ 的交等于 $\operatorname{cl} C$，因此

```math
\operatorname{depth}(x,C) = \inf_{H \in \mathcal{H}}\operatorname{dist}(x, \mathbf{R}^n \setminus H)
```

```math
= \inf_{y \ne 0}\left(S_C(y) - x^T y\right)/\Vert y\Vert_* = \inf_{\Vert y\Vert_* = 1}\left(S_C(y) - y^T x\right).
```

<span style="color:#1e8449;">**[译注]** 这条等式是全节的枢纽：它把「到**补集**的距离」这个看似要枚举无穷多个外界点的量，换成「对一个**单位对偶向量**取 inf 的仿射函数」。**机制**：$C$ 是它所有支撑半空间的交，故 $\mathbf{R}^n \setminus C$ 是这些半空间补集的并；到并的距离等于到各部分的距离的 inf，而到单个半空间的补集（即到一个超平面的外侧）的距离有闭式 $(S_C(y)-x^Ty)/\Vert y\Vert_*$。**消失测试**：没有这条，`depth` 只能靠采样近似，且**在边界附近误差最大**（距离趋于 0 时相对误差爆炸）；有了它，`depth` 是仿射函数族的下确界，直接得到凹性与可计算性。**量的方向感**：从「$n$ 维空间里搜索最近的外点」降到「单位球面上的一维参数族」（对多面体则是有限个面法向），维数从 $n$ 降到「面的个数」。**数值**：$C = \{x \in \mathbf{R}^2 \mid x_1 \le 1, x_2 \le 1\}$（象限），$x = (0,0)$，则 `depth` $= 1$（到 $x_1=1$ 或 $x_2=1$ 的距离）；取 $y = (1,0)/\sqrt2$（$\ell_2$ 对偶范数下单位向量），$S_C(y) = \max_{x\in C} y^Tx = \sqrt2$，故 $S_C(y) - y^Tx = \sqrt2$，再除以 $\Vert y\Vert_* = 1$ 得 $\sqrt2$ —— 说明 inf 要在 $y$ 取坐标轴方向时取到（此时给 1），与几何直觉一致。**落点**：Boyd §8.2.1、§A.1.6（支撑函数与对偶范数）、§8.5；挂到 Strang 线代的节点上是「支撑函数是集合的对偶描述」，与「列空间 ⊥ 零空间」同源。</span>

由构造可知，对一切 $G \in \mathcal{H}$ 必有 $\operatorname{dist}(x,C) \ge s(x,G)$。又取 $B$ 为以 $x$ 为心、半径 $\operatorname{dist}(x,C)$ 的球。由于 $B$ 与 $C$ 都凸且 $B$ 闭，存在分离超平面 $H$ 使 $H \in \mathcal{H}$ 且 $s(x,H) = \operatorname{dist}(x,C)$，于是

```math
\operatorname{dist}(x,C) \le \sup_{H \in \mathcal{H}} s(x,H),
```

即为所欲证。

<span style="color:#1e8449;">**[译注]** (a) 与 (b) 的对偶关系全在一个符号上：`depth` 取 **inf**（一族仿射函数的下确界）⇒ 凹；$s$ 取 **sup**（一族仿射函数的上确界）⇒ 凸。这不是巧合 —— 两者在 $C$ 内部与外部互相取负号，而「取负」把 sup 换成 inf。**消失测试**：如果硬把 `depth` 直接延拓成 $s$（不在 $C$ 内取负号），得到的函数在 $\operatorname{bd} C$ 处会有**两次折**（内部凹、外部凸），既非凸也非凹 —— 而优化里需要的恰是单侧性：$s$ 凸意味着 $\{x \mid s(x) \le 0\} = \operatorname{cl} C$ 是凸集，这就是「集合的凸性可以用一个凸函数的水平集刻画」。**量的方向感**：从「检查集合包含关系」($\forall x \in C$ 的无穷多约束) 降到「一条凸不等式」($s(x) \le 0$，可交给求解器)。**数值**：$C = \{x \in \mathbf{R} \mid x \le 0\}$，$s(x) = x$（外部正、内部负、边界 0）；取 $x_1 = 2$、$x_2 = 4$，$s(3) = 3 = \frac{1}{2}(2+4)$ ✓ 线性；换成 $C = \{x \mid x \le -1\}$，$s(x) = x+1$ 仍线性。**落点**：Boyd §8.2.1、§8.5、§A.1.6；挂到 Thomson 实分析的节点上是「上确界与下确界的对偶」，与「开集 / 闭集互补」同源。 **一句话记法**：集合外侧记正、内侧记负，于是 $s$ 的符号就是「在不在集合里」的连续版本，而 $s$ 的凸性正是「判断归属」可以写成凸约束的原因。</span>

## Distance between sets（集合之间的距离）

### Exercise 8.6

**8.6** Let $C$, $D$ be convex sets.

**(a)** Show that $\operatorname{dist}(C, x+D)$ is a convex function of $x$.

**(b)** Show that $\operatorname{dist}(tC, x+tD)$ is a convex function of $(x,t)$ for $t \gt 0$.

**中文话题**：把一个集合平移后与另一集合的距离关于平移量是凸的；再对尺度做透视（perspective）仍保持凸性。

#### 解答

先证第一问。注意

```math
\operatorname{dist}(C, x+D) = \inf_{u,v}\left(I_C(u) + I_D(v) + \Vert u - (x+v)\Vert\right).
```

右端关于 $(u,v,x)$ 是凸的，故由极小化规则（minimization rule）知 $\operatorname{dist}(C,x+D)$ 关于 $x$ 凸。

再证第二问。注意

```math
\operatorname{dist}(tC, x+tD) = t\,\operatorname{dist}(C, x/t + D).
```

右端是 (a) 中那个凸函数的透视（perspective）。

**† 原文错误（8.6(a)，指示函数下标）**：原文写作

```math
\operatorname{dist}(C, x+D) = \inf_{u,v}\left(I_C(u) + I_C(x+v) + \Vert u - (x+v)\Vert\right),
```

第二个指示函数应为 $I_D(v)$。$\operatorname{dist}(C, x+D)$ 的定义是「$u \in C$ 与 $w \in x+D$ 之间的最小距离」，把 $w$ 参数化成 $w = x+v$（$v \in D$），于是约束是 $u \in C$、$v \in D$ 两条，而原文把第二条也写成了 $I_C$，等于要求 $x+v \in C$ —— 那是另一个问题。**为什么会写错**：$I_C(u)$ 刚写完，紧接着的 $I_?(\cdot)$ 在键盘上是同一个字母，且两个集合都叫「凸集」，作者的注意力停留在「都是指示函数」这一层，没有回到「哪个集合对应哪个变量」。**数值反例**：$C = D = \{0\} \subset \mathbf{R}$、$x = 5$。真值 $\operatorname{dist}(\{0\}, \{5\}) = 5$。按原式，需 $u = 0$ 且 $x+v = 0$ 即 $v = -5$，目标 $\Vert u - (x+v)\Vert = \Vert 0 - 0\Vert = 0$ —— 原文式给 0，与真值 5 相差 5。**影响**：这正是「$C=D$ 时看不出差别」的典型错误（本块踩过的坑里的一条），只有 $C \ne D$ 才暴露；原文从此处出发的凸性论证（关于 $(u,v,x)$ 联合凸）在 $I_D$ 下同样成立，故结论不受影响。

<span style="color:#1e8449;">**[译注]** 本题的标准技巧叫「把距离写成联合变量的极小」，它是凸分析里最常用的一次改写。**机制**：$\operatorname{dist}(C,y) = \inf_u\left(I_C(u) + \Vert u-y\Vert\right)$ —— 集合的「距离」被换成「指示函数 + 范数」的联合极小，而 $I_C$（凸集的指示函数）本身就是凸的，$\Vert\cdot\Vert$ 凸，和仍凸；再对 $u$ 做极小化，凸性原样保留（minimization over a convex variable preserves convexity，这正是「partial minimization」规则）。**消失测试**：没有这一步，$\operatorname{dist}(C, x+D)$ 只能写成「两层 inf」，无法直接判断它关于 $x$ 是否凸 —— 而 $x$ 是决策变量时（如鲁棒优化里的不确定平移、模型预测控制里的参考轨迹）这个凸性是能不能用凸求解器的分水岭。**量的方向感**：变量块 $(u,v,x)$ 变成只关于 $x$ 的一层函数，维数从 $2n+n$ 降到 $n$，且不引入任何非线性。**数值**：$C = [0,1]$、$D = [0,1]$、$x = 0.5$，则 $x+D = [0.5,1.5]$，距离 $= 0$（相交）；$x = 3$ 时 $x+D = [3,4]$，距离 $= 2$；$x = -2$ 时距离 $= 2$ —— 关于 $|x|$ 的 V 形，凸 ✓。**落点**：Boyd §3.2.5（partial minimization）、§8.2、exercise 8.6；挂到 6.006 的节点上是「$\inf$ 与 $\min$ 的区别只在紧性」，这里 $C,D$ 凸闭且范数强制下界，故 inf 可达。 **这条规则的边界**：partial minimization 只对**联合凸**的变量成立；若 $I_C + I_D + \Vert\cdot\Vert$ 不是联合凸（例如某个集合非凸），极小化会造出一个非凸函数，凸性传递链当场断掉。</span>

#### 8.7 续（解答）

两个集合都闭且有界，故其交非空当且仅当存在 $a \ne 0$ 满足

```math
\inf_{x \in E_1} a^T x \gt \sup_{x \in E_2} a^T x .
```

该下确界由如下问题的最优值给出：

```math
\begin{aligned}
\text{minimize} \quad & a^T x \\
\text{subject to} \quad & (x-x_1)^T P_1^{-1}(x-x_1) \le 1 .
\end{aligned}
```

作变量替换 $y = P_1^{-1/2}(x-x_1)$，得

```math
\begin{aligned}
\text{minimize} \quad & a^T x_1 + a^T P_1^{1/2} y \\
\text{subject to} \quad & y^T y \le 1,
\end{aligned}
```

其最优值为 $a^T x_1 - \Vert P_1^{1/2}a\Vert_2$。同理，

```math
\sup_{x \in E_2} a^T x = a^T x_2 + \Vert P_2^{1/2}a\Vert_2 .
```

于是条件化为

```math
a^T x_1 - \Vert P_1^{1/2}a\Vert_2 \gt a^T x_2 + \Vert P_2^{1/2}a\Vert_2 .
```

我们也可以不用分离超平面定理、直接从对偶推出这个结果。两个集合之间的距离是如下问题的最优值：

```math
\begin{aligned}
\text{minimize} \quad & \Vert x - y\Vert_2 \\
\text{subject to} \quad & \Vert P_1^{-1/2}(x-x_1)\Vert_2 \le 1 \\
& \Vert P_2^{-1/2}(y-x_2)\Vert_2 \le 1,
\end{aligned}
```

变量为 $x$ 与 $y$。其最优值为正**当且仅当**两椭球之交为空，否则为零。

为导出对偶，先把问题改写为

```math
\begin{aligned}
\text{minimize} \quad & \Vert u\Vert_2 \\
\text{subject to} \quad & \Vert v\Vert_2 \le 1, \quad \Vert w\Vert_2 \le 1 \\
& P_1^{1/2} v = x - x_1 \\
& P_2^{1/2} w = y - x_2 \\
& u = x - y,
\end{aligned}
```

新变量为 $u,v,w$。Lagrangian 为

```math
L(x,y,u,v,w,\lambda_1,\lambda_2,z_1,z_2,z)
```

```math
= \Vert u\Vert_2 + \lambda_1(\Vert v\Vert_2 - 1) + \lambda_2(\Vert w\Vert_2 - 1) + z_1^T(P_1^{1/2}v - x + x_1) + z_2^T(P_2^{1/2}w - y + x_2) + z^T(u - x + y)
```

```math
= -\lambda_1 - \lambda_2 + z_1^T x_1 + z_2^T x_2 - (z+z_1)^T x + (z - z_2)^T y + \Vert u\Vert_2 + z^T u + \lambda_1\Vert v\Vert_2 + z_1^T P_1^{1/2}v + \lambda_2\Vert w\Vert_2 + z_2^T P_2^{1/2}w .
```

对 $x$ 取极小：除非 $z_1 = -z$，否则无下界。对 $y$ 取极小：除非 $z_2 = z$，否则无下界。消去 $z_1$ 与 $z_2$ 后，对偶函数可写成

```math
g(\lambda_1,\lambda_2,z) = -\lambda_1 - \lambda_2 + z^T(x_2 - x_1) + \inf_u\left(\Vert u\Vert_2 + z^T u\right)
```

```math
+ \inf_v\left(\lambda_1\Vert v\Vert_2 - z^T P_1^{1/2} v\right) + \inf_w\left(\lambda_2\Vert w\Vert_2 + z^T P_2^{1/2} w\right).
```

<span style="color:#1e8449;">**[译注]** 这里 $\inf_x$ 那一步值得单独看：Lagrangian 关于 $x$ 是**线性**的，系数是 $-(z+z_1)$。线性函数在 $\mathbf{R}^n$ 上有下界当且仅当系数为零，这就是「$z_1 = -z$」的来源 —— 它不是解得出来的，而是**可行性条件**（对偶可行域由 Lagrangian 有界的那部分参数组成）。**消失测试**：漏掉这一步，对偶函数会写成「$-\infty$ 或某个线性式」的两段式却不写出条件，对偶问题就成了无约束最大化一个可能无界的函数，强对偶的论证直接断掉。**机制**：三步固定套路 —— ① $x$ 的系数归零；② $y$ 的系数归零；③ 剩下的 $\inf$ 用对偶范数算（$\inf_u(\Vert u\Vert + z^Tu) = 0$ 当 $\Vert z\Vert_* \le 1$，否则 $-\infty$）。**数值**：$P_1 = P_2 = I$、$x_1 = (0,0)$、$x_2 = (3,0)$。条件变为 $2\Vert a\Vert_2 \lt a^T(-3,0) = -3a_1$；取 $a = (-1,0)$：左端 $2$、右端 $3$，$2 \lt 3$ ✓ 成立，对应两单位球相距 1（确实分离）。若把 $x_2$ 改成 $(1.5,0)$，左端仍是 $2$、右端 $1.5$，不成立 —— 两球相交（间距 0.5 小于半径和 2）✓ 与几何一致。**落点**：Boyd §8.2.1、§5.8（Lagrange 对偶的标准步骤）、exercise 8.7；挂到 Strang 线代的节点上是「$P^{1/2}$ 把椭球拉回单位球」，这就是椭球范数的定义。</span>

### Exercise 8.8 多面体的交与包含

**8.8 Intersection and containment of polyhedra.** Let $P_1$ and $P_2$ be two polyhedra defined as

```math
P_1 = \{x \mid Ax \preceq b\}, \qquad P_2 = \{x \mid Fx \preceq g\},
```

with $A \in \mathbf{R}^{m \times n}$, $b \in \mathbf{R}^m$, $F \in \mathbf{R}^{p \times n}$, $g \in \mathbf{R}^p$. Formulate each of the following problems as an LP feasibility problem, or a set of LP feasibility problems.

**(a)** Find a point in the intersection $P_1 \cap P_2$.

**(b)** Determine whether $P_1 \subseteq P_2$.

For each problem, derive a set of linear inequalities and equalities that forms a strong alternative, and give a geometric interpretation of the alternative.

Repeat the question for two polyhedra defined as

```math
P_1 = \operatorname{conv}\{v_1,\dots,v_K\}, \qquad P_2 = \operatorname{conv}\{w_1,\dots,w_L\}.
```

**中文话题**：多面体的「相交 / 包含」判定都能写成 LP 可行性；对偶给出的替代系统恰好是**分离证书**。

#### 解答（不等式描述）

**(a)** 求解

```math
Ax \preceq b, \qquad Fx \preceq g .
```

其替代系统为

```math
A^T u + F^T v = 0, \qquad u \succeq 0, \qquad v \succeq 0, \qquad b^T u + g^T v \lt 0 .
```

**解释**：若两集合不相交，则可用法向量为 $a = A^Tu = -F^Tv$ 的超平面把它们分离。若 $Ax \preceq b$ 且 $Fy \preceq g$，则

```math
a^T x = u^T A x \le u^T b \lt -v^T g \le -v^T F x \le a^T y .
```

#### 8.8 续

**(b)** $P_1 \subseteq P_2$ 当且仅当

```math
\sup_{Ax \preceq b} f_i^T x \le g_i, \qquad i = 1,\dots,p .
```

可以解 $p$ 个 LP，把最优值与 $g_i$ 比较。用 LP 对偶可把同一组条件写成

```math
\inf_{A^Tz = f_i,\; z \succeq 0} b^T z \le g_i, \qquad i = 1,\dots,p,
```

这又等价于 $p$ 个（解耦的）LP 可行性问题

```math
A^T z_i = f_i, \qquad z_i \succeq 0, \qquad b^T z_i \le g_i,
```

变量为 $z_i$。该系统的替代为

```math
Ax \preceq \lambda b, \qquad f_i^T x \gt \lambda g_i, \qquad \lambda \ge 0 .
```

若 $\lambda \gt 0$，这意味着 $(1/\lambda)x \in P_1$ 而 $(1/\lambda)x \notin P_2$。

若 $\lambda = 0$，它意味着：若 $\bar x \in P_1$，则当 $t$ 充分大时 $\bar x + tx \notin P_2$。

#### 解答（顶点描述）

**(a)** $P_1 \cap P_2 = \varnothing$？求解

```math
\lambda \succeq 0, \quad \mathbf{1}^T\lambda = 1, \quad \mu \succeq 0, \quad \mathbf{1}^T\mu = 1, \quad V\lambda = W\mu,
```

其中 $V$ 的列是 $v_i$、$W$ 的列是 $w_i$。由 Farkas 引理，替代系统为

```math
V^T z + t\mathbf{1} \succeq 0, \quad t \lt 0, \quad -W^T z + u\mathbf{1} \succeq 0, \quad u \lt 0,
```

即 $V^T z \succ 0$、$W^T z \prec 0$。因此 $z$ 定义了一个分离超平面。

**(b)** $P_1 \subseteq P_2$？对 $i = 1,\dots,L$，求解

```math
w_i = V\mu_i, \qquad \mu_i \succeq 0, \qquad \mathbf{1}^T\mu_i = 1 .
```

由 Farkas 引理，替代系统为

```math
V^T z_i + t_i\mathbf{1} \succeq 0, \qquad w_i^T z_i + t_i \lt 0,
```

即 $w_i^T z_i \lt V^T z_i$。因此 $z_i$ 定义了一个把 $w_i$ 与 $P_1$ 分开的超平面。

**† 原文错误（8.8(b) 顶点描述，指标范围）**：原文写「对 $i = 1,\dots,K$」求 $w_i = V\mu_i$，应为 $i = 1,\dots,L$。$K$ 是 $P_1$ 的顶点数、$L$ 是 $P_2$ 的顶点数，而此刻要检查的是「$P_2$ 的每个顶点是否落在 $P_1$ 内」，遍历对象是 $w_i$（$P_2$ 的顶点），故上界必须是 $L$。**为什么会写错**：$V$（$P_1$ 的顶点矩阵，$n \times K$）在上一小问里是主角，视线刚离开 $V$ 就顺手用了它的列数 $K$；而这一小问里 $V$ 只是「拿来判归属」的参照，真正被遍历的是 $W$ 的列。**数值反例**：取 $K = 1$、$L = 3$（$P_1$ 是单点 $\{(0,0)\}$，$P_2$ 是三角形）。按原文只检查 $w_1$，若恰好 $w_1 = (0,0)$ 就断言 $P_1 \subseteq P_2$ —— 而 $w_2 = (5,5)$、$w_3 = (-4,7)$ 都不在 $P_1$ 内，结论错得离谱（$P_1$ 只是三角形的一个点，绝不可能包含三角形）。正确的遍历跑 3 次，$i=2$ 时立即失败。**影响**：结论「用 Farkas 得到分离证书」不变，但照抄会在 $K \ne L$ 时给出错误判定。

<span style="color:#1e8449;">**[译注]** 「强替代」（strong alternative）是这一题真正的主题：**它把「判定问题」变成「证书问题」**。对 (a) 而言，两条路互斥且必居其一 —— 要么存在 $x$ 同时在 $P_1$ 与 $P_2$ 内，要么存在 $(u,v)$ 使 $b^Tu + g^Tv \lt 0$，后者就是一张「分离超平面」的收据。**消失测试**：没有替代系统，你可能枚举出所有候选 $x$ 都失败却无法证明「确实不存在」；有了它，一个满足 $A^Tu+F^Tv = 0$、$u,v \succeq 0$、$b^Tu+g^Tv \lt 0$ 的向量就把「不存在交点」钉死，且这个验证是 $O(mp)$ 的。**量的方向感**：原始判定要对 $n$ 维空间做搜索，证书只需**读一遍** $m+p$ 个不等式。**数值**：$P_1 = \{(x_1,x_2) \mid x_1 \ge 0\}$、$P_2 = \{x \mid x_1 \le -1\}$，取 $u = (1,0)$、$v = (1,0)$（对应 $A = [-1,0]$、$b = 0$；$F = [1,0]$、$g = -1$）：$A^Tu + F^Tv = (-1,0)+(1,0) = 0$ ✓，$b^Tu + g^Tv = 0 + (-1) = -1 \lt 0$ ✓ —— 证书成立，且分离法向 $a = A^Tu = (-1,0)$，把两侧正确分开。**落点**：Boyd §5.8.3（Farkas 引理与 alternatives）、§8.2.1、exercise 8.8；挂到 6.042J 的节点上是「命题与其否命题恰有一个成立」，这里把「否命题」具体化成一族不等式的可行性。 **验证成本**：矛盾的两侧都只需一次矩阵乘（$A^Tu$ 与 $F^Tv$），因此这种判定可以嵌进实时控制器，而不只是事后证明。</span>

## Euclidean distance and angle problems（欧氏距离与夹角问题）

### Exercise 8.9 最接近给定数据的欧氏距离矩阵

**8.9 Closest Euclidean distance matrix to given data.** We are given data $\hat d_{ij}$, for $i,j = 1,\dots,n$, which are corrupted measurements of the Euclidean distances between vectors in $\mathbf{R}^k$:

```math
\hat d_{ij} = \Vert x_i - x_j\Vert_2 + v_{ij}, \qquad i,j = 1,\dots,n,
```

where $v_{ij}$ is some noise or error. These data satisfy $\hat d_{ij} \ge 0$ and $\hat d_{ij} = \hat d_{ji}$, for all $i,j$. The dimension $k$ is not specified.

Show how to solve the following problem using convex optimization. Find a dimension $k$ and $x_1,\dots,x_n \in \mathbf{R}^k$ so that $\sum_{i,j=1}^{n}(d_{ij} - \hat d_{ij})^2$ is minimized, where $d_{ij} = \Vert x_i - x_j\Vert_2$, $i,j = 1,\dots,n$. In other words, given some data that are approximate Euclidean distances, you are to find the closest set of actual Euclidean distances, in the least-squares sense.

**中文话题**：把「距离矩阵的最小二乘拟合」从「找点坐标」$(x_i)$ 换成「找距离矩阵」$D$，约束变成 PSD 条件 —— 于是非凸的最小二乘变成凸问题。

页眉：`8 Geometric problems`。

#### 8.9 续（解答）

$d_{ij}$ 是真实欧氏距离这一条件可以用关联的欧氏距离矩阵（Euclidean distance matrix）$D_{ij} = d_{ij}^2$ 来表述：

```math
D_{ii} = 0, \quad i = 1,\dots,n, \qquad D_{ij} \ge 0, \quad i,j = 1,\dots,n,
```

```math
\left(I - (1/n)\mathbf{1}\mathbf{1}^T\right) D \left(I - (1/n)\mathbf{1}\mathbf{1}^T\right) \preceq 0,
```

这是关于 $D$ 的一组凸条件。

目标函数可以用 $D$ 表示：

```math
\sum_{i,j=1}^{n}\left(d_{ij} - \hat d_{ij}\right)^2 = \sum_{i,j=1}^{n}\left(D_{ij}^{1/2} - \hat d_{ij}\right)^2
```

```math
= \sum_{i,j=1}^{n}\left(D_{ij} - 2D_{ij}^{1/2}\hat d_{ij} + \hat d_{ij}^2\right),
```

它是 $D$ 的凸函数（因为 $D_{ij}^{1/2}\hat d_{ij}$ 是凹的）。于是我们在上述约束下极小化这个函数。点 $x_i$ 按正文所述的方式、用 Cholesky 分解重构。

<span style="color:#1e8449;">**[译注]** 这个改写是「换变量消掉非凸性」的教科书案例。原问题在 $(x_1,\dots,x_n) \in (\mathbf{R}^k)^n$ 上做最小二乘，$d_{ij} = \Vert x_i-x_j\Vert_2$ 关于 $x$ 非凸（两个凸函数之差的平方根），而且是**非确定维数**的（$k$ 也是自由变量）。**关键恒等式**是

```math
D \in \text{EDM} \iff D = D^T,\; \operatorname{diag}(D) = 0,\; -\tfrac{1}{2}HDH \succeq 0,\quad H = I - \tfrac{1}{n}\mathbf{1}\mathbf{1}^T,
```

其中 $-\frac{1}{2}HDH$ 正是点集的 Gram 矩阵 $G_{ij} = x_i^Tx_j$（已中心化）；$D$ 是 EDM 等价于存在某 $k$ 使 $G \succeq 0$ 且 $\operatorname{rank}(G) \le k$。原文把约束写成 $HDH \preceq 0$，等价于 $G \succeq 0$，但**丢掉了秩界**：秩约束会破坏凸性，所以降维后得到的是「最近的可实现距离矩阵」而非「维数最小的解」，$k$ 由 Cholesky 因子自动给出（等于 $G$ 的秩）。**消失测试**：不做这个换变量，问题既非凸又有变维数，只能靠 MDS 的启发式迭代（SMACOF），无全局最优保证；换变量后是一次凸优化，全局最优且可验证。**量的方向感**：变量从 $nk$ 个（$k$ 未知）变成 $n(n+1)/2$ 个，$n = 100$ 时是 $100k$ 对 $5050$；代价是约束里出现 $n \times n$ 的半定块。**数值**：$n = 3$、边长全为 1 的等边三角形，$D = \begin{bmatrix}0&1&1\\1&0&1\\1&1&0\end{bmatrix}$；$HDH = D - \frac{1}{n}\mathbf{1}\mathbf{1}^TD - \frac{1}{n}D\mathbf{1}\mathbf{1}^T + \frac{1}{n^2}\mathbf{1}\mathbf{1}^TD\mathbf{1}\mathbf{1}^T$，算得 $-\frac{1}{2}HDH$ 的特征值为 $(1,1,0)$ ⇒ PSD 且秩 2 ⇒ 可嵌入 $\mathbf{R}^2$ ✓（正三角形确实平面可嵌）。**落点**：Boyd §8.3.3、§4.2.4（秩约束与半定松弛）、exercise 8.9；挂到 Strang 线代的节点上是「Gram 矩阵 = 内积矩阵，$G = X^TX$ 的秩 = 点的维数」，这正是本节全部代数的基础。</span>

### Exercise 8.10 极小极大夹角拟合

**8.10 Minimax angle fitting.** Suppose that $y_1,\dots,y_m \in \mathbf{R}^k$ are affine functions of a variable $x \in \mathbf{R}^n$:

```math
y_i = A_i x + b_i, \qquad i = 1,\dots,m,
```

and $z_1,\dots,z_m \in \mathbf{R}^k$ are given nonzero vectors. We want to choose the variable $x$, subject to some convex constraints, (e.g., linear inequalities) to minimize the maximum angle between $y_i$ and $z_i$,

```math
\max\left\{\angle(y_1,z_1),\dots,\angle(y_m,z_m)\right\}.
```

The angle between nonzero vectors is defined as usual:

```math
\angle(u,v) = \cos^{-1}\frac{u^T v}{\Vert u\Vert_2\Vert v\Vert_2},
```

where we take $\cos^{-1}(a) \in [0,\pi]$. We are only interested in the case when the optimal objective value does not exceed $\pi/2$.

Formulate this problem as a convex or quasiconvex optimization problem. When the constraints on $x$ are linear inequalities, what kind of problem (or problems) do you have to solve?

**中文话题**：夹角关于其中一个向量是**拟凸**（quasiconvex）的，故极小化最大夹角是拟凸问题；用二分法（bisection）在 $\theta$ 上一层套一层的 SOCP。

#### 解答

这是一个拟凸优化问题。为看出这一点，注意

```math
\angle(u,v) = \cos^{-1}\frac{u^T v}{\Vert u\Vert_2\Vert v\Vert_2} \le \theta \iff \frac{u^T v}{\Vert u\Vert_2\Vert v\Vert_2} \ge \cos(\theta)
```

```math
\iff \cos(\theta)\Vert u\Vert_2\Vert v\Vert_2 \le u^T v,
```

第一行用的是 $\cos^{-1}$ 单调递减这一事实。现在设 $v$ 固定、$u$ 为变量。当 $\theta \le \pi/2$ 时，$\angle(u,v)$ 在 $u$ 上的下水平集是凸集，事实上就是一条简单的二阶锥约束。因此对固定的 $v$，只要 $u^Tv \ge 0$，$\angle(u,v)$ 就是 $u$ 的拟凸函数。于是夹角拟合问题中的目标

```math
\max\left\{\angle(y_1,z_1),\dots,\angle(y_m,z_m)\right\}
```

关于 $x$ 是拟凸的，只要它不超过 $\pi/2$。

为把夹角拟合问题写成具体形式，先检查最优值是否不超过 $\pi/2$。为此求解不等式组

```math
(A_i x + b_i)^T z_i \ge 0, \qquad i = 1,\dots,m,
```

连同 $x$ 上的不等式，比如 $Fx \preceq g$。这一步可以用 LP 完成。若该不等式组不可行，则夹角拟合问题的最优值超过 $\pi/2$，就此停止。若可行，则求解 SOC 不等式组

```math
Fx \preceq g, \qquad (A_i x + b_i)^T z_i \ge \cos(\theta)\Vert A_i x + b_i\Vert_2\Vert z_i\Vert_2, \quad i = 1,\dots,m,
```

（本页在此处中断，二分法的迭代细节延续到 p221。）

<span style="color:#1e8449;">**[译注]** 拟凸而不是凸，差别在一个具体的地方：**$\cos(\theta)$ 是 $x$ 的函数时不等式就不再凸**。原文的每一行都是「给定 $\theta$，判定是否存在 $x$」—— 那是一个 SOCP 可行性问题（$u^Tv \ge \cos\theta\Vert u\Vert\Vert v\Vert$ 两边都是 $x$ 的仿射/范数形式，属二阶锥）。**消失测试**：若强行把 $\theta$ 也当变量一起优化，约束变成双线性（$\cos\theta$ 乘范数），可行性集不再凸，直接投喂求解器会卡在局部解；而二分把 $\theta$ 提到外层，内层每步都是凸的。**量的方向感**：对 $\theta$ 二分，精度 $\varepsilon$ 需要 $\lceil\log_2((\pi/2)/\varepsilon)\rceil$ 次 SOCP，$\varepsilon = 10^{-3}$ 时约 11 次；每次 SOCP 的规模是 $m$ 条锥约束。**数值**：$u = (1,0)$、$v = (1,1)$，夹角 $45^\circ$；取 $\theta = 60^\circ$（$\cos\theta = 0.5$），检验 $0.5 \times 1 \times 1.414 = 0.707 \le u^Tv = 1$ ✓ 可行；取 $\theta = 30^\circ$（$\cos\theta = 0.866$），$0.866\times1.414 = 1.22 \gt 1$ ✗ 不可行 —— 二分会收敛到 $45^\circ$ ✓。**落点**：Boyd §4.2.5（quasiconvex 与 bisection）、§8.3、exercise 8.10；挂到 6.006 的节点上是「二分查找的复杂度 $\log$」，这里把它用在「可行性判定」上而不是数值比较上。 **边界情形**：$y_i$ 为零向量时夹角无定义，实际实现要先剔除或加正则（要求 $\Vert y_i\Vert_2 \ge \epsilon$），否则约束会退化成 $0 \ge 0$。</span>
