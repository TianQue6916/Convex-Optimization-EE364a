### 承接 p220：minimax angle fitting 的收尾

原文：

> to check if the optimal objective is more or less than θ. We can then bisect on θ to find the smallest value for which this system is feasible. Thus, we need to solve a sequence of SOCPs to solve the minimax angle fitting problem.

译文：用它判断最优目标值比 $\theta$ 大还是小。于是可以对 $\theta$ 做 bisection（二分），找出使该系统可行的最小取值。因此求解 minimax angle fitting（极小化极大夹角拟合）问题，归结为求解一串 SOCP（second-order cone program）。

<span style="color:#1e8449;">**[译注]** 这里的 bisection 不是「随便切的二分」，它的合法性来自单调性：可行性集合 $\Theta=\{\theta \mid \exists x\neq 0,\ a_i^Tx \ge \|a_i\|_2\|x\|_2\cos\theta,\ i=1..m\}$ 对 $\theta$ 单调——$\theta$ 越大，$\cos\theta$ 越小，右端越松，集合越大。于是「可行 / 不可行」这条黑箱谓词在 $[0,\pi/2]$ 上是一次相变，二分 $k$ 次把区间压到 $(\pi/2)/2^k$，取 $k=30$ 就是 $10^{-9}$ 量级的精度。**消失测试**：若没有单调性，可行域可能是一段一段的，二分会停在假区间上，得到比真最优大一截的角半径而不报错。**落点**：Boyd §8.8.1 与本节 (8.10)；bisection 的收敛率 $O(\log(1/\epsilon))$ 对应 6.006 的 binary search 分析，只是这里比较的是 SOCP feasibility 而非数组元素。**量的方向感**：每轮多花一次 SOCP 调用，换来精度加倍——成本 $\Theta(\log(1/\epsilon))$ 次 SOCP，而不是 $\Theta(1/\epsilon)$ 次网格搜索。**实现侧**：商用 solver 的 SOCP feasibility 返回码对容差极敏感，二分时要把 `tol` 固定成 $10^{-8}$ 这样的常数，否则三十轮里有几轮会因数值噪声给出相反判定，最终角半径偏小 $10^{-6}$ 量级且不报任何错；稳妥做法是先跑 25 轮定位区间，再用一次直接极小化 $\theta$ 的 SOCP 收尾。</span>


### Exercise 8.11 · Smallest Euclidean cone containing given points

题干（原文）：

> 8.11 Smallest Euclidean cone containing given points. In $R^n$, we define a Euclidean cone, with center direction $c \neq 0$, and angular radius $\theta$, with $0 \le \theta \le \pi/2$, as the set
>
> $\{x \in R^n \mid \angle(c,x) \le \theta\}$.
>
> (A Euclidean cone is a second-order cone, i.e., it can be represented as the image of the second-order cone under a nonsingular linear mapping.)
>
> Let $a_1,\dots,a_m \in R^n$. How would you find the Euclidean cone, of smallest angular radius, that contains $a_1,\dots,a_m$? (In particular, you should explain how to solve the feasibility problem, i.e., how to determine whether there is a Euclidean cone which contains the points.)

中文话题摘要：给定 $m$ 个点，求角半径最小的 Euclidean cone 把它们全包住；并说明可行性判定怎么解。

> 说明：PDF 文本层在题干处丢了两处记号，`∠` 与上标 `n` 未提取出来（显示为 `{x ∈ Rn | (c, x) ≤ θ}` 与 `a1,...,am ∈ R`）。按上下文（`angular radius`、后面的 `‖a_i‖₂`）配平后应为上行形式，见文末小瑕疵表。

解答（Solution）：

首先可以假定每个 $a_i$ 都非零：落在原点的点被所有 cone 包含，直接忽略即可。

这些点落在某个 Euclidean cone 中，当且仅当它们落在某个半空间（halfspace）中，而半空间正是「最大」的 Euclidean cone，其角半径为 $\pi/2$。这一点可以用一组线性不等式来检验：

```math
a_i^T x \ge 0, \quad i = 1,\dots,m.
```

接下来找最小的 cone。点集落在角半径为 $\theta$ 的 cone 中，当且仅当存在（非零的）向量 $x \in R^n$ 使

```math
\frac{a_i^T x}{\|a_i\|_2 \|x\|_2} \ge \cos\theta, \quad i = 1,\dots,m.
```

由于 $\theta \le \pi/2$，这与下式等价：

```math
a_i^T x \ge \|a_i\|_2 \|x\|_2 \cos\theta, \quad i = 1,\dots,m,
```

而这是一组 second-order cone 约束。因此，对 $\theta$ 做 bisection，反复求解 SOCP feasibility 问题，就能找出最小的 cone。

<span style="color:#1e8449;">**[译注]** 「Euclidean cone 是 second-order cone 在非奇异线性映射下的像」这句括注是全题的技术支点，值得单独拆开。单位向量集上比较夹角，等价于在 $\|a_i\|_2\|x\|_2$ 这个「归一化分母」下比较内积；而 `\|\cdot\|_2` 一旦写进约束右端，得到的就是标准的 second-order cone 约束 $(a_i^Tx,\ \|a_i\|_2\|x\|_2\cos\theta) \in \mathrm{SOC}$。它不是把角度线性化，而是把角度**搬到分母**：把 $\cos\theta$ 当常数，约束对 $x$ 就是齐次的二次锥约束。**消失测试**：若把 $\cos\theta$ 也当变量，约束 $a_i^Tx/\|a_i\|_2\|x\|_2 \ge \cos\theta$ 需要同时除两个变量，非凸，SOCP 表示立刻失效，只剩在球面上做非凸搜索。**落点**：Boyd §4.4.2（second-order cone 的定义与线性像）、§8.8.1（与 8.10 的夹角问题同构）。**量的方向感**：$m$ 个角度条件（每个都是非凸的「球面夹角」条件）被换成 $m$ 条 SOC 约束，加上一次外层 bisection，总调用量 $O(m\log(1/\epsilon))$。**量纲检验**：把全部 $a_i$ 同时乘以 2，锥约束两边同比放大，可行集不变——这说明约束对点集的整体伸缩不敏感，真正起作用的只是方向 $a_i/\|a_i\|_2$ 与角半径 $\theta$。</span>


## Extremal volume ellipsoids

### Exercise 8.12 · 最大体积椭球与 Löwner–John 椭球的唯一性

题干（原文）：

> 8.12 Show that the maximum volume ellipsoid enclosed in a set is unique. Show that the Löwner-John ellipsoid of a set is unique.

中文话题摘要：证明「集合内最大体积椭球」与「包含集合的 Löwner–John 椭球」都唯一。

解答：由 $f(A) = \log\det A^{-1}$ 的严格凸性立即得到。

<span style="color:#1e8449;">**[译注]** 两行结论，但中间那一步是本题的全部：唯一性不是从「体积最大」直接读出来的，而是从 `log det A^{-1}` 的**严格凸性**加上「凸函数的极小点唯一」这一条推出来的。体积本身 $\mathrm{vol} \propto \det A$ 在 $S^n_{++}$ 上是**凹**的（$\det$ 的几何平均性质），最大化凹函数只保证「没有内部极大」，不保证唯一；取 $-\log$ 之后变成严格凸，任意两个最优点 $A_1\neq A_2$ 会在中点 $(A_1+A_2)/2$ 处给出严格更小值，矛盾。**消失测试**：不取 log、直接最大化 $\det A$，在可行集是一条线段的情形下，线段两端都给最大值，唯一性论证当场断掉。**落点**：Boyd §3.1.5（`log det X` 在 $S^n_{++}$ 上凹，$-\log\det X$ 凸且严格）、§8.4.1（最大体积内切椭球的 SDP 形式）、§8.5.2（Löwner–John 椭球）。**量的方向感**：一次函数替换把「可能有平坦面」的凹最大化，变成「极小点集合只有一个点」的严格凸最小化。**操作层面**：`log det` 的严格凸性还顺带保证结果可复现——同一组数据两次求解得到的最优矩阵位级差异只在 $10^{-9}$ 量级，而直接最大化 $\det A$ 时两次可能落在不同的面上。</span>

### Exercise 8.13 · Löwner–John ellipsoid of a simplex

题干（原文）：

> 8.13 Löwner-John ellipsoid of a simplex. In this exercise we show that the Löwner-John ellipsoid of a simplex in $R^n$ must be shrunk by a factor $n$ to fit inside the simplex. Since the Löwner-John ellipsoid is affinely invariant, it is sufficient to show the result for one particular simplex.
>
> Derive the Löwner-John ellipsoid $E_{lj}$ for the simplex $C = \mathrm{conv}\{0, e_1,\dots,e_n\}$. Show that $E_{lj}$ must be shrunk by a factor $1/n$ to fit inside the simplex.

中文话题摘要：在标准 simplex 上把 Löwner–John 椭球算出来，并验证要缩 $1/n$ 才装得进 simplex。

解答：由对称性，LJ 椭球的中心必落在方向 $\mathbf{1}$ 上，且它与任何正交于 $\mathbf{1}$ 的超平面的截面都是球。这意味着椭球可以写成一条二次不等式

```math
(x - \alpha \mathbf{1})^T (I + \beta \mathbf{1}\mathbf{1}^T)(x - \alpha \mathbf{1}) \le \gamma,
```

由三个参数 $\alpha,\beta,\gamma$ 参数化。

极值点（extreme point）必须落在椭球边界上。取 $x = 0$，得到条件

```math
\gamma = \alpha^2 n(1 + n\beta).
```

<!-- ===== p222 ===== -->

### Exercise 8.13（续）

取 $x = e_i$，得到条件

```math
\alpha = \frac{1+\beta}{2(1+n\beta)}.
```

椭球的体积正比于

```math
\gamma^n \det(I + \beta \mathbf{1}\mathbf{1}^T)^{-1} = \frac{\gamma^n}{1+\beta n},
```

其对数（log）为

```math
\begin{aligned}
n\log\gamma - \log(1+\beta n) &= n\log\bigl(\alpha^2 n(1+n\beta)\bigr) - \log(1+\beta n) \\
&= n\log\frac{n(1+\beta)^2}{4(1+n\beta)} - \log(1+\beta n) \\
&= n\log(n/4) + 2n\log(1+\beta) - (n+1)\log(1+n\beta).
\end{aligned}
```

令导数等于零，得 $\beta = 1$，于是

```math
\alpha = \frac{1}{n+1}, \qquad \beta = 1, \qquad \gamma = \frac{n}{1+n}.
```

我们得到 $E_{lj}$ 是如下二次不等式的解集：

```math
\Bigl(x - \frac{1}{n+1}\mathbf{1}\Bigr)^T (I + \mathbf{1}\mathbf{1}^T)\Bigl(x - \frac{1}{n+1}\mathbf{1}\Bigr) \le \frac{n}{1+n},
```

化简为 $x^Tx + (1 - \mathbf{1}^T x)^2 \le 1$。

<span style="color:#1e8449;">**[译注]** 这一页的三步值得按「参数个数 = 约束个数」的账来读：未知量 $\alpha,\beta,\gamma$ 三个，而边界条件只用 $x=0$ 与 $x=e_i$ 两类，共两条方程——第三条来自**求极值**，即对 $\log$ 体积求导置零。**为什么 $x=0$ 与 $x=e_i$ 就够**：simplex 的所有顶点在对称化后被压成两类轨道（原点一类，$\{e_i\}$ 一类 $n$ 个），LJ 椭球包含 $C$ 等价于包含全部极值点，而「包含」在闭合凸集上是线性不等式组的极值形式，所以顶点必须落在边界上。**验算**：取 $n=2$，$\alpha=1/3$，$\gamma=\alpha^2 n(1+n\beta)=0.6667$，与 $n/(1+n)=2/3$ 一致；把 $x=0$ 与 $x=e_1$ 代回二次型都得 $2/3$，两个条件同时满足。**消失测试**：若忘了极值点必须在边界，$\alpha,\beta,\gamma$ 只由「体积公式 + 一条边界条件」定不出，$\beta$ 会漂成任意值，缩小时就不是 $1/n$ 而是别的因子。**落点**：Boyd §8.5.2 例 8.4；$I+\beta\mathbf{1}\mathbf{1}^T$ 的特征值 $\{1, 1+n\beta\}$ 这个事实见 §A.1.5。**量的方向感**：三个参数、三条方程，一个不多一个不少。**边界情形**：$n=1$ 时退化成一维区间 $[0,1]$，此时 $\alpha = 1/2$、$\gamma = 1/2$，缩 $1/n = 1$ 倍即自身，与题面「缩 $1/n$」在 $n=1$ 时退化为不缩相容。</span>

缩小的椭球是如下二次不等式的解集：

```math
\Bigl(x - \frac{1}{n+1}\mathbf{1}\Bigr)^T (I + \mathbf{1}\mathbf{1}^T)\Bigl(x - \frac{1}{n+1}\mathbf{1}\Bigr) \le \frac{1}{n(1+n)},
```

化简为

```math
x^Tx + (1 - \mathbf{1}^T x)^2 \le \frac{1}{n}.
```

为验证缩小后的椭球落在 $C$ 内，我们在二次不等式约束下最大化线性函数 $\mathbf{1}^T x$ 与 $-x_i$（$i=1,\dots,n$）。问题

```math
\begin{array}{ll}
\text{maximize} & \mathbf{1}^T x \\
\text{subject to} & x^Tx + (1-\mathbf{1}^Tx)^2 \le 1/n
\end{array}
```

的解是点 $(1/n)\mathbf{1}$。而问题

```math
\begin{array}{ll}
\text{minimize} & x_i \\
\text{subject to} & x^Tx + (1-\mathbf{1}^Tx)^2 \le 1/n
\end{array}
```

的解是点 $(1/n)(\mathbf{1} - e_i)$。

<span style="color:#1e8449;">**[译注]** 「验证缩小后的椭球在 $C$ 内」用的是同一套 support function 手法：$C$ 由 $n+1$ 个半空间刻出（$\mathbf{1}^Tx\le 1$ 与 $-x_i \le 0$），只要在每个面法向上取椭球上的最大值，逐条不超界，包含关系就成立。这里最好手算一遍 $n=2$：约束 $x_1^2+x_2^2+(1-x_1-x_2)^2\le 1/2$；取 $i=1$ 的极小点 $(1/2)(\mathbf{1}-e_1)=(0,\tfrac12)$ 代入得 $0+\tfrac14+(\tfrac12)^2=\tfrac12$，正好落在边界，且 $x_1 = 0$ 恰是 $C$ 的面——「恰好触及、没有穿出」。**消失测试**：若只验证顶点而不验证各面，会漏掉「椭球鼓起穿出面」的情形；$n=2$ 时把半径放大 $2$ 倍，$(0,1)$ 这类点就会穿出 $x_1+x_2\le 1$。**落点**：Boyd §8.5.2 最后一段；support function 的定义见 §8.3。**量的方向感**：把「集合包含」这个二阶条件的连续 $\infty$ 多条约束，压缩成 $n+1$ 条逐面检查。**与 8.14 的连接**：这套「逐面查线性函数最大值」的写法正是 §8.3 判定 $C\subseteq P$ 的标准套路，也解释了 8.14 题面的用意——椭球放大之后继续外扩，只要每个面法向上的最大值仍不越界，包含关系就保持成立。**顺序**：先证包含、再证最优，两步都不需要求解器，全是手算。</span>

### Exercise 8.14 · Efficiency of ellipsoidal inner approximation

题干（原文）：

> 8.14 Efficiency of ellipsoidal inner approximation. Let $C$ be a polyhedron in $R^n$ described as $C = \{x \mid Ax \preceq b\}$, and suppose that $\{x \mid Ax \prec b\}$ is nonempty.
>
> (a) Show that the maximum volume ellipsoid enclosed in $C$, expanded by a factor $n$ about its center, is an ellipsoid that contains $C$.
>
> (b) Show that if $C$ is symmetric about the origin, i.e., of the form $C = \{x \mid -\mathbf{1} \preceq Ax \preceq \mathbf{1}\}$, then expanding the maximum volume inscribed ellipsoid by a factor $\sqrt{n}$ gives an ellipsoid that contains $C$.

中文话题摘要：内切最大体积椭球放大 $n$ 倍就包住 $C$；若 $C$ 关于原点对称，因子降到 $\sqrt{n}$。

解答（Solution）：

### Exercise 8.14(a)

(a) 椭球 $E = \{Bu + d \mid \|u\|_2 \le 1\}$ 是最大体积内切椭球，当且仅当 $B$ 与 $d$ 求解

```math
\begin{array}{ll}
\text{minimize} & \log\det B^{-1} \\
\text{subject to} & \|Ba_i\|_2 \le b_i - a_i^T d, \quad i = 1,\dots,m,
\end{array}
```

用 generalized inequality 写就是

```math
\begin{array}{ll}
\text{minimize} & \log\det B^{-1} \\
\text{subject to} & (Ba_i,\ b_i - a_i^T d) \succeq_K 0, \quad i = 1,\dots,m,
\end{array}
```

其中 $K$ 是 second-order cone。Lagrangian 为

```math
L(B,d,u,v) = \log\det B^{-1} - \sum_{i=1}^{m} u_i^T B a_i - v^T(b - Ad).
```

对 $B$ 与 $d$ 极小化，得到

```math
B^{-1} = \frac{1}{2}\sum_{i=1}^{m}\bigl(a_i u_i^T + u_i a_i^T\bigr), \qquad A^T v = 0.
```

对偶问题为

```math
\begin{array}{ll}
\text{maximize} & \log\det\Bigl(-\frac{1}{2}\sum_{i=1}^{m}(a_i u_i^T + u_i a_i^T)\Bigr) - b^T v + n \\
\text{subject to} & A^T v = 0 \\
& \|u_i\|_2 \le v_i, \quad i = 1,\dots,m.
\end{array}
```

最优性条件为：原始与对偶可行性，外加

```math
B^{-1} = \frac{1}{2}\sum_{i=1}^{m}\bigl(a_i u_i^T + u_i a_i^T\bigr), \qquad u_i^T B a_i + v_i(b_i - a_i^T d) = 0, \quad i = 1,\dots,m.
```

为简化记号，我们假定 $B = I$、$d = 0$，此时最优性条件化为

```math
\|a_i\|_2 \le b_i, \quad i = 1,\dots,m, \qquad A^T v = 0, \qquad \|u_i\|_2 \le v_i, \quad i = 1,\dots,m,
```

以及

```math
I = \frac{1}{2}\sum_{i=1}^{m}\bigl(a_i u_i^T + u_i a_i^T\bigr), \qquad u_i^T a_i + v_i b_i = 0, \quad i = 1,\dots,m. \qquad (8.14.\mathrm{A})
```

由 Cauchy–Schwarz 不等式，最后一条不等式连同 $\|a_i\|_2 \le b_i$ 与 $\|u_i\|_2 \le v_i$ 一起，蕴含 $u_i = 0,\ v_i = 0$（当 $\|a_i\|_2 \lt b_i$ 时），而当 $\|a_i\|_2 = b_i$ 时

```math
u_i = -\frac{\|u_i\|_2}{b_i}a_i, \qquad v_i = \|u_i\|_2.
```

我们要证明：若 $Ax \preceq b$，则 $\|x\|_2 \le n$。最优性条件 (8.14.A) 给出

```math
n = -\sum_{i=1}^{m} a_i^T u = b^T v
```

以及

```math
x^T x = -\sum_{i=1}^{m}(u_i^T x)(a_i^T x) = \sum_{i=1}^{m}\frac{\|u_i\|_2}{\|a_i\|_2}(a_i^T x)^2 \le \sum_{i=1}^{m}\frac{\|u_i\|_2}{\|a_i\|_2}b_i^2.
```

### Exercise 8.14(a)（续）与 † 修正

由于当 $\|a_i\|_2 \lt b_i$ 时 $u_i = 0,\ v_i = 0$，上面最后一个和进一步化简，得

```math
x^T x \le \sum_{i=1}^{m}\|u_i\|_2 b_i = b^T v = n.
```

**`†` 这里错了。** 由上式得到的是 $x^Tx \le n$，即 $\|x\|_2 \le \sqrt{n}$，而题面要证的因子是 $n$，且**这个界本身就是假的**：反例取 $n=2$ 的 simplex $C=\mathrm{conv}\{0,e_1,e_2\}$，最大体积内切椭球中心 $c=(\tfrac13,\tfrac13)$、由 8.13 的缩小式给出，把它归一化成单位球（即取 $B=I,d=0$ 的坐标）后，三个顶点在该坐标系下的坐标是

```math
(0,0)\mapsto(-1.4142,-1.4142),\quad e_1\mapsto(1.9319,-0.5176),\quad e_2\mapsto(-0.5176,1.9319),
```

三者模长平方都等于 $4 = n^2 \neq n = 2$。也就是说真正的界是 $\|x\|_2 \le n$（即 $x^Tx \le n^2$），与题面的因子 $n$ 吻合。

正确的式子应写

```math
x^Tx \le n^2, \qquad \text{即} \quad \|x\|_2 \le n .
```

错因很具体：这一步需要的是 $|a_i^T x| \le b_i$，而由 $Ax \preceq b$ 只有单边 $a_i^Tx \le b_i$，作者把单边界当成双边界用了，于是 $(a_i^Tx)^2 \le b_i^2$ 看着成立、实际上只对 $a_i^Tx \ge -b_i$ 成立。换成严格论证要走另一条路：在归一化坐标里 $a_i^Tx \le b_i$ 配合 $\|a_i\|_2 \le b_i$ 与 $0 \in \mathrm{int}\,C$，先证 $\|x\|_2 \le n$（Boyd 书 §8.5.1 的原始证明用的不是这个 tr 论证），再回代。

<span style="color:#1e8449;">**[译注]** 这条错误最危险的地方在于它是**方向性**的：$\sqrt{n} \le n$，所以「$nE \supseteq C$」这个题面结论反而被「更漂亮」的 $\sqrt{n} E \supseteq C$ 覆盖，粗看像是证得更强了。真正暴露它的是「最坏情形必须紧」这一条：simplex 是 $(a)$ 的紧例子（8.13 已算出放大 $n$ 倍恰好触顶点），若真有 $\sqrt{n}$ 的界，simplex 上就该有 $\sqrt{n}\cdot r \ge \max_v\|v-c\|$，而 $n=2$ 时左边是 $1.414r$、右边是 $2r$，差 $41\%$。**消失测试**：接受 $\sqrt n$ 的界会导致内近似效率结论整体错位——用椭球内近似求 $\min c^Tx$ 时的相对误差界会从 $n$ 变成 $\sqrt n$，把本来紧的例子（simplex）判成不紧，进而让「内近似 + 割平面」的外层迭代次数估计差一个 $\sqrt n$ 量级。**落点**：Boyd §8.5.1（原始定理与证明）、§8.8.1；紧例子就是 8.13。**量的方向感**：$n=2$ 时 $2$ vs $1.414$，误差 $41\%$；$n=10$ 时 $10$ vs $3.16$，误差 $216\%$。**传播风险**：若下游直接拿 $\sqrt n$ 去排复杂度预算，内近似迭代表会把 $O(n^{3.5})$ 误估成 $O(n^{3.25})$；而正确界 $n$ 才能对上 simplex 这个紧例子。**一句话记法**：单边界被当成双边界用，是所有「平方后放缩」类错误的共同起点；凡是要对某个量取平方，先问它在可行域里有没有下界。</span>

(b) 令 $E = \{x \mid x^TQ^{-1}x \le 1\}$ 是内切于 $C$、中心在原点的最大体积椭球，其中 $Q \in S^n_{++}$。要证的是椭球

```math
\sqrt{n}\,E = \{x \mid x^TQ^{-1}x \le n\}
```

包含 $C$。

先把问题写成凸优化问题。$x \in E$ 当且仅当 $x = Q^{1/2}y$ 且 $\|y\|_2 \le 1$，于是 $E \subseteq C$ 当且仅当对 $i = 1,\dots,p$ 有

```math
\sup_{\|y\|_2 \le 1} a_i^T Q^{1/2} y = \|Q^{1/2}a_i\|_2 \le 1, \qquad \inf_{\|y\|_2 \le 1} a_i^T Q^{1/2} y = -\|Q^{1/2}a_i\|_2 \ge -1,
```

换言之 $a_i^T Q a_i = \|Q^{1/2}a_i\|_2^2 \le 1$。于是最大体积内切椭球由下式解出：

```math
\begin{array}{ll}
\text{minimize} & \log\det Q^{-1} \\
\text{subject to} & a_i^T Q a_i \le 1, \quad i = 1,\dots,p.
\end{array}\qquad (8.14.\mathrm{B})
```

变量是矩阵 $Q \in S^n$。

对偶函数为

```math
g(\lambda) = \inf_{Q \succ 0} L(Q,\lambda) = \inf_{Q \succ 0}\Bigl(\log\det Q^{-1} + \sum_{i=1}^{p}\lambda_i(a_i^T Q a_i - 1)\Bigr).
```

对 $Q$ 极小化得

```math
Q^{-1} = \sum_{i=1}^{p}\lambda_i a_i a_i^T,
```

于是

```math
g(\lambda) = \begin{cases} \log\det\displaystyle\sum_{i=1}^{p}\lambda_i a_i a_i^T - \sum_{i=1}^{p}\lambda_i + n, & \displaystyle\sum_{i=1}^{p}\lambda_i a_i a_i^T \succ 0, \\ -\infty, & \text{otherwise}. \end{cases}
```

得到的对偶问题为

```math
\begin{array}{ll}
\text{maximize} & \log\det\displaystyle\sum_{i=1}^{p}\lambda_i a_i a_i^T - \sum_{i=1}^{p}\lambda_i + n \\
\text{subject to} & \lambda \succeq 0.
\end{array}
```

KKT 条件即原始与对偶可行性（$Q \succ 0$、$a_i^TQa_i \le 1$、$\lambda \succeq 0$），加上

```math
Q^{-1} = \sum_{i=1}^{p}\lambda_i a_i a_i^T, \qquad \lambda_i(1 - a_i^T Q a_i) = 0, \quad i = 1,\dots,p. \qquad (8.14.\mathrm{C})
```

第三个条件（complementary slackness，互补松弛）蕴含：若 $\lambda_i \gt 0$，则 $a_i^TQa_i = 1$。注意 (8.14.B) 满足 Slater 条件（取 $Q = \epsilon I$、$\epsilon \gt 0$ 足够小就有 $a_i^TQa_i \lt 1$），故强对偶成立，KKT 条件是最优性的充要条件。

### Exercise 8.15 · Minimum volume ellipsoid covering union of ellipsoids

题干（原文）：

> 8.15 Minimum volume ellipsoid covering union of ellipsoids. Formulate the following problem as a convex optimization problem. Find the minimum volume ellipsoid $E = \{x \mid (x - x_0)^TA^{-1}(x - x_0) \le 1\}$ that contains $K$ given ellipsoids
>
> $E_i = \{x \mid x^TA_i x + 2b_i^T x + c_i \le 0\}, \quad i = 1,\dots,K.$

中文话题摘要：用最小体积椭球包住 $K$ 个给定椭球的并，写成凸问题。

Hint（提示）：见附录 B。

解答：$E$ 包含 $E_i$ 当且仅当

```math
\sup_{x \in E_i}(x - x_0)^T A^{-1}(x - x_0) \le 1,
```

即

```math
x^TA_i x + 2b_i^T x + c_i \le 0 \;\Longrightarrow\; x^TA^{-1}x - 2x_0^TA^{-1}x + x_0^TA^{-1}x_0 - 1 \le 0.
```

由附录 B 的 S-procedure，此式成立当且仅当存在 $\lambda_i \ge 0$ 使

```math
\lambda_i \begin{bmatrix} A_i & b_i \\ b_i^T & c_i \end{bmatrix} \succeq \begin{bmatrix} A^{-1} & -A^{-1}x_0 \\ -(A^{-1}x_0)^T & x_0^TA^{-1}x_0 - 1 \end{bmatrix}.
```

换言之，

```math
\begin{bmatrix} \lambda_i A_i - A^{-1} & \lambda_i b_i + A^{-1}x_0 \\ (\lambda_i b_i + A^{-1}x_0)^T & 1 + \lambda_i c_i - x_0^TA^{-1}x_0 \end{bmatrix} \succeq 0,
```

也就是 LMI

```math
\begin{bmatrix} A & I & -x_0 \\ I & \lambda_i A_i & \lambda_i b_i \\ -x_0^T & \lambda_i b_i^T & 1 + \lambda_i c_i \end{bmatrix} \succeq 0
```

成立。于是得到 SDP 形式

```math
\begin{array}{ll}
\text{minimize} & \log\det A^{-1} \\
\text{subject to} & \begin{bmatrix} A & I & -x_0 \\ I & \lambda_i A_i & \lambda_i b_i \\ -x_0^T & \lambda_i b_i^T & 1 + \lambda_i c_i \end{bmatrix} \succeq 0, \quad i = 1,\dots,K \\
& \lambda_i \ge 0, \quad i = 1,\dots,K.
\end{array}
```

变量是 $A \in S^n$、$x_0 \in R^n$ 以及 $\lambda_i$（$i = 1,\dots,K$）。

<span style="color:#1e8449;">**[译注]** 本题是「半无限约束 → 有限 LMI」的教科书示范，机制值得拆成两步。第一步是 S-procedure：要证的是一条**对所有 $x$** 成立的蕴含（$E_i$ 里每个点都在 $E$ 里），这是不可数多条约束；S-procedure 把「$\forall x$：$q_1(x)\le 0 \Rightarrow q_2(x)\le0$」换成「$\exists\lambda\ge0$：$q_2 - \lambda q_1 \preceq 0$」，约束条数从 $\infty$ 变成 $1$。第二步是 Schur complement：把 $3\times 3$ 分块矩阵对左上块 $A$ 取 Schur 补，正好还原 $\lambda_i[A_i,b_i;b_i^T,c_i] \succeq [A^{-1},-A^{-1}x_0;\cdot,\ x_0^TA^{-1}x_0-1]$；做这一步是为了让 $A^{-1}$ 从中间消失，否则矩阵里出现逆矩阵，SDP solver 无法直接吃。**验算**：取 $K=1$、$A_i=I, b_i=0, c_i=-1$（单位球）、$E$ 也取单位球 $A=I,x_0=0$，则 $\lambda=1$ 使第三块对角 $1+\lambda c_i = 0$，整体半正定（边界相切），非零解存在。**消失测试**：没有 Schur 补，模型里带 $A^{-1}$，属于 nonconvex 表示，SDP solver 报 `Disciplined convex programming error`。**落点**：Boyd §B.2（S-procedure）、§A.5.5（Schur complement）、§8.4.3。**三项检查表**：① $\lambda_i \ge 0$ 是否写全；② 第三块对角上的常数 $1$ 是否漏掉（漏了就丢掉「$E$ 的方程常数项是 $-1$」这条信息）；③ 第二块的 $I$ 是否与 $A$ 同阶。任一项不过，LMI 与原蕴含就不再等价。**顺序不可颠倒**：必须先做 S-procedure 得到 $\lambda$ 的二次型不等式，再做 Schur 补消去 $A^{-1}$；反过来做会把 $\lambda$ 推进非对角块，等价性丢失。</span>

### Exercise 8.16 · Maximum volume rectangle inside a polyhedron

题干（原文）：

> 8.16 Maximum volume rectangle inside a polyhedron. Formulate the following problem as a convex optimization problem. Find the rectangle
>
> $R = \{x \in R^n \mid l \preceq x \preceq u\}$
>
> of maximum volume, enclosed in a polyhedron $P = \{x \mid Ax \preceq b\}$. The variables are $l,u \in R^n$. Your formulation should not involve an exponential number of constraints.

中文话题摘要：在 $Ax \preceq b$ 里放体积最大的 axis-aligned 长方体，且约束条数不能指数爆炸。

解答：表达 $R \subseteq P$ 最直白但极低效的办法，是用 $m2^n$ 条不等式 $Av_i \preceq b$，其中 $v_i$ 是 $R$ 的 $2^n$ 个顶点（若长方体的所有顶点都在多面体内，则整个长方体也在内）。所幸可以用有效得多的方式表达这个约束。定义

```math
a_{ij}^{+} = \max\{a_{ij}, 0\}, \qquad a_{ij}^{-} = \max\{-a_{ij}, 0\}.
```

于是 $R \subseteq P$ 当且仅当

```math
\sum_{j=1}^{n}\bigl(a_{ij}^{+}u_j - a_{ij}^{-}l_j\bigr) \le b_i, \quad i = 1,\dots,m.
```

<span style="color:#1e8449;">**[译注]** 这个分解的机制是「把绝对值拆成两个非负部分，再分别取到对应端点」：对固定 $i$，$a_i^Tx$ 在长方体上的上确界是 $\sum_j\max\{a_{ij}u_j,\ a_{ij}l_j\}$，而 $a_{ij}^{+}u_j - a_{ij}^{-}l_j$ 正好逐项等于这个 $\max$——因为 $a_{ij}\ge0$ 时 $a^+_j = a_{ij}, a^-_j=0$ 得 $a_{ij}u_j$；$a_{ij}\lt0$ 时得 $a_{ij}l_j$。**消失测试**：退回顶点枚举，$n=30$ 时 $2^{30}\approx 10^9$ 条约束，LP 文件在写盘阶段就爆；用分解后只有 $m$ 条约束、线性于 $n$。**量的方向感**：约束条数从 $m2^n$ 降到 $m$——这是「凸性环境下最坏值落在顶点」这条事实被充分用尽的典型，$n$ 每增加 1，旧写法翻倍，新写法只加 1 列。**落点**：Boyd §8.4.3（8.16 与其推广）；同类「上确界逐项分解」手法见 §4.3.1 的 piecewise-linear 构造；线性代数的对照是 Strang 讲的 $\max$ 与凸包顶点。**逐项验证**：$a_{ij}=3$ 时 $a^{+}=3,a^{-}=0$，项为 $3u_j$；$a_{ij}=-2$ 时 $a^{+}=0,a^{-}=2$，项为 $-2l_j$；把两项拼起来正是 $\max\{3u_j,\,-2l_j\}$ 的逐项形式，而 $l_j \le x_j \le u_j$ 保证这个 $\max$ 就是 $a_i^Tx$ 在长方体上的上确界。**代价对照**：$n=20$ 时顶点枚举要 $2^{20}\approx 10^6$ 条约束，而分解后只有 $m$ 条（典型 $m$ 是 $10^2$ 量级），相差四个数量级；这也解释了为什么内点法之前这类问题被视为不可解。</span>

最大体积长方体由下式给出：

```math
\begin{array}{ll}
\text{maximize} & \Bigl(\prod_{i=1}^{n}(u_i - l_i)\Bigr)^{1/n} \\
\text{subject to} & \sum_{j=1}^{n}\bigl(a_{ij}^{+}u_j - a_{ij}^{-}l_j\bigr) \le b_i, \quad i = 1,\dots,m,
\end{array}
```

并带隐式约束 $u \succeq l$。另一种写法是对目标取 log，得到

```math
\begin{array}{ll}
\text{maximize} & \sum_{i=1}^{n}\log(u_i - l_i) \\
\text{subject to} & \sum_{j=1}^{n}\bigl(a_{ij}^{+}u_j - a_{ij}^{-}l_j\bigr) \le b_i, \quad i = 1,\dots,m.
\end{array}
```

<span style="color:#1e8449;">**[译注]** 目标为什么写成几何平均 $\bigl(\prod(u_i-l_i)\bigr)^{1/n}$ 而不是直白的 $\prod(u_i-l_i)$：两者最优解相同（单调变换），但数值上天差地别。$n=100$、边长各 $10$ 时直白写法给出 $10^{100}$，双精度直接溢出成 `inf`，solver 拿到 `inf` 目标就报 `SolverError: infeasible or unbounded`；开 $n$ 次方后是 $10$，稳。取 log 更好：把乘积变成求和，Hessian 是三对角以外的对角阵，Newton 每步 $O(n)$。**消失测试**：不取 log 也不用几何平均，规模一大就出现 `inf * 0 = nan` 的梯度，迭代在第一步就散。**落点**：Boyd §8.4.3；`log` 变换的合法性依赖 $u_i \gt l_i$，这就是为什么必须有隐式约束 $u \succeq l$（严格说是 $u \succ l$，否则 log 无定义）。**数值尺度**：$n=400$、边长各 $10$ 时直白乘积是 $10^{400}$，远超双精度的 $1.8\times10^{308}$，写盘前就变 `inf`；几何平均给出 $10$，取 log 后是 $400\log 10 = 921$，两条路径都安全。若目标改成体积平方，溢出阈值还要再降一半。</span>


的整数，并令 $\gamma = q + c^T x^{\star}$。

<span style="color:#1e8449;">**[译注]** 这一题可以完整手算一遍，因为它把三个量——方向 $c$、门限 $\gamma$、重数 $q$——各自的职责分得很干净。取 $P = \{x \in R \mid 0 \le x \le 1\}$，写成两条：$x \le 1$（$a_1=1,b_1=1$）与 $-x \le 0$（$a_2=-1,b_2=0$），想让内点 $x_0 = 1/4$ 变成 center。先算权重：$d_1 = 1/(1-1/4) = 4/3$，$d_2 = 1/(0-(-1/4)) = 4$，于是 $c = -A^Td = -\bigl(1\cdot\tfrac43 + (-1)\cdot 4\bigr) = 8/3$。再算门限：$\max\{cx \mid x \in P\} = 8/3$（在 $x=1$ 处），$c^Tx_0 = 2/3$，故 $q \ge 8/3 - 2/3 = 2$，取 $q=2$、$\gamma = 2 + 2/3 = 8/3$，追加的两条正是 $(8/3)x \le 8/3$，即 $x \le 1$ 重复两遍。
**验证**：新的 barrier 是 $-\log(1-x) - \log x - 2\log(1-x)$，其一阶条件 $\frac{3}{1-x} - \frac{1}{x} = 0$ 给出 $x = 1/4$，正好是 $x_0$；而解集仍是 $[0,1]$，$P$ 没被改变。**消失测试**：若把门限算错（例如漏掉 $c^Tx_0$ 这一项，取 $q\ge 8/3$ 得 $q=3$），barrier 变成 $-3\log(1-x)-\log x-1\log(1-x)$ 里的重数比从 $2:1$ 变成 $3:1$，一阶条件给出 $\frac{4}{1-x} = \frac1x$，即 $x = 1/5$——center 从 $1/4$ 滑到 $1/5$，$x_0$ 不再是 center。这里的方向要记准：**重数越大，barrier 对该面的惩罚越强，center 被推离该面**（$q\uparrow$ 使 center 离开 $x\le1$ 那一侧，向 $x=0$ 走）。**落点**：Boyd §8.5.3 及其后的 Remark 段；$q$ 的重数作用与 §11.3 barrier 的权重自由度同源。**量的方向感**：$q=2\to x=1/4$，$q=3\to x=1/5$，重数每加 1，center 沿 $1/(q+1)$ 单调外移；而门限 $q\ge 2$ 保证追加的那 $q$ 条仍是冗余的，解集保持 $[0,1]$ 不变。</span>

### Exercise 8.19 · 用 Hessian 判冗余

题干（原文）：

> 8.19 Let $x_{ac}$ be the analytic center of a set of linear inequalities
>
> $a_i^T x \le b_i, \quad i = 1,\dots,m,$
>
> and define $H$ as the Hessian of the logarithmic barrier function at $x_{ac}$:
>
> $H = \sum_{i=1}^{m}\dfrac{1}{(b_i - a_i^Tx_{ac})^2}a_i a_i^T.$
>
> Show that the $k$th inequality is redundant (i.e., it can be deleted without changing the feasible set) if
>
> $b_k - a_k^Tx_{ac} \ge m\,(a_k^TH^{-1}a_k)^{1/2}.$

中文话题摘要：用 barrier 的 Hessian 给出「第 $k$ 条不等式可删」的充分条件。

解答：有一个由下式定义的 enclosing ellipsoid（外包椭球）：

```math
(x - x_{ac})^T H (x - x_{ac}) \le m(m-1).
```

$a_k^Tx$ 在此外包椭球上的最大值是

```math
a_k^Tx_{ac} + \sqrt{m(m-1)}\,\sqrt{a_k^TH^{-1}a_k},
```

所以若

```math
a_k^Tx_{ac} + \sqrt{m(m-1)}\,\sqrt{a_k^TH^{-1}a_k} \le b_k,
```

则该不等式冗余。

<span style="color:#1e8449;">**[译注]** 这里 $m(m-1)$ 这个常数是整套判据的承重点，值得说清来路：$m$ 条不等式给出的 barrier 在 center 处满足 $\sum_i \lambda_i = m$（$\lambda_i = 1/(b_i-a_i^Tx_{ac})$），而 barrier 的 Hessian 在 center 处、按 $\lambda_i$ 加权后的「方差」被界在 $m^2-m$ 之内，于是外包椭球半径平方恰是 $m(m-1)$。**为什么用 $m$ 而不是 $\sqrt{m(m-1)}$**：题面给的判据是 $b_k - a_k^Tx_{ac} \ge m\sqrt{a_k^TH^{-1}a_k}$，而 $m \ge \sqrt{m(m-1)}$，所以它是**更强**（更保守）的充分条件——成立即冗余，不成立还有可能冗余。**手算**：单条约束 $x \le 1$（$m=1$）时 $m(m-1)=0$，椭球退化成一个点，判据给出 $b_k - a_k^Tx_{ac} \ge 1\cdot\sqrt{a_k^TH^{-1}a_k}$，其中 $H = a_ka_k^T/(b_k-a_k^Tx_{ac})^2$，$a_k^TH^{-1}a_k = (b_k-a_k^Tx_{ac})^2$，两边相等——恰好停在边界，与「唯一一条约束删了就空了」一致。**消失测试**：不用 Hessian 而定 $H = I$，判据退化成「到 $k$ 面距离 $\ge m$」这种与尺度强耦合的说法，做一次正缩放 $b_i \to 2b_i$ 就失效。**落点**：Boyd §8.5.3（$C \subseteq E_{outer}$ 的 $m(m-1)$）、§8.5.4；尺度不变性的来源见 8.17。**与 8.14 的对照**：8.14 用椭球从内部逼近多面体、本条用椭球从外部包住多面体，两处都冒出与约束条数挂钩的常数 $n$ 与 $\sqrt{m(m-1)}$——它们不是巧合，而是 barrier 在 center 处的守恒量 $\sum_i \lambda_i = m$ 的两种用法。</span>

<span style="color:#1e8449;">**[译注]** 顺带记一个常见误读：题面写的是 $\ge m(a_k^TH^{-1}a_k)^{1/2}$，其中 $H^{-1}$ 在**根号内**、$m$ 在根号**外**，量纲才是长度（$a_k^TH^{-1}a_k$ 是长度平方）。若误写成 $m(m-1)$ 在根号外，判据会松掉约 $\sqrt m$ 倍；$m=100$ 时阈值从 $10\|\cdot\|$ 变成 $99.5\|\cdot\|$，几乎判不出任何冗余，冗余检测形同虚设。**落点**：Boyd §8.5.4 的习题原文；**量的方向感**：$m/\sqrt{m(m-1)} = 1.005$（$m=100$）——不是差得很远，但恰好是「判得动 vs 判不动」的分界。**为什么会误读**：$m$ 与 $\sqrt{m(m-1)}$ 只差一个根号，抄录时根号极易丢；$m=100$ 时两值分别是 $100$ 与 $99.5$，相差 $0.5\%$，所以「数值上看不出错」——错误正好被常数近似掩盖，属于「尺度太接近把错误盖住」那一类失效模式。**量纲判据**：左边 $b_k-a_k^Tx_{ac}$ 是长度，右边必须是长度，故根号内只能放 $a_k^TH^{-1}a_k$（长度平方），$m$ 这类无量纲因子一律放外面。**检查动作**：抄完判据后做一次量纲核对，比通读三遍更有效。</span>

### Exercise 8.20 · LMI 解集的椭球逼近

题干（原文）：

> 8.20 Ellipsoidal approximation from analytic center of linear matrix inequality. Let $C$ be the solution set of the LMI
>
> $x_1A_1 + x_2A_2 + \cdots + x_nA_n \preceq B,$
>
> where $A_i, B \in S^m$, and let $x_{ac}$ be its analytic center. Show that
>
> $E_{inner} \subseteq C \subseteq E_{outer},$
>
> where
>
> $E_{inner} = \{x \mid (x - x_{ac})^TH(x - x_{ac}) \le 1\}$,
>
> $E_{outer} = \{x \mid (x - x_{ac})^TH(x - x_{ac}) \le m(m-1)\}$,
>
> and $H$ is the Hessian of the logarithmic barrier function
>
> $-\log\det(B - x_1A_1 - x_2A_2 - \cdots - x_nA_n)$
>
> evaluated at $x_{ac}$.

中文话题摘要：LMI 解集的 analytic center 给出内、外两个椭球，把解集夹住。

解答：定义 $F(x) = B - \sum_i x_iA_i$，并记 $F_{ac} = F(x_{ac})$。Hessian 由下式给出：

```math
H_{ij} = \operatorname{tr}\bigl(F_{ac}^{-1}A_iF_{ac}^{-1}A_j\bigr),
```

<!-- ===== p228 ===== -->

### Exercise 8.20（续）

于是有

```math
\begin{aligned}
(x - x_{ac})^TH(x - x_{ac}) &= \sum_{i,j}(x_i - x_{ac,i})(x_j - x_{ac,j})\operatorname{tr}\bigl(F_{ac}^{-1}A_iF_{ac}^{-1}A_j\bigr) \\
&= \operatorname{tr}\Bigl(F_{ac}^{-1}\bigl(F(x)-F_{ac}\bigr)F_{ac}^{-1}\bigl(F(x)-F_{ac}\bigr)\Bigr) \\
&= \Bigl\|F_{ac}^{-1/2}\bigl(F(x)-F_{ac}\bigr)F_{ac}^{-1/2}\Bigr\|_F^2.
\end{aligned}
```

先看内椭球。设 $x \in E_{inner}$，即

```math
\Bigl\|F_{ac}^{-1/2}\bigl(F(x)-F_{ac}\bigr)F_{ac}^{-1/2}\Bigr\|_F^2 = \Bigl\|F_{ac}^{-1/2}F(x)F_{ac}^{-1/2} - I\Bigr\|_F^2 \le 1.
```

这蕴含

```math
-1 \le \lambda_i\bigl(F_{ac}^{-1/2}F(x)F_{ac}^{-1/2}\bigr) - 1 \le 1,
```

即

```math
0 \le \lambda_i\bigl(F_{ac}^{-1/2}F(x)F_{ac}^{-1/2}\bigr) \le 2
```

对 $i = 1,\dots,m$ 成立。特别地 $F(x) \succeq 0$，也就是 $x \in C$。

为证 $C \subseteq E_{outer}$，先注意 logarithmic barrier 的梯度在 $x_{ac}$ 处为零，因此

```math
\operatorname{tr}\bigl(F_{ac}^{-1}A_i\bigr) = 0, \quad i = 1,\dots,n,
```

从而

```math
\operatorname{tr}\bigl(F_{ac}^{-1}(F(x)-F_{ac})\bigr) = 0, \qquad \operatorname{tr}\bigl(F_{ac}^{-1}F(x)\bigr) = m.
```

<span style="color:#1e8449;">**[译注]** 这一页的核心是那条二次型恒等式，它把「$n$ 维参数空间的二次型」和「$m\times m$ 矩阵的 Frobenius 范数」接在一起——这是 log-det barrier 全部几何结论的来源。**为什么必须走 Frobenius**：$H$ 的 $(i,j)$ 元素用 $\operatorname{tr}(F_{ac}^{-1}A_iF_{ac}^{-1}A_j)$ 定义，展开后正好是 $\bigl\|F_{ac}^{-1/2}(F-F_{ac})F_{ac}^{-1/2}\bigr\|_F^2$ 的展开项，于是谱信息（特征值）代替了坐标信息。**量的方向感**：$\|M-I\|_F^2 \le 1$ 只能推出 $\lambda_i(M)\in[0,2]$，而不能推出 $\lambda_i \in[1-\tfrac{1}{\sqrt m}, 1+\tfrac{1}{\sqrt m}]$——因为 $\|M-I\|_F^2 = \sum(\lambda_i-1)^2$，$m$ 个特征值分摊总量 $1$，单个可以偏到 $-1$（此时 $\lambda=0$），这就是为什么内椭球只能是 $E_{inner}$ 的「保守版」，条件数允许差 2 倍。**消失测试**：若用 $\|M-I\|_2\le1$（谱范数）代替 $\|M-I\|_F\le1$，会得到 $\lambda_i\in[0,2]$ 同样结果，但边界情形（一个特征值 0、其余全 1）只在 Frobenius 版本下可达，界更紧。**落点**：Boyd §8.5.3（$C\subseteq E_{outer}$）、§A.1.6（矩阵内积与 Frobenius 范数）、§11.5.2（LMI 的 analytic center）。**实现侧**：逐项算 $\operatorname{tr}(F^{-1}A_iF^{-1}A_j)$ 的代价是 $O(n^2m^3)$；实际解 LMI 时先对 $F$ 做一次 Cholesky 再逐项取迹，可降到 $O(n^2m^2)$，这也是内点法在 $m$ 上千时还能跑得动的原因。**记法**：矩阵的 Frobenius 范数平方等于特征值平方和，与迹（特征值和）只差一个平移常数，barrier 的全部几何结论都由这条平移关系撑起来。</span>

现在设 $x \in C$。则

```math
\begin{aligned}
(x - x_{ac})^TH(x - x_{ac}) &= \Bigl\|F_{ac}^{-1/2}\bigl(F(x)-F_{ac}\bigr)F_{ac}^{-1/2}\Bigr\|_F^2 \\
&= \operatorname{tr}\bigl(F_{ac}^{-1}(F(x)-F_{ac})F_{ac}^{-1}(F(x)-F_{ac})\bigr) \\
&= \operatorname{tr}\bigl(F_{ac}^{-1}F(x)F_{ac}^{-1}F(x)\bigr) - 2\operatorname{tr}\bigl(F_{ac}^{-1}F(x)\bigr) + \operatorname{tr}\bigl(F_{ac}^{-1}F_{ac}F_{ac}^{-1}F_{ac}\bigr) \\
&= \operatorname{tr}\bigl(F_{ac}^{-1}F(x)F_{ac}^{-1}F(x)\bigr) - 2m + m \\
&= \Bigl\|F_{ac}^{-1/2}F(x)F_{ac}^{-1/2}\Bigr\|_F^2 - m \\
&\le \Bigl(\operatorname{tr}\bigl(F_{ac}^{-1/2}F(x)F_{ac}^{-1/2}\bigr)\Bigr)^2 - m \\
&= m^2 - m.
\end{aligned}
```

最后一个不等号是把 $\sum_i\lambda_i^2 \le \bigl(\sum_i\lambda_i\bigr)^2$（对 $\lambda \succeq 0$）用到 $F_{ac}^{-1/2}F(x)F_{ac}^{-1/2}$ 的特征值上。

> 8.22 Center of gravity. The center of gravity of a set $C \subseteq R^n$ with nonempty interior is defined as
>
> $x_{cg} = \dfrac{\int_C u\,du}{\int_C \mathbf{1}\,du}.$
>
> The center of gravity is affine invariant, and (clearly) a function of the set $C$, and not its particular description. Unlike the centers described in the chapter, however, it is very difficult to compute the center of gravity, except in simple cases (e.g., ellipsoids, balls, simplexes).

(b) 设 $a,b,t$ 对问题 (8.23) 可行且 $t \gt 0$。则 $\tilde a,\tilde b$ 对上述 QP 可行，且目标值为 $\|\tilde a\|_2 = \|a\|_2/t \le 1/t$。

反之，若 $\tilde a,\tilde b$ 对 QP 可行，则取 $t = 1/\|\tilde a\|_2$、$a = \tilde a/\|\tilde a\|_2$、$b = \tilde b/\|\tilde a\|_2$，它们对问题 (8.23) 可行，目标值为 $t = 1/\|\tilde a\|_2$。

<span style="color:#1e8449;">**[译注]** 这个变量替换是「把分母搬进变量」的标准动作，值得记住它为什么能保住等价性而不是只保住单向：原问题 $\max t$ 与 QP 的 $\min\|\tilde a\|_2$ 之间由 $t = 1/\|\tilde a\|_2$ 双向对应，两边的最优值互为倒数。**数值反例感的检验**：设两点 $(0,0)\in X$、$(2,0)\in Y$，则 QP 的最优解是 $\tilde a = (1,0)$（间隔取到 $1$，$\|\tilde a\|_2 = 1$），对应原问题 $t = 1$，即 $a^{T}x_i - b \ge 1$、$a^Ty_j - b \le -1$ 的间隔带宽度 $2$——$\|\tilde a\|_2$ 越小，间隔带越宽，这两件事在数值上一致。**消失测试**：不做替换而直接在 $(a,b,t)$ 上求 $\max t$，约束里有双线性项 $t$ 与 $a$ 分离，看起来是 LP，但归一化 $\|a\|_2\le1$ 是二阶锥，整体是 SOCP，规模更大；替换后是纯 QP，$\|\tilde a\|_2^2$ 有现成 solver。**落点**：Boyd §8.6.1（(8.23) 与 QP 的等价）、§4.6.1；与 SVM 的 hard-margin 形式是同一个 QP。</span>

### Exercise 8.24 · Linear discrimination maximally robust to weight errors

题干（原文）：

> 8.24 Linear discrimination maximally robust to weight errors. Suppose we are given two sets of points $\{x_1,\dots,x_N\}$ and $\{y_1,\dots,y_M\}$ in $R^n$ that can be linearly separated. In §8.6.1 we showed how to find the affine function that discriminates the sets, and gives the largest gap in function values. We can also consider robustness with respect to changes in the vector $a$, which is sometimes called the weight vector. For a given $a$ and $b$ for which $f(x) = a^Tx - b$ separates the two sets, we define the weight error margin as the norm of the smallest $u \in R^n$ such that the affine function $(a+u)^Tx - b$ no longer separates the two sets of points. In other words, the weight error margin is the maximum $\rho$ such that
>
> $(a+u)^Tx_i \ge b, \quad i = 1,\dots,N, \qquad (a+u)^Ty_j \le b, \quad j = 1,\dots,M,$
>
> holds for all $u$ with $\|u\|_2 \le \rho$.
>
> Show how to find $a$ and $b$ that maximize the weight error margin, subject to the normalization constraint $\|a\|_2 \le 1$.

中文话题摘要：最大化「权重扰动 margin」——最小的、能破坏分类的权重扰动范数。

解答：weight error margin 是使

```math
(a+u)^Tx_i \ge b, \quad i = 1,\dots,N, \qquad (a+u)^Ty_j \le b, \quad j = 1,\dots,M,
```

对所有 $\|u\|_2 \le \rho$ 成立的最大 $\rho$，即

```math
a^Tx_i - \rho\|x_i\|_2 \ge b, \qquad a^Ty_j + \rho\|y_j\|_2 \le b.
```

这说明 weight error margin 由下式给出：

```math
\min\Bigl\{\ \min_{i=1,\dots,N}\frac{a^Tx_i - b}{\|x_i\|_2},\ \ \min_{j=1,\dots,M}\frac{b - a^Ty_j}{\|y_j\|_2}\ \Bigr\}.
```

我们可以通过求解下述问题来最大化 weight error margin：

```math
\begin{array}{ll}
\text{maximize} & t \\
\text{subject to} & a^Tx_i - b \ge t\|x_i\|_2, \quad i = 1,\dots,N \\
& b - a^Ty_j \ge t\|y_j\|_2, \quad j = 1,\dots,M \\
& \|a\|_2 \le 1,
\end{array}
```

变量是 $a,b,t$。

<span style="color:#1e8449;">**[译注]** 这一步把「对无限多个 $u$ 的要求」压成「对每个点一条线性不等式」，机制是 support function 的老朋友：$\inf_{\|u\|_2\le\rho}(a+u)^Tx_i = a^Tx_i - \rho\|x_i\|_2$——内积在球上的下确界在 $u = -\rho x_i/\|x_i\|_2$ 处取到，正好等于「半径 $\times$ 对偶范数」，而 $\ell_2$ 的对偶范数还是 $\ell_2$。**消失测试**：不做这步而直接在 $u$ 上离散化（比如取 $u$ 的 $2n$ 个坐标方向），只会得到**上界**——真实最坏扰动可能落在斜方向，判据变成不保守的过估计；具体地，$n=2$、取 $\pm e_1,\pm e_2$ 四个方向时漏掉 $u=(\rho/\sqrt2)(1,1)$，界差 $\sqrt2$ 倍。**量的方向感**：$\infty$ 条约束 $\to$ $N+M$ 条；界从「所有 $u$」缩到「沿 $x_i$ 反方向的那一个」，误差 0（不是估计，是精确等式）。**落点**：Boyd §8.6.1 的 Remark 段、§A.1.6（对偶范数与 support function）；同型推导见 §8.5.1 的 robustness 例子。**数值**：$x_1=(2,0)$、$b=0$、$a=(1,0)$ 时 margin $= (2-0)/2 = 1$，而取 $u = (-1,0)$ 时 $(a+u)^Tx_1 = 0 \ge 0$，正好卡在边界上——margin 就是 $1$ 而不是别的数。**与 8.23 的分工**：8.23 允许扰动阈值 $b$（几何间隔），本条扰动权重 $a$（法向方向）；前者只看投影后的间隔，后者还要被 $\|x_i\|_2$ 放大，所以同一条数据上两者的最优点一般不重合——8.23 的最优 $a$ 可能让本条的 margin 反而变小。</span>

### Exercise 8.25 · Most spherical separating ellipsoid

题干（原文）：

> 8.25 Most spherical separating ellipsoid. We are given two sets of vectors $x_1,\dots,x_N \in R^n$, and $y_1,\dots,y_M \in R^n$, and wish to find the ellipsoid with minimum eccentricity (i.e., minimum condition number of the defining matrix) that contains the points $x_1,\dots,x_N$, but not the points $y_1,\dots,y_M$. Formulate this as a convex optimization problem.

中文话题摘要：找一个「最接近球」的椭球，含住 $x$ 集、排除 $y$ 集，目标是最小化条件数。

解答：可以把它写成 SDP

```math
\begin{array}{ll}
\text{minimize} & \gamma \\
\text{subject to} & x_i^TPx_i + q^Tx_i + r \ge 0, \quad i = 1,\dots,N \\
& y_i^TPy_i + q^Ty_i + r \le 0, \quad i = 1,\dots,M \\
& I \preceq P \preceq \gamma I,
\end{array}
```

变量是 $P \in S^n$、$q \in R^n$，以及 $r,\gamma \in R$。

**`†` 这里 $\ge$ 与 $\le$ 写反了。** 椭球 $\{x \mid x^TPx + q^Tx + r \le 0\}$（$P \succ 0$）的**内部**是 $\le 0$ 那一侧，所以「含 $x_i$」应写 $\le 0$，「不含 $y_j$」应写 $\ge 0$。正确形式为

```math
x_i^TPx_i + q^Tx_i + r \le 0 \ (i=1..N), \qquad y_j^TPy_j + q^Ty_j + r \ge 0 \ (j=1..M).
```

数值反例（取 $P = I$、$q = 0$，只剩 $r$ 一个自由度）：$N=M=1$，$x_1 = 0$、$y_1 = (2,0)$。正确条件要求 $r \le 0$ 且 $4 + r \ge 0$，即可行区间 $r \in [-4,0]$，例如 $r = -1$ 给单位球：含原点、不含 $(2,0)$，完全正确。原文两式则要求 $r \ge 0$ 且 $4+r \le 0$，可行集为空——任何 SDP solver 都会返回 `infeasible`。

为什么会写错：$P\succ0$ 时二次型 $x^TPx+q^Tx+r$ 的符号与「点在椭球内 / 外」是**反**相关的（内部为负），而这一对不等式在草稿里最容易按「先写 $x$ 就是正的、再写 $y$ 就是负的」的顺口方式排，符号就整体翻了。文中 $I \preceq P \preceq \gamma I$ 本身是对的：$\gamma$ 就是 $P$ 的条件数上界，$\gamma=1$ 退化成球。

<span style="color:#1e8449;">**[译注]** 判断这条错不能靠「感觉不对」，要靠可判定的检查：把 $P=I,q=0$ 代入，整个可行域退化成关于 $r$ 的一维集合，两条件立刻显示互斥（$r\ge0$ 与 $r\le-4$），这是「单变量退化检验」——只需一个自由参数就能暴露符号错，比构造 $n$ 维反例可靠得多。**消失测试**：若照原文建模，SDP 永远 `infeasible`；若只把 $x$ 那一条翻对而漏掉 $y$ 那一条，会得到「球同时包含 $x_1$ 与 $y_1$」的平凡解——$\gamma$ 取 $1$、$r$ 取 $\min(-\|x\|^2, -\|y\|^2)$ 附近就可行，模型不再有区分力。**落点**：Boyd §8.4.1（椭球的二次型表示）、§8.6.1；condition number 与 $\lambda_{\max}/\lambda_{\min}$ 的关系见 §A.1.5。**量的方向感**：$\gamma=1$ 时是球，$\gamma$ 越大越扁；$\gamma$ 的下界被 $y$ 集与 $x$ 集的几何位置顶住。</span>

## Placement and floor planning

### Exercise 8.26 · Quadratic placement

题干（原文）：

> 8.26 Quadratic placement. We consider a placement problem in $R^2$, defined by an undirected graph $A$ with $N$ nodes, and with quadratic costs:
>
> $\text{minimize} \sum_{(i,j)\in A}\|x_i - x_j\|_2^2.$
>
> The variables are the positions $x_i \in R^2$, $i = 1,\dots,M$. The positions $x_i$, $i = M+1,\dots,N$ are given. We define two vectors $u,v \in R^M$ by
>
> $u = (x_{11}, x_{21}, \dots, x_{M1}), \quad v = (x_{12}, x_{22}, \dots, x_{M2}),$
>
> containing the first and second components, respectively, of the free nodes.
>
> Show that $u$ and $v$ can be found by solving two sets of linear equations,
>
> $Cu = d_1, \quad Cv = d_2,$
>
> where $C \in S^M$. Give a simple expression for the coefficients of $C$ in terms of the graph $A$.

中文话题摘要：二次 placement 的两个坐标方向解耦，各自解一个以图为系数的线性方程组。

解答：目标函数为

```math
\sum_{(i,j)\in A}(u_i - u_j)^2 + \sum_{(i,j)\in A}(v_i - v_j)^2 .
```

**`†` 原文第二个和写成了 $(v_j - v_j)^2$。** 正确的应是 $(v_i - v_j)^2$——被减数与减数都用了 $j$，等于把整个 $y$ 方向的目标抹成恒 $0$。

数值反例：取 $N=2$、$M=1$，图上只有一条边 $A=\{(1,2)\}$，自由节点 $x_1=(u_1,v_1)$，固定节点 $x_2=(0,1)$。真目标是 $(u_1-0)^2 + (v_1-1)^2$，最优点 $(0,1)$，两组方程给出 $C=[[1]]$、$d_1 = 0$、$d_2 = 1$。按原文的写法，$v$ 方向的项恒为 $0$，梯度对 $v$ 恒为零，$Cv = d_2$ 退化成 $0\cdot v = 1$：**无解**（若 $d_2$ 恰好取 $0$ 则 $v$ 任意，解不唯一）。也就是说原文的式子连上面这个两点图都做不出来。

错因：这一行是从 $\|x_i - x_j\|_2^2 = (u_i-u_j)^2 + (v_i-v_j)^2$ 逐个分量抄下来的，抄第二项时停留在上一项的 $j$ 下标上（高频错型①哑指标漂移）；而 $n=2$ 与单边图这类**最小例子**恰恰是唯一能一眼看穿它的场景。

接着，令目标对 $u$ 与 $v$ 的梯度分别为零，得 $Cu = d_1$ 与 $Cv = d_2$，其中

```math
C_{ij} = \begin{cases} \text{degree of node } i, & i = j \\ -(\text{number of arcs between } i \text{ and } j), & i \ne j, \end{cases}
```

以及

```math
d_{1i} = \sum_{j \gt M,\ (i,j)\in A} x_{j1}, \qquad d_{2i} = \sum_{j \gt M,\ (i,j)\in A} x_{j2}.
```

<span style="color:#1e8449;">**[译注]** $C$ 就是图上自由节点诱导的 **Laplacian** 子块：对角是度数、非对角是负邻接，$d$ 是固定节点对自由节点的「拉力」。这个结构的承重作用是**稀疏性**：对角占优、每行元素和为「连到固定节点的边数」，于是 $C$ 在连通的情形下正定，$Cu=d_1$ 唯一可解，且可以用共轭梯度在 $O(|A|\sqrt{\kappa})$ 内解完，不必显式求逆。
**消失测试**：若不用 Laplacian 而把 $M$ 个自由节点两两写方程（$\binom{M}{2}$ 条），规模 $M=10^4$ 时是 $5\times10^7$ 条，内存先崩；Laplacian 只有 $O(|A|)$ 个非零元。**量的方向感**：非零元个数从 $\Theta(M^2)$ 降到 $\Theta(|A|)$；解一组线性方程代替一次无约束 QP。
**落点**：Boyd §8.7（placement and floor planning）、§8.7.1；Laplacian 的标准结论（$L = D - A_{\mathrm{adj}}$，连通时零空间是常向量）与 Strang 讲的图 Laplacian 特征值问题同构。**手算**：两点情形 $C = [[1]]$，$d_1 = 0$ ⇒ $u_1 = 0$，与直接对 $(u_1-0)^2$ 求极小一致。</span>

### Exercise 8.27 · Problems with minimum distance constraints

题干（原文）：

> 8.27 Problems with minimum distance constraints. We consider a problem with variables $x_1,\dots,x_N \in R^k$. The objective, $f_0(x_1,\dots,x_N)$, is convex, and the constraints
>
> $f_i(x_1,\dots,x_N) \le 0, \quad i = 1,\dots,m,$
>
> are convex (i.e., the functions $f_i : R^{Nk} \to R$ are convex). In addition, we have the minimum distance constraints
>
> $\|x_i - x_j\|_2 \ge D_{min}, \quad i \ne j, \quad i,j = 1,\dots,N.$
>
> In general, this is a hard nonconvex problem.
>
> Following the approach taken in floorplanning, we can form a convex restriction of the problem, i.e., a problem which is convex, but has a smaller feasible set. (Solving the restricted problem is therefore easy, and any solution is guaranteed to be feasible for the nonconvex problem.) Let $a_{ij} \in R^k$, for $i \lt j$, $i,j = 1,\dots,N$, satisfy $\|a_{ij}\|_2 = 1$.
>
> Show that the restricted problem
>
> $\begin{array}{ll} \text{minimize} & f_0(x_1,\dots,x_N) \\ \text{subject to} & f_i(x_1,\dots,x_N) \le 0, \quad i = 1,\dots,m \\ & a_{ij}^T(x_i - x_j) \ge D_{min}, \quad i \lt j, \quad i,j = 1,\dots,N, \end{array}$
>
> is convex, and that every feasible point satisfies the minimum distance constraint.
>
> Remark. There are many good heuristics for choosing the directions $a_{ij}$. One simple one starts with an approximate solution $\hat x_1,\dots,\hat x_N$ (that need not satisfy the minimum distance constraints). We then set $a_{ij} = (\hat x_i - \hat x_j)/\|\hat x_i - \hat x_j\|_2$.

中文话题摘要：把非凸的「最小间距」约束换成沿给定方向的一条线性约束，得到凸限制。

解答：由 Cauchy–Schwarz 不等式立即得到：

```math
D_{min} \le a^T(u - v) \le \|a\|_2\|u - v\|_2 = \|u - v\|_2 .
```

<span style="color:#1e8449;">**[译注]** 「凸限制」这个词在这里是精确的技术用语，不是修辞：$a_{ij}^T(x_i-x_j) \ge D_{min}$（半空间）的可行集被包含在 $\|x_i-x_j\|_2 \ge D_{min}$（非凸外壳）之内，所以解受限问题一定得到原问题的可行解，但**可能错过**原问题的最优解——这是「宁可少找，不可找错」的设计取舍。方向 $a_{ij}$ 的作用是把「距离球」的一侧换成「平面」：它假定你知道两点大致沿哪个方向分开，把半径方向的判据换成投影判据。
**消失测试**：不做这层替换，$\|x_i-x_j\|_2 \ge D_{min}$ 是凹约束（补集意义上的非凸），Boyd 书里的凸优化软件没法定式化；做替换后变成 LP/SOCP-compatible 的线性约束，可以直接调 solver。
**量的方向感**：可行集从「非凸外壳」缩到「多面体近似」，合法解数减少但每步可判；$\|a_{ij}\|_2=1$ 保证缩放不引入误差（否则 $a^T(u-v) \ge D_{min}$ 相当于把距离要求放大 $\|a\|_2$ 倍）。
**落点**：Boyd §8.7.2（floorplanning 的方向约束）、§8.8.1；与 8.24 的 $\rho\|x_i\|_2$ 是同一种「support function 把球换成半空间」的手艺。</span>

### Exercise 8.28 · 用 $tP_2 + x_c$ 逼近 $P_1$

题干（原文）：

> 8.28 Let $P_1$ and $P_2$ be two polyhedra described as
>
> $P_1 = \{x \mid Ax \preceq b\}, \qquad P_2 = \{x \mid -\mathbf{1} \preceq Cx \preceq \mathbf{1}\},$
>
> where $A \in R^{m \times n}$, $C \in R^{p \times n}$, and $b \in R^m$. The polyhedron $P_2$ is symmetric about the origin. For $t \ge 0$ and $x_c \in R^n$, we use the notation $tP_2 + x_c$ to denote the polyhedron
>
> $tP_2 + x_c = \{tx + x_c \mid x \in P_2\},$
>
> which is obtained by first scaling $P_2$ by a factor $t$ about the origin, and then translating its center to $x_c$.
>
> Show how to solve the following two problems, via an LP, or a set of LPs.
>
> (a) Find the largest polyhedron $tP_2 + x_c$ enclosed in $P_1$, i.e.,
>
> $\begin{array}{ll} \text{maximize} & t \\ \text{subject to} & tP_2 + x_c \subseteq P_1 \\ & t \ge 0. \end{array}$
>
> (b) Find the smallest polyhedron $tP_2 + x_c$ containing $P_1$, i.e.,
>
> $\begin{array}{ll} \text{minimize} & t \\ \text{subject to} & P_1 \subseteq tP_2 + x_c \\ & t \ge 0. \end{array}$
>
> In both problems the variables are $t \in R$ and $x_c \in R^n$.

中文话题摘要：在对称多面体族 $tP_2+x_c$ 中，求 $P_1$ 的最大内接与最小外包；全部化成 LP。

解答：

(a) 问题可以写成

```math
\begin{array}{ll}
\text{maximize} & t \\
\text{subject to} & \sup_{x \in tP_2+x_c} a_i^Tx \le b_i, \quad i = 1,\dots,m,
\end{array}
```

也就是

```math
\begin{array}{ll}
\text{maximize} & t \\
\text{subject to} & a_i^T x_c + \sup_{-t\mathbf{1} \le Cv \le t\mathbf{1}} a_i^T v \le b_i, \quad i = 1,\dots,m. \qquad (8.28.\mathrm{A})
\end{array}
```

若定义

```math
p(a_i) = \sup_{-\mathbf{1} \le Cv \le \mathbf{1}} a_i^T v, \qquad (8.28.\mathrm{B})
```

则 (8.28.A) 可写成

```math
\begin{array}{ll}
\text{maximize} & t \\
\text{subject to} & a_i^T x_c + t\,p(a_i) \le b_i, \quad i = 1,\dots,m,
\end{array} \qquad (8.28.\mathrm{C})
```

这是关于 $x_c$ 与 $t$ 的 LP。注意 $p(a_i)$ 可以通过求解定义 (8.28.B) 中的 LP 来求值。

总之，先对 $i = 1,\dots,m$ 各解一个 LP 求出 $p(a_i)$，再解 LP (8.28.C) 得到 $t$ 与 $x_c$。

<span style="color:#1e8449;">**[译注]** 这里最容易被跳过的是「$t$ 去哪儿了」：$\sup$ 从 $tP_2+x_c$ 上搬到 $P_2$ 上时，线性函数在缩放集合上的上确界会**带出一个 $t$ 的正比因子**，即 $\sup_{v\in tP_2} a^Tv = t\sup_{v\in P_2}a^Tv$。这一步合法的前提是 $t \ge 0$——若允许 $t \lt 0$，$tP_2$ 是翻转的集合，$\sup$ 方向跟着翻，系数就成了 $|t|$，LP 的线性立刻消失。
**消失测试**：不把 $t$ 提出来，约束里是「$t$ 与 $v$ 的乘积构成的集合」，属于双线性，不是 LP；提出来之后 (8.28.C) 每行都是 $a_i^Tx_c + t\,p(a_i) \le b_i$，对 $(x_c,t)$ 线性。
**量的方向感**：一次求解需要 $m$ 次小 LP（每个 $a_i$ 一次）加 1 次主 LP，共 $m+1$ 次；若把 $m$ 个 $\sup$ 塞进主 LP 一起解，变量数是 $O(mn)$ 量级，规模大一个乘数因子。
**落点**：Boyd §8.3（support function 与集合的包含判据）、§8.2.2；与 8.24 的 $\rho\|x_i\|_2$ 同为「把球上的 sup 换成显式量」。</span>

(b) 先注意 $x \in tP_2 + x_c$ 当且仅当

```math
-t\mathbf{1} \le C(x - x_c) \le t\mathbf{1}.
```

因此问题等价于

```math
\begin{array}{ll}
\text{minimize} & t \\
```

### Exercise 8.29 · Outer polyhedral approximations

题干（原文）：

> 8.29 Outer polyhedral approximations. Let $P = \{x \in R^n \mid Ax \preceq b\}$ be a polyhedron, and $C \subseteq R^n$ a given set (not necessarily convex). Use the support function $S_C$ to formulate the following problem as an LP:
>
> $\begin{array}{ll} \text{minimize} & t \\ \text{subject to} & C \subseteq tP + x \\ & t \ge 0. \end{array}$
>
> Here $tP+x = \{tu + x \mid u \in P\}$, the polyhedron $P$ scaled by a factor of $t$ about the origin, and translated by $x$. The variables are $t \in R$ and $x \in R^n$.

中文话题摘要：用 support function 把「$C$ 被 $tP+x$ 包住」写成 LP。

解答：$C \subseteq tP + x$ 当且仅当 $(1/t)(C - x) \subseteq P$，也就是

```math
S_{(1/t)(C-x)}(a_i) \le b_i, \quad i = 1,\dots,m.
```

注意当 $t \ge 0$ 时，

```math
S_{(1/t)(C-x)}(a) = \sup_{u\in C} a^T\bigl((1/t)(u - x)\bigr) = \frac{1}{t}\bigl(S_C(a) - a^Tx\bigr),
```

于是问题可以写成

```math
\begin{array}{ll}
\text{minimize} & t \\
\text{subject to} & S_C(a_i) - a_i^Tx \le t\,b_i, \quad i = 1,\dots,m \\
& t \ge 0,
\end{array}
```

这是关于变量 $x, t$ 的 LP。

<span style="color:#1e8449;">**[译注]** 这一步之所以能把「包含一个**非凸**集合 $C$」变成 LP，全靠一个事实：包含关系只由 $C$ 在有限个方向 $a_i$ 上的**最大值**决定。$C$ 长什么样、凸不凸、连不连通，在 $S_C(a_i)$ 里全被抹掉了——这也是题面特意声明「$C$ 不必是凸集」的原因。
**消失测试**：若直接对 $C$ 做「逐点约束」$tu + x \preceq b\ (\forall u \in C)$，那是不可数多条；换成 $m$ 条 support function 不等式后，非凸性完全不影响可解性，代价是 $S_C(a_i)$ 必须事先知道（例如对离散点集 $S_C(a) = \max_k a^Tp_k$，对二次曲面要解一个小 QP）。
**量的方向感**：约束条数从 $|C|$（或 $\infty$）降到 $m$；$\frac1t$ 从变量里提到外面，用 $t \ge 0$ 保住不等号方向。
**落点**：Boyd §8.3（support function 与包含）、§8.5.1；与 8.28(a) 的 $t\,p(a_i)$ 结构完全同型，只是那次是把 $tP_2$ 内接，这次是把 $tP$ 外包。</span>

```math
D = \sum_{i=2}^{n}\bigl|\theta_{i-1} + \theta_i + \psi_i\bigr|,
```

另一个目标是总弧长，其表达式为

```math
L = \sum_{i=1}^{n-1} l_i\,\frac{\theta_i}{\sin\theta_i},
```

其中 $l_i = \|a_i - a_{i+1}\|_2$。下面说明 $L$ 是 $\theta$ 的凸函数。当然只需说明函数 $f(x) = x/\sin x$ 在区间 $|x| \lt \pi$ 上是凸的。事实上 $f$ 是 log-convex 的。令 $g = \log(x/\sin x)$，有

```math
g'' = -\frac{1}{x^2} + \frac{1}{\sin^2 x}.
```

由于对（所有）$x$ 都有 $|\sin x| \le |x|$，故 $1/x^2 \le 1/\sin^2 x$，于是 $g'' \ge 0$。

<span style="color:#1e8449;">**[译注]** 弧长公式 $l_i\theta_i/\sin\theta_i$ 值得推一遍，因为它把「半径」这个消掉的量显式找回来了：弦长 $l_i$、切角 $\theta_i$ 的圆弧，其半径 $R = l_i/(2\sin\theta_i)$（正弦定理），弧对应的圆心角是 $2\theta_i$，于是弧长 $= R\cdot 2\theta_i = l_i\theta_i/\sin\theta_i$。$\theta_i \to 0$ 时用 $\sin\theta \approx \theta$ 得极限 $l_i$，正是线段，与题面「$\theta_i=0$ 就是直线段」一致。
**为什么是 log-convex 而不是直接证凸**：$f = x/\sin x$ 在负半轴上 $\sin x \lt 0$ 使 $f \lt 0$，直接求 $f''$ 会出现 $(x\sin x - \cdots)$ 这类不定号表达式；取 $\log$ 后 $g'' = -1/x^2 + 1/\sin^2x$ 只剩两个平方项的比较，一眼可判。**消失测试**：若 $L$ 不凸，「用加权和 $D+\lambda L$ 扫出整个 Pareto 前沿」这一步就不成立——加权和只能触到凸前沿，非凸部分永远扫不到。**落点**：Boyd §4.5（log-convex 蕴含凸，$\log$ 之和 vs 之和的 log）、§8.8.1；**数值**：$\theta = \pi/4$ 时 $\theta/\sin\theta = 0.7854/0.7071 = 1.1107$，即弧长比弦长多 $11.07\%$。</span>

### Exercise 8.30（续）

因此 $D$ 与 $L$ 两个目标都是凸的。为求最优权衡曲线，我们对 $D$ 与 $L$ 的各种（非负）加权组合 $D + \lambda L$ 求极小，其中 $\lambda \ge 0$ 取不同值。

现在考虑权衡曲线的极值点。显然 $L$ 在取 $\theta_i = 0$ 时最小，此时曲线就是依次连接这些点的线段。所以 $\theta = 0$ 是最优权衡曲线的一个端点。

关于另一个端点，我们也可以说一些：我们断言它出现在总关节角不连续度为零时（即曲线可微）。这发生在递推

```math
\theta_i = -\theta_{i-1} - \psi_i, \qquad i = 2,\dots,n,
```

成立的时候。这说明一旦第一个角 $\theta_1$ 固定，整条曲线就固定了。因此，通过这些点的分段圆弧曲线构成一个单参数族，参数为 $\theta_1$。要找出最优权衡曲线的另一个端点，我们需要在这个族中找长度最小的曲线。这可以通过在上述递推下对 $\theta_1$ 求解一维的 $L$ 极小化问题来得到。

<span style="color:#1e8449;">**[译注]** 「另一个端点必是 $D=0$」这条断言需要一点说明才站得住：$D \ge 0$ 且 $L \ge \sum l_i$（因为 $\theta/\sin\theta \ge 1$ 在 $|\theta| \lt \pi$ 上成立），所以 $D + \lambda L$ 在 $\lambda \to \infty$ 时被逼到 $L$ 的最小点 $\theta = 0$，而 $\lambda \to 0$ 时被逼到 $D$ 的最小点，即 $D=0$（可微曲线）。于是 Pareto 前沿两端分别是「全直线（$D \gt 0$，$L = \sum l_i$）」与「$C^1$ 光滑（$D=0$，$L \gt \sum l_i$）」。
**递推为什么能定整条曲线**：$D = 0$ 是 $n-1$ 个方程 $|\theta_{i-1}+\theta_i+\psi_i| = 0$ 组成的链式系统，从 $\theta_1$ 出发逐个解出 $\theta_2,\dots,\theta_n$，自由度恰好剩 1——这就是「单参数族」的来源，也解释了为什么最后归结为一维搜索。
**消失测试**：若把 $D=0$ 直接当等式约束整个优化（不扫 $\lambda$），只能拿到前沿的一个端点；若用加权和而不检查凸性，非凸前沿的「凹陷段」会被跳过，端点之间的整段曲线被误认为不存在。
**量的方向感**：二维扫描降为一维搜索（$1$ 个自由度 $\theta_1$），每次评估 $O(n)$ 递推；$n=100$ 时是 $100$ 次乘加而非 $100$ 维优化。
**落点**：Boyd §4.7.4（bicriterion 与 Pareto 前沿）、§8.8.1 的这一题；曲线平滑性判据 $|\theta_{i-1}+\theta_i+\psi_i|$ 的来源见本节定义。</span>

### Exercise 9.1 · Minimizing a quadratic function

题干（原文）：

> 9.1 Minimizing a quadratic function. Consider the problem of minimizing a quadratic function:
>
> $\text{minimize} \quad f(x) = (1/2)x^TPx + q^Tx + r,$
>
> where $P \in S^n$ (but we do not assume $P \succeq 0$).
>
> (a) Show that if $P \not\succeq 0$, i.e., the objective function $f$ is not convex, then the problem is unbounded below.
>
> (b) Now suppose that $P \succeq 0$ (so the objective function is convex), but the optimality condition $Px^{\star} = -q$ does not have a solution. Show that the problem is unbounded below.

中文话题摘要：二次函数极小化何时下无界——非凸时必无界；凸但最优性条件无解时也无界。

解答：

(a) 若 $P \not\succeq 0$，可以找到 $v$ 使 $v^TPv \lt 0$。取 $x = tv$，有

```math
f(x) = t^2(v^TPv/2) + t(q^Tv) + r,
```

当 $t$ 变大时它收敛到 $-\infty$。

(b) 这意味着 $q \notin \mathcal{R}(P)$。把 $q$ 表示成 $q = \tilde q + v$，其中 $\tilde q$ 是 $q$ 到 $\mathcal{R}(P)$ 上的 Euclidean projection，并取 $v = q - \tilde q$。该向量非零且与 $\mathcal{R}(P)$ 正交，即 $v^TPv = 0$。于是对 $x = tv$ 有

```math
f(x) = tq^Tv + r = t(\tilde q + v)^Tv + r = t(v^Tv) + r,
```

它下无界。

<span style="color:#1e8449;">**[译注]** (b) 的机制要抓住「二次项消失、一次项留下」这一点：$v \perp \mathcal{R}(P)$ 且 $P \succeq 0$ 时必有 $Pv = 0$（因为 $Pv \in \mathcal{R}(P)$ 且 $v^TPv = 0$，半正定下这是充要），于是 $v^T P v = 0$，二次项整项消失；而 $q^Tv = (\tilde q + v)^Tv = 0 + \|v\|_2^2 \gt 0$，一次项是**正的且不消失**。沿 $x = tv$ 走，$t\to\pm\infty$ 时 $f\to\mp\infty$，所以取下界发散到 $-\infty$。**消失测试**：若 $q \in \mathcal{R}(P)$，则 $q = Px_0$ 某个 $x_0$，最优解存在（$x^\star = -x_0$ 加零空间分量），此时最优点**不唯一**（零空间维数 $n - \mathrm{rank}P$ 个自由参数），这是「解不唯一」而不是「无界」，两种情况常被混为一谈。**量的方向感**：$P$ 的最小特征值 $\lambda_{\min} \gt 0$ 时 $f$ 在下界附近像开口向上的抛物面，$\lambda_{\min}=0$ 时沿零空间退化成**线性**下降——降阶一次，恰好从 $\Theta(t^2)$ 变成 $\Theta(t)$。**落点**：Boyd §9.1.1 例、§4.2.3（二次型的凸性判据）；$\mathcal{R}(P)$ 与零空间的正交分解就是 Strang 的 four fundamental subspaces。</span>

### Exercise 9.2 · Minimizing a quadratic-over-linear fractional function

题干（原文）：

> 9.2 Minimizing a quadratic-over-linear fractional function. Consider the problem of minimizing the function $f : R^n \to R$, defined as
>
> $f(x) = \dfrac{\|Ax - b\|_2^2}{c^Tx + d}, \quad \mathrm{dom}\,f = \{x \mid c^Tx + d \gt 0\}.$
>
> We assume $\mathrm{rank}\,A = n$ and $b \notin \mathcal{R}(A)$.
>
> (a) Show that $f$ is closed.
>
> (b) Show that the minimizer $x^{\star}$ of $f$ is given by
>
> $x^{\star} = x_1 + t x_2$
>
> where $x_1 = (A^TA)^{-1}A^Tb$, $x_2 = (A^TA)^{-1}c$, and $t \in R$ can be calculated by solving a quadratic equation.

中文话题摘要：quadratic-over-linear 分式函数的极小点必落在 $x_1 + t x_2$ 这条直线上，$t$ 由二次方程定出。

解答：

(a) 由于 $b \notin \mathcal{R}(A)$，分子被一个正数 $\|Ax_{ls} - b\|_2^2$ 从下方界住。因此当 $x$ 趋近 $\mathrm{dom}\,f$ 的边界时 $f(x) \to \infty$。

(b) 最优性条件是

```math
\nabla f(x) = \frac{2(c^Tx+d)A^T(Ax-b) - \|Ax-b\|_2^2\,c}{(c^Tx+d)^2} = \frac{2(c^Tx+d)(x-x_1) - \|Ax-b\|_2^2\,x_2}{(c^Tx+d)^2} = 0,
```

<span style="color:#1e8449;">**[译注]** 第二个等号藏着一条恒等式，值得单独点出：$(A^TA)^{-1}A^T(Ax-b) = x - x_1$ 把「残差投影回参数空间」变成「$x$ 减去最小二乘解」，而 $x_2 = (A^TA)^{-1}c$ 则是「把方向 $c$ 也投回参数空间」。两者一并出现，说明**梯度只能落在 $x - x_1$ 与 $x_2$ 张成的二维平面内**，于是最优解必是 $x^\star = x_1 + tx_2$：一个本来 $n$ 维的非凸分式问题，被压成一条直线上的单变量问题。

### Exercise 9.5 · Backtracking line search

题干（原文）：

> 9.5 Backtracking line search. Suppose $f$ is strongly convex with $mI \preceq \nabla^2f(x) \preceq MI$. Let $\Delta x$ be a descent direction at $x$. Show that the backtracking stopping condition holds for
>
> $0 \lt t \le -\dfrac{\nabla f(x)^T\Delta x}{M\|\Delta x\|_2^2}.$
>
> Use this to give an upper bound on the number of backtracking iterations.

中文话题摘要：强凸下 backtracking 的充分步长阈值与迭代次数上界。

解答：上界 $\nabla^2f(x) \preceq MI$ 蕴含

```math
f(x + t\Delta x) \le f(x) + t\nabla f(x)^T\Delta x + (M/2)t^2\Delta x^T\Delta x,
```

于是当

```math
t(1-\alpha)\nabla f(x)^T\Delta x + (M/2)t^2\Delta x^T\Delta x \le 0
```

时，$f(x+t\Delta x) \le f(x) + \alpha t\nabla f(x)^T\Delta x$ 成立，即当 $0 \le t \le t_0$ 时退出条件必然成立，其中

```math
t_0 = \frac{-2(1-\alpha)\nabla f(x)^T\Delta x}{M\Delta x^T\Delta x} \ge \frac{-\nabla f(x)^T\Delta x}{M\Delta x^T\Delta x}.
```

假定 $t_0 \le 1$。则当 $k \ge \log(1/t_0)/\log(1/\beta)$ 时 $\beta^k t \le t_0$。

<span style="color:#1e8449;">**[译注]** 这条上界给出 backtracking 的**最坏迭代次数**，是分析「line search 便宜」这一常识的唯一依据。机制：初始步长 $t=1$，每次失败乘 $\beta$（典型 $\beta = 0.5$），所以第 $k$ 次的候选步长是 $\beta^k$；一旦 $\beta^k \le t_0$ 就必然退出，解出 $k = \lceil \log(1/t_0)/\log(1/\beta)\rceil$。**数值**：$\beta = 0.5$、$t_0 = 10^{-3}$ 时 $k = \log 1000/\log 2 = 9.97$，即最多 10 次回溯——而不是「可能无限次」。**消失测试**：没有强凸/光滑常数（$m, M$），$t_0$ 无从计算，line search 的最坏代价只能靠实测，且条件数 $\kappa = M/m$ 一大就可能出现「步长几乎不缩，函数值却还在涨」的无效回溯。**量的方向感**：迭代次数 $O(\log(1/t_0))$，而每次迭代只多算一次 $f$ 与一次内积——比在 $[0,1]$ 上做网格搜索的 $O(1/\epsilon)$ 便宜一个指数级。**落点**：Boyd §9.2（backtracking 的算法框）、§9.3.1 的引理；$\ge$ 那一步用的是 $\alpha \le 1/2$ ⇒ $2(1-\alpha)\ge1$。</span>

```math
\end{array}
```

> 9.8 Steepest descent method in $\ell_\infty$-norm. Explain how to find a steepest descent direction in the $\ell_\infty$-norm, and give a simple interpretation.

<span style="color:#1e8449;">**[译注]** 这个系数 $\|\nabla f\|_1$ 不是随手写的：按 9.7(b)，$\nabla f^T\Delta x_{sd} = -\|f\|_*^2$，而 $\ell_\infty$ 的对偶范数是 $\ell_1$，所以长度因子必须是 $\|\nabla f\|_1$。**手算**：$\nabla f = (3,-4)$，$\|\nabla f\|_1 = 7$，$\Delta x_{sd} = -7\cdot(1,-1) = (-7,7)$，内积 $= 3(-7) + (-4)(7) = -49$，而 $-\|\nabla f\|_1^2 = -49$ ✓，恰好对上 9.7(b)。**消失测试**：若把系数错写成 $\|\nabla f\|_\infty = 4$，内积变成 $-4\cdot 7 = -28 \neq -16 = -\|f\|_\infty^2$，两条恒等式同时失效，line search 的初始步长会按错的尺度给，实际表现出「步长忽大忽小」。**量的方向感**：$\|\nabla f\|_1 \ge \|\nabla f\|_\infty$（$n$ 维时最多差 $n$ 倍），所以 $\ell_\infty$ 的 unnormalized 步长比 $\ell_2$ 情形长——这也是 $\ell_\infty$ 下降在坐标轴上「走满」的直觉来源。**落点**：Boyd §9.4.2（$\ell_\infty$ 与 $\ell_1$ 的对偶关系）、§A.1.6；与 8.24 里 $\ell_2$ 对偶是自己的对称性对照。**一般推导**：由 9.7(c)，$\Delta x_{sd} = \arg\min_v\{\nabla f^Tv + \frac12\|v\|^2\}$，写 $v = tw$（$\|w\|=1$）后对 $t$ 求极小得 $\hat t = -\nabla f^Tw$，再对 $w$ 求极小便得 $\hat t = \|\nabla f\|_*$。这条推导与具体范数无关，但范数与对偶范数必须配对：$\ell_2$ 配 $\ell_2$、$\ell_\infty$ 配 $\ell_1$、$\ell_1$ 配 $\ell_\infty$，配错就得到错误的步长。</span>

## Newton's method

### Exercise 9.9 · Newton decrement

题干（原文）：

> 9.9 Newton decrement. Show that the Newton decrement $\lambda(x)$ satisfies
>
> $\lambda(x) = \sup_{v^T\nabla^2f(x)v = 1}\bigl(-v^T\nabla f(x)\bigr) = \sup_{v \ne 0}\frac{-v^T\nabla f(x)}{\bigl(v^T\nabla^2f(x)v\bigr)^{1/2}} .$

中文话题摘要：Newton decrement 的两种等价表达——一个带约束的 sup 与一个 Rayleigh 商形式。

解答：第一个表达式来自变量替换

```math
w = \nabla^2f(x)^{1/2}v, \qquad v = \nabla^2f(x)^{-1/2}w
```

以及

```math
\sup_{\|w\|_2 = 1}\bigl(-w^T\nabla^2f(x)^{-1/2}\nabla f(x)\bigr) = \bigl\|\nabla^2f(x)^{-1/2}\nabla f(x)\bigr\|_2 = \lambda(x).
```

第二个表达式由第一个立即得到。

<span style="color:#1e8449;">**[译注]** 这条恒等式是「Newton step 是 Hessian 度量下的 steepest descent」的精确表述：把 $\nabla^2 f$ 当内积矩阵，则约束 $v^T\nabla^2fv = 1$ 是「在 Hessian 度量下的单位球」，而 sup 取在该球上，正是对偶范数在加权内积下的版本。**为什么它等于 $-\nabla f^T\Delta x_{nt}$**：Newton 方向 $\Delta x_{nt} = -\nabla^2f^{-1}\nabla f$，于是 $-\nabla f^T\Delta x_{nt} = \nabla f^T\nabla^2f^{-1}\nabla f = \|\nabla^2f^{-1/2}\nabla f\|_2^2 = \lambda(x)^2$——所以 $\lambda^2$ 是「Newton 步带来的二阶模型下降量」，$\lambda(x) = (f(x)-f(x+\Delta x_{nt}))^{1/2}$ 在二次模型下精确成立。**消失测试**：没有这个量，Newton 法的停止判据只剩 $\|\nabla f\|_2 \le \epsilon$，而它对尺度敏感（把 $f$ 乘以 $10^3$ 梯度就乘 $10^3$），$\lambda$ 是无量纲的，尺度不变。**量的方向感**：$\lambda$ 从 $10^{-1}$ 降到 $10^{-8}$ 覆盖了「阻尼阶段」与「二次收敛阶段」的分界 $\lambda \le 0.1$。**落点**：Boyd §9.5.1、§9.6.3（$\lambda^2/2$ 即 $f(x) - \inf$ 的估计）；Rayleigh 商与广义特征值见 Strang 的对称矩阵一章。</span>
