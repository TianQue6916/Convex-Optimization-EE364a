### Exercise 9.10（续）· Newton method 在纯步长下的两条轨迹

> 话题摘要：纯 Newton 方法（fixed step size，$t=1$）何时二次收敛、何时发散——两个一维例子。

**(a)** $f(x)=\log(e^x+e^{-x})$ has a unique minimizer $x^\star=0$. Run Newton's method with fixed step size $t=1$, starting at $x^{(0)}=1$ and at $x^{(0)}=1.1$.

**(b)** $f(x)=-\log x+x$ has a unique minimizer $x^\star=1$. Run Newton's method with fixed step size $t=1$, starting at $x^{(0)}=3$.

Plot $f$ and $f'$, and show the first few iterates.

**中文话题摘要**：(a) 在 $x^\star=0$ 的凸偶函数上，从 $1$ 出发纯 Newton 二次收敛、从 $1.1$ 出发爆炸；(b) 在 barrier 型函数上，第一步就跳出定义域。

**Solution.**

- $f(x)=\log(e^x+e^{-x})$ 是光滑 convex function，唯一极小点在原点。从 $x^{(0)}=1$ 出发的 pure Newton method 产生如下序列。

| $k$ | $x^{(k)}$ | $f(x^{(k)})-p^\star$ |
|---|---|---|
| 1 | $-8.134\cdot10^{-01}$ | $4.338\cdot10^{-1}$ |
| 2 | $4.094\cdot10^{-01}$ | $2.997\cdot10^{-1}$ |
| 3 | $-4.730\cdot10^{-02}$ | $8.156\cdot10^{-2}$ |
| 4 | $7.060\cdot10^{-05}$ | $1.118\cdot10^{-3}$ |
| 5 | $-2.346\cdot10^{-13}$ | $2.492\cdot10^{-9}$ |

从 $x^{(0)}=1.1$ 出发，方法发散。

| $k$ | $x^{(k)}$ | $f(x^{(k)})-p^\star$ |
|---|---|---|
| 1 | $-1.129\cdot10^{0}$ | $5.120\cdot10^{-1}$ |
| 2 | $1.234\cdot10^{0}$ | $5.349\cdot10^{-1}$ |
| 3 | $-1.695\cdot10^{0}$ | $6.223\cdot10^{-1}$ |
| 4 | $5.715\cdot10^{0}$ | $1.035\cdot10^{0}$ |
| 5 | $-2.302\cdot10^{4}$ | $2.302\cdot10^{4}$ |

> `†` **原表第三列整体错位一行**。详见文末「原文错误清单」第 1 条：$x^{(0)}=1$ 时 $f(1)-p^\star=\log\bigl((e+e^{-1})/2\bigr)=0.4338$，恰是表里 $k=1$ 行的数；而 $f(-0.8134)-p^\star=0.2998$ 被排到了 $k=2$ 行。下文译文照录原表，读者按错位一行读即可还原真值。

- $f(x)=-\log x+x$ 在 $\text{dom}\,f=\{x\mid x\gt 0\}$ 上光滑且 convex，唯一极小点在 $x=1$。从 $x^{(0)}=3$ 出发的 pure Newton method 第一步给出

```math
x^{(1)} = 3 - f'(3)/f''(3) = -3,
```

落在 $\text{dom}\,f$ 之外。

<span style="color:#1e8449;">**[译注]** 为什么同一个函数从 $1$ 出发收敛、从 $1.1$ 出发就炸？答案藏在 Newton decrement 的初值里。对 $f(x)=\log(e^x+e^{-x})$ 有 $f'(x)=\tanh x$、$f''(x)=1-\tanh^2x$，于是 $\lambda(x)=\lvert f'(x)\rvert/\sqrt{f''(x)}=\lvert\tanh x\rvert/\sqrt{1-\tanh^2x}$。取 $x^{(0)}=1$：$\tanh 1=0.7616$，$\lambda=0.7616/0.6481=1.175$；取 $x^{(0)}=1.1$：$\tanh 1.1=0.8005$，$\lambda=0.8005/0.5993=1.336$。教科书对纯 Newton 二次收敛的保证是 $\lambda\lt 1$ 的区域内才成立，而这里两个初值的 $\lambda$ 都大于 $1$——所以「从 1 出发收敛」不是定理保证的，是撞上了 $\tanh$ 的偶对称。真正的分水岭是 $\lambda(x)=1$ 的临界点：$\lvert\tanh x\rvert=1/\sqrt2$，即 $\lvert x\rvert=\mathrm{artanh}(1/\sqrt2)=0.8814$。从 $x^{(0)}=1$ 出发，一步到 $-0.8134$，已经落进 $\lvert x\rvert\lt0.8814$ 的二次收敛区，此后 $f-p^\star$ 按 $0.2998\to0.0816\to1.1\cdot10^{-3}\to2.5\cdot10^{-9}$ 走；从 $x^{(0)}=1.1$ 出发，一步到 $-1.128$，仍在区外，于是 $\lvert x\rvert$ 单调放大，五步内到 $2.3\cdot10^{4}$。也就是说：**$1$ 与 $1.1$ 的差别不在「$1.1$ 更远」，而在「一步之后敢不敢回到 $0.8814$ 以内」**。

**消失测试**：没有「$t=1$ 的纯 Newton 只在本地区间内安全」这一认识，任何在非强凸、非自洽函数上直接令 $t=1$ 的实现都会在某个初值上静默溢出到 `inf`，而不会给出任何警告——这正是必须配 backtracking line search 的理由（Boyd §9.5.2），代价是每步多 1–2 次函数求值。

**落点**：Boyd §9.5.1（pure Newton）与 §9.5.2（damped Newton）；$x^\ast=1.0877$ 是方程 $\lambda(x)=2$ 的根，可用一行 `scipy.optimize.brentq` 复现；挂 Strang 线代里「迭代映射的局部收敛因子 = 不动点处导数」。

**量的方向感**：$\lambda$ 从 $1.175$ 涨到 $1.336$（$+13.7\%$），结果从 $5$ 步到 $10^{-13}$ 变成 $5$ 步到 $10^{4}$——差 $17$ 个数量级。</span>

### Exercise 9.11 · 复合函数的 gradient method 与 Newton method

> 话题摘要：$g=\varphi\circ f$（$\varphi$ 递增凸）与原 $f$ 的两个问题「等价」，但算法并不等价——exact line search 下两者轨迹逐点相同，Newton 方向只差一个正倍数。

**Gradient and Newton methods for composition functions.** Suppose $\varphi:R\to R$ is increasing and convex, and $f:R^n\to R$ is convex, so $g(x)=\varphi(f(x))$ is convex. (We assume that $f$ and $g$ are twice differentiable.) The problems of minimizing $f$ and minimizing $g$ are clearly equivalent.

Compare the gradient method and Newton's method, applied to $f$ and $g$. How are the search directions related? How are the methods related if an exact line search is used?

*Hint.* Use the matrix inversion lemma (see §C.4.3).

**中文话题摘要**：单调递增凸变换不改变极小点，但会改变搜索方向；问题等价 ≠ 算法等价。

**Solution.**

**(a) Gradient method.** 两个 gradient 相差一个正倍数

```math
\nabla g(x) = \varphi'(f(x))\,\nabla f(x),
```

所以在 exact line search 下，$f$ 与 $g$ 的 iterates 完全相同。换成 backtracking，就可能出现很大差别。

**(b) Newton method.** $g$ 的 Hessian 为

```math
\nabla^2 g(x) = \varphi''(f(x))\,\nabla f(x)\nabla f(x)^T + \varphi'(f(x))\,\nabla^2 f(x),
```

于是 $g$ 的 Newton direction 为

```math
\Delta x_{nt}^{g} = -\bigl(\varphi''(f(x))\nabla f(x)\nabla f(x)^T + \varphi'(f(x))\nabla^2 f(x)\bigr)^{-1}\varphi'(f(x))\,\nabla f(x).
```

由 matrix inversion lemma（矩阵求逆引理）可见，这个方向是 $f$ 的 Newton direction 的某个正倍数。因此配合 exact line search 时，iterates 完全相同。没有 exact line search 时（例如只用 Newton step one），差别可以很大。例如取 $f(x)=x^2$、$\varphi(x)=x^2$（$x\ge 0$）。

<span style="color:#1e8449;">**[译注]** 这一问的核心是「正倍数」这三个字为什么足以让两条轨迹重合。设 $B=\nabla^2f(x)$、$v=\nabla f(x)$、$s=\varphi''/\varphi'$，用 matrix inversion lemma 化简：

```math
(\varphi'B+\varphi''vv^T)^{-1}v = \frac{1}{\varphi'}\Bigl(B+\frac{\varphi''}{\varphi'}vv^T\Bigr)^{-1}v = \frac{B^{-1}v}{\varphi'\,(1+s\,v^TB^{-1}v)}.
```

关键是分母 $1+s\,v^TB^{-1}v$ 恒正：$\varphi$ 递增凸给出 $\varphi'\gt 0$、$\varphi''\ge 0$，而 $v^TB^{-1}v\ge 0$（$B\succ 0$）。于是 $\Delta x_{nt}^{g}$ 与 $\Delta x_{nt}^{f}=-B^{-1}v$ 只在标量系数上不同；exact line search 求得的是「沿方向走到最优」，方向的正倍数不改变这条射线，所以步点一致。反过来，backtracking 只沿方向做几何缩短，起点步长 $t=1$ 的「物理长度」不同，于是立刻分岔。

**消失测试**：如果误以为「目标函数等价 $\Rightarrow$ 算法等价」而在 Newton 法里嵌入任意单调重标定（例如给 log-barrier 乘 $10^3$），那么 exact line search 版本仍然一致，但固定步长版本会退化——$\varphi'\ne 1$ 时 $\Delta x$ 的模长被直接缩放，$t=1$ 可能一步跳过整个 trust 区间。

**落点**：Boyd §C.4.3（matrix inversion lemma / Sherman–Morrison）；§9.7.1（Newton step 的仿射不变性）；习题 9.13 用过同一引理的 $n$ 维版本。

**量的方向感**：$f(x)=x^2$、$\varphi(x)=x^2$ 时 $\varphi'=\varphi''=2$，$\Delta x_{nt}^{g}=\Delta x_{nt}^{f}/(1+\lambda^2/2)$ 量级被压小 $1+O(\lambda^2)$ 倍——$\lambda$ 越大压得越狠，正是牛顿法在 $\varphi$ 平坦区退化成慢方法的机制。</span>

> 说明（不作为 `†` 条目）：原文该式省略了分子上的 $\varphi'(f(x))$，见文末小瑕疵表第 1 条；缺这个因子不影响「正倍数」结论，故不标 `†`。

### Exercise 9.12 · Trust region Newton method

> 话题摘要：Hessian 奇异时 Newton step 无意义，改解一个带 $\|v\|_2\le\gamma$ 约束的二次模型；该解同时是某个 ridge 型正则化二次模型的**无约束**极小点——对偶把「约束」换成「乘子」。

**Trust region Newton method.** If $\nabla^2f(x)$ is singular (or very ill-conditioned), the Newton step $\Delta x_{nt}=-\nabla^2f(x)^{-1}\nabla f(x)$ is not well defined. Instead we can define a search direction $\Delta x_{tr}$ as the solution of

```math
\begin{aligned}
\text{minimize}\quad & (1/2)v^THv + g^Tv\\
\text{subject to}\quad & \|v\|_2 \le \gamma,
\end{aligned}
```

where $H=\nabla^2f(x)$, $g=\nabla f(x)$, and $\gamma$ is a positive constant. The point $x+\Delta x_{tr}$ minimizes the second-order approximation of $f$ at $x$, subject to the constraint that $\|(x+\Delta x_{tr})-x\|_2\le\gamma$. The set $\{v\mid \|v\|_2\le\gamma\}$ is called the trust region（信赖域）. The parameter $\gamma$, the size of the trust region, reflects our confidence in the second-order model.

Show that $\Delta x_{tr}$ minimizes

```math
(1/2)v^THv + g^Tv + \hat\beta\|v\|_2^2,
```

for some $\hat\beta$. This quadratic function can be interpreted as a regularized quadratic model for $f$ around $x$.

**中文话题摘要**：trust region（硬约束）与 Tikhonov 正则化（软惩罚）在同一二次模型上给出同一个解，两者只差一个 Lagrange multiplier。

**Solution.** 这直接来自 duality（对偶）。若给约束配一个 multiplier $\beta$，则最优的 $v$ 必是 Lagrangian 的极小点

```math
(1/2)v^THv + g^Tv + \beta(\|v\|_2^2-\gamma).
```

$\hat\beta$ 的取值可如下确定。optimality conditions 是

```math
Hv+g+\beta v = 0,\qquad v^Tv\le\gamma,\qquad \beta\ge 0,\qquad \beta(\gamma-v^Tv)=0.
```

- 若 $H\succ 0$，则对一切 $\beta\ge 0$ 矩阵 $H+\beta I$ 可逆，于是由第一式得

```math
v = -(H+\beta I)^{-1}g.
```

$v$ 的 norm 是 $\beta$ 的递减函数。若 $\|H^{-1}g\|_2\le\gamma$，最优解为

```math
v = -H^{-1}g,\qquad \beta = 0.
```

若 $\|H^{-1}g\|_2\gt\gamma$，则 $\beta$ 是方程 $\|(H+\beta I)^{-1}g\|_2=\gamma$ 的唯一正解。

- 若 $H$ 奇异，则只有 $g\in R(H)$ 且 $\|H^{\dagger}g\|_2\le\gamma$ 时才有 $\beta=0$。否则 $\beta$ 是方程 $\|(H+\beta I)^{-1}g\|_2=\gamma$ 的唯一正解。

<span style="color:#1e8449;">**[译注]** 这条结论的实用价值在于：它把「先猜 $\gamma$、解 QP、不合意再调 $\gamma$」的循环，换成「直接选 $\beta$、解一个线性系统」。两种做法的解集是**同一条曲线**——参数化的只是同一条解路径。取 $H=\mathrm{diag}(1,10^{-4})$、$g=(1,1)$，$\gamma$ 从 $10^3$ 缩到 $1$：$\beta=0$ 时 $\|H^{-1}g\|_2=\sqrt{1+10^8}\approx 10^4\gt\gamma$，故必须正 $\beta$。数值解方程 $\|(H+\beta I)^{-1}g\|_2=\gamma$ 得 $\gamma=1\Rightarrow\beta\approx\sqrt{2}-1\approx0.414$（此时两项各贡献 $1/\sqrt2$），$\gamma=10^3\Rightarrow\beta\approx1.99$（变成最速下降的尺度）。换句话说 $\beta$ 单调地随 $\gamma$ 减小而增大，$\beta\to\infty$ 时方向趋近 $-\nabla f$——这正是 trust region 半径收缩到零的极限行为。

**消失测试**：没有这个对偶等价，Hessian 奇异处（例如 logistics 里的完全分离数据、Gauss-Newton 里 $\nabla f_i$ 张不满 $R^n$）就只能靠伪逆 $H^\dagger$ 硬撑，而伪逆在 $g\notin R(H)$ 时分量为零、方向不是 descent 的——Levenberg–Marquardt 的整个 $\lambda$ 调节机制正是这条等价关系的工程实现。

**落点**：Boyd §4.4（Lagrange duality）、§9.5.3（trust region 的 Newton 变体）、§A.5.4（伪逆）；实现侧见 `scipy.optimize.least_squares` 的 `method='trf'` 与 `'lm'` 两个分支，源码里 `trf` 用 hard bound、`lm` 用 damping。

**量的方向感**：把 QP 换成线性系统，单步成本从 $O(n^3)$ 的 interior-point 迭代（通常 20–50 次）降到一次 $O(n^3)$ 的 Cholesky——常数差一到两个数量级。</span>

> 小注：原文 Lagrangian 写 $\beta(\|v\|_2^2-\gamma)$，而 KKT 条件写 $Hv+g+\beta v=0$（若对 $\beta\|v\|_2^2$ 求导应为 $2\beta v$）。这是常数 $2$ 的归属问题，不影响 $v$ 的表达式与 $\beta$ 的唯一性，列入小瑕疵表第 2 条。

### Exercise 9.13 · Self-concordance 与 inverse barrier

> 话题摘要：先验证一维函数 $1/x$ 在 $(0,8/9)$ 上 self-concordant，再用仿射重标定把这个一维结论搬到 $m$ 维 inverse barrier 上——常数 $9/8$ 是这一搬运的精确临界值。

**(a)** Show that $f(x)=1/x$ with domain $(0,8/9)$ is self-concordant（自洽）.

**(b)** Show that the function

```math
f(x) = \alpha\sum_{i=1}^{m}\frac{1}{b_i-a_i^Tx}
```

with $\text{dom}\,f=\{x\in R^n\mid a_i^Tx\lt b_i,\ i=1,\dots,m\}$, is self-concordant if $\text{dom}\,f$ is bounded and

```math
\alpha \gt (9/8)\max_{i=1,\dots,m}\ \sup_{x\in\text{dom}\,f}\,(b_i-a_i^Tx).
```

**中文话题摘要**：$1/x$ 的自洽性只依赖 $\sqrt{x}\le 2\sqrt2/3$ 这一个不等式；inverse barrier 靠 $y_i$ 重标定 + 有界性假设继承它。

**Solution.**

**(a)** 各阶导数为

```math
f'(x) = -1/x^2,\qquad f''(x) = 2/x^3,\qquad f'''(x) = -6/x^4,
```

于是 self-concordance condition 是

```math
\frac{6}{x^4} \le 2\Bigl(\frac{2}{x^3}\Bigr)^{3/2} = \frac{4\sqrt2}{x^{4}\sqrt{x}},
```

它在 $\sqrt{x}\le 4\sqrt2/6=\sqrt{8/9}$（即 $x\le 8/9$）时成立。

**(b)** 若作仿射变量替换 $y_i=8(b_i-a_i^Tx)/(9\alpha)$，则对一切 $x\in\text{dom}\,f$ 有 $y_i\lt 8/9$。函数 $f$ 化为 $\sum_{i=1}^{m}(1/y_i)$（差一个正的常数因子），由 (a) 的结论即知它 self-concordant。

<span style="color:#1e8449;">**[译注]** 这里的 $9/8$ 不是凑出来的，它被两件事共同钉死。第一件：$1/x$ 的自洽判据化简后是 $\sqrt{x}\le 2\sqrt2/3$，平方得 $x\le 8/9$——这就是 (a) 里定义域上界的来历。第二件：仿射重标定把 $y_i$ 的**上界**与 $\alpha$ 绑定，$b_i-a_i^Tx\le\sup\lt(8/9)\alpha$ 给出 $y_i=8(b_i-a_i^Tx)/(9\alpha)\lt 64/81$。看起来还有 $64/81$ vs $8/9$ 的余量，但差的这部分正好被「$f$ 只 equal 到 $(8/9)\sum 1/y_i$、而非 $\sum1/y_i$」吃掉：缩放到 $c=8/9\lt 1$ 时判据变成

```math
(3/\sqrt2)\sqrt{y} \le 2\sqrt{c} = 2\sqrt{8/9},
```

右侧是 $1.8856$，而 $\sqrt{y}\lt 8/9=0.8889$ 给出左侧 $1.8856$——**两边恰好相等**。所以 $9/8$ 的每一分都不能动：把它改成 $8/8$，$\sqrt{y}$ 就能顶到 $0.943$，判据立刻失效。

**消失测试**：没有「重标定 + 有界性 $\Rightarrow$ 高维自洽」这条搬运法，$m$ 维 inverse barrier 就得对每个方向 $v$ 手算三阶导再求和，而 barrier 的三阶导是 $m$ 项的和、交叉项 $O(m^3)$ 个——$m=10^4$ 时这条路直接不可行。

**落点**：Boyd §9.6.1（self-concordance 定义 9.41）；习题 9.14 给出更一般的「与 log 复合」规则（9.43），本块 p245 起用；有界性假设在 §11.5 的 analytic center 复杂度分析里再次出现。

**量的方向感**：判据的临界值 $\sqrt{x}=8/9$ 与安全上界 $\sqrt{y}\le 8/9$ 在数值上完全相等，误差余量为 $0$——意味着这个常数是「紧的」，换任何更小的 $\alpha$ 都会在某个 $x$（$b_i$ 取到上确界的方向）上违反自洽性。</span>

### Exercise 9.14 · 与 log 复合

> 话题摘要：$f=-\log(-g)-\log x$ 在 $|g'''|\le 3g''/x$ 下自洽；证明归结为一个 $p^2+q^2+r^2=1$ 上的三次不等式。

**Composition with logarithm.** Let $g:R\to R$ be a convex function with $\text{dom}\,g=R_{++}$, and

```math
|g'''(x)| \le 3\,\frac{g''(x)}{x}
```

for all $x$. Prove that $f(x)=-\log(-g(x))-\log x$ is self-concordant on $\{x\mid x\gt 0,\ g(x)\lt 0\}$.

*Hint.* Use the inequality

```math
\frac{3}{2}rp^2 + q^3 + \frac{3}{2}p^2q + r^3 \le 1
```

which holds for $p,q,r\in R_+$ with $p^2+q^2+r^2=1$.

**中文话题摘要**：这是 self-concordance 的「复合规则」：只要 $g$ 满足 $|g'''|\le 3g''/x$，加一层 $-\log(-g)$ 之后自洽性就自动传递。

**Solution.** $f$ 的各阶导数为

```math
f'(x) = \frac{-g'(x)}{g(x)} - \frac{1}{x},
```

```math
f''(x) = \Bigl(\frac{g'(x)}{g(x)}\Bigr)^{2} + \frac{-g''(x)}{g(x)} + \frac{1}{x^2},
```

```math
f'''(x) = -\frac{g'''(x)}{g(x)} - 2\Bigl(\frac{g'(x)}{g(x)}\Bigr)^{3} + \frac{3g''(x)g'(x)}{g(x)^2} - \frac{2}{x^3}.
```

我们有

```math
|f'''(x)| \le \frac{|g'''(x)|}{-g(x)} + 2\frac{|g'(x)|^3}{(-g(x))^3} + \frac{3g''(x)|g'(x)|}{g(x)^2} + \frac{2}{x^3}
\le \frac{3g''(x)}{-xg(x)} + 2\frac{|g'(x)|^3}{(-g(x))^3} + \frac{3g''(x)|g'(x)|}{g(x)^2} + \frac{2}{x^3}.
```

我们要证

```math
\frac{3g''(x)}{-xg(x)} + 2\frac{|g'(x)|^3}{(-g(x))^3} + \frac{3g''(x)|g'(x)|}{g(x)^2} + \frac{2}{x^3}
\le 2\Bigl(\Bigl(\frac{g'(x)}{g(x)}\Bigr)^2 + \frac{-g''(x)}{g(x)} + \frac{1}{x^2}\Bigr)^{3/2}.
```

为简化记号，定义

```math
p = \frac{(-g''(x)/g(x))^{1/2}}{\bigl(-g''(x)/g(x) + g'(x)^2/g(x)^2 + 1/x^2\bigr)^{1/2}},
```

```math
q = \frac{-|g'(x)|/g(x)}{\bigl(-g''(x)/g(x) + g'(x)^2/g(x)^2 + 1/x^2\bigr)^{1/2}},
```

```math
r = \frac{1/x}{\bigl(-g''(x)/g(x) + g'(x)^2/g(x)^2 + 1/x^2\bigr)^{1/2}}.
```

注意 $p\ge0$、$q\ge0$、$r\ge0$，且 $p^2+q^2+r^2=1$。作这些替换后，上述不等式化为题面 hint 里的那个不等式

```math
\frac{3}{2}rp^2 + q^3 + \frac{3}{2}p^2q + r^3 \le 1 .
```

为完整起见，我们也把这条不等式证出来：

```math
\begin{aligned}
\frac{3}{2}rp^2 + q^3 + \frac{3}{2}p^2q + r^3 &= (r+q)\Bigl(\frac{3}{2}p^2 + q^2 + r^2 - qr\Bigr)\\
&= (r+q)\Bigl(\frac{3}{2}(p^2+q^2+r^2) - \frac{1}{2}(r+q)^2\Bigr)\\
&= \frac{1}{2}(r+q)\bigl(3 - (r+q)^2\bigr)\\
&\le 1 .
\end{aligned}
```

最后一行用到不等式 $(1/2)x(3-x^2)\le1$（$0\le x\le1$），它容易逐项验证。

<span style="color:#1e8449;">**[译注]** 那个看似莫名其妙的三次不等式，其实是「$p,q,r$ 三者在单位球面正卦限上」时一个**齐次化的算子范数**问题。注意 $p,q,r$ 的定义里分母完全相同，都等于 $f''(x)^{1/2}$——于是 $p^2+q^2+r^2=1$ 自动成立，而 $|f'''|/f''^{3/2}$ 恰好等于 $\frac{3}{2}rp^2 + q^3 + \frac{3}{2}p^2q + r^3$ 的两倍。也就是说：**自洽性判据被翻译成「某个三次型在球面正卦限上的最大值 $\le 1$」**。证明用的是极简的代数把戏——把 $q^3+r^3$ 因式分解成 $(q+r)(q^2-qr+r^2)$，再用 $p^2=1-q^2-r^2$ 把括号里的 $\frac32p^2+q^2+r^2-qr$ 化成 $\frac32-\frac12(q+r)^2$，最后令 $t=q+r$，剩下一维 $\frac12t(3-t^2)$。注意 $t$ 的真实范围是 $[0,\sqrt2]$ 而不是题面写的 $[0,1]$；因为 $\frac12t(3-t^2)$ 在 $t\ge1$ 上递减、在 $t=1$ 取到 $1$，$t=\sqrt2$ 时只有 $0.707$，所以 $[0,\sqrt2]$ 上也安全——题面的 $[0,1]$ 是保守写法，不影响结论。

**消失测试**：没有这条复合规则，涉及 $\log$、$\log\det$、entropy 的每一族 barrier 都要重新验证三阶导；而 Boyd 书里 §9.6.3 的 $\log\log$ barrier、§11 的 entropy 型问题都直接调用它，省掉的是每族 $O(n^2)$ 个方向的验证。

**落点**：Boyd (9.43)（与 log 复合的充分条件）；习题 9.15 立即用它处理三个具体函数；对偶侧见习题 9.20（共轭保持自洽）。

**量的方向感**：不等式两边恰好在 $p=0$、$q=r=1/\sqrt2$ 时同时取到 $1/2+1/(2\sqrt2)\cdot2\dots$ 的等号情形附近饱和——等号点说明这个界是紧的，任何把常数 $2$ 调小的版本都会在某个 legit 的 $g$ 上失败。</span>

### Exercise 9.15 · 三个具体函数的自洽性

> 话题摘要：证明自洽性的标准套路——把函数限制到任意直线上，化成一维问题，再套 9.14 的复合规则。

Prove that the following functions are self-concordant. In your proof, restrict the function to a line, and apply the composition with logarithm rule.

**(a)** $f(x,y)=-\log(y^2-x^Tx)$ on $\{(x,y)\mid \|x\|_2\lt y\}$.

**(b)** $f(x,y)=-2\log y-\log(y^{2/p}-x^2)$, with $p\ge1$, on $\{(x,y)\in R^2\mid |x|^p\lt y\}$.

**(c)** $f(x,y)=-\log y-\log(\log y-x)$ on $\{(x,y)\mid e^x\lt y\}$.

**中文话题摘要**：(a) 二阶锥 barrier；(b) $\ell_p$ 型的 log-barrier；(c) $\log\log$ barrier——三者都靠「限制到直线 + 9.14」。

**Solution.**

**(a)** 把 $f$ 写成 $f(x,y)=-\log y-\log(y-x^Tx/y)$，再把函数限制到直线 $x=\hat x+tv$、$y=\hat y+tw$：

```math
f(\hat x+tv,\hat y+tw) = -\log\Bigl(\hat y+tw - \frac{\hat x^T\hat x - 2t\hat x^Tv - t^2v^Tv}{\hat y+tw}\Bigr) - \log(\hat y+tw).
```

若 $w=0$，log 的自变量退化成 $t$ 的二次函数，这正是例 9.6 处理过的情形。否则可以用 $y$ 代替 $t$ 作变量（即作替换 $t=(y-\hat y)/w$），得到

```math
f(\hat x+tv,\hat y+tw) = -\log(\alpha+\beta y-\gamma/y) - \log y
```

其中

```math
\alpha = 2\frac{\hat y\,v^Tv}{w^2} - 2\frac{\hat x^Tv}{w},\qquad
\beta = 1 - \frac{v^Tv}{w^2},
```

```math
\gamma = \hat x^T\hat x - 2\frac{\hat y\,\hat x^Tv}{w} + \frac{\hat y^2\,v^Tv}{w^2} = \Bigl\| \hat x - \frac{\hat y}{w}v \Bigr\|_2^2 .
```

令 $g(y)=-\alpha-\beta y+\gamma/y$，就有

```math
f(\hat x+tv,\hat y+tw) = -\log(-g(y)) - \log y .
```

函数 $g$ 是凸的（因为 $\gamma\gt 0$），且满足 (9.43)，理由是

```math
g'''(y) = -6\gamma/y^4,\qquad g''(y) = 2\gamma/y^3,
```

于是 $|g'''|=6\gamma/y^4=3g''(y)/y$，正好取等号。

**(b)** 可以把 $f$ 写成两个函数之和



即 $p\ge -1$；而题设已给 $p\ge1$，故成立。

```math
-\log y - \log(\log y - a - by),
```

于是只需证明 $g(y)=a+by-\log y$ 满足 (9.43)。我们有



<span style="color:#1e8449;">**[译注]** 「限制到直线」是这一节最值钱的证明范式，值得单独记住：二维（甚至 $n$ 维）函数自洽 $\iff$ 沿**每一条**直线的一元函数自洽。这不是技巧而是定义使然——$\nabla^3f(x)[v,v,v]$ 本来就是「沿方向 $v$ 的三阶方向导数」，把 $t\mapsto f(x+tv)$ 记作 $\tilde f(t)$，则 $\tilde f''' (0)=\nabla^3f(x)[v,v,v]$、$\tilde f''(0)=v^T\nabla^2f(x)v$，判据逐字对应。于是 $n$ 维问题被降到一维，可以用 9.14 那条复合规则。三个小题都靠同一个动作收尾：(a) 令 $g=-\alpha-\beta y+\gamma/y$ 后右端取等号 $6\gamma/y^4=3g''/y$；(c) 令 $g=a+by-\log y$ 后得 $2/y^3\le3/y^3$（差一个 $\frac32$ 的安全系数）。特别注意 (a) 里 $\gamma=\|\hat x-(\hat y/w)v\|_2^2\ge0$ 的几何含义：它正是「直线离锥边界有多远」的平方，$\gamma\gt 0$ 保证 $g$ 凸。

**消失测试**：没有「限制到直线」这一步，二阶锥 barrier 的自洽性要在 $R^{n+1}$ 上枚举 $O(n^3)$ 个三阶偏导组合；有了它只需算一个一元函数的三阶导，成本从 $O(n^3)$ 降到 $O(1)$——这是 §11 内点法复杂度证明能写得下的前提。

**落点**：Boyd §9.6.1（self-concordance 的直线判据）、例 9.6（$-\log(y^2-x^Tx)$ 的原始处理）、(9.43)；习题 9.14 是引用的引理；对偶锥侧见 §2.6.2。

**量的方向感**：$n$ 维时三阶张量有 $n^3$ 个独立分量，直线判据把它压成 $1$ 维的单一不等式——工作量从 $O(n^3)$ 到 $O(1)$。</span>

### Exercise 9.16 · 一维 self-concordant 函数的极值形态

> 话题摘要：一维自洽条件可改写成 $f''^{-1/2}$ 的 Lipschitz 常数为 $1$；两个极值函数是 $-x$ 与 $x$ 的两侧 log，并且 $f''$ 要么恒 $0$ 要么恒正。

Let $f:R\to R$ be a self-concordant function.

**(a)** Suppose $f''(x)\ne0$. Show that the self-concordance condition (9.41) can be expressed as

```math
\Bigl| \frac{d}{dx} f''(x)^{-1/2} \Bigr| \le 1 .
```

Find the 'extreme' self-concordant functions of one variable, i.e., the functions $f$ and $\tilde f$ that satisfy

```math
\frac{d}{dx} f''(x)^{-1/2} = 1,\qquad \frac{d}{dx} \tilde f''(x)^{-1/2} = -1,
```

respectively.

**(b)** Show that either $f''(x)=0$ for all $x\in\text{dom}\,f$, or $f''(x)\gt 0$ for all $x\in\text{dom}\,f$.

**中文话题摘要**：自洽性等价于 $f''^{-1/2}$ 是 $1$-Lipschitz；这个等价形式直接给出「$f''$ 不可能既正又触零」的结论。

**Solution.**

**(a)** 我们有

```math
\frac{d}{dx}f''(x)^{-1/2} = (-1/2)\frac{f'''(x)}{f''(x)^{3/2}} .
```

积分

```math
\frac{d}{dx}f''(x)^{-1/2} = 1
```

给出 $f(x)=-\log(x+c_0)+c_1x+c_2$。积分

```math
\frac{d}{dx}f''(x)^{-1/2} = -1
```

给出 $f(x)=-\log(-x+c_0)+c_1x+c_2$。

**(b)** 反设 $f''(0)\gt 0$、$f''(\bar x)=0$（$\bar x\gt 0$），且 $f''(x)\gt 0$ 在 $0$ 与 $\bar x$ 之间成立。不等式

```math
-1 \le \frac{d}{dx}f''(x)^{-1/2} \le 1
```

在 $x$ 介于 $0$ 与 $\bar x$ 之间时成立。积分给出

```math
f''(\bar x)^{-1/2} - f''(0)^{-1/2} \le \bar x,
```

这与 $f''(\bar x)=0$（左端为 $+\infty$）矛盾。

<span style="color:#1e8449;">**[译注]** 这一步把「三阶导被二阶导控制」换成了「$f''^{-1/2}$ 是 $1$-Lipschitz」，好处是**立刻可积**。设 $\phi(x)=f''(x)^{-1/2}$，则 $|\phi'|\le1$ 意味着 $\phi$ 的图形落在斜率为 $\pm1$ 的两条直线之间，于是 $\phi(\bar x)\ge\phi(0)-\bar x$；但 $f''(\bar x)=0$ 要求 $\phi(\bar x)=+\infty$，矛盾。这条论证顺便说明为什么自洽类函数只有「严格凸」和「完全平坦」两种命运：$(f'')^{-1/2}$ 是 Lipschitz 的，它若在某点有限、之后某点无穷，中间必须有无限斜率。工程含义是 **Hessian 的零空间不随 $x$ 变化**（下半题 9.17(b) 把它推广到 $n$ 维），所以自洽函数的 Newton 系统在整条路径上「同秩」——内点法里这意味着不存在从正定退化为半正定的中途状态。

两个极值函数 $f=-\log(x+c_0)+c_1x+c_2$ 与 $\tilde f=-\log(-x+c_0)+c_1x+c_2$ 分别把 $|f'''|=2f''^{3/2}$ 取成等号，可以当作「自洽性紧不紧」的标准砝码：任何新提出的自洽判据，先在 $-\log x$ 上验一遍。

**消失测试**：没有 $f''^{-1/2}$ 的 Lipschitz 形式，9.17(c) 的 Hessian 夹逼 $(1-t\alpha)^2\nabla^2f(x)\preceq\nabla^2f(x+tv)\preceq(1-t\alpha)^{-2}\nabla^2f(x)$ 就无从导出，而 9.18 的二次收敛率 $\lambda^+\le\lambda^2/(1-\lambda)^2$ 完全建立在这个夹逼上——整条「自洽 $\to$ 二次收敛」的链条会断在第一步。

**落点**：Boyd (9.41)（自洽定义）、(9.45)–(9.46)（由 9.16 得到的两个夹逼）、§9.7（自洽函数的收敛分析）；习题 9.18 用 9.17(c) 直接收尾。

**量的方向感**：$(f'')^{-1/2}$ 的 Lipschitz 常数从「有界」收紧到恰好 $1$，直接决定 9.18 里 $\lambda$ 的收敛因子——常数若为 $k$，最终率会变成 $\lambda^+\le k^2\lambda^2/(1-k\lambda)^2$。</span>

### Exercise 9.17 · Hessian 的上下界

> 话题摘要：二维自洽函数的全部三阶偏导被两个二阶偏导控制，以及 $t$ 方向上 Hessian 的乘性夹逼——9.18 的二次收敛全靠后者。

**(a)** Let $f:R^2\to R$ be a self-concordant function. Show that

```math
\Bigl| \frac{\partial^3f(x)}{\partial x_i^3} \Bigr| \le 2\Bigl(\frac{\partial^2f(x)}{\partial x_i^2}\Bigr)^{3/2},\qquad i=1,2,
```

```math
\Bigl| \frac{\partial^3f(x)}{\partial x_i^2\partial x_j} \Bigr| \le 2\Bigl(\frac{\partial^2f(x)}{\partial x_i^2}\Bigr)\Bigl(\frac{\partial^2f(x)}{\partial x_j^2}\Bigr)^{1/2},\qquad i\ne j,
```

for all $x\in\text{dom}\,f$.

```math
\begin{aligned}
h(u,v,w) = {} & a_1u_1v_1w_1 + a_2(u_1v_1w_2 + u_1v_2w_1 + u_2v_1w_1)\\
```

then

```math
\sup_{u,v,w\ne0}\frac{h(u,v,w)}{\|u\|_2\|v\|_2\|w\|_2} = \sup_{u\ne0}\frac{h(u,u,u)}{\|u\|_2^3}.
```

**中文话题摘要**：对称三线性型的「三变量 sup = 单变量 sup」是本题的全部技术核心，它把 $n^3$ 个偏导的界压成一条。

**Solution.** 先记下 hint 里结论的一个推广。设 $A\in S^2_{++}$、$h$ 对称且三线性。则 $h(A^{-1/2}u,A^{-1/2}v,A^{-1/2}w)$ 仍是 symmetric trilinear function，于是

```math
\sup_{u,v,w\ne0}\frac{h(A^{-1/2}u,A^{-1/2}v,A^{-1/2}w)}{\|u\|_2\|v\|_2\|w\|_2} = \sup_{u\ne0}\frac{h(A^{-1/2}u,A^{-1/2}u,A^{-1/2}u)}{\|u\|_2^3},
```

即

```math
\sup_{u,v,w\ne0}\frac{h(u,v,w)}{(u^TAu)^{1/2}(v^TAv)^{1/2}(w^TAw)^{1/2}} = \sup_{u\ne0}\frac{h(u,u,u)}{(u^TAu)^{3/2}}. \qquad\text{(9.17.A)}
```

按定义，$f:R^n\to R$ self-concordant 当且仅当

```math
\Bigl| u^T\frac{d}{dt}\nabla^2f(\hat x+tu)\Bigr|_{t=0}u \Bigr| \le 2\bigl(u^T\nabla^2f(\hat x)u\bigr)^{3/2}
```

对一切方向 $u$ 与一切 $\hat x\in\text{dom}\,f$ 成立。当 $n=2$ 时这意味着

```math
|h(u,u,u)| \le (u^TAu)^{3/2}
```

对一切 $u$ 成立，其中

```math
\begin{aligned}
h(u,v,w) &= u^T\frac{d}{dt}\nabla^2f(\hat x+tv)\Bigr|_{t=0}w\\
&= u_1v_1w_1\frac{\partial^3f(\hat x)}{\partial x_1^3} + (u_1v_1w_2 + u_1v_2w_1 + u_2v_1w_1)\frac{\partial^3f(\hat x)}{\partial x_1^2\partial x_2}\\
&\quad + (u_1v_2w_2 + u_2v_1w_2 + u_2v_2w_1)\frac{\partial^3f(\hat x)}{\partial x_1\partial x_2^2} + u_2v_2w_2\frac{\partial^3f(\hat x)}{\partial x_2^3},
\end{aligned}
```

```math
u^TAu = u_1^2\frac{\partial^2f(\hat x)}{\partial x_1^2} + 2u_1u_2\frac{\partial^2f(\hat x)}{\partial x_1\partial x_2} + u_2^2\frac{\partial^2f(\hat x)}{\partial x_2^2},
```

即 $A=\nabla^2f(\hat x)$（注意这里 $h$ 的定义里 $v$ 出现在微分方向、$w$ 出现在左侧向量位，与 hint 的哑指标顺序不同，但对称性保证结果一致）。换言之

```math

```

把 (9.17.A) 同时用到 $h$ 与 $-h$ 上，还得到

```math

```

对一切 $u,v,w$ 成立。不等式

```math
\Bigl|\frac{\partial^3f(x)}{\partial x_1^3}\Bigr| \le 2\Bigl(\frac{\partial^2f(x)}{\partial x_1^2}\Bigr)^{3/2},\qquad

```

```math
\Bigl|\frac{\partial^3f(x)}{\partial x_1^2\partial x_2}\Bigr| \le 2\Bigl(\frac{\partial^2f(x)}{\partial x_1^2}\Bigr)\Bigl(\frac{\partial^2f(x)}{\partial x_2^2}\Bigr)^{1/2},\qquad
```

**(b)** Let $f:R^n\to R$ be a self-concordant function. Show that the nullspace of $\nabla^2f(x)$ is independent of $x$. Show that if $f$ is strictly convex, then $\nabla^2f(x)$ is nonsingular for all $x\in\text{dom}\,f$.

*Hint.* Prove that if $w^T\nabla^2f(x)w=0$ for some $x\in\text{dom}\,f$, then $w^T\nabla^2f(y)w=0$ for all $y\in\text{dom}\,f$. To show this, apply the result in (a) to the self-concordant function $\tilde f(t,s)=f(x+t(y-x)+sw)$.

**中文话题摘要**：Hessian 的零空间是**不随 $x$ 移动**的不变集；这等价于说自洽函数不会「中途掉秩」。

**Solution.** 设 $w^T\nabla^2f(x)w=0$。我们要证对一切 $y\in\text{dom}\,f$ 都有 $w^T\nabla^2f(y)w=0$。令 $v=y-x$，并令 $\tilde f$ 是 $f$ 限制到由 $w$、$v$ 张成的过 $x$ 的平面：

```math
\tilde f(s,t) = f(x+sw+tv).
```

再定义

```math
g(t) = w^T\nabla^2f(x+tv)w = \frac{\partial^2\tilde f(0,t)}{\partial s^2}.
```

$\tilde f$ 是二元 self-concordant 函数，故由 (a) 得

```math
|g'(t)| = \Bigl|\frac{\partial^3\tilde f(0,t)}{\partial t\,\partial s^2}\Bigr|
\le 2\Bigl(\frac{\partial^2\tilde f(0,t)}{\partial t^2}\Bigr)^{1/2}\Bigl(\frac{\partial^2\tilde f(0,t)}{\partial s^2}\Bigr)
= 2\Bigl(\frac{\partial^2\tilde f(0,t)}{\partial t^2}\Bigr)^{1/2} g(t),
```

即当 $g(t)\ne0$ 时

```math
\frac{d}{dt}\log g(t) \ge -2\Bigl(\frac{\partial^2\tilde f(0,t)}{\partial t^2}\Bigr)^{1/2}.
```

按假设 $g(0)\gt0$ 而 $g(1)=0$（若不然，把 $t$ 换成最小的使 $g(t)=0$ 的正 $t$）。设 $g(\tau)\gt0$ 对 $0\le\tau\lt t$ 成立。把上面的不等式积分，得

```math
\log\frac{g(t)}{g(0)} \ge -2\int_0^t\Bigl(\frac{\partial^2\tilde f(0,\tau)}{\partial s^2}\Bigr)^{1/2}d\tau,
```

即

```math
\frac{g(t)}{g(0)} \ge \exp\Bigl(-2\int_0^t\Bigl(\frac{\partial^2\tilde f(0,\tau)}{\partial s^2}\Bigr)^{1/2}d\tau\Bigr),
```

这与假设 $g(t)=0$ 矛盾。于是结论是：要么 $g(t)=0$ 对一切 $t$ 成立，要么 $g(t)\gt0$ 对一切 $t$ 成立。由于 $x$ 与 $v$ 任意，一个向量 $w$ 要么满足 $w^T\nabla^2f(x)w=0$ 对一切 $x$ 成立，要么满足 $w^T\nabla^2f(x)w\gt0$ 对一切 $x$ 成立。

最后，设 $f$ strictly convex，但存在某个 $x$ 与 $v\ne0$ 使 $v^T\nabla^2f(x)v=0$。由刚才的结论，$v^T\nabla^2f(x+tv)v=0$ 对一切 $t$ 成立，即 $f$ 在直线 $x+tv$ 上是仿射的，这与严格凸矛盾。

<span style="color:#1e8449;">**[译注]** 这半题的正确定位是「**秩不变定理**」：自洽函数的 Hessian 在整个定义域上保持同一个零空间。它对数值计算的直接后果是——Newton 系统要么每一点都可解，要么每一点都不唯一，不存在「走到半路突然奇异」的中间态。反过来，这也给出一个免费的**奇异检测**：只要在任意一点发现 $\nabla^2f(x)$ 奇异，你就知道整条路径都不能用纯 Newton step，必须直接上 9.12 的 trust region 或伪逆。证明的技术点在于把「一维 $g(t)$ 的零点不能孤立出现」翻译成微分不等式 $(\log g)'\ge-2(\partial^2_{tt}\tilde f)^{1/2}$：右端可积，所以 $\log g$ 的衰减是有限的，$g$ 不可能从正数跌到 $0$ 再回升。注意这里要小心原文的取值方向：真正被假设的是 $w^T\nabla^2f(x)w=0$（即 $g(0)=0$），证明里出现的「$g(0)\gt0$ 而 $g(1)=0$」应理解为反证法的临时设定（先假定存在正的一段），否则与出发点直接冲突；这一点列入小瑕疵表第 3 条。

**消失测试**：没有秩不变定理，9.17(c) 的乘性夹逼无法在 $t$ 区间端点处取极限，因为 $\partial^2_{ss}\tilde f$ 可能中途归零使对数发散，9.18 的 $\lambda^+\le\lambda^2/(1-\lambda)^2$ 就整条失效——Newton 法的「二次收敛」就只剩经验观察而没有定理支撑。

**落点**：Boyd §9.6.3（(9.46) 与自洽函数的 Hessian 夹逼）、习题 9.17(c)；共轭侧对偶结论见 9.20；工程上的「同秩」检验可用 `numpy.linalg.matrix_rank` 在路径两端各算一次。

**量的方向感**：零空间维数从 $x$ 到 $y$ 变化量为 $0$（不是「很小」）；若某实现观察到秩改变，那一定是 bug 而不是数值噪声。</span>

**(c)** Let $f:R^n\to R$ be a self-concordant function. Suppose $x\in\text{dom}\,f$, $v\in R^n$. Show that

```math
(1-t\alpha)^2\nabla^2f(x) \preceq \nabla^2f(x+tv) \preceq \frac{1}{(1-t\alpha)^2}\nabla^2f(x)
```

for $x+tv\in\text{dom}\,f$, $0\le t\lt 1/\alpha$, where $\alpha=(v^T\nabla^2f(x)v)^{1/2}$.

**中文话题摘要**：沿 $t$ 方向 Hessian 的相对变化被 $(1-t\alpha)^{\pm2}$ 夹死，$\alpha$ 是初点的 Newton decrement；这是全部二次收敛论证的引擎。

**Solution.** 与 (b) 部分一样，可以证明

```math
\frac{d}{dt}\log g(t) \le 2\Bigl(\frac{\partial^2\tilde f(0,t)}{\partial t^2}\Bigr)^{1/2},
```

其中 $g(t)=w^T\nabla^2f(x+tv)w$、$\tilde f(s,t)=f(x+sw+tv)$。把 (9.46) 的上界用到单变量 self-concordant 函数 $\tilde f(0,t)=f(x+tv)$ 上，得到

```math
\frac{\partial^2\tilde f(0,t)}{\partial s^2} \le \frac{\alpha^2}{(1-t\alpha)^2},
```

于是

```math
-\frac{2\alpha}{(1-t\alpha)} \le \frac{d}{dt}\log g(t) \le \frac{2\alpha}{(1-t\alpha)} .
```

积分给出

```math
2\log(1-t\alpha) \le \log\bigl(g(t)/g(0)\bigr) \le -2\log(1-t\alpha),
```

<!-- ===== p249 ===== -->

即

```math
g(0)(1-t\alpha)^2 \le g(t) \le \frac{g(0)}{(1-t\alpha)^2}.
```

最后注意到 $g(0)=\alpha^2$，便得不等式

```math
(1-t\alpha)^2 w^T\nabla^2f(x)w \le w^T\nabla^2f(x+tv)w \le \frac{w^T\nabla^2f(x)w}{(1-t\alpha)^2}.
```

这对一切 $w$ 成立，因此

```math
(1-t\alpha)^2\nabla^2f(x) \preceq \nabla^2f(x+tv) \preceq \frac{1}{(1-t\alpha)^2}\nabla^2f(x).
```

<span style="color:#1e8449;">**[译注]** 这条夹逼值得单独记账，因为它是整个「自洽 $\Rightarrow$ 二次收敛」链条中唯一真正用到「常数 $2$」的地方。取 $f(x)=-\log x$、$x=1$、$v=1$：$\alpha=(f''(1))^{1/2}=1$，夹逼给出 $(1-t)^2\preceq 1/(1+t)^2\preceq(1-t)^{-2}$，$t=0.5$ 时 $0.25\le0.444\le4$——成立但上下界都留了 $4$ 倍以上的余量。这个余量说明夹逼**不是紧的**，它换来的是形式上的统一：无论 $f$ 是什么，指数都是 $2$。这个「指数恰好 2」正是 9.18 里二次收敛的根源——把 $(1-t\lambda)^{-2}$ 从 $t=0$ 积到 $t=1$ 得 $\int_0^1[(1-t\lambda)^{-2}-1]dt=\lambda/(1-\lambda)$，是一个**只含 $\lambda$ 的一次式**，于是 $\lambda^+\lesssim\lambda^2$。

**消失测试**：没有这条夹逼，9.18 的证明无法开工；退一步说，若只有加性界 $\nabla^2f(x+tv)\preceq\nabla^2f(x)+(t\alpha')\nabla^2f(x)$，则积分出来是 $O(\lambda^2)$ 的绝对误差，除以 $f''$ 之后只能得到**线性**收敛，$\lambda$ 每步至多减半——这正是普通 gradient method 的行为，10 位精度要多跑 $3\text{–}4$ 倍迭代。

**落点**：Boyd (9.46)（Hessian 的乘性夹逼，上式即其原形）；9.18 第一步就把 $v$ 取成 Newton step、$\alpha$ 取成 $\lambda(x)$；自洽函数的 \text{damped Newton} 复杂度 $O(\log\log(1/\epsilon))$ 阶段完全依赖它。

**量的方向感**：$t=0.5$、$\lambda=0.5$ 时夹逼上下界之比为 $1/(1-0.25)^2\div(0.25)=21.3$；而实际函数的比值只有 $1.78$——这说明定理的保守程度约一个数量级，工程上可据此预期「实际迭代数远低于理论上界」。</span>

### Exercise 9.18 · Quadratic convergence（二次收敛）

> 话题摘要：$\lambda\lt1$ 时一步 Newton 把 decrement 从 $\lambda$ 压到 $\lambda^2/(1-\lambda)^2$——指数是 **2**，不是 $2^k$。

Let $f:R^n\to R$ be a strictly convex self-concordant function. Suppose $\lambda(x)\lt1$, and define $x^+=x-\nabla^2f(x)^{-1}\nabla f(x)$. Prove that

```math
\lambda(x^+) \le \frac{\lambda(x)^2}{(1-\lambda(x))^2}.
```

*Hint.* Use the inequalities in exercise 9.17, part (c).

**中文话题摘要**：这就是「二次收敛」的精确陈述：误差的**对数**每步翻倍，故误差按 $\lambda^{2^k}$ 消失；把 $\lambda^2$ 误读成「每步平方」是不够的。

**Solution.** 令 $v=-\nabla^2f(x)^{-1}\nabla f(x)$。由习题 9.17(c) 得

```math
(1-t\lambda(x))^2\nabla^2f(x) \preceq \nabla^2f(x+tv) \preceq \frac{1}{(1-t\lambda(x))^2}\nabla^2f(x).
```

不妨设 $\nabla^2f(x)=I$（于是 $v=-\nabla f(x)$，且 $\|v\|_2=\lambda(x)$），此时

```math
(1-\lambda(x))^2 I \preceq \nabla^2f(x^+) \preceq \frac{1}{(1-\lambda(x))^2}I .
```

于是可以把 $\lambda(x^+)$ 写成并估计为

```math
\begin{aligned}
\lambda(x^+) &= \|\nabla^2f(x^+)^{-1}\nabla f(x^+)\|_2\\
&\le (1-\lambda(x))^{-1}\|\nabla f(x^+)\|_2\\
&= (1-\lambda(x))^{-1}\Bigl\| \int_0^1 \nabla^2f(x+tv)v\,dt + \nabla f(x) \Bigr\|_2\\
&= (1-\lambda(x))^{-1}\Bigl\| \int_0^1 \bigl(\nabla^2f(x+tv)-I\bigr)dt\; v \Bigr\|_2\\
&\le (1-\lambda(x))^{-1}\int_0^1\Bigl(\frac{1}{(1-t\lambda(x))^2}-1\Bigr)dt\;\|v\|_2\\
&\le \|v\|_2(1-\lambda(x))^{-1}\int_0^1\Bigl(\frac{1}{(1-t\lambda(x))^2}-1\Bigr)dt\\
&= \frac{\lambda(x)^2}{(1-\lambda(x))^2}.
\end{aligned}
```

<span style="color:#1e8449;">**[译注]** 这条结果最容易被讲错的地方是指数形式。$\lambda^+\le\lambda^2/(1-\lambda)^2$ 说的是**平方**，不是「每步误差平方」这么简单——真正的过程是：$\lambda_1\le2\lambda_0^2$，$\lambda_2\le2(2\lambda_0^2)^2=2^3\lambda_0^4$，$\lambda_k\le2^{2^k-1}\lambda_0^{2^k}$。所以 $\lambda_k\approx(\lambda_0)^{2^k}$，即**每次迭代把有效位数翻倍**：$\lambda_0=0.1$ 时 $\lambda_1\le0.0123$、$\lambda_2\le1.6\cdot10^{-4}$、$\lambda_3\le2.5\cdot10^{-8}$、$\lambda_4\le6.6\cdot10^{-16}$——4 步到机器精度。如果把它误写成 $2^{-k}$（几何下降），同样 4 步只能到 $0.0625$，要到 $10^{-16}$ 需 53 步，差 13 倍。这就是为什么「二次收敛」在 $-\log x$、二阶锥 barrier 这类问题上表现为**迭代数是常数**（典型 5–8 步），而不是随精度线性增长。

**消失测试**：把指数从 $2$ 写错成 $1$ 的直接后果不是数值精度下降，而是**复杂度类别判断错误**：内点法的阶段二会被估成 $O(\log(1/\epsilon))$ 而不是 $O(\log\log(1/\epsilon))$，对 $\epsilon=10^{-10}$ 就差出 $\log_2 10^{10}/\log_2\log_2 10^{10}=33.2/5.1\approx6.5$ 倍——恰好是「内点法比椭球法快多少」这一经典结论的数量级差。

**落点**：Boyd §9.5.3（(9.47) 前的准备）、(9.46)、§9.6.4 的 (9.56) 复杂度、§11.5 内点法阶段二；$\lambda_0=0.1$ 的表格可用 4 行 python 复算。

**量的方向感**：$\lambda_0=0.1$ 时 $2^{-k}$ 假象给 $k=53$，真实 $2^k$ 给 $k=4$——差 49 次迭代，按每次 $O(n^3)$ 的 Cholesky 计，$n=1000$ 时约差 $49\cdot3\cdot10^8$ flops。</span>

### Exercise 9.19 · 到最优点的距离界

> 话题摘要：$\lambda(\bar x)\lt1$ 加上 sublevel set 闭，就能保证极小点存在，并给出带 Hessian 度量的距离上界 $\lambda/(1-\lambda)$。

Let $f:R^n\to R$ be a strictly convex self-concordant function.

**(a)** Suppose $\lambda(\bar x)\lt1$ and the sublevel set $\{x\mid f(x)\le f(\bar x)\}$ is closed. Show that the minimum of $f$ is attained and

```math
\bigl((\bar x-x^\star)^T\nabla^2f(\bar x)(\bar x-x^\star)\bigr)^{1/2} \le \frac{\lambda(\bar x)}{1-\lambda(\bar x)} .
```

**(b)** Show that if $f$ has a closed sublevel set, and is bounded below, then its minimum is attained.

**中文话题摘要**：(a) 把「沿 Newton 方向能走多远」换成「到最优点的距离有多远」；(b) 有下界 + sublevel set 闭 $\Rightarrow$ 下确界可达。

**Solution.**

**(a)** 与 (9.47) 的推导一样，对任意 descent direction $v$ 考虑函数 $\tilde f(t)=f(\hat x+tv)$。由 (9.44) 注意

```math
1 + \frac{\tilde f'(0)}{\tilde f''(0)^{1/2}} \gt 0
```

只要 $\lambda(\bar x)\lt1$。

<!-- ===== p250 ===== -->

先论证 $\tilde f(t)$ 在某个正（有限）的 $t^\star$ 处取到极小。令 $t_0=\sup\{t\ge0\mid \hat x+tv\in\text{dom}\,f\}$。若 $t_0=\infty$（即 $\hat x+tv\in\text{dom}\,f$ 对一切 $t\ge0$ 成立），则由 (9.47)，$\tilde f'(t)\gt0$ 当

```math
t \gt \bar t = \frac{-\tilde f'(0)}{\tilde f''(0)+\tilde f''(0)^{1/2}\tilde f'(0)},
```

故 $\tilde f$ 必在区间 $(0,\bar t)$ 内取到极小。若 $t_0$ 有限，则由 sublevel set $\{t\mid \tilde f(t)\le\tilde f(0)\}$ 闭可知

```math
\lim_{t\to t_0}\tilde f(t) \gt \tilde f(0),
```

因此 $\tilde f$ 在 $(0,t_0)$ 内取到极小。两种情形下都有

```math
t^\star \le \frac{-\tilde f'(0)}{\tilde f''(0)+\tilde f''(0)^{1/2}\tilde f'(0)},
```

即

```math
\frac{\tilde f''(0)^{1/2}\,t^\star}{-\tilde f'(0)/\tilde f''(0)^{1/2}}
\le \frac{1}{1+\tilde f'(0)/\tilde f''(0)^{1/2}} \le \frac{\lambda(x)}{1-\lambda(x)},
```

这里又一次用了 (9.44)。这个对 $t^\star$ 的界对任意 descent vector $v$ 都成立。特别地，取方向 $v=x^\star-x$ 时有 $t^\star=1$，于是得到

```math
\bigl((\bar x-x^\star)^T\nabla^2f(\bar x)(\bar x-x^\star)\bigr)^{1/2} \le \frac{\lambda(\bar x)}{1-\lambda(\bar x)} .
```

**(b)** 若 $f$ 严格凸、self-concordant 且 sublevel set 闭，则此前对 Newton 法的收敛分析适用。换言之，经过有限次迭代后 $\lambda(x)$ 变得小于 $1$，再由上一条结论即知极小点被取到。

<span style="color:#1e8449;">**[译注]** (a) 的实用读法是：**Newton decrement 是一个「带尺度的距离」**。$\lambda(\bar x)\lt1$ 时你能保证最优点落在椭球

```math
\{ x \mid (x-\bar x)^T\nabla^2f(\bar x)(x-\bar x) \le (\lambda/(1-\lambda))^2 \}
```

之内，而这个椭球的长短轴由 $\nabla^2f(\bar x)$ 的特征值决定——也就是说，认证的「半径」是**仿射不变**的：换坐标、换单位都不改变 $\lambda$。这一点梯度范数做不到：$\|\nabla f\|_2$ 在重标定后可以任意缩放，同样的 $\|\nabla f\|=10^{-3}$ 在不同问题上可能意味着「差 $10^{-9}$」也可能意味着「差 $10^{3}$」。取 $\lambda=0.5$：界给 $1.0$；$\lambda=0.1$：界给 $0.111$；$\lambda=0.9$：界给 $9.0$——注意 $\lambda\to1$ 时界**爆炸**，所以这个工具只在 $\lambda$ 已经小的时候有用，这也正是 Newton 法两阶段的必然分工：先用 damped Newton 把 $\lambda$ 压到 $1$ 以下，再用这个界做停止判据，或用它做「有解性认证」。

**消失测试**：没有这个界，停机判据只能退回到 $\|\nabla f\|_2\le\eta$ 或 $f(x)-p^\star\le\epsilon$；前者对尺度敏感（条件数 $10^{6}$ 的二次型上会把误差估计得偏差 $10^{3}$ 倍），后者需要事先知道 $p^\star$，而 $p^\star$ 恰恰是要求的东西——循环依赖。

**落点**：Boyd §9.6.3 的 (9.47)、§9.7（收敛分析的分阶段论证）、§11.5 的「$\lambda\lt 1/4$ 时进入二次收敛阶段」；(9.44) 是这条界成立的关键不等式。

**量的方向感**：$\lambda$ 从 $0.1$ 涨到 $0.9$ 时距离界从 $0.111$ 涨到 $9.0$——$81$ 倍；而 $\lambda$ 本身只涨 $9$ 倍，因为界里有因子 $(1-\lambda)^{-1}$ 的平方效应（$1/\lambda\cdot\lambda^2$ 的组合）。</span>

### Exercise 9.20 · self-concordant 函数的共轭

> 话题摘要：闭、严格凸、自洽 $\Rightarrow$ Legendre 变换 $f^\star$ 也自洽；证明靠 $g''(0)=h''(0)$、$g'''(0)=-h'''(0)$ 两条恒等式。

**Conjugate of a self-concordant function.** Suppose $f:R^n\to R$ is closed, strictly convex, and self-concordant. We show that its conjugate（共轭函数，或称 Legendre transform）$f^\star$ is self-concordant.

**(a)** Show that for each $y\in\text{dom}\,f^\star$, there is a unique $x\in\text{dom}\,f$ that satisfies $y=\nabla f(x)$. *Hint.* Refer to the result of exercise 9.19.

**(b)** Suppose $\bar y=\nabla f(\bar x)$. Define

```math
g(t)=f(\bar x+tv),\qquad h(t)=f^\star(\bar y+tw)
```

where $v\in R^n$ and $w=\nabla^2f(\bar x)v$. Show that

```math
g''(0)=h''(0),\qquad g'''(0)=-h'''(0).
```

Use these identities to show that $f^\star$ is self-concordant.

**中文话题摘要**：自洽性在共轭运算下封闭——这条性质保证「原问题的 barrier 自洽」可以自动搬给对偶问题。

**Solution.**

**(a)** $y\in\text{dom}\,f^\star$ 意味着 $f(x)-y^Tx$ 作为 $x$ 的函数有下界。由习题 9.19(a)，该下界可达。最小化者满足 $\nabla f(x)=y$，且因 $f(x)-y^Tx$ 严格凸而唯一。

**(b)** 设 $F$ 是 $\nabla f$ 的逆映射，即 $x=F(y)$ 当且仅当 $y=\nabla f(x)$。于是 $\bar x=F(\bar y)$，且（由习题 3.40）

```math
\nabla f^\star(y)=F(y),\qquad \nabla^2f^\star(y)=\nabla^2f(F(y))^{-1}
```

对一切 $y\in\text{dom}\,f^\star$ 成立。

<!-- ===== p251 ===== -->

第一个等式由 $\nabla^2f^\star(\bar y)=\nabla^2f(\bar x)^{-1}$ 得出：

```math
g''(0) = v^T\nabla^2f(\bar x)v = w^T\nabla^2f^\star(\bar y)w = h''(0).
```

为证第二个等式，定义

```math
G = \frac{d}{dt}\nabla^2f(\bar x+tv)\Bigr|_{t=0},\qquad H = \frac{d}{dt}\nabla^2f^\star(\bar y+tw)\Bigr|_{t=0},
```

即对小 $t$ 有

```math
\nabla^2f(\bar x+tv) \approx \nabla^2f(\bar x)+tG,\qquad \nabla^2f^\star(\bar y+tw) \approx \nabla^2f^\star(\bar y)+tH,
```

并且

```math
\begin{aligned}
\nabla^2f^\star(\nabla f(\bar x+tv)) &\approx \nabla^2f^\star\bigl(\nabla f(\bar x)+t\nabla^2f(\bar x)v\bigr)\\
&= \nabla^2f^\star(\bar y+tw)\\
&\approx \nabla^2f^\star(\bar y)+tH.
\end{aligned}
```

把方程

```math
\nabla^2f^\star(\nabla f(\bar x+tv))\,\nabla^2f(\bar x+tv) = I
```

两边线性化，得

```math
H\nabla^2f(\bar x) + \nabla^2f^\star(\bar y)G = 0,
```

即 $G=-\nabla^2f(\bar x)H\nabla^2f(\bar x)$。于是

```math
\begin{aligned}
g'''(0) &= \frac{d}{dt}v^T\nabla^2f(\bar x+tv)v\Bigr|_{t=0} = v^TGv = -w^THw\\
&= -\frac{d}{dt}w^T\nabla^2f^\star(\bar y+tw)w\Bigr|_{t=0} = -h'''(0).
\end{aligned}
```

由此得

```math
|h'''(0)| \le 2h''(0)^{3/2},
```

对任意 $\bar y\in\text{dom}\,f^\star$ 与一切 $w$ 成立，故 $f^\star$ 是 self-concordant。

<span style="color:#1e8449;">**[译注]** 这条结论的真正用途是**让对偶问题的 barrier 免检**。举例：原始问题是二阶锥规划，其 barrier $-\log(y^2-x^Tx)$ 已证自洽（习题 9.15(a)），那么对偶问题的 barrier 不必重新验证三阶导——9.20 直接授权你把它搬过去。技术核心是 $h''(0)=g''(0)$ 与 $h'''(0)=-g'''(0)$ 这两条恒等式：前者说明两者的 Hessian 沿「对偶配对方向」$w=\nabla^2f(\bar x)v$ 完全一致（不是相似，而是数值相等），后者说明**三阶导符号翻转**——所以自洽判据 $|f'''|\le2f''^{3/2}$ 自动被继承。这个符号翻转的来源很干净：$\nabla^2f^\star\nabla^2f=I$，微分一次得 $H\nabla^2f+\nabla^2f^\star G=0$，即 $G=-\nabla^2fH\nabla^2f$，代入 $v^TGv=-w^THw$ 就得到。

**消失测试**：没有 9.20，每个对偶问题的复杂度分析都得从零做一遍三阶导验证；而这些验证在 §11 的对偶内点法里成对出现，工作量直接翻倍。更实际的是：设计新 barrier 时可以先在「自己熟悉的一侧」验证，再靠共轭搬到另一侧。

**落点**：Boyd §3.3（共轭函数的定义与 Fenchel 不等式）、习题 3.40（$\nabla f^\star=(\nabla f)^{-1}$）、§9.6.3；配套的 9.19(a) 保证 $\text{dom}\,f^\star$ 上的点总能对应到唯一原像。

**量的方向感**：$g'''(0)$ 与 $h'''(0)$ 严格反号、量值相等——误差为零而非「近似相等」，所以自洽常数 $2$ 在对偶侧一分不差。</span>

### Exercise 9.21 · 最优 line search 参数

> 话题摘要：把 Newton 迭代数上界 (9.56) 对 $\alpha,\beta$ 极小化，得到 $252$ 这个常数。

**Optimal line search parameters.** Consider the upper bound (9.56) on the number of Newton iterations required to minimize a strictly convex self-concordant functions. What is the minimum value of the upper bound, if we minimize over $\alpha$ and $\beta$?

**中文话题摘要**：上界里只有 $\alpha$ 与 $\beta$ 两个可调参数，前者出现在 $(20-8\alpha)/(\alpha(1-2\alpha)^2)$，后者以 $1/\beta$ 的形式单调参与。

**Solution.** 显然应取 $\beta$ 接近 $1$。

函数

```math
\frac{20-8\alpha}{\alpha(1-2\alpha)^2}
```

在 $\alpha=0.1748$ 处取到极小，极小值约为 $252$，故最低上界是

```math
252\bigl(f(x^{(0)})-p^\star\bigr) + \log_2\log_2(1/\epsilon).
```

<span style="color:#1e8449;">**[译注]** 这个 $252$ 是「理论最坏情形」与「实际观察」差得最远的一处，值得算清楚它从哪来。上界的形式是 $N\le\frac{20-8\alpha}{\alpha\beta(1-2\alpha)^2}\cdot\frac{f(x^{(0)})-p^\star}{\gamma}+\log_2\log_2(1/\epsilon)$，其中 $\gamma$ 是初点的 Newton decrement 平方、$\beta$ 是 backtracking 的收缩因子。$\beta$ 只以 $1/\beta$ 出现且单调递减，故取 $\beta\to1$（等价于 exact line search）；$\alpha$ 的驻点方程可由求导得到

```math
\frac{d}{d\alpha}\frac{20-8\alpha}{\alpha(1-2\alpha)^2}=0 \iff 32\alpha^2-120\alpha+20=0,
```

其小根为 $\alpha=(30-\sqrt{700})/16\approx0.1794$，代回得 $(20-8\alpha)/(\alpha(1-2\alpha)^2)\approx251.5$。原文给 $0.1748$ 与解析驻点 $0.1794$ 略差 $2.6\%$，但两者对应的函数值只差 $0.1$，都舍入成 $252$——所以**上界数值本身可信**，只有第四位有效数字可疑（列入小瑕疵表第 4 条）。实测量级是：一般问题从 $\lambda=1$ 起步、10 位精度，实测 $20\text{–}40$ 次迭代，理论与实测差 $6\text{–}12$ 倍，这就是「worst-case bound 只能用来定复杂度类，不能用来定超参数」的标准例子。

**消失测试**：没有这个极小化，你只能说「Newton 法 $O(\log\log(1/\epsilon))$ 步」而不知道常数；在只需要「是否 ≤ 100 步」的工程判断里，$252$ 与 $10^3$ 的差别会直接改变设计（例如是否值得为每步配一个稀疏求解器）。

**落点**：Boyd (9.56)（§9.6.4 的复杂度上界）、§9.5.2 的 backtracking 参数含义、图 9.6（$\alpha,\beta$ 对迭代数影响的数值实验）。

**量的方向感**：$\alpha$ 从 $0.1$ 挪到 $0.1794$，常数从 $330$ 降到 $251.5$（$-24\%$）；再挪到 $0.25$ 又涨到 $300$——最优点附近很平，取 $0.2$ 几乎无损。</span>

### Exercise 9.22 · 一般自洽常数的 Newton 步数

> 话题摘要：把 $|f'''|\le k f''^{3/2}$ 的 $k$-广义自洽函数按 $f\mapsto(k^2/4)f$ 归约到标准自洽情形。

Suppose that $f$ is strictly convex and satisfies (9.42). Give a bound on the number of Newton steps required to compute $p^\star$ within $\epsilon$, starting at $x^{(0)}$.

**中文话题摘要**：只要 $k$ 是常数，步数界与标准自洽情形只差目标值的缩放 $k^2/4$，$\log\log$ 项的形状完全不变。

**Solution.**

```math
\frac{(k^2/4)f(x^{(0)})-p^\star}{\gamma} + \log_2\log_2(4\epsilon/k^2)
```

其中 $\tilde f=(k^2/4)f$。换言之

```math
\frac{(k^2/4)\bigl(f(x^{(0)})-p^\star\bigr)}{\gamma} + \log_2\log_2(4\epsilon/k^2).
```

<span style="color:#1e8449;">**[译注]** 这题的关键是一个**缩放换算**，很容易写反。若 $f$ 满足 $|f'''|\le kf''^{3/2}$，取 $\tilde f=(k^2/4)f$，则

```math
|\tilde f'''| = \frac{k^2}{4}|f'''| \le \frac{k^3}{4}f''^{3/2},\qquad 2\tilde f''^{3/2}=2\Bigl(\frac{k^2}{4}\Bigr)^{3/2}f''^{3/2}=\frac{k^3}{4}f''^{3/2},
```

两边恰好相等——$\tilde f$ 是标准自洽的（常数 $2$）。于是把 9.21 的界套在 $\tilde f$ 上：步数 $\le252(\tilde f(x^{(0)})-\tilde p^\star)/\gamma+\log_2\log_2(1/\epsilon')$，其中 $\tilde p^\star=(k^2/4)p^\star$，这就是原文第一式的来源。精度换算要小心方向：要求 $\tilde f-\tilde p^\star\le\epsilon'$ 等价于 $f-p^\star\le4\epsilon'/k^2$；把 $\epsilon'=k^2\epsilon/4$ 代回即得 $4\epsilon/k^2$ 的倒数形式。$k$ 越小，需要的迭代越多（$\tilde f$ 更「平」），但只影响那个已经被 $\log\log$ 压平的项——$k=2$ 时 $\log_2\log_2(2/\epsilon)$ 与 $\log_2\log_2(1/\epsilon)$ 在 $\epsilon=10^{-10}$ 下只差 $0.1$ 步。

**消失测试**：没有这个归约，处理 $k$-广义自洽（例如 $-\log\det$ 在低秩扰动下的变体、或 logistic 的平滑版）就得重做整套两阶段分析；有了它，复杂度类直接继承，只需在目标值前面乘 $k^2/4$。

**落点**：Boyd §9.6.1 自洽定义与 (9.42) 的广义形式、§9.6.4 的 (9.56)；配套的 9.21 给出常数 $252$；(9.46) 的夹逼同样按 $k$/2 缩放。

**量的方向感**：$k=2$ 时主项系数从 $252$ 变成 $252\cdot k^2/4=252$——不变；精度项移位 $2$ 个 $\log\log$ 单位，实际迭代变化 $<1$ 步。</span>

### Exercise 9.23 · line search 的预计算

> 话题摘要：三族常见目标函数，只要把「与 $t$ 无关的中间量」预先算好，每次 line search 的 $g(t),g'(t)$ 都能从 $O(mn)$ 降到 $O(m)$。

**Pre-computation for line searches.** For each of the following functions, explain how the computational cost of a line search can be reduced by a pre-computation. Give the cost of the pre-computation, and the cost of evaluating $g(t)=f(x+t\Delta x)$ and $g'(t)$ with and without the pre-computation.

**(a)** $f(x)=-\sum_{i=1}^{m}\log(b_i-a_i^Tx)$.

**(b)** $f(x)=\log\Bigl(\sum_{i=1}^{m}\exp(a_i^Tx+b_i)\Bigr)$.

**(c)** $f(x)=(Ax-b)^T(P_0+x_1P_1+\cdots+x_nP_n)^{-1}(Ax-b)$, where $P_i\in S^m$, $A\in R^{m\times n}$, $b\in R^m$ and $\text{dom}\,f=\{x\mid P_0+\sum_{i=1}^{n}x_iP_i\succ0\}$.

**中文话题摘要**：log-barrier、log-sum-exp、以及带矩阵值变量的二次型——三者都能靠「预计算后只做 $m$ 次一维运算」把 line search 成本压到线性。

**Solution.**

**(a)** 不做预计算时成本是 $O(mn)$ 量级。可以把 $g$ 写成

```math
g(t) = -\sum_{i=1}^{m}\log(b_i-a_i^Tx) - \sum_{i=1}^{m}\log\bigl(1-t\,a_i^T\Delta x/(b_i-a_i^Tx)\bigr),
```

于是若预计算 $w_i=a_i^T\Delta x/(b_i-a_i^Tx)$，就能把 $g$ 写成

```math
g(t) = g(0) - \sum_{i=1}^{m}\log(1-tw_i),\qquad
g'(t) = \sum_{i=1}^{m}\frac{w_i}{1-tw_i}.
```

预计算的成本是 $2mn+m$（假定 $b-Ax$ 已经算好）。预计算之后，求值 $g$ 与 $g'$ 的成本对 $m$ 线性。

> `†` 原文把 $g'(t)$ 写成 $-\sum_i w_i/(1-tw_i)$，**符号错**。$g(t)=g(0)-\sum_i\log(1-tw_i)$ 求导得 $+\sum_i w_i/(1-tw_i)$；且 $g'(0)=\sum_iw_i=\langle\nabla f(x),\Delta x\rangle$，必须为负（$\Delta x$ 是 descent direction），原文的负号会给出相反的符号。详见文末「原文错误清单」第 2 条。

**(b)** 不做预计算时成本是 $O(mn)$ 量级。可以把 $g$ 写成

```math
g(t) = \log\Bigl(\sum_{i=1}^{m}\exp(a_i^Tx+b_i+t\,a_i^T\Delta x)\Bigr)
= \log\Bigl(\sum_{i=1}^{m}e^{t\alpha_i+\beta_i}\Bigr),
```

其中 $\alpha_i=a_i^T\Delta x$、$\beta_i=a_i^Tx+b_i$。若预计算 $\alpha_i$ 与 $\beta_i$（成本 $O(mn)$），就能把计算 $g$ 与 $g'$ 的成本降到 $O(m)$。

**(c)** 不做预计算时，成本是 $2mn$（算 $Ax-b$），加 $2nm^2$（算 $P(x)$），加 $(1/3)m^3$（算 $P(x)^{-1}(Ax-b)$），再加 $2m$ 做内积。总成本 $2nm^2+(1/3)m^3$。

以下预计算步骤可降低复杂度：

- 计算 Cholesky 分解 $P(x)=LL^T$。
- 计算特征分解 $L^{-1}\bigl(\sum_{i=1}^{n}\Delta x_iP_i\bigr)L^{-T}=Q\Lambda Q^T$。
- 计算 $y=Q^TL^{-1}Ax$，以及 $v=Q^TL^{-1}A\Delta x$。

预计算涉及 $O(m^3)$ 量级的步骤（Cholesky 分解、特征值分解）、$2nm^2$ 量级的步骤（计算 $P(x)$ 与 $\sum_i\Delta x_iP_i$），以及更低阶的项。

预计算之后可以把 $g$ 写成

```math
g(x+t\Delta x) = \sum_{i=1}^{m}\frac{(y_i+tv_i)^2}{1+t\lambda_i},
```

它可以用 $O(m)$ 次运算求值并求导。

<span style="color:#1e8449;">**[译注]** 三小题共用一条判据：**line search 里被反复求值的量，必须只依赖 $t$ 的低次多项式或分式**。(a) 的 $w_i$ 把 $mn$ 的内积一次性转成 $m$ 个标量；(b) 的 $\alpha_i,\beta_i$ 把 log-sum-exp 的 $m$ 次指数运算与 $n$ 维内积解耦；(c) 最漂亮——$P(x+t\Delta x)=P(x)+t\sum\Delta x_iP_i$，用 $L^{-T}$ 相似变换把 $P(x)$ 白化成 $I$，于是 $\sum\Delta x_iP_i$ 变成 $L^{-1}(\cdot)L^{-T}=Q\Lambda Q^T$ 可以直接对角化，于是矩阵求逆被替换成 $m$ 个标量分式 $(1+t\lambda_i)^{-1}$。这一步把「每试探一个 $t$ 就解一次 $m$ 维线性方程组」降成「每试探一个 $t$ 做 $m$ 次除法」，在 backtracking 平均 $10$ 次试探时收益是 $10$ 倍的 $(1/3)m^3$。

**消失测试**：没有预计算，一次 backtracking line search 的最坏成本是 $10\cdot O(m^3)$（(c) 情形），与一次 Newton 步同量级——等于把 Newton 法的 $O(1)$ 迭代优势吃掉，$m=500$ 时一次 line search 要多花 $10\cdot4\times10^7\approx4\times10^8$ flops。

**落点**：Boyd §9.5.2（backtracking 的算法框）、§11.4（(c) 这类结构化二次型的 Newton 步，与习题 9.27 的 (9.27.C) 同一技术）；实现侧见 CVXOPT 的 `solvers.conelp` 里对 $\lambda_i$ 的缓存。

**量的方向感**：$g$ 求值从 $2nm^2+(1/3)m^3$ 降到 $O(m)$；$n=100$、$m=100$ 时是 $2\times10^6+3.3\times10^5$ 对 $100$——四个数量级。</span>

### Exercise 9.24 · Hessian 块对角的意义

> 话题摘要：Hessian 块对角 $\iff$ 目标函数按变量分组可分离，于是「一个大 Newton 问题」退化成「若干独立小问题」。

**Exploiting block diagonal structure in the Newton system.** Suppose the Hessian $\nabla^2f(x)$ of a convex function $f$ is block diagonal. How do we exploit this structure when computing the Newton step? What does it mean about $f$?

**中文话题摘要**：块对角不是数值技巧，而是问题本身的解耦；发现它意味着模型写错了——本该分开求解。

**Solution.** 若 Hessian 块对角，则目标函数是**可分离的**（separable），即互不相交变量组上函数之和。这意味着不妨把各个子问题分别求解。

<span style="color:#1e8449;">**[译注]** 这题的答案只有两句话，但里面藏着一个判决性的成本事实：块对角 Hessian 的 Newton 系统可以按块并行求解，总成本是 $\sum_k(1/3)n_k^3$ 而不是 $(1/3)(\sum_k n_k)^3$。取 $10$ 块、每块 $100$ 维：分开算是 $10\cdot3.3\times10^5=3.3\times10^6$，合起来算是 $(1/3)(1000)^3=3.3\times10^8$——**差 100 倍**。更关键的是这句话的后半：「这意味着我们不妨分别求解」——块对角说明问题的**内在**结构就是解耦的，此时把它塞进一个大 Newton 系统不仅是慢，还会引入本不存在的耦合误差（例如稠密 Cholesky 的填充）。反过来说：如果你的 Hessian 在数值上「几乎块对角」（块间元素比块内小 $10^6$ 倍），可以考虑截断成块对角再解——这就是 domain decomposition 的代数版本。

**消失测试**：识别不出块对角，内点法在可分离问题（网络流、多商品流、多阶段随机规划）上会从 $O(\sum n_k^3)$ 退到 $O((\sum n_k)^3)$，且内存从 $\sum n_k^2$ 涨到 $(\sum n_k)^2$——$S$ 个 scenario 的随机规划正是这样从可算变成不可算（见习题 9.29）。

**落点**：Boyd §9.7（结构化 Newton 系统）、§11.7（可分离问题的分解）；与习题 9.29 的 block-arrow 是同一主题的两种拓扑（块对角 vs 块箭头）。

**量的方向感**：$10$ 块 $\times100$ 维：$3.3\times10^6$ vs $3.3\times10^8$ flops，$100$ 倍；内存 $6\times10^5$ vs $6\times10^7$ 个数。</span>

### Exercise 9.25 · 数据平滑拟合的 Hessian 结构

> 话题摘要：一维平滑拟合给出三对角 Hessian；二维（按列存储）给出块三对角、且次对角块是对角阵。

**Smoothed fit to given data.** Consider the problem

```math
\text{minimize}\quad f(x)=\sum_{i=1}^{n}\psi(x_i-y_i)+\lambda\sum_{i=1}^{n-1}(x_{i+1}-x_i)^2
```

where $\lambda\gt0$ is smoothing parameter, $\psi$ is a convex penalty function, and $x\in R^n$ is the variable. We can interpret $x$ as a smoothed fit to the vector $y$.

**(a)** What is the structure in the Hessian of $f$?

**(b)** Extend to the problem of making a smooth fit to two-dimensional data, i.e., minimizing the function

```math
\sum_{i,j=1}^{n}\psi(x_{ij}-y_{ij}) + \lambda\Bigl(\sum_{i=1}^{n-1}\sum_{j=1}^{n}(x_{i+1,j}-x_{ij})^2 + \sum_{i=1}^{n}\sum_{j=1}^{n-1}(x_{i,j+1}-x_{ij})^2\Bigr),
```

with variable $X\in R^{n\times n}$, where $Y\in R^{n\times n}$ and $\lambda\gt0$ are given.

**中文话题摘要**：一维差分算子 $D$ 让 $D^TD$ 成为三对角；二维把 $X$ 按列拉直后，两个方向的差分分别落到「对角块」与「次对角块」上。

**Solution.**

**(a)** 三对角（tridiagonal）。

**(b)** 若按列存储 $X$ 的元素，则是块三对角（block-tridiagonal）。块的大小为 $n\times n$。对角块是三对角的，第一个次对角上的块是对角阵。

<span style="color:#1e8449;">**[译注]** 把结构算清楚：$\lambda\sum(x_{i+1}-x_i)^2$ 的第二阶部分是 $\lambda D^TD$，其中 $D$ 是 $(n-1)\times n$ 的一阶差分矩阵，$D^TD$ 恰是 $\mathrm{tridiag}(-1,2,-1)$（端点处对角元为 $1$）——所以 (a) 的「三对角」不是观察，而是 $D^TD$ 的稀疏模式所致，与 $\psi$ 的具体形状无关（只要 $\psi$ 逐点作用，其贡献是对角阵 $\mathrm{diag}(\psi''(x_i-y_i))$）。二维情形按列拉直后，纵向差分（$i$ 方向）作用在**同一列内部**，落到 $n\times n$ 的每个对角块上（又是三对角）；横向差分（$j$ 方向）作用在**相邻列之间**，落到次对角块上，而由于它只把 $x_{i,j+1}$ 与 $x_{i,j}$ 相连、不碰 $i$，次对角块是 $-\lambda I$ 型的对角阵。于是总 Hessian 的 nnz 约为 $5n^2$，而稠密是 $n^4$——$n=100$ 时 $5\times10^4$ vs $10^8$。

**消失测试**：不知道次对角块是对角阵，就会用通用块三对角求解器（对 $n\times n$ 块做 LU），成本 $O(n\cdot n^3)=O(n^4)$；利用「块内三对角 + 次对角块对角」的结构，成本降到 $O(n^2)$（用二维 5 点 Laplacian 的 cyclic reduction 或直接稀疏 Cholesky）。

**落点**：Boyd §9.7 的结构化 Newton 系统、习题 9.24（块对角）、§C.2（稀疏矩阵的带宽与填充）；一维情形对应经典 Whittaker–Henderson smoother，见 Eilers 2003 *A perfect smoother*（A 一手：给出 $D^TD$ 与稀疏 Cholesky 的显式关系）。

**量的方向感**：$n=100$ 时 nnz 从 $10^8$ 降到 $5\times10^4$（$2000$ 倍），求解从 $O(n^4)=10^8$ 降到 $O(n^2)=10^4$ flops 量级。</span>

### Exercise 9.26 · 线性结构的 Newton 方程

> 话题摘要：$H=\sum_iA_i^TH_iA_i$ 是「矮宽矩阵夹心」之和，当 $n\gg m_i$ 且 $A_i$ 稀疏而 $H$ 稠密时，改解一个更大的**不定**系统反而更快。

**Newton equations with linear structure.** Consider the problem of minimizing a function of the form

```math
f(x) = \sum_{i=1}^{N}\psi_i(A_ix+b_i)
```

where $A_i\in R^{m_i\times n}$, $b_i\in R^{m_i}$, and the functions $\psi_i:R^{m_i}\to R$ are twice differentiable and convex. The Hessian $H$ and gradient $g$ of $f$ at $x$ are given by

```math
H = \sum_{i=1}^{N}A_i^TH_iA_i,\qquad g=\sum_{i=1}^{N}A_i^Tg_i,
```

where $H_i=\nabla^2\psi_i(A_ix+b_i)$ and $g_i=\nabla\psi_i(A_ix+b_i)$.

Describe how you would implement Newton's method for minimizing $f$. Assume that $n\gg m_i$, the matrices $A_i$ are very sparse, but the Hessian $H$ is dense.

**中文话题摘要**：把「稠密 $n\times n$ 系统」换成「稀疏 $(\sum m_i+n)$ 维不定系统」，用小 $m_i$ 的块结构换取稀疏性。

**Solution.** 在许多应用里（例如 $n$ 相对于各维 $m_i$ 较小时），计算 Newton direction 最简、最高效的做法就是用 (9.64) 算出 $H$ 与 $g$，再用稠密 Cholesky 分解解 Newton 系统。

然而也可能出现这样的情况：$A_i$ 非常稀疏、而 $H$ 本身稠密。此时那个直接的做法（解稠密的 $n$ 维线性方程组）可能并不是最高效的，因为它没有利用稀疏性。具体地说，假设 $n\gg m_i$、$\mathrm{rank}\,A_i=m_i$、$H_i\succ0$，于是 Hessian 是 $N$ 个秩为 $m_i$ 的矩阵之和。引入新变量 $y_i=H_iA_iv$，就可以把 Newton 系统写成

```math
\sum_{i=1}^{N}A_i^Ty_i = -g,\qquad y_i = H_iA_iv,\quad i=1,\dots,N.
```

这是一个含 $n+\sum_i m_i$ 个变量、$n+\sum_i m_i$ 个方程的**不定**系统：

```math
\begin{bmatrix}
-H_1^{-1} & 0 & \cdots & 0 & A_1\\
0 & -H_2^{-1} & \cdots & 0 & A_2\\
\vdots & \vdots & \ddots & \vdots & \vdots\\
0 & 0 & \cdots & -H_N^{-1} & A_N\\
A_1^T & A_2^T & \cdots & A_N^T & 0
\end{bmatrix}
\begin{bmatrix}
y_1\\ y_2\\ \vdots\\ y_N\\ v
\end{bmatrix}
=
\begin{bmatrix}
0\\ 0\\ \vdots\\ 0\\ -g
\end{bmatrix}.
```

这个系统比 Newton 系统大，但若 $n\gg m_i$ 且 $A_i$ 稀疏，用稀疏求解器解它可能比直接解 Newton 系统更容易。

> `†` 原文把 $y_i$ 定义为 $H_iA_i^Tv$，**转置错**：$A_i\in R^{m_i\times n}$、$v\in R^n$，故 $A_i^Tv$ 是 $(n\times m_i)\cdot(n\times1)$，形状不合法。按上式矩阵第一块行 $-H_i^{-1}y_i+A_iv=0$ 解得 $y_i=H_iA_iv$。详见文末「原文错误清单」第 3 条。

<span style="color:#1e8449;">**[译注]** 这是**Schur 补的逆向使用**，值得和 9.27、9.28 放在一起看。正方向是「消掉 $y$ 得到 $H=\sum A_i^TH_iA_i$」，成本 $O(n^3)$；反方向是「保留 $y$、把 $H_i^{-1}$ 放主对角」，得到不定系统，但它的矩阵**保留了 $A_i$ 的稀疏性**。判据很干脆：如果 $A_i$ 每行只有 $s$ 个非零、$m_i=m\ll n$，则原系统非零元 $O(n^2)$、稀疏求解 $O(n^3)$（填充不可避免）；新系统非零元 $O(Nm s+n)$、在 $A_i$ 是「窄带或树型」时填充极少，$N$ 大时可低到近线性。代价是系统不定：不能用 Cholesky，要用 $LDL^T$ 或 KKT 直接法，且数值上要 pivot——所以这是一次「用稳定性换稀疏性」的交易。

**消失测试**：不做这个转换，$n=10^5$、$N=10^3$、$m_i=10$ 的问题需要 $(1/3)n^3\approx3\times10^{14}$ flops 与 $8\times10^{10}$ bytes（$n^2$ 双精度）——内存就先爆掉；转成稀疏不定系统后，非零元约 $10^7$ 量级，单机可算。

**落点**：Boyd §9.7（结构化的 Newton 系统，含 (9.26.A) 这类 KKT 形式）、§C.4（Schur 补与分块消元）、§11.8（稀疏 KKT 的直接法）；实现侧对应 `scipy.sparse.linalg.spsolve` 的 `permc_spec` 与 SuiteSparse 的 `UMFPACK`。

**量的方向感**：$n=10^5$ 时从 $O(n^3)=10^{15}$ 降到 $O(\mathrm{nnz})$ 的近线性；内存从 $n^2=10^{10}$ 个数降到 $\mathrm{nnz}\approx10^7$，三个数量级。</span>

### Exercise 9.27 · 变量有界线性不等式的 analytic center

> 话题摘要：$H=D+A^T\hat DA$ 是「对角 + 矮宽夹心」，三种解法按 $m$ 与 $n$ 的大小切换；$m\lt n$ 时用 Schur 补把系统降到 $m$ 维。

**Analytic center of linear inequalities with variable bounds.** Give the most efficient method for computing the Newton step of the function

```math
f(x) = -\sum_{i=1}^{n}\log(x_i+1) - \sum_{i=1}^{n}\log(1-x_i) - \sum_{i=1}^{m}\log(b_i-a_i^Tx),
```

with $\text{dom}\,f=\{x\in R^n\mid -1\prec x\prec1,\ Ax\prec b\}$, where $a_i^T$ is the $i$th row of $A$. Assume $A$ is dense, and distinguish two cases: $m\ge n$ and $m\le n$. (See also exercise 9.30.)

**中文话题摘要**：可用 Cholesky 直接解 $n$ 维、也可用 Schur 补降到 $m$ 维、还可解 $m+n$ 维不定系统；选择的唯一依据是 $m,n$ 谁大以及 $A$ 是否稀疏。

**Solution.** 注意 $f$ 有 (9.60) 的形式，其中 $k=n$、$p=m$、$g=b$、$F=-A$，且

```math
\psi_0(y) = -\sum_{i=1}^{m}\log y_i,\qquad \psi_i(x_i) = -\log(1-x_i^2),\quad i=1,\dots,n .
```

$f$ 在 $x$ 处的 Hessian 由下式给出

```math
H = D + A^T\hat DA
```

其中 $D_{ii}=1/(1-x_i)^2+1/(x_i+1)^2$，$\hat D_{ii}=1/(b_i-a_i^Tx)^2$。

第一种做法是按上式组装出 $H$，再用稠密 Cholesky 分解解 Newton 系统。成本是 $mn^2$ 次运算（组装 $A^T\hat DA$）加 $(1/3)n^3$（Cholesky 分解）。

第二种做法是引入新变量 $y=\hat DA\,v$，把 Newton 系统写成

```math
D\Delta x_{nt} + A^Ty = -g,\qquad \hat D^{-1}y = A\Delta x_{nt}.
```

由第一式得 $\Delta x_{nt}=D^{-1}(-g-A^Ty)$，代入第二式得

```math
(\hat D^{-1}+AD^{-1}A^T)y = -AD^{-1}g.
```

这是一个含 $m$ 个变量 $y\in R^m$ 的正定线性方程组。已知 $y$ 后，用 $\Delta x_{nt}=-D^{-1}(g+A^Ty)$ 即得 Newton step。组装并求解该方程组的成本是 $mn^2+(1/3)m^3$ 次运算（假定 $A$ 稠密）。因此在 $m\lt n$ 时，第二种方法比直接解 Newton 系统 $H\Delta x_{nt}=-g$ 更快。

第三种做法是把 Newton 系统当作含 $m+n$ 个方程的不定系统来解

```math
\begin{bmatrix} D & A^T\\ A & -\hat D^{-1}\end{bmatrix}
\begin{bmatrix} \Delta x_{nt}\\ y\end{bmatrix}
=
\begin{bmatrix} -g\\ 0\end{bmatrix}.
```

当 $A$ 稀疏、而 $D+A^T\hat DA$ 与 $\hat D^{-1}+AD^{-1}A^T$ 都不稀疏时，这个方法才有意思：此时用稀疏求解器解上面这个不定系统可能比前两种方法更快。

<span style="color:#1e8449;">**[译注]** 三种做法是同一件事的三个消元顺序，成本表可以直接背下来：**解 $n$ 维** $mn^2+\frac13n^3$、**解 $m$ 维** $mn^2+\frac13m^3$、**解 $m+n$ 维不定** 视稀疏度而定。分岔点很清楚：$m\lt n/2$ 附近第二法开始明显占优，因为 $\frac13m^3$ 项被压掉而 $mn^2$ 项（组装 $AD^{-1}A^T$）两者相同。取 $n=1000$、$m=100$：第一法 $\frac13\cdot10^9\approx3.3\times10^8$ flops，第二法 $\frac13\cdot10^6\approx3.3\times10^5$——差 $1000$ 倍。反过来 $m=10^4\gt n$ 时第一法胜。第三种做法的价值不在 flops 而在**填充**：$A$ 稀疏（例如每行只有 $s=5$ 个非零）、$n=m=10^5$ 时，$H$ 与 $\hat D^{-1}+AD^{-1}A^T$ 都会被填充成稠密，而那个 $2\times2$ 块矩阵保持 $O(ns)$ 非零元——这正是内点法在稀疏问题上能做到「每步近线性」的机制。

**消失测试**：只会第一种做法时，$m\ll n$ 的场合（例如 $10^4$ 个观测、$10^6$ 个变量）在 $n$ 维稠密 Cholesky 上直接卡死（$n^2$ 内存就 $8\times10^{12}$ bytes）；只会第二种做法时，$m\gg n$ 的场合反过来卡死。**没有「按 $m,n$ 切换」这条判据，就没有可在实践中运行的通用内点法。**

**落点**：Boyd (9.60)（结构化 barrier 的一般形式）、§11.4（$A^T\hat DA$ 型结构）、(9.27.A)–(9.27.D) 四条编号；(9.27.C) 就是熟知的 Schur 补降维，与习题 9.28 的 (9.28.A) 同构。

**量的方向感**：$n=1000,m=100$：$3.3\times10^8$ vs $3.3\times10^5$ flops，$1000$ 倍；$n=m=10^5$、$s=5$ 时第三种解法的非零元 $5\times10^5$ 对稠密的 $10^{10}$，四个数量级以上。</span>

### Exercise 9.28 · 二次不等式的 analytic center

> 话题摘要：$H=Q+FF^T$ 是「稀疏 $Q$ + 低秩修正」，$m\ll n$ 时用 Woodbury 把 $n$ 维系统降成 $m$ 维。

**Analytic center of quadratic inequalities.** Describe an efficient method for computing the Newton step of the function

```math
f(x) = -\sum_{i=1}^{m}\log(-x^TA_ix-b_i^Tx-c_i),
```

with $\text{dom}\,f=\{x\mid x^TA_ix+b_i^Tx+c_i\lt0,\ i=1,\dots,m\}$. Assume that the matrices $A_i\in S^n_{++}$ are large and sparse, and $m\ll n$.

*Hint.* The Hessian and gradient of $f$ at $x$ are given by

```math
H = \sum_{i=1}^{m}\bigl(2\alpha_iA_i+\alpha_i^2(2A_ix+b_i)(2A_ix+b_i)^T\bigr),\qquad
g=\sum_{i=1}^{m}\alpha_i(2A_ix+b_i),
```

where $\alpha_i=1/(-x^TA_ix-b_i^Tx-c_i)$.

**中文话题摘要**：Hessian 是「$m$ 个稀疏矩阵的加权和」加「$m$ 个秩一修正」，而秩一修正是稠密的唯一来源——把它提出来做 Woodbury，$n$ 维求解变 $m$ 维。

**Solution.** 可以把 $H$ 写成 $H=Q+FF^T$，其中

```math
Q=2\sum_{i=1}^{m}\alpha_iA_i,\qquad
F=\begin{bmatrix}\alpha_1(2A_1x+b_1) & \alpha_2(2A_2x+b_2) & \cdots & \alpha_m(2A_mx+b_m)\end{bmatrix}.
```

一般说来，即使 $A_i$ 稀疏，Hessian 也会是稠密的，原因正是那些稠密的秩一项。因此用「组装并求解 Newton 系统 $Hv=-g$」来求 Newton direction 至少要 $(1/3)n^3$ 次运算，因为需要稠密 Cholesky 分解。

$n\gg m$ 时，下面这个替代做法可能更快。引入新变量 $y\in R^m$，把 Newton 系统写成

```math
Qv+Fy=-g,\qquad y=F^Tv.
```

把 $v=-Q^{-1}(g+Fy)$ 代入第二式得

```math
(I+F^TQ^{-1}F)y=-F^TQ^{-1}g,
```

这是一个含 $m$ 个线性方程的系统。

因此 Newton direction 也可以这样算：先用稀疏 Cholesky 分解因子化 $Q$；再逐列解矩阵方程 $QV=F$ 得到 $V=Q^{-1}F$，每列都用 $Q$ 的 Cholesky 因子做一次稀疏前代与回代；然后组装 $I+F^TV$（$m^2n$ flops），用稠密 Cholesky 因子化它（$(1/3)m^3$ flops），解出 $y$；最后解 $Qv=-g-Fy$ 得到 $v$。整个过程成本是 $(1/3)m^3+m^2n$ 次运算加固 $Q$ 的稀疏 Cholesky 分解与 $m$ 次稀疏前代回代。若 $n\gg m$ 且 $Q$ 稀疏，总成本可以远低于用稠密方法解 $Hv=-g$。

<span style="color:#1e8449;">**[译注]** 这是 Woodbury 恒等式的直接应用，把「$n$ 维、稠密」换成「$m$ 维、稠密 + $m$ 次稀疏解」。判据是 $m\ll n$ 且 $Q$ 稀疏——两者缺一不可：若 $Q$ 稠密，$m$ 次稀疏解会退化成 $m$ 次 $O(n^3)$，反而更慢。取 $n=10^4$、$m=50$、$Q$ 带宽 $10$：第一法 $(1/3)n^3\approx3.3\times10^{11}$ flops；第二法 $(1/3)m^3+m^2n\approx4\times10^4+2.5\times10^7$，加上 $50$ 次带宽 $10$ 的带状解各 $O(nb^2)=10^6$，合计约 $7.5\times10^7$——**四个数量级**。注意原文一处笔误：正文说「解 Newton 系统 $Hv=g$」，应为 $Hv=-g$（Newton 系统的右端是负梯度），列入小瑕疵表第 5 条。

**消失测试**：不做 Woodbury，$n=10^4$ 的二次约束 analytic center 在单机上不可算（$3\times10^{11}$ flops 每步 + $n^2=10^8$ 个数 = 800 MB 内存）；做了之后每步只有 $m^2n=2.5\times10^7$ flops，且内存主要是 $Q$ 的稀疏因子。

**落点**：Boyd (9.60)（结构化 barrier）、§C.4.3（matrix inversion lemma / Woodbury）、习题 9.27 的两条路径对比；(9.28.A) 与 (9.27.C) 同构，只是把 $D$ 换成稀疏的 $Q$。

**量的方向感**：$n=10^4,m=50$：$3.3\times10^{11}$ vs $7.5\times10^7$ flops，约 $4400$ 倍；$m$ 增长到 $500$ 时第二法退化为 $(1/3)m^3=4\times10^7$（仍占优），$m=5000$ 时 $(1/3)m^3\approx4\times10^{10}$ 反超——交叉点在 $m\approx n^{3/5}\cdot$ 常数附近。</span>

### Exercise 9.29 · 两阶段优化中的结构利用

> 话题摘要：$S$ 个 scenario 的 recourse 问题给出 block-arrow Hessian；消掉 $Sq$ 维右下块后，复杂度从 $S^3$ 变成 $S$ 的线性。

**Exploiting structure in two-stage optimization.** This exercise continues exercise 4.64, which describes optimization with recourse, or two-stage optimization. Using the notation and assumptions in exercise 4.64, we assume in addition that the cost function $f$ is a twice differentiable function of $(x,z)$, for each scenario $i=1,\dots,S$.

Explain how to efficiently compute the Newton step for the problem of finding the optimal policy. How does the approximate flop count for your method compare to that of a generic method (which exploits no structure), as a function of $S$, the number of scenarios?

**中文话题摘要**：两阶段（recourse）问题的 Hessian 是「$x$ 与各 scenario 的 $z_i$ 交叉、$z_i$ 之间无耦合」的块箭头；消元把 $S^3$ 变成「每加一个 scenario 只多 $O(n^2q)$」。

**Solution.** 要解的问题就是

```math
\text{minimize}\quad F(x)=\sum_{i=1}^{S}\pi_i f(x,z_i,i),
```

它 convex，因为对每个 $i$，$f(x,z_i,i)$ 在 $(x,z_i)$ 上 convex，且 $\pi_i\ge0$。

现在看如何高效计算 Newton step。$F$ 的 Hessian 具有 block-arrow（块箭头）形式

```math
\nabla^2F =
\begin{bmatrix}
\nabla^2_{x,x}F & \nabla^2_{x,z_1}F & \nabla^2_{x,z_2}F & \cdots & \nabla^2_{x,z_S}F\\
\nabla^2_{z_1,x}F & \nabla^2_{z_1,z_1}F & 0 & \cdots & 0\\
\nabla^2_{z_2,x}F & 0 & \nabla^2_{z_2,z_2}F & \cdots & 0\\
\vdots & \vdots & \vdots & \ddots & \vdots\\
\nabla^2_{z_S,x}F & 0 & 0 & \cdots & \nabla^2_{z_S,z_S}F
\end{bmatrix},
```

我们可以利用它高效地算出 Newton step。先看**不**利用这个结构会怎样：需要解 $n+Sq$ 个（对称正定）线性方程 $\nabla^2F\,\Delta_{nt}=-\nabla F$，成本约为 $(1/3)(n+Sq)^3$ flops。作为 scenario 数的函数，这是按 $S^3$ 增长的。

现在利用结构来算 $\Delta_{nt}$。做法是消元，消掉右下那个 $Sq\times Sq$ 的块。该块是块对角的，含 $S$ 个 $q\times q$ 的块，这一情形在教材第 677 页有描述。总体复杂度是

```math
(2/3)Sq^3 + 2nSq^2 + 2n^2Sq + 2n^2Sq + (2/3)n^3
= \Bigl(\frac{2}{3}q^3 + 2nq^2 + 4n^2q\Bigr)S + \frac{2}{3}n^3,
```

它按 $S$ 线性增长。

下面是利用结构解对称正定 block-arrow 方程组的显式细节：

```math
\begin{bmatrix}
A_{11} & A_{12} & A_{13} & \cdots & A_{1N}\\
A_{12}^T & A_{22} & 0 & \cdots & 0\\
A_{13}^T & 0 & A_{33} & \cdots & 0\\
\vdots & \vdots & \vdots & \ddots & \vdots\\
A_{1N}^T & 0 & 0 & \cdots & A_{NN}
\end{bmatrix}
\begin{bmatrix} x_1\\ x_2\\ \vdots\\ x_N\end{bmatrix}
=
\begin{bmatrix} b_1\\ b_2\\ \vdots\\ b_N\end{bmatrix}.
```

<!-- ===== p257 ===== -->

我们消去 $x_j$（$j=2,\dots,N$），得

```math
x_j = A_{jj}^{-1}(b_j-A_{1j}^Tx_1),\qquad j=2,\dots,N.
```

第一个块方程变为

```math
\Bigl(A_{11}-\sum_{j=2}^{N}A_{1j}A_{jj}^{-1}A_{1j}^T\Bigr)x_1 = b_1-\sum_{j=2}^{N}A_{1j}A_{jj}^{-1}b_j .
```

解这个方程得到 $x_1$，再用上面的式子求 $x_2,\dots,x_N$。具体做法：先做 $A_{22},\dots,A_{NN}$ 的 Cholesky 分解；再用回代算出 $A_{22}^{-1}A_{12}^T,\dots,A_{NN}^{-1}A_{1N}^T$ 与 $A_{22}^{-1}b_2,\dots,A_{NN}^{-1}b_N$；然后组装上面方程的右端与左端矩阵（即 Schur complement）；最后用 Cholesky 分解加回代求解。

<span style="color:#1e8449;">**[译注]** 这条结果是「两阶段随机规划可算」的全部理由。代价对比要按 $S$ 看：通用法 $(1/3)(n+Sq)^3$ 展开后含 $O(S^3q^3)$ 项，$S=1000$ 时就是 $10^9$ 量级的 $q^3$；块箭头法每加一个 scenario 只多 $O(n^2q)$（造 Schur 补的一块）与 $O(q^3)$（该块 Cholesky），于是 $S$ 从 $10$ 涨到 $1000$ 时成本线性涨 $100$ 倍，而通用法涨 $10^6$ 倍。取 $n=50$、$q=10$、$S=1000$：通用法 $(1/3)(50+10^4)^3\approx3.3\times10^{11}$；块箭头法 $\bigl(\frac23\cdot10^3+2\cdot50\cdot100+4\cdot2500\cdot10\bigr)\cdot1000+\frac23\cdot1.25\times10^5\approx(667+10^4+10^5)\cdot1000\approx1.1\times10^8$——**3000 倍**。工程含义很直接：Monte-Carlo scenario 数是为了降低方差、通常取 $10^3\sim10^4$，只有线性复杂度的方法才撑得住。

**消失测试**：不做块箭头消元，两阶段问题在 $S\gt100$ 时就无法在单机求解；这正是 1990 年代随机规划从「只做 $S\le20$ 的教学算例」走向「真实电力/金融问题」的技术转折点。

**落点**：Boyd §9.7（稀疏 Newton 系统）、§C.4（Schur 补）、教材第 677 页的 block-arrow 讨论；习题 4.64 是题面前置；对应的分解在实现上是「stage-wise decomposition」，见 Birge & Louveaux *Introduction to Stochastic Programming*（B 二手）。

**量的方向感**：$S$ 的指数从 $3$ 降到 $1$；$S=1000$ 时成本比 $1000^2=10^6$ 缩小到 $3\times10^3$ 量级（因 $n,q$ 的相对大小而变化）。</span>

### Exercise 9.30 · gradient method 与 Newton method 的实测对比

> 话题摘要：在一个 $m=200,n=100$ 的 analytic center 算例上，gradient 法要数百步、Newton 法只要 6 步；两段 Matlab 代码给出可复现的实现。

**Gradient and Newton methods.** Consider the unconstrained problem

```math
\text{minimize}\quad f(x)=-\sum_{i=1}^{m}\log(1-a_i^Tx)-\sum_{i=1}^{n}\log(1-x_i^2),
```

with variable $x\in R^n$, and $\text{dom}\,f=\{x\mid a_i^Tx\lt1,\ i=1,\dots,m,\ |x_i|\lt1,\ i=1,\dots,n\}$. This is the problem of computing the analytic center of the set of linear inequalities

```math
a_i^Tx\le1,\quad i=1,\dots,m,\qquad |x_i|\le1,\quad i=1,\dots,n .
```

Note that we can choose $x^{(0)}=0$ as our initial point. You can generate instances of this problem by choosing $a_i$ from some distribution on $R^n$.

**(a)** Use the gradient method to solve the problem, using reasonable choices for the backtracking parameters, and a stopping criterion of the form $\|\nabla f(x)\|_2\le\eta$. Plot the objective function and step length versus iteration number. (Once you have determined $p^\star$ to high accuracy, you can also plot $f-p^\star$ versus iteration.) Experiment with the backtracking parameters $\alpha$ and $\beta$ to see their effect on the total number of iterations required. Carry these experiments out for several instances of the problem, of different sizes.

**(b)** Repeat using Newton's method, with stopping criterion based on the Newton decrement $\lambda^2$. Look for quadratic convergence. You do not have to use an efficient method to compute the Newton step, as in exercise 9.27; you can use a general purpose dense solver, although it is better to use one that is based on a Cholesky factorization.

*Hint.* Use the chain rule to find expressions for $\nabla f(x)$ and $\nabla^2f(x)$.

**中文话题摘要**：这是全书唯一一处把两种方法放在同一算例上做「同尺度」对比的习题；结论是 Newton 的步数与问题规模几乎无关。

**Solution.**

**(a) Gradient method.** 下图给出 $m=200$、$n=100$ 的一个算例中，函数值与步长随迭代数的变化。我们取 $\alpha=0.01$、$\beta=0.5$，退出条件是 $\|\nabla f(x^{(k)})\|_2\le10^{-3}$。

[Figure 1：左图为 $f(x^{(k)})-p^\star$ 随 $k$ 的对数图（纵轴 $10^{4}$ 到 $10^{-8}$，横轴 $0$–$500$），右图为步长 $t^{(k)}$ 随 $k$（纵轴 $0$–$0.016$，横轴 $0$–$600$）；两者均单调下降]

下面是 Matlab 实现。

```
ALPHA = 0.01;
BETA = 0.5;
MAXITERS = 1000;
GRADTOL = 1e-3;

x = zeros(n,1);
for iter = 1:MAXITERS
   val = -sum(log(1-A*x)) - sum(log(1+x)) - sum(log(1-x));
   grad =  A'*(1./(1-A*x)) - 1./(1+x) + 1./(1-x);
   if norm(grad) < GRADTOL, break; end;
```

<!-- ===== p258 ===== -->

```
   v = -grad;
   fprime = grad'*v;
   t = 1;  while ((max(A*(x+t*v)) >= 1) | (max(abs(x+t*v)) >= 1)),
      t = BETA*t;
   end;
   while ( -sum(log(1-A*(x+t*v))) - sum(log(1-(x+t*v).^2)) >  ...
           val + ALPHA*t*fprime )
      t = BETA*t;
   end;
   x = x+t*v;
end;
```

**(b) Newton method.** 下图给出同一算例中函数值与步长随迭代数的变化。我们取 $\alpha=0.01$、$\beta=0.5$，退出条件是 $\lambda(x^{(k)})^2\le10^{-8}$。

[Figure 2：左图为 $f(x^{(k)})-p^\star$ 的对数图（纵轴 $10^{5}$ 到 $10^{-10}$，横轴 $0$–$7$），右图为 $t^{(k)}$（纵轴 $0$–$1$，横轴 $0$–$8$）；$k\approx5$ 之后曲线坠到底部，呈典型二次收敛的「悬崖」]

下面是 Matlab 实现。

```
ALPHA = 0.01;
BETA = 0.5;
MAXITERS = 1000;
NTTOL  = 1e-8;

x = zeros(n,1);
for iter = 1:MAXITERS
   val = -sum(log(1-A*x)) - sum(log(1+x)) - sum(log(1-x));
   d = 1./(1-A*x);
   grad =  A'*d - 1./(1+x) + 1./(1-x);
   hess =  A'*diag(d.^2)*A + diag(1./(1+x).^2 + 1./(1-x).^2);
   v = -hess\grad;
   fprime = grad'*v;
   if abs(fprime) < NTTOL, break; end;
   t = 1;  while ((max(A*(x+t*v)) >= 1) | (max(abs(x+t*v)) >= 1)),
      t = BETA*t;
   end;
   while ( -sum(log(1-A*(x+t*v))) - sum(log(1-(x+t*v).^2)) >  ...
           val + ALPHA*t*fprime )
      t = BETA*t;
   end;
   x = x+t*v;
end;
```

<span style="color:#1e8449;">**[译注]** 两张图放在一起看才有意义：横轴量程差 $70$ 倍（$500$ vs $7$），纵轴都能从 $10^{4}$ 掉到 $10^{-8}$。这就是「Newton 法的迭代数与问题规模无关」的直接证据——把 $n$ 从 $100$ 加到 $1000$，Newton 仍然 $6\text{–}8$ 步，而 gradient 法会按条件数线性变慢。代码里有两处值得盯：其一，`1./(1+x) - 1./(1-x)` 把 $-\sum\log(1-x_i^2)$ 的梯度 $-\frac{2x_i}{1-x_i^2}$ 写成了两个分式之差，避免除零且数值更稳；其二，`while ((max(A*(x+t*v)) >= 1) | (max(abs(x+t*v)) >= 1))` 是**可行性**回溯，先保证 $x+tv$ 落在 $\text{dom}\,f$ 内、再进 Armijo 条件——顺序不能反，否则第一次求 `val` 就对负数取 log 得 `NaN`，而 `NaN > ...` 恒假，Armijo 循环会被静默跳过。

**消失测试**：如果只在 $n=50$ 上跑，两种方法的迭代数差别（约 $30$ 倍）看起来还可以接受；不解剖这个对比，就不会意识到 $n$ 增大时 gradient 法的迭代数会按 $\sqrt{\kappa}$ 增长，而 Newton 的 $O(n^3)$ 单步成本换来的是**恒定**步数——这是所有内点法都必须用 Newton 的根本原因。

**落点**：Boyd §9.3（gradient method 与 backtracking）、§9.5（Newton method）、图 9.1 与图 9.5 是同组实验；习题 9.31 直接在本算例上做「近似 Hessian」的变体。

**量的方向感**：$500$ 步 vs $6$ 步（约 $83$ 倍）；而单步成本 Newton 是 $(1/3)n^3\approx3.3\times10^5$、gradient 是 $O(mn)=2\times10^4$——总成本 $1.2\times10^6$ vs $10^7$，Newton 仍然快近 $10$ 倍。</span>

### Exercise 9.31 · 两种近似 Newton 方法

> 话题摘要：省掉 Hessian 的重算（每 $N$ 步一次）会迅速退化；把它换成对角近似，则几乎退化成 gradient 法。

**Some approximate Newton methods.** The cost of Newton's method is dominated by the cost of evaluating the Hessian $\nabla^2f(x)$ and the cost of solving the Newton system. For large problems, it is sometimes useful to replace the Hessian by a positive definite approximation that makes it easier to form and solve for the search step. In this problem we explore some common examples of this idea.

For each of the approximate Newton methods described below, test the method on some instances of the analytic centering problem described in exercise 9.30, and compare the results to those obtained using the Newton method and gradient method.

**(a) Re-using the Hessian.** We evaluate and factor the Hessian only every $N$ iterations, where $N\gt1$, and use the search step $\Delta x=-H^{-1}\nabla f(x)$, where $H$ is the last Hessian evaluated. (We need to evaluate and factor the Hessian once every $N$ steps; for the other steps, we compute the search direction using back and forward substitution.)

**(b) Diagonal approximation.** We replace the Hessian by its diagonal, so we only have to evaluate the $n$ second derivatives $\partial^2f(x)/\partial x_i^2$, and computing the search step is very easy.

**中文话题摘要**：两个变体各砍掉一半成本——(a) 砍因子化频率、(b) 砍 Hessian 的非对角元；实测显示 (a) 的 $N$ 增大会迅速毁掉收敛速度，(b) 则退化成 gradient 法。

**Solution.**

**(a)** 下图给出函数值随迭代数的变化（与习题 9.30 的解中同一个算例），分别对应 $N=1$（即 Newton 法）、$N=2$、$N=5$。

<span style="color:#1e8449;">**[译注]** 这两个变体的失败方式**不同**，值得分开记。(a) 保持方向质量、只降低因子化频率，$N=2$ 时迭代数几乎不变而成本减半——这是 quasi-Newton（BFGS 类）的动机；$N=5$ 时旧 Hessian 与当前曲率失配，方向仍下降但不再是「Newton 方向」，二次收敛退化为线性，图中 $N=5$ 的曲线斜率与 gradient 已经很接近。关键判据是 $\|H_{\text{old}}-H_{\text{now}}\|/\|H_{\text{now}}\|$ 与 $\lambda$ 同阶时失效。(b) 更彻底：丢掉非对角元等于丢掉 $A^T\mathrm{diag}(d^2)A$ 这一整个秩-$m$ 结构，剩下的只有 $-\log(1-x_i^2)$ 的对角贡献——方向变成各坐标独立缩放的最速下降，而该问题的条件数由 $A$ 的最小奇异值决定，可能到 $10^4$，于是迭代数 $\sim\sqrt{\kappa}=100$，图中 $800$ 步与之吻合。教训：**Hessian 的信息主要在非对角元上**，对角近似只在变量几乎可分离时才有效（那正是习题 9.24 的块对角情形）。

**落点**：Boyd §9.5（Newton 的变体）、§9.7（结构化 Newton 系统）、§10.4（拟 Newton 与 BFGS）；(b) 的对角缩放本质是 Jacobi 预条件，见 §C.6 的预条件讨论。

### Exercise 9.32 · 凸非线性最小二乘的 Gauss-Newton 法

> 话题摘要：把 Hessian 里的 $f_i\nabla^2f_i$ 丢掉就得到 Gauss-Newton 方向；它在 $f_i$ 接近线性或接近零时才好，构造出的反例则收敛得很慢。

**Gauss-Newton method for convex nonlinear least-squares problems.** We consider a (nonlinear) least-squares problem, in which we minimize a function of the form

```math
f(x) = \frac12\sum_{i=1}^{m}f_i(x)^2,
```

where $f_i$ are twice differentiable functions. The gradient and Hessian of $f$ at $x$ are given by

```math
\nabla f(x) = \sum_{i=1}^{m}f_i(x)\nabla f_i(x),\qquad
\nabla^2f(x) = \sum_{i=1}^{m}\bigl(\nabla f_i(x)\nabla f_i(x)^T + f_i(x)\nabla^2f_i(x)\bigr).
```

<!-- ===== p260 ===== -->

We consider the case when $f$ is convex. This occurs, for example, if each $f_i$ is either nonnegative and convex, or nonpositive and concave, or affine.

The Gauss-Newton method uses the search direction

```math
\Delta x_{gn} = -\Bigl(\sum_{i=1}^{m}\nabla f_i(x)\nabla f_i(x)^T\Bigr)^{-1}\sum_{i=1}^{m}f_i(x)\nabla f_i(x).
```

(We assume here that the inverse exists, i.e., the vectors $\nabla f_1(x),\dots,\nabla f_m(x)$ span $R^n$.) This search direction can be considered an approximate Newton direction (see exercise 9.31), obtained by dropping the second derivative terms from the Hessian of $f$.

We can give another simple interpretation of the Gauss-Newton search direction $\Delta x_{gn}$. Using the first-order approximation $f_i(x+v)\approx f_i(x)+\nabla f_i(x)^Tv$ we obtain the approximation

```math
f(x+v) \approx \frac12\sum_{i=1}^{m}\bigl(f_i(x)+\nabla f_i(x)^Tv\bigr)^2.
```

The Gauss-Newton search step $\Delta x_{gn}$ is precisely the value of $v$ that minimizes this approximation of $f$. (Moreover, we conclude that $\Delta x_{gn}$ can be computed by solving a linear least-squares problem.)

Test the Gauss-Newton method on some problem instances of the form

```math
f_i(x) = (1/2)x^TA_ix+b_i^Tx+1,
```

with $A_i\in S^n_{++}$ and $b_i^TA_i^{-1}b_i\le2$ (which ensures that $f$ is convex).

**中文话题摘要**：Gauss-Newton 等价于「对残差做一次线性化后的线性最小二乘」；题设的 $b_i^TA_i^{-1}b_i\le2$ 正好保证每个 $f_i\ge0$、从而 $f$ 凸。

**Solution.** 我们生成随机的 $A_i\in S^n_{++}$、随机的 $b_i$，并把 $A_i$ 与 $b_i$ 缩放使 $b_i^TA_i^{-1}b_i=2$。取 $n=50$、$m=100$。下图给出一个典型的收敛曲线。

[Figure 5：$f(x^{(k)})-p^\star$ 的对数图，纵轴 $10^{0}$ 到 $10^{-10}$，横轴 $0$–$200$；曲线近似直线下降（线性收敛），斜率对应约每 $20$ 步降一个数量级]

可以看到 Gauss-Newton 方法线性收敛，且比 Newton 法慢得多（Newton 法在这个算例上 $2$ 步收敛）。

这在意料之中。把 Gauss-Newton 方法理解为近似 Newton 方法，就可以预期：只有当 Hessian 表达式中的第二项相对于第一项很小时它才表现良好，即要么 $\nabla^2f_i$ 很小（$f_i$ 近似线性），要么 $f_i$ 很小。对本题的测试算例，这两个条件都不满足。

<span style="color:#1e8449;">**[译注]** 这里有个容易被忽略的细节：题设的 $b_i^TA_i^{-1}b_i\le2$ 恰好是「$f_i(x)\ge0$ 对一切 $x$ 成立」的充要条件。验算：$f_i$ 的最小值在 $x=-A_i^{-1}b_i$ 处取得，值为 $1-\frac12b_i^TA_i^{-1}b_i$；要求 $\ge0$ 即 $b_i^TA_i^{-1}b_i\le2$。为什么非要 $f_i\ge0$？因为 $f=\frac12\sum f_i^2$ 的 Hessian 里那一项是 $f_i\nabla^2f_i$，当 $f_i\ge0$ 且 $A_i\succ0$ 时它半正定，$f$ 才凸——而整道题的「凸」前提就靠这个符号。实验取等号 $b_i^TA_i^{-1}b_i=2$ 是**故意把条件放宽到边界**：此时 $\min_x f_i=0$，某些 $i$ 在靠近最优点时 $f_i\approx0$，按理论 Gauss-Newton 应当变好；但同时 $\nabla^2f_i=A_i$ 并不小，两个条件相互抵消，结果是线性收敛。这个实验设计说明「Gauss-Newton 何时有效」不能只看一个量。

**消失测试**：不知道这个等价条件，就会在 $b_i^TA_i^{-1}b_i\gt2$ 的算例上得到**非凸** $f$，而 Gauss-Newton 仍会收敛到某个驻点——但那是鞍点或极大点，代码不会报错。

**落点**：Boyd §9.5（Newton 的近似）、习题 9.31(a)（同一思想的另一实现）、§4.5（非线性最小二乘的 Gauss-Newton 与 Levenberg–Marquardt）；实现侧见 `scipy.optimize.least_squares` 的文档对 `method='lm'` 收敛阶的说明。

**量的方向感**：Newton $2$ 步、Gauss-Newton 约 $150$ 步（$10$ 个数量级精度）；单步成本 Gauss-Newton 只需组装 $J^TJ$（$O(mn^2)$）而 Newton 还要 $\sum f_i\nabla^2f_i$，省下的常数约 $2$ 倍——用 $75$ 倍迭代换 $2$ 倍单步，净亏。</span>
