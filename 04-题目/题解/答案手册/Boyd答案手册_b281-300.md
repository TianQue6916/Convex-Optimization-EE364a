### Exercise 11.5 · 用标准 barrier method 解 SOCP（二阶锥规划）

> 话题摘要：二阶锥约束 $\|A_ix+b_i\|_2\le c_i^Tx+d_i$ 的左端在 $u=0$ 处不可微，标准 barrier method 用不上；把每个锥约束**拆成一条分式标量约束加一条非负标量约束**，就能回到标准 barrier method，且算出的 log barrier 与 §11.6 的 generalized logarithm 给出的**逐项相同**，得到的 $x^\star(t)$ 是原 SOCP 的 $2m/t$-suboptimal。

**Barrier method for second-order cone programming.** Consider the SOCP (without equality constraints, for simplicity)

```math
\begin{array}{ll}
\text{minimize} & f^Tx \\
\text{subject to} & \|A_ix+b_i\|_2 \le c_i^Tx+d_i, \qquad i=1,\dots,m .
\end{array}
```

The constraint functions in this problem are not differentiable (since the Euclidean norm $\|u\|_2$ is not differentiable at $u=0$) so the (standard) barrier method cannot be applied. In §11.6, we saw that this SOCP can be solved by an extension of the barrier method that handles generalized inequalities. In this exercise, we show how the standard barrier method (with scalar constraint functions) can be used to solve the SOCP. We first reformulate the SOCP as

```math
\begin{array}{ll}
\text{minimize} & f^Tx \\
\text{subject to} & \dfrac{\|A_ix+b_i\|_2^2}{c_i^Tx+d_i} \le c_i^Tx+d_i, \qquad i=1,\dots,m \\
& c_i^Tx+d_i \ge 0, \qquad i=1,\dots,m .
\end{array}
```

The constraint function

```math
f_i(x)=\frac{\|A_ix+b_i\|_2^2}{c_i^Tx+d_i}-c_i^Tx-d_i
```

is the composition of a quadratic-over-linear function with an affine function, and is twice differentiable (and convex), provided we define its domain as $\operatorname{\mathbf{dom}}f_i=\{x\mid c_i^Tx+d_i\gt 0\}$. Note that the two problems (11.63) and (11.64) are not exactly equivalent. If $c_i^Tx^\star+d_i=0$ for some $i$, where $x^\star$ is the optimal solution of the SOCP (11.63), then the reformulated problem (11.64) is not solvable; $x^\star$ is not in its domain. Nevertheless we will see that the barrier method, applied to (11.64), produces arbitrarily accurate suboptimal solutions of (11.64), and hence also for (11.63).

> **中译**：本题的约束函数不可微（Euclidean norm 在 $0$ 处折角），所以标准 barrier method 用不上；把锥约束改写成「二次-线性分式 $\le$ 仿射」加「仿射 $\ge 0$」两条标量约束后，问题变成可微凸问题；两个问题并不严格等价——若原 SOCP 的某个最优解让 $c_i^Tx^\star+d_i=0$，则该点不在 (11.64) 的 domain 内、reformulated 问题甚至没有最优解，但 barrier method 仍能给出任意精度的次优解。

**(a) Form the log barrier $\phi$ for the problem (11.64). Compare it to the log barrier that arises when the SOCP (11.63) is solved using the barrier method for generalized inequalities (in §11.6).**

**(b) Show that if $tf^Tx+\phi(x)$ is minimized, the minimizer $x^\star(t)$ is $2m/t$-suboptimal for the problem (11.63).**

**Solution.**

**(a)** 问题 (11.64) 的 log barrier 是

```math
\begin{aligned}
\phi(x) &= -\sum_{i=1}^{m}\log\left(c_i^Tx+d_i-\frac{\|A_ix+b_i\|_2^2}{c_i^Tx+d_i}\right)-\sum_{i=1}^{m}\log\left(c_i^Tx+d_i\right)\\
&= -\sum_{i=1}^{m}\log\left((c_i^Tx+d_i)^2-\|A_ix+b_i\|_2^2\right).
\end{aligned}
```

第一项是对分式约束取 $-\log\bigl(-f_i\bigr)$，第二项是非负约束 $c_i^Tx+d_i\ge0$ 自带的 barrier；两行之间只用了 $-\log\alpha-\log\beta=-\log(\alpha\beta)$，其中 $\alpha=c_i^Tx+d_i-\|A_ix+b_i\|_2^2/(c_i^Tx+d_i)$、$\beta=c_i^Tx+d_i$，乘积正好是 $(c_i^Tx+d_i)^2-\|A_ix+b_i\|_2^2$。**那个 $\log(c_i^Tx+d_i)$ 不是被丢掉的，是被第二条约束的 barrier 抵消掉的**。

而 SOCP (11.63) 用 §11.6 给出的二阶锥 generalized logarithm 写出来的 log barrier 是

```math
-\sum_{i=1}^{m}\log\left((c_i^Tx+d_i)^2-\|A_ix+b_i\|_2^2\right),
```

与上式**完全一样**。两者的 log barrier 相同。

<span style="color:#1e8449;">**[译注]** 「两条 barrier 相加恰好抵消成一条」不是巧合，而是 degree（次）这件事在起作用。二阶锥的 generalized logarithm 是 $\psi(y)=\log\bigl(y_{n+1}^2-\sum_{i=1}^n y_i^2\bigr)$，其 degree 是 $\theta=2$：对 $s\gt0$ 有 $\psi(sy)=\psi(y)+2\log s$。这个 $2$ 精确对应「拆成两条标量约束」时多出来的那一条——标准方法给出 $-\log(\text{分式残量})-\log(c_i^Tx+d_i)$，$-\log(\text{分式残量})$ 展开时带出一个 $+\log(c_i^Tx+d_i)$，与后面那个 $-1$ 系数相加归零。

**量上的后果**：两边 $t$ 的语义相同，但对偶间隙界不同——generalized inequality 侧每个锥贡献 $\theta=2$，$m$ 个锥给出 $2m/t$；若误按「$m$ 条标量约束」估，界变成 $m/t$，**乐观一倍**。拿 $m/t$ 当停止准则，你会在一半的精度上停：要 $10^{-6}$ 却拿到 $5\times10^{-7}$ 的假证书。

**消失测试**：没有「degree」这个概念，你无法判断一个 barrier 对应几条约束、间隙界该写多少，只能对每个新锥重推一遍；更糟的是本题的 reformulated 形式约束条数从 $m$ 涨到 $2m$，而间隙界**并不**随之涨到 $2m/t$ 的「新」值——它从头到尾就是 $2m/t$，因为这与锥的 degree 是同一件事。

**落点**：Boyd §11.6（generalized logarithm 与 degree 的定义）、example 11.8（p.599，SOC 的 barrier 与 $2m/t$）、exercise 11.16（degree 的四条恒等式）；挂 Strang 线代的「二次型 $y^TJy$ 与 $n+1$ 维 Minkowski 结构」。</span>

**(b)** centering 问题相同，central path 也相同，证明与 example 11.8 的推导逐行一致：取 $\lambda_i=-1/\bigl(tf_i(x^\star(t))\bigr)$ 即得 dual feasible 点，对偶函数值 $g(\lambda)=f^Tx^\star(t)-2m/t$，故 $x^\star(t)$ 是 $2m/t$-suboptimal；于是对 (11.64) 施加标准 barrier method 就能解原 SOCP (11.63)，即便 $x^\star$ 本身不在 (11.64) 的 domain 内。

### Exercise 11.6 · General barriers（一般 barrier：把 $-\log(-u)$ 换成别的凸增函数）

> 话题摘要：把 indicator 的近似 $-(1/t)\log(-u)$ 换成任意「二阶可微、闭、递增凸、$\operatorname{\mathbf{dom}}h=-\mathbf{R}_{++}$」的 $h$，得到 $h$-barrier 与 $h$-central path；对偶间隙变成 $(1/t)\sum_i h'(f_i(z))(-f_i(z))$，而它**只依赖 $t$ 与 $m$** 当且仅当 $h$ 是 log barrier 的伸缩加平移。

**General barriers.** The log barrier is based on the approximation $-(1/t)\log(-u)$ of the indicator function $\hat{\mathbf{I}}_-(u)$ (see §11.2.1, page 563). We can also construct barriers from other approximations, which in turn yield generalizations of the central path and barrier method. Let $h:\mathbf{R}\to\mathbf{R}$ be a twice differentiable, closed, increasing convex function, with $\operatorname{\mathbf{dom}}h=-\mathbf{R}_{++}$. (This implies $h(u)\to\infty$ as $u\to0$.) One such function is $h(u)=-\log(-u)$; another example is $h(u)=-1/u$ (for $u\lt0$).

Now consider the optimization problem (without equality constraints, for simplicity)

```math
\begin{array}{ll}
\text{minimize} & f_0(x) \\
\text{subject to} & f_i(x)\le 0, \qquad i=1,\dots,m,
\end{array}
```

where $f_i$ are twice differentiable. We define the $h$-barrier for this problem as

```math
\phi_h(x)=\sum_{i=1}^{m} h\bigl(f_i(x)\bigr),
```

with domain $\{x\mid f_i(x)\lt0,\ i=1,\dots,m\}$. When $h(u)=-\log(-u)$, this is the usual logarithmic barrier; when $h(u)=-1/u$, $\phi_h$ is called the inverse barrier（倒数 barrier）. We define the $h$-central path as

```math
x^\star(t)=\operatorname*{argmin}\ \bigl(tf_0(x)+\phi_h(x)\bigr),
```

where $t\gt0$ is a parameter. (We assume that for each $t$, the minimizer exists and is unique.)

<!-- ===== p282 ===== -->

> 页眉：`11 Interior-point methods`。本页是 11.6 的 (a)(b)(c) 与全部解答，末尾开始 11.7。

**(a) Explain why $tf_0(x)+\phi_h(x)$ is convex in $x$, for each $t\gt0$.**

**(b) Show how to construct a dual feasible $\lambda$ from $x^\star(t)$. Find the associated duality gap.**

**(c) For what functions $h$ does the duality gap found in part (b) depend only on $t$ and $m$ (and no other problem data)?**

**Solution.**

**(a)** composition rules（复合规则）表明 $tf_0(x)+\phi_h(x)$ 关于 $x$ 是凸的：$h$ 递增且凸，$f_i$ 凸，于是每个 $h(f_i(x))$ 是凸函数；再加上凸的 $tf_0$，整体仍凸。

**(b)** $tf_0(x)+\phi_h(x)$ 的极小点 $z=x^\star(t)$ 满足 $t\nabla f_0(z)+\nabla\phi_h(z)=0$。把 $\phi_h$ 展开，得

```math
t\nabla f_0(z)+\sum_{i=1}^{m}h'\bigl(f_i(z)\bigr)\nabla f_i(z)=0 .
```

这说明 $z$ 极小化 Lagrangian $f_0(z)+\sum_{i=1}^{m}\lambda_if_i(z)$，只要取

```math
\lambda_i=h'\bigl(f_i(z)\bigr)/t,\qquad i=1,\dots,m .
```

因为 $f_i(z)\lt0$ 而 $h$ 递增，有 $h'(f_i(z))\gt0$，故 $\lambda\succ0$；又 $z$ 让 Lagrangian 的梯度为零，$L(x,\lambda)$ 下方有界，于是 $\lambda$ 是 dual feasible 的。相应的对偶函数值是

```math
g(\lambda)=f_0(z)+\sum_{i=1}^{m}\lambda_if_i(z)=f_0(z)+\sum_{i=1}^{m}h'\bigl(f_i(z)\bigr)f_i(z)/t,
```

所以对偶间隙（duality gap）为

```math
\frac{1}{t}\sum_{i=1}^{m}h'\bigl(f_i(z)\bigr)\bigl(-f_i(z)\bigr).
```

**(c)** 上式要**只**依赖 $t$ 与 $m$（不依赖其余问题数据），唯一可能是乘积 $h'(u)(-u)$ 为常数。即 $h'(u)=a/(-u)$（$a$ 为常数），于是

```math
h(u)=-a\log(-u)+b,
```

其中 $b$ 为常数。由于 $h$ 必须凸且递增，需 $a\gt0$。因此这样的 $h$ 只给出**伸缩并平移后的 log barrier**；特别地，与它对应的 central path 与标准 log barrier 的 central path 是同一条。

<span style="color:#1e8449;">**[译注]** 三条假设「twice differentiable、closed、increasing convex」缺一条都会塌，这里逐条兑现。① **increasing** 让 §11.2.2 那套 dual 构造可以照搬：$\lambda_i=h'(f_i(z))/t$ 要满足 $\lambda\succeq0$，靠的就是 $f_i\lt0$ 加上 $h$ 递增给出 $h'\gt0$；若 $h$ 递减，$\lambda$ 直接变负，dual feasible 当场失效。② **closed** 保证 $u\to-\infty$ 一侧不漏气，从而 $\phi_h$ 在边界 $f_i\to0^-$ 上真的发散到 $+\infty$——barrier 的全部作用就是这条发散性把迭代关在可行域内部。③ **$\operatorname{\mathbf{dom}}h=-\mathbf{R}_{++}$** 把「$u\lt0$」写进 $h$ 自己的定义域，于是 $\phi_h$ 的 domain 自动等于严格可行集，不需要额外判断。

具体对比两个例子：$h(u)=-\log(-u)$ 给出 $h'(u)(-u)=1$，间隙恰好 $m/t$；$h(u)=-1/u$ 给出 $h'(u)=1/u^2$，于是 $h'(u)(-u)=-1/u$，间隙是 $(1/t)\sum_i 1/(-f_i(z))$——这一项**依赖每条约束的余量**，余量大的约束贡献小，余量接近零的约束贡献爆炸。数值感：$m=1$、$t=1$、$f_1(z)=-10^{-3}$ 时 inverse barrier 的间隙是 $10^{3}$，而 log barrier 恒为 $1$，相差三个数量级。

**消失测试**：没有「$h'(u)(-u)$ 为常数」这条判据，你会以为 central path 依赖 barrier 的具体形状；实际上 (c) 的答案说：**所有伸缩 log barrier 给出同一条 central path**，barrier 的自由度只影响「每步走多准」，不影响「最终走到哪里」。这条结论把 $\mu$ 与 $t$ 的调参降级成纯粹数值问题。

**落点**：Boyd §11.2.2（$\lambda_i=-1/(tf_i)$ 的 dual 构造）、p.563（indicator 的近似）、exercise 3.37（quadratic-over-linear 及其共轭）；挂 Thomson 实分析的「凸函数与凸增函数复合仍凸」。</span>

### Exercise 11.7 · Tangent to central path（central path 的切向量）

> 话题摘要：对中心性方程关于 $t$ 求导，得 $\mathrm{d}x^\star/\mathrm{d}t=-\bigl(t\nabla^2f_0+\nabla^2\phi\bigr)^{-1}\nabla f_0$；由此可证 $f_0(x^\star(t))$ 随 $t$ 单调下降。

**Tangent to central path.** This problem concerns $\mathrm{d}x^\star(t)/\mathrm{d}t$, which gives the tangent to the central path at the point $x^\star(t)$. For simplicity, we consider a problem without equality constraints; the results readily generalize to problems with equality constraints.

**(a) Find an explicit expression for $\mathrm{d}x^\star(t)/\mathrm{d}t$.** *Hint.* Differentiate the centrality equations (11.7) with respect to $t$.

**(b) Show that $f_0(x^\star(t))$ decreases as $t$ increases.** Thus, the objective value in the barrier method decreases, as the parameter $t$ is increased. (We already know that the duality gap, which is $m/t$, decreases as $t$ increases.)

**Solution.**

**(a)** 对中心性方程求导得

```math
\nabla f_0\bigl(x^\star(t)\bigr)+\Bigl(t\nabla^2f_0\bigl(x^\star(t)\bigr)+\nabla^2\phi\bigl(x^\star(t)\bigr)\Bigr)\frac{\mathrm{d}x^\star}{\mathrm{d}t}=0 .
```

因此 central path 在 $x^\star(t)$ 处的切向量为

```math
\frac{\mathrm{d}x^\star}{\mathrm{d}t}=-\Bigl(t\nabla^2f_0\bigl(x^\star(t)\bigr)+\nabla^2\phi\bigl(x^\star(t)\bigr)\Bigr)^{-1}\nabla f_0\bigl(x^\star(t)\bigr).
```

<!-- ===== p283 ===== -->

> 页眉：`Exercises`。本页含 11.7(b)、11.8 全题、11.9 题干。

**(b)** 下面证明 $\mathrm{d}f_0(x^\star(t))/\mathrm{d}t\lt0$。

```math
\begin{aligned}
\frac{\mathrm{d}f_0\bigl(x^\star(t)\bigr)}{\mathrm{d}t}
&= \nabla f_0\bigl(x^\star(t)\bigr)^T\frac{\mathrm{d}x^\star(t)}{\mathrm{d}t}\\
&= -\nabla f_0\bigl(x^\star(t)\bigr)^T\Bigl(t\nabla^2f_0\bigl(x^\star(t)\bigr)+\nabla^2\phi\bigl(x^\star(t)\bigr)\Bigr)^{-1}\nabla f_0\bigl(x^\star(t)\bigr)\\
&\lt 0 .
\end{aligned}
```

最后一步只用了 $t\nabla^2f_0+\nabla^2\phi\succ0$（centering 问题的 Hessian 正定），于是其逆也正定，二次型严格为负。

<span style="color:#1e8449;">**[译注]** 这条结论的用处不在「目标值在降」这个显然的事，而在于它把「$t$ 增大」与「目标值下降」变成**可判定的单调性**，从而给出 barrier method 的外层安全网：如果实现里某次 $\mu$-更新后目标值**上升**了，那不是「停在最优附近」，而是代码错了（Hessian 拼错、符号错、或 centering 提前中止）。这是最实用的自检——不需要知道 $p^\star$，只看 $f_0(x^\star(t))$ 是否随 $t$ 单调不增。

**量与机制**：下降速率不是常数，而是 $\mathrm{d}f_0/\mathrm{d}t=-\nabla f_0^TH^{-1}\nabla f_0$，其中 $H=t\nabla^2f_0+\nabla^2\phi$。在 $x^\star$ 附近 $\nabla f_0$ 被 $H$ 压住，导数趋于零；离最优点远时降得快。所以 $t$ 从 $1$ 涨到 $10^4$ 的这段里，前几轮拿走大部分精度，后几轮只是零头——这也解释了为什么实际代码里 $\mu=10$ 与 $\mu=100$ 的总 Newton 步数差得远小于 $10$ 倍。

**消失测试**：只盯 $m/t$ 而不管 $f_0$ 的单调性，你就无法区分「收敛慢」与「实现有 bug」；有了 (b)，任何一次目标值回升都是**硬错误信号**，比等对偶间隙跑偏更早暴露。

**落点**：Boyd §11.2（中心性方程 (11.7)）、§11.3.3（$\mu$-更新后必须重新 centering 的理由）、exercise 11.8（把这条切线当 predictor）；挂 CSAPP 的「把不变量写成 assertion」这一工程习惯。</span>

### Exercise 11.8 · Predictor-corrector method for centering problems（中心化问题的一阶预测-校正）

> 话题摘要：用 central path 的切线做一阶预测 $\hat{x}=x^\star(t)+\frac{\mathrm{d}x^\star}{\mathrm{d}t}(\mu t-t)$，与「直接从 $x^\star(t)$ 起 Newton」比较；两者只在 Hessian 的 $t\nabla^2f_0$ 项上不同，而**当 $f_0$ 线性时完全相同**。

**Predictor-corrector method for centering problems.** In the standard barrier method, $x^\star(\mu t)$ is computed using Newton's method, starting from the initial point $x^\star(t)$. One alternative that has been proposed is to make an approximation or prediction $\hat{x}$ of $x^\star(\mu t)$, and then start the Newton method for computing $x^\star(\mu t)$ from $\hat{x}$. The idea is that this should reduce the number of Newton steps, since $\hat{x}$ is (presumably) a better initial point than $x^\star(t)$. This method of centering is called a predictor-corrector method, since it first makes a prediction of what $x^\star(\mu t)$ is, then corrects the prediction using Newton's method.

The most widely used predictor is the first-order predictor, based on the tangent to the central path, explored in exercise 11.7. This predictor is given by

```math
\hat{x}=x^\star(t)+\frac{\mathrm{d}x^\star(t)}{\mathrm{d}t}(\mu t-t).
```

Derive an expression for the first-order predictor $\hat{x}$. Compare it to the Newton update obtained, i.e., $x^\star(t)+\Delta x_{\mathrm{nt}}$, where $\Delta x_{\mathrm{nt}}$ is the Newton step for $\mu tf_0(x)+\phi(x)$, at $x^\star(t)$. What can you say when the objective $f_0$ is linear?

**Solution.** 一阶预测由 exercise 11.7 的 $\mathrm{d}x^\star/\mathrm{d}t$ 表达式给出：

```math
\begin{aligned}
\hat{x} &= x^\star(t)+\frac{\mathrm{d}x^\star(t)}{\mathrm{d}t}(\mu t-t)\\
&= x^\star(t)-(\mu-1)t\Bigl(t\nabla^2f_0\bigl(x^\star(t)\bigr)+\nabla^2\phi\bigl(x^\star(t)\bigr)\Bigr)^{-1}\nabla f_0\bigl(x^\star(t)\bigr).
\end{aligned}
```

而 $\mu tf_0+\phi$ 在点 $x^\star(t)$ 处的 Newton 步是

```math
\begin{aligned}
\Delta x_{\mathrm{nt}}
&= -\Bigl(\mu t\nabla^2f_0\bigl(x^\star(t)\bigr)+\nabla^2\phi\bigl(x^\star(t)\bigr)\Bigr)^{-1}\Bigl(\mu t\nabla f_0\bigl(x^\star(t)\bigr)+\nabla\phi\bigl(x^\star(t)\bigr)\Bigr)\\
&= -(\mu-1)t\Bigl(\mu t\nabla^2f_0\bigl(x^\star(t)\bigr)+\nabla^2\phi\bigl(x^\star(t)\bigr)\Bigr)^{-1}\nabla f_0\bigl(x^\star(t)\bigr),
\end{aligned}
```

第二步用了中心性方程 $t\nabla f_0(x^\star(t))+\nabla\phi(x^\star(t))=0$，于是 $\mu t\nabla f_0+\nabla\phi=(\mu-1)t\nabla f_0$。Newton update 因此是

```math
x^\star(t)+\Delta x_{\mathrm{nt}}=x^\star(t)-(\mu-1)t\Bigl(\mu t\nabla^2f_0\bigl(x^\star(t)\bigr)+\nabla^2\phi\bigl(x^\star(t)\bigr)\Bigr)^{-1}\nabla f_0\bigl(x^\star(t)\bigr).
```

它与一阶预测**相似但并不相同**：标量因子 $(\mu-1)t$ 一致，差在括号里的 Hessian——预测用 $t\nabla^2f_0$，Newton 用 $\mu t\nabla^2f_0$。

现在看 $f_0$ 线性的特例，比如 $f_0(x)=c^Tx$。此时 $\nabla^2f_0=0$，一阶预测变成

```math
\hat{x}=x^\star(t)-(\mu-1)t\,\nabla^2\phi\bigl(x^\star(t)\bigr)^{-1}c ,
```

而 Newton update 与它**完全相同**：$\mu tf_0+\phi$ 在 $x^\star$ 处的 Newton 步恰好就是 central path 的切线。结论是——当目标线性时，名字很花哨的 predictor-corrector method，与「直接从当前点 $x^\star(t)$ 起 Newton」这个方法完全一样。

<span style="color:#1e8449;">**[译注]** 这条结论的可操作含义是：**predictor-corrector 的全部增益来自 $\nabla^2f_0\ne0$**，而且差多少可以显式算出来。写成公式：令 $A=t\nabla^2f_0+\nabla^2\phi$、$B=\mu t\nabla^2f_0+\nabla^2\phi$，两个初始点之差是 $-(\mu-1)t\,\bigl(A^{-1}-B^{-1}\bigr)\nabla f_0$，量级由 $\|A^{-1}-B^{-1}\|$ 决定。

**量的方向感**，两个极端都要看清。① 若 $\nabla^2\phi\ll t\nabla^2f_0$（barrier 曲率远小于目标曲率，例如高精度 $\mu$ 大、目标强凸），则 $A\approx t\nabla^2f_0$、$B\approx\mu t\nabla^2f_0$，$A^{-1}-B^{-1}\approx\bigl(1-1/\mu\bigr)\bigl(t\nabla^2f_0\bigr)^{-1}$，**差别最大**，predictor 真能省步数。② 若 $\nabla^2\phi\gg t\nabla^2f_0$（目标平坦或 $t$ 小），两个 Hessian 都被 $\nabla^2\phi$ 主导，$A^{-1}-B^{-1}\to0$，predictor 与「原地不动」等价，白花一次矩阵求解。LP 以及多数 QP 的早期迭代都落在情形 ②——这就是为什么在 LP 上 predictor-corrector 常被报告「没有收益」。

**消失测试**：不知道「$f_0$ 线性时两者恒等」，实现者很容易在 LP 上再叠一层 predictor，并把省下的步数归功于它，而收益其实全部来自 $\mu$ 的选择与停止准则；你会把工程精力投到一个**数学上恒等**的优化上。

**落点**：Boyd §11.3（barrier method 的 centering 步）、exercise 11.7（切向量的显式表达）、§11.5.3（predictor-corrector 与 Mehrotra 的原始动机）；挂 6.006 的「Newton 法二次收敛只在初始点进入 basin 后成立」。</span>

### Exercise 11.9 · Dual feasible points near the central path（近 central path 处的对偶可行点）

> 话题摘要：$x$ 只是「接近」中心化时 $\lambda_i=-1/(tf_i(x))$ 不再 dual feasible；把 Newton 步的一阶修正塞进去，$\lambda_i=\frac{1}{-tf_i(x)}\bigl(1+\frac{\nabla f_i(x)^T\Delta x_{\mathrm{nt}}}{-f_i(x)}\bigr)$ 又能重新可行——这就是「centering 不能随便提前停」的定量理由。

**Dual feasible points near the central path.** Consider the problem

```math
\begin{array}{ll}
\text{minimize} & f_0(x) \\
\text{subject to} & f_i(x)\le 0, \qquad i=1,\dots,m,
\end{array}
```

with variable $x\in\mathbf{R}^n$. We assume the functions $f_i$ are convex and twice differentiable. (We assume for simplicity there are no equality constraints.) Recall (from §11.2.2, page 565) that $\lambda_i=-1/\bigl(tf_i(x^\star(t))\bigr)$, $i=1,\dots,m$, is dual feasible, and in fact, $x^\star(t)$ minimizes $L(x,\lambda)$. This allows us to evaluate the dual function for $\lambda$, which turns out to be $g(\lambda)=f_0(x^\star(t))-m/t$. In particular, we conclude that $x^\star(t)$ is $m/t$-suboptimal.

In this problem we consider what happens when a point $x$ is close to $x^\star(t)$, but not quite centered. (This would occur if the centering steps were terminated early, or not carried out to full accuracy.) In this case, of course, we cannot claim that $\lambda_i=-1/\bigl(tf_i(x)\bigr)$, $i=1,\dots,m$, is dual feasible, or that $x$ is $m/t$-suboptimal. However, it turns out that a slightly more complicated formula does yield a dual feasible point, provided $x$ is close enough to centered.

Let $\Delta x_{\mathrm{nt}}$ be the Newton step at $x$ of the centering problem

```math
\text{minimize}\quad tf_0(x)-\sum_{i=1}^{m}\log\bigl(-f_i(x)\bigr).
```

Define

```math
\lambda_i=\frac{1}{-tf_i(x)}\left(1+\frac{\nabla f_i(x)^T\Delta x_{\mathrm{nt}}}{-f_i(x)}\right),\qquad i=1,\dots,m .
```

You will show that for small $\Delta x_{\mathrm{nt}}$ (i.e., for $x$ nearly centered), $\lambda$ is dual feasible (i.e., $\lambda\succeq0$ and $L(x,\lambda)$ is bounded below).

In this case, the vector $x$ does not minimize $L(x,\lambda)$, so there is no general formula for the dual function value $g(\lambda)$ associated with $\lambda$. (If we have an analytical expression for the dual objective, however, we can simply evaluate $g(\lambda)$.)

**Hint.** Use the results in exercise 3.41 to show that when $\Delta x_{\mathrm{nt}}$ is small enough, there exist $x_0,x_1,\dots,x_m$ such that

```math
\begin{aligned}
\nabla f_0(x_0) &= \nabla f_0(x)+\nabla^2f_0(x)\Delta x_{\mathrm{nt}},\\
\nabla f_i(x_i) &= \nabla f_i(x)+(1/\lambda_i)\nabla^2f_i(x)\Delta x_{\mathrm{nt}},\qquad i=1,\dots,m .
\end{aligned}
```

建（build）这些 $x_i$ 的方式是：把右端看成「$x$ 处梯度沿 $\Delta x_{\mathrm{nt}}$ 方向的一阶移动」，再由 exercise 3.41 的局部逆像结论保证存在对应的点。

**Solution.** 显然对足够小的 $\Delta x_{\mathrm{nt}}$ 有 $\lambda\succ0$。需要证明 $f_0+\sum_i\lambda_if_i$ 下方有界。

$x$ 处的 Newton 方程是

```math
t\nabla f_0(x)+\sum_{i=1}^{m}\frac{1}{-f_i(x)}\nabla f_i(x)+\Bigl(t\nabla^2f_0(x)+\sum_{i=1}^{m}\frac{1}{-f_i(x)}\nabla^2f_i(x)+\sum_{i=1}^{m}\frac{1}{f_i(x)^2}\nabla f_i(x)\nabla f_i(x)^T\Bigr)\Delta x_{\mathrm{nt}}=0 ,
```

即

```math
\nabla f_0(x)+\sum_{i=1}^{m}\lambda_i\nabla f_i(x)+\nabla^2f_0(x)\Delta x_{\mathrm{nt}}+\sum_{i=1}^{m}\frac{1}{-tf_i(x)}\nabla^2f_i(x)\Delta x_{\mathrm{nt}}=0 ,
```

其中用了上面 $\lambda$ 的定义。这行能合并成这个形状，靠的是把 $\sum_i\frac{1}{tf_i(x)^2}\nabla f_i\nabla f_i^T\Delta x_{\mathrm{nt}}$ 折进 $\sum_i\lambda_i\nabla f_i(x)$ 的一阶修正里（把 $\lambda_i$ 的定义展开即可看到）。

现在，由 exercise 3.41 的结果，当 $\Delta x_{\mathrm{nt}}$ 足够小时存在 $x_0,x_1,\dots,x_m$ 使

```math
\nabla f_0(x_0)=\nabla f_0(x)+\nabla^2f_0(x)\Delta x_{\mathrm{nt}},
```

以及

```math
\nabla f_i(x_i)=\nabla f_i(x)+(1/\lambda_i)\nabla^2f_i(x)\Delta x_{\mathrm{nt}},\qquad i=1,\dots,m .
```

于是 Newton 方程可以写成

```math
\nabla f_0(x_0)+\sum_{i=1}^{m}\lambda_i\nabla f_i(x_i)=0 .
```

<span style="color:#1e8449;">**[译注]** 这一步是 11.9 的技术核心，值得单独盯住：**「存在 $x_i$」用的是一阶 Taylor 的逆问题**，成立靠 $\nabla^2f_i$ 非退化加上 $\Delta x_{\mathrm{nt}}$ 足够小。而后一个条件等价于「$x$ 已近似中心化」，也就是 §11.3.3 那个停止准则 $\lambda(x)^2=\Delta x_{\mathrm{nt}}^T\bigl(t\nabla^2f_0+\nabla^2\phi\bigr)\Delta x_{\mathrm{nt}}\lt\epsilon$。这就把「centering 要跑多准」从经验参数变成**定理的前提**。

**量的方向感**：可行性条件是 $\lambda_i\gt0$，即 $1+\nabla f_i(x)^T\Delta x_{\mathrm{nt}}/(-f_i(x))\gt0$，最坏情形要

```math
\frac{\|\nabla f_i(x)\|\,\|\Delta x_{\mathrm{nt}}\|}{-f_i(x)}\lt 1
```

对每条约束成立。$-f_i(x)$ 是第 $i$ 条约束的余量：**余量越小，能容忍的 $\Delta x_{\mathrm{nt}}$ 越小**。这解释了一个常见现象——末段迭代里某条约束余量掉到 $10^{-8}$ 量级，此时哪怕 $\|\Delta x_{\mathrm{nt}}\|=10^{-4}$ 也会让公式失效，$\lambda$ 出现负分量，而你算出的「对偶界」变成垃圾（可能比 $p^\star$ 还小，于是 gap 变成负数）。诊断顺序：先查 centering 是否停太早，再查符号。

**消失测试**：没有这条一阶修正，你就只能在 $x$ **恰好**落在 central path 上时才拿到 dual feasible 点；任何数值实现的 centering 都不可能精确，于是「用 gap 做停止准则」在实践中直接不可用——你被迫用 $t$ 的绝对值当代理，而 $t$ 与真实误差的关系又依赖问题尺度。**这条公式是把理论上的 $m/t$ 界变成可运行代码的那座桥。**

**落点**：Boyd §11.3.3（Newton decrement 停止准则）、§11.2.2（$m/t$ 的推导）、exercise 3.41（近似点与梯度逆像）；挂 Thomson 实分析的「开映射／局部可逆」直觉（不必上升到反函数定理的完整陈述）。</span>

### Exercise 11.10 · Another parametrization of the central path（central path 的另一种参数化）

> 话题摘要：在原有 $m$ 条约束之外再加一条「$f_0(x)\le u$」，用 $u$ 当参数；所得 $z^\star(u)$ 与 $x^\star(t)$ 是同一条曲线，对应关系 $t=1/(u-f_0(z^\star(u)))$，反向 $u=1/t+f_0(x^\star(t))$。

**Another parametrization of the central path.** We consider the problem (11.1), with central path $x^\star(t)$ for $t\gt0$, defined as the solution of

```math
\begin{array}{ll}
\text{minimize} & tf_0(x)-\sum_{i=1}^{m}\log\bigl(-f_i(x)\bigr)\\
\text{subject to} & Ax=b .
\end{array}
```

In this problem we explore another parametrization of the central path. For $u\gt p^\star$, let $z^\star(u)$ denote the solution of

```math
\begin{array}{ll}
\text{minimize} & -\log\bigl(u-f_0(x)\bigr)-\sum_{i=1}^{m}\log\bigl(-f_i(x)\bigr)\\
\text{subject to} & Ax=b .
\end{array}
```

Show that the curve defined by $z^\star(u)$, for $u\gt p^\star$, is the central path. (In other words, for each $u\gt p^\star$, there is a $t\gt0$ for which $x^\star(t)=z^\star(u)$, and conversely, for each $t\gt0$, there is an $u\gt p^\star$ for which $z^\star(u)=x^\star(t)$.)

**Solution.** $z^\star(u)$ 满足最优性条件

```math
\frac{1}{u-f_0\bigl(z^\star(u)\bigr)}\nabla f_0\bigl(z^\star(u)\bigr)+\sum_{i=1}^{m}\frac{1}{-f_i\bigl(z^\star(u)\bigr)}\nabla f_i\bigl(z^\star(u)\bigr)+A^T\nu=0
```

（对某个 $\nu$）。与中心性方程 $t\nabla f_0+\sum_i\frac{1}{-f_i}\nabla f_i+A^T\nu=0$ 逐项比对可见 $z^\star(u)=x^\star(t)$，只要取

```math
t=\frac{1}{u-f_0\bigl(z^\star(u)\bigr)} .
```

反过来，对每个 $t\gt0$ 取

```math
u=\frac{1}{t}+f_0\bigl(x^\star(t)\bigr)\gt p^\star ,
```

就有 $x^\star(t)=z^\star(u)$。其中 $u\gt p^\star$ 由 $f_0(x^\star(t))\gt p^\star$ 与 $1/t\gt0$ 保证。

<span style="color:#1e8449;">**[译注]** 这个换参数化不是记号游戏：它把「$t$ 是一个**没有量纲意义**的算法参数」换成「$u$ 是一个**有物理意义的目标值上界**」——$u$ 表示「我承诺 $f_0\le u$」，而 $z^\star(u)$ 是「满足这个承诺的严格可行点中最居中的那个」。工程收益直接：可以用「当前已达成的最好目标值」当 $u$ 的初值，于是第一个 centering 问题从「解离可行域边界太近」变成「解留在当前最好解附近」。

**量与机制的映射**：$u=\frac1t+f_0(x^\star(t))$ 给出一个可检验的定量预测——$t\to\infty$ 时 $1/t\to0$，故 $u\to f_0(x^\star)=p^\star$，即**参数 $u$ 的极限正是最优值**；而 $t\to0$ 时 $u\to\infty$，barrier 权重趋于零，解被推到「最居中」而不顾目标。所以两种参数化把 central path 的两端分别送到有限点（$u\downarrow p^\star$）与无穷远（$t\uparrow\infty$），这正是 analytic-center 方法为什么用 $u$ 更自然（下一题 11.11 就这么做）。

**消失测试**：没有这个等价性，你就得为「用 $u$ 参数化的方法」重证一遍收敛性与复杂度；有了它，11.11 的收敛性可以直接引用 $m/t$ 的既有结论，只做一次代数替换。**它省下的不是一行代码，而是整个第 11 章定理的可复用性。**

**落点**：Boyd §11.2（central path 的定义）、§11.3.4（另一种解释）、exercise 11.11（直接使用本题结论）；挂 6.042J 的「同一集合的两种枚举方式之间的双射」。</span>

### Exercise 11.11 · Method of analytic centers（解析中心法）

> 话题摘要：用 11.10 的 $u$ 参数化做外层迭代，$u^{+}=\theta u+(1-\theta)f_0(x)$；证明 $u^{+}-p^\star\le\frac{m+\theta}{m+1}(u-p^\star)$，即线性收敛，收敛率由 $m$ 与 $\theta$ 决定。

**Method of analytic centers.** In this problem we consider a variation on the barrier method, based on the parametrization of the central path described in exercise 11.10. For simplicity, we consider a problem with no equality constraints,

```math
\begin{array}{ll}
\text{minimize} & f_0(x) \\
\text{subject to} & f_i(x)\le 0, \qquad i=1,\dots,m .
\end{array}
```

The method of analytic centers starts with any strictly feasible initial point $x^{(0)}$, and any $u^{(0)}\gt f_0(x^{(0)})$. We then set

```math
u^{(1)}=\theta u^{(0)}+(1-\theta)f_0\bigl(x^{(0)}\bigr),
```

where $\theta\in(0,1)$ is an algorithm parameter (usually chosen small), and then compute the next iterate as

```math
x^{(1)}=z^\star\bigl(u^{(1)}\bigr)
```

(using Newton's method, starting from $x^{(0)}$). Here $z^\star(s)$ denotes the minimizer of

```math
-\log\bigl(s-f_0(x)\bigr)-\sum_{i=1}^{m}\log\bigl(-f_i(x)\bigr),
```

which we assume exists and is unique. This process is then repeated. The point $z^\star(s)$ is the analytic center（解析中心）of the inequalities

```math
f_0(x)\le s,\quad f_1(x)\le 0,\ \dots,\ f_m(x)\le 0,
```

hence the algorithm name.

Show that the method of centers works, i.e., $x^{(k)}$ converges to an optimal point. Find a stopping criterion that guarantees that $x$ is $\epsilon$-suboptimal, where $\epsilon\gt0$.

**Hint.** The points $x^{(k)}$ are on the central path; see exercise 11.10. Use this to show that

```math
u^{+}-p^\star\le\frac{m+\theta}{m+1}\bigl(u-p^\star\bigr),
```

where $u$ and $u^{+}$ are the values of $u$ on consecutive iterations.

**Solution.** 令 $x=z^\star(u)$。由 exercise 11.10 的对偶结果，

```math
\begin{aligned}
p^\star &\ge f_0(x)-m\bigl(u-f_0(x)\bigr)\\
&= (m+1)f_0(x)-mu,
\end{aligned}
```

因此

```math
f_0(x)\le\frac{p^\star+mu}{m+1} .
```

令 $u^{+}=\theta u+(1-\theta)f_0(x)$。我们有

```math
\begin{aligned}
u^{+}-p^\star &= \theta u+(1-\theta)f_0(x)-p^\star\\
&\le (1-\theta)\frac{p^\star+mu}{m+1}+\theta u-p^\star\\
&= \left(\frac{1-\theta}{m+1}-1\right)p^\star+\left(\frac{(1-\theta)m}{m+1}+\theta\right)u\\
&= -\frac{m+\theta}{m+1}p^\star+\frac{m+\theta}{m+1}u\\
&= \frac{m+\theta}{m+1}\bigl(u-p^\star\bigr).
\end{aligned}
```

第三行到第四行只做了两处合并：$\frac{1-\theta}{m+1}-1=-\frac{m+\theta}{m+1}$，以及 $\frac{(1-\theta)m+\theta(m+1)}{m+1}=\frac{m+\theta}{m+1}$。由于 $0\lt\theta\lt1$，有 $\frac{m+\theta}{m+1}\lt1$，于是 $u^{(k)}-p^\star\le\left(\frac{m+\theta}{m+1}\right)^{k}\bigl(u^{(0)}-p^\star\bigr)\to0$，同时 $f_0(x^{(k)})\le\frac{p^\star+mu^{(k)}}{m+1}\to p^\star$，故 $x^{(k)}$ 收敛到最优点。

<span style="color:#1e8449;">**[译注]** 这个收敛率 $\kappa=\frac{m+\theta}{m+1}$ 值得盯一眼，因为它**几乎就是 1**：$m=100$、$\theta=0.1$ 时 $\kappa=\frac{100.1}{101}=0.9911$，要把 $u-p^\star$ 从 $10^{0}$ 压到 $10^{-6}$ 需要 $\ln(10^{6})/\ln(1/0.9911)\approx 1543$ 次外层迭代，而标准 barrier method 用 $\mu=10$ 只需 $\log_{10}(10^{6})=6$ 次。**这就是为什么 analytic-center 方法在实践里被 barrier method 压倒**——不是为了理论漂亮就必须用它。

**量的方向感**：$\theta\to0$ 时 $\kappa\to\frac{m}{m+1}$，仍是一个 $O(1/m)$ 的 gap，因为每步只把 $u$ 朝 $f_0(x)$ 挪一点点；$\theta\to1$ 时 $\kappa\to1$，几乎不收敛（但每步便宜）。所以 $\theta$ 是在「每步的 Newton 代价」与「外层步数」之间做交换，最佳折中在 $\kappa$ 与单步代价的乘积最小处。

**停止准则（本题问了但解答没写）**：由 $f_0(x)-p^\star\le m\bigl(u-f_0(x)\bigr)$，只要

```math
u-f_0(x)\le\frac{\epsilon}{m}
```

就有 $f_0(x)-p^\star\le\epsilon$，即 $x$ 是 $\epsilon$-suboptimal 的。这个判据**不需要知道 $p^\star$**，可以每一步算出来，比追 $u^{(k)}-p^\star$ 实用得多。（原文漏答这一问，见篇末小瑕疵表第 1 条。）

**消失测试**：没有 $u$ 参数化，你就无法把「目标值上界」当成单调下降的外层序列来记账，收敛性证明只能走「$t\to\infty$ 时 $x^\star(t)\to x^\star$」这条更弱的路径，拿不到任何速率；而没有上面的停止准则，整个算法在实现时没有可判定的出口。

### Exercise 11.12 · Barrier method for convex-concave games（凸-凹博弈的 barrier method）

> 话题摘要：带不等式约束的 $\min_w\max_z f_0(w,z)$，把 barrier 分别加在 $w$ 侧与 $z$ 侧的约束上，得到 $tf_0-\sum\log(-f_i(w))+\sum\log(-\tilde{f}_i(z))$，它在 $(w,z)$ 上 convex-concave；鞍点 $(w^\star(t),z^\star(t))$ 的次优性由 $\frac{m+\tilde{m}}{t}$ 控制。

**Barrier method for convex-concave games.** We consider a convex-concave game with inequality constraints,

```math
\begin{array}{ll}
\text{minimize}_w\ \text{maximize}_z & f_0(w,z)\\
\text{subject to} & f_i(w)\le 0,\qquad i=1,\dots,m\\
& \tilde{f}_i(z)\le 0,\qquad i=1,\dots,\tilde{m}.
\end{array}
```

Here $w\in\mathbf{R}^n$ is the variable associated with minimizing the objective, and $z\in\mathbf{R}^{\tilde{n}}$ is the variable associated with maximizing the objective. The constraint functions $f_i$ and $\tilde{f}_i$ are convex and differentiable, and the objective function $f_0$ is differentiable and convex-concave, i.e., convex in $w$, for each $z$, and concave in $z$, for each $w$. We assume for simplicity that $\operatorname{\mathbf{dom}}f_0=\mathbf{R}^n\times\mathbf{R}^{\tilde{n}}$.

A solution or saddle-point（鞍点）for the game is a pair $w^\star,z^\star$, for which

```math
f_0(w^\star,z)\le f_0(w^\star,z^\star)\le f_0(w,z^\star)
```

holds for every feasible $w$ and $z$. (For background on convex-concave games and functions, see §5.4.3, §10.3.4 and exercises 3.14, 5.24, 5.25, 10.10, and 10.13.) In this exercise we show how to solve this game using an extension of the barrier method, and the infeasible start Newton method (see §10.3).

**(a) Let $t\gt0$. Explain why the function**

```math
tf_0(w,z)-\sum_{i=1}^{m}\log\bigl(-f_i(w)\bigr)+\sum_{i=1}^{\tilde{m}}\log\bigl(-\tilde{f}_i(z)\bigr)
```

**is convex-concave in $(w,z)$. We will assume that it has a unique saddle-point, $(w^\star(t),z^\star(t))$, which can be found using the infeasible start Newton method.**

**(b) As in the barrier method for solving a convex optimization problem, we can derive a simple bound on the suboptimality of $(w^\star(t),z^\star(t))$, which depends only on the problem dimensions, and decreases to zero as $t$ increases. Let $W$ and $Z$ denote the feasible sets for $w$ and $z$,**

```math
W=\{w\mid f_i(w)\le0,\ i=1,\dots,m\},\qquad Z=\{z\mid\tilde{f}_i(z)\le0,\ i=1,\dots,\tilde{m}\}.
```

**Show that**

```math
\begin{aligned}
f_0\bigl(w^\star(t),z^\star(t)\bigr) &\le \inf_{w\in W}f_0\bigl(w,z^\star(t)\bigr)+\frac{m}{t},\\
f_0\bigl(w^\star(t),z^\star(t)\bigr) &\ge \sup_{z\in Z}f_0\bigl(w^\star(t),z\bigr)-\frac{\tilde{m}}{t},
\end{aligned}
```

**and therefore**

```math
\sup_{z\in Z}f_0\bigl(w^\star(t),z\bigr)-\inf_{w\in W}f_0\bigl(w,z^\star(t)\bigr)\le\frac{m+\tilde{m}}{t}.
```

**Solution.**

**(a)** 这直接来自 $f_0$ 的 convex-concave 性与两个 barrier 项的单调性：$-\log(-f_i(w))$ 关于 $w$ 凸（$-\log$ 递减凸复合凸的 $-f_i$，再取负号仍凸），$\log(-\tilde{f}_i(z))$ 关于 $z$ 凹（$\log$ 递增凹复合凹的 $-\tilde{f}_i$）。加上 $tf_0$ 后，整体关于 $w$ 凸、关于 $z$ 凹，即 convex-concave。

<span style="color:#1e8449;">**[译注]** 「convex-concave」这个性质是本题唯一可解的理由，值得和「凸」区分开。凸优化的招牌结论是「局部最优即全局最优」；博弈版本对应的是「鞍点存在且唯一」（von Neumann 型结论），而**算法**上的后果是：你不能用「沿负梯度下降」这类单一方向的方法，必须交替地「对 $w$ 下降、对 $z$ 上升」，而 infeasible start Newton method 恰好就是在这个乘积结构上做 Newton。

**符号上的陷阱**（也是本类题最高频的错型）：$z$ 侧的 barrier 是 $+\log(-\tilde{f}_i(z))$，**前面是正号**。原因是 $z$ 玩家在最大化，$\tilde{f}_i(z)\le0$ 对它是「希望往边界推」的约束，$-\log(-\tilde{f}_i)$ 在可行域内是正的惩罚，要加到**被最大化**的量上才是惩罚；写成 $-\sum\log(-\tilde{f}_i)$ 就变成奖励越界。验算：$m=\tilde{m}=1$、$t=1$、$\tilde{f}_1(z)=z-1$、$f_0=0$，正确写法在 $z\to1^-$ 时函数值 $\to+\infty$（把 $z$ 挡在里面），错误写法在 $z\to1^-$ 时 $\to-\infty$（把 $z$ 推到边界外）。

**消失测试**：没有 convex-concave 这个结构，$\min_w\max_z$ 一般**不存在**鞍点（有限博弈之外，纯策略鞍点可以没有），你算出的 $w^\star(t)$ 会依赖初始化而在不同局部之间跳；标准 barrier method 的整个对偶间隙论证也会失效，因为「对偶间隙」在非凸情形可以是负的。

**落点**：Boyd §5.4.3（convex-concave 与 minimax 定理）、§10.3.4（鞍点的 Newton 求解）、exercise 3.14/5.24/5.25（鞍点存在性）；挂 6.042J 的「偏序集上的极小极大与格」。</span>

**(b)** 因为 $(w^\star(t),z^\star(t))$ 是函数

其中 $\lambda_i=1/\bigl(-tf_i(w^\star(t))\bigr)$，也就是说对一切 $w$ 都有

```math
f_0\bigl(w^\star(t),z^\star(t)\bigr)+\sum_{i=1}^{m}\lambda_if_i\bigl(w^\star(t)\bigr)\le f_0\bigl(w,z^\star(t)\bigr)+\sum_{i=1}^{m}\lambda_if_i(w).
```

左端等于 $f_0(w^\star(t),z^\star(t))-m/t$；而对一切 $w\in W$，右端第二项非正，于是

```math
f_0\bigl(w^\star(t),z^\star(t)\bigr)\le\inf_{w\in W}f_0\bigl(w,z^\star(t)\bigr)+\frac{m}{t}.
```

<span style="color:#d35400;">**† 原文错误（本页第 1 处）**：紧接着的「A similar argument shows that」

```math
f_0\bigl(w^\star(t),z^\star(t)\bigr)\ge\sup_{z\in Z}f_0\bigl(w^\star(t),z\bigr)-\frac{m}{t}
```

**右端的 $m$ 应为 $\tilde{m}$**。$z$ 侧有 $\tilde{m}$ 条约束，鞍点在 $z$ 方向的对偶量是 $\tilde{\lambda}_i=-1/\bigl(t\tilde{f}_i(z^\star(t))\bigr)$，恒等式给的是 $\sum_i\tilde{\lambda}_i\bigl(-\tilde{f}_i\bigr)=\tilde{m}/t$。**同页题干自己写的就是 $\tilde{m}/t$**，解答内部自相矛盾。

**可手算反例**：取 $m=1$、$\tilde{m}=10$、$t=1$。真界是 $\sup_z f_0(w^\star,z)-10$，原文给的是减 $1$——宽了 $9$ 个单位，于是「$w^\star(t)$ 与 $z^\star(t)$ 之间的 gap 界」被低估到 $(1+1)/1=2$，而由题干 (11.12) 的第三式应为 $(1+10)/1=11$。若拿被低估的界当停止准则，你会以为已达到 $2$ 的精度，实际只到 $11$。

**为什么会写错**：$w$ 侧推导刚得到 $-m/t$，$z$ 侧是逐字照抄的对照句，只改了不等号方向与 $\inf/\sup$，忘了把符号体系从 $f_i,m$ 换成 $\tilde{f}_i,\tilde{m}$——**哑指标与哑常数一起被复制，这是本类错误最典型的形态**。$m=\tilde{m}$ 的对称博弈（例如零和矩阵博弈里两侧都是单纯形）会让这个错误完全隐形。

对 $z$ 侧做同样的论证则得到正确的

```math
f_0\bigl(w^\star(t),z^\star(t)\bigr)\ge\sup_{z\in Z}f_0\bigl(w^\star(t),z\bigr)-\frac{\tilde{m}}{t},
```

与上一式相加即得

```math
\sup_{z\in Z}f_0\bigl(w^\star(t),z\bigr)-\inf_{w\in W}f_0\bigl(w,z^\star(t)\bigr)\le\frac{m+\tilde{m}}{t}.
```

<span style="color:#1e8449;">**[译注]** 上面那条 † 的教训可以抽成一条通用检查法：**任何形如「对称论证」的段落，先数两边的约束条数，再看常数是否跟着换**。这里 $w$ 侧是 $m$ 条、$z$ 侧是 $\tilde{m}$ 条，两侧不对称是问题本身自带的（题面就写了两个不同的符号），所以 $-m/t$ 与 $-\tilde{m}/t$ 不相等是常态，而写成同一个 $m$ 只在 $m=\tilde{m}$ 时侥幸正确。判据是形状而不是直觉：$\sum_i\lambda_if_i=\sum_i(-1/t)=-m/t$ 与 $\sum_i\tilde{\lambda}_i\tilde{f}_i=-\tilde{m}/t$ 这两个恒等式各自只有一个求和上界，上界不同，值就不同。

**量的方向感**：$(m+\tilde{m})/t$ 才是真正的「博弈 gap」，它随 $t$ 以 $1/t$ 收敛。要是拿 $\frac{m+m}{t}$ 代替，误差倍数就是 $\frac{2m}{m+\tilde{m}}$：$\tilde{m}=100m$ 时低估近 50 倍，$\tilde{m}=m$ 时恰好为 1（**这就是该错误极其常见的隐藏方式**）。

**消失测试**：没有这条界，你无法为「把 barrier method 用到博弈上」给出任何精度证书；有了它，$\sup-\inf$ 的 gap 与普通优化里的对偶 gap 是同一个量纲、同一种收敛速度，于是停止准则可以照抄。

**落点**：Boyd §5.4.3（convex-concave 的 minimax 不等式）、(11.12)（本题的第三式）、§11.2.2（$m/t$ 的标准推导）；挂 6.042J 的「双射与对称性论证：对称只保证形状相同，不保证常数相同」。</span>

### Exercise 11.13 · Self-concordance and negative entropy（自和谐性与负熵）

> 话题摘要：$x\log x$ 在 $\mathbf{R}_{++}$ 上**不是** self-concordant（$|f'''|/f''^{3/2}=1/\sqrt{x}$ 在 $0$ 附近无界）；但加上 $t x\log x-\log x$ 之后，同一个比值被压到 $\le2$，于是 self-concordant。

**(a) Show that the negative entropy function $x\log x$ (on $\mathbf{R}_{++}$) is not self-concordant.**

**(b) Show that for any $t\gt0$, $tx\log x-\log x$ is self-concordant (on $\mathbf{R}_{++}$).**

**Solution.**

**(a)** 先看 $f(x)=x\log x$，其导数为

```math
f'(x)=1+\log x,\qquad f''(x)=\frac{1}{x},\qquad f'''(x)=-\frac{1}{x^2} .
```

因此

```math
\frac{|f'''(x)|}{f''(x)^{3/2}}=\frac{1/x^2}{1/x^{3/2}}=\frac{1}{\sqrt{x}},
```

而它在 $x\to0^{+}$ 时上方无界。特别地，self-concordance 不等式 $|f'''|\le2f''^{3/2}$ 在 $x=1/5$ 处失效（此时 $1/\sqrt{1/5}=\sqrt5\approx2.236\gt2$），所以 $f$ 不是 self-concordant。

**(b)** 再看 $g(x)=tx\log x-\log x$，其导数为

```math
g'(x)=t+t\log x-\frac{1}{x},\qquad g''(x)=\frac{1}{x^2}+\frac{t}{x},\qquad g'''(x)=-\frac{2}{x^3}-\frac{t}{x^2}.
```

因此

```math
\frac{|g'''(x)|}{g''(x)^{3/2}}=\frac{2/x^3+t/x^2}{\bigl(1/x^2+t/x\bigr)^{3/2}}=\frac{2+tx}{(1+tx)^{3/2}} .
```

定义辅助函数

```math
h(a)=\frac{2+a}{(1+a)^{3/2}},
```

于是

```math
h(tx)=\frac{|g'''(x)|}{g''(x)^{3/2}} .
```

```math
\frac{|g'''(x)|}{g''(x)^{3/2}}\le2 .
```

计算导数：

```math

h'(a) &= \frac{(1+a)^{3/2}-(3/2)(1+a)^{1/2}(2+a)}{(1+a)^{3}}\\
```

对 $a\gt0$ 成立，于是证毕。

<span style="color:#1e8449;">**[译注]** 这两小问合起来说明了 self-concordance 的一个反直觉性质：**加一个 $-\log x$ 就能把 $x\log x$ 从「不是」修成「是」**，而且修好之后常数恰好贴着上界 $2$。机制在 $h$ 的两端：$a\to0$（即 $tx\to0$，对应 $t\to0$ 或 $x\to0$）时 $h\to2$，也就是**极限情形正好压线**；$a\to\infty$ 时 $h(a)\approx a/a^{3/2}=a^{-1/2}\to0$，惩罚项 $-\log x$ 在 $x$ 大时权重可忽略，于是「$x\log x$ 本来在 $x\to\infty$ 一侧也没问题」这一点被保住了。真正失守在 $x\to0$：$x\log x$ 的 $f''=1/x\to\infty$ 而 $f'''=-1/x^2\to-\infty$，比值 $x^{-1/2}$ 发散；$-\log x$ 的加入给出 $g''=1/x^2+t/x\approx1/x^2$、$g'''\approx-2/x^3$，比值 $\approx2$ —— **分母多了一个 $1/x$ 的幂次，正好压住分子的发散**。

**量的方向感**：$(2+tx)/(1+tx)^{3/2}$ 的最大值在 $tx=0$ 处取到、等于 $2$；$tx=1$ 时是 $3/2^{3/2}=1.0607$，只有峰值的一半；$tx=100$ 时是 $102/101^{1.5}\approx0.01005$，比峰值小两个数量级。所以「self-concordant 常数 $=2$」这个界在最坏点（$x\to0$）才紧，在 $x$ 大的区域极度保守——这解释了为什么基于 self-concordance 的复杂度界常被实测进度打得远高于理论预测。

**消失测试**：没有 self-concordance 这个概念，Newton 法的「二次收敛」就只能在「$x$ 已经足够靠近最优点」这种无法先验检查的假设下成立；有了它，收敛条件变成 $\lambda(x)\lt0.68$ 这类**可计算**的判据（$0.68$ 来自 self-concordance 常数为 $2$ 时的 damping 阈值），算法才可能自带保证。

**落点**：Boyd §9.6（self-concordant 函数的定义与 $\lambda(x)$）、§9.6.4（复杂度定理）、exercise 9.17（Hessian 的 nullspace 与 $x$ 无关）；挂 Thomson 实分析的「三阶导被二阶导的 $3/2$ 次幂控制」这一尺度不变性直觉。</span>

### Exercise 11.14 · Self-concordance and the centering problem（自和谐性与中心化问题）

> 话题摘要：若原问题的 sublevel set 有界、$tf_0+\phi$ 闭且 self-concordant，则 $t\nabla^2f_0(x)+\nabla^2\phi(x)\succ0$ 在 $\operatorname{\mathbf{dom}}\phi$ 上处处成立。

**Self-concordance and the centering problem.** Let $\phi$ be the logarithmic barrier function of problem (11.1). Suppose that the sublevel sets of (11.1) are bounded, and that $tf_0+\phi$ is closed and self-concordant. Show that $t\nabla^2f_0(x)+\nabla^2\phi(x)\succ0$, for all $x\in\operatorname{\mathbf{dom}}\phi$. *Hint.* See exercises 9.17 and 11.3.

**Solution.** 由 exercise 11.3，$tf_0+\phi$ 的 sublevel set 有界。由 exercise 9.17，$tf_0+\phi$ 的 Hessian 的 nullspace 与 $x$ 无关。于是若 Hessian 不正定，$tf_0+\phi$ 沿某些直线是线性的，这与「sublevel set 有界」矛盾。

<span style="color:#1e8449;">**[译注]** 这条结论是 barrier method 的**合法性前提**，而不是它的推论：Newton 步要求 $\nabla^2(tf_0+\phi)$ 可逆，若它在某个 $x$ 上只是半正定，Newton 方程就有无穷多解或没有解，方向搜索直接失败。论证链条两点：① exercise 11.3 给「sublevel set 有界」；② exercise 9.17 给「nullspace 不随 $x$ 变」。合起来的反证是：若有非零 $v$ 使 $H v=0$，则沿射线 $x+sv$ 上 $tf_0+\phi$ 是**一次函数**（二阶导恒为零、三阶也恒为零），于是这条射线上函数值不趋于 $+\infty$，sublevel set 沿该方向无界，矛盾。

**量的方向感**：注意「不正定」与「负定」是两件不同的事，结论只说 $\succ0$。若某方向上 $H$ 的特征值严格为负，函数沿该方向是 $-as$ 型发散，sublevel set 反而**有界**——所以反证只能排除「零特征值」，不能排除「负特征值」。这也解释了为什么前提里要 $tf_0+\phi$ **凸**（凸性排除负特征值）加上这一题（排除零特征值），两条合起来才是 $\succ0$。

**消失测试**：没有这条，你无法保证 centering 问题的解唯一且 Newton 步有定义；实践中表现为 Hessian 条件数爆炸、步长被 line search 压到 $10^{-10}$、迭代在某个 $x$ 附近停滞——你会误以为是「barrier 参数 $t$ 太小导致的数值病态」，其实是问题本身在该处不满足强凸性。

**落点**：Boyd §9.6.1（self-concordant 与闭性）、§11.2.1（$\phi$ 的定义）、exercise 9.17 / exercise 11.3（本题的两个前提）；挂 Strang 线代的「半正定 vs 正定：核空间非平凡则解不唯一」。</span>

### Exercise 11.15 · Generalized logarithm is K-increasing（generalized logarithm 是 $K$-增的）

> 话题摘要：若 $y\succ_K0$，则 $\nabla\psi(y)\succeq_{K^*}0$；进一步，由 $\nabla^2\psi(y)\prec0$ 与非奇异性推出 $\nabla\psi(y)\succ_{K^*}0$。

**Generalized logarithm is K-increasing.** Let $\psi$ be a generalized logarithm for the proper cone $K$. Suppose $y\succ_K0$.

**(a) Show that $\nabla\psi(y)\succeq_{K^*}0$, i.e., that $\psi$ is $K$-nondecreasing.** *Hint.* If $\nabla\psi(y)\not\succeq_{K^*}0$, then there is some $w\succ_K0$ for which $w^T\nabla\psi(y)\le0$. Use the inequality $\psi(sw)\le\psi(y)+\nabla\psi(y)^T(sw-y)$, with $s\gt0$.

**Solution.** **(a)** 若 $\nabla\psi(y)\not\succeq_{K^*}0$，则存在 $w\succ_K0$ 使 $w^T\nabla\psi(y)\le0$。由 $\psi$ 的凹性有

```math
\begin{aligned}
\psi(sw) &\le \psi(y)+\nabla\psi(y)^T(sw-y)\\
&= \psi(y)-\theta+s\,w^T\nabla\psi(y)\\
&\le \psi(y)-\theta
\end{aligned}
```

对一切 $s\gt0$ 成立，其中用了 $\nabla\psi(y)^Ty=\theta$。特别地，$\psi(sw)$ 在 $s\ge0$ 上有界。但另一方面 $\psi(sw)=\psi(w)+\theta\log s$，当 $s\to\infty$ 时无界。（这里需要 $w\succ_K0$ 来保证 $sw\in\operatorname{\mathbf{dom}}\psi$。）矛盾。故 $\nabla\psi(y)\succeq_{K^*}0$。

### Exercise 11.16 · Properties of a generalized logarithm（generalized logarithm 的四条恒等式）

> 话题摘要：对 degree 为 $\theta$ 的 generalized logarithm，在 $y\succ_K0$ 处有 $\nabla\psi(sy)=\nabla\psi(y)/s$、$\nabla\psi(y)=-\nabla^2\psi(y)y$、$y^T\nabla^2\psi(y)y=-\theta$、$\nabla\psi(y)^T\nabla^2\psi(y)^{-1}\nabla\psi(y)=-\theta$。

**[NN94, page 41] Properties of a generalized logarithm.** Let $\psi$ be a generalized logarithm for the proper cone $K$, with degree $\theta$. Prove that the following properties hold at any $y\succ_K0$.

**(a) $\nabla\psi(sy)=\nabla\psi(y)/s$ for all $s\gt0$.**

**(b) $\nabla\psi(y)=-\nabla^2\psi(y)y$.**

**(c) $y^T\nabla^2\psi(y)y=-\theta$.**

**(d) $\nabla\psi(y)^T\nabla^2\psi(y)^{-1}\nabla\psi(y)=-\theta$.**

**Solution.** **(a)** 对 $\psi(sy)=\psi(y)+\theta\log s$ 关于 $y$ 求导，得 $s\nabla\psi(sy)=\nabla\psi(y)$，即 $\nabla\psi(sy)=\nabla\psi(y)/s$。

**(b)** 对恒等式 $(y+tv)^T\nabla\psi(y+tv)=\theta$ 关于 $t$ 求导，得

```math
\nabla\psi(y+tv)^Tv+(y+tv)^T\nabla^2\psi(y+tv)v=0 .
```

在 $t=0$ 处取值得

```math
\nabla\psi(y)^Tv+y^T\nabla^2\psi(y)v=0 .
```

它对一切 $v$ 成立，故 $\nabla\psi(y)=-\nabla^2\psi(y)y$。

**(c)** 由 (b) 得

```math
y^T\nabla^2\psi(y)y=-y^T\nabla\psi(y)=-\theta .
```

**(d)** 仍由 (b) 得

```math
\nabla\psi(y)^T\nabla^2\psi(y)^{-1}\nabla\psi(y)=-\nabla\psi(y)^Ty=-\theta .
```

<span style="color:#1e8449;">**[译注]** 这四条不是四个孤立事实，它们是同一个「degree」的四种读数，而且 (c)(d) 一起说明了一件结构性的事实：**$\nabla^2\psi(y)$ 在 $y$ 方向上的二次型恒为 $-\theta$，与 $y$ 的具体位置无关**。由于 $\psi$ 凹，$\nabla^2\psi\prec0$，所以 $y^T(-\nabla^2\psi)y=\theta$ 是一个**常数**——换句话说，Hessian 沿 $y$ 方向的「负曲率」被钉死在 $\theta$ 上。

**量的方向感**：以二阶锥为例，$\psi(y)=\log\bigl(y_{n+1}^{2}-\|y_{1:n}\|^{2}\bigr)$，$\theta=2$。取锥轴上的单位点 $y=(0,1)$：直接算得 $\nabla\psi(y)=(0,2)$ 与

```math
\nabla^{2}\psi(y)=\begin{bmatrix}-2&0\\0&-2\end{bmatrix},
```

于是

```math
y^{T}\nabla^{2}\psi(y)y=(0,1)\begin{bmatrix}-2&0\\0&-2\end{bmatrix}(0,1)^{T}=-2=-\theta ,
```

而 (d) 给出 $\nabla\psi(y)^{T}\nabla^{2}\psi(y)^{-1}\nabla\psi(y)=(0,2)\begin{bmatrix}-1/2&0\\0&-1/2\end{bmatrix}(0,2)^{T}=-2=-\theta$ ✓。**这个验算必须避开 $y$ 各分量都为 $1$ 的点**：那里 $\theta=2$ 与数值 $2$ 会巧合重合，把 Hessian 的符号错完全盖掉。

**消失测试**：没有 (b)，你无法把 $\nabla\psi(y)$ 换成 $-\nabla^2\psi(y)y$，于是 §11.6 中「$K$-increasing」的证明、以及 dual generalized logarithm 的所有性质都推不动；(d) 则是把 $\nabla\psi^T(-\nabla^2\psi)^{-1}\nabla\psi$ 解释成「$K$-相关的 Newton decrement」的唯一依据，缺了它，$K$-barrier 版本的收敛性分析无从下手。

**落点**：Boyd §11.6.1（generalized logarithm 的公理化定义、(11.49) 附近）、[NN94] p.41（Nesterov–Nemirovski 的原始表述）、exercise 11.15（(a)(b) 的前提）；挂 Strang 线代的「二次型沿特定方向的取值与基无关」。</span>

### Exercise 11.17 · Dual generalized logarithm（对偶 generalized logarithm 的 degree）

> 话题摘要：对偶 generalized logarithm $\psi_*$ 定义为 $\psi_*(v)=\inf_u\bigl(v^Tu-\psi(u)\bigr)$，它也满足 $\psi_*(sv)=\psi_*(v)+\theta\log s$，degree 与 $\psi$ 相同。

**Dual generalized logarithm.** Let $\psi$ be a generalized logarithm for the proper cone $K$, with degree $\theta$. Show that the dual generalized logarithm $\psi_*$, defined in (11.49), satisfies

```math
\psi_*(sv)=\psi_*(v)+\theta\log s,
```

for $v\succ_{K^*}0$, $s\gt0$.

**Solution.** 由定义

```math
\psi_*(sv)=\inf_u\bigl(sv^Tu-\psi(u)\bigr)=\inf_{\tilde{u}}\bigl(v^T\tilde{u}-\psi(\tilde{u}/s)\bigr),
```

其中做了换元 $\tilde{u}=su$。再用 $\psi$ 的对数性质 $\psi(\tilde{u}/s)=\psi(\tilde{u})-\theta\log s$，得

```math
\psi_*(sv)=\inf_{\tilde{u}}\bigl(v^T\tilde{u}-\psi(\tilde{u})\bigr)+\theta\log s=\psi_*(v)+\theta\log s .
```

<span style="color:#1e8449;">**[译注]** 换元那一步值得单独看：$\inf_u\bigl(sv^Tu-\psi(u)\bigr)$ 里 $u$ 与 $s$ 是**乘性纠缠**的，直接对 $s$ 求导拿不到干净结果；令 $\tilde u=su$ 之后，$s$ 从 $u$ 的尺度里被剥离，只剩在 $\psi$ 的宗量里，而 $\psi$ 的「准齐次性」$\psi(\tilde u/s)=\psi(\tilde u)-\theta\log s$ 正好把这个 $\log s$ 提出来。**这就是 degree 的全部技术用途：它是 $\psi$ 在伸缩下的唯一非齐次项。**

**量的方向感**：$\theta$ 在 $\psi$ 与 $\psi_*$ 上相同，不是巧合而是必然——因为 $(K,\psi)$ 与 $(K^*,\psi_*)$ 的对偶关系是对称的（$\psi_{**}=\psi$）。若你算出两个不同的 degree，一定是换元时把 $\log s$ 的系数搞错了：$\psi(su)$ 的系数是 $+\theta\log s$，而 $\psi(u/s)=\psi(u)-\theta\log s$，两者符号相反。数值验算：取一维 $K=\mathbf{R}_{++}$、$\psi(u)=\theta\log u$（$\theta=1$），则 $\psi_*(v)=\inf_u(vu-\log u)$。对 $v\lt0$，极值在 $u=1/v$ 处，$\psi_*(v)=1-\log(1/v)=1+\log v$（$v\lt0$ 时用 $|v|$ 写更清楚）。验 $\psi_*(sv)=1+\log(s|v|)=\psi_*(v)+\log s$ ✓ 系数为 $1=\theta$ ✓。

**消失测试**：没有这条，dual generalized logarithm 就不是「generalized logarithm」——degree 是定义的一部分，缺了它 §11.6 的对偶 barrier 无法与 primal 侧配对，generalized-inequality 版本的 barrier method 的复杂度分析（步数与 $\theta$ 成正比）就无从写起。

**落点**：Boyd §11.6.1（(11.49) 对偶 generalized logarithm 的定义）、§3.3（共轭函数与对偶锥）、exercise 11.16（primal 侧的四条恒等式）；挂 Strang 线代的「对偶空间上的二次型与 primal 的对应」。</span>

### Exercise 11.18 · 一个「几乎」是 generalized logarithm 的函数

> 话题摘要：$\psi(y)=\log\bigl(y_{n+1}-\sum_i y_i^2/y_{n+1}\bigr)$ 满足 generalized logarithm 除 **closedness** 之外的全部条件，因此它不是二阶锥的 generalized logarithm。

**Is the function**

```math
\psi(y)=\log\left(y_{n+1}-\frac{\sum_{i=1}^{n}y_i^2}{y_{n+1}}\right),
```

```math
(y_1,\dots,y_n)=\sqrt{t(t-a)/n},\qquad y_{n+1}=t
```

**落点**：Boyd §11.6.1（generalized logarithm 的五条公理，closedness 是其中之一）、§3.3（proper cone 与内点）、exercise 11.16/11.17（其余四条它都满足）；挂 Thomson 实分析的「闭函数：沿收敛序列的上极限不超过函数值」。</span>

### Exercise 11.19 · Yet another method for computing the Newton step（Newton 步的另一种算法）

> 话题摘要：把 (11.14) 的 $n\times n$ 系统扩大成 $(n+m+p)\times(n+m+p)$ 的 $3\times3$ 分块系统，第二行解出 $y$、第三行给出 $A\Delta x=0$，代回第一行即还原 (11.14)。

**Yet another method for computing the Newton step.** Show that the Newton step for the barrier method, which is given by the solution of the linear equations (11.14), can be found by solving a larger set of linear equations with coefficient matrix

```math
\begin{bmatrix}
t\nabla^2f_0(x)+\sum_{i}\frac{1}{-f_i(x)}\nabla^2f_i(x) & Df(x)^T & A^T\\
Df(x) & -\mathbf{diag}\bigl(f(x)\bigr)^{2} & 0\\
A & 0 & 0
\end{bmatrix}
```

where $f(x)=\bigl(f_1(x),\dots,f_m(x)\bigr)$. For what types of problem structure might solving this larger system be interesting?

**Solution.** 该系统的右端取 $\bigl(-g,\,0,\,0\bigr)$，其中 $g=t\nabla f_0(x)+\nabla\phi(x)$：

```math
\begin{bmatrix}
t\nabla^2f_0(x)+\sum_{i}\frac{1}{-f_i(x)}\nabla^2f_i(x) & Df(x)^T & A^T\\
Df(x) & -\mathbf{diag}\bigl(f(x)\bigr)^{2} & 0\\
A & 0 & 0
\end{bmatrix}
\begin{bmatrix}
\Delta x_{\mathrm{nt}}\\ y\\ \nu_{\mathrm{nt}}
\end{bmatrix}
=
\begin{bmatrix}
-g\\ 0\\ 0
\end{bmatrix}.
```

由第二行得

```math
y_i=\frac{\nabla f_i(x)^T\Delta x_{\mathrm{nt}}}{f_i(x)^{2}},
```

代回第一行就得到 (11.14)。（第三行给出 $A\Delta x_{\mathrm{nt}}=0$，正是等式约束的线性化。）

这个扩大系统可能有用的情形是：**大矩阵稀疏，而按 $\mathbf{diag}(f(x))^{2}$ 块做 pivoting 得到的 $2\times2$ 分块系统却有一个稠密的 $(1,1)$ 块**。例如大系统的 $(1,1)$ 块是分块对角、$m\ll n$ 很小、且 $Df(x)$ 稠密时——此时直接消元会把稠密性灌进 Hessian，而稀疏直接法（如稀疏 Cholesky 配最小度排序）反而更快。

<span style="color:#1e8449;">**[译注]** 这道题教的是「**把 Schur complement 的方向反过来用**」。标准做法消去 $\Delta x$，剩下 $m\times m$ 的稠密系统（$m$ 小时最优）；这里反过来保留 $\Delta x$、消去 $y$，把系统维持成大而稀疏的形状，交给**稀疏直接法**。两条路的代价对比可算：消元路线是 $O(n^{3}+n^{2}m)$ 加一次分解，其中 $S=t\nabla^{2}f_0+\nabla^{2}\phi+Df^{T}\mathbf{diag}(f)^{-2}Df$；稀疏路线是 $O(\mathrm{nnz})$ 量级但常数大、且取决于排序质量。

**量的方向感**：分界点在「$m$ 与 $n$ 的比值」与「$Df$ 的稀疏度」。$m=10$、$n=10^{5}$、$Df$ 每行只有 $3$ 个非零时，消元路线要构造 $m\times m$ 稠密块（$100$ 个元，可忽略），但**求解 $S\Delta x$ 需要 $n\times n$ 分解**，代价 $10^{15}$；稀疏路线只有 $\mathrm{nnz}\sim3\times10^{5}$ 个元，代价线性。相反 $m=n=10^{4}$ 且 $Df$ 稠密时，两条约在 $10^{12}$ 打平——所以「$m\ll n$」是这条替代路线成立的必要条件，题目里那句 "and $Df(x)$ is dense" 正是在排除 $Df$ 本身稀疏（那时 $2\times2$ 系统也是稀疏的）的情形。

**消失测试**：不知道这条路，面对「$m\ll n$、Hessian 稠密、$Df$ 稠密」的结构只能硬做 $n\times n$ 分解，实际跑不动；知道了以后，同一个问题变成「$m$ 维稠密 + 稀疏 $3\times3$ 分块」，规模下一个量级。

**落点**：Boyd §11.3（(11.14) 的 Newton 系统）、§11.8.4（稀疏性与矩阵求逆引理）、附录 C.4（稀疏矩阵直接法）；挂 6.006 的「稀疏表示与 nnz 传播」、CSAPP 的「局部性：稀疏存储把 cache miss 从 $n^{2}$ 降到 nnz」。</span>

### Exercise 11.20 · Network rate optimization via the dual problem（用对偶问题解网络速率优化）

> 话题摘要：对网络效用最大化 (11.62) 取对偶，得到只含 $n$ 个变量的问题 $\min\ c^T\lambda+\sum_i V_i\bigl(-(A^T\lambda)_i\bigr)$、$\lambda\succeq0$；Hessian 是「对角 + $A\mathbf{diag}(\cdot)A^T$」的形状，两个稀疏方向分别对应两种求逆策略。

**Network rate optimization via the dual problem.** In this problem we examine a dual method for solving the network rate optimization problem of §11.8.4. To simplify the presentation we assume that the utility functions $U_i$ are strictly concave, with $\operatorname{\mathbf{dom}}U_i=\mathbf{R}_{++}$, and that they satisfy $U_i'(x_i)\to\infty$ as $x_i\to0$ and $U_i'(x_i)\to0$ as $x_i\to\infty$.

**(a) Express the dual problem of (11.62) in terms of the conjugate utility functions $V_i=(-U_i)^\ast$, defined as**

```math
V_i(\lambda)=\sup_{x\gt0}\bigl(\lambda x+U_i(x)\bigr).
```

**Show that $\operatorname{\mathbf{dom}}V_i=-\mathbf{R}_{++}$, and that for each $\lambda\lt0$ there is a unique $x$ with $U_i'(x)=-\lambda$.**

**(b) Describe a barrier method for the dual problem. Compare the complexity per iteration with the complexity of the method in §11.8.4. Distinguish the same two cases as in §11.8.4 ($A^TA$ is sparse and $AA^T$ is sparse).**

<!-- ===== p292 ===== -->

> 页眉：`11 Interior-point methods`。本页是 11.20(a)(b) 的解答与 11.21 题干开头。

**Solution.**

**(a)** 设 $\lambda\lt0$。因为 $U_i$ 严格凹且递增、并满足 $U_i'(x_i)\to\infty$（$x_i\to0$）与 $U_i'(x_i)\to0$（$x_i\to\infty$），存在唯一的 $x$ 使

```math
U_i'(x)=-\lambda .
```

改写问题 (11.62) 后，其 Lagrangian 是

```math
\begin{aligned}
L(x,\lambda,z) &= \sum_{i=1}^{n}\bigl(-U_i(x)\bigr)+\lambda^{T}(Ax-c)-z^{T}x\\
&= -\sum_{i=1}^{n}U_i(x)-\bigl(A^{T}\lambda\bigr)_i x_i+z_i x_i-c^{T}\lambda .
\end{aligned}
```

对 $x$ 取下确界：

```math
\begin{aligned}
\inf_x L(x,\lambda,z) &= \inf_x\left(-\sum_{i=1}^{n}\bigl(U_i(x)-(A^{T}\lambda)_i x_i+z_i x_i\bigr)-c^{T}\lambda\right)\\
&= -\sum_{i=1}^{n}\sup_x\bigl(U_i(x)-(A^{T}\lambda)_i x_i+z_i x_i\bigr)-c^{T}\lambda\\
&= -\sum_{i=1}^{n}V_i\bigl(-(A^{T}\lambda)_i+z_i\bigr)-c^{T}\lambda,
\end{aligned}
```

所以对偶问题（再改一次符号）是

```math
\begin{array}{ll}
\text{minimize} & c^{T}\lambda+\sum_{i=1}^{n}V_i\bigl(-(A^{T}\lambda)_i+z_i\bigr)\\
\text{subject to} & \lambda\succeq0,\quad z\succeq0 .
\end{array}
```

由于 $V_i$ 在其定义域 $-\mathbf{R}_{++}$ 上递增，最优时 $z=0$，于是对偶问题化简为

```math
\begin{array}{ll}
\text{minimize} & c^{T}\lambda+\sum_{i=1}^{n}V_i\bigl(-(A^{T}\lambda)_i\bigr)\\
\text{subject to} & \lambda\succeq0 .
\end{array}
```

这里 $-\lambda_i$ 可以解释为链路 $i$ 上的**价格**，而 $-(A^{T}\lambda)_i$ 是第 $i$ 条流所经路径上价格之和。

**(b)** 函数

```math
t\left(c^{T}\lambda+\sum_{i=1}^{n}V_i\bigl(-(A^{T}\lambda)_i\bigr)\right)-\sum_{i}\log\lambda_i
```

的 Hessian 是

```math
H=tA\,\mathbf{diag}\bigl(V_i''(-(A^{T}\lambda)_i)\bigr)A^{T}+\mathbf{diag}(\lambda)^{-2}.
```

若 $AA^{T}$ 稀疏，就直接求解 Newton 方程 $H\Delta\lambda=-g$；若 $A^{T}A$ 稀疏，则应用 matrix inversion lemma（矩阵求逆引理），把 Newton 步化为先解一个系数矩阵形如 $D_1+A^{T}D_2A$ 的方程，其中 $D_1,D_2$ 为对角阵（见 §11.8.4）。原文此处把第一个分块印成 $\mathbf{diag}\bigl(-A^{T}\lambda\bigr)^{-2}$，那是错的，见下。

<span style="color:#d35400;">**† 原文错误（本页第 1 处）**：Hessian 的第一个分块应写成 $\mathbf{diag}\bigl(V_i''(-(A^{T}\lambda)_i)\bigr)$，**原文印成 $\mathbf{diag}\bigl(-A^{T}\lambda\bigr)^{-2}$**。后者只在**效用函数取对数**（$U_i(x)=\log x$，此时 $V_i(\lambda)=-1-\log(-\lambda)$、$V_i''(\lambda)=1/\lambda^{2}$）时巧合成立。

**可手算反例**：取 $U_i(x)=\sqrt{x}$（严格凹、递增，$U'\to\infty$ 于 $0$、$U'\to0$ 于 $\infty$，满足题设全部条件）。由 $U'(x)=1/(2\sqrt{x})=-\lambda$ 得 $x=1/(4\lambda^{2})$，于是 $V_i''(\lambda)=\mathrm{d}x/\mathrm{d}\lambda=1/(2|\lambda|^{3})$。取 $\lambda=-1$：真值 $1/2$，原文给 $1$，**差 2 倍**；取 $\lambda=-2$：真值 $1/16=0.0625$，原文 $0.25$，**差 4 倍**——偏差随 $|\lambda|$ 增大。

**为什么会写错**：$V_i$ 由 $U_i$ 隐式定义（通过 $U_i'(x)=-\lambda$），其二阶导 $V_i''=-1/U_i''(x(\lambda))$ 依赖 $U_i$ 的具体形式，不能从 $-\lambda$ 直接读出来。作者心里想的是网络效用最大化的标准例子 $\sum\log x_i$，于是把 log 特例的 $V_i''$ 当成了通式。**这是「单位尺度把错误盖住」的一个变体：特例恰是教科书里最常用的那个，所以错误从不显形。**

**(b) 的其余部分与复杂度结论正确**：若 $AA^{T}$ 稀疏（链路少、路径多），$H$ 是「对角加稀疏」，直接分解；若 $A^{T}A$ 稀疏（路径少、链路多），用 Woodbury 恒等式把 Newton 步化成 $D_1+A^{T}D_2A$ 的求解。

<span style="color:#1e8449;">**[译注]** 这条 † 的教学价值在于它揭示了「共轭函数」一个易被忽略的性质：**$V_i=(-U_i)^\ast$ 的二阶导不是 $\lambda$ 的普适函数，而是「$U_i$ 的曲率在 $x(\lambda)$ 处的倒数」**。链式法则写清楚：$U_i'(x)=-\lambda$ 两边对 $\lambda$ 求导得 $U_i''(x)x'(\lambda)=-1$，故

```math
V_i''(\lambda)=x'(\lambda)=-\frac{1}{U_i''\bigl(x(\lambda)\bigr)}\gt0 .
```

**量与方向感**：$V_i''$ 与 $U_i''$ 严格成反比。log 效用 $U_i''=-1/x^{2}$ 给 $V_i''=x^{2}=1/\lambda^{2}$；$\sqrt{x}$ 给 $U_i''=-1/(4x^{3/2})$、$V_i''=1/(2|\lambda|^{3})$；一般的 $U_i=-x^{-\gamma}$ 族给 $V_i''\propto|\lambda|^{-(1+2\gamma)/(1+\gamma)}$，指数随 $\gamma$ 变。所以 (b) 的 Hessian **是数据相关的**，写死成 $(-A^{T}\lambda)^{-2}$ 等于替用户选了 log 效用——这会让牛顿方向错，但**不会让代码崩**：Hessian 仍正定，收敛照样发生，只是从二次收敛退化为线性。

**消失测试**：照抄 $(-A^{T}\lambda)^{-2}$，在非 log 效用的实例上你会看到 Newton decrement 的平方每次只降一个常数因子而非平方级下降；诊断时极易误判为「$t$ 不够大」，实际是 Hessian 错了。判别只需一行：用一维实例数值验 $V_i''$ 与 $1/\lambda^{2}$ 是否相符。

**落点**：Boyd §11.8.4（网络速率优化的 primal 版本）、§3.3.1（共轭函数与 Fenchel 不等式）、附录 C.4.3（matrix inversion lemma）；挂 Strang 线代的「反函数的导数与原函数导数互为倒数」。</span>

### Exercise 11.21 · Log-Chebyshev approximation with bounds（带变量界的分式 Chebyshev 近似）

> 话题摘要：在 $l\preceq x\preceq u$、$Ax\succ0$ 下最小化**最大分数偏差** $\max\bigl\{\max_i a_i^{T}x/b_i,\ \max_i b_i/(a_i^{T}x)\bigr\}$；引入 $s$ 后是 $3m+2n$ 条标量约束的凸问题，配 barrier 与 MATLAB 实现。

**Log-Chebyshev approximation with bounds.** We consider an approximation problem: find $x\in\mathbf{R}^{n}$, that satisfies the variable bounds $l\preceq x\preceq u$, and yields $Ax\approx b$, where $b\in\mathbf{R}^{m}$. You can assume that $l\prec u$, and $b\succ0$ (for reasons we explain below). We let $a_i^{T}$ denote the $i$th row of the matrix $A$.

We judge the approximation $Ax\approx b$ by the maximum fractional deviation, which is

```math
\max\left\{\max_{i=1,\dots,m}\frac{a_i^{T}x}{b_i},\ \max_{i=1,\dots,m}\frac{b_i}{a_i^{T}x}\right\},
```

when $Ax\succ0$; we define the maximum fractional deviation as $\infty$ if $Ax\not\succ0$. The problem of minimizing the maximum fractional deviation is called the fractional Chebyshev approximation problem（分式 Chebyshev 近似问题）, or the logarithmic Chebyshev approximation problem, since it is equivalent to minimizing the objective

```math
\max_{i=1,\dots,m}\bigl|\log a_i^{T}x-\log b_i\bigr|.
```

(See also exercise 6.3, part (c).)

**(a) Formulate the fractional Chebyshev approximation problem (with variable bounds) as a convex optimization problem with twice differentiable objective and constraint functions.**

**(b) Implement a barrier method that solves the fractional Chebyshev approximation problem. You can assume an initial point $x^{(0)}$, satisfying $l\prec x^{(0)}\prec u$, $Ax^{(0)}\succ0$, is known.**

**Solution.**

**(a)** 带变量界的分式 Chebyshev 近似问题可以写成

```math
\begin{array}{ll}
\text{minimize} & s\\
\text{subject to} & (a_i^{T}x)/b_i\le s,\qquad i=1,\dots,m\\
& b_i/(a_i^{T}x)\le s,\qquad i=1,\dots,m\\
& a_i^{T}x\ge0,\qquad i=1,\dots,m\\
& l\preceq x\preceq u .
\end{array}
```

这显然是凸问题：除第二组不等式含倒数之外，其余全部线性。sublevel set 由最后一组约束保证有界。注意不失一般性可取 $b_i=1$ 并把 $a_i$ 换成 $a_i/b_i$；下面假定已完成这一步，且仍用 $a_i$ 表示缩放后的（即原数据里的 $a_i/b_i$）。

**(b)** 在 centering 问题里需要极小化

```math
\begin{aligned}
ts+\phi(s,x) &= ts-\sum_{i=1}^{m}\log\bigl(s-a_i^{T}x\bigr)-\sum_{i=1}^{m}\log a_i^{T}x-\sum_{i=1}^{m}\log\bigl(s-1/a_i^{T}x\bigr)\\
&\qquad -\sum_{i=1}^{n}\log(u_i-x_i)-\sum_{i=1}^{n}\log(x_i-l_i)\\
&= \phi_1(s,x)+\phi_2(s,x)+\phi_3(s,x),
\end{aligned}
```

变量为 $x,s$，其中

```math
\begin{aligned}
\phi_1(s,x) &= ts-\sum_{i=1}^{n}\log(u_i-x_i)-\sum_{i=1}^{n}\log(x_i-l_i),\\
\phi_2(s,x) &= -\sum_{i=1}^{m}\log\bigl(s-a_i^{T}x\bigr),\\
\phi_3(s,x) &= -\sum_{i=1}^{m}\log\bigl(s(a_i^{T}x)-1\bigr).
\end{aligned}
```

上面两组的对应关系是：$\phi_2+\phi_3$ 合起来等于中间那三项，因为

```math
-\log\bigl(s-1/a_i^{T}x\bigr)-\log\bigl(a_i^{T}x\bigr)=-\log\bigl(s\,a_i^{T}x-1\bigr).
```

<span style="color:#1e8449;">**[译注]** 这个「三项并两项」的恒等式是本题最容易看漏的地方，也是全书的通用模式：**当一条约束 $g(x)\ge0$ 有两种等价写法时，barrier 会差一个 $\log$；只要约束集合完整，差值必然被另一条约束的 barrier 吸收**。（同一手法在 p281 的 11.5(a) 出现过：那里 $\log(c_i^{T}x+d_i)$ 被非负约束的 barrier 抵掉。）

**量与方向感**：$\phi_3=-\sum\log(sa_i^{T}x-1)$ 与「$\phi_2$ 加两个独立 $\log$」相比，**少一次 $\log$、多一次乘法的非线性**。这直接决定 Hessian 形状：$\phi_3$ 的 Hessian 有一个 $s^{2}A^{T}\mathbf{diag}(\cdot)A$ 的块（见下页），若按三项写就会得到两个独立 $A^{T}\mathbf{diag}(\cdot)A$ 块相加——数学等价，但**条件数差一个量级**，因为后者把 $s$ 的依赖摊到两个几乎抵消的块上。

**消失测试**：不做合并也能写出「正确但难算」的 barrier，Newton 系统规模不变而条件数恶化；更糟的是当 $s\approx1/a_i^{T}x$（某约束将激活）时两个大块相减，出现灾难性抵消，数值表现为 Newton 方向乱跳而目标值几乎不降。

**落点**：Boyd §11.3（barrier 与等价约束形式的选取）、exercise 6.3(c)（log-Chebyshev 与 $\ell_\infty$ 的关系）、p281（11.5(a) 的同型恒等式）；挂 Thomson 实分析的「等价变换改变数值行为而不改变极限」。</span>

```math
\nabla\phi_2(s,x)=\begin{bmatrix} -\mathbf{1}^{T}\mathbf{diag}(s-Ax)^{-1}\mathbf{1}\\ A^{T}\mathbf{diag}(s-Ax)^{-1}\mathbf{1}\end{bmatrix},
```

```math
h(s,y)=-\sum_{i=1}^{m}\log\bigl(sy_i-1\bigr).
```

$h$ 的梯度与 Hessian 是

```math
\nabla h(s,y)=\begin{bmatrix} -\sum_{i=1}^{m}y_i/(sy_i-1)\\ -s/(sy_1-1)\\ \vdots\\ -s/(sy_m-1)\end{bmatrix},
```

以及

```math
\nabla^2h(s,y)=\begin{bmatrix}
\sum_i y_i^{2}/(sy_i-1)^{2} & 1/(sy_1-1)^{2} & \cdots & 1/(sy_m-1)^{2}\\
1/(sy_1-1)^{2} & s^{2}/(sy_1-1)^{2} & & 0\\
\vdots & & \ddots & \vdots\\
1/(sy_m-1)^{2} & 0 & & s^{2}/(sy_m-1)^{2}
\end{bmatrix}.
```

等价的紧凑写法是

```math
\nabla^2h(s,y)=\begin{bmatrix}
y^{T}\mathbf{diag}(sy-1)^{-2}y & \mathbf{1}^{T}\mathbf{diag}(sy-1)^{-2}\\
\mathbf{diag}(sy-1)^{-2}\mathbf{1} & s^{2}\mathbf{diag}(sy-1)^{-2}
```

```math
\nabla\phi_3(s,x)=\begin{bmatrix}1 & 0\\ 0 & A^{T}\end{bmatrix}\nabla h(s,Ax)=-\begin{bmatrix} y^{T}\mathbf{diag}(sAx-1)^{-1}\mathbf{1}\\ sA^{T}\mathbf{diag}(sAx-1)^{-1}\mathbf{1}\end{bmatrix},
```

```math

\nabla^2\phi_3(s,x) &= \begin{bmatrix}1 & 0\\ 0 & A^{T}\end{bmatrix}\nabla^2h(s,Ax)\begin{bmatrix}1 & 0\\ 0 & A\end{bmatrix}\\

\end{bmatrix}.
\end{aligned}
```

<span style="color:#1e8449;">**[译注]** 这一页全是机械的链式法则，但**形状配平**是唯一能自检的手段，值得把尺寸写死：$h:\mathbf{R}\times\mathbf{R}^{m}\to\mathbf{R}$，故 $\nabla h\in\mathbf{R}^{m+1}$、$\nabla^{2}h\in\mathbf{S}^{m+1}$；而 $\begin{bmatrix}1&0\\0&A\end{bmatrix}$ 是 $1+m$ 行、$1+n$ 列，于是 $\nabla^{2}\phi_3\in\mathbf{S}^{1+n}$、$\nabla\phi_3\in\mathbf{R}^{1+n}$。若你纸上得到 $\mathbf{R}^{1+m}$ 的梯度，必定是 $\begin{bmatrix}1&0\\0&A\end{bmatrix}$ 与 $\begin{bmatrix}1&0\\0&A^{T}\end{bmatrix}$ 放反了——这错在 $m=n$ 时**完全隐形**，而本题 $m$ 是 $A$ 的行数、$n$ 是 $x$ 的维数，一般不相等。

**落点**：Boyd §11.3（barrier 的梯度/Hessian）、附录 A.4.3（链式法则与矩阵微分）、exercise 11.21(b)（本题的 MATLAB 实现）；挂 Strang 线代的「分块矩阵乘与维数配平」。</span>

MATLAB 实现如下。

```matlab
MAXITERS = 200;
ALPHA = 0.01;
BETA = 0.5;
NTTOL = 1e-8;   % terminate Newton iterations if lambda^2 < NTTOL
MU = 20;
TOL = 1e-4;     % terminate if duality gap less than TOL

x = x0;  y = A*x;  s = 1.1*max([max(A*x), max(1./y)]);
t = 1;
for iter = 1:MAXITERS
   val = t*s - sum(log(u-x)) - sum(log(x-l)) - sum(log(s-y)) - ...
         sum(log(s*y-1));
   grad = [t-sum(1./(s-y))-sum(y./(s*y-1));
           1./(u-x)-1./(x-l)+A'*(1./(s-y)-s./(s*y-1))];
   hess = [sum((s-y).^(-2)+(y./(s*y-1)).^2)  ...
                  (-(s-y).^(-2) + (s*y-1).^(-2))'*A;
            A'*(-(s-y).^(-2) + (s*y-1).^(-2)) ...
            diag((u-x).^(-2) + (x-l).^(-2)) + ...
                A'*(diag((s-y).^(-2)+(s./(s*y-1)).^2))*A];
   step = -hess\grad;  fprime = grad'*step;
   if (abs(fprime) < NTTOL),
      gap = (3*m+2*n)/t;
      if (gap<TOL); break; end;
      t = MU*t;
   else
      ds = step(1);  dx = step(1+[1:n]);  dy = A*dx;
      tls = 1;
      news = s+tls*ds;  newx = x+tls*dx;  newy = y+tls*dy;
      while (min([news-newy; news-1./newy; newy; newx-l; u-newx]) <= 0),
         tls = BETA*tls;
         news = s+tls*ds;  newx = x+tls*dx;  newy = y+tls*dy;
      end;
      newval = t*news - sum(log(u-newx)) - sum(log(newx-l)) ...
               - sum(log(news-newy)) - sum(log(news*newy-1));
      while (newval >= val + tls*ALPHA*fprime),
         tls = BETA*tls;
         news = s+tls*ds;  newx = x+tls*dx;  newy = y+tls*dy;
         newval = t*news - sum(log(u-newx)) - sum(log(newx-l)) ...
              - sum(log(news-newy)) - sum(log(news*newy-1));
      end;
      x = x+tls*dx;  y = A*x;  s = s+tls*ds;
   end;
end;
```

<span style="color:#1e8449;">**[译注]** 这段代码里最值得注意的不是 Newton 步，而是两处 `while` 循环——**backtracking line search 必须先保可行、再降函数值**，顺序不能换。第一条 `while` 检查严格可行性（$s-y\gt0$、$sy-1\gt0$、$y\gt0$、$x-l\gt0$、$u-x\gt0$ 五个条件一次算完），第二条才检查 Armijo 条件 $f(x+t\Delta x)\le f(x)+\alpha t\nabla f^{T}\Delta x$。

**量的方向感**：`gap = (3*m+2*n)/t` 这个系数等于**标量约束总数**：$m$（上分式）$+m$（下分式）$+m$（$a_i^{T}x\ge0$）$+n$（$u-x$）$+n$（$x-l$），共 $3m+2n$。对偶间隙 $(3m+2n)/t$ 是 barrier method 唯一免费的精度证书，所以这个数**必须与约束条数一致**；任何一处漏算（例如把 $a_i^{T}x\ge0$ 当隐含约束不计数）都会让停止准则提前触发。$m=100,n=10$ 时漏掉 $m$ 项就是少算 $3m+2n=320$ 里的 $100$，精度虚报 31%。

**消失测试**：没有第一条 `while`，barrier 会在某步把 $s-y$ 或 $sy-1$ 变成负数，`log` 返回复数；MATLAB 不报错，后续全是 NaN——这是 barrier 方法「静默失败」的典型形态。有了它，每次试探退回可行域内部，代价只是多算几次函数值。

**落点**：Boyd §11.3.2（backtracking 的两个条件与顺序）、§11.3.3（$m/t$ 与约束计数）、§9.2（self-concordant 情形的步长下界）；挂 CSAPP 的「NaN 会静默传播，只有主动检查才能发现」。</span>

### Exercise 11.22 · Maximum volume rectangle inside a polyhedron（多面体内最大体积长方体）

> 话题摘要：求 $R=\{x\mid l\preceq x\preceq u\}$ 落在 $P=\{x\mid Ax\preceq b\}$ 内且体积最大；写成对 $(l,u)$ 的凸问题后体积目标变成 $-\sum\log(u_i-l_i)$，线性约束用 $A^{+}u-A^{-}l\preceq b$ 表示，配 barrier 与 MATLAB 实现。

**Maximum volume rectangle inside a polyhedron.** Consider the problem described in exercise 8.16, i.e., finding the maximum volume rectangle $R=\{x\mid l\preceq x\preceq u\}$ that lies in a polyhedron described by a set of linear inequalities, $P=\{x\mid Ax\preceq b\}$. Implement a barrier method for solving this problem. You can assume that $b\succ0$, which means that for small $l\prec0$ and $u\succ0$, the rectangle $R$ lies inside $P$.

Test your implementation on several simple examples. Find the maximum volume rectangle that lies in the polyhedron defined by

```math
A=\begin{bmatrix}0&-1\\ 2&-4\\ 2&1\\ -4&4\\ -4&0\end{bmatrix},\qquad b=\mathbf{1}.
```

Plot this polyhedron, and the maximum volume rectangle that lies inside it.

**Solution.** 采用 exercise 8.16 推出的形式

```math
\begin{array}{ll}
\text{minimize} & -\sum_{i=1}^{n}\log(u_i-l_i)\\
\text{subject to} & A^{+}u-A^{-}l\preceq b,
\end{array}
```

（隐含约束 $u\succ l$）。这里 $a^{+}_{ij}=\max\{a_{ij},0\}$，$a^{-}_{ij}=\max\{-a_{ij},0\}$。

函数

```math
\psi(l,u)=-t\sum_{i=1}^{n}\log(u_i-l_i)-\sum_{i=1}^{m}\log\bigl((b-A^{+}u+A^{-}l)_i\bigr)
```

的梯度与 Hessian 是

```math
\nabla\psi(l,u)=t\begin{bmatrix} \mathbf{1}\\ -\mathbf{1}\end{bmatrix}\mathbf{diag}(u-l)^{-1}\mathbf{1}+\begin{bmatrix} -A^{-T}\\ A^{+T}\end{bmatrix}\mathbf{diag}\bigl(b-A^{+}u+A^{-}l\bigr)^{-1}\mathbf{1},
```

```math
\begin{aligned}
\nabla^2\psi(l,u) &= t\begin{bmatrix} I\\ -I\end{bmatrix}\mathbf{diag}(u-l)^{-2}\begin{bmatrix} I & -I\end{bmatrix}\\
&\qquad +\begin{bmatrix} -A^{-T}\\ A^{+T}\end{bmatrix}\mathbf{diag}\bigl(b-A^{+}u+A^{-}l\bigr)^{-2}\begin{bmatrix} -A^{-} & A^{+}\end{bmatrix}.
\end{aligned}
```


<span style="color:#d35400;">**† 原文错误（本页第 1 处，形状判死）**：$\psi$ 的第二项求和上界写成 $\sum_{i=1}^{n}$，**应为 $\sum_{i=1}^{m}$**。$b-A^{+}u+A^{-}l\in\mathbf{R}^{m}$（$A\in\mathbf{R}^{m\times n}$、$b\in\mathbf{R}^{m}$），下标 $i$ 只在 $1..m$ 上有定义。

**形状反例（本题例题自带）**：题给的 $A$ 是 $5\times2$，故 $m=5$、$n=2$。$\sum_{i=1}^{2}\log\bigl((b-A^{+}u+A^{-}l)_i\bigr)$ 只保护 5 条线性约束中的 2 条，另外 3 条**完全没有 barrier**，迭代可随意越界——不报错，只给出一个 $P$ 之外的长方体。同页 $\nabla\psi$ 与 $\nabla^{2}\psi$ 里的 $\mathbf{diag}(b-A^{+}u+A^{-}l)$ 是 $m\times m$ 的，与 $\sum_{i=1}^{n}$ 自相矛盾：**同页三处两两冲突**。

**为什么会写错**：$\psi$ 第一项 $\sum_{i=1}^{n}\log(u_i-l_i)$ 是 $n$ 项（变量 $l,u$ 是 $n$ 维），写第二项时把求和上界顺手复制成了 $n$——**哑指标与哑上界一起被复制**，与 p288 那条 $m/\tilde{m}$ 的错误同源。

**同源的第二处错（在代码里）**：下面的 MATLAB 实现写 `gap = (2*m)/t`，而本题标量约束总数是 $n$（$u_i\gt l_i$）$+\,m$（$Ax\preceq b$），应为 $(n+m)/t$。以本题例题为反例：$n+m=7$，代码给 $2m=10$，**虚报 43%**；若换 $m=2,n=100$ 的实例，代码给 $4$ 而真实 $102$，**低估 25 倍**，停止准则提前触发。对照证据就在同一块：11.21 的代码写 `gap = (3*m+2*n)/t`，与那里 $3m+2n$ 条约束严格对应，说明作者知道规则，这里只是数错。

一维验算：$n=m=1$、$A=[1]$、$b=[1]$，约束为 $u\le1$ 与 $-l\le1$（由 $A^{+}u-A^{-}l\le1$），加 $u\gt l$ 共 3 条；$n+m=2$、$2m=2$——两种写法在此**恰好相同**，这就是漏数在最小例子上隐形的机制。

<span style="color:#1e8449;">**[译注]** 这两处错（求和上界 $n$ 与 gap 的 $2m$）其实是**同一个错误的两个投影**，所以在审计时应当一起修：$\psi$ 的项数与 gap 的因子都来自「约束条数」这一个量。写成可检查的形式：本题的约束清单是

```math
\underbrace{(u_i-l_i)\gt0}_{n\ \text{条}}+\underbrace{(b-A^{+}u+A^{-}l)_i\gt0}_{m\ \text{条}},
```

于是 barrier 必须恰好有 $n+m$ 个 $\log$、gap 必须是 $(n+m)/t$。**「$\psi$ 里 $\log$ 的个数 = gap 分子的数值」是这两处可以互校的不变量**，任何实现都可以用一行断言自检：`assert(length(find(obj_str=='-') ) ...)` 之类，或干脆把约束数当参数传进去。

**量的方向感**：本题例题 $n+m=7$ vs $2m=10$，误差 43%；$m\ll n$ 的实例（例如 $2$ 条约束、$100$ 维变量）误差方向反转成 25 倍的低估。所以这个错误**既可能让停止过早也可能过晚**，取决于 $m/n$，无法凭经验猜方向——只能靠数。

**消失测试**：没有「约束条数 = gap 分子」这条不变量，你只能在结果异常时回头再数一遍约束；有了它，可以在代码里直接断言，把静默错误变成崩溃。

**落点**：Boyd §11.3.3（对偶间隙与约束计数）、exercise 8.16（本题的 formulation 来源）、p295（11.21 的 `(3*m+2*n)` 代码对照）；挂 CSAPP 的「用断言把不变量写进代码」。</span>

> 页眉：`Exercises`。本页是 11.22 的 MATLAB 实现、多面体示意图，以及 11.23 的题干。

11.22 的 MATLAB 实现如下。

```matlab
MAXITERS = 200;
ALPHA = 0.01;
BETA = 0.5;
NTTOL = 1e-8;   % terminate Newton iterations if lambda^2 < NTTOL
MU = 20;
TOL = 1e-4;     % terminate if duality gap less than TOL
```

```matlab
Ap = max(A,0);  Am = max(-A,0);
r = max(Ap*ones(n,1) + Am*ones(n,1));
u = (.5/r)*ones(n,1);  l = -(.5/r)*ones(n,1);
t = 1;
for iter = 1:MAXITERS
   y = b+Am*l-Ap*u;
   val = -t*sum(log(u-l)) - sum(log(y));
   grad = t*[1./(u-l); -1./(u-l)] + [-Am'; Ap']*(1./y);
   hess = t*[diag(1./(u-l).^2), -diag(1./(u-l).^2);
             -diag(1./(u-l).^2),  diag(1./(u-l).^2)]  + ...
          [-Am'; Ap']*diag(1./y.^2)*[-Am Ap];
   step = -hess\grad;  fprime = grad'*step;
   if (abs(fprime) < NTTOL),
      gap = (2*m)/t;
      disp(['iter ', int2str(iter), '; gap = ', num2str(gap)]);
      if (gap<TOL); break; end;
      t = MU*t;
   else
      dl = step(1:n);  du = step(n+[1:n]);   dy = Am*dl-Ap*du;
      tls = 1;
      while (min([u-l+tls*(du-dl); y+tls*dy]) <= 0)
         tls = BETA*tls;
      end;
      while (-t*sum(log(u-l+tls*(du-dl))) - sum(log(y+tls*dy)) >= ...
             val + tls*ALPHA*fprime),
         tls = BETA*tls;
      end;
      l = l+tls*dl;  u = u+tls*du;
   end;
end;
```

[Figure 8：$A=\begin{bmatrix}0&-1\\2&-4\\2&1\\-4&4\\-4&0\end{bmatrix}$、$b=\mathbf{1}$ 所定义的多面体 $P$（$x_1,x_2\in[-0.5,0.5]$）与其中最大体积轴对齐长方体。多边形由五条直线 $2x_1-4x_2\le1$、$2x_1+x_2\le1$、$-4x_1+4x_2\le1$、$-4x_1\le1$、$-x_2\le1$ 围成；虚线矩形是两个方向都接近 $[-0.25,0.25]$ 量级的最大内接长方体，其左边界贴着 $-4x_1\le1$ 那条边、右边界被 $2x_1+x_2\le1$ 卡住。]

<span style="color:#1e8449;">**[译注]** 这段代码里有一个**必须照抄的初始化技巧**：`r = max(Ap*ones(n,1) + Am*ones(n,1))`、`u = (.5/r)*ones(n,1)`、`l = -(.5/r)*ones(n,1)`。它保证 $A^{+}u-A^{-}l\preceq b$ 严格成立：代入得 $A^{+}u-A^{-}l=\frac{1}{2r}\bigl(A^{+}\mathbf{1}+A^{-}\mathbf{1}\bigr)=\frac{1}{2r}|A|\mathbf{1}$，而 $r=\max_i\bigl(|A|\mathbf{1}\bigr)_i$ 是逐行绝对值之和的最大值，于是每个分量 $\le\frac{1}{2}\lt b_i$（题设 $b=\mathbf{1}$）。

**落点**：Boyd §11.4（barrier method 的严格可行初始化）、exercise 8.16（本题 formulation）、§11.3.2（$\mathbf{diag}$ 与矩阵-向量积的实现）；挂 CSAPP 的「浮点比较要留余量：`>= 0` 与 `> 0` 在边界上等价，迭代中不等价」。</span>

> 话题摘要：对 $\min x^{T}Wx$、$x_i^{2}=1$ 的划分问题取 Lagrange 对偶得 SDP，解出下界 $d^\star\le p^\star$；再用「最大特征向量取符号」「$X^\star$ 的 Gaussian 采样取符号」「贪心翻符号」三种启发式找上界，把 $p^\star$ 夹进区间。

**SDP bounds and heuristics for the two-way partitioning problem.** In this exercise we consider the two-way partitioning problem (5.7), described on page 219, and also in exercise 5.39:

```math

\text{minimize} & x^{T}Wx\\
\text{subject to} & x_i^{2}=1,\qquad i=1,\dots,n,
\end{array}
```

with variable $x\in\mathbf{R}^{n}$. We assume, without loss of generality, that $W\in\mathbf{S}^{n}$ satisfies $W_{ii}=0$. We denote the optimal value of the partitioning problem as $p^\star$, and $x^\star$ will denote an optimal partition. (Note that $-x^\star$ is also an optimal partition.)

with variable $X\in\mathbf{S}^{n}$. (This SDP can be interpreted as a relaxation of the two-way partitioning problem; see exercise 5.39.) The optimal values of these two SDPs are equal, and give a lower bound, which we denote $d^\star$, on the optimal value $p^\star$. Let $\nu^\star$ and $X^\star$ denote optimal points for the two SDPs.

**(a)** 我们对 SDP (11.66) 实现 barrier method。问题中唯一的约束是 LMI $W+\mathbf{diag}(\nu)\succeq0$，对它使用 log barrier $-\log\det\bigl(W+\mathbf{diag}(\nu)\bigr)$。启动 barrier method 需要严格可行点，而这里很容易找到：若 $\lambda_{\min}(W)$ 是 $W$ 的最小特征值，则 $W+\bigl(-\lambda_{\min}(W)+1\bigr)I$ 的最小特征值为 $1$，故正定。因此

是严格可行起点。

每个外层迭代用 Newton 法极小化

```math
f(\nu)=t\,\mathbf{1}^{T}\nu-\log\det\bigl(W+\mathbf{diag}(\nu)\bigr).
```

可以从 $t=1$ 开始，每个外层迭代结束时把 $t$ 乘以因子 $\mu=10$（比如），直到达到所需精度。每次迭代结束时的对偶间隙恰为 $n/t$，对偶可行点为

```math
Z=\frac{n}{t}\bigl(W+\mathbf{diag}(\nu)\bigr)^{-1}.
```

我们在第一次满足 $n/t\le\epsilon$ 的外层迭代结束时返回 $\nu$ 与 $Z$，其中 $\epsilon$ 是要求的容差。

<span style="color:#d35400;">**† 原文错误（本页第 1 处）**：对偶可行点应为

```math
X=\frac{1}{t}\bigl(W+\mathbf{diag}(\nu)\bigr)^{-1},
```

**原文的分子 $n$ 应为 $1$**。理由是硬的：中心路径上的最优点满足 $\nabla f(\nu)=t\mathbf{1}-\mathbf{diag}\bigl(Z^{-1}\bigr)=0$（记 $Z=W+\mathbf{diag}(\nu)$），即 $\bigl(Z^{-1}\bigr)_{ii}=t$ 对每个 $i$ 成立；把 $X=\frac{1}{t}Z^{-1}$ 代回得 $X_{ii}=\frac{1}{t}\cdot t=1$，正是 (11.67) 的等式约束。原文的 $X=\frac{n}{t}Z^{-1}$ 给出 $X_{ii}=n$，**违反 $X_{ii}=1$，根本不是可行点**。

**可手算反例**：取 $n=2$、$W=\begin{bmatrix}0&1\\1&0\end{bmatrix}$、$t=1$。由 $\bigl(Z^{-1}\bigr)_{11}=\bigl(Z^{-1}\bigr)_{22}=1$ 得 $\nu_1=\nu_2=\nu$ 且 $\nu/(\nu^{2}-1)=1$，即 $\nu^{2}-\nu-1=0$，$\nu=\frac{1+\sqrt5}{2}\approx1.618$（于是 $\nu^{2}-1=\nu$，$Z^{-1}=\begin{bmatrix}1&-1/\nu\\-1/\nu&1\end{bmatrix}=\begin{bmatrix}1&-0.618\\-0.618&1\end{bmatrix}$）。正确点对角元为 $1$ ✓；原文点 $X=2Z^{-1}$ 对角元为 $2$ ✗。

**间隙验算**：正确点给 $\operatorname{\mathbf{tr}}(WX)=2\cdot1\cdot(-0.618)=-1.236$，而 $-\mathbf{1}^{T}\nu=-2\nu=-3.236$，间隙 $=-1.236+3.236=2=n/t$ ✓；原文点给 $\operatorname{\mathbf{tr}}(WX)=-2.472$，间隙 $0.764$，既不等于 $n/t$、也不对应任何可行解。

**为什么会写错**：把「$X_{ii}=1$ 共 $n$ 条等式约束」这个**计数**误当成了**归一化因子**。SDP 的标准推导（$\operatorname{\mathbf{tr}}(A_iX)=b_i$ 情形下 $X=\frac1t Z^{-1}$ 配 $b_i=1$）本来没有这个 $n$；多乘一个「约束条数」之后，$n=1$ 时 $n/t=1/t$，**错误完全隐形**。

<span style="color:#1e8449;">**[译注]** 这条 † 值得单列，因为它演示了 SDP barrier 里「**归一化因子与约束计数是两个不同的量**」。把三件事分开记：① 中心路径条件 $\bigl(Z^{-1}\bigr)_{ii}=t$ 来自 $\partial f/\partial\nu_i=0$，是**逐分量**的；② primal 点 $X=\frac1t Z^{-1}$ 是**唯一**满足 $X_{ii}=1$ 的选择；③ 对偶间隙 $=n/t$ 里的 $n$ 来自 $\operatorname{\mathbf{tr}}(XZ)=\operatorname{\mathbf{tr}}(I)=n$。三者各含一个 $n$ 或 $1$，混淆任意两个都会破坏可行性，而**代码不会报错**——$X$ 仍正定、仍能算 $\operatorname{\mathbf{tr}}(WX)$，只是那个数不再是下界。

```math
\nabla g(X)=X^{-1}.
```

用链式法则，取

```math
X=W+\mathbf{diag}(\nu)=W+\sum_{i=1}^{n}\nu_iE_{ii},
```

其中 $E_{ii}$ 是 $(i,i)$ 元为 $1$、其余为零的矩阵，得到

```math
\nabla f(\nu)_i=t-\operatorname{\mathbf{tr}}\bigl((W+\mathbf{diag}(\nu))^{-1}E_{ii}\bigr)=t-\bigl((W+\mathbf{diag}(\nu))^{-1}\bigr)_{ii}
```

对 $i=1,\dots,n$ 成立。因此有极简公式

```math
\nabla f(\nu)=t\mathbf{1}-\mathbf{diag}\bigl((W+\mathbf{diag}(\nu))^{-1}\bigr).
```

$\log\det X$ 在 $X\in\mathbf{S}^{n}_{++}$ 处的二阶导由双线性形式给出：

```math
\nabla^{2}g(X)[Y,Z]=-\operatorname{\mathbf{tr}}\bigl(X^{-1}YX^{-1}Z\bigr).
```

把它用在我的函数上（$X=W+\mathbf{diag}(\nu)$）：

```math
\nabla^{2}f(\nu)_{ij}=\operatorname{\mathbf{tr}}\bigl(X^{-1}E_{ii}X^{-1}E_{jj}\bigr)=\bigl(X^{-1}\bigr)_{ij}^{2}
```

对 $i,j=1,\dots,n$ 成立。于是 Hessian 有极简公式

```math
\nabla^{2}f(\nu)=\bigl(W+\mathbf{diag}(\nu)\bigr)^{-1}\circ\bigl(W+\mathbf{diag}(\nu)\bigr)^{-1},
```

其中对 $U,V\in\mathbf{S}^{n}$，$U$ 与 $V$ 的 Schur（也叫 Hadamard、逐元）积 $W=U\circ V$ 定义为 $W_{ij}=U_{ij}V_{ij}$。

<span style="color:#1e8449;">**[译注]** 这里两个「极简公式」之所以能成立，全靠 $E_{ii}$ 是最稀疏的对称矩阵：$\operatorname{\mathbf{tr}}(X^{-1}E_{ii})=(X^{-1})_{ii}$、$\operatorname{\mathbf{tr}}(X^{-1}E_{ii}X^{-1}E_{jj})=(X^{-1})_{ij}^{2}$，把矩阵微分的通式一步压成了取元素。这也解释了为什么 SDP 的 barrier method 在**对角扰动**（$\mathbf{diag}(\nu)$）这类结构上是可算的：若约束是 $W+\sum_k \nu_kA_k\succeq0$ 且 $A_k$ 稠密，则 $\nabla^{2}f$ 的元素是 $\operatorname{\mathbf{tr}}(X^{-1}A_iX^{-1}A_j)$，需要 $p$ 次 $n\times n$ 的矩阵乘，**代价从 $O(n^{3})$ 跳到 $O(pn^{3})$**。

**量的方向感**：$\nabla^{2}f=Z^{-1}\circ Z^{-1}$ 是 Schur 积，它的条件数与 $Z^{-1}$ 的条件数**成平方**：$\kappa(\nabla^{2}f)\approx\kappa(Z^{-1})^{2}$。这就是 SDP barrier 在末期数值难做的根本原因——当 $Z$ 接近奇异（最优解在低秩边界上）时，条件数按平方恶化。$n=100$ 时若 $\kappa(Z)=10^{4}$，则 $\kappa(\nabla^{2}f)\approx10^{8}$，双精度只剩 $8$ 位有效数字。

**消失测试**：不知道 $\nabla^{2}f$ 是 Schur 积，就无法解释「为什么 SDP 在 $t$ 大时 Newton 步方向变差、需要更精确的线性代数」；你会把问题归咎于「$\mu$ 太大」，而实际上 $\mu$ 只通过 $t$ 影响 $Z$ 的谱，根子在平方条件数。
