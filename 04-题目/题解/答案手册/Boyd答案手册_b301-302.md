<span style="color:#1e8449;">**[译注]** 这两张图必须并读，因为它们的**收敛阶不同**，而这正是 primal-dual 方法优于 barrier 的地方。图 12 的 $\hat{\eta}$ 是 surrogate gap，它按定义每步只缩一个常数因子：代码里 `tinv = gap/(m*MU)` 把中心化目标设成 $s_{i}z_{i}=\hat{\eta}/(\mu m)$，于是下一次实测的 $\hat{\eta}$ 至多是本次的 $1/\mu = 1/10$——**线性收敛**，斜率被 $\mu$ 钉死。图 13 的 $\|r_{\text{dual}}\|_{2}$ 则走 Newton 的**二次收敛**，一旦步长 `step` 首次达到 $1$（$z$ 侧正性不再限制），残差一步从 $2.5\times10^{-1}$ 掉到 $10^{-14}$，即一步跨 $13$ 个 decade。

### 11.24 解答（续）· barrier 代码收尾与 primal-dual 代码

```matlab
      gap = m/t;

      t = MU*t;
   end;
end;
```

这段收尾把 barrier method 的**两级循环**显式写明：只有 centering 收敛（`-fprime` 即 Newton decrement 的平方小于 `NTTOL`）时才计算 `gap = m/t` 并检查停止准则 `gap < TOL`，否则继续在当前 $t$ 下做 Newton 步；未达 `TOL` 则 `t = MU*t` 进入下一次外迭代。$t$ 只在 centering 之后放大，是 barrier method 与「固定 $t$ 直接求解」的分水岭。

下面给出 primal-dual method 的 Matlab 代码。

```matlab
MAXITERS = 200;
TOL = 1e-6;
RESTOL = 1e-8;
MU = 10;
ALPHA = 0.01;
BETA = 0.5;
x = zeros(n,1);  s = b-A*x;  z = 1./s;
for iters = 1:MAXITERS
   gap = s'*z;   res = P*x + q + A'*z ;
   if ((gap < TOL) & (norm(res) < RESTOL)), break; end;
   tinv = gap/(m*MU);
   sol = -[ P     A';  A   diag(-s./z) ] \ ...
          [ P*x+q+A'*z;  -s + tinv*(1./z) ];
   dx = sol(1:n);  dz = sol(n+[1:m]);  ds = -A*dx;
   r = [P*x+q+A'*z;  z.*s-tinv];
   step = min(1.0, 0.99/max(-dz./z));
   while (min(s+step*ds) <= 0),  step = BETA*step;  end;
   newz = z+step*dz;  newx = x+step*dx;  news = s+step*ds;
   newr = [P*newx+q+A'*newz;  newz.*news-tinv];
   while (norm(newr) > (1-ALPHA*step)*norm(r))
      step = BETA*step;
      newz = z+step*dz;  newx = x+step*dx;  news = s+step*ds;
      newr = [P*newx+q+A'*newz;  newz.*news-tinv];
   end;
   x = x+step*dx;  z = z +step*dz;  s = b-A*x;
end;
```

注意 `x = zeros(n,1);  s = b-A*x;  z = 1./s;` 这一行：它把初始点钉成 $x^{(0)}=0$，于是 $s^{(0)}=b$、$z^{(0)}=1./b$。这与上一页文本给的 $\lambda^{(0)}_{i}=1/b_{i}$ 逐字吻合，却与同一句里写的 $x^{(0)}=1$ † 直接冲突。冲突的判定见本节附录 A。

<span style="color:#1e8449;">**[译注]** 这套 Newton 系统是全块唯一不能靠「看代码猜」的部分，逐块推一遍才知道它为什么长这样。KKT 是

```math
Px+q+A^{\top}z=0,\qquad Ax+s=b,\qquad s_{i}z_{i}=1/t,
```

三式各取残差 $r_{\text{dual}}=Px+q+A^{\top}z$、$r_{\text{prim}}=Ax+s-b$、$r_{\text{cent}}=\operatorname{diag}(s)z-\text{tinv}\cdot\mathbf{1}$，其中 $\text{tinv}=1/t_{\text{new}}$。代码每步都用 `s = b-A*x` 重算，故 $r_{\text{prim}}\equiv0$、$ds=-A\,dx$。代进第三式的线性化：

```math
\operatorname{diag}(z)\,ds+\operatorname{diag}(s)\,dz=-r_{\text{cent}}
\ \Longrightarrow\ -A\,dx+\operatorname{diag}(s/z)dz=-s+\text{tinv}/z,
```

两项同乘 $-1$ 就是代码里的 `A*dx + diag(-s./z)*dz = s - tinv./z`，再配上前一行的负号 `sol = -M \ rhs` 完全对上。

为什么 $\text{tinv}$ 取 $\hat{\eta}/(m\mu)$ 而不是 $\hat{\eta}/m$：目标 $s_{i}z_{i}=\text{tinv}$ 一旦成立，就有 $\hat{\eta}=m\,\text{tinv}$，于是「这一步把 $t$ 放大几倍」等价于「把 $\hat{\eta}$ 缩小几倍」。取 $\text{tinv}=\hat{\eta}/(m\mu)$ 即一步缩 $\mu=10$ 倍，这正好是 predictor-corrector 里的 centering parameter $\sigma=1/\mu=0.1$。取 $\sigma=1$（纯 Newton 步）会把 $z$ 直推到 $s$ 的边界上，下一步被 $0.99$ 的最大步长因子砍掉大半；取 $\sigma=0.1$ 是标准折中，代价是每次外迭代多花几步 centering。

**数值反例**：把 `diag(-s./z)` 误写成 `diag(-z./s)`，在 $s=1$、$z=100$ 处两块相差 $(100)^{2}=10^{4}$ 倍，Newton 方向整体歪掉，残差不再二次收敛——图 13 那条 13 个 decade 的陡崖就不会出现。

**量的方向感**：$s$ 与 $z$ 的量级差会随迭代翻转——初始 $s=b$、$z=1/b$，若 $b$ 的分量量级为 $10$ 则 $s/z\approx10^{2}$，比值写反就错 $10^{4}$ 倍；到终止时 $s_{i}z_{i}\approx\hat{\eta}/m\approx10^{-9}$ 附近，两侧已同量级，写反反而看不出。**错得最狠的地方在开头几步，最看不出错的地方在末尾**，这正是这类比值错必须靠推导而不是靠跑通来定案的原因。

**落点**：Boyd §11.7.1（primal-dual 的 Newton 系统）、§10.3（KKT 条件的线性化）、§4.4（KKT 与中心路径）；线代侧挂 Strang 的块矩阵消元。</span>

## 附录 A · 原文错误清单（本块标 `†` 的 1 条）

### †1 · p301（`Exercise 11.24` 解答）primal-dual 的初值 $x^{(0)}=1$ 与同页代码、同句 $\lambda^{(0)}$ 三方冲突，应为 $x^{(0)}=0$

- **错在哪**：p301 正文写 `We use µ = 10, α = 0.01, β = 0.5, x(0) = 1, and λ(0)i = 1/bi.`（已按 $500$ dpi 渲染核对，字形是 `1`，不是文本层误读）。但 p302 的 primal-dual 代码首行是 `x = zeros(n,1);  s = b-A*x;  z = 1./s;`，即 $x^{(0)}=0$、$s^{(0)}=b$、$z^{(0)}=1/b$。
- **正确式子**：$x^{(0)}=0$（$n$ 维零向量），从而 $s^{(0)}=b$、$z^{(0)}_{i}=1/b_{i}$，$\hat{\eta}(0)=\sum_{i=1}^{m}s_{i}z_{i}=m$。
- **三方互校**：① 代码 `zeros(n,1)`；② 同句 $\lambda^{(0)}_{i}=1/b_{i}$ 只有在 $s^{(0)}=b$ 时才与 $z=1./s$ 自洽；③ p300 明写 `We choose b ≻ 0`——只有在 $x^{(0)}=0$ 时 $b\succ0$ 才**足以**保证严格可行，若 $x^{(0)}=\mathbf{1}$ 还需逐分量追加条件 $b_{i}\gt (A\mathbf{1})_{i}$，而原文没有给这条。
- **数值反例**：取 $n=m=1$、$A=1$、$b=1$。$x^{(0)}=0$ 时 $s^{(0)}=1$、$z^{(0)}=1$、$\hat{\eta}(0)=1=m$，与中心化参数 $t^{(0)}=1$ 的中心条件 $s_{i}z_{i}=1$ 精确相符；$x^{(0)}=1$ 时 $s^{(0)}=b-Ax^{(0)}=0$，$z=1./s$ 立刻得 `Inf`，第一次 `s'*z` 就是 `NaN`。换 $b=3$ 同理：$x^{(0)}=1$ 得 $s^{(0)}=2$，若仍用 $\lambda^{(0)}=1/b=1/3$ 则 $s_{1}z_{1}=2/3\neq1$，初始点不在 $t^{(0)}=1$ 的中心路径邻域，第一步 `tinv` 与残差 $z.*s-\text{tinv}$ 不相容。
- **图 12 佐证**：图上首点 $\hat{\eta}\approx2\times10^{2}=m$，与 $x^{(0)}=0$ 推出的 $\hat{\eta}(0)=m$ 精确一致。
- **为什么写错**：p300 的 barrier 段刚写完 `and use x(0) = 0`，作者转写 primal-dual 段时想强调「换了初始点」，手改成 $1$ 却没同步改代码与 $\lambda^{(0)}_{i}$。$n=m$ 且取小规模的算例里 $s^{(0)}$ 仍为正，程序不一定立刻报错，只是初始点偏离中心路径，**静默降低前几步的下降率**——图 12 中段那 $5$ 步走平（$\hat{\eta}:0.5\to0.3$）正好是这类「初值不在中心邻域」的典型形状。
